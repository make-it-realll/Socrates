从进度块恢复

先看四件事。每一件你都会做，但多半说不出自己是怎么做到的。

第一件。 Cats 的结尾读 [s]，dogs 读 [z]，brushes 读 [əz]。没有人教过这条规律，母语者却从不出错；给小孩看一个从没见过的东西，告诉他“This is a wug”，再给他看两个，他会说 wugs，结尾是 [z]。

第二件。 I shot an elephant in my pajamas 有两个意思：穿着睡衣的是我，或者是大象。每个词的意思都没变，变的是词和词怎么组合。

第三件。 同学说“Some of the students passed”，你会听出“不是所有人都过了”。可是如果他接着说“in fact, all of them did”，你不会觉得他自相矛盾。

第四件。 你好 两个字单独念都是 third tone，连起来念，第一个字变成了 second tone。说 Mandarin 的人都这样念，几乎没有人意识到。

这门课把这类说不出来、却一直在用的知识当作研究对象：它是一套 rule，可以写下来，可以拿新的 data 去检验，写错了会被 data 推翻。研究的层次从小到大：先是 sound（第 2、3 站），然后是 word 的内部结构（第 4 站）、word 组成 sentence 的方式（第 5 站），再是 meaning（第 6 站）和 meaning 在 context 里怎么被使用（第 7 站），最后看 language 和 mind、society 的关系（第 8 站）。第 1 站先讲清楚这些 rule 是什么样的 hypothesis、用什么 data 检验。上面四件事分别在第 3、5、7、3 站得到解释。

两种 rule

学校教过一条 rule：句子不要以 preposition 结尾。对照一下母语者实际怎么说：

  • Who are you talking to?
  • I put the sweater on. / I put on the sweater. / I put it on. / *I put on it.

第一句以 to 结尾，完全自然，说“To whom are you talking?”反而显得做作。第二组里，星号（*）表示母语者判断这句不能说。四句话的意思相同，只有最后一句不行，而它并没有以 preposition 结尾。

所以有两种完全不同的 rule。学校教的那种叫 prescriptive rule，规定人“应该”怎么说。这门课研究的叫 descriptive rule：母语者脑子里实际有、却说不出来的那套规律。上面的 data 指向的 descriptive rule 大致是：put on 这种 verb 加 particle 的组合，object 是 pronoun 时必须放在 particle 前面。没有人教过这条，所有人都遵守。

一条 descriptive rule 是一个 hypothesis，它对没见过的句子做出预测。拿这条 rule 去测 24.900 第 1 讲的一对句子：

  • John walked up the stairs.
  • Mary looked up the reference.

两句的 category 序列一样，都是 N V P D N。把 object 换成 it：John walked up it 可以说，*Mary looked up it 不行，要说 Mary looked it up。Rule 预测：looked up 里的 up 是 particle，walked up 里的 up 不是。还有两个独立的 test 给出同样的结论：

test John walked up the stairs Mary looked up the reference
单独回答 Up the stairs?! *Up the reference?!
提问 Up which stairs did John walk? *Up which reference did Mary look?
并列 John walked up the stairs and up the hill. *Mary looked up the reference and up the vocabulary words.

三个 test 都说明 up the stairs 是一个单位，up the reference 不是。同样的词、同样的顺序，内部结构不同。这一点第 5 站会展开。

Grammatical 和 meaningful 是两回事

24.900 第 11 讲用了三组对比：

  • We're going to class.（熟悉）
  • My anteater is hula dancing.（陌生，但能说）
  • *We're class going to.（不能说）

第三句的意思谁都猜得出来，它的问题不在 meaning。反过来，Chomsky 的 Colorless green ideas sleep furiously 没有意义（green 的东西不会 colorless，idea 不会 sleep），母语者却判断它的形式没问题；把词倒过来，*Furiously sleep ideas green colorless，就连形式也坏了。

这说明母语者的判断里有一部分只关于形式，和 meaning 无关。这种判断叫 grammaticality judgment，是 syntax 最主要的 data。星号的意思是“母语者判断不能这样说”，和“不合 prescriptive rule”“听起来不礼貌”“意思荒谬”都不是一回事。

看起来对，其实不对母语者最清楚自己语言的 rule，问他就行

母语者给出的 judgment 是可靠的 data，但他对 rule 的陈述往往是错的。上面的母语者会告诉你“不要以 preposition 结尾”，这条 rule 被他自己的 judgment 推翻；而他真正遵守的 particle rule，他说不出来。所以 linguist 收集的是 judgment（这句能不能说、这两句意思是否相同），rule 由 linguist 根据 judgment 去推，母语者只负责当 data 的来源。

从 data 到 rule：一次 fieldwork

24.900 第 2 讲用一种虚构的 Martian 语言演示 fieldwork 怎么做。Consultant 给出这些形式：

肯定 否定
digdug 'dug' digwedug 'didn't dig'
gudgid 'is digging' gudwegid 'isn't digging'
bii 'is' noowee 'isn't'

前两行里否定都多了 we。它插在哪里？至少有三个 hypothesis 都和这两行吻合：

  • H1：插在第一个 syllable 之后（dig-we-dug，gud-we-gid）。
  • H2：插在前三个字母之后。
  • H3：插在最后一个 syllable 之前。

只有两行 data 时三者无法区分，所以要去找能把它们分开的词。Consultant 又给了两个 verb 的 negative form，先算出三个 hypothesis 各自的预测：

肯定 H1 预测 H2 预测 H3 预测 consultant 实际说
yodeleehihuu yo-we-deleehihuu yod-we-eleehihuu yodeleehi-we-huu yowedeleehihuu
munchmunchyum munch-we-munchyum mun-we-chmunchyum munchmunch-we-yum munchwemunchyum

只有 H1 两次都对。bii 和 noowee 不符合任何一个 hypothesis，处理办法是把它记成一个例外，单独存进词库，就像 English 的 go 和 went。

这个过程就是整门课的方法：data 给出若干 hypothesis，挑一个能让它们给出不同预测的例子去测，留下预测对了的那个；无法规则化的部分单独记下。挑例子这一步最关键：如果只是再找像 digdug 那样由两个三字母 syllable 组成的词，测多少次都分不开 H1、H2、H3。

Competence 与 performance

24.900 第 11 讲给出一串句子：

  • It's raining.
  • John thinks that it's raining.
  • Mary thinks that John thinks that it's raining.

每次都能在前面再套一层“X thinks that”。没有哪一层之后 rule 突然不允许继续，所以 grammar 能生成无穷多个句子。但没有人能说出无穷长的句子，也没有人记得住二十层的嵌套。这两件事分开叫：grammar 本身允许什么，叫 competence；人在有限的 memory 和时间里实际能说出、听懂什么，叫 performance。

这个区分最尖锐的例子是 center embedding。English 允许 relative clause 不带 that，直接跟在 noun 后面：the rat the cat killed（猫杀死的那只老鼠）。把这条 rule 用三次：

The rat the cat the dog chased killed ate the malt.

每一步都合乎 rule，整句却几乎没法懂。意思相同的 right-branching 版本 The dog chased the cat that killed the rat that ate the malt 却毫不费力。

看图上的 dependency：第一句是 nested 的，第二句一条接一条。Nested 的 dependency 要求听者同时记住所有还没配对的 subject，层数一多，memory 先撑不住。所以第一句难懂是 performance 的问题；把它判为“不合 grammar”反而说不通，因为每一层用的都是那条合法的 rule。

可以跳过吗

下面这一小节把 center embedding 和 automata theory 接起来。跳过它会少掉“为什么 English 的 grammar 不能是 finite-state 的”这个论证。

Center embedding 超出 finite-state machine 的能力

把 center embedding 抽象成形式：先来 nnn 个 noun，再来 nnn 个 verb，数目必须相等，记作 NnVnN^nV^nNnVn。设有一个 finite-state machine 能恰好接受所有这样的 string，它有 kkk 个 state。

  • 因为 NiViN^iV^iNiVi 应该被接受，从这个 state 读完 ViV^iVi 会到达 accepting state。
  • NjN^jNj 也停在这个 state，所以 NjViN^jV^iNjVi 同样会被接受。

但 j≠ij\ne ij=i，NjViN^jV^iNjVi 的数目不相等，不该被接受。矛盾。所以没有 finite-state machine 能识别任意深度的 center embedding，需要 context-free grammar 这一级（它可以写 S→N S VS\to N\,S\,VS→NSV 这样的 rule）。

这个论证有一个前提：任意深度的 embedding 属于 competence。如果只看 performance，人实际能处理的大概只有两三层，而深度有上限的 NnVnN^nV^nNnVn 只是有限个 string，finite-state machine 当然能识别。所以“English 不是 finite-state 的”这个结论，取决于把 competence 和 performance 分开。

Probability 与 grammaticality

Chomsky 当年用 Colorless green ideas sleep furiously 反对 statistical 的 language model：两个词序在任何 corpus 里都没出现过，按出现频率算，两句的 probability 都是 0，模型分不出哪句合 grammar。

Pereira（2000）指出，这个论证默认“没见过的东西 probability 为 0”。这只对直接用 relative frequency 的模型成立。他用一个带 16 个 hidden class 的 aggregate bigram model（在报纸文本上训练，经过 smoothing，没见过的组合也有非零 probability）去算，grammatical 的那句的 probability 约是倒序那句的 2×1052\times10^52×105 倍。

这推翻了 Chomsky 那个论证的前提，但不说明 probability 就是 grammaticality。原因很直接：一句话的 probability 是每个词的 conditional probability 的连乘，

P(w1⋯wn)=∏t=1nP(wt∣w1⋯wt−1)P(w_1\cdots w_n)=\prod_{t=1}^{n}P(w_t\mid w_1\cdots w_{t-1})P(w1​⋯wn​)=t=1∏n​P(wt​∣w1​⋯wt−1​)

每个因子都小于 1，句子越长乘积越小。一个 30 词的 grammatical 句子，probability 通常远低于一个 5 词的 ungrammatical 句子；用了生僻词也会让 probability 大降。所以拿 language model 测 grammar 时，只比较 minimal pair：同样的词、同样的长度，只差一处结构，看模型给哪一句更高的 probability。第 5 站用的 LLM 评测都是这样设计的。

Spelling 为什么不够

开头的 plural 已经说明问题：cats、dogs、brushes 写出来都是 -s，读出来是 [s]、[z]、[əz] 三个不同的东西。反过来也一样：electric 的 c 读 [k]，electricity 的 c 读 [s]。24.900 的一句总结是：English 大约有 14 个 vowel，只有 5 个字母可以拼。

要研究 sound 的规律，就需要一套“一个 symbol 对应一个 sound，一个 sound 只有一个 symbol”的写法，这就是 IPA（International Phonetic Alphabet）。方括号 [ ] 里写的是 sound 本身。

Consonant：三个 coordinate

说话时气流从肺里出来，在 vocal tract 的某处被阻挡。描述一个 consonant 只需要回答三个问题：在哪里挡（place of articulation），怎么挡（manner of articulation），vocal folds 振不振（voicing）。

manner ＼ place bilabial labiodental interdental alveolar postalveolar palatal velar glottal
stop p b t d k g ʔ
fricative f v θ ð s z ʃ ʒ h
affricate tʃ dʒ
nasal m n ŋ
approximant w l ɹ j

每格里成对出现时，左边 voiceless，右边 voiced。Stop 是气流完全堵住再放开；fricative 是留一条窄缝让气流摩擦；affricate 是 stop 紧接 fricative；nasal 是口腔堵住、velum 放下、气流从鼻腔出去；approximant 是舌头靠近但不接触，其中 [w]、[j] 叫 glide，[l]、[ɹ] 叫 liquid。

用一次。[s] 是 voiceless alveolar fricative，[z] 是 voiced alveolar fricative：两者只差 voicing。[t] 是 voiceless alveolar stop：和 [s] 只差 manner。这种“只差一个 coordinate”的关系，第 3 站写 rule 时会反复用到。

再用它读 24.900 第 5 讲最后的练习：

[tɑp tʃɑpstɪk ʃɑps stɑk tɑp tʃɑpstɪks]

逐个对照：[tʃ] 是 ch，[ʃ] 是 sh，[ɑ] 是 hot 的那个 vowel。读出来是 top chopstick shops stock top chopsticks。

Pinyin 里有几个 English 没有的 consonant，在 IPA 里各有 symbol：zh、ch、sh 是 retroflex 的 [ʈʂ]、[ʈʂʰ]、[ʂ]（舌尖翘向 palate），j、q、x 是 [tɕ]、[tɕʰ]、[ɕ]。最值得注意的是 pinyin 的 b、d、g：它们在 IPA 里是 [p]、[t]、[k]，而 p、t、k 是 [pʰ]、[tʰ]、[kʰ]。下面会说明这是为什么。

Vowel：tongue 的高低前后

Vowel 不靠阻挡气流，靠舌头的位置改变口腔的形状。要描述的是：舌头多高（height），靠前还是靠后（backness），嘴唇圆不圆（rounding）。

先读这张图：he'd 和 who'd 的 vowel 都是 high，一个最前、一个最后；had 的 [æ] 是 front low。图上还有一个规律，24.900 原话的意思是：English 里 rounded 的恰好是全部 nonlow back vowel。这不是必然的：German Gefühl 的 [y] 是 high front rounded，Mandarin 鱼 yú 的 ü 也是 [y]；Korean 的 [ɯ] 是 high back unrounded。

同一高度上成对的 vowel 有 tense 和 lax 之分：[i]/[ɪ]（he'd/hid）、[u]/[ʊ]（who'd/hood）、[e]/[ɛ]（hate/head）。这个区分立刻能用来描述一条 English 的规律（24.900 第 5 讲）：单 syllable 的 English 词不以 front 或 high 的 lax vowel 结尾，也就是 [ɪ]、[ʊ]、[ɛ] 不出现在单 syllable 词的末尾。[fli]、[flu]、[fle] 都是可能的 English 词，*[flɪ]、*[flʊ]、*[flɛ] 不是。没学过这条规律的母语者，对这几个生造的词照样有一致的判断。条件要写全：[ɔ] 也是 lax，但它既不 front 也不 high，所以 law [lɔ] 没有问题；多 syllable 的词也不受这条限制。

Aspiration、VOT 与 categorical perception

把手放在嘴前说 pin，会感到一股气；说 spin，几乎没有。这股气叫 aspiration，IPA 写作 [pʰ]。

精确地说，stop 放开（release）之后，vocal folds 要过一段时间才开始振动，这段时间叫 voice onset time（VOT）。VOT 很长，放开之后先出来一股不带 voicing 的气，就是 aspiration；VOT 接近 0，放开时几乎同时开始振动；VOT 是负数，表示 release 之前 vocal folds 已经在振动，叫 voicing lead。

VOT 是一个连续的量，但听者并不把它听成连续的。24.900 第 6、7 讲给的结果是：把 VOT 连续地调，English 听者在大约 25 ms 处从“听到 b”变成“听到 p”，同一类内部的差别很难听出来。这叫 categorical perception。出生一个月的婴儿就有这种反应，chinchilla 也有（Kuhl 与 Miller 1975）。

分界放在哪里、切成几类，各个语言不同：

Abramson 与 Whalen（2017）的说法是：VOT 上可用的区域通常只有三个，voicing lead、short lag、long lag。用到全部三个的语言有 Thai，他们图里一位说话人的三个 token 是 [b] −158 ms、[p] 13 ms、[pʰ] 62 ms，正好一个区一个。只区分两类的语言，多半挑相邻的两个区。

Hindi 有 bal 'hair'、pal 'take care of'、pʰal 'knife blade' 三个词，只靠 VOT 区分，所以 Hindi 至少要把 continuum 切成三类。Hindi 其实还有第四类 breathy voiced 的 [bʱ]，它和 [b] 的 VOT 都是 lead，区别在 vocal folds 振动的方式，VOT 分不开这两类（Abramson 与 Whalen 2017）。Mandarin 的 爸 bà 和 怕 pà 只差 aspiration：pinyin 的 b 落在 short lag，p 落在 long lag，两个都是 voiceless。

看起来对，其实不对English 的 b 和 p 的区别是 voicing：b 的 vocal folds 振动，p 不振动

在词中间（如 rabid 对 rapid）大致如此，在词首却不是主要区别。Abramson 与 Whalen（2017）写明，常见的 English variety 在 utterance 开头，/b d g/ 是 short lag，/p t k/ 是 long lag。他们给的一对 token 说得最清楚：同一个人说单独的 books，[b] 的 VOT 是 5 ms，release 前 vocal folds 没有振动；说 two books，前面的 vowel 让 voicing 一直延续，[b] 的 VOT 变成 −67 ms。同一个 /b/，在两个位置上落进了两个不同的区。真正把词首的 bin 和 pin 分开的是 VOT 的长短，也就是 aspiration。24.900 给的分界也是这样定的：English 听者把 0 到 25 ms 听成 b，25 ms 以上听成 p，分界两边都没有 voicing lead。这也解释了为什么说 Mandarin 的人觉得 English 的 b、p 和 pinyin 的 b、p 对得上：两边词首用的是同一种区分。

Tone：pitch 也能区分词

English 用 pitch 表达语气（升调问、降调陈述），但不靠 pitch 区分词。Mandarin 靠。把 pitch 范围分成 5 度，5 最高、1 最低，一个 tone 写成起点和终点（必要时加中间点）的度数，这叫 Chao 的 tone letter：

tone Chao 例
1 55 mā 妈 'mother'
2 35 má 麻 'hemp'
3 214 mǎ 马 'horse'
4 51 mà 骂 'scold'

四个词的 consonant 和 vowel 完全相同，只差 pitch 的走向，所以 tone 和 consonant、vowel 一样是区分词的单位。注意 tone 是 pitch 随时间的形状，不是绝对的高度：男声和女声的 55 绝对频率相差很多，听者照样认得出。

两边的 phonetics 讲法

24.900 用 3 讲讲 phonetics，内容和上面相同（place、manner、voicing、vowel chart、VOT），另外放了 spectrogram 和 McGurk effect（看到的嘴型会改变听到的 sound），并用大量 transcription 绕口令做练习。NUS 这一单元按学生笔记的标题是 articulatory phonetics，重心在发音部位和方式。Tone 两边都只是顺带一提，这里用 Mandarin 补足。

NUS 笔记描述 consonant 的顺序是 voicing、place、manner（[s] 读作 voiceless alveolar fricative，和上面一致）；manner 一栏把 [ɾ] 单列为 flap（American English water 里的 t），把 [w] 叫 central approximant、[l] 叫 lateral approximant。Vowel 用 backness、height、rounding、tenseness 四项，并区分 diphthong（[aɪ] 这类舌位在一个 vowel 里移动的）和 monophthong。笔记还提到 rhotic（US English，cure 的 r 发出来）与 non-rhotic（UK English）的差别，这正是第 8 站 Labov 研究的那个 variable。

同一个 sound，两种身份

上一站有一个没解释的现象：English 的 pin 里是 [pʰ]，spin 里是 [p]，两个 sound 明明不同，English 母语者却觉得是“同一个 p”；Mandarin 母语者听 爸 和 怕，觉得是两个完全不同的 consonant。Phonetics 只能说两个 sound 有什么物理差别，说不了它们在一个语言里算不算“同一个”。这就需要 phonology。

定义如下。一个语言里能区分词的 sound 单位叫 phoneme，写在斜线里，如 /p/。一个 phoneme 在不同环境里的实际发音叫它的 allophone，写在方括号里。判断两个 sound 是不是不同的 phoneme，24.900 第 7 讲给的步骤是：

  1. 先找 minimal pair：两个词只差这一个 sound，意思不同。找到了，就是两个 phoneme。爸 bà 对 怕 pà 是 Mandarin 的 minimal pair，所以 /p/ 和 /pʰ/ 在 Mandarin 里是两个 phoneme。
  2. 找不到 minimal pair，就看两个 sound 出现的环境。如果一个能出现的地方另一个从不出现，叫 complementary distribution，它们是同一个 phoneme 的 allophone，可以写一条 rule 预测哪里出现哪个。

English 的 [p] 和 [pʰ] 属于第二种：[p] 出现在 s 之后，[pʰ] 出现在词首等其他位置，没有一个 English 词靠这两个 sound 区分。

走一遍：Korean 的 [r] 与 [l]。 24.900 第 7 讲的 Korean data：

词 gloss 这个 liquid 后面是什么

第一步，找 minimal pair。 没有哪两个词只差 [r] 和 [l]。

第二步，看环境。 最后一列已经整理好：[r] 后面总是 vowel；[l] 后面是词尾或 consonant，从来不是 vowel。两组环境没有交集，是 complementary distribution，所以 [r] 和 [l] 是同一个 phoneme 的两个 allophone。

第三步，选 underlying form，写 rule。 两个选择：

  • 选 /l/：rule 是 /l/ → [r] / __ V（在 vowel 前变成 [r]），其余情况不动。
  • 选 /r/：rule 是“在词尾或 consonant 前变成 [l]”，要写两个环境。

一般选出现环境更“杂”的那个当 underlying form（这里是 [l]，它的环境是“其他一切”），这样 rule 只需要描述一个具体环境。用第一种写法检查每个词：saram、rupi、irɯm、ratio 里的 liquid 都在 vowel 前，变成 [r]；mul、pal、səul、ilkop、ipalsa 里都不在 vowel 前，保持 [l]。九个词全对。

同一个程序给 English 的 /t/ 写 rule。24.900 第 7 讲的 data：sit [sɪt] 对 sitter [sɪɾəɹ]，heat 对 heater，at 对 attic，在两个 vowel 之间 t 变成一个很快的 tap [ɾ]（American English）。但 atone [ətʰon]、attack [ətʰæk]、detect [dɪtʰɛkt] 里的 t 也在两个 vowel 之间，却没有变成 [ɾ]。差别在 stress：sitter、heater、attic 的 stress 在 t 前面的 vowel 上，atone、attack、detect 的 stress 在 t 后面。所以 rule 是

/t/ → [ɾ] / V́ __ V

（V́ 表示 stressed vowel）。讲义里 gat [gæt] 加 -er 得 gatter，母语者会念成 [gæɾəɹ]：rule 对新词照样起作用，说明它是母语者知识的一部分，而不是一个个词背下来的。

第三种关系：free variation

NUS 的 phonemic analysis 把两个 phone 的关系分成三种，按“出现的环境是否重叠”和“换了以后意思变不变”两个问题来分：

关系 出现在同一个环境吗 换了意思变吗 结论
contrastive distribution 会 变（有 minimal pair） 两个 phoneme
complementary distribution 从不 无从换起 同一个 phoneme 的 allophone，环境可以预测
free variation 会 不变 不 contrastive，但出现哪一个也不能由环境预测

Free variation 的例子：English 词尾的 /t/，cat 可以念成 release 的 [kʰæt]，也可以念成舌头停在 alveolar ridge 不放开的 [kʰæt̚]，意思不变，同一个人在同一个位置两种都会说（这个例子是我加的）。NUS 笔记说，free variation 里用哪一个，取决于正式不正式这类不属于 phonetic environment 的因素。

所以 NUS 的步骤是：

  1. 先假定没有 free variation。
  2. 找 minimal pair。找到了，两个 sound contrastive，是不同的 phoneme。
  3. 找不到，就给每个 sound 列出它出现的环境（前一个 sound，后一个 sound），看能不能用 voicing、place、manner 或 vowel 的 height、backness 这类 feature 概括出两组互不重叠的环境。能，就是 complementary distribution，选环境限制较少（less restricted）的那个当 phoneme 的名字；不能，就是两个 phoneme。

第 1 步的理由：如果一开始就允许 free variation，任何两个“环境有重叠、又没找到 minimal pair”的 sound 都可以说成 free variation，分析就再也不会出错，也就什么都没检验。上面 Korean 的走法和这三步一一对应：没有 minimal pair，环境可以概括成“vowel 之前”和“其他”，[l] 的环境限制少，所以 phoneme 记作 /l/。笔记还提醒一种失败：两个 sound 的环境都能概括成一个简单的 class 时，就分不出哪个限制较少，这时第 3 步定不下 underlying form。

Phonotactics

一个语言对 sound 怎样排列的限制叫 phonotactics：哪些 sequence 可以出现，某个位置上能放哪些 sound，允许哪些 syllable 类型。前面已经碰到几条 English 的 phonotactic constraint：

  • 单 syllable 词不以 [ɪ]、[ʊ]、[ɛ] 结尾（第 2 站）。
  • 词不以 sonorant 加 obstruent 开头：*rtip、*nsack（24.900 第 9 讲）。Mandarin 母语者同样会觉得这两个词“不可能”，但理由不同：Mandarin 的 syllable 开头最多一个 consonant，rt、ns 两个 consonant 本来就排不进去。
  • 词尾不能是 voiceless obstruent 加 voiced obstruent：*[ʃɪpz]。下一小节会看到，这一条正是 plural 选 /z/ 的理由。

NUS 笔记把 allophony 看作 phonotactics 的一个表现：笔记的例子是 English 的 /p/ 在 syllable 开头 aspirated（24.900 第 7 讲写作 /p/ → [p] / s __ V，其他位置 [pʰ]），这就是一条“这个位置上只能放 [pʰ]”的限制。学外语难，也可以拆成这两件事：sound 的 inventory 不同（English 没有 [ʂ]），phonotactic constraint 不同（同样有 [p] 和 [pʰ]，English 由位置决定用哪个，Mandarin 用来区分词）。

[−sonorant] → [−voice]  /  xx‾ #[-\text{sonorant}]\ \to\ [-\text{voice}]\ \ /\ \ \underline{\hphantom{xx}}\ \#[−sonorant] → [−voice]  /  xx​ #

再看一个 class 由 place 定义的例子。Arabic 的 definite article 是 al-（24.900 第 9、10 讲）：al-qamr 'the moon'、al-kitaab 'the book'、al-faras 'the mare'；但是 ad-daar 'the house'、an-nahr 'the river'、az-zajt 'the oil'、aθ-θawb 'the garment'、aʃ-ʃams 'the sun'。l 变成了后面那个 consonant。把两组 consonant 放回第 2 站的表：q、k、f 都不用舌尖舌面；d、n、z、θ、ʃ 都用舌尖或舌面，这个 feature 叫 [+coronal]。Rule 是：l 在 [+coronal] consonant 之前变得和它一样。一个 sound 变得像它的邻居，这类 rule 叫 assimilation。

三种读法是同一个 morpheme，underlying form 只能选一个，其余由 rule 推出。两种 story：

  • Story 1：underlying 是 /s/，在 voiced sound 后面变成 [z]。
  • Story 2：underlying 是 /z/，在 voiceless sound 后面变成 [s]。

两种都能推出上表。区分它们要看 rule 在 plural 以外是否成立。Story 1 的 rule 是“[s] 在 voiced sound 之后变 [z]”，可是 place [pʰlejs]、lance [læns]、purse [pʰəɹs] 都是 voiced sound 后面跟 [s]，没有变。要救 Story 1，只能规定 rule 只对 plural 的 -s 起作用，rule 就成了专门为这个 morpheme 设的特例。

Story 2 的 rule 是“voiceless obstruent 后面的 obstruent 在词尾变 voiceless”。English 里有没有 voiceless obstruent 加 voiced obstruent 结尾的词？没有，*[ʃɪpz] 这样的结尾在 English 里根本不存在。所以 Story 2 的 rule 对整个 lexicon 都成立，它表达的是 English 的一条一般规律，plural 只是碰上了它。选 /z/。

  • A：只有一个 syllable 的 stem 要补长：以 k 结尾补 -a（yak → yaka，lelk → lelka），否则补 -da（wun → wunda，bel → belda）。

  • C：词尾的 k 脱落（wangalk → wangal，kundulk → kundul）。

Mandarin third-tone sandhi：rule 还看 structure

开头的第四件事：两个 third tone 相连，前一个变成 second tone。

214 → 35 / __ 214

你好 nǐ hǎo 念成 ní hǎo，水果 shuǐguǒ 念成 shuíguǒ。三个 third tone 连在一起时，结果取决于结构。MIT 24.901 第 16 讲的例子 买好酒 mǎi hǎo jiǔ（三个字都是 third tone）有两个意思：

[[买 好] 酒]，'finished buying wine'。 先在内层 [买 好] 里用 rule：买 在 好 之前，变成 35。再看外层：好 在 酒 之前，变成 35。结果是 35 35 214。

[买 [好 酒]]，'buy good wine'。 先在内层 [好 酒] 里用 rule：好 变成 35。再看外层：买 后面现在是 35 而不是 214，rule 不适用。结果是 214 35 214。

同一串 syllable，两种 constituent structure，tone 不同。Rule 从内层到外层一层层地用，这种方式叫 cyclic application。24.901 同时提醒，第二种结构在实际说话里也常被念成 35 35 214，所以这个区别是一种倾向，不是绝对的。但它说明 phonology 的 rule 不只看左右相邻的 sound，还看 syntax 给出的结构，第 5 站会专门讲这种结构。

一串有顺序的 rule 是一个 finite-state transducer

为什么 lexicon 存 morpheme 而不存整词

记住一个词，就是记住一个 sound 和一个 meaning 的配对。这个配对是任意的：cat、neko（Japanese）、Katze（German）、koshka（Russian）指同一种动物，sound 和 meaning 之间没有内在联系（Saussure 的 arbitrariness of the sign）。既然任意，就只能一个个记。问题是：记的单位是什么？

24.900 第 2 讲的例子是 Nimboran（New Guinea 的一种语言）的 verb。一个 verb 有 4 种 tense，subject 有 14 种 person/number 组合，object 也有 14 种，还有 15 个 locative suffix 和 2 种 aspect，各选一个组合成一个形式。如果 lexicon 把每个形式都存下来，一个 verb 要存

4×14×14×15×2=23,5204\times14\times14\times15\times2=23{,}5204×14×14×15×2=23,520

个形式。如果只存 suffix，再加一条“依次组合”的 rule，要存的是

4+14+14+15+2=494+14+14+15+2=494+14+14+15+2=49

个 suffix。一个是 product，一个是 sum。几十个 suffix 的组合就足以让“全部存下来”不可行。

这个计算说明了存 morpheme 的经济性。母语者确实这样做，有三类证据：

  • Productivity。 Wug test（Berko 1958）：给孩子看一个虚构的 wug，再看两个，孩子说 wugs，读 [wʌgz]。他不可能存过这个词，只能是用 plural 的 rule 现场造的，而且用的正是第 3 站的 /z/ 加 rule。
  • Reuse。 Watergate 之后有了 Monicagate、Irangate：-gate 被切出来当成一个新 morpheme 用。
  • Backformation。 sculptor、beggar、swindler 被切成 sculpt + -or、beg + -ar、swindle + -er，于是有了 verb sculpt、beg、swindle。Pea 在 Middle English 里是 pease，一个 mass noun（24.900 第 23 讲），词尾的 [z] 被听成 plural 的 -s，于是倒推出了 count noun 的 pea。

Pea 这个例子正好检验了“母语者在切分”这个 hypothesis：如果大家只是整词记忆，pease 不会被切开。

切分的方法：Swahili

Morpheme 是有 meaning 的最小单位。拿到一组陌生语言的形式，切分的办法是：找 meaning 相同的部分，看 form 里有没有一段始终跟着它。24.900 第 2 讲给了 15 个 Swahili verb，这里取其中 7 个：

不只是往前后加

Affix 加在 root 前面叫 prefix，后面叫 suffix。24.900 的 data 里还有别的方式：

  • Infix（Tagalog）：lumangoy 'swam'、kumain 'ate'、bumili 'bought'，但 umawit 'sang'、umakyat 'climbed'、umuwi 'went home'。前三个是 l-um-angoy、k-um-ain、b-um-ili，-um- 在第一个 consonant 之后；后三个的 root 以 vowel 开头，-um- 就在最前面。两组合起来，位置只有一种说法：-um- 放在 root 的第一个 vowel 之前。

  • Reduplication（Tagalog）：future 复制 root 的第一个 consonant 加 vowel：lalangoy 'will swim'、kakain 'will eat'、bibili 'will buy'；以 vowel 开头的只复制那个 vowel：aawit 'will sing'、uuwi 'will go home'。复制出来的 sound 每个词都不同，rule 能固定的只是长度（一个 CV），内容由 root 填。讲义还有一种复制两个 syllable 的，表示 'rather'：mataas 'tall' → mataas-taas 'rather tall'，malapit 'close' → malapit-lapit。

    template s-k-n 'live in' d-x-l 'enter'

Derivation、inflection 与 word class

Affix 分两类。改变词的 category 或基本意思的叫 derivation：-ment 把 verb 变成 noun（govern → government），em- 把 noun 变成 verb（power → empower），-able 把 verb 变成 adjective。只给词加上句子需要的 grammatical information、不改变 category 的叫 inflection：plural -s、past -ed、third person -s。

24.900 第 4 讲提到一条跨语言的规律：inflection 总在 derivation 外层。Governments 是 govern-ment-s，*govern-s-ment 不可能。拿 empowerments 检验：em- + power（noun）先成 verb empower，再加 -ment 成 noun empowerment，最后加 inflection 的 -s。Derivation 在里，inflection 在外。

Category（也叫 word class 或 part of speech）本身怎么判断？学校说“noun 是表示事物的词”，这个定义拿 destruction（一个事件）一试就坏。24.900 第 4 讲的办法是看 distribution：一个词能放进只有 noun 才能放的位置，它就是 noun。两个 test frame：

  • We are talking about (the) ___：填进去能说的，是 noun。
  • I consider her ___（意思是“我认为她是 ___”）：填进去能说的，是 adjective。

Destruction 放进第一个 frame：We are talking about the destruction，能说，所以是 noun，不管它表示的是事物还是事件。

  • Morphological possibility：这个词能加哪些 inflection。
  • Distribution：它能出现在 phrase 或 sentence 的哪个位置。

用一次。Round 这个 form 在下面四句里各是什么 class？

  2. The workers rounded the corners.
  3. They sat at a round table.
  4. She walked round the lake.

逐句试：第 1 句里 round 前面有 determiner another，能变成 two rounds（plural），能填进 a round of golf，是 noun。第 2 句里它在 subject 之后、带了 past tense 的 -ed，能说 The workers didn't round the corners，是 verb。第 3 句里它在 determiner a 和 noun table 之间，能说 a rounder table，是 adjective。第 4 句里它在 NP the lake 前面，不能加任何 inflection（*She walked rounder the lake），round the lake 也不能被一个 pronoun 替换，是 preposition。同一个 form 在四句里属于四个 class，这说明 class 是词在句子里的位置决定的性质，查词典只告诉你它“可以是”哪几类。（这个例子和其中的 judgment 是我加的，第 4 句是 British English 常见的用法，American English 多说 around。）

还有一个大的划分：noun、verb、adjective、adverb 是 open class（content word），不断有新词加入，比如 google 变成 verb；determiner、preposition、pronoun、conjunction 是 closed class（function word），几乎不进新词，负责表达 content word 之间的 grammatical relation。

NUS 笔记的例子。按 selection，disappearance 有两条路：appear → disappear → disappearance，或者 appear → appearance → disappearance。可它只有一个意思，就是“disappear 这件事”。笔记的结论是：一个词先要有两个意思，才谈得上 structural ambiguity；两条合并路径都合乎 rule 而意思只有一个时，那个意思只对应其中一条（这里是 disappear 加 -ance 的那条），不能因为画得出两棵 tree 就说它 ambiguous。笔记同时强调 word formation 是一步一步来的，每一步都要得到一个合格的词。拿这条检查 unlockable：两条路的中间一步 unlock 和 lockable 都是合格的词，两个意思也都存在，所以它是真正的 structural ambiguity。

LLM 的 tokenizer 不按 morpheme 切

大多数 LLM 的输入先被切成 subword token，常用的办法是 BPE（byte pair encoding）：从单个字母开始，统计 corpus 里所有相邻的两个 symbol，把出现次数最多的那一对合并成一个新 symbol，重复若干次。合并的标准只有 frequency，没有 meaning。

拿一个很小的 corpus 走一遍。词和出现次数是 table 6、able 4、lock 5、unlock 3、lockable 2、unable 2、unlockable 1，每个词尾加一个结束符 _。第一轮统计 a 和 b 相邻：table、able、lockable、unable、unlockable 里各有一次，加权是 6+4+2+2+1=156+4+2+2+1=156+4+2+2+1=15，和另外几对并列最多，合并成 ab。照这样做 8 轮（并列时取先出现的那对），合并依次是 ab、abl、able、able_、lo、loc、lock、lock_，最后的切分是：

词 切分
table t + able_
unable u + n + able_
unlockable u + n + lock + able_

两件事很清楚。第一，table 里的 able 被当成一个单位切出来，而它在 table 里根本不是 morpheme，只是因为 able 这串字母常见。第二，un 在这 8 轮里没有被合并：它一共出现 3+2+1=63+2+1=63+2+1=6 次，敌不过 able 和 lock。而且切分是平的，unlockable 只有一种切法，两个意思靠 token 序列区分不了。Model 要分辨两个意思，只能从 context 里学。这不说明 LLM 学不到 morphology，只说明 morphology 不是由 tokenizer 给出的。

Constituency test

怎么知道一串词是不是 constituent？看 rule 能不能把它当作一个整体来搬动、替换、并列。24.900 第 11 讲用的句子是 I will find the red book。测 the red book：

test 结果
topicalization（移到句首） The red book, I will find.
coordination（和同类并列） I will find the red book and the blue pencils.
fragment answer（单独回答问题） What will you find? The red book.
pseudo-cleft（24.900 用的 frame） What I will find is the red book.

test 结果
topicalization *Find the red, I will book.
coordination *I will find the red and lose a blue book.

Phrase structure rule 与 head

the red book、books、those red books about linguistics、them，这些都能出现在 I will find ___ 的位置，都通过同样的 test。它们的核心是一个 noun（或代替 noun phrase 的 pronoun），这个 noun 叫 head，整个单位叫 noun phrase（NP）。同样，find the red book 的核心是 verb find，叫 verb phrase（VP）；in the garage 的核心是 preposition in，叫 PP。

Argument 与 adjunct

I will tickle the child with a feather 里，the child 和 with a feather 都跟在 verb 后面，都是 constituent。它们和 tickle 的关系一样吗？24.900 第 13、14 讲的办法是换 verb，看谁能留下：

  • I will tickle the child. / I will devour the child. / I will write the child. / *I will thrive the child.
  • I will tickle the child with this feather. / I will devour the child with this feather. / I will write a novel with this feather. / I will thrive with this feather.

The child 能不能出现，取决于 verb：thrive 不要它。With this feather 跟任何 verb 都行。所以前者是 verb 要求的，后者不是。NUS 的定义正是这样分的：

  • Argument：一个 argument-taking expression（这里是 verb）要求的成分。句子要 grammatical，每个 argument-taking expression 都要拿到它要的全部 argument。把 verb 看成一个 function，argument 就是它的参数：kick 是 kick(x, y)，The girl kicked the blue ball 里 x = the girl，y = the blue ball。
  • Subject 是 verb 所描述的那个 argument（the girl）；complement 是除 subject 以外的 argument（the blue ball）。
  • Adjunct：可有可无的成分，去掉以后句子照样成立。

Verb 对 argument 的要求可以很具体，具体到 head 是哪个词：It depends on the weather，*It depends at the weather，*It depends from the weather；I think that I have won the lottery、I wonder whether I have won the lottery，但 *I think whether…、*I wonder that…。Verb 选的是 complement 的 head（on、that、whether），从来不会要求它里面有某个 modifier。

走一遍：I decided on the boat。 这句有两个意思：“我在船上做了决定”和“我选了那条船”。前一个意思里 on the boat 是 adjunct（在哪里决定），后一个意思里它是 decide on 要求的 argument（决定的是什么）。现在加一个 PP：I decided on the boat on the plane。24.900 的判断是它只有一个意思：在飞机上选了那条船；“在船上选了那架飞机”不行。这正是表里最后一条：argument 要比 adjunct 更靠近 verb，所以紧挨着 decided 的 on the boat 只能是 argument，后面的 on the plane 只能是 adjunct。

再用 do so 测一次。I decided on the boat, and Mary did so on the plane。Did so 替换的是 verb 连同它的 argument，留在外面的只能是 adjunct。所以这句可以是“Mary 在飞机上也做了（同样的）决定”，不能是“Mary 选了那架飞机”。

Structure dependence：yes/no question

English 怎么把陈述句变成 yes/no question？

  • The man is tall. → Is the man tall?

最简单的 hypothesis 只看词序：把句子里第一个 is 移到句首。只有一个 is 时，它和正确的 hypothesis 给出同样的结果。要分开它们，需要一个有两个 is 的句子：

  • The man who is tall is happy.

Linear rule 移动第一个 is，得 *Is the man who tall is happy?。正确的是 Is the man who is tall happy?，移动的是 main clause 的 Aux。所以 rule 必须说成：把 main clause 的 Aux 移到句首。这条 rule 要知道 tree 的结构，这个性质叫 structure dependence。

24.900 第 16 讲把这种移动写成 head movement：Mary will type novels 里 will 是 T，yes/no question 把它移到 clause 最前面的 C，得到 Will Mary type novels?。同一讲还说明为什么被移的是 will 而不是 verb：*Type Mary will novels? 不行，因为从 T 到 C 的路比从 V 到 C 短，movement 总选最短的那条（Head Movement Constraint）。“最短”是按 tree 里经过的 node 数算的，这又是一个只能在 tree 上说清的条件。

Berwick、Pietroski、Yankama 与 Chomsky（2011）把这个论证推进了一步，证据不是“没人说错的句子”，而是一个合格句子少了一个意思：

  • Can eagles that fly eat? 只能是 Eagles that fly can eat 对应的问题（会飞的鹰能不能吃东西）。
  • 它不能理解成 Eagles that can fly eat 对应的问题（能飞的鹰吃不吃东西），尽管这个问题本身完全说得通。

如果 rule 是“把某个 can 移到句首”而不管结构，第二个意思应该也存在，因为 can 原来可以在 relative clause 里。他们的论证是：孩子听到的输入里只有说出来的句子，没有哪一句会告诉他“这句话没有第二个意思”，所以这种知识很难说是从输入里统计出来的。第 8 站会讲对方怎样回应。

这和第 1 站的 fieldwork 是同一个逻辑：只有一个 is 的句子分不开两个 hypothesis，要专门找一个能让它们给出不同预测的句子。

Structure dependence 是 acquisition 研究里争论最多的现象之一，第 8 站会讲两边的证据。这里先看 LLM 方面的结果。Linzen 与 Baroni（2021）的综述整理了用 minimal pair 测 neural language model 的研究：

  • Agreement。 The length of the forewings is…：verb 要和 head noun length 一致，不能被更近的 forewings 带偏。Linzen 等（2016）的 LSTM 总体正确率超过 99%，但这个数字被“最近的 noun 通常就是 head”抬高了；中间隔着 4 个和 head 数目不同的 noun 时，正确率是 82%。
  • Question formation。 McCoy 等（2020）的结果是：不同 architecture、不同 random seed 学到的东西不一样，按 structure 而不是按词序去 generalize 的倾向并不稳定。
  • Data 的量。 综述给的对比是：孩子每年大约听到 1000 万个词，而 T5 这样的模型训练用了超过 1000 亿个词。

所以“model 能做对一部分 structure-dependent 的 minimal pair”和“model 学到了 structure”之间还隔着一步，而它们用的 data 量和孩子不在一个数量级。Mandarin 的 yes/no question 用 吗 或 A-not-A（你是不是学生？），不移动 Aux，所以这个具体的 test 在 Mandarin 里不出现。

Movement 与跨语言的差别

Write 需要一个 object：Mary wrote the novel on a typewriter 可以说，*Mary wrote on a typewriter the novel 不行，object 要紧跟 verb。可是 What did Mary write on a typewriter? 里 write 后面没有 object。24.900 第 14 讲的结论是：what 在 underlying structure 里就在 object 的位置，后来被移到了句首。这叫 wh-movement。

Mandarin 不移动：张三买了什么？里的 什么 就待在 object 的位置（24.900 第 14 讲引用的正是 Zhangsan mai-le sheme）。这叫 wh-in-situ。English、Tagalog、Finnish 移动，Chinese、Bafut、Hopi 不移动。讲义还指出一个反面的 universal：把 wh-phrase 移到句末的语言至今没有发现。

另一个差别是 head 在 complement 前还是后（第 16 讲）。English 的 head 在前：find [the book]、in [the garage]、that [Mary ate sushi]。Japanese 的 head 在后，相当于 [Mary-ga hashi-de sushi-o tabe-reru] to，verb 在 object 之后，complementizer to 在 clause 之后。讲义列出的 head-final 语言有 Japanese、Tibetan、Korean、Chaha、Navajo、Basque；German 是混合的，C（dass）在前、verb 在后。Mandarin 也是混合的：verb 在 object 前（买 酒），但 relative clause 在 noun 前（咬死了猎人的 狗）（Mandarin 这一句是我加的）。

Meaning 至少有两层

24.900 第 17 讲从一个替换实验开始。Professor Richards、Norvin、that guy with the beard 指的是同一个人；在 Professor Richards is from Alabama 里把其中一个换成另一个，句子的真假不变。那么，指同一个东西的表达式是不是总能互换？看两句话：

  1. The temperature is 45 degrees.
  2. The temperature is rising.

第 1 句说 the temperature 和 45 degrees 此刻指同一个数。如果能互换，把第 2 句里的 the temperature 换成 45 degrees，得到 45 degrees is rising，这句是荒谬的：45 度不会上升。替换失败，说明 the temperature 的 meaning 不只是“它此刻指的那个数”。

于是要把 meaning 分成两层。一个表达式此刻挑出的东西叫它的 extension（也叫 reference）；挑出它的那个办法叫 intension（也叫 sense）。讲义的说法很具体：the current temperature 的 intension 是“去看温度计或天气网站”，extension 是看到的那个数，比如 45 度；the President of the United States 的 intension 是“找出最近一次总统选举的胜者”，extension 在讲课的那一年是 Joe Biden。Rising 说的是 intension 随时间给出的值在变大，所以它和 intension 打交道，不能用 extension 替换。In 1945, the President of the United States declared war on Japan 也一样：这里的 the President 按 1945 年去算，extension 是另一个人。

再用一次。The morning star 和 the evening star 的 extension 都是金星，intension 不同（“早上最后看见的那颗亮星”和“傍晚最先看见的那颗”），所以 The morning star is the evening star 是一个要靠天文观测才知道的事实，不是一句废话（Frege 的例子）。Demonstrative 和 pronoun 把这个区分推到极致：I 的 intension 固定（“说这句话的人”），extension 随说话人而变，NUS 笔记把这叫 shifting reference。

NUS 笔记另外区分 denotation 和 connotation：denotation 是字面的 meaning，connotation 是这个词引起的联想。两个 denotation 相同的词可以 connotation 不同，笔记还提到 connotation 久了可能变成 denotation 的一部分。

用 entailment 测 word 之间的关系

定义（24.900 第 17 讲）：句子 A entail 句子 B，当且仅当只要 A 为真，B 就一定为真。它只说 A 为真时怎样，不管 A 实际上是否为真，也不保证反方向：John killed the ant entail The ant is dead，这是 kill 的 meaning 决定的；Joe Biden is a bachelor entail Joe Biden is unmarried，反过来不成立（unmarried 的人不一定从未结过婚）。

两个句子之间还有两种关系可以直接用 entailment 定义：

  • Paraphrase（24.900 叫 equivalence）：A 和 B 互相 entail。Mary ate the bagel 和 The bagel was eaten by Mary。
  • Contradiction：A entail “B 为假”，B 也 entail “A 为假”。Noam is here 和 Noam is not here（Noam 指同一个人时）。

Word 之间的关系同样可以用 entailment 来测。NUS 笔记把它们分成两组：一组是 meaning 之间的关系，一组是 form 和 meaning 怎样对应。

Meaning 之间：

  • Hyponymy。 I saw a dog entail I saw an animal，反过来不成立。dog 是 animal 的 hyponym（subset），animal 是 dog 的 hypernym（superset）。NUS 笔记的例子是 human 和 great ape。
  • Meronymy。 部分与整体：wheel 是 car 的 meronym，car 是 wheel 的 holonym。它和 hyponymy 不同，用 entailment 一测就分开：This is a dog entail This is an animal，This is a wheel 不 entail This is a car。（wheel 和 car 是我加的例子。）

Form 和 meaning 之间：

  • Synonymy。 意思大致相同，互相 entail：The sofa is red 和 The couch is red；24.900 的例子是 purchase 和 buy。
  • Complementary antonym。 不是 X 就一定是 Y：not dead entail alive，两者之间没有中间状态。
  • Gradable antonym。 不是 X 不一定是 Y：not hot 不 entail cold，可以不冷不热。检验办法是 NUS 笔记说的“能问程度”：how hot is it? 能问，?how dead is it? 很怪；hotter 能说，?deader 很怪。
  • Converse。 同一个关系从两个视角说：A is B's employer 与 B is A's employee 互相 entail；left 和 right 也是。24.900 的例子提醒一个条件：Norman is Don's nephew 和 Don is Norman's uncle 只有在两人都是男性时才互相 entail。
  • Reverse。 方向相反的两个过程：ascend 和 descend，expand 和 contract。

一个 form 有几个意思时，还要分 polysemy（意思之间有联系：mouth of a person、mouth of a river）和 homonymy（意思之间没有联系，只是碰巧同形：river bank 和 savings bank）。两者的区分要靠 etymology，母语者的直觉并不总可靠。Homonymy 又按“同形”指的是什么再分：念法相同叫 homophone（write 和 right），拼法相同叫 homograph，不管念法是否相同（lead 'to guide' 和 lead 'the metal'）。（write、lead 的例子是我加的。）

Entailment 与 presupposition

John stopped smoking 让听者得到两条信息：

  1. John 现在不抽烟。
  2. John 以前抽烟。

加上 negation，看哪条还在：John didn't stop smoking。第 1 条不再成立（他可能还在抽）；第 2 条仍然成立（还是说他以前抽烟）。在 negation 下消失的是 entailment；在 negation 下保留的叫 presupposition。Stop 这类词叫 presupposition trigger。

24.900 第 17 讲给 presupposition 的定义比“在 negation 下保留”更根本：A presuppose B，当且仅当 B 必须为真，A 才谈得上是真还是假。经典的例子是 The present King of France is bald。现在没有法国国王，这句话既不能说是真，也不能说是假，讲义的说法是它“weird, not false”，这叫 presupposition failure。换成 The present King of France is not bald，同样 presuppose 有一个法国国王，同样无从判断，所以 negation test 只是这个定义的一个推论：B 是 A 和 not A 共同的前提，自然在 negation 下保留。

同一讲举的 Have you stopped beating your wife? 说明 presupposition 为什么会让人无从回答：答 yes 和答 no 都承认了“你以前打过”。讲义据此提了两个判断用的问题：

  • 不管 A 是真还是假，P 都必须为真吗？是，P 是 presupposition。
  • 只要 A 为真，P 就必须为真吗？是，P 是 entailment。

拿讲义的练习用一次：Bill isn't aware that Susan is pregnant。去掉 negation 得 Bill is aware that Susan is pregnant；两句都要求 Susan is pregnant 为真才谈得上真假，所以它是 presupposition（trigger 是 aware）。

听者通常不会因为 presupposition 卡住。有人突然说 The cat is at the door，你之前不知道有猫，也会直接把“有一只猫”加进自己的知识里，这叫 accommodation。讲义的对比是 The giraffe is at the door：同样的结构，要 accommodate 一头长颈鹿就让人一愣。I regret having been born in 1857 和 I don't regret having been born in 1857 都 presuppose 说话人生于 1857 年，这个前提荒谬，所以两句都怪。第 7 站会用更多的 test 把 presupposition 和第三种 inference 区分开。

Compositionality：quantifier 是 set 之间的关系

句子有无穷多个，母语者却能理解从没听过的句子，所以句子的 meaning 必须能由部分的 meaning 按结构算出来。这叫 compositionality。Semantics 要做的就是给每种部分指定一个 meaning，再给每种合并方式指定一个计算规则。

最简单的情况：name 指一个 individual，predicate（is an avid hangglider、smokes）指一个 set，句子为真当且仅当这个 individual 属于这个 set。

Every Italian 指什么？24.900 第 18 讲说明它不能是一个 individual，也不能是一群人。对比：

  • Paul is inside, and Paul is outside.（矛盾）
  • Several Americans are inside, and several Americans are outside.（不矛盾）

如果 several Americans 像 Paul 一样指一个固定的对象（哪怕是一群人），第二句也该矛盾。它不矛盾，因为两次说的可以是不同的人。所以 quantified NP 不指某个对象。24.900 给的答案是：determiner 表达两个 set 之间的关系。Every linguist smokes 里，A = linguists，B = smokers：

Determiner 的这种 meaning 还受一条真实的限制。所有 natural language 的 determiner 都满足一个性质（24.900 第 18 讲）：

Det(A,B) ⟺ Det(A, A∩B)\text{Det}(A,B)\ \Longleftrightarrow\ \text{Det}(A,\ A\cap B)Det(A,B) ⟺ Det(A, A∩B)

也就是说，判断 Det A B 时只需要看 A 里面的东西，A 以外的东西无关。Every opera singer smokes 和 Every opera singer is an opera singer who smokes 意思相同。这叫 conservativity。

它是一个真的限制，因为很容易定义出不满足它的 determiner。24.900 虚构了一个 glorp：glorp A B 为真当且仅当 ∣A∪B∣=3\lvert A\cup B\rvert=3∣A∪B∣=3。在一个有 2 个 circle、1 个红色 square 的世界里，glorp circles are red 算的是 circle 和红色东西的 union，∣{c1,c2,s}∣=3\lvert\{c_1,c_2,s\}\rvert=3∣{c1​,c2​,s}∣=3，真；glorp circles are red circles 算的是 circle 和红色 circle 的 union，∣{c1,c2}∣=2\lvert\{c_1,c_2\}\rvert=2∣{c1​,c2​}∣=2，假。两句不等价，glorp 不 conservative。没有任何语言有这样的 determiner。

这个性质还可以拿来做诊断。Only linguists smoke 和 Only linguists are linguists who smoke：第二句永远为真（是 linguist 且 smoke 的人当然都是 linguist），第一句却可以假。所以如果把 only 当作 determiner，它不 conservative。这正是把 only 归为另一类词（focus particle，第 7 站提到）的理由之一。

Scope ambiguity

Someone loves everyone 有两个意思：

∀x ∃y loves(y,x)（每个人都被某个人爱，可以是不同的人）\forall x\,\exists y\ \text{loves}(y,x)\qquad\text{（每个人都被某个人爱，可以是不同的人）}∀x∃y loves(y,x)（每个人都被某个人爱，可以是不同的人）
∃y ∀x loves(y,x)（有一个人爱所有人）\exists y\,\forall x\ \text{loves}(y,x)\qquad\text{（有一个人爱所有人）}∃y∀x loves(y,x)（有一个人爱所有人）

两个 quantifier 谁在外层，叫 scope。用 model 检验两个 reading 确实不同：

左边：Ann 被 Cy 爱，Bo 被 Ann 爱，Cy 被 Bo 爱，所以 ∀∃\forall\exists∀∃ 真；没有一个人爱所有三个人，所以 ∃∀\exists\forall∃∀ 假。右边两个都真。存在一个 model 让它们真假不同，说明这是两个不同的 meaning。右边的 model 同时说明：∃∀\exists\forall∃∀ 为真时 ∀∃\forall\exists∀∃ 一定为真（那个爱所有人的人就是每个人的那个 yyy），反过来不行。

再用前面的教室：Everyone in this room speaks two languages（24.900 第 18 讲的例子）。

  • 每个人各自会两种：a、b、c 都会两种，真。
  • 有两种语言，每个人都会：三人共同会的只有 English，一种，假。

24.900 的解释是：quantifier 可以在看不见的层面上移到更高的位置，再按位置决定 scope，这叫 Quantifier Raising（QR）。证据之一是这种移动受 clause 限制：A guard is standing in front of every building 有两个意思（一个守卫，或每栋楼各一个），A guard said that I should stand in front of every building 只有一个，every building 不能越过 that 引导的 clause 去取得更宽的 scope。

Monotonicity 与 negative polarity item

前面的 hyponymy 和 quantifier 合在一起，会给出一个可检验的预测。Cigar smoker 是 smoker 的 subset。

  • No American smokes ⟹ No American smokes cigars。把 B 换成它的 subset，真值保留：no 在这个位置是 downward entailing。
  • Every American smokes cigars ⟹ Every American smokes。把 B 换成它的 superset，真值保留：every 在这个位置是 upward entailing。

为什么这两个方向是对的，可以直接从 set 的定义推：no 要求 A∩B=∅A\cap B=\varnothingA∩B=∅，B 缩小成 B′⊆BB'\subseteq BB′⊆B，A∩B′⊆A∩B=∅A\cap B'\subseteq A\cap B=\varnothingA∩B′⊆A∩B=∅，仍然为空；every 要求 A⊆BA\subseteq BA⊆B，B 扩大成 B′⊇BB'\supseteq BB′⊇B，A⊆B⊆B′A\subseteq B\subseteq B'A⊆B⊆B′，仍然成立。

Any、ever、lift a finger、a red cent 这类词只能出现在某些位置，叫 negative polarity item（NPI）：

  • No one lifted a finger. / *Everyone lifted a finger.
  • John didn't lift a finger. / *John lifted a finger.

24.900 第 19 讲的 generalization：NPI 只能出现在不是 upward entailing 的位置。

determiner（看 B 的位置） downward upward 允许 NPI
no 是 否 是
every 否 是 否

这个 generalization 能做出一个不那么显然的预测。Every 在 A 的位置（restrictor）是 downward 的：Every American smokes ⟹ Every American from Ohio smokes，把 A 缩小，真值保留（理由是 A′⊆A⊆BA'\subseteq A\subseteq BA′⊆A⊆B）。所以预测 NPI 能出现在 every 的 restrictor 里，不能出现在 B 的位置：

  • Every student who has ever been to Paris loves it.（ever 在 restrictor 里，可以）
  • *Every student has ever been to Paris.（ever 在 B 的位置，不行）

两个判断都和预测一致。“哪个词能出现在哪里”这个看起来是 syntax 的问题，由 set 之间的 inclusion 关系决定了。

Monotonicity 也被用来测 neural model 的 inference。Yanaka 等（2019）为 natural language inference 建了一个专测 monotonicity 的 test set（MED），当时 state-of-the-art 的 NLI model 总体正确率低于 55%，在 downward 的 inference 上下降得尤其厉害。这是 2019 年的结果，不能直接推到现在的 LLM 上。

看起来对，其实不对Every 就是“全都”，所以和 no 正好相反

在 B 的位置上它们的方向确实相反：no 是 downward，every 是 upward。但 every 在 A 的位置是 downward 的，和 no 在 A 的位置一样（No American smokes ⟹ No American from Ohio smokes）。把 quantifier 当成一个整体的“正面”或“负面”词，就解释不了为什么 ever 能出现在 every student who has ever been to Paris 里。Monotonicity 是对每一个位置分别说的。

Some 为什么让人听出 not all

上一站给 some 的 meaning 是 A∩B≠∅A\cap B\ne\varnothingA∩B=∅。按这个定义，Some of the puppies escaped 在所有 puppy 都跑了的时候也为真。可是听者明明听出了“不是全部”。这多出来的信息不在 semantics 里，从哪里来？

Grice 的回答是：听者假定说话人在合作，即遵守 Cooperative Principle。它细分为四条 maxim：

  • Quantity：给出当前需要的信息量，不多也不少。
  • Quality：只说自己相信为真、有证据的话。
  • Relation：说相关的话。
  • Manner：说得清楚、有条理、不含糊。

从这几条出发，可以把“not all”推出来（Stanford Linguist 130A 的讲义用同样的步骤推导另一个例子）：

  1. 背景假设：说话人知道有几只 puppy 跑了。
  2. 假设说话人遵守 Cooperative Principle。
  3. 反设：说话人并不相信“不是全部跑了”。
  4. 结合 1，他相信全部跑了。
  5. 那么他本可以说 All of the puppies escaped，这句比 some 的那句 entail 得更多，信息量更大。
  6. 按 Quantity，他应该说信息量更大的那句。他没有说，所以第 3 步的反设不成立：他相信不是全部跑了。

这样由 Cooperative Principle 推出、不属于 semantics 的 inference 叫 conversational implicature。Some 和 all 构成一个按信息量排的 scale，说了弱的那个就意味着强的那个不成立，这种 implicature 叫 scalar implicature。同样的推理适用于 good 和 excellent、most 和 all：The play was good 让人听出“不算 excellent”。

数字也在这样的 scale 上。24.900 第 17 讲的例子：说 I am 21，听者听出“恰好 21 岁”；可是 I'm 21. In fact, I'm 50 并不矛盾，50 岁的人当然也满了 21 岁。所以“恰好 21”是 implicature，“至少 21”才是 semantics。

故意违反 maxim：flouting

上面的推导里，听者假定说话人遵守了 maxim，再推出他“没说的那部分”。NUS 笔记强调另一种情况：说话人明显地违反一条 maxim，而且知道听者看得出来，这时听者为了维持“对方仍在合作”的假定，会去找一个能解释这次违反的意思。这叫 flouting。

Grice 自己的例子（我没有读 Grice 原文，按通行的转述写）：一位教授给申请哲学教职的学生写推荐信，全文只有一句，Mr. X's command of English is excellent, and his attendance at tutorials has been regular。

  1. 推荐信需要的信息是 X 的哲学能力。这封信对此一字不提，明显违反 Quantity（信息太少）和 Relation（说的不相关）。
  2. 教授是 X 的老师，不可能不知道 X 的哲学水平，也不是不愿写（他写了信）。
  3. 读信的人假定教授仍在合作，就要找一个理由，解释他为什么只说这些。
  4. 唯一说得通的理由是：关于哲学能力他没有好话可说，而又不愿直接写出来。所以信的 implicature 是“X 的哲学不好”。

这和 puppies 的推导方向不同。Puppies 那里，说话人看起来遵守了 Quantity，implicature 来自“他本可以说更强的话”；这里，违反本身就是信号。NUS 笔记还区分了无意的违反：说话人不小心违反了 maxim，或者两人的 convention 不同（比如对“说多少才算够”的标准不同），听者照样会推出一个说话人并没打算传达的 implicature。所以 implicature 是听者推出来的，不保证是说话人想说的。

三种 inference 的 test

现在有三种“听者得到的信息”：entailment、presupposition、implicature。它们的行为不同，各有 test。

Cancellation：能不能在后面直接否认它？

  • Some of the puppies escaped; in fact, all of them did. 不矛盾。“not all”可以取消，是 implicature。
  • #Some of the puppies escaped, but none of them did. 矛盾。“至少一只跑了”取消不了，是 entailment。

Reinforcement：明说出来是不是多余？

  • Some, but not all, of the puppies escaped. 不多余，所以“not all”原来不是 entailment。

Projection：嵌进 negation、question、if 之后还在不在？ 这是 presupposition 的标志。SEP 用的句子是 It's the knave that stole the tarts，presuppose 有人偷了 tarts：

嵌入方式 句子 “有人偷了 tarts”
negation It isn't the knave that stole the tarts. 还在
question Is it the knave that stole the tarts? 还在
conditional If it's the knave that stole the tarts, he will be punished. 还在
modal Maybe it's the knave that stole the tarts. 还在

拿同一组 test 测 some 的“not all”：It's not the case that some of the puppies escaped 的意思是一只也没跑，“not all”跟着消失了，所以它不 project，不是 presupposition。

SEP 把三者总结成一张表：

entailment presupposition implicature
嵌入后是否保留（project） 否 是 否
嵌入时能否取消 能
不嵌入时能否取消 否 否 能

“嵌入时能否取消”指的是这类句子：In this court, it isn't the knave that steals the tarts: the king employs no knaves. 在 negation 下，presupposition 可以被后文取消；不嵌入时说 #It's the knave that stole the tarts, but there is no knave 就不行。

用这张表分析上一站的 John stopped smoking：“现在不抽”在 negation 下消失，不嵌入时取消会矛盾（#John stopped smoking, but he still smokes），是 entailment；“以前抽烟”在 negation、question（Did John stop smoking?）下都保留，是 presupposition。

看起来对，其实不对Implicature 就是“话里有话”，听者想推什么都行

Implicature 要能按 maxim 一步步算出来（calculability），而且有固定的性质：可以取消、明说不多余、换一个同义的说法照样产生（non-detachability）。Some of the puppies escaped 推出 not all，换成 A few of the puppies escaped 一样推出。听者凭印象“读出”的言外之意，如果不能这样推导，就不属于这里说的 implicature。

Speech act：说话就是做事

I now pronounce you husband and wife、I promise to come tomorrow、I name this ship the Queen Elizabeth：说出这些话就完成了一件事，这类句子 Austin 称为 performative。NUS 笔记给出判断一个 verb 能不能 performative 地用的三条 criteria：它描述的是一个自愿的行为；这个行为单靠说话就能完成；它能和 hereby 连用。I hereby promise to come 三条都满足，说的同时就做出了承诺；*I hereby insult you 不行，insult 要看听者是否觉得被冒犯，不是单靠说出这句话就能完成（这一例是我加的）。句子里用了这样一个 performative verb，illocution 就明说出来了，叫 explicit speech act；I'll come tomorrow 也可以是一个承诺，但没有明说，要靠听者推断。

一次说话可以从三个层面看：

  • Locution：说出一个有意义的句子，比如 You'll be more punctual in the future。
  • Illocution：这句话作为什么行为，同一句可以是预测、命令或威胁。
  • Perlocution：它在听者身上产生的效果，比如说服、吓到。

Hereby test 能把 illocution 和 perlocution 分开：I hereby urge you to shut the door 可以说，urge 是 illocution；*I hereby persuade you to shut the door 不行，说服要看听者是否被说服，是 perlocution。

Performative 要成功，还要满足 felicity condition。SEP 区分两种失败：misfire，行为根本没完成（一个没有授权的路人对船说“I name this ship…”，船并没有因此得名）；abuse，行为完成了但有缺陷（承诺一起吃午饭，心里根本不打算去，承诺仍然做出了，只是不真诚）。

Illocution 有哪几类？NUS 笔记用的分类是五类：

illocutionary type 做什么 例子（我加的）
representative 描述一个事态 It's raining.
directive 让听者去做一件事 Close the window.
question 让听者提供信息 What time is it?
commissive 让说话人自己承担一件事 I'll pay you back tomorrow.
declaration 改变一个对象的状态，说出来就使它成立 I declare the meeting closed.

句子在 grammar 上的形式叫 locutionary type，有三种：declarative（subject 在一个带 tense 或能带 tense 的 verb 前面）、imperative（没有带 tense 的 verb，subject 默认是 you）、interrogative（yes/no question 和 wh-question）。每类 illocution 有一个和它匹配的 locutionary type：

illocutionary type 匹配的 locutionary type
directive imperative
question interrogative
representative、commissive、declaration declarative

用匹配的形式说出来叫 direct speech act；形式和 illocution 不匹配时，叫 indirect speech act，NUS 笔记的说法是这时通常多传达了一点什么（客气、委婉、留余地）：

句子 形式 illocution
Pass the salt. imperative directive（request） direct
Can you pass the salt? interrogative directive（request） indirect
You're standing on my foot. declarative directive（要对方挪开） indirect

Can you pass the salt? 字面上是问能力，没有人会回答“yes”就不动。加上 please 是一个 test：Can you pass the salt, please? 只能理解为 request，不能理解为问能力，因为 please 只和 request 搭配。Mandarin 的 你能把盐递给我吗？ 也是同样的 indirect request。SEP 介绍的一种解释（Searle）把它看作 conversational implicature：问对方能不能做一件显然能做的事，这个问题本身没有用处，听者按 Cooperative Principle 推出说话人是在请求。

Text：pronoun 指谁

NUS 的大纲要求在 word、sentence、text 三个 level 看 meaning。Pronoun 的指称是 sentence level 和 text level 分工最清楚的地方。

Sentence 内：由 structure 限制。 24.900 第 20 讲的 data：

  • Susan likes herself.（herself = Susan）
  • Susan likes her.（her 不能 = Susan）
  • *Susan's father likes herself.

第三句里 Susan 就在 herself 前面，为什么不能当它的 antecedent？需要一个结构关系。定义：α c-command β，当且仅当每一个 dominate α 的 node 也 dominate β。Susan's father likes herself 里，NP Susan 被更大的 NP Susan's father dominate，而这个 NP 不 dominate herself，所以 Susan 不 c-command herself。三条 binding principle：

  • Principle A：herself、each other 这类 anaphor 必须在同一个 clause 里被一个 c-command 它的 antecedent bind。
  • Principle B：her 这类 pronoun 不能在同一个 clause 里被 bind。
  • Principle C：Susan 这类 name 不能被任何 c-command 它的东西 bind。

Principle C 解释了第 1 讲的一对句子：She thinks that Susan is smart 里 she 不能是 Susan，因为 she c-command Susan；Susan thinks that she is smart 里可以。After she came to MIT, Susan was happy 里 she 在前面却可以指 Susan，因为 she 在 adverbial clause 里，不 c-command Susan。决定因素是 c-command，不是先后顺序。

Structure 之外：由 context 决定。 Binding principle 只能排除。Principle B 说 pronoun 在自己的 clause 里必须 free，可它没说 pronoun 指的是哪一个；离开一个 sentence，c-command 根本不存在，pronoun 指谁只能看 context 和常识。即使在同一个 sentence 里，structure 允许的 antecedent 也常常不止一个。Levesque、Davis 与 Morgenstern 的 Winograd schema 专门把这一点做成 test：

  • The trophy doesn't fit in the brown suitcase because it's too big. What is too big?（the trophy）
  • The trophy doesn't fit in the brown suitcase because it's too small. What is too small?（the suitcase）

it 在 because 引导的 clause 里，和 the trophy、the suitcase 不在同一个 clause，Principle B 不禁止它指两者中的任何一个。两句只差一个词（论文叫 special word 和 alternate word），it 的 reference 就换了。决定它的是关于“放进去”的常识。论文对一个合格 schema 的要求是：有两个 party，pronoun 对两者在 grammar 上都说得通，换掉 special word 答案就翻转，人一读就知道答案，而且不能靠 selectional restriction 或 corpus 里的共现统计（他们叫 Google-proof）解决。论文说这类题最早出自 Winograd（1972）的例子：The town councillors refused to give the angry demonstrators a permit because they feared violence，把 feared 换成 advocated，they 就从 councillors 变成 demonstrators。Kocijan 等人回顾这项 challenge 的文章说，到 2019 年，基于大型 pretrained transformer、在这类题上 fine-tune 过的系统正确率已经超过 90%，而这个分数能说明多少“理解”，该文把它当作一个需要另外讨论的问题。

Dialect 还是 language

Cantonese 是 Chinese 的一个 dialect，还是一种 language？常见的标准是 mutual intelligibility：两种 variety 的说话人能互相听懂，就是同一个 language 的 dialect；听不懂，就是不同的 language。

把这个标准当作一个 definition 来检验。

  • Mandarin 和 Cantonese 的说话人一般听不懂对方，按这个标准是两种 language。可是两者共用书面语，传统上把 Cantonese 叫作“方言”。
  • Danish、Norwegian、Swedish 的说话人在相当程度上能互相听懂，却被叫作三种 language（24.900 第 22 讲把它们和 Mandarin/Cantonese、Portuguese/Spanish、分成 Serbian 和 Croatian 的 Serbo-Croatian 列在一起）。
  • 更根本的问题是 dialect continuum：相邻的 variety 能互相听懂，差别一路累积，两端听不懂。A 和 B 互通、B 和 C 互通，不推出 A 和 C 互通。

NUS 笔记的立场是把 mutual intelligibility 当作唯一的 linguistic criterion，一贯地用下去：Mandarin、Cantonese、Hokkien 互相听不懂，所以是三种 language，只是属于同一个 language family；共用的书面语不算数，因为 language 先于文字存在，要比较的是 phonology、lexicon 和 syntax。按这个立场，第一条的矛盾就消失了，代价是要承认“Chinese 的方言”这个日常说法在 linguistic 上不成立。第二条仍然是它的麻烦：按同样的标准，Danish、Norwegian、Swedish 应该算一种 language 的几个 dialect。笔记对 dialect 的定义也和日常说法不同：dialect 是一个 language 的完整 variety，在 phonology、lexicon、morphosyntax 每个层面都可以不同，比 accent（只在 phonology 上不同）、slang、jargon 都大；British English 和 American English 是两个 dialect，而 standard dialect 只是学校教、政府用的那一个，和别的 dialect 一样复杂、一样有规则。

最后一点说明，“能互相听懂”不是 transitive 的关系，所以它不是 equivalence relation，不可能把所有 variety 干净地分成一个个 language。实际的划分要靠别的东西：共用的标准语、国界、历史。24.900 引用的那句话概括得很直接：A language is a dialect with an army and a navy（Weinreich）。

24.900 还给出另一种看法（Chomsky）：真正存在的是每个人脑子里的 grammar，叫 i-language；“English”“Chinese”这样的 language 是很多 i-language 的模糊的 set，叫 e-language，linguistics 研究的对象是前者。

Nonstandard 也有规则：AAE 的 copula

African American English（AAE）常被说成“ungrammatical 的 English”。24.900 第 22 讲用几个特征说明它有自己的规则，而且这些规则可以精确地写出来。

Habitual be。 They usually be tired when they come home 表示经常性的状态；此刻的状态说 They tired right now，不能用 be。Standard English 没有这个区分，*They be tired right now 在 AAE 里同样不能说。AAE 在这里比 Standard English 多了一个 grammatical distinction。

Copula absence。 He is rich 在 AAE 里可以说成 He rich。但 is 不是随便都能省。Yale Grammatical Diversity Project 整理的规则是：

环境 Standard English 能否 contract AAE 能否省略
He is rich. He's rich. 能 He rich. 能
I don't care what you are.（clause 末尾） *I don't care what you're. 不能 *I don't care what you. 不能
It ain't a flower show, is it?（tag question） 不能 不能
He was rich.（past） was 不 contract 成 's 不能（省掉就成了 is 的意思）
I am driving. I'm driving. 能 *I driving. 不能

Labov（1969）的 generalization 是：Standard English 能把 is/are contract 的地方，AAE 能把它省略；不能 contract 的地方，AAE 也不能省略。前四行都符合。最后一行是例外：am 能 contract，却不能省略。所以这条 generalization 本身是一个 hypothesis，有它管不到的 data，这正是第 1 站说的那种情况。

对应不只在“能不能”上，也在“多常见”上。YGDP 转述 Labov 的统计：copula absence 在 gonna 前面最常见，其次是 -ing 形式的 verb 前，再其次是 adjective 和表示地点的成分前，在 NP 前最少；Standard English 的 contraction 按同样的顺序由多到少。YGDP 还列出两处要另外说明的地方：大多数说话人不在 it、what、that 后面省略 is（这里的 's 常和前面的 t 合在一起念成 i's、wha's、tha's），emphatic 的 is 也不能省（Allah IS God）。24.900 第 22 讲用的是同一个对照，只是换了一组环境：present 的 He rich，句末的 how rich he，infinitive 的 I want to be rich，past 的 He was rich，negation 的 He ain't rich 与 He not rich，每一个都和 Standard English 在同一位置能否 contract 并排比较。

看起来对，其实不对AAE 省掉 is 是因为说话人不在乎 grammar

如果是随意省略，clause 末尾的 is 也应该常被省掉。实际上那里从不省略，而且省略的分布和另一种 variety（Standard English）的 contraction 精确对应。一个没有规则的系统不会这样。母语者对 *I don't care what you 的判断和对 He rich 的判断一样稳定，这是 grammar 的标志。

Negative concord：两个 negative 不等于 positive

I didn't see nothing 常被当作“逻辑错误”：两个 negative 互相抵消，应该是“看到了东西”。24.900 第 22 讲把它放回第 6 站讲过的 NPI 旁边一起看。

Standard English 用 NPI：I didn't see anything；*I saw anything；问 What did you see?，可以答 Nothing，不能答 *Anything。Anything 自己没有 negative 的意思，只能出现在 negation 允许的位置。Greek 也是这样：Dhen idhe tipota（not saw anything）'He didn't see anything'，*Idhe tipota。

另一些语言用 negative concord：每个 negative 词都带 negation 的形式，合起来只表示一次 negation。

  • Italian：Non ho visto niente（not have seen nothing）'I didn't see anything'；问 What did you see?，答 Niente 'nothing'。
  • Ukrainian：Ja nikomu ne rozpovidala（I nobody not told）'I didn't tell anybody'。

“Concord”这个名字借自 agreement：Italian 的 quest-a farfall-a bell-a 'this beautiful butterfly' 每个词都带 feminine singular 的 -a，Lardil 的 diin-i mutha-n barnga-n 'this big rock'（accusative）每个词都带 case。同一个 feature 尽量标在每一个相关的词上，negation 也可以这样标。

English 两种系统都有：I didn't see anything 是 NPI 的 variety，I didn't see nothing（AAE 的 I ain't seen nothin）是 negative concord 的 variety。

看起来对，其实不对Two negatives make a positive，所以 I didn't see nothing 的意思是“看到了东西”

这把 natural language 的 negation 当成了 logic 里的 ¬。Italian 的 Non ho visto niente 有两个 negative，标准 Italian 的意思就是“什么都没看到”，没有人说 Italian 不合逻辑。说 I didn't see nothing 的人同样只表达一次 negation，就像 Italian 的 -a 标了三次也只表示一个 feminine singular。Negative concord 和 NPI 是两种都在许多语言里稳定存在的 grammar，哪一种成为 standard，是社会决定的。

Variation 是有结构的：Labov 的 department store

同一个 variety 内部，同一个人也会时而这样说、时而那样说。New York 的 English 里，fourth floor 的 r 有时发出来（constricted [r]），有时不发。Labov（1966）想知道这种 variation 是不是随机的。

Design。 三家 Manhattan 的百货公司，按社会地位从高到低：Saks Fifth Avenue、Macy's、S. Klein。Labov 装作顾客，问店员某个部门在哪，那个部门恰好在四楼，店员回答 fourth floor；他再说 Excuse me?，店员会更用力地重复一遍。这样每个店员给出 4 个可能有 r 的位置：fourth 和 floor，各一次随口的、一次 emphatic 的。一共 264 个店员：Saks 68、Macy's 125、S. Klein 71。

Hypothesis。 店员的说话方式会向顾客群靠拢，所以店的社会地位越高，店员的 [r] 越多。

结果。

62%、51%、20%，和店的地位顺序一致。第二遍 emphatic 的重复里 [r] 增加；Macy's 的店员两遍差得很大，emphatic 的那一遍接近 Saks 的水平，随口的那一遍低得多。一个“发不发 r”的细节，同时随社会地位和说话的正式程度系统地变化。

它能说明什么，不能说明什么。 它说明 variation 不是噪声，一个 variable 的频率是有结构的。但店员本人的社会背景没有被直接测量，“店的地位”只是一个 proxy；店员是否真的向顾客靠拢，也是 hypothesis 而不是被测到的东西。数据和 hypothesis 一致，但没有排除其他解释。

Language 与 mind：孩子怎样学会

第 5 站的 structure dependence，第 6 站的 NPI，第 7 站的 binding：没有人教过这些 rule。孩子是怎么学会的？24.900 第 25 讲把这叫 Plato's problem。

纠正不起作用。 24.900 引用的一段记录：孩子说 Nobody don't like me，父亲纠正“Say 'nobody likes me'”，重复了六次，孩子最后说 Oh! Nobody don't likes me。大人的纠正很少，就算有，孩子也很少照着改。

有限的 data 不能唯一决定 rule。 24.900 第 14、15 讲用一个 function 说明：已知 f(1)=1,f(2)=2,f(3)=3,f(4)=4f(1)=1,f(2)=2,f(3)=3,f(4)=4f(1)=1,f(2)=2,f(3)=3,f(4)=4，f(5)f(5)f(5) 是多少？f(n)=nf(n)=nf(n)=n 给出 5，但

f(n)=n+(n−1)(n−2)(n−3)(n−4)f(n)=n+(n-1)(n-2)(n-3)(n-4)f(n)=n+(n−1)(n−2)(n−3)(n−4)

在 n=1,2,3,4n=1,2,3,4n=1,2,3,4 时第二项都是 0，和 data 完全吻合，而 f(5)=5+4⋅3⋅2⋅1=29f(5)=5+4\cdot3\cdot2\cdot1=29f(5)=5+4⋅3⋅2⋅1=29。任何有限的 data 都和无穷多个 rule 一致，学习者必须对“哪种 rule 更可能”有某种偏好。讲义拿它说明的是 wh-movement：Bulgarian 的孩子听到 Kakvo na kogo e dal?（what to whom he-gave，'What did he give to whom?'）这种两个 wh-phrase 都移到句首的句子，他该得出“所有 wh-phrase 都移”，还是“最多移两个”“最多移三个”？听到的句子没有一句能把这几个 rule 分开。

争论在于这个偏好有多少是专门为 language 准备的、天生的。拿 structure dependence 说：

  • Innate 一方。 Crain 与 Nakayama（1987）让 30 个 3 到 5 岁的孩子说出带 relative clause 的 yes/no question。按他们的报告，孩子没有说出 *Is the man who tall is happy? 这种 linear rule 的产物。从没听过足够多这类 question 的孩子却从不尝试 linear rule，他们认为这说明 structure dependence 是天生的限制。
  • 另一方。 Ambridge、Rowland 与 Pine（2008）做了两项新的 elicited production 研究，发现孩子偶尔会犯 structure dependence 的错，而且 Is the boy who is smoking is crazy? 这类重复 auxiliary 的错误，和输入里词与词共现的频率有关。他们的结论是：现有 data 不支持“structure dependence 是 innate 的”，孩子可能是从本身具有 structure dependence 的输入里学到的。

“从输入里学到”的一个具体版本是 Reali 与 Christiansen 的 n-gram model：只统计 child-directed speech 里相邻两个、三个词的频率，再比较两个候选 question 哪个更可能。Berwick 等（2011）复核了这项工作，数字如下（Reali 与 Christiansen 的 test 是 100 对 grammatical 与 ungrammatical 的 question，例如 Is the little boy who is crying hurt? 对 Is the little boy who crying is hurt?；空格是 Berwick 等没有给出的数）：

model 选对 选错 分不出
bigram，Reali 与 Christiansen 的报告 96%
bigram，Kam 等的复现 87%
bigram，把 relative clause 里的 who、that 换成单独的 symbol（Kam 等） 20% 38% 42%

Kam 等给的解释是：正确的 question 里有 who is 这个 bigram，而 who is 在 main clause 的问句（Who is that?）里极常见；model 认出的是这个高频的词对，不是 relative clause 的结构。把 relative clause 的 who 和疑问词 who 分开记，这条捷径就断了，bigram 的正确率掉到 20%。这组数字说明“统计输入就能学会”这个说法需要比 n-gram 更强的 model；它不说明更强的 model 也做不到，这正是第 5 站 LLM 研究在测的东西。

分歧落在两处：孩子的错误到底有多罕见，以及输入里有多少 data 能直接支持 structural rule。第 5 站提到的 neural model 结果和这个争论有关，但它们用的 data 量比孩子多几个数量级，不能直接拿来裁决。

Language 与 thought：linguistic relativity

Language 会不会影响 thought？强的版本叫 linguistic determinism：语言决定人能怎样思考。弱的版本叫 linguistic relativity：语言影响思考。强版本很少有人辩护，争论集中在弱版本，而且要靠实验。

和 Mandarin 母语者直接有关的一个例子：Mandarin 用垂直的方向说时间，上个月 是 last month，下个月 是 next month。Boroditsky（2001）报告说，Mandarin 母语者在一个 spatial priming 任务里表现出对“垂直的时间”的偏好，English 母语者没有，并把它当作 language 影响 thought 的证据。

此后至少三项 replication 没有得到这个结果：Chen（2007）、January 与 Kako（2007）、Tse 与 Altarriba（2008）。Boroditsky、Fuhrman 与 McCormick（2011）用不同的任务报告了新的支持证据。Chen 与 O'Seaghdha（2013）的综述认为：这类效应是否出现，取决于任务、指导语用哪种语言、被试是否 bilingual、书写方向等许多因素；说两种语言的人“以根本不同的方式思考时间”，证据是弱的。

这个例子把争论落到一个可以检验的问题上：在哪个任务、哪种条件下，效应能被重复。

Pidgin 与 creole：结构从哪里来

Language acquisition 的争论里有一个极端的情形：如果孩子听到的输入本身几乎没有 grammar，他会学到什么？Pidgin 和 creole 就是这种情形。下面按 Middlebury College LNGT 101 的讲义来讲，NUS 笔记里的定义和它一致。

Pidgin。 说不同语言、又没有共同语言的人，为了贸易（历史上也包括奴隶制下的劳动）需要沟通，会很快凑出一套交流办法，叫 pidgin。它没有 native speaker。词汇多半来自当地占支配地位的语言，通常是殖民者的 English、French 或 Dutch，这个语言叫 lexifier（也叫 superstrate）；使用者各自的母语叫 substrate。讲义列出的 pidgin 的特点：

  • 词主要是 open class（noun、verb、adjective），preposition、determiner、conjunction 很少或没有；词少，所以一个词管很多意思（Solomon Islands Pidgin 的 stick 既是 stick 也是 tree），或者靠 compound（dog baby 'puppy'）。
  • 几乎没有 morphology：没有 plural、tense、aspect、agreement。
  • Word order 不固定，受说话人母语的影响；句子短，没有 embedding。

讲义引的 Hawaiian Pidgin English（HPE）：No can. I try hard get good ones. Before, plenty duck; now, no more. 没有 tense（时间靠 before、now 这样的词表达），没有 article，没有 embedded clause。

Creole。 在 pidgin 环境里长大的孩子，得到的 primary linguistic data 就是这样的句子。可是他们说出来的不是 pidgin：当一代人把 pidgin 当作第一语言习得时，它变成了 creole，一个有完整 grammar 的 natural language。讲义用 Hawaiian Creole English（HCE）和 HPE 对照：

HPE HCE
word order subject 总在 object 前，verb 的位置不定 SVO，其他语序只用于 pragmatic 的目的
article 有时有，用法很随意 da 标 known specific（听者知道是哪一个），wan 标 unknown specific，其余的 NP 不加 article
tense、modality、aspect 没有 bin 标 tense，go 标 modality，stei 标 aspect
embedding 没有 有，complementizer fo 用于假设的事，go 用于实际发生的事

HCE 的两个例句：

  • As tu bin get had taim reizing dag. 'The two of us used to have a hard time raising dogs.' bin 标过去。
  • Ai gata go haia wan kapinta go fiks da fom. 'I had to hire a carpenter to fix the form.' wan kapinta 是说话人知道、听者不知道的那个木匠；da fom 是双方都知道的那个；go fiks 引出一个实际发生了的 embedded event。对比 Mo beta a bin go hanalulu fo bai maiself 'It would have been better if I'd gone to Honolulu to buy it myself'，这里买东西没有发生，用的是 fo。

拿 HCE 的 article 和 English 比一下，能看出它不是“English 的简化版”：English 的 a 既用于 specific（I met a carpenter yesterday，有一个具体的人）也用于 nonspecific（I need a carpenter，随便哪个都行），HCE 的 wan 只用于前一种。这个区分在 lexifier 里没有对应的词，在 pidgin 输入里也没有。讲义的结论是：孩子把结构加到了输入上，加出了 preposition、article、tense 与 aspect 的 marker 和 embedded sentence。这和第 5 站、本站前面的 Plato's problem 是同一个问题，而且更尖锐，因为这里的输入连 English 那样的 grammar 都没有。这一页没有读到反对这种解读的材料（例如强调 substrate 语言影响的看法），所以只能说这是讲义给出的解释。

Creole 之后。 Creole 和它的 lexifier 往往并存，lexifier 是 standard，creole 被看作“nonstandard”。追求 prestige 的说话人向 standard 靠拢，叫 decreolization。结果是一条 post-creole continuum：最接近 standard 的一端叫 acrolect，离得最远的一端叫 basilect，中间是 mesolect。讲义举的 Guyanese 例子里，acrolect 的 I gave him one 在 basilect 一端是 Mɪ bɪn gi: æm wan，过去时间由 bɪn 标出，和 HCE 的 bin 是同一种手段。NUS 笔记举的例子是 Jamaican Creole：superstrate 是 English，substrate 包括 West Africa 的 Akan。

Language change：sound change 是有规律的

Latin、Greek 和 English 有一批意思相同的词（24.900 第 23 讲，最后两行是我补的）：

Latin Greek English 对应
duo dúo two d → t
decem déka ten d → t
ed-o éd-o eat d → t
genus genos kin g → k
ager agrós acre g → k
labium lip b → p
cannabis kánnabis hemp k → h，b → p

对应是成批出现的：Latin 和 Greek 的 d、g、b 在 English 里一律对应 voiceless 的 t、k、p；Latin 的 k、p、t 对应 English 的 fricative h、f、θ。这叫 Grimm's law（讲义同时列了 Rask 和 Grimm 两个名字），它说的是 English 所在的 Germanic 分支从共同的 proto-language 分出来时，整类 stop 一起变了：voiced stop 变成 voiceless stop，voiceless stop 变成 fricative。Sound change 在一个语言里成批、规则地发生，这个假设叫 Neogrammarian hypothesis，讲义的说法是：有了它，要找的就不再是“看起来像的词”的清单，而是“由规则的 sound law 联系起来的词”的清单。这让 comparative method 成为可能：先找规则的对应，再据此判断哪些词是 cognate，并 reconstruct 共同祖先的形式。讲义的例子是 Sanskrit ad-、Latin ed-、English eat，reconstruct 出 Proto-Indo-European 的 *ed- 'eat'：reconstruct 出来的形式不必和任何一个后代完全一样（Sanskrit 的 a 来自 *e）。

规则对应比表面的相似可靠得多。24.900 第 23 讲举了两个方向的反例。Armenian 的 erku 和 English 的 two、Greek 的 duo 是 cognate，表面并不像，所以相似不是必要条件。English 的 dog 和澳大利亚 Mbabaram 语的 dog（也是“狗”）表面一模一样，却没有任何关系：Mbabaram 的 dog 来自 *gudaga 'mastiff'（比较邻近语言 Yidiny 的 gudaga、Dyirbal 的 guda），English 的 dog 来自 Old English docga，所以相似也不是充分条件。讲义另外列了 Persian bad 与 English bad、Malay mata 与 Greek mati 'eye' 这类碰巧相似的词对。
