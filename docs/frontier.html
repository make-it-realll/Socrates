Introduction to Flow Matching and Diffusion Models

Flow matching 与 diffusion 入门

这门课只回答一个问题：怎样用 ODE/SDE 把 Gaussian noise 搬运成数据分布。它用 flow matching 把 diffusion、score matching、classifier-free guidance 统一成一套推导，6 讲就从 Euler 采样讲到 DiT 和 latent diffusion，最后一讲是 discrete diffusion。robot policy 里的 diffusion policy 和 flow matching action head 用的就是这套训练目标和 sampler，学完能读懂并自己改这些代码。

公开的材料6 段 lecture video（YouTube）和 slides 全部公开；lecture notes 公开（同时在 arXiv 2506.02070），课程页把 notes 当作主线；3 个 lab notebook 公开（Google Drive / Colab 链接），GitHub 仓库 eje24/iap-diffusion-labs 的 2026 branch 里有 labs/ 和 solutions/ 两套 notebook；没有公开 autograder，solutions 直接公开。2025 一期也还在线。

前置课程页写的是 linear algebra、multivariate calculus、basic probability、Python 和一些 PyTorch 经验。具体要会：Gaussian 的 reparameterization x = μ + σz、条件期望、向量场和 ODE 的 Euler 数值解、Brownian motion 的直觉；能自己写 PyTorch training loop。本站对应 ST2131（概率）、MA2101、DSA2102（ODE 数值解）、MA3220（ODE）、ST3236（随机过程）、CS3244。（本站：ST2131、MA2101、DSA2102、MA3220、ST3236、CS3244）

  • 值得做Lab 1: Simulating ODEs and SDEs

    实现 Euler 和 Euler-Maruyama simulator，写 Brownian motion、Ornstein-Uhlenbeck process 和 Langevin dynamics，在 2D Gaussian mixture 上观察 SDE 怎样把一个分布变成另一个。

    时间
    handout 未给出；估计 2 到 3 小时（自己的估计）。
    环境
    CPU 即可，free Colab 足够。可选的动画 cell 需要 ffmpeg，notebook 说要用 conda 安装，pip install ffmpeg 一般不行。
    • Euler-Maruyama 的噪声项是 √h · σ_t · z，不是 h · σ_t · z。diffusion coefficient 为 0 时它应与 Euler 完全一致，可以用这一点检查自己的 step。
    • OU process 的题目提示看 D = σ²/(2θ)：轨迹收敛到 N(0, D) 这个分布而不是一个点，3.2 节要你证明的 Langevin 与 OU 等价就是这个结论。
    • 仓库 changelog 记录过 Langevin dynamics 的 timestep bug（2025 年 3 月修复）和 Colab + Chrome 导出 PDF 被截断的问题；用 2026 branch 的 notebook，导出后检查 PDF 是否完整。

    提示来源：第 1、2 条来自 lab notebook 正文；第 3 条来自 GitHub 仓库 eje24/iap-diffusion-labs 的 README changelog。

  • 先做Lab 2: Flow Matching and Score Matching

    实现 Gaussian conditional probability path（α_t = t，β_t = √(1−t)）、conditional vector field 和 conditional score，用 MLP 训练 flow matching 和 score matching，再从学到的 vector field 推出 score，最后用 linear path 在两个任意分布之间做 flow。

    时间
    handout 未给出；notebook 说每次训练约 1 分钟，整份估计 3 到 4 小时（自己的估计）。
    环境
    2D toy data，CPU 或 free Colab 都够。
    • conditional SDE 采样在 σ 不大时就可能数值爆炸：t → 1 时 β_t → 0，score 项 (α_t z − x)/β_t² 发散，并且随 σ² 放大。notebook 给的处理是取 σ_t = β_t，让噪声和发散项一起衰减；自己写 sampler 时也不要在 t = 1 处直接求值。
    • flow matching 和 score matching 的 loss 会收敛但不会到 0。target 是 conditional field，模型学的是 marginal field，二者之差的方差不为 0，所以 loss 平台高不代表实现错了。
    • 从 vector field 换算 score 时分母是 β_t²α̇_t − α_t β̇_t β_t，只在 t ∈ [0,1) 非零；linear path 的 conditional vector field (z − x)/(1 − t) 也只在 [0,1) 有定义。时间网格要避开端点。
    • 2026 年 1 月仓库修过 ConditionalVectorFieldSDE 和 LangevinFlowSDE 中 diffusion coefficient 被重复乘的 bug（changelog 称为 doubly stochastic），用旧 notebook 会得到错误的 SDE 采样图。

    提示来源：第 1 至 3 条来自 lab notebook 的说明和公式；第 4 条来自仓库 README changelog。

  • 先做Lab 3: Diffusion Transformer and VAEs（conditional generation on MNIST）

    在 MNIST 上做 class-conditional 生成：实现 classifier-free guidance 的训练目标，从零写 DiT（Fourier time encoder、patchifier、multi-head attention、adaLN-Zero、depatchifier），再训练一个 VAE，并在它的 latent space 里训练 latent DiT。

    时间
    handout 未给出；notebook 注释写 DiT 约 15 个 A100 分钟能得到合理结果，整份估计 6 到 8 小时（自己的估计）。
    环境
    需要 GPU。free Colab T4 能跑，但比 A100 慢不少，DiT 训练估计要几十分钟（自己的估计）；VAE 和 latent DiT 还要再各训一次。
    • CFG 用 label 10 当 null label，所以 nn.Embedding 要开 11 类；训练时按概率 η 把 label 换成 10。采 t 用 torch.rand（uniform），采噪声用 torch.randn，notebook 特意提醒不要混。
    • 先用 2D GMM + MLP 跑 Sanity Check 2.4，确认 CFG trainer 和 guided ODE 没问题再上图像，图像上的 bug 很难从样本里看出来。
    • adaLN-Zero 指把 conditioning MLP 的最后一层 zero-init，让每个 block 初始时接近恒等映射，notebook 说这对稳定训练有帮助。positional encoding 可以直接用 nn.Parameter(torch.randn(n_tokens, dim))，加的时候注意 broadcasting。
    • latent trainer 里 vae.encode 要包在 torch.no_grad() 下（notebook 提示）；否则 VAE 的计算图会一起保留，显存明显上涨（后半句是自己的经验）。
    • 仓库 changelog 记录过 guidance embedding 维度 bug 和 solutions 中采样 conditioning variable 的 bug（均已修复），卡住时对照 2026 branch 的 solutions。

    提示来源：第 1 至 4 条前半来自 lab notebook 的 hints；第 4 条后半是自己的经验；第 5 条来自仓库 README changelog。
