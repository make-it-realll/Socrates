概念线

同一个想法在不同课里换着名字出现。一条概念线把这些地方串起来。

  • 看到证据之后有了新观测，原来的判断该怎么改。从一道条件概率题，一直通到机器人怎样知道自己在哪。
  • 最小二乘方程比未知数多、数据带噪声时，找“最不坏”的解。它在数值、统计、控制三条线上各有一个名字。

怎么用

每门课拆成几站

一站是一项能力。每站开头写明 3、4、5 级分别要做到什么，有往年卷子的课，4 级直接对应卷子上的某道题。

每站的写法固定

先说这一站要解决什么问题，再摆出一个看起来对的错想法，说清它错在哪，然后才是正确的推导、图解和边界情况。

等级自己点

0 没听过，1 听过，2 能跟上，3 有提示能做，4 能独立做，5 能讲给别人。网站没法考你，所以要对自己严一点：没独立做出来过，就不算 4。

想被提问

课程页里“复制进度块”，贴到 Claude 对话里说 “resume from:”，那边会按你的等级接着问。

讲义是按公开课、课程大纲和可查到的往年卷子写的自学笔记，不是任何课程的官方材料，可能有错。往年卷子的原题不在本站，页面里给的是图书馆的链接。

等级是你自己点的，只存在这台设备的浏览器里。
