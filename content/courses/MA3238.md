$$h_i=0.4\,h_{i-1}+0.6\,h_{i+1},\qquad i\ge1$$

$h_i=1$（对所有 $i$）满足它：$0.4+0.6=1$。$h_i=(2/3)^i$ 也满足它：

$$0.4\left(\tfrac23\right)^{i-1}+0.6\left(\tfrac23\right)^{i+1}=\left(\tfrac23\right)^{i-1}\left(0.4+0.6\cdot\tfrac49\right)=\left(\tfrac23\right)^{i-1}\cdot\tfrac23=\left(\tfrac23\right)^{i}$$

## [hit] Stopping time、strong Markov property 与 minimal solution

:::skip
能判断一个 random time 是不是 stopping time，能对 infinite chain 写出 first-step equations 的整族 nonnegative solution，并用 minimal solution theorem 挑出真实的那一个，就可以去第 2 站。
:::

### 什么样的 random time 之后，chain 会重新开始

First-step analysis 和 ST3236 里“返回次数是 Geometric”的论证都用到同一件事：chain 到了某个 state 之后，像从那里重新出发一样往下走。Markov property 只对固定的时刻 $m$ 保证这件事。可我们关心的时刻是 random 的：第一次碰到 0 的时刻、第一次回到 $k$ 的时刻。什么样的 random time 也行？

设 $T$ 取值于 $\{0,1,2,\dots\}\cup\{\infty\}$。如果对每个 $n$，event $\{T=n\}$ 只由 $X_0,\dots,X_n$ 决定，就称 $T$ 是 stopping time。意思是：走到第 $n$ 步时，看着已经发生的 path 就能判断“是不是现在停”，不用偷看未来。

用一次这个定义。设 $A$ 是一个 state 的集合，$H^A=\inf\{n\ge0:X_n\in A\}$ 是第一次碰到 $A$ 的时刻（碰不到记作 $\infty$）。

$$\{H^A=n\}=\{X_0\notin A,\ \dots,\ X_{n-1}\notin A,\ X_n\in A\}$$

右边只涉及 $X_0,\dots,X_n$，所以 $H^A$ 是 stopping time。第一次返回的时刻 $T_k=\inf\{n\ge1:X_n=k\}$ 同理。

反过来看一个不是的。在 $\mathbb Z$ 上的 random walk（往右 0.6）里，从 0 出发，令 $L$ 为“第一次碰到 5 之前，最后一次在 0 的时刻”。要判断 $L=n$，得知道 $n$ 之后 path 在碰到 5 之前再也不回 0，这要看未来，所以 $L$ 不是 stopping time。

**Strong Markov property。** 设 $T$ 是 stopping time。在 $T<\infty$、$X_T=i$ 的条件下，$(X_{T+n})_{n\ge0}$ 是从 $i$ 出发、transition matrix 为 $P$ 的 Markov chain，而且和 $X_0,\dots,X_T$ independent。

Proof。取任意一个由 $X_0,\dots,X_T$ 决定的 event $B$，也就是说对每个 $m$，$B\cap\{T=m\}$ 由 $X_0,\dots,X_m$ 决定。在 $\{T=m\}$ 上，$X_{T+r}=X_{m+r}$，所以

$$P\big(\{X_T=j_0,\dots,X_{T+n}=j_n\}\cap B\cap\{T=m,\,X_T=i\}\big)=P\big(\{X_m=j_0,\dots,X_{m+n}=j_n\}\cap B\cap\{T=m,\,X_m=i\}\big)$$

$B\cap\{T=m,X_m=i\}$ 只由 $X_0,\dots,X_m$ 决定，而 $m$ 是一个固定的时刻，对它用普通的 Markov property：

$$=P_i(X_0=j_0,\dots,X_n=j_n)\;P\big(B\cap\{T=m,\,X_T=i\}\big)$$

对 $m=0,1,2,\dots$ 求和：

$$P\big(\{X_T=j_0,\dots,X_{T+n}=j_n\}\cap B\cap\{T<\infty,\,X_T=i\}\big)=P_i(X_0=j_0,\dots,X_n=j_n)\;P\big(B\cap\{T<\infty,\,X_T=i\}\big)$$

两边除以 $P(T<\infty,X_T=i)$，左边是 conditional probability，它分解成“从 $i$ 出发的 path probability”乘“$B$ 的 conditional probability”。前一个因子说明 $(X_{T+n})$ 是从 $i$ 出发的 chain，乘积的形式说明它和 $B$ independent。证毕。

Proof 里唯一用到 stopping time 的地方，是 $B\cap\{T=m\}$ 只由 $X_0,\dots,X_m$ 决定。$T$ 若要偷看未来，这一步就不成立。

:::wrong 任何 random time 之后 chain 都重新开始
拿上面的 $L$ 检验。$X_L=0$，如果 chain 在 $L$ 之后重新开始，下一步应该以 0.6 往右、0.4 往左。但实际上 $X_{L+1}=1$ 的 probability 是 1：假如 $X_{L+1}=-1$，walk 每步只走一格，要碰到 5 必须先经过 0，这和“$L$ 是最后一次在 0”矛盾。$L$ 的定义里已经用掉了未来的信息（“之后不再回 0”），chain 在它之后的走法自然被这个信息扭曲了。
:::

### First-step equations 从哪里来

记 $h^A_i=P_i(H^A<\infty)$，从 $i$ 出发最终碰到 $A$ 的 probability。$i\in A$ 时 $H^A=0$，$h^A_i=1$。$i\notin A$ 时 $H^A\ge1$，按第一步分情况：

$$h^A_i=\sum_jP_i(X_1=j)\,P_i(H^A<\infty\mid X_1=j)=\sum_jp_{ij}\,h^A_j$$

第二个等号是对固定时刻 1 用 Markov property：$i\notin A$，所以“碰到 $A$”等于“从时刻 1 往后的 chain 碰到 $A$”，而后者从 $j$ 重新开始。于是 $h^A$ 满足

$$h_i=1\ (i\in A),\qquad h_i=\sum_jp_{ij}h_j\ (i\notin A)$$

开头的例子里 $A=\{0\}$，这就是那个 equation 组。

### 一个 equation 组，一整族 solution

先把开头那个例子的 solution 全部找出来。$h_i=0.4h_{i-1}+0.6h_{i+1}$ 是 second-order linear recurrence，$h_0$ 和 $h_1$ 一旦给定，后面每一项都被确定（$h_{i+1}=(h_i-0.4h_{i-1})/0.6$）。所以 solution 构成一个 2 维的 space。试 $h_i=r^i$：

$$r^i=0.4r^{i-1}+0.6r^{i+1}\iff0.6r^2-r+0.4=0\iff r=\frac{1\pm\sqrt{1-0.96}}{1.2}=\frac{1\pm0.2}{1.2}$$

两个 root 是 1 和 $\tfrac23$。全部 solution 是 $h_i=a+b(2/3)^i$，再用 $h_0=1$ 得 $b=1-a$：

$$h_i=a+(1-a)\left(\tfrac23\right)^i$$

哪些是 nonnegative 的？$i\to\infty$ 时 $h_i\to a$，所以 $a<0$ 不行。$0\le a\le1$ 时两项都非负。$a>1$ 时 $h_i=a-(a-1)(2/3)^i\ge a-(a-1)=1$，也非负（只是大于 1，不像 probability）。所以 nonnegative solution 恰好是 $a\ge0$ 这一族，其中最小的是 $a=0$。

::fig[ma3238-minimal] 四条 curve 是 $a=0,0.5,1,1.5$ 时的 $h_i$。方块是从“只有 $A$ 上为 1”开始 iterate 得到的 $P_i(H\le n)$：$n=3,10,50$ 时一层层往上，越来越贴近 $a=0$ 那条，但永远在它下面。

### Theorem：真实的 hitting probability 是 minimal nonnegative solution

**Theorem。** $h^A$ 是上面 equation 组的 nonnegative solution 里最小的那个：若 $x\ge0$ 满足 $x_i=1\ (i\in A)$、$x_i=\sum_jp_{ij}x_j\ (i\notin A)$，则对所有 $i$，$x_i\ge h^A_i$。

Proof。$i\in A$ 时 $x_i=1=h^A_i$。设 $i\notin A$，把 $j$ 按在不在 $A$ 里分开：

$$x_i=\sum_{j\in A}p_{ij}+\sum_{j\notin A}p_{ij}x_j$$

对 $j\notin A$ 的 $x_j$ 再用一次同一个 equation：

$$x_i=\sum_{j\in A}p_{ij}+\sum_{j\notin A}p_{ij}\sum_{k\in A}p_{jk}+\sum_{j\notin A}\sum_{k\notin A}p_{ij}p_{jk}x_k$$

前两项各有意义：第一项是 $P_i(X_1\in A)$，第二项是 $P_i(X_1\notin A,X_2\in A)$。合起来是 $P_i(H^A\le2)$。这样代 $n$ 次，

$$x_i=P_i(H^A\le n)+\sum_{j_1,\dots,j_n\notin A}p_{ij_1}p_{j_1j_2}\cdots p_{j_{n-1}j_n}\,x_{j_n}$$

最后那个和里每一项都 $\ge0$，所以 $x_i\ge P_i(H^A\le n)$。Event $\{H^A\le n\}$ 随 $n$ 增大，union 是 $\{H^A<\infty\}$，由 probability 的 continuity，$n\to\infty$ 得 $x_i\ge P_i(H^A<\infty)=h^A_i$。上一节已经 prove 了 $h^A$ 本身满足 equation 组，所以它就是最小的那个。证毕。

拿开头的例子检验：nonnegative solution 是 $a\ge0$ 那一族，最小的是 $a=0$，所以

$$h_i=\left(\tfrac23\right)^i,\qquad h_1=\tfrac23\approx0.667$$

Proof 里的 $P_i(H\le n)$ 也可以直接算出来：令 $h^{(0)}_i=\mathbf 1\{i\in A\}$，每次用 $h^{(n+1)}_i=\sum_jp_{ij}h^{(n)}_j$（$i\notin A$）update，$h^{(n)}_i$ 恰好是 $P_i(H^A\le n)$。对这个例子实际 iterate，$h^{(n)}_1$ 依次是 0.4（$n=1$）、0.496（$n=3$）、0.588（$n=10$）、0.659（$n=50$）、0.6666（$n=200$），从下面爬向 $\tfrac23$。这就是上图的方块。这个结果也和 ST3236 [第 4 站](../courses/ST3236.html#rec)里“没有上界时输光的 probability 是 $(q/p)^x$”一致，那里是从 finite 的 gambler's ruin 让上界 $N\to\infty$ 得到的。

同一个 theorem 也能处理方向反过来的情形。若每步往左 0.6、往右 0.4，equation 是 $h_i=0.6h_{i-1}+0.4h_{i+1}$，root 是 1 和 $\tfrac32$，solution 是 $h_i=a+(1-a)(3/2)^i$。$a>1$ 时 $(1-a)(3/2)^i\to-\infty$，不是 nonnegative；$a\le1$ 时 $h_i\ge a+(1-a)=1$。最小的是 $a=1$：往 0 漂的 walk 一定会到 0。

### Expected hitting time 也取 minimal

记 $k^A_i=E_i[H^A]$。同样按第一步分情况：$i\in A$ 时 $k^A_i=0$；$i\notin A$ 时多走了一步，

$$k^A_i=1+\sum_{j\notin A}p_{ij}k^A_j$$

**Theorem。** $k^A$ 是这个 equation 组的 minimal nonnegative solution。

Proof 和上面一样代下去。设 $x\ge0$ 是 solution，$i\notin A$：

$$x_i=1+\sum_{j\notin A}p_{ij}x_j=1+\sum_{j\notin A}p_{ij}+\sum_{j\notin A}\sum_{k\notin A}p_{ij}p_{jk}x_k$$

$1=P_i(H^A\ge1)$，$\sum_{j\notin A}p_{ij}=P_i(H^A\ge2)$。代 $n$ 次后丢掉非负的余项：

$$x_i\ge P_i(H^A\ge1)+P_i(H^A\ge2)+\dots+P_i(H^A\ge n)\ \xrightarrow{n\to\infty}\ \sum_{m\ge1}P_i(H^A\ge m)=E_i[H^A]$$

最后一步是 nonnegative integer random variable 的 tail-sum formula。证毕。

用一次。把方向反过来：往右 0.4、往左 0.6，问从 $i$ 走到 0 平均要几步。Equation 是 $k_0=0$，$k_i=1+0.4k_{i+1}+0.6k_{i-1}$。先猜一个 particular solution $k_i=ci$：

$$ci=1+0.4c(i+1)+0.6c(i-1)=1+ci-0.2c\iff c=5$$

再加上 homogeneous 部分（root 是 1 和 $\tfrac32$）：$k_i=5i+a+b(3/2)^i$，$k_0=0$ 给出 $a=-b$，

$$k_i=5i+b\left[\left(\tfrac32\right)^i-1\right]$$

$b<0$ 时 $(3/2)^i$ 那一项最终压过 $5i$，$k_i$ 变成负的；$b\ge0$ 时都非负。最小的是 $b=0$，所以 $k_i=5i$：每一步平均净往左 $0.6-0.4=0.2$ 格，走 $i$ 格要 $5i$ 步。

## [inv] Invariant measure：存在、唯一与 positive recurrence

:::skip
能用“一个 excursion 里的 expected 访问次数”造出 invariant measure，说清它为什么 up to scaling 唯一，并由 $\sum_i\gamma^k_i=m_k$ 区分 positive recurrent 和 null recurrent，就可以去第 3 站。
:::

### ST3236 留下的两个缺口

ST3236 [第 5 站](../courses/ST3236.html#stat)用 law of large numbers 说明：每次回到 $y$ 切出一个 i.i.d. 的 cycle，所以访问 $y$ 的 frequency 是 $1/m_y$。这说明了 frequency 是多少，没有说明两件事：这组 frequency 为什么满足 $\pi P=\pi$；$\pi P=\pi$ 的 solution 为什么只有一个。

在 infinite chain 上，这两件事都不是理所当然的。先放宽一点：nonnegative 的 row vector $\mu$（允许 $\sum_i\mu_i=\infty$）若满足 $\mu P=\mu$，叫 invariant measure；总和为 1 的才叫 stationary distribution。

看 $\mathbb Z$ 上往右 $p=0.6$、往左 $q=0.4$ 的 walk。$\mu P=\mu$ 写出来是 $\mu_j=0.6\,\mu_{j-1}+0.4\,\mu_{j+1}$。$\mu_j=1$ 满足它。$\mu_j=1.5^j$ 也满足它：

$$0.6\cdot1.5^{j-1}+0.4\cdot1.5^{j+1}=1.5^{j-1}(0.6+0.4\times2.25)=1.5^{j-1}\times1.5=1.5^j$$

两个 measure 不成比例。这条 walk 是 transient 的（第 1 站：从 1 出发只有 $\tfrac23$ 的 probability 回到 0），所以“唯一”一定需要什么条件。下面三个 theorem 说清楚，需要的就是 recurrence。

### 用一次 excursion 造出 invariant measure

固定一个 state $k$，令 $T_k=\inf\{n\ge1:X_n=k\}$。从 $k$ 出发、回到 $k$ 之前（时刻 $0,1,\dots,T_k-1$）访问 $i$ 的 expected 次数记作

$$\gamma^k_i=E_k\sum_{n=0}^{T_k-1}\mathbf 1\{X_n=i\}$$

$\gamma^k_k=1$：时刻 0 在 $k$，之后到 $T_k$ 之前都不在 $k$。

**Theorem（存在）。** 设 $P$ irreducible 且 recurrent。则 $\gamma^kP=\gamma^k$，而且对每个 $i$，$0<\gamma^k_i<\infty$。

Proof。Recurrent 意味着 $P_k(T_k<\infty)=1$，而 $X_0=X_{T_k}=k$。所以把求和范围从 $n=0,\dots,T_k-1$ 挪成 $n=1,\dots,T_k$，丢掉的 $n=0$ 那项和补上的 $n=T_k$ 那项都等于 $\mathbf 1\{i=k\}$，总和不变：

$$\gamma^k_j=E_k\sum_{n=1}^{T_k}\mathbf 1\{X_n=j\}=\sum_{n=1}^{\infty}P_k(X_n=j,\ n\le T_k)$$

（第二个等号把 random 的求和上限写成 indicator $\mathbf 1\{n\le T_k\}$，再交换 expectation 和求和，各项非负，可以交换。）按前一步在哪里分情况：

$$\gamma^k_j=\sum_i\sum_{n=1}^\infty P_k(X_{n-1}=i,\ n\le T_k,\ X_n=j)$$

$\{n\le T_k\}=\{T_k\le n-1\}^c$，它是否发生只看 $X_0,\dots,X_{n-1}$。所以对固定时刻 $n-1$ 用 Markov property：

$$P_k(X_{n-1}=i,\ n\le T_k,\ X_n=j)=P_k(X_{n-1}=i,\ n\le T_k)\;p_{ij}$$

代回去，令 $m=n-1$：

$$\gamma^k_j=\sum_ip_{ij}\sum_{m=0}^\infty P_k(X_m=i,\ m\le T_k-1)=\sum_i\gamma^k_i\,p_{ij}$$

这就是 $\gamma^kP=\gamma^k$。由它得 $\gamma^kP^n=\gamma^k$ 对所有 $n$ 成立。Irreducible，所以对每个 $i$ 有 $n,m$ 使 $p^{(n)}_{ik}>0$、$p^{(m)}_{ki}>0$。于是

$$\gamma^k_i=\sum_j\gamma^k_jp^{(m)}_{ji}\ge\gamma^k_k\,p^{(m)}_{ki}=p^{(m)}_{ki}>0,\qquad 1=\gamma^k_k=\sum_j\gamma^k_jp^{(n)}_{jk}\ge\gamma^k_i\,p^{(n)}_{ik}$$

后一个给出 $\gamma^k_i\le1/p^{(n)}_{ik}<\infty$。证毕。

Recurrence 只在第一步用到：它保证 $X_{T_k}=k$，从而求和范围可以挪一格。

### 算一个：reflecting random walk

取 ST3236 [第 4 站](../courses/ST3236.html#rec)的 reflecting random walk：state $0,1,2,\dots$，每步往上 $p=0.4$、往下 $q=0.6$，在 0 往下就留在 0。用 cut（ST3236 [第 5 站](../courses/ST3236.html#stat)）：$0.4\,\pi_i=0.6\,\pi_{i+1}$，所以 $\pi_i=\tfrac13(2/3)^i$，它是 positive recurrent 的。按 theorem，$\gamma^0$ 应该正比于它，而 $\gamma^0_0=1$，所以应该有 $\gamma^0_i=(2/3)^i$。不借助 $\pi$，直接按定义算一遍。

$i\ge1$ 时，一次 excursion 里访问 $i$ 的次数，要么是 0（还没到 $i$ 就回了 0），要么从第一次到 $i$ 起，每次在 $i$ 都以同样的 probability $e_i$ 一去不回（先到 0），以 $1-e_i$ 再回到 $i$。由 strong Markov property（第一次到 $i$ 的时刻、每次返回 $i$ 的时刻都是 stopping time），访问次数在到过 $i$ 的条件下是 Geometric，mean $1/e_i$。所以

$$\gamma^0_i=P_0(\text{回到 0 之前到达 } i)\times\frac1{e_i}$$

两个 probability 都是 gambler's ruin。记 $r=q/p=1.5$，ST3236 [第 2 站](../courses/ST3236.html#fsa)给出：从 $x$ 出发、先碰到 $N$ 而不是 0 的 probability 是 $\dfrac{r^x-1}{r^N-1}$。

- 从 0 出发，第一步必须往上（probability 0.4），然后从 1 出发先到 $i$：$P_0(\cdot)=0.4\times\dfrac{1.5-1}{1.5^i-1}=\dfrac{0.2}{1.5^i-1}$。
- 从 $i$ 出发，往上一步之后一定会回到 $i$（往下漂，第 1 站最后那个例子），所以一去不回只能是先往下一步（0.6），再从 $i-1$ 先到 0：

$$e_i=0.6\left(1-\frac{1.5^{i-1}-1}{1.5^i-1}\right)=0.6\cdot\frac{1.5^i-1.5^{i-1}}{1.5^i-1}=\frac{0.3\times1.5^{i-1}}{1.5^i-1}$$

相乘，$1.5^i-1$ 消掉：

$$\gamma^0_i=\frac{0.2}{1.5^i-1}\cdot\frac{1.5^i-1}{0.3\times1.5^{i-1}}=\frac23\cdot\left(\frac23\right)^{i-1}=\left(\frac23\right)^i$$

和预期一致。加起来 $\sum_i\gamma^0_i=1/(1-\tfrac23)=3$，正好是 ST3236 算过的 mean return time $m_0=3$。这不是巧合：一次 excursion 的长度 $T_0$ 等于它在各个 state 的访问次数之和，取 expectation，

$$m_k=E_k[T_k]=\sum_i\gamma^k_i$$

::fig[ma3238-cycle] 左边是一次真实的 excursion，第 18 步回到 0；每个圆点是一次访问，level 0 到 5 分别 1、2、3、5、5、2 次，加起来 18。右边是 $10^5$ 次 excursion 的平均（JavaScript 的 mulberry32 generator，seed 7），和竖线 $(2/3)^i$ 对齐到小数点后两位。

同样的算法用在 $\mathbb Z$ 上的 symmetric random walk：从 0 出发先到 $i\ge1$ 再回 0 的 probability 是 $\tfrac12\cdot\tfrac1i$；从 $i$ 一去不回的 probability 也是 $\tfrac12\cdot\tfrac1i$（往下一步，再从 $i-1$ 先到 0；往上一步一定回来，因为它 recurrent）。所以 $\gamma^0_i=1$，负的一侧对称。Invariant measure 是 $\mu\equiv1$，总和是 $\infty$，正对应 $m_0=\infty$（null recurrent）。

### 唯一性

**Theorem（唯一）。** 设 $P$ irreducible，$\lambda$ 是 invariant measure 且 $\lambda_k=1$。则 $\lambda\ge\gamma^k$。如果 $P$ 还是 recurrent 的，则 $\lambda=\gamma^k$。

Proof。对任意 $j$，用 $\lambda=\lambda P$，把 $i_0=k$ 那项单独拿出来（$\lambda_k=1$）：

$$\lambda_j=\sum_{i_0}\lambda_{i_0}p_{i_0j}=p_{kj}+\sum_{i_0\ne k}\lambda_{i_0}p_{i_0j}$$

对 $\lambda_{i_0}$ 再做一次同样的展开：

$$\lambda_j=p_{kj}+\sum_{i_0\ne k}p_{ki_0}p_{i_0j}+\sum_{i_0\ne k}\sum_{i_1\ne k}\lambda_{i_1}p_{i_1i_0}p_{i_0j}$$

第一项是 $P_k(X_1=j)$，第二项是 $P_k(X_1\ne k,X_2=j)$。展开 $n$ 次，丢掉非负的余项：

$$\lambda_j\ge\sum_{m=1}^{n}P_k(X_1\ne k,\dots,X_{m-1}\ne k,\ X_m=j)=\sum_{m=1}^nP_k(X_m=j,\ m\le T_k)$$

$j\ne k$ 时，$X_m=j$ 说明 $m\ne T_k$，所以 $m\le T_k$ 就是 $m\le T_k-1$。令 $n\to\infty$，右边是 $\gamma^k_j$。$j=k$ 时 $\lambda_k=1=\gamma^k_k$。所以 $\lambda\ge\gamma^k$。

再设 $P$ recurrent。由存在性 theorem，$\gamma^k$ 是 invariant measure，所以 $\mu=\lambda-\gamma^k$ 是 nonnegative 的 invariant measure，且 $\mu_k=0$。对任意 $i$，取 $n$ 使 $p^{(n)}_{ik}>0$：

$$0=\mu_k=\sum_j\mu_jp^{(n)}_{jk}\ge\mu_i\,p^{(n)}_{ik}$$

所以 $\mu_i=0$。$\lambda=\gamma^k$。证毕。

回到开头 transient 的例子：$\lambda_j=1$ 和 $\lambda_j=1.5^j$ 都满足 $\lambda_0=1$，前半个结论 $\lambda\ge\gamma^0$ 对两个都成立，后半个结论用不了，因为没有 recurrence，$\gamma^0$ 本身就不是 invariant 的。

### Stationary distribution 存在当且仅当 positive recurrent

**Theorem。** 设 $P$ irreducible。下面三条等价：(i) 每个 state positive recurrent；(ii) 某个 state $k$ positive recurrent；(iii) 存在 stationary distribution $\pi$。而且这时 $\pi_k=1/m_k$ 对每个 $k$ 成立，$\pi$ 唯一。

Proof。(i)$\Rightarrow$(ii) 不用证。

(ii)$\Rightarrow$(iii)：$k$ positive recurrent，当然 recurrent；recurrence 是 class property（ST3236 [第 3 站](../courses/ST3236.html#class)），所以整条 chain recurrent。存在性 theorem 给出 invariant 的 $\gamma^k$，而 $\sum_i\gamma^k_i=m_k<\infty$。令 $\pi_i=\gamma^k_i/m_k$，它是 stationary distribution。

(iii)$\Rightarrow$(i)：任取 state $k$。先说明 $\pi_k>0$：$\sum_i\pi_i=1$，总有某个 $\pi_j>0$；取 $n$ 使 $p^{(n)}_{jk}>0$，则 $\pi_k=\sum_i\pi_ip^{(n)}_{ik}\ge\pi_jp^{(n)}_{jk}>0$。令 $\lambda_i=\pi_i/\pi_k$，它是 invariant measure，$\lambda_k=1$。唯一性 theorem 的前半个结论不需要 recurrence，给出 $\lambda\ge\gamma^k$，于是

$$m_k=\sum_i\gamma^k_i\le\sum_i\frac{\pi_i}{\pi_k}=\frac1{\pi_k}<\infty$$

$m_k$ finite，$T_k$ 当然 a.s. finite，所以 $k$ recurrent，而且 positive recurrent。$k$ 是任取的，这就是 (i)。

最后，chain recurrent，唯一性 theorem 的后半个结论给出 $\lambda=\gamma^k$，所以 $m_k=\sum_i\lambda_i=1/\pi_k$。每个 $\pi_k$ 都被 $m_k$ 定死，$\pi$ 唯一。证毕。

两个例子都对得上。Reflecting walk：$\pi_0=\tfrac13$，$m_0=3$。Symmetric walk：唯一的 invariant measure（up to scaling）是 $\mu\equiv1$，乘任何常数总和都是 0 或 $\infty$，所以没有 stationary distribution，和 null recurrent 一致。

:::wrong $\mu P=\mu$ 有一个处处为正的 solution，chain 就是 recurrent 的
开头那条往右 0.6 的 walk 是反例：$\mu\equiv1$ 处处为正，满足 $\mu P=\mu$，可 chain 是 transient 的。Invariant measure 的存在不说明任何事，要的是 invariant 的 probability distribution：上面的 theorem 说，有总和为 1 的 solution 才推得出 recurrence（而且是 positive recurrence）。Finite chain 上两者没有区别，因为任何 invariant measure 都可以 normalize。
:::

:::back
Recurrence 是 class property、gambler's ruin 的 closed form、ST3236 用 law of large numbers 得到的 $\pi_y=1/m_y$，分别在 ST3236 的[第 3 站](../courses/ST3236.html#class)、[第 2 站](../courses/ST3236.html#fsa)和[第 5 站](../courses/ST3236.html#stat)。Visits 是 Geometric 用到[第 1 站](#hit)的 strong Markov property。
:::

:::from
“固定一个 state，数一个 block 里访问每个 state 的 expected 次数”这个构造、$\sum_j\mu_i(j)=E_iT_i$、“对 $\{T_i>n\}$ 用普通的 Markov property”这一步，来自 [Berkeley Stat 205B Lecture 4](https://www.stat.berkeley.edu/~pitman/s205s03/lecture4.pdf)；它把完整 proof 留给了 Durrett 的书。这里三个 theorem 的 proof（挪一格的求和、反复代入证 $\lambda\ge\gamma^k$、由 $m_k\le1/\pi_k$ 得 positive recurrence）是凭自己的知识按 Norris *Markov Chains* Theorem 1.7.5–1.7.7 的路线写的，没有读到原书核对。$\gamma^0_i=(2/3)^i$ 和 symmetric walk 的 $\gamma^0_i=1$ 的逐项计算、$\mathbb Z$ 上 transient walk 的两个 invariant measure、simulation，是为这一页做的。

## [poisson] Poisson process：三个等价的定义

:::skip
NUSMods 上的课程描述只列了 discrete-time Markov chain，这一站和后面四站都超出了描述，当学期讲不讲以 Canvas 为准。能从 small-interval 的定义推出 Poisson$(\lambda t)$，prove thinning 出来的两路 independent，并会用“给定 $N(t)=n$，arrival 时刻是 uniform 的 order statistics”，就可以去第 4 站。
:::

### 从 count 到 process

ST2131 [第 3 站](../courses/ST2131.html#dist)把一段时间里的 count 讲成 Binomial$(n,\lambda/n)$ 的 limit，得到 Poisson$(\lambda t)$，并由“到 $t$ 还没等到”等于“count 是 0”得到第一次 arrival 是 Exponential。那里只问了一段时间、一个 count。现在要问整条 process：前 1 分钟来了 3 个，后 2 分钟会来几个？已经等了 10 分钟，还要等多久？给定 3 分钟里来了 6 个，第一个是什么时候来的？这需要把 arrival 当成一列随机的时刻来描述。

记 arrival 时刻为 $S_1<S_2<\cdots$，interarrival time $X_1=S_1$，$X_n=S_n-S_{n-1}$；count $N(t)$ 是 $(0,t]$ 里的 arrival 个数。两套描述由下面这个 identity 互相翻译：

$$\{S_n\le t\}=\{N(t)\ge n\}$$

第 $n$ 个在 $t$ 之前到，和到 $t$ 为止至少来了 $n$ 个，是同一件事。

**Definition 1。** $X_1,X_2,\dots$ i.i.d.，都是 Exponential$(\lambda)$。

为什么偏偏是 Exponential？下面的论证说明，只要要求“已经等了多久不影响还要等多久”，就只能是它。

### Memoryless 逼出 Exponential

设 $X>0$ 满足 $P(X>s+t\mid X>s)=P(X>t)$ 对所有 $s,t\ge0$。令 $G(t)=P(X>t)$，条件写成 $G(s+t)=G(s)G(t)$。

令 $\lambda=-\ln G(1)$（$G(1)>0$，否则 $G(1/n)^n=G(1)=0$ 推出 $G(1/n)=0$ 对所有 $n$ 成立，$X$ 就不可能大于 0）。由 $G(1)=G(1/n)^n$ 得 $G(1/n)=e^{-\lambda/n}$；再由 $G(m/n)=G(1/n)^m$ 得 $G(m/n)=e^{-\lambda m/n}$。所以 $G(t)=e^{-\lambda t}$ 对所有 rational $t$ 成立。$G$ 是 decreasing 的，任何 real $t$ 都被两列 rational 从两边夹住，两边的 $e^{-\lambda t}$ 趋于同一个值，所以 $G(t)=e^{-\lambda t}$ 对所有 $t$ 成立。$X$ 是 Exponential$(\lambda)$。

### Definition 1 推出：任何固定时刻之后，process 重新开始

固定 $t$，令 $Z$ 为从 $t$ 到下一个 arrival 的时间。在 $N(t)=n$、$S_n=\tau$ 的条件下，下一个 arrival 是第 $n+1$ 个，$X_{n+1}$ 已知大于 $t-\tau$，$Z=X_{n+1}-(t-\tau)$。由 memoryless property，

$$P(Z>z\mid N(t)=n,\ S_n=\tau,\ X_1,\dots,X_n)=P(X_{n+1}>t-\tau+z\mid X_{n+1}>t-\tau)=e^{-\lambda z}$$

右边和 $n$、$\tau$、$X_1,\dots,X_n$ 都无关。所以 $Z$ 是 Exponential$(\lambda)$，和 $t$ 之前发生的一切 independent；之后的 interarrival $X_{n+2},X_{n+3},\dots$ 本来就和这些 independent。于是 $t$ 之后的 arrival 构成一个和原来 distribution 相同的 Poisson process，和 $t$ 之前 independent。立刻得到两条：

- **Independent increments**：不相交的时间段里的 count independent。
- **Stationary increments**：$N(t+s)-N(t)$ 和 $N(s)$ 同分布。

### Definition 3：每一小段里的 rate

**Definition 3。** Independent、stationary increments，并且 $h\to0$ 时

$$P(N(h)=1)=\lambda h+o(h),\qquad P(N(h)\ge2)=o(h)$$

这是“每一小段以 $\lambda h$ 来一个，几乎不会同时来两个”的精确写法。从它推出 $N(t)$ 的 PMF。记 $p_j(t)=P(N(t)=j)$。$t+h$ 时为 0，当且仅当 $t$ 时为 0 且 $(t,t+h]$ 里没来；由 independent、stationary increments，

$$p_0(t+h)=p_0(t)\big(1-\lambda h+o(h)\big)\ \Rightarrow\ \frac{p_0(t+h)-p_0(t)}{h}=-\lambda p_0(t)+\frac{o(h)}h$$

$h\to0$ 得 $p_0'=-\lambda p_0$，$p_0(0)=1$，所以 $p_0(t)=e^{-\lambda t}$。$j\ge1$ 时，$t+h$ 时为 $j$，要么 $t$ 时为 $j$ 且这段没来，要么 $t$ 时为 $j-1$ 且来了一个，其余情况 probability 是 $o(h)$：

$$p_j(t+h)=p_j(t)(1-\lambda h)+p_{j-1}(t)\lambda h+o(h)\ \Rightarrow\ p_j'=-\lambda p_j+\lambda p_{j-1}$$

两边乘 $e^{\lambda t}$，左边合成一个 derivative：$\big(e^{\lambda t}p_j\big)'=e^{\lambda t}(p_j'+\lambda p_j)=\lambda e^{\lambda t}p_{j-1}$。设 $p_{j-1}(t)=e^{-\lambda t}(\lambda t)^{j-1}/(j-1)!$（$j=1$ 时就是刚求出的 $p_0$），则

$$\big(e^{\lambda t}p_j\big)'=\lambda\frac{(\lambda t)^{j-1}}{(j-1)!}\ \Rightarrow\ e^{\lambda t}p_j(t)=\frac{(\lambda t)^j}{j!}+C$$

$p_j(0)=0$ 给出 $C=0$。由 induction，$N(t)\sim\text{Poisson}(\lambda t)$。

**Definition 2**（independent、stationary increments，$N(t)\sim$ Poisson$(\lambda t)$）夹在中间：Definition 1 推出 increments 的性质，再由 $P(N(t)=0)=P(X_1>t)=e^{-\lambda t}$ 等得到 PMF；Definition 3 推出 PMF；Definition 2 直接给出Definition 3 的两个 small-interval 条件（展开 $e^{-\lambda h}\lambda h=\lambda h+o(h)$）。从Definition 2 或 3 回到Definition 1，要说明 interarrival 是 i.i.d. Exponential：$P(X_1>t)=p_0(t)=e^{-\lambda t}$，再对第一次 arrival 之后的 process 重复，这一步要用到 strong 版本的“重新开始”，这里不展开。三个定义等价，用哪个方便就用哪个。

### Thinning 与 superposition

一台 server 收到 request，rate $\lambda=2$ per minute，每个 request independently 以 $p=\tfrac14$ 是 write，否则是 read。只看 write，它们是什么样的 process？

**Thinning。** 设 $N_1(t)$、$N_2(t)$ 分别是 write 和 read 的 count。在 $N(t)=m+k$ 的条件下，哪 $m$ 个是 write 是 Binomial：

$$P\big(N_1(t)=m,N_2(t)=k\big)=e^{-\lambda t}\frac{(\lambda t)^{m+k}}{(m+k)!}\binom{m+k}{m}p^m(1-p)^k$$

$\binom{m+k}{m}=\frac{(m+k)!}{m!\,k!}$，$(m+k)!$ 约掉，把 $e^{-\lambda t}=e^{-p\lambda t}e^{-(1-p)\lambda t}$、$(\lambda t)^{m+k}=(\lambda t)^m(\lambda t)^k$ 拆开配对：

$$=\left[e^{-p\lambda t}\frac{(p\lambda t)^m}{m!}\right]\left[e^{-(1-p)\lambda t}\frac{((1-p)\lambda t)^k}{k!}\right]$$

Joint PMF 分解成两个 Poisson PMF 的乘积：$N_1(t)\sim$ Poisson$(p\lambda t)$，$N_2(t)\sim$ Poisson$((1-p)\lambda t)$，而且两者 independent。对不相交的时间段各做一次，再用原 process 的 independent increments，就得到 write 本身是 rate $p\lambda$ 的 Poisson process，read 是 rate $(1-p)\lambda$ 的，两条 process independent。

例子里 write 的 rate 是 $0.5$ per minute。2 分钟里一个 write 都没有的 probability 是 $e^{-0.5\times2}=e^{-1}=0.368$；整体 2 分钟里一个 request 都没有的 probability 是 $e^{-4}=0.018$。

**Superposition。** 反过来，rate $\lambda_1$、$\lambda_2$ 的两个 independent Poisson process 合在一起，第一个 arrival 来得比 $t$ 晚，当且仅当两边的第一个都比 $t$ 晚：

$$P(\min(X^{(1)},X^{(2)})>t)=e^{-\lambda_1t}e^{-\lambda_2t}=e^{-(\lambda_1+\lambda_2)t}$$

合起来的第一个 interarrival 是 Exponential$(\lambda_1+\lambda_2)$。它来自第一路的 probability：

$$P(X^{(1)}<X^{(2)})=\int_0^\infty\lambda_1e^{-\lambda_1x}\,e^{-\lambda_2x}\,dx=\frac{\lambda_1}{\lambda_1+\lambda_2}$$

由 memoryless property，之后的每一个都如此。例子里 write 是 0.5、read 是 1.5，下一个 request 是 write 的 probability 是 $0.5/2=\tfrac14$，和 thinning 的描述一致。第 4 站用这两条把 continuous-time chain 的跳转拆成几个“同时在走的 clock”。

::fig[ma3238-poisson] 静止时是 6 分钟全部画完：一共 10 个 request，3 个 write（实心）。动起来时虚线是当前时刻，粗线是 $N(t)$，细的彩色线是只数 write 的 $N_1(t)$。按 rate，6 分钟的 expected count 分别是 12 和 3。（mulberry32，seed 2024。）

:::wrong Read 来得多，write 就来得少
直觉是两路分的是同一个总数，此消彼长。上面的 joint PMF 说两者 independent：知道 2 分钟里来了 8 个 read，2 分钟里没有 write 的 probability 仍然是 $e^{-1}=0.368$。此消彼长只在总数被固定时才成立：如果已知 2 分钟里一共来了 8 个，那么 write 的个数是 Binomial$(8,\tfrac14)$，一个 write 都没有的 probability 是 $0.75^8=0.100$，再已知其中 read 有 8 个，write 就一定是 0。区别在于 Poisson process 的总数本身是 random 的：read 多，说明总数大，这恰好抵消了“read 占掉名额”的效应。
:::

### 给定来了几个，它们是什么时候来的

已知 3 分钟里来了 6 个 request，第一个平均在什么时候来？

**Theorem。** 在 $N(t)=n$ 的条件下，$(S_1,\dots,S_n)$ 的 joint density 是 $n!/t^n$（在 $0<s_1<\dots<s_n<t$ 上），恰好是 $n$ 个 i.i.d. Uniform$(0,t)$ 排序后的 joint density。

Proof。$X_1,\dots,X_{n+1}$ 的 joint density 是 $\prod\lambda e^{-\lambda x_i}=\lambda^{n+1}e^{-\lambda(x_1+\dots+x_{n+1})}$。换成 $s_i=x_1+\dots+x_i$，这个 linear map 的 matrix 是 lower triangular、diagonal 全是 1，Jacobian 是 1，所以 $(S_1,\dots,S_{n+1})$ 的 joint density 是 $\lambda^{n+1}e^{-\lambda s_{n+1}}$（在 $0<s_1<\dots<s_{n+1}$ 上）。Event $\{N(t)=n\}=\{S_n\le t<S_{n+1}\}$，对 $s_{n+1}$ 从 $t$ 积到 $\infty$：

$$\int_t^\infty\lambda^{n+1}e^{-\lambda s_{n+1}}\,ds_{n+1}=\lambda^ne^{-\lambda t}$$

这是 $(S_1,\dots,S_n)$ 与 $\{N(t)=n\}$ 的 joint density，除以 $P(N(t)=n)=e^{-\lambda t}(\lambda t)^n/n!$：

$$\frac{\lambda^ne^{-\lambda t}}{e^{-\lambda t}(\lambda t)^n/n!}=\frac{n!}{t^n}$$

和 $s_1,\dots,s_n$ 无关，在 ordered region 上是常数。$n$ 个 i.i.d. Uniform$(0,t)$ 的 joint density 是 $1/t^n$，排序后 $n!$ 种顺序叠到同一个 ordered region 上，正好是 $n!/t^n$。证毕。

用在问题上：$S_1$ 是 6 个 Uniform$(0,3)$ 的 minimum。$P(S_1>s\mid N(3)=6)=\big((3-s)/3\big)^6$，所以

$$E[S_1\mid N(3)=6]=\int_0^3\left(1-\frac s3\right)^6ds=\left[-\frac37\left(1-\frac s3\right)^7\right]_0^3=\frac37\approx0.43\text{ minute}$$

和 $\lambda$ 无关。6 个点把 $[0,3]$ 平均切成 7 段，每段平均 $\tfrac37$。

## [ctmc] Continuous-time Markov chain

:::skip
超出 NUSMods 的课程描述。能从 Q-matrix 读出 holding rate 和 jump chain，推出 Kolmogorov equations，对 3 个 state 的 chain 解出 $P(t)$ 和 $\pi$，并分清 $\pi$ 与 jump chain 的 stationary distribution，就可以去第 5 站。
:::

### 停留的时间只能是 Exponential

一条 queue 里的人数在 random 的时刻变化：有人来、有人走。把时间切成 step 再用 discrete-time chain，step 取多大都是人为的。要的是 $\{X(t),t\ge0\}$，对任意 $s<t$ 满足

$$P\big(X(t)=j\mid X(s)=i,\ X(r),\,r<s\big)=p_{ij}(t-s)$$

先看它对“在一个 state 停多久”有什么要求。设现在在 $i$，已经停了 $s$ 那么久。由 Markov property，未来只看“现在在 $i$”，不看已经停了多久，所以还要停的时间和刚进入 $i$ 时要停的时间 distribution 相同。这正是第 3 站的 memoryless property，所以在 $i$ 的 holding time 是 Exponential，记它的 rate 为 $q_i$。

于是 continuous-time chain 由两样东西决定：

- **Holding rate** $q_i$：在 $i$ 停留 Exponential$(q_i)$ 的时间。
- **Jump chain** $\hat P$：离开 $i$ 时以 $\hat p_{ij}$ 跳到 $j$（$\hat p_{ii}=0$），和停了多久 independent。

把两者合成一个 matrix $Q$：$q_{ij}=q_i\hat p_{ij}$（$j\ne i$），$q_{ii}=-q_i$。每行加起来是 0。这叫 Q-matrix 或 generator。

用一次。取

$$Q=\begin{pmatrix}-2&1&1\\1&-1&0\\2&1&-3\end{pmatrix}$$

读出：$q_1=2$、$q_2=1$、$q_3=3$；jump chain 的每一行是 off-diagonal 除以 $q_i$，

$$\hat P=\begin{pmatrix}0&\tfrac12&\tfrac12\\1&0&0\\\tfrac23&\tfrac13&0\end{pmatrix}$$

还有一种等价的看法：在 $i$ 时，对每个 $j\ne i$ 有一个 rate $q_{ij}$ 的 Exponential clock 同时在走，谁先响就跳到谁。由第 3 站的 superposition，最早的一个是 Exponential$\big(\sum_jq_{ij}\big)=$ Exponential$(q_i)$，它是 $j$ 的 probability 是 $q_{ij}/q_i=\hat p_{ij}$，和上面的描述相同。在 state 3，到 1 的 clock rate 2、到 2 的 rate 1，平均停 $\tfrac13$，离开时以 $\tfrac23$ 去 1。

::fig[ma3238-ctmc] 箭头上的数是 rate $q_{ij}$。静止时显示 $t=40$ 时的结果；动起来时圈在 state 之间跳，每次停 Exponential 长的时间，右边柱子是到时刻 $t$ 为止各 state 占的时间比例，越来越靠近粗横线。（mulberry32，seed 31。）

### $P(t)$ 在 0 附近

设 state 有 finitely many 个。$h$ 很小时，从 $i$ 出发：

- 不跳的 probability 是 $e^{-q_ih}=1-q_ih+o(h)$。
- 跳两次以上，要两段 holding time 都小于 $h$，probability 不超过 $(q_{\max}h)^2=o(h)$。
- 恰好跳一次、跳到 $j$：$(1-e^{-q_ih})\,\hat p_{ij}+o(h)=q_ih\,\hat p_{ij}+o(h)=q_{ij}h+o(h)$。

所以

$$p_{ii}(h)=1-q_ih+o(h),\qquad p_{ij}(h)=q_{ij}h+o(h)\ (j\ne i)$$

写成 matrix 就是 $P(h)=I+hQ+o(h)$，即 $P'(0)=Q$。$q_{ij}$ 就是“每单位时间从 $i$ 跳到 $j$ 的 rate”。

### Kolmogorov equations

$P(t)$ 满足 Chapman–Kolmogorov：$P(s+t)=P(s)P(t)$，理由和 discrete time 一样（在时刻 $s$ 按所在的 state 分情况，再用 Markov property）。先走 $h$ 再走 $t$：

$$P(t+h)-P(t)=P(h)P(t)-P(t)=\big(P(h)-I\big)P(t)$$

除以 $h$，令 $h\to0$，用 $P'(0)=Q$：

$$P'(t)=QP(t)\qquad\text{（backward equation）}$$

先走 $t$ 再走 $h$，$P(t+h)-P(t)=P(t)\big(P(h)-I\big)$，同样得到

$$P'(t)=P(t)Q\qquad\text{（forward equation）}$$

Finite state space 上，满足 $P'=QP$、$P(0)=I$ 的唯一 solution 是 matrix exponential

$$P(t)=e^{tQ}=\sum_{n\ge0}\frac{t^nQ^n}{n!}$$

于是 $P^{(n)}(0)=Q^n$：在 0 处的 $n$ 阶 derivative 就是 $Q^n$。

### 解一个 $P(t)$

$e^{tQ}$ 的每个 entry 都是 $e^{\lambda t}$ 的组合，$\lambda$ 取遍 $Q$ 的 eigenvalue。先求 characteristic polynomial，沿第一行展开：

$$\det(Q-xI)=(-2-x)\big[(-1-x)(-3-x)\big]-1\cdot\big[1\cdot(-3-x)-0\big]+1\cdot\big[1\cdot1-(-1-x)\cdot2\big]$$

逐项：$(-1-x)(-3-x)=x^2+4x+3$，第一项是 $-(x+2)(x^2+4x+3)=-(x^3+6x^2+11x+6)$；第二项是 $3+x$；第三项是 $3+2x$。相加：

$$\det(Q-xI)=-x^3-6x^2-8x=-x(x+2)(x+4)$$

Eigenvalue 是 $0,-2,-4$，三个不同，$Q$ diagonalizable，所以

$$p_{11}(t)=a+b\,e^{-2t}+c\,e^{-4t}$$

三个 unknown 用 $t=0$ 处的三个条件定：$p_{11}(0)=1$；$p'_{11}(0)=q_{11}=-2$；$p''_{11}(0)=(Q^2)_{11}=(-2)(-2)+1\cdot1+1\cdot2=7$。即

$$a+b+c=1,\qquad -2b-4c=-2,\qquad 4b+16c=7$$

第二个给出 $b=1-2c$，代入第三个：$4-8c+16c=7$，$c=\tfrac38$，$b=\tfrac14$，$a=\tfrac38$。

$$p_{11}(t)=\tfrac38+\tfrac14e^{-2t}+\tfrac38e^{-4t}$$

用 `scipy.linalg.expm` 核对：$t=1$ 时 $e^{Q}$ 的 $(1,1)$ entry 是 0.41570，公式给出 $0.375+0.25\times0.13534+0.375\times0.01832=0.41570$。同样的办法得到 $p_{12}(t)=\tfrac12-\tfrac12e^{-2t}$、$p_{13}(t)=\tfrac18+\tfrac14e^{-2t}-\tfrac38e^{-4t}$。

::fig[ma3238-prow] 从 state 1 出发，三个 probability 随 $t$ 的变化。$t\to\infty$ 时 $e^{-2t}$、$e^{-4t}$ 都消失，只剩 eigenvalue 0 对应的常数。

### Stationary distribution：$\pi Q=0$

$p_{1j}(t)$ 的 limit 是 eigenvalue 0 那一项。一般地，$\pi$ 满足 $\pi P(t)=\pi$ 对所有 $t$ 成立，当且仅当 $\pi Q=0$：

- 若 $\pi P(t)=\pi$ 对所有 $t$ 成立，两边在 $t=0$ 求 derivative，$\pi Q=0$。
- 若 $\pi Q=0$，由 backward equation，$\frac d{dt}\big(\pi P(t)\big)=\pi QP(t)=0$，所以 $\pi P(t)=\pi P(0)=\pi$。

对例子解 $\pi Q=0$，按 column 写：

$$-2\pi_1+\pi_2+2\pi_3=0,\qquad \pi_1-\pi_2+\pi_3=0,\qquad \pi_1-3\pi_3=0$$

第三个给出 $\pi_1=3\pi_3$，第二个给出 $\pi_2=\pi_1+\pi_3=4\pi_3$；normalize，$8\pi_3=1$：

$$\pi=\left(\tfrac38,\ \tfrac12,\ \tfrac18\right)$$

第一个 equation 留作核对：$-\tfrac68+\tfrac48+\tfrac28=0$。$\tfrac38$ 正是 $p_{11}(t)$ 的 limit $a$。$\pi Q=0$ 的第 $j$ 个 equation 写成 $\sum_{i\ne j}\pi_iq_{ij}=\pi_jq_j$：流进 $j$ 的 rate 等于流出 $j$ 的 rate。

Finite、irreducible 的 chain 上，$p_{ij}(t)\to\pi_j$，而且不需要 aperiodic：$p_{ii}(t)\ge e^{-q_it}>0$ 对所有 $t>0$ 成立，continuous time 里没有 period。

### 和 jump chain 的关系

$\pi_x$ 是 long run 里待在 $x$ 的时间比例。还可以问另一个比例：所有的跳转里，有多少比例是跳进 $x$ 的？这是 jump chain $\hat P$ 的 stationary distribution $\hat\pi$。两者不同，关系由 $Q$ 的结构给出：$Q=\mathrm{diag}(q)\,(\hat P-I)$，所以

$$\pi Q=0\iff(\pi_xq_x)_x\,(\hat P-I)=0\iff(\pi_xq_x)_x\ \text{是}\ \hat P\ \text{的 invariant measure}$$

即 $\hat\pi_x\propto\pi_xq_x$。在 $x$ 停得越短（$q_x$ 越大），时间比例相对于访问比例就越小。

:::wrong Continuous-time chain 的 stationary distribution 就是 jump chain 的 stationary distribution
在例子里算出来比一比。$\pi_xq_x=\big(\tfrac38\cdot2,\ \tfrac12\cdot1,\ \tfrac18\cdot3\big)=\big(\tfrac68,\tfrac48,\tfrac38\big)$，normalize 得 $\hat\pi=\big(\tfrac6{13},\tfrac4{13},\tfrac3{13}\big)$。直接验证它是 $\hat P$ 的 stationary distribution：第一个 column $\tfrac4{13}\cdot1+\tfrac3{13}\cdot\tfrac23=\tfrac6{13}$，第二个 $\tfrac6{13}\cdot\tfrac12+\tfrac3{13}\cdot\tfrac13=\tfrac4{13}$，第三个 $\tfrac6{13}\cdot\tfrac12=\tfrac3{13}$。所以 $\tfrac6{13}=46\%$ 的跳转落在 state 1，可 chain 只有 $\tfrac38=37.5\%$ 的时间在 state 1，因为每次只停平均 $\tfrac12$；state 2 只占 $31\%$ 的跳转，却占 $50\%$ 的时间，因为每次平均停 1。
:::

再用 mean return time 核对一次。记 $m_1$ 为从 1 出发、离开后再回到 1 的 expected 时间，$k_j$ 为从 $j$ 出发到达 1 的 expected 时间。按 first-step analysis（第一段 holding time 加上之后的去向）：

$$k_2=\frac1{q_2}+\hat p_{21}\cdot0=1,\qquad k_3=\frac13+\frac23\cdot0+\frac13k_2=\frac23,\qquad m_1=\frac12+\frac12k_2+\frac12k_3=\frac43$$

而 $\dfrac1{q_1m_1}=\dfrac1{2\times4/3}=\dfrac38=\pi_1$。$\pi_x=1/(q_xm_x)$ 这个关系在第 6 站用 renewal-reward theorem prove：每次回到 $x$ 是一个 cycle，平均长 $m_x$，其中在 $x$ 待的时间平均 $1/q_x$。

:::edge Infinite state space 上的 explosion
设 state 是 $0,1,2,\dots$，从 $i$ 只能跳到 $i+1$，rate $q_i=2^i$。从 0 出发，第 $n$ 次跳之前的 holding time 平均 $2^{-n}$，所有 holding time 之和的 expectation 是 $\sum_{n\ge0}2^{-n}=2$。总时间 finite 的 expectation 说明它 a.s. finite：chain 在一段 finite 的时间里跳了 infinitely many 次，跑到“无穷远”去了，之后 $X(t)$ 没有定义。这叫 explosion。这时 $P(t)$ 每一行加起来小于 1，backward equation 的 solution 不唯一，上面的结论都要加上“non-explosive”的条件。Finite chain 不会 explode：$q_i\le q_{\max}$，holding time 之和至少是 i.i.d. Exponential$(q_{\max})$ 之和，后者由 law of large numbers 趋于 $\infty$。
:::

## [queue] M/M/1 queue 与 Little's law

:::skip
超出 NUSMods 的课程描述。能写出 M/M/1 的 stationary distribution 和 $L$、$W$，会用 Little's law 换算，知道 sojourn time 是 Exponential$(\mu-\lambda)$，并能解 M/M/2，就可以去第 6 站。
:::

### 排队人数是一条 birth–death chain

一个 server，customer 按 rate $\lambda$ 的 Poisson process 到达，每个人的 service time 是 i.i.d. Exponential$(\mu)$，first-come first-served。系统里的人数 $N(t)$（包括正在被服务的）是不是 continuous-time Markov chain？

在 $N(t)=n\ge1$ 时，同时有两个 clock 在走：下一个 arrival，Exponential$(\lambda)$，由第 3 站和过去 independent；正在服务的人还剩的 service time，由 memoryless property 也是 Exponential$(\mu)$，和已经服务了多久无关。所以 $N$ 是 continuous-time chain，

$$q_{n,n+1}=\lambda\ (n\ge0),\qquad q_{n,n-1}=\mu\ (n\ge1)$$

只往相邻的 state 跳，这叫 birth–death chain。记 $\rho=\lambda/\mu$，每单位时间里平均来的人数除以平均能服务的人数。

### Stationary distribution 与平均人数

$\pi Q=0$ 的第 0 个 equation：$-\lambda\pi_0+\mu\pi_1=0$。第 $n\ge1$ 个：$\lambda\pi_{n-1}-(\lambda+\mu)\pi_n+\mu\pi_{n+1}=0$，整理成

$$\mu\pi_{n+1}-\lambda\pi_n=\mu\pi_n-\lambda\pi_{n-1}$$

左右两边是同一个量在 $n$ 和 $n-1$ 处的值，往下一直推到 $n=0$，它等于 $\mu\pi_1-\lambda\pi_0=0$。所以对所有 $n$，$\lambda\pi_n=\mu\pi_{n+1}$：在 $n$ 和 $n+1$ 之间切一刀，向上跨的 rate 等于向下跨的 rate，和 ST3236 [第 5 站](../courses/ST3236.html#stat)的 cut 是同一件事。于是 $\pi_n=\rho^n\pi_0$，要能 normalize 必须 $\rho<1$，这时 $\pi_0=1-\rho$：

$$\pi_n=(1-\rho)\rho^n$$

平均人数 $L=\sum_nn\pi_n$。由 $\sum_{n\ge0}\rho^n=\frac1{1-\rho}$ 求 derivative 得 $\sum_{n\ge1}n\rho^{n-1}=\frac1{(1-\rho)^2}$，所以

$$L=(1-\rho)\rho\sum_{n\ge1}n\rho^{n-1}=\frac{\rho}{1-\rho}$$

取 $\mu=1$ per minute 代几个数：

| $\lambda$ | $\rho$ | $L=\rho/(1-\rho)$ | server 空闲的比例 $1-\rho$ |
|---|---|---|---|
| 0.5 | 0.5 | 1 | 50% |
| 0.8 | 0.8 | 4 | 20% |
| 0.9 | 0.9 | 9 | 10% |
| 0.95 | 0.95 | 19 | 5% |

Arrival 从 0.9 增加到 0.95，只多了 5.6%，平均人数翻了一倍多。$\rho\to1$ 时 $L$ 像 $1/(1-\rho)$ 一样发散。

::fig[ma3238-queue] $\rho=0.8$。静止时是 150 分钟的整条 path；动起来时上面的方块是此刻在系统里的人（深色的那个正在被服务），下面的 path 同步画出。这 150 分钟的 time average 只有 3.05，离 long run 的 4 还差得远：$\rho$ 接近 1 时 path 会长时间停在高处或低处，要很长的时间才 average 得出来。（mulberry32，seed 8。）

### Little's law

平均人数知道了，一个人平均在系统里待多久（sojourn time）$W$？

**Little's law。** $L=\lambda W$。

论证用一张图就够。设 $A(t)$、$D(t)$ 是到时刻 $t$ 为止到达、离开的累计人数，$N(t)=A(t)-D(t)$。两条 staircase 之间的面积，竖着切是 $\int_0^tN(s)\,ds$；横着切，第 $k$ 个人贡献一条从他到达到他离开的横条，宽度是他的 sojourn time $W_k$。在系统恰好为空的时刻 $t$，每个到过的人都已经离开，两种切法给出同一个面积：

$$\int_0^tN(s)\,ds=\sum_{k=1}^{A(t)}W_k\quad\Longrightarrow\quad\underbrace{\frac1t\int_0^tN(s)\,ds}_{\to L}=\underbrace{\frac{A(t)}t}_{\to\lambda}\cdot\underbrace{\frac1{A(t)}\sum_{k=1}^{A(t)}W_k}_{\to W}$$

让 $t$ 沿着系统变空的时刻趋于 $\infty$。三个 limit 的存在要靠第 6 站的 renewal-reward theorem：每次系统从空到有人再到空是一个 i.i.d. 的 cycle。

::fig[ma3238-little] 4 个人，到达时刻 0.5、1.5、2、4.5，service time 1.5、1、0.5、1。$t=6$ 时系统为空。

在图里核对：面积 5.5，$L$ 的 time average 是 $5.5/6=0.917$；$\lambda$ 的观测值是 $4/6$，$W$ 的平均是 $5.5/4=1.375$，乘积 $\tfrac46\times1.375=0.917$。这条关系对 service time 的 distribution、queueing discipline都没有要求，只用到面积的两种算法。

用到 M/M/1 上：

$$W=\frac L\lambda=\frac{\rho}{(1-\rho)\lambda}=\frac1{\mu-\lambda}$$

$\lambda=0.8$、$\mu=1$ 时 $W=5$ 分钟；$\lambda=0.9$ 时 10 分钟。

### 一个到达的人要等多久：distribution

Little's law 给出 mean。Distribution 要看一个新到的人看见什么。

**到达的人看见的是 $\pi$。** 在 $[t,t+h)$ 里有没有 arrival，由第 3 站的 independent increments，和 $t$ 之前发生的一切 independent，而 $N(t^-)$ 由 $t$ 之前的 arrival 和 service 决定。所以 $P(N(t^-)=n\mid t\text{ 附近有 arrival})=P(N(t^-)=n)$，在 steady state 里是 $\pi_n$。（这对 Poisson arrival 成立，对一般的 arrival process 不成立。）

**看见 $n$ 个人时要待多久。** 他要等正在服务的那人剩下的时间（memoryless，Exponential$(\mu)$）、前面 $n-1$ 个人的 service time，再加上自己的，一共 $n+1$ 个 i.i.d. Exponential$(\mu)$。$K=N+1$ 满足 $P(K=k)=(1-\rho)\rho^{k-1}$，是 Geometric$(1-\rho)$。

**Geometric 个 Exponential 之和。** 把 $n+1$ 个 Exponential$(\mu)$ 看成 rate $\mu$ 的 Poisson process 的前几个 interarrival。“$K$ 是 Geometric$(1-\rho)$”等价于：给这个 process 的每个点 independently 以 $1-\rho$ 的 probability 标“停”，$K$ 是第一个标“停”的点的编号。于是 $W$ 是第一个“停”点的时刻。由第 3 站的 thinning，标“停”的点构成 rate $\mu(1-\rho)=\mu-\lambda$ 的 Poisson process，第一个点的时刻是

$$W\sim\text{Exponential}(\mu-\lambda)$$

Mean 是 $1/(\mu-\lambda)$，和 Little's law 一致。$\lambda=0.8$、$\mu=1$ 时，待超过 10 分钟的 probability 是 $e^{-0.2\times10}=e^{-2}=0.135$，虽然 mean 只有 5 分钟。

:::wrong 两个 server 各开一条队，和两个 server 共用一条队，平均一样快
总 arrival rate 1.8，两个 server 各 $\mu=1$。分开时，每条队是 $\lambda=0.9$ 的 M/M/1，$W=1/(1-0.9)=10$。

合起来是 M/M/2：人数 $n\ge2$ 时两个 server 都在忙，向下的 rate 是 $2\mu=2$；$n=1$ 时只有一个在忙，rate 是 1。用 cut：$1.8\pi_0=1\cdot\pi_1$，$1.8\pi_n=2\pi_{n+1}$（$n\ge1$）。所以 $\pi_1=1.8\pi_0$，$\pi_n=1.8\times0.9^{n-1}\pi_0$（$n\ge1$）。Normalize：

$$\pi_0\left(1+\frac{1.8}{1-0.9}\right)=19\pi_0=1,\qquad \pi_0=\tfrac1{19}$$

$$L=\sum_{n\ge1}n\cdot1.8\times0.9^{n-1}\cdot\tfrac1{19}=\frac{1.8}{19}\cdot\frac1{(1-0.9)^2}=\frac{180}{19}=9.47,\qquad W=\frac{L}{1.8}=5.26$$

一样的 server、一样的 arrival，平均时间差了将近一半。分开时会出现“一条队排着人，另一个 server 闲着”，共用一条队时不会。一般地，$\rho=\lambda/(2\mu)$ 时，同样的计算给出 $W=\dfrac{1}{\mu(1-\rho^2)}$，分开时是 $\dfrac1{\mu(1-\rho)}$，比值 $1+\rho$，$\rho$ 越接近 1 越接近 2 倍。
:::

::fig[ma3238-pool] 左边是两种安排，右边是 $W$ 随 $\rho$ 的变化（单位 $1/\mu$）。$\rho=0.9$ 时是 10 对 5.26。

:::edge $\rho\ge1$
$\rho\ge1$ 时 $\sum\rho^n=\infty$，没有 stationary distribution。Jump chain 是往上 $\lambda/(\lambda+\mu)$、往下 $\mu/(\lambda+\mu)$ 的 reflecting walk：$\rho=1$ 时是 symmetric 的，recurrent 但 null recurrent，queue 一定会空，但空一次平均要等无穷久；$\rho>1$ 时 transient，人数以 $\lambda-\mu$ 的 rate 线性增长。这是第 2 站两个例子在 queue 上的样子。
:::

## [renewal] Renewal theory 与 renewal-reward

:::skip
超出 NUSMods 的课程描述。能用 renewal-reward theorem 算 residual life 的 time average、解释 inspection paradox，并能用它统一推出 $\pi_k=1/m_k$ 和 $\pi_x=1/(q_xm_x)$，就可以去第 7 站。Wald's equality 和 elementary renewal theorem 两节是 expectation 版本的加深。
:::

### 等车等多久

公交车平均 10 分钟一班，在 random 的时刻到站，平均要等多久？

- 车严格每 10 分钟一班：你到达的时刻在一个 10 分钟的 interval 里 uniform，平均等 5 分钟。
- 车按 rate $\tfrac1{10}$ 的 Poisson process 来：由第 3 站，任何固定时刻之后的等待都是 Exponential，平均等 10 分钟，等于整个 interval 的 mean。
- 间隔以各 $\tfrac12$ 的 probability 是 2 分钟或 18 分钟（mean 仍是 10）：平均等多久？

前两个答案差一倍，第三个连怎么算都不清楚。共同的结构是：相邻两次事件的间隔 $X_1,X_2,\dots$ i.i.d.，distribution 任意，mean $\mu$。这叫 renewal process。Poisson process 是 Exponential 的特例；Markov chain 每次回到 state $k$ 的时刻，由 strong Markov property，也构成 renewal process。

::fig[ma3238-inspect] 第三种车。上面是 80 分钟的 timeline，浅底是 18 分钟的 interval；12 个 uniform 的到站时刻里 11 个落在长 interval 里。下面是从 $t$ 到下一班车的时间 $Y(t)$，每个 interval 里是一条斜率 $-1$ 的线，从 $X$ 降到 0。（mulberry32，seed 19。）

### Renewal 的 strong law

记 $S_n=X_1+\dots+X_n$，$N(t)=\max\{n:S_n\le t\}$。

**Theorem。** With probability 1，$N(t)/t\to1/\mu$。

Proof。按定义，第 $N(t)$ 次 renewal 在 $t$ 之前、第 $N(t)+1$ 次在 $t$ 之后：

$$S_{N(t)}\le t<S_{N(t)+1}$$

三边除以 $N(t)$（$t$ 大时 $N(t)\ge1$）：

$$\frac{S_{N(t)}}{N(t)}\le\frac t{N(t)}<\frac{S_{N(t)+1}}{N(t)+1}\cdot\frac{N(t)+1}{N(t)}$$

每个 $X_i$ finite，所以 $N(t)\to\infty$。由 strong law of large numbers，$S_n/n\to\mu$ with probability 1，沿着 $n=N(t)\to\infty$ 也成立；$\frac{N(t)+1}{N(t)}\to1$。左右两边都趋于 $\mu$，所以 $t/N(t)\to\mu$。证毕。

### Renewal-reward theorem

每个 interval 带一个 reward $R_n$，$(X_n,R_n)$ 这些 pair i.i.d.（$R_n$ 可以和 $X_n$ 相关）。Reward 在 interval 里随时间累积，$R(t)$ 是到 $t$ 为止的总 reward。

**Theorem。** 设 $R_n\ge0$，$E[R_n]<\infty$。With probability 1，

$$\frac{R(t)}t\to\frac{E[R_1]}{\mu}$$

Proof。Reward 非负，$t$ 时已经完整拿到前 $N(t)$ 个 interval 的 reward，最多拿到前 $N(t)+1$ 个：

$$\sum_{n=1}^{N(t)}R_n\le R(t)\le\sum_{n=1}^{N(t)+1}R_n$$

左边写成 $\dfrac{N(t)}t\cdot\dfrac1{N(t)}\sum_{n=1}^{N(t)}R_n$，第一个因子由上一个 theorem 趋于 $1/\mu$，第二个由 strong law 趋于 $E[R_1]$。右边同理（多出的 $\frac{N(t)+1}{N(t)}\to1$）。夹住，证毕。

“Long-run 平均每单位时间的 reward = 一个 cycle 的 expected reward ÷ 一个 cycle 的 expected 长度”。用一次，回答等车的问题。到站时刻 uniform 地取，平均等待就是 $Y(t)$ 的 time average。一个长为 $X$ 的 interval 里，$Y$ 从 $X$ 线性降到 0，积分是三角形的面积：

$$R_n=\int_0^{X_n}(X_n-s)\,ds=\frac{X_n^2}2\qquad\Longrightarrow\qquad\frac1t\int_0^tY(s)\,ds\to\frac{E[X^2]}{2\mu}$$

三种车代进去：

| 间隔 $X$ | $E[X]$ | $E[X^2]$ | 平均等待 $E[X^2]/(2E[X])$ |
|---|---|---|---|
| 恒为 10 | 10 | 100 | 5 |
| Exponential，mean 10 | 10 | $2\times10^2=200$ | 10 |
| 2 或 18，各 $\tfrac12$ | 10 | $\tfrac12(4+324)=164$ | 8.2 |

平均等待取决于 $E[X^2]$，不只是 mean：间隔越不均匀，等得越久。原因是 random 的到站时刻更容易落在长 interval 里。也用 renewal-reward 算：reward 取“这个 interval 若是 18 分钟就是它的长度，否则为 0”，$E[R]=18\times\tfrac12=9$，所以落在长 interval 里的时间比例是 $9/10=0.9$，虽然只有一半的 interval 是长的。同样，reward 取 $X_n\cdot X_n$（interval 内每个时刻都记下“我所在 interval 的长度”），得到你碰上的那个 interval 的平均长度 $E[X^2]/\mu=16.4$，比 10 长得多。这叫 inspection paradox。

### 回头看 $\pi=1/m$

第 2 站用 invariant measure prove 了 $\pi_k=1/m_k$，ST3236 用 law of large numbers 解释它是 frequency。Renewal-reward theorem 把两种 chain 的情形一次说清：

- **Discrete time。** 每次回到 $k$ 开始一个 cycle，长度 i.i.d.，mean $m_k$。Reward 取“这个 cycle 里在 $k$ 的步数”，恒为 1。在 $k$ 的时间比例 $\to1/m_k$。
- **Continuous time。** 每次进入 $x$ 开始一个 cycle，mean 长度就是第 4 站的 $m_x$（从进入 $x$ 到下次进入 $x$，第一段停留算在内）。Reward 取“这个 cycle 里待在 $x$ 的时间”，即第一段 holding time，mean $1/q_x$。在 $x$ 的时间比例 $\to\dfrac{1/q_x}{m_x}=\dfrac1{q_xm_x}$。

第 4 站的例子里 $m_1=\tfrac43$、$q_1=2$，给出 $\tfrac38$，和 $\pi Q=0$ 解出的一样。第 5 站 Little's law 里三个 limit 的存在也是这样来的：以“系统变空”为 renewal，cycle 里的面积、人数都是 reward。

### Wald's equality

:::skip
这一节和下一节讲 $E[N(t)]/t$ 的 limit。Strong law 给出的是 sample path 上的 limit，它不自动推出 expectation 的 limit，所以要另外证。
:::

想证 $m(t)=E[N(t)]$ 满足 $m(t)/t\to1/\mu$。由 $S_{N(t)}\le t$，最自然的想法是对 $S_{N(t)}$ 取 expectation，希望 $E[S_{N(t)}]=\mu\,m(t)$。这需要“random 个 i.i.d. 项之和的 expectation 等于 mean 乘 expected 个数”，而这只对某些 random 的个数成立。

**Wald's equality。** 设 $X_i\ge0$ i.i.d.，mean $\mu$；$J\ge1$ 是 stopping time，即 $\{J=n\}$ 只由 $X_1,\dots,X_n$ 决定。则 $E[S_J]=\mu\,E[J]$。

Proof。把 random 的求和上限写成 indicator：$S_J=\sum_{n\ge1}X_n\mathbf 1\{J\ge n\}$。$\{J\ge n\}=\{J\le n-1\}^c$ 只由 $X_1,\dots,X_{n-1}$ 决定，所以和 $X_n$ independent：

$$E[S_J]=\sum_{n\ge1}E[X_n]\,P(J\ge n)=\mu\sum_{n\ge1}P(J\ge n)=\mu\,E[J]$$

（各项非负，expectation 和求和可以交换；最后一步是 tail-sum formula。）证毕。

$N(t)$ 是不是 stopping time？$\{N(t)=n\}=\{S_n\le t<S_{n+1}\}$，要看 $X_{n+1}$，不是。$N(t)+1$ 是：

$$\{N(t)+1=n\}=\{S_{n-1}\le t<S_n\}$$

只由 $X_1,\dots,X_n$ 决定。所以 Wald's equality 给出 $E[S_{N(t)+1}]=\mu\,(m(t)+1)$，而 $E[S_{N(t)}]=\mu\,m(t)$ 没有根据。

:::wrong $E[S_{N(t)}]=\mu\,E[N(t)]$
用 rate 1 的 Poisson process、$t=1$ 检验。$\mu=1$，$m(1)=1$，右边是 1。左边：$S_{N(1)}=1-A$，$A$ 是时刻 1 往回看到上一次 arrival 的距离（没有 arrival 时 $S_0=0$，$A=1$）。$A>a$ 当且仅当 $(1-a,1]$ 里没有 arrival，$P(A>a)=e^{-a}$（$a<1$）。所以

$$E[A]=\int_0^1e^{-a}\,da=1-e^{-1}=0.632,\qquad E[S_{N(1)}]=1-0.632=0.368\ne1$$

$S_{N(t)}$ 偏小，因为“最后一个在 $t$ 之前”这个条件挑中了被 $t$ 截断的那个 interval，而那个 interval 由 inspection paradox 偏长。改用 $N(t)+1$：$E[S_{N(1)+1}]=1+E[\text{residual}]=1+1=2=\mu\,(m(1)+1)$，对上了。
:::

### Elementary renewal theorem

**Theorem。** $m(t)/t\to1/\mu$。

Proof。**下界。** $t<S_{N(t)+1}$，取 expectation，用 Wald：$t<\mu\,(m(t)+1)$，即

$$\frac{m(t)}t>\frac1\mu-\frac1t$$

**上界。** $X_i$ 可能很大，$S_{N(t)+1}$ 可能超过 $t$ 很多，所以从另一边夹要先截断。固定 $b>0$，令 $\tilde X_i=\min(X_i,b)$，mean $\mu_b$，对应的 renewal count 是 $\tilde N(t)$。间隔变短了，renewal 只会更多，$\tilde m(t)\ge m(t)$。而截断后最后一个间隔不超过 $b$，$\tilde S_{\tilde N(t)+1}\le t+b$。对截断的 process 用 Wald：

$$\mu_b\,(\tilde m(t)+1)\le t+b\quad\Longrightarrow\quad\frac{m(t)}t\le\frac{\tilde m(t)}t\le\frac{t+b}{t\,\mu_b}$$

$t\to\infty$，右边趋于 $1/\mu_b$。再让 $b\to\infty$，$\mu_b=E[\min(X,b)]$ 单调增到 $\mu$（monotone convergence），所以 $\limsup m(t)/t\le1/\mu$。和下界合起来，证毕。

:::edge Arithmetic 的间隔
更细的问题是 $t$ 很大时，一个长 $\delta$ 的窗口里平均有几次 renewal，预期的答案是 $\delta/\mu$（Blackwell's theorem）。它要求间隔不是 arithmetic 的。反例：$X\equiv1$，renewal 恰好在整数时刻，$m(t+0.5)-m(t)$ 在 $t$ 的小数部分小于 0.5 时是 0，否则是 1，永远在 0 和 1 之间跳，没有 limit。这和 ST3236 [第 6 站](../courses/ST3236.html#limit) periodic chain 的 $P^n_{xx}$ 没有 limit 是同一个现象，time average（这里的 $m(t)/t\to1$）照样存在。
:::

:::back
Renewal 的时刻是 stopping time、cycle 之间 independent，用到[第 1 站](#hit)的 strong Markov property；$\pi_k=1/m_k$ 的另一个 proof 在[第 2 站](#inv)；continuous-time 的 $m_x$ 和 $q_x$ 在[第 4 站](#ctmc)。
:::

:::from
Renewal process 的定义、“Markov chain 返回某个 state”是 renewal 的例子、$S_{N(t)}\le t<S_{N(t)+1}$ 的 sandwich、renewal-reward theorem、residual life 的 time average $E[X^2]/(2\bar X)$、stopping trial 与 Wald's equality、用 $J=N(t)+1$ 得下界、用 $\min(b,X)$ 截断得上界、Blackwell's theorem 对 arithmetic distribution 的例外，跟着 [MIT 6.262 讲义第 4 章](https://www.ocw.mit.edu/courses/6-262-discrete-stochastic-processes-spring-2011/931ffa0940899c27f34b71ad64fd2bb0_MIT6_262S11_chap04.pdf) 第 4.1–4.6 节（详细转述，前 10 万字符）。Bus 每 10 分钟一班等 5 分钟、Poisson 等 10 分钟的对比和 size-biased 的说法来自 [Cambridge 讲义](https://dpmms.cam.ac.uk/~ps422/notes-new.pdf)第 4 节。2 或 18 分钟的例子、8.2 和 16.4、0.9 的比例、$E[S_{N(1)}]=0.368$ 的反例、用 renewal-reward 重新推 $\pi_x=1/(q_xm_x)$，是为这一页做的。

## [mart] Martingale 与 optional stopping

:::skip
超出 NUSMods 的课程描述。能验证几个常用的 martingale，用 optional stopping 解 gambler's ruin，并能对具体的 stopping time 检查三组条件里哪一组成立，就读完了这一页。

### 换一种办法解 gambler's ruin

ST3236 [第 2 站](../courses/ST3236.html#fsa)的例子：手里有 2 美元，每局押 1 美元，以 $p=0.4$ 赢、$q=0.6$ 输，到 0 或 4 美元为止。用 first-step analysis 解一组 linear equation，得到到达 4 美元的 probability $\tfrac4{13}$、expected 局数 $\tfrac{50}{13}$。每换一个问题就要重新列一组 equation。

有没有一个随着游戏进行、平均来看不变的量？试 $M_n=1.5^{S_n}$（$1.5=q/p$，$S_n$ 是手里的钱）。已知前 $n$ 局，下一局之后：

$$E\big[1.5^{S_{n+1}}\mid S_0,\dots,S_n\big]=1.5^{S_n}\left(0.4\times1.5+0.6\times\tfrac1{1.5}\right)=1.5^{S_n}(0.6+0.4)=1.5^{S_n}$$

如果在停下来的 random 时刻 $T$ 也有 $E[1.5^{S_T}]=1.5^{S_0}$，那么记 $h=P(S_T=4)$，

$$1.5^2=h\cdot1.5^4+(1-h)\cdot1.5^0\quad\Longrightarrow\quad 2.25=5.0625h+1-h\quad\Longrightarrow\quad h=\frac{1.25}{4.0625}=\frac4{13}$$

一行就得到了。

::fig[ma3238-ruinmart] 每个 state 下面是 $1.5^x$。如果停下时 $1.5^{S_T}$ 的 expectation 仍是起点的 2.25，它只能是两端 1 和 5.0625 按 $1-h$ 与 $h$ 的加权平均，2.25 在线段上的位置就读出了 $h$。

问题是：“每一步平均不变”推出“在 random 时刻平均不变”，需要什么条件？

### Martingale

记 $\mathcal F_n$ 为前 $n$ 步的信息（$X_0,\dots,X_n$ 的值）。Given $\mathcal F_n$ 的 conditional expectation $E[Y\mid\mathcal F_n]$ 是 $X_0,\dots,X_n$ 的一个 function，满足 tower property $E\big[E[Y\mid\mathcal F_n]\big]=E[Y]$（ST2131 [第 5 站](../courses/ST2131.html#hier)）。

Process $(M_n)$ 若每个 $M_n$ 由 $\mathcal F_n$ 决定、$E|M_n|<\infty$，并且

$$E[M_{n+1}\mid\mathcal F_n]=M_n$$

就叫 martingale。对两边取 expectation，用 tower property，$E[M_{n+1}]=E[M_n]$，所以 $E[M_n]=E[M_0]$ 对每个固定的 $n$ 成立。

设 $S_n$ 是每步 $+1$（probability $p$）或 $-1$（probability $q$）的 random walk，$\xi_{n+1}=S_{n+1}-S_n$ 和 $\mathcal F_n$ independent。三个常用的 martingale：

- $S_n-n(p-q)$：$E[S_{n+1}-(n+1)(p-q)\mid\mathcal F_n]=S_n+(p-q)-(n+1)(p-q)=S_n-n(p-q)$。
- $(q/p)^{S_n}$：上一节已验证，括号里是 $p\cdot\frac qp+q\cdot\frac pq=q+p=1$。
- $p=\tfrac12$ 时 $S_n^2-n$：$E[(S_n+\xi)^2\mid\mathcal F_n]=S_n^2+2S_nE[\xi]+E[\xi^2]=S_n^2+1$，减去 $n+1$ 正好是 $S_n^2-n$。

ST3236 [第 7 站](../courses/ST3236.html#branch)的 branching process 也有一个：第 $n$ 代人数 $Z_n$，offspring mean $\mu$，$E[Z_{n+1}\mid\mathcal F_n]=\mu Z_n$，所以 $Z_n/\mu^n$ 是 martingale。

### 停下来的 martingale 仍是 martingale

设 $T$ 是 stopping time（[第 1 站](#hit)的定义），$T\wedge n=\min(T,n)$。

**Theorem。** $M_{T\wedge n}$ 是 martingale，所以 $E[M_{T\wedge n}]=E[M_0]$ 对每个 $n$ 成立。

Proof。走到 $T$ 之后就不再变，所以 $M_{T\wedge n}$ 只累积 $T$ 之前的 increment：

$$M_{T\wedge n}=M_0+\sum_{k=1}^n\mathbf 1\{T\ge k\}\,(M_k-M_{k-1})$$

$\{T\ge k\}=\{T\le k-1\}^c$ 由 $\mathcal F_{k-1}$ 决定，可以提到 conditional expectation 外面：

$$E\big[\mathbf 1\{T\ge k\}(M_k-M_{k-1})\mid\mathcal F_{k-1}\big]=\mathbf 1\{T\ge k\}\,\big(E[M_k\mid\mathcal F_{k-1}]-M_{k-1}\big)=0$$

所以 $M_{T\wedge n}-M_{T\wedge(n-1)}$ 的 conditional mean 是 0，$M_{T\wedge n}$ 是 martingale。证毕。

这里又一次只用到“$\{T\ge k\}$ 由过去决定”。赌徒只能根据已经发生的结果决定何时离场，这样的策略改变不了一个公平游戏的 expectation。

### Optional stopping theorem

$E[M_{T\wedge n}]=E[M_0]$ 对每个 $n$ 成立。若 $T<\infty$，$n\to\infty$ 时 $M_{T\wedge n}\to M_T$。要得到 $E[M_T]=E[M_0]$，还要 expectation 跟着 limit 走，这需要条件。

**Theorem。** 设 $M$ 是 martingale，$T$ 是 stopping time。下面三组条件任一成立，则 $E[M_T]=E[M_0]$：

(a) $T\le K$，$K$ 是常数；
(b) $P(T<\infty)=1$，且存在常数 $K$ 使 $|M_{T\wedge n}|\le K$ 对所有 $n$ 成立；
(c) $E[T]<\infty$，且存在常数 $c$ 使 $|M_k-M_{k-1}|\le c$ 对所有 $k$ 成立。

Proof。(a)：取 $n=K$，$M_{T\wedge K}=M_T$，直接由上一个 theorem。

(b)：$T\le n$ 时 $M_T=M_{T\wedge n}$，两者只在 $\{T>n\}$ 上可能不同，而在那里差的绝对值不超过 $2K$：

$$\big|E[M_T]-E[M_{T\wedge n}]\big|\le2K\,P(T>n)\xrightarrow{n\to\infty}0$$

$E[M_{T\wedge n}]=E[M_0]$ 对每个 $n$ 成立，所以 $E[M_T]=E[M_0]$。

(c)：$E[T]<\infty$ 推出 $T<\infty$ a.s.。$M_T-M_{T\wedge n}=\sum_{k>n}\mathbf 1\{T\ge k\}(M_k-M_{k-1})$，每项绝对值不超过 $c\,\mathbf 1\{T\ge k\}$：

$$\big|E[M_T]-E[M_{T\wedge n}]\big|\le c\sum_{k>n}P(T\ge k)\xrightarrow{n\to\infty}0$$

因为 $\sum_{k\ge1}P(T\ge k)=E[T]<\infty$，tail 趋于 0。证毕。

回到 gambler's ruin。$1.5^{S_{T\wedge n}}$ 在 $1.5^0$ 和 $1.5^4$ 之间，有界；$T<\infty$ a.s.（finite chain 上 transient state 迟早离开，ST3236 第 2 站的 fundamental matrix 还给出 $E[T]<\infty$）。条件 (b) 成立，$h=\tfrac4{13}$ 有了根据。

Expected 局数用 $M_n=S_n-n(p-q)=S_n+0.2n$。它的 increment 是 $\xi+0.2$，绝对值不超过 1.2；$E[T]<\infty$。条件 (c) 成立：

$$E[S_T]+0.2\,E[T]=S_0=2,\qquad E[S_T]=4\times\tfrac4{13}=\tfrac{16}{13}$$

$$E[T]=\frac{2-\tfrac{16}{13}}{0.2}=\frac{10}{13}\times5=\frac{50}{13}\approx3.85$$

和 ST3236 用 first-step analysis 解出的 $\tfrac{50}{13}$ 相同。

$p=\tfrac12$ 时，从 $k$ 出发到 0 或 $N$ 为止。$S_n$ 本身是 martingale，条件 (b)：$E[S_T]=k$，所以 $P(S_T=N)=k/N$。$S_n^2-n$ 的 increment 是 $(S_{n-1}+\xi_n)^2-S_{n-1}^2-1=2S_{n-1}\xi_n$，在 $T$ 之前 $|S_{n-1}|\le N$，所以绝对值不超过 $2N$（(c) 的 proof 里只用到 $k\le T$ 的 increment，所以只要求 $T$ 之前有界），条件 (c)：$E[S_T^2]-E[T]=k^2$，而 $E[S_T^2]=N^2\cdot\frac kN=kN$，所以

$$E[T]=kN-k^2=k(N-k)$$

$N=4$、$k=2$ 时是 4 局。

### 条件为什么不能省

$p=\tfrac12$ 的 random walk 从 0 出发，没有下界，碰到 1 就停：$T=\inf\{n:S_n=1\}$。一维 symmetric walk recurrent（ST3236 [第 4 站](../courses/ST3236.html#rec)），所以 $P(T<\infty)=1$，而 $S_T=1$，

$$E[S_T]=1\ne0=E[S_0]$$

一个公平的游戏，按“赢 1 美元就走”的策略，必然赢。三组条件都不成立：$T$ 无界；$S_{T\wedge n}$ 往下没有界；如果 $E[T]<\infty$，increment 有界，(c) 就会给出 $E[S_T]=0$，矛盾，所以 $E[T]=\infty$。

每个固定的 $n$ 上，$E[S_{T\wedge n}]=0$ 仍然成立。把它按“到 $n$ 时停没停”拆开：

$$0=E[S_{T\wedge n}]=1\cdot P(T\le n)+E\big[S_n\mathbf 1\{T>n\}\big]\quad\Longrightarrow\quad E\big[S_n\mathbf 1\{T>n\}\big]=-P(T\le n)\to-1$$

还没停的 path 越来越少，但走得越来越低，它们对 expectation 的贡献始终约为 $-1$。$n\to\infty$ 时这部分 path 的 probability 趋于 0，贡献却不趋于 0，limit 和 expectation 不能交换，正是条件 (b) 要排除的情况。

::fig[ma3238-stopped] 12 条从 0 出发的 symmetric walk，碰到 1 就停。11 条在 60 步内停在 1，没停的那条已经到了很低的位置。（mulberry32，seed 5。）

:::wrong $E[T]<\infty$ 就可以 optional stopping
条件 (c) 要两样东西，increment 有界不能省。Double-or-nothing：$Z_0=1$，每一步 $Z_{n+1}=Z_n\cdot Y_{n+1}$，$Y$ i.i.d.，以各 $\tfrac12$ 取 0 或 2。$E[Z_{n+1}\mid\mathcal F_n]=Z_n\cdot1$，是 martingale。令 $T$ 为第一次 $Z_n=0$ 的时刻，每一步以 $\tfrac12$ 发生，$T$ 是 Geometric$(\tfrac12)$，$E[T]=2<\infty$。可是 $Z_T=0$，$E[Z_T]=0\ne1$。Increment $Z_{n+1}-Z_n=\pm Z_n$ 可以大到 $2^n$。和上一个例子一样，expectation 1 全部压在一条越来越不可能的 path 上：$P(Z_{10}=1024)=\tfrac1{1024}$，其余时候 $Z_{10}=0$。
:::

:::edge Martingale convergence
Double-or-nothing 里 $Z_n\to0$ with probability 1，而 $E[Z_n]=1$。这是一般现象的一个例子：nonnegative martingale 一定 a.s. converge（martingale convergence theorem），但 limit 的 expectation 可以比 $E[Z_0]$ 小。Branching process 的 $Z_n/\mu^n$ 也是 nonnegative martingale，所以 converge 到某个 $W$；$\mu\le1$ 时 $W=0$（必然灭绝，ST3236 第 7 站），$\mu>1$ 时 $W$ 以 extinction probability 为 0、否则为正。
:::
