先看三件事。每一件里，用的工具在别的市场上都算得过去，放到 crypto 上就出了事。

**第一件。** 用 normal distribution 描述 Bitcoin 的 return。Normal 的 kurtosis 是 3；Bitstamp 上 2013 到 2020 年的 BTC 5 小时 return，kurtosis 是 72.64。按 normal 算，1000 天里超过 4 个 standard deviation 的日子应该只有 0.06 天；第 1 站那组 1000 天的数据里有 9 天。

**第二件。** 一个 Uniswap pool 的 ETH price 从 3000 涨到 3300 又跌回 3000，pool 回到和开始时一模一样的状态，impermanent loss 是 0。但这一来一回，arbitrageur 从 pool 里拿走了 1,396.12 USDC。第 6 站解释这笔钱从哪里来。

**第三件。** 一个 ETH/USDC pool 上有 8 个 over-collateralized 的 borrower。有人卖 38 ETH，price 跌 3.7%，什么都没发生；卖 45 ETH，price 最终跌 26%。多卖的 7 ETH 本身只多压低了 0.7%，剩下的跌幅全是 liquidation 自己造成的。第 7 站一步步算这个过程。

## [facts] Crypto return 的 stylized facts

:::skip
能对一组 return 算出 kurtosis、超过 4σ 的天数和 $r_t$、$|r_t|$ 的 ACF，并据此说出 heavy tail、volatility clustering、“return 几乎不可预测”这三条在数据里各是什么样子，就可以去第 2 站。
:::

### Return 用哪一个

价格 $P_t$ 本身不能直接拿来做统计：它的 level 一直在变，今天 60,000 的 BTC 和五年前 6,000 的 BTC，同样跌 600 意义完全不同。所以研究的对象是 return。有两种定义：simple return $R_t=P_t/P_{t-1}-1$ 和 log return $r_t=\ln(P_t/P_{t-1})$。

用一个例子看两者的差别。价格从 100 涨到 150 再跌回 100：

| | 100 → 150 | 150 → 100 | 两天合计 |
|---|---|---|---|
| simple return | $+50\%$ | $-33.3\%$ | 两个数相加是 $+16.7\%$，可实际是 0 |
| log return | $\ln1.5=+0.405$ | $\ln(2/3)=-0.405$ | $0$ |

Log return 可以按时间相加：$r_{t-h+1}+\cdots+r_t=\ln(P_t/P_{t-h})$，所以多日的 return 就是 daily return 之和，多日的 variance 在 independent 时就是 daily variance 之和。这是 time series 分析几乎都用 log return 的原因。$|r|$ 很小时两者几乎相等，$R=e^r-1\approx r$。

Annualization 也从这里来：一年有 $N$ 个交易期，各期 independent 且 variance 相同，那么一年的 variance 是 $N\sigma^2$，standard deviation 是 $\sqrt N\,\sigma$。MIT 18.S096 的讲义对 stock 用 $N=252$。Crypto 每天 24 小时、每周 7 天都在交易，所以 $N=365$。Daily standard deviation 3.79% 对应 annualized volatility $3.79\%\times\sqrt{365}=72.4\%$。

### 这一站用的数据

真实的 crypto 价格数据不能随页面发布，所以这一站和下一站用一组**模拟数据**，并随时对照已发表的真实数据结果。模拟数据的好处是“正确答案”已知，第 2 站估计 model 时可以检查估得准不准。

它由下一站要讲的 GARCH(1,1) model 生成：$r_t=\sigma_t z_t$，$\sigma_t^2=6.125\times10^{-5}+0.10\,r_{t-1}^2+0.85\,\sigma_{t-1}^2$，$z_t$ 取 standardized Student-$t$（degrees of freedom 4）。参数让 long-run 的 daily volatility 正好是 3.5%，和 BTC 的量级相当。一共 1000 天，random seed 固定，图里每个点都由同一段代码算出。

::fig[dse4211-series] 1000 天的 daily log return（灰线）。彩线是 model 里的 $\pm2\sigma_t$：它时宽时窄，宽的那几段，大的 return 也扎堆出现。第 932 天的 log return 是 −0.33，换成 simple return 是 −28.1%。

### Heavy tail

先算 sample mean 和 sample standard deviation：$\bar r=-0.19\%$，$s=3.79\%$。把每天的 return 标准化成 $z_t=(r_t-\bar r)/s$，数一数有多少天 $|z_t|$ 超过某个值，再和 normal 的预期对比。Normal 的 $P(|Z|>4)=6.33\times10^{-5}$，乘上 1000 天是 0.063 天。

| $\lvert z\rvert$ 超过 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|
| 模拟数据的天数 | 19 | 9 | 3 | 1 |
| normal 的预期天数 | 2.7 | 0.063 | 0.00057 | 0.000002 |

最大的一天是第 932 天，$|z|=8.66$。Normal 给 $P(|Z|>8.66)$ 的值是 $4.9\times10^{-18}$。

把这个现象压缩成一个数，用 kurtosis：

$$\kappa=\frac{\frac1n\sum_t(r_t-\bar r)^4}{s^4}$$

四次方让大的 deviation 占绝对主导。Normal 的 $\kappa=3$；这组数据是 12.92；Bitstamp 上真实的 BTC 5 小时 return 是 72.64。

一个数不能说明 tail 具体是什么形状。更好的办法是画 survival function $P(|Z|>x)$，并把 y 轴取 log：

::fig[dse4211-tail] 黑线是 normal 的 $P(|Z|>x)$，在 log scale 上越往右掉得越快；彩线是模拟数据，每一个台阶是一天。到 $x=4$ 时两者已经差了两个数量级以上。

Normal 的 tail 按 $e^{-x^2/2}$ 衰减，比任何 power 都快。真实数据的 tail 更接近 power law：$P(|r|>x)\propto x^{-k}$，在 log-log 图上是一条 slope 为 $-k$ 的直线，$k$ 叫 tail index。上面那篇 Bitstamp 的研究估出 BTC 的 $k=3.49\pm0.02$，他们指出这和 intraday 的外汇、stock 市场估出的值接近。所以 heavy tail 不是 crypto 独有的，crypto 的特别之处在于 volatility 本身的 level 高。

:::edge Tail index 小于 4 时，kurtosis 这个数靠不住
$P(|r|>x)\propto x^{-k}$ 时，$E|r|^m$ 只在 $m<k$ 时有限。原因是把 $|r|^m=\int_0^{|r|}mx^{m-1}\,dx$ 取 expectation、交换积分次序，得到

$$E|r|^m=\int_0^\infty mx^{m-1}\,P(|r|>x)\,dx$$

Tail 上 $P(|r|>x)\approx Cx^{-k}$，$x$ 很大时被积函数约为 $mC\,x^{m-1-k}$，而 $\int^\infty x^{m-1-k}\,dx$ 只在 $m-1-k<-1$，即 $m<k$ 时有限。$k=3.49$ 意味着 fourth moment 是无穷大，population 的 kurtosis 根本不存在，sample kurtosis 不会 converge 到任何数，每多一个极端的日子就跳一下。可以直接看到这一点：用同样的 GARCH 参数、只换 random seed，各生成 1500 天，sample kurtosis 分别是 7.89、11.90、15.75、43.49。所以报告 crypto return 的 kurtosis 时，它只说明“tail 很粗”；要比较 tail 有多粗，用 tail index。
:::

### Return 本身几乎不可预测

如果昨天的 return 能预测今天的 return，就能赚钱，市场里的人会把这种关系交易掉。检验的工具是 autocorrelation function（ACF）：

$$\hat\rho(\ell)=\frac{\sum_{t=\ell+1}^{n}(r_t-\bar r)(r_{t-\ell}-\bar r)}{\sum_{t=1}^{n}(r_t-\bar r)^2}$$

它是 $r_t$ 和 $\ell$ 天前的 $r_{t-\ell}$ 的 sample correlation。判断它是不是显著需要一个参照：如果 $r_t$ 是 i.i.d.，$\hat\rho(\ell)$ 近似服从 $N(0,1/n)$，所以 95% 的 lag 应该落在 $\pm1.96/\sqrt n$ 之内。$n=1000$ 时这个 band 是 $\pm0.062$。

这组数据前三个 lag 是 $\hat\rho(1)=0.009$、$\hat\rho(2)=0.031$、$\hat\rho(3)=0.089$。第 3 个超出了 band。这能说明 return 可预测吗？看 40 个 lag，每个 lag 有 5% 的机会纯粹因为 noise 落到 band 外，40 个里平均就有 2 个；这组数据实际有 3 个（lag 3、7、19，分别是 0.089、−0.064、0.074），都只是略微越界。数据本来就是按 $r_t=\sigma_t z_t$ 生成的，$z_t$ 之间 independent，所以这几个越界确实是 noise。只看到一两个 lag 越界，不构成证据。

真实数据的结论一样：Bitstamp 的研究里，Pearson autocorrelation 接近可以忽略，只有少数 lag 略高于 significance level。他们同时算了只用排名的 Spearman autocorrelation，它比 Pearson 的小，作者认为 Pearson 那几个越界有一部分是 tail 里的极端值推高的。Heavy tail 让 sample correlation 本身也不稳。

### Volatility clustering

Return 的方向不可预测，return 的大小却可以。把 ACF 用在 $|r_t|$ 上：

::fig[dse4211-acf] 同一组 1000 天的数据。左边是 $r_t$ 的 ACF，几乎都在 noise 带里；右边是 $|r_t|$ 的 ACF，lag 1 到 11 全部远在 band 上方，到 lag 20 左右仍有几个越出，再往后降到 0 附近。

$|r_t|$ 的 ACF 在 lag 1 是 0.198，lag 10 是 0.119，lag 20 是 0.072，lag 30 是 0.005；40 个 lag 里有 15 个在 band 上方。今天波动大，明天、下周波动也倾向于大，这就是第一张图里“宽的一段”。Bitstamp 的 BTC 数据里，$|r|$ 的 lag-1 autocorrelation 是 0.39，之后按 power law 衰减，exponent 是 0.31。

还有一条和方向有关的事实，叫 leverage effect：今天的 return 和未来的 $r^2$ 是 negative correlation，下跌之后的 volatility 比上涨之后的大。Bitstamp 的研究在 BTC 上找到了它：return 和之后各个 lag 的 $r^2$ 显著负相关，和之前的没有显著相关；把这个 correlation 逐 lag 累加，累加值在 $\tau_0=10$ 个 5 小时处到最低，也就是影响持续略多于两天。这个 negative correlation 比 stock index 上通常看到的更大；stock 上它的典型 decay time 是个股约 50 天、index 约 10 天。这一页的模拟数据是对称的，没有这条性质；第 2 站末尾提到的 asymmetric GARCH 就是为它设计的。

:::wrong $r_t$ 的 autocorrelation 都在 noise 带里，所以每天的 return 是 independent 的
Independent 的定义是：知道 $r_{t-1}$ 不改变 $r_t$ 的 distribution。如果真是这样，那么 $r_{t-1}$ 的任何 function 都和 $r_t$ 的任何 function 不相关，$|r_{t-1}|$ 和 $|r_t|$ 的 correlation 也应该在 $\pm0.062$ 之内。实际是 0.198，是 band 宽度的 3.2 倍。

“Uncorrelated”只说 linear 的关系为 0。$r_t=\sigma_tz_t$ 这种结构里，$z_t$ 的符号随机，所以 $r_t$ 和 $r_{t-1}$ 的乘积平均为 0；可 $\sigma_t$ 由 $r_{t-1}^2$ 决定，所以 $|r_t|$ 和 $|r_{t-1}|$ 一起大一起小。Uncorrelated 而不 independent，正是 volatility 可以 model 的前提。
:::

## [garch] Volatility model：EWMA 与 GARCH

:::skip
能按 recursion 手算几天的 $\sigma_t$，能写出 long-run variance、h 步 forecast 和 half-life，并解释为什么 shock 之后 $\sqrt h$ 规则会高估多日的 risk，就可以去第 3 站。
:::

### 问题：今天的 volatility 是多少

第 1 站的第一张图里，$\sigma_t$ 在 2.3% 和 10.8% 之间变动。Risk 管理要的是“明天”的 $\sigma$，可它看不见，只能从过去的 return 估计。最直接的办法是取最近 $m$ 天的 sample standard deviation，问题是 $m$ 取多少。

拿第 940 天来试，那时第 932 天的 −33% 刚过去 8 天，model 里真实的 $\sigma_{940}=7.53\%$。

| 估计方法 | 第 940 天给出的 σ |
|---|---|
| 最近 365 天的 sample sd | 3.21% |
| 最近 30 天的 sample sd | 7.09% |
| EWMA，$\lambda=0.94$ | 7.62% |
| 真实值 | 7.53% |

365 天的窗口把最近的 crash 和一年前平静的日子同等对待，严重低估。30 天的窗口反应快，代价是 30 天后那次 crash 会突然整个掉出窗口，估计值断崖式下跌，而真实的 $\sigma$ 是慢慢回落的。

### EWMA：让权重平滑地衰减

把“最近 $m$ 天等权、更早的权重为 0”改成按 geometric 衰减的权重：

$$\tilde\sigma_{t+1}^2=(1-\lambda)\,r_t^2+\lambda\,\tilde\sigma_t^2$$

反复代入，$\tilde\sigma_{t+1}^2=(1-\lambda)\sum_{j\ge0}\lambda^j r_{t-j}^2$，$j$ 天前的权重是 $(1-\lambda)\lambda^j$。这正是 RiskMetrics Technical Document 的写法，它对 daily data 取 $\lambda=0.94$，对 monthly data 取 0.97。

$\lambda$ 和“窗口取多长”是同一个问题的两种问法。最近 $K$ 天的权重合计 $(1-\lambda)(1+\lambda+\cdots+\lambda^{K-1})=1-\lambda^K$。$\lambda=0.94$ 时，$1-0.94^{74}=0.990$：最近 74 天已经占了 99% 的权重，Technical Document 的 Table 5.7 列的正是这个数。权重的平均年龄是 $\sum_j j(1-\lambda)\lambda^j=\lambda/(1-\lambda)=15.7$ 天，和 30 天窗口差不多（等权的 $j=0,\dots,29$ 平均是 14.5 天，365 天窗口是 182 天），但权重是慢慢减小的，没有断崖。上表里它给出 7.62%，最接近真实值。

EWMA 有一个结构上的缺陷。今天预测 $h$ 天以后的 variance 是多少？公式里没有任何东西会把它拉回某个正常水平，最好的猜测只能是 $\tilde\sigma_{t+1}^2$ 本身，对所有 $h$ 都一样。Crash 之后，它预测一年后的 volatility 仍然是 7.62%。

### GARCH(1,1)

在 EWMA 上加一个 constant：

$$\sigma_t^2=\omega+\alpha\,\varepsilon_{t-1}^2+\beta\,\sigma_{t-1}^2,\qquad\varepsilon_t=\sigma_tz_t$$

这里 $\varepsilon_t$ 是 return 减去 mean（这一页 mean 取 0，$\varepsilon_t=r_t$），$z_t$ 是 mean 0、variance 1 的 i.i.d. innovation。$\omega>0$，$\alpha,\beta\ge0$。$\omega=0$ 且 $\alpha+\beta=1$ 时就是 EWMA。

这个 constant 带来了 long-run level。对两边取 unconditional expectation，stationary 时 $E[\sigma_t^2]=E[\varepsilon_t^2]=\bar\sigma^2$：

$$\bar\sigma^2=\omega+\alpha\bar\sigma^2+\beta\bar\sigma^2\quad\Longrightarrow\quad\bar\sigma^2=\frac{\omega}{1-\alpha-\beta}$$

它要求 $\alpha+\beta<1$，这就是 stationarity 条件。第 1 站的参数：$\bar\sigma^2=6.125\times10^{-5}/0.05=1.225\times10^{-3}$，$\bar\sigma=3.5\%$。

### 手算几天

从 $\sigma^2=1.225\times10^{-3}$（3.5%）出发，接下来 5 天的 return 是 $+2\%$、$-15\%$、$+1\%$、$-3\%$、$0$。每一行把三项分开写：

| 当天 return | 当天 $\sigma^2$ | $\omega$ | $\alpha\varepsilon^2$ | $\beta\sigma^2$ | 次日 $\sigma^2$ | 次日 σ |
|---|---|---|---|---|---|---|
| $+2\%$ | $1.2250\times10^{-3}$ | $6.125\times10^{-5}$ | $4.0\times10^{-5}$ | $1.0413\times10^{-3}$ | $1.1425\times10^{-3}$ | 3.38% |
| $-15\%$ | $1.1425\times10^{-3}$ | $6.125\times10^{-5}$ | $2.25\times10^{-3}$ | $9.711\times10^{-4}$ | $3.2824\times10^{-3}$ | 5.73% |
| $+1\%$ | $3.2824\times10^{-3}$ | $6.125\times10^{-5}$ | $1.0\times10^{-5}$ | $2.7900\times10^{-3}$ | $2.8613\times10^{-3}$ | 5.35% |
| $-3\%$ | $2.8613\times10^{-3}$ | $6.125\times10^{-5}$ | $9.0\times10^{-5}$ | $2.4321\times10^{-3}$ | $2.5833\times10^{-3}$ | 5.08% |
| $0$ | $2.5833\times10^{-3}$ | $6.125\times10^{-5}$ | $0$ | $2.1958\times10^{-3}$ | $2.2571\times10^{-3}$ | 4.75% |

$-15\%$ 那天，$\alpha\varepsilon^2$ 一项单独就有 $2.25\times10^{-3}$，比原来整个 $\sigma^2$ 还大，于是次日的 σ 从 3.38% 跳到 5.73%。之后每天 $\beta\sigma^2$ 只保留 85%，加上的 $\omega$ 和小 return 补不回来，σ 一天天往 3.5% 回落。

::fig[dse4211-garch] 同一个 model 走 60 天，第 12 天放一个 −15% 的 shock，其余日子是随机的小 return。下面的柱子逐天出现，上面的点同步走在 $\sigma_t$ 上。

这张图也说明了 GARCH 不能做什么：$\sigma_t$ 在 shock **之后**才跳。第 932 天那个 −33%，model 在前一天给出的 $\sigma_{932}$ 只有 2.95%，那一天的 $z$ 是 −11.2，完全来自 Student-$t$ 的 tail。GARCH 描述的是“shock 之后 volatility 怎么演化”，不预测 shock 本身。

### Forecast 与 half-life

站在第 $t$ 天，$\sigma_{t+1}^2$ 已经知道了。$\sigma_{t+2}^2$ 的 conditional expectation 是

$$E_t[\sigma_{t+2}^2]=\omega+\alpha\,E_t[\varepsilon_{t+1}^2]+\beta\,\sigma_{t+1}^2=\omega+(\alpha+\beta)\,\sigma_{t+1}^2$$

因为 $E_t[\varepsilon_{t+1}^2]=\sigma_{t+1}^2E[z^2]=\sigma_{t+1}^2$。两边减去 $\bar\sigma^2=\omega+(\alpha+\beta)\bar\sigma^2$，$\omega$ 消掉：

$$E_t[\sigma_{t+2}^2]-\bar\sigma^2=(\alpha+\beta)\,(\sigma_{t+1}^2-\bar\sigma^2)$$

同样的一步可以一直往前推，每推一天乘一次 $\alpha+\beta$：

$$E_t[\sigma_{t+h}^2]=\bar\sigma^2+(\alpha+\beta)^{h-1}(\sigma_{t+1}^2-\bar\sigma^2)$$

和 long-run level 的差距按 geometric 速度缩小。差距减半所需的天数满足 $(\alpha+\beta)^h=\tfrac12$，即 half-life $h=\ln0.5/\ln(\alpha+\beta)$。$\alpha+\beta=0.95$ 时是 13.5 天。这个 $\alpha+\beta$ 叫 persistence。

具体算一次。从 steady state 出发遇到一天 $-15\%$：$\sigma_{t+1}^2=6.125\times10^{-5}+0.1\times0.0225+0.85\times1.225\times10^{-3}=3.3525\times10^{-3}$，即 5.79%。往后的 forecast：

| $h$ | 1 | 2 | 5 | 10 | 14 | 30 | 60 |
|---|---|---|---|---|---|---|---|
| $\sqrt{E_t[\sigma_{t+h}^2]}$ | 5.79% | 5.70% | 5.44% | 5.07% | 4.81% | 4.13% | 3.64% |

:::wrong 10 天的 volatility 等于 1 天的乘以 $\sqrt{10}$
$\sqrt h$ 规则来自“各天 independent 且 variance 相同”。Shock 之后第二个条件不成立：未来每天的 variance forecast 在下降。Log return 可加，10 天 return 的 variance 是 10 个 daily variance forecast 之和：

$$\sum_{h=1}^{10}E_t[\sigma_{t+h}^2]=0.029324,\qquad\sqrt{0.029324}=17.12\%$$

而 $\sqrt{10}\times5.79\%=18.31\%$，高估了 7%。反过来，平静时期 $\sigma_{t+1}$ 低于 $\bar\sigma$，$\sqrt h$ 规则会低估。只有正好处在 long-run level 时，$\sqrt{10}\times3.5\%=11.07\%$ 才是对的。
:::

### 用 maximum likelihood 估计参数

$\omega,\alpha,\beta$ 要从数据里估。给定参数，从一个起始值出发就能按 recursion 算出每一天的 $\sigma_t^2$，于是每一天的 return 有了一个 density。假设 $z_t$ 是 normal，log-likelihood 是

$$\log L(\omega,\alpha,\beta)=-\frac12\sum_{t=1}^n\left[\ln(2\pi)+\ln\sigma_t^2+\frac{\varepsilon_t^2}{\sigma_t^2}\right]$$

$\sigma_t^2$ 通过 recursion 依赖于全部参数，没有 closed form，只能 numerical optimization。常用的简化是 variance targeting：令 $\omega=s^2(1-\alpha-\beta)$，$s^2$ 是 sample variance，只剩两个参数。

在第 1 站的 1000 天数据上（$\sigma_1^2$ 取 sample variance），对 $\alpha,\beta$ 以 0.005 为步长做 grid search，得到 $\hat\alpha=0.100$、$\hat\beta=0.820$，真实值是 0.10 和 0.85。三组参数的 log-likelihood：

| 参数 | log-likelihood |
|---|---|
| 估计值 $\hat\alpha=0.100,\hat\beta=0.820$ | 1926.61 |
| 真实值 $\alpha=0.10,\beta=0.85$ | 1924.10 |
| constant variance（$\alpha=\beta=0$） | 1852.97 |

估计值的 likelihood 比真实值略高，这是 sample 有限时的正常现象。和 constant variance 比，likelihood ratio statistic 是 $2\times(1926.61-1852.97)=147.3$，多了两个参数，$\chi^2_2$ 的 5% critical value 是 5.99，constant variance 被彻底拒绝。

估计并不精确：$\hat\alpha+\hat\beta=0.92$，真实是 0.95，换成 half-life 是 $\ln0.5/\ln0.92=8.3$ 天对 13.5 天。1000 天的数据对 persistence 只能估个大概。

数据其实是用 Student-$t$ 的 innovation 生成的，这里却用了 normal 的 likelihood，这叫 quasi-maximum likelihood（QMLE）。Lee 和 Hansen（1994）证明，GARCH(1,1) 的 Gaussian QMLE 不要求 $z_t$ 是 normal，甚至不要求 independent：只要 $z_t$ 的 conditional moment 到 $2+\delta$ 阶有界、$\alpha+\beta<1$，估计就是 consistent 的；asymptotic normality 还要求 conditional fourth moment 有界。$t_4$ 满足前一条，不满足后一条（它的 fourth moment 无穷，见第 1 站）。所以在这组数据上估计会收敛到真值，但按通常公式算出的 standard error 没有理论保证。

### Diagnostics：clustering 有没有被 model 吸收

18.S096 的讲义给的检验是 ARCH 的 LM test：把 $\varepsilon_t^2$ 对 constant 和 $\varepsilon_{t-1}^2,\dots,\varepsilon_{t-p}^2$ 做 linear regression，原假设是没有 ARCH effect（$\alpha_1=\cdots=\alpha_p=0$），此时 $nR^2$ 近似服从 $\chi^2_p$，$n$ 是 regression 用到的 observation 数。

在原始 return 上取 $p=5$：$n=995$，$R^2=0.0296$，$nR^2=29.47$。$\chi^2_5$ 的 5% critical value 是 11.07，拒绝：return 的平方可以用过去的平方预测，这就是 clustering。

换成 standardized residual $\hat z_t=\varepsilon_t/\hat\sigma_t$（$\hat\sigma_t$ 用估计出的参数按 recursion 算）再做一次：$R^2=0.0004$，$nR^2=0.38$，远小于 11.07。40 个 lag 的 ACF 里，$r_t^2$ 有 8 个越出 $\pm0.062$ 的 band，$\hat z_t^2$ 只有 1 个。Clustering 被 model 吸收了。

Tail 没有被吸收。$\hat z_t$ 的 kurtosis 是 18.72，比原始 return 的 12.92 还大：第 932 天前一天 model 给的 $\hat\sigma_{932}$ 只有 3.18%，那天的 $\hat z=-10.37$。GARCH 把平时的波动解释掉以后，剩下的那次 crash 显得更极端。这时该把 likelihood 里的 normal 换成 $t$ distribution，并用 QQ plot、Jarque–Bera 之类的 normality test 检查（讲义列的也是这几种）。

### 用来算 VaR

1-day 99% Value-at-Risk 是 return 的 1% quantile 的相反数。$-15\%$ 那天之后，$\sigma_{t+1}=5.79\%$：

- 假设 $z$ 是 normal，quantile 是 $-2.326$，VaR $=2.326\times5.79\%=13.47\%$。
- 假设 $z$ 是 standardized $t_4$：$t_4$ 的 99% quantile 是 3.747，标准化要乘 $\sqrt{(4-2)/4}=0.707$，得 2.650，VaR $=15.34\%$。

同一个 σ，tail 的假设让 VaR 差了 1.9 个百分点。

:::edge Asymmetric GARCH
第 1 站的 leverage effect（下跌后 volatility 更高）在 GARCH(1,1) 里没有位置，因为 $\varepsilon^2$ 不分正负。18.S096 的讲义列了几种扩展：EGARCH（Nelson）、TGARCH（讲义归于 Glosten、Jagannathan 和 Runkle 1993）、PGARCH（Ding、Engle、Granger）、GARCH-in-mean，以及 $t$ 或 generalized error distribution 的 innovation。GJR 的做法是在 $\varepsilon_{t-1}<0$ 时多加一项 $\gamma\varepsilon_{t-1}^2$，这个式子讲义里没有写，是凭自己的知识补的。
:::

## [network] Correlation network、MST 与 transaction network

:::skip
能把 correlation matrix 换成 distance，跑一遍 Kruskal 得到 MST，说清 MST 里的一条 path 代表什么、crash 时 tree 怎样变化，并能用 common-input heuristic 合并 address，就可以去第 4 站。

### 15 个数看不出结构

想知道 6 个 asset 之间的关系，最直接的是 correlation matrix。下面是一个说明用的例子：数值是构造的，量级仿照 crypto 之间高度相关、与 stock index 中等相关、与 gold 几乎不相关的常见情形（已检查它是 positive definite 的 matrix）。

| | BTC | ETH | SOL | DOGE | SPX | Gold |
|---|---|---|---|---|---|---|
| BTC | 1 | 0.85 | 0.75 | 0.65 | 0.35 | 0.10 |
| ETH | | 1 | 0.80 | 0.60 | 0.33 | 0.08 |
| SOL | | | 1 | 0.55 | 0.30 | 0.05 |
| DOGE | | | | 1 | 0.20 | 0.05 |
| SPX | | | | | 1 | 0.15 |
| Gold | | | | | | 1 |

6 个 asset 已经有 15 个数，157 个 coin 就有 12,246 个。需要一种办法只留下最重要的那些关系。思路是：把 asset 当成 node，correlation 越高的两个 node 离得越近，然后用最少的 edge 把所有 node 连起来，每次都优先用最短的。

### 从 correlation 到 distance

Correlation 不能直接当 distance 用：它越大越“近”，方向反了，而且不满足 triangle inequality。Mantegna 用的变换是

$$d_{ij}=\sqrt{2(1-\rho_{ij})}$$

它为什么是一个真正的 distance？把两个 asset 的 return 各自标准化成 mean 0、variance 1 的 vector $\mathbf z_i,\mathbf z_j\in\mathbb R^n$，于是 $\frac1n\mathbf z_i\cdot\mathbf z_i=1$，$\frac1n\mathbf z_i\cdot\mathbf z_j=\rho_{ij}$。两个 vector 的 Euclidean distance 的平方展开：

$$\frac1n\|\mathbf z_i-\mathbf z_j\|^2=\frac1n\left(\mathbf z_i\cdot\mathbf z_i-2\,\mathbf z_i\cdot\mathbf z_j+\mathbf z_j\cdot\mathbf z_j\right)=1-2\rho_{ij}+1=2(1-\rho_{ij})$$

所以 $d_{ij}$ 就是 $\mathbb R^n$ 里两个点的距离（差一个 $\sqrt n$），自然满足 triangle inequality。$\rho=1$ 时 $d=0$，$\rho=0$ 时 $d=\sqrt2$，$\rho=-1$ 时 $d=2$。下面会用到的那篇 crypto 研究写成 $2\sqrt{1-\rho}$，只差一个常数倍，得到的 tree 完全一样。

这个形式不是一开始就有的。Mantegna 1998 年的 arXiv 预印本用的是 $d=1-\rho^2$，triangle inequality 只在他的几个 portfolio 上 numerical 地检查过。它在 $\rho=-1$ 时也等于 0，把完全反相关的两个 asset 放在同一个点上，而 $\rho=-1$ 时上面的 $\mathbf z_i=-\mathbf z_j$，两个点离得最远。$\sqrt{2(1-\rho)}$ 不需要检查：它是 Euclidean distance，metric 的三条性质自动成立。Onnela 等人用的就是这个形式，并把它引作 Mantegna 1999 年发表的版本。

### Kruskal：每次加最短的、不成 cycle 的 edge

Minimum spanning tree（MST）是连通全部 $N$ 个 node、edge 总长最小的 tree，恰好有 $N-1$ 条 edge。Kruskal algorithm：把所有 edge 按 distance 从小到大排好，逐条考虑；如果它连的两个 node 还不在同一个 component 里，就加入，否则跳过（加了会成 cycle）；加满 $N-1$ 条为止。

::fig[dse4211-kruskal] 对上面那个 matrix 跑 Kruskal。每一步亮起一条候选 edge：保留的变成实线，会成 cycle 的闪一下虚线后消失。下面的表逐行记录。

逐步写出来：

1. BTC–ETH，$d=\sqrt{0.30}=0.548$，加入。
2. ETH–SOL，$d=\sqrt{0.40}=0.632$，加入。
3. BTC–SOL，$d=0.707$：BTC 和 SOL 已经通过 ETH 连通，跳过。
4. BTC–DOGE，$d=0.837$，加入。
5. ETH–DOGE（0.894）、SOL–DOGE（0.949）：都已连通，跳过。
6. BTC–SPX，$d=\sqrt{1.30}=1.140$，加入。
7. ETH–SPX、SOL–SPX、DOGE–SPX：跳过。
8. SPX–Gold，$d=\sqrt{1.70}=1.304$，加入。5 条，结束。

结果：ETH 和 DOGE 挂在 BTC 上，SOL 挂在 ETH 上，traditional asset 只通过 BTC–SPX 这一条 edge 接进来，Gold 在最外面。“判断两个 node 是否已在同一 component”用 union-find 实现，下面合并 address 时还会用到同一个结构。

:::wrong MST 里 BTC 和 SOL 之间没有 edge，所以它们的 correlation 低
BTC–SOL 的 $\rho=0.75$，是整个 matrix 里第三高的。它被跳过，是因为 BTC 到 SOL 已经有一条 path BTC–ETH–SOL，path 上最长的一段 0.632 比直连的 0.707 还短。

MST 保留的是这样一种信息：任意两个 node 之间 tree 上的那条 path，其最长的一段，是所有可能的 path 里最短的。BTC 和 SOL 的关系在 tree 里被表示成“经过 ETH”，直接的 0.75 被丢掉了。15 个数压成 5 个数，丢掉信息是必然的；读 MST 时只能说“相邻的很近”，不能说“不相邻的就远”。
:::

### Crash 时 tree 收缩

Correlation 不是常数。上面那篇研究从 coinmarketcap 等网站取 daily price，留下 2017 年 10 月 15 日到 2022 年 10 月 15 日一直在交易、缺失不超过 10 天的 157 个 coin，以 30 天为 window、每次往前移 1 天滚动计算 correlation 并建 MST。平均 distance $\langle d\rangle$ 平时在 1 到 2 之间大幅波动；在 2018 年 1 月的 BTC crash 和 2020 年 2 至 3 月 COVID 爆发时显著下降，也就是 correlation 一起升高。Stock 上早有同样的现象：Onnela 等人用 116 个 S&P 500 stock 的 tree，1987 年 crash 时 tree 的总长明显缩短。

::fig[dse4211-mst] 左边是上面那棵 tree。右边假设 tree 的形状不变，只把五条 edge 上的 correlation 换成 crash 时可能的量级（0.92、0.90、0.85、0.60、0.30，示意数值），每条 edge 都变短，总长从 4.46 缩到 3.47。

对投资组合的含义很直接：平时看起来分散在 tree 不同分支上的 asset，恰恰在最需要分散的时候挤到了一起。那篇研究据此在 tree 外围挑 coin。它给每个 coin 算 $L_i$，即 node $i$ 沿 tree 上的 path 到其他 $N-1$ 个 node 的平均距离，$L_i$ 越大越在外围、和别人越不相关；按 $L_i$ 从外到内取 $n$ 个 coin，只用过去 30 天的数据、用 Markowitz mean-variance 定权重，持有 1 到 14 天。$n=46$ 时最好，比较对象是随机取 46 个、市值最大的 5 个（BTC、ETH、LTC、USDT、XRP）和单持 BTC。它报告的 return 数字前后不一致（同一个 portfolio 1 天的 return，摘要写 1,066%，正文写超过 10,000%），本页不引用那些数字。

### Transaction network：从 address 到 entity

另一种 network 不是由 correlation 构造的，而是 blockchain 上本来就有的：node 是 address，edge 是一笔 transfer。Bitcoin 的 ledger 公开（[IS4302 第 4 站](../courses/IS4302.html#utxo)讲了 UTXO 结构），可是一个人可以有任意多个 address，直接在 address 上做 network 分析，看到的是碎片。

第一步是把属于同一个人的 address 合并成 entity。最常用的规则叫 common-input-ownership heuristic：一笔 transaction 的所有 input 都必须由各自的 private key 签名，所以一笔 transaction 的全部 input address 被认为属于同一个 entity。

::fig[dse4211-txnet] 四笔 transaction。Common-input 只能把同一笔里的 input 合并成小组；再把 a3、b2 认作找零，小组才连成 entity A（a1 到 a4）和 B（b1 到 b3）。

执行时就是 union-find：每笔 transaction 把它的 input address 两两 union。tx1 合并 {a1, a2}，tx2 合并 {a3, a4}，tx4 合并 {b2, b3}。a3 是 tx1 的 output，这一条规则本身不合并 output；再加一条 change address heuristic（认定某个 output 是付款人给自己的找零），把 a3 认作 tx1 的找零，{a3, a4} 就并进 {a1, a2}，得到 A。同样把 b2 认作 tx3 的找零，b1 和 {b2, b3} 合并成 B。合并之后，network 的 node 变成 entity，exchange、mining pool 这类 entity 会成为 degree 极高的 hub。

Meiklejohn 等人（2013）把这两条写成 Heuristic 1 和 Heuristic 2，并在当时整条 Bitcoin chain 上跑了一遍。Heuristic 1 他们说明前人已多次用过（包括 Reid 和 Harrigan），依据就是发起 transaction 的人必须持有每个 input 的 private key。用它，约 1,206 万个 public key 合并成约 558 万个 cluster。Change address 的判定本身是猜的，所以 Heuristic 2 只认一种很窄的情形：一个 output address 是第一次出现；这笔不是 coin generation；没有哪个 output 同时也是 input（付款人没有把找零发回自己原来的 address）；所有 output 里只有它一个是第一次出现。第一版 Heuristic 2 标出 400 多万个 change address，其中 13% 是错的，大多来自 Satoshi Dice 把赌金退回原 address；排除这种情形后降到 1%，再把判定推迟一段时间、看那个 address 之后的用法（推迟一天 0.28%，一周 0.17%）。加上 Heuristic 2 之后，cluster 数降到约 338 万个。他们特别提醒，哪怕错连几个 change address，整张图就会塌成一个 super-cluster：第一版里 Mt. Gox、Instawallet、BitPay 和 Silk Road 的 public key 被并在一起，约 160 万个。

Heuristic 1 也会出错。Greg Maxwell 提出的 CoinJoin 就是多个人刻意把各自的 input 放进同一笔 transaction，专门破坏这条规则。

:::back
Distance 的推导只用到 correlation 的定义。第 7 站的 liquidation cascade 和这里 crash 时 correlation 升高是同一类现象：平时独立的风险在 shock 时连在一起。
:::

## [perp] Perpetual futures 与 funding rate

:::skip
能说出 funding 在什么时候由谁付给谁、推出 perpetual 的 no-arbitrage price、算出 leveraged position 的 liquidation price，并能指出 cash-and-carry 在哪里有风险，就可以去第 5 站。
:::

### 有 expiry 的 futures 靠 expiry 钉住 spot

普通的 futures 约定在 expiry $T$ 按 $F$ 买入 underlying。到期那一刻 $F$ 必须等于 spot $S_T$，否则立刻有 arbitrage。到期之前，cash-and-carry 决定它的价格：借 $S$ 买入 spot，同时 short futures，到期交割，不承担任何价格风险，所以 $F=Se^{rT}$。$S=60{,}000$、$r=5\%$、3 个月：$F=60000\times e^{0.0125}=60{,}754.71$。

Crypto 交易量最大的 derivative 却没有 expiry，它叫 perpetual future（perp），可以永远持有。没有到期那一刻，什么东西阻止 $F$ 漂离 $S$？

### Funding：每 8 小时按偏离付一次钱

He、Manela、Ross 和 von Wachter 的论文这样定义：long 和 short 之间是一个 swap，开仓不付钱，任何时候可以平仓；持仓期间 long 持续付给 short $\kappa(F_s-S_s)\,ds$。$F>S$ 时 long 付 short，$F<S$ 时反过来 short 付 long。实际的交易所每 8 小时结算一次，一年 1095 次；论文取 $\kappa=1095$，于是 $F-S$ 维持在 $G$ 不变时，每次结算正好付 $G$。

这个 rule 怎样把 $F$ 拉回 $S$？$F>S$ 时持有 long 要不断付钱，持有 short 不断收钱，于是有人平掉 long、开 short，$F$ 被压低。

::fig[dse4211-funding] 64 小时里 9 次结算。前 5 次 perp 高于 index，long 付钱；之后低于 index，方向翻过来。右下角是 1 BTC 仓位每次付多少：premium 乘以当时的 index price。

把图里 9 次的数字加起来：$36.00+66.66+55.35+24.48+6.05-17.94-41.30-23.72+11.98=117.56$ USD，这是 1 BTC 的 long 在这 9 次结算里净付出的 funding。

Funding rate 习惯报“每 8 小时百分之几”，换成年化要乘 1095。0.01% 每 8 小时是 $0.01\%\times1095=10.95\%$ 每年；0.03% 是 32.85%。数字看着小，年化以后和 leveraged position 的 return 是同一量级。

### No-arbitrage price

Perp 和 futures 一样每天 mark-to-market：long 的 margin account 随 $F$ 的变化收到 $dF$，同时付出 funding。开仓不花钱，所以在 risk-neutral measure 下，long 每一小段时间的 expected 净收入必须为 0，否则开 long 或开 short 就是白赚：

$$E^Q[dF_t]=\kappa\,(F_t-S_t)\,dt$$

Spot 在 risk-neutral measure 下的 drift 是 $r-r'$：持有 spot 本身带来 $r'$ 的收益（比如把 BTC 借出去的 lending rate），价格变动只需补足剩下的 $r-r'$，总共赚到 risk-free rate $r$。猜 $F_t=cS_t$，左边是 $c(r-r')S_t\,dt$，右边是 $\kappa(c-1)S_t\,dt$：

$$c\,(r-r')=\kappa\,(c-1)\quad\Longrightarrow\quad c=\frac{\kappa}{\kappa-(r-r')},\qquad F=\frac{\kappa}{\kappa-(r-r')}\,S$$

这就是论文给出的 no-arbitrage price。Premium $p=F/S-1=\dfrac{r-r'}{\kappa-(r-r')}$。代入 $\kappa=1095$、$r-r'=5\%$：$p=0.05/1094.95=4.57\times10^{-5}$，$S=60{,}000$ 时 $F-S=2.74$ USD。Funding 每 8 小时结算一次，力量很强，理论上 perp 几乎贴着 spot。

论文的证明不用 risk-neutral measure，而是直接构造 strategy。记 $\lambda=\kappa/(\kappa-(r-r'))$。$F_0>\lambda S_0$ 时 short 1 个 perp、借钱买 $\lambda$ 个 spot；$F_0<\lambda S_0$ 时反过来。持仓期间收或付 funding、付利息、spot 自己带来 $r'$；$\lambda$ 的取法正好让 $F=\lambda S$ 时这些现金流互相抵消（他们由此得到 $\lambda=1+(r-r')\lambda/\kappa$，和上面 $c(r-r')=\kappa(c-1)$ 是同一个式子）。然后等 $F$ 回到 $\lambda S$ 的那一刻平仓。Perp 没有到期日，这个时刻是随机的，所以论文叫它 random-maturity arbitrage，并假设偏离 $|F_t-\lambda S_t|$ 有上界（Assumption 2），保证这一刻在有限时间内到来。

有 trading cost 时，开平仓的 round-trip 成本是 price 的 $C$，偏离不超过 $C$ 就不值得做，于是 price 只被钉在一个 band 里（论文的 Proposition 2）：

$$\left|F_t-\frac{\kappa}{\kappa-(r-r')}\,S_t\right|\le C$$

### 实测的偏离有多大

实证部分用 Binance 上 BTC、ETH、BNB、DOGE、ADA 的 hourly price（2020 年起到 2024 年 3 月），risk-free rate 取 Aave 上 USDT、USDC、DAI 的平均 rate。偏离被换算成一个年化的数：记 $f=\ln F$、$s=\ln S$，

$$\rho=\kappa\left(1-e^{-(f-s)}\right)-(r-r')\approx\kappa(f-s)-(r-r')$$

它的意思是“要多大的 $r-r'$ 才能让观察到的 $F/S$ 成为 no-arbitrage price”。$\kappa=1095$ 把很小的 price 差放大：$f-s$ 比 benchmark 多 0.01%，$\rho$ 就多 10.95%。

| | BTC | ETH | BNB | DOGE | ADA |
|---|---|---|---|---|---|
| $\rho$ 的 mean | −0.06 | 0.04 | −0.10 | 0.01 | 0.03 |
| $\lvert\rho\rvert$ 的 mean | 0.57 | 0.63 | 0.88 | 0.86 | 0.83 |

带符号的 mean 都不显著（Newey–West 的 p-value 在 0.31 到 0.85），benchmark 平均来说是对的；绝对值的 mean 在 57% 到 88%，论文的说法是“每年 60% 到 90%”。BTC 的 0.57 换回 price 是 $0.57/1095=0.052\%$，$S=60{,}000$ 时约 31 USD。比 benchmark 的 2.74 USD 大十倍，但只是 price 的万分之五。

这个万分之五要和 trading cost 比。论文按 Binance 的 VIP 档位设了几档 fee，最低一档 spot 0.0225%、perp 0.0018%。两条腿开仓、平仓各付一次，$C=2\times(0.0225\%+0.0018\%)=0.0486\%$，换成 $\rho$ 是 $1095\times\ln(1.000486)=53.2\%$，和论文 Table 3 的数一致；最高一档 fee 的 band 是 179%。BTC 的平均偏离 57% 只比最低一档的 band 宽一点。“年化 60% 到 90%”听起来大，相当一部分落在 arbitrageur 的 cost band 之内。

偏离超出 band 时开仓、回到 0 时平仓，这个 strategy 在 BTC 上的年化 Sharpe ratio 是：不计 fee 3.53，最低一档 fee 2.20，最高一档 1.80（引言里的说法是 retail 的 cost 下 1.8、不付 fee 的 market maker 3.5）。偏离平均每年缩小约 11%，整个样本累计超过 44%，作者联系到 arbitrage 资本和竞争的增加。偏离在各个 coin 之间同涨同跌。对过去 120 天的 return 做 pooled regression，coefficient 显著为正：过去涨得多，perp 相对 spot 更贵，作者认为这是 positive feedback（momentum）trading 的迹象。引言说这个 regression 的 $R^2$ 超过 50%，同一稿 Table 9 里的 $R^2$ 是 0.26（加上 volatility 是 0.33），两处对不上，这里以表为准。Volatility 不显著，作者据此认为 arbitrageur 的融资约束不是主因，limits to arbitrage 主要来自 trading friction。

:::note 交易所实际用的 formula
Binance 的文档把每 8 小时的 funding rate 写成 premium index 加一个 interest 项再 clamp：$\text{funding}=P+\text{clamp}(I-P,\,-0.05\%,\,0.05\%)$。$I$ 多数合约固定为每 8 小时 0.01%（每天 0.03%）。$P$ 由 impact bid/ask price 和 index price 的差算出，每 5 秒算一次，8 小时内按时间加权平均。Clamp 的效果是：$P$ 在 $-0.04\%$ 到 $0.06\%$ 之间时，$I-P$ 落在 $\pm0.05\%$ 内，funding 正好等于 $I=0.01\%$。文档的例子：$P=0.0429\%$，$\text{clamp}(0.01\%-0.0429\%)=-0.0329\%$，funding $=0.0100\%$。所以平静时 funding 停在 0.01%，年化 10.95%，扮演的就是上面推导里 $r-r'$ 的角色。实际付的钱是 mark price 乘仓位大小乘 funding rate，只有在结算时刻（UTC 0、8、16 点）持仓的人才付或收。触及上下限的合约会改成每小时结算，参数也会调整，以交易所当时的文档为准。
:::

### Leverage 与 liquidation price

Perp 的另一个用途是 leverage。开 1 BTC 的 long，entry $P_0=60{,}000$，10x leverage 意味着只放 initial margin $P_0/10=6{,}000$。设 maintenance margin rate 是 0.5%，equity 跌到 position 价值的 0.5% 时被强制平仓。（Binance 的 maintenance margin 是 notional 乘 maintenance margin rate 再减一个 maintenance amount，rate 按 position 大小分档，position 越大 rate 越高；这里取一个固定的 0.5% 作示例。）Price 为 $P$ 时，equity 是 margin 加上浮动盈亏：

$$\text{equity}=\frac{P_0}{L}+(P-P_0)$$

令它等于 maintenance margin $0.005\,P$：

$$\frac{P_0}{L}+P-P_0=0.005\,P\quad\Longrightarrow\quad P_{\text{liq}}=P_0\,\frac{1-1/L}{1-0.005}=60000\times\frac{0.9}{0.995}=54{,}271.36$$

::fig[dse4211-perpliq] 6,000 USD 的 margin 能吸收的下跌只到 54,271。到那里 equity 剩 271 USD，等于 maintenance margin。

跌 9.55% 就被平仓。用第 2 站的方法估计 probability：daily σ 取 4%，normal 下单日跌超 9.55% 的 probability 是 0.84%；standardized $t_4$ 下是 1.39%。按每天 1.39% 算，30 天里至少有一天跌超 9.55% 的 probability 是 $1-(1-0.0139)^{30}=34.3\%$，这还没算几天连续下跌累积到 9.55% 的情形。

:::wrong Cash-and-carry 收 funding，价格风险两边抵消，所以没有风险
价格风险在两边账户的**总和**上抵消了，在每一边上没有。Spot 放在一个地方，short perp 是交易所里一个有 margin 的 position。设 short perp 用 3x leverage，maintenance margin 0.5%，按上面同样的推导，short 的 liquidation price 是

$$P_0\,\frac{1+1/3}{1+0.005}=79{,}601.99$$

BTC 涨 32.7%，short 那条腿被强制平仓，spot 那条腿涨出来的钱帮不上忙，因为它不在这个 margin account 里。此后只剩一个没有对冲的 long spot。另外 funding 的方向会翻：上面的图里，第 6 到第 8 次结算是 short 付给 long。

## [options] Crypto options 与 implied volatility

:::skip
能用 Newton method 由一个 option price 反解 implied volatility（包括 starting point 不好时会发生什么），并能说明 jump 怎样让 implied volatility 随 strike 变化，就可以去第 6 站。
:::

### 从 price 反推 σ

Black–Scholes formula（$r=0$，crypto 市场惯例按 365 天计 $T$）：

$$C=S\,N(d_1)-K\,N(d_2),\qquad d_1=\frac{\ln(S/K)+\tfrac12\sigma^2T}{\sigma\sqrt T},\quad d_2=d_1-\sigma\sqrt T$$

$S,K,T$ 都是已知的，只有 $\sigma$ 不知道。Option 市场的做法是反过来：看到 market price，问“多大的 $\sigma$ 能让 formula 给出这个价格”。这个 $\sigma$ 叫 implied volatility（IV）。它把不同 strike、不同 expiry 的价格换到同一把尺子上比较。

例子：BTC 的 spot $S=60{,}000$，30 天后到期、strike $K=65{,}000$ 的 call，market price 2,000 USD。求 IV，就是解 $C(\sigma)-2000=0$。$C(\sigma)$ 是 $\sigma$ 的 increasing function，所以解唯一，但没有 closed form，要用 [DSA2102](../courses/DSA2102.html) 里的 root-finding。

### Newton method

Newton 的一步是 $\sigma_{k+1}=\sigma_k-\dfrac{C(\sigma_k)-C_{\text{mkt}}}{C'(\sigma_k)}$。$C$ 对 $\sigma$ 的 derivative 叫 vega，可以从 formula 直接求出：

$$\frac{\partial C}{\partial\sigma}=S\,\varphi(d_1)\sqrt T$$

$\varphi$ 是 standard normal 的 density。推导：对 $C$ 求导，

$$\frac{\partial C}{\partial\sigma}=S\varphi(d_1)\frac{\partial d_1}{\partial\sigma}-K\varphi(d_2)\frac{\partial d_2}{\partial\sigma},\qquad\frac{\partial d_2}{\partial\sigma}=\frac{\partial d_1}{\partial\sigma}-\sqrt T$$

又 $\varphi(d_2)=\varphi(d_1-\sigma\sqrt T)=\varphi(d_1)\,e^{d_1\sigma\sqrt T-\sigma^2T/2}$，而 $d_1\sigma\sqrt T=\ln(S/K)+\tfrac12\sigma^2T$，所以 $\varphi(d_2)=\varphi(d_1)\,S/K$，即 $K\varphi(d_2)=S\varphi(d_1)$。代回去，两项里含 $\partial d_1/\partial\sigma$ 的部分抵消，只剩 $K\varphi(d_2)\sqrt T=S\varphi(d_1)\sqrt T$。Vega 处处为正，$C$ 是 $\sigma$ 的 continuous、increasing function，所以 market price 落在 no-arbitrage 的范围内时（$r=0$ 时是 $\max(S-K,0)<C<S$），IV 存在且唯一。

从 $\sigma_0=20\%$ 出发：

| $k$ | $\sigma_k$ | $C(\sigma_k)$ | vega | $\sigma_{k+1}$ |
|---|---|---|---|---|
| 0 | 20.000% | 132.43 | 2694.7 | $0.2-\dfrac{132.43-2000}{2694.7}=89.305\%$ |
| 1 | 89.305% | 4173.13 | 6746.4 | $0.89305-\dfrac{2173.13}{6746.4}=57.093\%$ |
| 2 | 57.093% | 2053.24 | 6316.5 | $0.57093-\dfrac{53.24}{6316.5}=56.250\%$ |
| 3 | 56.250% | 2000.09 | 6294.3 | 56.249% |

::fig[dse4211-newton] 黑线是 $C(\sigma)$，虚线是 market price。每一步从 curve 上的点沿 tangent 走到虚线，再竖直回到 curve。第一步冲过了头。

验算最后的 $\sigma=56.249\%$：$\sigma\sqrt T=0.56249\times\sqrt{30/365}=0.16126$，$d_1=\dfrac{\ln(60/65)+\tfrac12\times0.16126^2}{0.16126}=\dfrac{-0.08004+0.01300}{0.16126}=-0.4157$，$d_2=-0.5770$，$N(d_1)=0.3388$，$N(d_2)=0.2820$，$C=60000\times0.3388-65000\times0.2820=2000$（末位的差来自 $N$ 只保留了四位）。

### 为什么第一步冲过头，以及从哪里起步

$\sigma_0=20\%$ 时这个 call 是 deep out-of-the-money 的，$C$ 和 vega 都很小，tangent 很平，沿着它走到 2000 要走很远。落点在哪一侧，由 $C(\sigma)$ 的 convexity 决定。对 vega 再求一次 derivative：由 $d_1=\dfrac{\ln(S/K)}{\sigma\sqrt T}+\tfrac12\sigma\sqrt T$，

$$\frac{\partial d_1}{\partial\sigma}=-\frac{\ln(S/K)}{\sigma^2\sqrt T}+\frac{\sqrt T}2=-\frac{d_1-\sigma\sqrt T}{\sigma}=-\frac{d_2}{\sigma}$$

再用 $\varphi'(x)=-x\varphi(x)$：

$$\frac{\partial^2C}{\partial\sigma^2}=S\sqrt T\,\varphi'(d_1)\,\frac{\partial d_1}{\partial\sigma}=S\sqrt T\,\varphi(d_1)\,\frac{d_1d_2}{\sigma}=\text{vega}\cdot\frac{d_1d_2}{\sigma}$$

符号由 $d_1d_2$ 决定。记 $a=\ln(S/K)/(\sigma\sqrt T)$，$d_1=a+\tfrac12\sigma\sqrt T$，$d_2=a-\tfrac12\sigma\sqrt T$，

$$d_1d_2=\frac{\ln^2(S/K)}{\sigma^2T}-\frac{\sigma^2T}{4}$$

它随 $\sigma$ 递减，在 $\sigma^4T^2=4\ln^2(S/K)$ 处变号。所以 $C(\sigma)$ 只有一个 inflection point

$$\hat\sigma=\sqrt{\frac{2\,|\ln(S/K)|}{T}}$$

左边 convex，右边 concave。这个例子里 $\hat\sigma=\sqrt{2\times0.08004/0.08219}=139.56\%$，root 56.25% 在 convex 的一段。从 20% 出发，起点在 root 左边，convex 的 curve 在 tangent 上方，tangent 碰到 2000 时 curve 已经高过 2000，落点必然越过 root，这就是第一步的 89.3%。

这里冲过头以后还能收回来，换成更极端的 strike 就不行了。$K=90{,}000$、真实 IV 60% 的 call 价格是 38.98；从 20% 出发，第一步跳到 $\sigma\approx3.35\times10^8$，那里 vega 是 0，迭代无法继续。

Regina STAT 441 讲 Higham 教材这一章时给的办法是从 $\hat\sigma$ 起步。Root 在 $\hat\sigma$ 左边时，root 到 $\hat\sigma$ 整段是 convex 的，起点在 root 右边，curve 在 tangent 上方，每一步都落在 root 和当前点之间，单调地往下收；root 在 $\hat\sigma$ 右边时，那一段是 concave 的，对称地单调往上收。这个例子从 139.56% 出发：

| $k$ | $\sigma_k$ | $C(\sigma_k)$ | vega |
|---|---|---|---|
| 0 | 139.560% | 7604.97 | 6862.4 |
| 1 | 57.884% | 2103.23 | 6336.4 |
| 2 | 56.254% | 2000.34 | 6294.4 |
| 3 | 56.249% | 2000.00 | 6294.3 |

每一步都在 root 右边，没有冲过头。实用的写法再加一个 bracket：先确定 root 所在的 interval，Newton 的落点跑出 interval 就改用 bisection。

:::note Deribit 的 option 用 BTC 计价
Crypto option 最大的交易所 Deribit 的 BTC option 是 European、inverse 的：premium 用 BTC 报，到期用 BTC cash settle。到期时先算 USD 的差额 $\max(S_T-K,0)$，再除以 settlement price 换成 BTC，所以按 BTC 计的 payoff 是 $\max(S_T-K,0)/S_T$。文档的例子：strike 100,000，到期 index 125,000，call 付 $25000/125000=0.2$ BTC。按 USD 算它就是普通 call 的 payoff，所以上面那个 call 在 Deribit 上报 $2000/60000=0.0333$ BTC，反解 IV 前先乘回 index price。Deribit 还编了一个类似 VIX 的指数 DVOL：用各 expiry 的 implied volatility smile、按 variance swap 的方法，算出未来 30 天的年化 expected volatility。换成 daily 用第 1 站的 $\sqrt{365}$：DVOL 80 对应每天 $80\%/\sqrt{365}=4.19\%$（文档给的粗算是除以 20）。
:::

### 同一个 underlying，不同 strike 有不同的 IV

如果 BTC 真的服从 Black–Scholes 的 geometric Brownian motion，所有 strike 反解出来的 IV 应该都一样。实际市场上不一样，这条 IV 对 strike 的 curve 叫 volatility smile（向一边倾斜时叫 skew）。

它从哪里来？第 1 站说过真实 return 有 heavy tail，而 Black–Scholes 假设 normal。做一个实验：用带 jump 的 model（Merton jump-diffusion）生成 option price，再用 Black–Scholes 反解 IV。18.S096 的讲义把这种 model 叫 Poisson jump diffusion：在 geometric Brownian motion 上叠加一个 rate 为 $\lambda$ 的 Poisson process，每次 jump 时 price 乘上一个 random factor $Y$。参数：diffusion 部分的 σ 是 50%；jump 平均每年 $\lambda=6$ 次，每次的 $\ln Y$ 服从 $N(-0.08,\,0.10^2)$，也就是偏向下跌的 crash。

价格用 Merton（1976）对 log-normal jump 给出的公式算。条件在“到期前恰好 jump $n$ 次”上，$\ln S_T$ 仍是 normal，只是 variance 和 drift 变了，所以每一项都是一个 Black–Scholes 价格，再按 Poisson probability 加权：

$$C=\sum_{n\ge0}e^{-\lambda'T}\frac{(\lambda'T)^n}{n!}\,C_{\text{BS}}(\sigma_n,r_n),\qquad\lambda'=\lambda(1+k),\quad\sigma_n^2=\sigma^2+\frac{n\delta^2}{T},\quad r_n=r-\lambda k+\frac{n\ln(1+k)}{T}$$

$k=E[Y-1]=e^{-0.08+0.10^2/2}-1=-0.0723$，$\delta=0.10$ 是 $\ln Y$ 的 standard deviation，$r=0$，$C_{\text{BS}}(\sigma_n,r_n)$ 是 volatility 为 $\sigma_n$、interest rate 为 $r_n$ 的 Black–Scholes call 价格。求和取到 $n=39$。

::fig[dse4211-smile] 每个点是一个 strike 上反解出的 IV。低 strike（深度 out-of-the-money 的 put 对应的区域）的 IV 最高，向右单调下降。

Jump 让 return 的 distribution 有更粗的左 tail，深度 out-of-the-money 的低 strike option 最依赖这条 tail，它的价格比 Black–Scholes 用一个 σ 能给出的更贵，反解出的 IV 就更高。Merton 当年就指出了这个方向：jump 的影响大时，Black–Scholes 会低估 deep out-of-the-money option，因为连续的 path 在到期前几乎走不到那么远的 strike，一次 jump 却可以。

这个实验有一处不合实际。Merton 的公式假设 jump risk 可以 diversify 掉（他设想的 jump 来自个别公司的消息），所以 jump 不带 risk premium；BTC 的 crash 是整个市场一起跌，这个假设说不过去。上面的实验只用来看 smile 的形状。Haugh 的讲义列的解释除了 jump（向下的 jump 比向上的更大、更频繁），还有两条：market 下跌时 volatility 上升（第 1 站的 leverage effect），以及买 out-of-the-money put 做保护的需求让低 strike 更贵。

:::wrong 同一个 underlying、同一个 expiry 只有一个 volatility，所以 IV 应该处处相等，不相等就是 mispricing
上图的价格全部来自同一个、内部完全一致的 model，没有任何 mispricing，IV 却从 strike 42,000 的 65.1% 降到 78,000 的 55.3%。这个 model 下 return 的总 volatility 是 $\sqrt{0.5^2+6\times(0.08^2+0.10^2)}=59.0\%$，没有一个 strike 的 IV 恰好等于它。

IV 是“把这个价格塞进 Black–Scholes 需要的 σ”，它随 strike 变化，说明的是 Black–Scholes 的 normal 假设和真实 distribution 之间的差距在不同 strike 上大小不同。
:::

## [amm] Market microstructure、AMM 与 LVR

:::skip
能在 constant product curve 上算出一次 arbitrage 后 pool 的新状态和 arbitrageur 的利润，能用 LVR formula 估计 LP 每天的成本并和 fee income 比较，就可以去第 7 站。
:::

### Order book 与 AMM 的价格从哪里来

Centralized exchange（CEX）用 order book：buyer 挂 bid，seller 挂 ask，最好的 bid 和 ask 之间的差叫 bid-ask spread，每个价位挂着多少数量叫 depth。一笔大单会吃掉好几档，成交均价比最好的 ask 差，这个差就是 price impact。

Market maker 为什么要留一个 spread？Glosten–Milgrom model 给的答案是 adverse selection。设 ETH 的真实价值 $v$ 以各一半的 probability 是 3100 或 2900。来下单的人里 20% 是 informed trader，知道 $v$，$v=3100$ 就买，$v=2900$ 就卖；其余 80% 是 liquidity trader，买卖各一半，与 $v$ 无关。Market maker 不知道来的是谁，只能按“这一笔是 buy”这个信息定价：$a=E[v\mid\text{buy}]$，$b=E[v\mid\text{sell}]$。

$$P(\text{buy}\mid v=3100)=0.2+0.8\times0.5=0.6,\qquad P(\text{buy}\mid v=2900)=0.8\times0.5=0.4$$

两种 $v$ 的 prior 相等，所以 $P(v=3100\mid\text{buy})=0.6/(0.6+0.4)=0.6$，$a=0.6\times3100+0.4\times2900=3020$；同理 $b=2980$。

Spread 40 不是 market maker 的利润。一笔 buy 来自 informed trader 的 probability 是 $0.2\times0.5/0.5=0.2$，这时 $v=3100$，他按 3020 卖出亏 80；来自 liquidity trader 时 $v$ 的 expectation 是 3000，平均赚 20。合起来 $0.2\times(-80)+0.8\times20=0$。Spread 是 liquidity trader 替 informed trader 付的钱：informed 的人越多，spread 越宽，informed 的比例到 100% 时没人愿意做 market，交易停止。

AMM 用一条 curve 代替 order book。[IS4302 第 6 站](../courses/IS4302.html#defi)用过一个 pool：100 ETH 和 300,000 USDC，constant product $xy=k=3\times10^7$，marginal price $y/x=3000$。从 curve 可以直接读出它“挂”在每个价位上的数量：price 为 $P$ 时 pool 里的 ETH 是

$$x(P)=\sqrt{k/P},\qquad y(P)=\sqrt{kP}$$

（由 $xy=k$ 和 $y/x=P$ 两式解出。）Price 从 3000 推到 3300，pool 要卖出 $x(3000)-x(3300)=100-95.3463=4.6537$ ETH，这就是 AMM 在 3000 到 3300 之间的 depth。

AMM 自己不看外面的价格，价格由 arbitrage 跟上外面（IS4302 那一站算过一次 arbitrage）。问题是，跟上的过程中谁赚、谁亏，亏多少，能不能事先算出来。

### 一来一回：impermanent loss 是 0，钱还是少了

外面的 ETH price 从 3000 涨到 3300，然后跌回 3000。先不算 fee。

**涨到 3300。** Arbitrageur 从 pool 买 ETH，直到 pool 的 marginal price 也是 3300。新状态 $x=\sqrt{3\times10^7/3300}=95.3463$，$y=\sqrt{3\times10^7\times3300}=314{,}642.65$。他买走 4.6537 ETH，付 $314642.65-300000=14{,}642.65$ USDC，均价 3146.43，拿到外面按 3300 卖得 $4.6537\times3300=15{,}357.34$，赚 714.69。

**跌回 3000。** 反过来，arbitrageur 在外面按 3000 买 4.6537 ETH（花 13,961.22），卖给 pool，pool 回到 100 ETH 和 300,000 USDC，他拿回 14,642.65，又赚 681.43。

::fig[dse4211-lvr] Pool 的状态是 curve 上的一个点，虚线是那一点的 tangent，slope 就是 pool 的 marginal price。外面 price 变了，arbitrageur 把点推到 tangent slope 等于新 price 的位置。

Pool 回到了原点，impermanent loss 按定义（和“一直拿着初始的 100 ETH、300,000 USDC”比）是 0。可是 arbitrageur 两次共拿走 1,396.12。这笔钱谁付的？

### Loss-versus-rebalancing

Milionis、Moallemi、Roughgarden 和 Zhang 给的比较对象是一个 rebalancing strategy：它在每个时刻持有和 pool 一样多的 ETH，但调仓按外面的 market price 做。两者的 market exposure 完全一样，差别只在成交价。

用上面的例子算这个 strategy。开始持有 100 ETH 和 300,000 USDC，价值 600,000。

- 涨到 3300：价值 $100\times3300+300000=630{,}000$。按 3300 卖掉 4.6537 ETH，持有 95.3463 ETH 和 $630000-95.3463\times3300=315{,}357.34$ USDC。
- 跌回 3000：价值 $95.3463\times3000+315357.34=601{,}396.12$。按 3000 买回 4.6537 ETH，回到 100 ETH。

它最后是 601,396.12，pool 是 600,000，差 1,396.12，正好是 arbitrageur 的利润。Pool 每次调仓都按 curve 上的平均价成交（涨时以 3146.43 卖出 ETH，比 3300 便宜；跌时以 3146.43 买回 ETH，比 3000 贵），差价落进 arbitrageur 的口袋。这个差叫 loss-versus-rebalancing（LVR），论文的定义就是 $\text{LVR}_t=R_t-V_t$：rebalancing strategy 的价值减 pool 的价值。

这正是上一小节 Glosten–Milgrom 的结构。LP 是 market maker；arbitrageur 是 informed trader，他知道 CEX 上的 price，只在 pool 的 price 落后时来成交；LVR 是 LP 被 informed trader 拿走的那部分。Fee 相当于 spread，要靠不看 CEX、为了换币来 swap 的人付。论文把 delta-hedge 之后 LP 的 P&L 写成 fee 减 LVR，就是这个意思。

Impermanent loss 在论文里叫 loss-versus-holding（LVH），比较对象是一直拿着初始的 100 ETH 和 300,000 USDC。LVH 只看起点和终点的 price，与中间的路径无关，所以一来一回之后是 0；LVR 依赖整条路径，一来一回之后是 1,396.12。论文证明两者在 risk-neutral measure 下的 expectation 相等，但 LVH 混着 ETH 涨跌的 market risk（任何持有 ETH 的人都有），noise 大得多；LVR 把 market risk 去掉，只量成交价比市场差的那部分。论文的 empirical 部分给出：delta-hedge 之后 LP 的 P&L 的 standard deviation 只有不 hedge 时的约 1% 到 6%（hedge 越频繁越小），LP 收益的波动绝大部分来自 market exposure。

### 每天亏多少：$\sigma^2V/8$

一次小的价格变动 $\Delta P$。Pool 卖出 $\Delta x\approx-x'(P)\,\Delta P$ 的 ETH，成交均价大约是起点和终点 marginal price 的中点 $P+\tfrac12\Delta P$；rebalancing strategy 按终点 $P+\Delta P$ 成交。两者的差是

$$\left(P+\Delta P-P-\tfrac12\Delta P\right)\cdot|x'(P)|\,\Delta P=\tfrac12\,|x'(P)|\,(\Delta P)^2$$

涨跌都是正的，所以会累积。Price 的 volatility 是 $\sigma$ 时，$E[(\Delta P)^2]\approx\sigma^2P^2\Delta t$，单位时间的 expected LVR 是

$$\ell=\tfrac12\,\sigma^2P^2\,|x'(P)|$$

这就是论文的 Theorem 1：$\text{LVR}_t=\int_0^t\ell(\sigma_s,P_s)\,ds$，$\ell(\sigma,P)=\tfrac12\sigma^2P^2\,|x^{*\prime}(P)|$，$x^*(P)$ 是 pool 在 price $P$ 时持有的 ETH（论文叫 demand curve）。论文给的直观推导也是这样：pool 沿 secant 成交，rebalancing 沿 tangent 成交，差 $\tfrac12\,dx\,dP$，再用 $(dP)^2=\sigma^2P^2\,dt$。LVR 只取决于 price 的 variance 和 curve 在当前 price 的 slope（marginal liquidity）。对 constant product，$x(P)=\sqrt kP^{-1/2}$，$|x'(P)|=\tfrac12\sqrt kP^{-3/2}$，pool 的价值 $V=xP+y=2\sqrt{kP}$：

$$\ell=\tfrac12\,\sigma^2P^2\cdot\tfrac12\sqrt k\,P^{-3/2}=\tfrac14\,\sigma^2\sqrt{kP}=\frac{\sigma^2}{8}\,V$$

论文的 Example 3 得到同一个结果 $\ell/V=\sigma^2/8$，并举了 daily σ 为 5% 的例子：每天损失 pool 价值的 3.125 bp。代这一页的数字：ETH 的 daily σ 取 4%，$V=600{,}000$，每天 $\ell=0.04^2/8\times600000=120$ USDC。用 1,440 步（每分钟一次 arbitrage）、400 条 path 模拟一天，平均 LVR 是 120.06，和 formula 吻合。

能不能用 fee 补回来？Fee 0.3%，每天需要的 volume 是 $120/0.003=40{,}000$ USDC，即 pool 价值的 6.7%。Volume 不到这个数，LP 扣掉 hedge 以后就是亏的。论文在 Uniswap v2 的 WETH-USDC pool 上（2021 年 8 月到 2022 年 7 月，平均价值 2.09 亿美元，price 取 Binance 的分钟数据）实际算了一遍，年化的数字是：

| | mean return | standard deviation |
|---|---|---|
| 不 hedge 的 LP | −6.20% | 42.08% |
| 每天 hedge 一次 | 5.04% | 2.87% |
| 每分钟 hedge 一次 | 9.04% | 0.39% |
| 按 formula 算的 fee − LVR | 8.16% | 0.48% |

这一年这个 pool 的 fee 超过了 LVR，hedge 之后的 LP 是赚的；不 hedge 的亏损来自 ETH 本身的下跌。Formula 算的 fee − LVR 和每分钟 hedge 的实际结果只差不到一个百分点。论文建议 protocol 设计者用 LVR 来定 fee，例如在一个回看的 window 里比较 LVR 和 fee income。

:::wrong Impermanent loss 在 price 回到原位时消失，所以只要等得够久，LP 就没有损失
上面的一来一回，impermanent loss 确实回到 0，但 arbitrageur 拿走的 1,396.12 不会回来，它已经是别人的了。和 exposure 相同、按市价调仓的 strategy 相比，LP 落后 1,396.12。Price 每来回一次，这笔差距就再累积一次，expected value 按 $\sigma^2V/8$ 的速度线性增长，与 price 最后停在哪里无关。“impermanent”只描述了 market risk 那一部分。
:::

:::edge Fee 让 pool 只在偏离够大时才被 arbitrage
有 0.3% 的 fee，外面 price 偏离 pool 不到 0.3% 时 arbitrage 不赚钱，pool 的 price 落后在一个 band 里，LVR 比无 fee 的 formula 小。论文的 formula 是无 fee、连续 arbitrage 的情形，arbitrageur 也要付 fee 的情形作者留作后续的工作。
:::

:::edge Concentrated liquidity 让每一块钱的 LVR 变大
Uniswap v3 允许 LP 只在一个 price 区间 $[P_a,P_b]$ 里提供 liquidity。论文的 Example 4 算出，区间内的 $\ell$ 和同样 $L$ 的 v2 pool 一样，是 $\tfrac14L\sigma^2\sqrt P$（$L=\sqrt k$），但 position 的价值只有

$$V=L\left(2\sqrt P-\frac{P}{\sqrt{P_b}}-\sqrt{P_a}\right)$$

取 $L=\sqrt{3\times10^7}=5477.23$、区间 [2700, 3300]、$P=3000$：$V=5477.23\times(109.545-52.223-51.962)=29{,}356$，只有 v2 pool 的 1/20.4。它持有的 4.6537 ETH 正是 v2 pool 从 3000 涨到 3300 要卖出的量。每天的 LVR 仍是 120 USDC，即 position 价值的 0.41%。区间收窄到 [2900, 3100]，$V=9{,}921$，每天 1.21%。区间越窄，这个比例越大，$P_a,P_b\to P$ 时趋于无穷。
:::

## [lend] DeFi lending、P2P lending 与 liquidation cascade

:::skip
能用 kinked curve 算 borrow rate 和 supply rate，能给有 default risk 的 loan 定价并说明 adverse selection 怎样破坏单一 rate，能一步步模拟 liquidation cascade，就可以去第 8 站。
:::

### Interest rate 由 utilization 决定

[IS4302 第 6 站](../courses/IS4302.html#defi)讲了 Aave 上一个 position 的 health 和 liquidation price。这里看 pool 本身：lender 把 USDC 存进 pool，borrower 从 pool 借。Borrow rate 是谁定的？

没有人定，它是 utilization 的 function。Utilization $U$ 是借出去的占存入的比例。Aave 的文档给的 model 是一条折线：

$$R(U)=\begin{cases}R_0+\dfrac{U}{U^*}\,R_1,&U<U^*\\[2mm]R_0+R_1+\dfrac{U-U^*}{1-U^*}\,R_2,&U\ge U^*\end{cases}$$

USDC 的 variable rate 参数是 $U^*=90\%$、$R_0=0$、$R_1=4\%$、$R_2=60\%$。

::fig[dse4211-kink] 左边是 rate curve，右边是 $U=80\%$ 时的 pool：存入 100，借出 80，留 20 给想取钱的 lender。

- $U=80\%$：$R=\dfrac{0.8}{0.9}\times4\%=3.56\%$。
- $U=95\%$：$R=4\%+\dfrac{0.95-0.9}{0.1}\times60\%=34\%$。

为什么折得这么急？Pool 里留着的那部分是 lender 随时取钱的来源。文档的解释是：liquidity risk 在 utilization 高时出现，$U$ 越接近 100% 越严重，lender 想取也取不出来；所以 capital 稀缺时用高 rate 鼓励 borrower 还钱、吸引新的 deposit，把 $U$ 推回去。参数表里 USDC 在 100% utilization 时的 rate 是 $4\%+60\%=64\%$，文档说的就是“full utilisation 时升到 50% APY 以上”。不同 asset 的 kink 位置不一样：ETH 的 $U^*$ 是 65%，$R_1=8\%$，$R_2=100\%$。

Lender 拿到多少？Borrower 付的 interest 按存入的每 100 USDC 算是 $80\times3.56\%=2.84$，protocol 留一部分作 reserve（reserve factor，这里设为 10%），剩下的分给 lender：

$$\text{supply rate}=\text{borrow rate}\times U\times(1-\text{reserve factor})=3.56\%\times0.8\times0.9=2.56\%$$

Supply rate 总低于 borrow rate，差在 $U$ 和 reserve factor 两个因子上。

### P2P lending：给 default risk 定价

DeFi lending 全部 over-collateralized，因为 address 背后是谁不知道（IS4302 讲了为什么）。课程描述里的 P2P lending 是另一条路：平台撮合个人之间的 loan，通常没有足额 collateral，lender 承担 default risk。

一笔 1 年期的 loan，risk-free rate 4%。Borrower default 的 probability $\text{PD}=5\%$，default 时能收回应得金额的 40%（recovery rate $R=40\%$）。Lender 要求的 rate $r$ 满足 expected payoff 等于 risk-free：

$$(1+r)\left[(1-\text{PD})+\text{PD}\cdot R\right]=1.04$$

$$1+r=\frac{1.04}{0.95+0.05\times0.4}=\frac{1.04}{0.97}=1.0722,\qquad r=7.22\%$$

Spread 3.22% 补偿的是 expected loss $\text{PD}\times(1-R)=3\%$（再乘上 $1+r$ 的那一点）。这只算了 expected value，没有给承担 risk 的补偿，是 risk-neutral 的定价。

### Adverse selection：rate 越高，来借的人越差

上面的定价假设 lender 知道 PD。平台分不清 borrower 时，能不能按平均 PD 定一个 rate、再把 rate 提高一点来补偿不确定性？Stiglitz 和 Weiss（1981）指出 interest rate 对 lender 有两个副作用。一是 adverse selection：rate 越高，愿意来借的人 risk 越大。二是 incentive effect：rate 高了，同一个 borrower 会换成更冒险的 project。下面只算第一个。

为什么 risky 的人更愿意付高 rate？关键在 limited liability。SW 的设定里，borrower 借 $B$ 做一个 project，return $R$ 是 random 的，还不上时只损失 collateral $C$，所以 borrower 的 profit 是（论文的式 4a）

$$\pi(R,r)=\max\bigl(R-(1+r)B,\,-C\bigr)$$

这个 function 在 $R$ 上是 convex 的：好结果全归 borrower，坏结果的损失被 $-C$ 截住。两个 project 的 mean 相同时，$R$ 越分散，borrower 的 $E[\pi]$ 越大，lender 收到的 $\min\bigl((1+r)B,\,R+C\bigr)$ 的 expectation 越小。

具体算。每人借 $B=100$，collateral $C=5$，lender 的 funding cost 是 4%（每借出 100 要收回 expected value 104）。两类 borrower 各占一半，PD 分别是 2% 和 12%，project 的 mean 都是 110：

| | 成功 | 失败 | mean |
|---|---|---|---|
| safe | 98% 得 112 | 2% 得 12 | 110 |
| risky | 88% 得 125 | 12% 得 0 | 110 |

记应还金额 $D=100(1+r)$。失败时 borrower 交出 project 剩下的和 collateral，lender 收到 $R+C$；borrower 的 expected profit 为负就不借。

- Safe：$E[\pi]=0.98(112-D)+0.02\times(-5)=109.66-0.98D$，$D>111.90$ 时为负。Lender 收到 $0.98D+0.02\times(12+5)=0.98D+0.34$。
- Risky：$E[\pi]=0.88(125-D)+0.12\times(-5)=109.4-0.88D$，要到 $D>124.32$ 才为负。Lender 收到 $0.88D+0.12\times5=0.88D+0.6$。

两类都来借时，lender 平均收到 $0.93D+0.47$。令它等于 104，$D=111.32$，$r=11.32\%$，这时两类都愿意借。

现在 lender 想多赚一点，把 $D$ 提到 111.90 以上。Safe 退出，只剩 risky，每笔的 expected value 从 $0.93\times111.90+0.47=104.54$ 掉到 $0.88\times111.90+0.6=99.07$。Rate 高了，收到的反而少了 5.47。

::fig[dse4211-sw] 横轴是 loan rate，曲线是 lender 每借出 100 收回的 expected value。到 11.90% 为止两类都借；再往上 safe 退出，曲线往下跳一截；过了 24.32% 谁都不借。

这就是 SW 的 Theorem 2 和 3：rate 越高，不来借的 riskiness 门槛越高；lender 的 expected return 随 borrower 的 riskiness 递减。合起来，expected return 不是 rate 的 increasing function，靠提高 rate 补偿 risk 会适得其反。SW 由此推出 credit rationing：lender 宁可停在 expected return 局部最高的 rate 上，拒绝一部分申请人，也不加价。图里也能看到这个推论需要的条件：rate 一路加到 24.32%、只借给 risky 的人，lender 收到 110.0，比 104.54 还高，这时 lender 宁可只做 risky 的生意，rationing 就不会出现。Rationing 是否出现取决于 expected return 的全局形状，Arnold（2005）在 SW 原模型的设定下证明 expected return 的全局最大值就在最高的 rate 处，据此质疑 rationing 能否出现。

不管 rationing 是否出现，结论是同一个：P2P 平台的核心在 credit scoring，也就是把两类人分开。分开以后，safe 由 $0.98D+0.34=104$ 得 $r=5.78\%$，risky 由 $0.88D+0.6=104$ 得 $r=17.50\%$，各付各的。Blockchain 能做的是让还款记录公开、可验证，做不了的是确认 address 背后是谁。

### Liquidation cascade

回到 over-collateralized 的 DeFi lending。它对单个 lender 很安全，可是所有 position 的 liquidation 都要把 collateral 卖进同一个市场。

设定：一个 ETH/USDC 的 constant product pool，2000 ETH 和 6,000,000 USDC，price 3000。8 个 borrower 各以 40 ETH 作 collateral，liquidation threshold 0.83（IS4302 用的 Aave ETH 参数），liquidation price 从 2880 起每隔 80 一个，到 2320。Liquidation price 为 $L$ 的 borrower 的 debt 是 $D=40\times L\times0.83$，例如 $L=2880$ 时 $D=95{,}616$。规则简化为：price 低于 $L$ 时，liquidator 还清全部 debt，拿走价值 $1.05D$ 的 ETH（5% 是 liquidation bonus），立刻卖进 pool。

先有人卖 45 ETH。Pool 变成 2045 ETH，$y=6\times10^6\times2000/2045=5{,}867{,}970.66$，price 2869.42，跌破 2880。

**第 1 轮。** $L=2880$ 的 borrower 被 liquidate，liquidator 拿走 $1.05\times95616/2869.42=34.99$ ETH 卖进 pool，price 变成 2773.70，跌破 2800。

**第 2 轮。** $L=2800$ 的被 liquidate，卖 35.19 ETH，price 2682.17，跌破 2720。

如此一轮带一轮：

| 轮次 | 被 liquidate 的 $L$ | 卖进 pool 的 ETH | 之后的 price |
|---|---|---|---|
| 起点 | | 45（外部卖单） | 2869.42 |
| 1 | 2880 | 34.99 | 2773.70 |
| 2 | 2800 | 35.19 | 2682.17 |
| 3 | 2720 | 35.35 | 2594.72 |
| 4 | 2640 | 35.47 | 2511.20 |
| 5 | 2560 | 35.54 | 2431.50 |
| 6 | 2480 | 35.56 | 2355.50 |
| 7 | 2400 | 35.52 | 2283.08 |
| 8 | 2320 | 35.42 | 2214.13 |

::fig[dse4211-cascade] 左边的格子是 8 个 position，按 liquidation price 排。彩线是 pool 的 price，每跌破一格，那一格被 liquidate（变实心），卖出的 ETH 又把 price 往下推一截。

每卖 35 ETH，price 掉 3% 多，而相邻两个 liquidation price 只差 80，不到 3%，所以每一次 liquidation 都恰好触发下一次。外部卖单换成 38 ETH，price 停在 2889.17，比 2880 高 9 块钱，一个 position 都不触发，price 只跌了 3.7%。38 和 45 之间是一个 threshold：越过它，结局从 −3.7% 跳到 −26.2%。

这个 model 夸大了 pool 的作用（真实的 liquidator 也在 CEX 上卖，pool 也更深），但结构是真的：liquidation 是“price 下跌时卖出”的规则，它把 price 的 shock 放大，放大的程度取决于 liquidation price 在 shock 附近有多密。

:::wrong Over-collateralized，所以 lender 没有风险
Threshold 0.83 意味着在 $L$ 处 collateral 价值是 debt 的 $1/0.83=1.20$ 倍，看起来有 20% 的缓冲。可是 liquidation 不是在 $L$ 处精确成交：price 可能一步跳过好几档（oracle 更新有延迟、network 拥堵时 liquidation transaction 进不去块），上面的 cascade 里每一轮都是如此。Liquidator 要拿到 $1.05D$ 才愿意动手，需要 $40P\ge1.05D=1.05\times0.83\times40L$，即 $P\ge0.8715L$；price 一次跳过 $L$ 以下 12.85%，就没有 liquidator 愿意出手。跳过 17%（$P<0.83L$），collateral 不够还 debt，差额成为 bad debt，由 lender 承担。
:::

## [stable] Stablecoin 的 peg、collateral 与 run

:::skip
能用 fee 和成本推出 peg 的 no-arbitrage band，能由 σ 和 liquidation 延迟估计 collateral ratio，能用 first-come-first-served 的 payoff 解释 run，就可以去第 9 站。
:::

三类 stablecoin（custodial、crypto-collateralized、algorithmic）的机制，以及 USDC 在 2023 年 3 月、UST 在 2022 年 5 月的经过，在 [IS4302 第 7 站](../courses/IS4302.html#stable)。这一站回答三个定量的问题：peg 允许偏离多少，collateral 要放多少，reserve 只差一点时为什么会发生 run。

### Peg 的 band

一个 custodial stablecoin 的 issuer 承诺：任何时候 1 USD mint 一个，一个 redeem 1 USD，redeem 收 0.1% 的 fee（USDT 的 redemption fee 就是 0.1%，见下文）。Market 上它的 price 是 0.995，会发生什么？

::fig[dse4211-peg] 上面是 arbitrage 的路线：在 market 买、向 issuer redeem。下面是 price 能停留的 band。

Arbitrageur 在 market 花 0.995 买 1 个，向 issuer redeem 得 $1-0.001=0.999$，每个赚 0.004。再设其他成本（gas、银行转账、资金被占用的时间）合计 0.1%，净赚 0.003，仍然值得做。持续的买入把 market price 推高，直到利润为 0：price 到 $1-0.001-0.001=0.998$。上方同理，mint 也有成本时 price 不会超过 1.002。所以 peg 不是一个点，是 [0.998, 1.002] 这个 band，宽度由 fee 和成本决定。

据此定义 depeg：price 离开 band。用数据研究一次 depeg，要量的是三样：最大偏离（离 1 最远到多少）、持续时间（在 band 外多久）、恢复路径（是否回到 band 内）。

Band 只在 redemption 真的可用时存在，而实际上大多数 holder 用不了。Ma、Zeng 和 Zhang 整理了两大 stablecoin 的规则和数据：一般 holder 只能像买卖 ETF 份额一样在 secondary market（exchange）上交易，能直接向 issuer mint 和 redeem 的只有通过审核的 arbitrageur。USDT 要经过很长的 due diligence，平均每个月只有 6 个 arbitrageur 在 redeem，最大的一个占 66%；USDC 允许一般企业注册，平均每月 521 个，最大的占 45%。USDT 的 redemption 最低 100,000 USD，fee 是 0.1% 和 1,000 USD 取较大者：redeem 100,000 USD 付 1,000，即 1%，要 redeem 到 1,000,000 USD 以上 fee 才降到 0.1%。

Arbitrage 越集中、门槛越高，band 越宽，price 在 band 里待的位置也越随意。实测的 discount：USDT 平均 54 bp、median 11 bp；USDC 平均 1 bp、median 不到 1 bp。Redemption 在周末暂停（bank 不处理 wire）时，arbitrage 暂时断掉，band 也随之消失。

### Collateral 放多少

Crypto-collateralized 的 stablecoin（如 DAI 的原始设计）用 ETH 作 collateral，IS4302 那一站引用的比例是 150%。150% 是怎么来的？

问题可以这样提：collateral 价值 $V$，发行的 stablecoin（debt）是 $D$，collateral ratio $\rho=V/D$。从 price 跌破 liquidation 线到 liquidation 完成，需要 $\Delta$ 天。要求在这段时间里 $V$ 跌到 $D$ 以下的 probability 不超过 $\epsilon$。

$\Delta$ 天的 log return 是 $\sigma\sqrt\Delta\cdot Z$，$Z$ 的 $\epsilon$ quantile 是 $-q$。要求 $V e^{-q\sigma\sqrt\Delta}\ge D$，即

$$\rho\ge e^{\,q\,\sigma\sqrt\Delta}$$

代入第 1、2 站的数字（daily σ 4%，shock 之后 5.79%）：

| 假设 | $q$ | σ | $\Delta$ | 需要的 $\rho$ |
|---|---|---|---|---|
| normal，$\epsilon=1\%$ | 2.326 | 4% | 1 天 | 1.098 |
| standardized $t_4$，$\epsilon=1\%$ | 2.650 | 4% | 1 天 | 1.112 |
| normal，$\epsilon=0.1\%$ | 3.090 | 4% | 1 天 | 1.132 |
| standardized $t_4$，$\epsilon=0.1\%$ | 5.072 | 4% | 1 天 | 1.225 |
| normal，$\epsilon=0.1\%$ | 3.090 | 4% | 3 天 | 1.239 |
| standardized $t_4$，$\epsilon=0.1\%$，shock 之后 | 5.072 | 5.79% | 1 天 | 1.341 |

最后一行已经到 134%。再加上第 7 站的 cascade（liquidation 自己压低 price，相当于让 $\sigma$ 变大），150% 并不宽裕。

:::wrong 按 normal 和平时的 σ 算出 110% 就够了，150% 是浪费
表的第一行假设了三件事：tail 是 normal、σ 是平时的 4%、liquidation 一天内完成。三个假设恰好在最需要 collateral 的时候同时失效：crash 时 tail 事件发生（第 1 站），σ 刚刚跳升（第 2 站），network 拥堵让 liquidation 延迟（第 7 站）。三个一起换掉，需要的 ratio 从 1.098 升到 $e^{5.072\times0.0579\times\sqrt3}=1.663$，超过了 150%。Collateral ratio 是为坏日子定的，用平时的参数检验它，结论必然是“太保守”。
:::

### Run：reserve 只差一点也会发生

一个 custodial stablecoin 发行了 100 个。Reserve 里 90 USD 是现金，另有面值 10 USD 的资产，持有到期能收回 10，但现在急卖只能卖 5。Redemption 按先来后到（first-come-first-served），每人 1 个。

- 没有人run：资产到期，reserve 共 100，人人拿到 1。
- 所有人都来 redeem：前 90 个人拿到现金 1，issuer 把资产急卖得 5，分给最后 10 个人，每人 0.5。

站在一个持有者的角度：如果别人都不跑，我也不跑，拿 1。如果我认为别人会跑，我早跑能拿 1，晚了只拿 0.5。所以只要“别人会跑”的信念出现，跑就是最优反应，哪怕 reserve 的真实价值只差 5%。

这个结构来自 Diamond 和 Dybvig（1983）的 bank run model。他们的设定有三期 $T=0,1,2$：bank 把 deposit 投进一个 technology，持有到 $T=2$ 每单位得 $R>1$，在 $T=1$ 中断只能收回本金。一部分人在 $T=1$ 就要用钱，其余的人到 $T=2$ 才用，bank 不知道谁是哪种。Demand deposit 合约承诺 $T=1$ 取钱的人每单位拿固定的 $r_1$，并且受 sequential service constraint 约束：付给一个人多少只取决于他在队伍里排第几，不能等后面的人来了再定。于是有两个 equilibrium。好的那个里，只有需要用钱的人在 $T=1$ 取，合约实现了最优的 risk sharing；另一个是 run，所有人都在 $T=1$ 取。DD 强调 run 由 expectation 的转变引发，坏的 earnings 消息、别家 bank 的 run，甚至 sunspot，任何让人预期会有 run 的东西都会导致 run。问题出在 liquidity 而不是 solvency。

DD 给了两个消除 run 的办法。一是 suspension of convertibility：事先宣布取款量超过某个比例就暂停兑付。放到上面的例子里，issuer 宣布现金付完 90 个就暂停，剩下的人等资产到期再兑：资产到期收回 10，剩下 10 个人每人拿 1。早跑和晚跑拿到的一样，跑就没有理由了，run 的 equilibrium 消失，而且这个宣布事后根本用不上。二是 deposit insurance：政府保证兑付，事后用税收补上，同样让晚到的人不吃亏。

Stablecoin 比 DD 多了 secondary market 这一层。Holder 跑的时候不是去 redeem，而是在 market 上卖；arbitrageur 买进再向 issuer redeem。Ma、Zeng 和 Zhang 的核心结论是：arbitrage 越有效率，卖的人的 price impact 越小，先跑的人越不吃亏，run 越容易发生；arbitrage 低效时，卖压先把 secondary market 的 price 压下去，跑的代价高，run 反而少。Issuer 选让多少人做 arbitrage，是在 price stability 和 run risk 之间取舍。上一小节 USDT 和 USDC 的差别就是这两种选择。

USDC 在 2023 年 3 月的 depeg 就是这个结构：部分 reserve 存在倒闭的 SVB，短时间内取不出来（数字见 IS4302 那一站）。Algorithmic 的 UST 更糟，它的“reserve”是 LUNA，跑的人越多 LUNA 越不值钱，没有一个“资产到期就恢复”的好 equilibrium 可回。

## [behav] 行为偏差、neuroeconomics 与 predictability 的检验

:::skip
能用 prospect theory 算一个 gamble 的 value，并据此解释 disposition effect 和 lottery-like coin 的吸引力；能算 Sharpe ratio 的 standard error 并说明 multiple testing 怎样抬高 backtest 的结果，就读完了。
:::

### 一个 expected value 为负、却有人买的 coin

一个新 coin 的 payoff 像彩票：花 1 买入，有 1% 的 probability 涨到 81（赚 80），99% 的 probability 归零（亏 1）。Expected value 是 $0.01\times80-0.99\times1=-0.19$。按 expected value 或任何 concave 的 utility，都不该买。可这种 coin 一直有人买。

### Prospect theory

Kahneman 和 Tversky 的 prospect theory 用两个 function 描述人怎样评价 gamble。

**Value function**。以参照点（通常是买入价）为 0，按 gain 和 loss 分别计：

$$v(x)=\begin{cases}x^{\alpha},&x\ge0\\-\lambda(-x)^{\alpha},&x<0\end{cases}$$

Tversky 和 Kahneman（1992）估出的参数是 $\alpha=0.88$、$\lambda=2.25$。$\lambda>1$ 叫 loss aversion：亏 20 的痛苦是赚 20 的快乐的 2.25 倍。$\alpha<1$ 让 gain 一侧 concave、loss 一侧 convex。

**Probability weighting**。人不按真实 probability $p$ 加权，而按

$$w(p)=\frac{p^{\gamma}}{\left(p^{\gamma}+(1-p)^{\gamma}\right)^{1/\gamma}}$$

Gain 一侧 $\gamma=0.61$，loss 一侧 $\delta=0.69$（loss 一侧的 $w^-$ 把 $\gamma$ 换成 $\delta$）。小 probability 被高估，大 probability 被低估。这四个数是 1992 年那篇的 median 估计：25 个 Berkeley 和 Stanford 的研究生，对 28 个 gain 和 28 个 loss 的 two-outcome prospect 给出 certainty equivalent，$\alpha$ 在 gain 和 loss 两侧的 median 都是 0.88。

1992 年的版本叫 cumulative prospect theory，$w$ 不是直接套在每个 outcome 自己的 probability 上，而是套在“至少这么好”的累计 probability 上。Gain 按从好到坏排，最好的 outcome 的 decision weight 是 $w^+(p_1)$，第二好的是 $w^+(p_1+p_2)-w^+(p_1)$，依此类推；loss 从最坏的开始，用 $w^-$ 同样做。这样一个全是 gain 的 prospect，decision weight 加起来正好是 $w^+(1)=1$。只有一个 gain 和一个 loss 的 gamble，weight 就是 $w^+(p_{\text{gain}})$ 和 $w^-(p_{\text{loss}})$。

::fig[dse4211-pt] 左边的 value function 在 0 处折弯，loss 一侧陡 2.25 倍。右边的 weighting function，虚线是 $w(p)=p$；1% 被当成 5.5%。

拿那个 coin 来用：

$$w^+(0.01)=0.0553,\quad v(80)=80^{0.88}=47.28,\quad w^-(0.99)=0.9451,\quad v(-1)=-2.25$$

$$V=0.0553\times47.28+0.9451\times(-2.25)=2.614-2.126=+0.49$$

Expected value 是 −0.19，prospect value 是 +0.49。正是 1% 被放大成 5.5% 让它变得有吸引力。同样的计算，赚 50 的版本（expected value −0.49）prospect value 是 −0.40，就不再吸引人。

### Disposition effect

同样的 value function 预测一个交易行为：倾向于过早卖出赚钱的、过久持有亏钱的，叫 disposition effect。

两个人都在 100 买入。A 的 coin 现在 120（gain 20），B 的现在 80（loss 20）。下一期各有一半 probability 涨 10 或跌 10。现在卖，还是再持有一期？

- A 现在卖：$v(20)=13.96$。持有：两个 outcome 都是 gain，30 是较好的那个，weight $w^+(0.5)=0.4206$；10 的 weight 是 $w^+(1)-w^+(0.5)=0.5794$。Value $=0.4206\times19.95+0.5794\times7.59=12.79$。卖更好。
- B 现在卖：$v(-20)=-31.41$。持有：两个 outcome 都是 loss，从最坏的 −30 开始，weight $w^-(0.5)=0.4540$；−10 的 weight 是 $1-0.4540=0.5460$。Value $=0.4540\times(-44.88)+0.5460\times(-17.07)=-29.69$。持有更好。

不计 probability weighting、只用 $v$ 的 concave/convex 也得到同样的方向（A：13.96 对 13.77，B：−31.41 对 −30.97）。Gain 一侧 concave，确定的 gain 胜过 gamble；loss 一侧 convex，gamble 胜过确定的 loss。

### Crypto 市场上的证据

**Momentum 与 attention。** Liu 和 Tsyvinski 用 Bitcoin（2011 年起）、Ripple（2013 年起）和 Ethereum（2015 年起）到 2018 年 5 月的 price。BTC 的 daily return mean 0.52%、standard deviation 5.55%，比 traditional asset 高一个数量级。Crypto return 对 stock market factor、currency、commodity 和 macro factor 都没有一致的 exposure；用电力和芯片公司的 stock 代表挖矿成本，BTC 和 Ripple 对它们也没有显著 exposure。能预测 crypto return 的是两样：

- Time-series momentum。BTC 本周 return 对下周 return 的 regression coefficient 是 0.19（t=3.73）。Weekly return 的 standard deviation 是 16.64%，所以本周高一个 standard deviation，下周平均高 $0.19\times16.64\%=3.16\%$。
- Investor attention。Google 上“Bitcoin”的 search 量偏离趋势高一个 standard deviation，下周 return 高 1.84%；Twitter 的帖子数高一个 standard deviation，下周高 2.50%。“Bitcoin hack”相对“Bitcoin”的 search 比例高一个 standard deviation，下周 return 低 2.75%。

**同一批人，在 crypto 上换了一种做法。** Kogan、Makarov、Niessner 和 Schoar 用 eToro 上约 20 万个 retail trader 在 2015 年到 2019 年 12 月的记录，把每天持有份额的 log change 对当天和过去的 return（标准化后）做 regression。当天 return 的 coefficient：crypto（BTC、ETH、XRP）是 +0.035，200 个交易最多的 stock 是 −0.006，gold 是 −0.216，都在 1% 水平显著。同一批人在 stock 和 gold 上是 contrarian（涨了卖），在 crypto 上跟着涨买。作者逐一检验了几种解释：

- 个人特征：加上各类个人特征的 interaction，各组的做法差不多。
- Inattention：只看过去 7 天内交易过的 active user，二分依旧。
- Fee：2019 年 eToro 在 18 个国家取消 stock 的 fee，前后的 coefficient 没有显著变化。
- 对 lottery-like asset 的偏好：用 stock 的 maximum return、volatility、skewness 做 interaction，结果不一致，解释不了。

他们的 conjecture 是这些人心里有一个 model：price 上涨意味着 crypto 被广泛 adopt 的可能更大，于是更值得买。这是推测，论文引用 Liu 和 Tsyvinski 关于“return 预测后来 adoption 的增长”的结果作为旁证，并说明需要更多研究。

### Neuroeconomics：Kuhnen 和 Knutson 的实验

Kuhnen 和 Knutson 让 19 个被试（Stanford 的 PhD 学生，一部分学金融、经济或会计，其余学人文学科）在 fMRI 里做 200 次选择：20 个 block，每个 block 10 次，每次在一个 bond 和两个 stock 里选一个。Bond 每次稳拿 1 美元。每个 block 开始时，两个 stock 里随机一个是 good，另一个是 bad，被试不知道哪个是哪个：

| | +10 | 0 | −10 |
|---|---|---|---|
| good stock | 50% | 25% | 25% |
| bad stock | 25% | 25% | 50% |

每次选完，被试能看到所有 asset 这一次的结果。

作为比较的 benchmark 是一个 risk-neutral、按 Bayes rule 更新 belief 的 agent。设 A 是 good 的 posterior 为 $x$，A 的 expected payoff 是

$$x\,(0.5\times10-0.25\times10)+(1-x)\,(0.25\times10-0.5\times10)=5x-2.5$$

比 bond 的 1 高要求 $x\ge0.7$。Block 开始时 $x=0.5$，该选 bond。第一次看到 A 得 +10、B 得 −10：A good（B bad）时这个结果的 probability 是 $0.5\times0.5=0.25$，A bad（B good）时是 $0.25\times0.25=0.0625$，posterior $x=0.25/(0.25+0.0625)=0.8$，该选 A。如果看到的是 A 得 +10、B 得 0：$0.5\times0.25=0.125$ 对 $0.25\times0.25=0.0625$，$x=0.667<0.7$，仍该选 bond。这时选 A 就是一次 risk-seeking mistake；反过来，该选 stock 时选了 bond 是 risk-aversion mistake。

被试常犯这两种错：两组被试的 risk-seeking mistake 比例是 26% 和 35%，risk-aversion mistake 是 23% 和 29%，组间差别不显著。Nucleus accumbens 的激活出现在 risky choice 和 risk-seeking mistake 之前，anterior insula 的激活出现在 riskless choice 和 risk-aversion mistake 之前。作者的结论是两个与 anticipatory affect 相关的 circuit 推动不同类型的选择，其中一个过度激活可能导致 mistake。他们也写明了局限：没有确立激活和选择谁先谁后的 causal 关系，样本只有 19 个人，每次的钱很少。实验和 crypto 无关，它说明的是“决定前的情绪状态可以预测选择偏离 Bayesian benchmark 的方向”。

### 怎样检验“我的 model 能预测 return”

课程 Week 11 讲 machine learning。用 ML 预测 crypto return，最常见的错误不在 model，而在检验。

**Sharpe ratio 本身有很大的 sampling error。** Lo（2002）给出：return i.i.d. 时，用 $n$ 个 observation 估计的 per-period Sharpe ratio $\widehat{SR}_p$ 近似服从 normal，standard error 是

$$\text{SE}(\widehat{SR}_p)=\sqrt{\frac{1+\tfrac12SR_p^2}{n}}$$

$SR_p$ 和 $n$ 必须是同一个 frequency：用 daily data，就是 daily 的 Sharpe 和天数。年化时 Sharpe ratio 乘 $\sqrt q$（$q$ 是一年的期数），standard error 也乘 $\sqrt q$。Crypto 一年 $q=365$ 天，$T$ 年的数据 $n=365T$，年化的 $SR=\sqrt q\,SR_p$：

$$\text{SE}(\widehat{SR})=\sqrt q\cdot\sqrt{\frac{1+\tfrac12\,SR^2/q}{qT}}=\sqrt{\frac{1+SR^2/(2q)}{T}}\approx\frac1{\sqrt T}$$

$SR^2/(2q)$ 是年化 Sharpe 的平方除以 730，几乎可以忽略。所以估计的精度只取决于数据跨了几年，切成 daily 还是 hourly 帮不上忙。

一个 strategy 两年 backtest 得到年化 Sharpe 1.5：SE $=\sqrt{(1+2.25/730)/2}=0.708$，t-statistic 2.12，刚过 5% 的 1.96。

**Multiple testing。** 试 100 个完全没有预测力的 signal（真实 Sharpe 都是 0），每个跑两年 backtest。每个的 $\widehat{SR}$ 近似 $N(0,\,1/2)$。100 个 independent standard normal 的最大值的 expected value 是 2.508（对 $x\cdot100\,\varphi(x)\,\Phi(x)^{99}$ 做数值积分），所以 100 个 $\widehat{SR}$ 里最大值的 expected value 是 $2.508\times\sqrt{1/2}=1.77$。只报告最好的那个，看到的就是一个 Sharpe 1.77 的“strategy”，而它的真实 Sharpe 是 0。

上面那个 t-statistic 2.12 也要这样看。单独一个纯 noise 的 signal，$\widehat{SR}$ 超过 1.5 的 probability 是 $1-\Phi(1.5/0.707)=1.7\%$；100 个里至少有一个超过的 probability 是 $1-(1-0.017)^{100}=82\%$。

**Look-ahead bias。** 用了在那个时刻还不知道的信息：拿全样本算的 mean 和 sd 做 standardization、用事后的 coin 列表（今天还活着的 coin 就是 survivorship bias）、用收盘价产生 signal 又按同一个收盘价成交。办法是 walk-forward：只用 $t$ 之前的数据 fit，在 $t$ 之后的一段上测，然后整体往前滚。

:::wrong Backtest 的 Sharpe 是 1.8，比 BTC 本身高，说明找到了 alpha
如果这个 1.8 是从 100 个候选里挑出来的最好一个，上面算过，纯 noise 的 expected 最大值就是 1.77。要问的不是“这个数大不大”，而是“在我试过的所有东西里，纯靠运气能得到多大”。所以报告 backtest 时要同时报告试过多少个 variant，并在一段从未碰过的 out-of-sample 数据上再测一次。Momentum 在 crypto 上有学术证据（Liu 和 Tsyvinski），这不等于任何一个具体的 momentum strategy 在扣掉 fee 和 funding（第 4 站）之后还能赚钱。
:::

:::edge Return 有 autocorrelation 时，乘 $\sqrt q$ 会出错
$\sqrt q$ 来自 i.i.d.：$q$ 期 return 的 variance 是单期的 $q$ 倍。有 autocorrelation 时，$q$ 期 return 的 variance 是 $\sigma^2\bigl(q+2\sum_{k=1}^{q-1}(q-k)\rho_k\bigr)$，mean 仍是 $q\mu$，所以 Lo 给出 $SR(q)=\eta(q)\,SR$，

$$\eta(q)=\frac{q}{\sqrt{q+2\sum_{k=1}^{q-1}(q-k)\rho_k}}$$

$\rho_k$ 是 lag $k$ 的 autocorrelation，全为 0 时 $\eta(q)=\sqrt q$。Liu 和 Tsyvinski 测到的 BTC weekly momentum coefficient 是 0.19，按 AR(1) 近似取 $\rho_k=0.19^k$，$q=52$：$\eta=5.97$，而 $\sqrt{52}=7.21$。用 $\sqrt{52}$ 把 weekly Sharpe 年化，会高估 21%。Positive autocorrelation 让 return 在一年里互相加强，年化的 variance 比 $q$ 倍更大。
:::
