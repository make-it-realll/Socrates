先看三次计算。每一次在数学上都毫无问题，在计算机上都出了事。

**第一次。** 在任何一门语言里输入 `0.1 + 0.2`，得到的是 `0.30000000000000004`，它和 `0.3` 不相等。

**第二次。** 用 elimination 解一个两个 unknown 的 system，exact solution 是 $x_1\approx1$、$x_2\approx1$，计算机给出 $x_1=0$。

**第三次。** 取 50 个点，用一个 degree-11 polynomial 去 fit，data 是事先造好的，正确答案是所有 coefficient 都等于 1。用教科书上的 formula 算，coefficient 最大偏了 0.23；换一种 algorithm，偏差是 $10^{-8}$。

三件事的原因是同一个：计算机里的数只有有限位。这门课研究的就是在这个前提下，linear algebra 和 calculus 里的那些“解出来”还剩下多少、怎样把它们保住。所以每学一个方法都要问三件事：算得出来吗，要算多久，结果有几位可信。

课程的顺序是：先弄清计算机里的数（第 1 站），然后解 system（第 2、3 站），equation 比 unknown 多时改求 least squares（第 4 站），再求 eigenvalue 和 singular value（第 5 站），最后回到 function，用有限个点去 approximate 它、对它做 differentiation 和 integration（第 6、7 站）。上面三次事故分别在第 1、2、4 站得到解释。

前五站反复用同一个办法：把一个不好对付的 matrix 写成几个好对付的 matrix 的 product。好对付的 matrix 只有三种。

| 好对付的 matrix | 为什么好对付 | 对应的 factorization | 用来做什么 |
|---|---|---|---|
| triangular matrix | 每个 equation 只多出一个新 unknown，逐个代入就能解 | $A=LU$ | 解 system |
| orthogonal matrix | inverse 就是 transpose，而且不改变 vector 的 length | $A=QR$ | least squares |
| diagonal matrix | 各个方向互不干扰，各自乘一个数 | $A=Q\Lambda Q^\top$，$A=U\Sigma V^\top$ | eigenvalue、dimensionality reduction |

## [fp] Floating point 与 error

:::skip
能从“每次 operation 带一个 $10^{-16}$ 量级的 relative error”推出两个相近的数相减为什么危险，并且分得清“问题 ill-conditioned”和“algorithm unstable”，就可以去第 2 站。
:::

### 计算机里的数是什么样的

计算机存 real number 的办法就是 scientific notation，只不过用 binary，而且位数固定。Double precision 是

$$\pm\,1.b_1b_2\cdots b_{52}\times2^{e}$$

小数点后恰好 52 位。位数固定，意味着能表示的数只是 number line 上一些孤立的点。

::fig[dsa2102-fp] 把位数缩到 3 位、exponent 只取四个值，就能把整个系统画出来。每过一个 2 的 power，相邻两个数的间隔翻倍。

这张图里最重要的事实是：间隔和数本身的大小成正比。在 1 附近间隔是 $2^{-52}$，在 $10^6$ 附近间隔就是 $10^6\times2^{-52}$。所以 floating-point number 给出的不是“小数点后多少位”，而是“一共多少位 significant digits”。这个相对间隔记作 $\varepsilon=2^{-52}\approx2.2\times10^{-16}$，叫 machine epsilon，相当于大约 16 位 decimal significant digits。

现在可以解释第一次事故了。0.1 写成 binary 是 $0.000110011001100\cdots$，无限循环，就像 $1/3$ 写成 decimal 一样，存不下，只能存离它最近的那个点。三个数实际存下的是

| 写的是 | 存下的是 |
|---|---|
| 0.1 | 0.1000000000000000055… |
| 0.2 | 0.2000000000000000111… |
| 0.3 | 0.2999999999999999889… |

0.1 和 0.2 都存大了一点，0.3 存小了一点。前两个相加再 rounding，落在 0.3000000000000000444…，是“0.3 存下的那个点”右边紧挨着的下一个点。

### 一条规则管所有 operation

整门课对 floating-point number 只需要一条假设：两个 floating-point number 做一次加减乘除，得到的是 exact result 再 rounding 到最近的 floating-point number。写出来是

$$\mathrm{fl}(a\circ b)=(a\circ b)(1+\delta),\qquad|\delta|\le\varepsilon$$

每做一次 operation，结果被乘上一个离 1 极近的 factor。后面关于 error 的一切，都是从这一条推出来的。

先看它对乘法意味着什么。连乘两次，error factor 是 $(1+\delta_1)(1+\delta_2)\approx1+\delta_1+\delta_2$，relative error 只是相加。做一千次乘法，也不过损失三位。乘除法是安全的。

再看减法。减法这一步自己带的那个 $\delta$ 同样无害，要看的是 $a$、$b$ 进来时已经带着的 error。设它们实际是 $a(1+\delta_a)$ 和 $b(1+\delta_b)$，相减得

$$a(1+\delta_a)-b(1+\delta_b)=(a-b)+(a\,\delta_a-b\,\delta_b)$$

后一个括号是 error，大小最多是 $(|a|+|b|)\,\delta$。它本身并不大。但现在要拿它和结果 $a-b$ 比，relative error 是

$$\frac{|a|+|b|}{|a-b|}\;\delta$$

前面那个分数是 amplification factor。$a$ 和 $b$ 相差很大时它接近 1；$a$ 和 $b$ 很接近时，denominator 很小，它可以大到任意程度。相减没有制造新的 error：error 的绝对大小没变，是结果变小了，原来排在第 16 位的 error 就被推到了前面。

这就找到了 floating-point arithmetic 里 accuracy 突然丢失的唯一来源：两个相近的数相减。它有个名字，叫 cancellation。

:::wrong Double precision 有 16 位 significant digits，所以算出来的结果也有 16 位
取 $x=10^{12}$，算 $\sqrt{x+1}-\sqrt{x}$，一步一步看机器里发生了什么。

$\sqrt{x}=10^6$，恰好能存。$\sqrt{x+1}$ 的 true value 是 $1000000.00000049999999999987\cdots$。在 $10^6$ 附近，相邻 floating-point number 的间隔是 $1.2\times10^{-10}$，离 true value 最近的那个点是

$$1000000.000000500003807\cdots$$

偏了 $3.8\times10^{-12}$。对 $\sqrt{x+1}$ 自己来说，这是第 18 位上的事，完全正常。

然后相减。两个数的前 13 位相同，减完全部消失，剩下 $5.00003807\times10^{-7}$。那个 $3.8\times10^{-12}$ 原封不动地留在结果里，而结果只有 $5\times10^{-7}$ 这么大，于是它成了第 6 位上的事。True value 是 $4.99999999999875\times10^{-7}$，算出来的只有前 5 位是对的。

用上面的 formula 核对：amplification factor 是 $\dfrac{2\times10^6}{5\times10^{-7}}=4\times10^{12}$，乘上 $10^{-16}$，最坏的 relative error 在 $10^{-4}$ 量级；这次实际是 $7.6\times10^{-6}$，在这个界之内。
:::

::fig[dsa2102-cancel] 上面这个 $x=10^{12}$ 的例子逐位对齐，小数点后取 15 位。前 13 位相同，相减后只剩后面几位；stored 值里那几位 error 原封不动地搬进了结果。

### 同一个 function，两种 algorithm

Cancellation 往往可以靠改写算式避开。把上面的式子乘上 conjugate 再除回去：

$$\sqrt{x+1}-\sqrt{x}=\frac{1}{\sqrt{x+1}+\sqrt{x}}$$

右边只有加法、开方和除法，没有相近数相减。同样在 double precision 下，它给出 $4.999999999998749\times10^{-7}$，16 位全对。

两个式子数学上是同一个 function，数值上一个只有 5 位、一个有 16 位。这说明“结果准不准”取决于两样互相独立的东西，必须分开谈。

**问题本身有多敏感。** Input 变动一点点，真实的答案变动多少倍？这只和 function 有关，和怎么算无关。Input 从 $x$ 变到 $x+\Delta x$，output 大约变化 $f'(x)\,\Delta x$。把 output 的 relative change 除以 input 的 relative change：

$$\kappa=\left|\frac{f'(x)\,\Delta x}{f(x)}\right|\Big/\left|\frac{\Delta x}{x}\right|=\left|\frac{x\,f'(x)}{f(x)}\right|$$

这个倍数叫 condition number。对 $f(x)=\sqrt{x+1}-\sqrt{x}$，

$$f'(x)=\frac{1}{2\sqrt{x+1}}-\frac{1}{2\sqrt{x}}=\frac{\sqrt{x}-\sqrt{x+1}}{2\sqrt{x}\sqrt{x+1}}=\frac{-f(x)}{2\sqrt{x(x+1)}},\qquad\kappa=\frac{x}{2\sqrt{x(x+1)}}\approx\frac12$$

Input 的 relative error 传到 output 时还要减半。这个问题一点也不敏感。

**Algorithm 有没有添乱。** 第一种写法把一个不敏感的问题拆成了几步，其中那次减法单独看也是一个“问题”，它的 condition number 就是前面的 amplification factor $4\times10^{12}$。第二种写法的每一步都不敏感。前者叫 unstable 的 algorithm，后者叫 stable 的 algorithm。

所以算错了要先问：是问题本身敏感，还是 algorithm 绕了一条敏感的路？前一种情况换 algorithm 没有用，后一种情况换 algorithm 就能救回来。

### 衡量 algorithm 的正确标准

对一个 algorithm，直接要求“output 接近 true value”是不公平的，因为问题本身可能就敏感。合理的要求是：

> Algorithm 给出的结果，恰好是某个邻近 input 的 exact answer。

Input 本来就带着 $\varepsilon$ 量级的 rounding，algorithm 只要不比这更糟，就已经尽了本分。满足这个要求的 algorithm 叫 backward stable。

拿刚才两种写法来检验。问：Input 要挪到哪个 $\tilde x$，才能让算出来的数成为 $f(\tilde x)$ 的 exact value？

| 写法 | 算出的结果 | 它是哪个 input 的 exact answer | Input 挪动了多少 |
|---|---|---|---|
| $\dfrac{1}{\sqrt{x+1}+\sqrt{x}}$ | $4.999999999998749\times10^{-7}$ | $\tilde x=10^{12}\times(1+2.6\times10^{-16})$ | 约 $\varepsilon$ |
| $\sqrt{x+1}-\sqrt{x}$ | $5.00003807\times10^{-7}$ | $\tilde x=0.9999848\times10^{12}$ | $1.5\times10^{-5}$，是 $\varepsilon$ 的 $10^{11}$ 倍 |

第一种写法 backward stable，第二种不是。

有了这个标准，答案的 error 就可以算了。Backward stable 的 algorithm 给出的是 $f(\tilde x)$，而 $\tilde x$ 相对 $x$ 只偏了大约 $\varepsilon$；condition number 的定义正是 input 的相对偏差传到 output 时放大的倍数。所以

$$\text{答案的 relative error}\ \approx\ \kappa\times\text{input 的 relative change}\ \lesssim\ \kappa\,\varepsilon$$

表里两行都对得上：$\tfrac12\times2.6\times10^{-16}=1.3\times10^{-16}$，是第一种写法的实际 error；$\tfrac12\times1.5\times10^{-5}=7.6\times10^{-6}$，是第二种的。

Condition number 归问题管，$\varepsilon$ 归机器管，algorithm 只负责不再往里添东西。后面三站每介绍一个 algorithm，都是在对着这个标准检查它。

:::edge 相近的数相减，有时躲不掉
用 $\dfrac{f(x+h)-f(x)}{h}$ approximate derivative，numerator 天生就是两个相近的数相减，而且 $h$ 越小越相近。这不是能靠改写消掉的 cancellation，只能在“$h$ 太大 formula 不准”和“$h$ 太小 cancellation 严重”之间折中。第 7 站用实算的 curve 把这个折中画出来。
:::

## [lu] Elimination、LU factorization 与 pivoting

:::skip
能解释 elimination 时用的 multiplier 为什么正好拼成 $L$、不需要任何额外计算；能说出小 pivot 为什么危险、pivoting 为什么能治，就可以去第 3 站。
:::

### 为什么目标是 triangular

解 system，先问什么样的 system 不用“解”。Upper triangular system 就是：

$$\begin{aligned}u_{11}x_1+u_{12}x_2+u_{13}x_3&=c_1\\u_{22}x_2+u_{23}x_3&=c_2\\u_{33}x_3&=c_3\end{aligned}$$

最后一个 equation 只有一个 unknown，直接得到 $x_3$；代进上一个 equation，又只剩一个 unknown。每一步只面对一个新 unknown，从下往上代一遍就完了，这叫 back substitution，一共大约 $n^2$ 次 operation。

所以所有直接解法的思路都是同一句话：把一般的 system 变成 triangular 的。

### 走一遍 elimination

这一站都用同一个例子，出自 18.06 第 2 讲：

$$\begin{aligned}x+2y+z&=2\\3x+8y+z&=12\\4y+z&=2\end{aligned}$$

把 coefficient 和 right-hand side 并排写，每一步从下面的某个 row 里减去上面某个 row 的若干倍，目的是在 diagonal 下方造出 0。

$$\left(\begin{array}{ccc|c}1&2&1&2\\3&8&1&12\\0&4&1&2\end{array}\right)\ \xrightarrow{\ \text{row 2}-3\times\text{row 1}\ }\ \left(\begin{array}{ccc|c}1&2&1&2\\0&2&-2&6\\0&4&1&2\end{array}\right)\ \xrightarrow{\ \text{row 3}-2\times\text{row 2}\ }\ \left(\begin{array}{ccc|c}1&2&1&2\\0&2&-2&6\\0&0&5&-10\end{array}\right)$$

Row 3 的第一个 entry 本来就是 0，所以它减去的是 0 倍的 row 1。一共用了三个倍数，叫 multiplier：$\ell_{21}=3$，$\ell_{31}=0$，$\ell_{32}=2$。Diagonal 上留下的 1、2、5 叫 pivot，每个 multiplier 都是“要消掉的数除以 pivot”。

现在是 upper triangular 的了，back substitution：$5z=-10$ 得 $z=-2$；$2y-2z=6$ 得 $y=1$；$x+2y+z=2$ 得 $x=2$。

### Elimination 其实是一次 factorization

那三个 multiplier 用完就扔掉太可惜了。把它们留下来会发生什么？

盯着 $A$ 的 row 3，看它在 elimination 里的经历。它先被减去 $\ell_{31}$ 倍的 row 1，再被减去 $\ell_{32}$ 倍的 row 2，然后就成了 $U$ 的 row 3。关键在于：它每次减去的那个 row，在那一刻都已经是 elimination 完成的样子，也就是 $U$ 的 row。把这句话反过来读：

$$\text{row 3 of }A=\ell_{31}\,(\text{row 1 of }U)+\ell_{32}\,(\text{row 2 of }U)+(\text{row 3 of }U)$$

用例子核对：$0\times(1,2,1)+2\times(0,2,-2)+(0,0,5)=(0,4,1)$，正是 $A$ 的 row 3。每个 row 都是这样。把这些式子叠在一起，就是一个 matrix equation：

$$\underbrace{\begin{pmatrix}1&2&1\\3&8&1\\0&4&1\end{pmatrix}}_{A}=\underbrace{\begin{pmatrix}1&0&0\\3&1&0\\0&2&1\end{pmatrix}}_{L}\underbrace{\begin{pmatrix}1&2&1\\0&2&-2\\0&0&5\end{pmatrix}}_{U}$$

$L$ 里装的正是 elimination 用过的 multiplier，各在各的位置上，一个不多，一个不少，不需要任何额外的计算。

这一点没有看上去那么理所当然。换一种记法，把“对 $A$ 做了什么”直接记成一个 matrix $E$，使 $EA=U$。Row 3 最终变成了什么？它减去了 2 倍的“新的 row 2”，而新的 row 2 是“row 2 减 3 倍 row 1”，所以

$$\text{row 3}-2\times(\text{row 2}-3\times\text{row 1})=\text{row 3}-2\times\text{row 2}+6\times\text{row 1}$$

$$E=\begin{pmatrix}1&0&0\\-3&1&0\\6&-2&1\end{pmatrix},\qquad L=\begin{pmatrix}1&0&0\\3&1&0\\0&2&1\end{pmatrix}$$

$E$ 的左下角冒出一个 6，它不是任何一步用过的 multiplier，是两步互相干扰的产物。$L$ 的同一个位置是 0，就是那个没用上的 $\ell_{31}$。原因正是上面那句话：从 $U$ 往回拼 $A$ 时，用的都是 $U$ 的 row，彼此不相干；而从 $A$ 往 $U$ 走时，后面的步骤用的是已经被前面改过的 row。这是把 elimination 写成 $A=LU$ 而不是 $EA=U$ 的理由。

### 有了 L 和 U，怎么解 equation

$Ax=b$ 就是 $L(Ux)=b$。把括号里的东西先叫作 $y$，一个 system 拆成两个 triangular 的：

$$Ly=b,\qquad\text{然后}\qquad Ux=y$$

第一个是 lower triangular 的，从上往下代，叫 forward substitution。用例子的 $b=(2,12,2)$：

$$y_1=2,\qquad3y_1+y_2=12\Rightarrow y_2=6,\qquad2y_2+y_3=2\Rightarrow y_3=-10$$

得到的 $y=(2,6,-10)$ 正是刚才 elimination 时 right-hand side 那个 column 最后的样子。Forward substitution 就是把 elimination 对 $b$ 重做一遍，只是这回 multiplier 是现成的。第二个 system $Ux=y$ 就是前面做过的 back substitution。

::fig[dsa2102-lu] 上面的 elimination 一步一步走。看每一步的 multiplier（浅色格的数除以深色的 pivot）怎样原样落进右边 $L$ 的同一个位置；最后左边三列成了 $U$，$b$ 那一列成了 $y=(2,6,-10)$。

### 要算多久

Eliminate column 1 时，要更新右下角大约 $n\times n$ 个 entry；eliminate column 2 时是 $(n-1)\times(n-1)$ 个；一直到 1。总数是

$$n^2+(n-1)^2+\cdots+1^2\approx\int_0^nx^2\,dx=\frac{n^3}{3}$$

每个 entry 的更新是一次乘法加一次减法，所以 factorization 大约要 $\tfrac13n^3$ 组“乘减”，按单次 operation 算是 $\tfrac23n^3$。Forward substitution 和 back substitution 各要 $\tfrac12n^2$ 组，合起来 $n^2$。

| | operation count（leading term，按“乘减”计） |
|---|---|
| LU factorization | $\tfrac13n^3$ |
| 每个 right-hand side 的 forward substitution 加 back substitution | $n^2$ |

这两个数的差距决定了用法：factorization 一次，存下 $L$ 和 $U$；之后每换一个 $b$，只做便宜的那一步。$n$ 翻倍，factorization 的时间变成 8 倍，换 right-hand side 的时间变成 4 倍。

:::wrong 解 equation 就是求出 $A^{-1}$ 再乘 $b$
纸上没错，机器上是坏习惯。$A^{-1}$ 的 column $j$ 是 $Ax=e_j$ 的 solution，求 inverse 等于解 $n$ 个 system，比解一个贵得多，error 也更大。而求出来的 $A^{-1}$ 唯一的用处就是去乘 $b$，这件事 $L$ 和 $U$ 已经能做了。Formula 里出现 $A^{-1}b$ 时，把它读成“解一个 system”。
:::

### 小 pivot 毁掉了什么

每个 multiplier 都要除以 pivot。Pivot 是 0 当然进行不下去，交换两个 row 就行。问题是 pivot 不为 0 但很小的时候。这就是开头的第二次事故：

$$\begin{pmatrix}10^{-20}&1\\1&1\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix}=\begin{pmatrix}1\\2\end{pmatrix}$$

Exact solution 是 $x_1\approx1$，$x_2\approx1$。按部就班 elimination，multiplier 是 $1/10^{-20}=10^{20}$，row 2 变成

$$(1-10^{20})\,x_2=2-10^{20}$$

看左边的 coefficient $1-10^{20}$。在 16 位 significant digits 里，$10^{20}$ 旁边的那个 1 根本存不下，结果就是 $-10^{20}$。右边同理。于是 $x_2=1$；代回 row 1：$10^{-20}x_1+x_2=1$，得 $x_1=0$。

出错的那一刻很清楚：matrix 右下角原来的那个 1 被 $10^{20}$ 淹没，从计算里消失了。用第 1 站的标准来检查，把机器里实际得到的 $L$ 和 $U$ 乘回去：

$$\begin{pmatrix}1&0\\10^{20}&1\end{pmatrix}\begin{pmatrix}10^{-20}&1\\0&-10^{20}\end{pmatrix}=\begin{pmatrix}10^{-20}&1\\1&0\end{pmatrix}$$

右下角是 0 而不是 1。Algorithm 确实精确地解了一个 system，但那个 system 和原来的差了一个和 matrix entry 一样大的量，不是 $\varepsilon$。所以这个 algorithm 不是 backward stable 的。而这个 matrix 本身的 condition number 只有 2.6 左右，问题一点也不敏感。

原因是 multiplier 太大。治法也就明确了：让 multiplier 的 absolute value 不超过 1。每一步在当前 column 里找 absolute value 最大的 entry，把它所在的 row 换上来当 pivot，这叫 **partial pivoting**。上面的例子先交换两个 row：

$$\begin{pmatrix}1&1\\10^{-20}&1\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix}=\begin{pmatrix}2\\1\end{pmatrix}$$

Multiplier 变成 $10^{-20}$，row 2 变成 $(1-10^{-20})\,x_2=1-2\times10^{-20}$。这回被舍掉的是无关紧要的 $10^{-20}$，得到 $x_2=1$，back substitution 得 $x_1=1$。乘回去检查，得到的 matrix 和交换后的 matrix 只在右下角差 $10^{-20}$。

Row exchange 用 permutation matrix $P$ 记录（把 identity matrix 的 row 按同样的方式交换），factorization 写成

$$PA=LU$$

解 equation 时先把 $b$ 的各个 entry 按同样的次序换好，即解 $Ly=Pb$，再解 $Ux=y$。Multiplier 都不超过 1，elimination 过程中的数就不会涨到把原来的 entry 淹没。带 partial pivoting 的 elimination 在实际问题里是 backward stable 的，这是它成为标准 algorithm 的原因。

### SPD matrix：Cholesky

有一类 matrix 后面会不断遇到（第 4 站 normal equations 的 $A^\top A$、统计里的 covariance matrix）：symmetric，而且 elimination 时 pivot 全是正的。这样的 matrix 叫 symmetric positive definite，简写 SPD。对它可以省一半的工作。看一个 2×2 的：

$$\begin{pmatrix}4&2\\2&5\end{pmatrix}=\begin{pmatrix}1&0\\\tfrac12&1\end{pmatrix}\begin{pmatrix}4&2\\0&4\end{pmatrix}=\begin{pmatrix}1&0\\\tfrac12&1\end{pmatrix}\begin{pmatrix}4&0\\0&4\end{pmatrix}\begin{pmatrix}1&\tfrac12\\0&1\end{pmatrix}$$

第一个等号是普通的 LU，pivot 是 4 和 4。第二个等号把 pivot 从 $U$ 里提出来，剩下的那个 upper triangular 恰好是 $L$ 的 transpose，这是 symmetry 带来的。Pivot 是正的，可以取 square root，各分一半给左右两边：

$$\begin{pmatrix}4&2\\2&5\end{pmatrix}=\begin{pmatrix}2&0\\1&2\end{pmatrix}\begin{pmatrix}2&1\\0&2\end{pmatrix}=LL^\top$$

这就是 Cholesky factorization。只需要算一个 triangular factor，operation count 是 $\tfrac16n^3$，LU 的一半。

它还不需要 pivoting。看 $LL^\top$ 的 diagonal：$L$ 每个 row 的 sum of squares 等于 $A$ 对应的 diagonal entry（上面 row 2：$1^2+2^2=5$）。所以 $L$ 里的数不可能比 $A$ 的 diagonal entry 的 square root 更大，小 pivot 那种“数越算越大”的事不会发生。Factorization 中途如果要对负数取 square root，说明 matrix 不是 positive definite，这也是检验它最省事的办法。

:::from
System $x+2y+z=2$、$3x+8y+z=12$、$4y+z=2$ 和它的 elimination 过程出自 [18.06 第 2 讲](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-2-elimination-with-matrices/)。“elimination 是一次 factorization”、$E$ 与 $L$ 的对比、$n^3/3$ 的数法跟着 [18.06 第 4 讲](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-4-factorization-into-a-lu/)；那一讲对比时用的是 multiplier 2 和 5（多出来的数是 10），这里换成了第 2 讲的 matrix，好让每个数都能核对。两讲都只在 pivot 为 0 时才交换 row；小 pivot 在 floating-point number 下的问题、Cholesky 不必 pivoting 的理由，是数值课另加的。
:::

## [cond] Norm、condition number 与 iterative methods

:::skip
能从“matrix 把 circle 变成 ellipse”推出 condition number 的定义，能说出为什么 residual 很小并不说明 solution 是准的，并能写出 Jacobi iteration 和它 converge 的条件，就可以去第 4 站。
:::

### 还差一个问题

上一站的结论是：带 pivoting 的 elimination 给出的 $\hat x$，精确满足一个邻近的 system。也就是说，它相当于把 $b$（或 $A$）动了 $10^{-16}$ 那么一点，然后精确求解。

那么 $\hat x$ 离 exact solution 有多远？这取决于第 1 站说的另一半：问题本身有多敏感。$b$ 动一点，solution 会动多少？要回答它，先得能说清一个 matrix “把 vector 放大多少倍”。

### Matrix 有多大

Vector 的大小用 norm 量。常用三种：

$$\|x\|_1=\sum_i|x_i|,\qquad\|x\|_2=\Big(\sum_ix_i^2\Big)^{1/2},\qquad\|x\|_\infty=\max_i|x_i|$$

Matrix 的大小，定义成它最多能把 vector 拉长多少倍：

$$\|A\|=\max_{x\ne0}\frac{\|Ax\|}{\|x\|}$$

量 vector 用哪种 norm，matrix 就跟着有哪种 norm。其中两种可以直接从 matrix entry 读出来。

**∞-norm 等于最大的 absolute row sum。** $Ax$ 的第 $i$ 个 component 是 $\sum_ja_{ij}x_j$，它的 absolute value 最多是 $\big(\sum_j|a_{ij}|\big)\cdot\max_j|x_j|$，所以 amplification factor 不超过最大的 absolute row sum。让 $x$ 的每个 component 取 $\pm1$，sign 和那个 row 的 entry 一致，就恰好达到。

**1-norm 等于最大的 absolute column sum。** $Ax$ 是 $A$ 各个 column 的 combination，$x_j$ 是各个 column 的 weight。Weight 的 absolute value 之和固定为 1 时，把全部 weight 押在 1-norm 最大的那个 column 上，得到的结果最大。

$$A=\begin{pmatrix}1&-2\\3&4\end{pmatrix}:\qquad\|A\|_\infty=\max(3,\,7)=7,\ \text{取 }x=\begin{pmatrix}1\\1\end{pmatrix};\qquad\|A\|_1=\max(4,\,6)=6,\ \text{取 }x=\begin{pmatrix}0\\1\end{pmatrix}$$

2-norm 没有这么直接的 formula，但有一张图。

::fig[dsa2102-ellipse] 把所有 length 为 1 的 vector（左边的 circle）都乘上 $A$，得到的总是一个 ellipse。Circle 上有一对互相 perpendicular 的方向 $v_1$、$v_2$，恰好被送到 ellipse 的 major axis 和 minor axis 上。

Ellipse 的 semi-major axis $\sigma_1$ 是 $A$ 能达到的 maximum stretch，所以 $\|A\|_2=\sigma_1$。Semi-minor axis $\sigma_2$ 是 minimum stretch。这两个数叫 singular value。为什么总是 ellipse、$\sigma$ 怎么求，要到第 5 站才能说清；这里先只用这张图。

### Condition number 是被这张图逼出来的

解 $Ax=b$ 是从 ellipse 那一边往 circle 这一边走：已知 image $b$，求 preimage $x$。沿 major axis 方向的 $b$，往回走时被除以 $\sigma_1$；沿 minor axis 方向的，被除以 $\sigma_2$。Minor axis 方向被放大得最厉害。

现在设想最坏的情形。真正的 $b$ 恰好沿 major axis，所以 solution 不大，$\|x\|=\|b\|/\sigma_1$。而 $b$ 上的 perturbation $\delta b$ 恰好沿 minor axis，于是 solution 的 perturbation 是 $\|\delta x\|=\|\delta b\|/\sigma_2$。把两个 relative error 一比：

$$\frac{\|\delta x\|/\|x\|}{\|\delta b\|/\|b\|}=\frac{\sigma_1}{\sigma_2}$$

这就是 relative error 被放大的最大倍数，叫 condition number。Condition number 就是 ellipse 有多扁。Circle（orthogonal matrix、identity matrix 的倍数）的 condition number 是 1，是最好的情形；ellipse 越扁，越接近把 plane 压成一条 line，也就是越接近 singular，condition number 越大。

同一个结论不靠图也能得到，而且对任何 norm 都成立，只需要把 norm 的定义用两次。Perturbation 满足 $A\,\delta x=\delta b$，所以

$$\delta x=A^{-1}\delta b\ \Rightarrow\ \|\delta x\|\le\|A^{-1}\|\,\|\delta b\|;\qquad b=Ax\ \Rightarrow\ \|b\|\le\|A\|\,\|x\|$$

第一个 inequality 除以 $\|x\|$，再用第二个把 $1/\|x\|$ 换成 $\|A\|/\|b\|$：

$$\frac{\|\delta x\|}{\|x\|}\le\underbrace{\|A\|\,\|A^{-1}\|}_{\kappa(A)}\ \frac{\|\delta b\|}{\|b\|}$$

在 2-norm 下 $\|A\|=\sigma_1$；$A^{-1}$ 把 ellipse 送回 circle，它最大的 stretch 发生在 minor axis 方向，所以 $\|A^{-1}\|=1/\sigma_2$，乘起来正是 $\sigma_1/\sigma_2$。

和第 1 站的结论接起来：stable 的 algorithm 相当于让 input 有 $\varepsilon$ 的 relative perturbation，所以 solution 的 relative error 大约是 $\kappa(A)\,\varepsilon$。$\kappa(A)\approx10^k$ 时，16 位里要丢掉大约 $k$ 位。

### 算一个，再看一眼

两个 unknown 的 system 就是求两条 line 的 intersection。取

$$A=\begin{pmatrix}1&1\\1&1.05\end{pmatrix},\qquad b=\begin{pmatrix}2\\2.05\end{pmatrix},\qquad\text{solution }x=\begin{pmatrix}1\\1\end{pmatrix}$$

两条 line 几乎 parallel。先算 condition number，用 ∞-norm：

$$A^{-1}=\frac{1}{0.05}\begin{pmatrix}1.05&-1\\-1&1\end{pmatrix}=\begin{pmatrix}21&-20\\-20&20\end{pmatrix},\qquad\kappa_\infty=\|A\|_\infty\,\|A^{-1}\|_\infty=2.05\times41\approx84$$

$A$ 的 entry 都是 1 左右，$A^{-1}$ 的 entry 却是 20 左右，condition number 大就大在这里。用 2-norm 算，singular value 是 2.025 和 0.0247，$\kappa_2\approx82$。两种 norm 给出的数不同，量级相同。

::fig[dsa2102-cond] 左边是 condition number 接近 1 的情形，右边是上面这个 $A$。把第二个 equation 的 right-hand side 从 2.05 改成 2.08，第二条 line 平移了一点点，intersection 却沿着两条 line 的方向滑出很远。

把右图里的数算出来。Right-hand side 改成 $(2,\,2.08)$ 后，两式相减得 $0.05\,x_2=0.08$，所以 $x_2=1.6$，$x_1=0.4$。

$$\frac{\|\delta b\|_\infty}{\|b\|_\infty}=\frac{0.03}{2.05}\approx1.5\%,\qquad\frac{\|\delta x\|_\infty}{\|x\|_\infty}=\frac{0.6}{1}=60\%$$

放大了 41 倍，在 84 这个 upper bound 之内。

:::wrong 把 solution 代回去，residual 很小，所以 solution 是准的
Residual $r=b-A\hat x$ 衡量的是 equation 被满足得多好。因为 $b=Ax$，有 $r=A(x-\hat x)$，所以它和 error 之间差着一个 $A^{-1}$：

$$\hat x-x=-A^{-1}r\qquad\Longrightarrow\qquad\frac{\|\hat x-x\|}{\|x\|}\le\kappa(A)\,\frac{\|r\|}{\|b\|}$$

这和上面是同一个 inequality，只是把 $\delta b$ 换成了 $r$。看刚才的数：把 $\hat x=(0.4,\,1.6)$ 代回原来的 system，residual 是 $(0,\,-0.03)$，只有 right-hand side 的 1.5%，可它离 exact solution $(1,1)$ 差了 60%。Stable 的 algorithm 能保证 residual 小；只有 condition number 也小的时候，才能进一步保证 solution 准。
:::

:::edge Determinant 小不等于 ill-conditioned
$0.1\,I$（$100\times100$）的 determinant 是 $10^{-100}$，但它把 circle 变成一个小一点的 circle，condition number 是 1。Determinant 会随整体 scale 而变，ellipse 的扁平程度不会。判断 ill-conditioned 只看 condition number。
:::

### Iterative method：有一个不够好的 inverse 也行

Elimination 要 $n^3$ 量级的 operation，而且会把 sparse matrix 里的零填满。$n$ 到了百万量级、每个 row 只有几个 nonzero entry 时，elimination 做不动。换一个问法：如果手头有一个容易求 inverse、又和 $A$ 差不太多的 matrix $M$，能不能用它凑出 solution？

可以。对当前的猜测 $x^{(k)}$，residual $b-Ax^{(k)}$ 说明了还差多少。如果有真正的 $A^{-1}$，乘上去一步就能补齐；手头只有 $M^{-1}$，那就用它补，补不齐就再来一次：

$$x^{(k+1)}=x^{(k)}+M^{-1}\big(b-Ax^{(k)}\big)$$

最简单的选择是让 $M$ 只取 $A$ 的 diagonal $D$，这叫 **Jacobi iteration**。把上式按 component 写开，$x_i$ 那两个 term 正好消掉，剩下

$$x_i^{(k+1)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{j\ne i}a_{ij}\,x_j^{(k)}\Big)$$

读法很直接：用第 $i$ 个 equation 解出 $x_i$，其他 unknown 先用上一轮的值顶着。

**Gauss–Seidel iteration**只改一处：算 $x_i$ 时，前面 $x_1,\dots,x_{i-1}$ 这一轮的新值已经有了，就用新的。对应的 $M$ 是 $A$ 的 diagonal 连同 lower triangular 部分。

用一个小例子把两种方法都走几步：

$$\begin{aligned}4x_1+x_2&=1\\x_1+3x_2&=2\end{aligned}\qquad\text{exact solution }x=\big(\tfrac1{11},\tfrac7{11}\big)\approx(0.0909,\ 0.6364)$$

Jacobi 是 $x_1\leftarrow(1-x_2)/4$、$x_2\leftarrow(2-x_1)/3$，两个式子右边都用旧值；Gauss–Seidel 的第二个式子用刚算出的 $x_1$。都从 $(0,0)$ 出发：

| 轮数 | Jacobi | error | Gauss–Seidel | error |
|---|---|---|---|---|
| 1 | $(0.2500,\ 0.6667)$ | 0.159 | $(0.2500,\ 0.5833)$ | 0.159 |
| 2 | $(0.0833,\ 0.5833)$ | 0.053 | $(0.1042,\ 0.6319)$ | 0.0133 |
| 3 | $(0.1042,\ 0.6389)$ | 0.0133 | $(0.0920,\ 0.6360)$ | 0.0011 |
| 4 | $(0.0903,\ 0.6319)$ | 0.0044 | $(0.0910,\ 0.6363)$ | 0.00009 |

（error 取两个 component 里偏得多的那个。）两种都在 converge，Gauss–Seidel 的一轮相当于 Jacobi 的两轮。

::fig[dsa2102-jacobi] 同一张表画在 $(x_1,x_2)$ plane 里，两种方法同步各走 4 轮。看点怎么移动：Gauss–Seidel 每轮先横走到 line ①、再竖走到 line ②；Jacobi 一步斜着跳，绕着交点（solution）来回。下方读数与表中数字一致。

### 它为什么 converge，有多快

Exact solution $x$ 的 residual 是 0，所以它满足 $x=x+M^{-1}(b-Ax)$。拿 iteration formula 减去这个式子，error $e^{(k)}=x^{(k)}-x$ 满足

$$e^{(k+1)}=e^{(k)}-M^{-1}A\,e^{(k)}=\underbrace{\big(I-M^{-1}A\big)}_{G}\,e^{(k)}$$

每一轮 error 被乘上同一个 matrix $G$，$k$ 轮之后是 $G^k e^{(0)}$。$M$ 越像 $A$，$G$ 越接近 zero matrix。

对上面的例子，Jacobi 的 $G$ 是

$$G=I-D^{-1}A=\begin{pmatrix}0&-\tfrac14\\-\tfrac13&0\end{pmatrix}$$

要知道 $G^k$ 会不会趋于零，看 $G$ 的 eigenvalue。把初始 error 按 $G$ 的 eigenvector expand，每乘一次 $G$，各个 component 各自乘上对应的 eigenvalue $\lambda_i$（第 5 站会细讲这个 expansion），所以 $G^k e^{(0)}\to0$ 当且仅当所有 $|\lambda_i|<1$。其中最大的 $|\lambda_i|$ 叫 spectral radius $\rho(G)$，它就是长期来看每一轮 error 缩小的倍数。

这个 $G$ 的 eigenvalue 满足 $\lambda^2=\tfrac1{12}$，$\rho=0.289$，两轮缩小到 $\tfrac1{12}$。表里 Jacobi 的 error 从第 1 轮的 0.159 到第 3 轮的 0.0133，正是 $\tfrac1{12}$。Gauss–Seidel 的 $G$ 的 eigenvalue 是 0 和 $\tfrac1{12}$，所以它每一轮就缩小到 $\tfrac1{12}$。

不必每次都去算 eigenvalue。如果 $A$ 每个 row 的 diagonal entry，absolute value 都大于同一个 row 其余 entry 的 absolute value 之和，就说 $A$ strictly diagonally dominant，这时 Jacobi 一定 converge。理由只要一行：Jacobi 的 $G$ 在 row $i$ 的 entry 是 $-a_{ij}/a_{ii}$（$j\ne i$），diagonally dominant 正好是说每个 row 的 absolute row sum 小于 1，即 $\|G\|_\infty<1$，于是

$$\|e^{(k+1)}\|_\infty\le\|G\|_\infty\,\|e^{(k)}\|_\infty$$

每一轮 error 都严格变小。例子里 $\|G\|_\infty=\tfrac13$，表中 Jacobi 的 error 每一轮至少缩小到三分之一。

另外两条常用的结论这里只给出，不证：$A$ strictly diagonally dominant 时 Gauss–Seidel 也 converge；$A$ 是 SPD 时 Gauss–Seidel converge。

:::back
“error 被反复乘上同一个 matrix，最后由 absolute value 最大的 eigenvalue 说了算”，就是[第 5 站](#eig)的 power iteration，只不过那里是故意利用它。
:::

## [ls] Least squares 与 QR

:::skip
能把“fit 一条 line”的图和“向 column space 做 projection”的图对上，由后者写出 normal equations；能说出为什么实际计算宁愿做 QR 也不直接解 normal equations，就可以去第 5 站。
:::

### 一个没有 solution 的 system

三个 data point $(1,1)$、$(2,2)$、$(3,2)$，想用一条 line $b=C+Dt$ 穿过它们。每个点给一个 equation：

$$\begin{aligned}C+D&=1\\C+2D&=2\\C+3D&=2\end{aligned}\qquad\text{即}\qquad\underbrace{\begin{pmatrix}1&1\\1&2\\1&3\end{pmatrix}}_{A}\begin{pmatrix}C\\D\end{pmatrix}=\underbrace{\begin{pmatrix}1\\2\\2\end{pmatrix}}_{b}$$

三个 equation，两个 unknown，三个点不 collinear，所以没有 solution。Data 多于 parameter 时总是这样。既然不能让三个 equation 都成立，就退一步，让它们“总体上最接近成立”：找 $C$、$D$ 使三个 error 的 sum of squares 最小。

::fig[dsa2102-fit3] 第一张图，在 data 所在的 plane 里看。Error 是每个点到 line 的 vertical distance。

### 换一个空间看同一个问题

把三个 error 并成一个 vector $e=b-Ax$。要最小化的 sum of squares 就是 $\|e\|^2$，也就是 $Ax$ 和 $b$ 之间的距离。现在不在 data plane 里看，改在三维空间里看 $b$ 这个 vector。

$x$ 取遍所有可能的 $(C,D)$ 时，$Ax=C\,(1,1,1)^\top+D\,(1,2,3)^\top$ 扫过的是由 $A$ 的两个 column span 的一个 plane，叫 $A$ 的 column space。这个 system 没有 solution，意思是 $b$ 不在这个 plane 上。问题变成：plane 上哪个点离 $b$ 最近？

::fig[dsa2102-proj] 第二张图，在 $b$ 所在的空间里看。Plane 上离 $b$ 最近的点是 $b$ 的 projection $p=A\hat x$，此时 error vector $e=b-A\hat x$ 与 plane perpendicular。

答案是 $b$ 在 plane 上的 projection，它的特征是：$b$ 到它的连线与 plane perpendicular。与 plane perpendicular 就是与 span 这个 plane 的每个 column 都 perpendicular，即 $A$ 的每个 column 与 $e$ 的 inner product 为 0。把这几个 inner product 并在一起写，就是 $A^\top(b-A\hat x)=0$，即

$$A^\top A\,\hat x=A^\top b$$

这叫 normal equations。对上面的例子：

$$A^\top A=\begin{pmatrix}3&6\\6&14\end{pmatrix},\quad A^\top b=\begin{pmatrix}5\\11\end{pmatrix},\qquad\text{即}\qquad\begin{aligned}3C+6D&=5\\6C+14D&=11\end{aligned}$$

第二式减去 2 倍的第一式得 $2D=1$，所以 $D=\tfrac12$，$C=\tfrac23$。最佳 line 是 $b=\tfrac23+\tfrac12t$。

它在三个点上的值是 $\tfrac76,\tfrac53,\tfrac{13}6$，所以 error 是 $e=(-\tfrac16,\tfrac13,-\tfrac16)$。可以验证它和 $A$ 的两个 column 都 perpendicular：component 之和为 0，与 $(1,2,3)$ 的 inner product 也为 0。两张图说的是同一件事：第一张图里的三段竖直的 segment，就是第二张图里那个 perpendicular 于 plane 的 vector 的三个 component。

### 为什么偏偏是 square

从第二张图能看出 square 的作用。用 sum of squares 量距离，“最近”才等价于“perpendicular”，而 perpendicular 是一个 linear condition，于是得到一个 linear system，可以用前两站的办法解。如果改成让 error 的 absolute value 之和最小，或者让最大的 error 最小，问题仍然有意义，但不再有“perpendicular”可用，solution 不再由一个 linear system 给出。

Square 也有代价：error 被 square 之后，一个离得很远的 outlier 会主导整个 fit。Data 里有明显的坏点时，least squares 不是好选择。

还有一个细节：normal equations 一定有 unique solution 吗？只要 $A$ 的各个 column linearly independent 就有。理由是，若 $A^\top Ax=0$，左乘 $x^\top$ 得 $x^\top A^\top Ax=\|Ax\|^2=0$，所以 $Ax=0$，而 column linearly independent 意味着只有 $x=0$。

### Normal equations 在机器上的问题

到这里，数学上的事情做完了。现在回到开头的第三次事故。

:::wrong Normal equations 最直接，解它就行了
取 $[0,1]$ 上的 50 个点，fit degree-11 polynomial，data 由“coefficient 全是 1”的 polynomial 生成，所以正确答案已知。在 double precision 下实际算一遍：

| algorithm | 算出的 coefficient 与 1 的最大偏差 |
|---|---|
| 形成 $A^\top A$，解 normal equations | $2.3\times10^{-1}$ |
| 对 $A$ 做 QR factorization | $1.6\times10^{-8}$ |

同一个问题，同一台机器，差了七个 orders of magnitude。这个 $A$ 的 condition number 是 $1.2\times10^{8}$，而 $A^\top A$ 的 condition number 是 $1.4\times10^{16}$，正好是它的 square。按第 3 站的估计，error 大约是 $\kappa\,\varepsilon$：$10^{16}\times10^{-16}$，一位都剩不下；$10^{8}\times10^{-16}=10^{-8}$，正是表里第二行的数。
:::

Condition number 为什么会被 square？回到第 3 站的 ellipse。$A$ 把方向 $v_i$ 拉长 $\sigma_i$ 倍；$A^\top A$ 把同一个方向拉长 $\sigma_i^2$ 倍（第 5 站给出这一步的推导）。Ellipse 的 semi-axis 从 $\sigma_i$ 变成 $\sigma_i^2$，扁平程度从 $\sigma_1/\sigma_n$ 变成它的 square。原来的 least squares 问题只有 $\kappa(A)$ 那么敏感，形成 $A^\top A$ 这一步凭空造出了一个敏感得多的问题。按第 1 站的说法，这是 algorithm 的问题，可以治。

### 治法：换一组 perpendicular 的 column

Normal equations 里碍事的是 $A^\top A$。什么时候它不碍事？当各个 column 互相 perpendicular 且 length 为 1 时。把这样的 matrix 记作 $Q$，那么 $Q^\top Q=I$，normal equations 直接给出 $\hat x=Q^\top b$，什么都不用解。

一般的 $A$ 没有这么好的 column，但可以换。Column space 是一个 plane，span 它的 vector 可以随便挑；把 $A$ 的 column 换成同一个 plane 里一组互相 perpendicular 的 unit vector，projection 不变，计算变得容易。换的办法叫 **Gram–Schmidt**：逐个 column 来，从当前 column 里减去它在已有各个方向上的 component，剩下的部分就与它们都 perpendicular，再 scale 成 unit length。

对例子里的两个 column $a_1=(1,1,1)^\top$、$a_2=(1,2,3)^\top$ 做一遍。

Column 1 只需要 scale：$\|a_1\|=\sqrt3$，$q_1=\tfrac{1}{\sqrt3}(1,1,1)^\top$。

Column 2 在 $q_1$ 方向上的 component 是 $(q_1^\top a_2)\,q_1$。Inner product $q_1^\top a_2=\tfrac{6}{\sqrt3}=2\sqrt3$，所以这个 component 是 $2\sqrt3\,q_1=(2,2,2)^\top$。减掉它：

$$a_2-(2,2,2)^\top=(-1,0,1)^\top$$

它和 $(1,1,1)$ 的 inner product 是 0，确实 perpendicular。Length 是 $\sqrt2$，所以 $q_2=\tfrac{1}{\sqrt2}(-1,0,1)^\top$。

::fig[dsa2102-gs] 两个 column 张成的 plane 就是 column space，Gram–Schmidt 的两步都在这个 plane 里。

把刚才的两步倒过来读，就是用新的 column 表示旧的 column：

$$a_1=\sqrt3\,q_1,\qquad a_2=2\sqrt3\,q_1+\sqrt2\,q_2$$

写成 matrix：

$$\underbrace{\begin{pmatrix}1&1\\1&2\\1&3\end{pmatrix}}_{A}=\underbrace{\begin{pmatrix}\tfrac1{\sqrt3}&-\tfrac1{\sqrt2}\\[4pt]\tfrac1{\sqrt3}&0\\[4pt]\tfrac1{\sqrt3}&\tfrac1{\sqrt2}\end{pmatrix}}_{Q}\underbrace{\begin{pmatrix}\sqrt3&2\sqrt3\\0&\sqrt2\end{pmatrix}}_{R}$$

$R$ 是 upper triangular 的，因为 $A$ 的 column $j$ 只用到前 $j$ 个 $q$。$R$ 里记的是过程中出现的 length 和 inner product，和 $L$ 里记 multiplier 是一个道理。

### 用 QR 解 least squares

把 $b$ 分成两部分：落在 column space 里的 $QQ^\top b$，和剩下的 $b-QQ^\top b$。后者与每个 $q$ 都 perpendicular（左乘 $Q^\top$ 得 $Q^\top b-Q^\top b=0$）。于是

$$Ax-b=\underbrace{Q\,(Rx-Q^\top b)}_{\text{在 column space 里}}\ -\ \underbrace{(b-QQ^\top b)}_{\text{perpendicular to column space}}$$

两部分互相 perpendicular，按 Pythagorean theorem length 的 square 相加；$Q$ 的 column 是 perpendicular 的 unit vector，所以 $\|Qy\|=\|y\|$：

$$\|Ax-b\|^2=\|Rx-Q^\top b\|^2+\|b-QQ^\top b\|^2$$

$x$ 只出现在第一个 term 里，而第一个 term 可以做到恰好为 0：

$$R\,\hat x=Q^\top b$$

这是一个 triangular system，back substitution 即可。第二个 term 和 $x$ 无关，它就是最小的 residual sum of squares。

对例子算一遍。$Q^\top b$ 的两个 component 是 $q_1^\top b=\tfrac{5}{\sqrt3}$ 和 $q_2^\top b=\tfrac{1}{\sqrt2}$，system 是

$$\begin{pmatrix}\sqrt3&2\sqrt3\\0&\sqrt2\end{pmatrix}\begin{pmatrix}C\\D\end{pmatrix}=\begin{pmatrix}5/\sqrt3\\1/\sqrt2\end{pmatrix}$$

从下往上：$\sqrt2\,D=\tfrac1{\sqrt2}$ 得 $D=\tfrac12$；$\sqrt3\,C+\sqrt3=\tfrac5{\sqrt3}$ 得 $C=\tfrac23$。和 normal equations 的答案相同。最小 residual 也能直接读出来：$\|b\|^2-\|Q^\top b\|^2=9-\big(\tfrac{25}3+\tfrac12\big)=\tfrac16$，正是前面 $e=(-\tfrac16,\tfrac13,-\tfrac16)$ 的 length 的 square。

整个过程没有形成 $A^\top A$。要解的 system 的 matrix 是 $R$，而 $A=QR$ 里的 $Q$ 不改变 length，所以 $R$ 把 circle 变成的 ellipse 和 $A$ 的一样扁：$\kappa(R)=\kappa(A)$，condition number 没有被 square。

### 更稳的办法：Householder reflection

Gram–Schmidt 直观，但有一个弱点：两个 column 接近 parallel 时，“减去 component”是两个相近的 vector 相减，又是第 1 站的 cancellation，算出的 $q$ 会不够 perpendicular。

Householder 的办法把方向倒过来。Gram–Schmidt 是对 $A$ 的 column 做 triangular 的操作，把它们变成 orthogonal 的；Householder 是对 $A$ 做 orthogonal 的操作，把它变成 triangular 的。和 elimination 一样逐个 column 地在 diagonal 下方造零，只是每一步乘的不是 elimination matrix，而是一个 reflection。

要把一个 vector $x$ 除第一个以外的 component 全部变成 0，又不改变 length，目标只能是 $\pm\|x\|e_1$。Reflection 只改变 perpendicular 于 mirror 的那个 component，所以 $x$ 和它的 image 之差就是 mirror 的 normal：

$$v=x-(\pm\|x\|e_1)$$

::fig[dsa2102-householder] Mirror 取在 $x$ 与目标的 angle bisector 上，normal $v$ 是两者之差。

$x$ 在 $v$ 方向上的 component 是 $\dfrac{v^\top x}{v^\top v}\,v$。减掉一次，落到 mirror 上；减掉两次，到达 mirror 另一侧：

$$Hx=x-2\,\frac{v^\top x}{v^\top v}\,v,\qquad\text{即}\qquad H=I-\frac{2\,vv^\top}{v^\top v}$$

最小的例子：$x=(3,4)^\top$，$\|x\|=5$，目标取 $(-5,0)^\top$，于是 $v=(8,4)^\top$。$v^\top x=40$，$v^\top v=80$，

$$Hx=\begin{pmatrix}3\\4\end{pmatrix}-2\cdot\frac{40}{80}\begin{pmatrix}8\\4\end{pmatrix}=\begin{pmatrix}-5\\0\end{pmatrix}$$

计算时用的是 $v$，不需要把 $H$ 这个 matrix 写出来。

对一个 matrix：第一个 reflection 由 $A$ 的 column 1 决定，作用到所有 column 上，column 1 变成 $(\pm\|a_1\|,0,\dots,0)^\top$；第二个 reflection 只动 row 2 及以下，把 column 2 在 diagonal 下方的 entry 清零；如此下去，$n$ 步之后 $A$ 变成 upper triangular 的 $R$。解 least squares 时，把同样的 reflection 依次作用在 $b$ 上，得到的就是 $Q^\top b$，然后 back substitution。

每一步乘的都是 orthogonal matrix，length 不变，error 不会被放大，所以 Householder 是 backward stable 的，是软件里求 QR 的标准做法。

:::edge Householder 的 sign 要选对
目标取 $+\|x\|e_1$ 还是 $-\|x\|e_1$ 都能把 $x$ reflect 到 coordinate axis 上。但 $x$ 本来就几乎沿着 $e_1$ 时，取 + 号意味着 $v=x-\|x\|e_1$ 是两个几乎相等的 vector 相减，正是 cancellation。所以总取让 $v$ 的第一个 component 做加法的那个：$v=x+\mathrm{sign}(x_1)\|x\|e_1$。上面的例子取的就是它；图里为了看得清，画的是另一个 sign。
:::

:::edge 不是 full column rank，或者接近 rank-deficient
各个 column linearly dependent 时，projection 仍然唯一，但能得到它的 $x$ 有无穷多个，$A^\top A$ 不 invertible，$R$ 的 diagonal 上出现 0，上面两种办法都走不通。这时要在 infinitely many solutions 里指定一个，通常取 length 最小的。怎么取、column“几乎 dependent”时又该怎么办，要用到 singular value，放在[第 5 站](#eig)讲完 SVD 之后。
:::

:::back
Normal equations 的 matrix 是 SPD，一定要解它时用[第 2 站](#lu)的 Cholesky。Condition number 被 square 的解释用了[第 3 站](#cond)的 ellipse。跨课程的脉络见概念线[“least squares”](../threads/least-squares.html)。
:::

## [eig] Eigenvalue 问题与 SVD

:::skip
能说出 power iteration 为什么 converge、inverse iteration 为什么只是“换了一个 matrix 做 power iteration”，以及一般 matrix 为什么需要两组 orthonormal 的 basis 才能 diagonalize，就可以去第 6 站。
:::

### 哪些 vector 出来时方向没变

把 $A$ 乘到一个 vector 上，一般会既改变 length 又改变方向。问一个简单的问题：有没有哪些 vector，乘完之后方向没变，只是被 scale 了？

$$Av=\lambda v$$

这样的 $v$ 叫 eigenvector，scale 的倍数 $\lambda$ 叫 eigenvalue。很多时候不用算，从 matrix 的作用就能直接看出来：

- **Projection 到一个 plane 上。** Plane 里的 vector 做 projection 后不变，$\lambda=1$；perpendicular 于 plane 的 vector 被送到 0，$\lambda=0$。
- **Permutation：交换两个 component。** $(1,1)$ 交换后不变，$\lambda=1$；$(1,-1)$ 交换后变成自己的 negative，$\lambda=-1$。
- **Rotation 90°。** 没有任何 real vector 转完之后还在原来的方向上，所以它没有 real eigenvalue，eigenvalue 是 $\pm i$。Real matrix 也可能有 complex eigenvalue。

这一站反复用的例子是

$$A=\begin{pmatrix}2&1\\1&2\end{pmatrix}:\qquad A\begin{pmatrix}1\\1\end{pmatrix}=3\begin{pmatrix}1\\1\end{pmatrix},\qquad A\begin{pmatrix}1\\-1\end{pmatrix}=1\cdot\begin{pmatrix}1\\-1\end{pmatrix}$$

两条随手可用的事实可以拿它核对：eigenvalue 之和等于 diagonal entry 之和（叫 trace，$3+1=2+2$），eigenvalue 之积等于 determinant（$3\times1=4-1$）。另外，把 $A$ 换成 $A+cI$，每个 eigenvalue 加上 $c$，eigenvector 不变，因为 $(A+cI)v=\lambda v+cv$。

### 为什么关心它们

因为在 eigenvector 的方向上，matrix 表现得就像一个数。这在需要把 $A$ 反复作用的时候最有用。如果 $A$ 有 $n$ 个 linearly independent 的 eigenvector，任意 vector 都能按它们 expand，$x=c_1v_1+\dots+c_nv_n$，那么

$$A^kx=c_1\lambda_1^kv_1+c_2\lambda_2^kv_2+\cdots+c_n\lambda_n^kv_n$$

Matrix 的 $k$-th power 本来是很难看清的东西，现在变成了 $n$ 个数各自的 $k$-th power。任何“把同一个 linear operation 重复很多遍”的过程，长期行为都由 eigenvalue 决定。第 3 站的 iterative method 会不会 converge、Markov chain 最后停在哪、一个振动系统 stable 不 stable，都是这个式子。

### 怎么算：不能走 characteristic polynomial

:::wrong 求 eigenvalue 就是解 $\det(A-\lambda I)=0$
手算 2×2、3×3 时是这样。Matrix 一大，这条路有两处走不通。

第一，degree 5 以上的 polynomial equation 没有 root 的通用 formula。求 eigenvalue 等价于求 polynomial 的 root，所以任何 eigenvalue algorithm 都不可能在有限步内给出 exact answer，必然是 iterative 的。

第二，polynomial 的 root 对 coefficient 极其敏感。先算出 characteristic polynomial 的 coefficient 再求 root，是把一个不敏感的问题绕到一个敏感的问题上去，和第 1 站的 cancellation、第 4 站的 normal equations 是同一类错误。

实际的 algorithm 都直接对 matrix 做 iteration，从不经过 characteristic polynomial。
:::

### Power iteration

把上面那个 expansion 倒过来用。设 $|\lambda_1|$ 严格最大。随便取一个 vector 反复乘 $A$，每个 term 各自放大 $\lambda_i^k$ 倍，$\lambda_1$ 那个 term 长得最快，最终压倒其他所有 term，vector 的方向就转到了 $v_1$ 上。

对上面的 $A$，从 $x=(1,0)^\top$ 出发。按 eigenvector expand，$x=\tfrac12(1,1)^\top+\tfrac12(1,-1)^\top$，所以

$$A^kx=\tfrac12\cdot3^k\begin{pmatrix}1\\1\end{pmatrix}+\tfrac12\cdot1^k\begin{pmatrix}1\\-1\end{pmatrix}$$

| $k$ | $A^kx$ | 两个 component 之比 | $\dfrac{x^\top Ax}{x^\top x}$ |
|---|---|---|---|
| 0 | $(1,\ 0)$ | | 2 |
| 1 | $(2,\ 1)$ | 2 | 2.8 |
| 2 | $(5,\ 4)$ | 1.25 | 2.976 |
| 3 | $(14,\ 13)$ | 1.077 | 2.9973 |
| 4 | $(41,\ 40)$ | 1.025 | 2.9997 |

::fig[dsa2102-power] 同一个过程画出来。每一帧把当前方向拆成沿 $v_1=(1,1)$ 的部分（粗黑线）和沿 $(1,-1)$ 的部分（蓝虚线）：看蓝虚线每乘一次 $A$ 相对缩短到三分之一，vector 随之转向 $v_1$。

第二个 term 相对于第一个 term，每一步缩小 $|\lambda_2/\lambda_1|=\tfrac13$：表里“component 之比”与 1 的差是 $1,\ \tfrac14,\ \tfrac1{13},\ \tfrac1{40}$，大约每步除以 3。这就是 convergence rate：最大的两个 eigenvalue 离得越开越快，几乎相等时会很慢。实际计算时每乘一次要把 vector scale 到 unit length，免得数值 overflow，方向不受影响。

方向有了，eigenvalue 怎么读？对一个 approximate 的 eigenvector $x$，找一个数 $\lambda$ 让 $Ax\approx\lambda x$ 尽量成立。这是只有一个 unknown 的 least squares 问题，它的 normal equation 是 $x^\top x\,\lambda=x^\top Ax$，所以

$$\lambda\approx\frac{x^\top Ax}{x^\top x}$$

叫 Rayleigh quotient，就是表的最后一个 column。它与 3 的差是 $0.2,\ 0.024,\ 0.0027$，每步缩小到 $\tfrac19$：symmetric matrix 的 Rayleigh quotient 比方向本身 converge 得快一倍。

### 想要别的 eigenvalue：换一个 matrix 做 power iteration

Power iteration 只能找到 absolute value 最大的那个。要找别的，不必发明新 algorithm，只要造一个新 matrix，让想要的那个 eigenvalue 在新 matrix 里变成最大的。

$A-\mu I$ 的 eigenvalue 是 $\lambda_i-\mu$；再取 inverse，eigenvalue 是 $\dfrac{1}{\lambda_i-\mu}$，eigenvector 始终没变。哪个 $\lambda_i$ 离 $\mu$ 最近，它对应的 $\dfrac1{\lambda_i-\mu}$ 就最大。所以对 $(A-\mu I)^{-1}$ 做 power iteration，converge 到离 $\mu$ 最近的 eigenvalue。这叫 **inverse iteration**。

还是上面的 $A$，取 $\mu=0.9$。$(A-0.9I)^{-1}$ 的两个 eigenvalue 是 $\tfrac{1}{3-0.9}=0.48$ 和 $\tfrac{1}{1-0.9}=10$，每步的缩小倍数是 $0.048$，而不是 $\tfrac13$。从 $(1,0)$ 出发，三步的 Rayleigh quotient 是 $1.0045,\ 1.00001,\ 1.00000002$。$\mu$ 猜得越准，那个 reciprocal 越突出，converge 越快。

每一步“乘 $(A-\mu I)^{-1}$”按第 2 站的规矩读成解一个 system：对 $A-\mu I$ 做一次 LU，之后每步只做 forward 和 back substitution。

### 一次求出全部：QR algorithm

要所有 eigenvalue 时，标准 algorithm 出奇地简单。把 matrix factor 成 $QR$，再把两个 factor 倒过来乘，反复做：

$$A_k=Q_kR_k,\qquad A_{k+1}=R_kQ_k$$

对上面的 $A$ 实际做四步：

$$\begin{pmatrix}2&1\\1&2\end{pmatrix}\to\begin{pmatrix}2.8&0.6\\0.6&1.2\end{pmatrix}\to\begin{pmatrix}2.976&0.220\\0.220&1.024\end{pmatrix}\to\begin{pmatrix}2.9973&0.074\\0.074&1.0027\end{pmatrix}\to\begin{pmatrix}2.9997&0.025\\0.025&1.0003\end{pmatrix}$$

Diagonal 以外的 entry 每步缩小到三分之一，diagonal 趋向 3 和 1。有两件事要解释。

**为什么 eigenvalue 没变。** 由 $A_k=Q_kR_k$ 得 $R_k=Q_k^\top A_k$，所以 $A_{k+1}=Q_k^\top A_kQ_k$。如果 $A_kv=\lambda v$，那么 $A_{k+1}(Q_k^\top v)=Q_k^\top A_kv=\lambda\,(Q_k^\top v)$：同一个 $\lambda$，只是 eigenvector 换了 coordinate。这样的两个 matrix 叫 similar。

**为什么会变成 diagonal 的。** 左上角依次出现的 $2.8,\ 2.976,\ 2.9973,\ 2.9997$，和上一张表的 Rayleigh quotient 一模一样。这不是巧合。$A=Q_1R_1$ 且 $R_1$ 是 upper triangular，所以 $Q_1$ 的 column 1 就是 $A$ 的 column 1 除以 length，也就是 $Ae_1$ 的方向 $(2,1)$：从 $e_1=(1,0)$ 出发做了一步 power iteration。再往下，

$$A^2=Q_1(R_1Q_1)R_1=Q_1(Q_2R_2)R_1=(Q_1Q_2)(R_2R_1)$$

右边是 $A^2$ 的 QR factorization，所以 $Q_1Q_2$ 的 column 1 是 $A^2e_1$ 的方向 $(5,4)$。QR algorithm 的 column 1 一直在做 power iteration；其余各个 column 也在做，只是每一步都被 QR factorization 拉回到与前面的 column perpendicular，所以不会全都倒向 $v_1$，而是各自 converge 到其余的 eigenvector。而 $A_{k+1}=(Q_1\cdots Q_k)^\top A\,(Q_1\cdots Q_k)$ 是 $A$ 在这组 basis 下的样子，basis 越接近 eigenvector，它越接近 diagonal（一般的非 symmetric matrix 是接近 upper triangular），diagonal 上就是 eigenvalue。

软件里的 QR algorithm 多做两件事。先用 orthogonal transformation 把 matrix 化成“upper triangular 再多一条 subdiagonal”的形状（Hessenberg 形），这样每一步 QR factorization 的代价从 $n^3$ 降到 $n^2$；再加上 shift，即对 $A_k-\mu I$ 做上面的一步、之后把 $\mu I$ 加回来，道理和 inverse iteration 相同，converge 快得多。

### SVD：eigenvector 不够用的时候

Symmetric matrix 的 eigenvector 互相 perpendicular（上面的 $(1,1)$ 和 $(1,-1)$），可以用一个 orthogonal matrix diagonalize，$A=Q\Lambda Q^\top$，这是最理想的情形。一般的 matrix 做不到：eigenvector 通常不 perpendicular，可能是 complex 的，可能不够 $n$ 个；rectangular 的 matrix 干脆没有 eigenvalue。

问题出在 eigenvector 要求得太多：它要求 input 和 output 用同一组 basis。如果允许 input 用一组 orthonormal 的 basis、output 用另一组，那么任何 matrix 都能 diagonalize：

$$Av_i=\sigma_iu_i,\qquad\text{合起来就是}\qquad A=U\Sigma V^\top$$

$v_i$ 是 input 空间里一组互相 perpendicular 的 unit vector，$u_i$ 是 output 空间里的一组，$\sigma_1\ge\sigma_2\ge\dots\ge0$ 叫 singular value。

第 3 站那张图现在可以说清了。Circle 上的任意一点写成 $x=c_1v_1+c_2v_2$，$c_1^2+c_2^2=1$。乘上 $A$：

$$Ax=c_1\sigma_1u_1+c_2\sigma_2u_2$$

在 $u_1,u_2$ 这组 perpendicular 的 coordinate axis 下，image 的 coordinate 是 $(y_1,y_2)=(c_1\sigma_1,\ c_2\sigma_2)$，满足 $\big(\tfrac{y_1}{\sigma_1}\big)^2+\big(\tfrac{y_2}{\sigma_2}\big)^2=1$。这是一个 semi-axis 为 $\sigma_1$、$\sigma_2$ 的 ellipse。SVD 说的就是：这样一对 perpendicular 的 $v_1,v_2$ 总是存在。

怎么找它们？把 $A=U\Sigma V^\top$ 代进 $A^\top A$，中间的 $U^\top U=I$ 消掉：

$$A^\top A=V\Sigma^\top U^\top U\Sigma V^\top=V\,\Sigma^2\,V^\top$$

右边是 symmetric matrix $A^\top A$ 的 diagonalization。所以 $v_i$ 是 $A^\top A$ 的 eigenvector，$\sigma_i^2$ 是它的 eigenvalue。（这也是第 4 站“$A^\top A$ 把 $v_i$ 拉长 $\sigma_i^2$ 倍”的出处。）看 18.06 第 29 讲的例子：

$$A=\begin{pmatrix}4&4\\-3&3\end{pmatrix},\qquad A^\top A=\begin{pmatrix}25&7\\7&25\end{pmatrix}$$

$A^\top A$ 和这一站的例子是同一种形状，eigenvector 仍是 $(1,1)$ 和 $(1,-1)$，eigenvalue 是 $25+7=32$ 和 $25-7=18$。所以

$$v_1=\tfrac1{\sqrt2}\begin{pmatrix}1\\1\end{pmatrix},\quad\sigma_1=\sqrt{32};\qquad v_2=\tfrac1{\sqrt2}\begin{pmatrix}1\\-1\end{pmatrix},\quad\sigma_2=\sqrt{18}$$

然后由定义 $u_i=Av_i/\sigma_i$：

$$Av_1=\tfrac1{\sqrt2}\begin{pmatrix}8\\0\end{pmatrix}\Rightarrow u_1=\begin{pmatrix}1\\0\end{pmatrix};\qquad Av_2=\tfrac1{\sqrt2}\begin{pmatrix}0\\-6\end{pmatrix}\Rightarrow u_2=\begin{pmatrix}0\\-1\end{pmatrix}$$

:::edge $U$ 不能另外单独求
$u_i$ 也是 $AA^\top$ 的 eigenvector，这个例子里 $AA^\top=\begin{pmatrix}32&0\\0&18\end{pmatrix}$ 恰好是 diagonal 的，一眼就能看出 eigenvector 是 $(1,0)$ 和 $(0,1)$。但 eigenvector 的 sign 是任意的，单独求出的 $(0,1)$ 和上面的 $u_2=(0,-1)$ 差一个 sign，乘回去得不到 $A$。$U$ 和 $V$ 的 sign 必须配套，稳妥的做法是只求 $V$，再用 $u_i=Av_i/\sigma_i$ 得到 $U$。
:::

:::edge 数值上不去形成 $A^\top A$
上面经过 $A^\top A$ 的 algorithm 是为了看清 SVD 是什么。实际计算时形成 $A^\top A$ 会把 condition number square，理由和[第 4 站](#ls)一模一样。软件里的做法是先用两侧的 orthogonal transformation 把 $A$ 化成只有两条 diagonal 的形状，再对它做类似 QR algorithm 的 iteration。
:::

### 最有用的一个结论

把 SVD 写成一个 term 一个 term 的和：

$$A=\sigma_1u_1v_1^\top+\sigma_2u_2v_2^\top+\cdots+\sigma_ru_rv_r^\top$$

每个 term 是一个 rank 为 1 的 matrix，按 $\sigma$ 从大到小排好了。只留前 $k$ 个 term 得到 $A_k$。Eckart–Young theorem 说：在所有 rank 不超过 $k$ 的 matrix 里，$A_k$ 离 $A$ 最近，距离（按 2-norm）正好是被丢掉的第一个 singular value $\sigma_{k+1}$。

对刚才的例子取 $k=1$：

$$A_1=\sqrt{32}\begin{pmatrix}1\\0\end{pmatrix}\tfrac1{\sqrt2}\begin{pmatrix}1&1\end{pmatrix}=\begin{pmatrix}4&4\\0&0\end{pmatrix},\qquad A-A_1=\begin{pmatrix}0&0\\-3&3\end{pmatrix}$$

剩下的那部分把 $(1,-1)/\sqrt2$ 拉长 $\sqrt{18}$ 倍，把 perpendicular 于它的方向送到 0，所以 $\|A-A_1\|_2=\sqrt{18}=\sigma_2$。Singular value 衰减得快时，前几个 term 就抓住了 matrix 的大部分内容。图像压缩、去噪、推荐系统里的 low-rank 模型用的都是这一条。

PCA 是它在 data 上的说法。把 data matrix 每个 column 减去 mean 得到 $X$（每个 row 是一个 sample，共 $n$ 个）。Data 在 unit vector $v$ 方向上的 variance 是 $\|Xv\|^2/(n-1)$。让它最大的 $v$，按 $\sigma_1$ 的定义（maximum stretch），就是 $X$ 的 $v_1$，variance 是 $\sigma_1^2/(n-1)$；在与 $v_1$ perpendicular 的方向里再找最大的，是 $v_2$；依此类推。所以 principal component 的方向就是 $X$ 的 right singular vector。

:::edge 回到第 4 站：rank-deficient 或接近 rank-deficient 时的 least squares
把 $x$ 按 $v_i$ expand，$x=\sum c_iv_i$，那么 $Ax=\sum c_i\sigma_iu_i$。要它离 $b$ 最近，就让它在每个 $u_i$ 方向上的 component 等于 $b$ 的 component：$c_i\sigma_i=u_i^\top b$。于是

$$\hat x=\sum_{\sigma_i\ne0}\frac{u_i^\top b}{\sigma_i}\,v_i$$

某个 $\sigma_i=0$ 时，对应的 $c_i$ 取什么都不影响 $Ax$，这就是“infinitely many solutions”的来源；取 $c_i=0$ 得到 length 最小的那个。上式对应的 matrix 叫 pseudoinverse，记作 $A^+$，$\hat x=A^+b$。

更常见的麻烦是某个 $\sigma_i$ 不为 0 但很小。这时 $1/\sigma_i$ 很大，$b$ 里那个方向上的一点 noise 被放大到淹没其他部分。Ridge regression 解的是 $(A^\top A+\delta I)\,\hat x=A^\top b$，用同样的 expansion 可以算出它把上式里的 $\dfrac{1}{\sigma_i}$ 换成了

$$\frac{\sigma_i}{\sigma_i^2+\delta}$$

$\sigma_i$ 远大于 $\sqrt\delta$ 时它几乎就是 $1/\sigma_i$，什么也没改；$\sigma_i$ 远小于 $\sqrt\delta$ 时它约等于 $\sigma_i/\delta$，趋于 0 而不是 infinity。$\delta$ 的作用就是把靠不住的方向压掉。让 $\delta\to0$，得到的正是 pseudoinverse 的 solution（18.065 第 9 讲）。
:::

:::back
Inverse iteration 每步解 system，靠的是[第 2 站](#lu)。$\|A\|_2=\sigma_1$、$\kappa_2(A)=\sigma_1/\sigma_n$，把[第 3 站](#cond)的 norm 和 condition number 接到了 SVD 上。
:::

:::from
“哪些 vector 出来时方向不变”的问法和 projection、permutation、rotation 三个例子来自 [18.06 第 21 讲](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-21-eigenvalues-and-eigenvectors/)；“input 空间的一组 orthonormal basis 送到 output 空间的一组 orthonormal basis”和 $\begin{pmatrix}4&4\\-3&3\end{pmatrix}$ 的例子来自 [18.06 第 29 讲](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-29-singular-value-decomposition/)；Hessenberg 形、QR iteration、shift 的顺序和 pseudoinverse 作为 $\delta\to0$ 的 limit 来自 18.065 [第 12 讲](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/resources/lecture-12-computing-eigenvalues-and-singular-values/)和[第 9 讲](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/resources/lecture-9-four-ways-to-solve-least-squares-problems/)的摘要。$\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 上的几张数表，以及“QR algorithm 的 column 1 在做 power iteration”的推导，是为这一页写的。

## [interp] Polynomial interpolation

:::skip
能从 error formula 解释为什么用 degree-10 polynomial 通过 11 个 equispaced 的点去 approximate 一个 smooth function 可能很糟，并说出两种补救办法各改了 formula 里的哪个 factor，就可以去第 7 站。
:::

### 为什么是 polynomial

计算机真正会做的只有加减乘除。只用这四种 operation 就能精确 evaluate 的 function，只有 polynomial 和它们的商。$\sin$、$\exp$、一个 integral、一个 differential equation 的 solution，最终都要在某个环节被换成 polynomial。Interpolation 是做这种替换最直接的办法：只知道 function 在几个点（叫 node）上的值，找一个 polynomial 恰好通过这些点，然后拿它代替原来的 function 去 evaluate、differentiate、integrate。下一站的所有 formula 都是这样来的。

### 存在、唯一，以及三种写法

给定 $n+1$ 个 $x$ coordinate 互不相同的点，degree 不超过 $n$ 的 interpolating polynomial 恰好有一个。$n+1$ 个 coefficient 对 $n+1$ 个条件，数目对得上；唯一性是因为两个这样的 polynomial 相减，得到一个 degree 不超过 $n$ 却有 $n+1$ 个 root 的 polynomial，只能是 zero polynomial。

既然唯一，剩下的问题就只是怎么把它写出来。Polynomial 要靠一组 basis 来表示，选哪组 basis，决定了求 coefficient 时要解一个什么样的 system。这里又遇到了开头那张“好对付的 matrix”的表。

拿第 4 站的三个点 $(1,1)$、$(2,2)$、$(3,2)$ 来做。那里用 line（两个 coefficient）只能尽量靠近它们；现在用 quadratic polynomial（三个 coefficient），正好能穿过。

**Monomial basis $1,x,x^2$。** 设 $p(x)=c_0+c_1x+c_2x^2$，三个点给出

$$\begin{pmatrix}1&1&1\\1&2&4\\1&3&9\end{pmatrix}\begin{pmatrix}c_0\\c_1\\c_2\end{pmatrix}=\begin{pmatrix}1\\2\\2\end{pmatrix}$$

这个 matrix 叫 Vandermonde matrix（它的前两个 column 就是第 4 站的 $A$）。它是 full matrix，要用 elimination 解；更糟的是 degree 一高，$x^{10}$ 和 $x^{11}$ 这样的 column 几乎 parallel，condition number 极大。开头第三次事故里的 matrix 就是它。

**Lagrange basis。** 为每个 node 造一个 basis function，在自己的 node 上等于 1，在别的 node 上等于 0：

$$\ell_i(x)=\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}$$

Numerator 保证它在别的 node 上为 0，denominator 把它在 $x_i$ 处的值调成 1。三个点时

$$\ell_0=\frac{(x-2)(x-3)}{(1-2)(1-3)},\qquad\ell_1=\frac{(x-1)(x-3)}{(2-1)(2-3)},\qquad\ell_2=\frac{(x-1)(x-2)}{(3-1)(3-2)}$$

在这组 basis 下，system 的 matrix 是 identity matrix，coefficient 就是 function value，不用解：

$$p(x)=\sum_iy_i\,\ell_i(x)=1\cdot\frac{(x-2)(x-3)}{2}-2\,(x-1)(x-3)+2\cdot\frac{(x-1)(x-2)}{2}$$

::fig[dsa2102-lagrange] 左边是三个 $\ell_i$；右边是 $1\cdot\ell_0+2\,\ell_1+2\,\ell_2$，它穿过三个点。虚线是第 4 站的 least squares line，它只能尽量靠近。

适合推导；缺点是加一个 node，每个 $\ell_i$ 都要重写。

**Newton basis $1,\ (x-x_0),\ (x-x_0)(x-x_1),\dots$。** 每个 basis function 在前面所有的 node 上都等于 0。设 $p(x)=c_0+c_1(x-1)+c_2(x-1)(x-2)$，依次代入三个点：

$$\begin{pmatrix}1&0&0\\1&1&0\\1&2&2\end{pmatrix}\begin{pmatrix}c_0\\c_1\\c_2\end{pmatrix}=\begin{pmatrix}1\\2\\2\end{pmatrix}$$

Lower triangular，forward substitution 即可：$c_0=1$，$c_1=1$，$1+2+2c_2=2$ 得 $c_2=-\tfrac12$。再加一个 node，只是在下面多一个 row，已经算出的 coefficient 不变。

实际计算不去列这个 system，而是用一张 divided difference 表，它做的是同一件事。Zeroth-order 的就是 function value；order 高一级的由相邻两个低一级的相减，除以它们所跨的 node 之差：

$$f[x_i,\dots,x_{i+k}]=\frac{f[x_{i+1},\dots,x_{i+k}]-f[x_i,\dots,x_{i+k-1}]}{x_{i+k}-x_i}$$

| $x_i$ | $f[x_i]$ | first-order | second-order |
|---|---|---|---|
| 1 | **1** | | |
| 2 | 2 | $\dfrac{2-1}{2-1}=$ **1** | |
| 3 | 2 | $\dfrac{2-2}{3-2}=0$ | $\dfrac{0-1}{3-1}=$ $\mathbf{-\tfrac12}$ |

每个 column 最上面的数（粗体）就是 Newton 形式的 coefficient：

$$p(x)=1+1\cdot(x-1)-\tfrac12(x-1)(x-2)=-\tfrac12x^2+\tfrac52x-1$$

三种写法 expand 后是同一个 polynomial，可以代入 $x=1,2,3$ 核对。

| Basis | 求 coefficient 要解的 system | 评价 |
|---|---|---|
| Monomial | full matrix（Vandermonde） | condition number 极差 |
| Lagrange | identity matrix | 不用解，coefficient 就是 $y_i$ |
| Newton | lower triangular matrix | forward substitution，加 node 方便 |

### Error formula 里有两个 factor

如果 $f$ 足够 smooth，对每个 $x$ 存在某个 $\xi$ 使得

$$f(x)-p(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\;\underbrace{\prod_{i=0}^{n}(x-x_i)}_{\omega(x)}$$

先看它为什么应该长这样。Error 在每个 node 上都等于 0，所以应该含有 factor $\omega(x)=\prod(x-x_i)$，这个 polynomial 叫 node polynomial。让所有 node 都挤到同一点 $x_0$，$\omega(x)$ 变成 $(x-x_0)^{n+1}$，formula 就变回 Taylor remainder。

证明只有几行。固定一个不是 node 的 $x$，取 constant $K$ 使 $f(x)-p(x)=K\,\omega(x)$，要证的就是 $K=f^{(n+1)}(\xi)/(n+1)!$。看 $t$ 的 function

$$g(t)=f(t)-p(t)-K\,\omega(t)$$

它在 $n+1$ 个 node 上为 0，在 $t=x$ 处也为 0，共 $n+2$ 个 zero。相邻两个 zero 之间 derivative 必有一个 zero（Rolle's theorem），所以 $g'$ 至少有 $n+1$ 个 zero，$g''$ 至少有 $n$ 个，一直到 $g^{(n+1)}$ 至少有一个，记作 $\xi$。而 $p$ 的 degree 不超过 $n$，求 $n+1$ 次 derivative 是 0；$\omega$ 的 leading term 是 $t^{n+1}$，求 $n+1$ 次 derivative 是 $(n+1)!$。所以

$$0=g^{(n+1)}(\xi)=f^{(n+1)}(\xi)-K\,(n+1)!$$

用一次：两个 node $x_0,x_1$ 相距 $h$，用 line 做 interpolation。$|\omega(x)|=(x-x_0)(x_1-x)$ 在 midpoint 最大，等于 $\tfrac{h^2}{4}$，所以

$$|f(x)-p(x)|\le\frac{h^2}{8}\max|f''|$$

Node 加密一倍，error 缩小到四分之一。下一站 trapezoidal rule 的 error 就是把这个式子 integrate。

Formula 里两个 factor 各管一件事。第一个取决于 function 本身：higher-order derivative 有多大。第二个只取决于 node 怎么摆，和 function 无关。

:::wrong Node 越多、degree 越高，interpolation 就越准
对 $f(x)=\dfrac{1}{1+25x^2}$ 在 $[-1,1]$ 上取 equispaced 的 node 做 interpolation。Node 越多，interval 两端的 error 越大，最后 diverge。
:::

::fig[dsa2102-runge] 同一个 function，同样是 11 个 node、degree-10 polynomial。左边 node equispaced，右边 node 向两端加密。

这叫 Runge 现象。用 error formula 的两个 factor 去看，原因很清楚。先看 node 那个 factor：

::fig[dsa2102-nodepoly] 11 个 equispaced node 的 $|\omega(x)|$，在两端附近的峰值约 0.0085，在中间只有约 0.0001，相差近百倍。Equispaced 的 node 天然把 error 堆到两端。

这是 equispaced grid 本身的性质，和被 approximate 的是什么 function 无关，所以 Runge 现象总是出现在两端、从不出现在中间。再看 function 那个 factor：$\dfrac1{1+25x^2}$ 的 higher-order derivative 增长得极快，快过 $(n+1)!$。两个 factor 在两端同时失控。

同一个 function，interval 的大小也有关系。$\dfrac1{1+x^2}$ 在 $[-5,5]$ 上用 equispaced node 会 diverge（把 $x$ 缩小 5 倍，它就是上面的例子），在 $[-1,1]$ 上却 converge。Function 在 interval 内变化得越剧烈，high-degree 的 equispaced interpolation 越危险。

补救的办法正好对应两个 factor。

**改 node。** Chebyshev node $x_i=\cos\dfrac{(2i+1)\pi}{2(n+1)}$ 是把 semicircle 等分之后 project 到 diameter 上，所以两端密、中间疏。上图里它的 $|\omega(x)|$ 各个峰一样高，都是 $2^{-10}\approx0.001$；在所有 node 的摆法里，这个 maximum 是最小的。

**不用 high-degree。** 把 interval 切成 subinterval，每个 subinterval 用 low-degree polynomial，$n$ 小了，$f^{(n+1)}$ 和 $\omega$ 都失控不起来。最常用的是 cubic spline：每个 subinterval 是一个 cubic polynomial，在连接处要求 function value、first derivative、second derivative 都接得上。数一下条件够不够。$n$ 个 subinterval 共有 $4n$ 个 coefficient。每个 subinterval 要通过自己的两个 endpoint，$2n$ 个条件；$n-1$ 个内部 node 上 first、second derivative continuous，$2(n-1)$ 个条件。合计 $4n-2$，还差 2 个，要在两端另外规定，最常见的是让两端的 second derivative 为 0（natural spline）。

解这些条件时，通常把各个 node 上的 second derivative 当 unknown。每个 equation 只把一个 node 和它左右两个邻居联系起来，所以 system 是 tridiagonal 的，而且 strictly diagonally dominant。用[第 2 站](#lu)的 elimination，每个 row 只需要 eliminate 一个 entry，总共 $O(n)$ 次 operation，不必 pivoting，一定有 solution。

:::back
三种写法对应三种 matrix，是开头那张表在 function approximation 里的重现。对 interpolating polynomial 做 differentiation、integration，就得到[第 7 站](#quad)的 difference formula 和 quadrature rule。
:::

:::from
用 node polynomial 解释 Runge 现象、“这是 equispaced grid 本身的性质”、$[-5,5]$ 与 $[-1,1]$ 的对比、spline 的 system 是 tridiagonal 且 diagonally dominant，都来自 [18.330 讲义第 3 章](https://ocw.mit.edu/courses/18-330-introduction-to-numerical-analysis-spring-2012/resources/mit18_330s12_chapter3/)。那份讲义没有展开讲 Newton 的 divided difference，这一部分、三个点上的三种写法和 error formula 的证明（标准的 Rolle's theorem 论证）是按本课大纲补的。
:::

## [quad] Numerical differentiation 与 integration

:::skip
能由 Taylor expansion 推出 central difference 的 order of accuracy，能解释为什么 step size 取太小 derivative 反而算不准、而 integration 没有这个问题，就读完这门课了。
:::

Derivative 和 integral 的定义里都有 limit，而计算机取不了 limit，手里只有 function 在一些 grid point 上的值。办法是上一站准备好的：把 function 换成过这些点的 polynomial，对 polynomial 精确地 differentiate、integrate。衡量换得好不好，工具始终是 Taylor expansion。

### Numerical integration

把 $[a,b]$ 等分成若干 subinterval，每个 subinterval 宽 $h$。在每个 subinterval 上用一个简单的图形代替 curve 下的 area。

最粗的办法是用左 endpoint 的 function value 当整个 subinterval 的高（rectangle rule）。在一个 subinterval $[x_i,x_i+h]$ 上，$f(x)=f(x_i)+f'(x_i)(x-x_i)+\cdots$，被忽略的第一个 term integrate 之后是 $\tfrac12f'(x_i)\,h^2$，所以每个 subinterval 的 error 是 $h^2$ 量级。一共有 $(b-a)/h$ 个 subinterval，加起来：

$$\frac{b-a}{h}\times O(h^2)=O(h)$$

每个 subinterval 的 error 和 total error 差一个 order，后面所有 formula 都是这样。Total error $O(h)$ 叫 first-order accuracy：step size 减半，error 只减半。

改进只需要让被忽略的第一个 term 消失。

**Midpoint rule。** 改用 midpoint $m$ 的 function value，在 $m$ 处 expand：$f(x)=f(m)+f'(m)(x-m)+\tfrac12f''(m)(x-m)^2+\cdots$。在 $[m-\tfrac h2,\,m+\tfrac h2]$ 上 integrate，linear term 左右一正一负，integral 为 0；quadratic term 给出 $\tfrac12f''(m)\cdot\tfrac{h^3}{12}$。所以

$$\int f=h\,f(m)+\frac{h^3}{24}f''+\cdots$$

**Trapezoidal rule。** 用过两个 endpoint 的 line 代替 curve，area 是 $\tfrac h2\,[f(x_i)+f(x_{i+1})]$。它的 error 是上一站那个 line interpolation 的 error 的 integral：$\int\tfrac12f''\,(x-x_i)(x-x_{i+1})\,dx=-\tfrac{h^3}{12}f''$。所以

$$\int f=\frac h2\,[f(x_i)+f(x_{i+1})]-\frac{h^3}{12}f''+\cdots$$

两者每个 subinterval 的 error 都是 $h^3$ 量级，total error 是 $h^2$，second-order accuracy。注意两个 error term 的 sign 相反，大小差一倍：curve 向上弯时，midpoint rule 偏小，trapezoidal rule 偏大一倍。

::fig[dsa2102-quad] 左边用过两个 endpoint 的 line 代替 curve，右边用过两个 endpoint 和 midpoint 的 parabola。

**Simpson's rule。** 既然如此，取 $\tfrac23$ 的 midpoint 加 $\tfrac13$ 的 trapezoidal，$h^3$ term 正好抵消（$\tfrac23\cdot\tfrac1{24}-\tfrac13\cdot\tfrac1{12}=0$）：

$$\int f\approx\frac23\,h\,f(m)+\frac13\cdot\frac h2\,[f(x_i)+f(x_{i+1})]=\frac h6\,\big[f(x_i)+4f(m)+f(x_{i+1})\big]$$

它等于过两个 endpoint 和 midpoint 的 parabola 下的 area。习惯上把 midpoint 也算作 grid point，即把这里的 $h/2$ 改叫 $h$，coefficient 就成了常见的 $\tfrac h3[1,4,1]$。把各个 subinterval 的 formula 相加，得到 composite 的形式：

| Rule | Composite 形式 | true value 减去 approximation |
|---|---|---|
| Trapezoidal | $\dfrac h2\big[f_0+2f_1+\dots+2f_{n-1}+f_n\big]$ | $-\dfrac{(b-a)h^2}{12}f''(\xi)$ |
| Simpson（$n$ 为 even） | $\dfrac h3\big[f_0+4f_1+2f_2+4f_3+\dots+4f_{n-1}+f_n\big]$ | $-\dfrac{(b-a)h^4}{180}f^{(4)}(\xi)$ |

内部的点被左右两个 subinterval 各用一次，所以 trapezoidal 的 coefficient 是 2。表里第一行的 error 就是每个 subinterval 的 $-\tfrac{h^3}{12}f''$ 乘上 subinterval 的个数 $(b-a)/h$。

用 $\displaystyle\int_0^1e^x\,dx=e-1=1.7182818$ 检验：

| $h$ | Trapezoidal | error | Simpson | error |
|---|---|---|---|---|
| 1 | 1.8591409 | $1.4\times10^{-1}$ | | |
| 1/2 | 1.7539311 | $3.6\times10^{-2}$ | 1.7188612 | $5.8\times10^{-4}$ |
| 1/4 | 1.7272219 | $8.9\times10^{-3}$ | 1.7183188 | $3.7\times10^{-5}$ |

Step size 减半，trapezoidal 的 error 缩小到四分之一，Simpson 的缩小到十六分之一。

:::edge Simpson's rule 比预期多出一个 order
用 parabola 代替 curve，按理只应对 degree 2 及以下的 polynomial exact。但 error term 里出现的是 fourth derivative，说明它对 cubic polynomial 也 exact。原因是 symmetry：node 关于 midpoint symmetric，cubic term 的 error 在 midpoint 两侧一正一负抵消。Midpoint rule 比 rectangle rule 高一个 order 是同一个道理。
:::

:::edge 为什么不继续用 degree 更高的 polynomial
既然 parabola 比 line 好，用 8 个点上的 degree-7 polynomial 会不会更好？实际中很少超过 order 4。Equispaced node 上的 high-degree interpolation 有上一站的 Runge 现象，表现在 quadrature rule 里就是 weight 出现 negative，data 稍有 error 就被放大。要更高的 accuracy，办法是把 step size 减小，而不是把 degree 提高。
:::

### Numerical differentiation

把 $f(x+h)$ 和 $f(x-h)$ 在 $x$ 处 expand：

$$f(x\pm h)=f(x)\pm h\,f'(x)+\frac{h^2}{2}f''(x)\pm\frac{h^3}{6}f'''(x)+\cdots$$

只用上面那一个，移项除以 $h$，得 forward difference：

$$\frac{f(x+h)-f(x)}{h}=f'(x)+\frac h2f''(x)+\cdots\qquad\text{error }O(h)$$

两个相减，even-order 的 term 全部消掉，再除以 $2h$，得 central difference：

$$\frac{f(x+h)-f(x-h)}{2h}=f'(x)+\frac{h^2}{6}f'''(x)+\cdots\qquad\text{error }O(h^2)$$

到这里和 integration 完全平行。差别在于 formula 里除了一个 $h$。

:::wrong Step size 越小，derivative 算得越准
上面的 error term 确实随 $h$ 变小而变小。但 numerator $f(x+h)-f(x)$ 是两个相近的数相减，正是第 1 站的 cancellation，而且 $h$ 越小越严重。两个 function value 各带 $\varepsilon|f|$ 左右的 rounding error，相减后还是这么大，除以 $h$ 之后是 $\varepsilon|f|/h$。
:::

把两种 error 加在一起：

$$E(h)\approx\underbrace{\frac h2|f''|}_{\text{formula error}}+\underbrace{\frac{\varepsilon|f|}{h}}_{\text{rounding error}}$$

一个 term 随 $h$ 增大，一个随 $h$ 减小。对 $h$ 求 derivative 令其为 0：$\tfrac12|f''|=\varepsilon|f|/h^2$，所以

$$h_{\text{opt}}=\sqrt{\frac{2\varepsilon|f|}{|f''|}}\sim\sqrt\varepsilon\approx10^{-8},\qquad E(h_{\text{opt}})\sim\sqrt\varepsilon$$

能达到的最好 accuracy 只有 8 位左右。对 central difference 做同样的事，formula error 是 $\tfrac{h^2}6|f'''|$，optimal 的 $h\sim\varepsilon^{1/3}\approx10^{-5}$，error $\sim\varepsilon^{2/3}\approx10^{-11}$。

::fig[dsa2102-hcurve] 对 $e^x$ 在 $x=1$ 处求 derivative，在 double precision 下实际算出的 error。右半边是 formula 本身的 error，slope 分别是 1 和 2；左半边是 rounding error，两条 curve 重合，slope 是 −1。

图里两条 curve 的最低点正在上面算出的位置。Order 更高的 formula 能把最低点压得更低，但同样不是 $h$ 越小越好。

### 为什么 integration 好算、differentiation 难算

Numerical integration 里 function value 的 rounding error 也存在。Trapezoidal rule 是 $\sum h\,f_i$ 这样的 sum，每个 $f_i$ 带 $\varepsilon|f|$ 的 error，合起来最多是 $\sum h\,\varepsilon|f|=(b-a)\,\varepsilon\max|f|$，和 $h$ 无关，仍然只是 $\varepsilon$ 量级：integration 是求平均，error 被摊薄。Differentiation 是相减再除以一个小数，error 被放大。同样的 data，integration 可以算到接近 16 位，differentiation 最多 8 到 11 位。这是两个问题本身的差别，不是 formula 写得好不好的问题。

### Richardson extrapolation

上面每个 formula 的 error 都不只是“$O(h^p)$”这么一句话，它有确定的形式：

$$D(h)=\text{true value}+c\,h^p+\text{higher-order terms}$$

$c$ 是多少不知道，但 $p$ 是知道的。用 step size $h$ 和 $h/2$ 各算一次：

$$D(h)\approx\text{true value}+c\,h^p,\qquad D(h/2)\approx\text{true value}+\frac{c\,h^p}{2^p}$$

两个式子，两个 unknown（true value 和 $c$）。第二式乘 $2^p$ 减去第一式，$c$ 被消掉：

$$\text{true value}\approx\frac{2^pD(h/2)-D(h)}{2^p-1}$$

不必知道 error 有多大，只要知道它按什么规律随 $h$ 变化，就能把 leading term 消去。

拿上面那张表的 trapezoidal 那个 column 来试（$p=2$）：

$$\frac{4\times1.7539311-1.8591409}{3}=1.7188612$$

Error 从 $3.6\times10^{-2}$ 降到 $5.8\times10^{-4}$，而且这个数正是表里 $h=\tfrac12$ 的 Simpson 值。这不是巧合：把两个 trapezoidal 的式子代进去，$\tfrac43\cdot\tfrac h4[f_0+2f_1+f_2]-\tfrac13\cdot\tfrac h2[f_0+f_2]=\tfrac h6[f_0+4f_1+f_2]$，就是 Simpson's rule。

对 Simpson 那个 column 再做一次（它的 $p=4$）：$\dfrac{16\times1.7183188-1.7188612}{15}=1.7182827$，error $8.6\times10^{-7}$。这样一层一层做下去，叫 Romberg integration，每层提高两个 order。

:::back
Step size 与 rounding error 的折中是[第 1 站](#fp)最后那个“躲不掉的 cancellation”。Quadrature rule 和 difference formula 都来自[第 6 站](#interp)的 interpolating polynomial，不用 high-degree formula 的理由也是那里的 Runge 现象。
:::
