先看一个真实 robot joint 上的三次实验。Joint 带着一节 1 kg 的 link，要从竖直向下转到水平，controller 都是教科书上的那几个。

**第一次。** 用 P 和 D，gain 按“critically damped、$\omega_n=20$ rad/s”算好。Link 到不了水平，停在差 5.6° 的地方，再等多久也不动。

**第二次。** 加上 integral，5.6° 的 error 消失了。但 motor 在 joint 一侧最多只能给 3 N·m，这一次 link 冲过水平 54°。

**第三次。** 把同一组 gain 从 1 kHz 的 control loop 搬到 55 Hz 的 loop 上，link 来回摆，越摆越大。

::fig[rb2203-three] 上面是 link 本身（按 1/4 速度播放），下面是它的 angle 曲线，点同步走。看三件事：① link 转上来后停在 target 下面一点，不再动；② link 冲过 target 一大截才回来；③ 灰色细 link（1 kHz）稳稳停住，同一组 gain 在 55 Hz 下的粗 link 越摆越大。第 2、3 站会逐个解释。

三次都没有写错 model：gravity 要靠 torque 顶住，torque 有上限，computer 只能隔一段时间看一眼。这门课讲的就是在这些前提下让 robot 按要求运动。先把一个 joint 的 model 写对（第 1 站），用 feedback 让它听话（第 2 站），再处理真机上的 saturation、noise 和 sampling（第 3 站）。一个 joint 的 state 多于两个时 PID 不够用，换成 state space（第 4 站）。然后从“到达一个点”走到“沿一条 trajectory 走”（第 5 站），从一个 joint 走到一整条 arm（第 6、7 站），最后是靠 wheel 移动的 robot（第 8 站）。三次实验分别在第 2、3 站得到解释。

## [model] Joint 的 model：DC motor、gear 与 system identification

:::skip
能从 motor 的两条 equation 写出 voltage 到 speed 的 transfer function，说清 gear 为什么让 rotor inertia 乘 $N^2$、back-EMF 为什么像一个 damper，并能从 step response 或 Bode plot 读出 first-order model 的两个 parameter，就可以去第 2 站。
:::

### 两条 equation

Motor 里的 current $i$ 产生 torque $K_ti$；rotor 以 $\omega_m$ 旋转时，coil 里感应出与 speed 成正比的 back-EMF $K_e\omega_m$。用 SI 单位时 $K_t=K_e$，都记作 $K$。Armature 回路用 Kirchhoff's voltage law，rotor 用 Newton's law：

$$L\frac{di}{dt}+Ri=V-K\omega_m,\qquad J_m\dot\omega_m=Ki-\tau_g$$

$\tau_g$ 是 gear 反过来作用在 rotor 上的 torque。Joint J 的 motor：$K=0.05$ N·m/A，$R=1\ \Omega$，$L=0.5$ mH，rotor inertia $J_m=4\times10^{-6}$ kg·m²。

### Gear：torque 乘 N，inertia 乘 N²

Gear ratio $N=50$ 的意思是 motor 转 50 圈、joint 转 1 圈，所以 $\omega_m=N\dot\theta$；gear 把 rotor 一侧的 torque $\tau_g$ 放大成 joint 一侧的 $N\tau_g$。Link 一侧：

$$J_l\ddot\theta=N\tau_g-b\dot\theta-mgr\cos\theta$$

由 rotor 的 equation 解出 $\tau_g=Ki-J_m\dot\omega_m=Ki-J_mN\ddot\theta$，代进去：

$$J_l\ddot\theta=NKi-N^2J_m\ddot\theta-b\dot\theta-mgr\cos\theta\quad\Longrightarrow\quad\underbrace{(J_l+N^2J_m)}_{M}\,\ddot\theta+b\dot\theta+mgr\cos\theta=\underbrace{NKi}_{\tau}$$

Rotor 的 inertia 在 joint 一侧乘了 $N^2$：一个 $N$ 来自“rotor 转得快 $N$ 倍，要更大的 torque 去 accelerate”，另一个 $N$ 来自“这个 torque 经过 gear 又放大 $N$ 倍”。$J_m=4\times10^{-6}$ 小得可以忽略，乘上 2500 变成 0.01，占了 $M$ 的五分之一。反过来从 motor 看，link 的 inertia 和 gravity 被分别除以 $N^2$ 和 $N$；arm 的 configuration 一变 link 的 inertia 就跟着变，gear ratio 越大，motor 感到的变化越小。

Joint 一侧的 3 N·m 对应 motor current $3/(NK)=1.2$ A。

### Voltage drive：back-EMF 是一个 damper

先看 motor driver 直接给 voltage 的情形。Electrical time constant $L/R=0.5$ ms，比 joint 的运动快得多，先令 $L=0$（下面用 Bode plot 检查这个近似）。于是 $i=(V-KN\dot\theta)/R$，代进上面的 equation：

$$M\ddot\theta+\Big(b+\frac{N^2K^2}{R}\Big)\dot\theta+mgr\cos\theta=\frac{NK}{R}\,V$$

Back-EMF 进到了 $\dot\theta$ 的 coefficient 里，和 friction 并列。原因很直接：voltage 固定时，转得越快 back-EMF 越大，current 越小，torque 越小，这正是一个 damper 做的事。它的大小是 $N^2K^2/R=2500\times0.0025/1=6.25$，是 $b=0.1$ 的 62 倍。

Joint 水平放置、没有 gravity 时，speed $\omega=\dot\theta$ 满足 $0.05\,\dot\omega+6.35\,\omega=2.5\,V$。做 Laplace transform（见 [EE2023 第 4 站](../courses/EE2023.html#laplace)）：

$$\frac{\Omega(s)}{V(s)}=\frac{K_{dc}}{T_ms+1},\qquad K_{dc}=\frac{2.5}{6.35}=0.394\ \frac{\text{rad/s}}{\text{V}},\qquad T_m=\frac{0.05}{6.35}=7.87\text{ ms}$$

:::wrong 用 voltage step 测出 time constant，就能反推出 joint 的 friction
从 time constant $T_m=7.87$ ms 和 $M=0.05$ 会得出 damping coefficient $M/T_m=6.35$，其中 6.25 是 back-EMF。几乎所有 robot joint 的 driver 都工作在 current mode（下一站），driver 不断调整 voltage 让 current 等于 command，back-EMF 的作用被抵消，剩下的 damping 只有 $b=0.1$。如果拿 6.35 去设计 position loop，按 $\zeta=1$、$\omega_n=20$ 算出的 $K_d=2\zeta\omega_nM-6.35=-4.35$，结论是“不需要 $K_d$”；真机上 $K_d=0$ 时 $\zeta=\dfrac{0.1}{2\sqrt{20\times0.05}}=0.05$，几乎没有 damping。
:::

### System identification：从 step response 读

First-order model 只有两个 parameter，一次 step 实验就能读出来。在 joint 上加 12 V 的 step（这里用含 $L$ 的完整 model 模拟“测量”）：

- Speed 最后停在 4.72 rad/s，所以 $K_{dc}=4.72/12=0.393$。
- First-order system 在 $t=T_m$ 时到达 final value 的 $1-e^{-1}=63.2\%$。测得 2.98 rad/s 出现在 7.9 ms，所以 $T_m\approx7.9$ ms。

同一次实验里 current 的 peak 是 10.5 A：$t=0$ 时 $\omega=0$，没有 back-EMF，current 只受 $R$ 限制，接近 $V/R=12$ A。Motor driver 如果没有 current limit，这一下是 3 N·m 对应的 1.2 A 的近 9 倍。

### System identification：从 Bode plot 读

Step response 只给出一个 time constant。要知道 model 在多高的 frequency 以内可信，就用 sinusoidal voltage 逐个 frequency 测 speed 的 amplitude 和 phase，画成 Bode plot（读法见 [EE2023 第 6 站](../courses/EE2023.html#bode)）。

::fig[rb2203-bode] Joint J 的 motor 从 voltage 到 speed 的 Bode plot，用含 $L$ 的完整 model 算出。低 frequency 是平的；过第一个 corner 后 slope 变成 −20 dB/decade，过第二个 corner 后变成 −40 dB/decade。

从图上读：

| 读什么 | 读到的值 | 推出的 parameter |
|---|---|---|
| 低 frequency 的高度 | −8.1 dB | $K_{dc}=10^{-8.1/20}=0.394$ |
| 比低 frequency 低 3 dB 的 frequency | 135 rad/s | 第一个 pole，$T_m\approx1/135=7.4$ ms |
| Phase 到 −90° 的 frequency | 504 rad/s | 两个 corner 的 geometric mean：第二个 pole $\approx504^2/135=1880$ rad/s |
| 高 frequency 的 slope | −40 dB/decade | 一共两个 pole |

完整 model 的两个 pole 是 136 rad/s 和 1866 rad/s，读数和它相差不到 1%。第二个 pole 来自 $L$，它在 100 rad/s 处造成的 phase lag 是 $\arctan(100/1866)=3.1°$。Joint 的 position loop 只工作在几十 rad/s，所以令 $L=0$ 是可以的。

Step response 读出的 7.9 ms 和 Bode plot 读出的 7.4 ms 不完全一样：第二个 pole 让 step response 晚了一点。两种读法都是 first-order model 对 second-order system 的 approximation，各自对一种用途准确。

:::back
Transfer function、partial fractions 来自 [EE2023 第 4 站](../courses/EE2023.html#laplace)，corner frequency 与 asymptote 来自 [EE2023 第 6 站](../courses/EE2023.html#bode)。Joint 的 dynamics 如何由 Lagrange equations 得出，见 [RB2202](../courses/RB2202.html)。
:::

## [pid] PID：从 current loop 到 joint position

:::skip
能用 pole placement 为 first-order plant 设计 PI，能推出 PD 在 gravity 下的 steady-state error 和 PID 对 $K_i$ 的上限，能解释为什么 integral 一定带来 overshoot，会用 Ziegler–Nichols 的两张表，并能算出 velocity loop 套 position loop 时两层的 pole，就可以去第 3 站。
:::

### 先让 motor 变成 torque source

上一站最后那个 equation 的 input 是 $\tau=NKi$。要让 joint 服从 position command，先要能指定 current。Armature 回路 $L\,\dfrac{di}{dt}+Ri=V-K\omega_m$ 本身是一个 first-order plant，back-EMF 变化很慢，当作 disturbance。

First-order plant 一般写成 $\dot y=-ay+bu$。用 PI controller $u=k_pe+k_i\int e\,dt$，$e=r-y$。代进去，两边再对 time 求一次 derivative 消去 integral：

$$\ddot y=-a\dot y+b\big(k_p(\dot r-\dot y)+k_i(r-y)\big)\quad\Longrightarrow\quad\ddot y+(a+bk_p)\dot y+bk_iy=bk_p\dot r+bk_ir$$

Characteristic polynomial 是 $s^2+(a+bk_p)s+bk_i$，两个 coefficient 各由一个 gain 控制。要 closed-loop pole 落在 $s^2+2\zeta\omega_0s+\omega_0^2$ 的 root 上，对比 coefficient：

$$k_p=\frac{2\zeta\omega_0-a}{b},\qquad k_i=\frac{\omega_0^2}{b}$$

Current loop 里 $a=R/L=2000$，$b=1/L=2000$。取 $\omega_0=6000$ rad/s（约 950 Hz）、$\zeta=1$：

$$k_p=\frac{12000-2000}{2000}=5\ \text{V/A},\qquad k_i=\frac{3.6\times10^7}{2000}=18000\ \text{V/(A·s)}$$

模拟 1 A 的 step：0.18 ms 到达 90%，overshoot 5.5%。$\zeta=1$ 却有 overshoot，是因为 transfer function 的 numerator $bk_ps+bk_i$ 在 $-k_i/k_p=-3600$ 有一个 zero，它改变了两个 mode 的 weight（见 [EE2023 第 5 站](../courses/EE2023.html#pz)）。Motor 转起来后 back-EMF 慢慢变大，integral 会把它补回来。

Torque 在 0.2 ms 内跟上 command，比 joint 的运动快两个 orders of magnitude。所以从这里开始，joint 的 input 就是 torque：

$$M\ddot\theta+b\dot\theta+mgr\cos\theta=\tau$$

### P 和 PD

Error $e=\theta_d-\theta$。只用 P，$\tau=K_pe$，先不管 gravity，closed loop 是 $M\ddot\theta+b\dot\theta+K_p\theta=K_p\theta_d$，和 mass-spring-damper 一样：$K_p$ 是 spring，$b$ 是 damper。

$$\omega_n=\sqrt{\frac{K_p}{M}},\qquad\zeta=\frac{b}{2\sqrt{K_pM}}$$

$K_p=20$ 时 $\omega_n=20$ rad/s，$\zeta=\dfrac{0.1}{2\times1}=0.05$。按 second-order system 的 formula，overshoot 是 $e^{-\pi\zeta/\sqrt{1-\zeta^2}}=85\%$。实际从 $-90°$ 出发，link 冲过水平 70°（gravity 让数字略有不同）。

缺的是 damping，所以加一个与 velocity 成正比的 torque：

$$\tau=K_pe-K_d\dot\theta,\qquad\zeta=\frac{b+K_d}{2\sqrt{K_pM}}$$

$\zeta=1$ 要求 $K_d=2\sqrt{K_pM}-b=2-0.1=1.9$。Derivative 作用在 $-\dot\theta$ 而不是 $\dot e$ 上，$\theta_d$ 不变时两者相同，$\theta_d$ 跳变时差别在下一站讲。

现在加回 gravity。Link 停下来时 $\dot\theta=\ddot\theta=0$，equation 只剩

$$K_p\,e=mgr\cos\theta$$

Gravity torque 只能由 P term 来顶，P term 要不为 0，error 就不能为 0。$\theta_d=0$，$\theta=-e$，解 $20e=1.962\cos e$ 得 $e=0.0976$ rad，即 5.6°。这就是开头的第一次实验。先忽略 $\cos e\approx1$ 估一下是 $1.962/20=0.098$，几乎一样。把 $K_p$ 加倍只能把 error 减半，而 gain 不能无限加（第 3、4 站）。

### Integral：多一个 state，多一个 stability 条件

加上 integral：

$$\tau=K_pe+K_i\int_0^te\,dt-K_d\dot\theta$$

Steady state 时 integral term 停在 $mgr\cos\theta$，P term 就可以是 0，error 消失。代价是 system 多了一个 state。在水平 position 附近把 gravity 当作 constant disturbance $d$，closed loop 是 $M\ddot\theta+(b+K_d)\dot\theta=K_pe+K_i\int e-d$。$\theta_d$ 不变，所以 $\ddot\theta=-\ddot e$，$\dot\theta=-\dot e$；再对 time 求一次 derivative，constant $d$ 消失：

$$M\dddot e+(b+K_d)\ddot e+K_p\dot e+K_ie=0$$

Characteristic polynomial 是 $Ms^3+(b+K_d)s^2+K_ps+K_i$。$K_i$ 从 0 开始增大，三个 root 连续移动；$K_i$ 很小时它们都在 left half-plane（两个是 PD 原来的 pole，一个在 origin 左边一点）。System 变得不 stable，必须有 root 穿过 imaginary axis。把 $s=j\omega$ 代入：

$$-jM\omega^3-(b+K_d)\omega^2+jK_p\omega+K_i=0$$

Real part 和 imaginary part 分别为 0：$K_i=(b+K_d)\omega^2$，$\omega(K_p-M\omega^2)=0$。所以穿越发生在 $\omega^2=K_p/M$、$K_i=(b+K_d)K_p/M$ 处：

$$0<K_i<\frac{(b+K_d)\,K_p}{M}=\frac{2\times20}{0.05}=800$$

用 $K_i=800$ 核对，三个 root 是 $\pm20j$ 和 $-40$，正好在边界上。

### $K_i$ 怎么选

在上限以内，$K_i$ 越大，最慢的那个 pole 离 origin 越远，gravity 造成的 offset 起初消失得越快；但 overshoot 越来越大，$K_i$ 再大时振荡又把 settling 拖长：

| $K_i$ | 三个 closed-loop pole | Overshoot | 进入 ±0.01 rad 并不再出去的时间 |
|---|---|---|---|
| 20 | $-24.1,\ -14.8,\ -1.12$ | 2.6° | 1.89 s |
| 50 | $-26.2,\ -10.0,\ -3.82$ | 11.4° | 1.25 s |
| 100 | $-28.4,\ -5.8\pm6.1j$ | 22.7° | 0.97 s |
| 200 | $-31.3,\ -4.35\pm10.4j$ | 39.1° | 1.21 s |
| 400 | $-35.1,\ -2.45\pm14.9j$ | 61.2° | 2.11 s |

（都是从 $-90°$ 转到 $0°$，$K_p=20$，$K_d=1.9$，没有 torque limit。）$K_i=20$ 时三个 pole 都是 real 的，仍然有 2.6° 的 overshoot。原因在 integral 自己身上。Steady state 时 integral term 等于 gravity torque，所以

$$K_i\int_0^\infty e\,dt=mgr\quad\Longrightarrow\quad\int_0^\infty e\,dt=\frac{1.962}{K_i}$$

Error 的 signed area 被固定死了。Link 从 $-90°$ 出发，前半程 error 是正的，积出来的 area 是 0.149 rad·s（$K_i=20$）或 0.127 rad·s（$K_i=100$）；而总 area 只能是 $1.962/20=0.098$ 或 $1.962/100=0.0196$。多出来的部分必须由负的 error 抵消，也就是 link 必须冲过头：模拟里负的 area 分别是 0.051 和 0.107，加起来恰好等于要求的值。

所以起点离目标越远，integral 的 overshoot 越不可避免。办法有三个：只在接近目标时才打开 integral；用 model 把 gravity 直接补上，integral 只管剩下的一点（第 5、6 站）；不给 step，给一条 trajectory，让 error 从头到尾都小（第 5 站）。

::fig[rb2203-pid] Joint J 从 $-90°$ 转到 $0°$。P 几乎没有 damping；PD 停在 5.6° 之外；PID 消除了 steady-state error，但 $K_i$ 越大冲得越多。

### Ziegler–Nichols：一次实验，读两个数，查表

NUS 的大纲给 PID 列了两种 tuning 方法：Ziegler–Nichols 和 trial-and-error。前面的做法都是先写出 model 再放 pole。Ziegler–Nichols 针对的是 model 写不出来的 plant：做一次实验，读两个数，查表得到 gain。表里的 PID 写成

$$u=K\Big(e+\frac{1}{T_i}\int_0^te\,dt+T_d\,\frac{de}{dt}\Big),\qquad K_p=K,\quad K_i=\frac{K}{T_i},\quad K_d=KT_d$$

$T_i$ 叫 integral time，$T_d$ 叫 derivative time。

**Step response method。** Open loop 给 plant 一个 unit step，在 response 斜率最大的地方画切线。切线与 time axis 交于 $t=L$，与纵轴交于 $-a$。这条切线是 $\dfrac aL(t-L)$，也就是把 plant 近似成 slope 为 $a/L$ 的 integrator 加一段 time delay $L$。表格（Åström 与 Hägglund 的 Table 6.1）：

| Controller | $K$ | $T_i$ | $T_d$ |
|---|---|---|---|
| P | $1/a$ | | |
| PI | $0.9/a$ | $3L$ | |
| PID | $1.2/a$ | $2L$ | $L/2$ |

**Frequency response method。** Closed loop 只用 P，从小往大加 gain，直到 output 出现 amplitude 不增不减的 oscillation，记下这时的 ultimate gain $K_u$ 和 oscillation 的 period $T_u$。这时 loop 恰好在 stability 的边界上：在 $\omega_u=2\pi/T_u$ 处 $\angle P(j\omega_u)=-180°$，$K_u\lvert P(j\omega_u)\rvert=1$。表格（Table 6.2）：

| Controller | $K$ | $T_i$ | $T_d$ |
|---|---|---|---|
| P | $0.5K_u$ | | |
| PI | $0.4K_u$ | $0.8T_u$ | |
| PID | $0.6K_u$ | $0.5T_u$ | $0.125T_u$ |

（Åström 与 Murray 把 $K_u$、$T_u$ 写作 $k_c$、$T_c$。PI 一行，Ziegler 与 Nichols 原文是 $0.45K_u$ 和 $T_u/1.2$，Åström 与 Murray 的 errata 页指出过这个差别；课上用哪一组以讲义为准。）

**例子：$P(s)=\dfrac{1}{(s+1)^3}$**（Åström 与 Hägglund 的 Example 6.1、6.2，下面逐步算一遍）。

Step response 是 $y(t)=1-e^{-t}\big(1+t+\tfrac12t^2\big)$，求 derivative 得 $\dot y=\tfrac12t^2e^{-t}$。$\ddot y=\big(t-\tfrac12t^2\big)e^{-t}=0$ 给出 $t=2$，那里 slope $\dot y(2)=2e^{-2}=0.271$，$y(2)=1-5e^{-2}=0.323$。切线是 $y=y(2)+\dot y(2)\,(t-2)$。分别令 $y=0$ 和 $t=0$：

$$L=2-\frac{1-5e^{-2}}{2e^{-2}}=\frac{9-e^2}{2}=0.805,\qquad-a=\big(1-5e^{-2}\big)-2\times2e^{-2}=1-9e^{-2}=-0.218$$

所以 $a=0.218$。查表：$K=1.2/0.218=5.50$，$T_i=2\times0.805=1.61$，$T_d=0.805/2=0.403$。

Frequency response：$\angle P(j\omega)=-3\arctan\omega=-180°$ 给出 $\arctan\omega_u=60°$，$\omega_u=\sqrt3$；$\lvert P(j\sqrt3)\rvert=\dfrac{1}{(1+3)^{3/2}}=\dfrac18$，所以 $K_u=8$，$T_u=2\pi/\sqrt3=3.63$。查表：$K=4.8$，$T_i=1.81$，$T_d=0.453$。

::fig[rb2203-zn] 两个实验各读出什么。左：open loop 的 step response，在最陡处画切线，读出 $L$ 和 $a$。右：closed loop 只用 P、gain 取 $K_u=8$ 时，output 以不变的 amplitude 振荡，相邻两个 peak 相隔 $T_u$。

两组 gain 用在 setpoint 的 unit step 上（为这一页算的）：

| 方法 | $K,\ T_i,\ T_d$ | Overshoot | 第二个 peak 与第一个之比 | $M_s$ |
|---|---|---|---|---|
| Step response | 5.50, 1.61, 0.403 | 52% | 0.29 | 2.78 |
| Frequency response | 4.8, 1.81, 0.453 | 41% | 0.17 | 2.13 |

Ziegler 与 Nichols 定这些系数时的目标是 quarter amplitude decay，每个 peak 是上一个的四分之一，step method 的 0.29 接近这个目标。Åström 与 Hägglund 认为这个目标本身就太激进，damping 不够。

$M_s=\max_\omega\big\lvert1/(1+P(j\omega)C(j\omega))\big\rvert$ 是 sensitivity function 的峰值，$1/M_s$ 等于 Nyquist curve 离 $-1$ 的最近距离。Frequency method 的 PID 有一个与 plant 无关的下限：在 $\omega_u$ 处 $\omega_uT_i=2\pi/T_u\times0.5T_u=\pi$，$\omega_uT_d=\pi/4$，所以

$$C(j\omega_u)=0.6K_u\Big(1+\frac{1}{j\pi}+j\frac{\pi}{4}\Big)=0.6K_u\,(1+0.467j)$$

又 $P(j\omega_u)=-1/K_u$，相乘得 $P(j\omega_u)C(j\omega_u)=-0.6-0.28j$。它到 $-1$ 的距离是 $\sqrt{0.4^2+0.28^2}=0.49$，Nyquist curve 至少有这一点离 $-1$ 这么近，所以 $M_s\ge1/0.49=2.05$，不论 plant 是什么。上表的 2.13 符合这个下限。

### Trial-and-error

Åström 与 Hägglund 6.3 节列了手调时用的四条经验：加大 $K$ 降低 stability；减小 $T_i$ 让 error 消得更快；减小 $T_i$ 降低 stability；加大 $T_d$ 改善 stability。上面 $K_i$ 的数表就是第二、三条：$K_p=20$ 不变，$K_i$ 从 20 加到 400 等于 $T_i=K_p/K_i$ 从 1 s 减到 0.05 s，offset 消得更快，overshoot 从 2.6° 涨到 61°。

这些规则有反例。Plant 是 integrator 时（例如第 7 站那种接受 velocity command 的 joint），PI 的 closed loop 是 $s^2+Ks+K/T_i$，$\zeta=\dfrac{K}{2\sqrt{K/T_i}}=\dfrac{\sqrt{KT_i}}{2}$：$T_i$ 不变时加大 $K$，damping 反而变好。这是他们的 Example 6.5。

:::wrong 先把 P 调到临界 oscillation，再按 Ziegler–Nichols 的表算 PID
在 Joint J 上做一遍 frequency response method（1 kHz，computation 占一个 sampling period）。Continuous model 里 P control 的 characteristic polynomial $Ms^2+bs+K_p$ 对任何 $K_p>0$ 都 stable，根本没有 ultimate gain；sampled loop 里 $K_u=66.7$，$T_u=0.172$ s，这个临界点是 sampling delay 造成的，和 joint 本身关系不大。查表得 $K_p=40.0$，$K_i=K_p/T_i=465$，$K_d=K_pT_d=0.86$。Dominant pole 是 $-3.14\pm26.6j$，$\zeta=0.12$：从 $-90°$ 出发 overshoot 68°，只走 0.1 rad 也有 37%。这套规则是为带 dead time、model 未知的 process plant 定的，上面已经看到它连 $M_s<2$ 都做不到。Robot joint 的 model 可以写出来、可以测出来，用 pole placement 更好。
:::

### Velocity loop 套着 position loop

上面的 PD 直接算 torque。Corke 的《Robotics and Control》（NUS reading list 的第一本）讲 independent joint control 用的是两层 loop：里层的 velocity loop 让 motor speed $\omega_m$ 跟上 command $\omega^*$，外层的 position loop 由 position error 算出 $\omega^*$。书的配套代码（`vloop.py`、`ploop.py`）里 Puma 560 第 2 个 joint 的参数：motor 一侧 inertia $J=5.8\times10^{-4}$ kg·m²，viscous friction $B=8.17\times10^{-4}$ N·m·s/rad，torque constant $K_m=0.228$ N·m/A，gear ratio $G=107.8$，motor torque 上限 0.9 N·m。Driver 是 current mode：torque 等于 $K_m$ 乘 current command。

::fig[rb2203-cascade] 两层 loop。里层把 speed error 换成 current command，外层把 angle error 换成 speed command；$\tau_d$ 是折算到 motor 一侧的 load torque。

**里层。** Current command 是 $K_v(\omega^*-\omega_m)$，$K_v=0.6$ A·s/rad：

$$J\dot\omega_m=K_mK_v(\omega^*-\omega_m)-B\omega_m-\tau_d$$

$\omega^*$ 到 $\omega_m$ 是 first-order 的，pole 在 $-(B+K_mK_v)/J=-(0.000817+0.1368)/0.00058=-237$ rad/s。Motor 自己的 time constant 是 $J/B=0.71$ s，feedback 把它缩短了 170 倍。

**外层。** Link angle $\theta$ 满足 $\dot\theta=\omega_m/G$，外层取 $\omega^*=K_p(\theta_d-\theta)$，$K_p=4000$。如果里层是理想的（$\omega_m=\omega^*$），$\dot\theta=\dfrac{K_p}{G}(\theta_d-\theta)$，pole 在 $-K_p/G=-37.1$ rad/s。不做这个近似，把 $\omega_m=G\dot\theta$ 和 $\omega^*$ 代进里层的 equation，两边除以 $G$：

$$J\ddot\theta+(B+K_mK_v)\,\dot\theta+\frac{K_mK_vK_p}{G}\,\theta=\frac{K_mK_vK_p}{G}\,\theta_d-\frac{\tau_d}{G}$$

即 $s^2+237.3s+8751=0$，root 是 $-45.7$ 和 $-191.6$。外层的 pole 比近似值快了一些；两个 pole 相差 4 倍多，所以“里层先跟上，外层再看”这个分开设计的想法基本成立。

**Load torque。** Steady state 时 $\dot\theta=\ddot\theta=0$，上式给出 $\theta_d-\theta=\dfrac{\tau_d}{K_mK_vK_p}$。Corke 的测试代码在 motor 一侧加了 $\tau_d=20/G=0.186$ N·m（相当于 link 一侧 20 N·m），error 是 $0.186/(0.228\times0.6\times4000)=3.4\times10^{-4}$ rad，即 0.019°。折算到 link 一侧，这个 loop 的 stiffness 是 $GK_mK_vK_p=5.9\times10^4$ N·m/rad，Joint J 的 PD 只有 20 N·m/rad。Gear ratio 大，gravity 这类 load 到了 motor 一侧被除以 $G$，这是 independent joint control 在这种 robot 上能用的原因。

**Velocity feedforward。** 跟踪 Corke 测试代码里的 quintic（1 s 内从 0 到 1 rad），只有 P 的外层 tracking error 最大 0.0506 rad（2.9°），出现在速度最大处。原因和 Modern Robotics 11.3.1 说的一样：velocity input 下的 P control 跟踪匀速 reference 时总落后 $\dot\theta_d/K$，这里 $K=K_p/G=37.1$，$\dot\theta_d$ 最大是 $1.875$ rad/s，$1.875/37.1=0.0505$ rad。把 reference 的 velocity 直接加进去，$\omega^*=K_p(\theta_d-\theta)+G\dot\theta_d$，最大 error 降到 0.00079 rad（0.045°）；再加上 20/G 的 load，最大 0.065°，终点 0.019°。整个过程 torque 最大 0.63 N·m，没有碰到 0.9 N·m 的上限。（Corke 代码里这一项的 gain 默认是 0；加 feedforward 的这一组是为这一页算的。）

单个 joint 的 model $M\ddot\theta+b\dot\theta+mgr\cos\theta=\tau$、PD 的 $\zeta=(b+K_d)/2\sqrt{K_pM}$、gravity 下的 steady-state error、从 $-\pi/2$ 转到 0 的例子、加 integral 后 order 变成 3、$K_i$ 有上限以及 root 随 $K_i$ 移动的描述，来自 [Modern Robotics 11.4 第 1 部分](https://modernrobotics.northwestern.edu/nu-gm-book-resource/11-4-motion-control-with-torque-or-force-inputs-part-1-of-3/)和[第 2 部分](https://modernrobotics.northwestern.edu/nu-gm-book-resource/11-4-motion-control-with-torque-or-force-inputs-part-2-of-3/)的逐字稿。书本（[Modern Robotics v2 preprint](https://hades.mech.northwestern.edU/images/2/25/MR-v2.pdf)）的式 11.29、11.30 给出了同一个 third-order error dynamics，并写明 stability 要求 $(b+K_d)K_p/M>K_i>0$，和这里用 $s=j\omega$ 求出的 800 一致；书里的例子用的是 $M=0.5$、$r=0.1$ m、$K_d=2$、$K_p=2.205$、$K_i=1$，这一页换成了 Joint J 的数字。First-order plant 上 PI 的 pole placement formula 来自 [Åström 与 Murray 第 10 章](http://www.cds.caltech.edu/~murray/books/AM08/pdf/am08-pid_28Sep12.pdf)（上一次写这页时读的）。Ziegler–Nichols 的两张表、Example 6.1 与 6.2 的 plant、quarter amplitude decay、$C(j\omega_u)=0.6K_u(1+0.467j)$ 与 $M_s>2$ 的论证、trial-and-error 的四条规则和 integrator 的反例，来自 [Åström 与 Hägglund 第 6 章](https://skoge.folk.ntnu.no/puublications_others/books/%C3%85strom-2006_Advanced%20PID%20Control/6.PID%20Design.pdf)；PI 一行原文系数的差别来自 [Åström 与 Murray 的 errata 页](https://www.cds.caltech.edu/~murray/amwiki/Ziegler-Nichols_tuning_rules_don't_quite_match_the_original_gains_from_the_Ziegler-Nichols_paper.html)，Ziegler 与 Nichols 1942 年的原文没有读。Velocity loop 套 position loop 的结构和 Puma 560 joint 的参数取自 Corke 书配套的 [RVC3-python](https://github.com/petercorke/RVC3-python) 仓库里的 `vloop.py`、`ploop.py`、`ploop_test.py`，书的正文没有读到；两层 pole、load 下的 error、feedforward 的模拟是为这一页算的。Current loop 的数字、$K_i$ 的数表、error area 的论证、Ziegler–Nichols 两组 gain 的 overshoot 与 $M_s$、Ziegler–Nichols 在 Joint J 上的实算，也是为这一页做的。

## [real] 真机上的 saturation、windup、noise 与 sampling

:::skip
能解释 actuator saturation 怎样让 integral wind up 并给出两种 anti-windup，能算出 encoder quantization 经 finite difference 后造成的 torque spike，能用 $z$ 的 root 判断一个 sampled loop 的 stability，就可以去第 4 站。
:::

### Saturation：loop 断开了

上一站的 PD 在 $t=0$ 时要的 torque 是 $K_p\times\pi/2=31.4$ N·m，motor 只有 3 N·m。只要 torque 停在上限，它就和 error 无关，feedback loop 实际上是断开的，closed-loop pole 不再描述 system。PD 在 saturation 下仍然到达同一个终点（还是差 5.6°），只是慢一些。加上 integral 就不一样了。

### Integral windup

Torque 卡在上限的这段时间里，error 一直很大，integral 照常往上积。模拟 $K_i=100$：

| 情形 | Integral term 的最大值 | Overshoot |
|---|---|---|
| 没有 torque limit | 12.1 N·m | 22.7° |
| 3 N·m limit，不做处理 | 27.3 N·m | 54.1° |
| 3 N·m limit，clamping | 5.5 N·m | 7.9° |
| 3 N·m limit，back-calculation，$T_t=0.05$ s | | 4.3° |
| 3 N·m limit，back-calculation，$T_t=0.01$ s | | 2.9° |

不做处理时，integral term 一项就要 27 N·m，是 motor 能力的 9 倍。Link 过了水平之后 error 变号，但 P term 抵消不了这么大的 integral，torque 继续顶在 +3 N·m 往前推，直到 integral 被负的 error 慢慢消掉。这就是开头的第二次实验。

::fig[rb2203-windup] 表中前三种情形。右边是 integral term 的大小：不处理时它在 saturation 期间一路涨到 27 N·m，要靠 link 冲过头产生的负 error 才能降回 1.96 N·m。

治法是 actuator saturate 时不让 integral 再往 saturation 的方向积：

- **Clamping**（conditional integration）：算出的 command $u$ 超过 limit，而且 error 和 $u$ 同号时，这一步不积分。
- **Back-calculation**：把“实际给出的 torque 减去算出的 command”feed back 给 integrator，$\dfrac{d}{dt}\Big(K_i\!\int\!e\Big)=K_ie+\dfrac{\tau-u}{T_t}$。没有 saturation 时 $\tau=u$，这一项为 0；saturate 时 integral term 以 time constant $T_t$ 被拉回到刚好让 $u$ 等于 limit 的地方。$T_t$ 越小拉得越快，但太小时 noise 一碰到 limit 就把 integral 清掉。

表里有个现象：有 torque limit 加 clamping（7.9°）比没有 limit（22.7°）还好。上一站的 area 论证说明了原因：没有 limit 时，link 快速逼近的那段 error 全被积进去；clamping 在这段时间冻结了 integral。

Robot 被人用手按住、或者 end-effector 顶在墙上时，也会 wind up：$e=0.5$ rad 持续 1 s，integral term 涨到 $100\times0.5\times1=50$ N·m，一松手 arm 就甩出去。Manipulation 里常常干脆不用 integral，原因之一就是这个。

### Derivative noise

Joint J 的 link 一侧装着一个 12-bit absolute encoder，分辨率 $q=2\pi/4096=1.53\times10^{-3}$ rad。$\dot\theta$ 只能由相邻两次读数相减除以 sampling period $h=1$ ms 得到。读数跳一格，算出的 velocity 就是

$$\frac{1.53\times10^{-3}}{0.001}=1.53\ \text{rad/s},\qquad K_d\times1.53=1.9\times1.53=2.9\ \text{N·m}$$

一格 quantization 就用掉了整个 3 N·m 的 torque budget。让 Joint J 跟踪 $\theta_d=0.5\sin\pi t$（velocity 最大时大约每毫秒跳一格），derivative term 造成的 torque jitter 的 RMS 是 1.09 N·m，最大 2.99 N·m。Motor 会发出啸叫，gear 会磨损。

::fig[rb2203-dnoise] 跟踪 $0.5\sin\pi t$ 时 torque command 的一段（含 gravity compensation）。直接差分的那条每跳一格就上下跳近 3 N·m；加了 5 ms filter 的那条贴着没有 quantization 的理想曲线。

办法是先给 velocity 做 low-pass filter 再乘 $K_d$。最简单的 first-order filter 每个 sample 做一次

$$\hat v_k=a\,\hat v_{k-1}+(1-a)\,\frac{\theta_k-\theta_{k-1}}{h},\qquad a=\frac{T_f}{T_f+h}$$

$a$ 在 0 和 1 之间，所以这个 recursion 对任何 $h$ 都 stable。$T_f$ 越大越平滑，但 filter 本身是一段 delay，会压低能用的最大 gain。在 1 kHz、带一个 sample 的 computation delay、按 $\zeta=1$ 设计的条件下：

| $T_f$ | 0 | 2 ms | 5 ms | 10 ms | 20 ms |
|---|---|---|---|---|---|
| Torque jitter 的 RMS（N·m） | 1.09 | 0.30 | 0.15 | 0.086 | 0.051 |
| 仍然 stable 的最大 $\omega_n$（rad/s） | 323 | 213 | 161 | 124 | 93 |

Joint J 用的是 $\omega_n=20$，$T_f=5$ ms 把 jitter 降到七分之一，stability 余量仍然很大。Åström 与 Murray 的建议是 $T_f=(K_d/K_p)/N$，$N$ 取 2 到 20；这里 $K_d/K_p=0.095$ s，5 ms 对应 $N=19$。

另外两件事：

- **Derivative 作用在 measurement 上。** 如果写成 $K_d\dot e$，$\theta_d$ 突然改 0.2 rad 的那一个 sample 里，$\dot e$ 是 $0.2/0.001=200$ rad/s，torque 要 380 N·m。用 $-K_d\dot\theta$ 就没有这一下；需要跟踪运动时，用第 5 站的 smooth trajectory 提供 $\dot\theta_d$。
- **Encoder 装在 motor 一侧。** 分辨率细了 $N=50$ 倍，spike 降到 0.058 N·m。但它量的是 motor 的 angle，gear 有 compliance 时这不等于 link 的 angle，第 4 站专门讲这个问题。

### Sampling 与 delay：先手算一个

Controller 每 $h$ 秒读一次 sensor、算一次、output 一次，output 保持到下一次（zero-order hold）。先看最简单的情形：joint 直接接受 velocity command，$\dot\theta=K_pe$。Continuous 时 $e(t)=e(0)e^{-K_pt}$，任何 $K_p>0$ 都 stable。

Sampled 版本：第 $k$ 个时刻算出 $K_pe_k$，在接下来 $h$ 秒里保持：

$$\theta_{k+1}=\theta_k+hK_pe_k\quad\Longrightarrow\quad e_{k+1}=(1-hK_p)\,e_k$$

每一步 error 乘上 $1-hK_p$，stable 当且仅当 $|1-hK_p|<1$，即 $0<hK_p<2$。$hK_p$ 在 1 和 2 之间时 error 每步变号，越过 2 就发散。

如果计算要用掉一个 sampling period，第 $k$ 步算出的 command 到第 $k+1$ 步才生效：

$$e_{k+1}=e_k-hK_pe_{k-1}$$

试 $e_k=z^k$，得 $z^2-z+hK_p=0$。两个 root 的乘积是 $hK_p$；$hK_p>\tfrac14$ 时它们是一对 complex conjugate，$|z|^2=hK_p$。所以 stable 当且仅当 $hK_p<1$。一个 sample 的 delay 让允许的 gain 减半。[RB4301 第 4 站](../courses/RB4301.html#s2r)用的就是这个式子。

::fig[rb2203-samplede] 从 $e_0=1$ 开始的 error 序列。左边 $hK_p$ 在 1 和 2 之间时每步变号，超过 2 发散；右边多了一个 sample 的 delay，$hK_p>1$ 就发散。

### Joint J 需要多快的 loop

Torque 驱动的 Joint J 是 second-order 的，再加上 finite difference 要记住上一次的 $\theta$、delay 要记住上一次的 command，sampled closed loop 有 4 个 state $(\theta_k,\dot\theta_k,\theta_{k-1},u_{k-1})$，写成 $x_{k+1}=Fx_k$。和上面一样，stable 当且仅当 $F$ 的所有 eigenvalue 满足 $|z|<1$，最大的那个 $|z|$ 记作 $\rho$，它是每个 sample error 缩小的倍数。$\omega_n=20$、$\zeta=1$ 的那组 gain：

| Sampling rate | 1000 Hz | 200 Hz | 100 Hz | 75 Hz | 65 Hz | 55 Hz |
|---|---|---|---|---|---|---|
| $\rho$ | 0.984 | 0.932 | 0.882 | 0.909 | 0.959 | 1.023 |
| 0.2 rad step 的 overshoot | 0 | 0 | 0 | 1.1% | 12.5% | 发散 |

（100 Hz 的 $\rho$ 比 200 Hz 的小，不是更好：$\rho$ 是每个 sample 的倍数，sample 长了一倍，同样的 decay rate 对应更小的 $\rho$。看 overshoot 一行。）$\rho$ 在 58 与 59 Hz 之间越过 1，低于 59 Hz 就不 stable 了。$\omega_n=20$ rad/s 对应 3.2 Hz，不 stable 的界线大约是它的 19 倍；要 response 和 continuous 的设计基本一样，要 30 倍左右。反过来，1 kHz 的 loop 能支持的最大 $\omega_n$ 约 323 rad/s。

::fig[rb2203-rate] 同一组 gain 在四个 sampling rate 下的 step response（含一个 sample 的 delay）。100 Hz 和 1 kHz 几乎重合，65 Hz 开始 overshoot，55 Hz 发散。

:::wrong Sampling rate 满足 Nyquist，比 signal 最高 frequency 的 2 倍高，就够了
[EE2023 第 7 站](../courses/EE2023.html#sampling)的 Nyquist rate 说的是能否从 sample 重建 signal。Control loop 的问题是 sample 和 delay 在 loop 里造成的 phase lag。Joint J 的 closed loop 在 3.2 Hz，按 Nyquist 6.4 Hz 就“够了”，实际 59 Hz 以下就发散。
:::

### 合在一起

一个 sampled PID 的完整写法（Python，$h$ 是 sampling period）：

```python
def pid_step(theta_d, theta, s, h, Kp=20.0, Ki=100.0, Kd=1.9, Tf=0.005, tau_max=3.0):
    # s 保存 integral、上一次的 theta、filter 过的 velocity
    a = Tf / (Tf + h)
    s.v = a * s.v + (1 - a) * (theta - s.theta_prev) / h   # filtered derivative
    s.theta_prev = theta
    e = theta_d - theta
    u = Kp * e + Ki * s.I - Kd * s.v                       # D 作用在 measurement 上
    tau = max(-tau_max, min(tau_max, u))
    if tau == u or e * u < 0:                              # clamping anti-windup
        s.I += e * h
    return tau
```

:::back
Joint 的 closed-loop 设计来自[第 2 站](#pid)；integral 的 area 论证解释了 clamping 为什么比不 saturate 还好。Delay 压低 gain 的手算和 [RB4301 第 4 站](../courses/RB4301.html#s2r) 是同一个式子。
:::

:::from
Windup 的机理、back-calculation、derivative filter 的形式与 $N$ 的取值、setpoint weighting（这里只用了 $\gamma=0$ 即 D 作用在 measurement 上）、离散实现的顺序，来自 [Åström 与 Murray 第 10 章](http://www.cds.caltech.edu/~murray/books/AM08/pdf/am08-pid_28Sep12.pdf)。“integrated error 要设上限”“gain 太高时 discrete-time 实现、actuator limit 会让 robot 不 stable”来自 [Modern Robotics 11.4](https://modernrobotics.northwestern.edu/nu-gm-book-resource/11-4-motion-control-with-torque-or-force-inputs-part-2-of-3/) 的逐字稿，书本 11.4.1 节把 $K_p$ 的实际上限列为四条：actuator saturation、torque 快速变化造成的 chattering、未建模的 flexibility 引起的 vibration、有限的 servo rate，并说实际的 robot controller 常取 $K_i=0$；“integral 只在接近目标时用，快速运动时会 wind up”来自 [CS223A 第 14 讲](https://see.stanford.edu/materials/aiircs223a/transcripts/IntroductionToRobotics-Lecture14.html)；“robot 被墙挡住时 integral wind up，所以 manipulation 常常不用”来自 [6.4210 的 force control 一章](https://manipulation.mit.edu/force.html)。Velocity input 的 discrete 分析、encoder 的数字、所有数表和 step response，是为这一页算的。
:::

## [ss] State space：linearization、state feedback 与 LQR

:::skip
能在一个 equilibrium 附近 linearize 出 $A$、$B$，用 coefficient matching 求 state feedback gain 并用 controllability matrix 判断能不能做到；能说清 flexible joint 上为什么只用 link 的 PD 永远不 stable；能推出只罚 position 的 LQR 给出 $\zeta=1/\sqrt2$，就可以去第 5 站。
:::

### 把 joint 写成 state space

取 state $x=(\theta,\dot\theta)$，Joint J 是

$$\dot x=f(x,u)=\begin{pmatrix}\dot\theta\\[2pt]\big(u-b\dot\theta-mgr\cos\theta\big)/M\end{pmatrix}$$

$\cos\theta$ 让它是 nonlinear 的。在 equilibrium $(x_0,u_0)$ 附近，令 $x=x_0+\delta x$，$u=u_0+\delta u$，把 $f$ 展开到 first order：$\delta\dot x\approx A\,\delta x+B\,\delta u$，$A$ 和 $B$ 是 $f$ 对 $x$、$u$ 的 partial derivative。这里

$$A=\begin{pmatrix}0&1\\[2pt]\dfrac{mgr\sin\theta_0}{M}&-\dfrac bM\end{pmatrix},\qquad B=\begin{pmatrix}0\\[2pt]\dfrac1M\end{pmatrix}$$

三个 equilibrium，$A$ 的 eigenvalue 由 $\lambda^2+2\lambda-39.24\sin\theta_0=0$ 给出（$b/M=2$，$mgr/M=39.24$）：

| $\theta_0$ | 维持它的 torque $u_0$ | $A$ 的 eigenvalue | 意思 |
|---|---|---|---|
| $0$（水平） | 1.962 N·m | $0,\ -2$ | 没有额外 torque 时停在哪都行，velocity 慢慢 decay |
| $-\pi/2$（向下） | 0 | $-1\pm6.18j$ | Pendulum，6.2 rad/s 摆动 |
| $+\pi/2$（竖直向上） | 0 | $5.34,\ -7.34$ | 倒立，一碰就倒 |

Eigenvalue 就是 [EE2023 第 5 站](../courses/EE2023.html#pz)的 pole。

### PD 就是 state feedback

令 $\delta u=-K\delta x=-(K_1\delta\theta+K_2\delta\dot\theta)$，closed loop 是 $\delta\dot x=(A-BK)\delta x$：

$$A-BK=\begin{pmatrix}0&1\\[2pt]\dfrac{mgr\sin\theta_0-K_1}{M}&-\dfrac{b+K_2}M\end{pmatrix},\qquad\det(sI-A+BK)=s^2+\frac{b+K_2}{M}s+\frac{K_1-mgr\sin\theta_0}{M}$$

和 $s^2+2\zeta\omega_ns+\omega_n^2$ 对比 coefficient：

$$K_1=M\omega_n^2+mgr\sin\theta_0,\qquad K_2=2\zeta\omega_nM-b$$

水平位置 $K_1=20$、$K_2=1.9$，正是第 2 站的 PD。竖直向上时 $K_1=20+1.962=21.96$，多出来的部分恰好抵消 gravity 的“负 spring”。

两个 gain 对两个 coefficient，所以 pole 想放哪就放哪。一般地，$n$ 个 state 的 system，能不能这样任意放 pole，看 controllability matrix

$$W_r=\begin{pmatrix}B&AB&A^2B&\cdots&A^{n-1}B\end{pmatrix}$$

是否 rank $n$。Joint J：$AB=\big(\tfrac1M,\ -\tfrac{b}{M^2}\big)^\top$，$W_r=\begin{pmatrix}0&1/M\\1/M&-b/M^2\end{pmatrix}$，determinant $-1/M^2\ne0$，rank 2。

### 两个 state 不够的时候：flexible joint

:::skip
NUS 大纲的 state space 一项只写到 state equation 和 linearized robot system。跳过这一节会少掉“为什么 link 一侧的 PD 永远不 stable”和 full state feedback 的一个实际用处；第 5 站最后一节要用到这里的 flexible joint。
:::

真实的 gear（尤其是 harmonic drive）有 torsional stiffness。把 Joint J 拆成 motor 一侧的 inertia $J_m=0.01$ 和 link 一侧的 $J_l=0.04$，中间是一根 stiffness $k=300$ N·m/rad 的 spring，torque 加在 motor 上（这里忽略 friction 和 gravity）：

$$J_m\ddot\theta_m=u-k(\theta_m-\theta_l),\qquad J_l\ddot\theta_l=k(\theta_m-\theta_l)$$

::fig[rb2203-flex] Flexible joint：torque 加在 motor 一侧，要控制的是 link 一侧，两者之间隔着 spring。Motor 一侧的 encoder 和 torque 在同一处（collocated），link 一侧的 encoder 隔着 spring（non-collocated）。

State 有四个：$(\theta_m,\dot\theta_m,\theta_l,\dot\theta_l)$。Motor 被锁住时 link 以 $\sqrt{k/J_l}=86.6$ rad/s vibrate；两边都自由时 resonance 在 $\sqrt{k(1/J_m+1/J_l)}=194$ rad/s。

**PD 作用在 link 的 angle 上。** 这是最想做的：要控制的是 link。做 Laplace transform，由第二式 $\Theta_m=\dfrac{J_ls^2+k}{k}\Theta_l$，代进第一式：

$$\frac{(J_ms^2+k)(J_ls^2+k)-k^2}{k}\,\Theta_l=U\quad\Longrightarrow\quad\frac{J_mJ_ls^4+k(J_m+J_l)s^2}{k}\,\Theta_l=U$$

令 $U=-(K_p+K_ds)\Theta_l$：

$$J_mJ_ls^4+k(J_m+J_l)s^2+kK_ds+kK_p=0$$

没有 $s^3$ 这一项。所有 root 都在 left half-plane 的 polynomial 可以写成若干个 $(s+\alpha)$ 和 $(s^2+\beta s+\gamma)$ 的 product，$\alpha,\beta,\gamma>0$，展开后每个 coefficient 都是正的。少了一项，就不可能 stable，无论 $K_p$、$K_d$ 取什么。$\omega_n=20$ 的那组 gain 给出的 pole 是 $19.6\pm195.6j$ 和 $-19.6\pm2.0j$。

**PD 作用在 motor 的 angle 上。** 令 $U=-(K_p+K_ds)\Theta_m$，同样消去 $\Theta_l$：

$$J_mJ_ls^4+K_dJ_ls^3+\big(J_mk+J_lK_p+J_lk\big)s^2+K_dks+K_pk=0$$

每一项都是正的（这只是必要条件，算出来确实 stable）。但它只直接管住 motor，link 的 vibration 只能靠 spring 间接带过去。Gain 小时没问题；想让 joint 快一点，把 $\omega_n$ 往 link 的 resonance 推，link 的那对 pole 反而越来越靠近 imaginary axis。

**Full state feedback。** $u=k_rr-K x$，$K$ 有四个 entry，对四个 coefficient，任意放 pole；controllability matrix $\begin{pmatrix}B&AB&A^2B&A^3B\end{pmatrix}$ 算出来 rank 4，所以做得到。$k_r$ 让 link 的 steady state 等于 reference。下表把四个 pole 放在 $-\omega_n,\ -1.5\omega_n,\ -2\omega_n,\ -2.5\omega_n$，和 motor 一侧 PD（gain 按总 inertia 0.05 算）比较，都是 0.1 rad 的 step：

| 设计的 $\omega_n$ | Motor PD：overshoot | Motor PD：2% settling | Motor PD：peak torque | State feedback：settling | State feedback：peak torque |
|---|---|---|---|---|---|
| 20 | 0 | 0.289 s | 2.0 N·m | 0.305 s | 0.63 N·m |
| 60 | 5.0% | 0.122 s | 18 N·m | 0.101 s | 13 N·m |
| 80 | 21.9% | 0.192 s | 32 N·m | 0.076 s | 41 N·m |
| 100 | 35.7% | 0.302 s | 50 N·m | 0.061 s | 100 N·m |

（State feedback 都没有 overshoot。）Motor PD 在 $\omega_n=60$ 附近最好，再往上调，link 的 pole 从 $-25\pm74.7j$ 走到 $-11.2\pm78.7j$，越来越晃。State feedback 能继续变快，代价是两样：要同时测 motor 和 link 两侧（很多新的 robot joint 两侧都装了 encoder），以及 torque 跟着涨。Khatib 在 CS223A 里说的“closed-loop frequency 要远离 structural resonance”，量化出来就是这张表的左半边。

### LQR：不放 pole，改为规定代价

:::skip
大纲没有列 LQR。跳过它只少掉“用代价代替 pole 位置”的设计方法，后面各站不再用到。
:::

State 一多，“把 pole 放在哪”就很难凭感觉选。LQR 换一个问法：让 state 偏离和用掉的 torque 的总代价最小，

$$J=\int_0^\infty\big(x^\top Qx+u^\top Ru\big)\,dt$$

最优的 $u$ 是 linear state feedback $u=-Kx$，$K=R^{-1}B^\top S$，$S$ 是 algebraic Riccati equation 的 symmetric positive definite solution：

$$SA+A^\top S-SBR^{-1}B^\top S+Q=0$$

对 $M\ddot\theta=u$（Joint J 去掉 friction 和 gravity）可以手解。$A=\begin{pmatrix}0&1\\0&0\end{pmatrix}$，$B=\begin{pmatrix}0\\1/M\end{pmatrix}$，$Q=\begin{pmatrix}q_1&0\\0&q_2\end{pmatrix}$，$R=r$，设 $S=\begin{pmatrix}s_1&s_2\\s_2&s_3\end{pmatrix}$。逐项算：

$$SA=\begin{pmatrix}0&s_1\\0&s_2\end{pmatrix},\quad A^\top S=\begin{pmatrix}0&0\\s_1&s_2\end{pmatrix},\quad SBR^{-1}B^\top S=\frac{1}{rM^2}\begin{pmatrix}s_2^2&s_2s_3\\s_2s_3&s_3^2\end{pmatrix}$$

Riccati equation 的 $(1,1)$ entry：$-\dfrac{s_2^2}{rM^2}+q_1=0$，所以 $s_2=M\sqrt{rq_1}$。$(2,2)$ entry：$2s_2-\dfrac{s_3^2}{rM^2}+q_2=0$，所以 $s_3=M\sqrt{r(2s_2+q_2)}$。$(1,2)$ entry 只决定 $s_1$，求 $K$ 用不到。

$$K=\frac1r\begin{pmatrix}0&\tfrac1M\end{pmatrix}S=\frac{1}{rM}\begin{pmatrix}s_2&s_3\end{pmatrix}=\begin{pmatrix}\sqrt{q_1/r}&\sqrt{2MK_1+q_2/r}\end{pmatrix}$$

$M=1$、$Q=I$、$R=1$ 时 $K=(1,\sqrt3)$，和 Underactuated 讲义里 double integrator 的结果一致。

只罚 position（$q_2=0$）时，$K_2=\sqrt{2MK_1}$，closed loop $Ms^2+K_2s+K_1$ 的 damping ratio 是

$$\zeta=\frac{K_2}{2\sqrt{MK_1}}=\frac{\sqrt{2MK_1}}{2\sqrt{MK_1}}=\frac{1}{\sqrt2}$$

与 $q_1$、$r$ 无关。$q_1/r$ 只决定快慢，形状永远是 $\zeta=0.707$。

$q_1$、$r$ 怎么取？Bryson's rule：取 $q_1=1/\theta_{\max}^2$、$r=1/\tau_{\max}^2$，$\theta_{\max}$、$\tau_{\max}$ 是“可以接受的最大 error”和“可以接受的最大 torque”。那么 $K_1=\tau_{\max}/\theta_{\max}$：允许 0.05 rad 的 error、3 N·m 的 torque，$K_1=60$，$K_2=\sqrt{2\times0.05\times60}=2.45$。带上 $b=0.1$ 用数值解 Riccati equation，$K=(60,\ 2.35)$，pole 在 $-24.5\pm24.5j$，$\zeta=0.708$；总 damping $b+K_2=\sqrt{b^2+2MK_1}$，friction 只是从 $K_2$ 里扣掉了一点。

:::wrong 想控制 link，就用 link 的 angle 做 feedback
看起来最直接，却正好是上面那个缺了 $s^3$ 项的 polynomial：只用 link 一侧的 PD，flexible joint 不可能 stable。Link 一侧的 sensor 要用，就要连同 motor 一侧的 state 一起做 full state feedback，或者只拿它来修正慢的 offset。
:::

:::back
Pole 与 stability 来自 [EE2023 第 5 站](../courses/EE2023.html#pz)。Controllability 在[第 8 站](#mobile)还会出现一次：mobile robot 的 reference 停下来时，linearized system 的 $W_r$ 掉 rank。
:::

:::from
Reachability matrix、coefficient matching、$k_r$ 的写法和 Bryson's rule 来自 [Åström 与 Murray 第 6 章](http://www.cds.caltech.edu/~murray/books/AM08/pdf/am08-statefbk_28Sep12.pdf)。LQR 的 formulation、$K=R^{-1}B^\top S$、Riccati equation 和 double integrator 的 $K=(1,\sqrt3)$ 来自 [Underactuated Robotics 的 LQR 一章](https://underactuated.csail.mit.edu/lqr.html)；那一章没有给出手算过程，这里的逐项推导和 $\zeta=1/\sqrt2$ 的结论是自己推的。“gain 不能高到碰上 structural flexibility”来自 [CS223A 第 14 讲](https://see.stanford.edu/materials/aiircs223a/transcripts/IntroductionToRobotics-Lecture14.html)。Flexible joint 的两个 mass 加一根 spring 的 model、用全部四个 state 做 feedback 的思路，和 Corke 书 9.6.2 节 series-elastic actuator 的配套代码（[RVC3-python](https://github.com/petercorke/RVC3-python) 的 `SEA.py`：motor 0.5、load 1、spring 5，四个 state 的 LQR gain）是同一个结构，书的正文没有读到。两个 characteristic polynomial、“link 一侧的 PD 缺 $s^3$ 项所以永远不 stable”的论证和数表，是凭自己的知识推导、为这一页算的，没有找到对照的讲义。

## [traj] Trajectory planning 与 tracking

:::skip
能写出 cubic、quintic、trapezoidal 三种 profile 并说出它们的 velocity 和 acceleration 最大值，能过 via point 解出 cubic spline 的 velocity，能说清 feedforward 在 tracking 里做了什么，就可以去第 6 站。
:::

### 为什么不直接给一个 step

前两站的麻烦大多出在 step 上：一开始 error 就有 1.57 rad，torque 要 31 N·m，saturation、windup、integral 的 overshoot 接踵而来。换一种给法：让 $\theta_d(t)$ 在 $T=1$ s 内平滑地从 $-90°$ 走到 $0°$，每一刻的 error 都很小。下面会算到，这样跟踪只需要 2 N·m 左右的 torque。

Trajectory 是 path 加 time scaling：$\theta_d(t)=\theta_0+\Delta\,s(t)$，$s$ 从 0 走到 1，$\Delta=\theta_f-\theta_0$。Velocity 是 $\Delta\dot s$，acceleration 是 $\Delta\ddot s$。下面都用 $\sigma=t/T$。

### Cubic

Rest-to-rest：起点和终点 velocity 为 0。$\dot s$ 在 $\sigma=0$ 和 $\sigma=1$ 都为 0，最简单的 polynomial 是 $\dot s\propto\sigma(1-\sigma)$。Integral $\int_0^1\sigma(1-\sigma)\,d\sigma=\tfrac16$，要让 $s$ 从 0 走到 1，coefficient 是 6：

$$\frac{ds}{d\sigma}=6\sigma(1-\sigma)\quad\Longrightarrow\quad s=3\sigma^2-2\sigma^3$$

Maximum velocity 在 $\sigma=\tfrac12$：$\dot s=\tfrac{6}{4T}=\dfrac{1.5}{T}$。Acceleration $\ddot s=\dfrac{6-12\sigma}{T^2}$，在 $t=0$ 从 0 跳到 $6/T^2$。

### Quintic

要 acceleration 在两端也为 0，$\dot s$ 在两端就要有 double zero：$\dot s\propto\sigma^2(1-\sigma)^2$。$\int_0^1\sigma^2(1-\sigma)^2\,d\sigma=\tfrac1{30}$，所以

$$\frac{ds}{d\sigma}=30\sigma^2(1-\sigma)^2\quad\Longrightarrow\quad s=10\sigma^3-15\sigma^4+6\sigma^5$$

Maximum velocity $30/16=1.875/T$。Acceleration $60\sigma(1-\sigma)(1-2\sigma)/T^2$，对 $\sigma$ 求 derivative 令其为 0 得 $\sigma=\tfrac12\pm\tfrac{1}{2\sqrt3}$，maximum 是 $\dfrac{10}{\sqrt3}\dfrac1{T^2}=\dfrac{5.77}{T^2}$。

### Trapezoidal

先以 constant acceleration $a$ accelerate $t_a$ 秒，以 constant velocity $v$ 走一段，最后对称地 decelerate。Velocity curve 下的 area 是走过的 distance：$v(T-t_a)=1$，所以 $v=\dfrac{1}{T-t_a}$，$a=\dfrac{v}{t_a}$。取 $t_a=T/3$：$v=1.5/T$，$a=4.5/T^2$。$t_a=T/2$ 时没有匀速段，$a=4/T^2$：给定 acceleration 上限，这是最快的 rest-to-rest。

::fig[rb2203-profiles] 三种 time scaling 的 $s$、$\dot s$、$\ddot s$（$T=1$）。Cubic 和 trapezoidal 的 acceleration 有跳变，quintic 两端从 0 开始。

| Profile | $\max\dot s\cdot T$ | $\max|\ddot s|\cdot T^2$ | Acceleration 有没有跳变 |
|---|---|---|---|
| Cubic | 1.5 | 6 | 两端跳 |
| Trapezoidal（$t_a=T/3$） | 1.5 | 4.5 | 四处跳 |
| Quintic | 1.875 | 5.77 | 没有 |

### 过 via point：cubic spline

要经过中间的点（绕开障碍物），每两个点之间用一段 cubic。一段 cubic 有 4 个 coefficient，由两端的 position 和 velocity 决定。中间点的 velocity 怎么选？要求 acceleration 在中间点连续。

一段从 $p_0$ 到 $p_1$、两端 velocity $v_0$、$v_1$、时长 $h$ 的 cubic，设 $p(\tau)=p_0+v_0\tau+c_2\tau^2+c_3\tau^3$。由 $p(h)=p_1$、$\dot p(h)=v_1$ 两个条件解出 $c_2$、$c_3$，两端的 acceleration 是

$$\ddot p(0)=\frac{6(p_1-p_0)}{h^2}-\frac{4v_0+2v_1}{h},\qquad\ddot p(h)=-\frac{6(p_1-p_0)}{h^2}+\frac{2v_0+4v_1}{h}$$

在中间点 $i$，令前一段的 $\ddot p(h)$ 等于后一段的 $\ddot p(0)$，整理得

$$v_{i-1}+4v_i+v_{i+1}=\frac{3\,(\theta_{i+1}-\theta_{i-1})}{h}$$

每个中间点一个 equation，只牵涉相邻三个 velocity，所以是 tridiagonal system，和 [DSA2102 第 6 站](../courses/DSA2102.html#interp)的 spline 一样。例子：$\theta=0,\ 0.6,\ 0.9,\ 1.0$ 在 $t=0,1,2,3$，两端 velocity 为 0：

$$4v_1+v_2=3\times0.9=2.7,\qquad v_1+4v_2=3\times0.4=1.2\quad\Longrightarrow\quad v_1=0.64,\ v_2=0.14$$

核对第一个中间点：前一段末端 $-6\times0.6+(0+4\times0.64)\cdot1=-1.04$，后一段起点 $6\times0.3-(4\times0.64+2\times0.14)=-1.04$，连续。如果按“相邻两段 slope 的平均”取 $v_1=0.45$、$v_2=0.2$，acceleration 在第一个中间点从 $-1.8$ 跳到 $-0.4$；如果每个中间点都停下，跳变是从 $-3.6$ 到 $1.8$。

::fig[rb2203-spline3] 三种选法都经过同样四个点，区别在 acceleration 是否连续。

### Tracking：feedforward 加 feedback

Trajectory 给出了每一刻的 $\theta_d$、$\dot\theta_d$、$\ddot\theta_d$。如果 model 是对的，跟着它走需要的 torque 可以直接算出来：

$$\tau_{ff}=M\ddot\theta_d+b\dot\theta_d+mgr\cos\theta$$

Feedback 只负责修正剩下的 error：$\tau=\tau_{ff}+K_pe+K_d\dot e$。代入 model，$M\ddot\theta+b\dot\theta+mgr\cos\theta=\tau$ 减去 $\tau_{ff}$ 那部分：

$$M\ddot e+(b+K_d)\dot e+K_pe=0$$

Error 一开始是 0 就永远是 0。Joint J 跟踪 $-90°$ 到 $0°$、$T=1$ s 的 quintic：

| Controller | 最大 tracking error | $t=1.5$ s 的 error | 最大 torque |
|---|---|---|---|
| PD（$K_d$ 作用在 $\dot e$ 上） | 5.59° | 5.59° | 1.99 N·m |
| PID，$K_i=100$ | 1.96° | 0.02° | 2.01 N·m |
| PD 加 gravity feedforward | 1.64° | 0 | 1.99 N·m |
| PD 加完整 feedforward | 0.00° | 0 | 1.96 N·m |
| 同上，但 model 的 $M$ 和 $mgr$ 都高估 20% | 1.12° | 1.12° | |

同样的运动，step 要 31 N·m，trajectory 只要 2 N·m。PID 的 overshoot 也没了：error 从头到尾都小，integral 积不出多余的 area。最后一行的 1.12° 是 gravity 多补了 $0.2\times1.962=0.39$ N·m，被 $K_p=20$ 顶出的 $0.39/20=0.0196$ rad。

### Smoothness 对 flexible joint 的意义

在第 4 站的 flexible joint 上，用 motor 一侧的 PD（$\omega_n=20$）加 rigid model 的 feedforward 走 1 rad。到达终点之后 spring 里残留的 vibration（motor 与 link 的 angle 之差）：

| $T$ | Cubic | Trapezoidal | Quintic |
|---|---|---|---|
| 0.3 s | 8.9 mrad | 6.7 mrad | 1.3 mrad |
| 0.4 s | 5.0 mrad | 3.7 mrad | 0.6 mrad |

:::wrong Peak acceleration 越小，trajectory 越温和
三者的 peak acceleration 是 trapezoidal 4.5 最小、quintic 5.77、cubic 6 最大，而残留的 vibration 是 quintic 最小、比 trapezoidal 小 5 倍。Spring 被激起多少 vibration，取决于 acceleration（也就是 torque）变化得有多突然。Trapezoidal 有四次跳变，每一次都是一记敲击；quintic 的 acceleration 连续，jerk 有界。
:::

:::edge 在 joint space 还是在 Cartesian space 规划
上面都是对 joint angle 规划，每个 joint 各自一条 profile，同时开始同时结束。这时 end-effector 走的是一条事先说不清的 curve。要 end-effector 走 straight line，就得在 Cartesian space 规划，每个 control cycle 做一次 inverse kinematics；这会碰上 reach 不到的中间点、singularity、以及起点终点分属不同的 IK branch 等问题。第 7 站的 resolved-rate control 是绕开逐点 IK 的一种办法。
:::

:::from
Time scaling 的概念，cubic、quintic、trapezoidal、S-curve 的对比，以及“cubic 和 trapezoidal 有 acceleration 跳变、会激起 vibration”的理由，来自 [Modern Robotics 9.1 与 9.2 第 2 部分](https://modernrobotics.northwestern.edu/nu-gm-book-resource/9-1-and-9-2-point-to-point-trajectories-part-2-of-2/)的逐字稿；公式对照了[书本](https://hades.mech.northwestern.edU/images/2/25/MR-v2.pdf)：cubic 的 $a_2=3/T^2$、$a_3=-2/T^3$，最大 velocity $\tfrac{3}{2T}$、最大 acceleration $6/T^2$，quintic 的最大 velocity $\tfrac{15}{8T}$，trapezoidal 的 $vaT=a+v^2$（这里 $t_a=T/3$ 时 $1.5\times4.5=4.5+1.5^2$）。书的 9.3 节给 via point 之间的 cubic 系数，via point 的 velocity 由使用者指定或按相邻点的启发式取，并明说这样 velocity 连续而 acceleration 不连续；这里要求 acceleration 也连续、解 tridiagonal system，是 spline 的做法。Via point 的 velocity 可以由连续性条件解出、joint space 与 Cartesian space 规划的取舍和 Cartesian straight line 的三种失败，来自 [CS223A 第 10 讲](https://see.stanford.edu/materials/aiircs223a/transcripts/IntroductionToRobotics-Lecture10.html)；那一讲没有写出公式。用“$\dot s$ 必须有几重 zero”推出 cubic 和 quintic、spline 的 tridiagonal equation、feedforward 的数表和 flexible joint 的 vibration 数表，是为这一页推和算的。
:::

## [joint] Manipulator 的 joint-space control

:::skip
能说出 Arm A 的 mass matrix 随 configuration 变多少、independent joint PD 因此差在哪；能用 energy 论证 PD 加 gravity compensation 在 setpoint 上没有 steady-state error；能推出 computed torque 的 error dynamics 并说明 model error 怎样进来，就可以去第 7 站。
:::

### Arm A 的 dynamics

两个 joint 的 arm 写成 manipulator equation（推导见 [RB2202](../courses/RB2202.html)）：

$$M(q)\ddot q+C(q,\dot q)\dot q+g(q)=\tau$$

Arm A 的两节 link 各 1 kg、长 0.4 m，center of mass 在中点，绕自身 center of mass 的 inertia $\tfrac1{12}ml^2=0.0133$。代进通用的 2-link 公式：

$$M(q)=\begin{pmatrix}0.2667+0.16\cos q_2&0.0533+0.08\cos q_2\\0.0533+0.08\cos q_2&0.0533\end{pmatrix}$$

$$C(q,\dot q)\dot q=0.08\sin q_2\begin{pmatrix}-2\dot q_1\dot q_2-\dot q_2^2\\\dot q_1^2\end{pmatrix},\qquad g(q)=\begin{pmatrix}5.886\cos q_1+1.962\cos(q_1+q_2)\\1.962\cos(q_1+q_2)\end{pmatrix}$$

$q_1$ 从水平量起，$q_2$ 是第二节相对第一节的 angle。Joint 1 感到的 inertia $M_{11}$ 在 arm 伸直（$q_2=0$）时是 0.427，折叠（$q_2=\pi$）时是 0.107，相差 4 倍。$M_{12}$ 不为 0：joint 2 有 acceleration 时，joint 1 也受到一个 torque。

任务：在 $T=1$ s 内用 quintic 从 $q=(-90°,0°)$（垂下）走到 $(0°,90°)$（大臂水平、小臂竖直向上）。

### Independent joint PD

最简单的做法是把每个 joint 当成第 2 站的 Joint J，各自一个 PD，耦合项和 gravity 都当 disturbance。$M_{11}$ 会变，取哪个值设计？取最小和最大的 geometric mean $\sqrt{0.107\times0.427}=0.213$，按 $\omega_n=20$、$\zeta=1$：$K_{p1}=85.3$，$K_{d1}=8.53$；joint 2 的 $M_{22}$ 不变，$K_{p2}=21.3$，$K_{d2}=2.13$。实际上 joint 1 的 $\omega_n=\sqrt{85.3/M_{11}}$ 在 14.1 到 28.3 rad/s 之间变，geometric mean 让两头偏离的倍数一样（都是 $\sqrt2$）。

结果：最大 tracking error joint 1 是 4.23°，joint 2 是 6.91°；到终点后 joint 1 停在差 4.04° 的地方。和 Joint J 一样，是 gravity。

### PD 加 gravity compensation

把 gravity 用 model 直接补上：

$$\tau=K_p(q_d-q)-K_d\dot q+g(q)$$

对 setpoint（$q_d$ 不变），这个 controller 不论 $M(q)$ 怎么变都能让 $q\to q_d$，可以用 energy 证明。设 $e=q_d-q$，取 kinetic energy 加上 $K_p$ 这根“虚拟 spring”的 potential energy：

$$V=\tfrac12\dot q^\top M(q)\dot q+\tfrac12e^\top K_pe$$

求 time derivative，$\dot e=-\dot q$：

$$\dot V=\dot q^\top M\ddot q+\tfrac12\dot q^\top\dot M\dot q-\dot q^\top K_pe$$

由 dynamics，$M\ddot q=\tau-C\dot q-g=K_pe-K_d\dot q-C\dot q$，代入后 $K_pe$ 那两项抵消：

$$\dot V=-\dot q^\top K_d\dot q+\dot q^\top\big(\tfrac12\dot M-C\big)\dot q$$

最后一项是 0，物理意思是 Coriolis force 和 centrifugal force 不做 work。对 Arm A 直接核对：$\dot M$ 只来自 $\cos q_2$，$\tfrac12\dot q^\top\dot M\dot q=\tfrac12\big(-0.16\sin q_2\,\dot q_2\dot q_1^2-2\times0.08\sin q_2\,\dot q_2\dot q_1\dot q_2\big)=-0.08\sin q_2\,(\dot q_1^2\dot q_2+\dot q_1\dot q_2^2)$；$\dot q^\top C\dot q=0.08\sin q_2\big(\dot q_1(-2\dot q_1\dot q_2-\dot q_2^2)+\dot q_2\dot q_1^2\big)=-0.08\sin q_2\,(\dot q_1^2\dot q_2+\dot q_1\dot q_2^2)$，两者相等。

所以 $\dot V=-\dot q^\top K_d\dot q\le0$：只要在动，energy 就在减少。$\dot V$ 里没有 $e$，所以还要说明 arm 不会停在 $e\ne0$ 的地方：假如某一刻 $\dot q=0$ 而 $e\ne0$，dynamics 给出 $M\ddot q=K_pe\ne0$，arm 马上又动起来，energy 继续减少。能一直停住（$\dot q$ 恒为 0，于是 $\ddot q=0$）的只有 $K_pe=0$，即 $e=0$。这一步叫 Krasovskii–LaSalle invariance principle。论证对任意多个 joint、任意 symmetric positive definite 的 $K_p$、$K_d$ 都成立（前提是 friction 忽略、gravity model 准确）。

跟踪同一条 trajectory：最大 error 3.35° 和 4.72°，终点 error 0。

### Computed torque

:::skip
NUS 大纲在 manipulator 一项下没有列 computed torque。跳过这一节和下一节，会少掉“用完整 model 把 error dynamics 变成 linear、decoupled”以及 model 不准时它怎样失效；第 7 站的 operational space control 是它在 task space 的版本。
:::

Tracking 时 error 仍然有几度，因为 inertia 和 coupling 没补。把整个 model 都用上：

$$\tau=M(q)\big(\ddot q_d+K_p'e+K_d'\dot e\big)+C(q,\dot q)\dot q+g(q)$$

代进 dynamics，$C\dot q$ 和 $g$ 两边抵消，剩下 $M(q)\ddot q=M(q)(\ddot q_d+K_p'e+K_d'\dot e)$。$M(q)$ 总是 invertible（它是 SPD），两边左乘 $M^{-1}$：

$$\ddot e+K_d'\dot e+K_p'e=0$$

Nonlinear、coupled 的 arm 变成了两个互不相干的 unit-mass system，每个 joint 的 error dynamics 和 configuration 无关。取 $K_p'=400$、$K_d'=40$（$\omega_n=20$，$\zeta=1$），最大 tracking error 是 0.000°。

::fig[rb2203-armtrack] 左：Arm A 和它的变量。右：跟踪同一条 quintic 时 tracking error（两个 joint 合起来的大小）随 time 的变化。

### Model 不准的时候

Gripper 抓起一个 0.5 kg 的东西，model 不知道：

| Controller | Joint 1 最大 error | Joint 2 最大 error | 终点 error |
|---|---|---|---|
| Computed torque，model 准确 | 0.000° | 0.000° | 0 |
| Computed torque，0.5 kg payload 未建模 | 3.38° | 15.3° | 1.32°、1.27° |
| PD 加 gravity compensation，同样的 payload | 6.86° | 13.2° | 1.35°、0.14° |

Model error 怎样进来？把真实的 $M,C,g$ 和 controller 用的 $\hat M,\hat C,\hat g$ 分开写，同样的代入得到

$$\ddot e+K_d'\dot e+K_p'e=\hat M^{-1}\big[(M-\hat M)\ddot q+(C-\hat C)\dot q+(g-\hat g)\big]$$

右边是一个 disturbance，被 $\hat M^{-1}$ 换算成 acceleration。Joint 2 的 $\hat M_{22}K_p'=0.0533\times400=21.3$ N·m/rad，和 independent PD 的 $K_{p2}$ 一样大；payload 在 0.4 m 处的 gravity torque 最大是 $0.5\times9.81\times0.4=1.96$ N·m，单这一项就能顶出 $1.96/21.3=0.092$ rad，约 5°，再加上 inertia 的 error。“stiffness”没有变大，model 又错了，computed torque 就没有优势。

:::wrong Computed torque 用了完整的 model，所以总比 PD 好
它把 error dynamics 变成 linear、decoupled 的前提是 model 准确。上表里 payload 一来，joint 2 的最大 error 比 PD 加 gravity compensation 还大（15.3° 对 13.2°）。实际 robot 上常用的是更简单的 PD 加 gravity compensation（MIT 6.4210 里 KUKA iiwa 的 joint impedance mode 就是这个结构，典型 stiffness 是每个 joint 200 到 800 N·m/rad），或者在 computed torque 上再加 integral、加 payload 估计。
:::

:::edge 每个 control cycle 都要算 $M(q)$ 和 $C(q,\dot q)\dot q$
Joint 多了以后计算量不小。直接需要的是 $M(q)\,a+C\dot q+g$ 这个 vector，不需要 $M$ 这个 matrix 本身，可以用 recursive Newton–Euler 一遍算出，计算量与 joint 数成正比（见 [RB2202](../courses/RB2202.html)）。
:::

:::back
Unit-mass 的 error dynamics 和第 2 站的 PD 是同一个 second-order system；feedforward 的思路来自[第 5 站](#traj)。
:::

## [task] Task-space control：Jacobian、resolved-rate 与 Cartesian stiffness

:::skip
能用 Jacobian 把 end-effector velocity 换成 joint velocity 并说出 singularity 附近会发生什么；能解释 Jacobian transpose control 为什么走弯路、operational space control 怎样把路拉直；能算出用 Cartesian stiffness 压在桌面上的 force，就可以去第 8 站。
:::

### Jacobian

上一站规定的是 joint 怎么动。很多任务规定的是 end-effector 怎么动：沿 straight line 擦桌子、把杯子平移到另一个 position。Arm A 的 end-effector position $x=\big(l_1\cos q_1+l_2\cos(q_1+q_2),\ l_1\sin q_1+l_2\sin(q_1+q_2)\big)$，对 time 求 derivative：

$$\dot x=J(q)\,\dot q,\qquad J(q)=\begin{pmatrix}-l_1\sin q_1-l_2\sin(q_1+q_2)&-l_2\sin(q_1+q_2)\\l_1\cos q_1+l_2\cos(q_1+q_2)&l_2\cos(q_1+q_2)\end{pmatrix}$$

这一站反复用的 configuration 是 $q=(0,90°)$，end-effector 在 $(0.4,\,0.4)$：

$$J=\begin{pmatrix}-0.4&-0.4\\0.4&0\end{pmatrix},\qquad\det J=0.16,\qquad J^{-1}=\begin{pmatrix}0&2.5\\-2.5&-2.5\end{pmatrix}$$

### Resolved-rate control

如果 joint 能可靠地执行 velocity command（各自有第 2 站那样的 velocity loop），task space 的 control 可以完全在 kinematics 层面做：

$$\dot q=J(q)^{-1}\big(\dot x_d+K(x_d-x)\big)$$

代回 $\dot x=J\dot q$ 得 $\dot x=\dot x_d+K(x_d-x)$，即 error $e=x_d-x$ 满足 $\dot e=-Ke$，exponential 地收敛，end-effector 沿 straight line 回到 trajectory 上。不需要逐点解 inverse kinematics，每个 cycle 只解一个 $2\times2$ 的 linear system。

在 $q=(0,90°)$：end-effector 要以 0.1 m/s 向 $+x$ 走，$\dot q=J^{-1}(0.1,0)^\top=(0,\,-0.25)$，只有 joint 2 转；向 $+y$ 走，$\dot q=(0.25,\,-0.25)$，joint 1 正转、joint 2 反转同样多，小臂保持竖直平移。

### Singularity

$\det J=l_1l_2\sin q_2$，$q_2=0$ 或 $\pi$ 时 $J$ 不 invertible：arm 伸直或折叠，end-effector 沿 radial 方向一阶上动不了。接近 singularity 时会发生什么？离 base 的 distance $r$ 满足 $r^2=l_1^2+l_2^2+2l_1l_2\cos q_2$，求 derivative：

$$2r\dot r=-2l_1l_2\sin q_2\,\dot q_2\quad\Longrightarrow\quad\dot q_2=-\frac{r\,\dot r}{l_1l_2\sin q_2}$$

End-effector 以 0.1 m/s 径向往外走：

| $q_2$ | 60° | 30° | 10° | 3° | 1° |
|---|---|---|---|---|---|
| 精确 inverse 要的 $|\dot q_2|$（rad/s） | 0.50 | 0.97 | 2.87 | 9.55 | 28.6 |
| Damped least squares（$\lambda=0.04$）的 $|\dot q_2|$ | 0.48 | 0.81 | 1.09 | 0.50 | 0.17 |
| Damped least squares 实际给出的 speed（m/s） | 0.095 | 0.084 | 0.038 | 0.005 | 0.0006 |

精确 inverse 让 joint velocity 随 $1/\sin q_2$ 爆掉。Damped least squares 不再要求 $J\dot q$ 恰好等于 $\dot x$，改为最小化

$$\|J\dot q-\dot x\|^2+\lambda^2\|\dot q\|^2$$

对 $\dot q$ 求 gradient 令其为 0：$(J^\top J+\lambda^2I)\dot q=J^\top\dot x$，等价地 $\dot q=J^\top(JJ^\top+\lambda^2I)^{-1}\dot x$。用 SVD 看，它把 $J^{-1}$ 里的 $1/\sigma_i$ 换成了 $\sigma_i/(\sigma_i^2+\lambda^2)$，和 [DSA2102 第 5 站](../courses/DSA2102.html#eig)的 ridge regression 是同一个式子：$\sigma_i$ 远大于 $\lambda$ 时几乎不变，远小于 $\lambda$ 时被压到 0。代价写在表的最后一行：靠近 singularity 时它干脆不往那个方向走了。

### Jacobian transpose：把 end-effector 挂在一根 spring 上

:::skip
NUS 大纲在 task space 一项只列了 Jacobian 和 velocity control using kinematics，到上一节为止。从这里到本站末尾（Jacobian transpose、task-space inertia、operational space control、Cartesian stiffness）是 torque input 下的 task-space control，跳过后第 8 站不受影响。
:::

Robot 的 input 是 torque 时，可以在 end-effector 上“施加”一个 force $F$。功率在 joint space 和 task space 里相同：$F^\top\dot x=F^\top J\dot q=(J^\top F)^\top\dot q$，所以产生 $F$ 需要的 joint torque 是

$$\tau=J(q)^\top F$$

让 $F$ 是一根虚拟的 spring 加 damper，再补上 gravity：

$$\tau=J^\top\big(K(x_d-x)-D\dot x\big)+g(q)$$

和上一站一样用 energy 论证：取 $V=\tfrac12\dot q^\top M\dot q+\tfrac12K\|x_d-x\|^2$，同样的步骤得 $\dot V=-D\|\dot x\|^2$；停下来时 $J^\top K(x_d-x)=0$，$J$ 不 singular 就推出 end-effector 停在 $x_d$。不需要 inverse，singularity 处也不会算出无穷大。

但它走的不是 straight line。从 $(0.4,0.4)$ 到 $(0.55,0.25)$，$K=100$ N/m，路线偏离 straight line 最多 24 mm，1% 以内到达要 0.92 s。原因是 end-effector 在不同方向上“重量”不同。Task space 里的 inertia 是

$$\Lambda(q)=\big(J M^{-1}J^\top\big)^{-1}$$

在 $q=(0,90°)$，$M=\begin{pmatrix}0.2667&0.0533\\0.0533&0.0533\end{pmatrix}$，用上面的 $J^{-1}$：$\Lambda=J^{-\top}MJ^{-1}$。先算 $MJ^{-1}=\begin{pmatrix}-0.1333&0.5333\\-0.1333&0\end{pmatrix}$，再左乘 $J^{-\top}=\begin{pmatrix}0&-2.5\\2.5&-2.5\end{pmatrix}$：

$$\Lambda=\begin{pmatrix}0.333&0\\0&1.333\end{pmatrix}\ \text{kg}$$

推 end-effector 沿 $x$ 方向只需要转 joint 2，动的只有小臂，感觉 0.333 kg；沿 $y$ 方向要两个 joint 一起转、小臂整体平移，感觉 1.333 kg。同一个 $K=100$，$x$ 方向的 $\omega=\sqrt{100/0.333}=17.3$ rad/s，$y$ 方向只有 8.7 rad/s：先横着走，再慢慢降下来。

**Operational space control** 在 task space 里做第 6 站的 computed torque：

$$F=\Lambda(q)\big(\ddot x_d+K_p'(x_d-x)-K_d'\dot x\big)+\mu(q,\dot q)+p(q),\qquad\tau=J^\top F$$

$\mu$、$p$ 是 Coriolis 和 gravity 在 task space 里的对应项。和 joint space 一样，error 变成 $\ddot e+K_d'\dot e+K_p'e=0$，两个方向各自独立，路线是 straight line。同样的起点和终点，$K_p'=100$、$K_d'=20$，偏离 straight line 0 mm，0.66 s 到达。

::fig[rb2203-task] 两条 Arm A 从同一个 configuration 同时出发（1/2 速度），end-effector 去同一个目标。看两个 end-effector 点：黑色的（Jacobian transpose）先往 x 方向横着冲出去再拐回来，彩色的（operational space control）沿 straight line 直走。Ellipse 是起点处的 $\Lambda$，长轴方向最“重”，所以同样的力在 x 方向推得更快。

:::wrong Jacobian inverse 和 Jacobian transpose 都是把 task space 换到 joint space，可以互换着用
$J^{-1}$ 换的是 velocity，$J^\top$ 换的是 force。在 $q=(0,90°)$，$J^{-1}(0.1,0)^\top=(0,-0.25)$，$J^\top(0.1,0)^\top=(-0.04,-0.04)$：方向完全不同。只有 $J$ 是 orthogonal matrix 时两者成比例。Jacobian transpose control 能收敛靠的是 energy 论证，不是“近似的 inverse”。
:::

### 碰到桌面：Cartesian stiffness

Jacobian transpose control 把 end-effector 变成挂在 $x_d$ 上的 spring。$x_d$ 设在桌面以下 $d$ 处，end-effector 就压在桌面上，force 由 spring 决定。用一个 1 DOF 的例子算：end-effector 的等效 mass 是 1 kg，桌面 stiffness $k_e=2\times10^4$ N/m，$K=400$ N/m，$d=25$ mm。两根 spring 串联，steady-state force 是

$$F=\frac{Kk_e}{K+k_e}\,d=\frac{400\times20000}{20400}\times0.025=9.80\ \text{N}\approx Kd$$

从桌面上方 50 mm 出发，damping 取 critical 的 $D=40$ 时碰撞瞬间的 peak force 是 46 N；$D=10$ 时是 144 N。如果 robot 是一个很硬的 position controller（$K\gg k_e$），同样“往桌面下 25 mm”的 command 会压出 $k_ed=500$ N。所以和环境接触的任务通常用低的 Cartesian stiffness 做 position control，让 force 由 $K$ 和 $d$ 决定。NUS 的大纲没有列 force control，这里只讲到这一步。

::fig[rb2203-contact] 1 DOF 的例子。End-effector 被 virtual spring 拉向桌面以下的 $x_d$，桌面像另一根很硬的 spring 把它顶住。

:::back
Damped least squares 与 [DSA2102 第 5 站](../courses/DSA2102.html#eig)的 ridge regression 相同；energy 论证与[第 6 站](#joint)相同。Jacobian 的推导见 [RB2202](../courses/RB2202.html)。
:::

:::from
Task space 用 velocity input 时的 feedforward 加 feedback、用 Jacobian inverse 或 pseudoinverse 换成 joint velocity，来自 [Modern Robotics 11.3 第 3 部分](https://modernrobotics.northwestern.edu/nu-gm-book-resource/11-3-motion-control-with-velocity-inputs-part-3-of-3/)（书本的式 11.16、11.17：$\dot x=\dot x_d+K_p(x_d-x)+K_i\int(x_d-x)\,dt$，再用 pseudoinverse 换成 $\dot\theta$）；Corke 书 8.2 节的配套代码 `RRMC.py` 是不带 position feedback 的版本，每个 cycle 算 $\dot q=J^{-1}\nu$，$\nu$ 为常数；resolved motion rate control 的由来和它在 singularity、redundancy 上的问题、“目标是一个 attractor”的 task-level 观点，来自 [CS223A 第 13 讲](https://see.stanford.edu/materials/aiircs223a/transcripts/IntroductionToRobotics-Lecture13.html)。$\Lambda=(JM^{-1}J^\top)^{-1}$、$u=J^\top f$、task-space stiffness、operational space control 的结构来自 [6.4210 force control 一章](https://manipulation.mit.edu/force.html)；[Modern Robotics 书本](https://hades.mech.northwestern.edU/images/2/25/MR-v2.pdf)的式 11.47（task-space computed torque，$\tau=J^\top[\tilde\Lambda(\cdots)+\tilde\eta]$）与 11.65（impedance control）是同一个结构，书里 $\Lambda$ 的定义在 8.6 节，没有读到。CS223A 讲 operational space 的那几讲（第 15、16 讲）没有读到推导：第 15 讲的逐字稿抓下来和第 14 讲是同一段内容，第 16 讲是应用综述。$\Lambda$ 的手算、路线偏离的模拟、singularity 的数表、damped least squares 与 ridge 的对应、接触 force 的例子，是为这一页推和算的。

## [mobile] Differential-drive mobile robot 的 control

:::skip
能在 wheel speed 与 $(v,\omega)$ 之间换算，能推出 offset point 的 controller 并说清 heading 由什么决定，能写出 polar coordinates 下停到一个 pose 的 law 及其 gain 条件，能写出 robot frame 里的 tracking error dynamics、由 controllability 解释为什么 reference 停下来时它失效，就读完这门课了。
:::

### 两个轮子，三个 coordinate

Differential drive 有左右两个独立驱动的 wheel，radius $r=0.05$ m，track width $W=0.3$ m。车身 configuration 是两轮中点的 $(x,y)$ 和 heading $\theta$。两个 wheel 的 speed $\omega_R$、$\omega_L$ 决定车身的 forward velocity $v$ 和 angular velocity $\omega$：

$$v=\frac{r(\omega_R+\omega_L)}{2},\qquad\omega=\frac{r(\omega_R-\omega_L)}{W}\qquad\Longleftrightarrow\qquad\omega_R=\frac{v+\omega W/2}{r},\quad\omega_L=\frac{v-\omega W/2}{r}$$

例如 $v=0.3$ m/s、$\omega=0.3$ rad/s，要 $\omega_R=6.9$、$\omega_L=5.1$ rad/s。每个 wheel 的 speed 由第 2 站的 PI 跟踪，plant 用第 1 站的办法 identify。Wheel speed 上限 10 rad/s 时，$(v,\omega)$ 的可行范围是 $\dfrac{|v|}{0.5}+\dfrac{|\omega|}{3.33}\le1$，一个菱形：全速直行时不能转，原地转时不能走。

车身的运动是

$$\dot x=v\cos\theta,\qquad\dot y=v\sin\theta,\qquad\dot\theta=\omega$$

消去 $v$ 得 $\dot x\sin\theta-\dot y\cos\theta=0$：车身不能侧着走。三个 coordinate，只有两个 velocity input。这个 constraint 不能 integrate 成 $(x,y,\theta)$ 之间的关系（robot 绕几步就能到达任意 configuration），所以叫 nonholonomic。对 $x$、$y$ 各用一个 PID 的做法因此走不通：$\theta=0$ 时，无论 controller 想要多大的 $\dot y$，都给不出来。

### 控制车前面的一个点

既然只有两个 input，就只控制两个量。取车身前方 distance $d$ 处的一点 $P$：

$$P=\begin{pmatrix}x+d\cos\theta\\y+d\sin\theta\end{pmatrix},\qquad\dot P=\underbrace{\begin{pmatrix}\cos\theta&-d\sin\theta\\\sin\theta&d\cos\theta\end{pmatrix}}_{A(\theta)}\begin{pmatrix}v\\\omega\end{pmatrix}$$

$\det A=d$。只要 $d\ne0$，$P$ 的 velocity 可以任意指定，用和 resolved-rate 一样的写法：

$$\begin{pmatrix}v\\\omega\end{pmatrix}=A(\theta)^{-1}\big(\dot P_d+K(P_d-P)\big)\quad\Longrightarrow\quad\dot e=-Ke$$

$P$ 的 error exponential 收敛。$d=0$（取两轮中点）时 $A$ singular：中点不能侧移。

那 heading 呢？没有被控制。看 reference 沿 $x$ 轴以 $v_r$ 前进、$P$ 已经精确跟上的情形，$\dot P=(v_r,0)$。$A^{-1}=\dfrac1d\begin{pmatrix}d\cos\theta&d\sin\theta\\-\sin\theta&\cos\theta\end{pmatrix}$，所以

$$v=v_r\cos\theta,\qquad\omega=\dot\theta=-\frac{v_r}{d}\sin\theta$$

$d>0$ 时 $\theta=0$ 是 stable 的 equilibrium，$\theta=\pi$ 不 stable：车头会转向前进方向。$d<0$（$P$ 在车后）时反过来：$\theta=\pi$ stable，车倒着开，$v=-v_r$。模拟：从 heading 60° 出发，$d=0.1$ m 时 heading 在 5 s 内回到 −0.7°、最终 0°；$d=-0.1$ m 时 $P$ 同样精确跟上，heading 却停在 180°，一路倒车。

Reference 停下来时，$\dot P_d=0$，$P$ 停在目标点，heading 停在哪里取决于出发时的朝向：从 0°、90°、180° 出发，最后分别是 51°、39°、40°。

### 开到一个点，停成指定的 heading

NUS 大纲在 mobile robot 一项下写的是 position control 和 velocity control of wheeled robots。Corke 书 4.1.1 节（car-like robot）按配套 notebook 的目录分成 driving to a point、driving along a line、driving along a path、driving to a configuration 四小节；下面取第一和第四个，换成 differential drive。目标放在 origin、heading 为 0；任何目标 pose 都可以先换到它自己的 frame 里再这样做。

**开到一个点。** 车到目标的 distance 是 $\rho=\sqrt{x^2+y^2}$，从车指向目标的方向是 $\varphi=\operatorname{atan2}(-y,-x)$。Corke 的配套代码 `drivepoint.py` 让 speed 与 distance 成正比、转向与 heading error 成正比；换成 differential drive，就是

$$v=K_v\rho,\qquad\omega=K_h(\varphi-\theta)$$

$\varphi-\theta$ 要 wrap 到 $(-\pi,\pi]$ 之间。$K_v=0.3$、$K_h=1$，从 $(-1,\,0.6)$、heading 0° 出发，16.0 s 后离目标不到 1 cm，最后的 heading 是 −43.9°：车一路对着目标开，到达时的朝向就是最后那一段的方向。从 $(0.2,\,-1)$、heading 90° 出发，最后是 106.1°。

**换成 polar coordinates。** 要连 heading 一起管，Corke 用三个量描述车相对于目标的位置：$\rho$；$\alpha=\varphi-\theta$，目标偏在车头左边多少；$\beta=-\varphi$。三个都为 0 时，$\theta=\varphi-\alpha=-\beta-\alpha=0$，正好是目标 pose。

它们怎样随 time 变化？$x=-\rho\cos\varphi$，$y=-\rho\sin\varphi$，再用 $\dot x=v\cos\theta$、$\dot y=v\sin\theta$：

$$\dot\rho=\frac{x\dot x+y\dot y}{\rho}=-v\,(\cos\varphi\cos\theta+\sin\varphi\sin\theta)=-v\cos\alpha$$

$$\dot\varphi=\frac{x\dot y-y\dot x}{\rho^2}=\frac{v\,(\sin\varphi\cos\theta-\cos\varphi\sin\theta)}{\rho}=\frac{v\sin\alpha}{\rho}$$

（第二式用了 $\dfrac{d}{dt}\operatorname{atan2}(Y,X)=\dfrac{X\dot Y-Y\dot X}{X^2+Y^2}$，$X=-x$，$Y=-y$。）于是

$$\dot\rho=-v\cos\alpha,\qquad\dot\alpha=\frac{v\sin\alpha}{\rho}-\omega,\qquad\dot\beta=-\frac{v\sin\alpha}{\rho}$$

**Control law。** Corke 的 `driveconfig.py` 取

$$v=k_\rho\rho,\qquad\omega=k_\alpha\alpha+k_\beta\beta$$

代进去，$v/\rho=k_\rho$，后两式里的 $\rho$ 消掉了：

$$\dot\rho=-k_\rho\rho\cos\alpha,\qquad\dot\alpha=k_\rho\sin\alpha-k_\alpha\alpha-k_\beta\beta,\qquad\dot\beta=-k_\rho\sin\alpha$$

在 $(\rho,\alpha,\beta)=0$ 附近 linearize（$\sin\alpha\approx\alpha$，$\cos\alpha\approx1$）：

$$\begin{pmatrix}\dot\rho\\\dot\alpha\\\dot\beta\end{pmatrix}=\underbrace{\begin{pmatrix}-k_\rho&0&0\\0&-(k_\alpha-k_\rho)&-k_\beta\\0&-k_\rho&0\end{pmatrix}}_{A}\begin{pmatrix}\rho\\\alpha\\\beta\end{pmatrix}$$

按第 4 站的办法看 eigenvalue。第一行只有 $-k_\rho$，沿它展开，右下角 $2\times2$ 的 block 给出 $\lambda\big(\lambda+k_\alpha-k_\rho\big)-k_\beta k_\rho$：

$$\det(\lambda I-A)=(\lambda+k_\rho)\big(\lambda^2+(k_\alpha-k_\rho)\lambda-k_\rho k_\beta\big)$$

Second-order 的 polynomial 两个 root 都在 left half-plane 当且仅当两个 coefficient 都为正，所以条件是

$$k_\rho>0,\qquad k_\beta<0,\qquad k_\alpha>k_\rho$$

Corke 代码里的 $k_\rho=1$、$k_\alpha=5$、$k_\beta=-2$ 满足这三条。这台车的 speed 上限是 0.5 m/s，取 $k_\rho=0.3$、$k_\alpha=1$、$k_\beta=-0.4$，$\det(\lambda I-A)=(\lambda+0.3)(\lambda^2+0.7\lambda+0.12)=(\lambda+0.3)^2(\lambda+0.4)$。同样两个起点：16.2 s 和 17.0 s 后离目标不到 1 cm，最后的 heading 都是 0.0°，途中 $(v,\omega)$ 一直在第一小节那个菱形以内。$\lvert\alpha\rvert>\pi/2$ 时目标在车后，Corke 的代码改为倒着开过去；这里的两个起点用不到。

::fig[rb2203-pose] 左：$\rho$、$\alpha$、$\beta$ 的定义，目标在 origin、朝 $+x$。右：两块各是一个起点，每块里两辆车同时出发（4 倍速），灰色的用“开到一个点”，彩色的用 polar coordinates 的 law。两辆都到了目标点，只有彩色的车头最后朝 $+x$。

这个 law 在目标点不连续：$\rho=0$ 时 $\varphi$ 没有定义，离目标很近时车往左或往右挪一点，$\varphi$ 就跳一大截，$\omega$ 跟着跳。这是躲不开的：本站末尾关于 Brockett 的那一条说明，能把车停到一个 pose 的 time-invariant feedback 都不可能连续。

### 停车 law 的 Lyapunov 证明

:::skip
上面只证明了目标附近 linearization 的 stability。这一节给另一个 nonlinear law 和整体的证明，跳过不影响后面。
:::

Stanford AA274A 第 4 讲用 $\alpha$ 和 $\delta=\alpha+\theta=\varphi$（就是上面的 $-\beta$），dynamics 是 $\dot\rho=-v\cos\alpha$、$\dot\alpha=v\sin\alpha/\rho-\omega$、$\dot\delta=v\sin\alpha/\rho$。取

$$V=\tfrac12\rho^2+\tfrac12\big(\alpha^2+k_3\delta^2\big),\qquad k_3>0$$

它只在 $\rho=\alpha=\delta=0$ 时为 0。求 derivative，代入 dynamics：

$$\dot V=\rho\dot\rho+\alpha\dot\alpha+k_3\delta\dot\delta=-\rho v\cos\alpha+\frac{v\sin\alpha}{\rho}\,(\alpha+k_3\delta)-\alpha\omega$$

取 $v=k_1\rho\cos\alpha$：第一项变成 $-k_1\rho^2\cos^2\alpha$，第二项变成 $k_1\sin\alpha\cos\alpha\,(\alpha+k_3\delta)$。再取

$$\omega=k_2\alpha+k_1\,\frac{\sin\alpha\cos\alpha}{\alpha}\,(\alpha+k_3\delta)$$

则 $-\alpha\omega=-k_2\alpha^2-k_1\sin\alpha\cos\alpha\,(\alpha+k_3\delta)$，正好消去第二项：

$$\dot V=-k_1\rho^2\cos^2\alpha-k_2\alpha^2\le0$$

（$\sin\alpha/\alpha$ 在 $\alpha=0$ 处取 1。）$\dot V$ 里没有 $\delta$，和第 6 站一样再走一步：如果 $\alpha$ 一直为 0，那么 $\dot\alpha=0$，而这时 $\dot\alpha=-\omega=-k_1k_3\delta$，所以 $\delta=0$；$\alpha=0$ 时 $\dot V=-k_1\rho^2$，$\rho$ 也只能停在 0。

$k_1=0.3$、$k_2=1$、$k_3=1$，从 $(-1,\,0.6)$、heading 0° 出发：16.2 s 后离目标不到 1 cm，40 s 时 heading 还差 1.2°。$\delta$ 只靠 $\omega$ 里 $k_1k_3\delta$ 这一项拉回，比 Corke 的 law 慢。

### 连 heading 一起跟踪

要跟踪完整的 $(x_d,y_d,\theta_d)$，把 error 放到 robot 自己的 frame 里：

$$e_x=\cos\theta\,\Delta x+\sin\theta\,\Delta y,\qquad e_y=-\sin\theta\,\Delta x+\cos\theta\,\Delta y,\qquad e_\theta=\theta_d-\theta$$

$\Delta x=x_d-x$，$\Delta y=y_d-y$。Reference 本身也满足 unicycle 的运动，velocity 是 $v_d$、$\omega_d$。对 $e_x$ 求 derivative：

$$\dot e_x=\omega\,(-\sin\theta\,\Delta x+\cos\theta\,\Delta y)+\cos\theta\,(v_d\cos\theta_d-v\cos\theta)+\sin\theta\,(v_d\sin\theta_d-v\sin\theta)=\omega e_y+v_d\cos e_\theta-v$$

同样地

$$\dot e_y=-\omega e_x+v_d\sin e_\theta,\qquad\dot e_\theta=\omega_d-\omega$$

Input 写成 feedforward 加 correction：$v=v_d\cos e_\theta+u_1$，$\omega=\omega_d+u_2$。在 $e=0$ 附近 linearize（$\cos e_\theta\approx1$，$\sin e_\theta\approx e_\theta$，略去 error 与 correction 的乘积）：

$$\begin{pmatrix}\dot e_x\\\dot e_y\\\dot e_\theta\end{pmatrix}=\underbrace{\begin{pmatrix}0&\omega_d&0\\-\omega_d&0&v_d\\0&0&0\end{pmatrix}}_{A}\begin{pmatrix}e_x\\e_y\\e_\theta\end{pmatrix}+\underbrace{\begin{pmatrix}-1&0\\0&0\\0&-1\end{pmatrix}}_{B}\begin{pmatrix}u_1\\u_2\end{pmatrix}$$

用第 4 站的 controllability matrix。$AB$ 的两个 column 是 $(0,\omega_d,0)^\top$ 和 $(0,-v_d,0)^\top$，加上 $B$ 本身的 $(-1,0,0)^\top$ 和 $(0,0,-1)^\top$：只要 $v_d$、$\omega_d$ 不全为 0，就能凑出 $e_y$ 方向，rank 3。Reference 停下来（$v_d=\omega_d=0$）时 $A=0$，$W_r$ 只剩 $B$ 的两个 column，rank 2：$e_y$ 方向（侧向）没有任何 input 能影响。车在动的时候，侧向 error 可以通过“先偏一点 heading 再往前走”消掉；车不动时这条路就断了。

选 gain。$\omega_d$ 小时 $e_x$ 与另外两个分开：取 $u_1=k_xe_x$，得 $\dot e_x=-k_xe_x$。$(e_y,e_\theta)$ 满足 $\dot e_y=v_de_\theta$，取 $u_2=k_yv_de_y+k_\theta e_\theta$，$\dot e_\theta=-k_yv_de_y-k_\theta e_\theta$，合起来

$$\ddot e_y+k_\theta\dot e_y+k_yv_d^2\,e_y=0$$

要 $\omega_n=a$、damping ratio $\zeta$：$k_\theta=2\zeta a$，$k_y=a^2/v_d^2$。$v_d\to0$ 时 $k_y$ 发散，和上面的 controllability 结论一致。实际用的 nonlinear 形式把 $e_\theta$ 换成 $\sin e_\theta$：

$$v=v_d\cos e_\theta+k_xe_x,\qquad\omega=\omega_d+k_yv_de_y+k_\theta\sin e_\theta$$

跟踪 radius 1 m、$v_d=0.3$ m/s 的 circle，$a=1$、$\zeta=0.7$、$k_x=1$，从 reference 起点侧面 0.4 m、heading 差 90° 的地方出发：position error 5 s 后 4.4 mm、10 s 后 0.2 mm，heading error 5 s 后 2.3°、10 s 后 0.03°，$|\omega|$ 最大 1.1 rad/s。同样的起点用 offset point controller（$d=0.1$、$K=1$）也能收敛，但开头要 $|\omega|=4.0$ rad/s，超过了这台车 3.33 rad/s 的上限。

Modern Robotics 书本 13.3.4 节给的 tracking law（式 13.31）把 error 放在 reference 的 frame 里，而且是 actual 减 desired：$\varphi_e=\theta-\theta_d$，$(x_e,y_e)$ 是 $(x-x_d,\,y-y_d)$ 转到 reference frame 后的两个分量。$k_1,k_2,k_3>0$：

$$v=\frac{v_d-k_1\lvert v_d\rvert\,(x_e+y_e\tan\varphi_e)}{\cos\varphi_e},\qquad\omega=\omega_d-\big(k_2v_dy_e+k_3\lvert v_d\rvert\tan\varphi_e\big)\cos^2\varphi_e$$

Error 小时 $\tan\varphi_e\approx\varphi_e$，$\cos\varphi_e\approx1$，两个 frame 只差一个小角度，$x_e\approx-e_x$，$y_e\approx-e_y$，$\varphi_e=-e_\theta$。代进去，略去 error 的乘积：

$$v\approx v_d+k_1\lvert v_d\rvert\,e_x,\qquad\omega\approx\omega_d+k_2v_de_y+k_3\lvert v_d\rvert\,e_\theta$$

和上面的 law 是同一个 linear 结构，对应关系是 $k_x=k_1\lvert v_d\rvert$，$k_y=k_2$，$k_\theta=k_3\lvert v_d\rvert$；上面那组 gain 换过去是 $k_1=1/0.3=3.33$，$k_2=11.1$，$k_3=1.4/0.3=4.67$。差别有两处。13.31 把 $k_1$、$k_3$ 乘上 $\lvert v_d\rvert$，reference 走得慢，correction 也跟着变弱，$v_d=0$ 时整个 law 失效，书里因此说它不适合原地转的 trajectory。$\tan\varphi_e$ 在 $\varphi_e\to\pm\pi/2$ 时发散，书里要求 tracking 时 $\lvert\varphi_e\rvert<\pi/2$；上面那个 heading 差 90° 的起点正好落在边界上，用 $\sin e_\theta$ 的 law 没有这个限制。书里说这个 law 的 stability 证明超出了书的范围，没有给出。

::fig[rb2203-mobile] 所有车按 4 倍速同时开，五边形的尖头是车头，小点是 offset point $P$。左：跟踪 circle 形的 reference（彩色小点沿虚线走），两种 controller 从同一个错位的起点出发，都追上了它。右：offset point 取在车前（$d>0$）和车后（$d<0$），$P$ 都跟上了 straight line；看下面那辆车，它一直往右走，车头却朝左，是在倒车。

:::wrong Robot 能到达任何 configuration，所以总能用一个 smooth 的 feedback 把它停到指定的位置和朝向
能到达是一回事，能用 feedback stabilize 是另一回事。上面 linearization 在停车点掉 rank，只说明 linear feedback 不行。更强的结论来自 Brockett：$\dot q=G(q)u$ 这种没有 drift 的 system，如果 $G$ 的 column 在目标点 linearly independent，那么能用 smooth、time-invariant 的 feedback 把它 stabilize 在这一点的必要条件是 input 的个数等于 state 的个数。Unicycle 有 3 个 state、2 个 input，不满足。Modern Robotics 的 Theorem 13.1 把它加强为：没有任何对 state 连续、不随 time 变化的 feedback 能把 nonholonomic mobile robot 停在一个 configuration（这里只给出，不证）。所以停车要用 discontinuous 的 law（上面的 polar coordinates law 在目标点不连续）或 time-varying 的 law，或者先规划一条在动的 trajectory，再用 tracking controller 跟它。
:::
