先看三段推理。每一段里的 premise 单独拿出来都很难否认，推出的 conclusion 却很难接受。

**第一段。** 你知道自己有两只手。可是，假如你此刻是一个泡在营养液里的 brain，由一台计算机喂给全套 experience，你看到、摸到的一切会和现在一模一样，所以你没有办法知道自己不是这样一个 brain。而如果你知道自己有手，你就应该能知道自己不是一个没有手的 brain。于是，你并不知道自己有手。

**第二段。** 你刚才可以不点开这一页。可是，你点开它这件事，是你出生之前 world 的状态加上 laws of nature 的 consequence。出生之前的事不由你决定，laws of nature 也不由你决定，所以它们的 consequence 同样不由你决定。于是，你刚才并没有别的可能。

**第三段。** 五条命比一条命要紧。一个医生手上有五个等 organ 的病人，都活不过今天；诊室里坐着一个来体检的健康人，organ 全都匹配。于是，医生应该把他拆开。

三段的结构相同：几条看起来成立的 premise，一步一步推出一个看起来不成立的 conclusion。面对这样的推理只有三种做法：指出某条 premise 是假的，指出某一步推不出来，或者接受 conclusion。哪一种都有代价，这门课做的事就是把每一种代价算清楚。

## [arg] Argument、validity 与 soundness

:::skip

### “我不同意这个 conclusion”还不算回应

先看一个后面要用整整一站来讨论的 argument。这里的 God 指一个 omnipotent（什么都做得到）、omniscient（什么都知道）、perfectly good 的 being。

- **P1.** If God exists, there is no evil.
- **P2.** There is evil.
- **C.** God does not exist.

不接受 C 的人，只说一句“我不同意”是不够的。一个 argument 是用几条 premise 去支持一个 conclusion，它成不成立可以拆成两个互相独立的问题：

1. 假设 premise 都是真的，conclusion 是不是一定跟着真？
2. Premise 实际上是不是真的？

第一个问题问的是 **validity**。

> 一个 argument 是 valid 的，意思是：不可能出现 premise 全真而 conclusion 假的情况。

拿它检验上面的 argument。假设 P1、P2 都真，再假设 C 假，也就是 God exists。由 P1 得 there is no evil，这和 P2 矛盾。所以“premise 全真而 conclusion 假”不可能出现，这个 argument 是 valid 的。

这就把不接受 C 的人逼到一个确定的位置上：他必须说 P1 是假的，或者 P2 是假的，并给出理由。第 2 站讲的就是双方围绕 P1 的攻防。

::fig[gex1015-argmap] 一个 argument 有两处可以反对：某一条 premise，或者从 premise 到 conclusion 的那一步。两处都反对不了，就只能接受 conclusion。

### Validity 只看 form，不看内容

把上面的 argument 换一套内容：

- If it is raining, the ground is wet.
- The ground is not wet.
- So it is not raining.

两个 argument 的骨架是同一个：“If P then Q. Not-Q. So not-P.”（在第一个 argument 里，Q 是 “there is no evil”，P2 说的正是 not-Q。）刚才检验 validity 的那几行推理没有用到 God 或 evil 的任何性质，只用到了这个骨架，所以换成下雨照样成立。Validity 是 form 的性质。

因此 valid 和“说得对”是两回事。下面三个 argument 的 form 相同，都是 “All A are B. All C are A. So all C are B.”，都 valid：

| | Premise | Conclusion |
|---|---|---|
| ① | All mammals are animals. All whales are mammals.（全真） | All whales are animals.（真） |
| ② | All fish are mammals. All whales are fish.（全假） | All whales are mammals.（真） |
| ③ | All fish can fly. All whales are fish.（全假） | All whales can fly.（假） |

Valid 的 argument 可以有假的 premise，可以有假的 conclusion，也可以从假的 premise 推出真的 conclusion。被排除的组合只有一种：premise 全真而 conclusion 假。所以只知道一个 argument valid，对它的 conclusion 是真是假还一无所知，要再加上“premise 全真”才行。两条都满足的 argument 叫 **sound**，sound 的 argument 的 conclusion 一定是真的。

表里只有 ① 是 sound 的。Problem of evil 那个 argument 是 valid 的，它 sound 不 sound 正是争论所在。

:::wrong Premise 和 conclusion 都是真的，所以这个 argument 是 valid 的
看这个 argument：“Singapore is in Asia. Seven is a prime number. So NUS is a university.” 三句话都是真的，可是 premise 和 conclusion 毫不相干。完全可以设想 Singapore 在 Asia、7 是 prime number、而 NUS 从未建校，那时 premise 全真、conclusion 假。按定义，它 invalid。

反方向的错同样常见：看到一条 premise 是假的，就说 argument invalid。表里的 ②、③ premise 全假，照样 valid。Premise 假，毛病出在 soundness 上；validity 只管 premise 和 conclusion 之间的关系。三个词各有所指：true 说的是单独一句话，valid 说的是一个 argument 的 form，sound 说的是 valid 并且 premise 全真。
:::

### Conditional 的四种 form

“If P then Q” 这样的句子叫 conditional，P 是 antecedent，Q 是 consequent。按入门逻辑的标准读法，它只断言一件事：不会出现 P 真而 Q 假。拿一条 conditional 当 premise，再加一条关于 P 或 Q 的 premise，一共有四种推法。

| 名称 | Form | Valid 吗 |
|---|---|---|
| Modus ponens | If P then Q. P. So Q. | valid |
| Modus tollens | If P then Q. Not-Q. So not-P. | valid |
| Affirming the consequent | If P then Q. Q. So P. | invalid |
| Denying the antecedent | If P then Q. Not-P. So not-Q. | invalid |

判断的办法是把 P、Q 的四种真假组合全部列出来，看有没有哪一行 premise 全真而 conclusion 假。

| 行 | P | Q | If P then Q |
|---|---|---|---|
| 1 | true | true | true |
| 2 | true | false | false |
| 3 | false | true | true |
| 4 | false | false | true |

- Modus ponens 的两条 premise 是 “if P then Q” 和 P，同时为真的只有第 1 行，那一行 Q 是真的。找不到反例，valid。
- Modus tollens 的 premise 是 “if P then Q” 和 not-Q，同时为真的只有第 4 行，那一行 P 是假的，也就是 not-P 为真。Valid。
- Affirming the consequent 的 premise 是 “if P then Q” 和 Q，第 1、3 行都满足。第 3 行里 P 是假的，conclusion 假。Invalid。
- Denying the antecedent 的 premise 是 “if P then Q” 和 not-P，第 3、4 行都满足。第 3 行里 Q 是真的，conclusion “not-Q” 假。Invalid。

两种 invalid 的 form 栽在同一行上：P 假而 Q 真。放进下雨的例子，第 3 行就是“没下雨，地却是湿的”，比如洒水车刚开过去。这时 “If it is raining, the ground is wet. The ground is wet. So it is raining.” 的 premise 全真，conclusion 假。这样一个具体的情况叫 **counterexample**。说明一个 form invalid 的标准做法，就是给出一个 form 相同、premise 明显为真而 conclusion 明显为假的 argument。

### Necessary condition 与 sufficient condition

哲学里大量的 claim 是在说一件事是另一件事的 condition，这类 claim 都可以改写成 conditional。

- A 是 B 的 **sufficient condition**：有 A 就有 B，即 if A then B。
- A 是 B 的 **necessary condition**：没有 A 就没有 B，即 if not-A then not-B。它和 if B then A 说的是同一件事，两者排除的都是“B 真而 A 假”。

| 说法 | 改写 |
|---|---|
| A is sufficient for B | If A then B |
| A is necessary for B | If B then A |
| B only if A | If B then A |
| B if A | If A then B |
| A if and only if B | If A then B, and if B then A |

例如 being a square 是 being a rectangle 的 sufficient condition，却不是 necessary condition；有 oxygen 是着火的 necessary condition，却不是 sufficient condition。

改写之后，怎样反驳一条关于 condition 的 claim 就清楚了。Conditional 排除的只有“antecedent 真、consequent 假”，所以：

- 反驳 “A is necessary for B”，要找一个有 B 而没有 A 的 case。
- 反驳 “A is sufficient for B”，要找一个有 A 而没有 B 的 case。

后面几站里最有名的几个 thought experiment，都是这两种之一。

| 站 | 被检验的 claim | Thought experiment 给出的 case | 反驳的是 |
|---|---|---|---|
| 第 3 站 | Justified true belief is sufficient for knowledge | 有 justified true belief 而没有 knowledge（Gettier case） | sufficiency |
| 第 5 站 | Having the same personality is sufficient for being the same person | 两个人都有 Napoleon 的 personality，却不可能都是 Napoleon | sufficiency |
| 第 6 站 | Being able to do otherwise is necessary for moral responsibility | 有 moral responsibility 而不能 do otherwise（Frankfurt case） | necessity |

:::wrong “B only if A” 的意思是“只要有 A，就有 B”
“You graduate only if you pass this course” 说的是 pass 是 graduate 的 necessary condition：if you graduate, then you passed this course。它没有说 pass 了就能 graduate，还有别的课要过。把 only if 读成 if，就是把 necessary condition 读成 sufficient condition，接着就会犯上一节的 affirming the consequent：“If you graduate, you passed. You passed. So you graduate.”
:::

### 面对一个 argument 只有三种回应

回到开头。一个 argument 的 conclusion 让你不舒服，可以做的事只有三种。

**否认一条 premise。** 要指明是哪一条，并说出理由。

**指出 inference invalid。** 要给出 counterexample。哲学里的 argument 很少犯上面那种一眼可见的 form 错误，常见的是 **equivocation**：同一个词在两条 premise 里意思不同。例如

- Nothing is better than eternal happiness.
- A ham sandwich is better than nothing.
- So a ham sandwich is better than eternal happiness.

第一句的 nothing 是说“不存在比它更好的东西”，第二句的 nothing 是说“什么都没有”。把词义固定成其中任何一种，都有一条 premise 变成假的。第 4 站对 Mary 的一种回应、第 6 站对 Consequence Argument 的回应，都是指对方 equivocation。

**接受 conclusion。** 哲学里叫 bite the bullet。第 7 站里就有 utilitarian 这样对待 transplant case。

三种回应之外，有两件事会反复用到。

第一件：valid 的 argument 可以倒过来用。如果 “P1, P2, so C” valid，那么 “P1, not-C, so not-P2” 也 valid。理由是，假如 P1、not-C 为真而 P2 也为真，原来的 argument 就出现了 premise 全真而 conclusion 假的情况，这不可能。所以逻辑本身不规定推理朝哪边走。一方从 P1、P2 推出 C，另一方可以从 P1 和“C 明显是假的”推出 P2 是假的，谁有道理取决于 P2 和 not-C 哪一个更可信。第 3 站 Moore 回应 sceptic 用的就是这一招。

第二件：一个 argument 可以 valid，甚至 sound，却没有用处。如果它的某条 premise 只有已经接受 conclusion 的人才会接受，它就给不了任何人新的理由，这叫 **begging the question**。例如 “Whatever the Bible says is true, because it is the word of God. The Bible says God exists. So God exists.” 第一条 premise 只有已经相信 God exists 的人才会接受。第 2 站对 ontological argument 的一种诊断就是这个。

:::wrong 这个 thought experiment 现实里不会发生，所以不用理它
“Justified true belief is sufficient for knowledge” 这样的 claim 说的是一切可能的情况，包括从没发生过的。所以一个仅仅 possible 的 case 就足以反驳它，就像一辆假想的洒水车足以说明 affirming the consequent invalid。“现实里没有人会把 brain 切成两半装进两个 body” 不构成回应。

可以质疑的是另外两点。一是这个 case 是否真的 possible，里面有没有藏着矛盾。二是我们对它的 intuition 靠不靠得住：第 5 站里 Williams 把同一个 case 用两种方式讲出来，听的人给出相反的判断，说明 intuition 会跟着讲法摇摆。
:::

### 不 valid 的好 argument

“The sun has risen every day so far. So it will rise tomorrow.” 按定义这个 argument invalid：premise 真而 conclusion 假的情况是可以设想的。但没有人因此认为它是坏的推理。这类 argument 本来就不声称 premise 保证 conclusion，只声称 premise 让 conclusion 很可能为真，叫 inductive argument。评价它用的词是 strong 和 weak，不用 valid 和 invalid。

其中一种后面要用：**inference to the best explanation**。观察到一个 fact E；hypothesis H 对 E 的 explanation 比其他候选都好；所以 E 是支持 H 的 evidence。反驳这种 argument 的办法也跟着变了，不再是找 counterexample，而是提出一个同样好的 explanation，或者否认 E 需要 explanation。第 2 站的 fine-tuning argument 是这一种。同一站里 problem of evil 有 logical 和 evidential 两个版本，区别正是一个声称 valid，一个只声称 strong。

## [god] God 的存在与 problem of evil

:::skip
能说出 Gaunilo 的 parody 说明了什么、没有说明什么；能把 logical problem of evil 写成 premise，指出 free will defence 否认的是哪一条；能说清 logical 与 evidential 两个版本对 theist 的要求有什么不同，就可以去第 3 站。
:::

### 争的是哪一个 God

这一站所有的 argument 针对的是同一个 definition：God 是一个 omnipotent、omniscient、perfectly good 的 creator。Definition 一换，argument 就要重做。对一个 power 有限的 creator，problem of evil 不构成威胁；反过来，一个只能推到“有某个 designer”的 argument，离 perfectly good 还差得远。所以对每个 argument 都要问一句：它的 conclusion 说的是不是这个 God。

支持的一方有两条路。一条不看 world，只从 God 的 concept 出发，叫 ontological argument。一条从 world 的某个特征出发，推到一个 designer。反对的一方最重的 argument 是 problem of evil。

### Ontological argument：从 concept 推出 existence

Anselm 在 *Proslogion*（1078 年前后）里把 God 定义成 “that than which no greater can be conceived”，然后对否认 God 的人（他称之为 the fool）作如下推理。SEP 的条目把它整理成七步，转述如下：

1. 连 the fool 也 understand “that than which no greater can be conceived” 这个说法。
2. 被 understand 的东西 exists in the understanding。
3. 所以这个 being exists in the understanding。
4. 如果它只 exists in the understanding，那么可以 conceive 它同时 exists in reality。
5. Exists in reality 的，比只 exists in the understanding 的更 great。
6. 没有比这个 being 更 great 的东西可以被 conceive。
7. 所以这个 being exists in reality。

从 3 到 7 中间是一个 reductio。假设这个 being 只 exists in the understanding。由 4，可以 conceive 一个各方面相同、并且 exists in reality 的 being；由 5，后者更 great。于是我们 conceive 出了比它更 great 的东西，和 6 矛盾。假设不成立，所以得到 7。

它 valid 吗？这取决于怎么读 “exists in the understanding”。如果把 understanding 当成一个东西可以待的地方，同一个 being 可以只待在那里，也可以同时待在 reality 里，那么 4、5 是在比较同一个 being 的两种处境，reductio 走得通。如果 “exists in the understanding” 只是“有人有这个 concept”的另一种说法，那么 4、5 比较的是一个 concept 和一个东西，推不出矛盾。SEP 的评价是从 3 至 6 到 7 的这一步并不清楚。

**最强的 objection：Gaunilo 的 parody。** 和 Anselm 同时代的 Gaunilo 把 “being” 全部换成 “island”：that island than which no greater island can be conceived。七步照搬，conclusion 是这座完美的 island exists in reality。

Parody 起作用的方式要用第 1 站来说。两个 argument 的 form 相同，所以要 valid 就都 valid。Island 那个的 conclusion 明显是假的，所以它或者 invalid，或者有一条 premise 是假的。而它的 premise 和 Anselm 的逐条对应：能 understand 前一个说法的人没有理由 understand 不了后一个；认为 existence in reality 让 being 更 great 的人，没有理由否认它让 island 更 great。所以 Anselm 的 argument 里有同样的毛病。

Parody 的局限也在这里：它说明有地方出了错，却没有说错在哪一步。

**对 parody 的 reply。** Plantinga 的回应是否认两者对应：island 的好处没有上限，树总可以再多一棵，所以 “greatest conceivable island” 这个 concept 本身不成立；knowledge、power 这些让 being 变 great 的性质有上限。这个 reply 是否成功有争议，SEP 条目的作者认为不成功。

**错在哪一步：两种诊断。** 第一种来自 Kant：existence 不是一个 real predicate。描述一座 island 时，沙滩、淡水、气候是它的 property，每加一条，对这座 island 的描述就多一点内容。“它 exists” 不往描述里加内容，它说的是这份描述在 world 里有对应的东西。第 5 条 premise 把 existence 当成能让一个东西更 great 的 property，和其他 property 排在一起比较，这一步不合法。

第二种诊断用 Descartes 的版本最容易看清。他在 Meditation V 里说，existence 不能和 God 的 essence 分开，正如 “the idea of a mountain” 不能和 “that of a valley” 分开。SEP 把核心整理成：

- **P1.** God 有一切 perfection。
- **P2.** Existence 是一种 perfection。
- **C.** God exists。

P1 有两种读法，把这个例子从头走一遍。

读法甲：“有一个 being，它是 God，并且有一切 perfection。”这样读，argument valid，但 P1 自己已经断言了 God exists。Atheist 不会接受这条 premise，这是第 1 站说的 begging the question。

读法乙：“God 这个 concept，是一个有一切 perfection 的 being 的 concept。”换句话说，if anything is God, it has every perfection。Atheist 可以接受这条。可是它和 P2 一起只能推出 if anything is God, it exists。这句话 atheist 同样可以接受，它没有说 world 里真的有什么东西是 God。要的那个 C 推不出来，argument invalid。

没有一种读法能让 P1 既被 atheist 接受，又推得出 C。SEP 对整个 ontological argument 家族的总评也是这个结构：已有的版本或者 invalid，或者含有 non-theist 有充分理由拒绝的 premise，或者 conclusion 弱到没有宗教意义。同一个条目也承认，没有人证明过“任何 ontological argument 都不可能成功”，并引了 Russell 的感受：觉得它不对很容易，说清它哪里不对很难。

:::wrong 驳倒了 ontological argument，就说明 God 不存在
指出一个 argument unsound，只是说它没能支持它的 conclusion，conclusion 本身仍然可能是真的。第 1 站的表里，③ 的 premise 全假，同样 form 的 ② conclusion 却是真的。Gaunilo 本人是修士，他反对的是这条 proof，不是 God。要得出 “God does not exist”，需要另一个以它为 conclusion 的 argument，比如下面的 problem of evil。
:::

### Fine-tuning：从 world 的特征推到 designer

物理学里有一组 constant，取值只要偏一点，universe 里就不会出现 life。MIT 24.00 的讲义按 Roger White 的表述把 argument 写成：

- **P1.** 如果一个 fact E 需要 explanation，而 hypothesis H 对 E 的 explanation 令人满意、又比其他现成的候选都好，那么 E 是支持 H 的重要 evidence。
- **P2.** “我们的 universe 是 life-permitting 的”需要 explanation。
- **P3.** “God 把 constant 调成了允许 life 的值”令人满意地解释了它。
- **P4.** 没有同样令人满意的其他 explanation。
- **C.** “我们的 universe 是 life-permitting 的”是支持 theism 的重要 evidence。

先看 C 说了什么。它没有说 God exists，只说有一条 evidence 支持 theism。P1 是第 1 站最后一节的 inference to the best explanation 写成的一条一般原则，科学里天天在用。有了它，P1 到 P4 推出 C 这一步是 valid 的，争论集中在 P2 和 P4。

**针对 P2。** 不是每件 improbable 的事都需要 explanation。把一袋字母牌倒在桌上，排出任何一串特定的乱码都极不可能，没有人要求解释；排出 *Hamlet* 里的一句台词，就要解释了。P2 的支持者说 life-permitting 属于后一种。反对者说：universe 要是不允许 life，就没有人在这里观察它，所以我们观察到一个 life-permitting 的 universe 毫不奇怪。White 的 reply 是把两句话分开：“只要我们在观察，观察到的 universe 必定 life-permitting” 这一句是必然的；“universe 是 life-permitting 的” 这一句不是必然的，而需要 explanation 的是后一句。

**针对 P4。** 如果有极多个 universe，constant 各不相同，其中出现一个 life-permitting 的就不奇怪，这是 multiverse hypothesis。White 的 reply：它解释的是“为什么有某一个 universe 允许 life”，没有解释“为什么我们这一个允许 life”。讲义接着做了一个限定：如果另有独立的 evidence 支持 multiverse，P2 就可能站不住。很多人买了彩票之后再问“为什么偏偏是 Smith 中奖”，这个问题就失去了分量。

**就算 sound，推到了哪里。** C 支持的是 “有某个 agent 调过 constant”。Omnipotent、omniscient、perfectly good 三条一条也没有出现在 premise 里。从 designer 到这一站定义的那个 God，还需要别的 argument。

### Logical problem of evil

现在看反对的一方。第 1 站那个 argument 的 P1 “if God exists, there is no evil” 不是凭空说的，它来自 God 的三条 attribute。SEP 把它展开成这样：

- **P1.** 如果 God exists，God 是 omnipotent、omniscient、morally perfect 的。
- **P2.** Omnipotent 的 being 有 power 消除一切 evil。
- **P3.** Omniscient 的 being 知道 evil 何时存在。
- **P4.** Morally perfect 的 being 有 desire 消除一切 evil。
- **P5.** Evil exists。
- **P6.** 如果 evil exists 而 God exists，那么 God 或者没有 power 消除它，或者不知道它，或者没有 desire 消除它。
- **C.** God does not exist。

这个 argument valid。假设 God exists，由 P1 至 P4，God 有 power、知情、有 desire；由 P5、P6，三者至少缺一个。矛盾。

它叫 logical problem of evil，是因为它声称的东西很强：“God exists” 和 “evil exists” 这两句话，加上几条关于三种 attribute 的 truth，放在一起自相矛盾。Mackie 在 1955 年的 “Evil and Omnipotence” 里就是这样提出的，他给 P4 的依据是：good 与 evil 对立，一个 good 的东西总会尽其所能消除 evil。

这个强度决定了回应需要做到什么。要挡住“自相矛盾”的指控，theist 只需要说明两句话可以同时为真，即给出一个 possible 的情形，其中 God 和 evil 并存。这个情形不必是真的，甚至不必可信。

::fig[gex1015-evil] Logical problem of evil 的四条实质 premise。主要的回应都集中在 P4 上。

**否认 P5。** 说 world 里其实没有 evil。很少有人愿意这样说。

**限定 P2。** Omnipotent 不包括做 logically impossible 的事，比如造一个圆的方。多数 theist 接受这个限定，它本身不解决问题，但为下一步留出了位置：如果某种 good 在 logic 上离不开某种 evil，那么连 omnipotent 的 being 也不能只要前者、不要后者。

**否认 P4。** 一个 good 的 being 会消除 evil，除非它有 morally sufficient reason 允许它。Mackie 把这条路分层讨论。第一层的 evil 是 pain，第一层的 good 是 pleasure。第二层的 good 是 sympathy、courage 这些，它们在 logic 上需要第一层的 evil：没有 suffering 就谈不上 sympathy。Mackie 的 reply 是第二层同样有 evil：cruelty、cowardice。问题原样搬到了上一层。

于是回应再上一层：第二层的 evil 是 free will 的代价，而有 free will 的 world 比没有的更好。Mackie 追问：God 为什么不造一批有 free will、却每一次都选择 good 的人？一个人在某一次自由地选了 good 是 possible 的，那么他每一次都这样选也是 possible 的。

**Free will defence。** 这是对 Mackie 这个追问的回答，一般归于 Plantinga。关键在于 free will 的含义：如果一个 choice 是 free 的，它就不能由 agent 之外的东西引起。God 可以造出有 free will 的人，但他们怎么选不由 God 决定；God 要是保证了他们只选 good，他们就不再 free。所以下面的情形是 possible 的：God 能造的每一个含有 free 的 creature 的 world 里，都有人选了 evil。在这种情形下，God 要 free will 这种 good，就得容许 moral evil。

这就给出了那个 possible 的并存情形。SEP 的判断是 logical 版本因此很难维持，原因正是 P4 可以为假。

:::edge Free will defence 靠的是哪一种 free will
上面的关键一步是 “God 保证他们只选 good，他们就不再 free”。它预设 free will 和被决定不能并存，这是第 6 站的 incompatibilism。按第 6 站的 compatibilism，一个被决定的 choice 只要出自 agent 自己的 desire 就是 free 的，那么 God 完全可以把每个人造成自愿只选 good。Mackie 的追问正是站在这一边提的，他还说，如果 free will 意味着 choice 带有 randomness，就看不出它为什么这么有价值。所以这一站的攻防有一部分要到第 6 站才能定。
:::

### Evidential problem of evil

退一步。就算 God 和 evil 不矛盾，world 里实际存在的 evil 是不是让 God 的存在变得不太可能？这是 evidential 版本。它不再声称 valid，只声称 strong，theist 的任务也跟着变重：只给出一个 possible 的情形不够，要说明这个情形有理由相信。

SEP 转述了 Rowe 的两个例子。E1：森林起火，一只 fawn 被困，烧伤后挣扎多日才死。E2：一个小女孩被强暴、殴打、杀害。Argument 是：

- **P.** 我们知道的任何一种 good，都不足以让一个 omnipotent、omniscient、perfectly good 的 being 有理由容许 E1 和 E2。
- **Q.** 所以（很可能）没有任何 good 足以让这样的 being 有理由容许它们。
- **C.** 所以（很可能）这样的 being 不存在。

从 Q 到 C 是 deductive 的：这样的 being 只会容许有理由容许的 evil。从 P 到 Q 是 inductive 的：从“我们找不到”推到“没有”。争论都在这一步上。

把 E1 当作从头走到尾的例子，逐个检验上一节的回应。

| 回应 | 用在 E1 上 | 结果 |
|---|---|---|
| Free will | 森林火灾不是任何人的 choice 造成的。E1 是 natural evil，不是 moral evil。 | 用不上。Plantinga 提过 natural evil 可能出自某种超自然 agent 的 free choice；这作为 possible 的情形可以挡住 logical 版本，SEP 认为它极不可信，所以挡不住 evidential 版本。 |
| Soul-making（Hick）：world 是让人在克服困难中养成 character 的环境 | 没有人在场，没有人的 character 因此成长；fawn 自己不在这个方案里。 | 用不上。SEP 列的反驳正是 animal 的 suffering、幼儿的 suffering，以及远超养成 character 所需的 suffering。 |
| Natural law：有规律的 world 才能让 action 有可预期的效果，规律难免造成伤害 | Fawn 的 pain 可以被一次没人察觉的干预消除，不影响任何人对规律的依赖。 | 很难用上。 |
| 人的认识有限：God 可能有我们想不到的 reason | 直接否认从 P 到 Q 的那一步。 | 用得上，争论转到这一步是否合理。 |

E1 是有意这样设计的：它绕开了所有说得出具体 reason 的回应，只留下最后一种。最后一种通常叫 sceptical theism，理由是：只有在“如果有 reason，我们多半看得见”的前提下，才能从“看不见”推到“没有”；对一个 omniscient 的 being 的 reason，这个前提不成立。SEP 条目作者的反驳是，如果人的认识有限就足以挡住这个推理，那么它会连带挡住大量我们平时依赖的 inductive 推理。这场争论没有结束。

:::wrong Free will defence 解释了 world 里为什么有 evil
它没有，也没打算这样做。Free will defence 回应的是 logical 版本，目标只是说明 God 和 moral evil 并存是 possible 的，为此连“这个情形是真的”都不需要主张。把它当成对实际 evil 的 explanation，会立刻撞上 E1：火灾里的 fawn 和任何人的 free choice 无关。

文献里用两个词区分这两种任务。给出让 God 容许某种 evil 的具体 reason，并主张它可信，叫 theodicy；只主张存在或可能存在这样的 reason，而不说是什么，叫 defence。对付 logical 版本，defence 就够；evidential 版本逼着人去做 theodicy，或者像 sceptical theism 那样论证我们本来就不该指望看见 reason。
:::

## [know] Knowledge 与 scepticism

:::skip
能把 Descartes 的 dream argument 写成用 closure 的 argument，并说出 Moore、Dretske 与 Nozick、contextualist 各放弃哪一条；能用一个 Gettier case 说明 JTB 被反驳的是 necessity 还是 sufficiency，就可以去第 4 站。

### Descartes 的三级 doubt

Descartes 在 Meditation I 里要检查自己全部 belief 的 foundation。他的办法不是把 belief 一条条证伪，那做不完；只要在 foundation 上找到一个可以 doubt 的理由就够了，因为 foundation 一撤，上面的东西全都跟着倒。他一共往下挖了三级，每一级都是因为上一级还留着没碰到的东西。

**第一级：senses 有时出错。** 远处的、细小的东西会看错。但这碰不到近处的事：他坐在火炉边，穿着睡袍，手里拿着纸，这些看起来不可能弄错。

**第二级：dream。** 他想起自己不止一次梦见正是这样坐在火炉边，其实躺在床上。他的结论是 “there exist no certain marks by which the state of waking can ever be distinguished from sleep”。这一级让关于眼前物体的 belief 全部可疑。它碰不到的是 arithmetic 和 geometry：不管醒着还是睡着，2 加 3 都是 5，“a square has but four sides”。

**第三级：malignant demon。** 设想有一个 “exceedingly potent and deceitful” 的 demon，用全部的 power 来骗他，连他每次做加法时都让他算错。到这一级，没有哪条 belief 是安全的。

要看清这三级要求的是什么。Descartes 没有说自己正在做梦，也没有说 demon 存在。他需要的只是：我没有办法排除这些情形。

### 把它写成 argument

今天的讨论通常用一个版本更干净的情形。令 h 是一条再普通不过的 belief，比如 “I have hands”。令 SH 是一个 sceptical hypothesis：我是一个没有手的 brain in a vat（简写 BIV），全部 experience 由计算机提供，和现在的毫无分别。SH 的定义里有两条：如果它是真的，h 就是假的；而且从里面看，它和 h 为真的情形分辨不出来。

- **P1.** 如果我 know h，那么我 know not-SH。
- **P2.** 我不 know not-SH。
- **C.** 我不 know h。

这是 modus tollens，valid。两条 premise 各有依据。

P1 的依据是 **closure principle**：如果你 know p，并且 know p entails q，那么你 know q（或者至少只要做一步推理就能 know q）。平时我们一直这样用 knowledge：你知道今天是星期三，也知道星期三的后一天是星期四，于是你知道明天是星期四。Deduction 是扩充 knowledge 的标准办法。这里 “I have hands” entails “I am not a handless BIV”，所以 know 前者就该 know 后者。

P2 的依据是 SH 的定义。你能做的任何检查，掐自己一下、问旁边的人、去照 X 光，在 SH 里都会得到和现在一样的 experience。你手里的 evidence 在两种情形下完全相同，所以它分辨不了两者。

:::wrong Sceptic 认为我们其实在做梦，或者 external world 不存在
C 说的是 “我不 know 我有手”，不是 “我没有手”。Sceptic 不需要主张 SH 为真，也不需要说它有多大的可能。整个 argument 只用到“我 know 不了 SH 是假的”。所以回答 “可我明明有手” 或者 “BIV 的可能性太小了” 都没有碰到任何一条 premise：前者是在重申 h，而 argument 从没否认 h；后者谈的是 probability，而 P2 谈的是 knowledge。
:::

### 三条里必须放弃一条

把 argument 里出现的三句话并排放：

- **(A)** 我 know 我有手。
- **(B)** Closure principle。
- **(C)** 我不 know 我不是 BIV。

三句不能同时为真：任意两句合起来都推出第三句是假的。所以每一种立场都必须放弃其中一句，区别只在放弃哪一句。

::fig[gex1015-triad] 三句话里任意两句都推出第三句为假。Sceptic、Moore、Dretske 与 Nozick 各保留一条边上的两句。

**Sceptic 留下 (B)、(C)，放弃 (A)。** 代价是日常的 knowledge 几乎全部失去。

**Moore 留下 (A)、(B)，放弃 (C)。** 这是第 1 站说的把 valid 的 argument 倒过来用：“我 know 我有手；closure；所以我 know 我不是 BIV。”它和 sceptic 的 argument 一样 valid，所以问题变成 (A) 和 (C) 哪一句更可信。Moore 的回答是 (A)：“我有手”比任何一条哲学 premise 都确定。反对者说这是 begging the question：我关于“有手”的全部 evidence 是我的 experience，而这些 experience 只有在已经假定 not-SH 的时候才支持 “有手”，所以不能反过来用 “有手” 去确立 not-SH。

**Dretske 和 Nozick 留下 (A)、(C)，放弃 (B)。** Nozick 的理由来自他对 knowledge 的一个 condition，叫 sensitivity：S know p，要求 “假如 p 是假的，S 就不会相信 p”。拿它一步步算。

| Belief | 假如它是假的，会发生什么 | 我还会相信它吗 | Sensitive 吗 |
|---|---|---|---|
| 我有手 | 最接近现实的情形是我出过事故失去了双手；我会看见手腕以下是空的 | 不会 | sensitive |
| 我不是 BIV | 我是 BIV；experience 和现在一样 | 仍然相信我不是 BIV | 不 sensitive |

第一条满足 condition，第二条不满足。所以按这个 theory，我 know 我有手，却不 know 我不是 BIV，尽管前者 entail 后者。Closure 在这里失效。

这个立场的代价是它要人说出这样的句子：“I know I have hands, but I don't know that I'm not a handless brain in a vat.” DeRose 把这类句子叫 abominable conjunction。而且放弃 closure 等于说，从已知的 premise 做 valid 的推理，有时得不到 knowledge。

**Contextualism 三句都想留。** 它说 “know” 的 standard 随 context 变，就像 “tall” 的标准随场合变。在日常的 context 里 standard 低，(A) 为真，(C) 为假。有人认真提出 SH 之后，standard 升高，(C) 为真，(A) 为假。在每一个 context 内部 closure 都成立，sceptic 的 argument 在哲学课堂上 sound，在日常场合 unsound。SEP 指出它的两处麻烦：它在高 standard 的 context 里把结论让给了 sceptic；而且它仍然需要另外说明，凭什么在日常 standard 下我们就算排除了 SH。

### 走一遍：动物园里的 zebra

Dretske 用来反对 closure 的例子不需要 demon。你在动物园的围栏前看见一匹有黑白条纹的马形动物，牌子上写着 zebra。“那是一匹 zebra” entails “那不是一头被巧妙涂成 zebra 模样的 mule”。你没有检查过任何伪装。用 sensitivity 算：假如那不是 zebra，围栏里多半是别的动物，看起来不像 zebra，你不会相信它是 zebra，所以第一条 sensitive；假如那是一头伪装的 mule，它看起来还是 zebra，你仍然相信它不是伪装的 mule，所以第二条不 sensitive。

| 立场 | “那是 zebra”，你 know 吗 | “那不是伪装的 mule”，你 know 吗 | 要咽下的东西 |
|---|---|---|---|
| Sceptic | 不 know | 不 know | 连这样的事都不算 knowledge |
| Moore 式 | know | know，由前一条推出 | 没检查过伪装，却凭“看起来像 zebra”就知道了它没有伪装 |
| Dretske、Nozick | know | 不 know | Closure 失效，得说出 abominable conjunction |
| Contextualist | 平时 know | 平时 know；有人认真提出伪装之后，两条都不 know | 一句话的真假取决于谈话里提到了什么 |

四行里没有一行是免费的。

### Knowledge 是什么：JTB

上面一直在用 “know”，却没有说 knowledge 要求什么，而 P2 可信到什么程度取决于这一点。传统的 analysis 有三条，简称 JTB：S know that p，当且仅当

1. p 是 true 的；
2. S believe p；
3. S 的 belief 是 justified 的。

用第 1 站的话说：三条各自是 necessary condition，合起来是 sufficient condition。每一条 necessary 都有理由。没有人能 know 84 是 prime number，因为它不是，这是 truth condition。William 毫无根据地猜硬币是反面，恰好猜对，这不算 knowledge，所以光有 true belief 不够，还要 justification。

### Gettier case 与补丁的命运

Gettier 在 1963 年给出了有 JTB 而没有 knowledge 的 case。SEP 转述的那一个是这样的：Smith 有很强的 evidence 相信 “Jones owns a Ford”。他由此推出 “Jones owns a Ford, or Brown is in Barcelona”，虽然他完全不知道 Brown 在哪。实际上 Jones 并没有 Ford，而 Brown 碰巧在 Barcelona。

逐条核对。Smith 的 belief 是那句 “or” 连起来的话。

- True 吗？是，因为后半句为真。
- Smith believe 它吗？是。
- Justified 吗？是：他有很强的 evidence 支持前半句，而 “P, so P or Q” 是 valid 的推理。
- 是 knowledge 吗？不是。让这句话为真的是 Brown 的行踪，Smith 对此一无所知，他是碰巧对的。

三条全满足，却不是 knowledge。所以 JTB 不 sufficient。这个 case 用了两条假设：一个人可以 justified 地相信一句假话；justification 能沿着 valid 的推理传下去。第二条正是关于 justification 的 closure。

:::wrong Gettier 说明 knowledge 不需要 justification，或者 JTB 这三条都错了
Gettier case 是“有 JTB 而没有 knowledge”的 case，按第 1 站，它反驳的是 sufficiency。要反驳 necessity，得找“有 knowledge 而缺某一条”的 case，Gettier 没有给，这三条各自是 necessary 的仍然是多数人的看法。Gettier 之后的工作几乎都是在三条之外找第四条，而不是删掉哪一条。
:::

最自然的第四条是 **no false lemmas**：S 的 belief 不是从任何假话推出来的。它挡住了 Smith，因为他是从假的 “Jones owns a Ford” 推出来的。但是看 Goldman 和 Ginet 的 barn case：Henry 开车经过一个地方，那里路边立着的 barn 几乎全是只有一面墙的假货，他不知情，碰巧看着唯一一座真的，相信 “那是一座 barn”。这个 belief 是直接看出来的，没有经过任何假的 lemma；它 true，也 justified。可是只要他看的是旁边任何一座，他就会被骗，所以多数人判断这不是 knowledge。

Zagzebski 指出这不是哪一条补丁的偶然失败，而是有一张通用的配方。对任何 “JTB 加 X” 的 analysis，只要满足 justification 和 X 并不保证 truth：

1. 先造一个 case，S 的 belief 满足 justification 和 X，却因为运气不好是假的。
2. 再加一份好运气，让这个 belief 碰巧为真。

SEP 举的例子：Mary 视力正常，看见客厅椅子上坐着一个男人，相信 “我丈夫在客厅”。坐着的其实是她丈夫的兄弟，两人长得一样（第 1 步）。而她丈夫恰好也在客厅，坐在她看不见的角落（第 2 步）。

:::edge 两头为难
配方只对“不保证 truth”的 condition 有效。如果把 justification 的要求提高到保证 truth，Gettier case 就造不出来了。可是我们的 experience 从不保证 external world 的 truth，那样一来几乎没有 belief 算 justified，等于把 P2 白送给 sceptic。要求低一点，Gettier case 进来；要求高到头，sceptic 进来。SEP 列出的出路有三种：承认 knowledge 无法 analyse，把它当作起点（Williamson 的 “knowledge first”）；坚持 justification 确实 entail truth；或者改用反运气的 condition，比如上面的 sensitivity，那就回到了 closure 失效的问题上。
:::

Modus tollens 与“倒过来用”、begging the question、necessary 与 sufficient condition 的反驳方式，都在[第 1 站](#arg)。
:::

### 一样东西，还是两样

你牙疼。牙医能给出一份完整的 physical 描述：哪条 nerve 发炎，哪些 neuron 在放电，信号传到 brain 的哪个区域。除此之外还有一件事：疼的那种感觉。它是那份描述里已经包括的东西，还是描述之外的另一样东西？

Kagan 在 Yale PHIL 176 第 2 讲里把两种回答摆成这样。**Dualism**：一个 person 是 body 加 soul。Soul 是 immaterial 的，consciousness 和 thought 发生在它里面；两者互相影响，针扎在 body 上，pain 出现在 soul 里，soul 又指挥 body 缩手。**Physicalism**：只有 body。Person 是一种很特别的 body，它能 think、plan、feel、communicate，一支粉笔做不到这些。按这种看法，mind 不是 body 之外的一件东西，说一个 person 有 mind，就是说这个 body 能做这些事。

NUS 课程描述里“我们是不是 non-spiritual 的”问的就是这个。

### Descartes：从 conceivable 到 distinct

Descartes 在 Meditation II 里发现有一条 belief 连 demon 也骗不了：“I am, I exist, is necessarily true each time it is expressed by me”。他可以 doubt 自己有 body，却不能 doubt 自己在思考时存在。由此很容易写出这样一个 argument：

- **P1.** 我可以 doubt 我的 body 存在。
- **P2.** 我不能 doubt 我的 mind 存在。
- **C.** 我的 mind 不是我的 body。

背后的原则叫 Leibniz's law：如果 x 和 y 是同一个东西，那么 x 有的 property，y 都有。Mind 有 “我不能 doubt 它存在” 这个 property，body 没有，所以两者不同。

它 valid 吗？用第 1 站的办法，找一个 form 相同的 counterexample。Churchland 给的是：Lois Lane 知道 Superman 会飞；Lois Lane 不知道 Clark Kent 会飞；所以 Superman 不是 Clark Kent。在故事里两条 premise 都真，conclusion 假。所以这个 form invalid。毛病出在 “被某人知道会飞”“被我 doubt” 不是东西本身的 property，它取决于这个东西是以哪个名字、哪种方式出现在这个人面前的。

Descartes 在 Meditation VI 里真正给出的 argument 不是这一个。他写道，“I have a clear and distinct idea of myself, in as far as I am only a thinking and unextended thing”，对 body 则有一个只是 extended、不思考的东西的 idea；而凡是他 clearly and distinctly conceive 的，God 都能照样造出来；所以他 “is entirely and truly distinct from my body, and may exist without it”。SEP 的整理是：

- **P1.** 我的 mind 离开 body 而存在，是 conceivable 的。
- **P2.** Conceivable 的就是 possible 的。
- **P3.** 所以，我的 mind 离开 body 而存在是 possible 的。
- **C.** 所以，我的 mind 和我的 body 不是同一个东西。

从 P3 到 C 靠的是：一个东西不可能离开它自己而存在。如果 mind 就是 body，那么 mind 离开 body 存在就是 impossible 的，和 P3 矛盾。这一步同样用 Leibniz's law，但这回的 property 是 “possibly exists without the body”，说的是东西本身能怎样，和谁知道什么无关，所以 Lois Lane 的 counterexample 打不到它。这个 argument valid，要反对只能反对 premise。

**最强的 objection 针对 P2。** 化学出现之前的人可以毫不费力地 conceive “water 不是 H₂O”。可是 water 就是 H₂O；按 Kripke 的看法，这种 identity 一旦成立就是 necessary 的，不可能有 water 不是 H₂O 的情形。于是有东西 conceivable 而 impossible，P2 是假的。Physicalist 接着说，“mind 不是 brain” 和 “water 不是 H₂O” 是同一类。

**Reply。** SEP 转述 Chalmers 的回应：在 water 的例子里，人们 conceive 的其实是一个 possible 的情形，其中有一种看起来、喝起来都像 water 的液体，成分不是 H₂O。这个情形被错误地描述成了 “water 不是 H₂O”。能这样重新描述，是因为 water 的外观和它的本质之间有距离。Pain 没有这段距离：感觉起来是 pain 的就是 pain。所以 “pain 离开 brain state 而存在” 没法用同样的办法解释掉。这一轮之后双方仍在争，physicalist 一方的继续回应是 mind 与 brain 之间有一种 conceivability 探测不到的 necessity。

**Dualism 自己的麻烦。** Elisabeth of Bohemia 当年就问过 Descartes：一个没有 extension、不占空间的东西，怎么推得动 body？Descartes 承认两者结合得极紧，他说自己不是像 “a pilot in a vessel” 那样待在 body 里的：船破了，pilot 是看见的；body 受伤，他是觉得疼。但结合得紧不等于说明了它们怎样互相作用。这个问题在本站最后一节还会回来。

### Identity theory 与 functionalism

Physicalist 要说清 pain 到底是 body 的什么。最直接的回答是 **identity theory**：每一种 mental state 就是一种 brain state，pain 就是 C-fibre stimulation，就像 water 就是 H₂O。

它的麻烦是 **multiple realizability**。设想一种生物，brain 的构造和我们完全不同，没有 C-fibre；或者一个用 silicon 做的 android。它们受伤会躲、会叫、会记住教训、以后绕着走。按 identity theory，它们没有 C-fibre，所以不可能有 pain，不管行为多么相似。Block 把这种后果叫 chauvinism：只因为材料不同就否认对方有 mind。

**Functionalism** 是从这个麻烦里出来的。它说，一个 state 是哪一种 mental state，只取决于它在整个系统里起的作用，也就是它的 causal role，不取决于它由什么材料构成。SEP 给 pain 写的 role 大致是：由 body 的损伤引起；引起 “body 出了问题” 的 belief 和摆脱这个 state 的 desire；引起 anxiety；在没有更强的相反 desire 时，引起皱眉、呻吟。任何占据这个 role 的 state 就是 pain。

拿定义去检验刚才的例子。人身上占据这个 role 的也许是 C-fibre stimulation，那么人的 pain 由它 realize。Android 身上占据同一个 role 的是某种 silicon state，那么 android 也有 pain。Identity theory 的麻烦消失了。严格说，functionalism 对 realizer 是什么不作限制，连 non-physical 的东西原则上也可以；实际上采用它的多是 physicalist。

::fig[gex1015-mindmap] 这一站出现的四种立场，以及各自最主要的麻烦。

**最强的 objection：absent qualia。** Block 设想让全中国的人每人按一套规则收发信号，合起来复制一个人 brain 的 functional organization，连到一个 body 上。按 functionalism，这个由十几亿人组成的系统有 pain。多数人的 intuition 是它什么感觉也没有。如果 intuition 是对的，占据 causal role 就不 sufficient：一个 state 做了 pain 该做的一切，仍然可能缺少 pain 的那种感觉，哲学里把这种感觉叫 qualia。

**Reply。** Functionalist 的回应有两种。一种说这个 intuition 不可靠，它来自我们对各部分分散在空间里的系统的偏见；一个个 neuron 单独看同样不像有感觉的东西。另一种说 case 只打倒了粗糙的版本，role 写得足够细时，这个系统未必还能满足。

### Knowledge argument：Mary

Absent qualia 靠的是对一个古怪系统的 intuition。Jackson 1982 年的 argument 想把同一个担心变成一条 valid 的推理，对象是一切形式的 physicalism。他把 physicalism 定义为：all facts are physical facts。

Mary 是一位出色的 neuroscientist，从出生起就住在一个只有黑白两色的房间里，通过黑白屏幕学习。她知道关于 colour vision 的全部 physical fact：光的波长，retina 的反应，brain 里的每一步处理，人们说 “red” 时的发声过程。有一天她走出房间，第一次看见一个熟透的番茄。

- **P1.** 出房间之前，Mary 知道关于看见 red 的全部 physical fact。
- **P2.** 出房间之前，Mary 不知道看见 red 是什么感觉（what it is like to see red）。
- **P3.** 如果有一件事是她原来不知道、后来知道的，那么存在一个她原来不知道的 fact。
- **C.** 存在不是 physical fact 的 fact。Physicalism 是假的。

Valid：由 P2、P3，有一个 fact 她在房间里不知道；由 P1，这个 fact 不在 physical fact 之列。

注意 P1 是规定出来的。它说的不是今天的 neuroscience，而是完成了的、一条不漏的 physical 知识。所以 “科学还没发展到那一步” 不构成回应。

三种回应各否认一条。

**否认 P2（Churchland）。** 我们觉得 Mary 会吃惊，是因为我们想象的是一个懂得很多的人，不是一个真的知道全部 physical fact 的人。真有全部知识的 Mary，也许第一眼就能认出 red，因为她知道自己的 brain 进入那种 state 时会怎样。Churchland 认为这是一个 empirical 的问题，不能靠 intuition 定。

**否认 P3，之一：她得到的是 ability。** “Know” 有两种意思。一种是 knowing that，知道一个 fact；一种是 knowing how，会做一件事。Mary 出来后得到的是后一种：认出 red、想象 red、记住 red 的 ability。学会骑车的人没有多知道一个 fact。照这个说法，原 argument 在 “know” 上 equivocate：P1 用的是 knowing that，P2 只有理解成 knowing how 才为真。

**否认 P3，之二：旧的 fact，新的把握方式。** Lois Lane 发现 Clark Kent 会飞时，确实得到了新的 knowledge。可是 “Clark Kent 会飞” 和她早就知道的 “Superman 会飞” 是同一个 fact。Mary 也是这样：她出来后用一种新的 concept 把握了一个早已知道的 physical fact。新的 knowledge 推不出新的 fact。

**Jackson 一方的 reply。** 对 ability 的说法：Mary 出来后明白的不只是自己能做什么，她还明白了别人这些年看见番茄时一直有的是什么感觉，这是关于 world 的一件事。对 Lois Lane 的类比：Lois 之所以能学到新东西，是因为她原先缺一个 fact，即两个名字指同一个人。Mary 按规定不缺任何 physical fact。MIT 的讲义也提醒了这一点：一个真的知道某人全部情况的人，会知道他的另一个名字。

SEP 记了一笔：Jackson 本人后来不再支持这个 argument。

:::wrong Mary 的 argument 如果成立，就说明 soul 存在
它的 conclusion 是 “有 non-physical 的 fact”，说的是 experience 有一种 physical 描述抓不住的 property。这叫 property dualism。它没有说有一个能离开 body 独立存在的东西；那是 substance dualism，是 Descartes 的 conclusion。Jackson 自己从不主张 soul，他主张的是 brain 除了 physical property 之外还有 qualia 这种 property。两种 dualism 的 argument 不同，麻烦也不同，考试里常拿它们互相干扰。
:::

### 接受 conclusion 的代价：epiphenomenalism

假设 knowledge argument 成立，qualia 是 non-physical 的。再加一条很多人接受的 premise，叫 causal closure：每一个有 cause 的 physical event，都有一个充分的 physical cause。你喊 “疼” 是一个 physical event，它的 cause 链条从声带到 motor cortex 再到 C-fibre，全是 physical 的。那么 non-physical 的 pain 感觉在这条链上没有位置，它什么也没引起。这个立场叫 **epiphenomenalism**：physical event 引起 qualia，qualia 不引起任何 physical 的东西。Jackson 当年接受了它，并回答了三个 objection。

| Objection | Jackson 的 reply |
|---|---|
| Pain 引起喊疼，这是明摆着的。 | 明摆着的只是 pain 之后总跟着喊疼。两者可以是同一个 brain 过程的两个结果，就像电影里前一帧并不引起后一帧。 |
| Pain 的难受是 evolution 选出来让我们躲避伤害的；它要是不起作用，natural selection 就选不到它。 | 被选中的是 brain 的那个过程，qualia 是跟着来的。北极熊被选中的是保暖的厚毛，毛很重是副产品，没有被选。 |
| 我们靠别人的行为推知别人有 pain；pain 要是不引起行为，这个推断就没有根据。 | 一件事可以是另一件事的 evidence，而两者谁也不引起谁。在一份报纸上读到球队赢了，是另一份报纸也这样报道的好 evidence；两篇报道互不相干，只是有共同的来源。行为和 pain 也可以这样：出自同一个 brain 过程。 |

还有一个 Jackson 那张清单之外、后来常被提起的 objection：Mary 走出房间说 “原来 red 是这样的”，这句话是一个 physical event。按 epiphenomenalism，red 的 qualia 没有参与引起这句话。那么支撑 knowledge argument 的那些关于 qualia 的判断，本身就不是由 qualia 引起的。

所以这一站的选择是这样的：接受 physicalism，要回答 Mary；接受 property dualism，要么放弃 causal closure，要么接受 epiphenomenalism；接受 substance dualism，还要再加上 Elisabeth 的问题。

## [identity] Personal identity

:::skip
能说出 soul theory、body theory、personality theory 在 duplication 和 fission 里各自给出的 verdict；能重构 Parfit 从 fission 推到 “identity 不是 what matters” 的 argument；能解释 no-branching 条款为什么让人不安，就可以去第 6 站。
:::

### 问的是什么

你现在存一笔钱，打算 2050 年用。到时候花这笔钱的人是不是你？

这里的 “是你” 问的是 **numerical identity**：是不是同一个 person，而不是像不像。Kagan 在 PHIL 176 第 10 讲里用一列 train 来分开这两件事。站在车尾指着说 “这列 train”，沿着走到车头再指着说 “这列 train”，指的是同一列，尽管车尾和车头长得完全不同。问 “是不是同一列”，问的是这两处是否属于同一个延伸开去的整体。跨时间也一样：他 1990 年买的 car 到 2006 年已经满是划痕、换过零件，每个时刻的切面都不相同，car 是同一辆。

所以 2050 年的那个人可以和现在的你很不一样，仍然是你；需要的是把各个时刻连成一个 person 的那种东西，Kagan 叫它 glue。问题就是：glue 是什么。

还要分开一件事。SEP 的条目强调，这个问题问的是什么 “构成” 同一个 person，不是我们靠什么 “认出” 同一个 person。指纹是极好的 evidence，但没有人认为指纹相同就是 “是同一个人” 的意思。

:::wrong 两个人的 memory 和 personality 如果完全一样，他们就是同一个人
这是把 qualitative identity（一模一样）当成了 numerical identity（同一个）。两枚刚出厂的硬币一模一样，仍然是两枚。下面 Napoleon 的例子里，Michigan 一个人、New York 一个人，各有 Napoleon 的全部 personality，数一数是两个。两个东西不可能都和第三个东西 numerically identical，除非它们彼此也是同一个，这是 identity 的 transitivity。这一站最难的地方全都从这一条出来。
:::

候选的 glue 有三种。

| Theory | 同一个 person 就是 | 你死后还能存在吗 |
|---|---|---|
| Soul theory | 同一个 soul | 能，只要 soul 还在 |
| Body theory | 同一个 body；讲究一点，是同一个 brain | 一般不能 |
| Personality theory | 同一套 belief、memory、desire、goal，允许逐渐变化 | 只要这套 personality 被别的载体接续，就能 |

Body theory 为什么落到 brain 上：Kagan 的例子是，失去一只手、四肢，人还是那个人；brain 要是被搅成一锅 “pea soup”，人就没了。所以把你的 brain 移到别人的躯干上，按 body theory 应该说是你得到了一副新的躯干。Personality theory 允许逐渐变化：Kagan 十岁时想当清洁工，后来想当 logician，中间每一段都和前后大量重叠，像一根绳子由许多比绳子短得多的纤维搭接而成。

### Soul theory：换了也没人知道

Kagan 转述的 objection 来自 Locke。假设 soul 存在，并且 soul theory 为真。再假设今天凌晨三点，God 把你 body 里的 soul 拿走，换上另一个，并把你全部的 memory、belief、desire 原样装进新的 soul。早上醒来的人说 “我是某某”，记得昨天的事，继续过你的生活。

- **P1.** 如果 soul theory 为真，那么早上醒来的不是你，你在凌晨三点已经不存在了。
- **P2.** 这样的调换，无论从外面看还是从里面感觉，都发现不了。
- **P3.** 所以，如果 soul theory 为真，没有人有任何根据相信自己和昨天的那个人是同一个人。
- **P4.** 我们有很好的根据相信自己和昨天的那个人是同一个人。
- **C.** Soul theory 是假的。

这个 argument 不否认 soul 存在，它否认的是 “同一个 soul” 是 glue。Soul theory 的支持者可以否认 P4 的力量，说我们的根据本来就只是 “God 平时不这样做”；代价是承认 personal identity 落在一件原则上无法检查的事情上。

### Body 还是 personality：同一个 case 的两种讲法

平时同一个 body 总是带着同一套 personality，要知道哪一个是 glue，只能靠 thought experiment 把两者拆开。Williams 的 case 是这样的：A 和 B 两个人被接上一台机器，机器把各自 brain 里的全部信息互换。之后，A 的 body 带着 B 的全部 memory 和 personality 醒来，B 的 body 带着 A 的。

**第一种讲法。** 手术前告诉你（你是 A）：术后两个人里一个会得到 100,000 美元，一个会受酷刑，你可以完全出于自私来指定。多数人的回答是：钱给 B 的 body，酷刑给 A 的 body。理由是术后 “我” 在 B 的 body 里。这支持 personality theory。

**第二种讲法。** 有人告诉你：明天你会受酷刑。你害怕。他接着一条一条往上加：

1. 受刑之前，你的 memory 会被全部抹掉。
2. 你的 personality 也会被改掉。
3. 还会给你装上一套虚假的 memory。
4. 这套 memory 和 personality 其实是照着一个真人 B 的样子装的。
5. 它们是用一台机器直接从 B 的 brain 里读出来的。
6. 同一台机器还会把你原来的那一套装进 B 的 brain。

Williams 问：加到哪一条，你可以松一口气？第 1 条不能，失忆之后受刑仍然是受刑。第 2、3 条只让事情更糟。第 4、5 条说的是那套 memory 的来历，和你将要感到的 pain 无关。第 6 条说的是另一个人身上发生的事。可是六条加完，得到的正是第一种讲法里的 case，而这一回你怕的是 A 的 body 受刑。这支持 body theory。

同一个 case，两种讲法，两个相反的 verdict。Williams 自己的结论是他不知道该选哪个，并且觉得这一点令人不安。对这门课来说，这个 case 的用处是提醒：对一个 thought experiment 的 intuition 不能直接当成 evidence，它可能只是讲法的产物。

### Duplication 与 fission：三种 theory 都要打补丁

**Personality theory 先遇到麻烦。** Kagan 在第 12 讲里从一个容易的 case 出发。Michigan 有一个人一觉醒来，带着 Napoleon 的全部 memory 和 personality，从加冕到流放 Elba 都记得清清楚楚。按 personality theory，他是 Napoleon。这听着古怪，但也许可以接受。现在再加一个：New York 同时也有一个人带着同样的全套 personality 醒来。四种说法：

| 说法 | 麻烦 |
|---|---|
| Michigan 那个是 Napoleon，New York 那个不是 | 两人条件完全对称，没有任何理由偏向一个 |
| New York 那个是，Michigan 那个不是 | 同上 |
| 两个都是 | 由 transitivity，他们俩就是同一个 person，一个 person 同时在两个地方、做两件不同的事 |
| 两个都不是 | 最不坏。但这就承认了：有同样的 personality 并不 sufficient |

选第四种，personality theory 就得加一个条款：未来某人有我的 personality，**并且没有别人同时也有**，他才是我。这叫 no-branching 条款。

代价是这样的。按加了条款的 theory，星期四讲课的人是不是星期二讲课的那个人，不只取决于这两个人之间的关系，还取决于 Michigan 或者火星上有没有冒出一个复制品。一个人是不是他自己，竟然由远处一件与他毫无因果联系的事决定。Kagan 的评价是 “very, very hard to believe”。

**Body theory 逃不掉。** 第 13 讲把同样的事做在 brain 上。假设半个 brain 就足以支撑全部 personality（这在现实里多半不成立，但 thought experiment 只需要它 possible）。把你的 brain 分成两半，左半装进一副躯干，右半装进另一副。两个人醒来，Kagan 叫他们 Lefty 和 Righty。四种说法和上表一模一样，body theory 也得加 no-branching 条款。

**Soul theory 看似幸免。** 如果 soul 不可分，它只会跟着其中一个走。但没有人能知道是哪一个，Lefty 和 Righty 自己也不能，两人都会说 “我是原来那个”。而且没得到原来那个 soul 的那一位照样有 consciousness，能思考、能交谈，这就削弱了当初假定 soul 的理由：我们本来是为了解释这些能力才需要 soul 的。

### Parfit：identity 不是 what matters

Parfit 从 fission 里读出的是另一件事。他把三个 case 排成一列。

- **Brain transplant 1.** 你的整个 brain 被移进一个新的 body，那个人有你的 personality 和 memory。
- **Brain transplant 2.** 你的 body 和半个 brain 被毁，剩下的半个 brain 被移进一个新的 body。
- **Fission.** 你的 brain 分成两半，各移进一个新的 body。

然后是 argument：

- **P1.** 在 brain transplant 1 里你 survive。
- **P2.** 在 brain transplant 2 里你 survive。现实里就有半个 brain 被毁而活下来的人。
- **P3.** Fission 和 brain transplant 2 的唯一区别，是另外半个 brain 也被保住了。
- **P4.** 多保住一些属于你的东西，不会把 survival 变成 death。
- **C.** 在 fission 里，你至少没有失去 brain transplant 2 里保住的任何东西。

可是另一方面，Lefty 和 Righty 是两个 person：他们可以身处两个房间，一个饿了，另一个不饿。由 transitivity，你不可能和两个都 identical；由对称，也没有理由说你是其中一个。所以 fission 之后没有人和你 numerically identical。

两头合起来：fission 之后没有人是你，而你在普通 survival 里在乎的一切都还在，而且有两份。Parfit 由此得出，我们在乎的本来就不是 identity。平时 identity 和我们在乎的那种关系总是一起出现，所以没人把它们分开；fission 把它们拆开了。Identity 在这里失败，只是因为它在 logic 上必须一对一。

他认为真正要紧的关系是 psychological continuity：后来的人的 belief、desire、memory、性情由你的发展而来，一环扣一环。No-branching 的 psychological continuity 可以当作 identity 的 criterion，但其中 “no-branching” 这一半只是为了满足一对一，要紧的是另一半。

Kagan 从另一头走到了相近的地方。按 body theory，如果你的 brain 被彻底抹空、长出一套全新的 personality，那个人还是你。Kagan 的反应是 “me, but who cares?”。只剩 identity 而没有 personality 的 survival，不是他想要的。

**这个 conclusion 带来什么。** Psychological continuity 有程度之分，那么 survival 也有程度之分；多远的未来的那个人算 “我”，没有一条深刻的界线。Parfit 认为这会削弱两样东西：只为自己未来打算的 self-interest，和对自己死亡的特殊恐惧。

**最强的 objection。** Williams 的第二种讲法本身就是一个：在那个序列里，psychological continuity 全部转移到了别人身上，我对酷刑的恐惧却没有跟着走。Williams 还给了一个更直接的检验：假设你临死前，你的一部分 memory 被移植到另一个人身上，死亡会因此变得容易接受一些吗？如果答案是不会，Parfit 说的 “要紧的关系” 就没有他说的那么要紧。

:::wrong Parfit 认为 fission 之后你同时是两个人
“你是 Lefty，你也是 Righty” 是上表的第三种说法，Parfit 把它排在第二位。他首选的说法是：“fission 之后哪一个是你” 这个问题没有答案，也不需要答案。他的主张不是关于 identity 落在哪里，而是 identity 落在哪里并不重要。讲义里还提醒了一个用词问题：Parfit 有时说你 “survive” fission，那是宽松的用法，意思是 survival 里要紧的东西保住了；严格地说也可以讲成 “你没有 survive，但这并不可怕”。
:::

:::edge Personality theory 的另一个麻烦：你当过胎儿吗
SEP 的条目从完全不同的方向反对 psychological 的路线。现在没有任何人和一个 12 周的 foetus 有 psychological continuity，那时还没有任何 mental 的东西可供接续。所以按这条路线，你从来不曾是一个 foetus；如果你将来陷入永久的植物状态，躺在那里的也不是你。多数人的看法相反。另外，坐在你椅子上的那个 human animal 有 brain，看起来也在思考；如果你不是它，这里就有两个在思考的东西。主张 “我们就是 animal” 的立场叫 animalism，它没有这些麻烦，代价是在 brain transplant 1 里它得说：你留在了原地，是那个 brain 被取走的空壳。
:::

:::back
Transitivity 之所以致命，靠的是[第 1 站](#arg)里 sufficient condition 的反驳方式和 “thought experiment 为什么算数” 那一段。Soul 是否存在在[第 4 站](#mind)。

## [free] Free will 与 determinism

:::skip
能写出 Consequence Argument 并指出 compatibilist 的回应落在哪一步；能用 Frankfurt case 说明 PAP 被反驳的是 necessity；能说出 Galen Strawson 的 Basic Argument 为什么不需要 determinism 这条 premise，就可以去第 7 站。

### 问题：他本来可以不这样做吗

用 van Inwagen 的例子。法官 J 在时刻 T 只要举一下手，就能赦免一个犯人。他考虑之后没有举。我们无论责备他还是赞同他，都预设了一件事：他当时可以举手。van Inwagen 把 free will 定义成这种 power：能做出和实际所做不同的事（could have done otherwise）。

**Determinism** 是关于 world 的一个 thesis。SEP 的表述是：对 world 在任一时刻的完整描述，加上对 laws of nature 的完整陈述，entail 对 world 在其他任一时刻的完整描述。令 P₀ 是 J 出生之前某一时刻 world 的状态，L 是全部 laws，P 是时刻 T 的状态（包括 J 的手没有举）。Determinism 说 P₀ 和 L 合起来 entail P。

Determinism 是真是假是物理学的问题。哲学问的是：假如它是真的，J 还有没有 free will。

:::wrong 如果 determinism 为真，那么不管我怎么选，结果都一样
这是 fatalism，不是 determinism。Fatalism 说结果与你的 choice 无关：J 举不举手，犯人都会被处决。Determinism 说的正相反：犯人被处决，是因为 J 没举手；假如 J 举了，犯人就被赦免了。J 的考虑和决定是因果链上真实的一环。Determinism 让人不安的地方在更前面：J 怎样考虑、怎样决定，本身也被更早的状态和 laws 所 entail。另外，determinism 也不等于可预测：一个被决定的系统可以复杂到没有人算得出来。
:::

### Consequence Argument

认为 free will 和 determinism 不能并存的立场叫 **incompatibilism**。它最有分量的 argument 是 van Inwagen 的 Consequence Argument，MIT 的讲义按原文列成七步：

1. 如果 determinism 为真，那么 P₀ 和 L 合起来 entail P。
2. 如果 J 在 T 举了手，P 就是假的。
3. 所以，如果 J 当时能举手，J 就能使 P 为假。
4. 如果 J 能使 P 为假，而 P₀ 和 L 合起来 entail P，那么 J 能使 “P₀ 并且 L” 为假。
5. 如果 J 能使 “P₀ 并且 L” 为假，那么 J 能使 L 为假。
6. J 不能使 L 为假。
7. 所以，如果 determinism 为真，J 当时不能举手。

它 valid。假设 determinism 为真而 J 当时能举手。由 3，J 能使 P 为假；由 1 和 4，J 能使 “P₀ 并且 L” 为假；由 5，J 能使 L 为假。这和 6 矛盾。

每一步的依据：

- 第 4 步靠 logic。P₀ 和 L entail P，等于说 P 假的时候 “P₀ 并且 L” 必假。
- 第 5 步靠 past 的固定。P₀ 说的是 J 出生之前的事，没有人能改变。“P₀ 并且 L” 要为假，只能是 L 为假。
- 第 6 步靠 laws 的固定。van Inwagen 的说法是：一条有人能让它不成立的 proposition，就不算 law of nature。

接受这个 argument 的人有两种去处。认为 determinism 为真，于是没有 free will，叫 **hard determinism**。认为我们明明有 free will，于是 determinism 必须为假，叫 **libertarianism**。不接受这个 argument，认为两者可以并存，叫 **compatibilism**。

::fig[gex1015-freemap] 两个问题把立场分开：free will 和 determinism 能不能并存；determinism 是不是真的。底下那一条是 Galen Strawson 的立场，它不在这张 2×2 的表里。

### Compatibilist 的回应

**指对方 equivocation（Lewis）。** “J 能使 L 为假” 有两种读法。

- 弱读法：J 能做某件事，并且假如他做了，L 就会和实际的不一样。
- 强读法：J 能做某件事，这件事本身会 cause 一条 law 被打破。

按强读法，第 6 步显然为真：没有人能 cause 一条 law 被打破。可是前面几步推出来的只是弱读法。假如 J 举了手，那么在 determinism 之下，past 或 laws 必定和实际的有一点不同，这的确跟得出来；跟不出来的是 “这点不同是 J 举手 cause 的”。按弱读法，compatibilist 否认第 6 步：J 有一种 ability，它只有在 past 或 laws 稍有不同的情形下才会被行使，这并不比 “我们的 ability 依赖许多自己控制不了的环境” 更离奇。所以没有哪一种读法能让七步全部通过，这是第 1 站说的 equivocation。

Incompatibilist 的 reply：一种只有在 past 或 laws 与实际不同时才会行使的 ability，很难说是 J 在实际的 world 里真的拥有的 ability。SEP 的作者站在 compatibilist 一边，也承认这一点确实让人难以相信。

**给 “能” 一个 analysis（Hume）。** Hume 认为这场争论 “has hitherto turned merely upon words”。他给 liberty 的定义是：

> By liberty, then, we can only mean a power of acting or not acting, according to the determinations of the will.

也就是：假如你 choose 去做，你就做了；假如你 choose 不做，你就没做。这种 liberty 属于每一个 “not a prisoner and in chains” 的人，它的反面是 constraint，不是 causation。按这个 analysis，“J 当时能举手” 的意思是 “假如 J 当时 choose 举手，他就举了”。没有人按着他的胳膊，所以这句话为真，哪怕 determinism 也为真。

Counterexample 来自 SEP 转述的一个 case。Danielle 有一种心理障碍，使她不可能产生去碰金色小狗的 desire。父亲带来两只小狗，一只金色，一只黑色，她高兴地抱起了黑色的。她当时能抱起金色的吗？按 Hume 的 analysis，能：假如她 choose 抱金色的，她就抱了，没有东西拦着她的手。可是她根本无法 choose 那样做，所以实际上她不能。Analysis 给出的 condition 满足了，“能” 却不成立，它不 sufficient。

Hume 还有第二个论点，针对的是 libertarianism。Moral 的评价要落到人身上，必须经过 character：action 本身 “temporary and perishing”，只有当它出自这个人身上某种持久的东西时，才能算在他头上。如果 J 的决定不是由他的 reason、desire、character 引起的，它就只是碰巧发生在他身上的一件事。今天这叫 luck objection：没有被决定的 choice，看起来和轮盘转出的结果一样不受 agent 控制。

所以 incompatibilist 也有自己的两难：determinism 为真，有 Consequence Argument；determinism 为假，有 luck objection。

### Frankfurt：moral responsibility 不需要 alternative

到这里双方争的都是 “J 当时能不能举手”。Frankfurt 的做法是绕开它。我们关心 free will，是因为关心 moral responsibility；而把两者连起来的是一条通常没人怀疑的原则，叫 **Principle of Alternate Possibilities**（PAP）：一个人对他做的事负 moral responsibility，only if 他当时能 do otherwise。按第 1 站的改写，PAP 说 “能 do otherwise” 是 moral responsibility 的 necessary condition。要反驳它，得找一个有 responsibility 而没有 alternative 的 case。

Frankfurt 给的 case，按 SEP 的转述：Jones 已经决定开枪打死 Smith。Black 也希望 Smith 死，并且宁愿 Jones 自己动手。为防万一，Black 暗中做了安排：只要 Jones 露出一点要反悔的迹象，Black 就会操纵他，让他照样开枪。结果 Jones 没有反悔，出于自己的理由开了枪，Black 自始至终没有介入。

- Jones 负 moral responsibility 吗？负。他是自己想清楚、自己动的手，Black 的存在对实际发生的事没有任何影响。
- Jones 当时能不开枪吗？不能。无论如何他都会开枪。

有 responsibility，没有 alternative，PAP 是假的。于是就算 Consequence Argument 完全成立，它夺走的只是 “能 do otherwise”，而 responsibility 并不需要这个。要紧的不是有没有别的路，而是实际走的这条路是怎么来的。

**最强的 objection** 抓的是那个 “迹象”。Black 要在 Jones 做决定之前就看出他会不会反悔。如果这个迹象百分之百可靠，那就等于假定了 Jones 的决定被之前的状态所决定，而 incompatibilist 本来就不承认被决定的 Jones 负 responsibility，case 对他没有说服力。如果迹象不是百分之百可靠，Jones 就保留着一点 alternative：他至少可以开始反悔。Frankfurt 一方的 reply 是：这点残余太小，撑不起 responsibility；解释 Jones 为什么负责的仍然是他实际的决定过程。

**Frankfurt 的正面说法。** 既然要紧的是 action 的来源，就得说什么样的来源算 “出自这个人自己”。他区分两层 desire。First-order desire 的对象是做某件事，比如想吸毒。Second-order volition 的对象是自己的 desire：想让某个 first-order desire 成为实际推动自己的那个。一个人的 will 是 free 的，当推动他行动的 desire 正是他想要被它推动的那个。

拿三个 addict 检验。Unwilling addict 想吸，又不想让这个 desire 得逞，结果还是吸了：她的 will 不是她想要的，不 free。Willing addict 想吸，也乐于被这个 desire 推动：按 Frankfurt，他是 of his own free will 吸的，尽管成瘾使他没法不吸。Wanton addict 对哪个 desire 获胜毫不在意，他没有 second-order volition，谈不上 free 不 free。这套说法里没有一处要求 determinism 为假，所以是 compatibilism。

Objection：这套两层结构可以被人从外面装进去。如果有人靠洗脑或催眠，让你既想做一件事、又乐于想做它，两层完全吻合，按 Frankfurt 的 condition 你是 free 的，可是没有人会说你对这件事负责。所以光看此刻的结构不够，还得看它的来历。而 incompatibilist 接着问：在 determinism 之下，你的两层 desire 同样来自你控制不了的遥远原因，它和一场时间拉得很长的操纵，区别在哪里？

### Galen Strawson：不管 determinism 真假

上面的 objection 再往前推一步，就是 Galen Strawson 的 Basic Argument。它完全不提 determinism。

- **P1.** 你做一件事，是因为你是这样一个人（你的 character、preference、value）。
- **P2.** 要对你做的事负真正的 moral responsibility，你必须对 “你是这样一个人” 负责。
- **P3.** 要对 “你是这样一个人” 负责，你必须是有意把自己造成这样的。
- **P4.** 可是你有意把自己造成某个样子时，依据的是你当时已经有的 preference 和 value。要对这次塑造负责，你又得对那一套负责，于是又需要更早的一次有意塑造，如此往前，没有尽头。
- **P5.** 没有人能完成一个无穷的塑造序列。最早的那套 preference 来自 heredity 和幼年经历，不是你选的。
- **C.** 没有人对自己做的事负真正的 moral responsibility。

如果 determinism 为真，起点由 past 决定。如果 determinism 为假，中间掺进来的是 random 的事件，而 random 的事件同样不是你的作为。两种情况下 argument 都照常进行，所以这个立场在上面那张图的格子之外。

Compatibilist 否认 P2：负责只要求 action 以恰当的方式出自你自己，比如符合你的 second-order volition，不要求你是自己的最初原因。Strawson 的 reply：那样得到的不是 “真正的” responsibility。他说的真正的 responsibility，是那种能让惩罚和奖赏在最终意义上 just 的东西；如果人最终不是自己造成的，因为一个人的 action 惩罚他，并不比因为他头发的颜色惩罚他更 just。

所以分歧落在一个更前面的问题上：我们责备、感激、怨恨别人的这套 practice，需要的是 Strawson 说的那种终极的 responsibility，还是 compatibilist 说的那种就够了。P. F. Strawson（Galen 的父亲）站在后一边：resentment、indignation、guilt 这些 reactive attitude 是人际生活的组成部分，把某人当作 responsible 的，就是对他持有这些态度；这套态度不等哲学对 determinism 作出裁决，也不会因为裁决而被放弃。

### 走一遍：各方怎么判 J

回到法官 J。假设他没有受到任何胁迫，没举手是他权衡之后自己愿意的决定。

| 立场 | J 当时能举手吗 | J 负 moral responsibility 吗 | 这个立场必须回答的 objection |
|---|---|---|---|
| Hard determinism | 不能（Consequence Argument 加 determinism） | 不负 | 我们整套责备与赞扬的 practice 都建立在错误上吗 |
| Libertarianism | 能，条件是他的决定没有被 P₀ 和 L 决定 | 负 | Luck objection：没被决定的决定凭什么算他的 |

## [ethics] Right and wrong：utilitarianism、Kant 与 trolley cases

:::skip
能用“数人头”、killing 与 letting die 的区分、Formula of Humanity 分别分析 switch、footbridge、transplant、loop，并说出每一条 principle 卡在哪个 case 上；能说清 experience machine 反驳的是 utilitarianism 的哪一个 component，就读完这门课了。
:::

### 三个 case，两种 reasoning

Sandel 的 Justice 第一讲从这里开始。

**Trolley driver。** 你是一辆 trolley 的司机，车速每小时 60 英里，刹车坏了。前方轨道上有五个工人，撞上去必死。你可以把车拐进一条岔道，岔道上有一个工人。拐不拐？

**Footbridge。** 这回你不是司机，你站在轨道上方的桥上。前方还是五个工人。你身边有一个很胖的人探身在栏杆外，把他推下去，他的身体能挡住 trolley，他会死，五个人得救。推不推？

**Transplant。** 你是外科医生，有五个病人各缺一个 organ，今天不移植就会死。隔壁有一个来体检的健康人。取不取？

三个 case 里摆着的数字相同：一条命换五条命。Gendler 在 Yale PHIL 181 的课堂上让学生用按键投票，结果是：

| Case | 认为这样做 morally prohibited 的比例 |
|---|---|
| Trolley driver 拐进岔道 | 约 7% |
| Footbridge 推人 | 约 78% |
| Transplant 取 organ | 85% |

Sandel 把人们给出的理由分成两种。说 “五个人活比一个人活好” 的，是在看 action 的 consequence，他称为 consequentialist reasoning。说 “推人、杀人这件事本身就不能做” 的，是在看 action 本身的性质，他称为 categorical reasoning。同一批人在第一个 case 里用前一种，在后两个 case 里用后一种。一个 moral theory 要么说明这种切换有道理，要么说明其中一些判断是错的。

### Utilitarianism 由哪几条组成

把 consequentialist reasoning 贯彻到底的 theory 是 utilitarianism。Mill 的表述是 “actions are right in proportion as they tend to promote happiness”，其中 happiness 指 pleasure 和没有 pain；而且算的不是行动者自己的 happiness，是 “that of all concerned”，行动者要像一个 “disinterested and benevolent spectator” 那样 impartial。

SEP 的条目把这个立场拆成十来条互相独立的 claim。对后面的 objection 来说，要紧的是三条：

| Component | 说的是 | 针对它的 case |
|---|---|---|
| Consequentialism | 一个 action 是不是 right，只取决于它的 consequence | Footbridge、transplant |
| Hedonism | Consequence 的好坏只取决于 pleasure 和 pain | Experience machine |
| Maximizing 加 impartial 的求和 | 把所有受影响者的得失加起来，总和最大的那个 action 是 right 的；每个人的同等得失分量相同 | Transplant |

三条可以分开接受。看清一个 objection 打的是哪一条，才知道被打中之后还剩下什么。

:::wrong Utilitarianism 就是多数人说了算
它比较的是总和，不是人数。设一个 action 让三个人各得 1 个单位的 happiness，让第四个人失去 10 个单位。受益的是多数，3 比 1。总和是 3 × 1 − 10 = −7，utilitarianism 判它 wrong。反过来，让一个人得 10、另外三个人各失 1 的 action，总和是 +7，utilitarianism 判它 right，尽管多数人受损。“The greatest happiness of the greatest number” 这句口号里，起作用的是前半句。
:::

**Mill 给它的理由。** 一条关于终极目的的原则没法从别的原则推出来，Mill 承认这一点，他给的是一种间接的支持：“the sole evidence it is possible to produce that anything is desirable, is that people do actually desire it”。每个人都 desire 自己的 happiness，所以每个人的 happiness 对这个人是 good；于是 general happiness 对所有人合起来是 good。这两步都受到过批评，而且用的正是第 1 站的工具。第一步在 “desirable” 上 equivocate：它可以指 “能够被 desire”，也可以指 “值得被 desire”，people desire it 只支持前一个意思，utilitarianism 需要的是后一个。第二步从 “每个人各自 desire 自己的 happiness” 到 “所有人 desire 所有人的 happiness”，推不过去。

**“没有时间算”。** 每次行动前把所有人的得失算一遍，做不到。Mill 的回答是人类有整个历史的经验可用，“不要撒谎”“不要偷” 这些 secondary principle 就是算好了的结果，就像航海的人出海前不必自己重算一遍星表。SEP 把这个回答说得更一般：utilitarianism 是 right 的 criterion，说的是什么使一个 action right；它不是 decision procedure，不要求人照着它一步步做决定。

### Experience machine：针对 hedonism

Hedonism 最早的 objection 是说它把人降到了动物的水平，Mill 引述为 “a doctrine worthy only of swine”。他的回答是 pleasure 有 quality 的高低，判断标准是两种都体验过的人更偏向哪一种，所以 “better to be Socrates dissatisfied than a fool satisfied”。批评者说，一旦承认有的 pleasure 因为别的原因更有价值，就已经不是 hedonism 了。

Nozick 的 experience machine 把问题推到了头。有一台机器，接上之后它给你一辈子的 experience：你以为自己有挚友、拿了奥运金牌、得了 Nobel Prize，pleasure 一分不少，pain 很少。你不会知道这是假的。

- **P1.** 如果 hedonism 为真，那么接上机器过一辈子是对你最好的人生。
- **P2.** 接上机器过一辈子不是对你最好的人生。
- **C.** Hedonism 是假的。

Modus tollens，valid。P1 来自 hedonism 的定义和机器的规定。P2 的依据是：多数人不愿接上，而且这种不愿意看起来是合理的。我们想要的是真的有朋友、真的做成事，不只是有 “有朋友” 的感觉。

Hedonist 的 reply，SEP 记了一种：有一类 pleasure 是 “为某件事而高兴”，比如母亲为女儿成绩好而高兴。机器里女儿并没有考好，这件事不存在，所以这种 pleasure 机器给不了，hedonist 可以把它算进去。

要注意这个 argument 打掉的范围。它只针对三条里的 hedonism。把 “好的 consequence” 换成 desire 得到满足，或者换成 friendship、knowledge、achievement 这样的多种 good，consequentialism 和 maximizing 可以原样保留。

### Transplant：针对 maximizing

SEP 把 case 的条件定得很严：五个病人，一个与五人都匹配的体检者，医生做了不会被任何人发现。

- **P1.** 如果 act utilitarianism 为真，那么医生应该杀死体检者，把 organ 分给五个人。
- **P2.** 医生不应该这样做。
- **C.** Act utilitarianism 是假的。

Valid。P1：五条命的总和大于一条，case 已经规定没有别的后果。P2：几乎所有人的判断。Utilitarian 有三种回应。

**否认 P1：算上长远的 consequence。** 医院可以拆病人的消息传开，没有人敢再去体检，死的人更多。所以 utilitarianism 的 verdict 本来就是不取。Objector 的 reply：case 规定了没有人会知道。

**修改 theory：rule consequentialism。** 不问单个 action 的 consequence，问 rule 的：如果人们普遍接受某条 rule，consequence 最好，那么违反这条 rule 的 action 就是 wrong 的。“医生可以取不自愿者的 organ” 这条 rule 被普遍接受的后果很糟，所以医生不该取。Act 一方的 reply（SEP 引的是 Smart 的问题）：既然出发点是 consequence，在明知这一次违反 rule 的 consequence 更好的时候，凭什么还要守 rule？别的医生会弄错，为什么让这个医生的正确 action 变成 wrong 的？

**否认 P2。** 这是 bite the bullet：承认医生应该取。理由是：这个 case 极不正常，我们的 moral intuition 是在正常情形下形成的，不该拿来判断这种情形。

### Kant：看 maxim，不看 consequence

Kant 的出发点和 Mill 相反。Gendler 在第 13 讲里先摆出他的第一个论断：世上唯一 good without qualification 的东西是 good will。聪明、坚毅、财富、健康都是有条件的 good：一个聪明、坚毅、健康的小偷，只是一个更成功的小偷。Good will 的价值不靠它达成了什么。

于是一个 action 有没有 moral worth，要看它出自什么。一个店主对每个顾客都如实找钱。如果是因为老实做生意对他有利，这个 action 只是 in conformity with duty。如果是因为如实找钱是对的，哪怕欺骗永远不会被发现他也这样做，才是 from duty，才有 moral worth。出于同情帮助别人，Kant 归在前一类。这常被误读成 Kant 反对同情。他没有说出于同情的帮助是 wrong 的，只说它的 moral worth 不来自同情。

所以 Kant 评价的对象是 **maxim**：行动者给自己立的规则，形式是 “在某种情况下，我就做某事，为了某个目的”。检验 maxim 的原则叫 categorical imperative。它是 categorical 的，因为它不以 “如果你想要某某” 开头，对任何有 reason 的 agent 都成立。第一种表述是 **Formula of Universal Law**：

> Act only in accordance with that maxim through which you can at the same time will that it become a universal law.

SEP 把用法整理成四步，用 Kant 自己的例子走一遍。

1. **写出 maxim。** “缺钱的时候，我就向人借，并承诺归还，尽管我知道自己不会还。”
2. **把它设想成一条 universal law。** 每个人缺钱时都作这种假承诺。
3. **问：这样一个 world 能不能被 conceive？** 在那个 world 里，人人知道缺钱者的承诺是假的，没有人会因为一句承诺而借钱，promise 这种 practice 不存在了。而我的 maxim 正是要靠 promise 弄到钱。Maxim 一旦成为 universal law，就毁掉了它自己要用的工具。这叫 contradiction in conception。
4. **如果能 conceive，再问：我能不能 will 这样一个 world？** 这个例子在第 3 步已经失败，用不到第 4 步。

第 3 步失败的 maxim 对应 perfect duty，没有例外：不许作假承诺。第 3 步通过、第 4 步失败的对应 imperfect duty。Kant 的例子是 “别人有难，我一概不帮”：人人如此的 world 可以 conceive，但我不能 will 它，因为我自己迟早需要别人帮助。所以有帮助别人的 duty，但帮谁、帮多少有余地。

:::wrong Universal law 的检验就是问 “如果人人都这样做，后果好不好”
那是 rule consequentialism 的问法，上一节刚见过。Kant 问的是另一件事：我的 maxim 成为 universal law 之后，它自己还行不行得通。假承诺被否决，原因不是 “人人说谎的 world 很不幸福”，而是在那个 world 里假承诺这件事根本做不成。区别可以用一个 maxim 试出来：“为了自己省事，我从不帮别人。”人人如此的 world 也许并不比现在更不幸福，rule consequentialism 未必禁止它；Kant 的第 4 步禁止它，理由和 happiness 的总量无关。
:::

第二种表述是 **Formula of Humanity**：对待 humanity，无论在自己还是在别人身上，决不能 merely as a means，总要同时当作 end。“Merely” 这个词不能漏。我们时时在用别人当 means，坐出租车就是在用司机。SEP 的解释是：被禁止的是以对方无法同意的方式使用他。司机同意载客收费，所以不是 merely as a means。假承诺的受害者被蒙在鼓里，他没法同意一个他不知道的计划，所以是。

### Trolley problem：五个 case，没有一条 principle 全对

拿 Formula of Humanity 去检验开头的三个 case。

- **Transplant。** 体检者的 body 被拿来当 organ 的来源，他没有同意。Merely as a means，禁止。
- **Footbridge。** 胖子的 body 被拿来当挡车的东西。Merely as a means，禁止。
- **Trolley driver。** 岔道上的工人没有被拿来做任何事。检验的办法是问：假如他不在那里，计划还成不成？成，而且更好。他的死是拐弯的 side effect，不是救人的 means。“Merely as a means” 这条禁令没有被触犯。

三个 case 的判断都和课堂投票一致。这个按 “means 还是 side effect” 划线的想法，在 Kant 之外另有一个名字，叫 doctrine of double effect：为了好的结果，有时可以造成一种预见到但并非有意的伤害，却不可以把同样的伤害当作手段。

Foot 提出过另一条线：**killing 比 letting die 更难被辩护**。司机不拐弯是他开的车撞死五个人，拐弯是撞死一个，他在 “kill 五个” 和 “kill 一个” 之间选，当然选后者。医生不动手是 let 五个人 die，动手是 kill 一个，所以不许。

Thomson 用两个新的 case 分别检验这两条线。

**Bystander at the switch。** 你不是司机，只是站在道岔旁边的路人，可以扳道岔。不扳，是 let 五个人 die；扳，是 kill 一个人。按 Foot 的线，这和 transplant 是同一种选择，应当禁止。Gendler 课堂上的投票：15% 认为必须扳，70% 认为可以扳，15% 认为不许。Foot 的线和判断对不上。

**Loop。** 还是路人和道岔，但岔道绕一圈之后接回主轨。岔道上那个人块头很大，trolley 撞上他会停住；假如他不在那里，trolley 会绕回来照样撞死五个人。这回他的 body 正是救人的 means。按 Formula of Humanity 和 double effect，这和 footbridge 是同一种，应当禁止。课堂投票：14% 必须，68% 可以，18% 不许，和 bystander 几乎一样。“Means” 这条线也对不上。

::fig[gex1015-trolley] 三种轨道的俯视图。方块是 trolley，五个小点是五个人，彩色的点是那一个人。在 switch 里，岔道上的人不在场，五个人照样得救；在 footbridge 和 loop 里，没有那个人的 body，五个人就得不了救。

把五个 case 和三条 principle 排在一起。

| Case | 数人头 | Killing 比 letting die 更难辩护 | 不许 merely as a means | 课堂上的多数判断 |
|---|---|---|---|---|
| Trolley driver | 拐 | 拐（kill 一个对 kill 五个） | 可以 | 可以（约 93%） |
| Bystander at the switch | 扳 | 不许（kill 一个对 let 五个 die） | 可以 | 可以（85%） |
| Transplant | 取 | 不许 | 不许 | 不许（85%） |
| Footbridge | 推 | 不许 | 不许 | 不许（约 78%） |
| Loop | 扳 | 不许 | 不许 | 可以（82%） |

每一列 principle 都至少和一行判断冲突：数人头错在 transplant 和 footbridge，killing 与 letting die 错在 bystander 和 loop，means 错在 loop。Trolley problem 指的就是这个局面：找不到一条简单的 principle 同时说明这五个判断。

出路有三个方向，每一个都有人在走。

- 继续找 principle。Gendler 在课上转述 Thomson 的一个方向是诉诸 rights：transplant 侵犯了体检者对自己 body 的 right，而 right 压过 utility。它要解释为什么 loop 里的人没有同样的 right。
- 放弃一部分 intuition。Utilitarian 会说 footbridge 和 transplant 里的抗拒是一种不该当作 evidence 的反应。Sandel 课上做过一个试探：把 “亲手推” 改成 “转一个把手，让胖子脚下的活板门打开”。被问到的学生仍然认为不该做，但没有原先那么肯定。Utilitarian 会说，一个随着 “手有没有碰到人” 而松动的判断，追踪的可能不是 moral 上要紧的东西。
- 放弃另一部分 intuition。Thomson 本人在 2008 年改了看法，认为 bystander 其实不许扳道岔。
