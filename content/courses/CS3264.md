先看三个和直觉对不上的现象。

**第一个。** 造 1000 个 classifier，每个对每个 input 都抛一次硬币决定 label，所以每个的 true error 都是 0.5。拿 100 个 training example 去评，挑出 training error 最小的那个，它的 training error 平均是 0.34。只看 training error，会以为找到了一个比随机好得多的 classifier。

::fig[cs3264-pick] 动图：一组实际抽出的 coin-flip classifier（固定 seed），个数从 1 加到 1000。看灰点堆在 0.5 两侧，而 ERM 选中的那一个（彩色箭头）随着个数增加一路往左走；它的 true error 始终在虚线 0.5 上。

**第二个。** 两个都只有一个 parameter 的 hypothesis class：threshold $h_a(x)=\mathbf 1[x\ge a]$，和 $h_\omega(x)=\mathbf 1[\sin(\omega x)>0]$。前者 74 个 example 就能以 95% 的 probability 把 error 压到 5% 以内；后者对任意多个点、任意一组 label 都有一个 $\omega$ 能全部拟合，因而存在让任何 learner 都学不好的 distribution。

**第三个。** AdaBoost 在一个二维 dataset（300 个 training example）上跑到第 85 轮，training error 变成 0。再跑下去，每轮都往 model 里多加一个 stump，test error 却从 5.6% 继续降到第 562 轮的 4.2%。

这门课问的是：training error 和 true error 之间的 gap 由什么决定，以及能不能用有限的 data、有限的计算把 true error 压下来。第一个现象说明 gap 和“在多少个 hypothesis 里挑”有关；第二个说明 parameter 的个数不是正确的量；第三个说明连 hypothesis class 的大小都不够，还要看 margin。各站给出一串越来越精细的 complexity 度量，每一种配一个 bound：

| 站 | 问题 | complexity 用什么量 | 核心 bound 的量级 |
|---|---|---|---|
| 1 | 有限个 hypothesis | $\lvert H\rvert$ | $\sqrt{\ln\lvert H\rvert/m}$ |
| 2、3 | infinite 的 class | VC dimension $d$、Rademacher complexity | $\sqrt{d\ln(m/d)/m}$ |
| 3、6 | dimension 比 data 还多 | weight 的 norm 与 margin $\gamma$ | $BX/(\gamma\sqrt m)$ |
| 4 | ERM 怎么算出来 | smoothness、strong convexity | $1/k$、$(1-\mu/L)^k$、$B\rho/\sqrt T$ |
| 5 | data 不是 i.i.d. | regret | $\sqrt{T\ln N}$ |
| 7 | 输出 probability | log-loss 与 KL divergence | excess risk 就是 KL |
| 8 | 很多 weak learner 一起 vote | voting margin | 与轮数无关 |

通篇的记号：data $S=(z_1,\dots,z_m)$，$z_i=(x_i,y_i)$ 从未知的 distribution $\mathcal D$ i.i.d. 抽出；$L_{\mathcal D}(h)$ 是 true error（或一般的 loss 的 expectation），$L_S(h)=\frac1m\sum_i\ell(h,z_i)$ 是 training error。课程描述里的 reinforcement learning 这一页没有写，见 [CS4246](../courses/CS4246.html)。

## [pac] PAC learning、ERM 与 concentration

:::skip
能从 Markov inequality 一路推到 Hoeffding inequality，能对有限的 $H$ 写出 realizable 与 agnostic 两种情形的 sample complexity 并说明 $1/\varepsilon$ 与 $1/\varepsilon^2$ 的差别从哪里来，就可以去第 2 站。
:::

### 为什么必须事先限定 hypothesis class

最自然的 learner 是 empirical risk minimization（ERM）：在所有候选里挑 training error 最小的。如果候选是所有 function，ERM 可以选这样一个 memorizer：

$$h_S(x)=\begin{cases}y_i&x=x_i\text{ 对某个 }i\\0&\text{otherwise}\end{cases}$$

它的 training error 永远是 0。设 $x$ 在 $[0,1]$ 上 uniform，真实的 label 是 $\mathbf 1[x\ge0.5]$。新抽的 $x$ 以 probability 1 不在 training set 里，$h_S$ 一律答 0，在 $x\ge0.5$ 的那一半上全错，true error 是 0.5。

毛病不止 memorizer 一家。设 domain 里有 $2m$ 个点，$\mathcal D$ 在这 $2m$ 个点上 uniform，真实的 labeling $f$ 从全部 $2^{2m}$ 种里随机抽一种。$m$ 个 sample 最多看到 $m$ 个不同的点，至少一半的点没见过。对一个没见过的点，$f$ 在它上面的 label 是一枚和 $S$ independent 的 fair coin，任何 learner 的 prediction 猜对的 probability 都是 $\tfrac12$。所以

$$\mathbb E_f\,\mathbb E_S\big[L_{\mathcal D}(A(S))\big]\ \ge\ \underbrace{\tfrac12}_{\text{没见过的点的比例}}\times\underbrace{\tfrac12}_{\text{在这些点上猜错}}=\tfrac14$$

对 $f$ 取平均至少是 $\tfrac14$，那么至少有一个具体的 $f$ 使 $\mathbb E_S[L_{\mathcal D}(A(S))]\ge\tfrac14$。这叫 No-Free-Lunch：没有一个 learner 能对所有 distribution 都学好。要学，就必须在看 data 之前把候选限定在一个 hypothesis class $H$ 里，这是一种 prior knowledge，叫 inductive bias。这一站和下一站回答：$H$ 满足什么条件，ERM 才靠得住。

### 一个 hypothesis：从 Chebyshev 到 Hoeffding

先固定一个 $h$。每个 example 上的 loss $\mathbf 1[h(x_i)\ne y_i]$ 是 i.i.d. 的 Bernoulli random variable，mean 是 $p=L_{\mathcal D}(h)$，$L_S(h)$ 是它们的平均。要问 $L_S(h)$ 离 $p$ 有多远。

Chebyshev inequality 给出 $\Pr(|L_S-p|\ge\varepsilon)\le\dfrac{p(1-p)}{m\varepsilon^2}\le\dfrac1{4m\varepsilon^2}$，只随 $m$ 按 $1/m$ 衰减。对一个 $h$ 这够用，麻烦在后面：ERM 要同时照顾 $H$ 里所有的 $h$，得把 $|H|$ 个 failure probability 加起来（union bound）。用 Chebyshev，$|H|$ 个加起来是 $\dfrac{|H|}{4m\varepsilon^2}$，要它不超过 $\delta$，就要

$$m\ \ge\ \frac{|H|}{4\delta\varepsilon^2}$$

$|H|=1000$、$\varepsilon=\delta=0.05$ 时是 2,000,000 个 example，而且和 $|H|$ 成正比。要让 $|H|$ 只以 $\ln|H|$ 的形式进来，failure probability 必须随 $m$ exponential 地衰减。

办法是对 $e^{\lambda X}$ 用 Markov inequality。设 $X_1,\dots,X_m$ independent，$X_i\in[a,b]$，mean 都是 $\mu$。对任意 $\lambda>0$：

$$\Pr\Big(\sum_i(X_i-\mu)\ge m\varepsilon\Big)=\Pr\Big(e^{\lambda\sum_i(X_i-\mu)}\ge e^{\lambda m\varepsilon}\Big)\le e^{-\lambda m\varepsilon}\,\mathbb E\,e^{\lambda\sum_i(X_i-\mu)}=e^{-\lambda m\varepsilon}\prod_i\mathbb E\,e^{\lambda(X_i-\mu)}$$

最后一步用了 independence。剩下要估计一个 bounded、mean 为 0 的 random variable $Y$ 的 $\mathbb E\,e^{\lambda Y}$，这就是 Hoeffding's lemma：

$$Y\in[a,b],\ \mathbb EY=0\quad\Longrightarrow\quad\mathbb E\,e^{\lambda Y}\le e^{\lambda^2(b-a)^2/8}$$

代进去：

$$\Pr\Big(\frac1m\sum_iX_i-\mu\ge\varepsilon\Big)\le\exp\Big(-\lambda m\varepsilon+\frac{m\lambda^2(b-a)^2}{8}\Big)$$

右边对 $\lambda$ 是一个 quadratic 的 exponent，在 $\lambda=\dfrac{4\varepsilon}{(b-a)^2}$ 取最小，代回去 exponent 是 $-\dfrac{4m\varepsilon^2}{(b-a)^2}+\dfrac{2m\varepsilon^2}{(b-a)^2}$。另一侧同理，合起来就是 Hoeffding inequality：

$$\Pr\Big(\Big|\frac1m\sum_iX_i-\mu\Big|\ge\varepsilon\Big)\le2\exp\Big(-\frac{2m\varepsilon^2}{(b-a)^2}\Big)$$

0-1 loss 有 $b-a=1$。拿 $p=0.5$、$\varepsilon=0.05$、$m=1000$ 比一下三个数：真实的 probability 是 0.0017，Chebyshev 给 0.1，Hoeffding 给 $2e^{-5}=0.0135$。

::fig[cs3264-tail] 同一个 tail probability，$p=0.5$、$\varepsilon=0.05$，横轴是 $m$。Chebyshev 是 $100/m$，在 log scale 上几乎是平的；Hoeffding 和真实值是同样陡的 exponential，只差一个 constant factor。

### Hoeffding's lemma 的 proof

:::skip
跳过它，后面只需要记住结论：bounded、mean 为 0 的 random variable 的 $\mathbb E\,e^{\lambda Y}$ 不超过 $e^{\lambda^2(b-a)^2/8}$。第 3 站的 McDiarmid 和第 5 站的 Hedge 都会再用它。
:::

$e^{\lambda y}$ 是 convex function，所以在 $[a,b]$ 上它在连接两个 endpoint 的 chord 下方：

$$e^{\lambda y}\le\frac{b-y}{b-a}e^{\lambda a}+\frac{y-a}{b-a}e^{\lambda b}$$

两边取 expectation，用 $\mathbb EY=0$：

$$\mathbb E\,e^{\lambda Y}\le\frac{b}{b-a}e^{\lambda a}-\frac{a}{b-a}e^{\lambda b}$$

记 $p=\dfrac{-a}{b-a}$（$a\le0\le b$，所以 $p\in[0,1]$），$u=\lambda(b-a)$。右边可以写成 $e^{\phi(u)}$，其中

$$\phi(u)=-pu+\ln\big(1-p+pe^u\big)$$

逐项验证：$e^{\phi(u)}=e^{-pu}(1-p+pe^u)$，而 $-pu=\lambda a$，$e^{\lambda a}(1-p)=\frac{b}{b-a}e^{\lambda a}$，$e^{\lambda a}pe^{u}=\frac{-a}{b-a}e^{\lambda b}$，正好是右边两项。

现在对 $\phi$ 在 0 处做 Taylor expansion。$\phi(0)=0$。$\phi'(u)=-p+\dfrac{pe^u}{1-p+pe^u}$，所以 $\phi'(0)=0$。记 $q=\dfrac{pe^u}{1-p+pe^u}\in[0,1]$，再求一次 derivative 得 $\phi''(u)=q(1-q)\le\tfrac14$。由 Taylor's theorem，存在 $\xi$ 使

$$\phi(u)=\phi(0)+\phi'(0)u+\tfrac12\phi''(\xi)u^2\le\frac{u^2}{8}=\frac{\lambda^2(b-a)^2}{8}$$

### Realizable：有一个 hypothesis 完全正确

假设 $H$ 有限，而且有某个 $h^\star\in H$ 的 true error 是 0（realizable）。ERM 选出的 $h_S$ 的 training error 是 0。它的 true error 超过 $\varepsilon$，意味着有一个“坏的”$h$（$L_{\mathcal D}(h)>\varepsilon$）在 $m$ 个 example 上一个都没错。对一个固定的坏 $h$：

$$\Pr\big(L_S(h)=0\big)=\prod_{i=1}^m\Pr\big(h(x_i)=y_i\big)\le(1-\varepsilon)^m\le e^{-\varepsilon m}$$

最后一步用 $1-\varepsilon\le e^{-\varepsilon}$。坏的 $h$ 最多 $|H|$ 个，union bound：

$$\Pr\big(L_{\mathcal D}(h_S)>\varepsilon\big)\le|H|\,e^{-\varepsilon m}$$

令右边 $\le\delta$，得 sample complexity

$$m\ \ge\ \frac{\ln|H|+\ln(1/\delta)}{\varepsilon}$$

这里没有用 Hoeffding：坏 $h$ 要“一个都不错”，这件事本身的 probability 就 exponential 地小。

用一次。$x$ 在 $[0,1)$ 上 uniform，真实 label 是 $\mathbf 1[x\ge0.5]$，$H$ 是 threshold $a\in\{0,0.001,\dots,0.999\}$，$|H|=1000$。取 $\varepsilon=\delta=0.05$：

$$m\ge\frac{6.908+2.996}{0.05}=198.07,\qquad\text{即 199 个 example}$$

再看这个 bound 有多松。Threshold $a$ 的 true error 是 $|a-0.5|$。在 training error 为 0 的 threshold 里挑最坏的一个，它的 error 超过 0.05，当且仅当 $[0.45,0.5)$ 里没有 sample，或者 $[0.5,0.55)$ 里没有 sample。用 inclusion-exclusion，probability 约为 $2\times0.95^{199}-0.90^{199}=7.4\times10^{-5}$，比要求的 0.05 小了约 700 倍。Union bound 把 1000 个 hypothesis 各算了一遍，而真正决定成败的只有 0.45 和 0.55 附近那两个。第 2 站从这里接着讲。

::fig[cs3264-sandwich] 一组实际抽出的 199 个 sample（seed 7）。下面一行放大了 0.5 附近；第 2 站的 $a_-$、$a_+$ 就是这里的 0.45 和 0.55。

:::edge $\delta$ 只出现在 log 里
同一个例子，把 $\delta$ 从 0.05 降到 0.0001，$\ln(1/\delta)$ 从 3.0 变成 9.2，$m$ 只从 199 变成 323。可信度要得很高并不贵，accuracy $\varepsilon$ 要得高才贵。
:::

### Agnostic：没有完美的 hypothesis

一般情况下 label 有 noise，$H$ 里最好的 $h^\star$ 也有 error。这时目标改成和 $h^\star$ 比：$L_{\mathcal D}(h_S)\le L_{\mathcal D}(h^\star)+\varepsilon$。

办法是让 training error 同时对 $H$ 里所有的 $h$ 都接近 true error，叫 uniform convergence。对每个 $h$ 用 Hoeffding，再 union bound：

$$\Pr\big(\exists h\in H:\ |L_S(h)-L_{\mathcal D}(h)|>\varepsilon'\big)\le2|H|\,e^{-2m\varepsilon'^2}$$

在这个事件不发生时，ERM 的结果可以和 $h^\star$ 连起来比：

$$L_{\mathcal D}(h_S)\le L_S(h_S)+\varepsilon'\le L_S(h^\star)+\varepsilon'\le L_{\mathcal D}(h^\star)+2\varepsilon'$$

中间那步是 ERM 的定义。取 $\varepsilon'=\varepsilon/2$，令 $2|H|e^{-2m(\varepsilon/2)^2}\le\delta$：

$$m\ \ge\ \frac{2\ln(2|H|/\delta)}{\varepsilon^2}$$

同样的 $|H|=1000$、$\varepsilon=\delta=0.05$：$\dfrac{2\times\ln(40000)}{0.0025}=\dfrac{2\times10.597}{0.0025}=8477.3$，要 8478 个 example，是 realizable 的 43 倍。

差别来自 $1/\varepsilon$ 与 $1/\varepsilon^2$。Realizable 时要排除一个 error 为 $\varepsilon$ 的 $h$，只需要它出一次错，大约 $1/\varepsilon$ 个 example 就会碰上。Agnostic 时要分辨 error 为 0.30 和 0.35 的两个 hypothesis，得把 mean 估计到 $\pm\varepsilon$ 以内。$L_S(h)$ 的 standard deviation 是 $\sqrt{p(1-p)/m}$，$p=0.3$ 时是 $0.46/\sqrt m$，要它小于 $\varepsilon$ 就得 $m\gtrsim0.21/\varepsilon^2$。Realizable 时要排除的 $h$ 的 $p$ 只有 $\varepsilon$，variance $p(1-p)\approx\varepsilon$ 本身就小，这正是省下的那个 $1/\varepsilon$。

:::wrong 选出来的 $h_S$ 的 training error 是 $m$ 个 i.i.d. 的平均，直接用 Hoeffding 就能估计它的 true error
回到开头的 1000 个抛硬币的 classifier，$m=100$。对一个固定的 classifier，Hoeffding 说 training error 低于 0.35 的 probability 不超过 $e^{-2\times100\times0.15^2}=e^{-4.5}=0.011$（真实值是 0.0018）。可是在 1000 个里挑最小的，最小值不超过 0.35 的 probability 是 $1-(1-0.0018)^{1000}=0.83$，最小值的 expectation 是 0.339。

问题在于 $h_S$ 是看了 $S$ 之后挑的，对它来说 $S$ 已经不是一组新鲜的 sample。Hoeffding 只对事先固定的 $h$ 成立。正确的做法是上面的 union bound：$1000\times0.011=11$，比 1 还大，所以不能保证任何事，和观察到的现象一致。Uniform convergence 给出的是 $|L_S-L_{\mathcal D}|\le\sqrt{\ln(2|H|/\delta)/(2m)}=0.23$，于是只能说 $L_{\mathcal D}(h_S)\le0.34+0.23=0.57$，这是对的。
:::

## [vc] VC dimension 与 Sauer's lemma

:::skip
能判断 threshold、interval、plane 上的 halfspace 能 shatter 几个点，说出 VC dimension 和 parameter 个数为什么无关，并讲得出 Sauer's lemma 的 induction，就可以去第 3 站。
:::

### $|H|$ 是 infinite，问题却很简单

把上一站的 threshold 换成连续的：$H=\{\mathbf 1[x\ge a]:a\in\mathbb R\}$，$|H|=\infty$，上一站的 bound 失效。可这个问题直接做反而更容易。设真实 threshold 是 $a^\star$，取 $a_-<a^\star<a_+$ 使 $[a_-,a^\star)$ 和 $[a^\star,a_+)$ 的 probability 都是 $\varepsilon$。只要两个 interval 里各落进至少一个 sample，任何 training error 为 0 的 threshold 都被夹在 $(a_-,a_+)$ 里，true error 小于 $\varepsilon$。两个 interval 之一一个 sample 都没有的 probability 不超过 $2(1-\varepsilon)^m\le2e^{-\varepsilon m}$，所以

$$m\ge\frac{\ln(2/\delta)}{\varepsilon}=\frac{\ln40}{0.05}=73.8$$

74 个 example 就够，比 1000 个格点时的 199 还少。$|H|$ 显然不是正确的量。上一站的 union bound 实际用到的是“在 sample 上能表现出多少种不同的行为”：$m$ 个排好序的点，threshold 只能给出 $m+1$ 种 labeling（前 $k$ 个是 0、其余是 1，$k=0,\dots,m$），不管 $a$ 有多少种取法。

### Restriction、growth function、shattering

对一组点 $C=(c_1,\dots,c_m)$，$H$ 在 $C$ 上的 restriction 是它能产生的所有 label vector：

$$H_C=\{(h(c_1),\dots,h(c_m)):h\in H\}$$

$|H_C|\le2^m$。对 $m$ 个点取最坏的情形，得到 growth function $\tau_H(m)=\max_{|C|=m}|H_C|$。如果 $|H_C|=2^{|C|}$，即每种 labeling 都能做出来，就说 $H$ shatter $C$。$H$ 能 shatter 的最大点集的大小叫 VC dimension，记作 $\mathrm{VCdim}(H)$。

用两个 class 检验：

- **Threshold。** $\tau_H(m)=m+1$。一个点可以 shatter；两个点 $x_1<x_2$ 的 labeling $(1,0)$ 做不出来，因为 $x_1$ 已经过了 threshold，$x_2$ 更大，也一定过了。VC dimension 是 1。
- **Interval $\mathbf 1[x\in[s,t]]$。** 被标成 1 的点必须是排序后连续的一段。非空的一段由它的第一个点和最后一个点决定，有 $\binom m2+m$ 种，加上全 0，$\tau_H(m)=\tfrac{m(m+1)}2+1$。两个点能 shatter；三个点的 $(1,0,1)$ 做不出来，因为包含两端的 interval 必包含中间。VC dimension 是 2。

### Plane 上的 halfspace：VC dimension 是 3

$h(x)=\mathbf 1[w^\top x+b>0]$，$x\in\mathbb R^2$。三个不 collinear 的点，8 种 labeling 每种都能用一条 line 切出来。

四个点做不到，分三种情形。四个点 collinear 时，按顺序标成 $1,0,1,0$，和 interval 的论证一样不行。有一个点落在另外三个点组成的 triangle 里（含边上）时，把三个 vertex 标 1、中间的点标 0：halfspace 是 convex set，包含三个 vertex 就包含整个 triangle。四个点构成 convex quadrilateral 时，两条 diagonal 相交于一点 $z$；把一条 diagonal 的两端标 1、另一条的两端标 0。$z$ 是第一条 diagonal 两端的 convex combination，两端都满足 $w^\top x+b>0$，所以 $z$ 也满足；$z$ 又是第二条 diagonal 两端的 convex combination，两端都满足 $w^\top x+b\le0$，所以 $z$ 也满足。矛盾。

::fig[cs3264-shatter] 左边：三个点的 8 种 labeling，每种都有一条 line 把实心点和空心点分开。右边：四个点在 convex position，diagonal 标成同色时没有 line 能分开（XOR）。

### $\mathbb R^d$ 里是 $d+1$

:::skip
跳过它少掉的是一般 dimension 的结论：$\mathbb R^d$ 里 halfspace 的 VC dimension 是 $d+1$。后面只在第 3 站引用这个数。
:::

**能 shatter $d+1$ 个点。** 取 $0,e_1,\dots,e_d$。对任意 label $y_0,y_1,\dots,y_d\in\{\pm1\}$（用 $\pm1$ 表示 1 和 0），令 $w=\sum_{i\ge1}y_ie_i$，$b=y_0/2$。在 $0$ 处 $w^\top0+b=y_0/2$，sign 正是 $y_0$；在 $e_i$ 处是 $y_i+y_0/2$，因为 $|y_0/2|<1$，sign 是 $y_i$。

**不能 shatter $d+2$ 个点。** 对 $x_1,\dots,x_{d+2}\in\mathbb R^d$，unknown $\lambda_1,\dots,\lambda_{d+2}$ 的 system

$$\sum_i\lambda_ix_i=0,\qquad\sum_i\lambda_i=0$$

有 $d+1$ 个 equation、$d+2$ 个 unknown，所以有非零 solution。把 $\lambda_i>0$ 的下标记作 $P$，其余记作 $N$，$s=\sum_{i\in P}\lambda_i>0$。两个 equation 合起来说

$$z=\sum_{i\in P}\frac{\lambda_i}{s}x_i=\sum_{i\in N}\frac{-\lambda_i}{s}x_i$$

左边是 $P$ 中点的 convex combination，右边是 $N$ 中点的 convex combination（weight 非负、和为 1），这是同一个点 $z$。把 $P$ 标 1、$N$ 标 0：halfspace 包含 $P$ 就包含 $z$，不包含 $N$ 中任何点就不包含 $z$，矛盾。这叫 Radon's theorem。

:::wrong VC dimension 就是 parameter 的个数
$h_\omega(x)=\mathbf 1[\sin(\omega x)>0]$ 只有一个 parameter，VC dimension 是 infinite。取 $x_j=10^{-j}$，$j=1,\dots,m$。对任意 label $y\in\{0,1\}^m$，令

$$\omega=\pi\Big(1+\sum_{i=1}^m(1-y_i)\,10^i\Big)$$

看 $\omega x_j=\pi\big(10^{-j}+\sum_i(1-y_i)10^{i-j}\big)$ 里各项的贡献。$i>j$ 的项，$10^{i-j}$ 是 even integer，贡献 $2\pi$ 的整数倍，不影响 sine。$i=j$ 的项贡献 $\pi(1-y_j)$。其余部分 $10^{-j}+\sum_{i<j}(1-y_i)10^{i-j}$ 是正的，且不超过 $\sum_{k\ge1}10^{-k}=\tfrac19$。所以 $\omega x_j$ 除以 $2\pi$ 的余数落在 $(0,\tfrac\pi9]$（当 $y_j=1$）或 $(\pi,\tfrac{10\pi}9]$（当 $y_j=0$），sine 的 sign 正好给出 $y_j$。

代一组数：$m=5$，$y=(1,0,1,1,0)$，$\omega=\pi(1+10^2+10^5)=100101\pi$。在 $x_2=0.01$ 处，$\omega x_2=1001.01\pi$，减去 $1000\pi$ 剩 $1.01\pi$，在 $(\pi,2\pi)$ 里，sine 为负，label 0，正确。用 python 把 $m=3,4,5$ 的全部 $8+16+32$ 种 labeling 都验证过。于是对任何 $m$ 都有 $2m$ 个点被 shatter，上面 No-Free-Lunch 的论证原样适用：$h_\omega$ 这个 class 不是 PAC learnable。
:::

### Sauer's lemma

现在要问：VC dimension 有限时，$\tau_H(m)$ 长多快？Threshold 是 $m+1$，interval 是 $\tfrac{m(m+1)}2+1$，看起来都是 $m^d$ 量级。

**Sauer's lemma。** $\mathrm{VCdim}(H)=d$，则 $\tau_H(m)\le\sum_{i=0}^d\binom mi$。

先证一个更强的结论：对任意点集 $C$，

$$|H_C|\le\#\{B\subseteq C:\ H\text{ shatter }B\}$$

（空集算作被 shatter。）有了它，被 shatter 的 $B$ 大小都不超过 $d$，大小为 $i$ 的 subset 有 $\binom mi$ 个，加起来就是 lemma。

对 $|C|$ 做 induction。$|C|=1$ 时，$H_C$ 有 1 种或 2 种 labeling；有 2 种时空集和 $\{c_1\}$ 都被 shatter，右边是 2；有 1 种时右边至少是 1（空集）。

设对 $m-1$ 个点成立。把 $C$ 写成 $\{c_1\}\cup C'$。$H_C$ 里的 labeling 按“去掉第一个 coordinate 后剩下什么”分组，每组有 1 个或 2 个成员。令

$$\begin{aligned}Y_0&=\{y'\in\{0,1\}^{m-1}:\ (0,y')\in H_C\text{ 或 }(1,y')\in H_C\}\\Y_1&=\{y'\in\{0,1\}^{m-1}:\ (0,y')\in H_C\text{ 且 }(1,y')\in H_C\}\end{aligned}$$

每组成员个数是 1 时只在 $Y_0$ 里数一次，是 2 时在 $Y_0$、$Y_1$ 里各数一次，所以 $|H_C|=|Y_0|+|Y_1|$。

$Y_0$ 就是 $H_{C'}$，由 induction hypothesis，$|Y_0|\le\#\{B\subseteq C':H\text{ shatter }B\}$，也就是 $C$ 里不含 $c_1$ 的被 shatter 的 subset 的个数。

$Y_1$ 是 $H'_{C'}$，其中 $H'$ 由 $H$ 里这样的 $h$ 组成：$H$ 里另有一个 $h'$，在 $C'$ 上和 $h$ 一样，在 $c_1$ 上和 $h$ 相反。由 induction hypothesis，$|Y_1|\le\#\{B\subseteq C':H'\text{ shatter }B\}$。而 $H'$ shatter $B$ 时，$H$ 一定 shatter $B\cup\{c_1\}$：$B$ 上的每种 labeling 都有一个 $h\in H'$ 做到，它在 $c_1$ 上的相反版本也在 $H$ 里，所以 $c_1$ 取 0 和取 1 都能配上。于是 $|Y_1|$ 不超过 $C$ 里含 $c_1$ 的被 shatter 的 subset 的个数。两部分相加，就是要证的结论。

用前面两个 class 核对。Threshold，$d=1$：$\binom m0+\binom m1=m+1$，相等。Interval，$d=2$：$1+m+\tfrac{m(m-1)}2=\tfrac{m(m+1)}2+1$，也相等。Sauer's lemma 对这两个 class 是 tight 的。

为了代进 bound，再把 sum 化成好用的形式。$m\ge d$ 时 $(m/d)^{d-i}\ge1$，所以

$$\sum_{i=0}^d\binom mi\le\sum_{i=0}^d\binom mi\Big(\frac md\Big)^{d-i}=\Big(\frac md\Big)^d\sum_{i=0}^d\binom mi\Big(\frac dm\Big)^i\le\Big(\frac md\Big)^d\Big(1+\frac dm\Big)^m\le\Big(\frac{em}d\Big)^d$$

第二个 inequality 把 sum 补全成 binomial expansion，最后一步用 $1+t\le e^t$。

Plane 上的 halfspace，$d=3$，$m=100$：

| | 值 | ln |
|---|---|---|
| $\sum_{i\le3}\binom{100}i=1+100+4950+161700$ | 166,751 | 12.0 |
| $(e\cdot100/3)^3$ | 743,909 | 13.5 |
| $2^{100}$ | $1.27\times10^{30}$ | 69.3 |

上一站的 bound 里 $|H|$ 出现在 $\ln$ 里。如果能把 $\ln|H|$ 换成 $\ln\tau_H$，就是从 69.3 换成 12.0，而且只随 $d\ln m$ 增长。

:::edge Growth function 只有两种长法
Sauer's lemma 说明：要么 VC dimension infinite，$\tau_H(m)=2^m$ 对所有 $m$ 成立；要么 VC dimension 是某个 $d$，从 $m>d$ 开始 $\tau_H(m)\le(em/d)^d$ 是 polynomial。中间没有别的可能。
:::

## [rad] Rademacher complexity 与 generalization bound

:::skip
能讲清 ghost sample 和 random sign 是怎么把 $L_{\mathcal D}$ 换掉的，能推出 Massart's lemma 和 linear class 的 $BX/\sqrt m$，并把它们代成 VC bound 和 margin bound 算出数字，就可以去第 4 站。
:::

### 卡在哪里

上一站想把 union bound 里的 $|H|$ 换成“在 sample 上的 labeling 个数”。直接换不行：两个 hypothesis 在 $S$ 上给出同样的 labeling，它们的 $L_S$ 相同，$L_{\mathcal D}$ 却可以不同，因为 $L_{\mathcal D}$ 取决于整个 distribution。要想只在有限个点上数 labeling，得先把 $L_{\mathcal D}(h)$ 也换成某个有限 sample 上的量。

办法是想象另一组 independent 的 sample $S'=(z'_1,\dots,z'_m)$，叫 ghost sample。它只出现在推导里，不需要真的去抽。$L_{\mathcal D}(h)=\mathbb E_{S'}L_{S'}(h)$，于是整个问题只涉及 $2m$ 个点。

### Symmetrization

要控制的是最坏的 gap $\Phi(S)=\sup_{h\in H}\big(L_{\mathcal D}(h)-L_S(h)\big)$。先估计它的 expectation。sup 里面的 expectation 拿到外面，不会变小：

$$\mathbb E_S\Phi(S)=\mathbb E_S\sup_h\mathbb E_{S'}\big[L_{S'}(h)-L_S(h)\big]\le\mathbb E_{S,S'}\sup_h\frac1m\sum_i\big(\ell(h,z'_i)-\ell(h,z_i)\big)$$

$z_i$ 和 $z'_i$ independent 且 distribution 相同，把任意几对交换，$(S,S')$ 的 joint distribution 不变。交换第 $i$ 对，相当于第 $i$ 项乘上 $-1$。所以对任意固定的 sign vector $\sigma\in\{\pm1\}^m$，

$$\mathbb E_{S,S'}\sup_h\frac1m\sum_i\big(\ell(h,z'_i)-\ell(h,z_i)\big)=\mathbb E_{S,S'}\sup_h\frac1m\sum_i\sigma_i\big(\ell(h,z'_i)-\ell(h,z_i)\big)$$

既然对每个 $\sigma$ 都相等，对 $\sigma$ 取 uniform 的平均也相等。这样的 $\sigma_i$ 叫 Rademacher variable。再把 sup 拆成两个 sup 之和（一个 sup 不超过两部分各自的 sup 相加），$-\sigma$ 和 $\sigma$ 的 distribution 相同：

$$\mathbb E_S\Phi(S)\le\mathbb E\sup_h\frac1m\sum_i\sigma_i\ell(h,z'_i)+\mathbb E\sup_h\frac1m\sum_i(-\sigma_i)\ell(h,z_i)=2\,\mathbb E_S\,\mathcal R(\ell\circ H\circ S)$$

其中对一个由 vector 组成的 set $A\subseteq\mathbb R^m$，

$$\mathcal R(A)=\mathbb E_\sigma\sup_{a\in A}\frac1m\sum_{i=1}^m\sigma_ia_i$$

叫 Rademacher complexity，$\ell\circ H\circ S$ 是所有 $(\ell(h,z_1),\dots,\ell(h,z_m))$ 组成的 set。它的意思很直接：给 $m$ 个点随机贴上 $\pm1$ 的 noise，$H$ 最多能和这组 noise 有多大的 correlation。现在 sup 只涉及 $S$ 上的有限个 vector，第 2 站的 counting 就能派上用场。

对 0-1 loss 还有一步化简。$h$ 取值 $\{0,1\}$ 时，$\ell(h,z_i)=|h(x_i)-y_i|=y_i+(1-2y_i)h(x_i)$。于是 $\sum_i\sigma_i\ell(h,z_i)=\sum_i\sigma_iy_i+\sum_i\sigma_i(1-2y_i)h(x_i)$：第一项与 $h$ 无关，expectation 为 0；第二项里 $\sigma_i(1-2y_i)$ 和 $\sigma_i$ 的 distribution 相同。所以 $\mathcal R(\ell\circ H\circ S)=\mathcal R(H\circ S)$，label 不影响。

用一次。连续 threshold，$m$ 个不同的点排好序，$H\circ S$ 是 $m+1$ 个形如 $(0,\dots,0,1,\dots,1)$ 的 vector，$\sum_i\sigma_ia_i$ 是 $\sigma$ 的某个 suffix sum。$\mathcal R$ 就是“$\pm1$ random walk 倒着走，最大 suffix sum 的 expectation 除以 $m$”，和点在哪里无关。Monte Carlo 算出 $m=100$ 时是 0.0755，$m=1000$ 时是 0.0246。

### 从 expectation 到 high probability

上面只控制了 $\mathbb E\Phi$。$\Phi(S)$ 有一个好性质：把 $S$ 里任意一个 $z_i$ 换掉，每个 $L_S(h)$ 最多变 $\tfrac1m$（loss 在 $[0,1]$ 里），所以 sup 也最多变 $\tfrac1m$。这样的 function 集中在它的 expectation 附近，这是 McDiarmid's inequality：若改变第 $i$ 个 argument 最多让 $\Phi$ 变 $c_i$，则

$$\Pr\big(\Phi-\mathbb E\Phi\ge t\big)\le\exp\Big(-\frac{2t^2}{\sum_ic_i^2}\Big)$$

这里 $c_i=\tfrac1m$，右边是 $e^{-2mt^2}$。令它等于 $\delta$，$t=\sqrt{\ln(1/\delta)/(2m)}$。合起来：

> 以至少 $1-\delta$ 的 probability，对所有 $h\in H$ 同时有 $L_{\mathcal D}(h)\le L_S(h)+2\,\mathbb E_S\mathcal R(\ell\circ H\circ S)+\sqrt{\dfrac{\ln(1/\delta)}{2m}}$。

连续 threshold，$m=1000$，$\delta=0.05$：$2\times0.0246+\sqrt{\ln20/2000}=0.049+0.039=0.088$。这是一个 infinite class 的 uniform 保证，第 1 站的工具给不出来。

### McDiarmid 的 proof

:::skip
跳过它少掉的是“为什么 bounded difference 就够了”。只要记住结论和 $c_i=1/m$ 就能往下读。
:::

把 $\Phi-\mathbb E\Phi$ 拆成 $m$ 步，每步揭开一个 sample：

$$V_k=\mathbb E[\Phi\mid z_1,\dots,z_k]-\mathbb E[\Phi\mid z_1,\dots,z_{k-1}],\qquad\Phi-\mathbb E\Phi=\sum_{k=1}^mV_k$$

固定 $z_1,\dots,z_{k-1}$。记 $g(z)=\mathbb E[\Phi\mid z_1,\dots,z_{k-1},z_k=z]$，则 $V_k=g(z_k)-\mathbb E\,g(z_k)$，conditional mean 为 0。对任意两个值 $z,\tilde z$，$g(z)-g(\tilde z)$ 是“只有第 $k$ 个 argument 不同”的两个 $\Phi$ 之差的平均，不超过 $c_k$，所以 $V_k$ 落在一个长度不超过 $c_k$ 的 interval 里。Hoeffding's lemma 给出

$$\mathbb E\big[e^{\lambda V_k}\mid z_1,\dots,z_{k-1}\big]\le e^{\lambda^2c_k^2/8}$$

从 $k=m$ 开始一层层取 conditional expectation，$\mathbb E\,e^{\lambda(\Phi-\mathbb E\Phi)}\le e^{\lambda^2\sum c_k^2/8}$。之后和第 1 站推 Hoeffding inequality 完全一样：Markov，再选最好的 $\lambda$，得到 $\exp(-2t^2/\sum c_k^2)$。

### Massart's lemma：把 VC dimension 接上

$\mathcal R(A)$ 是有限个 vector 的 sup 的 expectation，可以用和 Hoeffding 同样的 exponential 技巧来估计。

**Massart's lemma。** $A\subseteq\mathbb R^m$ 有 $N$ 个 vector，$r=\max_{a\in A}\lVert a\rVert$，则 $\mathcal R(A)\le\dfrac{r\sqrt{2\ln N}}{m}$。

对任意 $\lambda>0$，先用 Jensen（$e^{x}$ convex）再把 sup 换成 sum：

$$e^{\lambda\,\mathbb E\sup_a\sum_i\sigma_ia_i}\le\mathbb E\,e^{\lambda\sup_a\sum_i\sigma_ia_i}\le\sum_{a\in A}\mathbb E\,e^{\lambda\sum_i\sigma_ia_i}=\sum_{a\in A}\prod_i\cosh(\lambda a_i)$$

最后一步用了 $\sigma_i$ independent 且 $\mathbb E\,e^{\lambda\sigma_ia_i}=\tfrac12(e^{\lambda a_i}+e^{-\lambda a_i})$。比较 Taylor series 的每一项，$\cosh x=\sum_k\frac{x^{2k}}{(2k)!}\le\sum_k\frac{x^{2k}}{2^kk!}=e^{x^2/2}$（因为 $(2k)!\ge2^kk!$）。所以右边不超过 $\sum_ae^{\lambda^2\lVert a\rVert^2/2}\le Ne^{\lambda^2r^2/2}$。两边取 log、除以 $\lambda$：

$$\mathbb E\sup_a\sum_i\sigma_ia_i\le\frac{\ln N}{\lambda}+\frac{\lambda r^2}{2}$$

取 $\lambda=\sqrt{2\ln N}/r$，两项都等于 $r\sqrt{\ln N/2}$，加起来是 $r\sqrt{2\ln N}$，再除以 $m$。

0-1 loss 的 vector 在 $\{0,1\}^m$ 里，$r\le\sqrt m$；不同的 vector 至多 $|H_S|\le\tau_H(m)\le(em/d)^d$ 个。代进去：

$$\mathcal R(\ell\circ H\circ S)\le\sqrt{\frac{2d\ln(em/d)}m}$$

于是有 VC bound：以至少 $1-\delta$ 的 probability，对所有 $h$，

$$L_{\mathcal D}(h)\le L_S(h)+2\sqrt{\frac{2d\ln(em/d)}m}+\sqrt{\frac{\ln(1/\delta)}{2m}}$$

Plane 上的 halfspace，$d=3$，$m=10000$，$\delta=0.05$：$\ln(e\cdot10000/3)=9.11$，第二项是 $2\sqrt{6\times9.11/10000}=0.148$，第三项是 0.012，gap 的 upper bound 是 0.160。要压到 0.05 以下，需要 $m\ge129{,}007$。

::fig[cs3264-rad] 连续 threshold 的 Rademacher complexity：Monte Carlo 实算值与 Massart 给出的 upper bound $\sqrt{2\ln(m+1)/m}$。两者都按 $1/\sqrt m$ 下降，Massart 多出一个 $\sqrt{\ln m}$ factor，在 $m=1000$ 时松了约 5 倍。

### Norm 代替 dimension：linear class 与 margin

$\mathbb R^d$ 里 halfspace 的 VC dimension 是 $d+1$。Bag-of-words 的 text classification 很容易有 $d=10^6$ 个 feature，手里只有 $m=10^4$ 个 example，VC bound 里的 $d/m$ 是 100，bound 没有意义。可 SVM 在这种问题上照样好用。第 2 站的 counting 看不到的是 weight 的大小。

先看 real-valued 的 linear function $\{x\mapsto\langle w,x\rangle:\lVert w\rVert\le B\}$，设所有 $\lVert x_i\rVert\le X$。sup 可以直接算出来：$\sup_{\lVert w\rVert\le B}\langle w,v\rangle=B\lVert v\rVert$（Cauchy–Schwarz，$w$ 沿 $v$ 方向时取到）。所以

$$\mathcal R=\frac1m\mathbb E_\sigma\sup_{\lVert w\rVert\le B}\Big\langle w,\sum_i\sigma_ix_i\Big\rangle=\frac Bm\,\mathbb E\Big\lVert\sum_i\sigma_ix_i\Big\rVert\le\frac Bm\sqrt{\mathbb E\Big\lVert\sum_i\sigma_ix_i\Big\rVert^2}=\frac Bm\sqrt{\sum_i\lVert x_i\rVert^2}\le\frac{BX}{\sqrt m}$$

inequality 是 Jensen（square root 是 concave 的）；展开 $\lVert\sum_i\sigma_ix_i\rVert^2$ 时 cross term $\sigma_i\sigma_j\langle x_i,x_j\rangle$ 的 expectation 为 0，只剩 $\sum_i\lVert x_i\rVert^2$。结果里没有 $d$。

剩下的麻烦是 0-1 loss 不是 $\langle w,x\rangle$ 的 Lipschitz function。换一个夹在中间的 loss。对 $\gamma>0$ 定义 ramp loss

$$\varphi_\gamma(t)=\begin{cases}1&t\le0\\1-t/\gamma&0<t<\gamma\\0&t\ge\gamma\end{cases}$$

作用在 $t=y\langle w,x\rangle$ 上（这里 $y\in\{\pm1\}$）。它处处不小于 0-1 loss，并且是 $\tfrac1\gamma$-Lipschitz。Lipschitz function 不会增加 Rademacher complexity，只乘上 Lipschitz constant（contraction lemma，proof 在下一小节）。label $y_i$ 乘在里面也不影响，因为 $\sigma_iy_i$ 和 $\sigma_i$ 的 distribution 相同。所以对 $\lVert w\rVert\le1$：

$$L^{01}_{\mathcal D}(w)\le L^{\varphi_\gamma}_{\mathcal D}(w)\le L^{\varphi_\gamma}_S(w)+\frac2\gamma\cdot\frac X{\sqrt m}+\sqrt{\frac{\ln(1/\delta)}{2m}}$$

而 $L^{\varphi_\gamma}_S(w)$ 不超过 training set 里 $y_i\langle w,x_i\rangle<\gamma$ 的点的比例。这叫 margin bound。如果 data 能以 geometric margin $\gamma$ 分开，第一项是 0。

代数字：$X=1$，$\gamma=0.1$，$m=10^4$，$\delta=0.05$，$d=10^6$。Margin bound 的 gap 是 $\frac{2}{0.1\times100}+0.012=0.212$，和 $d$ 无关；VC bound 在 $m<d$ 时根本没有意义。$m=10^6$ 时 margin bound 降到 0.021。决定难度的是 $(X/\gamma)^2$，这个量在第 5 站的 Perceptron 里会再出现一次。

::fig[cs3264-ramp] 三种 loss 作为 margin $t=y\langle w,x\rangle$ 的 function。Ramp loss 夹在 0-1 loss 和 hinge loss 之间：它比 0-1 loss 大，所以能 bound 住 true error；它是 Lipschitz 的，所以 Rademacher complexity 能控制住。

### Contraction lemma 的 proof

:::skip
跳过它少掉的是“为什么 Lipschitz 的 loss 只乘一个 factor”。
:::

设每个 $\varphi_i$ 是 $\rho$-Lipschitz，要证 $\mathcal R(\{(\varphi_1(a_1),\dots,\varphi_m(a_m)):a\in A\})\le\rho\,\mathcal R(A)$。一次只换一个 coordinate。固定 $\sigma_2,\dots,\sigma_m$，把其余的项记作 $u(a)=\sum_{i\ge2}\sigma_i\varphi_i(a_i)$。对 $\sigma_1$ 取 expectation：

$$\begin{aligned}\mathbb E_{\sigma_1}\sup_a\big[\sigma_1\varphi_1(a_1)+u(a)\big]&=\frac12\sup_{a,a'}\big[\varphi_1(a_1)-\varphi_1(a'_1)+u(a)+u(a')\big]\\&\le\frac12\sup_{a,a'}\big[\rho|a_1-a'_1|+u(a)+u(a')\big]\end{aligned}$$

等号把 $\sigma_1=+1$ 和 $-1$ 两个 sup 写成一个对 $(a,a')$ 的 sup。右边交换 $a$ 和 $a'$ 不变，所以 absolute value 可以去掉，写成 $\rho(a_1-a'_1)$；这又正是 $\mathbb E_{\sigma_1}\sup_a[\sigma_1\rho a_1+u(a)]$。第一个 coordinate 换完，对其余 coordinate 重复同样的论证。

:::edge $\gamma$ 不能看了 data 再选
上面的 bound 对事先固定的 $\gamma$ 成立。实际中 $\gamma$ 是 training 之后量出来的。补救是对一列 $\gamma_k=2^{-k}$ 各分一份 failure probability $\delta_k=\delta\,2^{-k}$，$\sum_k\delta_k\le\delta$，union bound 后对所有 $k$ 同时成立，量出来的 $\gamma$ 落在两个格点之间时用较小的那个格点，$2/\gamma$ 那一项最多放大一倍；另一个代价是第三项里 $\ln(1/\delta)$ 变成 $\ln(1/\delta)+k\ln2$。$\gamma=\tfrac18$（$k=3$）、$m=10^4$ 时第三项从 0.0122 变成 0.0159，几乎不变。
:::

:::from
“finite class 的 bound 看不到 norm”这个动机、symmetrization 的顺序（ghost sample、交换、插入 random sign）、用 McDiarmid 转成 high probability、margin 与 ramp loss、Talagrand 的 contraction、linear class 的 $\ell_2$ bound 的四步 proof、VC bound 不能处理 kernel，来自 [STATS214 讲义](https://tselilschramm.org/mltheory/ma.pdf)第 4.4 到 4.7 节和 5.1、5.2 节。Rademacher complexity 写成 vector 的 set 的形式、Massart's lemma 的 Jensen 加 $\lambda$ 的 proof、Theorem 26.12 那种“$2\rho BR/\sqrt m$”的 margin 形式，来自 [Understanding Machine Learning](https://cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf) 第 26 章。McDiarmid 的 martingale proof 和 contraction lemma 的 proof 是凭标准教材的知识写的，两份材料里这两段都没有读到完整原文。这里给的 bound 用 $\ln(1/\delta)$ 而不是书里的 $\ln(2/\delta)$，因为只需要 one-sided。Monte Carlo、$d=3$ 与 $d=10^6$ 的对比、$129{,}007$ 是为这一页算的。
:::

## [opt] Convex optimization：GD 与 SGD 的 rate

:::skip
能从 $L$-smooth 推出 descent lemma，再推出 convex 的 $1/k$ 和 strongly convex 的 $(1-\mu/L)^k$；能推出 subgradient method 与 SGD 的 $B\rho/\sqrt T$，并说出 SGD 为什么能直接最小化 $L_{\mathcal D}$，就可以去第 5 站。
:::

### 为什么要关心 rate

前三站假设 ERM 的 solution 能拿到手。Logistic loss、hinge loss 没有 closed form，只能 iterate。要回答两件事：走多少步能到 $\varepsilon$ 以内；以及 $\varepsilon$ 要多小才够。后一个问题第 3 站已经给了答案的量级：statistical error 是 $1/\sqrt m$，optimization error 比它小很多没有意义。

这一站用 $m$ 以外的字母：$\mu$ 是 strong convexity 的 constant，$L$ 是 smoothness 的 constant，$k$ 或 $T$ 是步数。

### Smoothness 给出一个 quadratic upper bound

$f$ 叫 $L$-smooth，如果 $\lVert\nabla f(x)-\nabla f(y)\rVert\le L\lVert x-y\rVert$。沿着 $x$ 到 $y$ 的 segment 做 integration：

$$\begin{aligned}f(y)&=f(x)+\int_0^1\nabla f\big(x+s(y-x)\big)^\top(y-x)\,ds\\&=f(x)+\nabla f(x)^\top(y-x)+\int_0^1\big(\nabla f(x+s(y-x))-\nabla f(x)\big)^\top(y-x)\,ds\end{aligned}$$

最后一个 integral 里，integrand 不超过 $Ls\lVert y-x\rVert\cdot\lVert y-x\rVert$，积出来是 $\tfrac L2\lVert y-x\rVert^2$。所以

$$f(y)\le f(x)+\nabla f(x)^\top(y-x)+\frac L2\lVert y-x\rVert^2$$

代入一步 gradient descent $y=x^+=x-t\nabla f(x)$：

$$f(x^+)\le f(x)-t\Big(1-\frac{Lt}2\Big)\lVert\nabla f(x)\rVert^2\le f(x)-\frac t2\lVert\nabla f(x)\rVert^2\qquad(t\le1/L)$$

这叫 descent lemma：step size 不超过 $1/L$ 时，每一步都让 $f$ 至少下降 $\tfrac t2\lVert\nabla f\rVert^2$。

这一站的例子是 $f(x)=\tfrac12(10x_1^2+x_2^2)$，minimum 在原点，$f^\star=0$。Hessian 是 $\mathrm{diag}(10,1)$，$L=10$。从 $x_0=(1,1)$ 出发，$f(x_0)=5.5$，$\nabla f(x_0)=(10,1)$。取 $t=0.1$：$x_1=(1,1)-0.1\times(10,1)=(0,\,0.9)$，$f(x_1)=0.405$。Descent lemma 预言 $f(x_1)\le5.5-0.05\times101=0.45$，对得上。

### Convex：$1/k$

再加上 convexity：$f(x^\star)\ge f(x)+\nabla f(x)^\top(x^\star-x)$，即 $f(x)\le f^\star+\nabla f(x)^\top(x-x^\star)$。代进 descent lemma：

$$f(x^+)\le f^\star+\nabla f(x)^\top(x-x^\star)-\frac t2\lVert\nabla f(x)\rVert^2$$

右边后两项可以凑成两个 square 之差。展开 $\lVert x^+-x^\star\rVert^2=\lVert x-x^\star-t\nabla f(x)\rVert^2=\lVert x-x^\star\rVert^2-2t\nabla f(x)^\top(x-x^\star)+t^2\lVert\nabla f(x)\rVert^2$，移项除以 $2t$，正好是那两项：

$$f(x^+)-f^\star\le\frac1{2t}\Big(\lVert x-x^\star\rVert^2-\lVert x^+-x^\star\rVert^2\Big)$$

对 $i=1,\dots,k$ 相加，右边 telescope，剩下不超过 $\tfrac1{2t}\lVert x_0-x^\star\rVert^2$。左边是 $k$ 个 $f(x_i)-f^\star$ 之和，descent lemma 说 $f(x_i)$ monotone 地下降，所以每一项都不小于最后一项：

$$f(x_k)-f^\star\le\frac{\lVert x_0-x^\star\rVert^2}{2tk}$$

例子里 $\lVert x_0\rVert^2=2$，$t=0.1$，bound 是 $10/k$。实际值：$k=10$ 时 0.061，bound 是 1.0；$k=50$ 时 $1.3\times10^{-5}$，bound 是 0.2。差这么多，是因为这个 $f$ 比“convex”好得多。

### Strongly convex：linear rate

$f$ 叫 $\mu$-strongly convex，如果 $f(y)\ge f(x)+\nabla f(x)^\top(y-x)+\tfrac\mu2\lVert y-x\rVert^2$。右边是 $y$ 的 quadratic function，在 $y=x-\nabla f(x)/\mu$ 取 minimum，值是 $f(x)-\tfrac1{2\mu}\lVert\nabla f(x)\rVert^2$。左边对 $y$ 取 minimum 是 $f^\star$，所以

$$\lVert\nabla f(x)\rVert^2\ge2\mu\big(f(x)-f^\star\big)$$

离 minimum 越远，gradient 一定越大。代进 descent lemma（$t=1/L$）：

$$f(x^+)-f^\star\le f(x)-f^\star-\frac1{2L}\lVert\nabla f(x)\rVert^2\le\Big(1-\frac\mu L\Big)\big(f(x)-f^\star\big)$$

每步乘一个固定的 factor，叫 linear rate。例子里 $\mu=1$，factor 是 0.9，bound 是 $5.5\times0.9^k$：$k=10$ 时 1.92，$k=50$ 时 0.028。

对 quadratic function 可以看得更清楚。Hessian 的每个 eigenvector 方向互不干扰：$x_1$ 每步乘 $1-10t$，$x_2$ 每步乘 $1-t$。要 converge 需要每个 $|1-t\lambda_i|<1$，即 $t<2/L=0.2$。

| $t$ | $x_1$ 的 factor | $x_2$ 的 factor | 前四步的 $x_1$ |
|---|---|---|---|
| 0.1 | 0 | 0.9 | 1, 0, 0, 0 |
| $2/11\approx0.182$ | $-9/11$ | $9/11$ | 1, −0.818, 0.669, −0.548 |
| 0.2 | −1 | 0.8 | 1, −1, 1, −1 |
| 0.21 | −1.1 | 0.79 | 1, −1.1, 1.21, −1.331 |

最好的 fixed step size 让两个方向的 factor 一样大：$1-t\mu=-(1-tL)$，$t=\tfrac2{L+\mu}=\tfrac2{11}$，factor 是 $\tfrac{\kappa-1}{\kappa+1}=\tfrac9{11}$，其中 $\kappa=L/\mu=10$ 是 condition number。要把 $x_2$ 缩小 $10^6$ 倍，$t=0.1$ 时每步乘 0.9，要 132 步；$t=\tfrac2{11}$ 时两个 component 每步都乘 $\tfrac9{11}$ 的 absolute value，要 69 步。

::fig[cs3264-gd] 动图：两边同时一步一步走，虚线是整条路线，实线是已经走过的部分，框下面是当前的 $k$ 和 $x_k$。左边 $t=2/11$：彩色的点每步越过谷底再弹回来，弹的幅度每次缩成 $9/11$，zigzag 地走向 minimum。右边 $t=0.21$：$x_1$ 方向的 factor 是 −1.1，每次弹得更远，第 7 步跑出框外。

:::wrong Step size 越大走得越快
从 0.1 加到 $\tfrac2{11}$ 确实更快，但只快到 $2/L$ 为止。$t=0.2$ 时 $x_1$ 在 1 和 −1 之间来回，永远不 converge；$t=0.21$ 时它按 $1.1^k$ 增长。Step size 的 upper bound 由最陡的方向 $L$ 决定，而速度由最平的方向 $\mu$ 决定，两者之比 $\kappa$ 越大，gradient descent 越慢。
:::

### Non-smooth 与 stochastic：$1/\sqrt T$

Hinge loss 在折点处没有 gradient。改用 subgradient：$v$ 是 $f$ 在 $w$ 处的 subgradient，如果 $f(u)\ge f(w)+v^\top(u-w)$ 对所有 $u$ 成立。Convex function 处处有 subgradient。

先证一个只关于 update 的恒等式，它不用任何关于 $f$ 的假设。设 $w_1=0$，$w_{t+1}=w_t-\eta v_t$，$w^\star$ 任意。展开 $\lVert w_{t+1}-w^\star\rVert^2=\lVert w_t-w^\star\rVert^2-2\eta\langle w_t-w^\star,v_t\rangle+\eta^2\lVert v_t\rVert^2$，移项：

$$\langle w_t-w^\star,v_t\rangle=\frac1{2\eta}\Big(\lVert w_t-w^\star\rVert^2-\lVert w_{t+1}-w^\star\rVert^2\Big)+\frac\eta2\lVert v_t\rVert^2$$

对 $t=1,\dots,T$ 相加，telescope 后不超过 $\dfrac{\lVert w^\star\rVert^2}{2\eta}+\dfrac\eta2\sum_t\lVert v_t\rVert^2$。

现在设 $f$ convex、$\rho$-Lipschitz（所以 $\lVert v_t\rVert\le\rho$），$\lVert w^\star\rVert\le B$。由 subgradient 的定义，$f(w_t)-f(w^\star)\le\langle w_t-w^\star,v_t\rangle$。取平均点 $\bar w=\tfrac1T\sum_tw_t$，Jensen 给出 $f(\bar w)\le\tfrac1T\sum_tf(w_t)$。合起来：

$$f(\bar w)-f(w^\star)\le\frac{B^2}{2\eta T}+\frac{\eta\rho^2}2$$

取 $\eta=\dfrac B{\rho\sqrt T}$，两项相等，得到 $\dfrac{B\rho}{\sqrt T}$。

这个 proof 只在一处用到 $v_t$：$f(w_t)-f(w^\star)\le\langle w_t-w^\star,v_t\rangle$。如果 $v_t$ 是 random 的，只要它的 conditional expectation 是 subgradient，$\mathbb E[v_t\mid w_t]\in\partial f(w_t)$，取 expectation 后这一步照样成立，于是 SGD 有同样的 bound：$\mathbb E f(\bar w)-f(w^\star)\le B\rho/\sqrt T$。

关键的应用是取 $f=L_{\mathcal D}$。每一步抽一个新的 example $z_t$，用 $\ell(w,z_t)$ 的 subgradient 当 $v_t$，它的 expectation 正是 $L_{\mathcal D}$ 的 subgradient。于是把 $m$ 个 example 各用一次，

$$\mathbb E\,L_{\mathcal D}(\bar w)-L_{\mathcal D}(w^\star)\le\frac{B\rho}{\sqrt m}$$

这直接控制 true risk，没有经过 uniform convergence。Hinge loss、$\lVert x\rVert\le1$ 时 $\rho=1$；要和 $\lVert w^\star\rVert\le10$ 的最好 hypothesis 差 0.05 以内，需要 $(10/0.05)^2=40{,}000$ 个 example，和第 3 站 margin bound 的量级一致。

实际算一个例子看 bound 有多松：$f(w)=\mathbb E|w-z|$，$z\sim N(3,1)$，minimum 在 median $w^\star=3$。$B=3$，$\rho=1$，$\eta=3/\sqrt T$，从 $w_1=0$ 出发，每个 $T$ 重复几百到两千次取平均：

| $T$ | 实际的 $\mathbb E f(\bar w)-f^\star$ | bound $3/\sqrt T$ |
|---|---|---|
| 10 | 0.226 | 0.949 |
| 100 | 0.0214 | 0.300 |
| 1000 | 0.00197 | 0.0949 |
| 10000 | 0.000203 | 0.0300 |

实际值按 $1/T$ 下降，比 bound 快。这个 $f$ 在 $w^\star$ 附近是 smooth 的，而且 $f''(w^\star)=2\times\tfrac1{\sqrt{2\pi}}=0.80>0$，局部 strongly convex。$B\rho/\sqrt T$ 是对所有 convex Lipschitz function 的保证，碰上好的 $f$ 会快得多。

:::wrong Training loss 要优化到 machine precision 才算训练好
Excess risk 拆成三部分：$H$ 里最好的 hypothesis 本身的 error、statistical error（第 3 站的 gap）、optimization error。$m=10^4$、$B=10$、$X=1$ 时，第 3 站给出的 gap 的主项是 $2BX/\sqrt m=0.2$。把 optimization error 从 $10^{-2}$ 压到 $10^{-8}$，总的 bound 变化不到 0.01，却要多花几个量级的计算。合理的停止点是 optimization error 和 statistical error 同量级。
:::

:::from
Descent lemma、convex 情形“先 descent、再 convexity、completing the square、telescope”的 $1/k$ proof、strongly convex 的 linear rate 与 condition number、$(10x_1^2+x_2^2)/2$ 这个例子以及“step size 太大会 diverge”，来自 [CMU 10-725 Gradient descent scribed notes](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/scribes/grad-descent-scribed.pdf)；那份讲义对 strongly convex 只给了结论，这里用 gradient 的下界（PL inequality）补上了 proof，表里四个 step size 的数是这里算的。“只关于 update 的恒等式”（Lemma 14.1）、averaged iterate 的 $B\rho/\sqrt T$、SGD 只需要 conditional expectation 是 subgradient、SGD 直接最小化 $L_{\mathcal D}$，来自 [Understanding Machine Learning](https://cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf) 第 14 章。$\mathbb E|w-z|$ 的模拟是为这一页算的。
:::

## [online] Online learning：mistake bound 与 regret

:::skip
能推出 Halving 的 $\log_2|H|$、Perceptron 的 $(R/\gamma)^2$、Hedge 的 $\sqrt{T\ln N/2}$，能说出 deterministic learner 为什么在 non-realizable 时一定失败，以及 regret 怎么变回第 1 站的 excess risk，就可以去第 6 站。
:::

### 去掉 distribution

前四站都假设 data 是从一个固定的 distribution i.i.d. 抽出来的。spam filter、股票、推荐系统里，对方会根据你的行为改变策略，这个假设站不住。Online learning 把它整个去掉：第 $t$ 轮收到 $x_t$，给出 prediction，然后看到真正的 $y_t$，记一次 loss；$x_t$、$y_t$ 可以由一个 adversary 任意选。

先看 realizable 的情形：$H$ 有限，有一个 $h^\star\in H$ 从不出错。**Halving algorithm** 维护 version space $V_t$（到目前为止一个错都没犯的 hypothesis），用其中的 majority vote 做 prediction。每犯一次错，说明多数派错了，至少一半被淘汰：$|V_{t+1}|\le|V_t|/2$。犯了 $M$ 次错之后 $1\le|V|\le|H|\,2^{-M}$，所以

$$M\le\log_2|H|$$

$|H|=1000$ 时 $\log_2 1000=9.97$，最多犯 9 次错，不管 sequence 有多长，也不需要任何 distribution。

连续 threshold 就不一样了。Adversary 维护一个 interval $(lo,hi]$，里面的每个 $a$ 都和到目前为止的 label 一致。每一轮问中点 $x=(lo+hi)/2$，等 learner 回答之后给出相反的 label。$a\le x$ 和 $a>x$ 两种情况在 interval 里都还有，所以这个 label 总能被某个 threshold 解释；interval 减半，游戏永远继续。Learner 每一轮都错。第 2 站说 74 个 example 就能 PAC learn 它，在 online 的设定下却一次都学不会：adversary 可以把所有 example 都放在最难的位置。

### Perceptron 的 mistake bound

Linear classifier 也是 infinite class。如果 data 有 margin，可以 bound 住 mistake 的个数。

设 $\lVert x_t\rVert\le R$，存在 unit vector $w^\star$ 使所有 $y_t\langle w^\star,x_t\rangle\ge\gamma>0$。Perceptron 从 $w=0$ 出发，在犯错（$y_t\langle w,x_t\rangle\le0$）时更新 $w\leftarrow w+y_tx_t$，否则不动。设第 $k$ 次更新后是 $w_k$。

**第一步：和 $w^\star$ 的 inner product 每次至少涨 $\gamma$。** $\langle w^\star,w_k\rangle=\langle w^\star,w_{k-1}\rangle+y_t\langle w^\star,x_t\rangle\ge\langle w^\star,w_{k-1}\rangle+\gamma$，所以 $\langle w^\star,w_k\rangle\ge k\gamma$。

**第二步：length 的 square 每次最多涨 $R^2$。** $\lVert w_k\rVert^2=\lVert w_{k-1}\rVert^2+2y_t\langle w_{k-1},x_t\rangle+\lVert x_t\rVert^2$，中间项因为犯了错而 $\le0$，所以 $\lVert w_k\rVert^2\le kR^2$。

**第三步：两者之比是 cosine，不超过 1。**

$$1\ge\frac{\langle w^\star,w_k\rangle}{\lVert w^\star\rVert\,\lVert w_k\rVert}\ge\frac{k\gamma}{\sqrt k\,R}\qquad\Longrightarrow\qquad k\le\Big(\frac R\gamma\Big)^2$$

Inner product 线性增长，length 只按 $\sqrt k$ 增长，两者的 angle 必然越来越小，而 cosine 又不能超过 1，所以更新的次数有 upper bound。

走一遍。四个点 $x_1=(1,2)$、$x_2=(3,1)$ 标 $+1$，$x_3=(-1,-2)$、$x_4=(2,-1)$ 标 $-1$。取 $w^\star=(0,1)$，四个点的 $y\langle w^\star,x\rangle$ 是 2、1、2、1，$\gamma=1$；$R=\lVert x_2\rVert=\sqrt{10}$；bound 是 10。按顺序反复扫：

| 更新次数 $k$ | 在哪个点犯错 | 那时的 $y\langle w,x\rangle$ | 新的 $w_k$ | $\langle w^\star,w_k\rangle\ge k\gamma$ | $\lVert w_k\rVert^2\le kR^2$ |
|---|---|---|---|---|---|
| 1 | $x_1$（第 1 遍） | 0 | $(1,2)$ | $2\ge1$ | $5\le10$ |
| 2 | $x_4$（第 1 遍） | 0 | $(-1,3)$ | $3\ge2$ | $10\le20$ |
| 3 | $x_2$（第 2 遍） | 0 | $(2,4)$ | $4\ge3$ | $20\le30$ |
| 4 | $x_4$（第 2 遍） | 0 | $(0,5)$ | $5\ge4$ | $25\le40$ |

第 3 遍四个点都对，停止。4 次 mistake，在 bound 10 以内。

::fig[cs3264-perc] 动图：按上表一次一次更新。每一帧圈出犯错的点，虚线箭头是加上的 $y_tx_t$，灰箭头是更新前的 $w$；浅色半平面是 $\langle w,x\rangle>0$ 的一侧，跟着 $w$ 转。看 $w_k$ 一步步转向 $w^\star=(0,1)$，右边的表随之多一行，第 3 遍时四个点都落在正确的一侧。

$(R/\gamma)^2$ 和第 3 站 margin bound 里的 $(X/\gamma)^2$ 是同一个量：data 的 radius 和 margin 之比决定难度，dimension 不出现。

### Non-realizable：deterministic learner 必然失败

没有完美的 hypothesis 时，mistake 的个数没法 bound，改为和事后看来最好的那个比，差值叫 regret：

$$\text{Regret}_T=\sum_{t=1}^T\ell_t(\text{learner})-\min_{h\in H}\sum_{t=1}^T\ell_t(h)$$

即使只有两个 hypothesis，“永远答 0”和“永远答 1”，deterministic 的 learner 也逃不掉。Adversary 知道 learner 的 rule，每一轮先算出 learner 会答什么，再给出相反的 label。Learner 每轮都错，共 $T$ 次；而两个 constant hypothesis 一共犯 $T$ 次错，较好的那个不超过 $T/2$。Regret 至少 $T/2$，平均每轮不趋于 0。

不需要 adversary 那么聪明也会出事。两个 expert 的 loss 交替出现：第 1、3、5……天 expert 1 的 loss 是 1，第 2、4、6……天 expert 2 的 loss 是 1。Follow-the-leader（每天跟到目前为止 loss 最小的那个，平局选 expert 1）每天都恰好跟错，$T=1000$ 天 loss 是 1000，最好的 expert 是 500，regret 是 500。

出路是 randomize：维护一个 distribution $p_t$，按它随机选 expert，loss 记作 expectation $\langle p_t,\ell_t\rangle$。Adversary 能知道 $p_t$，但不知道这一轮硬币的结果。

### Hedge

$N$ 个 expert，loss 在 $[0,1]$ 里，$L_{t}(i)$ 是 expert $i$ 前 $t$ 轮的累计 loss。**Hedge** 取

$$p_t(i)\propto e^{-\eta L_{t-1}(i)}$$

累计 loss 越大，weight 按 exponential 衰减。

Regret bound 用一个 potential $W_t=\sum_ie^{-\eta L_t(i)}$，$W_0=N$。相邻两轮之比：

$$\frac{W_t}{W_{t-1}}=\sum_i\frac{e^{-\eta L_{t-1}(i)}}{W_{t-1}}e^{-\eta\ell_t(i)}=\mathbb E_{i\sim p_t}\big[e^{-\eta\ell_t(i)}\big]$$

把 $\ell_t(i)$ 看成 $i\sim p_t$ 时的 random variable，它在 $[0,1]$ 里，mean 是 $\langle p_t,\ell_t\rangle$。第 1 站的 Hoeffding's lemma 用在 $\ell_t(i)-\langle p_t,\ell_t\rangle$ 上：

$$\mathbb E_{i\sim p_t}\big[e^{-\eta\ell_t(i)}\big]=e^{-\eta\langle p_t,\ell_t\rangle}\,\mathbb E\big[e^{-\eta(\ell_t(i)-\langle p_t,\ell_t\rangle)}\big]\le e^{-\eta\langle p_t,\ell_t\rangle+\eta^2/8}$$

取 log、对 $t$ 相加：$\ln W_T-\ln N\le-\eta\sum_t\langle p_t,\ell_t\rangle+T\eta^2/8$。另一方面 $W_T$ 不小于其中任何一项，$\ln W_T\ge-\eta\min_iL_T(i)$。两式合起来除以 $\eta$：

$$\sum_t\langle p_t,\ell_t\rangle-\min_iL_T(i)\le\frac{\ln N}\eta+\frac{\eta T}8$$

取 $\eta=\sqrt{8\ln N/T}$，两项相等：

$$\text{Regret}_T\le\sqrt{\frac{T\ln N}2}$$

Regret 随 $T$ 按 $\sqrt T$ 增长，平均每轮的 regret 趋于 0。对交替的例子，$N=2$，$T=1000$：$\eta=0.0745$，bound 是 18.6；实际算出的 regret 是 9.30，而 follow-the-leader 是 500。

::fig[cs3264-regret] 交替 loss 的 sequence 上，两个 learner 的累计 regret（每两天取一个点）。Follow-the-leader 每两天比最好的 expert 多亏 1；Hedge 每两天只多亏约 $\eta/4=0.019$。

:::wrong Regret 小，learner 的表现就好
Regret 是和最好的 expert 比。交替的例子里 Hedge 的 regret 只有 9.3，可它的总 loss 是 509.3，一半的时候是错的，因为最好的 expert 本身就错一半。Regret bound 说的是“不比事后最好的那个差多少”，好不好要看 expert 本身。
:::

### Online-to-batch：回到 i.i.d.

如果 data 其实是 i.i.d. 的，一个 regret 小的 online algorithm 自动给出一个 excess risk 小的 batch learner。设第 $t$ 轮用的 hypothesis $h_t$ 只依赖于 $z_1,\dots,z_{t-1}$。$z_t$ 是新抽的，和 $h_t$ independent，所以

$$\mathbb E\big[\ell(h_t,z_t)\big]=\mathbb E\big[L_{\mathcal D}(h_t)\big]$$

对 $t$ 相加，再用 regret 的定义，把“事后最好”换成一个事先固定的 $h^\star$（它不会比事后最好的更好）：

$$\mathbb E\sum_tL_{\mathcal D}(h_t)=\mathbb E\sum_t\ell(h_t,z_t)\le\mathbb E\sum_t\ell(h^\star,z_t)+\text{Regret}_T=T\,L_{\mathcal D}(h^\star)+\text{Regret}_T$$

从 $h_1,\dots,h_T$ 里随机挑一个输出（loss convex 时也可以输出 average），它的 expected risk 不超过 $L_{\mathcal D}(h^\star)+\text{Regret}_T/T$。

把 Hedge 用在第 1 站的 1000 个 hypothesis 上，$T=m=8478$：excess risk 的 expectation 不超过 $\sqrt{\ln1000/(2\times8478)}=0.020$。第 1 站的 ERM 用同样多的 example 保证的是“以 95% 的 probability 不超过 0.05”。两者一个是 expectation、一个是 high probability，不能直接比大小，但量级都是 $\sqrt{\ln|H|/m}$。第 4 站的 SGD 正是 online gradient descent 加上这一步 conversion。

:::from
Online learning 的 setup、regret 的定义、follow-the-leader 在交替 loss 上失败的那张表、online-to-batch 的结论（讲义只给了 statement），来自 [STATS214 讲义](https://tselilschramm.org/mltheory/ma.pdf)第 11 章。Halving 的 $\log_2|H|$、threshold 的 Littlestone dimension 是 infinite、Cover 的两个 constant hypothesis 的论证、Weighted-Majority 的 potential 证法，来自 [Understanding Machine Learning](https://cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf) 第 21 章；书里用 $e^{-a}\le1-a+a^2/2$ 得到 $\sqrt{2T\ln N}$，这里改用第 1 站的 Hoeffding's lemma，得到更紧的 $\sqrt{T\ln N/2}$。Perceptron 的三步 proof 与 geometric margin 来自 [MIT 6.867 Lecture 2](https://www.ocw.mit.edu/courses/6-867-machine-learning-fall-2006/df535ce359aad52f48c203db64558fe8_lec2.pdf)。四个点的例子、Hedge 的实算、online-to-batch 的推导是为这一页写和算的。
:::

## [kernel] Kernel、RKHS 与 representer theorem

:::skip
能推出 representer theorem 和 kernel ridge regression 的 $\alpha=(K+\lambda mI)^{-1}y$，能用 RKHS norm bound 住 function 的变化，并说出 infinite-dimensional feature space 为什么不破坏第 3 站的 bound，就可以去第 7 站。
:::

这一站接着 CS2109S 的 kernel 往下讲：那里已经有 $K(x,z)=\langle\phi(x),\phi(z)\rangle$、Gaussian kernel 对应 infinite-dimensional 的 $\phi$、合法的 kernel 的 Gram matrix 是 positive semidefinite。这里回答两个那里没回答的问题：在 infinite-dimensional 的 space 里怎么解 optimization，以及为什么不会 overfit。

### Infinite dimension 里的 optimization

Regularized ERM 是

$$\min_w\ \frac1m\sum_{i=1}^m\ell\big(\langle w,\phi(x_i)\rangle,y_i\big)+\lambda\lVert w\rVert^2$$

$\phi$ 是 Gaussian kernel 的 feature map 时，$w$ 是 infinite-dimensional 的，存都存不下。

**Representer theorem。** 存在 optimal solution 形如 $w=\sum_{i=1}^m\alpha_i\phi(x_i)$。

Proof：把任意 $w$ 分成两部分，$w=w_\parallel+u$，$w_\parallel$ 在 $\mathrm{span}\{\phi(x_1),\dots,\phi(x_m)\}$ 里，$u$ 和每个 $\phi(x_i)$ perpendicular。第一项只依赖于 $\langle w,\phi(x_i)\rangle=\langle w_\parallel,\phi(x_i)\rangle+\langle u,\phi(x_i)\rangle=\langle w_\parallel,\phi(x_i)\rangle$，丢掉 $u$ 不变。第二项 $\lVert w\rVert^2=\lVert w_\parallel\rVert^2+\lVert u\rVert^2$（Pythagorean theorem），丢掉 $u$ 只会变小。所以把 $u$ 换成 0 不会更差，optimal solution 可以在 span 里找。

于是 prediction 和 norm 都只用到 kernel：

$$f(x)=\langle w,\phi(x)\rangle=\sum_i\alpha_iK(x_i,x),\qquad\lVert w\rVert^2=\sum_{i,j}\alpha_i\alpha_jK(x_i,x_j)=\alpha^\top K\alpha$$

其中 $K$ 是 $m\times m$ 的 Gram matrix。Infinite-dimensional 的问题变成了 $m$ 个 unknown 的问题。

### Kernel ridge regression 的 closed form

Squared loss 时 objective 是

$$J(\alpha)=\frac1m\lVert K\alpha-y\rVert^2+\lambda\,\alpha^\top K\alpha$$

对 $\alpha$ 求 gradient（$K$ symmetric）：

$$\nabla J=\frac2mK(K\alpha-y)+2\lambda K\alpha=\frac2mK\big[(K+\lambda mI)\alpha-y\big]$$

$J$ 的两项都是 $\alpha$ 的 convex quadratic function（$K$ 和 $K^\top K$ 都 positive semidefinite），所以 stationary point 就是 minimum。令方括号为 0 就得到一个。$K$ 是 positive semidefinite，$\lambda>0$，$K+\lambda mI$ 的 eigenvalue 都至少是 $\lambda m$，一定 invertible：

$$\alpha=(K+\lambda mI)^{-1}y$$

三个点 $x=0,1,2$，$y=0,1,0$，Gaussian kernel $K(x,z)=e^{-(x-z)^2/2}$：

$$K=\begin{pmatrix}1&0.6065&0.1353\\0.6065&1&0.6065\\0.1353&0.6065&1\end{pmatrix}$$

取 $\lambda=0.1$，$\lambda m=0.3$。解 $(K+0.3I)\alpha=y$ 得 $\alpha=(-0.5367,\ 1.2700,\ -0.5367)$。核对第二个 equation：$0.6065\times(-0.5367)\times2+1.3\times1.2700=-0.651+1.651=1.000$。在三个点上的 prediction 是 $K\alpha=(0.161,\ 0.619,\ 0.161)$，在 $x=1.5$ 处是 $0.473$，norm 的 square 是 $\alpha^\top K\alpha=0.613$。

令 $\lambda\to0$，$\alpha=K^{-1}y=(-1.518,\ 2.841,\ -1.518)$，三个点上恰好是 $0,1,0$（interpolation），norm 的 square 是 2.841。$\lambda$ 越小，fit 得越准，norm 越大。

::fig[cs3264-krr3] 两个 $\alpha$ 画成 function $f(x)=\sum_i\alpha_iK(x_i,x)$。

### RKHS norm 衡量什么

由 $K$ 生成的所有 $f=\sum_i\alpha_iK(x_i,\cdot)$，配上 inner product $\langle K(x,\cdot),K(z,\cdot)\rangle=K(x,z)$，构成一个 Hilbert space，叫 reproducing kernel Hilbert space（RKHS）。名字来自这个性质：

$$\langle f,K(x,\cdot)\rangle=\sum_i\alpha_iK(x_i,x)=f(x)$$

和 $K(x,\cdot)$ 做 inner product，就是在 $x$ 处 evaluate。由 Cauchy–Schwarz：

$$|f(x)-f(x')|=|\langle f,K(x,\cdot)-K(x',\cdot)\rangle|\le\lVert f\rVert\sqrt{K(x,x)-2K(x,x')+K(x',x')}$$

Norm 小的 function 不能变化得快。Gaussian kernel、$x'=x\pm1$ 时，右边的 square root 是 $\sqrt{2-2e^{-1/2}}=0.887$。核对上面两个 fit：interpolant 的 norm 是 $\sqrt{2.841}=1.686$，bound 是 1.495，实际 $|f(1)-f(0)|=1$；$\lambda=0.1$ 的 fit 的 norm 是 0.783，bound 是 0.695，实际是 $0.619-0.161=0.458$。

### Dimension 消失了

第 3 站 linear class 的 bound $BX/\sqrt m$，推导里只用到了 $\lVert\sum_i\sigma_ix_i\rVert^2$ 的 expectation 等于 $\sum_i\lVert x_i\rVert^2$。把 $x_i$ 换成 $\phi(x_i)$，$\lVert\phi(x_i)\rVert^2=K(x_i,x_i)$，同样的几行给出

$$\mathcal R\big(\{f:\lVert f\rVert\le B\}\circ S\big)\le\frac Bm\sqrt{\sum_iK(x_i,x_i)}=\frac Bm\sqrt{\mathrm{tr}\,K}$$

Gaussian kernel 的 $K(x,x)=1$，右边是 $B/\sqrt m$。Feature space 是 infinite-dimensional 的，complexity 却只由 $B$ 决定。第 3 站的 VC bound 在这里用不上，因为 Gaussian kernel 的 classifier 的 VC dimension 是 infinite；norm 才是正确的量，而 $\lambda$ 就是在控制它。

::fig[cs3264-krr] 12 个带 noise 的点（真实 function 是 $\sin2\pi x$），Gaussian kernel 的 bandwidth 是 0.1。$\lambda=10^{-6}$ 时几乎 interpolate，norm 是 60.5，在两个挨得很近的点之间冲到 18；$\lambda=10^{-3}$ 时 norm 是 2.10；$\lambda=0.1$ 时 norm 是 1.30，curve 最平滑。

三个 fit 在 training set 上的 mean squared error 是 0.015、0.029、0.104，离真实 function 的 RMS 距离是 4.30、0.37、0.24。Training error 最小的那个离真相最远；它的 norm 是另外两个的 29 到 47 倍，第 3 站 bound 里的 complexity 项也大这么多倍。

:::wrong 任何衡量“相似”的 function 都可以当 kernel
$K(x,z)=|x-z|$ 看起来是个合理的 similarity（准确说是 distance）。两个点 $x=0,1$ 的 Gram matrix 是 $\begin{pmatrix}0&1\\1&0\end{pmatrix}$，eigenvalue 是 $1$ 和 $-1$。沿 eigenvector $v=(1,-1)/\sqrt2$ 取 $\alpha=cv$，$K\alpha=-cv$，“norm 的 square”$\alpha^\top K\alpha=-c^2$ 是负的。代进 kernel ridge regression 的 objective：$J=\tfrac1m\lVert-cv-y\rVert^2-\lambda c^2$，$c^2$ 的 coefficient 是 $\tfrac1m-\lambda$。$m=2$、$\lambda=1$ 时它是负的，$c\to\infty$ 时 $J\to-\infty$，optimization 没有 solution。Gram matrix 必须 positive semidefinite，“norm”才是 norm。
:::

:::edge $\lambda\to0$ 与 Gram matrix 的 condition number
上图的 data 里有两个点 $x=0.300$ 和 $0.303$，label 分别是 1.159 和 0.542。Bandwidth 0.1 下两点的 kernel 值几乎是 1，$K$ 接近 singular，最小 eigenvalue 是 $1.2\times10^{-6}$。$\lambda\to0$ 等于要求 $f$ 在相距 0.003 的两点上差 0.6，norm 只能爆掉。$\lambda m$ 加在 diagonal 上，把最小 eigenvalue 至少抬到 $\lambda m$，这和 [DSA2102 第 5 站](../courses/DSA2102.html#eig) ridge regression 把 $1/\sigma_i$ 换成 $\sigma_i/(\sigma_i^2+\delta)$ 是同一件事。
:::

:::from
RKHS 从“evaluation 是 bounded”出发、reproducing property、Tikhonov regularization、用 span 与 orthogonal complement 证 representer theorem，来自 [MIT 9.520 Class 3 scribe notes](https://www.mit.edu/~9.520/scribe-notes/class03_gdurett.pdf)；那份 notes 没有给 kernel ridge regression 的 closed form。Representer theorem 的一般形式（任意依赖于 $\langle w,\phi(x_i)\rangle$ 的 loss 加 nondecreasing 的 $R(\lVert w\rVert)$）、kernel ridge regression 用 Gram matrix 改写、Gram matrix positive semidefinite 的刻画，来自 [Understanding Machine Learning](https://cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf) 第 16 章，书里把 closed form 留作习题。“VC bound 处理不了 kernel、norm 才是正确的量”来自 [STATS214 讲义](https://tselilschramm.org/mltheory/ma.pdf)第 4.7、5.2 节。Closed form 的推导、三个点和 12 个点的例子是为这一页写和算的。

## [prob] Probabilistic model：MLE、MAP 与 Bayesian prediction

:::skip
能推出 log-loss 的 risk 等于 entropy 加 KL divergence，能用 Beta prior 算 predictive probability 并说出它和 MAP 的区别，能从 Gaussian prior 推出 ridge、从 shared covariance 推出 LDA 的 linear boundary，就可以去第 8 站。
:::

### Log-loss 把 MLE 变成 ERM

很多时候要的是一个 probability，一个 label 不够：这封邮件是 spam 的 probability、这个病人五年内复发的 probability。Model 是一族 distribution $p_\theta(z)$，用 log-loss $\ell(\theta,z)=-\ln p_\theta(z)$ 衡量。ERM 就是

$$\min_\theta\ \frac1m\sum_i-\ln p_\theta(z_i)$$

也就是 maximum likelihood estimation（MLE）。

它的 true risk 可以拆开。设真实 distribution 是 $P$：

$$\mathbb E_{z\sim P}\big[-\ln p_\theta(z)\big]=\mathbb E_P\big[-\ln P(z)\big]+\mathbb E_P\Big[\ln\frac{P(z)}{p_\theta(z)}\Big]=H(P)+\mathrm{KL}(P\,\Vert\,p_\theta)$$

第一项是 entropy，和 $\theta$ 无关；第二项叫 KL divergence。它不小于 0：$-\mathrm{KL}=\mathbb E_P\ln\frac{p_\theta}{P}\le\ln\mathbb E_P\frac{p_\theta}{P}=\ln\sum_{z:P(z)>0}p_\theta(z)\le\ln1=0$，inequality 是 Jensen（log 是 concave 的），等号当且仅当 $p_\theta=P$。所以 excess risk 正好是 KL divergence。

例子：一种罕见的副作用，每个病人出现的 probability 是 $\theta^\star=0.01$。Entropy 是 $-(0.01\ln0.01+0.99\ln0.99)=0.0560$ nats，这是任何 model 的 risk 的 lower bound。

### MLE 在 log-loss 下 overfit

Bernoulli 的 MLE 是 $\hat\theta=k/m$，$k$ 是 $m$ 个病人里出现副作用的人数。$m=50$ 时，一个都不出现的 probability 是 $0.99^{50}=0.605$。这时 $\hat\theta=0$，model 断言副作用不可能发生；下一个病人只要出现一次，loss 是 $-\ln0=\infty$。以 60% 的 probability，MLE 的 true risk 是 infinite。

第 1 站的 Hoeffding 说 $|\hat\theta-\theta^\star|\le\sqrt{\ln(2/\delta)/(2m)}=0.19$（$\delta=0.05$），可这对 log-loss 毫无帮助：前三站的所有 bound 都要求 loss bounded，而 $-\ln p$ 在 $p\to0$ 时没有上界。

### Bayes：prior、posterior、predictive

把 $\theta$ 当成 random variable，先给一个 prior。取 $[0,1]$ 上的 uniform prior，看到 $k$ 个 1、$m-k$ 个 0 之后，posterior 正比于 likelihood：

$$p(\theta\mid S)\propto\theta^k(1-\theta)^{m-k}$$

这是 $\mathrm{Beta}(k+1,m-k+1)$ distribution。预测下一个时不挑出一个 $\theta$，直接对 posterior 平均：

$$\Pr(z_{m+1}=1\mid S)=\int_0^1\theta\,p(\theta\mid S)\,d\theta=\frac{\int_0^1\theta^{k+1}(1-\theta)^{m-k}d\theta}{\int_0^1\theta^{k}(1-\theta)^{m-k}d\theta}$$

用 Beta integral $\int_0^1\theta^a(1-\theta)^b\,d\theta=\dfrac{a!\,b!}{(a+b+1)!}$，比值是

$$\frac{(k+1)!\,(m-k)!/(m+2)!}{k!\,(m-k)!/(m+1)!}=\frac{k+1}{m+2}$$

相当于事先多看了一个 1 和一个 0，叫 Laplace smoothing。$k=0$、$m=50$ 时 predictive probability 是 $1/52=0.0192$。它的 risk 是 $-(0.01\ln\tfrac1{52}+0.99\ln\tfrac{51}{52})=0.0587$，比 lower bound 0.0560 只多 0.0027。对 $k\sim\mathrm{Bin}(50,0.01)$ 取平均，excess risk 的 expectation 是 0.0094，有限。

::fig[cs3264-beta] 一直看到 0 时的 posterior：看 10 个、50 个之后，density 越来越集中在 0 附近，但始终给正的 $\theta$ 留着 mass。Predictive probability 取的是 posterior 的 mean。

:::wrong 用 MAP 代替 MLE，prior 就能修好这个问题
MAP（maximum a posteriori）取 posterior 的 mode。Uniform prior 下 posterior 正比于 likelihood，mode 就是 MLE：$k=0$ 时还是 $\hat\theta=0$，risk 还是 infinite。一般地，prior 取 $\mathrm{Beta}(a,b)$ 时 posterior 是 $\mathrm{Beta}(k+a,m-k+b)$，对 $(k+a-1)\ln\theta+(m-k+b-1)\ln(1-\theta)$ 求 derivative 令其为 0，得 mode $\dfrac{k+a-1}{m+a+b-2}$。只有 $a>1$ 才能让它离开 0：$\mathrm{Beta}(2,2)$ 给出 $\tfrac1{52}$。修好问题的是“对 posterior 平均”或者一个足够强的 prior，光是“用了 prior”并不够。
:::

### Gaussian prior 就是 ridge

Linear regression 的 probabilistic 版本：$y=w^\top x+\epsilon$，$\epsilon\sim N(0,\sigma^2)$，prior $w\sim N(0,\tau^2I)$。Posterior 的 negative log 是

$$-\ln p(w\mid S)=\frac1{2\sigma^2}\sum_i(y_i-w^\top x_i)^2+\frac1{2\tau^2}\lVert w\rVert^2+\text{const}$$

乘上 $2\sigma^2$，MAP 就是 ridge regression $\min_w\sum_i(y_i-w^\top x_i)^2+\lambda\lVert w\rVert^2$，$\lambda=\sigma^2/\tau^2$：noise 越大或 prior 越窄，regularization 越强。

一维的例子：$x=(1,2,3)$，$y=(1,2,2)$，$\sigma^2=0.25$，$\tau^2=1$。Posterior 的 exponent 是 $w$ 的 quadratic function：

$$-\frac12\Big[\Big(\frac{\sum x_i^2}{\sigma^2}+\frac1{\tau^2}\Big)w^2-2\,\frac{\sum x_iy_i}{\sigma^2}\,w\Big]+\text{const}=-\frac12\big[57w^2-88w\big]+\text{const}$$

（$\sum x_i^2=14$，$\sum x_iy_i=11$。）Completing the square 得 posterior 是 Gaussian，precision 57，mean $\tfrac{44}{57}=0.7719$。Ridge 用 $\lambda=0.25$：$\tfrac{11}{14+0.25}=0.7719$，相同；MLE 是 $\tfrac{11}{14}=0.7857$，被 prior 往 0 拉了一点。

Ridge 只给一个数，posterior 还给出不确定性。新的 $x_\ast$ 处 $y_\ast=wx_\ast+\epsilon$，predictive variance 是 $\sigma^2+x_\ast^2/57$：$x_\ast=1$ 时 0.268，$x_\ast=3$ 时 0.408，$x_\ast=10$ 时 2.004。离 data 越远，越没把握。

### Generative 与 discriminative：LDA 的 boundary 是 linear

另一种用 probability 做 classification 的办法是 model $p(x\mid y)$ 和 $p(y)$，再用 Bayes rule 反过来。设两个 class 的 prior 相等，$x\mid y\sim N(\mu_y,\Sigma)$，两个 class 共用 covariance $\Sigma$。Log-likelihood ratio 是

$$\ln\frac{p(x\mid1)}{p(x\mid0)}=-\frac12(x-\mu_1)^\top\Sigma^{-1}(x-\mu_1)+\frac12(x-\mu_0)^\top\Sigma^{-1}(x-\mu_0)$$

展开后 $x^\top\Sigma^{-1}x$ 两项抵消（这正是共用 $\Sigma$ 的作用），剩下

$$\ln\frac{p(x\mid1)}{p(x\mid0)}=w^\top x+b,\qquad w=\Sigma^{-1}(\mu_1-\mu_0),\quad b=\frac12\big(\mu_0^\top\Sigma^{-1}\mu_0-\mu_1^\top\Sigma^{-1}\mu_1\big)$$

所以 $\Pr(y=1\mid x)=\dfrac1{1+e^{-(w^\top x+b)}}$，和 logistic regression 是同一个 hypothesis class。这叫 linear discriminant analysis（LDA）。

取 $\mu_0=(0,0)$，$\mu_1=(2,1)$，$\Sigma=\begin{pmatrix}1&0.5\\0.5&1\end{pmatrix}$。$\Sigma^{-1}=\tfrac43\begin{pmatrix}1&-0.5\\-0.5&1\end{pmatrix}$，

$$w=\Sigma^{-1}\begin{pmatrix}2\\1\end{pmatrix}=\frac43\begin{pmatrix}2-0.5\\-1+1\end{pmatrix}=\begin{pmatrix}2\\0\end{pmatrix},\qquad b=-\frac12\mu_1^\top w=-2$$

Boundary 是 $x_1=1$，$x_2$ 的 weight 是 0，尽管两个 class 的 mean 在 $x_2$ 上差 1。原因是：给定 $x_1$ 之后，$x_2$ 的 conditional mean 在 class 0 是 $0.5x_1$，在 class 1 是 $1+0.5(x_1-2)=0.5x_1$，conditional variance 也相同，所以知道 $x_1$ 之后 $x_2$ 不再提供任何信息。$x=(2,0)$ 处 $\Pr(y=1\mid x)=\frac1{1+e^{-2}}=0.881$。

::fig[cs3264-lda] 两个 class 的 Gaussian 的 contour 都斜着，mean 在两个 coordinate 上都不同，boundary 却是竖直的 line $x_1=1$。

LDA 和 logistic regression 输出同一种形式的 classifier，区别在于怎么选 $w$。LDA 估计 $\mu_0,\mu_1,\Sigma$（两个 dimension 时是 7 个数）再换算成 $w,b$；logistic regression 直接 fit $\Pr(y\mid x)$ 的 3 个 parameter。Gaussian 的假设对时，LDA 用上了更多结构；假设错时，data 足够多的 logistic regression 找到的仍然是这个 class 里 log-loss 最小的那个，LDA 则没有这个保证。

:::from
MLE 就是 log-loss 下的 ERM、risk 拆成 entropy 加 relative entropy、Bernoulli 的 MLE 在 $\theta^\star$ 很小时得到 infinite log-loss、uniform prior 下 predictive 是 $(k+1)/(m+2)$、MAP 的定义、LDA 的 $w$ 与 $b$，以及 Vapnik“不要把更一般的问题当中间步骤”的原则，来自 [Understanding Machine Learning](https://cs.huji.ac.il/~shais/UnderstandingMachineLearning/understanding-machine-learning-theory-algorithms.pdf) 第 24 章。Beta integral 的计算、MAP 只有在 $a>1$ 时才离开 0、Gaussian prior 等价于 ridge、Bayesian linear regression 的 predictive variance，是凭标准教材的知识写的，没有对照这几门课的原文。副作用、一维 regression 和 LDA 的数字是为这一页算的。
:::

## [boost] Boosting：exponential loss 与 voting margin

:::skip
能推出 AdaBoost 的 $\alpha$、training error 的 $\prod2\sqrt{\varepsilon_t(1-\varepsilon_t)}$，能手算两三轮，并能用第 3 站的工具解释为什么 margin bound 和轮数无关，就读完这门课了。
:::

### Weak learner 能不能变强

Decision stump 只看一个 feature、切一刀：$h(x)=s\cdot\mathrm{sign}(x-\theta)$，$s\in\{\pm1\}$。一维的 10 个点 $x=1,\dots,10$，label 是

$$y=(+,+,+,-,-,-,-,+,+,+)$$

最好的 stump 也要错 3 个，error 0.3。问题是：只有这样比瞎猜好一点的 weak learner，能不能组合出任意准确的 classifier。

### AdaBoost

每个 example 有一个 weight $D_t(i)$，开始时都是 $\tfrac1m$。第 $t$ 轮：

1. 找 weighted error $\varepsilon_t=\sum_iD_t(i)\,\mathbf 1[h_t(x_i)\ne y_i]$ 最小的 stump $h_t$。
2. 给它的 vote $\alpha_t=\tfrac12\ln\dfrac{1-\varepsilon_t}{\varepsilon_t}$。
3. 更新 $D_{t+1}(i)\propto D_t(i)\,e^{-\alpha_ty_ih_t(x_i)}$：分对的乘 $e^{-\alpha_t}$，分错的乘 $e^{\alpha_t}$，再 normalize。

最后输出 $\mathrm{sign}(F_T(x))$，$F_T=\sum_t\alpha_th_t$。

$\alpha_t$ 从哪里来？AdaBoost 在一轮一轮地（stagewise）最小化 exponential loss $\frac1m\sum_ie^{-y_iF(x_i)}$。$F$ 加上 $\alpha h$ 之后，每个 example 的 exponential loss 乘上 $e^{-\alpha y_ih(x_i)}$；按当前的 normalized weight 加权，总 loss 乘上

$$Z(\alpha)=(1-\varepsilon)e^{-\alpha}+\varepsilon e^{\alpha}$$

对 $\alpha$ 求 derivative 令其为 0：$-(1-\varepsilon)e^{-\alpha}+\varepsilon e^\alpha=0$，$e^{2\alpha}=\frac{1-\varepsilon}\varepsilon$，就是上面的 $\alpha_t$。代回去，

$$Z=(1-\varepsilon)\sqrt{\tfrac\varepsilon{1-\varepsilon}}+\varepsilon\sqrt{\tfrac{1-\varepsilon}\varepsilon}=2\sqrt{\varepsilon(1-\varepsilon)}$$

$\varepsilon<\tfrac12$ 时 $Z<1$，每一轮 exponential loss 都严格下降。

更新之后还有一个性质：$h_t$ 在新的 weight 下的 weighted error 正好是 $\tfrac12$。分错的部分正比于 $\varepsilon e^{\alpha}=\sqrt{\varepsilon(1-\varepsilon)}$，分对的部分正比于 $(1-\varepsilon)e^{-\alpha}=\sqrt{\varepsilon(1-\varepsilon)}$，两者相等。新一轮里 $h_t$ 和瞎猜一样，所以下一轮不会立刻再选它，每一轮都被迫去找刚才没照顾到的方向。

在 10 个点上跑三轮（同样好的 stump 按 threshold 从小到大、$s=+1$ 优先选）：

| 轮 | 选中的 stump | 分错的点 | $\varepsilon_t$ | $\alpha_t$ | $Z_t=2\sqrt{\varepsilon_t(1-\varepsilon_t)}$ |
|---|---|---|---|---|---|
| 1 | $x\le3$ 为 $+$ | 8、9、10 | $0.3$ | $\tfrac12\ln\tfrac73=0.424$ | 0.917 |
| 2 | $x\ge8$ 为 $+$ | 1、2、3 | $\tfrac3{14}=0.214$ | $\tfrac12\ln\tfrac{11}3=0.650$ | 0.821 |
| 3 | 全部为 $+$ | 4 到 7 | $\tfrac2{11}=0.182$ | $\tfrac12\ln\tfrac92=0.752$ | 0.771 |

第 1 轮之后，分对的 7 个点 weight 变成 $\tfrac1{14}$，分错的 3 个变成 $\tfrac16$，两组各占一半。第 2 轮选的 stump 在点 1 到 3 上犯错，那里每个的 weight 是 $\tfrac1{14}$，合计 $\tfrac3{14}$。更新后点 1 到 3 各 $\tfrac16$、点 4 到 7 各 $\tfrac1{22}$、点 8 到 10 各 $\tfrac7{66}$。第 3 轮的“stump”是 constant $+1$，它只在点 4 到 7 上犯错，合计 $4\times\tfrac1{22}=\tfrac2{11}$。

三轮之后逐段算 $F_3=\alpha_1h_1+\alpha_2h_2+\alpha_3h_3$：点 1 到 3 上三个 stump 依次答 $+,-,+$，$F_3=0.424-0.650+0.752=0.526$；点 4 到 7 上答 $-,-,+$，$F_3=-0.424-0.650+0.752=-0.321$；点 8 到 10 上答 $-,+,+$，$F_3=-0.424+0.650+0.752=0.978$。Sign 是 $(+,-,+)$，10 个点全对。三个 error 0.3 左右的 stump，vote 之后 error 是 0。

::fig[cs3264-adaboost] 上表和上面两段的数字画在 10 个点上。

### Training error 的 bound

由 update rule，$D_{t+1}(i)=\dfrac{D_t(i)\,e^{-\alpha_ty_ih_t(x_i)}}{Z_t}$（$Z_t$ 正是 normalize 用的那个和）。从 $D_1=\tfrac1m$ 一路展开：

$$D_{T+1}(i)=\frac{e^{-y_iF_T(x_i)}}{m\prod_tZ_t}$$

对 $i$ 求和，左边是 1，所以 $\frac1m\sum_ie^{-y_iF_T(x_i)}=\prod_tZ_t$。分错时 $y_iF_T(x_i)\le0$，$e^{-y_iF_T(x_i)}\ge1$，所以 0-1 loss 不超过 exponential loss：

$$L_S\big(\mathrm{sign}\,F_T\big)\le\prod_{t=1}^T2\sqrt{\varepsilon_t(1-\varepsilon_t)}$$

记 $\varepsilon_t=\tfrac12-\gamma_t$，$2\sqrt{(\tfrac12-\gamma_t)(\tfrac12+\gamma_t)}=\sqrt{1-4\gamma_t^2}\le e^{-2\gamma_t^2}$（用 $1-u\le e^{-u}$）：

$$L_S\le\exp\Big(-2\sum_t\gamma_t^2\Big)$$

只要每一轮都比瞎猜好一个固定的 $\gamma$，training error 就按 $e^{-2\gamma^2T}$ exponential 地下降；降到 $1/m$ 以下就只能是 0，最多需要 $\ln m/(2\gamma^2)$ 轮。

核对例子：$0.917\times0.821\times0.771=0.580$，正是三轮后 $\frac1{10}\sum_ie^{-y_iF_3(x_i)}$ 的值；$\gamma_t=0.2,\ 0.286,\ 0.318$，$e^{-2\sum\gamma_t^2}=0.640$。Training error 0 在两个 bound 之内。

### 轮数越多，为什么不 overfit

每加一轮，model 就多一个 stump 和一个 $\alpha$。用第 2 站的办法数一下 $T$ 轮的 ensemble 在 $m$ 个点上能产生多少种 labeling：$T$ 个 stump 在这些点上的 restriction 最多有 $\tau_B(m)^T$ 种组合；组合固定之后，$\mathrm{sign}(\sum_t\alpha_th_t(x))$ 是 $\mathbb R^T$ 里的 vector $(h_1(x),\dots,h_T(x))$ 上的一个 halfspace，由第 2 站和 Sauer's lemma 最多 $(em/(T+1))^{T+1}$ 种。所以 $\ln$（labeling 个数）随 $T$ 线性增长，VC bound 的 complexity 项按 $\sqrt T$ 增长，预言轮数越多越容易 overfit。

实际跑一次。$x$ 在 $[-1,1]^2$ 上 uniform，$x_1^2+x_2^2<0.5$ 时 label 为 $+1$，否则 $-1$。300 个 training example，20000 个 test example，base learner 是两个 coordinate 上的 stump。

::fig[cs3264-boost] Training error、test error 和 bound $\prod_tZ_t$ 随轮数的变化（横轴 log scale）。Training error 在第 85 轮变成 0；test error 在那之后从 5.6% 继续降到第 562 轮的 4.2%，到第 1000 轮回升到 4.6%。

第 85 轮之后 training error 不能再降，exponential loss 却还在降，因为 $e^{-yF}$ 对已经分对的点仍然奖励更大的 $yF$。把 vote normalize：$f=F_T/\sum_t\alpha_t$，$yf(x)\in[-1,1]$ 叫 voting margin。最小的 voting margin 在第 85 轮是 0.0011，第 500 轮 0.036，第 1000 轮 0.043；margin 不超过 0.05 的 training example 从 6% 降到 4%。

第 3 站的 margin bound 正好不依赖 $T$。$f$ 是 stump 的 convex combination（$\alpha_t\ge0$，除以总和）。Convex combination 不增加 Rademacher complexity：

$$\sup_{\alpha}\sum_i\sigma_i\sum_t\frac{\alpha_t}{\sum_s\alpha_s}h_t(x_i)=\sup_\alpha\sum_t\frac{\alpha_t}{\sum_s\alpha_s}\Big(\sum_i\sigma_ih_t(x_i)\Big)\le\max_t\sum_i\sigma_ih_t(x_i)$$

一个 weighted average 不会超过其中最大的那一项。所以所有 stump 的 convex combination 组成的 class，Rademacher complexity 和 stump 的 class 一样，与 $T$ 无关。代进第 3 站的 ramp loss 论证：

$$L_{\mathcal D}\le\frac1m\#\{i:y_if(x_i)<\gamma\}+\frac2\gamma\,\mathbb E_S\mathcal R(B\circ S)+\sqrt{\frac{\ln(1/\delta)}{2m}}$$

AdaBoost 在 training error 为 0 之后继续推高小的 margin，第一项继续下降，第二项不动。

这个 bound 能解释形状，解释不了数字。Stump 在两个 coordinate、两个方向上，$m=300$ 个点最多给出 $4(m+1)=1204$ 种 labeling，vector 是 $\pm1$ 的，length 是 $\sqrt m$，Massart 给出 $\mathcal R\le\sqrt{2\ln1204/300}=0.217$；$\gamma=0.1$ 时第二项是 4.35，远大于 1。要让第二项小于 0.1，需要大约 $1.2\times10^6$ 个 example。同样，第 1000 轮 test error 回升也不和 bound 矛盾：bound 只是 upper bound；而且 AdaBoost 推高最小的 margin 时，median margin 从 0.146 降到了 0.100。

:::wrong Boosting 不会 overfit，轮数越多越好
上面不带 noise 的 data 上 test error 已经从 4.2% 回升到 4.6%。把 300 个 training label 随机翻转 10%（30 个），test error（对着没翻转的 label 算）在第 30 轮是 5.7%，到第 1000 轮升到 11.3%，同时 training error 降到 3.3%：AdaBoost 给翻错的点越来越大的 weight，硬去 fit 它们。Exponential loss 对分错的点按 $e^{|yF|}$ 惩罚，label noise 正好落在它最敏感的地方。轮数要用 validation set 来选。
:::

:::back
AdaBoost 的 weight update $D_{t+1}\propto D_te^{-\alpha y h}$ 和[第 5 站](#online)的 Hedge 是同一个 exponential weighting，一个给 example 加 weight，一个给 expert 加 weight。Margin bound 的每一块都来自[第 3 站](#rad)：symmetrization、contraction、Massart。
:::
