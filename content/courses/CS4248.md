先看三次失败。

**第一次。** 用三句话训练一个 bigram model：“I am Sam”“Sam I am”“I do not like green eggs and ham”。再拿“I do not like ham”去测，每个 word 都在训练里出现过，model 给这句话的 probability 却恰好是 0。

**第二次。** 让一个 RNN 读一句 5 个 word 的句子再翻译，读完留给 decoder 的是 $d$ 个数；换成 50 个 word 的句子，留下的还是那 $d$ 个数。句子越长，译文越差。

**第三次。** 一个在海量文本上 pretrain 过的 model，问它一个问题，它接着写出另一个相似的问题，没有回答。

这门课的对象是 language model：给一串 token 一个 probability。按 chain rule，

$$P(w_1,w_2,\dots,w_n)=\prod_{t=1}^{n}P(w_t\mid w_1,\dots,w_{t-1})$$

这个等式不含任何近似，所以全部问题只有三个：拿什么当 token（第 1 站）；怎样估计右边每个 conditional probability（第 2、3、5、6、7 站）；估计好了以后，怎样让 model 去做人要它做的事（第 8 站）。上面三次失败分别在第 2、5、8 站得到解释。第 4 站 sequence tagging 是同一套 probability 工具用在“给每个 word 标一个 label”上，NUS 的大纲把它列为单独的 topic。

每一个方法都是被上一个方法的失败逼出来的：

| 方法 | 它解决了什么 | 它卡在哪里 |
|---|---|---|
| n-gram counts | 能直接从文本估计 probability | 没见过的组合 probability 为 0；不知道哪些 word 相似 |
| word embedding | 相似的 word 有相近的 vector，可以共享统计 | 一个 word 只有一个 vector，不看 context |
| RNN | context 不限长度 | 信息和 gradient 都要一步一步传；encoder 只留一个 vector |
| attention、Transformer | 任意两个位置一步直达；可以并行 | cost 随长度平方增长；pretrain 完不会听指令 |
| post-training、RAG | 让 model 按指令回答，并能查到 weight 里没有的知识 | 依赖 preference data 和 retrieval 的质量 |

动手的部分，[labs 页](../labs.html)在这门课下面列了 Stanford CS336 的几个 assignment：从零写 BPE tokenizer 和 Transformer、拟合 scaling law、做 SFT 和 RL。

## [token] Tokenization 与 BPE

:::skip
能在一个小 corpus 上手算 BPE 的 merge，并按学到的顺序切分新词；能说出 word-level 和 byte-level tokenization 各自卡在哪里，就可以去第 2 站。
:::

### 先要决定一个 token 是什么

Language model 在每一步输出一个 vocabulary 上的 probability distribution，所以第一件事是定一个有限的 vocabulary。最直接的两个选择都走不通。

**以 word 为单位。** Vocabulary 会跟着 corpus 一起涨。J&M 第 2 章的统计：Shakespeare 全集 884K 个 token 里有 29K 种 word；COCA 有 4.4 亿个 token、200 万种 word。经验上 vocabulary 大小 $|V|$ 和 corpus 长度 $N$ 满足 Heaps' law $|V|=kN^\beta$，$\beta$ 在 0.44 到 0.56 左右。取 $\beta=0.5$，corpus 扩大 100 倍，vocabulary 扩大 $100^{0.5}=10$ 倍，永远涨不到头。所以测试时总会遇到训练里没有的 word：训练里有 low、new、newer，没有 lower，model 对 lower 无话可说，只能把它映射到一个统一的 UNK token。CS336 第 1 讲指出 UNK 还会搅乱 perplexity 的计算：所有生词合并成同一个 UNK，它出现得多、容易猜中，perplexity 被人为压低。中文、日文、泰文没有空格，word 本身就不好定义。

**以 byte 为单位。** 把 text 编码成 UTF-8，vocabulary 就是 256 个 byte，任何 string 都能表示，没有 UNK。代价是 sequence 太长。CS336 用 compression ratio（byte 数除以 token 数）衡量 tokenizer，byte-level 的 compression ratio 恰好是 1。中文更吃亏：“语言模型”4 个 character，UTF-8 是 12 个 byte。第 6 站会看到 Transformer 的 attention cost 随 sequence length 平方增长，context window 的长度也是固定的，sequence 长 3 倍，同一个 window 里就只装得下三分之一的文字。

想要的是两者之间：常见的 string 整个当一个 token，罕见的拆成小块。哪些算常见，由训练数据决定。这就是 byte-pair encoding（BPE）。

### BPE 的 training：反复合并最常见的相邻 pair

Algorithm 只有一条规则：

1. 每个 word 拆成 character。Word 开头加一个记号 `_`，表示它前面有空格。
2. 统计所有相邻 symbol pair 出现的次数，每个 word 按它在 corpus 里的 count 加权。
3. 把次数最多的 pair 合成一个新 symbol，加入 vocabulary，并记下这条 merge。
4. 重复第 2、3 步 $k$ 次。

合并只发生在一个 word 内部，不跨过空格。

用 J&M 第 2 章的 corpus：“set new new renew reset renew”。整理成 word 和 count：

| word | count | 拆开 |
|---|---|---|
| `_new` | 2 | `_ n e w` |
| `_renew` | 2 | `_ r e n e w` |
| `_set` | 1 | `_ s e t` |
| `_reset` | 1 | `_ r e s e t` |

初始 vocabulary 是 `_ e n r s t w` 这 7 个 symbol。Token 总数是 $4\times2+6\times2+4\times1+6\times1=30$。

第一轮数 pair。`n e` 在 `_new` 里出现一次，`_new` 有 2 个；在 `_renew` 里出现一次，`_renew` 也有 2 个；合计 4。同样数下去：

| pair | `n e` | `e w` | `_ r` | `r e` | `_ n` | `e n` | `s e` | `e t` | `_ s` | `e s` |
|---|---|---|---|---|---|---|---|---|---|---|
| count | 4 | 4 | 3 | 3 | 2 | 2 | 2 | 2 | 1 | 1 |

`n e` 和 `e w` 并列第一，合并 `n e`。合并之后重新数，`ne w` 的 count 是 4，第二轮合并它。如此做 8 轮：

| 轮 | merge | count | 这一轮之后 `_renew` 和 `_reset` 的样子 | token 总数 |
|---|---|---|---|---|
| 1 | `n e` → `ne` | 4 | `_ r e ne w`，`_ r e s e t` | 26 |
| 2 | `ne w` → `new` | 4 | `_ r e new`，`_ r e s e t` | 22 |
| 3 | `_ r` → `_r` | 3 | `_r e new`，`_r e s e t` | 19 |
| 4 | `_r e` → `_re` | 3 | `_re new`，`_re s e t` | 16 |
| 5 | `_ new` → `_new` | 2 | 不变（`_new` 变成一个 token） | 14 |
| 6 | `_re new` → `_renew` | 2 | `_renew`，`_re s e t` | 12 |
| 7 | `s e` → `se` | 2 | `_renew`，`_re se t` | 10 |
| 8 | `se t` → `set` | 2 | `_renew`，`_re set` | 8 |

第 5 到 8 轮，`_ new`、`_re new`、`s e`、`e t` 的 count 都是 2，并列时选哪个都可以，这里按 J&M 的次序。每一轮 token 总数下降的量，正好是被合并的 pair 的 count：第 1 轮 30 减 4 得 26，第 3 轮 22 减 3 得 19。

8 轮之后 vocabulary 有 $7+8=15$ 个 symbol，30 个 token 压成了 8 个。`_new` 和 `_renew` 各成一个 token；`_reset` 是 `_re` 加 `set`，出现得少的 word 被拆成了出现得多的零件。

::fig[cs4248-bpe] 同一个 corpus 在 0、2、4、8 次 merge 之后的样子。每个格子是一个 token，右边是按 count 加权后的 token 总数。

### 切分新文本：按学到的顺序 apply merge

Encode 一个新 word 时，先拆成 character，然后把 8 条 merge 按学到的先后顺序逐条 apply。新文本里哪个 pair 多不起作用。

| 新 word | 切分结果 | 说明 |
|---|---|---|
| `_renews` | `_renew s` | 训练过的 word 加一个 suffix |
| `_newest` | `_new e s t` | `est` 没学过，拆回 character |
| `_resent` | `_re se n t` | 学到的 prefix `_re` 被复用 |
| `_tree` | `_ t r e e` | 没有一条 merge 用得上 |

`_resent` 那一行值得一步步走。拆开是 `_ r e s e n t`。第 1 条 merge 找 `n e`：这里是 `e n`，顺序不对，不合并。第 2 条找 `ne w`，没有。第 3 条把 `_ r` 合成 `_r`，第 4 条把 `_r e` 合成 `_re`。第 5、6 条没有对象。第 7 条把 `s e` 合成 `se`。第 8 条找 `se t`，`se` 后面是 `n`，不合并。结果 `_re se n t`。

再试 `_reuse`：`u` 从没在训练里出现，不在 base vocabulary 里，这个 word 根本无法表示，又回到了 UNK。

### Byte-level BPE

办法是把 base vocabulary 换成 256 个 byte：text 先做 UTF-8 encode，BPE 在 byte 上做 merge。任何 Unicode string 都是一串 byte，所以不可能出现表示不了的输入。GPT-2 的 vocabulary 是 50,257 个 token。

Karpathy 的 minbpe 用一个只有 a、b、c、d 的例子演示这件事：“aaabdaaabac”，11 个 token。`aa` 最多，合成 Z，得到 `ZabdZabac`；`ab` 合成 Y，得到 `ZYdZYac`；`ZY` 合成 X，得到 `XdXac`。3 次 merge，11 个 token 变 5 个。在 minbpe 里 0 到 255 留给 byte，三个新 token 的编号是 256、257、258，所以结果是 `[258, 100, 258, 97, 99]`（d 的 byte 是 100，a 是 97，c 是 99）。

实际的 tokenizer 在 BPE 之前还先用一个 regular expression 把 text 切成 word、数字、标点等块，merge 不跨块。GPT-2 论文的理由是：否则 “dog.”“dog!”“dog?” 会各自变成一个 token，vocabulary 浪费在同一个 word 的不同标点组合上。

:::wrong Token 就是 word，model 看得见每个字母
Model 看到的是 token 的编号。Karpathy 的 tokenizer 讲座里，GPT-2 把 “Tokenization” 切成 2 个 token；“ is” 连同前面的空格是一个 token（编号 318）；数字 “127” 是一个 token，“677” 是两个。问 model 一个 word 里某个字母出现几次、把 string 倒过来写、做多位数加法，它面对的都是这些不规则的块。上面的小例子也一样：`_reset` 进入 model 时是 `_re` 和 `set` 两个编号，其中的 e 和 s 并不单独存在。LLM 在 spelling 和 arithmetic 上的一部分毛病来自这里。
:::

:::edge 同样的意思，不同 language 的 token 数不同
Tokenizer 的 merge 是在以英语为主的数据上学的，其他 language 的常见 string 得不到 merge，被切得更碎。J&M 第 2 章的例子里，一句英语是 19 个 token，意思相同的 16 个 Spanish word 切成了 33 个 token。Token 多意味着 compute 更贵、同一个 context window 里装得更少。
:::

## [ngram] N-gram language model、smoothing 与 perplexity

:::skip
能从 counts 算 bigram probability 和 perplexity，能用数字说明 sparsity 为什么不可避免，并说出 Laplace smoothing 和 interpolation 各自付出的代价，就可以去第 3 站。
:::

### 从 chain rule 到 Markov assumption

开头那个 chain rule 是精确的，难处在右边：$P(w_t\mid w_1,\dots,w_{t-1})$ 要求在整个前文的条件下估计下一个 word。用 counts 估计，就是“前文后面跟着 $w_t$ 的次数”除以“前文出现的次数”。可是长一点的前文在任何 corpus 里都几乎只出现一次或者根本不出现，两个 count 都是 0。

退一步：假设下一个 word 只依赖前面 $N-1$ 个 word。这叫 Markov assumption。$N=2$ 时是 bigram model：

$$P(w_t\mid w_1,\dots,w_{t-1})\approx P(w_t\mid w_{t-1})=\frac{C(w_{t-1}\,w_t)}{C(w_{t-1})}$$

这个 count 之比是 maximum likelihood estimate，理由如下。

对一个固定的前一个 word $a$，要选 $p(b\mid a)$ 让训练数据的 log-likelihood $\sum_bC(a\,b)\log p(b\mid a)$ 最大，约束是 $\sum_bp(b\mid a)=1$。加 Lagrange multiplier $\lambda$，对每个 $p(b\mid a)$ 求 derivative 令其为 0：

$$\frac{C(a\,b)}{p(b\mid a)}-\lambda=0\quad\Rightarrow\quad p(b\mid a)=\frac{C(a\,b)}{\lambda}$$

代回约束，$\lambda=\sum_bC(a\,b)=C(a)$。

用 J&M 第 3 章的三句话。每句前后加上开始记号 `<s>` 和结束记号 `</s>`：

```
<s> I am Sam </s>
<s> Sam I am </s>
<s> I do not like green eggs and ham </s>
```

$C(\texttt{<s>})=3$，其中 2 次后面是 I，所以 $P(\text{I}\mid\texttt{<s>})=\tfrac23$。I 出现 3 次，2 次后面是 am、1 次是 do：$P(\text{am}\mid\text{I})=\tfrac23$，$P(\text{do}\mid\text{I})=\tfrac13$。am 出现 2 次，后面一次是 Sam、一次是 `</s>`：$P(\text{Sam}\mid\text{am})=\tfrac12$。Sam 后面一次是 `</s>`、一次是 I：$P(\texttt{</s>}\mid\text{Sam})=\tfrac12$。于是

$$P(\texttt{<s>}\ \text{I am Sam}\ \texttt{</s>})=\tfrac23\cdot\tfrac23\cdot\tfrac12\cdot\tfrac12=\tfrac19$$

### Perplexity：每一步平均有几个选择

一句话的 probability 随长度指数下降，没法拿不同长度的句子比较。取 geometric mean 的倒数：

$$\mathrm{PP}(W)=P(w_1\cdots w_N)^{-1/N}$$

这里 $N$ 是被预测的 token 个数。上面那句预测了 I、am、Sam、`</s>` 四个，$\mathrm{PP}=(1/9)^{-1/4}=\sqrt3\approx1.73$。

这个数可以直接读：如果 model 每一步都在 $k$ 个选项里均匀地猜，每步 probability 是 $1/k$，$N$ 步乘起来是 $k^{-N}$，perplexity 恰好是 $k$。J&M 的例子：10 个 digit 均匀出现的 language，perplexity 是 10。所以 perplexity 1.73 的意思是这个 model 在这句话上平均相当于在 1.73 个选项里猜。

取 log 再看：

$$\log\mathrm{PP}=-\frac1N\sum_{t=1}^N\log P(w_t\mid w_{<t})$$

右边是每个 token 的平均 negative log-likelihood，也就是第 7 站 training 时要最小化的 cross-entropy loss。Perplexity 就是 $e^{\text{loss}}$。

J&M 在 Wall Street Journal 上的数字：3800 万个 word 训练、150 万个 word 测试，unigram 的 perplexity 是 962，bigram 是 170，trigram 是 109。看的前文越长，预测越准。

### Sparsity：用 counts 看

现在测“I do not like ham”：

$$\tfrac23\cdot\underbrace{\tfrac13}_{\text{do}\mid\text{I}}\cdot\underbrace{1}_{\text{not}\mid\text{do}}\cdot\underbrace{1}_{\text{like}\mid\text{not}}\cdot\underbrace{0}_{\text{ham}\mid\text{like}}\cdot\underbrace{1}_{\texttt{</s>}\mid\text{ham}}=0$$

训练里 like 只出现一次，后面是 green，所以 $P(\text{ham}\mid\text{like})=0/1$。一个 factor 为 0，整句为 0，perplexity 是 $0^{-1/6}$，infinite。这就是开头的第一次失败。还有更糟的一种：如果前一个 word 在训练里根本没出现过，分母 $C(a)$ 也是 0，这个 probability 连定义都没有。

这不是 corpus 太小的偶然。Shakespeare 全集 $N=884{,}647$ 个 token，$|V|=29{,}066$ 种 word。可能的 bigram 有

$$|V|^2=29{,}066^2=844{,}832{,}356$$

种，而全集里一共只有 $884{,}646$ 个相邻 pair。就算它们两两不同，也最多覆盖 $884{,}646/844{,}832{,}356\approx0.105\%$ 的可能 bigram。99.9% 以上的 bigram count 是 0，其中大量是完全正常的英语。换成 4-gram，可能的组合是 $|V|^4\approx7.1\times10^{17}$ 种。$N$ 越大，model 越准（trigram 胜过 bigram），也越 sparse。

:::wrong Count 是 0，说明这个组合不可能出现
Count 是 0 只说明“训练里没见过”。J&M 引的 WSJ counts：“denied the”后面跟过 allegations 5 次、speculation 2 次、rumors 1 次、report 1 次，别的没有。按 MLE，$P(\text{offer}\mid\text{denied the})=0$，可 test set 里偏偏有“denied the offer”和“denied the loan”。只要 test set 里有一个这样的组合，整个 test set 的 probability 就是 0，perplexity 算不出来。所以 smoothing 不是可选的修饰，没有它 model 根本没法评估。
:::

### Laplace smoothing 和它的代价

最简单的修补：每个 count 都加 1。分母要加上 vocabulary 大小 $|V|$，probability 才仍然合计为 1：

$$P_{\text{Laplace}}(b\mid a)=\frac{C(a\,b)+1}{C(a)+|V|}$$

这里 $|V|$ 是所有可能出现在后面的 symbol：10 个 word 加 `</s>`，共 11 个（`<s>` 不会被预测）。测试句逐项重算：

$$\tfrac{2+1}{3+11}\cdot\tfrac{1+1}{3+11}\cdot\tfrac{1+1}{1+11}\cdot\tfrac{1+1}{1+11}\cdot\tfrac{0+1}{1+11}\cdot\tfrac{1+1}{1+11}=\tfrac{3}{14}\cdot\tfrac17\cdot\tfrac16\cdot\tfrac16\cdot\tfrac1{12}\cdot\tfrac16\approx1.18\times10^{-5}$$

不再是 0，perplexity 是 $(1.18\times10^{-5})^{-1/6}\approx6.63$。

代价在别处。like 后面训练里只见过 green，现在 green 只分到 $\tfrac2{12}=\tfrac16$，其余 10 个从没跟在 like 后面的 symbol 每个 $\tfrac1{12}$，合计 $\tfrac{10}{12}$。见过的那一个反而只占六分之一。

::fig[cs4248-laplace] 训练数据里 like 后面只跟过 green。左边是 MLE，右边是 Laplace smoothing：green 从 1 降到六分之一，十个没见过的 symbol 平分了其余六分之五。

后果在训练句上就能看到：“I am Sam”的 perplexity 从 1.73 涨到 5.51。$|V|$ 越大越严重。J&M 用 Berkeley Restaurant 的数据（$|V|=1446$）算过：“want to”原本出现 608 次，加 1 之后相当于只出现了 238 次，$P(\text{to}\mid\text{want})$ 从 0.66 跌到 0.26。

### Interpolation：向 lower-order 借估计

Laplace 的毛病是把 probability 平均分给所有没见过的 word，不管它们本身常不常见。更合理的办法是：bigram 没见过时，退到 unigram，至少知道一个 word 整体上有多常见。把两者按 weight 混合：

$$\hat P(b\mid a)=\lambda\,P_{\text{MLE}}(b\mid a)+(1-\lambda)\,P(b),\qquad P(b)=\frac{C(b)}{\text{token 总数}}$$

训练数据里被预测的 token 共 17 个（14 个 word 加 3 个 `</s>`），ham 出现 1 次，$P(\text{ham})=\tfrac1{17}$。取 $\lambda=0.7$：

$$\hat P(\text{ham}\mid\text{like})=0.7\times0+0.3\times\tfrac1{17}=0.0176,\qquad\hat P(\text{green}\mid\text{like})=0.7\times1+0.3\times\tfrac1{17}=0.7176$$

见过的 green 保住了七成以上。把每个 factor 这样算完：

| 方法 | “I am Sam”的 perplexity | “I do not like ham”的 perplexity |
|---|---|---|
| MLE | 1.73 | infinite |
| Laplace | 5.51 | 6.63 |
| Interpolation，$\lambda=0.7$ | 2.23 | 3.22 |

$\lambda$ 不能在训练数据上选：在训练数据上 bigram 从不出错，最优的 $\lambda$ 总是 1，又回到 MLE。要留出一份 held-out data，在那上面选让 perplexity 最小的 $\lambda$。同样的道理适用于这门课里所有 hyperparameter。

:::edge Smoothing 不知道 ham 和 eggs 相似
上面两种方法给“like ham”的 probability，都只取决于 ham 自己的 count。训练里明明有“like green eggs”，而 ham 和 eggs 都是食物，可在 counts 的世界里每个 word 只是一个编号，ham 和 eggs 之间没有任何关系可用。要让 model 从“green eggs”推到“ham”，word 必须有一个能比较相似度的表示。这是第 3 站的事。
:::

三句话的 corpus、MLE 的 bigram probability、perplexity 的定义与 digit 的例子、WSJ 的三个 perplexity、Shakespeare 的 $N$ 和 $|V|$、“denied the”、Laplace smoothing 在 Berkeley Restaurant 上的数字、interpolation 与 held-out，都来自 [SLP3 第 3 章](https://web.stanford.edu/~jurafsky/slp3/3.pdf)。“分子为 0 和分母为 0 是两种 sparsity”参考了 [CS224N 2019 notes 05](https://web.stanford.edu/class/cs224n/readings/cs224n-2019-notes05-LM_RNN.pdf)。测试句“I do not like ham”、MLE 的 Lagrange 推导、0.105% 的上界、表中的六个 perplexity 是我加的、实际算过的；J&M 那一章没有给出 Shakespeare 里 zero bigram 的比例。

## [embed] Word embeddings 与 word2vec

:::skip
能用 count vector 算 cosine similarity；能写出 skip-gram with negative sampling 的 loss 和 gradient、手算一步 update；知道 SGNS 的 optimum 和 PMI 的关系，就可以去第 4 站。
:::

### One-hot vector 让所有 word 彼此一样远

上一站的 model 里 word 只是编号。把编号写成 vector，就是 one-hot vector：长度 $|V|$，只有自己那一位是 1。任意两个不同 word 的 one-hot vector，dot product 都是 0。CS224N 的例子：hotel 和 motel 的 dot product 是 0，hotel 和 cat 的 dot product 也是 0。在这个表示下，“ham 与 eggs 相似”无从表达。

### 用 context 定义一个 word

Distributional hypothesis：出现在相似 context 里的 word，意思相似。最直接的实现是数 count：每个 word 记录它和各个 context word 一起出现了多少次。J&M 第 5 章的数据（只取三个 context word）：

| | pie | data | computer |
|---|---|---|---|
| cherry | 442 | 8 | 2 |
| digital | 5 | 1683 | 1670 |
| information | 5 | 3982 | 3325 |

比较两个 vector 用 cosine：

$$\cos(v,w)=\frac{v\cdot w}{|v|\,|w|}$$

算 cherry 和 information：

$$v\cdot w=442\times5+8\times3982+2\times3325=2210+31856+6650=40716$$

$$|\text{cherry}|=\sqrt{442^2+8^2+2^2}=442.08,\qquad|\text{information}|=\sqrt{5^2+3982^2+3325^2}=5187.68$$

$$\cos=\frac{40716}{442.08\times5187.68}=0.018$$

同样算出 digital 和 information 的 cosine 是 0.996。用 cosine 而不用 dot product，是因为 dot product 随 vector 的 length 变大，而 length 主要反映 word 的出现频率：information 出现得多，它和谁的 dot product 都偏大。除以 length 之后只剩方向。

这种 count vector 有 $|V|$ 维（通常一万到五万），几乎全是 0。想要的是 50 到 1000 维的 dense vector，叫 embedding。

### Skip-gram with negative sampling：把“谁和谁一起出现”变成 classification

Word2vec 不去数 count，而是训练一个 classifier。J&M 的例句，target word 是 apricot，window 取前后各 2 个 word：

```
... lemon, a [tablespoon of apricot jam, a] pinch ...
```

(apricot, tablespoon)、(apricot, of)、(apricot, jam)、(apricot, a) 是四个 positive pair。每个 positive pair 再从 vocabulary 里随机抽 $k$ 个 word 当 negative，例如 (apricot, aardvark)。Classifier 要分辨一个 pair 是真的邻居还是随机凑的：

$$P(+\mid w,c)=\sigma(c\cdot w)=\frac{1}{1+e^{-c\cdot w}}$$

每个 word 有两个 vector：当 target 时用 $w$，当 context 时用 $c$。

为什么不直接预测“下一个 context word 是谁”？那要在整个 vocabulary 上做 softmax：

$$P(c\mid w)=\frac{e^{c\cdot w}}{\sum_{v\in V}e^{v\cdot w}}$$

Denominator 每次都要对 $|V|$ 个 word 求和，$|V|$ 是几十万到上百万，每一步 update 都这么贵。Negative sampling 把它换成 $k+1$ 个 binary classification，每步只碰 $k+1$ 个 context vector。

一个 positive $c_{\text{pos}}$ 加 $k$ 个 negative $c_{\text{neg},i}$ 的 loss 是

$$L=-\Big[\log\sigma(c_{\text{pos}}\cdot w)+\sum_{i=1}^k\log\sigma(-c_{\text{neg},i}\cdot w)\Big]$$

求 gradient 只需要 $\sigma$ 的一个性质：$\sigma'(x)=\sigma(x)(1-\sigma(x))$，所以

$$\frac{d}{dx}\log\sigma(x)=\frac{\sigma(x)(1-\sigma(x))}{\sigma(x)}=1-\sigma(x),\qquad\frac{d}{dx}\log\sigma(-x)=-\big(1-\sigma(-x)\big)=-\sigma(x)$$

后一个先用 chain rule 带出 $-1$，再用 $1-\sigma(-x)=\sigma(x)$。再用 chain rule，$c\cdot w$ 对 $c$ 的 gradient 是 $w$，对 $w$ 的 gradient 是 $c$：

$$\frac{\partial L}{\partial c_{\text{pos}}}=\big[\sigma(c_{\text{pos}}\cdot w)-1\big]\,w,\qquad\frac{\partial L}{\partial c_{\text{neg},i}}=\sigma(c_{\text{neg},i}\cdot w)\,w$$

$$\frac{\partial L}{\partial w}=\big[\sigma(c_{\text{pos}}\cdot w)-1\big]\,c_{\text{pos}}+\sum_{i}\sigma(c_{\text{neg},i}\cdot w)\,c_{\text{neg},i}$$

手算一步。取 2 维、$k=1$、learning rate $\eta=1$：

$$w=(0.5,\,0.2),\qquad c_{\text{pos}}=(0.1,\,0.4),\qquad c_{\text{neg}}=(0.6,\,0.1)$$

$c_{\text{pos}}\cdot w=0.05+0.08=0.13$，$\sigma(0.13)=0.532$；$c_{\text{neg}}\cdot w=0.30+0.02=0.32$，$\sigma(0.32)=0.579$。Loss 是 $-[\ln0.532+\ln(1-0.579)]=-[-0.630-0.866]=1.496$。三个 gradient：

$$\frac{\partial L}{\partial c_{\text{pos}}}=-0.468\,(0.5,0.2)=(-0.234,\,-0.094),\qquad\frac{\partial L}{\partial c_{\text{neg}}}=0.579\,(0.5,0.2)=(0.290,\,0.116)$$

$$\frac{\partial L}{\partial w}=-0.468\,(0.1,0.4)+0.579\,(0.6,0.1)=(-0.047+0.348,\ -0.187+0.058)=(0.301,\,-0.129)$$

各自减去 gradient：

$$c_{\text{pos}}\to(0.334,\,0.494),\qquad c_{\text{neg}}\to(0.310,\,-0.016),\qquad w\to(0.199,\,0.329)$$

新的 dot product：$c_{\text{pos}}\cdot w=0.229$，从 0.13 上升；$c_{\text{neg}}\cdot w=0.057$，从 0.32 下降。Loss 降到 1.307。

::fig[cs4248-sgns] 同一步 update 画在 plane 上。$w$ 转向 $c_{\text{pos}}$，$c_{\text{pos}}$ 被拉向 $w$，$c_{\text{neg}}$ 被推离 $w$。

Negative 从哪个 distribution 抽？按 unigram 频率抽，negative 几乎全是 the、of 这类 word。Word2vec 把频率取 0.75 次方再 normalize：

$$P_\alpha(w)=\frac{C(w)^{0.75}}{\sum_{w'}C(w')^{0.75}}$$

J&M 的例子：两个 word 的频率是 0.99 和 0.01，取 0.75 次方后变成 0.97 和 0.03，罕见 word 被抽中的机会提高到约 3 倍。

### Training 的终点是什么

:::skip
这一小节推导 SGNS 的 optimum。跳过它会少掉“embedding 为什么能反映 context 相似度”的理由，不影响后面几站。
:::

固定一对 $(w,c)$，看 loss 里所有含 $x=c\cdot w$ 的 term。这对 word 作为 positive 出现了 $C(w,c)$ 次。作为 negative：$w$ 一共出现 $C(w)$ 次，每次抽 $k$ 个 negative，抽中 $c$ 的 probability 是 $P_n(c)$，expected count 是 $k\,C(w)\,P_n(c)$。所以要最大化的是

$$C(w,c)\log\sigma(x)+k\,C(w)\,P_n(c)\log\sigma(-x)$$

对 $x$ 求 derivative 令其为 0，用上面的两个 derivative：

$$C(w,c)\,\big(1-\sigma(x)\big)-k\,C(w)\,P_n(c)\,\sigma(x)=0\quad\Rightarrow\quad\frac{\sigma(x)}{1-\sigma(x)}=\frac{C(w,c)}{k\,C(w)\,P_n(c)}$$

左边等于 $e^x$（$\sigma(x)/(1-\sigma(x))=\frac{1}{1+e^{-x}}\cdot\frac{1+e^{-x}}{e^{-x}}=e^x$）。取 $P_n(c)=C(c)/T$（$\alpha=1$，$T$ 是 token 总数）：

$$c\cdot w=\log\frac{C(w,c)\,T}{C(w)\,C(c)}-\log k=\log\frac{P(w,c)}{P(w)P(c)}-\log k=\mathrm{PMI}(w,c)-\log k$$

$\mathrm{PMI}(w,c)$ 叫 pointwise mutual information：两个 word 一起出现的次数，比“各自独立出现时预期的次数”多出多少倍，再取 log。所以 SGNS 训练好之后，$w$ 和每个 context vector 的 dot product 就是 PMI 表里 $w$ 那一行（这个推导假设 dimension 够大，每个 $c\cdot w$ 都能单独达到最优；dimension 有限时，embedding 是这张表的一个 low-rank approximation）。两个 word 的 PMI 行相近，也就是它们和同一批 context word 的关联程度相近，它们的 $w$ 就会相近。这正是 distributional hypothesis 的精确版本。

:::wrong king − man + woman 算出来就是 queen
这个 analogy 只在“去掉几个 word 之后”成立。J&M 指出，离 $\text{king}-\text{man}+\text{woman}$ 最近的 vector 往往是 king 自己或它的变形，所以通常要把输入的几个 word 和它们的变形排除在外，才轮得到 queen。另外，embedding 会忠实地复制训练文本里的偏见：Bolukbasi 等人 2016 年发现，在新闻上训练的 word2vec 里，离 $\text{computer programmer}-\text{man}+\text{woman}$ 最近的 occupation 是 homemaker。Analogy 测出来的是 corpus 的统计，不是一条语义定律。
:::

:::edge 意思相反的 word 也会靠得很近
Hot 和 cold 都出现在“the water is ___”“it was very ___ today”这类 context 里。按上面的推导，它们的 PMI 行很像，embedding 也就很近。Distributional similarity 衡量的是“能不能出现在同样的位置”，antonym 恰好满足。
:::

### Static embedding 的极限

每个 word 只有一个 vector。J&M 第 7 章的例子：“The chicken didn't cross the road because it was too tired”里 it 指 chicken，“because it was too wide”里 it 指 road，两个 it 的 embedding 却完全相同。Bank 在“river bank”和“bank account”里也是同一个 vector。Word 的表示必须随 context 改变，这要等第 5、6 站。

## [tag] Sequence tagging：HMM 与 Viterbi

:::skip
能从 counts 估计 HMM 的两张 table，能在 J&M 的 Janet will back the bill 上把 Viterbi 的 trellis 算完并 backtrace，并能说出为什么逐列取最大会出错，就可以去第 5 站。
:::

### 每个 word 一个 label，label 之间互相牵连

Part-of-speech tagging 给每个 word 标上 noun、verb 这样的 label。难处是 ambiguity：“book that flight”里 book 是 verb，“hand me that book”里是 noun。J&M 在 WSJ 上的统计：只有 14% 的 word type 有歧义，却占了 55% 的 token，因为有歧义的恰恰是最常用的 word。一个 baseline：每个 word 永远标它在训练里最常见的 tag，accuracy 约 92%；最好的方法约 97%。

Named entity recognition 也写成 tagging：B 表示一个 entity 的开头，I 表示 entity 内部，O 表示不属于任何 entity。“Jane Villanueva of United Airlines” 标成 B-PER、I-PER、O、B-ORG、I-ORG。有 $n$ 种 entity 时共 $2n+1$ 个 tag。

逐个 word 独立分类不够：back 可以是 6 种 tag，它在“will back”里是 verb，正是因为前一个 tag 是 modal verb。Tag 之间的依赖必须进 model。

### HMM：两张 table

Hidden Markov model 假设：tag sequence 是一个 Markov chain，每个 tag 再“生成”一个 word。

- Transition probability $a_{ij}=P(t_k=j\mid t_{k-1}=i)$，用 counts 估计。J&M：WSJ 里 MD（modal verb）出现 13,124 次，后面跟 VB 10,471 次，$P(\text{VB}\mid\text{MD})=10471/13124=0.80$。
- Emission probability $b_j(w)=P(w\mid t=j)$。13,124 个 MD 里有 4,046 个是 will，$P(\text{will}\mid\text{MD})=0.31$。

一句话和一串 tag 的 joint probability 是

$$P(w_{1:n},t_{1:n})=\prod_{k=1}^nP(w_k\mid t_k)\,P(t_k\mid t_{k-1})$$

要找的是给定 word 时最可能的 tag sequence。由 Bayes rule，$P(t\mid w)=P(w,t)/P(w)$，而 $P(w)$ 对所有候选 $t$ 都一样，所以只需要让 joint probability 最大。

### 枚举太多，逐个选又会错

5 个 word、7 个候选 tag，tag sequence 有 $7^5=16{,}807$ 种；30 个 word 是 $7^{30}\approx2.3\times10^{25}$ 种，枚举不可能。

逐个 word 选当前最好的 tag 又不对，下面的例子会给出具体的数。原因是：一个 tag 现在看起来好，可能让下一步付出很大代价。

### Viterbi：每个格子只留最好的 prefix

关键观察：设 $t_1,\dots,t_k$ 是“所有在第 $k$ 个位置以 tag $j$ 结尾的 sequence”里最好的那条，那么它的 prefix $t_1,\dots,t_{k-1}$ 一定是“在第 $k-1$ 个位置以 $t_{k-1}$ 结尾”的 sequence 里最好的。否则把 prefix 换成更好的那条，后面的 factor 不变，整条 sequence 就更好了，矛盾。

所以对每个位置 $k$、每个 tag $j$ 只需要记一个数，到这里为止最好 prefix 的 probability：

$$v_k(j)=\max_i\ v_{k-1}(i)\;a_{ij}\;b_j(w_k)$$

同时记下取到 max 的 $i$（backpointer）。最后一列取最大，沿 backpointer 往回走就是答案。每个位置要对 $T$ 个 tag 各比较 $T$ 个前驱，总共 $nT^2$ 次，5 个 word、7 个 tag 是 245 次。

用 J&M 的例子 Janet will back the bill，7 个 tag 是 NNP（proper noun）、MD、VB、JJ（adjective）、NN（noun）、RB（adverb）、DT（determiner）。两张 table 由 WSJ 估计，这里只摘要用到的 entry：

| emission | Janet | will | back | the | bill |
|---|---|---|---|---|---|
| NNP | 0.000032 | | | 0.000048 | |
| MD | | 0.308431 | | | |
| VB | | 0.000028 | 0.000672 | | 0.000028 |
| JJ | | | 0.000340 | | |
| NN | | 0.000200 | 0.000223 | | 0.002337 |
| RB | | | 0.010446 | | |
| DT | | | | 0.506099 | |

空格是 0。Transition 用到的有 $P(\text{NNP}\mid\texttt{<s>})=0.2767$、$P(\text{MD}\mid\text{NNP})=0.0110$、$P(\text{VB}\mid\text{MD})=0.7968$、$P(\text{RB}\mid\text{MD})=0.1698$、$P(\text{DT}\mid\text{VB})=0.2231$、$P(\text{DT}\mid\text{RB})=0.0479$、$P(\text{NN}\mid\text{DT})=0.4744$ 等。

**Janet。** 只有 NNP 的 emission 不为 0：$v_1(\text{NNP})=0.2767\times0.000032=8.85\times10^{-6}$。

**will。** 前一列只有 NNP 活着，所以 max 只有一个候选：

$$v_2(\text{MD})=8.85\times10^{-6}\times0.0110\times0.308431=3.00\times10^{-8}$$

同样 $v_2(\text{NN})=1.03\times10^{-10}$，$v_2(\text{VB})=2.23\times10^{-13}$。

**back。** 四个 tag 的 emission 不为 0。以 VB 为例，三个前驱各算一次：

$$\max\big(\underbrace{3.00\times10^{-8}\times0.7968}_{\text{from MD}},\ \underbrace{2.23\times10^{-13}\times0.0050}_{\text{from VB}},\ \underbrace{1.03\times10^{-10}\times0.0014}_{\text{from NN}}\big)=2.39\times10^{-8}$$

乘 emission 0.000672，$v_3(\text{VB})=1.61\times10^{-11}$，backpointer 指向 MD。RB 也是从 MD 来：$3.00\times10^{-8}\times0.1698\times0.010446=5.33\times10^{-11}$。JJ 和 NN 约 $5\times10^{-15}$。这一列最大的是 RB，比 VB 大三倍多。

**the。** $v_4(\text{DT})$ 的两个主要候选：

$$\underbrace{1.61\times10^{-11}\times0.2231}_{\text{from VB}}=3.59\times10^{-12},\qquad\underbrace{5.33\times10^{-11}\times0.0479}_{\text{from RB}}=2.55\times10^{-12}$$

VB 胜出。VB 后面接 DT 的 transition 比 RB 后面接 DT 大 4.7 倍，抵掉了它在上一列的劣势。$v_4(\text{DT})=3.59\times10^{-12}\times0.506099=1.82\times10^{-12}$。

**bill。** $v_5(\text{NN})=1.82\times10^{-12}\times0.4744\times0.002337=2.01\times10^{-15}$，远大于 $v_5(\text{VB})$。

从 NN 往回走：NN ← DT ← VB ← MD ← NNP，即 Janet/NNP will/MD back/VB the/DT bill/NN。

::fig[cs4248-viterbi] 每个格子是 $v_k(j)$（只画出不为 0 的）。粗线是最终的 backpointer 路径；虚线框标出 back 那一列的最大值 RB，它不在最优路径上。

:::wrong 每一列取 $v$ 最大的 tag，连起来就是答案
那一列的最大值只说明“到这里为止哪个 prefix 最好”，后面的 transition 还没算。逐列取最大会在 back 处选 RB，得到 NNP MD RB DT NN，它的 joint probability 是 $1.43\times10^{-15}$，比 Viterbi 给出的 $2.01\times10^{-15}$ 小。答案只能在最后一列确定之后，沿 backpointer 倒着读出来。
:::

:::edge Probability 连乘会 underflow
5 个 word 已经乘到 $10^{-15}$，平均每个 word 缩小约 3 个 order of magnitude。Double precision 能表示的最小正数约 $10^{-308}$，一百个 word 左右就会变成 0。实际实现对每个 factor 取 log，把乘法变成加法；log 是 increasing function，max 取在同一个位置，Viterbi 不受影响。
:::

:::edge HMM 只看 $P(\text{word}\mid\text{tag})$
训练里没见过的 word，在所有 tag 下 emission 都是 0，整列归零，Viterbi 无法进行。HMM 也用不上“以 -ed 结尾”“首字母大写”这类线索。CRF 和 neural tagger 把这些作为 feature 直接用于 $P(\text{tag}\mid\text{word})$，但在英语 POS tagging 上，J&M 报告 HMM、CRF、BERT 的 accuracy 都在 97% 左右。
:::

## [rnn] Neural language model、RNN 与 attention 的由来

:::skip
能写出 RNN language model 的 recurrence，能用 Jacobian 连乘说明 vanishing gradient，能说清 encoder-decoder 的 bottleneck，并对 3 个 encoder state 手算一次 attention，就可以去第 6 站。
:::

### Fixed-window neural language model

把第 3 站的 embedding 接到第 2 站的问题上：预测下一个 word 时，取前面 $n$ 个 word 的 embedding 拼成一个 vector，过一个 hidden layer，再对 vocabulary 做 softmax（Bengio 等人 2003）：

$$e=[e_{t-n};\dots;e_{t-1}],\qquad h=\tanh(We+b),\qquad\hat y=\mathrm{softmax}(Uh)$$

设训练里见过“green eggs and”，测试时遇到“green ham and”。两个 context 拼成的 $e$ 只在一处不同，而 ham 和 eggs 的 embedding 相近，所以 hidden layer 算出的 $h$ 相近，对下一个 word 的预测也相近：在一个 context 上学到的东西自动推广到相似的 context。在 counts 看来，“green ham and”是一个从没见过的 trigram。

Parameter 数也不再随 $n$ 爆炸。$|V|=10{,}000$ 时，4-gram 的 table 可能有 $10^{16}$ 个 entry；window model 取 3 个 word、$d=100$、hidden size 500，输入层只有 $3\times100\times500=150{,}000$ 个 weight，加一个 word 只多 50,000 个。

问题是 window 仍然固定。J&M 的例子：“The flights the airline was canceling were full”，要预测 were 而不是 was，必须看到 5 个 word 之前的 flights，中间还隔着单数的 airline。Window 开到多大都会遇到更远的依赖。

### RNN：同一组 weight 一步一步读

让 model 带一个 hidden state，每读一个 word 更新一次：

$$h_t=g(Uh_{t-1}+We_t),\qquad\hat y_t=\mathrm{softmax}(Vh_t)$$

$h_t$ 原则上概括了 $w_1,\dots,w_t$ 的全部信息，context 没有长度限制。每一步用的都是同一组 $U$、$W$、$V$，parameter 数和句子长度无关。

### Vanishing gradient：用数字看

原则上能记住，不等于训练得出来。$t$ 时刻的 loss 对 $k$ 时刻 hidden state 的 gradient，要经过中间每一步：

$$\frac{\partial h_t}{\partial h_k}=\prod_{j=k+1}^{t}\frac{\partial h_j}{\partial h_{j-1}}$$

先看只有一个数的 RNN：$h_j=\tanh(u\,h_{j-1}+w\,x_j)$。由 $\tanh'(z)=1-\tanh^2(z)$，

$$\frac{\partial h_j}{\partial h_{j-1}}=u\,(1-h_j^2)$$

取 $u=0.9$，hidden state 典型值 $h_j\approx0.5$，每一步的 factor 是 $0.9\times0.75=0.675$。

| 往回传的步数 | 5 | 10 | 20 | 50 |
|---|---|---|---|---|
| $0.675^{\,k}$ | 0.14 | 0.020 | $3.9\times10^{-4}$ | $2.9\times10^{-9}$ |

“were”的 loss 要告诉 model“这里取决于 5 步之前的 flights”，这个信号先被乘上 0.14；隔 20 个 word，就只剩万分之四。和近处的信号一比，远处的信号在 gradient 里几乎消失，model 分不清“远处没有依赖”和“有依赖但学不到”。

Vector 的情形是一样的：每一步的 Jacobian 是 $U^\top$ 乘一个 diagonal matrix（$\tanh'$），若它们的 norm 都不超过 $\beta<1$，连乘 $t-k$ 次后 norm 不超过 $\beta^{t-k}$，按 exponential 衰减。Factor 大于 1 时则按 exponential 爆炸，实践中用 gradient clipping：gradient 的 norm 超过 threshold 就按比例缩回来。

LSTM 针对的就是这个连乘。它另设一个 cell state，更新方式是相加：

$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$$

$f_t$ 是 forget gate，取值在 0 和 1 之间，由 network 自己决定。沿 cell state 往回传，每一步乘的是 $f_t$，不再有 $U$ 和 $\tanh'$；当 network 选择记住（$f_t\approx1$）时，信号可以几乎无损地传很多步。

### Encoder-decoder 与 bottleneck

翻译要把一个 sequence 变成另一个长度不同的 sequence。Encoder-decoder 用一个 RNN（encoder）读完源句，把最后的 hidden state $h_n$ 交给另一个 RNN（decoder），decoder 从它出发逐个生成译文。

这就是开头的第二次失败。源句的全部信息必须塞进 $h_n$ 这 $d$ 个数：5 个 word 是 $d$ 个数，50 个 word 也是 $d$ 个数。Decoder 生成第 30 个译词时，需要的往往是源句里某个特定的 word，它只能从这个大小固定的 vector 里挖。而源句开头的 word 要经过 $n$ 步 recurrence 才进入 $h_n$，又是上面那个连乘。

:::wrong 把 hidden size 加大就能解决 bottleneck
加大 $d$ 只是把固定的容量换成一个更大的固定容量，它仍然不随源句长度增长；源句第一个 word 到 decoder 的路径仍然要穿过 $n$ 步 recurrence。真正需要的是：源句有多长，decoder 能取用的信息就有多少；而且每个源 word 到 decoder 的路径长度与 $n$ 无关。下面的 attention 同时满足这两点：一个 50 个 word 的源句，decoder 可以取用 $50\times d$ 个数，每个 encoder state 一步直达。
:::

::fig[cs4248-bottleneck] 上：decoder 只能看到 encoder 的最后一个 state。下：decoder 每一步对所有 encoder state 做 weighted average，weight 每一步重新计算。

### Attention：每一步自己去源句里取

Decoder 在第 $i$ 步，用自己当前的 state $s$ 给每个 encoder state $h_j$ 打一个分（最简单的是 dot product），softmax 变成 weight，再对 encoder state 做 weighted average：

$$e_j=s\cdot h_j,\qquad\alpha_j=\frac{e^{e_j}}{\sum_{j'}e^{e_{j'}}},\qquad c_i=\sum_j\alpha_j\,h_j$$

$c_i$ 叫 context vector，和 $s$ 一起决定这一步输出什么。

手算一次。源句 the green witch，三个 encoder state 取成 2 维：

$$h_{\text{the}}=(1,\,0),\qquad h_{\text{green}}=(0.5,\,2),\qquad h_{\text{witch}}=(1.5,\,0.5)$$

Decoder 正要生成 verde，当前 state $s=(0,\,1)$。三个分数是 $0$、$2$、$0.5$。Softmax：$e^0=1$，$e^2=7.389$，$e^{0.5}=1.649$，合计 10.038，所以

$$\alpha=(0.100,\ 0.736,\ 0.164)$$

$$\begin{aligned}c&=0.100\,(1,0)+0.736\,(0.5,2)+0.164\,(1.5,0.5)\\&=(0.100+0.368+0.246,\ 0+1.472+0.082)=(0.714,\ 1.554)\end{aligned}$$

Context vector 大部分来自 green。Weight $\alpha$ 可以直接读成“这个译词对准了哪个源 word”，这就是 alignment。

:::edge RNN 本身还有一个问题：不能并行
$h_t$ 要等 $h_{t-1}$ 算完才能算，一句 1000 个 token 的话就是 1000 步串行，GPU 上大量计算单元闲着。Attention 本身没有这个限制：每个 weight 只依赖两个 vector。如果把 recurrence 整个拿掉、只留 attention，就得到第 6 站的 Transformer。
:::

:::from
Fixed-window model 的局限、RNN 的 recurrence、flights 的例子、encoder-decoder、“final state 必须表示源句的一切”、attention 的三个式子，来自 [SLP3 第 14 章](https://web.stanford.edu/~jurafsky/slp3/14.pdf)。Jacobian 连乘的写法、$\beta^{t-k}$ 的 bound、gradient clipping、Bengio 的 model，来自 [CS224N 2019 notes 05](https://web.stanford.edu/class/cs224n/readings/cs224n-2019-notes05-LM_RNN.pdf)；seq2seq 的 bottleneck 和 Bahdanau attention 来自 [notes 06](https://web.stanford.edu/class/cs224n/readings/cs224n-2019-notes06-NMT_seq2seq_attention.pdf)。“RNN 不能并行”来自 [CS224N 的 self-attention notes](https://web.stanford.edu/class/cs224n/readings/cs224n-self-attention-transformers-2023_draft.pdf)。$0.675^k$ 的表、parameter 数的对比、the green witch 的数值例子是我加的、算过的。
:::

## [attn] Self-attention 与 Transformer

:::skip
能对 3 个 token 手算 causal self-attention，能从 variance 推出 $1/\sqrt{d_k}$ 并用 softmax 的 Jacobian 说明不 scaling 的后果，能画出 pre-norm block 并数出 $12d^2$，就可以去第 7 站。
:::

### 把 attention 用在句子自己身上

第 5 站的 attention 是 decoder 去看 encoder。现在让句子里每个 token 去看同一句里的所有 token：J&M 的例子里，“because it was too tired”中的 it 要从 chicken 那里取信息，“because it was too wide”中的 it 要从 road 那里取。

每个 token 的 input vector $x_i$ 乘三个不同的 matrix，得到三个 vector：

$$q_i=x_iW^Q,\qquad k_i=x_iW^K,\qquad v_i=x_iW^V$$

$q_i$ 用来和别人的 $k_j$ 比较、决定 weight，$v_j$ 是被 weighted average 的内容。分成三个是因为“决定看谁”和“取走什么”是两件事，用同一个 vector 会把它们绑死。Token $i$ 的 output：

$$a_i=\sum_j\alpha_{ij}\,v_j,\qquad\alpha_{ij}=\mathrm{softmax}_j\Big(\frac{q_i\cdot k_j}{\sqrt{d_k}}\Big)$$

$\sqrt{d_k}$ 的来历下一小节讲。任意两个位置之间只隔一步，所有位置可以同时算。

### 3 个 token 手算

取 $d=d_k=2$，三个 token 的 input 叠成 matrix $X$ 的三个 row，$W^K$ 和 $W^V$ 取 identity matrix：

$$X=\begin{pmatrix}1&0\\0&2\\1&1\end{pmatrix},\qquad W^Q=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad Q=XW^Q=\begin{pmatrix}1&1\\0&2\\1&2\end{pmatrix},\qquad K=V=X$$

所有 pair 的 $q_i\cdot k_j$ 就是 $QK^\top$：

$$QK^\top=\begin{pmatrix}1&2&2\\0&4&2\\1&4&3\end{pmatrix},\qquad\frac{QK^\top}{\sqrt2}=\begin{pmatrix}0.707&1.414&1.414\\0&2.828&1.414\\0.707&2.828&2.121\end{pmatrix}$$

Language model 预测第 $i+1$ 个 token 时只能用前 $i$ 个，否则答案就在 input 里。所以把 $j>i$ 的 entry 换成 $-\infty$（causal mask），softmax 之后它们的 weight 是 $e^{-\infty}=0$：

$$\begin{pmatrix}0.707&-\infty&-\infty\\0&2.828&-\infty\\0.707&2.828&2.121\end{pmatrix}$$

Row 1 只剩自己，weight 是 1。Row 2：$e^0=1$，$e^{2.828}=16.92$，合计 17.92，weight 是 $(0.056,\,0.944)$。Row 3：$e^{0.707}=2.028$，$e^{2.828}=16.92$，$e^{2.121}=8.342$，合计 27.29，weight 是 $(0.074,\,0.620,\,0.306)$。

Output 是 weight 乘 $V$：

$$a_1=(1,\,0),\qquad a_2=0.056\,(1,0)+0.944\,(0,2)=(0.056,\,1.888)$$

$$a_3=0.074\,(1,0)+0.620\,(0,2)+0.306\,(1,1)=(0.380,\,1.546)$$

整个过程写成一行是 $\mathrm{softmax}\big(\mathrm{mask}(QK^\top/\sqrt{d_k})\big)V$。

::fig[cs4248-attn3] 三个 token 的 attention weight。每个 row 是一个 query，合计为 1；对角线右上方被 mask 掉。

Mask 还带来一个好处：一个长度 $T$ 的 sequence 一次 forward pass 就同时得到 $T$ 个位置的预测，每个位置都只看到了自己之前的 token，相当于一次给出 $T$ 个 training example。Karpathy 在 Let's build GPT 里用的正是这个写法：先造一个 lower triangular 的 matrix，把上三角填成 $-\infty$，再做 softmax。

### 为什么除以 $\sqrt{d_k}$

设 $q$ 和 $k$ 的各个 component 互相 independent，mean 0，variance 1（initialization 时大致如此）。

$$q\cdot k=\sum_{m=1}^{d_k}q_mk_m,\qquad\mathrm{E}[q_mk_m]=0,\qquad\mathrm{Var}(q_mk_m)=\mathrm{E}[q_m^2]\,\mathrm{E}[k_m^2]=1$$

$d_k$ 个 independent term 相加，variance 是 $d_k$，standard deviation 是 $\sqrt{d_k}$。$d_k=64$ 时，score 的 standard deviation 是 8。

Score 的差距放大 8 倍，softmax 会变成什么样？Karpathy 的例子：

$$\mathrm{softmax}(0.1,\,-0.2,\,0.3,\,-0.2,\,0.5)=(0.192,\,0.143,\,0.235,\,0.143,\,0.287)$$

$$\mathrm{softmax}(0.8,\,-1.6,\,2.4,\,-1.6,\,4.0)=(0.033,\,0.003,\,0.162,\,0.003,\,0.800)$$

几乎变成 one-hot。这对 training 的害处在 gradient。$p_i=e^{s_i}/\sum_me^{s_m}$，对 $s_j$ 求 derivative：

$$\frac{\partial p_i}{\partial s_j}=\frac{e^{s_i}\delta_{ij}\sum_me^{s_m}-e^{s_i}e^{s_j}}{\big(\sum_me^{s_m}\big)^2}=p_i\,\delta_{ij}-p_i\,p_j$$

即 Jacobian $=\mathrm{diag}(p)-pp^\top$。当 $p$ 接近 one-hot，比如 $p_1=1-\epsilon$，diagonal entry $p_1(1-p_1)\approx\epsilon$，其余 $p_i$ 都小于 $\epsilon$，Jacobian 的每个 entry 都趋于 0。Score 再怎么变，weight 也几乎不动，gradient 传不回 $W^Q$ 和 $W^K$。

模拟一下看规模：query 对 8 个 key，$q,k$ 的 component 都是 standard normal，各重复两万次取平均（seed 固定）：

| $d_k$ | 4 | 16 | 64 | 256 | 1024 |
|---|---|---|---|---|---|
| 不 scaling：最大 weight | 0.53 | 0.75 | 0.88 | 0.94 | 0.97 |
| 不 scaling：Jacobian 的 Frobenius norm | 0.34 | 0.25 | 0.15 | 0.085 | 0.041 |
| 除以 $\sqrt{d_k}$：最大 weight | 0.34 | 0.36 | 0.36 | 0.36 | 0.36 |
| 除以 $\sqrt{d_k}$：Jacobian 的 Frobenius norm | 0.36 | 0.36 | 0.37 | 0.37 | 0.37 |

::fig[cs4248-softmax] 上表画成图。不 scaling 时，$d_k$ 越大 softmax 越接近 one-hot、gradient 越小；除以 $\sqrt{d_k}$ 之后两者都与 $d_k$ 无关。

除以 $\sqrt{d_k}$ 把 score 的 variance 拉回 1，softmax 的行为从此不依赖 $d_k$。

:::wrong 除以 $\sqrt{d_k}$ 是为了防止 $e^x$ overflow
Overflow 另有办法，而且不改变结果：softmax 对所有 score 同时减去一个常数不变，因为分子分母同乘 $e^{-c}$。实现里总是先减去最大的 score，最大的 exponent 变成 $e^0=1$，不会 overflow。上面乘 8 的例子减去最大值 4.0 后是 $(e^{-3.2},\,e^{-5.6},\,e^{-1.6},\,e^{-5.6},\,1)$，数值完全安全，最大 weight 仍是 0.800。Scaling 要解决的是 saturation：distribution 太尖，gradient 消失。
:::

### Self-attention 不知道顺序

去掉 mask，把第 1 个和第 3 个 token 交换位置再算一遍。原来的三个 output 是

$$a_1=(0.599,\,1.203),\qquad a_2=(0.232,\,1.723),\qquad a_3=(0.380,\,1.546)$$

交换后得到的三个 output 依次是 $(0.380,\,1.546)$、$(0.232,\,1.723)$、$(0.599,\,1.203)$：还是那三个 vector，跟着 token 换了位置。原因是每个 output 只依赖“自己的 query”和“所有 token 的 key、value 组成的集合”，集合没有顺序。于是“dog bites man”和“man bites dog”在 self-attention 看来，每个 word 收到的信息完全一样。

所以必须把位置信息加进去。最简单的是给每个位置 $i$ 学一个 position embedding $p_i$，input 改成 $x_i+p_i$；原始 Transformer 用固定的 sine、cosine function。现在多数 LLM 用 RoPE：把 $q$ 和 $k$ 的每两个 component 看成一个 plane 上的点，按位置旋转，位置 $i$ 转 $i\theta$ 角。Rotation matrix $R(\phi)$ 是 orthogonal 的，$R(a)^\top R(b)=R(b-a)$，所以

$$\big(R(i\theta)q\big)^\top\big(R(j\theta)k\big)=q^\top R(i\theta)^\top R(j\theta)\,k=q^\top R\big((j-i)\theta\big)\,k$$

Score 只取决于两个 token 的相对距离 $j-i$，和它们在句子里的绝对位置无关。

### 一个 block 里还有什么

**Multi-head。** 一个 softmax 只能产生一组 weight。把 $d$ 维拆成 $A$ 个 head，每个 head 的 $d_k=d/A$，各自有 $W^Q,W^K,W^V$、各自做 softmax，output 拼起来再乘 $W^O$。原始 Transformer 是 $d=512$、$A=8$、$d_k=64$。各 head 的 $W^Q$ 合起来仍是 $d\times d$，加上 $W^K,W^V,W^O$，attention 共 $4d^2$ 个 parameter，和单个 head 一样。

**Feedforward network。** Attention 的 output 只是 value 的 weighted average，value 又是 input 的 linear function。CS224N 的 notes 指出，叠两层不带 nonlinearity 的 attention，结果仍然是某组 weight 乘 $V^{(2)}V^{(1)}x$，还是 weighted average。所以每个 block 在每个位置上单独加一个两层 network：

$$\mathrm{FFN}(x)=W_2\,\mathrm{ReLU}(W_1x+b_1)+b_2,\qquad W_1\in\mathbb R^{4d\times d},\ W_2\in\mathbb R^{d\times4d}$$

**Residual connection 与 LayerNorm。** 每个 sublayer 的 output 加回它的 input，形成一条贯穿所有层的 residual stream。LayerNorm 把一个 token 的 $d$ 个数减去 mean、除以 standard deviation，再乘一个学到的 gain。现在的 LLM 多用 pre-norm：

$$h=x+\mathrm{MultiHeadAttention}\big(\mathrm{LN}(x)\big),\qquad\text{out}=h+\mathrm{FFN}\big(\mathrm{LN}(h)\big)$$

对比第 5 站的连乘：$\partial\,\text{out}/\partial x$ 里总有一项 identity matrix，gradient 至少可以沿这条加法通路原样传回去，不必穿过每一层的 Jacobian。

::fig[cs4248-block] Pre-norm Transformer block。中间的竖线是 residual stream，两个 sublayer 读一份 normalize 过的副本，把结果加回去。

数一下 parameter。每层 attention $4d^2$，FFN $d\times4d+4d\times d=8d^2$，合计 $12d^2$（忽略 bias 和 LayerNorm）。$L$ 层是 $12Ld^2$。

- GPT-3：$L=96$，$d=12288$，$12\times96\times12288^2=1.74\times10^{11}$，正是它的 175B。
- GPT-2 small：$L=12$，$d=768$，$12\times12\times768^2=84.9\text{M}$；token embedding $50257\times768=38.6\text{M}$，position embedding $1024\times768=0.8\text{M}$，合计 124.3M，正是常说的 124M。

### 代价：长度的平方

Attention 要算 $n\times n$ 个 score。一层的 FLOPs（一次 multiply 加一次 add 算 2）：$QK^\top$ 是 $2n^2d$，乘 $V$ 又是 $2n^2d$，共 $4n^2d$；四个 projection 是 $4\times2nd^2=8nd^2$，FFN 是 $2\times2n\cdot4d^2=16nd^2$，共 $24nd^2$。两者之比

$$\frac{4n^2d}{24nd^2}=\frac{n}{6d}$$

$d=4096$ 时，sequence 超过 $6\times4096=24{,}576$ 个 token，attention 才开始比其余部分贵。Context 长度翻倍，attention 这部分变成 4 倍。这也是第 1 站说 sequence 不能太长的原因。

:::back
Attention 的公式就是[第 5 站](#rnn)的那一个，只是 query、key、value 都来自同一个 sequence。Residual stream 治的是第 5 站的连乘。
:::

## [pretrain] Pretraining、scaling law 与 decoding

:::skip
能把 loss 换算成 perplexity，能用 $6ND$ 估计 compute，能由 Chinchilla 的 fit 推出 compute-optimal 的 $N$ 和 $D$，能手算 temperature 和 top-p，就可以去第 8 站。
:::

### Objective：next-token cross-entropy

Pretraining 用的是最朴素的 objective：在大量文本上，每个位置预测下一个 token。

$$L=\frac1T\sum_{t=1}^T-\log\hat y_t[w_{t+1}]$$

$\hat y_t$ 是 model 在位置 $t$ 输出的 distribution，$\hat y_t[w_{t+1}]$ 是它给真实下一个 token 的 probability。不需要任何人工 label，文本自己就是答案，所以叫 self-supervised。Training 时每个位置喂的都是真实的前文，不是 model 自己生成的，这叫 teacher forcing。

两个换算随手可用。第一，perplexity $=e^L$：loss 3.0 对应 perplexity 20.1。第二，initialization 时 model 对 GPT-2 的 50,257 个 token 大致均匀，loss 应该在 $\ln50257=10.82$ 附近；第一步的 loss 偏离这个数很多，多半是代码有 bug。

为什么偏偏是 cross-entropy？设真实文本的 distribution 是 $p$，model 是 $q$：

$$\mathrm{E}_{w\sim p}[-\log q(w)]=\underbrace{\mathrm{E}_{p}[-\log p(w)]}_{H(p)}+\underbrace{\mathrm{E}_{p}\Big[\log\frac{p(w)}{q(w)}\Big]}_{\mathrm{KL}(p\,\|\,q)}$$

$H(p)$ 与 model 无关，所以最小化 cross-entropy 就是最小化 $q$ 到 $p$ 的 KL divergence，也就是 maximum likelihood。KL 不小于 0，所以 loss 永远降不到 $H(p)$ 以下：文本本身的不确定性是一个下限。下面的 scaling law 里那个常数 $E$ 就是它。

### 另一种 objective：masked language model

BERT 这类 encoder 的做法是随机遮住一部分 token（BERT 是 15%），让 model 同时看左右两边去猜被遮的 token，不用 causal mask。理解一个 word 时两边的 context 都有用，所以它在 classification、tagging 上表现好。代价有两个。一是每个 sequence 只有被遮的那 15% 产生 loss，而 causal model 的每个位置都产生 loss。二是它不能从左到右逐个生成，因为 training 时每个预测都看到了右边。现在的 LLM 都是 causal 的 decoder-only model。

### 要算多少：$6ND$

一个 $m\times n$ matrix 乘 $n\times p$ matrix，每个 output entry 要 $n$ 次乘法和 $n$ 次加法，共 $2mnp$ 次 floating-point operation（FLOP）。一个 token 过一个 $d_{\text{in}}\times d_{\text{out}}$ 的 linear layer，就是 $2d_{\text{in}}d_{\text{out}}$ FLOP，恰好是 parameter 数的 2 倍。Model 的 parameter 几乎全在 linear layer 里，所以 forward pass 每个 token 约 $2N$ FLOP（$N$ 是 parameter 数，忽略上一站那个只在长 context 下才显著的 $n^2$ 项）。

Backward pass 对每个 linear layer 要算两个 gradient：对 input 的（传给下一层）和对 weight 的（用来 update），各是一次同样大小的 matrix 乘法，共 $4N$。合起来每个 token $6N$，training $D$ 个 token：

$$C\approx6ND$$

CS336 第 2 讲的估算：70B 的 model 训练 15T 个 token，$C=6\times70\times10^9\times15\times10^{12}=6.3\times10^{24}$ FLOP。一块 H100 的 bf16 峰值约 $989\times10^{12}$ FLOP/s，实际能用上一半（MFU 0.5），1024 块：

$$\frac{6.3\times10^{24}}{989\times10^{12}\times0.5\times1024}=1.24\times10^7\ \text{s}\approx144\ \text{天}$$

### Scaling law：给定 compute，model 多大、data 多少

Compute $C$ 定了以后，$6ND=C$ 还留一个选择：大 model 少看 data，还是小 model 多看 data。在最大的 model 上试错太贵，所以先在一系列小 model 上拟合 loss 随 $N$、$D$ 变化的规律，再外推。Chinchilla（Hoffmann 等人 2022）拟合出

$$L(N,D)=1.69+\frac{406.4}{N^{0.34}}+\frac{410.7}{D^{0.28}}$$

第一项是上面说的下限 $E$；第二项是 model 有限造成的额外 loss，$N$ 越大越小；第三项是 data 有限造成的。

拿它比较两个 compute 相近的 model：

| model | $N$ | $D$ | $6ND$ | $406.4/N^{0.34}$ | $410.7/D^{0.28}$ | 预测的 $L$ |
|---|---|---|---|---|---|---|
| Gopher | 280B | 300B | $5.0\times10^{23}$ | 0.052 | 0.251 | 1.993 |
| Chinchilla | 70B | 1.4T | $5.9\times10^{23}$ | 0.083 | 0.163 | 1.937 |

Gopher 把 compute 都花在 model 上，model 那一项已经很小，data 那一项却很大。Chinchilla 缩小 4 倍、多看 4.7 倍的 data，两项都不大，总 loss 更低。

最优的分配可以推出来。把 $D=C/(6N)$ 代入：

$$L(N)=E+AN^{-\alpha}+B\Big(\frac{6N}{C}\Big)^{\beta}$$

对 $N$ 求 derivative 令其为 0：

$$-\alpha AN^{-\alpha-1}+\beta B\Big(\frac6C\Big)^{\beta}N^{\beta-1}=0\quad\Rightarrow\quad N^{\alpha+\beta}=\frac{\alpha A}{\beta B}\Big(\frac C6\Big)^{\beta}$$

$$N_{\text{opt}}=G\Big(\frac C6\Big)^{\frac{\beta}{\alpha+\beta}},\qquad D_{\text{opt}}=G^{-1}\Big(\frac C6\Big)^{\frac{\alpha}{\alpha+\beta}},\qquad G=\Big(\frac{\alpha A}{\beta B}\Big)^{\frac1{\alpha+\beta}}$$

代入 $\alpha=0.34$、$\beta=0.28$，两个 exponent 是 0.45 和 0.55，接近各一半：compute 每多 100 倍，model 多 $100^{0.45}\approx8$ 倍，data 多 $100^{0.55}\approx13$ 倍。把上面令 derivative 为 0 的那个式子两边乘 $N$，得到 $\alpha A/N^\alpha=\beta B/D^\beta$：在最优点，model 那一项和 data 那一项按 exponent 加权后相等，哪一项都不该被单独压得很低。

::fig[cs4248-isoflop] 按上面的 fit 画的 iso-FLOP curve：每条 curve 固定 $C$，横轴是 $N$（$D$ 随之等于 $C/6N$），每条都有一个最低点。彩色那条是论文给 Gopher 和 Chinchilla 的共同 compute $5.76\times10^{23}$：在它上面，70B 比最低点只高 0.007，280B 高 0.053。

论文 Table 3 用另一种方法（取各个 run 的最小值）直接给出了最优配置：1B parameter 配 20.2B token，10B 配 205B，67B 配 1.5T，大约每个 parameter 20 个 token。CS336 第 9 讲列出的实际 model：GPT-3 每个 parameter 2 个 token，Chinchilla 20，Llama 3 70B 是 215。Llama 3 远超“最优”，因为 compute-optimal 只考虑 training；model 训练好后要被调用无数次，inference 的 cost 跟 $N$ 成正比，用更多 data 训练一个更小的 model 更划算。

:::edge 这个 fit 给出的最优点和 Table 3 对不上
把 $C=5.76\times10^{23}$ 代入上面的 $N_{\text{opt}}$ 公式，得到约 32B parameter、3.0T token，每个 parameter 93 个 token，而 Table 3 在同样的 compute 下是 67B 和 1.5T。论文里三种方法的 exponent 也不完全一样（model 那一项分别是 0.50、0.49、0.46）。CS336 第 9 讲指出第三种方法（就是这里的 parametric fit）的原始拟合很可能有问题，Besiroglu 等人 2024 年重新拟合后更接近前两种方法。所以这个 fit 用来理解形状和比较 Gopher、Chinchilla 可以，具体的最优 $N$ 以 Table 3 为准。
:::

### Decoding：从 distribution 到一个 token

Model 每一步给出 distribution，生成时还要决定取哪个。设某一步四个候选 token 的 logit 是 $(2.0,\,1.0,\,0.5,\,-1.0)$。

$e^{2.0}=7.389$，$e^{1.0}=2.718$，$e^{0.5}=1.649$，$e^{-1.0}=0.368$，合计 12.124，softmax 是 $(0.609,\,0.224,\,0.136,\,0.030)$。

**Greedy decoding** 每步取最大的那个。J&M 指出它生成的文本平淡、容易重复：每一步都选最常见的说法，整句就是最常见说法的堆砌，还容易陷进循环。

**Temperature。** 把 logit 除以 $\tau$ 再 softmax。$\tau<1$ 拉大差距，$\tau>1$ 缩小差距：

| $\tau$ | 四个 token 的 probability |
|---|---|
| 0.5 | $(0.842,\ 0.114,\ 0.042,\ 0.002)$ |
| 1 | $(0.609,\ 0.224,\ 0.136,\ 0.030)$ |
| 2 | $(0.434,\ 0.263,\ 0.205,\ 0.097)$ |

$\tau\to0$ 就是 greedy，$\tau\to\infty$ 是 uniform。

**Top-p（nucleus）sampling。** 只在“probability 从大到小累加，刚好达到 $p$ 的那些 token”里抽，去掉长尾里的怪 token。取 $p=0.9$、$\tau=1$：$0.609<0.9$，$0.609+0.224=0.833<0.9$，再加 $0.136$ 得 $0.970\ge0.9$，留下前三个。重新 normalize：$(0.628,\,0.231,\,0.140)$。

:::wrong Perplexity 低的 model 就是更好的 model
在同一个 tokenizer 下比较是对的，换了 tokenizer 就不能直接比。Perplexity 是“每个 token”的平均，token 的大小不同，同一段文本被切成的 token 数就不同。设一段 1000 个 byte 的文本：model A 的 tokenizer 切成 250 个 token，平均 loss 3.0，perplexity $e^{3}=20.1$；model B 切成 400 个 token，平均 loss 2.0，perplexity $e^2=7.4$。B 看起来好得多。但整段文本的 total loss，A 是 $250\times3.0=750$，B 是 $400\times2.0=800$：A 给整段文本的 probability 更高。按每个 byte 算，A 是 $750/1000/\ln2=1.08$ bits per byte，B 是 1.15。跨 tokenizer 比较要用这种以 byte 或 character 为单位的指标。
:::

Cross-entropy loss、teacher forcing、perplexity 与 loss 的关系、greedy、temperature、top-p 的定义来自 [SLP3 第 7 章](https://web.stanford.edu/~jurafsky/slp3/7.pdf)。$2mnp$、forward $2N$、backward $4N$、70B 训练 15T token 的估算方法（H100 的峰值、MFU 0.5、1024 块）来自 [CS336 lecture_02.py](https://github.com/stanford-cs336/spring2025-lectures/blob/main/lecture_02.py)，页面没有印出最后的天数，144 天是我按它的式子算的。“在小 model 上拟合再外推”的动机、三种拟合方法、第三种方法可能有问题、各 model 每个 parameter 的 token 数，来自 [CS336 第 9 讲 slides](https://stanford-cs336.github.io/spring2025-lectures/nonexecutable/2025%20Lecture%209%20-%20Scaling%20laws%20basics.pdf)。Fit 的常数、$N_{\text{opt}}$ 的公式、Table 3、Gopher 与 Chinchilla 的配置来自 [Chinchilla 论文](https://ar5iv.labs.arxiv.org/html/2203.15556)。BERT 那一小节是凭我自己的知识写的，没有读 J&M 第 9 章或 BERT 论文。KL 分解、$N_{\text{opt}}$ 的推导步骤、表中的预测 loss、decoding 的数值例子、bits per byte 的例子是我加的、算过的。

## [post] Post-training：SFT、RLHF、DPO、LoRA 与 RAG

:::skip
能写出 Bradley–Terry model；能从 KL-regularized objective 推出 optimal policy 并进一步推出 DPO loss；能数出 LoRA 的 parameter 数；能说清 RAG 改变的是 input 而不是 weight，就读完这门课了。
:::

### Pretrained model 为什么不回答问题

开头的第三次失败。Pretraining 的 objective 是“续写网上的文本”。网上一个问题后面常常跟着另一个问题（论坛、试卷、FAQ 列表），所以 model 续写出一个相似的问题，完全符合它被训练的目标。J&M 第 8 章的例子正是这样：早期 GPT 被问一个问题，回答是另一个相关的问题。Model 的知识没有问题，它不知道现在的任务是“回答”。

**Instruction tuning（supervised fine-tuning，SFT）** 是最直接的修补：收集大量 (instruction, response) pair，接着用同样的 next-token cross-entropy 训练，只是 loss 只算 response 的 token。比如 prompt 有 5 个 token、response 有 3 个，loss 是 response 那 3 个位置的平均；prompt 的位置照样参与 attention，但不产生 loss，否则 model 会同时学着“生成用户的提问”。这一步的数据量是几百万条量级，远小于 pretraining。

### SFT 不够的地方

CS224N 的 post-training 一讲列了三点。Demonstration 要人写，贵。开放式的任务（写一个故事）没有唯一正确的答案，SFT 却把一条 response 当成标准答案逐 token 去逼近。Token-level 的 loss 对所有偏差一视同仁，而有的错（事实错误）比有的错（换一个同义词）严重得多。

人写一个好答案很难，比较两个答案哪个更好却容易得多，判断也更一致。于是改收集 preference data：同一个 prompt $x$，两个 response，标出更好的 $y_w$ 和更差的 $y_l$。

### Bradley–Terry model 与 reward model

假设每个 response 有一个 scalar 分数 $r(x,y)$，人偏好 $y_w$ 的 probability 是

$$P(y_w\succ y_l\mid x)=\sigma\big(r(x,y_w)-r(x,y_l)\big)$$

分数差 1，偏好的 probability 是 $\sigma(1)=0.731$；差 0 是 0.5。这就是对分数差做 logistic regression。Reward model 从一个 pretrained LM 初始化，把输出 vocabulary 的那一层换成输出一个数，loss 是

$$L_{\text{RM}}=-\mathrm{E}\big[\log\sigma\big(r(x,y_w)-r(x,y_l)\big)\big]$$

注意 probability 只依赖分数的差：所有 $r(x,\cdot)$ 同时加一个只和 $x$ 有关的常数，什么都不变。DPO 会用到这一点。

### RLHF 的 objective 和它的 closed-form solution

有了 reward model，就去调 policy $\pi$（即 LM 本身），让它生成的 response 的 reward 高。但 reward model 只是对人类偏好的近似，任由 policy 去最大化它，policy 会找到 reward model 打分虚高的怪 response，这叫 reward hacking。所以加一个惩罚，不许 policy 离初始的 $\pi_{\text{ref}}$（通常是 SFT model）太远：

$$\max_\pi\ \mathrm{E}_{y\sim\pi}\big[r(x,y)\big]-\beta\,\mathrm{KL}\big(\pi\,\|\,\pi_{\text{ref}}\big)$$

这个 objective 的最优解可以直接写出来。把 KL 展开，objective 是

$$\sum_y\pi(y)\Big[r(y)-\beta\log\frac{\pi(y)}{\pi_{\text{ref}}(y)}\Big]=-\beta\sum_y\pi(y)\log\frac{\pi(y)}{\pi_{\text{ref}}(y)\,e^{r(y)/\beta}}$$

（省略了 $x$。）分母不是 distribution，除以它的总和 $Z=\sum_y\pi_{\text{ref}}(y)e^{r(y)/\beta}$ 就是了。定义

$$\pi^*(y)=\frac{1}{Z}\,\pi_{\text{ref}}(y)\,e^{r(y)/\beta}$$

则分母等于 $Z\pi^*(y)$，objective 变成

$$-\beta\sum_y\pi(y)\log\frac{\pi(y)}{\pi^*(y)}+\beta\log Z=-\beta\,\mathrm{KL}(\pi\,\|\,\pi^*)+\beta\log Z$$

$\beta\log Z$ 与 $\pi$ 无关，KL 不小于 0、只在 $\pi=\pi^*$ 时为 0。所以 $\pi^*$ 就是最优 policy：在 $\pi_{\text{ref}}$ 的基础上，按 $e^{r/\beta}$ 重新加权。

算一个例子。三个 response，$\pi_{\text{ref}}=(0.5,\,0.3,\,0.2)$，reward $r=(0,\,1,\,2)$，$\beta=1$：

$$\pi_{\text{ref}}\,e^{r}=(0.5\times1,\ 0.3\times2.718,\ 0.2\times7.389)=(0.500,\ 0.815,\ 1.478),\qquad Z=2.793$$

$$\pi^*=(0.179,\ 0.292,\ 0.529)$$

换几个 $\beta$：

| $\beta$ | $\pi^*$ | expected reward | $\mathrm{KL}(\pi^*\|\pi_{\text{ref}})$ |
|---|---|---|---|
| 0.5 | $(0.037,\ 0.163,\ 0.801)$ | 1.76 | 0.92 |
| 1 | $(0.179,\ 0.292,\ 0.529)$ | 1.35 | 0.32 |
| 2 | $(0.325,\ 0.322,\ 0.353)$ | 1.03 | 0.08 |
| $\infty$ | $(0.5,\ 0.3,\ 0.2)$ | 0.70 | 0 |

::fig[cs4248-dpo] 同一个 $\pi_{\text{ref}}$ 和 reward，不同 $\beta$ 下的最优 policy。$\beta$ 越小越贪 reward，离 $\pi_{\text{ref}}$ 越远。

实际中 $y$ 是所有可能的 string，$Z$ 没法算，$\pi^*$ 也就没法直接写出。经典的 RLHF 用 PPO 这类 RL algorithm 去逼近它：从当前 policy sample response，用 reward model 打分，再按 policy gradient 更新。这要同时在 memory 里放 policy、reference、reward model 和一个 value model，sampling 慢，对 hyperparameter 敏感。

### DPO：把 reward 写成 policy

上面的 $\pi^*$ 公式可以反过来解出 reward。两边取 log：

$$\log\pi^*(y)=\log\pi_{\text{ref}}(y)+\frac{r(y)}{\beta}-\log Z\quad\Rightarrow\quad r(y)=\beta\log\frac{\pi^*(y)}{\pi_{\text{ref}}(y)}+\beta\log Z$$

拿例子核对（$\beta=1$，第三个 response）：$\log(0.529/0.2)+\log2.793=0.973+1.027=2.000$，正是它的 reward。

这说明：每一个 policy 都对应着一个“以它为最优解”的 reward。把这个关系代入 Bradley–Terry model，$\beta\log Z$ 在两个 response 的差里抵消，这正是上面“只依赖分数差”那一点：

$$P(y_w\succ y_l\mid x)=\sigma\Big(\beta\log\frac{\pi(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)}-\beta\log\frac{\pi(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\Big)$$

右边不再含 reward，也不含 $Z$，只含 policy 自己的 log-probability。直接对 preference data 做 maximum likelihood，就是 Direct Preference Optimization 的 loss：

$$L_{\text{DPO}}(\pi_\theta)=-\mathrm{E}_{(x,y_w,y_l)}\Big[\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)}-\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\Big)\Big]$$

不需要单独的 reward model，不需要在 training 中 sample，memory 里只有 $\pi_\theta$ 和 $\pi_{\text{ref}}$ 两个 model。$\beta$ 通常取 0.01 到 0.1。

括号里的量叫 margin，记作 $m$。开始时 $\pi_\theta=\pi_{\text{ref}}$，$m=0$，loss 是 $\ln2=0.693$。对 $m$ 的 derivative 是 $-\big(1-\sigma(m)\big)=-\sigma(-m)$：model 把这对 response 排错（$m<0$）时 gradient 大，排对了而且 margin 已经大时 gradient 趋于 0。

:::wrong DPO 就是提高 preferred response 的 probability
DPO 的 loss 只看 margin，两个 probability 可以一起下降。设 $\pi_{\text{ref}}(y_w)=0.2$、$\pi_{\text{ref}}(y_l)=0.5$，$\beta=0.1$。Training 之后 $\pi_\theta(y_w)=0.15$、$\pi_\theta(y_l)=0.1$，preferred response 的 probability 反而降了：

$$m=0.1\Big(\ln\frac{0.15}{0.2}-\ln\frac{0.1}{0.5}\Big)=0.1\,(-0.288+1.609)=0.132$$

$$L=-\log\sigma(0.132)=0.629<0.693$$

Loss 照样下降了。被两个 response 让出来的 probability 去了数据里没有的 response，那里可能有好的，也可能有坏的。所以 DPO 训练中常看到 chosen response 的 log-probability 也在下降，这是 objective 本身允许的。
:::

### LoRA：只训练一个 low-rank 的改动

Full fine-tuning 的 memory 账：用 AdamW、float32 时，每个 parameter 要存 parameter、gradient 和两个 optimizer state，共 16 byte（CS336 第 2 讲）。7B model 就是 $7\times10^9\times16=112$ GB，还没算 activation，一块 80 GB 的 H100 装不下。

LoRA 的做法：pretrained weight $W\in\mathbb R^{d\times k}$ 冻结不动，只学一个 rank 为 $r$ 的改动：

$$W'=W+BA,\qquad B\in\mathbb R^{d\times r},\quad A\in\mathbb R^{r\times k},\quad r\ll\min(d,k)$$

要学的 parameter 是 $r(d+k)$ 个。$d=k=4096$、$r=8$ 时，$2\times4096\times8=65{,}536$ 个，而 $W$ 本身有 $4096^2=16{,}777{,}216$ 个，只占 0.39%。对一个 32 层的 model，每层的 $W^Q$ 和 $W^V$ 各加一个 LoRA，共 $32\times2\times65{,}536=4.19$M 个可训练 parameter，按 16 byte 算是 67 MB；冻结的 7B weight 用 bf16 存，14 GB。

::fig[cs4248-lora] LoRA 的形状。$W$ 冻结；改动 $BA$ 的 rank 不超过 $r$，parameter 数是 $r(d+k)$ 而不是 $dk$。

为什么 low-rank 够用？CS224N 的 PEFT 一讲引用的论证是：fine-tuning 对 weight 的改动本身具有很低的“intrinsic rank”，大量 parameter 并不需要各自独立地动。$B$ 通常初始化为 0，这样 training 开始时 $W'=W$，恰好是 pretrained model（这一点是 LoRA 原论文的做法，那一讲的 slides 没有讲）。训练完可以把 $BA$ 加进 $W$，inference 不多任何计算；换任务时减去 $BA$ 再加上另一组 $B'A'$。

### RAG：不改 weight，改 input

Fine-tuning 改变 model 的 weight。有三类问题它解决不好：model 发布之后的新信息；不在公开数据里的私有文档（公司内部资料、个人邮件）；以及 hallucination，J&M 第 11 章引的一项研究发现 LLM 在法律问题上的 hallucination rate 在 69% 到 88% 之间。Retrieval-augmented generation 的做法是：先从一个文档库里 retrieve 出和问题最相关的 $k$ 段，把它们放进 prompt，再让 model 根据这些文本回答。

$$p(y_1,\dots,y_n)=\prod_ip\big(y_i\mid\text{retrieved passages};\ \text{question};\ y_{<i}\big)$$

Retrieval 的核心是给 (query, document) 打分。最经典的是 tf-idf 加 cosine。一个 term 在 document 里出现得多，tf 大；它在整个文档库里出现得少，idf 大，说明它有区分度：

$$\mathrm{tf}_{t,d}=1+\log_{10}\mathrm{count}(t,d),\qquad\mathrm{idf}_t=\log_{10}\frac{N}{\mathrm{df}_t}$$

J&M 的 nano corpus：query 是“sweet love”，四个 document：

| doc | 内容 | 与 query 的 cosine |
|---|---|---|
| 1 | Sweet sweet nurse! Love? | 0.747 |
| 2 | Sweet sorrow | 0.078 |
| 3 | How sweet is love? | 0.358 |
| 4 | Nurse! | 0 |

算 doc 1。sweet 出现在 3 个 document 里，$\mathrm{idf}=\log_{10}(4/3)=0.125$；love 和 nurse 各在 2 个里，$\mathrm{idf}=\log_{10}2=0.301$。doc 1 里 sweet 出现 2 次，$\mathrm{tf}=1+\log_{10}2=1.301$，tf-idf 是 $1.301\times0.125=0.163$；nurse 和 love 各 0.301。Query 的 vector 是 sweet 0.125、love 0.301。

$$\cos=\frac{0.125\times0.163+0.301\times0.301}{\sqrt{0.125^2+0.301^2}\ \sqrt{0.163^2+0.301^2+0.301^2}}=\frac{0.111}{0.326\times0.456}=0.747$$

:::edge 两个 query word 都有的 doc 3 反而输给 doc 1
doc 3 含有 sweet 和 love，却只得 0.358。在这四个 document 里，how 和 is 各只出现一次，idf 是 $\log_{10}4=0.602$，比 love 还大一倍，它们把 doc 3 的 vector length 撑大，cosine 就被压低。在真实的大文档库里 how、is 几乎处处出现，idf 接近 0，不会有这个问题。idf 衡量的是“在这个文档库里”有多罕见，文档库太小时它会把 stopword 当成关键词。
:::

Tf-idf 只认字面上相同的 term：query 写 car、document 写 automobile，score 是 0。Dense retrieval 改用 neural encoder：query 和 document 各自过一个 encoder 得到 vector，用 dot product 打分。Document 的 vector 可以事先全部算好存起来，查询时只需对 query 编码一次，再在所有 document vector 里找 dot product 最大的几个，这是 nearest neighbor search，大规模时用 Faiss 这类 approximate 的方法。

评估分两层。Retrieval 用 precision@$k$（前 $k$ 个结果里相关的比例）和 recall@$k$（相关文档里有多少进了前 $k$）。最终答案用 exact match 或 token F1：问 The Magic Flute 哪天首演，标准答案“30 September 1791”，model 答“September 1791”。Exact match 是 0；token F1 把两边看成 token 的集合，precision $=2/2=1$，recall $=2/3$，$F_1=\dfrac{2\times1\times\tfrac23}{1+\tfrac23}=0.8$。

:::back
RLHF 里用 policy gradient 更新 policy 的部分，见 [CS4246 的 policy gradient 一站](CS4246.html#pg)。Dense retrieval 的 dot product 打分和[第 3 站](#embed)的 cosine 是同一件事，只是 vector 来自 Transformer encoder。Response 上的 loss 仍是[第 7 站](#pretrain)的 cross-entropy。
:::
