先看同一份 initial data 在三个 equation 里分别变成什么。

**第一个。** 一根无限长的 string，$t=0$ 时被捏成一个高 1、底宽 2 的 triangle，静止释放。按 wave equation $u_{tt}=u_{xx}$，它分成两个半高的 triangle，一个往左一个往右，每个 corner 都原样保留，永远不会变圆。

**第二个。** 一根无限长的 rod，$t=0$ 时温度分布是同一个 triangle。按 heat equation $u_t=u_{xx}$，只过了 $t=0.05$，所有 corner 就都没了，顶点从 1 降到 0.75；而且在 $x=100$ 处，温度在任意 $t>0$ 都已经不是 0。

**第三个。** 一块圆形金属板，boundary 上半圆保持温度 1、下半圆保持 0，等它不再变化。这时没有 time，只有 Laplace equation $u_{xx}+u_{yy}=0$；圆心的温度恰好是 0.5，是 boundary 温度的 average，而且板上每一点都是它周围任意一个圆上的 average。

::fig[ma4221-twoeq] 左右两边的 initial data 一样。Wave equation 只是把它搬走，heat equation 立刻把它抹平。

三个 equation 都是 linear 的、second-order 的，只差在符号和 derivative 的阶数上，行为却完全不同：一个有有限的传播速度、保留 singularity，一个瞬间传到无穷远、立刻变 smooth，一个没有“传播”可言，每一点由整个 boundary 决定。这门课要回答的就是：差别从哪里来，每一种要给什么条件才能定下唯一的 solution，以及怎样把 solution 算出来。

课程的顺序是：先从 first-order equation 学会 characteristic 这个工具（第 1 站）；然后从物理推出三个 equation，看给错条件会出什么事（第 2 站）；用 coefficient 判断一个 second-order equation 属于哪一类（第 3 站）；在 whole line 上分别解 wave 和 heat equation（第 4、5 站）；在 bounded interval 上用 separation of variables 把 solution 写成 series（第 6 站），再回头弄清这种 series 什么时候、在什么意义下 converge （第 7 站）；最后是 Laplace equation 和 harmonic function（第 8 站）。开头三个现象分别在第 4、5、8 站得到解释。

## [first] First-order linear PDE 与 characteristics

:::skip
能用 characteristic 把 $a(x,y)u_x+b(x,y)u_y=c(x,y)u$ 化成沿 curve 的 ODE，解出 general solution 再代 data，并能判断 data 给在哪条 curve 上会出问题，就可以去第 2 站。
:::

### Solution 里多出来的是 function

ODE $u'(x)=0$ 的 solution 是 constant。PDE $u_x=0$（$u$ 是 $x,y$ 的 function）说的是：固定 $y$，$u$ 对 $x$ 不变。不同的 $y$ 上可以不变成不同的值，所以

$$u(x,y)=f(y),\qquad f\text{ 任意}$$

原来的“任意 constant”变成了“另一个 variable 的任意 function”。再看 $u_x=xe^{3y}$：对 $x$ integrate，$y$ 当 constant，

$$u=\tfrac12x^2e^{3y}+f(y)$$

核对：$\partial_x\big(\tfrac12x^2e^{3y}\big)=xe^{3y}$，$\partial_xf(y)=0$。所以 PDE 的 general solution 里装的是任意 function，要靠 data 去定它。这一站要学的就是：data 应该给在哪里、怎样把 function 定下来。

这一站的 equation 都是 linear 的。把左边看成作用在 $u$ 上的 operator $\mathcal L$，例如 $\mathcal Lu=u_x+yu_y$，linear 指的是

$$\mathcal L(\alpha u+\beta v)=\alpha\,\mathcal Lu+\beta\,\mathcal Lv$$

对 $u_x+yu_y$，左边展开是 $\alpha u_x+\beta v_x+y(\alpha u_y+\beta v_y)$，正好等于右边。由此得到 superposition principle：$\mathcal Lu=0$ 和 $\mathcal Lv=0$ 的 solution 加起来、乘 constant，还是 solution。不 linear 的例子是 $\mathcal Lu=u_t+uu_x$：取 $u=x$，$\mathcal Lu=x$；取 $u=2x$，$\mathcal L(2x)=2x\cdot2=4x\ne2\cdot x$。这个 operator 不 linear，后面所有“把 solution 加起来”的做法对它都不成立。

### Constant coefficient：沿一个方向不变

$au_x+bu_y$ 是 $\nabla u\cdot(a,b)$，也就是 $u$ 沿方向 $(a,b)$ 的 directional derivative（差一个 length 的 factor）。所以 $au_x+bu_y=0$ 说的是：$u$ 沿方向 $(a,b)$ 不变。方向为 $(a,b)$ 的直线是 $bx-ay=\text{constant}$，$u$ 在每条这样的直线上取一个值，不同直线可以不同：

$$u(x,y)=f(bx-ay)$$

这些直线叫 characteristic line。

最简单的例子是 $u_t+2u_x=0$。这里 variable 是 $(t,x)$，方向是 $(1,2)$：$t$ 每增加 1，$x$ 增加 2。Characteristic 是 $x-2t=\text{constant}$，general solution 是 $u=f(x-2t)$。$t=0$ 时 $u=f(x)$，所以 $f$ 就是 initial profile；之后的 $u(x,t)=f(x-2t)$ 是同一个形状往右平移了 $2t$。

::fig[ma4221-transport] 上面是 $f(x)=e^{-x^2/0.16}$ 在各个时刻的样子，下面是 $x$–$t$ plane。Peak 的位置 $(2t,t)$ 正好沿着 $x-2t=0$ 那条 characteristic 走。

带 data 的例子：解 $3u_x+2u_y=0$，$u(x,0)=\cos x$。方向 $(3,2)$，characteristic 是 $2x-3y=\text{constant}$，$u=f(2x-3y)$。代 $y=0$：

$$f(2x)=\cos x\quad\Longrightarrow\quad f(s)=\cos\tfrac s2\quad\Longrightarrow\quad u=\cos\Big(x-\tfrac32y\Big)$$

核对：$u_x=-\sin(x-\tfrac32y)$，$u_y=\tfrac32\sin(x-\tfrac32y)$，$3u_x+2u_y=-3\sin(\cdot)+3\sin(\cdot)=0$；$y=0$ 时 $u=\cos x$。

同一件事也可以换 coordinate 来做。取一个沿 characteristic 方向的 variable 和一个垂直方向的 variable：

$$\xi=ax+by,\qquad\eta=bx-ay$$

Chain rule：$u_x=u_\xi\,\xi_x+u_\eta\,\eta_x=au_\xi+bu_\eta$，$u_y=bu_\xi-au_\eta$。代进去

$$au_x+bu_y=a(au_\xi+bu_\eta)+b(bu_\xi-au_\eta)=(a^2+b^2)\,u_\xi$$

$a,b$ 不全为 0，所以 equation 变成 $u_\xi=0$，$u=f(\eta)=f(bx-ay)$，和上面一样。换到 characteristic 的 coordinate 以后，PDE 变成了只对一个 variable 求 derivative 的 equation，这是整站的思路。

### Variable coefficient：characteristic 变成 curve

$u_x+yu_y=0$ 说的是 $u$ 沿方向 $(1,y)$ 不变，方向随位置而变。顺着这个方向走出来的是 curve，它的 slope 满足

$$\frac{dy}{dx}=\frac y1\quad\Longrightarrow\quad y=Ce^{x}$$

验证 $u$ 沿这些 curve 真的不变：

$$\frac{d}{dx}\,u\big(x,Ce^x\big)=u_x+Ce^x\,u_y=u_x+y\,u_y=0$$

所以 $u$ 只依赖于“在哪条 curve 上”，即 $C=ye^{-x}$：$u=f(ye^{-x})$。

加上 data $u(1,y)=y^2$：$f(ye^{-1})=y^2$，令 $s=ye^{-1}$，$f(s)=e^2s^2$，所以

$$u(x,y)=e^2\big(ye^{-x}\big)^2=y^2e^{2-2x}$$

核对：$u_x=-2u$，$u_y=2u/y$，$u_x+yu_y=-2u+2u=0$；$x=1$ 时 $u=y^2$。

::fig[ma4221-charcurve] $u_x+yu_y=0$ 的 characteristic $y=y_1e^{x-1}$，$y_1$ 是 curve 在 $x=1$ 处的高度。沿每条 curve，$u$ 等于它穿过 $x=1$ 时的 data $y_1^2$。

一般地，$a(x,y)u_x+b(x,y)u_y=0$ 的 characteristic 由 ODE $\dfrac{dy}{dx}=\dfrac{b}{a}$ 给出，解出 curve 族 $\Gamma(x,y)=C$，general solution 是 $u=f\big(\Gamma(x,y)\big)$。

### 右边带 $u$：沿 characteristic 解一个 ODE

$3u_x+2u_y=-u$。Characteristic 还是方向 $(3,2)$ 的直线，写成 $y-\tfrac23x=s$。在一条 characteristic 上用 $x$ 当参数，$u$ 的变化率是

$$\frac{d}{dx}\,u\big(x,s+\tfrac23x\big)=u_x+\tfrac23u_y=\tfrac13\big(3u_x+2u_y\big)=-\tfrac13u$$

$u$ 不再沿 characteristic 不变，但沿它满足一个 ODE，解是 $u=(\text{constant})\cdot e^{-x/3}$，constant 随 characteristic 而变，也就是 $s$ 的 function：

$$u(x,y)=f\big(y-\tfrac23x\big)\,e^{-x/3}$$

给 data $u(0,y)=y$：$f(y)\cdot1=y$，$u=(y-\tfrac23x)e^{-x/3}$。核对：

$$u_x=-\tfrac23e^{-x/3}-\tfrac13\big(y-\tfrac23x\big)e^{-x/3},\qquad u_y=e^{-x/3}$$

$$3u_x+2u_y=-2e^{-x/3}-\big(y-\tfrac23x\big)e^{-x/3}+2e^{-x/3}=-u$$

Linear first-order equation 的做法到此为止就是一句话：沿 characteristic，PDE 变成 ODE。

:::wrong 只要在某条 curve 上给了 $u$ 的值，solution 就定下来了
取 $3u_x+2u_y=0$，data 给在直线 $y=\tfrac23x$ 上：$u(x,\tfrac23x)=g(x)$。General solution 是 $u=f(2x-3y)$，在这条直线上 $2x-3y=0$，所以 $u\equiv f(0)$，是一个 constant。

- $g(x)=x$：要求 $f(0)=x$ 对所有 $x$ 成立，做不到，没有 solution。
- $g(x)\equiv1$：只要求 $f(0)=1$。$f(s)=1+s$ 和 $f(s)=\cos s$ 都满足，给出 $u=1+2x-3y$ 和 $u=\cos(2x-3y)$ 两个不同的 solution，实际上有无穷多个。

原因是 $y=\tfrac23x$ 本身就是一条 characteristic：在它上面 $u$ 本来就由 equation 决定（只能是 constant），data 要么和 equation 冲突，要么什么也没告诉我们；其余的 characteristic 一条也没碰到它，那里的 $f$ 完全没有约束。Data 必须给在一条和每条 characteristic 恰好相交一次的 curve 上。同样地，$u_x+yu_y=0$ 的 data 可以给在 $x=1$ 上，不能给在 $y=0$ 上，因为 $y=0$ 是 $C=0$ 的那条 characteristic。
:::

::fig[ma4221-baddata] 粗线 $y=0$ 和每条 characteristic 交一次；彩线 $y=\tfrac23x$ 自己就是 characteristic。

:::edge Data 只覆盖一部分 characteristic
$u_x+yu_y=0$ 的 data 若只给在 $x=1$、$y>0$ 上，定下来的只有 $C>0$ 的那些 curve，即 upper half-plane。Curve $y=Ce^x$ 永远不穿过 $y=0$，所以 lower half-plane 的 $u$ 仍然是任意的。“solution 在哪里被定下来”要看 characteristic 从 data 出发能走到哪里。
:::

## [model] 从 conservation law 到三个 equation，以及 well-posedness

:::skip
能从“$[a,b]$ 里的量的变化 = 两端的 flux 之差”推出 $u_t+q_x=0$，代入两种 flux 得到 transport 和 heat equation，从 string 的受力推出 wave equation，并能各举一个例子说明条件给多了、给少了、以及 solution 不 stable 是什么样子，就可以去第 3 站。
:::

### 一条 balance，两种 flux

设一条直线上分布着某种量（热量、污染物的质量），$u(x,t)$ 是它在 $x$ 处的 density，$q(x,t)$ 是 flux：单位时间里从左往右穿过 $x$ 这一点的量。看任意一段 $[a,b]$：里面的总量是 $\int_a^bu\,dx$，它的变化只能来自两端，从 $a$ 流进 $q(a,t)$，从 $b$ 流出 $q(b,t)$：

$$\frac{d}{dt}\int_a^bu(x,t)\,dx=q(a,t)-q(b,t)=-\int_a^bq_x(x,t)\,dx$$

把左边的 derivative 放进 integral，移项得 $\int_a^b(u_t+q_x)\,dx=0$。这对每一段 $[a,b]$ 都成立。如果 integrand 在某点 $x_0$ 处大于 0，由 continuity 它在 $x_0$ 附近一小段上都大于 0，在那一小段上 integral 就大于 0，矛盾。所以

$$u_t+q_x=0$$

这叫 conservation law。它还不是一个 equation，因为 $q$ 是新的 unknown；要再给一个“flux 由 $u$ 怎样决定”的 model。

::fig[ma4221-rod] $[a,b]$ 里的总量只能通过两端变化。在 heat 的 model 里，flux 从热处指向冷处，大小正比于温度的 slope。

**第一种 model：被水带着走。** 污染物在以 speed $c$ 流动的水里，单位时间里穿过 $x$ 的量是 density 乘 speed，$q=cu$。代进去就是第 1 站的 transport equation

$$u_t+(cu)_x=0,\qquad c\text{ 是 constant 时即 }u_t+cu_x=0$$

**第二种 model：Fourier's law。** 热从热处流向冷处，流量正比于温度的 slope：$q=-\kappa u_x$，$\kappa>0$ 叫 thermal conductivity。这里 $u$ 是温度，热量的 density 是 $c_v\rho u$（$c_v$ 是 specific heat，$\rho$ 是 density），conservation law 写成 $c_v\rho\,u_t+q_x=0$：

$$c_v\rho\,u_t=\kappa u_{xx}\qquad\Longrightarrow\qquad u_t=ku_{xx},\quad k=\frac{\kappa}{c_v\rho}$$

这是 heat equation，也叫 diffusion equation（污染物在静水里扩散，flux 同样正比于 $-u_x$，这时叫 Fick's law）。图里在 $a$ 处温度往右下降，$u_x<0$，所以 $q(a)=-\kappa u_x(a)>0$，热往右流，和直觉一致。

三维时同样的论证用在任意 region $V$ 上：$\frac{d}{dt}\int_Vu=-\int_{\partial V}\mathbf q\cdot\mathbf n\,dS=-\int_V\nabla\cdot\mathbf q$，再用 $\mathbf q=-\kappa\nabla u$，得到 $u_t=k\Delta u$，$\Delta u=u_{xx}+u_{yy}+u_{zz}$。

温度不再随时间变化时 $u_t=0$，剩下

$$\Delta u=0$$

这是 Laplace equation，它的 solution 叫 harmonic function。开头那块圆板的稳定温度就满足它。

### String：Newton's second law 给出 wave equation

一根拉紧的 string，$u(x,t)$ 是 $x$ 处偏离平衡位置的高度。假设每一点只上下动，tension $T$ 沿 tangent 方向，string 的 density（单位 length 的 mass）是 $\rho$。

::fig[ma4221-string] 取 $x$ 到 $x+\Delta x$ 这一小段，两端各受一个大小为 $T$、方向沿 tangent 的拉力。

Tangent 和水平方向的夹角记作 $\theta$，$\tan\theta=u_x$。这一小段的 mass 是 $\rho\Delta x$，竖直方向的合力是 $T\sin\theta(x+\Delta x)-T\sin\theta(x)$，Newton's second law：

$$\rho\,\Delta x\,u_{tt}=T\sin\theta(x+\Delta x)-T\sin\theta(x)$$

振动很小时 $\theta$ 很小，$\sin\theta\approx\tan\theta=u_x$。代入，两边除以 $\Delta x$，令 $\Delta x\to0$：

$$\rho\,u_{tt}=T\,u_{xx}\qquad\Longrightarrow\qquad u_{tt}=c^2u_{xx},\quad c=\sqrt{T/\rho}$$

这是 wave equation。它对 $t$ 是 second-order 的，所以 initial condition 要给两个：initial position $u(x,0)=\varphi(x)$ 和 initial velocity $u_t(x,0)=\psi(x)$。Heat equation 对 $t$ 是 first-order，只给 $u(x,0)$。

### Boundary condition

Rod 只占 $[0,l]$ 时，两端要给条件。物理上有三种情形，每一种对应一种数学形式。

| 物理情形 | 条件 | 名字 |
|---|---|---|
| 端点泡在温度为 $g(t)$ 的大水箱里；string 端点被固定 | $u(0,t)=g(t)$ | Dirichlet |
| 端点给定的 heat flux；完全绝热时 flux 为 0；string 端点套在光滑竖杆上自由滑动 | $u_x(0,t)=h(t)$，绝热时 $u_x=0$ | Neumann |
| 端点和温度为 0 的空气换热，换热量正比于端点温度（Newton's law of cooling） | $u_x(l,t)+au(l,t)=0$，$a>0$ | Robin |

Robin 的符号这样确定。在 $x=l$，往外流（往右）的 flux 是 $q(l)=-\kappa u_x(l)$，它应等于 $Hu(l)$，$H>0$ 是换热 coefficient，所以 $u_x(l)+\tfrac H\kappa u(l)=0$。在 $x=0$，往外是往左，往外的 flux 是 $-q(0)=\kappa u_x(0)$，同样令它等于 $Hu(0)$，得 $u_x(0)-au(0)=0$。两端的符号相反，都表示“热往外跑”。String 的 Neumann condition 来自端点没有竖直方向的外力：竖直分力 $Tu_x=0$。

### Well-posedness

一个问题（equation 加上条件）叫 well-posed，要同时满足三条：

1. existence：至少有一个 solution；
2. uniqueness：至多一个 solution；
3. stability：data 改变一点点，solution 也只改变一点点。

第 3 条要求的原因是 data 来自测量，总带着 error。下面三个例子各破坏一条。

**条件给多了：没有 solution。** 在 $0<x<1$、$t>0$ 上解 $u_t+5u_x=0$，给三个条件：$u(x,0)=0$，$u(0,t)=0$，$u(1,t)=1$。Characteristic 是 $x-5t=\text{constant}$，往右上方走，$u$ 沿它不变。

::fig[ma4221-strip] 每条 characteristic 从底边或左边进入 strip，带着那里的 data 一直走到右边。

从底边 $(x_0,0)$ 出发的 characteristic 带着 $u=0$；从左边 $(0,t_0)$ 出发的带着 $u=0$。它们一起铺满了整个 strip，于是 $u\equiv0$，到右边 $x=1$ 处也是 0。第三个条件要求那里是 1，没有 solution 能同时满足。

**条件给少了：不唯一。** 同一个 equation，只给 $u(x,0)=0$。底边出发的 characteristic 只覆盖 $x>5t$ 的部分；$x<5t$ 的部分由左边进来的 characteristic 覆盖，而左边没有 data。$u=f(x-5t)$，$f$ 在 $(0,1)$ 上必须是 0，在负数上可以随便取，例如 $f(s)=s^2$（$s<0$）、$f(s)=0$（$s\ge0$），这是 $C^1$ 的，给出一个不恒为 0 的 solution。

**Stability 失败：backward heat equation。** 想从现在的温度反推过去的温度，等于解 $u_t=-u_{xx}$（把 $t$ 换成 $-t$）。在 $(0,\pi)$ 上、两端为 0，取 data

$$u_n(x,0)=\tfrac1n\sin nx$$

Solution 是 $u_n(x,t)=\tfrac1ne^{n^2t}\sin nx$。核对：$\partial_tu_n=n^2u_n$，$-\partial_x^2u_n=-\tfrac1ne^{n^2t}\cdot(-n^2\sin nx)=n^2u_n$，两边相等；两端 $\sin0=\sin n\pi=0$。

Data 的大小是 $\tfrac1n$，$n$ 越大越接近 0 这个 data（它的 solution 是 $u\equiv0$）。但在 $t=\tfrac1n$ 时，$u_n$ 的 amplitude 是 $\tfrac1ne^{n^2/n}=\tfrac{e^n}{n}$：$n=10$ 时是 2203，$n=20$ 时是 $2.4\times10^7$。Data 差 $0.05$，solution 差两千多万倍。

::fig[ma4221-hadamard] 纵轴是 log scale。实线是 backward 的 $\tfrac1ne^{n^2t}$，虚线是正常 heat equation 下同一组 data 的 $\tfrac1ne^{-n^2t}$。

**Stability 失败：Laplace equation 的 Cauchy problem。** 在 upper half-plane $y>0$ 上解 $\Delta u=0$，像 wave equation 那样在 $y=0$ 上同时给 $u$ 和 $u_y$：

$$u(x,0)=0,\qquad u_y(x,0)=e^{-\sqrt n}\sin nx$$

Solution 是 $u_n=\tfrac1ne^{-\sqrt n}\sin nx\,\sinh ny$。核对：$\partial_x^2(\sin nx\sinh ny)=-n^2\sin nx\sinh ny$，$\partial_y^2(\cdots)=+n^2\sin nx\sinh ny$，相加为 0；$y=0$ 时 $\sinh0=0$；$\partial_yu_n=e^{-\sqrt n}\sin nx\cosh ny$，$y=0$ 时 $\cosh0=1$。

| $n$ | data $u_y(x,0)$ 的 amplitude $e^{-\sqrt n}$ | $u_n(x,1)$ 的 amplitude $\tfrac1ne^{-\sqrt n}\sinh n$ |
|---|---|---|
| 1 | 0.368 | 0.432 |
| 25 | $6.7\times10^{-3}$ | $9.7\times10^{6}$ |
| 100 | $4.5\times10^{-5}$ | $6.1\times10^{36}$ |

同样是 second-order、同样给了两个条件，wave equation 这样给条件是 well-posed 的（第 4 站），Laplace equation 就不是。Laplace equation 要的是在一条围起来的 boundary 上只给一种条件（第 8 站）。哪种 equation 配哪种条件，取决于 equation 的 type，这是第 3 站的内容。

:::wrong Equation 是 linear 的，data 差一点，solution 自然也只差一点
Linear 只保证差别满足同一个 equation：两个 data 的 solution 之差，是“data 之差”的 solution。它不保证这个差不被放大。上面 backward heat equation 的例子正是 linear 的，data 之差 $\tfrac1{20}\sin20x$ 在 $t=0.05$ 时被放大成 $\tfrac{e^{20}}{20}\approx2.4\times10^7$。Stability 是要对每个问题单独证明的性质，第 4、5、8 站分别用 energy 和 maximum principle 来证。
:::

:::back
Characteristic 和 data 的关系来自[第 1 站](#first)；“条件给多了”“给少了”的两个例子就是沿 characteristic 数一数 data 够不够。
:::

## [class] Second-order equation 的分类

:::skip
能用 $a_{12}^2-a_{11}a_{22}$ 判断类型、记得 $a_{12}$ 是 $u_{xy}$ 的 coefficient 的一半，能用配方把 constant coefficient 的 hyperbolic equation 拆成两个 first-order operator 并写出 general solution，就可以去第 4 站。
:::

### 配方

第 2 站最后看到，同样给两个条件，wave equation 没事，Laplace equation 就崩了。要在拿到一个 equation 时就知道它像哪一个，先看两个 variable、constant coefficient 的情形：

$$a_{11}u_{xx}+2a_{12}u_{xy}+a_{22}u_{yy}+(\text{lower-order terms})=0$$

$u_{xy}$ 的 coefficient 写成 $2a_{12}$，是为了让 coefficient matrix $\begin{pmatrix}a_{11}&a_{12}\\a_{12}&a_{22}\end{pmatrix}$ 是 symmetric 的。只看 second-order 的部分，把 $\partial_x,\partial_y$ 当成数，它是一个 quadratic form，可以配方。设 $a_{11}\ne0$，乘以 $a_{11}$：

$$a_{11}^2\partial_x^2+2a_{11}a_{12}\partial_x\partial_y+a_{11}a_{22}\partial_y^2=\big(a_{11}\partial_x+a_{12}\partial_y\big)^2-\big(a_{12}^2-a_{11}a_{22}\big)\partial_y^2$$

展开右边第一项是 $a_{11}^2\partial_x^2+2a_{11}a_{12}\partial_x\partial_y+a_{12}^2\partial_y^2$，减去 $a_{12}^2\partial_y^2$ 再加 $a_{11}a_{22}\partial_y^2$，正好是左边。记

$$D=a_{12}^2-a_{11}a_{22}$$

结构完全由 $D$ 的符号决定。

**$D>0$：hyperbolic。** 平方差可以拆开：

$$\big(a_{11}\partial_x+a_{12}\partial_y\big)^2-D\,\partial_y^2=\big(a_{11}\partial_x+(a_{12}-\sqrt D)\partial_y\big)\big(a_{11}\partial_x+(a_{12}+\sqrt D)\partial_y\big)$$

Second-order operator 变成两个 first-order operator 的 product，每一个都有第 1 站的 characteristic line，一共两族。没有 lower-order term 时，每个 factor 消灭一族 function，solution 是两族之和。$u_{xx}-u_{yy}=0$（$a_{11}=1$，$a_{12}=0$，$a_{22}=-1$，$D=1$）就是这一类。

**$D<0$：elliptic。** 平方和拆不开，没有 real 的 characteristic。换 variable

$$\xi=\frac{x}{a_{11}},\qquad\eta=\frac{a_{11}y-a_{12}x}{a_{11}\sqrt{-D}}$$

用 chain rule 核对：$(a_{11}\partial_x+a_{12}\partial_y)\xi=1$，$(a_{11}\partial_x+a_{12}\partial_y)\eta=\dfrac{-a_{11}a_{12}+a_{12}a_{11}}{a_{11}\sqrt{-D}}=0$，$\sqrt{-D}\,\partial_y\xi=0$，$\sqrt{-D}\,\partial_y\eta=1$。所以 $a_{11}\partial_x+a_{12}\partial_y=\partial_\xi$，$\sqrt{-D}\,\partial_y=\partial_\eta$，second-order 部分变成 $\partial_\xi^2+\partial_\eta^2$，是 Laplace operator。

**$D=0$：parabolic。** 只剩一个平方 $(a_{11}\partial_x+a_{12}\partial_y)^2$，在新 coordinate 里只有一个方向有 second derivative，另一个方向只剩 lower-order term，像 heat equation 的 $u_t=u_{xx}$（$a_{11}=1$，其余为 0，$D=0$）。

Lower-order term 不影响 $D$，所以不影响 type。$a_{11}=0$ 而 $a_{22}\ne0$ 时把 $x,y$ 对调做同样的配方；两者都为 0 时 equation 是 $2a_{12}u_{xy}+\cdots$，$D=a_{12}^2>0$，hyperbolic。

### 例：$u_{tt}-4u_{tx}+2u_{xx}=0$

$a_{11}=1$，$2a_{12}=-4$ 即 $a_{12}=-2$，$a_{22}=2$。$D=4-2=2>0$，hyperbolic。配方：

$$\partial_t^2-4\partial_t\partial_x+2\partial_x^2=(\partial_t-2\partial_x)^2-2\partial_x^2=\big(\partial_t-(2+\sqrt2)\partial_x\big)\big(\partial_t-(2-\sqrt2)\partial_x\big)$$

$\partial_t-r\partial_x$ 消灭 $F(x+rt)$：$\partial_tF(x+rt)=rF'$，$r\partial_xF(x+rt)=rF'$，相减为 0。所以

$$u=F\big(x+(2+\sqrt2)t\big)+G\big(x+(2-\sqrt2)t\big)$$

直接代回去核对：$u=F(x+rt)$ 时 $u_{tt}=r^2F''$，$u_{tx}=rF''$，$u_{xx}=F''$，equation 变成 $(r^2-4r+2)F''=0$，$r=2\pm\sqrt2$ 正是这个 quadratic 的两个 root。

::fig[ma4221-charfam] 两族 characteristic 的 slope 不同。过 $(-2,1)$ 的两条往下各落在 $t=0$ 上一点，那一点的值由这两个落脚点的 data 决定。

也可以只换一个 variable：令 $\tilde x=x+2t$，$\tilde t=t$。Chain rule 给出 $\partial_t=\partial_{\tilde t}+2\partial_{\tilde x}$，$\partial_x=\partial_{\tilde x}$，于是 $\partial_t-2\partial_x=\partial_{\tilde t}$，equation 变成

$$u_{\tilde t\tilde t}-2u_{\tilde x\tilde x}=0$$

这是 speed $\sqrt2$ 的 wave equation，它的 characteristic $\tilde x\pm\sqrt2\tilde t=\text{constant}$ 换回来就是 $x+(2\pm\sqrt2)t=\text{constant}$。

### Elliptic 和 parabolic 的例子

$-2u_{tt}-2u_{tx}-u_{xx}+u_x=0$：$a_{11}=-2$，$a_{12}=-1$，$a_{22}=-1$，$D=1-2=-1<0$，elliptic。$u_x$ 那一项不影响判断。

$u_{tt}-2u_{tx}+u_{xx}+u_x=0$：$a_{11}=1$，$a_{12}=-1$，$a_{22}=1$，$D=1-1=0$，parabolic。配方得 $(\partial_t-\partial_x)^2u+u_x=0$。令 $\tilde t=t$，$\tilde x=x+t$，则 $\partial_t-\partial_x=\partial_{\tilde t}+\partial_{\tilde x}-\partial_{\tilde x}=\partial_{\tilde t}$，$\partial_x=\partial_{\tilde x}$，equation 变成

$$u_{\tilde t\tilde t}+u_{\tilde x}=0$$

即 $u_{\tilde x}=-u_{\tilde t\tilde t}$：把 $-\tilde x$ 当作 time，这就是 heat equation。

### Coefficient 随位置变化：type 可以逐点不同

Coefficient 是 function 时，在每一点用那一点的 coefficient 算 $D$。例如

$$y\,u_{xx}-2u_{xy}+x\,u_{yy}=0$$

$a_{11}=y$，$a_{12}=-1$，$a_{22}=x$，$D=1-xy$。在 hyperbola $xy=1$ 上 parabolic，$xy>1$ 的两块里 elliptic，其余地方 hyperbolic。

::fig[ma4221-regions] 同一个 equation 在 plane 的不同部分属于不同的 type。右边三个点各代进去算了一次 $D$。

### 多个 variable：看 eigenvalue

$\sum_{i,j}a_{ij}u_{x_ix_j}+\cdots=0$，$a_{ij}=a_{ji}$。Coefficient matrix $A=(a_{ij})$ 是 symmetric 的，可以 orthogonally diagonalize：$A=Q\Lambda Q^\top$。取新 variable $\mathbf y=Q^\top\mathbf x$，second-order 部分变成 $\sum_i\lambda_iu_{y_iy_i}$，各个方向互不干扰，type 由 eigenvalue 的符号决定：

| eigenvalue 的符号 | type | 例子 |
|---|---|---|
| 全正或全负 | elliptic | $\Delta u=0$：$(1,1,1)$ |
| 全不为 0，一个和其余的反号 | hyperbolic | $u_{tt}-\Delta u=0$：$(1,-1,-1,-1)$ |
| 恰有一个为 0，其余同号 | parabolic | $u_t-\Delta u=0$：$(0,-1,-1,-1)$ |

两个 variable 时这和 $D$ 是一回事：$\det A=a_{11}a_{22}-a_{12}^2=-D$ 是两个 eigenvalue 的 product。$D<0$ 即 product 为正、两个同号，elliptic；$D>0$ 即异号，hyperbolic；$D=0$ 即有一个为 0，parabolic。

:::wrong $u_{xx}+3u_{xy}+u_{yy}=0$ 的两个 square term coefficient 都是正的，所以是 elliptic
$u_{xy}$ 的 coefficient 是 $2a_{12}=3$，所以 $a_{12}=\tfrac32$，$D=\tfrac94-1=\tfrac54>0$，是 hyperbolic。试 $u=F(y-rx)$：$u_{xx}=r^2F''$，$u_{xy}=-rF''$，$u_{yy}=F''$，equation 变成 $(r^2-3r+1)F''=0$，$r=\tfrac{3\pm\sqrt5}2$，即 $2.618$ 和 $0.382$，两个 real root，两族 characteristic。Cross term 足够大时，它能把两个同号的 square term 压成一个平方差。只有把 $a_{12}$ 一起算进去才算数，而且要记得除以 2。
:::

:::from
Coefficient matrix、按 eigenvalue 分类、用 linear change of variable 化成 canonical form，以及 $u_{tt}-4u_{tx}+2u_{xx}$、$-2u_{tt}-2u_{tx}-u_{xx}+u_x$、$u_{tt}-2u_{tx}+u_{xx}+u_x$ 三个例子来自 [MIT 18.152 Class 15](https://ocw.mit.edu/courses/18-152-introduction-to-partial-differential-equations-fall-2011/99308a127797b9626b2d9216af24b52e_MIT18_152F11_lec_15.pdf)（那份讲义的第三个例子 characteristic polynomial 有个符号错，不影响结论）。以 $a_{12}^2-a_{11}a_{22}$ 判断、ultrahyperbolic 的定义来自 [CUHK MATH4220 Lecture 3](https://www.math.cuhk.edu.hk/course_builder/2021/math4220/PDE3.pdf)，$yu_{xx}-2u_{xy}+xu_{yy}$ 是 Thang Pang Ern 笔记的例 3.7。配方拆成两个 factor 的写法、elliptic 情形的那组 $\xi,\eta$、parabolic 例子的换元、$u_{xx}+3u_{xy}+u_{yy}$ 是为这一页写的。

## [wave] Wave equation：d'Alembert、causality、energy、reflection

:::skip
能用 d'Alembert formula 算 $u(x,t)$、画出 domain of dependence 和 domain of influence、用 energy 证明 uniqueness、用 odd extension 解 half-line 问题，就可以去第 5 站。
:::

### 拆成两个 transport equation

$u_{tt}=c^2u_{xx}$ 在 $-\infty<x<\infty$ 上，$u(x,0)=\varphi(x)$，$u_t(x,0)=\psi(x)$。按第 3 站，$a_{11}=1$、$a_{22}=-c^2$、$D=c^2>0$，hyperbolic，operator 可以拆开：

$$\partial_t^2-c^2\partial_x^2=(\partial_t-c\partial_x)(\partial_t+c\partial_x)$$

展开右边：$\partial_t^2+c\,\partial_t\partial_x-c\,\partial_x\partial_t-c^2\partial_x^2$，中间两项相消。所以 equation 是 $(\partial_t-c\partial_x)v=0$，其中 $v=u_t+cu_x$。

第一步，$v_t-cv_x=0$ 是 transport equation，方向 $(1,-c)$，$v=h(x+ct)$，$h$ 任意。

第二步，$u_t+cu_x=h(x+ct)$，又是一个 transport equation，只是右边不为 0。找一个 particular solution：试 $u=f(x+ct)$，左边是 $cf'+cf'=2cf'$，令它等于 $h$，$f$ 取 $h/(2c)$ 的一个 antiderivative 即可。再加上 homogeneous equation $u_t+cu_x=0$ 的 general solution $g(x-ct)$：

$$u(x,t)=f(x+ct)+g(x-ct)$$

$f(x+ct)$ 是以 speed $c$ 往左走的形状，$g(x-ct)$ 是往右走的。Wave equation 的每个 solution 都是两个反向 transport 的和。

### d'Alembert formula

用 initial data 定 $f$ 和 $g$。$t=0$：

$$f(x)+g(x)=\varphi(x),\qquad cf'(x)-cg'(x)=\psi(x)$$

第二式 integrate：$f(x)-g(x)=\dfrac1c\displaystyle\int_0^x\psi(s)\,ds+A$，$A$ 是 constant。和第一式联立：

$$f(x)=\tfrac12\varphi(x)+\frac1{2c}\int_0^x\psi+\frac A2,\qquad g(x)=\tfrac12\varphi(x)-\frac1{2c}\int_0^x\psi-\frac A2$$

把 $x+ct$ 代进 $f$、$x-ct$ 代进 $g$ 再相加，$A$ 消掉，两个 integral 合成一个：

$$u(x,t)=\tfrac12\big[\varphi(x+ct)+\varphi(x-ct)\big]+\frac1{2c}\int_{x-ct}^{x+ct}\psi(s)\,ds$$

这就是 d'Alembert formula。$\varphi\in C^2$、$\psi\in C^1$ 时它给出 classical solution，而且推导的每一步都是必须的，所以 solution 唯一。

**例 1：plucked string。** $\varphi(x)=\max(0,1-|x|)$，$\psi=0$，$c=1$。$u=\tfrac12\varphi(x+t)+\tfrac12\varphi(x-t)$：初始的 triangle 分成两个高 $\tfrac12$ 的 triangle，各自以 speed 1 往两边走。算几个值：

- $u(0,0.5)=\tfrac12[\varphi(0.5)+\varphi(-0.5)]=\tfrac12[0.5+0.5]=0.5$；
- $u(1,0.5)=\tfrac12[\varphi(1.5)+\varphi(0.5)]=\tfrac12[0+0.5]=0.25$；
- $u(0,2)=\tfrac12[\varphi(2)+\varphi(-2)]=0$：$t\ge1$ 以后两半完全分开，中间回到 0。

::fig[ma4221-pluck] 两条虚线是两个半高的 copy，彩线是它们的和。右边的 bar 是 energy，下一小节解释。

**例 2：hammer blow。** $\varphi=0$，$\psi(x)=1$（$|x|<1$），$\psi=0$（其他），$c=1$。这是用一把宽 2 的锤子在 string 中间打一下，给它一个 initial velocity。

$$u(x,t)=\tfrac12\int_{x-t}^{x+t}\psi(s)\,ds=\tfrac12\times\big(\,[x-t,\,x+t]\text{ 和 }[-1,1]\text{ 重叠部分的 length}\big)$$

在 $x=3$ 处看：$t\le2$ 时 $[3-t,3+t]$ 碰不到 $[-1,1]$，$u=0$；$2<t<4$ 时重叠部分是 $[3-t,1]$，length $t-2$，$u=\tfrac{t-2}2$；$t\ge4$ 时整个 $[-1,1]$ 都在里面，$u=\tfrac12\times2=1$。例如 $u(3,3)=\tfrac12\times|[0,6]\cap[-1,1]|=\tfrac12$。

::fig[ma4221-cone] 左边是 $x$–$t$ plane 上 $u$ 的分区，右边是 $x=3$ 处 $u$ 随 $t$ 的变化。点 $(3,3)$ 往下的两条 characteristic 落在 $x=0$ 和 $x=6$。

### Causality

d'Alembert formula 显示，$u(x,t)$ 只用到两样东西：$\varphi$ 在 $x\pm ct$ 两点的值，$\psi$ 在 $[x-ct,x+ct]$ 上的值。这个 interval 是从 $(x,t)$ 沿两条 characteristic 往下走、落到 $t=0$ 上截出的一段，叫 $(x,t)$ 的 domain of dependence。在它外面怎么改 data，$u(x,t)$ 都不变。

反过来看，$t=0$ 时 $x_0$ 处的 data 能影响到的点是 $|x-x_0|\le ct$，即从 $(x_0,0)$ 出发、两条 characteristic 夹住的扇形，叫 domain of influence。上面 hammer blow 的图里，浅色 region 就是 $[-1,1]$ 的 domain of influence，外面 $u=0$；$x=3$ 处要等到 $t=2$ 才开始动，因为 characteristic $x=1+t$ 在 $t=2$ 时才到达 $x=3$。

> 信号以有限的 speed $c$ 传播，这一条贯穿整个 wave equation。

### Energy 与 uniqueness

$\rho u_{tt}=Tu_{xx}$，定义

$$E(t)=\underbrace{\tfrac12\int_{-\infty}^\infty\rho\,u_t^2\,dx}_{\text{kinetic energy}}+\underbrace{\tfrac12\int_{-\infty}^\infty T\,u_x^2\,dx}_{\text{potential energy}}$$

设 $\varphi,\psi$ 在某个 $[-R,R]$ 外为 0。由 causality，每个固定的 $t$，$u(\cdot,t)$ 在 $[-R-ct,R+ct]$ 外为 0，integral 都是有限的，boundary term 都为 0。求 derivative：

$$\frac{dE}{dt}=\int\big(\rho u_tu_{tt}+Tu_xu_{xt}\big)\,dx=\int\big(u_t\,Tu_{xx}+Tu_xu_{xt}\big)\,dx=T\int\big(u_tu_x\big)_x\,dx=T\big[u_tu_x\big]_{-\infty}^{\infty}=0$$

第二个等号用了 equation，第三个用了 product rule $(u_tu_x)_x=u_{tx}u_x+u_tu_{xx}$。Energy 守恒。

用 plucked string（$\rho=T=1$）核对。$t=0$ 时 $u_t=0$，$u_x=\varphi'=\pm1$ 在 $(-1,1)$ 上，$E=0+\tfrac12\times2=1$。$t\ge1$ 时两个半高的 triangle 各自 slope 为 $\pm\tfrac12$；往右走的那个是 $g(x-t)$，$u_t=-g'$，$u_x=g'$，所以 $u_t^2=u_x^2=\tfrac14$，在 length 2 上各 integrate 出 $\tfrac12$。两个 triangle 合起来 kinetic energy $\tfrac12\times(\tfrac12+\tfrac12)=\tfrac12$，potential energy 也是 $\tfrac12$，总和仍是 1。上面动图右边的 bar 就是用 $u$ 数值算出的这两项。

**Uniqueness。** 设 $u$、$\tilde u$ 是同一组 data 的两个 solution，$w=u-\tilde u$ 满足 wave equation，$w(x,0)=0$，$w_t(x,0)=0$。$t=0$ 时 $w_t=0$，$w_x=0$（$w(\cdot,0)\equiv0$），所以 $E(0)=0$。Energy 守恒，$E(t)=0$；两个 integrand 都非负，只能 $w_t\equiv w_x\equiv0$，$w$ 是 constant，又 $w(x,0)=0$，所以 $w\equiv0$。

### Half-line：reflection

String 只占 $x>0$，左端固定：$u(0,t)=0$。d'Alembert formula 要用到 $\varphi(x-ct)$，当 $x<ct$ 时 $x-ct<0$，那里没有 data。办法是造出 data：把 $\varphi,\psi$ 延拓成 odd function，

$$\varphi_{\text{odd}}(x)=\begin{cases}\varphi(x)&x>0\\-\varphi(-x)&x<0\end{cases}$$

$\psi_{\text{odd}}$ 同样。用 d'Alembert 解 whole line 上的问题，得到 $u$。它是 odd 的：$u(-x,t)$ 也是 wave equation 的 solution，data 是 $\varphi_{\text{odd}}(-x)=-\varphi_{\text{odd}}(x)$ 和 $-\psi_{\text{odd}}(x)$，所以由 uniqueness $u(-x,t)=-u(x,t)$，代 $x=0$ 得 $u(0,t)=0$。于是 $u$ 限制在 $x>0$ 上就是要的 solution。

$x>ct$ 时公式不变。$0<x<ct$ 时，$\varphi_{\text{odd}}(x-ct)=-\varphi(ct-x)$；integral 拆成 $[x-ct,\,ct-x]$ 和 $[ct-x,\,x+ct]$ 两段，前一段关于 0 symmetric，odd function 在上面 integrate 为 0：

$$u(x,t)=\tfrac12\big[\varphi(x+ct)-\varphi(ct-x)\big]+\frac1{2c}\int_{ct-x}^{ct+x}\psi(s)\,ds,\qquad0<x<ct$$

**例。** $c=1$，$\psi=0$，$\varphi$ 是以 $x=3$ 为中心、半宽 $0.8$、高 1 的 triangle。往左走的那一半在 $t=2.2$ 时碰到 $x=0$。$t=2.6$、$x=0.2$：$u=\tfrac12[\varphi(2.8)-\varphi(2.4)]=\tfrac12[0.75-0.25]=0.25$。$t=6$、$x=3$：$u=\tfrac12[\varphi(9)-\varphi(3)]=\tfrac12[0-1]=-\tfrac12$，反弹回来的那一半倒过来了。

::fig[ma4221-reflect] 灰色 region 是虚构的 odd extension。它里面那个倒着的 pulse 往右走，正好在真实的 pulse 撞墙时从墙里走出来，替它完成反弹。

Neumann condition $u_x(0,t)=0$（自由端）用 even extension，同样的论证给出 $u_x(0,t)=0$，反弹回来的 pulse 不倒过来。

:::wrong Initial velocity 的 bump 和 initial displacement 的 bump 一样，分成两半各自走开

## [heat] Heat equation：maximum principle、heat kernel 与 distribution

:::skip
能写出并证明 weak maximum principle、用它和 energy 各证一次 uniqueness，能从 scaling 推出 heat kernel，按定义算 $H'=\delta$，用 $u=\int S(x-y,t)\varphi(y)\,dy$ 解 box 形 data，就可以去第 6 站。

### Weak maximum principle

开头那根 rod 的温度从来没有超过初始的最高温度，这是对的吗？在 $0\le x\le l$、$0\le t\le T$ 的 rectangle 上看 $u_t=ku_{xx}$。把 rectangle 的底边和两条侧边合起来叫 parabolic boundary $\Gamma$，顶边 $t=T$ 不算。

> Weak maximum principle：$u$ 在整个 closed rectangle 上的 maximum 和 minimum，都在 parabolic boundary 上取到。

::fig[ma4221-maxp] 彩色三条边是 parabolic boundary。证明要排除的是 maximum 落在内部或顶边。

**证明。** 取 $k=1$（一般的 $k$ 只是把 $x$ 换个 scale）。记 $M=\max_\Gamma u$。先看一个更容易的情形：如果 $v$ 满足 $v_t-v_{xx}<0$（严格小于），$v$ 的 maximum 不能落在 $\Gamma$ 之外。因为假设落在 $(x_0,t_0)$，$0<x_0<l$，$0<t_0\le T$：

- $x_0$ 在 $x$ 方向是内部点，对 $x$ 的 second derivative test 给出 $v_{xx}(x_0,t_0)\le0$；
- $t_0<T$ 时 $v_t(x_0,t_0)=0$；$t_0=T$ 时 $v(x_0,t)\le v(x_0,T)$ 对 $t<T$ 成立，从下面逼近的 difference quotient 非负，$v_t(x_0,T)\ge0$。

两条合起来 $v_t-v_{xx}\ge0$，和假设矛盾。

$u$ 本身只满足 $u_t-u_{xx}=0$，上面的论证会得到 $0\ge0$，推不出矛盾。所以把它往下压一点：$v=u-\varepsilon t$，$\varepsilon>0$，则 $v_t-v_{xx}=-\varepsilon<0$。由刚才的结论，在整个 rectangle 上

$$v\le\max_\Gamma v\le\max_\Gamma u=M$$

（第二个不等号因为 $-\varepsilon t\le0$。）于是 $u=v+\varepsilon t\le M+\varepsilon T$。这对每个 $\varepsilon>0$ 成立，令 $\varepsilon\to0$，$u\le M$。Minimum 的情形对 $-u$ 用同样的论证。

**例。** $u=1-x^2-2t$ 在 $0\le x\le1$、$0\le t\le1$ 上。核对：$u_t=-2$，$u_{xx}=-2$，满足 $u_t=u_{xx}$。Parabolic boundary 上：底边 $1-x^2\in[0,1]$；左边 $x=0$，$1-2t\in[-1,1]$；右边 $x=1$，$-2t\in[-2,0]$。所以 maximum 是 1，在 $(0,0)$；minimum 是 $-2$，在 $(1,1)$。内部任取一点，例如 $(0.5,0.5)$：$1-0.25-1=-0.25$，在 $[-2,1]$ 里。

**Uniqueness 与 stability。** 设 $u_1,u_2$ 在 $[0,l]$ 上满足同一个 heat equation，有相同的 initial data 和 Dirichlet data。$w=u_1-u_2$ 在 $\Gamma$ 上为 0，由 maximum principle $w\le0$，由 minimum principle $w\ge0$，所以 $w\equiv0$。如果 data 不同，对 $w$ 和 $-w$ 用 maximum principle：

$$\max_{\text{rectangle}}|u_1-u_2|\le\max_\Gamma|u_1-u_2|$$

Boundary data 差一点，solution 处处只差那么一点，这就是 stability。

### Energy 方法

另一种证 uniqueness 的办法不用 maximum principle。还是 $w=u_1-u_2$，$w_t=kw_{xx}$，$w(x,0)=0$，$w(0,t)=w(l,t)=0$。令 $e(t)=\int_0^lw^2\,dx$：

$$\frac{de}{dt}=2\int_0^lw\,w_t\,dx=2k\int_0^lw\,w_{xx}\,dx=2k\big[w\,w_x\big]_0^l-2k\int_0^lw_x^2\,dx\le0$$

第三个等号是 integration by parts，boundary term 因为 $w(0,t)=w(l,t)=0$ 而为 0。所以 $e(t)\le e(0)=0$，又 $e\ge0$，$e\equiv0$，$w\equiv0$。同样的计算对一般的 data 给出 $\int_0^l(u_1-u_2)^2dx$ 随 $t$ 不增：heat equation 在 $L^2$ 的意义下也是 stable 的。

### Heat kernel：从 scaling 出发

在 whole line 上解 $u_t=u_{xx}$，$u(x,0)=\varphi(x)$。先找一个特别的 solution。

**Scaling。** 如果 $u(x,t)$ 是 solution，$u(\lambda x,\lambda^2t)$ 也是：对 $t$ 求 derivative 多出 $\lambda^2$，对 $x$ 求两次也多出 $\lambda^2$，两边一起乘 $\lambda^2$。所以 $x$ 和 $\sqrt t$ 是同一种“单位”，组合 $z=x/\sqrt t$ 在 scaling 下不变。

**Conservation。** $\dfrac{d}{dt}\displaystyle\int u\,dx=\int u_{xx}\,dx=\big[u_x\big]_{-\infty}^\infty=0$（$u_x$ 在无穷远为 0 时）。总热量不变。

找一个只依赖 $z$、又守恒的 solution。$\int v(x/\sqrt t)\,dx=\sqrt t\int v(z)\,dz$ 随 $t$ 增长，要守恒得再除以 $\sqrt t$，所以试

$$u=\frac1{\sqrt t}\,v(z),\qquad z=\frac x{\sqrt t}$$

逐项求 derivative，$z_t=-\tfrac12xt^{-3/2}=-\tfrac z{2t}$，$z_x=t^{-1/2}$：

$$u_t=-\tfrac12t^{-3/2}v+t^{-1/2}v'\cdot\Big(-\frac z{2t}\Big)=-\tfrac12t^{-3/2}\big(v+zv'\big),\qquad u_{xx}=t^{-1/2}\cdot t^{-1}v''=t^{-3/2}v''$$

$u_t=u_{xx}$ 两边消去 $t^{-3/2}$：

$$v''+\tfrac12\big(v+zv'\big)=0\qquad\Longleftrightarrow\qquad\Big(v'+\tfrac12zv\Big)'=0$$

因为 $(zv)'=v+zv'$。所以 $v'+\tfrac12zv=C$。要一个 even 的 $v$（向左向右 symmetric 地扩散），$v'(0)=0$，代 $z=0$ 得 $C=0$。$v'=-\tfrac12zv$ 是 separable ODE，$v=Ae^{-z^2/4}$。总热量取 1：$\int Ae^{-z^2/4}dz=A\cdot2\sqrt\pi=1$，$A=\dfrac1{2\sqrt\pi}$。代回去，并把 $t$ 换成 $kt$ 得到一般的 $k$：

$$S(x,t)=\frac1{\sqrt{4\pi kt}}\,e^{-x^2/(4kt)}$$

叫 heat kernel，也叫 fundamental solution。

### $S$ 的 initial data 是什么：$\delta$ 与 distribution

$t\to0^+$ 时 $S(x,t)$ 在 $x\ne0$ 处趋于 0，在 $x=0$ 处趋于 $\infty$，而 $\int S\,dx$ 始终是 1。没有一个 function 是这样的。但拿 $S$ 去和一个 continuous 的 $\varphi$ 做 integral，limit 是清楚的。取 $k=1$、$\varphi=\cos x$，用 Gaussian integral $\int e^{-ax^2}\cos bx\,dx=\sqrt{\pi/a}\,e^{-b^2/(4a)}$，$a=\tfrac1{4t}$，$b=1$：

$$\int_{-\infty}^\infty S(x,t)\cos x\,dx=\frac1{\sqrt{4\pi t}}\sqrt{4\pi t}\,e^{-t}=e^{-t}$$

$t=1,0.1,0.01$ 时分别是 $0.368$、$0.905$、$0.990$，趋于 $\cos0=1$。

::fig[ma4221-delta] $S$ 越来越窄、越来越高，curve 下的 area 始终是 1，和 $\cos x$ 的 integral 趋于 $\cos0$。

所以 $S(\cdot,t)$ 的 limit 应该理解成“把 $\varphi$ 送到 $\varphi(0)$ 的那个操作”。把这个想法做成定义：

- **Test function**：$C^\infty$、在某个有界 interval 外为 0 的 function $\phi$。全体记作 $\mathcal D$。
- **Distribution**：$\mathcal D$ 上的 continuous linear functional，记作 $(F,\phi)$。每个 locally integrable 的 $f$ 给出一个 distribution $(f,\phi)=\int f\phi\,dx$。
- **Dirac delta**：$(\delta,\phi)=\phi(0)$。它是 linear 的，但不来自任何 function：假如 $(\delta,\phi)=\int g\phi$，对所有在 0 附近为 0 的 $\phi$ 都有 $\int g\phi=0$，于是 $g=0$ 几乎处处，那么对所有 $\phi$ 都有 $\int g\phi=0$，和 $\phi(0)\ne0$ 的 $\phi$ 矛盾。
- **Derivative**：对 differentiable 的 $f$，integration by parts 给出 $\int f'\phi=\big[f\phi\big]-\int f\phi'=-\int f\phi'$（$\phi$ 在远处为 0，boundary term 消失）。对一般的 distribution 就拿这个当定义：$(F',\phi)=-(F,\phi')$。

用定义算 Heaviside function $H$（$x>0$ 时为 1，$x<0$ 时为 0）的 derivative：

$$(H',\phi)=-\int_{-\infty}^\infty H\phi'\,dx=-\int_0^\infty\phi'\,dx=-\big[\phi\big]_0^\infty=\phi(0)=(\delta,\phi)$$

所以 $H'=\delta$：一个跳了 1 的 function，derivative 是集中在跳处、总量为 1 的 $\delta$。再算 $|x|$：在 classical 意义下 $|x|'=\operatorname{sgn}x$，而

$$(\operatorname{sgn}',\phi)=-\int_{-\infty}^\infty\operatorname{sgn}(x)\,\phi'(x)\,dx=\int_{-\infty}^0\phi'\,dx-\int_0^\infty\phi'\,dx=\phi(0)-\big(-\phi(0)\big)=2\phi(0)$$

所以 $|x|''=2\delta$，coefficient 2 正是 $\operatorname{sgn}$ 在 0 处跳的高度。在这个意义下 $S(x,t)\to\delta(x)$ 指的是 $(S(\cdot,t),\phi)\to\phi(0)$ 对每个 test function 成立；上面用的 $\cos x$ 不在 $\mathcal D$ 里，但对有界 continuous 的 $\varphi$ 这个 limit 同样成立。

### Solution formula

$S(x-y,t)$ 是 initial data 为 $\delta(x-y)$ 的 solution（heat equation 对平移不变）。Initial data $\varphi(x)=\int\delta(x-y)\varphi(y)\,dy$ 是许多个 $\delta$ 按 $\varphi(y)$ 加权的叠加，由 superposition：

$$u(x,t)=\int_{-\infty}^\infty S(x-y,t)\,\varphi(y)\,dy=\frac1{\sqrt{4\pi kt}}\int_{-\infty}^\infty e^{-(x-y)^2/(4kt)}\varphi(y)\,dy$$

直接核对：$S$ 满足 heat equation，对 $x,t$ 的 derivative 可以拿进 integral（$S$ 在远处 decay 得极快），所以 $u$ 满足 heat equation；$t\to0^+$ 时由上一小节，$u(x,t)\to\varphi(x)$。$\varphi$ 有界 continuous 时这就是 solution。

**例：box。** $k=1$，$\varphi=1$（$|x|<1$），$\varphi=0$（其他）。

$$u(x,t)=\int_{-1}^{1}\frac{e^{-(x-y)^2/(4t)}}{\sqrt{4\pi t}}\,dy$$

令 $p=\dfrac{x-y}{\sqrt{4t}}$，$dy=-\sqrt{4t}\,dp$，$y=-1$ 对应 $p=\tfrac{x+1}{\sqrt{4t}}$，$y=1$ 对应 $p=\tfrac{x-1}{\sqrt{4t}}$：

$$u(x,t)=\frac1{\sqrt\pi}\int_{(x-1)/\sqrt{4t}}^{(x+1)/\sqrt{4t}}e^{-p^2}\,dp=\tfrac12\Big[\operatorname{erf}\Big(\frac{x+1}{\sqrt{4t}}\Big)-\operatorname{erf}\Big(\frac{x-1}{\sqrt{4t}}\Big)\Big]$$

其中 $\operatorname{erf}(z)=\dfrac2{\sqrt\pi}\displaystyle\int_0^ze^{-p^2}dp$。中心 $x=0$ 处 $u(0,t)=\operatorname{erf}\big(\tfrac1{\sqrt{4t}}\big)$：$t=0.25$ 时 $\operatorname{erf}(1)=0.843$，$t=1$ 时 $\operatorname{erf}(0.5)=0.520$，$t=4$ 时 $\operatorname{erf}(0.25)=0.276$。

::fig[ma4221-kernel] 背景细线是四个固定时刻，前景是连续的变化。彩点是中心，黑点是 $x=2$。

这个例子显示 heat equation 的两个和 wave equation 相反的性质。

**Infinite speed。** Initial data 在 $|x|\ge1$ 处为 0，但 $u(2,0.01)=7.7\times10^{-13}>0$。对任何 $t>0$、任何 $x$，integrand 都是正的，$u(x,t)>0$。热瞬间传到无穷远，只是远处的量极小。

**Smoothing。** $\varphi$ 在 $x=\pm1$ 处有 jump，$u(\cdot,t)$ 对任何 $t>0$ 都是 $C^\infty$ 的：$S$ 是 $C^\infty$ 的，derivative 全落在 $S$ 上。

### Half-line

$0<x<\infty$ 上 $u_t=ku_{xx}$，$u(0,t)=0$。和第 4 站一样用 odd extension，在 whole line 上解，再限制到 $x>0$：

$$u(x,t)=\int_0^\infty\big[S(x-y,t)-S(x+y,t)\big]\varphi(y)\,dy$$

$\varphi(y)$ 在 $y<0$ 处是 $-\varphi(-y)$，换元 $y\to-y$ 就变成第二项。取 $\varphi\equiv1$：用上面同样的换元，$\int_0^\infty S(x-y,t)\,dy=\tfrac12\big[1+\operatorname{erf}\big(\tfrac x{\sqrt{4kt}}\big)\big]$，$\int_0^\infty S(x+y,t)\,dy=\tfrac12\big[1-\operatorname{erf}\big(\tfrac x{\sqrt{4kt}}\big)\big]$，相减

$$u(x,t)=\operatorname{erf}\Big(\frac x{\sqrt{4kt}}\Big)$$

初温处处为 1 的半无限长 rod，端点突然降到 0，$k=1$ 时 $x=1$ 处在 $t=1$ 降到 $\operatorname{erf}(0.5)=0.520$。Neumann condition $u_x(0,t)=0$ 用 even extension，第二项前面是加号；$\varphi\equiv1$ 时得到 $u\equiv1$，绝热端点，温度一直不变。

### 和 wave equation 对照

| | wave equation | heat equation |
|---|---|---|
| 传播 speed | 有限，$\le c$ | 无限 |
| Singularity | 沿 characteristic 平移，不变 | $t>0$ 立刻消失 |
| $t<0$ 方向 | 同样 well-posed | ill-posed（第 2 站） |
| Maximum principle | 没有 | 有 |
| $t\to\infty$ | energy 守恒，不 decay | bounded interval 上 decay 到 steady state |

Wave equation 没有 maximum principle：hammer blow 的 initial position 处处为 0，但 $u(0,t)$ 在 $t\ge1$ 时是 1，比 initial 和 boundary 上的值都大。

:::wrong Maximum principle 说温度只降不升，所以每一点的温度都随 $t$ 减小
Maximum principle 管的是整个 rectangle 的 maximum，不是每一点。Box 例子里 $x=2$ 处：$t=0$ 时 $u=0$，$t=0.25$ 时 $0.079$，$t=1$ 时 $0.223$，到 $t\approx1.82$ 涨到最大值 $0.242$，之后才慢慢下降（$t=4$ 时 $0.217$）。中心的热流过来，那一点先升温。整体的 maximum（$t=0$ 时的 1）确实不再被超过。
:::

:::edge Whole line 上的 uniqueness 需要 growth condition
上面的 uniqueness 证明都在 bounded interval 上。在 whole line 上，存在不恒为 0、initial data 却为 0 的 solution，它在 $|x|\to\infty$ 时增长得比 $e^{ax^2}$ 还快。所以 whole line 上的 uniqueness theorem 要加上 $|u(x,t)|\le Ae^{ax^2}$ 这样的条件，solution formula 给出的正是这个 class 里唯一的 solution。这一点的证明不在这门课的范围里。
:::

:::back
Half-line 的 odd extension 和[第 4 站](#wave)的 reflection 是同一个想法。
:::

## [sep] Separation of variables 与 eigenvalue problem

:::skip
能对 Dirichlet、Neumann、Robin condition 分三种情形求出 eigenvalue 和 eigenfunction，写出 heat 和 wave equation 的 series solution 并算出 coefficient，说出 Neumann heat problem 趋于什么，就可以去第 7 站。
:::

### Bounded interval 上为什么要换办法

Rod 只占 $0<x<l$，两端温度保持为 0：

$$u_t=ku_{xx},\qquad u(0,t)=u(l,t)=0,\qquad u(x,0)=\varphi(x)$$

第 5 站的 heat kernel 是为 whole line 造的，在 bounded interval 上要用两次 reflection、得到无穷多项 image，写起来很难用。这里换一个思路：先找形状最简单的 solution，再把它们加起来。

最简单的形状是“空间上的样子不变，只是整体按某个时间规律缩放”：$u=X(x)T(t)$。代进 equation：

$$X(x)T'(t)=kX''(x)T(t)\qquad\Longrightarrow\qquad\frac{T'(t)}{kT(t)}=\frac{X''(x)}{X(x)}$$

左边只依赖 $t$，右边只依赖 $x$。固定 $x$ 让 $t$ 变，右边不动，所以左边是 constant；同理右边也是那个 constant。记为 $-\lambda$：

$$X''+\lambda X=0,\qquad T'=-\lambda kT$$

Boundary condition 落在 $X$ 上：$u(0,t)=X(0)T(t)=0$ 对所有 $t$ 成立，$T\not\equiv0$，所以 $X(0)=0$；同理 $X(l)=0$。

### Eigenvalue problem：$\lambda$ 只能取一串离散的值

$X''+\lambda X=0$，$X(0)=X(l)=0$，要找 $X\not\equiv0$ 的 solution。不知道 $\lambda$ 的符号，三种情形都要看。

- $\lambda=\beta^2>0$：$X=C\cos\beta x+D\sin\beta x$。$X(0)=C=0$。$X(l)=D\sin\beta l=0$，要 $D\ne0$ 就得 $\sin\beta l=0$，$\beta=\dfrac{n\pi}l$，$n=1,2,\dots$
- $\lambda=0$：$X=C+Dx$。$X(0)=C=0$，$X(l)=Dl=0$，$D=0$。没有非零 solution。
- $\lambda=-\gamma^2<0$：$X=C\cosh\gamma x+D\sinh\gamma x$。$X(0)=C=0$，$X(l)=D\sinh\gamma l=0$，而 $\gamma l>0$ 时 $\sinh\gamma l>0$，$D=0$。没有。

所以

$$\lambda_n=\Big(\frac{n\pi}l\Big)^2,\qquad X_n(x)=\sin\frac{n\pi x}l,\qquad n=1,2,3,\dots$$

$\lambda_n$ 叫 eigenvalue，$X_n$ 叫 eigenfunction：它们是 operator $-\dfrac{d^2}{dx^2}$ 在这个 boundary condition 下的 eigenvalue 和 eigenvector。（Complex 的 $\lambda$ 为什么不用考虑，第 7 站证明。）对应的 $T_n=e^{-\lambda_nkt}$，separated solution $e^{-\lambda_nkt}\sin\frac{n\pi x}l$。Equation 和 boundary condition 都是 linear homogeneous 的，superposition：

$$u(x,t)=\sum_{n=1}^\infty A_ne^{-(n\pi/l)^2kt}\sin\frac{n\pi x}l$$

$t=0$ 要等于 $\varphi$：$\varphi(x)=\sum A_n\sin\frac{n\pi x}l$。这叫 $\varphi$ 的 Fourier sine series，coefficient 是（第 7 站推导）

$$A_n=\frac2l\int_0^l\varphi(x)\sin\frac{n\pi x}l\,dx$$

### 例：$u(x,0)=x$

$l=1$，$k=1$，$\varphi(x)=x$。Integration by parts：

$$\int_0^1x\sin(m\pi x)\,dx=\Big[-\frac{x\cos m\pi x}{m\pi}\Big]_0^1+\int_0^1\frac{\cos m\pi x}{m\pi}\,dx=-\frac{\cos m\pi}{m\pi}+0=\frac{(-1)^{m+1}}{m\pi}$$

所以 $A_m=\dfrac{2(-1)^{m+1}}{m\pi}$，

$$u(x,t)=\sum_{m=1}^\infty\frac{2(-1)^{m+1}}{m\pi}\,e^{-m^2\pi^2t}\sin m\pi x$$

第 $m$ 项相对第一项多了 factor $\tfrac1me^{-(m^2-1)\pi^2t}$。$t=0.1$ 时 $m=2$ 是 $\tfrac12e^{-3\pi^2\times0.1}=\tfrac12e^{-2.96}=0.026$，$m=3$ 是 $\tfrac13e^{-7.9}=1.2\times10^{-4}$。所以没过多久，solution 就只剩第一项 $\tfrac2\pi e^{-\pi^2t}\sin\pi x$：一个 sine 形的拱，整体按 $e^{-\pi^2t}$ decay。$x=0.5$ 处的实际数值：

| $t$ | series 的和 | 只留 $m=1$ |
|---|---|---|
| 0.05 | 0.3862 | 0.3887 |
| 0.1 | 0.23724 | 0.23727 |
| 0.2 | 0.088434 | 0.088434 |

::fig[ma4221-sepheat] 动图里彩线是 series 的和，虚线是第一项。一开始两者差得远（initial data 是斜线），$t=0.1$ 以后几乎重合。

Data $\varphi(1)=1$ 和 boundary condition $u(1,t)=0$ 在角上冲突，series 在 $t=0$、$x=1$ 处 converge 到 0 而不是 1；$t>0$ 时 factor $e^{-m^2\pi^2t}$ 让 series converge 得极快，这个冲突立刻消失。这类 series 在什么意义下等于 $\varphi$，是第 7 站的问题。

### Wave equation：同一组 eigenfunction，不同的时间规律

两端固定的 string：$u_{tt}=c^2u_{xx}$，$u(0,t)=u(l,t)=0$，$u(x,0)=\varphi$，$u_t(x,0)=\psi$。同样代 $u=X(x)T(t)$：

$$\frac{T''}{c^2T}=\frac{X''}X=-\lambda$$

$X$ 的问题和上面完全一样，$\lambda_n=(n\pi/l)^2$，$X_n=\sin\frac{n\pi x}l$。$T$ 满足 $T''+\lambda_nc^2T=0$，是 harmonic oscillator：

$$T_n=A_n\cos\frac{n\pi ct}l+B_n\sin\frac{n\pi ct}l$$

$$u(x,t)=\sum_{n=1}^\infty\Big(A_n\cos\frac{n\pi ct}l+B_n\sin\frac{n\pi ct}l\Big)\sin\frac{n\pi x}l$$

$t=0$：$\varphi=\sum A_n\sin\frac{n\pi x}l$；对 $t$ 求 derivative 再令 $t=0$：$\psi=\sum\frac{n\pi c}lB_n\sin\frac{n\pi x}l$。所以

$$A_n=\frac2l\int_0^l\varphi\sin\frac{n\pi x}l\,dx,\qquad B_n=\frac2{n\pi c}\int_0^l\psi\sin\frac{n\pi x}l\,dx$$

第 $n$ 个 mode 的 angular frequency 是 $\frac{n\pi c}l$，全是最低那个的整数倍。这就是弦乐器的 harmonics：一根 string 只能以这一串 frequency 振动。

**例。** $l=\pi$，$c=1$，$\varphi=0$，$\psi=1$。$A_n=0$。

$$B_n=\frac2{n\pi}\int_0^\pi\sin nx\,dx=\frac2{n\pi}\cdot\frac{1-(-1)^n}n=\begin{cases}\dfrac4{\pi n^2}&n\text{ odd}\\0&n\text{ even}\end{cases}$$

$$u(x,t)=\frac4\pi\sum_{n\text{ odd}}\frac{\sin nt\,\sin nx}{n^2}$$

用第 4 站核对。$x=\tfrac\pi2$、$t=0.5$ 时 $[x-t,x+t]=[1.07,2.07]$ 整个在 $(0,\pi)$ 里，两端的固定还没有影响到这一点，d'Alembert 给出 $u=\tfrac12\int_{x-t}^{x+t}1\,ds=t=0.5$。Series 取前 4000 项算出 $0.50000001$。$t=\tfrac\pi2$ 时 interval 是 $[0,\pi]$，仍然 $u=\tfrac\pi2=1.5708$，series 给出 $1.57072$。

::fig[ma4221-strike] 用 odd extension 加 d'Alembert 画出的形状，和 series 是同一个 function。period 是 $2\pi$，因为每个 mode 的 frequency 都是奇数。

### Neumann condition：多出 $\lambda=0$

两端绝热的 rod：$u_x(0,t)=u_x(l,t)=0$。同样得到 $X''+\lambda X=0$，条件变成 $X'(0)=X'(l)=0$。

- $\lambda=\beta^2>0$：$X'=-C\beta\sin\beta x+D\beta\cos\beta x$。$X'(0)=D\beta=0$，$D=0$；$X'(l)=-C\beta\sin\beta l=0$，$\beta=\frac{n\pi}l$，$X_n=\cos\frac{n\pi x}l$。
- $\lambda=0$：$X=C+Dx$，$X'=D=0$，$X=C$。**Constant 是 eigenfunction**，eigenvalue 是 0。
- $\lambda=-\gamma^2<0$：$X'=C\gamma\sinh\gamma x+D\gamma\cosh\gamma x$，$X'(0)=D\gamma=0$，$X'(l)=C\gamma\sinh\gamma l=0$，$C=0$。没有。

$\lambda_0=0$ 对应的 $T$ 满足 $T'=0$，是 constant。所以

$$u(x,t)=\tfrac12A_0+\sum_{n=1}^\infty A_ne^{-(n\pi/l)^2kt}\cos\frac{n\pi x}l,\qquad A_n=\frac2l\int_0^l\varphi\cos\frac{n\pi x}l\,dx$$

$t\to\infty$ 时其余项全部 decay，$u\to\tfrac12A_0=\dfrac1l\int_0^l\varphi\,dx$，是初始温度的 average。

**例。** $l=1$，$k=1$，$\varphi=x$。$A_0=2\int_0^1x\,dx=1$。$n\ge1$：

$$\int_0^1x\cos n\pi x\,dx=\Big[\frac{x\sin n\pi x}{n\pi}\Big]_0^1-\int_0^1\frac{\sin n\pi x}{n\pi}dx=0+\Big[\frac{\cos n\pi x}{(n\pi)^2}\Big]_0^1=\frac{(-1)^n-1}{n^2\pi^2}$$

$A_n=\dfrac{2[(-1)^n-1]}{n^2\pi^2}$，偶数 $n$ 为 0，奇数 $n$ 为 $-\dfrac4{n^2\pi^2}$：

$$u(x,t)=\frac12-\frac4{\pi^2}\sum_{n\text{ odd}}\frac{e^{-n^2\pi^2t}\cos n\pi x}{n^2}$$

左端 $x=0$ 处，$t=0.05$ 时 $u=0.252$，$t=0.2$ 时 $0.444$，趋于 $0.5$。总热量 $\int_0^1u\,dx$：每个 $\cos n\pi x$ 的 integral 为 0，所以始终是 $\tfrac12$，和“两端绝热、热量跑不掉”一致。

### Heat 和 wave 的 mode 对照

| | heat：$T_n$ | wave：$T_n$ |
|---|---|---|
| 形式 | $e^{-\lambda_nkt}$ | $\cos(\sqrt{\lambda_n}\,ct)$、$\sin(\sqrt{\lambda_n}\,ct)$ |
| $n$ 大的 mode | decay 最快 | oscillate 最快，amplitude 不变 |
| $t\to\infty$ | 只剩 $\lambda$ 最小的那个 mode（Dirichlet 时趋于 0，Neumann 时趋于 average）| 没有 limit，按 period $2l/c$ 重复 |

两者用同一个 eigenvalue problem，区别只在 $T$ 的 ODE 是 first-order 还是 second-order。第 5 站说 heat equation 立刻 smoothing、wave equation 保留 corner，在这里看得很具体：corner 需要很多 high-$n$ 的 mode 才拼得出来，heat equation 让它们以 $e^{-n^2\cdots}$ 的速度消失，wave equation 让它们原样保留。

### Robin condition：eigenvalue 由一个 transcendental equation 决定

$X''+\lambda X=0$，$X(0)=0$，$X'(1)+aX(1)=0$，先取 $a=1$（右端向温度为 0 的空气散热）。

- $\lambda=\beta^2>0$：$X(0)=0$ 给出 $X=\sin\beta x$。$X'(1)+X(1)=\beta\cos\beta+\sin\beta=0$，即 $\tan\beta=-\beta$。
- $\lambda=0$：$X=Dx$，$X'(1)+X(1)=2D=0$，没有。
- $\lambda=-\gamma^2<0$：$X=\sinh\gamma x$，$X'(1)+X(1)=\gamma\cosh\gamma+\sinh\gamma$，两项都是正的，不可能为 0，没有。

$\tan\beta=-\beta$ 解不出 closed form，用图看 root 在哪里，再数值求出来。

::fig[ma4221-robin] $\tan\beta$ 的每个 branch 和直线 $y=-\beta$ 恰好交一次，交点在 $(n-\tfrac12)\pi$ 和 $n\pi$ 之间。

前三个是 $\beta_1=2.029$、$\beta_2=4.913$、$\beta_3=7.979$，$\lambda_n=\beta_n^2=4.12$、$24.14$、$63.66$。$n$ 大时 $\tan\beta=-\beta$ 是一个很大的负数，$\beta$ 贴近 branch 的左端 $(n-\tfrac12)\pi$，所以 $\lambda_n\approx(n-\tfrac12)^2\pi^2$。Heat equation 的 solution 是 $\sum A_ne^{-\beta_n^2kt}\sin\beta_nx$，coefficient 照样由 orthogonality 给出（第 7 站证明这组 $\sin\beta_nx$ 两两 orthogonal），只是 $\beta_n$ 不再是 $\pi$ 的整数倍。

:::wrong 两端绝热的 rod 和两端保持 0 度的 rod 一样，温度最后趋于 0
两端绝热时 Neumann problem 有 eigenvalue $\lambda_0=0$，对应的 mode 是 constant，不 decay。上面 $\varphi=x$ 的例子最后趋于 $0.5$，左端 $x=0$ 处从 0 升到 $0.25$（$t=0.05$）、$0.44$（$t=0.2$）。物理上也是如此：热量跑不出去，只能在 rod 里摊平。漏掉 $\lambda=0$ 那一种情形，就会丢掉这个最重要的项。
:::

:::edge $a<-1$ 时出现 negative eigenvalue
Robin condition 里 $a<0$ 表示右端的热流方向反过来：$u>0$ 时热从外面流进来，而且端点越热流进越多。$\lambda=-\gamma^2$ 时条件变成 $\gamma\cosh\gamma+a\sinh\gamma=0$，即 $\tanh\gamma=-\gamma/a$。$\tanh\gamma$ 在 0 处的 slope 是 1、之后越来越平，所以直线 $-\gamma/a$ 的 slope $-1/a$ 小于 1 时（即 $a<-1$）才有正的 root。取 $a=-2$：$\tanh\gamma=\gamma/2$，$\gamma=1.915$，$\lambda=-3.667$，heat equation 的这个 mode 是 $e^{+3.667kt}\sinh1.915x$，随时间增长。$a=-1$ 恰好是临界：$X=x$ 满足 $X'(1)-X(1)=0$，$\lambda=0$。
:::

Eigenvalue problem 的做法和 Sturm–Liouville problem 的一般性质，在 MA3220 的[第 4 站](../courses/MA3220.html#adjoint)讲过。

## [fourier] Fourier series：coefficient、orthogonality 与 convergence

:::skip
能从 symmetric boundary condition 推出 orthogonality、写出三种 series 的 coefficient formula，知道 series 在 jump 处 converge 到两侧 average、uniform convergence 要什么条件、Parseval 怎么用来求和，并能用 Fourier transform 解 whole line 上的 heat equation，就可以去第 8 站。
:::

### Orthogonality 从哪里来

第 6 站假定了 $\varphi=\sum A_nX_n$ 可以展开，并且 coefficient 有一个 formula。推 formula 靠的是一件事：不同的 eigenfunction 两两 orthogonal，$\int_0^lX_mX_n\,dx=0$（$m\ne n$）。它不是 sine 的巧合，而是来自 boundary condition。

设 $X_1''+\lambda_1X_1=0$、$X_2''+\lambda_2X_2=0$，满足同一组 boundary condition。直接求 derivative 可以验证

$$\frac{d}{dx}\big(-X_1'X_2+X_1X_2'\big)=-X_1''X_2-X_1'X_2'+X_1'X_2'+X_1X_2''=-X_1''X_2+X_1X_2''$$

两边 integrate，并用 $-X_1''=\lambda_1X_1$、$X_2''=-\lambda_2X_2$：

$$(\lambda_1-\lambda_2)\int_0^lX_1X_2\,dx=\Big[-X_1'X_2+X_1X_2'\Big]_0^l$$

如果对任意两个满足 boundary condition 的 function，右边的 bracket 都是 0，就称这组 boundary condition 是 symmetric 的。这时 $\lambda_1\ne\lambda_2$ 推出 $\int X_1X_2=0$。逐个检查：

- Dirichlet：两端 $X_1=X_2=0$，bracket 每一项都含 $X_1$ 或 $X_2$ 的端点值，为 0。
- Neumann：两端 $X_1'=X_2'=0$，同样为 0。
- Periodic（$X(-l)=X(l)$，$X'(-l)=X'(l)$）：两端的 bracket 相等，相减为 0。
- Robin $X'(l)=-aX(l)$：$x=l$ 处 $-X_1'X_2+X_1X_2'=aX_1X_2-aX_1X_2=0$。

所以第 6 站的 $\sin\beta_nx$ 也两两 orthogonal。同一个等式还给出两件事。

**Eigenvalue 是 real 的。** 设 $\lambda$ 是 complex 的，$X$ 是对应的 eigenfunction。取 conjugate，$\bar X$ 满足同一个 boundary condition，eigenvalue 是 $\bar\lambda$。代入 $X_1=X$、$X_2=\bar X$：$(\lambda-\bar\lambda)\int|X|^2=0$，所以 $\lambda=\bar\lambda$。

**Dirichlet 时 eigenvalue 是正的。** $\lambda\int X^2=\int(-X'')X=\big[-X'X\big]_0^l+\int X'^2=\int X'^2$，$X\not\equiv0$ 而两端为 0，$X'\not\equiv0$，所以 $\lambda>0$。这和第 6 站逐个排除 $\lambda\le0$ 的结论一样，但不用解 ODE。同样的论证在高维也成立：drumhead 上 $-\Delta U=\lambda U$、$U|_{\partial D}=0$，由第 8 站的 Green's first identity $\lambda\int_DU^2=\int_D|\nabla U|^2>0$。

### Coefficient formula 与 best approximation

在 $\varphi=\sum_nA_nX_n$ 两边乘 $X_m$ 再 integrate，orthogonality 让 $n\ne m$ 的项全部消失：

$$A_m=\frac{\int\varphi X_m\,dx}{\int X_m^2\,dx}$$

三种常用的 series：

| series | interval | function | coefficient |
|---|---|---|---|
| sine | $(0,l)$ | $\sin\frac{n\pi x}l$，$\int\sin^2=\frac l2$ | $A_n=\frac2l\int_0^l\varphi\sin\frac{n\pi x}l$ |
| cosine | $(0,l)$ | $1$、$\cos\frac{n\pi x}l$ | $A_n=\frac2l\int_0^l\varphi\cos\frac{n\pi x}l$，constant term $\frac12A_0$ |
| full | $(-l,l)$ | $1$、$\cos\frac{n\pi x}l$、$\sin\frac{n\pi x}l$ | $A_n=\frac1l\int_{-l}^l\varphi\cos\frac{n\pi x}l$，$B_n=\frac1l\int_{-l}^l\varphi\sin\frac{n\pi x}l$ |

constant term写成 $\frac12A_0$，是为了让 $A_0$ 也能用同一个 formula：$\int_0^l1^2=l$ 是 $\int_0^l\cos^2=\frac l2$ 的两倍。

即使 series 不 converge 到 $\varphi$，这组 coefficient 也有一个确定的意义。只用前 $N$ 个 function，选 $c_1,\dots,c_N$ 让 error $\|\varphi-\sum_{n\le N}c_nX_n\|^2=\int(\varphi-\sum c_nX_n)^2$ 最小。展开，cross term $\int X_mX_n$ 全为 0：

$$\Big\|\varphi-\sum c_nX_n\Big\|^2=\|\varphi\|^2-2\sum c_n\int\varphi X_n+\sum c_n^2\|X_n\|^2=\|\varphi\|^2-\sum A_n^2\|X_n\|^2+\sum(c_n-A_n)^2\|X_n\|^2$$

最后一步用了 $\int\varphi X_n=A_n\|X_n\|^2$ 并配方。所以 $c_n=A_n$ 时 error 最小，最小值是

$$E_N=\|\varphi\|^2-\sum_{n=1}^NA_n^2\|X_n\|^2\ \ge0$$

Fourier coefficient 就是 least squares 的答案。$E_N\ge0$ 对所有 $N$ 成立，得到 Bessel's inequality $\sum A_n^2\|X_n\|^2\le\|\varphi\|^2$。

### 例：$x$ 在 $(0,1)$ 上的三种展开

第 6 站已经算过两个 coefficient：

$$x=\frac2\pi\Big(\sin\pi x-\frac12\sin2\pi x+\frac13\sin3\pi x-\cdots\Big)\qquad(\text{sine})$$

$$x=\frac12-\frac4{\pi^2}\Big(\cos\pi x+\frac19\cos3\pi x+\frac1{25}\cos5\pi x+\cdots\Big)\qquad(\text{cosine})$$

在 $(0,1)$ 里两个 series 都应该 converge 到 $x$，但在 $(0,1)$ 外它们是不同的 function。每个 $\sin n\pi x$ 都是 odd 的、period 2，所以 sine series 在整条 line 上 converge 到的是 $x$ 的 odd periodic extension；cosine series converge 到的是 even periodic extension。

::fig[ma4221-ext] 浅色 interval 外的部分由 extension 决定。Sine series 对应的 extension 在 $x=\pm1,\pm3$ 处有 jump，cosine series 对应的处处 continuous。

### 三种 convergence

$S_N=\sum_{n\le N}f_n$ converge 到 $f$，有三种不同强度的意思：

- **pointwise**：每个固定的 $x$，$S_N(x)\to f(x)$；
- **uniform**：$\max_x|S_N(x)-f(x)|\to0$；
- **$L^2$（mean-square）**：$\int|S_N-f|^2dx\to0$。

Uniform 推出另外两个。反过来不成立，例子是 $[0,1]$ 上的 $f_n=x^n-x^{n-1}$：partial sum telescope，$S_N=x^N-1$。

- Pointwise：$0\le x<1$ 时 $x^N\to0$，$S_N\to-1$；$x=1$ 时 $S_N=0$。所以 limit 是 $g=-1$（$x<1$）、$g(1)=0$。
- 不 uniform：$\sup_{[0,1)}|S_N-g|=\sup_{[0,1)}x^N=1$，对每个 $N$ 都是 1。
- $L^2$：$\int_0^1|S_N-g|^2=\int_0^1x^{2N}dx=\frac1{2N+1}\to0$，converge。

Error 集中在 $x=1$ 附近越来越窄的一段里：高度不降，宽度趋于 0。下面的 Gibbs phenomenon 是同一回事。

### Fourier series converge 到什么

下面三个 theorem 对 sine、cosine、full 三种 series 都成立，$\varphi_{\text{ext}}$ 指对应的那种 periodic extension。

1. **$L^2$**：只要 $\int|\varphi|^2<\infty$，series 在 $L^2$ 意义下 converge 到 $\varphi$。
2. **Pointwise**：$\varphi$ 和 $\varphi'$ piecewise continuous 时，series 在每一点 converge 到 $\tfrac12\big[\varphi_{\text{ext}}(x^+)+\varphi_{\text{ext}}(x^-)\big]$。在 $\varphi_{\text{ext}}$ continuous 的点就是 $\varphi_{\text{ext}}(x)$，在 jump 处是两侧的 average。
3. **Uniform**：$\varphi\in C^2[a,b]$ 并且满足产生这组 function 的 boundary condition（sine：两端为 0；cosine：两端 $\varphi'=0$；full：$\varphi(-l)=\varphi(l)$、$\varphi'(-l)=\varphi'(l)$）时，series 在 $[a,b]$ 上 uniformly converge。

拿上面的例子检验。

- $x$ 的 sine series 在 $x=1$ 处：odd periodic extension 从左边的 1 跳到右边的 $-1$，series converge 到 $\tfrac12(1-1)=0$。直接代 $x=1$，每一项 $\sin n\pi=0$，确实是 0。$\varphi(1)=1\ne0$，不满足 sine 的 boundary condition，theorem 3 不保证 uniform；实际上也不 uniform（见下面 Gibbs）。
- $e^x$ 在 $(-1,1)$ 上的 full series，在 $x=\pm1$ 处 periodic extension 从 $e$ 跳到 $e^{-1}$，series converge 到 $\tfrac12(e+e^{-1})=\cosh1=1.543$。
- $x(1-x)$ 在 $(0,1)$ 上：$C^2$，两端为 0，sine series uniformly converge。

:::edge Theorem 3 是 sufficient condition
$x$ 的 cosine series 不满足 theorem 3：$\varphi'=1$，两端不为 0。但它的 coefficient 是 $\frac4{\pi^2n^2}$，$\sum\frac4{\pi^2n^2}<\infty$，而 $|A_n\cos n\pi x|\le|A_n|$，由 Weierstrass M-test，series 在整条 line 上 uniformly converge。图里 even extension 处处 continuous，也和这一点一致。判断 uniform convergence 时，coefficient 绝对可和往往比 theorem 3 更好用。
:::

### Gibbs phenomenon

$\varphi\equiv1$ 在 $(0,\pi)$ 上，$A_n=\frac2\pi\int_0^\pi\sin nx\,dx=\frac{2(1-(-1)^n)}{n\pi}$：

$$1=\frac4\pi\Big(\sin x+\frac13\sin3x+\frac15\sin5x+\cdots\Big),\qquad0<x<\pi$$

在 $x=0$ 处 odd extension 从 $-1$ 跳到 1。Partial sum $S_N$（$N=2m-1$）的 derivative 可以求和：

$$S_N'(x)=\frac4\pi\sum_{k=1}^m\cos(2k-1)x=\frac4\pi\cdot\frac{\sin2mx}{2\sin x}$$

（$\sum_{k=1}^m\cos(2k-1)x=\frac{\sin2mx}{2\sin x}$ 可以用 $2\sin x\cos(2k-1)x=\sin2kx-\sin(2k-2)x$ 求和后 telescope 得到。）$S_N'$ 的第一个 zero 在 $x=\frac\pi{2m}$，那里是 $S_N$ 的第一个 peak：

$$S_N\Big(\frac\pi{2m}\Big)=\frac2\pi\int_0^{\pi/2m}\frac{\sin2mx}{\sin x}\,dx\approx\frac2\pi\int_0^{\pi/2m}\frac{\sin2mx}{x}\,dx=\frac2\pi\int_0^\pi\frac{\sin s}s\,ds=1.1790$$

（$x$ 很小时 $\sin x\approx x$；最后令 $s=2mx$。）Peak 的位置趋于 0，高度不趋于 1，而是停在 $1.179$，比 limit 高出 $0.179$，约是 jump 高度 2 的 9%。

::fig[ma4221-gibbs] $N$ 从 1 加到 61。中间越来越平，peak 越来越窄，但高度一直在 1.18 附近。右边是每个 $N$ 的 peak 实际数值。

所以 $\max|S_N-1|$ 不趋于 0，convergence 不 uniform；每个固定的 $x>0$，peak 最终移到它左边，$S_N(x)\to1$，pointwise 仍然成立。只要 $\varphi_{\text{ext}}$ 有 jump，partial sum 在 jump 附近就有这个约 9% 的 overshoot。

### Parseval's identity

$L^2$ convergence 说的是 $E_N\to0$，由上面 $E_N$ 的表达式，它等价于

$$\sum_{n=1}^\infty A_n^2\int X_n^2\,dx=\int\varphi^2\,dx$$

这是 Parseval's identity。用在 $\varphi\equiv1$、$(0,\pi)$ 上：$\int_0^\pi\sin^2nx\,dx=\frac\pi2$，$\int_0^\pi1^2=\pi$，

$$\sum_{n\text{ odd}}\Big(\frac4{n\pi}\Big)^2\frac\pi2=\pi\qquad\Longrightarrow\qquad\sum_{n\text{ odd}}\frac1{n^2}=\frac{\pi^2}8$$

用它核对 $x$ 的 cosine series 在 $x=0$ 处：$\frac12-\frac4{\pi^2}\cdot\frac{\pi^2}8=0$，正是 $\varphi(0)$。再把 even 的部分补上：$\sum_{\text{all}}\frac1{n^2}=\sum_{\text{odd}}+\frac14\sum_{\text{all}}$，所以 $\sum_{\text{all}}\frac1{n^2}=\frac43\cdot\frac{\pi^2}8=\frac{\pi^2}6$。

### Coefficient decay 有多快

| $\varphi$ 在 $(0,1)$ 上，series | extension 的样子 | coefficient |
|---|---|---|
| $1$，sine | 有 jump | $\frac4{n\pi}$（$n$ odd），$\sim\frac1n$ |
| $x$，cosine | continuous，有 corner | $\frac4{n^2\pi^2}$（$n$ odd），$\sim\frac1{n^2}$ |
| $x(1-x)$，sine | continuous，derivative 也 continuous | $\frac8{n^3\pi^3}$（$n$ odd），$\sim\frac1{n^3}$ |

第三行：$2\int_0^1x(1-x)\sin n\pi x\,dx$ 做两次 integration by parts 得 $\frac{4(1-(-1)^n)}{n^3\pi^3}$。规律是 extension 每多一阶 continuous 的 derivative，coefficient 就多一个 $\frac1n$：integration by parts 一次，把 $\varphi$ 的 coefficient 写成 $\varphi'$ 的 coefficient 除以 $n\pi$，再加上端点的 boundary term；extension 在端点不 continuous 时 boundary term 不为 0，decay 就停在那一阶。

### Whole line：Fourier transform

在 whole line 上没有 boundary condition 来选出离散的 eigenvalue，所有 frequency $\xi\in\mathbb R$ 都要用上，sum 变成 integral：

$$\hat f(\xi)=\int_{-\infty}^\infty f(x)e^{-i\xi x}\,dx,\qquad f(x)=\frac1{2\pi}\int_{-\infty}^\infty\hat f(\xi)e^{i\xi x}\,d\xi$$

两条性质就够解 heat equation。

**Derivative 变成乘法。** Integration by parts，$f$ 在无穷远为 0：$\widehat{f'}(\xi)=\int f'e^{-i\xi x}dx=-\int f\cdot(-i\xi)e^{-i\xi x}dx=i\xi\hat f(\xi)$。所以 $\widehat{f''}=-\xi^2\hat f$。

**Convolution 变成乘法。** $(f*g)(x)=\int f(x-y)g(y)\,dy$。

$$\widehat{f*g}(\xi)=\iint f(x-y)g(y)e^{-i\xi x}\,dy\,dx=\int f(z)e^{-i\xi z}dz\int g(y)e^{-i\xi y}dy=\hat f(\xi)\hat g(\xi)$$

中间令 $z=x-y$，$e^{-i\xi x}=e^{-i\xi z}e^{-i\xi y}$。

对 $u_t=ku_{xx}$ 两边按 $x$ 做 Fourier transform，$\xi$ 当作参数：

$$\partial_t\hat u(\xi,t)=-k\xi^2\hat u(\xi,t)\qquad\Longrightarrow\qquad\hat u(\xi,t)=e^{-k\xi^2t}\hat\varphi(\xi)$$

PDE 变成了每个 $\xi$ 各自的一个 ODE。哪个 function 的 transform 是 $e^{-k\xi^2t}$？第 5 站算过 $\int S(x,t)\cos\xi x\,dx$（那里 $k=1$、$\xi=1$），一般地 $a=\frac1{4kt}$、$b=\xi$ 给出 $e^{-k\xi^2t}$；$S$ 是 even 的，$\int S\sin\xi x=0$，所以 $\hat S(\xi,t)=e^{-k\xi^2t}$。于是 $\hat u=\hat S\hat\varphi$，由 convolution 的性质

$$u(x,t)=\int S(x-y,t)\varphi(y)\,dy$$

和第 5 站靠 scaling 猜出来的 formula 一致，这次不用猜。Factor $e^{-k\xi^2t}$ 也解释了 smoothing：frequency $\xi$ 的成分按 $e^{-k\xi^2t}$ decay，高 frequency 最先消失，正是第 6 站 heat 的 mode 的 continuous 版本。Wave equation 做同样的事得到 $\hat u=\hat\varphi\cos(c\xi t)+\hat\psi\frac{\sin(c\xi t)}{c\xi}$，没有 decay 的 factor，所以没有 smoothing。

Fourier series 的 Parseval's identity 在这里对应 Plancherel's theorem：$\int|f|^2dx=\frac1{2\pi}\int|\hat f|^2d\xi$。用在 heat equation 上，$\int u^2dx=\frac1{2\pi}\int e^{-2k\xi^2t}|\hat\varphi|^2d\xi$ 随 $t$ 递减，这是第 5 站 energy 方法的结论的另一种看法。

:::wrong Fourier series converge，所以在 interval 的端点也 converge 到 $\varphi$ 在那里的值

## [harmonic] Laplace equation 与 harmonic function

:::skip
能证明 weak maximum principle，用 Green's first identity 证明 uniqueness 和 Neumann problem 的 compatibility condition，对 rectangle 和 disk 做 separation of variables、写出 Poisson formula，能用 mean value property 和 method of images 算具体的值，就可以去最后一节。
:::

### Maximum principle

开头那块圆板：boundary 温度在 0 和 1 之间，板里任何一点都不会超过 1、低于 0。一般地，$D$ 是 bounded domain，$\Delta u=0$ 在 $D$ 里，$u$ 在 $\bar D$ 上 continuous：

$$\max_{\bar D}u=\max_{\partial D}u,\qquad\min_{\bar D}u=\min_{\partial D}u$$

**证明。** 和第 5 站同一个思路：先造一个严格不等式。$v=u+\varepsilon|\mathbf x|^2$，$\varepsilon>0$，在 $\mathbb R^n$ 里 $\Delta|\mathbf x|^2=2n$，所以 $\Delta v=2n\varepsilon>0$。如果 $v$ 在内部点取到 maximum，那里每个方向的 second derivative $v_{x_ix_i}\le0$，加起来 $\Delta v\le0$，矛盾。所以 $v$ 的 maximum 在 $\partial D$ 上。设 $D$ 包含在半径 $\ell$ 的 ball 里：

$$u\le v\le\max_{\partial D}v\le\max_{\partial D}u+\varepsilon\ell^2$$

令 $\varepsilon\to0$。Minimum 对 $-u$ 用同样的论证。

Corollary 和 heat equation 一样：$\Delta u=f$、$u|_{\partial D}=h$ 的 Dirichlet problem 至多一个 solution（两个 solution 之差是 harmonic 的、在 boundary 上为 0，max 和 min 都是 0），并且 $\max_D|u_1-u_2|\le\max_{\partial D}|h_1-h_2|$。

### Green's first identity：energy 与 Neumann problem

Divergence theorem 用在 vector field $v\nabla u$ 上，$\nabla\cdot(v\nabla u)=\nabla v\cdot\nabla u+v\Delta u$：

$$\int_{\partial D}v\,\frac{\partial u}{\partial n}\,dS=\int_D\nabla v\cdot\nabla u\,d\mathbf x+\int_Dv\,\Delta u\,d\mathbf x$$

$\frac{\partial u}{\partial n}=\nabla u\cdot\mathbf n$ 是沿 outward normal 的 derivative。这叫 Green's first identity。它有三个直接的用处。

**$v=1$：Neumann problem 的 compatibility condition。** $\int_{\partial D}\frac{\partial u}{\partial n}dS=\int_D\Delta u\,d\mathbf x$。所以 $\Delta u=f$、$\frac{\partial u}{\partial n}=g$ 要有 solution，必须

$$\int_{\partial D}g\,dS=\int_Df\,d\mathbf x$$

稳态时，从 boundary 流进的总热量要等于 $D$ 里的 source 消耗掉的总量。

**$v=u$：用 energy 证 uniqueness。** $w=u_1-u_2$，$\Delta w=0$。Dirichlet 时 $w|_{\partial D}=0$，identity 给出 $\int_D|\nabla w|^2=0$，$\nabla w\equiv0$，$w$ 是 constant，boundary 上为 0，所以 $w\equiv0$。Neumann 时 $\frac{\partial w}{\partial n}=0$，同样得到 $\nabla w\equiv0$，但没有条件把 constant 定下来：Neumann problem 的 solution 唯一到差一个 constant。

**Dirichlet principle。** 在所有满足 $w|_{\partial D}=h$ 的 function 里，harmonic 的那个 $u$ 让 energy $E[w]=\frac12\int_D|\nabla w|^2$ 最小。令 $v=u-w$，$v|_{\partial D}=0$：

$$E[w]=\tfrac12\int|\nabla u-\nabla v|^2=E[u]-\int\nabla u\cdot\nabla v+E[v]$$

中间一项由 Green's first identity（$u,v$ 对调角色）等于 $\int_{\partial D}v\frac{\partial u}{\partial n}-\int_Dv\Delta u=0-0$。所以 $E[w]=E[u]+E[v]\ge E[u]$，等号当且仅当 $\nabla v\equiv0$，即 $w=u$。

:::wrong Neumann problem 和 Dirichlet problem 一样，任给 boundary data 都有 solution
Unit disk 里 $\Delta u=0$，$\frac{\partial u}{\partial n}=1$ 在 circle 上：要求 $\int_{\partial D}\frac{\partial u}{\partial n}=2\pi$，而 $\int_D\Delta u=0$，compatibility condition 不满足，没有 solution。物理上是 boundary 处处往里灌热、里面又没有地方消耗，不可能有 steady state。换成 $\frac{\partial u}{\partial n}=\cos\theta$，$\int_0^{2\pi}\cos\theta\,d\theta=0$，满足条件，$u=r\cos\theta+C=x+C$ 就是 solution（$\frac{\partial u}{\partial r}=\cos\theta$），$C$ 任意。
:::

### Rectangle：separation of variables

$(0,\pi)\times(0,\pi)$ 上 $\Delta u=0$，上边 $u(x,\pi)=1$，其余三边为 0。代 $u=X(x)Y(y)$：$X''Y+XY''=0$，$\frac{X''}X=-\frac{Y''}Y=-\lambda$。$X$ 带着两个 homogeneous 的条件 $X(0)=X(\pi)=0$，是第 6 站的 eigenvalue problem：$\lambda=n^2$，$X_n=\sin nx$。$Y''=n^2Y$，$Y(0)=0$：$Y_n=\sinh ny$。

$$u=\sum_{n=1}^\infty A_n\sinh ny\,\sin nx$$

$y=\pi$：$\sum A_n\sinh n\pi\,\sin nx=1$，这是 1 的 sine series，第 7 站算过 coefficient 是 $\frac4{n\pi}$（$n$ odd）：

$$u(x,y)=\sum_{n\text{ odd}}\frac4{n\pi}\,\frac{\sinh ny}{\sinh n\pi}\,\sin nx$$

中心的值：$n=1$ 项 $\frac4\pi\frac{\sinh(\pi/2)}{\sinh\pi}=0.25372$，$n=3$ 项 $\frac4{3\pi}\frac{\sinh(3\pi/2)}{\sinh3\pi}\sin\frac{3\pi}2=-0.00381$，$n=5$ 项 $+0.00010$，和是 $0.25000$。

::fig[ma4221-rect] 正方形 plate 的 steady state 温度。Level curve 从热的上边往下排开，越往下越稀。

$0.25$ 不是巧合。把“1 放在上边”换成放在下边、左边、右边，得到四个 solution，由 symmetry 它们在中心的值相等。四个加起来是 harmonic 的、四条边上都是 1，由 uniqueness 就是 $u\equiv1$。所以每一个在中心都是 $\frac14$。

### Disk：polar coordinate 与 Poisson formula

圆形的 domain 用 polar coordinate，Laplacian 变成

$$\Delta u=u_{rr}+\frac1ru_r+\frac1{r^2}u_{\theta\theta}$$

用两个 function 检验一下：$u=x^2+y^2=r^2$，左边 $\Delta u=2+2=4$，右边 $2+\frac1r\cdot2r+0=4$；$u=x=r\cos\theta$，右边 $0+\frac{\cos\theta}r-\frac{\cos\theta}r=0$，正是 $\Delta x=0$。

$r<a$ 里 $\Delta u=0$，$u(a,\theta)=h(\theta)$。代 $u=R(r)\Theta(\theta)$，乘 $\frac{r^2}{R\Theta}$：

$$\frac{r^2R''+rR'}R=-\frac{\Theta''}\Theta=\lambda$$

$\Theta$ 必须 $2\pi$-periodic（$\theta$ 和 $\theta+2\pi$ 是同一点），所以 $\lambda=n^2$，$\Theta=A\cos n\theta+B\sin n\theta$，$n=0,1,2,\dots$。$R$ 满足 Euler equation $r^2R''+rR'-n^2R=0$，试 $R=r^\alpha$：$\alpha(\alpha-1)+\alpha-n^2=0$，$\alpha=\pm n$；$n=0$ 时是 $R=C+D\log r$。在圆心 $u$ 要有界，$r^{-n}$ 和 $\log r$ 都去掉：

$$u(r,\theta)=\tfrac12A_0+\sum_{n=1}^\infty r^n\big(A_n\cos n\theta+B_n\sin n\theta\big)$$

$r=a$ 时是 $h$ 的 full Fourier series，$A_n=\dfrac1{\pi a^n}\displaystyle\int_0^{2\pi}h(\phi)\cos n\phi\,d\phi$，$B_n$ 同样用 $\sin$。

把 coefficient 代回去，交换 sum 和 integral：

$$u(r,\theta)=\frac1{2\pi}\int_0^{2\pi}h(\phi)\Big[1+2\sum_{n=1}^\infty\Big(\frac ra\Big)^n\cos n(\theta-\phi)\Big]d\phi$$

（$\cos n\theta\cos n\phi+\sin n\theta\sin n\phi=\cos n(\theta-\phi)$。）Bracket 是一个 geometric series。令 $w=\frac rae^{i(\theta-\phi)}$，$|w|<1$：

$$1+2\sum_{n\ge1}\operatorname{Re}w^n=\operatorname{Re}\Big(1+\frac{2w}{1-w}\Big)=\operatorname{Re}\frac{1+w}{1-w}=\frac{\operatorname{Re}\big[(1+w)(1-\bar w)\big]}{|1-w|^2}=\frac{1-|w|^2}{|1-w|^2}$$

（$(1+w)(1-\bar w)=1-|w|^2+(w-\bar w)$，$w-\bar w$ 是纯 imaginary。）$|1-w|^2=1-2\frac ra\cos(\theta-\phi)+\frac{r^2}{a^2}$，分子分母乘 $a^2$：

$$u(r,\theta)=\frac{a^2-r^2}{2\pi}\int_0^{2\pi}\frac{h(\phi)}{a^2-2ar\cos(\theta-\phi)+r^2}\,d\phi$$

这是 Poisson formula。$h\equiv1$ 时 series 只剩 constant term 1，bracket 的 integral 是 $2\pi$，$u\equiv1$，formula 自洽。

**例：开头的圆板。** $a=1$，$h=1$（$0<\theta<\pi$），$h=0$（$\pi<\theta<2\pi$）。$A_0=\frac1\pi\int_0^\pi1=1$，$A_n=\frac1\pi\int_0^\pi\cos n\phi=0$，$B_n=\frac1\pi\int_0^\pi\sin n\phi=\frac{1-(-1)^n}{n\pi}$：

$$u=\frac12+\frac2\pi\sum_{n\text{ odd}}\frac{r^n\sin n\theta}n$$

这个 series 可以求和。$\log(1+w)-\log(1-w)=2\sum_{n\text{ odd}}\frac{w^n}n$，取 $w=re^{i\theta}$ 的 imaginary part：$\sum_{n\text{ odd}}\frac{r^n\sin n\theta}n=\frac12\arg\frac{1+w}{1-w}=\frac12\arg\big(1-r^2+2ir\sin\theta\big)$。$r<1$ 时 real part $1-r^2>0$，所以

$$u=\frac12+\frac1\pi\arctan\frac{2r\sin\theta}{1-r^2}$$

圆心 $r=0$：$u=\frac12$。点 $(0,0.5)$：$r=0.5$，$\theta=\frac\pi2$，$\frac{2\times0.5}{0.75}=\frac43$，$u=\frac12+\frac1\pi\arctan\frac43=0.7952$。$u=c$ 的 level curve：令 $T=\tan\pi(c-\frac12)$，$\frac{2y}{1-x^2-y^2}=T$ 即 $x^2+y^2+\frac2Ty=1$，是圆心 $(0,-\frac1T)$、经过 $(\pm1,0)$ 的 circle。

::fig[ma4221-disk] 每条 level curve 都经过 boundary data 跳的两点 $(\pm1,0)$，所以它们在那里挤在一起。

### Mean value property

Poisson formula 在 $r=0$ 处给出 $u(0)=\frac1{2\pi}\int_0^{2\pi}h(\phi)\,d\phi$：圆心的值是 boundary 上的 average。上面的例子里正是 $\frac12$。这对任何 harmonic function、任何圆都成立：

> Mean value property：$u$ 在包含 $\overline{B_r(\mathbf x_0)}$ 的 open set 里 harmonic，则 $u(\mathbf x_0)$ 等于 $u$ 在 circle $\partial B_r(\mathbf x_0)$ 上的 average，也等于在 disk $B_r(\mathbf x_0)$ 上的 average。

**证明（二维，$\mathbf x_0=0$）。** 令 $g(r)=\frac1{2\pi}\int_0^{2\pi}u(r,\theta)\,d\theta$，circle 上的 average。$u$ continuous，$r\to0$ 时 $g(r)\to u(0)$。对 $r$ 求 derivative，放进 integral：

$$g'(r)=\frac1{2\pi}\int_0^{2\pi}u_r\,d\theta=\frac1{2\pi r}\int_{\partial B_r}\frac{\partial u}{\partial n}\,ds=\frac1{2\pi r}\int_{B_r}\Delta u\,d\mathbf x=0$$

第二个等号因为 circle 上 $ds=r\,d\theta$、outward normal 就是 $r$ 方向；第三个是 Green's first identity 取 $v=1$。所以 $g$ 是 constant，等于 $u(0)$。Disk 上的 average：$\int_{B_R}u=\int_0^R2\pi r\,g(r)\,dr=\pi R^2u(0)$。

**Strong maximum principle。** $D$ connected，$u$ harmonic，在内部点取到 maximum $M$，则 $u\equiv M$。记 $\Sigma=\{\mathbf x\in D:u(\mathbf x)=M\}$。$\mathbf x_0\in\Sigma$ 时，取 $D$ 里的小 disk $B$，$M=u(\mathbf x_0)=$ $u$ 在 $B$ 上的 average，而 $u\le M$；如果 $B$ 里有一点 $u<M$，由 continuity 在一小块正 area 上都 $<M$，average 就 $<M$，矛盾。所以 $B\subset\Sigma$，$\Sigma$ 是 open 的。$u$ continuous，$\Sigma$ 在 $D$ 里也是 closed 的。$D$ connected，非空的 open 且 closed 子集只能是 $D$ 本身。

**Liouville's theorem。** $\mathbb R^2$ 上有界（$|u|\le M$）的 harmonic function 是 constant。任取两点 $\mathbf p,\mathbf q$，用 disk 上的 mean value property，半径 $R$：

$$|u(\mathbf p)-u(\mathbf q)|=\frac1{\pi R^2}\Big|\int_{B_R(\mathbf p)}u-\int_{B_R(\mathbf q)}u\Big|\le\frac{M}{\pi R^2}\,\big|B_R(\mathbf p)\,\triangle\,B_R(\mathbf q)\big|$$

两个 disk 重叠的部分相消，剩下的 symmetric difference 的 area 不超过 $2\times2R|\mathbf p-\mathbf q|$（每个 disk 平移 $|\mathbf p-\mathbf q|$ 扫过的 region 是宽 $2R$ 的带子）。右边 $\le\frac{4M|\mathbf p-\mathbf q|}{\pi R}\to0$（$R\to\infty$），所以 $u(\mathbf p)=u(\mathbf q)$。

### Fundamental solution 与 representation formula

Disk 的 Poisson formula 靠 separation 得到，换一个形状就不行了。一般 domain 上的办法是先找一个“点 source”的 solution。Laplace equation 对 rotation 不变，找只依赖 $r$ 的 solution：二维时 $u_{rr}+\frac1ru_r=0$，即 $(ru_r)'=0$，$u=C\log r$。取

$$\Phi(\mathbf x)=\frac1{2\pi}\log|\mathbf x|\qquad(\text{二维}),\qquad\Phi(\mathbf x)=-\frac1{4\pi|\mathbf x|}\qquad(\text{三维})$$

$\Phi$ 在 $\mathbf x\ne0$ 处 harmonic（三维时 $\Phi_r=\frac1{4\pi r^2}$，$\Phi_{rr}=-\frac2{4\pi r^3}$，$\Phi_{rr}+\frac2r\Phi_r=0$）。穿过半径 $\varepsilon$ 的 circle 的 flux：二维 $\int\frac{\partial\Phi}{\partial r}ds=\frac1{2\pi\varepsilon}\cdot2\pi\varepsilon=1$，三维 $\frac1{4\pi\varepsilon^2}\cdot4\pi\varepsilon^2=1$，和 $\varepsilon$ 无关。按 Green's first identity（$v=1$），这相当于原点处有总量为 1 的 source：$\Delta\Phi=\delta$，这个 constant 就是为此选的。

**Green's second identity。** Green's first identity 写两遍，$u,v$ 对调，相减，$\nabla u\cdot\nabla v$ 消掉：

$$\int_D\big(u\Delta v-v\Delta u\big)\,d\mathbf x=\int_{\partial D}\Big(u\frac{\partial v}{\partial n}-v\frac{\partial u}{\partial n}\Big)dS$$

**Representation formula（二维）。** $u$ 在 $D$ 里 harmonic，$\mathbf x_0\in D$。取 $v=\Phi(\mathbf x-\mathbf x_0)$，它在 $\mathbf x_0$ 处 singular，所以在 $D_\varepsilon=D\setminus B_\varepsilon(\mathbf x_0)$ 上用 second identity。$u,v$ 都 harmonic，左边为 0。$D_\varepsilon$ 的 boundary 是 $\partial D$ 加上小 circle，小 circle 上的 outward normal 指向 $\mathbf x_0$，$\frac{\partial v}{\partial n}=-\frac1{2\pi\varepsilon}$：

- $\int_{\text{小 circle}}u\frac{\partial v}{\partial n}ds=-\frac1{2\pi\varepsilon}\int u\,ds\to-u(\mathbf x_0)$（circle 上的 average 趋于中心的值）；
- $\int_{\text{小 circle}}v\frac{\partial u}{\partial n}ds$ 的大小不超过 $\frac{|\log\varepsilon|}{2\pi}\cdot2\pi\varepsilon\cdot\max|\nabla u|\to0$。

令 $\varepsilon\to0$：

$$u(\mathbf x_0)=\int_{\partial D}\Big(u\,\frac{\partial\Phi(\mathbf x-\mathbf x_0)}{\partial n}-\Phi(\mathbf x-\mathbf x_0)\,\frac{\partial u}{\partial n}\Big)dS$$

内部每一点的值由 boundary 上的 $u$ 和 $\frac{\partial u}{\partial n}$ 决定。但 Dirichlet problem 只给 $u$，$\frac{\partial u}{\partial n}$ 不知道（第 2 站说过，两个同时给是 ill-posed 的），所以还要把第二项消掉。

### Green's function 与 method of images

在 $\Phi(\mathbf x-\mathbf x_0)$ 上加一个在 $D$ 里 harmonic 的 $H(\mathbf x)$，让和在 boundary 上为 0：

$$G(\mathbf x,\mathbf x_0)=\Phi(\mathbf x-\mathbf x_0)+H(\mathbf x),\qquad\Delta H=0\text{ 在 }D\text{ 里},\qquad G=0\text{ 在 }\partial D\text{ 上}$$

对 $u$ 和 $H$（都 harmonic、都没有 singularity）用 second identity：$0=\int_{\partial D}\big(u\frac{\partial H}{\partial n}-H\frac{\partial u}{\partial n}\big)$。加到 representation formula 上，$\frac{\partial u}{\partial n}$ 的 coefficient 变成 $G$，在 boundary 上为 0：

$$u(\mathbf x_0)=\int_{\partial D}u(\mathbf x)\,\frac{\partial G(\mathbf x,\mathbf x_0)}{\partial n}\,dS$$

$G$ 叫 Green's function，$\frac{\partial G}{\partial n}$ 叫 Poisson kernel。只要找到 $G$，Dirichlet problem 就变成一个 integral。$H$ 的找法：在 $D$ 外放一个 image source，让它在 boundary 上正好抵消 $\Phi$。

**Half-plane $y>0$。** $\mathbf x_0=(\xi,\eta)$，image $\mathbf x_0^*=(\xi,-\eta)$。boundary $y=0$ 上的点到两者距离相等，所以

$$G=\frac1{2\pi}\Big(\log|\mathbf x-\mathbf x_0|-\log|\mathbf x-\mathbf x_0^*|\Big)$$

在 $y=0$ 上为 0；第二项的 singularity 在 $y<0$，在 $D$ 里 harmonic。Outward normal 是 $-y$ 方向。$\partial_y\log|\mathbf x-\mathbf x_0|=\frac{y-\eta}{|\mathbf x-\mathbf x_0|^2}$，在 $y=0$ 上是 $\frac{-\eta}{(x-\xi)^2+\eta^2}$；image 那一项是 $\frac{\eta}{(x-\xi)^2+\eta^2}$。

$$\frac{\partial G}{\partial n}=-\partial_yG\Big|_{y=0}=-\frac1{2\pi}\cdot\frac{-2\eta}{(x-\xi)^2+\eta^2}=\frac{\eta}{\pi\big((x-\xi)^2+\eta^2\big)}$$

$$u(\xi,\eta)=\frac\eta\pi\int_{-\infty}^\infty\frac{h(x)}{(x-\xi)^2+\eta^2}\,dx$$

例：$h=1$（$x>0$），$h=0$（$x<0$）。$u=\frac\eta\pi\int_0^\infty\frac{dx}{(x-\xi)^2+\eta^2}=\frac1\pi\Big[\arctan\frac{x-\xi}\eta\Big]_0^\infty=\frac12+\frac1\pi\arctan\frac\xi\eta$。在 $(1,1)$ 处是 $\frac12+\frac14=0.75$。这个 $u$ 等于 $1-\frac\theta\pi$（$\theta$ 是 $(\xi,\eta)$ 的 polar angle），$\theta$ 是 harmonic 的（$u_{\theta\theta}=0$，$u_r=0$），boundary 上 $\theta=0$ 处为 1、$\theta=\pi$ 处为 0，核对无误。

::fig[ma4221-images] 左：half-plane 的 image 是 mirror image。右：unit disk 的 image 是 inversion $\mathbf x_0^*=\mathbf x_0/|\mathbf x_0|^2$，circle 上每一点到 image 的距离是到 $\mathbf x_0$ 的固定倍数。

**Unit disk。** 镜像不再是 reflection。对 $|\mathbf x|=1$，

$$\Big|\mathbf x-\frac{\mathbf x_0}{|\mathbf x_0|^2}\Big|^2=1-\frac{2\mathbf x\cdot\mathbf x_0}{|\mathbf x_0|^2}+\frac1{|\mathbf x_0|^2}=\frac{|\mathbf x_0|^2-2\mathbf x\cdot\mathbf x_0+1}{|\mathbf x_0|^2}=\frac{|\mathbf x-\mathbf x_0|^2}{|\mathbf x_0|^2}$$

最后一步用了 $|\mathbf x-\mathbf x_0|^2=1-2\mathbf x\cdot\mathbf x_0+|\mathbf x_0|^2$。所以 circle 上 $|\mathbf x-\mathbf x_0^*|=|\mathbf x-\mathbf x_0|/|\mathbf x_0|$。图里 $\mathbf x_0=(0.5,0)$，$\mathbf y=(\frac12,\frac{\sqrt3}2)$：$|\mathbf y-\mathbf x_0|=0.866$，$|\mathbf y-\mathbf x_0^*|=1.732$，比值 2。于是

$$G=\frac1{2\pi}\Big(\log|\mathbf x-\mathbf x_0|-\log\big(|\mathbf x_0|\,|\mathbf x-\mathbf x_0^*|\big)\Big)$$

在 circle 上为 0。求 Poisson kernel：circle 上 outward normal 就是 $\mathbf x$，$\frac{\partial}{\partial n}\log|\mathbf x-\mathbf p|=\frac{(\mathbf x-\mathbf p)\cdot\mathbf x}{|\mathbf x-\mathbf p|^2}=\frac{1-\mathbf p\cdot\mathbf x}{|\mathbf x-\mathbf p|^2}$。$\mathbf p=\mathbf x_0$ 给出 $\frac{1-\mathbf x_0\cdot\mathbf x}{|\mathbf x-\mathbf x_0|^2}$；$\mathbf p=\mathbf x_0^*$ 给出 $\frac{1-\mathbf x_0\cdot\mathbf x/|\mathbf x_0|^2}{|\mathbf x-\mathbf x_0|^2/|\mathbf x_0|^2}=\frac{|\mathbf x_0|^2-\mathbf x_0\cdot\mathbf x}{|\mathbf x-\mathbf x_0|^2}$。相减：

$$\frac{\partial G}{\partial n}=\frac{1-|\mathbf x_0|^2}{2\pi|\mathbf x-\mathbf x_0|^2}$$

$\mathbf x_0=(r\cos\theta,r\sin\theta)$、$\mathbf x=(\cos\phi,\sin\phi)$ 时 $|\mathbf x-\mathbf x_0|^2=1-2r\cos(\theta-\phi)+r^2$，$dS=d\phi$，这正是 $a=1$ 的 Poisson formula。Separation of variables 和 Green's function 两条路得到同一个 kernel。
