先看三个问题。

**第一个。** 一串 bit 一个一个地到来，最高位在前，读完之后要回答：这个 binary number 能不能被 3 整除。String 可能有一百万位长，你没有地方把它存下来。

**第二个。** 同样一个一个地读，读完回答：前面若干个 0 和后面若干个 1 的个数是不是相等，也就是 input 是不是形如 $0^m1^m$。

**第三个。** 给你任意一个 program 的 source code 和一个 input，回答：这个 program 在这个 input 上会不会停。

第一个问题只要记住 3 种情况就够了，不管 string 多长（第 1 站）。第二个问题用任何有限的 memory 都做不到，要证明这一点需要一个专门的 argument（第 4 站）；加一个 stack 就能做（第 5 站）。第三个问题用任何 program 都做不到，这是可以证明的（第 7 站）。

这门课就是按 memory 的形态给 machine 分级，再精确地划出每一级能做什么、不能做什么：

| Machine | Memory | 能识别的 language | Grammar | 典型的“做不到” |
|---|---|---|---|---|
| DFA、NFA | 有限个 state | regular language | right-linear | $\{0^m1^m\}$ |
| PDA | 有限个 state 加一个 stack | context-free language | context-free | $\{a^kb^kc^k\}$ |
| Turing machine | 有限个 state 加一条无限长的 tape | recursively enumerable language | unrestricted | halting problem |

每一级都要回答两类问题：怎样证明一个 language 属于这一级（造一台 machine 或写一个 grammar），怎样证明它不属于（一个 impossibility proof）。后一类是这门课的难点，也是 midterm 和 final 的主要分值所在。最后两站把“能不能算”换成“用多少 time 和 space 能算”，引出 linear speedup、hierarchy theorem 和 P 与 NP。

NUS 这门课用 Hopcroft–Motwani–Ullman（下面简称 HMU）的记号，本页全部照它：regular expression 里的 union 写成 $+$；DFA 的 extended transition function 写成 $\hat\delta$；regular 的 pumping lemma 写成“存在 $n$，$w=xyz$，$xy^kz\in L$”，CFL 的写成 $z=uvwxy$；TM 能接受的叫 recursively enumerable（RE），总会停的叫 recursive；关于 TM 的几个标准 language 叫 $L_d$、$L_u$、$L_e$、$L_{ne}$。MIT 18.404J 用的是 Sipser 的记号（union 写成 $\cup$，pumping length 叫 $p$，$A_{TM}$、$E_{TM}$，Turing-recognizable、decidable），内容一致，看 MIT 的材料时对照着换名字就行。

## [dfa] DFA 与 regular language

:::skip
能写出一个 DFA 的 5-tuple、用 $\hat\delta$ 走完一个 string、用 parallel simulation 造出 intersection 和 union 的 DFA，并且知道做 complement 之前 DFA 必须是 complete 的，就可以去第 2 站。
:::

### 只记住 remainder

回到第一个问题。设已经读过的 prefix 表示的数是 $v$，下一个 bit 是 $b$。在 binary 里，后面添一位相当于乘 2 再加这一位，所以新的数是 $2v+b$。要判断的只是它除以 3 的 remainder，而

$$v=3q+r,\quad r=v\bmod 3\qquad\Longrightarrow\qquad 2v+b=6q+(2r+b)$$

$6q$ 能被 3 整除，所以 $(2v+b)\bmod3=(2r+b)\bmod3$。新的 remainder 只取决于旧的 remainder $r$ 和新的 bit $b$，和 $v$ 本身有多大无关。于是只需要记住 $r\in\{0,1,2\}$ 三种情况之一。把 $r'=(2r+b)\bmod 3$ 逐个算出来：

| 当前 $r$ | 读到 0：$2r\bmod3$ | 读到 1：$(2r+1)\bmod3$ |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 2 | 0 |
| 2 | 1 | 2 |

开始时什么都没读，$v=0$，$r=0$。读完之后 $r=0$ 就回答 yes。

::fig[cs3231-mod3] 这张表画成 state diagram，再让它读 1001（也就是 9）。看当前 state 怎样随每个 bit 跳动，下方同时给出 prefix 的值和它的 remainder，两者始终一致。

### 定义

一台 deterministic finite automaton（DFA）是一个 5-tuple $A=(Q,\Sigma,\delta,q_0,F)$：$Q$ 是有限的 state set，$\Sigma$ 是 alphabet，$\delta:Q\times\Sigma\to Q$ 是 transition function，$q_0\in Q$ 是 start state，$F\subseteq Q$ 是 accepting state 的 set。$\delta$ 对每一对 (state, symbol) 恰好给出一个 state，这就是 deterministic 的意思。

$\delta$ 一次只吃一个 symbol。为了谈论整个 string，把它扩展成 $\hat\delta:Q\times\Sigma^*\to Q$，对 string 的长度做 inductive definition：

$$\hat\delta(q,\varepsilon)=q,\qquad \hat\delta(q,xa)=\delta\big(\hat\delta(q,x),a\big)$$

$\varepsilon$ 是 empty string，$x$ 是任意 string，$a$ 是一个 symbol。DFA 的 language 是 $L(A)=\{w\mid\hat\delta(q_0,w)\in F\}$。如果某个 DFA 的 language 恰好是 $L$，就说 $L$ 是 regular language。

拿上面的 DFA 检验一遍。$Q=\{0,1,2\}$，$\Sigma=\{0,1\}$，$q_0=0$，$F=\{0\}$，$\delta$ 是那张表。按定义一层一层展开 $\hat\delta(0,1001)$：

$$\begin{aligned}
\hat\delta(0,\varepsilon)&=0\\
\hat\delta(0,1)&=\delta(0,1)=1\\
\hat\delta(0,10)&=\delta(1,0)=2\\
\hat\delta(0,100)&=\delta(2,0)=1\\
\hat\delta(0,1001)&=\delta(1,1)=0\in F
\end{aligned}$$

所以 1001 被 accept，和 $9=3\times3$ 一致。

后面几站反复要把一个 string 切成两段来读：先读 $x$，停在某个 state，再从那里读 $y$。这需要一个性质（Tutorial 2 要求证明它）：对所有 state $q$ 和 string $x$、$y$，

$$\hat\delta(q,xy)=\hat\delta\big(\hat\delta(q,x),y\big)$$

对 $|y|$ 做 induction。$y=\varepsilon$ 时左边是 $\hat\delta(q,x)$，右边是 $\hat\delta(\hat\delta(q,x),\varepsilon)=\hat\delta(q,x)$。设对 $y$ 成立，看 $ya$：

$$\hat\delta(q,xya)=\delta\big(\hat\delta(q,xy),a\big)=\delta\Big(\hat\delta\big(\hat\delta(q,x),y\big),a\Big)=\hat\delta\big(\hat\delta(q,x),ya\big)$$

第一个和第三个等号是 $\hat\delta$ 的定义（把 $xy$、$y$ 当作定义里的“$x$”），第二个用 induction hypothesis。在例子上：$\hat\delta(0,10)=2$，$\hat\delta(2,01)=\delta(\delta(2,0),1)=\delta(1,1)=0$，和上面直接算的 $\hat\delta(0,1001)=0$ 一样。

### 证明它恰好 accept 该 accept 的

走通一个例子不等于 DFA 对所有 string 都对。要证的是：对每个 $w\in\{0,1\}^*$，$\hat\delta(0,w)=\mathrm{val}(w)\bmod3$，其中 $\mathrm{val}(w)$ 是 $w$ 表示的数（$\mathrm{val}(\varepsilon)=0$）。对 $|w|$ 做 induction。

**Base**：$|w|=0$，$w=\varepsilon$。$\hat\delta(0,\varepsilon)=0=\mathrm{val}(\varepsilon)\bmod3$。

**Step**：设对长度为 $k$ 的 $x$ 成立，看 $w=xb$。

$$\hat\delta(0,xb)=\delta\big(\hat\delta(0,x),b\big)=\delta\big(\mathrm{val}(x)\bmod3,\;b\big)=\big(2(\mathrm{val}(x)\bmod3)+b\big)\bmod3$$

第一个等号是 $\hat\delta$ 的定义，第二个用 induction hypothesis，第三个是 $\delta$ 的构造方式。由第一小节的计算，$(2r+b)\bmod3=(2v+b)\bmod3$，而 $2\,\mathrm{val}(x)+b=\mathrm{val}(xb)$，所以右边等于 $\mathrm{val}(xb)\bmod3$。

于是 $w\in L(A)\iff\hat\delta(0,w)=0\iff\mathrm{val}(w)\bmod3=0$。

设计 DFA 的一般做法就是这一站的做法：先问“读完一个 prefix 之后，为了将来能答对，必须记住关于它的什么”，把可能的答案列成 state，再用 induction 证明每个 state 的含义被每次 transition 保持。

### 两台 DFA 同时跑：parallel simulation

现在要判断两件事同时成立：能被 3 整除，并且含有偶数个 1。第二件事也有一个 DFA，两个 state $e$（目前偶数个 1）和 $o$（奇数个），读 0 不动，读 1 互换。

一台 DFA 读 input 只能读一遍，但它可以同时记住两台 DFA 各自的 state。设 $A_1=(Q_1,\Sigma,\delta_1,p_0,F_1)$，$A_2=(Q_2,\Sigma,\delta_2,q_0,F_2)$，造

$$Q=Q_1\times Q_2,\qquad \delta\big((p,q),a\big)=\big(\delta_1(p,a),\,\delta_2(q,a)\big),\qquad\text{start}=(p_0,q_0)$$

Sanjay Jain 的讲义把它叫作两台 DFA 的 parallel simulation，accepting state 的 set“看需要而定”。对 $|w|$ 做 induction 得到 $\hat\delta((p_0,q_0),w)=(\hat\delta_1(p_0,w),\hat\delta_2(q_0,w))$：base 两边都是 $(p_0,q_0)$；step 中 $\hat\delta((p_0,q_0),xa)=\delta((\hat\delta_1(p_0,x),\hat\delta_2(q_0,x)),a)=(\delta_1(\hat\delta_1(p_0,x),a),\delta_2(\hat\delta_2(q_0,x),a))$，两个 component 分别就是 $\hat\delta_1(p_0,xa)$ 和 $\hat\delta_2(q_0,xa)$。

所以读完 $w$ 时两台 machine 各自停在哪里，product 都知道，accepting state 怎么选，就决定了得到哪种 Boolean combination：

| $F$ 取 | 得到 |
|---|---|
| $F_1\times F_2$ | $L(A_1)\cap L(A_2)$ |
| $(F_1\times Q_2)\cup(Q_1\times F_2)$ | $L(A_1)\cup L(A_2)$ |
| $F_1\times(Q_2\setminus F_2)$ | $L(A_1)-L(A_2)$ |

::fig[cs3231-product] 两台 DFA 的 product 有 $3\times2=6$ 个 state。横着是 remainder，竖着是 1 的个数的 parity。读 0 只在同一行里走，读 1 一定换行。

用 1001 检验 intersection：$(0,e)\xrightarrow{1}(1,o)\xrightarrow{0}(2,o)\xrightarrow{0}(1,o)\xrightarrow{1}(0,e)$，停在 $(0,e)\in F_1\times F_2$。9 能被 3 整除，有两个 1，对得上。再看 111（7）：$(0,e)\to(1,o)\to(0,e)\to(1,o)$，reject，7 既不能被 3 整除，1 的个数也是奇数。Difference 的 accepting state 是 $\{0\}\times\{o\}=\{(0,o)\}$：能被 3 整除但有奇数个 1，例如 10101（21），走 $(0,e)\to(1,o)\to(2,o)\to(2,e)\to(1,e)\to(0,o)$，accept。

Complement 更简单：$L$ 有 DFA，就把 $F$ 换成 $Q\setminus F$。每个 $w$ 停在唯一一个 state，这个 state 要么在 $F$ 里要么不在，所以换完恰好 accept 原来 reject 的 string。

由此 regular language 对 union、intersection、difference、complement 都 closed。

:::wrong Union 的 product 也只要两边都 accept 的 pair 当 accepting state
取 $w=101$（5）。5 不能被 3 整除，但有两个 1，所以 $w$ 属于 union。在 product 里走：$(0,e)\xrightarrow{1}(1,o)\xrightarrow{0}(2,o)\xrightarrow{1}(2,e)$。$(2,e)$ 只有第二个 component 是 accepting，不在 $F_1\times F_2$ 里，于是 101 被 reject。只取 $F_1\times F_2$ 得到的是 intersection；union 要求“至少一边 accept”，accepting state 必须是 $(F_1\times Q_2)\cup(Q_1\times F_2)$，这里共有 $1\times2+3\times1-1\times1=4$ 个。
:::

:::edge 画图时省掉的 transition
很多题目画 DFA 时只画“有用”的 transition，没画出来的 (state, symbol) 默认去一个看不见的 dead state，它不是 accepting，而且所有 transition 都回到自己。做 complement 前必须先把这个 dead state 补出来：如果直接交换画出来的那几个 state，原来掉进 dead state 而被 reject 的 string，换完之后仍然被 reject，complement 就错了。
:::

## [nfa] NFA、ε-transition 与 subset construction

:::skip
能对一个 NFA 逐 symbol 算 active set，能做 subset construction（含 Eclose），能说清它为什么正确，就可以去第 3 站。
:::

### 一个要“猜”的 language

设 $L_2$ 是所有倒数第二个 symbol 是 1 的 binary string。读的时候不知道哪里是结尾，所以 DFA 每一步都得为“也许再读一个就结束”做准备。

换一个角度：如果允许 machine 在读到某个 1 的时候“猜”这就是倒数第二个，事情就很简单。$q_0$ 读什么都留在 $q_0$；在 $q_0$ 读到 1 时，也可以去 $q_1$，表示“我猜这个 1 是倒数第二个”；$q_1$ 再读任意一个 symbol 去 $q_2$；$q_2$ 是 accepting state，没有出去的 transition。猜错的那一路要么太早到 $q_2$ 然后又读到 symbol 无路可走（死掉），要么停在 $q_0$ 或 $q_1$。规定：只要有一条路在读完时停在 accepting state，就 accept。

这样的 machine 叫 nondeterministic finite automaton（NFA）。它不是物理上能造的机器，但它有一个确定的执行方式：把所有可能的路同时跟踪，每一步记下“现在可能在哪些 state”，也就是一个 state 的 set。

::fig[cs3231-nfarun] 这个 NFA 读 0110。实心的 state 是当前 active 的。读到第一个 1 时 active set 分裂成两个 state；读完时 set 里含有 $q_2$，所以 accept。

逐步写出来：

| 已读 | active set |
|---|---|
| $\varepsilon$ | $\{q_0\}$ |
| 0 | $\{q_0\}$ |
| 01 | $\{q_0,q_1\}$ |
| 011 | $\{q_0,q_1,q_2\}$ |
| 0110 | $\{q_0,q_2\}$ |

0110 的倒数第二个 symbol 确实是 1。换成 0101：读完 01 是 $\{q_0,q_1\}$；读 0，$q_0\to\{q_0\}$，$q_1\to\{q_2\}$，得 $\{q_0,q_2\}$；读 1，$q_0\to\{q_0,q_1\}$，$q_2$ 没有 transition，得 $\{q_0,q_1\}$，不含 $q_2$，reject。0101 的倒数第二个是 0，对得上。每一步都是把当前 set 里每个 state 的 transition 并起来，一个 state 都不能漏。

### 定义

NFA 也是 5-tuple $(Q,\Sigma,\delta,q_0,F)$，只是 $\delta:Q\times\Sigma\to\mathcal P(Q)$，给出的是 $Q$ 的一个 subset（可以是 $\varnothing$）。Extended transition function 同样对长度做 inductive definition：

$$\hat\delta(q,\varepsilon)=\{q\},\qquad \hat\delta(q,xa)=\bigcup_{p\in\hat\delta(q,x)}\delta(p,a)$$

$L(N)=\{w\mid \hat\delta(q_0,w)\cap F\neq\varnothing\}$。

上面那张表就是在逐行计算 $\hat\delta(q_0,\cdot)$。例如从第 3 行到第 4 行：$\hat\delta(q_0,011)=\delta(q_0,1)\cup\delta(q_1,1)=\{q_0,q_1\}\cup\{q_2\}=\{q_0,q_1,q_2\}$。

### Subset construction

上表里出现的每个 set 只取决于已读的 prefix，下一个 set 只取决于当前 set 和下一个 symbol。这正是一台 DFA：它的 state 是 NFA 的 state 的 subset。

给定 NFA $N=(Q,\Sigma,\delta,q_0,F)$，造 DFA $D$：

- state 是 $Q$ 的 subset；start state 是 $\{q_0\}$；
- $\delta_D(S,a)=\bigcup_{p\in S}\delta(p,a)$；
- $S$ 是 accepting state 当且仅当 $S\cap F\neq\varnothing$。

$Q$ 有 $n$ 个 state 时，subset 共有 $2^n$ 个。Sanjay Jain 的例题讲义（NFA to DFA）把全部 8 个 subset 连同 transition 都列了出来，其中从 $\{q_0\}$ 出发到得了的只有 3 个。实际做题时只需要从 $\{q_0\}$ 出发、按需生成 reachable 的那些：维护一个待处理的 list，每处理一个 subset 就算出它在每个 symbol 上去哪里，遇到新的 subset 就加入 list。

::fig[cs3231-subset] 对上面的 NFA 做 subset construction。每一帧处理一个 subset，新出现的 subset 加到表的下方；处理到第 4 行时不再有新的 subset，构造结束。

结果是 4 个 state，不是 $2^3=8$ 个，其余 4 个 subset（例如 $\{q_1\}$）从 $\{q_0\}$ 永远到不了。4 个 state 各有含义：set 含 $q_1$ 当且仅当刚读的 symbol 是 1，含 $q_2$ 当且仅当倒数第二个是 1。所以 $\{q_0\}$、$\{q_0,q_1\}$、$\{q_0,q_2\}$、$\{q_0,q_1,q_2\}$ 分别表示最后两位是 00、01、10、11。DFA 在记最后两位，这正是一开始觉得 DFA 难写的原因。

### 为什么它是对的

要证 $L(D)=L(N)$。关键 claim：对每个 string $w$，

$$\hat\delta_D(\{q_0\},w)=\hat\delta_N(q_0,w)$$

对 $|w|$ 做 induction。

**Base**：$\hat\delta_D(\{q_0\},\varepsilon)=\{q_0\}$（DFA 的定义），$\hat\delta_N(q_0,\varepsilon)=\{q_0\}$（NFA 的定义），相等。

**Step**：设对 $x$ 成立，记 $S=\hat\delta_N(q_0,x)$，于是 $\hat\delta_D(\{q_0\},x)=S$。

$$\hat\delta_D(\{q_0\},xa)=\delta_D\big(\hat\delta_D(\{q_0\},x),a\big)=\delta_D(S,a)=\bigcup_{p\in S}\delta(p,a)=\hat\delta_N(q_0,xa)$$

依次用了 DFA 的 $\hat\delta$ 定义、induction hypothesis、$\delta_D$ 的定义、NFA 的 $\hat\delta$ 定义。

有了 claim：$w\in L(D)\iff\hat\delta_D(\{q_0\},w)\cap F\neq\varnothing\iff\hat\delta_N(q_0,w)\cap F\neq\varnothing\iff w\in L(N)$。

反过来，每个 DFA 都是一个每个 $\delta(q,a)$ 恰好是 singleton 的 NFA。所以 NFA 和 DFA 识别的 language 是同一类：regular language。

### ε-transition

再放宽一步：允许 NFA 不读 symbol 就换 state，这种 transition 标作 $\varepsilon$，于是 $\delta$ 定义在 $Q\times(\Sigma\cup\{\varepsilon\})$ 上。第 3 站把 regular expression 转成 automaton 时会大量用到它。

需要一个新概念：$\mathrm{Eclose}(q)$ 是从 $q$ 出发只走 $\varepsilon$-transition（可以走零步）能到的所有 state。讲义按 inductive 的方式求它：先放入 $q$；若 $p$ 已在里面，就把 $\delta(p,\varepsilon)$ 里的 state 都放进去；重复到不再变化。

$\hat\delta$ 的定义随之改成每读一个 symbol 之后再取一次 closure：

$$\hat\delta(q,\varepsilon)=\mathrm{Eclose}(q),\qquad \hat\delta(q,wa)=\bigcup_{r\in R}\mathrm{Eclose}(r),\quad R=\bigcup_{p\in\hat\delta(q,w)}\delta(p,a)$$

Subset construction 也只改两处：start state 是 $\mathrm{Eclose}(q_0)$；$\delta_D(S,a)=\bigcup_{r\in R}\mathrm{Eclose}(r)$，$R=\bigcup_{p\in S}\delta(p,a)$。

例子：state $p$ 读 0 回到 $p$，$p$ 有一条 $\varepsilon$-transition 到 $r$，$r$ 读 1 回到 $r$，$r$ 是 accepting state。它的 language 是 $0^*1^*$。$\mathrm{Eclose}(p)=\{p,r\}$，$\mathrm{Eclose}(r)=\{r\}$。

- 读 001：$\{p,r\}\xrightarrow{0}\mathrm{Eclose}(p)=\{p,r\}\xrightarrow{0}\{p,r\}\xrightarrow{1}\mathrm{Eclose}(r)=\{r\}$，含 $r$，accept。
- 读 10：$\{p,r\}\xrightarrow{1}\{r\}\xrightarrow{0}\varnothing$，reject。

正确性的 claim 变成 $\hat\delta_D(\mathrm{Eclose}(q_0),w)=\hat\delta_N(q_0,w)$。Base 两边都是 $\mathrm{Eclose}(q_0)$；step 和上面逐字相同，因为 $\delta_D$ 和 $\hat\delta_N$ 在“读一个 symbol 再取 closure”这一点上用的是同一个式子。

:::wrong 把 NFA 的 accepting state 和其余 state 对调，就得到 complement 的 NFA
对 $L_2$ 的 NFA 这样做，新的 accepting state 是 $\{q_0,q_1\}$。但 $q_0$ 读任何 symbol 都留在 $q_0$，所以对每个 string，active set 里总有 $q_0$，新 NFA accept 所有 string，包括 0110 这样本来就在 $L_2$ 里的。原因是 NFA 的 accept 是“存在一条路”，对调之后变成“存在一条路不停在原来的 accepting state”，它的否定才是“所有路都不停在那里”，两者不是一回事。正确做法：先做 subset construction 得到 DFA，再在 DFA 上对调，得到的 accepting state 是 $\{q_0\}$ 和 $\{q_0,q_1\}$，恰好对应最后两位是 00、01。
:::

:::edge 2ⁿ 不是虚惊
上面的例子只用了 4 个 subset，但有的 NFA 确实要用到指数多个。把 $L_2$ 推广成 $L_t$（倒数第 $t$ 个 symbol 是 1，讲义里 NFA 的例子正是这个 language），NFA 只要 $t+1$ 个 state，任何 DFA 却至少要 $2^t$ 个。证明要用第 4 站的 distinguishability，在那里补上。
:::

:::from
NFA 的三种理解方式（parallel thread、tree、guess）和 subset construction 的定义来自 [MIT 18.404J 第 2 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/d741901d23b4522588e267177c77d10d_MIT18_404f20_lec2.pdf)；把 NFA 看成同时在很多 state 里的 DFA、DFA 可能指数级变大，来自 [Stanford CS103 Lecture 16](https://web.stanford.edu/class/archive/cs/cs103/cs103.1264/lectures/16/Condensed%20Lecture%20Slides.pdf)。$\hat\delta$ 的 inductive definition、Eclose 的求法、ε-NFA 的 $\hat\delta$ 和转 DFA 的构造跟 Sanjay Jain 的[讲义](http://www.comp.nus.edu.sg/~sanjay/cs3231/dfa.pdf)，讲义里 NFA 的例子是“倒数第 $n$ 个 symbol 是 1”（没有取具体的 $n$）；“列出全部 8 个 subset”来自例题讲义 [NFA to DFA](http://www.comp.nus.edu.sg/~sanjay/cs3231/ex-nfa.pdf)。$n=2$ 的 4 个 subset、$0^*1^*$ 的 ε-NFA 和 induction 证明是我写的。

## [regex] Regular expression 与 Kleene's theorem

:::skip
能把 regular expression 转成 ε-NFA，能用 $R^{(k)}_{ij}$ 把 2 到 3 个 state 的 DFA 转成 regular expression，就可以去第 4 站。
:::

### 用一行字描述 language

Automaton 是一台 machine，写在纸上要画图。搜索文本、写 lexer 时需要一种能打成一行字的描述方式。Regular expression 对结构做 inductive definition：

- **Base**：$\varnothing$ 表示 empty language；$\varepsilon$ 表示 $\{\varepsilon\}$；每个 symbol $a$ 表示 $\{a\}$。
- **Induction**：若 $r$、$s$ 是 regular expression，则 $r+s$ 表示 $L(r)\cup L(s)$；$rs$ 表示 concatenation $\{xy\mid x\in L(r),y\in L(s)\}$；$r^*$ 表示 $L(r)$ 中零个或多个 string 的 concatenation（所以总含 $\varepsilon$）；$(r)$ 表示 $L(r)$。

Precedence 从高到低是 $^*$、concatenation、$+$。

用定义读一个 expression：$(0+1)^*1(0+1)$。$L(0+1)=\{0,1\}$，所以 $L((0+1)^*)$ 是所有 binary string；后面接一个 1，再接一个 symbol。整体是 $\{x1y\mid x\in\{0,1\}^*,\ y\in\{0,1\}\}$，正是第 2 站的 $L_2$。

:::wrong $(0+1)^*$ 和 $0^*+1^*$ 是一样的
$01\in L((0+1)^*)$：从 $L(0+1)$ 里先取 0、再取 1，接起来。而 $L(0^*+1^*)$ 里的 string 要么全是 0、要么全是 1，不含 01。Star 每次重复可以重新选一个 string，所以它不能分配到 $+$ 的两边。
:::

:::exam Mid Term 1（2026）第 3 题
按 answer sketch，这道题问 $L(R^*(S+R)^*)=L((R(S+R)^*)^*)$ 是否对所有 regular expression $R$、$S$ 成立，答案是不成立，反例取 $R=a$、$S=b$。

左边：$R^*$ 取零次得 $\varepsilon$，$(S+R)^*$ 取一次 $S$ 得 $b$，所以 $b\in L(a^*(b+a)^*)$。右边：$(a(b+a)^*)^*$ 的 string 要么是 $\varepsilon$，要么是一个或多个 $a(b+a)^*$ 块接起来，每块都以 $a$ 开头，所以每个非空的 string 都以 $a$ 开头，$b$ 不在里面。

一个反例就推翻“对所有 $R$、$S$ 成立”。反过来想证明这类等式成立，就得对任意 string 两边都论证（Tutorial 2 第 5 题是同类的题）。
:::

### Regular expression 转成 ε-NFA

要证每个 regular expression 的 language 都是 regular，就沿着它的 inductive definition 造 automaton：base 的三种情况各给一台小 automaton，每个 operator 给一种拼接方法。讲义的构造让每台 automaton 都保持一个 invariant：恰好一个 accepting state，它和 start state 不同，start state 没有进来的 transition，accepting state 没有出去的 transition。

- $a$：两个 state，一条标 $a$ 的 transition。$\varepsilon$：一条 $\varepsilon$-transition。$\varnothing$：两个 state，没有 transition。
- $r+s$：新的 start state 用 $\varepsilon$ 连到两台的 start state，两台的 accepting state 用 $\varepsilon$ 连到新的 accepting state。
- $rs$：同样新加一个 start state 和一个 accepting state。新 start 用 $\varepsilon$ 连到 $r$ 的 start，$r$ 的 accepting state 用 $\varepsilon$ 连到 $s$ 的 start，$s$ 的 accepting state 用 $\varepsilon$ 连到新 accepting。
- $r^*$：新的 start state 和新的 accepting state；新 start 用 $\varepsilon$ 连到 $r$ 的 start 和新 accepting（这一条负责 $\varepsilon$）；$r$ 的 accepting state 用 $\varepsilon$ 连回 $r$ 的 start（再来一遍）和新 accepting。

Invariant 的用处在 star 里看得最清楚：如果 $r$ 的 start state 有进来的 transition，“连回 start”就可能让 machine 在 $r$ 内部绕出 $L(r)$ 以外的路。Concatenation 里新加的两个 state 其实可以省掉（直接拿 $r$ 的 start 当 start、$s$ 的 accepting 当 accepting，invariant 照样成立），讲义加上它们是为了让三种 operator 的形状统一；考试照讲义画不会错。

::fig[cs3231-thompson] 按讲义的规则为 $0^*1$ 造出的 ε-NFA。0 的 automaton 是 $s_0\to f_0$，star 加上 $s$、$f$ 和四条 $\varepsilon$；1 的 automaton 是 $s_1\to f_1$；concatenation 再加 $q_0$、$q_f$ 和三条 $\varepsilon$。下方是它读 001 时的 active set。

在这台 ε-NFA 上跑一遍 001：$\mathrm{Eclose}(q_0)=\{q_0,s,s_0,f,s_1\}$。读 0，只有 $s_0$ 有 0-transition，到 $f_0$，$\mathrm{Eclose}(f_0)=\{f_0,s_0,f,s_1\}$。再读 0，同样得到 $\{f_0,s_0,f,s_1\}$。读 1，只有 $s_1$ 有 1-transition，到 $f_1$，$\mathrm{Eclose}(f_1)=\{f_1,q_f\}$，含 accepting state $q_f$，accept。

### DFA 转成 regular expression：$R^{(k)}_{ij}$

反方向要证：每个 DFA 的 language 都能写成 regular expression。难处在于 DFA 里的 path 可以任意绕圈，没法直接“读出”一个 expression。办法是按“path 途经的 state 编号最大是多少”分层，从不允许途经任何 state 开始，一层一层放开。

把 state 编号为 $1,\dots,n$，start state 是 1。$R^{(k)}_{ij}$ 表示所有从 $i$ 到 $j$、中途只经过编号 $\le k$ 的 state（两端 $i$、$j$ 不算“中途”）的 path 上读到的 string。

**$k=0$**：中途不许经过任何 state，path 只能是一条 transition，或者在 $i=j$ 时什么都不走。所以 $R^{(0)}_{ij}$ 是所有满足 $\delta(i,a)=j$ 的 $a$ 之和；$i=j$ 时再加上 $\varepsilon$；一个都没有就是 $\varnothing$。

**从 $k$ 到 $k+1$**：看一条中途只经过 $\le k+1$ 的 path。如果它中途没经过 $k+1$，它已经在 $R^{(k)}_{ij}$ 里。如果经过了，在第一次和最后一次到达 $k+1$ 处把它切开：第一段从 $i$ 到 $k+1$，中途 $\le k$；中间若干段从 $k+1$ 回到 $k+1$，每段中途 $\le k$；最后一段从 $k+1$ 到 $j$，中途 $\le k$。所以

$$R^{(k+1)}_{ij}=R^{(k)}_{ij}+R^{(k)}_{i,k+1}\big(R^{(k)}_{k+1,k+1}\big)^*R^{(k)}_{k+1,j}$$

**答案**：$k=n$ 时不再有限制，$L(A)$ 等于所有 accepting state $j$ 的 $R^{(n)}_{1j}$ 之和。

::fig[cs3231-odd] 一个两 state 的 DFA：1 表示目前读到偶数个 1，2 表示奇数个，2 是 accepting state。彩色的 path 是 $R^{(1)}_{22}$ 中“经过 state 1”的那一部分：从 2 读 1 到 1，在 1 上读若干个 0，再读 1 回到 2。

对这个 DFA 算一遍。$k=0$：

$$R^{(0)}_{11}=\varepsilon+0,\quad R^{(0)}_{12}=1,\quad R^{(0)}_{21}=1,\quad R^{(0)}_{22}=\varepsilon+0$$

$k=1$，公式里的中间 state 是 1，要用 $(R^{(0)}_{11})^*=(\varepsilon+0)^*=0^*$：

$$\begin{aligned}
R^{(1)}_{12}&=R^{(0)}_{12}+R^{(0)}_{11}(R^{(0)}_{11})^*R^{(0)}_{12}=1+(\varepsilon+0)0^*1=0^*1\\
R^{(1)}_{22}&=R^{(0)}_{22}+R^{(0)}_{21}(R^{(0)}_{11})^*R^{(0)}_{12}=(\varepsilon+0)+10^*1
\end{aligned}$$

化简 $R^{(1)}_{12}$ 时用了 $(\varepsilon+0)0^*=0^*$（$0^*$ 前面多一个可有可无的 0，language 不变），再与 1 合并：$1$ 本身是 $0^*1$ 取零个 0 的情形。

$k=2$，accepting state 只有 2，答案是 $R^{(2)}_{12}$，中间 state 是 2：

$$R^{(2)}_{12}=R^{(1)}_{12}+R^{(1)}_{12}\big(R^{(1)}_{22}\big)^*R^{(1)}_{22}=R^{(1)}_{12}\big(R^{(1)}_{22}\big)^*=0^*1\,(0+10^*1)^*$$

第二个等号先提出公因子得 $R^{(1)}_{12}\big(\varepsilon+(R^{(1)}_{22})^*R^{(1)}_{22}\big)$，而对任何 $R$ 都有 $\varepsilon+R^*R=R^*$（重复零次，或者重复至少一次）；第三个等号是因为 star 里面的 $\varepsilon$ 可有可无，$(\varepsilon+0+10^*1)^*=(0+10^*1)^*$。

检验：expression 先读若干个 0 和第一个 1，之后每一块要么是一个 0，要么是“1，若干个 0，1”，每块带 0 个或 2 个 1，所以总的 1 的个数是奇数。111：第一部分取 1，剩下的 11 是一块 $10^*1$（取零个 0），accept。11：第一部分只能是 1，剩下的 1 凑不成任何一块，reject。

两个方向合起来就是 Kleene's theorem：regular expression、NFA、DFA 描述的是同一类 language。

## [nonreg] Pumping lemma、closure property 与 minimization

:::skip
能用 distinguishing set 或 pumping lemma 证明一个 language 不是 regular（处理所有 split，不自己挑），会用 intersection 和 homomorphism 把问题归到已知的 nonregular language，能用 table-filling 做 minimization，就可以去第 5 站。
:::

### DFA 唯一的限制是有限

回到开头第二个问题：为什么 $\{0^m1^m\mid m\ge0\}$ 没有 DFA？“DFA 不会数数”只是直觉，要变成 proof，得说清 DFA 在什么情况下被迫犯错。

两个 string $x$、$y$ 关于 $L$ distinguishable，是说存在某个 $z$，使 $xz$ 和 $yz$ 恰好一个在 $L$ 里。

**Lemma**：若 $x$、$y$ 关于 $L$ distinguishable，则任何识别 $L$ 的 DFA 读完 $x$ 和读完 $y$ 必然停在不同 state。

**Proof**：设 $\hat\delta(q_0,x)=\hat\delta(q_0,y)=q$。接着读 $z$，由第 1 站的 $\hat\delta(q,xz)=\hat\delta(\hat\delta(q,x),z)$，两边都等于 $\hat\delta(q,z)$，同一个 state，要么都 accept 要么都 reject，与 distinguishable 矛盾。

**Theorem**：若存在一个无限的 set $S$，其中任意两个不同的 string 都关于 $L$ distinguishable，则 $L$ 不是 regular。

**Proof**：设 DFA 有 $s$ 个 state。从 $S$ 里取 $s+1$ 个 string，由 pigeonhole 有两个停在同一个 state，与 lemma 矛盾。

用在 $\{0^m1^m\}$ 上：取 $S=\{0^m\mid m\ge0\}$。对 $i\neq j$，取 $z=1^i$，$0^i1^i\in L$，$0^j1^i\notin L$。所以 $S$ 中任两个都 distinguishable，$L$ 不是 regular。

同一个 lemma 还能给 DFA 的大小定下界。第 2 站的 $L_t$（倒数第 $t$ 个是 1）：取长度为 $t$ 的全部 $2^t$ 个 string。任取两个不同的 $x$、$y$，设它们第一次不同在从左数第 $i$ 位。接上 $z=0^{i-1}$ 之后长度是 $t+i-1$，倒数第 $t$ 位是从左数第 $(t+i-1)-t+1=i$ 位，也就是 $x_i$ 或 $y_i$，一个是 1 一个是 0，所以恰好一个在 $L_t$ 里。$2^t$ 个 string 两两 distinguishable，任何 DFA 至少 $2^t$ 个 state。$t=2$ 时下界是 4，第 2 站 subset construction 得到的恰好是 4 个，已经最小。

### Pumping lemma

NUS 的讲义主要用另一个工具，它的证明同样是 pigeonhole，只是用在一个 string 的内部。

**Pumping lemma**：若 $L$ regular，则存在一个只取决于 $L$ 的常数 $n$，使每个满足 $|w|\ge n$ 的 $w\in L$ 都能写成 $w=xyz$，满足

1. $y\neq\varepsilon$；
2. $|xy|\le n$；
3. 对所有 $k\ge0$，$xy^kz\in L$。

**Proof**：取识别 $L$ 的 DFA，令 $n$ 为它的 state 数。设 $w=a_1a_2\cdots a_\ell\in L$，$\ell\ge n$。记 $q_i=\hat\delta(q_0,a_1\cdots a_i)$，$i=0,1,\dots,n$，这是 $n+1$ 个 state，DFA 只有 $n$ 个，所以存在 $0\le i<j\le n$ 使 $q_i=q_j$。令

$$x=a_1\cdots a_i,\qquad y=a_{i+1}\cdots a_j,\qquad z=a_{j+1}\cdots a_\ell$$

$|xy|=j\le n$，$|y|=j-i\ge1$。$y$ 从 $q_i$ 出发回到 $q_j=q_i$，即 $\hat\delta(q_i,y)=q_i$，对 $k$ 做 induction 得 $\hat\delta(q_i,y^k)=q_i$（$k=0$ 时是 $\hat\delta(q_i,\varepsilon)=q_i$；$\hat\delta(q_i,y^{k+1})=\hat\delta(\hat\delta(q_i,y^k),y)=\hat\delta(q_i,y)=q_i$）。所以

$$\hat\delta(q_0,xy^kz)=\hat\delta\big(\hat\delta(q_i,y^k),z\big)=\hat\delta(q_i,z)=\hat\delta(q_0,xyz)\in F$$

::fig[cs3231-pump] $n=7$ 时读 $0^71^7$。前 7 个 symbol 经过 8 个 state，必有重复，这里设 $q_2=q_5$。Path 形成一个套索：$x$ 是柄，$y$ 是圈，$z$ 是剩下的路。绕圈 0 次、1 次、2 次，终点都一样。

### 怎样用它证明 nonregular

Lemma 的 quantifier 顺序是：存在 $n$；对所有够长的 $w$；存在一种 split；对所有 $k$。要推出矛盾，就要对它取 negation：对每个 $n$，**你**挑一个 $w\in L$，$|w|\ge n$，使得**每一种**满足 1、2 的 split 都有某个 $k$ 让 $xy^kz\notin L$。$n$ 不是你选的，split 也不是你选的。

**例 1：$\{0^m1^m\}$。** 设它 regular，常数为 $n$。取 $w=0^n1^n$，长度 $2n\ge n$。任一 split 有 $|xy|\le n$，而 $w$ 的前 $n$ 个 symbol 全是 0，所以 $y=0^\ell$，$\ell\ge1$。取 $k=2$：$xy^2z=0^{n+\ell}1^n$，0 比 1 多，不在 $L$ 里。矛盾。讲义的例子 $\{a^mb^m\mid m\ge1\}$ 和 $\{a^ib^j\mid i<j\}$ 是同一个做法，后者取 $w=a^nb^{n+1}$，pump 上去之后 $a$ 的个数 $n+\ell\ge n+1$，不再少于 $b$。

**例 2：$\{ww\mid w\in\{0,1\}^*\}$。** 先看一个坏选择 $w=0^{2n}=0^n0^n$：split 可以取 $y=00$，pump 后 $0^{2n+2\ell'}$ 仍是 $0^{n+\ell'}0^{n+\ell'}$，推不出矛盾。坏选择不证明任何事。好的选择是 $0^n1\,0^n1$：$|xy|\le n$ 迫使 $y$ 落在第一段 0 里，$y=0^\ell$。$xy^2z=0^{n+\ell}10^n1$，长度 $2n+2+\ell$。如果 $\ell$ 是奇数，长度为奇数，不可能是 $ww$。如果 $\ell$ 是偶数（于是 $\ell\ge2$），假设它等于 $ww$，则 $|w|=n+1+\ell/2$。整个 string 以 1 结尾，所以 $w$ 以 1 结尾，前一半的最后一个 symbol（第 $n+1+\ell/2$ 位）应该是 1。但 1 只出现在第 $n+\ell+1$ 位和最后一位，而 $n+1+\ell/2\le n+\ell<n+\ell+1$，这一位是 0。所以不在 $L$ 里。矛盾。

**例 3：$\{a^p\mid p\text{ 是 prime}\}$。** 只有一个 symbol，distinguishing set 不好找，pumping lemma 却很直接。设常数为 $n$，取一个 prime $p>n$，$w=a^p$。任一 split 有 $y=a^\ell$，$1\le\ell\le n$。$xy^kz$ 的长度是 $p+(k-1)\ell$，取 $k=p+1$：

$$p+p\ell=p(1+\ell)$$

$p\ge2$，$1+\ell\ge2$，两个 factor 都至少是 2，长度不是 prime，$xy^{p+1}z\notin L$。矛盾。例如 $n=3$、$p=5$、$\ell=2$ 时长度是 $5\times3=15$。

:::wrong 我选 y 是第一个 1，pump 之后 1 变多，所以 $0^m1^m$ 不是 regular
取 $n=3$，$w=000111$。这个 proof 选了 $x=000$，$y=1$，但 split 是 lemma 给的，不是你给的：lemma 只保证存在某一种 split 能 pump，它完全可以是 $x=0$，$y=00$，$z=0111$。你要证明的是每一种都失败。正因为 split 不受你控制，才要挑 $0^n1^n$ 这样的 $w$，靠 $|xy|\le n$ 把 $y$ 逼进全是 0 的那一段，让所有 split 都只剩一种情况。
:::

:::wrong 一个 language 满足 pumping lemma 的条件，它就是 regular
Pumping lemma 只是 necessary condition。看 $L=\{a^ib^jc^j\mid i\ge1,\,j\ge0\}\cup\{b^jc^r\mid j,r\ge0\}$：以 $a$ 开头时要求 $b$、$c$ 个数相等，不以 $a$ 开头时只要求形如 $b^*c^*$。

取 $n=1$，它满足 lemma 的结论。以 $a$ 开头的 $w=a^ib^jc^j$：取 $y$ 为第一个 $a$，$xy^kz=a^{i-1+k}b^jc^j$；$i-1+k\ge1$ 时仍以 $a$ 开头且 $b$、$c$ 相等，$i-1+k=0$ 时变成 $b^jc^j$，属于第二部分。不以 $a$ 开头的 $w$：取 $y$ 为第一个 symbol，pump 之后仍形如 $b^*c^*$。

但 $L$ 不是 regular：取 $S=\{ab^j\mid j\ge0\}$，对 $i\neq j$，$z=c^i$ 使 $ab^ic^i\in L$ 而 $ab^jc^i\notin L$（以 $a$ 开头但个数不等）。Distinguishing set 的方法没有这个漏洞，下面 minimization 那一节会说明：$L$ regular 当且仅当没有无限的 distinguishing set。
:::

### 用 closure property 证明 nonregular

讲义列出的 closure property 有 union、concatenation、complement、intersection、difference、reversal 和 homomorphism。它们反过来用就是证明 nonregular 的工具：把要证的 language 经过一个保持 regular 的操作变成一个已知 nonregular 的 language。

**Intersection。** 设 $E$ 是 0 和 1 个数相等的 string。如果 $E$ regular，由第 1 站 $E\cap L(0^*1^*)$ 也 regular，而它恰好是 $\{0^m1^m\}$，矛盾。直接对 $E$ pump 也可以，但这样省掉了处理 split 的麻烦。

**Homomorphism。** 设 $\Sigma$、$\Gamma$ 是两个 alphabet，$h$ 把每个 symbol $a\in\Sigma$ 映到一个 string $h(a)\in\Gamma^*$。按 concatenation 扩展到 string：$h(\varepsilon)=\varepsilon$，$h(a_1a_2\cdots a_\ell)=h(a_1)h(a_2)\cdots h(a_\ell)$，于是 $h(xy)=h(x)h(y)$。$h(L)=\{h(w)\mid w\in L\}$。

**Theorem**：若 $L$ regular，则 $h(L)$ regular。

**Proof**：取 $L=L(M)$ 的 regular expression $M$，对 $M$ 的结构定义一个新的 regular expression $R(M)$，把每个 symbol 换成它的像：

$$R(\varnothing)=\varnothing,\quad R(\varepsilon)=\varepsilon,\quad R(a)=h(a),\quad R(M+N)=R(M)+R(N),\quad R(MN)=R(M)R(N),\quad R(M^*)=R(M)^*$$

对结构做 induction 证 $L(R(M))=h(L(M))$。Base：$L(R(a))=\{h(a)\}=h(\{a\})$，$\varnothing$ 和 $\varepsilon$ 两边都相同。$+$：$L(R(M+N))=h(L(M))\cup h(L(N))=h(L(M)\cup L(N))$。Concatenation：

$$L(R(MN))=h(L(M))\,h(L(N))=\{h(x)h(y)\mid x\in L(M),y\in L(N)\}=\{h(xy)\mid\dots\}=h(L(MN))$$

Star 同理：$L(R(M)^*)$ 的 string 是 $h(x_1)\cdots h(x_r)=h(x_1\cdots x_r)$，$x_i\in L(M)$，正好是 $h(L(M)^*)$。

用一次：$h(0)=ab$，$h(1)=\varepsilon$，$M=(01)^*0$。$R(M)=(ab\,\varepsilon)^*ab=(ab)^*ab$。检验：$010\in L(M)$，$h(010)=ab\cdot\varepsilon\cdot ab=abab$，确实在 $L((ab)^*ab)$ 里。

拿它证 nonregular：$L'=\{0^m21^m\mid m\ge0\}$。取 $h(0)=0$，$h(1)=1$，$h(2)=\varepsilon$，则 $h(L')=\{0^m1^m\}$。如果 $L'$ regular，$h(L')$ 也 regular，矛盾。

:::wrong $h(L)$ 是 regular，所以 $L$ 也是 regular
Theorem 只有一个方向。取 $L=\{0^m1^m\}$，$h(0)=h(1)=a$，则 $h(L)=\{a^{2m}\mid m\ge0\}=L((aa)^*)$，regular，而 $L$ 不是。Homomorphism 会把信息“抹掉”（这里抹掉了 0 和 1 的区别），所以只能从“像不 regular”推出“原来不 regular”。
:::

:::exam Mid Term 1（2026）第 4 题
按 answer sketch，这是一道判断某个 closure 说法真假的题，答案是 false：取 regular 的 $L=(01)^+$，经过题目里的那个变换得到 $\{0^m1^m\mid m\ge1\}$，而后者不 regular。Answer sketch 证明后者不 regular 的理由就是 homomorphism：$h(0)=a$，$h(1)=b$ 把它变成讲义例 1 的 $\{a^mb^m\mid m\ge1\}$。题干里的变换 answer sketch 没有写出来，这里不复述。这道题的套路是：要否定“regular 经过某操作仍 regular”，找一个 regular 的 $L$，让它的像是一个已知的 nonregular language。
:::

**Reversal** 用同样的办法：$\mathrm{rev}(\varnothing)=\varnothing$，$\mathrm{rev}(\varepsilon)=\varepsilon$，$\mathrm{rev}(a)=a$，$\mathrm{rev}(r+s)=\mathrm{rev}(r)+\mathrm{rev}(s)$，$\mathrm{rev}(r^*)=\mathrm{rev}(r)^*$，只有 concatenation 要调换顺序，$\mathrm{rev}(rs)=\mathrm{rev}(s)\,\mathrm{rev}(r)$，因为 $(xy)^R=y^Rx^R$。例如 $\mathrm{rev}\big((0+1)^*1(0+1)\big)=(0+1)\,1\,(0+1)^*$：$L_2$ 反过来就是“第二个 symbol 是 1”。

### Minimization：把分不开的 state 合并

Distinguishability 还能回答另一个问题：一个 regular language 最少要几个 state。讲义先定义 string 之间的 relation：

$$u\equiv_L w\iff\text{对所有 }x,\ ux\in L\Leftrightarrow wx\in L$$

$u\equiv_L w$ 就是 $u$、$w$ 不 distinguishable。它是 equivalence relation（reflexive、symmetric、transitive 都直接从 $\Leftrightarrow$ 来）。

**从 class 造 DFA。** 若 $\equiv_L$ 只有有限个 class，记 $w$ 所在的 class 为 $[w]$，令 $Q=\{[w]\}$，start state $[\varepsilon]$，$F=\{[w]\mid w\in L\}$，$\delta([w],a)=[wa]$。$\delta$ 要 well-defined：若 $u\equiv_Lw$，对任意 $x$ 取 $ax$ 代入定义，$uax\in L\Leftrightarrow wax\in L$，所以 $ua\equiv_Lwa$。$F$ 也 well-defined：取 $x=\varepsilon$，$u\in L\Leftrightarrow w\in L$。对 $|w|$ 做 induction 得 $\hat\delta([\varepsilon],w)=[w]$，所以这台 DFA accept $w$ 当且仅当 $w\in L$。

**它是 minimal 的。** 任取识别 $L$ 的 DFA $A'$。由开头的 lemma，$u\not\equiv_Lw$ 时 $A'$ 读完 $u$ 和 $w$ 停在不同 state，所以 $A'$ 的 state 数至少是 class 的个数。讲义进一步说明，任何 minimal DFA 都和这台只差 state 的名字。

两件事合起来：$L$ regular 当且仅当 $\equiv_L$ 只有有限个 class（Myhill–Nerode theorem）。“有无限的 distinguishing set”就是“有无限多个 class”，所以上一节那个 lemma 两个方向都成立。

**Table-filling。** 给了一台 DFA $A$，读完 $u$ 停在同一个 state 的 string 一定 $\equiv_L$，但反过来不一定：两个不同的 state 可能对将来没有任何区别。State $p$、$q$ distinguishable，是说存在 $w$ 使 $\hat\delta(p,w)$、$\hat\delta(q,w)$ 恰好一个在 $F$ 里。讲义的 algorithm：

0. 先删掉从 start state 到不了的 state。
1. 一个 accepting、一个不 accepting 的 pair，用 $w=\varepsilon$ 就区分了，先标记。
2. 反复检查未标记的 pair $\{p,q\}$：如果某个 symbol $a$ 使 $\{\delta(p,a),\delta(q,a)\}$ 已被标记，就标记 $\{p,q\}$。
3. 一轮下来没有新标记就停。没被标记的 pair 是 indistinguishable，这个 relation 是 equivalence relation，每个 class 合并成新 DFA 的一个 state；$\delta(p,a)=q$ 就让 $p$ 的 class 读 $a$ 去 $q$ 的 class；含 start state 的 class 是新的 start，含 accepting state 的 class 是新的 accepting state。

第 0 步不能省：table-filling 只比较 state 对将来的反应，看不出一个 state 到不到得了。一个到不了的 state 如果和别的 state 都 distinguishable，它会作为一个单独的 class 留下来，结果就多了一个 state，不是 minimal 的。

**为什么标记的恰好是全部 distinguishable 的 pair。** 两个方向各做一次 induction。

- 标记的都是 distinguishable 的（对 algorithm 的步数做 induction）：第 1 步用 $\varepsilon$ 区分。第 2 步因为 $\{p',q'\}=\{\delta(p,a),\delta(q,a)\}$ 已被标记而标记 $\{p,q\}$ 时，由 induction hypothesis 有 $x$ 区分 $p'$、$q'$，于是 $ax$ 区分 $p$、$q$。
- Distinguishable 的都会被标记（对区分它们的最短 string 的长度做 induction）：长度 0 的只能是 $\varepsilon$，第 1 步全部标记了。设长度 $\le r$ 的都已找到，$\{p,q\}$ 被长度 $r+1$ 的 $ax$ 区分，则 $\{\delta(p,a),\delta(q,a)\}$ 被长度 $r$ 的 $x$ 区分，已被标记，于是第 2 步会标记 $\{p,q\}$。

## [cfl] CFG、PDA 与 context-free language

:::skip

### Grammar：用规则生成 string

$\{0^k1^k\}$ 不是 regular，但它有一个一眼就能看出的递归结构：要么是空的，要么是一个 0、一个更小的同类 string、一个 1。把这句话直接写成规则：

$$S\to0S1\mid\varepsilon$$

一个 context-free grammar（CFG）是 4-tuple $G=(V,T,P,S)$：$V$ 是有限的 variable set，$T$ 是有限的 terminal set，$V\cap T=\varnothing$，$P$ 是有限的 production set，每条形如 $A\to\gamma$，$A\in V$，$\gamma\in(V\cup T)^*$；$S\in V$ 是 start symbol。若 $A\to\gamma$ 在 $P$ 里，就有一步 derivation $\alpha A\beta\Rightarrow\alpha\gamma\beta$；$\Rightarrow^*$ 按 induction 定义：$\alpha\Rightarrow^*\alpha$，并且 $\alpha\Rightarrow^*\beta$、$\beta\Rightarrow\gamma$ 时 $\alpha\Rightarrow^*\gamma$。$L(G)=\{w\in T^*\mid S\Rightarrow^*w\}$，这样的 language 叫 context-free language（CFL）。$S\Rightarrow^*\alpha$ 的 $\alpha$ 叫 sentential form。每步都换最左边那个 variable 的是 leftmost derivation，换最右边的是 rightmost derivation。

用它生成 0011：

$$S\Rightarrow0S1\Rightarrow00S11\Rightarrow0011$$

最后一步用了 $S\to\varepsilon$。把每一步“谁被换成了什么”画成 tree，就是 parse tree：root 是 $S$，它的 children 是 $0,S,1$，中间的 $S$ 再展开成 $0,S,1$，最里面的 $S$ 展开成 $\varepsilon$。从左到右读 leaf，得到 0011。

:::exam Mid Term 2（2026）第 1 题
为 $L_1=\{a^ib^j\mid i\le j\le1.5i\}$ 写一个 CFG。Answer sketch 给的是

$$S\to aSb\mid aaSbbb\mid\varepsilon$$

想法：每用一次 $aSb$，$a$ 和 $b$ 各加一个；每用一次 $aaSbbb$，加 2 个 $a$、3 个 $b$，比例恰好是 1.5。两种步数凑起来，比例就落在 1 和 1.5 之间。证明两个方向：

（$L(G)\subseteq L_1$）每条 production 都把 $a$ 加在 $S$ 左边、$b$ 加在右边，所以 sentential form 总是 $a^{\cdot}Sb^{\cdot}$。用了 $t$ 次 $aSb$、$s$ 次 $aaSbbb$ 后得到 $a^{t+2s}b^{t+3s}$。$i=t+2s$，$j=t+3s$，于是 $j-i=s\ge0$，$1.5i-j=1.5t+3s-t-3s=0.5t\ge0$。

（$L_1\subseteq L(G)$）给定 $i\le j\le1.5i$，令 $s=j-i\ge0$，$t=3i-2j\ge0$（因为 $2j\le3i$）。代回去：$t+2s=3i-2j+2j-2i=i$，$t+3s=3i-2j+3j-3i=j$。先用 $t$ 次 $aSb$、再用 $s$ 次 $aaSbbb$，最后 $S\to\varepsilon$，就得到 $a^ib^j$。

例：$a^4b^5$，$s=1$，$t=2$：$S\Rightarrow aSb\Rightarrow aaSbb\Rightarrow aaaaSbbbbb\Rightarrow a^4b^5$。

Answer sketch 的说法是：string 形如 $a^{2r+\ell}b^{2r+\ell+e}$，$\ell\in\{0,1\}$，$e\le r$，每两个 $a$ 配两个或三个 $b$，$a$ 的个数是奇数时最后一个 $a$ 配一个 $b$。两种说法数的是同一件事。
:::

### Right-linear grammar 恰好是 regular

CFG 能生成 nonregular 的 $\{0^k1^k\}$。限制 production 的形状，可以得到恰好 regular 的那一部分。若每条 production 都形如 $A\to wB$ 或 $A\to w$（$w\in T^*$，$B\in V$），grammar 叫 right-linear。

**Theorem 1**：每个 regular language 都由某个 right-linear grammar 生成。

取 DFA $A=(Q,\Sigma,\delta,q_0,F)$（不妨设 $Q\cap\Sigma=\varnothing$），令 $G=(Q,\Sigma,P,q_0)$：$\delta(q,a)=p$ 时放 $q\to ap$；$q\in F$ 时放 $q\to\varepsilon$。对 $|w|$ 做 induction 证明 $\hat\delta(q_0,w)=p\iff q_0\Rightarrow^*wp$：$|w|=0$ 时两边都是 $p=q_0$；$w=ua$ 时

$$\hat\delta(q_0,ua)=p'\iff\exists p\,[\hat\delta(q_0,u)=p\text{ 且 }\delta(p,a)=p']\iff\exists p\,[q_0\Rightarrow^*up\text{ 且 }p\to ap']\iff q_0\Rightarrow^*uap'$$

最后一步的“$\Leftarrow$”成立，是因为 sentential form 里始终只有最右边一个 variable，到达 $uap'$ 的 derivation 上一步只能是某个 $up$ 用了 $p\to ap'$。于是 $w\in L(G)\iff q_0\Rightarrow^*wp$ 且 $p\to\varepsilon\iff\hat\delta(q_0,w)\in F$。

用第 1 站的 mod 3 DFA 做一次。State 0、1、2 和 terminal 0、1 重名，改叫 $A_0,A_1,A_2$：

$$A_0\to0A_0\mid1A_1\mid\varepsilon,\qquad A_1\to0A_2\mid1A_0,\qquad A_2\to0A_1\mid1A_2$$

生成 1001：$A_0\Rightarrow1A_1\Rightarrow10A_2\Rightarrow100A_1\Rightarrow1001A_0\Rightarrow1001$。每个 sentential form 是“已读的 prefix 加当前 state”，variable 依次是 $A_0,A_1,A_2,A_1,A_0$，和第 1 站 $\hat\delta$ 走过的 0、1、2、1、0 一样。

**Theorem 2**：right-linear grammar 生成的 language 是 regular。

先把每条 production 化成 $A\to bC$ 或 $A\to\varepsilon$，$b\in\Sigma\cup\{\varepsilon\}$：$A\to b_1\cdots b_rB$ 换成一串新 variable，$A\to b_1B_1$，$B_1\to b_2B_2$，…，$B_{r-1}\to b_rB$；$A\to b_1\cdots b_r$ 同样换成一串，最后加 $B_r\to\varepsilon$。然后造 ε-NFA：state 是 variable，start 是 $S$；$A\to bC$ 时 $C\in\delta(A,b)$；accepting state 是有 $A\to\varepsilon$ 的那些 $A$。对 derivation 的步数做 induction 得 $A\Rightarrow^*wB\iff B\in\hat\delta(A,w)$，所以 $S\Rightarrow^*w\iff\hat\delta(S,w)\cap F\neq\varnothing$。

例：$S\to01S\mid1$。拆开得 $S\to0B_1$，$B_1\to1S$，$S\to1B_2$，$B_2\to\varepsilon$。NFA：$S\xrightarrow0B_1\xrightarrow1S$，$S\xrightarrow1B_2$，$B_2$ accepting，language 是 $(01)^*1$。011：grammar 里 $S\Rightarrow01S\Rightarrow011$；NFA 里 $S\to B_1\to S\to B_2$，accept。

### Ambiguity

Grammar 通常是给 compiler 读的，parse tree 决定了程序的意思。看算术表达式的 grammar

$$E\to E+E\mid E\times E\mid(E)\mid a$$

$a+a\times a$ 有两个 leftmost derivation：

$$\begin{aligned}
&E\Rightarrow E+E\Rightarrow a+E\Rightarrow a+E\times E\Rightarrow a+a\times E\Rightarrow a+a\times a\\
&E\Rightarrow E\times E\Rightarrow E+E\times E\Rightarrow a+E\times E\Rightarrow a+a\times E\Rightarrow a+a\times a
\end{aligned}$$

第一个先在 root 用 $+$，对应 $a+(a\times a)$；第二个先用 $\times$，对应 $(a+a)\times a$。取 $a=2$，两个值分别是 6 和 8。

::fig[cs3231-parse] 同一个 string 的两个 parse tree。左边 × 在下面，先算；右边 + 在下面，先算。

一个 grammar 有某个 string 存在两个不同的 parse tree（等价地，两个不同的 leftmost derivation），就叫 ambiguous。修法是把 precedence 写进 grammar，每一层 variable 只负责一种 operator：

$$E\to E+T\mid T,\qquad T\to T\times F\mid F,\qquad F\to(E)\mid a$$

$+$ 只能出现在 $E$ 这一层，$\times$ 只在 $T$ 这一层，$T$ 生成的东西里不会有不带括号的 $+$，所以 $a+a\times a$ 只能在 root 拆成 $E+T$，$T$ 再拆成 $T\times F$，只有一个 parse tree。两个 grammar 生成同一个 language，ambiguity 是 grammar 的性质。讲义里的同一个例子不带括号、用 $\mathrm{id}$：$E\to E+E\mid E*E\mid\mathrm{id}$ 有歧义，改写成 $S\to S+T\mid T$，$T\to T*\mathrm{id}\mid\mathrm{id}$。

:::edge 有的 language 换哪个 grammar 都 ambiguous
讲义给的例子是 $L=\{a^ib^ic^jd^j\mid i,j\ge1\}\cup\{a^ib^jc^jd^i\mid i,j\ge1\}$，以及生成它的 grammar $S\to A\mid B$，$A\to CD$，$B\to aBd\mid aEd$，$C\to aCb\mid ab$，$D\to cDd\mid cd$，$E\to bEc\mid bc$。两部分的交集 $\{a^ib^ic^id^i\}$ 里的 string 两条路都能生成，例如 $abcd$：$S\Rightarrow A\Rightarrow CD\Rightarrow abD\Rightarrow abcd$，以及 $S\Rightarrow B\Rightarrow aEd\Rightarrow abcd$。讲义的结论是这个 language 的任何 grammar 都 ambiguous（inherently ambiguous），证明不在讲义里，本页也不证。
:::

### PDA：NFA 加一个 stack

DFA 无法识别 $\{0^k1^k\}$，是因为它要记住的 $k$ 没有上界。给 machine 加一个可以无限增长、但只能从顶部存取的 stack：读 0 时 push，读 1 时 pop，最后 stack 空了就说明个数相等。

讲义（HMU）的定义：pushdown automaton（PDA）是 7-tuple $(Q,\Sigma,\Gamma,\delta,q_0,Z_0,F)$。$\Gamma$ 是 stack alphabet，$Z_0\in\Gamma$ 是一开始 stack 里唯一的 symbol。$\delta(q,a,X)$ 是 $Q\times\Gamma^*$ 的一个有限 subset，$a\in\Sigma\cup\{\varepsilon\}$：$(p,\gamma)\in\delta(q,a,X)$ 表示在 state $q$、读 $a$（$a=\varepsilon$ 就是不读）、stack 顶是 $X$ 时，可以去 state $p$，pop 掉 $X$ 再 push $\gamma$，$\gamma$ 的第一个 symbol 成为新的顶；$\gamma=\varepsilon$ 就是单纯 pop。

格局写成 instantaneous description（ID）$(q,w,\alpha)$：当前 state、剩下的 input、stack 内容（第一个 symbol 是顶）。若 $(p,\beta)\in\delta(q,a,X)$，则 $(q,aw,X\alpha)\vdash(p,w,\beta\alpha)$；$\vdash^*$ 是零步或多步。两种 acceptance：

- by final state：$L(P)=\{w\mid(q_0,w,Z_0)\vdash^*(q_f,\varepsilon,\alpha)$，某个 $q_f\in F\}$；
- by empty stack：$N(P)=\{w\mid(q_0,w,Z_0)\vdash^*(q,\varepsilon,\varepsilon)$，某个 $q\in Q\}$。

$\{0^k1^k\mid k\ge0\}$ 的 PDA，accept by final state，$F=\{q_2\}$：

| Transition | 作用 |
|---|---|
| $\delta(q_0,0,Z_0)=\{(q_0,0Z_0)\}$，$\delta(q_0,0,0)=\{(q_0,00)\}$ | 读 0，push 0 |
| $\delta(q_0,1,0)=\{(q_1,\varepsilon)\}$，$\delta(q_1,1,0)=\{(q_1,\varepsilon)\}$ | 读 1，pop 一个 0 |
| $\delta(q_0,\varepsilon,Z_0)=\{(q_2,Z_0)\}$，$\delta(q_1,\varepsilon,Z_0)=\{(q_2,Z_0)\}$ | 看到 $Z_0$，去 accepting state |

::fig[cs3231-pda] 这个 PDA 读 0011。左边是 input 和读头，右边是 stack（顶在上）。两个 0 依次 push，两个 1 依次 pop，露出 $Z_0$ 时走 ε-transition 进入 $q_2$。

ID 序列：

$$(q_0,0011,Z_0)\vdash(q_0,011,0Z_0)\vdash(q_0,11,00Z_0)\vdash(q_1,1,0Z_0)\vdash(q_1,\varepsilon,Z_0)\vdash(q_2,\varepsilon,Z_0)$$

Input 读完且到了 accepting state，accept。换成 0010：读完 001 后是 $(q_1,0,0Z_0)$，$q_1$ 读 0 没有 transition，这条路卡住，又没有别的路，reject。

### 两种 acceptance 一样强

两个方向各加一个新的 start state $p_0$ 和一个新的 bottom marker $X_0$：第一步 $\delta(p_0,\varepsilon,X_0)=\{(q_0,Z_0X_0)\}$，把原来的 $Z_0$ 放在 $X_0$ 上面，然后照原来的 $\delta$ 走。

- **Empty stack 改成 final state**：对每个 $p\in Q$ 加 $(p_f,\varepsilon)\in\delta(p,\varepsilon,X_0)$，$p_f$ 是唯一的 accepting state。$X_0$ 露出来，恰好说明原来的 stack 空了。
- **Final state 改成 empty stack**：对每个 $p\in F$ 和每个 stack symbol $Z$（含 $X_0$）加 $(p_f,\varepsilon)\in\delta(p,\varepsilon,Z)$；$p_f$ 在任何 stack 顶上都 $\varepsilon$-pop，直到 stack 清空。

:::wrong Final state 改成 empty stack，只要在 accepting state 后面把 stack 清空就够了
少了 $X_0$ 就会多 accept。看只有一个 state 的 PDA：$\delta(q_0,a,Z_0)=\{(q_0,\varepsilon)\}$，$F=\varnothing$。By final state 它什么都不 accept。只加“从 accepting state 清空 stack”的 transition（这里一条都加不上），by empty stack 却有 $(q_0,a,Z_0)\vdash(q_0,\varepsilon,\varepsilon)$，accept 了 $a$：原来的 PDA 自己在一个不 accepting 的 state 把 stack pop 空了。垫上 $X_0$ 之后，pop 掉 $Z_0$ 露出的是 $X_0$，stack 不空，只有经过 $p_f$ 才能把 $X_0$ 也 pop 掉。
:::

### Nondeterminism 在这里是必需的

看 $\{ww^R\}$（偶数长度的 palindrome）。PDA 在 $q_0$ 读一个 push 一个；任何时刻都可以走 $\delta(q_0,\varepsilon,X)\ni(q_1,X)$，猜“到中点了”，之后在 $q_1$ 读一个 pop 一个并比较。在 0110 上，猜中点的位置有 5 种：

| 猜在读完几个 symbol 后 | 结果 |
|---|---|
| 0 | stack 只有 $Z_0$，去 $q_2$，但 input 没读完，这条路不 accept |
| 1 | stack 顶 0，下一个 input 是 1，不匹配，卡住 |
| 2 | stack 顶 1、0，依次和 1、0 匹配，露出 $Z_0$，accept |
| 3 | stack 顶 1，下一个 input 是 0，不匹配 |
| 4 | input 已读完，stack 不空，到不了 $q_2$ |

只有一条路 accept，就够了。

Deterministic PDA（DPDA）有两个条件：每个 $\delta(q,a,Z)$（$a\in\Sigma\cup\{\varepsilon\}$）至多一个元素；若 $\delta(q,\varepsilon,X)$ 非空，则对所有 $a\in\Sigma$，$\delta(q,a,X)$ 都是空的（不读 input 的 move 和读 input 的 move 不能同时可选）。讲义里关于它的结论：

- By final state，每个 regular language 都有 DPDA：DFA 本身就是一台从不动 stack 的 DPDA。
- By empty stack，DPDA 的 language 有 prefix property：$x$ 在里面时，$x$ 的任何更长的延伸都不在里面。因为 DPDA 读 $xy$ 时，读完 $x$ 那一刻和单独读 $x$ 走的是同一串 move，此时 stack 已空，任何 move 都需要一个 stack 顶，machine 停下来，$y$ 读不进去。所以 $\{a,aa\}$ 没有 by empty stack 的 DPDA：$a$ 是 $aa$ 的 prefix。
- 存在 PDA 能 accept、DPDA 不能 accept 的 language。讲义只说存在；常用的例子是 $\{ww^R\}$，证明不在讲义里，本页不证。

### CFG 与 PDA 互相转换

**CFG 转成 PDA。** 构造本身就是一台“边猜边验证 leftmost derivation”的机器。给定 $G=(V,T,P,S)$，只用一个 state $q$，$\Sigma=T$，$\Gamma=V\cup T$，stack 一开始是 $S$（$S$ 充当 $Z_0$），acceptance by empty stack：

- 对每个 variable $A$：$\delta(q,\varepsilon,A)=\{(q,\gamma)\mid A\to\gamma\in P\}$。stack 顶是 variable，就猜一条 production 展开它。
- 对每个 terminal $a$：$\delta(q,a,a)=\{(q,\varepsilon)\}$。stack 顶是 terminal，就和 input 对一下，对上了 pop。

为什么只展开 stack 顶：PDA 只看得到顶，而 leftmost derivation 每次展开的恰好是最左边的 variable；它左边的 terminal 已经和 input 对过、pop 掉了，于是它正好在顶上。

用 $S\to0S1\mid\varepsilon$ 读 0011：

| 剩余 input | Stack（顶在左） | 动作 |
|---|---|---|
| 0011 | $S$ | 展开 $S\to0S1$ |
| 0011 | $0S1$ | 匹配 0 |
| 011 | $S1$ | 展开 $S\to0S1$ |
| 011 | $0S11$ | 匹配 0 |
| 11 | $S11$ | 展开 $S\to\varepsilon$ |
| 11 | $11$ | 匹配 1 |
| 1 | $1$ | 匹配 1 |
| $\varepsilon$ | 空 | accept |

**PDA 转成 CFG。** 设 PDA by empty stack。对每对 state $q,p$ 和每个 stack symbol $X$ 造一个 variable $[qXp]$，目标是让它生成的恰好是“从 $q$ 出发、把 $X$ 净 pop 掉、停在 $p$”的 input，即 $[qXp]\Rightarrow^*w\iff(q,w,X)\vdash^*(p,\varepsilon,\varepsilon)$。Production：

- 对每个 state $p$：$S\to[q_0Z_0p]$；
- 若 $(r,Y_1Y_2\cdots Y_t)\in\delta(q,a,X)$，则对所有 state $r_1,\dots,r_t$：$[qXr_t]\to a\,[rY_1r_1][r_1Y_2r_2]\cdots[r_{t-1}Y_tr_t]$；$t=0$ 时就是 $[qXr]\to a$。

第二条的意思：读 $a$ 把 $X$ 换成 $Y_1\cdots Y_t$ 之后，要把 $X$ 净 pop 掉，就得依次把 $Y_1$、$Y_2$、… 各自净 pop 掉，中间经过的 state $r_1,\dots$ 是猜的，grammar 对所有猜法都放一条 production。证明对步数做 induction。所以 CFG 和 PDA 描述同一类 language。

### 化简 grammar 与 Chomsky normal form

$\{a^kb^kc^k\}$ 看起来只比 $\{0^k1^k\}$ 多一段，但一个 stack 用完 $a$ 的计数去对 $b$ 之后，就没有东西可以再对 $c$ 了。证明它不是 CFL 需要 CFL 版本的 pumping lemma，它的证明要看 parse tree 有多高，先把 grammar 化成统一的形状更方便：**Chomsky normal form（CNF）** 要求每条 production 是 $A\to BC$（两个 variable）或 $A\to a$（一个 terminal）。讲义的转换分三步：去掉 $\varepsilon$-production，去掉 unit production（$A\to B$），再把长的右边拆开；要求结果不含 useless symbol 时，最后再去一次 useless symbol（前两步可能让某些 variable 再也用不到）。

**Useless symbol。** $X$ 是 generating 的，指 $X\Rightarrow^*w$ 对某个 terminal string $w$；是 reachable 的，指 $S\Rightarrow^*\alpha X\beta$。Useful 要求出现在某个 $S\Rightarrow^*\alpha X\beta\Rightarrow^*w$ 里。两个 set 都用 induction 求：terminal 都 generating，右边全是 generating symbol 的 production 让左边也 generating；$S$ reachable，reachable variable 的右边全 reachable。讲义强调顺序：**先去掉 non-generating，再去掉 unreachable**。用讲义例题里的 grammar：

$$S\to Aa\mid AC,\qquad A\to a,\qquad C\to EC,\qquad E\to b$$

Generating：$a,b$；$A$（$A\to a$）、$E$（$E\to b$）、$S$（$S\to Aa$）。$C$ 唯一的 production 右边含 $C$ 自己，永远停不下来，不 generating。删掉 $C$ 和所有含 $C$ 的 production，剩 $S\to Aa$，$A\to a$，$E\to b$。再看 reachable：从 $S$ 只到得了 $A$、$a$，$E$ 删掉。结果 $S\to Aa$，$A\to a$。

顺序反过来就错：先看 reachable，$S\to AC$ 让 $C$ reachable，$C\to EC$ 让 $E$ reachable，什么都不删；再删 non-generating 的 $C$，剩下 $S\to Aa$，$A\to a$，$E\to b$。$E$ 已经 unreachable 却留了下来。

**$\varepsilon$-production。** $A$ 是 nullable，指 $A\Rightarrow^*\varepsilon$：有 $A\to\varepsilon$ 的 $A$ nullable，右边全是 nullable 的 production 让左边也 nullable。然后每条 production 里的 nullable symbol 取“留”或“删”两种，所有组合都加进去（全删成 $\varepsilon$ 的那种不加），最后删掉所有 $\varepsilon$-production。结果生成 $L(G)-\{\varepsilon\}$。

**Unit production。** $(A,B)$ 是 unit pair，指只用 unit production 就有 $A\Rightarrow^*B$：$(A,A)$ 都是；$(A,B)$ 是且 $B\to C$ 时 $(A,C)$ 也是。对每个 unit pair $(A,B)$ 和 $B$ 的每条非 unit production $B\to\gamma$，加 $A\to\gamma$，再删掉全部 unit production。讲义例题里的 grammar：

$$S\to A\mid AB,\qquad A\to b\mid B\mid ab,\qquad B\to c\mid b$$

Unit pair：$(S,S),(A,A),(B,B),(S,A),(A,B)$，以及由 $(S,A)$ 和 $A\to B$ 得到的 $(S,B)$。$S$ 收集 $S$、$A$、$B$ 的非 unit production：$AB$；$b,ab$；$c,b$。$A$ 收集 $A$、$B$ 的：$b,ab$；$c,b$。结果 $S\to AB\mid b\mid ab\mid c$，$A\to b\mid ab\mid c$，$B\to c\mid b$。

**拆右边。** Terminal 出现在长度 $\ge2$ 的右边时换成新 variable $Z\to a$；$A\to X_1X_2\cdots X_r$（$r\ge3$）换成 $A\to X_1B_2$，$B_2\to X_2B_3$，…，$B_{r-1}\to X_{r-1}X_r$。

拿 $\{0^k1^k\mid k\ge1\}$ 走一遍：

- $S\to0S1\mid\varepsilon$ 生成的 language 含 $\varepsilon$。$S$ nullable，把右边里的 $S$ 换成“有或没有”两种，得 $S\to0S1\mid01$，生成的是 $k\ge1$ 的部分。
- 没有 unit production，也没有 useless symbol。
- Terminal 换成新 variable：$A\to0$，$B\to1$，得 $S\to ASB\mid AB$。
- 右边长度 3 的拆成两段：$S\to AT$，$T\to SB$。

结果 $S\to AT\mid AB$，$T\to SB$，$A\to0$，$B\to1$。检验 0011：$S\Rightarrow AT\Rightarrow 0T\Rightarrow0SB\Rightarrow0ABB\Rightarrow00BB\Rightarrow0011$。

### CFL 的 pumping lemma

**Lemma（tree 的大小）**：CNF 的 parse tree 中，若 root 到 leaf 最长的 path 长 $s$（数 edge），则 yield 的长度不超过 $2^{s-1}$。对 $s$ 做 induction：$s=1$ 时 root 只能用 $A\to a$，yield 长 $1=2^0$；$s>1$ 时 root 用 $A\to BC$，两棵 subtree 的最长 path 都不超过 $s-1$，yield 各不超过 $2^{s-2}$，合起来不超过 $2^{s-1}$。

**CFL pumping lemma**：若 $L$ 是 CFL，存在常数 $n$，使每个 $|z|\ge n$ 的 $z\in L$ 能写成 $z=uvwxy$，满足

1. $|vwx|\le n$；
2. $vx\neq\varepsilon$；
3. 对所有 $i\ge0$，$uv^iwx^iy\in L$。

**Proof**：取 $L-\{\varepsilon\}$ 的 CNF grammar，设它有 $m$ 个 variable，取 $n=2^m$。$|z|\ge2^m>2^{m-1}$，由上面的 lemma，parse tree 的最长 path 长度至少 $m+1$，上面至少 $m+2$ 个 node，除最后的 leaf 外都是 variable，至少 $m+1$ 个。只看这条 path 最下面的 $m+1$ 个 variable，由 pigeonhole 有一个 variable $A$ 出现两次。上面那个 $A$ 生成 $vwx$，下面那个生成 $w$，也就是

$$S\Rightarrow^*uAy,\qquad A\Rightarrow^*vAx,\qquad A\Rightarrow^*w$$

- 由 $A\Rightarrow^*vAx$ 反复用 $i$ 次得 $A\Rightarrow^*v^iAx^i$，再接 $A\Rightarrow^*w$，所以 $S\Rightarrow^*uv^iwx^iy$（$i=0$ 就是把上面的 $A$ 的 subtree 换成下面那个）。
- 上面那个 $A$ 在 path 最下面 $m+1$ 个 variable 之内，从它往下到 leaf 最多 $m+1$ 条 edge；这条 path 是全 tree 最长的，所以以它为 root 的 subtree 的最长 path 也不超过 $m+1$，yield $|vwx|\le2^m=n$。
- CNF 没有 unit production 和 $\varepsilon$-production，$A\Rightarrow^*vAx$ 至少用了一次 $A\to BC$，另一边的 variable 至少生成一个 terminal，所以 $vx\neq\varepsilon$。

::fig[cs3231-cflpump] 左边：parse tree 里同一条 path 上出现两次 $A$，yield 被切成 $u,v,w,x,y$。右边：把下面的 $A$ 换成上面那棵 subtree 的 copy，$v$ 和 $x$ 各多出一份。

**例 1：$\{a^kb^kc^k\mid k\ge1\}$ 不是 CFL。** 设常数为 $n$，取 $z=a^nb^nc^n$。任一 split 中 $|vwx|\le n$，而 $a$ 段和 $c$ 段之间隔着 $n$ 个 $b$，所以 $vwx$ 不可能同时含 $a$ 和 $c$。

- $vwx$ 不含 $c$：取 $i=2$，$a$ 和 $b$ 的总数增加了 $|vx|\ge1$，$c$ 还是 $n$ 个，三种个数不再相等；若 $v$ 或 $x$ 同时含两种 symbol，pump 后顺序也会乱。不在 $L$ 里。
- $vwx$ 不含 $a$：同理，$b$ 和 $c$ 增加，$a$ 还是 $n$ 个。

每种 split 都失败，矛盾。

**例 2：$\{\alpha\alpha\mid\alpha\in\{a,b\}^*\}$ 不是 CFL。** 第 4 站证过它不是 regular。

:::wrong 沿用第 4 站的 $0^n10^n1$（这里写成 $a^nba^nb$）就能证明它不是 CFL
取 $z=a^nba^nb$，$n\ge3$。令 $v$ 是第一段 $a$ 的最后一个 $a$，$w$ 是中间的 $b$，$x$ 是第二段 $a$ 的第一个 $a$，$u$、$y$ 是其余部分。$|vwx|=3\le n$，$vx=aa\neq\varepsilon$，而 $uv^iwx^iy=a^{n-1+i}ba^{n-1+i}b$ 对所有 $i$ 都是 $\alpha\alpha$ 的形式。这个 split 通过了所有检查，推不出矛盾。CFL 的 lemma 允许 $v$、$x$ 分在两处同时 pump，正好能对称地改两半；regular 的 lemma 只有一个 $y$，而且被 $|xy|\le n$ 钉在开头，才拿 $0^n10^n1$ 证得出来。
:::

讲义的选择是 $z=a^{n+1}b^{n+1}a^{n+1}b^{n+1}$，四段各长 $n+1$，取 $i=0$。$uwy$ 的长度是 $4n+4-|vx|$，$1\le|vx|\le n$。长度是奇数就不可能是 $\alpha\alpha$；是偶数时 $|\alpha|=2n+2-|vx|/2$，介于 $n+1$ 和 $2n+2$ 之间（不含 $2n+2$）。$|vwx|\le n$ 而每段长 $n+1$，$vwx$ 最多跨相邻两段，分三种情况：

- **$vwx$ 落在前半 $a^{n+1}b^{n+1}$ 里。** 后半没动，$uwy$ 以 $a^{n+1}b^{n+1}$ 结尾。第二个 $\alpha$ 是长 $|\alpha|<2n+2$ 的 suffix，以 $b$ 结尾。第一个 $\alpha$ 是长 $|\alpha|$ 的 prefix；被删短的前半只有 $2n+2-|vx|<|\alpha|$ 长，所以 prefix 还要伸进后半的 $a$ 段 $|vx|/2\ge1$ 个，以 $a$ 结尾。两个 $\alpha$ 结尾不同，矛盾。
- **$vwx$ 落在后半里。** 对称：第一个 $\alpha$ 以 $a$ 开头，第二个 $\alpha$ 从前半的 $b$ 段里开始，以 $b$ 开头，矛盾。
- **$vwx$ 落在中间的 $b^{n+1}a^{n+1}$ 里。** 开头的 $a^{n+1}$ 和结尾的 $b^{n+1}$ 都没动。$|\alpha|\ge n+1$，所以第一个 $\alpha$ 以 $a^{n+1}$ 开头，第二个以 $b^{n+1}$ 结尾。两者是同一个 $\alpha$，它既以 $a^{n+1}$ 开头又以 $b^{n+1}$ 结尾，这两段不会重叠，$|\alpha|\ge2n+2$，矛盾。

### Closure property 与 decision property

CFL 对 union、concatenation、star closed，直接写 grammar：设 $G_1$、$G_2$ 的 start symbol 是 $S_1$、$S_2$（variable 先改名使两边不重名），新 start $S$ 分别加 $S\to S_1\mid S_2$、$S\to S_1S_2$、$S\to S_1S\mid\varepsilon$。讲义里还有：

- **Substitution**：每个 terminal $a$ 换成一个 CFL $L_a$，把 grammar 里的 $a$ 换成 $L_a$ 的 start symbol 并带上它的 production。Homomorphism 是 $L_a=\{h(a)\}$ 的特例，所以 CFL 对 homomorphism closed。
- **Reversal**：每条 $A\to\alpha$ 换成 $A\to\alpha^R$。
- **与 regular language 的 intersection**：PDA 在 finite control 里同时跑那台 DFA，state 是 $Q\times Q'$，accepting state 是 $F\times F'$，和第 1 站的 parallel simulation 一样，stack 只归 PDA 用。

:::wrong CFL 和 regular language 一样，对 intersection 和 complement 也 closed
$L_1=\{a^kb^kc^r\mid k,r\ge1\}$ 是 CFL：$S\to XC$，$X\to aXb\mid ab$，$C\to cC\mid c$。同理 $L_2=\{a^rb^kc^k\mid k,r\ge1\}$ 是 CFL。$L_1\cap L_2=\{a^kb^kc^k\mid k\ge1\}$，刚证明了它不是 CFL。Parallel simulation 在这里失效，是因为两台 PDA 各要一个 stack，而一台 PDA 只有一个。

Complement 也不 closed。讲义的例子：$L=\{a^ib^jc^r\mid i\neq j\text{ 或 }j\neq r\}$ 是 CFL（$i\neq j$ 拆成 $i<j$ 和 $i>j$，每一种都是先配对再多出一段，后面接 $c^*$；$j\neq r$ 同理；最后取 union）。如果 $\overline L$ 是 CFL，它和 regular 的 $a^*b^*c^*$ 的 intersection 也是 CFL，而 $\overline L\cap a^*b^*c^*=\{a^kb^kc^k\}$，矛盾。
:::

讲义里 CFL 的 decision property 有两个。**Emptiness**：$L(G)=\varnothing$ 当且仅当 $S$ 不是 generating，用上面求 generating symbol 的 algorithm。**Membership**：$w\in L(G)$？用 CYK algorithm，要求 grammar 是 CNF。

对 $w=a_1\cdots a_\ell$，令 $X_{i,j}$ 为能生成 $a_i\cdots a_j$ 的 variable 的 set。

- Base：$X_{i,i}=\{A\mid A\to a_i\}$。
- Induction：$X_{i,j}=\{A\mid A\to BC,\ B\in X_{i,k},\ C\in X_{k+1,j},\ i\le k<j\}$。CNF 里长度至少 2 的 substring 只能由 $A\to BC$ 生成，$B$ 生成前一段、$C$ 生成后一段，切点 $k$ 逐个试。
- 按 substring 的长度从 1 到 $\ell$ 逐层算，$w\in L(G)$ 当且仅当 $S\in X_{1,\ell}$。

用上一小节的 CNF grammar $S\to AT\mid AB$，$T\to SB$，$A\to0$，$B\to1$ 判断 0011：

::fig[cs3231-cyk] CYK 的表一层一层填：最下一行是长度 1 的 substring，往上每行长 1。每一格把它下面能拼出它的两格配对，空格就是 $\varnothing$。$S$ 出现在最上面那一格，0011 在 language 里。

- 长度 1：$X_{11}=X_{22}=\{A\}$，$X_{33}=X_{44}=\{B\}$。

换成 0101：$X_{12}=X_{34}=\{S\}$，$X_{23}$（$BA$）为空；$X_{13}$ 的两种拆法是 $A\varnothing$ 和 $SA$，$X_{24}$ 的是 $BS$ 和 $\varnothing B$，都没有对应的 production；$X_{14}$ 的三种拆法 $A\varnothing$、$SS$、$\varnothing B$ 也没有。$S\notin X_{14}$，reject。

表有 $\ell(\ell+1)/2$ 格，每格最多试 $\ell-1$ 个切点，grammar 固定时每个切点是常数时间，所以 CYK 是 $O(\ell^3)$。

## [tm] Turing machine

:::skip
能追踪一个 TM 的 ID 序列，说出 recursive 和 RE 的区别，知道 multi-tape、semi-infinite tape 和 nondeterministic TM 怎样被 simulate，就可以去第 7 站。

### 一条能写的 tape

$\{a^kb^kc^k\}$ 不是 CFL，但写个 program 检查它毫无困难：数一数三段各多长。PDA 不行，是因为 stack 只能从顶上读，读过就丢。把 memory 换成一条可以来回移动、随处读写的 tape，就得到 Turing machine（TM）。

讲义（HMU）的定义：TM 是 7-tuple $M=(Q,\Sigma,\Gamma,\delta,q_0,B,F)$。$\Sigma\subseteq\Gamma$，$\Gamma$ 是 tape alphabet，$B\in\Gamma-\Sigma$ 是 blank，$F\subseteq Q$。Input 连续写在 tape 上，两边全是 $B$，head 在 input 的第一个 symbol 上。$\delta(q,X)=(p,Y,D)$：在 state $q$、head 下是 $X$ 时，把 $X$ 改写成 $Y$，head 向 $D\in\{L,R\}$ 移一格，进入 $p$。$\delta$ 可以在某些 (state, symbol) 上没有定义，machine 走到那里就 halt。

格局写成 ID $x_0x_1\cdots x_{i-1}\,q\,x_ix_{i+1}\cdots x_r$：$q$ 写在 head 正在读的 symbol $x_i$ 左边，两端的 blank 省略（head 停在 blank 上时，那个 blank 要写出来）。$\vdash$ 是一步，$\vdash^*$ 是零步或多步。$M$ accept $x$，指 $q_0x\vdash^*\alpha\,q_f\,\beta$ 对某个 $q_f\in F$；$L(M)$ 是被 accept 的 string 的 set。讲义在证明里不妨设 accepting state 没有出去的 transition，所以进入 $F$ 也就停了。

### 一台 TM 的完整运行

讲义的例子：识别 $a$ 和 $b$ 个数相等的 string，$\Sigma=\{a,b\}$。每一轮从左边找到第一个还没配对的 symbol，改成 $X$，然后向右找一个和它不同的 symbol 也改成 $X$，再回到最左边。所有 symbol 都变成 $X$ 时 accept；找不到搭档就 halt，不 accept。

| | $a$ | $b$ | $X$ | $B$ |
|---|---|---|---|---|
| $q_0$ | $(q_1,X,R)$ | $(q_2,X,R)$ | $(q_0,X,R)$ | $(q_A,B,R)$ |
| $q_1$ | $(q_1,a,R)$ | $(q_3,X,L)$ | $(q_1,X,R)$ | |
| $q_2$ | $(q_3,X,L)$ | $(q_2,b,R)$ | $(q_2,X,R)$ | |
| $q_3$ | $(q_3,a,L)$ | $(q_3,b,L)$ | $(q_3,X,L)$ | $(q_0,B,R)$ |
| $q_A$ | | | | |

各 state 的意思：$q_0$ 越过 $X$ 找下一个未配对的 symbol；$q_1$ 刚标了一个 $a$，向右找 $b$；$q_2$ 刚标了一个 $b$，向右找 $a$；$q_3$ 配对完成，向左走到 input 左边的 blank，再转回 $q_0$；$q_A\in F$。空格是没有定义：$q_1$ 或 $q_2$ 一路走到右边的 blank 还没找到搭档，machine halt，不在 $F$ 里。

::fig[cs3231-tm] 这台 TM 读 abba，一共 17 步。每一帧是一个 ID：tape 内容、head 的位置、当前 state，下方的表里亮起的是这一步要用的 transition。

完整的 ID 序列：

$$\begin{aligned}
&q_0abba\vdash Xq_1bba\vdash q_3XXba\vdash q_3BXXba\vdash q_0XXba\vdash Xq_0Xba\vdash XXq_0ba\vdash XXXq_2a\vdash XXq_3XX\\
&\vdash Xq_3XXX\vdash q_3XXXX\vdash q_3BXXXX\vdash q_0XXXX\vdash Xq_0XXX\vdash XXq_0XX\vdash XXXq_0X\vdash XXXXq_0B\vdash XXXXBq_A
\end{aligned}$$

第一轮：$a$ 和它右边第一个 $b$ 配对（第 1、2 步），走回最左边（第 3、4 步）。第二轮：$q_0$ 越过两个 $X$，标第二个 $b$，向右找 $a$（第 5 到 7 步），配对后再走回去。第三轮 $q_0$ 一路越过四个 $X$ 读到 blank，accept。

换成 aab：$q_0aab\vdash Xq_1ab\vdash Xaq_1b\vdash Xq_3aX\vdash q_3XaX\vdash q_3BXaX\vdash q_0XaX\vdash Xq_0aX\vdash XXq_1X\vdash XXXq_1B$，$q_1$ 在 $B$ 上没有定义，halt，不 accept：第二个 $a$ 找不到 $b$。

同样的“标记再回来”的手法，按 $a$、$b$、$c$ 的顺序各标一个，就能识别 $\{a^kb^kc^k\}$。

### Recursive 与 recursively enumerable

TM 在一个 input 上有三种结局：accept、halt 但不 accept、永远不停。第三种是 DFA 和 PDA 没有的（PDA 的 ε-transition 也能造出无限循环，但总可以改掉；TM 不行，第 7 站证明）。例如一台 TM 在 $q_0$ 读到 $B$ 时 $\delta(q_0,B)=(q_0,B,R)$，它在 empty input 上会一直向右走。

于是有两种“识别”：

- $L$ 是 **recursively enumerable（RE）**：存在 TM $M$，$L(M)=L$。$M$ 在 $L$ 外的 input 上可以 halt 不 accept，也可以永远不停。
- $L$ 是 **recursive**：存在一台在所有 input 上都 halt 的 TM 识别它。

站在外面看一台还在运行的 TM，你无法分辨它是快要 accept 了还是会永远跑下去。这个区别是第 7 站的核心。讲义同样区分两种 function：TM 在 $f(x)$ 有定义时停下并把 $f(x)$ 留在 tape 上、在没有定义时不停，$f$ 叫 partial recursive；处处有定义的叫 recursive function。

### 更强的 TM 并不更强

**Multi-tape TM**：$k$ 条 tape，各有一个 head，一步同时读 $k$ 个 symbol、各写各移。Single-tape TM 可以 simulate 它：把一条 tape 分成 $2k$ 个 track，每两个 track 记一条 tape 的内容和那条 tape 的 head 位置的标记。Simulate 一步时，从左到右扫一遍收集 $k$ 个标记下的 symbol（记在 finite control 里），再扫一遍按 $\delta$ 改写并移动标记。若 multi-tape TM 跑了 $t$ 步，tape 上的内容最多扩展到 $t$ 格，每步扫两遍是 $O(t)$，共 $O(t^2)$ 步。能识别的 language 不变，只是时间变成平方，第 8 站会用到这个数。

**Semi-infinite tape**：反方向也成立，tape 只向右无限长，能力不变。把两个方向都无限的 tape 在某个位置对折：位置 0 往右的 cell 0、1、2、… 放在 upper track，往左的 cell $-1,-2,\dots$ 依次放在 lower track 的位置 1、2、…，lower track 的位置 0 放一个端点标记。Finite control 多记一个 bit，表示 head 现在在 upper 还是 lower。在 upper 上照常移动；在 lower 上 L 和 R 对调（原来往左，在 lower 上是往右走离端点更远）；在位置 0 碰到标记时换到另一个 track。

**Nondeterministic TM**：$\delta(q,X)$ 是有限多个可能的 move，有一条路 accept 就算 accept。Deterministic TM 可以 simulate 它：所有可能的运行构成一棵 tree，每个 node 是一个 ID。按 breadth-first 的顺序逐层展开（用 multi-tape TM 维护一个 ID 的 queue），遇到 accepting ID 就 accept。必须用 breadth-first：depth-first 可能沉进一条永远不停的分支，错过别的分支上近在眼前的 accept。若最短的 accepting 分支长 $s$、每个 ID 最多 $b$ 种 move，最多展开 $1+b+\dots+b^s$ 个 ID，有限，所以一定能找到。

:::wrong 加上 nondeterminism 或者多几条 tape，TM 能 accept 的 language 就更多
上面几个 simulation 说明不会：deterministic single-tape TM 能做到一样的事。变化的只是时间。Nondeterministic 的 simulation 用了 $b^s$ 量级的步数，指数级变慢；这个代价能不能省掉，正是第 9 站的 P vs NP。对 NFA 和 DFA 也是同一个故事：能力相同（第 2 站），大小可能差 $2^n$。PDA 是例外，nondeterministic PDA 严格强于 deterministic PDA（第 5 站）。
:::

### Church–Turing thesis 与 universal TM

各种看起来更强的 model（multi-tape、nondeterministic、RAM、各种 programming language）最后都被证明和 TM 能力相同。Church–Turing thesis 说：任何能用 algorithm 完成的计算（算一个 function 或 accept 一个 language），TM 都能完成。它不是 theorem，因为“algorithm”没有数学定义；它是在说，TM 是这个直观概念的正确的数学定义。从此“存在 TM”和“存在 algorithm”可以互换，下一站证明“没有 TM 能做”时，结论就是“没有任何 algorithm 能做”。

TM 本身是有限的对象，可以编码成一个 binary string。讲义的编码（input alphabet 是 $\{0,1\}$）：state 记为 $q_1,q_2,\dots$，$q_1$ 是 start state，$q_2$ 是唯一的 accepting state；tape symbol 记为 $X_1=0$、$X_2=1$、$X_3=B$，其余 $X_4,X_5,\dots$；方向 $D_1=L$、$D_2=R$。一条 transition $\delta(q_i,X_j)=(q_k,X_l,D_m)$ 编码成

$$0^i\,1\,0^j\,1\,0^k\,1\,0^l\,1\,0^m$$

所有 transition 的编码用 11 隔开连起来就是整台 machine 的编码。例如 $\delta(q_1,X_2)=(q_3,X_1,D_2)$ 编码成 $0\,1\,00\,1\,000\,1\,0\,1\,00$。编码可以读成一个自然数，讲义记编码为 $i$ 的 machine 为 $M_i$，$W_i=L(M_i)$（不是合法编码的 $i$ 看作一台什么都不 accept 的 machine）。

存在一台 universal TM $U$：在 input $(M,w)$ 上，它按 $M$ 的编码一步步 simulate $M$ 在 $w$ 上的运行，$M$ accept 它就 accept。讲义的构造用几条 tape：一条放 $M$ 的编码，一条放 $M$ 当前的 state（写成 $0^i$），一条放 $M$ 的 tape 内容，再加一条 scratch tape；每一步在编码里找和当前 state、symbol 匹配的那条 transition，照着改 state 和 tape。这就是“一台能运行任何 program 的计算机”的数学版本，下一站的 undecidability 都从“TM 能把别的 TM 当作 input”开始。

### Unrestricted grammar：grammar 也能到这一级

:::skip
讲义在 TM 一讲的最后讲 grammar 这一边，Tutorial 11 有题。跳过它会少掉开头那张表最下面一行的 grammar。
:::

把 CFG 对 production 左边“只能是一个 variable”的限制去掉。Unrestricted grammar $G=(N,\Sigma,S,P)$ 的 production 形如 $\alpha\to\beta$，$\alpha$ 至少含一个 variable，$\beta$ 任意；一步 derivation 是 $\gamma\alpha\gamma'\Rightarrow\gamma\beta\gamma'$。若每条都有 $|\alpha|\le|\beta|$，叫 context-sensitive grammar。讲义给的 $\{a^kb^kc^k\mid k\ge1\}$ 的 grammar：

$$S\to aSBC\mid aBC,\quad CB\to BC,\quad aB\to ab,\quad bB\to bb,\quad bC\to bc,\quad cC\to cc$$

生成 aabbcc：

$$S\Rightarrow aSBC\Rightarrow aaBCBC\Rightarrow aaBBCC\Rightarrow aabBCC\Rightarrow aabbCC\Rightarrow aabbcC\Rightarrow aabbcc$$

第三步用 $CB\to BC$ 把 $C$ 换到 $B$ 后面，第四步起从左往右把 variable 变成 terminal。一般地，$S\Rightarrow^*a^{k-1}S(BC)^{k-1}\Rightarrow a^k(BC)^k$，用 $CB\to BC$ 排成 $a^kB^kC^k$，再从左往右变成 terminal，所以每个 $a^kb^kc^k$ 都生成得出来。

反过来为什么只生成这些：$S$ 的两条 production 每次在 $S$ 左边加一个 $a$、右边加一个 $B$ 和一个 $C$，所以 $a$ 全在最左边，之后 $B$ 只会变成 $b$、$C$ 只会变成 $c$，三种个数都是 $k$。每个 $b$ 生成时（$aB\to ab$ 或 $bB\to bb$）左边紧挨着 terminal $a$ 或 $b$；每个 $c$ 生成时左边紧挨着 terminal $b$ 或 $c$。Terminal 生成之后不再改变、不再移动，$S$ 也插不到两个 terminal 中间，所以这些相邻关系保留到最后。于是最后的 string 里不会出现 $ac$ 或 $cb$ 这样的相邻对，它只能是 $a^kb^kc^k$。

讲义的两个 theorem：unrestricted grammar 生成的 language 都是 RE（TM 可以按长度枚举所有 derivation，遇到 $w$ 就 accept）；每个 RE language 都由某个 unrestricted grammar 生成（grammar 先猜出 input 和 tape 内容，再倒着 simulate TM 的 transition，从 accepting ID 退回 start ID，最后把多余的 symbol 清掉）。所以开头那张表的最下面一行，machine 是 TM，grammar 是 unrestricted grammar。

## [undec] Undecidability、reduction 与 PCP

:::skip

### 关于 automaton 和 grammar 的问题都能 decide

先看能 decide 的问题，它们说明“问题的 input 是一台 machine”并不可怕。讲义列出的 regular language 的 decision problem：

- **Membership**：$w\in L(A)$？Simulate DFA $A$ 走 $|w|$ 步，一定停。
- **Emptiness**：$L(A)=\varnothing$？从 start state 做 graph search（[CS2040 的 BFS](../courses/CS2040.html#graph)），看能不能到达某个 accepting state。
- **Universality**：$L(A)=\Sigma^*$？对 complement 的 DFA（第 1 站，换 $F$）问 emptiness。
- **Equivalence**：$L(A)=L(A')$？用第 1 站的 parallel simulation 造出 symmetric difference $(L\cap\overline{L'})\cup(\overline L\cap L')$ 的 DFA，两个 language 相等当且仅当它为空。

CFG 的 emptiness 和 membership 也能 decide（第 5 站的 generating symbol 和 CYK）。这些 algorithm 都能停，是因为 DFA 和 CFG 的运行有一个事先算得出的上界。TM 没有。

### 数一数：TM 不够用

讲义把 binary string 编号：在 $x$ 前面加一个 1，当作 binary number 读，$\varepsilon\mapsto1$，$0\mapsto2$，$1\mapsto3$，$00\mapsto4$，$01\mapsto5$，……每个 string 恰好得到一个正整数，记编号为 $i$ 的 string 为 $w_i$。所以 string 是 countable 的。上一站的编码又让每台 TM 得到一个编号，$M_i$ 是编号 $i$ 的 machine，TM 也是 countable 的。

Language 却不是。假设所有 language 能排成一列 $L_1,L_2,\dots$，造 $L^*=\{w_i\mid w_i\notin L_i\}$。$L^*$ 和每个 $L_i$ 在 $w_i$ 上不一致，所以不在列表里，矛盾。（讲义用另一个说法：只有一个 symbol $a$ 时，$[0,1)$ 里每个实数的 binary 展开 $0.b_0b_1\cdots$ 对应 language $\{a^i\mid b_i=1\}$，language 至少和实数一样多。）

TM 只有 countable 多个，language 有 uncountable 多个，所以一定存在不是 RE 的 language。这只说明“存在”，下面要找具体的。

### $L_d$ 不是 RE

把上面的 diagonal argument 直接用在 TM 上：

$$L_d=\{w_i\mid w_i\notin L(M_i)\}$$

**Theorem**：$L_d$ 不是 RE。

**Proof**：任取一台 $M_j$。若 $w_j\in L(M_j)$，按定义 $w_j\notin L_d$；若 $w_j\notin L(M_j)$，则 $w_j\in L_d$。两种情况下 $L(M_j)$ 和 $L_d$ 都在 $w_j$ 上不一致，所以 $L(M_j)\neq L_d$。每台 TM 都不 accept $L_d$。

::fig[cs3231-diag] 把所有 TM 和所有 string 排成一张表，第 $i$ 行第 $j$ 列写 $M_i$ 是否 accept $w_j$。$L_d$ 在第 $j$ 列取对角线那一格的反面，所以它和每一行都至少差一格，不是任何一行。

表里的数据是示意，实际的表是无限的。换成 program 的说法：要是有一个 program 能 accept $L_d$，问它关于它自己的编号那个 string 的问题，它的回答和自己的定义正好相反。

### Recursive、RE 与 complement

**Theorem 1**：$L$ recursive，则 $\overline L$ 也 recursive。

**Proof**：取总会停的 $M$，不妨设 accepting state 没有出去的 transition。新加一个 accepting state $q_{new}$；原来在非 accepting state 上 $\delta$ 没有定义的地方（$M$ 在那里 halt 并 reject），都改成去 $q_{new}$；原来的 accepting state 改成非 accepting。$M$ 总会停，所以 accept 和 reject 恰好对调。

**Theorem 2**：$L$ recursive 当且仅当 $L$ 和 $\overline L$ 都是 RE。

**Proof**：若 $L$ recursive，由 Theorem 1 两者都 recursive，当然都 RE。反过来，设 $M_1$ accept $L$，$M_2$ accept $\overline L$。造 $M$：在两条 tape 上交替地让 $M_1$、$M_2$ 各走一步。任一 input $w$ 要么在 $L$ 里（$M_1$ 迟早 accept），要么在 $\overline L$ 里（$M_2$ 迟早 accept），所以总有一个会停下来 accept；$M_1$ accept 则 $M$ accept，$M_2$ accept 则 $M$ reject。$M$ 总会停。必须交替，不能先跑完 $M_1$ 再跑 $M_2$，因为 $M_1$ 可能永远不停。

### $L_u$：RE 但不是 recursive

$$L_u=\{(M,w)\mid M\text{ accept }w\}$$

上一站的 universal TM 就 accept $L_u$，所以 $L_u$ 是 RE：$M$ accept $w$ 时 $U$ accept；$M$ 不停时 $U$ 也不停，这是允许的。

**$\overline{L_u}$ 不是 RE。** 假设有 $M$ accept $\overline{L_u}$。造 $M'$：在 input $w_i$ 上，先算出编号 $i$，再把 $(M_i,w_i)$ 交给 $M$，$M$ accept 就 accept。于是

$$M'\text{ accept }w_i\iff(M_i,w_i)\in\overline{L_u}\iff w_i\notin L(M_i)\iff w_i\in L_d$$

$M'$ accept $L_d$，与上面的 theorem 矛盾。

**所以 $L_u$ 不是 recursive。** 否则由 Theorem 1，$\overline{L_u}$ recursive，当然 RE，矛盾。$L_u$ 和 $\overline{L_u}$ 正好说明 Theorem 2 的两个条件缺一不可：$L_u$ 满足一半。

### Reduction

有了一个难的问题，其他问题不必每次都重新 diagonalize，只要说明“能解决它就能解决前一个”。

讲义的定义：$P_1\le_mP_2$（$P_1$ reduce 到 $P_2$），指存在一个 recursive function $f$（某台总会停的 TM 把 $x$ 变成 $f(x)$），使

$$x\in P_1\iff f(x)\in P_2$$

推论有四条：(a) $P_2$ recursive 则 $P_1$ recursive；(b) $P_2$ RE 则 $P_1$ RE；(a') $P_1$ 不是 recursive 则 $P_2$ 也不是；(b') $P_1$ 不是 RE 则 $P_2$ 也不是。(a)(b) 的证明都是先算 $f(x)$ 再交给 $P_2$ 的 machine；(a')(b') 是它们的 contrapositive。上面 $\overline{L_u}$ 的证明就是 $L_d\le_m\overline{L_u}$，$f(w_i)=(M_i,w_i)$，用的是 (b')。

**Halting problem 不是 recursive。** $H=\{(M,w)\mid M\text{ 在 }w\text{ 上会停}\}$。假设它有总会停的 $R$。造 $L_u$ 的 decider：在 $(M,w)$ 上先运行 $R$；$R$ 说不停，就 reject（不停当然不 accept）；$R$ 说会停，就用 $U$ simulate $M$ 在 $w$ 上的运行，这次一定会停，照它的结果 accept 或 reject。这台 machine 总会停，decide 了 $L_u$，矛盾。

:::wrong 要证 $P$ 不是 recursive，就把 $P$ reduce 到 $L_u$
$P\le_mL_u$ 说的是“$P$ 不比 $L_u$ 难”，由 (b) 任何满足它的 $P$ 都是 RE，而 decidable 的问题也满足它。例如 DFA 的 emptiness：把 $A$ 变成 $(M,\varepsilon)$，$M$ 是一台先自己判断 $L(A)$ 是否为空、空就 accept、不空就 reject 的 TM。$A$ 的 language 为空当且仅当 $M$ accept $\varepsilon$，这个 reduction 完全合法，而 emptiness 是 recursive 的，所以这个方向什么也证明不了。方向必须是 $L_u\le_mP$（或 $\overline{L_u}\le_mP$）：已知难的放左边，要证难的放右边，reduction 把左边的难度传到右边。
:::

### $L_e$ 与 $L_{ne}$

$$L_e=\{M\mid L(M)=\varnothing\},\qquad L_{ne}=\{M\mid L(M)\neq\varnothing\}$$

**$L_{ne}$ 是 RE。** 在 input $M$ 上：对 $t=0,1,2,\dots$，对 $i=0,\dots,t$，若 $M$ 在 $t$ 步内 accept $w_i$，就 accept。这叫 dovetailing。若 $L(M)\neq\varnothing$，有某个 $w_i$ 在某个 $t_0$ 步内被 accept，到 $t\ge\max(i,t_0)$ 那一轮一定找到。不能逐个 string 跑到底：$M$ 可能在 $w_0$ 上永远不停，后面的 string 永远轮不到。

**$L_{ne}$ 不是 recursive。** 给定 $(M,w)$，造 $M'$：

> $M'$ 在 input $x$ 上：不管 $x$ 是什么，对 $t=0,1,2,\dots$，若 $M$ 在 $t$ 步内 accept $w$，就 accept。

$M$ accept $w$ 时 $M'$ accept 所有 $x$，$L(M')=\Sigma^*\neq\varnothing$；否则 $M'$ 什么都不 accept，$L(M')=\varnothing$。造出 $M'$ 的编码只是改写 table，一定能停，并不运行 $M$。所以 $(M,w)\in L_u\iff M'\in L_{ne}$，即 $L_u\le_mL_{ne}$，由 (a') $L_{ne}$ 不是 recursive，于是它的 complement $L_e$ 也不是。

**$L_e$ 不是 RE。** 若 $L_e$ 是 RE，它和 complement $L_{ne}$ 都是 RE，由 Theorem 2 它 recursive，矛盾。（同一个 $M'$ 也给出 $\overline{L_u}\le_mL_e$，用 (b') 得到同样的结论。）

### Rice's theorem

上面的证明里，真正用到的只是“$L(M')$ 要么是 $\varnothing$，要么是另一个固定的 language，取决于 $M$ 的某个行为”。这可以推广到关于 $L(M)$ 的任何问题。

$P$ 是 RE language 的一个性质：它只看 language，不看 machine（$L(M_1)=L(M_2)$ 时两台 machine 要么都有要么都没有）；nontrivial 指有的 RE language 有 $P$、有的没有。记 $L_P=\{M\mid L(M)\text{ 有 }P\}$。

**Rice's theorem**：$P$ nontrivial，则 $L_P$ 不是 recursive。

**Proof**：不妨设 $\varnothing$ 有 $P$（否则对“没有 $P$”这个性质做同样的论证；$L_P$ recursive 当且仅当它的 complement recursive）。由 nontrivial，取一个没有 $P$ 的 RE language $L$ 和 accept 它的 $M''$。给定 $M$，造 $M'$：

> $M'$ 在 input $x$ 上：对 $t=0,1,2,\dots$，对 $i=0,\dots,t$，若 $M$ 在 $t$ 步内 accept $w_i$，并且 $M''$ 在 $t$ 步内 accept $x$，就 accept $x$。

$L(M)=\varnothing$ 时第一个条件永远不成立，$L(M')=\varnothing$，有 $P$。$L(M)\neq\varnothing$ 时第一个条件迟早成立，$M'$ accept $x$ 当且仅当 $M''$ accept $x$，$L(M')=L$，没有 $P$。所以 $M\in L_e\iff M'\in L_P$，$L_e\le_mL_P$。$L_e$ 不是 recursive，$L_P$ 也不是。

用它：“$L(M)$ 是 regular”“$L(M)$ 含 0110”“$L(M)$ 有限”都是 nontrivial 的 language 性质，对应的 $L_P$ 全部不是 recursive。“$M$ 有超过 5 个 state”不是 language 的性质（同一 language 可以有大小不同的 TM），Rice 管不到，它显然 recursive。

:::edge Rice's theorem 只说不是 recursive
“$L(M)\neq\varnothing$”由 Rice 不是 recursive，但它是 RE（上面的 dovetailing）；$L_e$ 则连 RE 都不是。Rice 不区分这两种情况。Tutorial 10 特别提醒，要证某个关于 machine 的 language 不是 RE，Rice's theorem 用不上，得自己做 reduction。
:::

### Post correspondence problem

前面的问题都在问 TM。要证明关于 grammar 的问题不可判定，需要一个“长得不像 TM”的中间问题。

**PCP**：给两个等长的 list $A=(w_1,\dots,w_k)$、$B=(x_1,\dots,x_k)$，每个都是非空 string。问有没有一个非空的 index 序列 $i_1,\dots,i_r$，使

$$w_{i_1}w_{i_2}\cdots w_{i_r}=x_{i_1}x_{i_2}\cdots x_{i_r}$$

**MPCP**（modified PCP）多一个要求：序列必须以 1 开头。

例：$A=(1,\ 10111,\ 10)$，$B=(111,\ 10,\ 0)$。逐个 index 往上接，每一步检查上下两行能不能互为 prefix：

- 开头只能是 1 或 2（$w_3=10$、$x_3=0$ 第一个 symbol 就不同）。
- 以 1 开头：上 $1$、下 $111$，下面多出 $11$。接 2 或 3，上面下一位是 0，和下面多出的 1 冲突；只能再接 1，下面多出的变成 $1111$，每接一次多 2 个，永远对不齐。
- 以 2 开头：上 $10111$、下 $10$，上面多出 $111$。只有 $x_1=111$ 能接，上 $101111$、下 $10111$，上面多出 $1$。仍只能接 1，上 $1011111$、下 $10111111$，下面多出 $1$。这时接 3：上 $101111110$、下 $101111110$，相等。

解是 $2,1,1,3$。

::fig[cs3231-pcp] PCP 的解 $2,1,1,3$：每块 domino 上面是 $w_i$，下面是 $x_i$。上下两行各自接起来是同一个 string 101111110，但 domino 的边界上下错开。

**Theorem**：PCP 不是 recursive。讲义的证明是 $L_u\le_m\text{MPCP}\le_m\text{PCP}$。

:::skip
下面两个 reduction 只看构造的意思也可以。跳过它们会少掉“为什么 PCP 能 simulate TM”的理由，后面 grammar 的部分不受影响。
:::

**MPCP $\le_m$ PCP。** 用两个新 symbol $*$ 和 $\text{\textdollar}$：$w_i$ 的每个 symbol **后面**插一个 $*$ 得 $w_i'$，$x_i$ 的每个 symbol **前面**插一个 $*$ 得 $x_i'$。再加两对：第 0 对 $(*w_1',\ x_1')$，第 $k+1$ 对 $(\text{\textdollar},\ *\text{\textdollar})$。上面的 string 都以原来的 symbol 开头，下面的都以 $*$ 开头，只有第 0 对上下都以 $*$ 开头，所以 PCP 的解必须从第 0 对开始，这就把“必须先用第 1 对”强加进来；同理上面都以 $*$ 结尾、下面不是，只有第 $k+1$ 对能收尾。MPCP 的解把开头的 1 换成 0、末尾接上 $k+1$，就是 PCP 的解；反过来也一样。

**$L_u\le_m$ MPCP。** 讲义假设 TM 不写 blank、不移到 input 左端的左边。给定 $(M,w)$，pair 如下（$\#$ 是新 symbol，隔开相邻的 ID）：

| 用途 | $A$ | $B$ |
|---|---|---|
| 第 1 对 | $\#$ | $\#q_0w\#$ |
| 抄写 | $X$（每个 tape symbol）、$\#$ | $X$、$\#$ |
| $\delta(q,X)=(p,Y,R)$ | $qX$ | $Yp$ |
| $\delta(q,X)=(p,Y,L)$ | $ZqX$（每个 $Z$） | $pZY$ |
| 在右端读 blank，$\delta(q,B)=(p,Y,R)$ | $q\#$ | $Yp\#$ |
| 在右端读 blank，$\delta(q,B)=(p,Y,L)$ | $Zq\#$ | $pZY\#$ |
| $q\in F$ 吃掉旁边的 symbol | $XqY$、$Xq$、$qY$ | $q$ |
| 收尾，$q\in F$ | $q\#\#$ | $\#$ |

$B$ 那一行一开始就领先一个 ID。上面要追上，就得把下面多出的那个 ID 逐个 symbol 抄过来，而抄的同时下面会长出下一个 ID：head 附近用 transition 的 pair，其余用抄写的 pair。所以部分解永远是“上面是 $\#ID_0\#\cdots\#ID_{s-1}\#$，下面多一个 $ID_s\#$”，上下都在写 $M$ 在 $w$ 上的运行。只有进入 accepting state 之后，“吃掉旁边 symbol”的 pair 让下面的 ID 每次少一个 symbol，上面才追得上，最后用收尾的 pair 对齐。所以 MPCP 有解当且仅当 $M$ accept $w$。

用最小的例子走一遍：$M$ 只有一条 $\delta(q_0,0)=(q_f,0,R)$，$q_f\in F$，$w=0$，$q_00\vdash0q_f$。依次用第 1 对、$(q_00,\ 0q_f)$、$(\#,\#)$、$(0q_f,\ q_f)$、$(\#,\#)$、$(q_f\#\#,\ \#)$：

| 用到第几对后 | 上面 | 下面 |
|---|---|---|
| 第 1 对 | $\#$ | $\#q_00\#$ |
| $(q_00,0q_f)$、$(\#,\#)$ | $\#q_00\#$ | $\#q_00\#0q_f\#$ |
| $(0q_f,q_f)$、$(\#,\#)$ | $\#q_00\#0q_f\#$ | $\#q_00\#0q_f\#q_f\#$ |
| $(q_f\#\#,\#)$ | $\#q_00\#0q_f\#q_f\#\#$ | $\#q_00\#0q_f\#q_f\#\#$ |

### PCP 推出 grammar 的问题不可判定

给 PCP instance $A$、$B$，再取 $k$ 个新的 index symbol $a_1,\dots,a_k$，造两个 grammar：

$$G_A:\ A\to w_iAa_i\mid w_ia_i,\qquad G_B:\ B\to x_iBa_i\mid x_ia_i\qquad(1\le i\le k)$$

$G_A$ 生成 $w_{i_1}\cdots w_{i_r}\,a_{i_r}\cdots a_{i_1}$：前面是 $w$ 的 concatenation，后面倒着记下用了哪些 index。再令 $G$ 的 start symbol 是 $S$，加 $S\to A\mid B$。

**Claim**：$G$ ambiguous 当且仅当 PCP 有解。

- 若有解 $i_1,\dots,i_r$，则 $w_{i_1}\cdots w_{i_r}a_{i_r}\cdots a_{i_1}=x_{i_1}\cdots x_{i_r}a_{i_r}\cdots a_{i_1}$，它从 $S\Rightarrow A$ 和 $S\Rightarrow B$ 各有一个 derivation，两个 parse tree。
- 反过来，$G_A$ 自己不 ambiguous：string 末尾的 index 从右往左读，每一个都定死了那一步用的是哪条 production。$G_B$ 也一样。所以一个 string 若有两个 parse tree，只能一个从 $A$、一个从 $B$ 来；两边的 index 部分是同一段，所以是同一个序列 $i_1,\dots,i_r$，前面那段相等，正是 PCP 的解。

在上面的 instance 上：$101111110\,a_3a_1a_1a_2$ 既是 $A\Rightarrow w_2Aa_2\Rightarrow w_2w_1Aa_1a_2\Rightarrow w_2w_1w_1Aa_1a_1a_2\Rightarrow w_2w_1w_1w_3a_3a_1a_1a_2$，也是 $B$ 那边同样的四步。

PCP 不是 recursive，所以“给一个 CFG，它是否 ambiguous”不是 recursive。同一个构造也说明“$L(G_A)\cap L(G_B)=\varnothing$ 吗”不可判定：两者相交当且仅当 PCP 有解。

:::note 本页没有展开的部分
讲义接着证明 $\overline{L(G_A)}$ 也是 CFL，由此推出 $L(G_1)=L(G_2)$、$L(G)=L(R)$（$R$ 是 regular expression）、$L(G)=T^*$、$L(G_1)\subseteq L(G_2)$、$L(R)\subseteq L(G)$ 对 CFG 都不可判定。那个 grammar 的构造本页没有写，复习以讲义为准。
:::

## [cx] Time 与 space complexity、linear speedup 与 hierarchy

:::skip
能写出 DTIME、DSPACE 的定义，说清 linear speedup 和 tape compression 为什么让常数无关紧要，会用 hierarchy theorem 的条件判断两个 class 是否真的不同，就可以去第 9 站。两个 theorem 的证明细节可以只看结构。
:::

### 先把“多快”“多省”说准

可 decide 的问题也可能慢得没法用，或者要的 memory 大得没法用。讲义的 model 是固定条数的 multi-tape TM：input tape 只读，input 两端有 endmarker；其余是 work tape，tape alphabet 有限但可以任意大。

- $\mathrm{Time}_M(x)$ 是 $M$ 在 $x$ 上停下之前走的步数，不停就是 $\infty$。Nondeterministic 的 $M$ 取**所有**分支（包括不 accept 的）里最长的那个。若对所有长度为 $n$ 的 $x$ 都有 $\mathrm{Time}_M(x)\le T(n)$，$M$ 叫 $T(n)$ time bounded。通常假设 $T(n)\ge n$，至少得把 input 读一遍。
- $\mathrm{Space}_M(x)$ 是所有 work tape 上访问过的 cell 数的最大值，只读的 input tape 不算。不停就是 $\infty$。$S(n)$ space bounded 的定义同上。

$$\begin{aligned}
\mathrm{DTIME}(T(n))&=\{L\mid\text{某台 }T(n)\text{ time bounded 的 deterministic TM accept }L\}\\
\mathrm{DSPACE}(S(n))&=\{L\mid\text{某台 }S(n)\text{ space bounded 的 deterministic TM accept }L\}
\end{aligned}$$

NTIME、NSPACE 把 deterministic 换成 nondeterministic。Input tape 不算 space，是为了让 sublinear 的 space（比如 $\log n$）有意义：只用一个 counter 记位置的 machine，work tape 上只有 $O(\log n)$ 格。

### 同一个 language，三种速度

拿 $\{a^kb^k\}$ 比较三台 decider（input 长度 $n=2k$）：

1. **来回划掉，single tape。** 先扫一遍检查形如 $a^*b^*$，$O(n)$。然后每一轮从左扫到右，划掉一个 $a$ 和一个 $b$，再回到左端，每轮 $O(n)$，最多 $k=n/2$ 轮。共 $O(n)+\tfrac n2\cdot O(n)=O(n^2)$。第 6 站的 TM 就是这一种。
2. **每轮划掉一半，single tape。** 每一轮先数剩下的 $a$ 和 $b$ 的个数的奇偶（扫一遍，finite control 记住两个 parity bit），奇偶不同就 reject；然后从第一个开始，隔一个划掉一个 $a$，$b$ 也一样。剩 $r$ 个时划掉 $\lceil r/2\rceil$ 个，剩下 $\lfloor r/2\rfloor$ 个，所以 $O(\log n)$ 轮之后全部划完。每轮扫两遍 $O(n)$，共 $O(n\log n)$。
3. **两条 tape。** 把 $a$ 复制到第二条 tape，再让两个 head 同时前进，一个走 $b$、一个走 $a$ 的 copy，同时走完则 accept。$O(n)$。

第 2 种为什么对：每轮读到的 parity 恰好是剩余个数的 binary representation 的最低位，划掉一半相当于右移一位。逐轮比较 parity 就是逐位比较 $a$ 的个数和 $b$ 的个数的 binary representation。

::fig[cs3231-cross] 第 2 台 machine 在 $a^6b^6$ 上的各轮。每轮剩下的个数 6、3、1 的 parity 依次是 0、1、1，正是 6 的 binary 110 从低位读起。

所以“多快”依赖 model：single-tape 是 $O(n\log n)$（可以证明 single-tape 不能更快，本页不证），two-tape 是 $O(n)$。但依赖得很有限：第 6 站说过，$t(n)$ 步的 multi-tape TM 可以用 $O(t(n)^2)$ 步的 single-tape TM simulate。所有“合理”的 deterministic model 之间互相 simulate 都只差一个 polynomial，这是第 9 站定义 P 的理由。

上面一直写 $O(\cdot)$，而 DTIME 的定义里没有 $O$，界就是 $T(n)$ 本身。下面两个 theorem 说明这样定义并不吃亏：常数因子总能压掉。

### Tape compression

**Theorem**：固定 $c>0$。若 $L$ 被一台 $k$-tape、$S(n)$ space bounded 的 $M$ accept，则 $L$ 也被一台 $k$-tape、$\lceil cS(n)\rceil$ space bounded 的 $M'$ accept。

**Proof**：$M'$ 的每条 work tape 上，一个 cell 存 $M$ 对应 tape 上相邻的 $m$ 个 cell，tape alphabet 变成 $\Gamma^m$（再乘上记 head 位置的信息），变大了，但仍有限。$M'$ 的 finite control 记住：当前这个大 cell 里的 $m$ 个格子中，$M$ 的 head 在第几个。$M$ 的一步在 $M'$ 里是同一个大 cell 里改一个 component，或者移到相邻的大 cell。$M'$ accept 当且仅当 $M$ accept。$M$ 用了 $\mathrm{Space}_M(x)$ 个 cell，$M'$ 用 $\lceil\mathrm{Space}_M(x)/m\rceil$ 个。取 $m>1/c$，即 $1/m<c$，就有 $\lceil\mathrm{Space}_M(x)/m\rceil\le\lceil c\,\mathrm{Space}_M(x)\rceil$。

例：$c=1/2$，取 $m=3$。$M$ 用 100 个 cell 时，$M'$ 用 $\lceil100/3\rceil=34\le50$ 个。

### Linear speedup

时间也能这样压，但要多付一点：$M'$ 一步只能动一个大 cell，而 $M$ 的 head 在 $m$ 步之内可能跨出当前的大 cell。

**Theorem**：固定 $c>0$。若 $L$ 被一台 $k\ge2$ tape、$T(n)$ time bounded 的 $M$ accept，并且 $\lim_{n\to\infty}T(n)/n=\infty$，则 $L$ 也被一台 $\lceil cT(n)\rceil$ time bounded 的 $M'$ accept。

**Proof 的构造。** 和 tape compression 一样，每 $m$ 个 cell 压成一个。Input tape 也要压，所以先做初始化：把 input 复制到一条 work tape 上，复制时每 $m$ 个 symbol 写成一个，然后把这条 tape 的 head 移回开头。此后这条 work tape 当作新的 input tape，原来的 input tape 当作 work tape 用（它的 head 不必移回去，在那里做个记号就行）。初始化用 $n+\lceil n/m\rceil$ 步。

之后 $M'$ 反复做一个 basic step，每条 tape 上 head 所在的大 cell 叫 home cell：

1. 读每条 tape 的 home cell，以及它左右两个相邻的大 cell；
2. 在 finite control 里算出 $M$ 接下来的运行，直到 $M$ 的某个 head 第一次离开它的 home cell 和左右邻居这三格范围，或者 $M$ accept；
3. 改写 home cell 和左右邻居，把 head 移到新的 home cell。

::fig[cs3231-speedup] $m=3$。上面是 $M$ 的 tape，每 3 格一组；下面是 $M'$ 的 tape，每格是 $M$ 的一组。$M$ 的 head 从 home cell 里出发走了 3 步，始终没有离开 home cell 和左右邻居（框起来的三组），所以 $M'$ 读这三格就能算出这 3 步。

为什么每个 basic step 至少 simulate 了 $M$ 的 $m$ 步：$M$ 的 head 从 home cell 的某个位置出发，要离开“home cell 加左右邻居”这 $3m$ 格，至少要走 $m$ 步（最近的出口也在 $m$ 格以外）。第 2 步在 finite control 里完成，不花时间，因为三格的内容是有限多种，$M$ 在这期间的行为可以事先算好放进 transition table。第 1 步和第 3 步只要移动 head 去读、写邻居再回来，讲义算出不超过 8 步。所以 $M'$ 用 8 步 simulate $M$ 的至少 $m$ 步。

**数一数。** 总时间不超过

$$n+\lceil n/m\rceil+8\lceil T(n)/m\rceil\le n+\frac nm+\frac{8T(n)}m+9$$

要让它 $\le cT(n)$。不妨设 $0<c<1$，取 $m>40/c$，则 $8T(n)/m<cT(n)/5\le cT(n)/4$。由 $T(n)/n\to\infty$，$n$ 够大时 $n\le cT(n)/4$，于是 $n/m\le cT(n)/4$，$9\le cT(n)/4$ 也成立。四项各不超过 $cT(n)/4$，合起来不超过 $cT(n)$。有限个短的 input 单独处理。

具体一次：$T(n)=n^2$，$c=1/2$，取 $m=81>80$。$n=100$ 时左边是 $100+\lceil100/81\rceil+8\lceil10000/81\rceil=100+2+8\times124=1094$，右边是 $5000$。逐个检查，$n\ge6$ 时都成立；$n=5$ 时左边 $5+1+8=14>12.5$，属于要单独处理的短 input。

两个条件的作用都在初始化：复制和压缩 input 要 $n+\lceil n/m\rceil$ 步，这部分压不掉，所以需要 $T(n)$ 远大于 $n$；复制要一条 work tape，所以要 $k\ge2$。讲义补充说，真正需要的只是存在 $m$ 使上面的总时间 $\le cT(n)$。$T(n)$ 是 linear 时就用这个：若 $M$ 是 $k\ge2$ tape、$dn$ time bounded，则对任意 $c>0$，$L$ 被一台 $(1+c)n$ time bounded 的 machine accept（取 $m>\max(24d/c,\,3/c)$）。

:::wrong $\mathrm{DTIME}(n^2)$ 比 $\mathrm{DTIME}(2n^2)$ 小，因为 $2n^2$ 给了两倍的时间
Linear speedup 说两者相等：$T(n)=2n^2$ 满足 $T(n)/n=2n\to\infty$，取 $c=1/2$，任何 $2n^2$ time bounded（至少 2 条 tape）的 machine 都能换成 $\lceil n^2\rceil=n^2$ time bounded 的。下一节的 time hierarchy theorem 也不会说它们不同：它要求 $T_1\log T_1/T_2\to0$，这里 $\dfrac{n^2\log_2n^2}{2n^2}=\log_2n\to\infty$，条件不满足。
:::

### Time 与 space 之间

讲义列出三条包含关系：

- $\mathrm{DTIME}(S(n))\subseteq\mathrm{DSPACE}(S(n))$：$S(n)$ 步之内每条 tape 最多走到 $S(n)$ 格以外。
- 若 $S(n)\ge\log n$，$L\in\mathrm{DSPACE}(S(n))$，则存在只取决于 $L$ 的常数 $c$，使 $L\in\mathrm{DTIME}(c^{S(n)})$。
- 若 $L\in\mathrm{NTIME}(T(n))$，则存在常数 $c$，使 $L\in\mathrm{DTIME}(c^{T(n)})$：第 6 站的 breadth-first simulation，分支数 $b$ 的 tree 深 $T(n)$，最多 $b^{T(n)+1}$ 个 node。

第二条的理由是数 ID。设 $M$ 有 $s$ 个 state、一条 work tape、tape alphabet 有 $t$ 个 symbol。一个 ID 由 state、input head 的位置（含两个 endmarker 共 $n+2$ 种）、work head 的位置（$S(n)$ 种）和 work tape 的内容（$t^{S(n)}$ 种）决定，总共

$$N=s\,(n+2)\,S(n)\,t^{S(n)}$$

种。Deterministic 的 $M$ 若走了超过 $N$ 步，某个 ID 出现了两次，它会永远绕圈，不会再 accept。所以 $M$ accept 的 input 都在 $N$ 步内 accept，再加一个数到 $N$ 的 counter，超过就 reject。$S(n)\ge\log_2n$ 时 $n\le2^{S(n)}$，于是 $n+2\le3n\le3\cdot2^{S(n)}$，又 $S(n)\le2^{S(n)}$，

$$N\le3s\,(4t)^{S(n)}\le(12st)^{S(n)}$$

（$S(n)\ge1$ 时）。$c=12st$。条件 $S(n)\ge\log n$ 正是为了把 input head 的 $n+2$ 种位置吸收进 $c^{S(n)}$：space 是常数的 machine 光是把 input 读一遍就要 $n$ 步，而 $c^{O(1)}$ 是常数。

### Hierarchy theorem：多给资源，真的能做更多

Linear speedup 说常数倍不算数。那么多给多少才算数？还是用 diagonalization。需要一个技术条件：$S(n)$ 是 fully space constructible，指有一台 TM 在每个长度为 $n$ 的 input 上恰好用 $S(n)$ 格 space；$T(n)$ 是 fully time constructible，指有一台 TM 在每个长度为 $n$ 的 input 上恰好走 $T(n)$ 步停下。$n^2$、$2^n$ 这些常见的 function 都满足。

**Space hierarchy**：若 $S_1(n),S_2(n)\ge\log n$，$S_2$ fully space constructible，且 $\lim_{n\to\infty}S_1(n)/S_2(n)=0$，则存在一个 language 属于 $\mathrm{DSPACE}(S_2(n))$ 而不属于 $\mathrm{DSPACE}(S_1(n))$。

**构造**：$M_0,M_1,\dots$ 是所有 tape alphabet 为 $\{0,1,B\}$ 的 2-tape TM 的一个 enumeration。造 $M$：

- input 形如 $1^k$：reject；
- input 形如 $1^k0x$：先在 work tape 上标出 $S_2(|1^k0x|)$ 格（$S_2$ fully space constructible，所以标得出来）；在这些格子里 simulate $M_x$ 在 $1^k0x$ 上的运行；要用到界外的格子就 reject；$M_x$ 在界内停下，则 $M_x$ 不 accept 时 $M$ accept，$M_x$ accept 时 $M$ reject。

$M$ 是 $S_2$ space bounded 的，所以 $L(M)\in\mathrm{DSPACE}(S_2(n))$。

**为什么不在 $\mathrm{DSPACE}(S_1(n))$ 里**：假设有 $S_1$ space bounded 的 machine accept $L(M)$。讲义先说明：$S(n)\ge\log n$ 时，space bounded 的 machine 可以换成同样 space、在所有 input 上都停的（就是上一节数 ID 的 counter）；再把 alphabet 和 tape 数换成 $\{0,1,B\}$ 和 2 条，space 只乘一个常数。于是有某个 $M_x$，总会停，在 $dS_1(n)$ space 内 accept $L(M)$。$M$ simulate $M_x$ 要 $c\,S_1(n)$ 格，$c$ 取决于 $x$，不取决于 $k$。因为 $S_1/S_2\to0$，可以取 $k$ 大到 $c\,S_1(|1^k0x|)<S_2(|1^k0x|)$，这时 simulation 一定在界内做完，$M$ 在 $1^k0x$ 上的结果和 $M_x$ 相反，$L(M_x)\neq L(M)$，矛盾。

Padding $1^k$ 的作用就在这里：同一台 $M_x$ 对应无限多个 input $1^k0x$，长度可以任意大，总有一个长度让 $S_2$ 超过 simulation 需要的 $c\,S_1$。不加 padding，$M_x$ 只对应一个 input，那个长度上 $c$ 可能太大。

**Time hierarchy**：若 $T_2(n)$ fully time constructible，$T_1(n),T_2(n)\ge(1+\varepsilon)n$，且 $\lim_{n\to\infty}\dfrac{T_1(n)\log T_1(n)}{T_2(n)}=0$，则存在一个 language 属于 $\mathrm{DTIME}(T_2(n))$ 而不属于 $\mathrm{DTIME}(T_1(n))$。

构造和 space 的一样：$M$ 在 $1^k0x$ 上 simulate $M_x$，同时数步数，超过 $T_2(|1^k0x|)$ 步就 reject；$T_2$ fully time constructible，保证这个 counter 自己不超时。$M$ 的时间是 $T_2$ 的常数倍，由 linear speedup 压回 $T_2$。多出的 $\log$ 因子来自 tape 的条数：$M$ 的 tape 条数是固定的（讲义用至少 5 条），而它要 simulate 任意条数的 machine，讲义把被 simulate 的 machine 先换成 2-tape 的，这一步让时间从 $T_1$ 变成 $dT_1\log T_1$。所以要 $T_2$ 比 $T_1\log T_1$ 大得多，simulation 才来得及做完。（MIT 18.404J 用 single-tape model，把这个 $\log$ 解释成每步都要去更新放在 tape 上的 step counter。两边的 theorem 形状相同。）

用一次。$\mathrm{DTIME}(n^2)\subsetneq\mathrm{DTIME}(n^3)$：$\dfrac{n^2\log_2n^2}{n^3}=\dfrac{2\log_2n}{n}\to0$。$\mathrm{DSPACE}(\log n)\subsetneq\mathrm{DSPACE}(n)$：$\dfrac{\log n}{n}\to0$。再往上：每个 $n^k$ 最终都小于 $2^n$（有限个短 input 在 finite control 里查表），所以 $\mathrm P\subseteq\mathrm{DTIME}(2^n)$；而 $\dfrac{2^n\log_22^n}{4^n}=\dfrac{n}{2^n}\to0$，$\mathrm{DTIME}(2^n)\subsetneq\mathrm{DTIME}(4^n)$。于是存在 $4^n$ 时间能 decide、polynomial 时间不能 decide 的 language：P 严格小于 $\bigcup_k\mathrm{DTIME}(2^{n^k})$（EXPTIME）。这是 P 与 NP 那种“不知道”之外，少数确知的 separation。

:::edge 任意难的问题
讲义在 linear speedup 后面还有一个同样用 diagonalization 的结论：对任何 total recursive function $f$，存在 total recursive function $g$，没有 $f(n)$ time bounded 的 machine 能算它。定义 $g(x)$：simulate $M_x$ 在 $x$ 上的运行；若 $f(|x|)$ 步内没停，输出 0；若停了，输出一个和 $M_x(x)$ 不同的值，比如 $M_x(x)+1$。若某台 $f(n)$ time bounded 的 $M_y$ 算 $g$，看 $y$ 本身：$M_y(y)$ 在 $f(|y|)$ 步内停（它是 $f(n)$ time bounded 的），于是 $g(y)\neq M_y(y)$，它算错了。
:::

## [np] P、NP 与 NP-completeness

:::skip
能说出 P 与 NP 的定义、给一个问题写 certificate 和 verifier、写对 polynomial-time reduction 的方向，并能做讲义里 3-SAT 到 vertex cover 的 reduction，就可以结束。Cook–Levin 那一小节只看结构的话可以跳过证明细节。
:::

### P

$$\mathrm P=\bigcup_k\mathrm{DTIME}(n^k)$$

上一站说过，合理的 deterministic model 之间互相 simulate 只差一个 polynomial，所以一个 language 在不在 P 与选哪个 model 无关。这是选 polynomial 作为分界的理由：它是 model 换来换去也不变的最小的类。

例：$PATH=\{\langle G,s,t\rangle\mid\text{directed graph }G\text{ 中有 }s\text{ 到 }t\text{ 的 path}\}$。标记 $s$，然后反复扫所有 edge，把从已标记 node 出发能到的 node 标记上，直到没有新标记。最多 $|V|$ 轮，每轮扫一遍 edge，polynomial，所以 $PATH\in\mathrm P$。

### NP：答案容易检查

$$\mathrm{NP}=\bigcup_k\mathrm{NTIME}(n^k)$$

即能被 polynomial time 的 nondeterministic TM accept 的 language（按上一站的定义，所有分支都要在 polynomial 步内停）。$\mathrm{coNP}$ 是 complement 在 NP 里的 language。

$HAMPATH$：graph 中有没有一条从 $s$ 到 $t$、恰好经过每个 node 一次的 path。暴力尝试 node 的所有排列，$n!$ 种，不是 polynomial。没有人知道 polynomial 的 algorithm。但它在 NP 里：nondeterministic TM 先“猜”出一个 node 序列 $v_1,\dots,v_n$，再检查 $v_1=s$、$v_n=t$、没有重复、相邻两个之间有 edge，都是 polynomial 的。

讲义证明了一个等价的说法：$L\in\mathrm{NP}$ 当且仅当存在 polynomial $q$ 和一个 polynomial time 可算的 predicate $P(x,y)$，使

$$x\in L\iff\exists y\,\big[\,|y|\le q(|x|)\ \text{且}\ P(x,y)\,\big]$$

$y$ 叫 certificate，算 $P$ 的 machine 叫 verifier。

- （$\Rightarrow$）取 accept $L$ 的 $q(n)$ time bounded nondeterministic TM $N$，不妨设每一步恰好有两个选择。让 $y$ 的第 $i$ 个 bit 决定第 $i$ 步走哪一个，$P(x,y)$ 就照着 $y$ deterministic 地重放这一条分支，accept 则为真。$|y|\le q(|x|)$。
- （$\Leftarrow$）nondeterministic TM 先逐 bit 猜出 $y$（$q(|x|)$ 步），再运行 $P$ 的 polynomial time algorithm。

$HAMPATH$ 的 certificate 就是那条 path。$\mathrm P\subseteq\mathrm{NP}$：能 decide 就不需要 certificate，verifier 忽略 $y$ 直接算。$\mathrm P=\mathrm{NP}$ 是否成立是 open problem。注意不对称：图里没有 Hamiltonian path 时，通常拿不出这样短的证据，所以 $\overline{HAMPATH}$ 在不在 NP 里并不知道。

:::wrong NP 就是 not polynomial，NP 里的问题都要 exponential time
NP 是 nondeterministic polynomial。$PATH\in\mathrm P\subseteq\mathrm{NP}$，它是 NP 里的问题，却有 polynomial 的 algorithm；把一条 path 当 certificate，verifier 只需检查它，也说明 $PATH\in\mathrm{NP}$。“NP 里的问题都很难”恰好是还没有被证明的 $\mathrm P\neq\mathrm{NP}$；就算它成立，也只说明 NP 里有些问题不在 P 里。
:::

### Polynomial-time reduction 与 NP-completeness

和第 7 站的 $\le_m$ 一样，只是要求 $f$ 在 polynomial time 内算完：$L_1\le_m^pL_2$，指存在 polynomial time 可算的 $f$，使 $x\in L_1\iff f(x)\in L_2$。若 $L_2\in\mathrm P$，则 $L_1\in\mathrm P$：算 $f(x)$ 是 polynomial，$|f(x)|$ 也就是 polynomial，再跑 $L_2$ 的 polynomial algorithm，polynomial 套 polynomial 仍是 polynomial。$\le_m^p$ 是 transitive 的：$f$ 给出 $L_1\le_m^pL_2$、$g$ 给出 $L_2\le_m^pL_3$，则 $g(f(x))$ 给出 $L_1\le_m^pL_3$。

$L$ 是 **NP-hard**，指每个 $L'\in\mathrm{NP}$ 都有 $L'\le_m^pL$；再加上 $L\in\mathrm{NP}$，就是 **NP-complete**。讲义的 theorem：若某个 NP-complete 问题在 P 里，则 $\mathrm P=\mathrm{NP}$；等价地，若 $\mathrm P\neq\mathrm{NP}$，没有 NP-complete 问题在 P 里。由 transitivity，证明新问题 $L'$ NP-complete 只需两件事：$L'\in\mathrm{NP}$，以及某个已知 NP-complete 的 $L$ 满足 $L\le_m^pL'$。方向和第 7 站一样：已知难的放左边。

### Cook–Levin：SAT 是 NP-complete

:::skip
讲义把 SAT 列为第一个 NP-complete 问题，没有给证明。这一小节按 MIT 18.404J 第 16 讲给出证明的结构和每一部分的大小。跳过它会少掉“为什么第一个 NP-complete 问题存在”的理由。
:::

$SAT$：一个 Boolean formula 有没有 satisfying assignment。$SAT\in\mathrm{NP}$，certificate 就是 assignment。难的是证明每个 $L\in\mathrm{NP}$ 都 $\le_m^pSAT$，这时对 $L$ 一无所知，只知道有一台 $n^k$ 时间的 nondeterministic TM $N$ accept 它。

思路：$N$ 在 $w$ 上的一条 accepting 分支可以写成一张表（tableau），$n^k$ 行，每行是一个 ID，第一行是 start ID，相邻两行是一步合法的 move，某一行含 accepting state。Tape 不会超过 $n^k$ 格，所以表是 $n^k\times n^k$ 的。给每一格、每个可能的 symbol（tape symbol 或 state）一个 Boolean variable $x_{i,j,\sigma}$，表示“第 $i$ 行第 $j$ 格是 $\sigma$”。造 formula $\varphi_w=\varphi_{cell}\wedge\varphi_{start}\wedge\varphi_{move}\wedge\varphi_{accept}$：

- $\varphi_{cell}$：每格恰好一个 symbol；
- $\varphi_{start}$：第一行是 $N$ 在 $w$ 上的 start ID，即对第一行每个位置 $j$ 取 $x_{1,j,c_j}$ 的 conjunction，$c_j$ 是 start ID 的第 $j$ 个 symbol；
- $\varphi_{accept}$：$\bigvee_{i,j}x_{i,j,q_{accept}}$；
- $\varphi_{move}$：每个 $2\times3$ 的 window 都是 legal 的。TM 一步只改 head 附近的格子，下一行每一格只取决于上一行它附近的三格，所以“每个 window 都 legal”保证“每一行由上一行走一步得到”。每个 window 的 legal 内容是一个只取决于 $N$ 的有限 list。

$\varphi_w$ satisfiable 当且仅当存在 accepting tableau，当且仅当 $N$ accept $w$。表有 $n^{2k}$ 格，每部分对每格或每个 window 写常数长的 clause，所以 $\varphi_w$ 的长度是 $O(n^{2k})$，能在 polynomial time 内写出来。这就是 $L\le_m^pSAT$。MIT 接着把 SAT reduce 到 3-SAT：formula 的每个 $\wedge$、$\vee$ 节点引入一个新 variable，写几个每个至多 3 个 literal 的 clause 约束它和两个 child 的关系，再加一个 clause 要求 root 为真；satisfiability 不变，formula 只变长常数倍。

### 讲义的 reduction：3-SAT 到 vertex cover

**Vertex cover**：graph $G=(V,E)$ 和 integer $k$，有没有 $V'\subseteq V$，$|V'|\le k$，使每条 edge 至少有一个 endpoint 在 $V'$ 里。它在 NP 里：猜 $V'$，检查大小和每条 edge。

**构造。** 给 3-SAT 的 instance：variable $x_1,\dots,x_n$，clause $c_1,\dots,c_m$，$c_j=(l_{j,1}\vee l_{j,2}\vee l_{j,3})$。

- 每个 variable $x_i$ 两个 vertex $u_i$、$w_i$，连一条 edge $(u_i,w_i)$。$u_i$ 代表 $x_i$，$w_i$ 代表 $\neg x_i$。
- 每个 clause $c_j$ 三个 vertex $z_{j,1},z_{j,2},z_{j,3}$，两两相连成 triangle。$z_{j,r}$ 代表 literal $l_{j,r}$。
- $l_{j,r}=x_i$ 时连 $(z_{j,r},u_i)$；$l_{j,r}=\neg x_i$ 时连 $(z_{j,r},w_i)$。
- $k=2m+n$。

Vertex 有 $2n+3m$ 个，edge 有 $n+3m+3m$ 条，polynomial time 内造完。

**下界。** 任何 vertex cover 都要在每条 $(u_i,w_i)$ 上至少选一个，在每个 triangle 里至少选两个（只选一个，另外两个之间那条 edge 就没盖住）。这些 edge 互不共享 endpoint，所以任何 cover 至少 $n+2m$ 个 vertex；大小 $\le2m+n$ 的 cover 必须**恰好**每对选一个、每个 triangle 选两个。

**（$\Rightarrow$）satisfiable 则有大小 $k$ 的 cover。** $x_i$ 为真就选 $u_i$，为假就选 $w_i$。每个 clause 里挑一个为真的 literal $l_{j,r}$，triangle 里留下 $z_{j,r}$ 不选，选另外两个。检查连向 variable 的 edge：被选中的 $z$ 那两条自然盖住了；留下的 $z_{j,r}$ 连到代表 $l_{j,r}$ 的那个 vertex，而 $l_{j,r}$ 为真，那个 vertex 被选了。

**（$\Leftarrow$）有大小 $\le k$ 的 cover 则 satisfiable。** 由下界，每对恰好一个。令 $x_i$ 为真当且仅当 $u_i$ 在 cover 里。每个 triangle 恰好有一个 $z_{j,r}$ 不在 cover 里，它连出去的那条 edge 只能靠另一端盖住，所以代表 $l_{j,r}$ 的 vertex 在 cover 里，也就是 $l_{j,r}$ 为真，$c_j$ 被满足。

用 [CS3230 第 8 站](../courses/CS3230.html#np)的同一个 formula：

$$\varphi=(x_1\lor\lnot x_2\lor x_3)\land(\lnot x_1\lor x_2\lor x_3)\land(\lnot x_1\lor\lnot x_2\lor\lnot x_3)$$

$n=m=3$，$k=2\cdot3+3=9$，15 个 vertex，$3+9+9=21$ 条 edge。取 $x_1=$ false、$x_2=$ false、$x_3=$ true：选 $w_1,w_2,u_3$；$c_1$ 里 $\lnot x_2$ 为真，留下 $z_{1,2}$，选 $z_{1,1},z_{1,3}$；$c_2$ 里 $\lnot x_1$ 为真，留下 $z_{2,1}$，选 $z_{2,2},z_{2,3}$；$c_3$ 里 $\lnot x_1$ 为真，留下 $z_{3,1}$，选 $z_{3,2},z_{3,3}$。共 9 个。

::fig[cs3231-vc] $\varphi$ 对应的 graph。上面一排是三对 $u_i$、$w_i$，下面是三个 triangle。实心的 9 个 vertex 是上面那个 cover；每个 triangle 里留空的那个 vertex，连出去的 edge 都由上面实心的 vertex 盖住。

逐条核对三条留下的 vertex 连出去的 edge：$z_{1,2}$ 代表 $\lnot x_2$，连 $w_2$，选了；$z_{2,1}$、$z_{3,1}$ 代表 $\lnot x_1$，连 $w_1$，选了。用程序枚举：这个 graph 没有 8 个 vertex 的 cover，9 个的 cover 有 18 个；$\varphi$ 有 5 个 satisfying assignment。两边并不一一对应，reduction 也不需要，只需要“有”与“有”对应。

**Clique 与 independent set。** 讲义接着用 complement 一次推出两个。$S$ 是 independent set（两两不相邻）当且仅当 $V-S$ 是 vertex cover：每条 edge 不会两端都在 $S$ 里，等价于至少一端在 $V-S$ 里。$S$ 在 $G$ 里是 independent set 当且仅当它在 complement graph $G'=(V,E^c)$（$E^c$ 是所有不在 $E$ 里的 pair）里是 clique。所以三者等价：$G$ 有大小 $k$ 的 vertex cover；$G$ 有大小 $|V|-k$ 的 independent set；$G'$ 有大小 $|V|-k$ 的 clique。这两个转换都是 polynomial 的，clique 和 independent set 都在 NP 里，所以它们也是 NP-complete。在上面的 graph 上，cover 以外的 6 个 vertex $u_1,u_2,w_3,z_{1,2},z_{2,1},z_{3,1}$ 就是一个 independent set。
