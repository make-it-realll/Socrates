先看三个问题。

**第一个。** 一串 bit 一个一个地到来，最高位在前，读完之后要回答：这个 binary number 能不能被 3 整除。String 可能有一百万位长，你没有地方把它存下来。

**第二个。** 同样一个一个地读，读完回答：前面若干个 0 和后面若干个 1 的个数是不是相等，也就是 input 是不是形如 $0^n1^n$。

**第三个。** 给你任意一个 program 的 source code 和一个 input，回答：这个 program 在这个 input 上会不会停。

第一个问题只要记住 3 种情况就够了，不管 string 多长（第 1 站）。第二个问题用任何有限的 memory 都做不到，要证明这一点需要一个专门的 argument（第 4 站）；加一个 stack 就能做（第 5 站）。第三个问题用任何 program 都做不到，这是可以证明的（第 7 站）。

这门课就是按 memory 的形态给 machine 分级，再精确地划出每一级能做什么、不能做什么：

| Machine | Memory | 能识别的 language | 典型的“做不到” |
|---|---|---|---|
| DFA、NFA | 有限个 state | regular language | $\{0^n1^n\}$ |
| PDA | 有限个 state 加一个 stack | context-free language | $\{a^nb^nc^n\}$ |
| Turing machine | 有限个 state 加一条无限长的 tape | recognizable language | halting problem |

每一级都要回答两类问题：怎样证明一个 language 属于这一级（造一台 machine），怎样证明它不属于（一个 impossibility proof）。后一类是这门课的难点，也是 midterm 和 final 的主要分值所在。最后一站把“能不能算”换成“能不能在 polynomial time 内算”，引出 P 与 NP。

NUS 这门课用 Hopcroft–Motwani–Ullman（下面简称 HMU）的记号：regular expression 里的 union 写成 $+$，DFA 的 extended transition function 写成 $\hat\delta$。MIT 18.404J 用的是 Sipser 的记号（union 写成 $\cup$），两者内容一致。

## [dfa] DFA 与 regular language

:::skip
能写出一个 DFA 的 5-tuple、用 $\hat\delta$ 走完一个 string、用 product construction 造出 intersection 和 union 的 DFA，并且知道做 complement 之前 DFA 必须是 complete 的，就可以去第 2 站。
:::

### 只记住 remainder

回到第一个问题。设已经读过的 prefix 表示的数是 $v$，下一个 bit 是 $b$。在 binary 里，后面添一位相当于乘 2 再加这一位，所以新的数是 $2v+b$。要判断的只是它除以 3 的 remainder，而

$$v=3q+r,\quad r=v\bmod 3\qquad\Longrightarrow\qquad 2v+b=6q+(2r+b)$$

$6q$ 能被 3 整除，所以 $(2v+b)\bmod3=(2r+b)\bmod3$。新的 remainder 只取决于旧的 remainder $r$ 和新的 bit $b$，和 $v$ 本身有多大无关。于是只需要记住 $r\in\{0,1,2\}$ 三种情况之一。把 $r'=(2r+b)\bmod 3$ 逐个算出来：

| 当前 $r$ | 读到 0：$2r\bmod3$ | 读到 1：$(2r+1)\bmod3$ |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 2 | 0 |
| 2 | 1 | 2 |

开始时什么都没读，$v=0$，$r=0$。读完之后 $r=0$ 就回答 yes。

::fig[cs3231-mod3] 这张表画成 state diagram，再让它读 1001（也就是 9）。看当前 state 怎样随每个 bit 跳动，下方同时给出 prefix 的值和它的 remainder，两者始终一致。

### 定义

一台 deterministic finite automaton（DFA）是一个 5-tuple $A=(Q,\Sigma,\delta,q_0,F)$：$Q$ 是有限的 state set，$\Sigma$ 是 alphabet，$\delta:Q\times\Sigma\to Q$ 是 transition function，$q_0\in Q$ 是 start state，$F\subseteq Q$ 是 accepting state 的 set。$\delta$ 对每一对 (state, symbol) 恰好给出一个 state，这就是 deterministic 的意思。

$\delta$ 一次只吃一个 symbol。为了谈论整个 string，把它扩展成 $\hat\delta:Q\times\Sigma^*\to Q$，对 string 的长度做 inductive definition：

$$\hat\delta(q,\varepsilon)=q,\qquad \hat\delta(q,xa)=\delta\big(\hat\delta(q,x),a\big)$$

$\varepsilon$ 是 empty string，$x$ 是任意 string，$a$ 是一个 symbol。DFA 的 language 是 $L(A)=\{w\mid\hat\delta(q_0,w)\in F\}$。如果某个 DFA 的 language 恰好是 $L$，就说 $L$ 是 regular language。

拿上面的 DFA 检验一遍。$Q=\{0,1,2\}$，$\Sigma=\{0,1\}$，$q_0=0$，$F=\{0\}$，$\delta$ 是那张表。按定义一层一层展开 $\hat\delta(0,1001)$：

$$\begin{aligned}
\hat\delta(0,\varepsilon)&=0\\
\hat\delta(0,1)&=\delta(0,1)=1\\
\hat\delta(0,10)&=\delta(1,0)=2\\
\hat\delta(0,100)&=\delta(2,0)=1\\
\hat\delta(0,1001)&=\delta(1,1)=0\in F
\end{aligned}$$

所以 1001 被 accept，和 $9=3\times3$ 一致。

### 证明它恰好 accept 该 accept 的

走通一个例子不等于 DFA 对所有 string 都对。要证的是：对每个 $w\in\{0,1\}^*$，$\hat\delta(0,w)=\mathrm{val}(w)\bmod3$，其中 $\mathrm{val}(w)$ 是 $w$ 表示的数（$\mathrm{val}(\varepsilon)=0$）。对 $|w|$ 做 induction。

**Base**：$|w|=0$，$w=\varepsilon$。$\hat\delta(0,\varepsilon)=0=\mathrm{val}(\varepsilon)\bmod3$。

**Step**：设对长度为 $n$ 的 $x$ 成立，看 $w=xb$。

$$\hat\delta(0,xb)=\delta\big(\hat\delta(0,x),b\big)=\delta\big(\mathrm{val}(x)\bmod3,\;b\big)=\big(2(\mathrm{val}(x)\bmod3)+b\big)\bmod3$$

第一个等号是 $\hat\delta$ 的定义，第二个用 induction hypothesis，第三个是 $\delta$ 的构造方式。由第一小节的计算，$(2r+b)\bmod3=(2v+b)\bmod3$，而 $2\,\mathrm{val}(x)+b=\mathrm{val}(xb)$，所以右边等于 $\mathrm{val}(xb)\bmod3$。

于是 $w\in L(A)\iff\hat\delta(0,w)=0\iff\mathrm{val}(w)\bmod3=0$。

设计 DFA 的一般做法就是这一站的做法：先问“读完一个 prefix 之后，为了将来能答对，必须记住关于它的什么”，把可能的答案列成 state，再用 induction 证明每个 state 的含义被每次 transition 保持。

### 两台 DFA 同时跑：product construction

现在要判断两件事同时成立：能被 3 整除，并且含有偶数个 1。第二件事也有一个 DFA，两个 state $e$（目前偶数个 1）和 $o$（奇数个），读 0 不动，读 1 互换。

一台 DFA 读 input 只能读一遍，但它可以同时记住两台 DFA 各自的 state。设 $A_1=(Q_1,\Sigma,\delta_1,p_0,F_1)$，$A_2=(Q_2,\Sigma,\delta_2,q_0,F_2)$，造

$$Q=Q_1\times Q_2,\qquad \delta\big((p,q),a\big)=\big(\delta_1(p,a),\,\delta_2(q,a)\big),\qquad\text{start}=(p_0,q_0)$$

对 $|w|$ 做 induction 立刻得到 $\hat\delta((p_0,q_0),w)=(\hat\delta_1(p_0,w),\hat\delta_2(q_0,w))$：base 两边都是 $(p_0,q_0)$；step 中 $\hat\delta((p_0,q_0),xa)=\delta((\hat\delta_1(p_0,x),\hat\delta_2(q_0,x)),a)=(\delta_1(\hat\delta_1(p_0,x),a),\delta_2(\hat\delta_2(q_0,x),a))$，两个 component 分别就是 $\hat\delta_1(p_0,xa)$ 和 $\hat\delta_2(q_0,xa)$。

所以 accepting state 怎么选，决定了得到什么 language：

| $F$ 取 | 得到 |
|---|---|
| $F_1\times F_2$ | $L(A_1)\cap L(A_2)$ |
| $(F_1\times Q_2)\cup(Q_1\times F_2)$ | $L(A_1)\cup L(A_2)$ |

::fig[cs3231-product] 两台 DFA 的 product 有 $3\times2=6$ 个 state。横着是 remainder，竖着是 1 的个数的 parity。读 0 只在同一行里走，读 1 一定换行。

用 1001 检验 intersection：$(0,e)\xrightarrow{1}(1,o)\xrightarrow{0}(2,o)\xrightarrow{0}(1,o)\xrightarrow{1}(0,e)$，停在 $(0,e)\in F_1\times F_2$。9 能被 3 整除，有两个 1，对得上。再看 111（7）：$(0,e)\to(1,o)\to(0,e)\to(1,o)$，reject，7 既不能被 3 整除，1 的个数也是奇数。

Complement 更简单：$L$ 有 DFA，就把 $F$ 换成 $Q\setminus F$。每个 $w$ 停在唯一一个 state，这个 state 要么在 $F$ 里要么不在，所以换完恰好 accept 原来 reject 的 string。

由此 regular language 对 union、intersection、complement 都 closed。

:::wrong Union 的 product 也只要两边都 accept 的 pair 当 accepting state
取 $w=101$（5）。5 不能被 3 整除，但有两个 1，所以 $w$ 属于 union。在 product 里走：$(0,e)\xrightarrow{1}(1,o)\xrightarrow{0}(2,o)\xrightarrow{1}(2,e)$。$(2,e)$ 只有第二个 component 是 accepting，不在 $F_1\times F_2$ 里，于是 101 被 reject。只取 $F_1\times F_2$ 得到的是 intersection；union 要求“至少一边 accept”，accepting state 必须是 $(F_1\times Q_2)\cup(Q_1\times F_2)$，这里共有 $1\times2+3\times1-1\times1=4$ 个。
:::

:::edge 画图时省掉的 transition
很多题目画 DFA 时只画“有用”的 transition，没画出来的 (state, symbol) 默认去一个看不见的 dead state，它不是 accepting，而且所有 transition 都回到自己。做 complement 前必须先把这个 dead state 补出来：如果直接交换画出来的那几个 state，原来掉进 dead state 而被 reject 的 string，换完之后仍然被 reject，complement 就错了。
:::

## [nfa] NFA、ε-transition 与 subset construction

:::skip
能对一个 NFA 逐 symbol 算 active set，能做 subset construction（含 ECLOSE），能说清它为什么正确，就可以去第 3 站。
:::

### 一个要“猜”的 language

设 $L_2$ 是所有倒数第二个 symbol 是 1 的 binary string。读的时候不知道哪里是结尾，所以 DFA 每一步都得为“也许再读一个就结束”做准备。

换一个角度：如果允许 machine 在读到某个 1 的时候“猜”这就是倒数第二个，事情就很简单。$q_0$ 读什么都留在 $q_0$；在 $q_0$ 读到 1 时，也可以去 $q_1$，表示“我猜这个 1 是倒数第二个”；$q_1$ 再读任意一个 symbol 去 $q_2$；$q_2$ 是 accepting state，没有出去的 transition。猜错的那一路要么太早到 $q_2$ 然后又读到 symbol 无路可走（死掉），要么停在 $q_0$ 或 $q_1$。规定：只要有一条路在读完时停在 accepting state，就 accept。

这样的 machine 叫 nondeterministic finite automaton（NFA）。它不是物理上能造的机器，但它有一个确定的执行方式：把所有可能的路同时跟踪，每一步记下“现在可能在哪些 state”，也就是一个 state 的 set。

::fig[cs3231-nfarun] 这个 NFA 读 0110。实心的 state 是当前 active 的。读到第一个 1 时 active set 分裂成两个 state；读完时 set 里含有 $q_2$，所以 accept。

逐步写出来：

| 已读 | active set |
|---|---|
| $\varepsilon$ | $\{q_0\}$ |
| 0 | $\{q_0\}$ |
| 01 | $\{q_0,q_1\}$ |
| 011 | $\{q_0,q_1,q_2\}$ |
| 0110 | $\{q_0,q_2\}$ |

0110 的倒数第二个 symbol 确实是 1。换成 0101：读完 01 是 $\{q_0,q_1\}$；读 0，$q_0\to\{q_0\}$，$q_1\to\{q_2\}$，得 $\{q_0,q_2\}$；读 1，$q_0\to\{q_0,q_1\}$，$q_2$ 没有 transition，得 $\{q_0,q_1\}$，不含 $q_2$，reject。0101 的倒数第二个是 0，对得上。每一步都是把当前 set 里每个 state 的 transition 并起来，一个 state 都不能漏。

### 定义

NFA 也是 5-tuple $(Q,\Sigma,\delta,q_0,F)$，只是 $\delta:Q\times\Sigma\to\mathcal P(Q)$，给出的是 $Q$ 的一个 subset（可以是 $\varnothing$）。Extended transition function 同样对长度做 inductive definition：

$$\hat\delta(q,\varepsilon)=\{q\},\qquad \hat\delta(q,xa)=\bigcup_{p\in\hat\delta(q,x)}\delta(p,a)$$

$L(N)=\{w\mid \hat\delta(q_0,w)\cap F\neq\varnothing\}$。

上面那张表就是在逐行计算 $\hat\delta(q_0,\cdot)$。例如从第 3 行到第 4 行：$\hat\delta(q_0,011)=\delta(q_0,1)\cup\delta(q_1,1)=\{q_0,q_1\}\cup\{q_2\}=\{q_0,q_1,q_2\}$。

### Subset construction

上表里出现的每个 set 只取决于已读的 prefix，下一个 set 只取决于当前 set 和下一个 symbol。这正是一台 DFA：它的 state 是 NFA 的 state 的 subset。

给定 NFA $N=(Q,\Sigma,\delta,q_0,F)$，造 DFA $D$：

- state 是 $Q$ 的 subset；start state 是 $\{q_0\}$；
- $\delta_D(S,a)=\bigcup_{p\in S}\delta(p,a)$；
- $S$ 是 accepting state 当且仅当 $S\cap F\neq\varnothing$。

$Q$ 有 $n$ 个 state 时，subset 共有 $2^n$ 个，但实际上只需要从 $\{q_0\}$ 出发、按需生成 reachable 的那些：维护一个待处理的 list，每处理一个 subset 就算出它在每个 symbol 上去哪里，遇到新的 subset 就加入 list。

::fig[cs3231-subset] 对上面的 NFA 做 subset construction。每一帧处理一个 subset，新出现的 subset 加到表的下方；处理到第 4 行时不再有新的 subset，构造结束。

结果是 4 个 state，不是 $2^3=8$ 个，其余 4 个 subset（例如 $\{q_1\}$）从 $\{q_0\}$ 永远到不了。4 个 state 各有含义：set 含 $q_1$ 当且仅当刚读的 symbol 是 1，含 $q_2$ 当且仅当倒数第二个是 1。所以 $\{q_0\}$、$\{q_0,q_1\}$、$\{q_0,q_2\}$、$\{q_0,q_1,q_2\}$ 分别表示最后两位是 00、01、10、11。DFA 在记最后两位，这正是一开始觉得 DFA 难写的原因。

### 为什么它是对的

要证 $L(D)=L(N)$。关键 claim：对每个 string $w$，

$$\hat\delta_D(\{q_0\},w)=\hat\delta_N(q_0,w)$$

对 $|w|$ 做 induction。

**Base**：$\hat\delta_D(\{q_0\},\varepsilon)=\{q_0\}$（DFA 的定义），$\hat\delta_N(q_0,\varepsilon)=\{q_0\}$（NFA 的定义），相等。

**Step**：设对 $x$ 成立，记 $S=\hat\delta_N(q_0,x)$，于是 $\hat\delta_D(\{q_0\},x)=S$。

$$\hat\delta_D(\{q_0\},xa)=\delta_D\big(\hat\delta_D(\{q_0\},x),a\big)=\delta_D(S,a)=\bigcup_{p\in S}\delta(p,a)=\hat\delta_N(q_0,xa)$$

依次用了 DFA 的 $\hat\delta$ 定义、induction hypothesis、$\delta_D$ 的定义、NFA 的 $\hat\delta$ 定义。

有了 claim：$w\in L(D)\iff\hat\delta_D(\{q_0\},w)\cap F\neq\varnothing\iff\hat\delta_N(q_0,w)\cap F\neq\varnothing\iff w\in L(N)$。

反过来，每个 DFA 都是一个每个 $\delta(q,a)$ 恰好是 singleton 的 NFA。所以 NFA 和 DFA 识别的 language 是同一类：regular language。

### ε-transition

再放宽一步：允许 NFA 不读 symbol 就换 state，这种 transition 标作 $\varepsilon$。第 3 站把 regular expression 转成 automaton 时会大量用到它。

需要一个新概念：$\mathrm{ECLOSE}(q)$ 是从 $q$ 出发只走 $\varepsilon$-transition（可以走零步）能到的所有 state。Subset construction 只改两处：start state 是 $\mathrm{ECLOSE}(q_0)$；每读一个 symbol 之后再取一次 closure，

$$\delta_D(S,a)=\bigcup_{r\in R}\mathrm{ECLOSE}(r),\qquad R=\bigcup_{p\in S}\delta(p,a)$$

例子：state $p$ 读 0 回到 $p$，$p$ 有一条 $\varepsilon$-transition 到 $r$，$r$ 读 1 回到 $r$，$r$ 是 accepting state。它的 language 是 $0^*1^*$。$\mathrm{ECLOSE}(p)=\{p,r\}$，$\mathrm{ECLOSE}(r)=\{r\}$。

- 读 001：$\{p,r\}\xrightarrow{0}\mathrm{ECLOSE}(p)=\{p,r\}\xrightarrow{0}\{p,r\}\xrightarrow{1}\mathrm{ECLOSE}(r)=\{r\}$，含 $r$，accept。
- 读 10：$\{p,r\}\xrightarrow{1}\{r\}\xrightarrow{0}\varnothing$，reject。

正确性的证明和上面一样，只是 claim 里的 $\hat\delta_N$ 换成带 closure 的版本。

:::wrong 把 NFA 的 accepting state 和其余 state 对调，就得到 complement 的 NFA
对 $L_2$ 的 NFA 这样做，新的 accepting state 是 $\{q_0,q_1\}$。但 $q_0$ 读任何 symbol 都留在 $q_0$，所以对每个 string，active set 里总有 $q_0$，新 NFA accept 所有 string，包括 0110 这样本来就在 $L_2$ 里的。原因是 NFA 的 accept 是“存在一条路”，对调之后变成“存在一条路不停在原来的 accepting state”，它的否定才是“所有路都不停在那里”，两者不是一回事。正确做法：先做 subset construction 得到 DFA，再在 DFA 上对调，得到的 accepting state 是 $\{q_0\}$ 和 $\{q_0,q_1\}$，恰好对应最后两位是 00、01。
:::

:::edge 2ⁿ 不是虚惊
上面的例子只用了 4 个 subset，但有的 NFA 确实要用到指数多个。把 $L_2$ 推广成 $L_k$（倒数第 $k$ 个 symbol 是 1），NFA 只要 $k+1$ 个 state，任何 DFA 却至少要 $2^k$ 个。证明要用第 4 站的 distinguishability，在那里补上。
:::

NFA 的三种理解方式（parallel thread、tree、guess）和 subset construction 的定义来自 [MIT 18.404J 第 2 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/d741901d23b4522588e267177c77d10d_MIT18_404f20_lec2.pdf)（MIT 用“concatenation 不知道在哪里切开”引出 nondeterminism，本页改用 $L_2$ 的“猜”来引出）；把 NFA 看成同时在很多 state 里的 DFA、DFA 可能指数级变大，来自 [Stanford CS103 Lecture 16](https://web.stanford.edu/class/archive/cs/cs103/cs103.1264/lectures/16/Condensed%20Lecture%20Slides.pdf)（它的 subset construction 例子抽出的文字不完整，没有用）。$\hat\delta$ 的 inductive definition、ECLOSE 的写法和 induction 证明跟 Sanjay Jain 的[讲义](http://www.comp.nus.edu.sg/~sanjay/cs3231/dfa.pdf)。“倒数第二个是 1”的例子、它的 4 个 subset 和 $0^*1^*$ 的 ε-NFA 是我自己的例子。

## [regex] Regular expression 与 Kleene's theorem

:::skip
能把 regular expression 转成 ε-NFA，能用 $R^{(k)}_{ij}$ 把 2 到 3 个 state 的 DFA 转成 regular expression，就可以去第 4 站。
:::

### 用一行字描述 language

Automaton 是一台 machine，写在纸上要画图。搜索文本、写 lexer 时需要一种能打成一行字的描述方式。Regular expression 对结构做 inductive definition：

- **Base**：$\varnothing$ 表示 empty language；$\varepsilon$ 表示 $\{\varepsilon\}$；每个 symbol $a$ 表示 $\{a\}$。
- **Induction**：若 $r$、$s$ 是 regular expression，则 $r+s$ 表示 $L(r)\cup L(s)$；$rs$ 表示 concatenation $\{xy\mid x\in L(r),y\in L(s)\}$；$r^*$ 表示 $L(r)$ 中零个或多个 string 的 concatenation（所以总含 $\varepsilon$）。

Precedence 从高到低是 $^*$、concatenation、$+$。

用定义读一个 expression：$(0+1)^*1(0+1)$。$L(0+1)=\{0,1\}$，所以 $L((0+1)^*)$ 是所有 binary string；后面接一个 1，再接一个 symbol。整体是 $\{x1y\mid x\in\{0,1\}^*,\ y\in\{0,1\}\}$，正是第 2 站的 $L_2$。

:::wrong $(0+1)^*$ 和 $0^*+1^*$ 是一样的
$01\in L((0+1)^*)$：从 $L(0+1)$ 里先取 0、再取 1，接起来。而 $L(0^*+1^*)$ 里的 string 要么全是 0、要么全是 1，不含 01。Star 每次重复可以重新选一个 string，所以它不能分配到 $+$ 的两边。
:::

### Regular expression 转成 ε-NFA

要证每个 regular expression 的 language 都是 regular，就沿着它的 inductive definition 造 automaton：base 的三种情况各给一台小 automaton，每个 operator 给一种拼接方法。为了拼接时不出意外，每台 automaton 都保持一个 invariant：恰好一个 accepting state，start state 没有进来的 transition，accepting state 没有出去的 transition。

- $a$：两个 state，一条标 $a$ 的 transition。$\varepsilon$：一条 $\varepsilon$-transition。$\varnothing$：两个 state，没有 transition。
- $r+s$：新的 start state 用 $\varepsilon$ 连到两台的 start state，两台的 accepting state 用 $\varepsilon$ 连到新的 accepting state。
- $rs$：$r$ 的 accepting state 用 $\varepsilon$ 连到 $s$ 的 start state。
- $r^*$：新的 start state 和新的 accepting state；新 start 用 $\varepsilon$ 连到 $r$ 的 start 和新 accepting（这一条负责 $\varepsilon$）；$r$ 的 accepting state 用 $\varepsilon$ 连回 $r$ 的 start（再来一遍）和新 accepting。

Invariant 的用处在 star 里看得最清楚：如果 $r$ 的 start state 有进来的 transition，“连回 start”就可能让 machine 在 $r$ 内部绕出 $L(r)$ 以外的路。Sanjay Jain 的讲义在 concatenation 时也另加新的 start 和 accepting state，多两个 state，language 不变。

::fig[cs3231-thompson] 按上面的规则为 $0^*1$ 造出的 ε-NFA。先给 0 造 $s_0\to f_0$，加 star 得到 $s$、$f$ 和四条 $\varepsilon$，再给 1 造 $s_1\to f_1$，最后用 $f\to s_1$ 接起来。下方是它读 001 时的 active set。

在这台 ε-NFA 上跑一遍 001：$\mathrm{ECLOSE}(s)=\{s,s_0,f,s_1\}$。读 0，只有 $s_0$ 有 0-transition，到 $f_0$，$\mathrm{ECLOSE}(f_0)=\{f_0,s_0,f,s_1\}$。再读 0，同样得到 $\{f_0,s_0,f,s_1\}$。读 1，只有 $s_1$ 有 1-transition，到 $f_1$，$\mathrm{ECLOSE}(f_1)=\{f_1\}$，含 accepting state，accept。

### DFA 转成 regular expression：$R^{(k)}_{ij}$

反方向要证：每个 DFA 的 language 都能写成 regular expression。难处在于 DFA 里的 path 可以任意绕圈，没法直接“读出”一个 expression。办法是按“path 途经的 state 编号最大是多少”分层，从不允许途经任何 state 开始，一层一层放开。

把 state 编号为 $1,\dots,n$，start state 是 1。$R^{(k)}_{ij}$ 表示所有从 $i$ 到 $j$、中途只经过编号 $\le k$ 的 state（两端 $i$、$j$ 不算“中途”）的 path 上读到的 string。

**$k=0$**：中途不许经过任何 state，path 只能是一条 transition，或者在 $i=j$ 时什么都不走。所以 $R^{(0)}_{ij}$ 是所有满足 $\delta(i,a)=j$ 的 $a$ 之和；$i=j$ 时再加上 $\varepsilon$；一个都没有就是 $\varnothing$。

**从 $k$ 到 $k+1$**：看一条中途只经过 $\le k+1$ 的 path。如果它中途没经过 $k+1$，它已经在 $R^{(k)}_{ij}$ 里。如果经过了，在第一次和最后一次到达 $k+1$ 处把它切开：第一段从 $i$ 到 $k+1$，中途 $\le k$；中间若干段从 $k+1$ 回到 $k+1$，每段中途 $\le k$；最后一段从 $k+1$ 到 $j$，中途 $\le k$。所以

$$R^{(k+1)}_{ij}=R^{(k)}_{ij}+R^{(k)}_{i,k+1}\big(R^{(k)}_{k+1,k+1}\big)^*R^{(k)}_{k+1,j}$$

**答案**：$k=n$ 时不再有限制，$L(A)$ 等于所有 accepting state $j$ 的 $R^{(n)}_{1j}$ 之和。

::fig[cs3231-odd] 一个两 state 的 DFA：1 表示目前读到偶数个 1，2 表示奇数个，2 是 accepting state。彩色的 path 是 $R^{(1)}_{22}$ 中“经过 state 1”的那一部分：从 2 读 1 到 1，在 1 上读若干个 0，再读 1 回到 2。

对这个 DFA 算一遍。$k=0$：

$$R^{(0)}_{11}=\varepsilon+0,\quad R^{(0)}_{12}=1,\quad R^{(0)}_{21}=1,\quad R^{(0)}_{22}=\varepsilon+0$$

$k=1$，公式里的中间 state 是 1，要用 $(R^{(0)}_{11})^*=(\varepsilon+0)^*=0^*$：

$$\begin{aligned}
R^{(1)}_{12}&=R^{(0)}_{12}+R^{(0)}_{11}(R^{(0)}_{11})^*R^{(0)}_{12}=1+(\varepsilon+0)0^*1=0^*1\\
R^{(1)}_{22}&=R^{(0)}_{22}+R^{(0)}_{21}(R^{(0)}_{11})^*R^{(0)}_{12}=(\varepsilon+0)+10^*1
\end{aligned}$$

化简 $R^{(1)}_{12}$ 时用了 $(\varepsilon+0)0^*=0^*$（$0^*$ 前面多一个可有可无的 0，language 不变），再与 1 合并：$1$ 本身是 $0^*1$ 取零个 0 的情形。

$k=2$，accepting state 只有 2，答案是 $R^{(2)}_{12}$，中间 state 是 2：

$$R^{(2)}_{12}=R^{(1)}_{12}+R^{(1)}_{12}\big(R^{(1)}_{22}\big)^*R^{(1)}_{22}=R^{(1)}_{12}\big(R^{(1)}_{22}\big)^*=0^*1\,(0+10^*1)^*$$

第二个等号先提出公因子得 $R^{(1)}_{12}\big(\varepsilon+(R^{(1)}_{22})^*R^{(1)}_{22}\big)$，而对任何 $R$ 都有 $\varepsilon+R^*R=R^*$（重复零次，或者重复至少一次）；第三个等号是因为 star 里面的 $\varepsilon$ 可有可无，$(\varepsilon+0+10^*1)^*=(0+10^*1)^*$。

检验：expression 先读若干个 0 和第一个 1，之后每一块要么是一个 0，要么是“1，若干个 0，1”，每块带 0 个或 2 个 1，所以总的 1 的个数是奇数。111：第一部分取 1，剩下的 11 是一块 $10^*1$（取零个 0），accept。11：第一部分只能是 1，剩下的 1 凑不成任何一块，reject。

两个方向合起来就是 Kleene's theorem：regular expression、NFA、DFA 描述的是同一类 language。

:::from
Regular expression 的定义、precedence 和 Thompson 式构造（含“一个 accepting state、start 无入边、accepting 无出边”的 invariant）、$R^{(k)}_{ij}$ 的 recurrence 跟 Sanjay Jain 的[讲义](http://www.comp.nus.edu.sg/~sanjay/cs3231/dfa.pdf)；[MIT 18.404J 第 3 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/a77711ed3d212bf472f3485883a121e0_MIT18_404f20_lec3.pdf)用的是 GNFA 逐个删 state 的办法，本页没有采用，因为 NUS 的讲义用 $R^{(k)}_{ij}$。“按第一次和最后一次到达 $k+1$ 切开 path”的解释、$0^*1$ 的 ε-NFA 和 odd-number-of-1s 的完整计算是我写的，凭的是 HMU 第 3 章的做法（没有重新查书核对）。

## [nonreg] Nonregular language、pumping lemma 与 minimization

:::skip
能用 distinguishing set 或 pumping lemma 证明一个 language 不是 regular（处理所有 split，不自己挑），能用 table-filling 做 minimization，就可以去第 5 站。
:::

### DFA 唯一的限制是有限

回到开头第二个问题：为什么 $\{0^n1^n\mid n\ge0\}$ 没有 DFA？“DFA 不会数数”只是直觉，要变成 proof，得说清 DFA 在什么情况下被迫犯错。

两个 string $x$、$y$ 关于 $L$ distinguishable，是说存在某个 $z$，使 $xz$ 和 $yz$ 恰好一个在 $L$ 里。

**Lemma**：若 $x$、$y$ 关于 $L$ distinguishable，则任何识别 $L$ 的 DFA 读完 $x$ 和读完 $y$ 必然停在不同 state。

**Proof**：设 $\hat\delta(q_0,x)=\hat\delta(q_0,y)=q$。接着读 $z$，两边都从 $q$ 出发，所以 $\hat\delta(q_0,xz)=\hat\delta(q,z)=\hat\delta(q_0,yz)$，同一个 state，要么都 accept 要么都 reject，与 distinguishable 矛盾。（这里用了 $\hat\delta(q_0,xz)=\hat\delta(\hat\delta(q_0,x),z)$，对 $|z|$ 做 induction 即得。）

**Theorem**：若存在一个无限的 set $S$，其中任意两个不同的 string 都关于 $L$ distinguishable，则 $L$ 不是 regular。

**Proof**：设 DFA 有 $k$ 个 state。从 $S$ 里取 $k+1$ 个 string，由 pigeonhole 有两个停在同一个 state，与 lemma 矛盾。

用在 $\{0^n1^n\}$ 上：取 $S=\{0^n\mid n\ge0\}$。对 $m\neq n$，取 $z=1^m$，$0^m1^m\in L$，$0^n1^m\notin L$。所以 $S$ 中任两个都 distinguishable，$L$ 不是 regular。

同一个 lemma 还能给 DFA 的大小定下界。第 2 站的 $L_k$（倒数第 $k$ 个是 1）：取长度为 $k$ 的全部 $2^k$ 个 string。任取两个不同的 $x$、$y$，设它们第一次不同在从左数第 $i$ 位。接上 $z=0^{i-1}$ 之后长度是 $k+i-1$，倒数第 $k$ 位是从左数第 $(k+i-1)-k+1=i$ 位，也就是 $x_i$ 或 $y_i$，一个是 1 一个是 0，所以恰好一个在 $L_k$ 里。$2^k$ 个 string 两两 distinguishable，任何 DFA 至少 $2^k$ 个 state。$k=2$ 时下界是 4，第 2 站 subset construction 得到的恰好是 4 个，已经最小。

### Pumping lemma

NUS 和 MIT 都主要用另一个工具，它的证明同样是 pigeonhole，只是用在一个 string 的内部。

**Pumping lemma**：若 $L$ regular，则存在 $p\ge1$，使每个满足 $|s|\ge p$ 的 $s\in L$ 都能写成 $s=xyz$，满足

1. $|xy|\le p$；
2. $|y|\ge1$；
3. 对所有 $i\ge0$，$xy^iz\in L$。

**Proof**：取识别 $L$ 的 DFA，令 $p$ 为它的 state 数。设 $s=s_1s_2\cdots s_m\in L$，$m\ge p$。记 $r_t=\hat\delta(q_0,s_1\cdots s_t)$，$t=0,1,\dots,p$，这是 $p+1$ 个 state，DFA 只有 $p$ 个，所以存在 $0\le j<k\le p$ 使 $r_j=r_k$。令

$$x=s_1\cdots s_j,\qquad y=s_{j+1}\cdots s_k,\qquad z=s_{k+1}\cdots s_m$$

$|xy|=k\le p$，$|y|=k-j\ge1$。$y$ 从 $r_j$ 出发回到 $r_k=r_j$，即 $\hat\delta(r_j,y)=r_j$，对 $i$ 做 induction 得 $\hat\delta(r_j,y^i)=r_j$（$i=0$ 时是 $\hat\delta(r_j,\varepsilon)=r_j$；$\hat\delta(r_j,y^{i+1})=\hat\delta(\hat\delta(r_j,y^i),y)=\hat\delta(r_j,y)=r_j$）。所以

$$\hat\delta(q_0,xy^iz)=\hat\delta\big(\hat\delta(r_j,y^i),z\big)=\hat\delta(r_j,z)=\hat\delta(q_0,xyz)\in F$$

::fig[cs3231-pump] $p=7$ 时读 $0^71^7$。前 7 个 symbol 经过 8 个 state，必有重复，这里设 $r_2=r_5$。Path 形成一个套索：$x$ 是柄，$y$ 是圈，$z$ 是剩下的路。绕圈 0 次、1 次、2 次，终点都一样。

### 怎样用它证明 nonregular

Lemma 的 quantifier 顺序是：存在 $p$；对所有够长的 $s$；存在一种 split；对所有 $i$。要推出矛盾，就要对它取 negation：对每个 $p$，**你**挑一个 $s\in L$，$|s|\ge p$，使得**每一种**满足 1、2 的 split 都有某个 $i$ 让 $xy^iz\notin L$。$p$ 不是你选的，split 也不是你选的。

**例 1：$\{0^n1^n\}$。** 设它 regular，pumping length 为 $p$。取 $s=0^p1^p$，长度 $2p\ge p$。任一 split 有 $|xy|\le p$，而 $s$ 的前 $p$ 个 symbol 全是 0，所以 $y=0^\ell$，$\ell\ge1$。取 $i=2$：$xy^2z=0^{p+\ell}1^p$，0 比 1 多，不在 $L$ 里。矛盾。

**例 2：$\{ww\mid w\in\{0,1\}^*\}$。** 先看一个坏选择 $s=0^{2p}=0^p0^p$：split 可以取 $y=00$，pump 后 $0^{2p+2\ell'}$ 仍是 $0^{p+\ell'}0^{p+\ell'}$，推不出矛盾。坏选择不证明任何事。好的选择是 $s=0^p1\,0^p1$：$|xy|\le p$ 迫使 $y$ 落在第一段 0 里，$y=0^\ell$。$xy^2z=0^{p+\ell}10^p1$，长度 $2p+2+\ell$。如果 $\ell$ 是奇数，长度为奇数，不可能是 $ww$。如果 $\ell$ 是偶数（于是 $\ell\ge2$），假设它等于 $ww$，则 $|w|=p+1+\ell/2$。整个 string 以 1 结尾，所以 $w$ 以 1 结尾，前一半的最后一个 symbol（第 $p+1+\ell/2$ 位）应该是 1。但 1 只出现在第 $p+\ell+1$ 位和最后一位，而 $p+1+\ell/2\le p+\ell<p+\ell+1$，这一位是 0。所以不在 $L$ 里。矛盾。

**例 3：用 closure。** 设 $E$ 是 0 和 1 个数相等的 string。如果 $E$ regular，由第 1 站 $E\cap L(0^*1^*)$ 也 regular，而它恰好是 $\{0^n1^n\}$，矛盾。直接对 $E$ pump 也可以，但这样省掉了处理 split 的麻烦。

:::wrong 我选 y 是第一个 1，pump 之后 1 变多，所以 $0^n1^n$ 不是 regular
取 $p=3$，$s=000111$。这个 proof 选了 $x=000$，$y=1$，但 split 是 lemma 给的，不是你给的：lemma 只保证存在某一种 split 能 pump，它完全可以是 $x=0$，$y=00$，$z=0111$。你要证明的是每一种都失败。正因为 split 不受你控制，才要挑 $0^p1^p$ 这样的 $s$，靠 $|xy|\le p$ 把 $y$ 逼进全是 0 的那一段，让所有 split 都只剩一种情况。
:::

:::wrong 一个 language 满足 pumping lemma 的条件，它就是 regular
Pumping lemma 只是 necessary condition。看 $L=\{a^ib^jc^j\mid i\ge1,\,j\ge0\}\cup\{b^jc^k\mid j,k\ge0\}$：以 $a$ 开头时要求 $b$、$c$ 个数相等，不以 $a$ 开头时只要求形如 $b^*c^*$。

取 $p=1$，它满足 lemma 的结论。以 $a$ 开头的 $s=a^ib^jc^j$：取 $y$ 为第一个 $a$，$xy^tz=a^{i-1+t}b^jc^j$；$i-1+t\ge1$ 时仍以 $a$ 开头且 $b$、$c$ 相等，$i-1+t=0$ 时变成 $b^jc^j$，属于第二部分。不以 $a$ 开头的 $s$：取 $y$ 为第一个 symbol，pump 之后仍形如 $b^*c^*$。

但 $L$ 不是 regular：取 $S=\{ab^n\mid n\ge0\}$，对 $m\neq n$，$z=c^m$ 使 $ab^mc^m\in L$ 而 $ab^nc^m\notin L$（以 $a$ 开头但个数不等）。Distinguishing set 的方法没有这个漏洞：Myhill–Nerode theorem 说，$L$ regular 当且仅当没有无限的 distinguishing set，两个方向都成立。
:::

### Minimization：把分不开的 state 合并

上面的 lemma 反过来用：如果 DFA 里两个 state $p$、$q$ 对所有 $z$ 都有 $\hat\delta(p,z)\in F\iff\hat\delta(q,z)\in F$，它们对将来没有区别，可以合并。Table-filling algorithm 找出所有能区分的 pair：

1. 一个 accepting、一个不 accepting 的 pair，用 $z=\varepsilon$ 就区分了，先标记。
2. 反复检查未标记的 pair $\{p,q\}$：如果某个 symbol $a$ 使 $\{\delta(p,a),\delta(q,a)\}$ 已被标记，就标记 $\{p,q\}$（区分前者的 $z$ 前面加上 $a$ 就区分后者）。
3. 一轮下来没有新标记就停。没被标记的 pair 合并。

::fig[cs3231-minim] 一个 5 state 的 DFA，C 是唯一的 accepting state。浅色框圈出 table-filling 之后合并的三组。

Transition table：

| | 0 | 1 |
|---|---|---|
| →A | B | E |
| B | D | C |
| \*C | D | E |
| D | D | C |
| E | B | A |

第 1 步标记含 C 的 4 个 pair：AC、BC、CD、CE。第 2 步检查其余 6 个 pair：

| Pair | 读 0 到 | 读 1 到 | 结果 |
|---|---|---|---|
| AB | B, D | E, C | CE 已标记，标记 |
| AD | B, D | E, C | 标记 |
| AE | B, B | E, A | 两边都未标记 |
| BD | D, D | C, C | 两边都相同 |
| BE | D, B | C, A | AC 已标记，标记 |
| DE | D, B | C, A | 标记 |

再检查一轮：AE 读 0 到同一个 B，读 1 到 $\{E,A\}$，这正是它自己，未标记；BD 两个 symbol 都到同一个 state。没有新标记，停。合并成 $\{A,E\}$、$\{B,D\}$、$\{C\}$ 三个 state：$\{A,E\}$ 读 0 去 $\{B,D\}$、读 1 回自己；$\{B,D\}$ 读 0 回自己、读 1 去 C；C 读 0 去 $\{B,D\}$、读 1 去 $\{A,E\}$。这是“以 01 结尾”的 DFA：$\{B,D\}$ 表示刚读了 0，C 表示刚读了 01。

为什么 3 个已经最少：三个 state 分别由 $\varepsilon$、0、01 到达，两两 distinguishable（$\varepsilon$ 与 0 用 $z=1$ 区分，$\varepsilon$ 与 01、0 与 01 用 $z=\varepsilon$），由 lemma 任何 DFA 至少 3 个 state。

## [cfl] CFG、PDA 与 context-free language

:::skip
能写 CFG、画 parse tree、设计并追踪 PDA，能把 CFG 转成 PDA 和 CNF，能用 CFL pumping lemma 证明 $\{a^nb^nc^n\}$ 不是 context-free，就可以去第 6 站。
:::

### Grammar：用规则生成 string

$\{0^n1^n\}$ 不是 regular，但它有一个一眼就能看出的递归结构：要么是空的，要么是一个 0、一个更小的同类 string、一个 1。把这句话直接写成规则：

$$S\to0S1\mid\varepsilon$$

一个 context-free grammar（CFG）是 4-tuple $G=(V,T,P,S)$：$V$ 是 variable 的 set，$T$ 是 terminal 的 set，$P$ 是 production 的 set，每条形如 $A\to\alpha$，$A\in V$，$\alpha\in(V\cup T)^*$；$S$ 是 start variable。一步 derivation $\alpha A\beta\Rightarrow\alpha\gamma\beta$ 是把某个 variable 换成它的一条 production 的右边；$\Rightarrow^*$ 是零步或多步。$L(G)=\{w\in T^*\mid S\Rightarrow^*w\}$。这样的 language 叫 context-free language（CFL）。

用它生成 0011：

$$S\Rightarrow0S1\Rightarrow00S11\Rightarrow0011$$

最后一步用了 $S\to\varepsilon$。把每一步“谁被换成了什么”画成 tree，就是 parse tree：root 是 $S$，它的 children 是 $0,S,1$，中间的 $S$ 再展开成 $0,S,1$，最里面的 $S$ 展开成 $\varepsilon$。从左到右读 leaf，得到 0011。

### Ambiguity

Grammar 通常是给 compiler 读的，parse tree 决定了程序的意思。看算术表达式的 grammar

$$E\to E+E\mid E\times E\mid(E)\mid a$$

$a+a\times a$ 有两个 leftmost derivation：

$$\begin{aligned}
&E\Rightarrow E+E\Rightarrow a+E\Rightarrow a+E\times E\Rightarrow a+a\times E\Rightarrow a+a\times a\\
&E\Rightarrow E\times E\Rightarrow E+E\times E\Rightarrow a+E\times E\Rightarrow a+a\times E\Rightarrow a+a\times a
\end{aligned}$$

第一个先在 root 用 $+$，对应 $a+(a\times a)$；第二个先用 $\times$，对应 $(a+a)\times a$。取 $a=2$，两个值分别是 6 和 8。

::fig[cs3231-parse] 同一个 string 的两个 parse tree。左边 × 在下面，先算；右边 + 在下面，先算。

一个 grammar 有某个 string 存在两个不同的 parse tree，就叫 ambiguous。修法是把 precedence 写进 grammar，每一层 variable 只负责一种 operator：

$$E\to E+T\mid T,\qquad T\to T\times F\mid F,\qquad F\to(E)\mid a$$

$+$ 只能出现在 $E$ 这一层，$\times$ 只在 $T$ 这一层，$T$ 生成的东西里不会有不带括号的 $+$，所以 $a+a\times a$ 只能在 root 拆成 $E+T$，$T$ 再拆成 $T\times F$，只有一个 parse tree。两个 grammar 生成同一个 language，ambiguity 是 grammar 的性质。

### PDA：NFA 加一个 stack

DFA 无法识别 $\{0^n1^n\}$，是因为它要记住的 $n$ 没有上界。给 machine 加一个可以无限增长、但只能从顶部存取的 stack：读 0 时 push，读 1 时 pop，最后 stack 空了就说明个数相等。

HMU 的定义：pushdown automaton（PDA）是 7-tuple $(Q,\Sigma,\Gamma,\delta,q_0,Z_0,F)$。$\Gamma$ 是 stack alphabet，$Z_0\in\Gamma$ 是一开始就在 stack 里的 bottom marker。$\delta(q,a,X)$ 是一个 set，元素形如 $(p,\gamma)$：在 state $q$、读 input symbol $a$（或者 $a=\varepsilon$，不读）、stack 顶是 $X$ 时，可以去 state $p$，并把 $X$ 换成 string $\gamma$（$\gamma$ 的第一个 symbol 成为新的顶；$\gamma=\varepsilon$ 就是 pop）。PDA 的格局写成 instantaneous description（ID）$(q,w,\gamma)$：当前 state、剩下的 input、stack 内容（顶在左）。

$\{0^n1^n\mid n\ge0\}$ 的 PDA，$F=\{q_2\}$：

| Transition | 作用 |
|---|---|
| $\delta(q_0,0,Z_0)=\{(q_0,0Z_0)\}$，$\delta(q_0,0,0)=\{(q_0,00)\}$ | 读 0，push 0 |
| $\delta(q_0,1,0)=\{(q_1,\varepsilon)\}$，$\delta(q_1,1,0)=\{(q_1,\varepsilon)\}$ | 读 1，pop 一个 0 |
| $\delta(q_0,\varepsilon,Z_0)=\{(q_2,Z_0)\}$，$\delta(q_1,\varepsilon,Z_0)=\{(q_2,Z_0)\}$ | 看到 bottom marker，去 accepting state |

::fig[cs3231-pda] 这个 PDA 读 0011。左边是 input 和读头，右边是 stack（顶在上）。两个 0 依次 push，两个 1 依次 pop，露出 $Z_0$ 时走 ε-transition 进入 $q_2$。

ID 序列：

$$(q_0,0011,Z_0)\vdash(q_0,011,0Z_0)\vdash(q_0,11,00Z_0)\vdash(q_1,1,0Z_0)\vdash(q_1,\varepsilon,Z_0)\vdash(q_2,\varepsilon,Z_0)$$

Input 读完且到了 accepting state，accept。换成 0010：读完 001 后是 $(q_1,0,0Z_0)$，$q_1$ 读 0 没有 transition，这条路卡住，又没有别的路，reject。

HMU 还定义了 acceptance by empty stack（读完 input 时 stack 为空就 accept）。两种 acceptance 能识别的 language 相同：从 final state 改成 empty stack，只要在 accepting state 加 ε-transition 把 stack 清空；反过来，在最底下垫一个新的 bottom marker，看到它露出来就说明原来的 stack 空了，转去 accepting state。

**Nondeterminism 在这里是必需的。** 看 $\{ww^R\}$（偶数长度的 palindrome）。PDA 在 $q_0$ 读一个 push 一个；任何时刻都可以走 $\delta(q_0,\varepsilon,X)\ni(q_1,X)$，猜“到中点了”，之后在 $q_1$ 读一个 pop 一个并比较。在 0110 上，猜中点的位置有 5 种：

| 猜在读完几个 symbol 后 | 结果 |
|---|---|
| 0 | stack 只有 $Z_0$，去 $q_2$，但 input 没读完，这条路不 accept |
| 1 | stack 顶 0，下一个 input 是 1，不匹配，卡住 |
| 2 | stack 顶 1、0，依次和 1、0 匹配，露出 $Z_0$，accept |
| 3 | stack 顶 1，下一个 input 是 0，不匹配 |
| 4 | input 已读完，stack 不空，到不了 $q_2$ |

只有一条路 accept，就够了。Deterministic PDA 识别的 language 严格少于 PDA，$\{ww^R\}$ 就是例子（这个结论本页不证）。

### CFG 转成 PDA

PDA 能识别所有 CFL，构造本身就是一台“边猜边验证 leftmost derivation”的机器。只用一个 state $q$，acceptance by empty stack，stack 里放 leftmost derivation 中还没匹配的部分：

- 对每条 production $A\to\alpha$：$\delta(q,\varepsilon,A)\ni(q,\alpha)$。stack 顶是 variable，就猜一条 production 展开它。
- 对每个 terminal $a$：$\delta(q,a,a)=\{(q,\varepsilon)\}$。stack 顶是 terminal，就和 input 对一下，对上了 pop。

Stack 一开始是 $S$。为什么只展开 stack 顶：PDA 只看得到顶，而 leftmost derivation 每次展开的恰好是最左边的 variable；它左边的 terminal 已经和 input 对过、pop 掉了，于是它正好在顶上。

用 $S\to0S1\mid\varepsilon$ 读 0011：

| 剩余 input | Stack（顶在左） | 动作 |
|---|---|---|
| 0011 | $S$ | 展开 $S\to0S1$ |
| 0011 | $0S1$ | 匹配 0 |
| 011 | $S1$ | 展开 $S\to0S1$ |
| 011 | $0S11$ | 匹配 0 |
| 11 | $S11$ | 展开 $S\to\varepsilon$ |
| 11 | $11$ | 匹配 1 |
| 1 | $1$ | 匹配 1 |
| $\varepsilon$ | 空 | accept |

反方向（PDA 转成 CFG）也成立，HMU 的构造为每个 state pair $p,q$ 和 stack symbol $X$ 造一个 variable $[pXq]$，它生成的恰好是让 PDA 从 $p$ 出发、把 $X$ 净 pop 掉并停在 $q$ 的 input string。所以 CFG 和 PDA 描述同一类 language。

### Chomsky normal form 与 CFL 的 pumping lemma

$\{a^nb^nc^n\}$ 看起来只比 $\{0^n1^n\}$ 多一段，但一个 stack 用完 $a$ 的计数去对 $b$ 之后，就没有东西可以再对 $c$ 了。证明它不是 CFL，需要 CFL 版本的 pumping lemma。它的证明要看 parse tree 有多高，先把 grammar 化成统一的形状更方便。

**Chomsky normal form（CNF）**：每条 production 是 $A\to BC$（两个 variable）或 $A\to a$（一个 terminal）。不含 $\varepsilon$ 的 CFL 都有 CNF 的 grammar。HMU 的转换顺序是：去掉 $\varepsilon$-production，去掉 unit production（$A\to B$），去掉 useless symbol，再把长的右边拆开。拿 $\{0^n1^n\mid n\ge1\}$ 走一遍：

- $S\to0S1\mid\varepsilon$ 生成的 language 含 $\varepsilon$。去掉 $\varepsilon$-production：$S$ 是 nullable，把每条右边里的 $S$ 换成“有或没有”两种，得 $S\to0S1\mid01$，生成的是 $n\ge1$ 的部分。
- 没有 unit production，也没有 useless symbol。
- Terminal 出现在长度 $\ge2$ 的右边时，换成新 variable：$A\to0$，$B\to1$，得 $S\to ASB\mid AB$。
- 右边长度 3 的拆成两段：$S\to AT$，$T\to SB$。

结果 $S\to AT\mid AB$，$T\to SB$，$A\to0$，$B\to1$。检验 0011：$S\Rightarrow AT\Rightarrow 0T\Rightarrow0SB\Rightarrow0ABB\Rightarrow00BB\Rightarrow0011$。

CNF 的 parse tree 每个内部 node 最多两个 child，所以高度（root 到 leaf 最长 path 上的 edge 数）为 $h$ 的 tree，yield 长度不超过 $2^{h-1}$（最后一层是 $A\to a$，不分叉）。

**CFL pumping lemma**：若 $L$ 是 CFL，存在 $p$，使每个 $|s|\ge p$ 的 $s\in L$ 能写成 $s=uvxyz$，满足 $|vxy|\le p$，$|vy|\ge1$，并且对所有 $i\ge0$，$uv^ixy^iz\in L$。

**Proof**：设 CNF grammar 有 $m$ 个 variable，取 $p=2^m$。$|s|\ge2^m>2^{m-1}$，所以 parse tree 高度至少 $m+1$，最长的 path 上有至少 $m+2$ 个 node，除最后的 leaf 外都是 variable，至少 $m+1$ 个。只看这条 path 最下面的 $m+1$ 个 variable，由 pigeonhole 有一个 variable $R$ 出现两次。上面那个 $R$ 生成 $vxy$，下面那个生成 $x$。

- 把上面的 $R$ 的 subtree 换成下面那个，得到 $uxz$（$i=0$）；把下面的换成上面那个的 copy，得到 $uv^2xy^2z$，重复下去得所有 $i$。
- 上面那个 $R$ 在 path 最下面 $m+1$ 个 variable 之内，以它为 root 的 subtree 高度不超过 $m+1$，yield $|vxy|\le2^m=p$。
- 上面的 $R$ 用的是 $R\to BC$，下面的 $R$ 只在其中一边，另一边的 variable 至少生成一个 terminal，所以 $v$、$y$ 不会都空。

::fig[cs3231-cflpump] 左边：parse tree 里同一条 path 上出现两次 $R$，yield 被切成 $u,v,x,y,z$。右边：把下面的 $R$ 换成上面那棵 subtree 的 copy，$v$ 和 $y$ 各多出一份。

**例：$\{a^nb^nc^n\}$ 不是 CFL。** 设 pumping length 为 $p$，取 $s=a^pb^pc^p$。任一 split 中 $|vxy|\le p$，而 $a$ 段和 $c$ 段之间隔着 $p$ 个 $b$，所以 $vxy$ 不可能同时含 $a$ 和 $c$。

- $vxy$ 不含 $c$：取 $i=2$，$a$ 和 $b$ 的总数增加了 $|vy|\ge1$，$c$ 还是 $p$ 个，三种个数不再相等；而且若 $v$ 或 $y$ 同时含两种 symbol，pump 后顺序都会乱。不在 $L$ 里。
- $vxy$ 不含 $a$：同理，$b$ 和 $c$ 增加，$a$ 还是 $p$ 个。

每种 split 都失败，矛盾。

### Closure

CFL 对 union、concatenation、star closed，直接写 grammar：设 $G_1$、$G_2$ 的 start variable 是 $S_1$、$S_2$（variable 先改名使两边不重名），新 start $S$ 分别加 $S\to S_1\mid S_2$、$S\to S_1S_2$、$S\to S_1S\mid\varepsilon$。

CFL 与 regular language 的 intersection 仍是 CFL：PDA 在 finite control 里同时跑那台 DFA，和第 1 站的 product construction 一样，stack 只归 PDA 用。

:::wrong CFL 和 regular language 一样，对 intersection 也 closed
$L_1=\{a^nb^nc^m\mid n,m\ge0\}$ 是 CFL：$S\to XC$，$X\to aXb\mid\varepsilon$，$C\to cC\mid\varepsilon$。同理 $L_2=\{a^mb^nc^n\}$ 是 CFL。$L_1\cap L_2=\{a^nb^nc^n\}$，刚证明了它不是 CFL。Product construction 在这里失效，是因为两台 PDA 各要一个 stack，合起来需要两个 stack，而一台 PDA 只有一个。由 De Morgan，$L_1\cap L_2=\overline{\overline{L_1}\cup\overline{L_2}}$，union closed 而 intersection 不 closed，所以 complement 也不 closed。
:::

:::back
CFL pumping lemma 的证明结构与[第 4 站](#nonreg)完全相同：有限个 variable 对应有限个 state，path 上 variable 重复对应 state 重复。CFL 与 regular 的 intersection 用的是[第 1 站](#dfa)的 product construction。
:::

## [tm] Turing machine

:::skip
能追踪一个 TM 的 ID 序列，说出 recognize 和 decide 的区别，知道 multi-tape 和 nondeterministic TM 怎样被 simulate，就可以去第 7 站。
:::

### 一条能写的 tape

$\{a^nb^nc^n\}$ 不是 CFL，但写个 program 检查它毫无困难：数一数三段各多长。PDA 不行，是因为 stack 只能从顶上读，读过就丢。把 memory 换成一条可以来回移动、随处读写的 tape，就得到 Turing machine（TM）。

HMU 的定义：TM 是 7-tuple $M=(Q,\Sigma,\Gamma,\delta,q_0,B,F)$。$\Gamma\supseteq\Sigma$ 是 tape alphabet，$B\in\Gamma\setminus\Sigma$ 是 blank。Input 写在 tape 上，两边全是 $B$，head 在 input 的第一个 symbol 上。$\delta(q,X)=(p,Y,D)$：在 state $q$、head 下是 $X$ 时，把 $X$ 改写成 $Y$，head 向 $D\in\{L,R\}$ 移一格，进入 $p$。$\delta$ 可以没有定义，这时 machine halt。进入 $F$ 中的 state 就 accept 并 halt。

格局写成 ID $\alpha\,q\,\beta$：$q$ 是当前 state，tape 上非 blank 的部分是 $\alpha\beta$，head 在 $\beta$ 的第一个 symbol 上。

### 一台 TM 的完整运行

用标记来回配对：识别 $\{0^n1^n\mid n\ge1\}$。每轮把最左边一个未配对的 0 改成 $X$，向右找到第一个未配对的 1 改成 $Y$，再回到左边。0 用完时检查后面没有剩下的 1。

| | 0 | 1 | X | Y | B |
|---|---|---|---|---|---|
| $q_0$ | $(q_1,X,R)$ | | | $(q_3,Y,R)$ | |
| $q_1$ | $(q_1,0,R)$ | $(q_2,Y,L)$ | | $(q_1,Y,R)$ | |
| $q_2$ | $(q_2,0,L)$ | | $(q_0,X,R)$ | $(q_2,Y,L)$ | |
| $q_3$ | | | | $(q_3,Y,R)$ | $(q_4,B,R)$ |
| $q_4$ | | | | | |

各 state 的意思：$q_0$ 准备标下一个 0；$q_1$ 向右越过 0 和 $Y$ 找 1；$q_2$ 向左越过 $Y$ 和 0 回到最右边的 $X$；$q_3$ 0 已用完，向右确认只剩 $Y$；$q_4\in F$。

::fig[cs3231-tm] 这台 TM 读 0011，一共 13 步。每一帧是一个 ID：tape 内容、head 的位置、当前 state，下方的表里亮起的是这一步要用的 transition。

完整的 ID 序列：

$$\begin{aligned}
&q_00011\vdash Xq_1011\vdash X0q_111\vdash Xq_20Y1\vdash q_2X0Y1\vdash Xq_00Y1\vdash XXq_1Y1\\
&\vdash XXYq_11\vdash XXq_2YY\vdash Xq_2XYY\vdash XXq_0YY\vdash XXYq_3Y\vdash XXYYq_3B\vdash XXYYBq_4
\end{aligned}$$

0010 在第 8 步走到 $XXY0q_1B$：$q_1$ 读到 $B$ 没有定义，halt，不在 $F$ 里，reject。$\{0^n1^n\}$ 已经是 CFL，这台 TM 只是练手；同样的“标记再回来”的手法加一种标记就能识别 $\{a^nb^nc^n\}$。

### Recognize 与 decide

TM 在一个 input 上有三种结局：accept、halt 但不 accept、永远不停。第三种是 DFA 和 PDA 没有的（PDA 的 ε-transition 也能造出无限循环，但总可以改掉；TM 不行，第 7 站证明）。例如一台 TM 在 $q_0$ 读到 $B$ 时 $\delta(q_0,B)=(q_0,B,R)$，它在 empty input 上会一直向右走。

于是有两种“识别”：

- $L$ 是 **recursively enumerable**（Sipser 叫 Turing-recognizable）：存在 TM $M$，$L(M)=L$。$M$ 在 $L$ 外的 input 上可以 reject，也可以永远不停。
- $L$ 是 **recursive**（decidable）：存在一台在所有 input 上都 halt 的 TM 识别它。

站在外面看一台还在运行的 TM，你无法分辨它是快要 accept 了还是会永远跑下去。这个区别是第 7 站的核心。

### 更强的 TM 并不更强

**Multi-tape TM**：$k$ 条 tape，各有一个 head，一步同时读 $k$ 个 symbol、各写各移。Single-tape TM 可以 simulate 它：把一条 tape 分成 $2k$ 个 track，每两个 track 记一条 tape 的内容和那条 tape 的 head 位置的标记。Simulate 一步时，从左到右扫一遍收集 $k$ 个标记下的 symbol（记在 finite control 里），再扫一遍按 $\delta$ 改写并移动标记。若 multi-tape TM 跑了 $t$ 步，tape 上的内容最多扩展到 $t$ 格，每步扫两遍是 $O(t)$，共 $O(t^2)$ 步。能识别的 language 不变，只是时间变成平方，第 8 站会用到这个数。

**Nondeterministic TM**：$\delta(q,X)$ 是一组可能的 move，有一条路 accept 就算 accept。Deterministic TM 可以 simulate 它：所有可能的运行构成一棵 tree，每个 node 是一个 ID。按 breadth-first 的顺序逐层展开（用 multi-tape TM 维护一个 ID 的 queue），遇到 accepting ID 就 accept。必须用 breadth-first：depth-first 可能沉进一条永远不停的分支，错过别的分支上近在眼前的 accept。若最短的 accepting 分支长 $m$、每个 ID 最多 $b$ 种 move，最多展开 $1+b+\dots+b^m$ 个 ID，有限，所以一定能找到。

:::wrong 加上 nondeterminism 或者多几条 tape，TM 能 decide 的 language 就更多
上面两个 simulation 说明不会：deterministic single-tape TM 能做到一样的事。变化的只是时间。nondeterministic 的 simulation 用了 $b^m$ 量级的步数，指数级变慢；这个代价能不能省掉，正是第 8 站的 P vs NP。对 NFA 和 DFA 也是同一个故事：能力相同（第 2 站），大小可能差 $2^n$。PDA 是例外，nondeterministic PDA 严格强于 deterministic PDA（第 5 站的 $ww^R$）。
:::

### Church–Turing thesis 与 universal TM

各种看起来更强的 model（multi-tape、nondeterministic、RAM、各种 programming language）最后都被证明和 TM 能力相同。Church–Turing thesis 说：直观意义上“有一个 algorithm 能算”的东西，恰好就是 TM 能算的东西。它不是 theorem，因为“直观意义上的 algorithm”没有数学定义；它是在说，TM 是这个直观概念的正确的数学定义。从此“存在 TM”和“存在 algorithm”可以互换，下一站证明“没有 TM 能做”时，结论就是“没有任何 algorithm 能做”。

TM 本身是有限的对象（有限的 state、有限的 table），可以编码成一个 string，记作 $\langle M\rangle$；TM 和 input 一起编码成 $\langle M,w\rangle$。存在一台 universal TM $U$：在 input $\langle M,w\rangle$ 上，它按 $M$ 的 table 一步步 simulate $M$ 在 $w$ 上的运行，$M$ accept 它就 accept。这就是“一台能运行任何 program 的计算机”的数学版本，下一站的 undecidability 都从“TM 能把别的 TM 当作 input”开始。

:::from
“TM 有 tape、head、可以在任何时候 accept 或 reject”的 model、用划掉标记识别 $\{a^kb^kc^k\}$ 的思路、recognizer 和 decider 的定义来自 [MIT 18.404J 第 5 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/18c8cd00b14d48dc5865f3bdc41abd76_MIT18_404f20_lec5.pdf)；multi-tape 的 $t^2$ simulation 来自[第 12 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/7278be637b3ba371d16c9dd574705e23_MIT18_404f20_lec12.pdf)。7-tuple、ID 记号和 $\{0^n1^n\}$ 的 TM table 凭的是我对 HMU 8.2 节的记忆（我没有读 Sanjay Jain 的 TM 讲义，NUS 的记号若有差别以讲义为准）；ID 序列和步数是用程序 simulate 出来的。Nondeterministic TM 的 breadth-first simulation、Church–Turing thesis 和 universal TM 的写法凭自己的知识。MIT 第 6 讲（TM variants）我没有读。
:::

## [undec] Decidability、halting problem 与 reduction

:::skip
能复述 $A_{TM}$ 的 diagonalization，能用 reduction 证明一个关于 TM 的问题 undecidable 并写对方向，能说出 Rice's theorem 的条件，就可以去第 8 站。
:::

### 关于 automaton 的问题都能 decide

先看能 decide 的问题，它们说明“问题的 input 是一台 machine”并不可怕。

- $A_{DFA}=\{\langle D,w\rangle\mid D\text{ accept }w\}$：simulate $D$ 在 $w$ 上走 $|w|$ 步，一定停。
- $E_{DFA}=\{\langle D\rangle\mid L(D)=\varnothing\}$：从 start state 做 graph search（[CS2040 的 BFS](../courses/CS2040.html#graph)），看能不能到达某个 accepting state。
- $EQ_{DFA}=\{\langle D_1,D_2\rangle\mid L(D_1)=L(D_2)\}$：用第 1 站的 product construction 造出 symmetric difference $(L_1\cap\overline{L_2})\cup(\overline{L_1}\cap L_2)$ 的 DFA，两个 language 相等当且仅当它为空，再用 $E_{DFA}$。
- $A_{CFG}$：先化成 CNF。CNF 中生成长度 $n\ge1$ 的 string 恰好需要 $2n-1$ 步 derivation（$n-1$ 次 $A\to BC$ 把一个 variable 变成 $n$ 个，再 $n$ 次 $A\to a$），所以只要枚举所有 $2n-1$ 步的 derivation，有限多个。

这些 algorithm 都能停，是因为 DFA 和 CFG 的运行有一个事先算得出的上界。TM 没有。

### 数一数：TM 不够用

每台 TM 编码成一个有限 string，所以全体 TM 可以按编码的长度和字典序排成一列 $M_1,M_2,\dots$：TM 是 countable 的。

全体 language 却不是。把所有 string 也排成一列 $w_1,w_2,\dots$，假设所有 language 能排成一列 $L_1,L_2,\dots$，造 $L^*=\{w_i\mid w_i\notin L_i\}$。$L^*$ 和每个 $L_i$ 在 $w_i$ 上不一致，所以不在列表里，矛盾。

TM 只有 countable 多个，language 有 uncountable 多个，所以一定存在没有 TM 能识别的 language。这只说明“存在”，下面要找一个具体的、而且有意义的。

### $A_{TM}$ undecidable

$A_{TM}=\{\langle M,w\rangle\mid M\text{ 是 TM，且 }M\text{ accept }w\}$。

它是 recognizable 的：universal TM $U$ 就是它的 recognizer。$M$ accept $w$ 时 $U$ accept；$M$ 不停时 $U$ 也不停，这是允许的。

**Theorem**：$A_{TM}$ 不是 decidable。

**Proof**：假设有 decider $H$：$H(\langle M,w\rangle)$ 在 $M$ accept $w$ 时 accept，否则 reject，总会停。用 $H$ 造 TM $D$：

> $D$ 在 input $\langle M\rangle$ 上：运行 $H$ 于 $\langle M,\langle M\rangle\rangle$；$H$ accept 就 reject，$H$ reject 就 accept。

$H$ 总会停，所以 $D$ 总会停，而且 $D$ accept $\langle M\rangle$ 当且仅当 $M$ 不 accept $\langle M\rangle$。把 $D$ 自己的编码喂给它：

$$D\text{ accept }\langle D\rangle\iff D\text{ 不 accept }\langle D\rangle$$

矛盾。所以 $H$ 不存在。

::fig[cs3231-diag] 把所有 TM 和它们的编码排成一张表，第 $i$ 行第 $j$ 列写 $M_i$ 是否 accept $\langle M_j\rangle$。$D$ 的那一行把对角线逐格取反，所以它和每一行都至少差一格；$D$ 若在表里，它与自己那一行在对角线那一格上必须既相同又相反。

这正是上一小节的 diagonal argument，表里的数据是示意，实际的表是无限的。

### Recognizable、co-recognizable 与 decidable

$L$ 的 complement $\overline L$ 是 recognizable，就说 $L$ 是 co-recognizable。

**Theorem**：$L$ decidable 当且仅当 $L$ 既 recognizable 又 co-recognizable。

**Proof**：若 $L$ 被 decider $M$ 识别，$M$ 本身就是 recognizer；把 accept 和 reject 对调（$M$ 总会停，所以对调有效），就得到 $\overline L$ 的 decider。反过来，设 $M_1$ 识别 $L$，$M_2$ 识别 $\overline L$。造 $M$：在两条 tape 上交替地让 $M_1$、$M_2$ 各走一步。任一 input $w$ 要么在 $L$ 里（$M_1$ 迟早 accept），要么在 $\overline L$ 里（$M_2$ 迟早 accept），所以总有一个会停下来 accept；$M_1$ accept 则 $M$ accept，$M_2$ accept 则 $M$ reject。$M$ 总会停，是 $L$ 的 decider。必须交替，不能先跑完 $M_1$ 再跑 $M_2$，因为 $M_1$ 可能永远不停。

**Corollary**：$\overline{A_{TM}}$ 不是 recognizable。否则 $A_{TM}$ 既 recognizable 又 co-recognizable，就 decidable 了。

### Reduction

有了一个 undecidable 的问题，其他问题不必每次都重新 diagonalize，只要说明“能解决它就能解决 $A_{TM}$”。

**$HALT_{TM}=\{\langle M,w\rangle\mid M\text{ 在 }w\text{ 上会停}\}$ undecidable。** 假设它有 decider $R$。造 $A_{TM}$ 的 decider $S$：在 $\langle M,w\rangle$ 上先运行 $R$；$R$ 说不停，就 reject（不停当然不 accept）；$R$ 说会停，就用 $U$ simulate $M$ 在 $w$ 上的运行，这次一定会停，照它的结果 accept 或 reject。$S$ 总会停，decide 了 $A_{TM}$，矛盾。

**$E_{TM}=\{\langle M\rangle\mid L(M)=\varnothing\}$ undecidable。** 假设它有 decider $R$。给定 $\langle M,w\rangle$，先造一台新的 TM $M_w$：

> $M_w$ 在 input $x$ 上：若 $x\neq w$，reject；若 $x=w$，运行 $M$ 于 $w$，$M$ accept 就 accept。

$M_w$ 只可能 accept $w$ 一个 string，而且只在 $M$ accept $w$ 时 accept，所以 $L(M_w)=\varnothing\iff M$ 不 accept $w$。$A_{TM}$ 的 decider：造出 $\langle M_w\rangle$（只是改写 table，一定能停，并不运行 $M$），运行 $R$，$R$ 说空就 reject，说不空就 accept。矛盾。

**Mapping reduction**：$A\le_m B$ 指存在 computable function $f$（某台总会停的 TM 把 $w$ 变成 $f(w)$），使

$$w\in A\iff f(w)\in B$$

若 $B$ decidable，先算 $f(w)$ 再问 $B$ 的 decider，就 decide 了 $A$。所以：$A\le_m B$ 且 $A$ undecidable $\Rightarrow$ $B$ undecidable。对 recognizable 同理：$A\le_m B$ 且 $A$ 不是 recognizable $\Rightarrow$ $B$ 不是 recognizable。上面 $E_{TM}$ 的构造正是 $f(\langle M,w\rangle)=\langle M_w\rangle$，它满足 $\langle M,w\rangle\in\overline{A_{TM}}\iff\langle M_w\rangle\in E_{TM}$，即 $\overline{A_{TM}}\le_mE_{TM}$。因为 $\overline{A_{TM}}$ 不是 recognizable，$E_{TM}$ 也不是 recognizable。

:::wrong 要证 $B$ undecidable，就把 $B$ reduce 到 $A_{TM}$
$B\le_m A_{TM}$ 说的是“$B$ 不比 $A_{TM}$ 难”，任何 recognizable 的 $B$ 都满足，包括 decidable 的。例如 $E_{DFA}\le_mA_{TM}$：把 $\langle D\rangle$ 变成 $\langle M,\varepsilon\rangle$，$M$ 是一台先 decide $E_{DFA}$、空就 accept 的 TM。这个 reduction 完全合法，而 $E_{DFA}$ 是 decidable 的，所以这个方向什么也证明不了。方向必须是 $A_{TM}\le_mB$（或 $\overline{A_{TM}}\le_m B$）：已知难的放左边，要证难的放右边，因为 reduction 把左边的难度传到右边。
:::

### Rice's theorem

$E_{TM}$ 的证明里，真正用到的只是“$L(M_w)$ 要么是 $\varnothing$，要么是 $\{w\}$，取决于 $M$ 是否 accept $w$”。这可以推广到关于 $L(M)$ 的任何问题。

**Rice's theorem**：设 $P$ 是 recursively enumerable language 的一个性质，只看 language 不看 machine（$L(M_1)=L(M_2)$ 时 $\langle M_1\rangle$、$\langle M_2\rangle$ 要么都有 $P$ 要么都没有），而且 nontrivial（有的 TM 的 language 有 $P$，有的没有）。则 $\{\langle M\rangle\mid L(M)\text{ 有 }P\}$ undecidable。

**Proof**：不妨设 $\varnothing$ 没有 $P$（否则对 $P$ 的否定做同样论证，decidable 对 complement closed）。由 nontrivial，取一台 $M_P$，$L(M_P)$ 有 $P$。给定 $\langle M,w\rangle$，造 $M'$：

> $M'$ 在 input $x$ 上：先运行 $M$ 于 $w$；若 $M$ accept，再运行 $M_P$ 于 $x$，照它的结果。

$M$ accept $w$ 时 $L(M')=L(M_P)$，有 $P$；否则 $M'$ 什么都不 accept，$L(M')=\varnothing$，没有 $P$。所以 $\langle M,w\rangle\mapsto\langle M'\rangle$ 是 $A_{TM}\le_m\{\langle M\rangle\mid L(M)\text{ 有 }P\}$。

用它：“$L(M)$ 是 regular”“$L(M)$ 含 0110”“$L(M)$ 有限”都是 nontrivial 的 language 性质，全部 undecidable。“$M$ 有超过 5 个 state”不是 language 的性质（同一 language 可以有大小不同的 TM），Rice 管不到，它显然 decidable。

:::edge Rice's theorem 只说 undecidable
“$L(M)\neq\varnothing$”由 Rice 是 undecidable，但它是 recognizable 的：用 dovetailing，第 $k$ 轮对前 $k$ 个 string 各 simulate $M$ $k$ 步，任何一个 accept 就 accept。$E_{TM}$ 本身则连 recognizable 都不是（上面的 mapping reduction）。Rice 不区分这两种情况。
:::

:::from
$A_{TM}$ 的 diagonalization（$H$、$D$、那张表）、TM countable 而 language uncountable、“recognizable 且 co-recognizable 则 decidable”、由 $A_{TM}$ 推 $HALT_{TM}$ 来自 [MIT 18.404J 第 8 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/3ab8452b4b29eb28a1416e4a1575323c_MIT18_404f20_lec8.pdf)；$HALT_{TM}$ 的完整 reduction、$E_{TM}$ 的 $M_w$、mapping reduction 的定义和方向、$\overline{A_{TM}}\le_mE_{TM}$ 来自[第 9 讲](https://ocw.mit.edu/courses/18-404j-theory-of-computation-fall-2020/dae35894f6f5d5d09bb9fc225c664fff_MIT18_404f20_lec9.pdf)。Self-reference 的讲法（问 decider 关于自己的问题，然后反着做）参考了 [Stanford CS103 Unsolvable Problems](https://web.stanford.edu/class/archive/cs/cs103/cs103.1198/lectures/19-Unsolvable/Unsolvable%20Problems.pdf)。$A_{DFA}$ 等 decidable 问题对应 MIT 第 7 讲，那一讲我没有读，按自己的知识写。Rice's theorem 的陈述和证明、$E_{DFA}\le_mA_{TM}$ 的反例、dovetailing 的 edge case 凭自己的知识写；Sanjay Jain 的课程主页把 Rice's theorem 列在大纲里但没有讲义链接。

## [cx] Time complexity、P 与 NP

:::skip
能数一个 TM 的 running time，说出 P 与 NP 的定义、给一个问题写 verifier、写对 polynomial-time reduction 的方向，就可以结束。Cook–Levin 那一小节只看结构的话可以跳过证明细节。
:::

### 同一个 language，三种速度

可 decide 的问题也可能慢得没法用。先在 TM 上把“多快”说准：TM $M$ 的 running time 是 $t(n)$，指它在每个长度为 $n$ 的 input 上至多 $t(n)$ 步就停。

拿 $\{a^kb^k\}$ 比较三台 decider（input 长度 $n=2k$）：

1. **来回划掉，single tape。** 先扫一遍检查形如 $a^*b^*$，$O(n)$。然后每一轮从左扫到右，划掉一个 $a$ 和一个 $b$，再回到左端，每轮 $O(n)$，最多 $k=n/2$ 轮。共 $O(n)+\tfrac n2\cdot O(n)=O(n^2)$。上一站的 TM 就是这一种。
2. **每轮划掉一半，single tape。** 每一轮先数剩下的 $a$ 和 $b$ 的个数的奇偶（扫一遍，finite control 记住两个 parity bit），奇偶不同就 reject；然后从第一个开始，隔一个划掉一个 $a$，$b$ 也一样。剩 $m$ 个时划掉 $\lceil m/2\rceil$ 个，剩下 $\lfloor m/2\rfloor$ 个，所以 $O(\log n)$ 轮之后全部划完。每轮扫两遍 $O(n)$，共 $O(n\log n)$。
3. **两条 tape。** 把 $a$ 复制到第二条 tape，再让两个 head 同时前进，一个走 $b$、一个走 $a$ 的 copy，同时走完则 accept。$O(n)$。

第 2 种为什么对：每轮读到的 parity 恰好是剩余个数的 binary representation 的最低位，划掉一半相当于右移一位。逐轮比较 parity 就是逐位比较 $a$ 的个数和 $b$ 的个数的 binary representation。

::fig[cs3231-cross] 第 2 台 machine 在 $a^6b^6$ 上的各轮。每轮剩下的个数 6、3、1 的 parity 依次是 0、1、1，正是 6 的 binary 110 从低位读起。

所以“多快”依赖 model：single-tape 是 $O(n\log n)$（可以证明 single-tape 不能更快，本页不证），two-tape 是 $O(n)$。但依赖得很有限：第 6 站说过，$t(n)$ 步的 multi-tape TM 可以用 $O(t(n)^2)$ 步的 single-tape TM simulate。所有“合理”的 deterministic model 之间互相 simulate 都只差一个 polynomial。

### P

$$\mathrm P=\bigcup_k\mathrm{TIME}(n^k)$$

$\mathrm{TIME}(t(n))$ 是能被 $O(t(n))$ 时间的 single-tape deterministic TM decide 的 language。因为 model 之间只差 polynomial，一个 language 在不在 P 与选哪个合理的 model 无关。这是选 polynomial 作为分界的理由：它是 model 换来换去也不变的最小的类。

例：$PATH=\{\langle G,s,t\rangle\mid\text{directed graph }G\text{ 中有 }s\text{ 到 }t\text{ 的 path}\}$。标记 $s$，然后反复扫所有 edge，把从已标记 node 出发能到的 node 标记上，直到没有新标记。最多 $|V|$ 轮，每轮扫一遍 edge，polynomial，所以 $PATH\in\mathrm P$。

### NP：答案容易检查

$HAMPATH$：graph 中有没有一条从 $s$ 到 $t$、恰好经过每个 node 一次的 path。暴力尝试 node 的所有排列，$n!$ 种，不是 polynomial。没有人知道 polynomial 的 algorithm。但如果有人给你一条 path，检查它只要 polynomial 时间：长度对不对、node 有没有重复、相邻两个之间有没有 edge。

**Verifier**：$V$ 是 $L$ 的 verifier，指 $w\in L\iff$ 存在 string $c$（certificate）使 $V$ accept $\langle w,c\rangle$。$L\in\mathrm{NP}$ 指 $L$ 有一个以 $|w|$ 的 polynomial 为 running time 的 verifier（于是 $c$ 的有用部分也只有 polynomial 长）。

等价的定义：$L$ 能被 polynomial time 的 nondeterministic TM decide。两边互相转换：
- 有 verifier $V$：nondeterministic TM 先“猜”出 certificate $c$（每一步分支写下一个 symbol），再运行 $V$。
- 有 polynomial time 的 nondeterministic TM $N$：accepting 分支上每一步做了哪个选择，这串选择就是 certificate，verifier 照着它 deterministic 地重放 $N$ 的那一条分支。

$\mathrm P\subseteq\mathrm{NP}$：能 decide 就不需要 certificate，verifier 忽略 $c$ 直接算。$\mathrm P=\mathrm{NP}$ 是否成立是 open problem。

:::wrong NP 就是 not polynomial，NP 里的问题都要 exponential time
NP 是 nondeterministic polynomial。$PATH\in\mathrm P\subseteq\mathrm{NP}$，它是 NP 里的问题，却有 polynomial 的 algorithm；把一条 path 当 certificate，verifier 只需检查它，也说明 $PATH\in\mathrm{NP}$。“NP 里的问题都很难”恰好是还没有被证明的 $\mathrm P\neq\mathrm{NP}$；就算它成立，也只说明 NP 里有些问题不在 P 里。
:::

### Polynomial-time reduction 与 NP-completeness

和上一站的 mapping reduction 一样，只是要求 $f$ 在 polynomial time 内算完：$A\le_pB$。若 $B\in\mathrm P$，则 $A\in\mathrm P$（算 $f(w)$ 是 polynomial，$|f(w)|$ 也就是 polynomial，再跑 $B$ 的 polynomial algorithm，polynomial 套 polynomial 仍是 polynomial）。

$B$ 是 NP-complete，指 $B\in\mathrm{NP}$，并且每个 $A\in\mathrm{NP}$ 都有 $A\le_pB$。于是只要有一个 NP-complete 的问题在 P 里，$\mathrm P=\mathrm{NP}$。证明新问题 NP-complete 的方向和上一站一样：拿一个已知 NP-complete 的问题 reduce 到它。这一部分（P、NP 的直观、3-SAT $\le_p$ Independent Set 的完整构造、方向上的常见错误）在 [CS3230 的 NP-completeness 站](../courses/CS3230.html#np)里讲过，这里只补 CS3231 特有的部分：第一个 NP-complete 问题从哪里来。

### Cook–Levin：SAT 是 NP-complete

:::skip
这一小节给出证明的结构和每一部分的大小，细节（每个 window 的合法性怎样逐个列出）在 Sipser 7.4 节。跳过它会少掉“为什么第一个 NP-complete 问题存在”的理由。
:::

$SAT$：一个 Boolean formula 有没有 satisfying assignment。$SAT\in\mathrm{NP}$，certificate 就是 assignment。难的是证明每个 $A\in\mathrm{NP}$ 都 $\le_pSAT$，这时对 $A$ 一无所知，只知道有一台 $n^k$ 时间的 nondeterministic TM $N$ decide 它。

思路：$N$ 在 $w$ 上的一条 accepting 分支可以写成一张表（tableau），$n^k$ 行，每行是一个 ID，相邻两行是一步合法的 move。Tape 不会超过 $n^k$ 格，所以表是 $n^k\times n^k$ 的。给每一格、每个可能的 symbol（tape symbol 或 state）一个 Boolean variable $x_{i,j,s}$，表示“第 $i$ 行第 $j$ 格是 $s$”。造 formula $\varphi=\varphi_{cell}\wedge\varphi_{start}\wedge\varphi_{move}\wedge\varphi_{accept}$：

- $\varphi_{cell}$：每格恰好一个 symbol；
- $\varphi_{start}$：第一行是 $N$ 在 $w$ 上的 start ID；
- $\varphi_{accept}$：某一行出现 accepting state；
- $\varphi_{move}$：每个 $2\times3$ 的 window 都是合法的。TM 一步只改 head 附近的格子，所以“相邻两行合法”可以拆成局部的 window 检查，每个 window 的合法内容是一个只取决于 $N$ 的有限 list。

$\varphi$ satisfiable 当且仅当存在 accepting tableau，当且仅当 $N$ accept $w$。表有 $n^{2k}$ 格，每部分对每格或每个 window 写常数长的 clause，所以 $\varphi$ 的长度是 $O(n^{2k})$，能在 polynomial time 内写出来。这就是 $A\le_pSAT$。
