先看几个具体的问题，每一个都卡在“算是算得出，但做法太笨”，或者“照常识去做，答案是错的”。

**一个 rover 在陨石坑里找最好的采样点，手里没有地图。** 它只量得出脚下和相邻几个位置的分数，也没法被搬到别处重新开始。CS2109S 的 A* 要先知道每个 action 会把 agent 带到哪里，这里一步也用不上；只往分数更高的邻居走，又会停在一个周围都更差、但不是最好的位置。

**一个 agent 知道几条规则，想推出某处是否安全。** 规则里有 7 个 true/false 的 symbol，把所有 truth assignment 列出来是 $2^7=128$ 种，逐个检查还行；格子多到 16 个，symbol 是 32 个，就有 $2^{32}\approx4.3\times10^9$ 种。

**给 7 个 region 涂 3 种颜色，相邻的不同色。** 所有涂法有 $3^7=2187$ 种；换成美国 50 个州、4 种颜色，是 $4^{50}\approx1.3\times10^{30}$ 种。

**两个邻居都打电话说你家 alarm 响了，被盗的 probability 是多少。** 只有 5 个 binary random variable，完整的 joint table 已经要 31 个数；30 个 variable 要 $2^{30}-1\approx1.07\times10^9$ 个。这些数还得从 data 里估出来：50 行记录，几乎每一行都是“什么都没发生”，31 个数里大多数一次都没被观测到。

**看到 alarm 响了，和自己按响 alarm，是两回事。** 前者让被盗的 probability 从 0.001 升到 0.374；后者对被盗毫无影响。同一个 network、同一个 conditional probability，却要回答两个不同的问题。

**每天只看到一份 weather forecast，想知道今天的天气。** 把过去 $t$ 天所有可能的天气 sequence 列出来，是 $2^t$ 条。

**下雨的 probability 知道了，带不带伞；forecast 要花钱，值不值得买。** 这需要给每种结果一个数，还要说清楚这些数怎么比。

**两个人同时出手指，谁也不先手。** CS2109S 里的 minimax 要求轮流走，这里用不上。

这门课的每一站都是同一个套路：选一种 representation，把问题的结构写进去（哪些 symbol 之间有规则、哪些 variable 之间有 constraint、哪些 variable 之间直接相关），然后找一个 inference algorithm，利用这个结构，避开“全部列出来”。第 1 站是没有地图时的 search，第 2、3 站是 logic，第 4 站是 constraint，第 5 到 9 站是 probability（第 7 站从 data 学 CPT，第 8 站区分观测和干预，第 9 站加上时间），第 10 站把 probability 和 preference 合起来做决定，并看人自己做判断时会偏在哪里，第 11 站是不止一个决策者的情形。Uninformed search 与 A* 在 [CS2109S 第 1 站](CS2109S.html#search)，Bayes' rule 在 [ST2131 第 2 站](ST2131.html#bayes)，这里不重讲。

### 不知道 action 会把你带到哪里

AY22/23 midterm 第 10 题的设定：rover Persy 在 Jezero Crater 里找做 rock analysis 的位置。在任何一个位置，它只能探到 $k$ 个相邻位置，并能用仪器量出脚下和这些邻居的“goodness”分数；电量不限，但探索的时间 $T$ 有限。

A*（[CS2109S 第 2 站](CS2109S.html#astar)）在出发之前就在脑子里展开 search tree，这要求事先知道每个 state 的每个 action 会到哪个 state。Persy 没有地图，它要知道往东走会到哪里，只能真的往东走一次。这类问题有两种办法：只盯着当前位置往好的方向走（local search），或者一边走一边记下走过的地方、修正自己的估计（online search）。

### Hill climbing 的几种变体

Midterm 里的 Algorithm A 是：从 $k$ 个邻居里 uniformly random 地挑一个，分数严格更高就过去，否则留在原地。这是 hill climbing 的 first-choice 版本：不看全部邻居，随机抽到一个更好的就走。

题目还假设每个位置恰好有一个邻居比它好。于是每次 iteration 抽中它的 probability 是 $1/k$，抽不中的是 $1-1/k$，各次独立。$N$ 次都没抽中的 probability 是 $(1-1/k)^N$，所以 $N$ 次以内离开当前位置的 probability 是

$$1-\Big(1-\frac1k\Big)^N$$

$k=4$ 时，$N=1$ 是 0.25，$N=4$ 是 0.684，$N=10$ 是 0.944。邻居越多，抽中那一个越难：$k=8$、$N=10$ 只有 0.737。

几种变体放在一起：

| 名字 | 每一步怎么走 | 停在哪里 |
|---|---|---|
| steepest-ascent | 看全部邻居，走到最好的那个 | 没有更好的邻居，即 local maximum |
| stochastic | 在更好的邻居里随机挑，probability 可以随分数高低变化（midterm 的 Algorithm B） | 同上 |
| first-choice | 随机抽邻居，抽到更好的就走（Algorithm A） | 同上，而且可能要抽很多次才动一步 |
| random restart | 一次 hill climbing 停住了，就换一个随机的起点再来，最后取最好的（Algorithm C） | 由 restart 的次数决定 |

前三种只是“往上走”的方式不同，都会停在 local maximum。Random restart 换来的是一个 probability 上的保证：设一次 hill climbing 找到 global maximum 的 probability 是 $p$，$R$ 次 independent 的 restart 至少成功一次的 probability 是 $1-(1-p)^R$，$R\to\infty$ 时趋于 1。用 [CS2109S 第 3 站](CS2109S.html#adv) 实测的 8-queens 数字 $p=0.143$：$R=5$ 是 0.538，$R=10$ 是 0.786，$R=30$ 是 0.990。可 Persy 没法被搬到陨石坑的随机位置重新开始，midterm 的 solution 特意指出了这一点：random restart 需要能“跳”到任意 state，一个在真实环境里移动的 agent 做不到。

### Simulated annealing 在 $T=0$ 时是什么

课程讲义用的是 AIMA 的 pseudocode（midterm solution 称作 RN Figure 4.4，aima-python 的 `simulated_annealing` 按另一版的编号写作 Figure 4.5）：

1. 对 $t=1,2,\dots$：$T\leftarrow\mathrm{schedule}(t)$；若 $T=0$，返回 current。
2. 从 current 的邻居里随机抽一个 next，$\Delta E=\mathrm{value}(\text{next})-\mathrm{value}(\text{current})$。
3. 若 $\Delta E>0$，current ← next；否则以 probability $e^{\Delta E/T}$ 让 current ← next。

$\Delta E=-1$ 时，$T=10$ 接受的 probability 是 $e^{-0.1}=0.905$，$T=1$ 是 0.368，$T=0.1$ 是 $e^{-10}=4.5\times10^{-5}$。$T$ 越小，变差的一步越难被接受。CS188 给的保证是：$T$ 降得足够慢，找到 global maximum 的 probability 趋于 1。

:::exam AY23/24 midterm 第 2 题
题目说：$T=0$ 时 simulated annealing 和 greedy（steepest-ascent）hill climbing 完全一样。答案是 False，solution 给了两条理由，都可以从上面的 pseudocode 读出来。第一，就算把 $T$ 推到很接近 0，变差的一步几乎不再被接受，但第 2 步的 next 仍然是随机抽的一个邻居，而不是最好的邻居，所以它像 first-choice hill climbing，不像 steepest-ascent。第二，照讲义那份 pseudocode，$T=0$ 是停机条件，到这里直接返回；$e^{\Delta E/0}$ 本身没有定义。
:::

:::wrong Random restart 和 simulated annealing 都保证找到 global optimum，所以给它们跑完的结果就是最好的
两个保证都是极限意义上的。AY22/23 midterm 第 5 题说两者都能保证 global optimality、只是可能收敛得慢，答案是 True；同一份卷子的第 10 题却说，时间 $T$ 有限时，Algorithm A、B、C、D 都不保证找到最好的位置。两题不矛盾：random restart 的成功 probability 是 $1-(1-p)^R$，用 $p=0.143$ 跑 5 次只有 0.538；simulated annealing 要 $T$ 降得“足够慢”，而有限的时间里只能降到某个程度就停。只有让 restart 次数或降温时间趋于无穷，probability 才趋于 1。
:::

### Online search：一边走一边建地图

Online search problem 里，agent 事先知道的是：当前 state 有哪些 action、一步的 cost $c(s,a,s')$、goal test，以及一个 heuristic $h(s)$。它不知道 $\mathrm{result}(s,a)$，要在 $s$ 真的做了 $a$ 才看到结果。

Hill climbing 本身就是 online 的（每步只看当前位置），但它会停在 local minimum 不动；random restart 又做不到。办法是给 hill climbing 加上记忆：对每个到过的 state 存一个当前的 cost-to-goal 估计 $H(s)$，一开始等于 $h(s)$，每离开一个 state 就用刚看到的邻居修正它。这就是 learning real-time A*（LRTA*，AIMA Figure 4.24）：

1. 到达 $s'$。若 $s'$ 是 goal，停。若 $s'$ 第一次到，$H(s')\leftarrow h(s')$。
2. 若有上一步 $(s,a)$：记下 $\mathrm{result}(s,a)=s'$，然后更新
$$H(s)\leftarrow\min_{b}\ \text{LRTA-cost}(s,b),\qquad \text{LRTA-cost}(s,b)=\begin{cases}c(s,b,s'')+H(s'')&\mathrm{result}(s,b)=s''\text{ 已知}\\h(s)&b\text{ 还没试过}\end{cases}$$
3. 在 $s'$ 选让 LRTA-cost$(s',b)$ 最小的 action $b$，执行。

没试过的 action 估成 $h(s)$，等于假设它直接通向一条最便宜的路，这叫 optimism under uncertainty：它鼓励 agent 去试没走过的方向。

走一个例子。一条走廊上 7 个位置 $x_0,\dots,x_6$，goal 是 $x_6$，每步 cost 1，从 $x_3$ 出发。真实的距离是 $(6,5,4,3,2,1,0)$；$h=(6,5,1,0,2,1,0)$ 每一项都不超过真实距离（admissible），但在 $x_3$ 有一个 local minimum：$h(x_3)=0$，两个邻居是 1 和 2。只按 $h$ 走的 hill climbing 在 $x_3$ 看到两边都更差，永远停在那里。

为了让例子短一点，假设 agent 站在一个位置就看得到左右两格是谁（aima-python 的 `LRTAStarAgent` 和 NUS 的 maze 环境都直接给出 `result`），于是每个方向的 cost 都是 $1+H(\text{邻居})$，没到过的邻居用 $h$：

::fig[cs3263-lrta] 动图。每格里是当前的 $H$，上面一行是初始的 $h$；圆点是 agent，粗框是这一步刚被更新的 $H$。静止时显示整条路线和最后的 $H$。

1. 在 $x_3$：去 $x_2$ 是 $1+1=2$，去 $x_4$ 是 $1+2=3$，往左。
2. 到 $x_2$，先更新刚离开的 $x_3$：$H(x_3)=\min(1+H(x_2),\ 1+h(x_4))=\min(2,3)=2$。再选：去 $x_1$ 是 $1+5=6$，去 $x_3$ 是 $1+2=3$，往右。
3. 到 $x_3$，更新 $H(x_2)=\min(1+5,\ 1+2)=3$。选：去 $x_2$ 是 $1+3=4$，去 $x_4$ 是 $1+2=3$，往右。
4. 到 $x_4$，更新 $H(x_3)=\min(1+3,\ 1+2)=3$。选：去 $x_3$ 是 4，去 $x_5$ 是 $1+1=2$，往右。
5. 到 $x_5$，更新 $H(x_4)=\min(1+3,\ 1+1)=2$。选：去 $x_4$ 是 3，去 $x_6$ 是 $1+0=1$，往右，到达 goal。

$H(x_3)$ 从 0 升到 2 再升到 3，正好是真实距离；$H(x_2)$ 升到 3。local minimum 是被“填平”的：每来回一次，坑底的估计就被抬高到“一步加上邻居的估计”，直到另一边看起来更便宜。aima-python 的 notebook 提醒，state space 是 infinite 时 LRTA* 可能停不下来；有限、而且不会走进出不来的 dead end（safely explorable）时它一定到达 goal，这一条是 AIMA 第 4.5 节的结论，这里凭记忆写，没有对照原书。

AY22/23 midterm 的 Algorithm D 是这个想法的一个版本：走到邻居里分数最好的，把离开的位置的分数记进一张 table，所有邻居都去过、而当前位置是 table 里最好的就停。Solution 的判断是：它是 LRTA* 的一种，时间够长时可能找到 global optimum，但“够长”没法事先说清，所以在有限的 $T$ 里同样不保证。

:::exam AY22/23 midterm 第 10 题
四种算法在有限时间 $T$ 内能否保证找到陨石坑里最好的位置，答案全是 NO。Solution 把 A、B、C、D 依次认作 hill climbing（first-choice 式的随机抽邻居）、stochastic hill climbing、random restart hill climbing 和 LRTA*，理由是：A 一般只到 local optimum；B 不保证在有限时间内到 global optimum；C 只有当各次 restart 的时间之和 $\sum_{i=1}^RT_i\le T$ 时才可能找到，而且 Persy 无法被搬到随机起点；D 要时间“足够长”。第 (a) 小题问 Algorithm A 在 $N$ 次以内离开一个位置的 probability，就是上面推出的 $1-(1-1/k)^N$。
:::

### MCTS：rollout 越多，结果不一定越好

MCTS 在 [CS4246 第 9 站](CS4246.html#mcts)。AY23/24 midterm 第 3 题问：对任意 $M<N$，做 $N$ 次 rollout 的 MCTS 是否总比 $M$ 次给出更好的决定。答案是 False：rollout 趋于无穷时 MCTS 给出 optimal 的那一步，可每次 rollout 是随机的，有限次数下多做几次只是让“选对”的 probability 变大。

算一个最简单的情形：两步棋，真实的胜率是 0.6 和 0.5，每步各做 $n$ 次 rollout，选平均胜率高的那步（平手时各一半）。选对的 probability，$n=10$ 是 0.672，$n=20$ 是 0.737，$n=100$ 是 0.923，$n=400$ 是 0.998。$n$ 从 10 加到 20，选对的 probability 只多了 0.065：两轮独立地各跑一次，20 次的那一轮选错、10 次的那一轮选对的 probability 是 $(1-0.737)\times0.672=0.177$。“多做 rollout 更好”说的是 probability，不是每一次。

## [logic] Propositional logic、entailment 与 resolution

:::skip
能把一句规则写成 propositional sentence，在 truth table 上判断 entailment，把 sentence 化成 CNF，并用 resolution 做一次 proof by contradiction，就可以去第 3 站。
:::

### 让 agent 自己推出结论

一个 agent 在一个 grid 里走。有的格子里有 pit，走进去就完了；和 pit 上下左右相邻的格子里有 breeze，agent 站在一个格子里能感觉到这里有没有 breeze，但看不见 pit。它从 [1,1] 出发（[1,1] 保证安全），走到 [2,1]。在 [1,1] 没有 breeze，在 [2,1] 有。现在它想知道：[1,2] 能不能走？[2,2] 有没有 pit？

用 $P_{xy}$ 表示“[x,y] 里有 pit”，$B_{xy}$ 表示“[x,y] 里有 breeze”。Agent 知道的事情写成 5 个 sentence，合起来叫 knowledge base（KB）：

$$\begin{aligned}R_1&:\ \lnot P_{11}\\R_2&:\ B_{11}\Leftrightarrow(P_{12}\lor P_{21})\\R_3&:\ B_{21}\Leftrightarrow(P_{11}\lor P_{22}\lor P_{31})\\R_4&:\ \lnot B_{11}\\R_5&:\ B_{21}\end{aligned}$$

$R_2$、$R_3$ 是这个世界的规则（[1,1] 的邻居是 [1,2]、[2,1]；[2,1] 的邻居是 [1,1]、[2,2]、[3,1]），$R_1$、$R_4$、$R_5$ 是出发条件和两次感觉到的结果。

::fig[cs3263-wumpus] 左边是 agent 走过的两格和感觉到的结果；右边是下一节要找的东西：所有让 KB 成立的世界。

几个 connective 的意思用 truth table 定死：

| $A$ | $B$ | $\lnot A$ | $A\land B$ | $A\lor B$ | $A\Rightarrow B$ | $A\Leftrightarrow B$ |
|---|---|---|---|---|---|---|
| F | F | T | F | F | T | T |
| F | T | T | F | T | T | F |
| T | F | F | F | T | F | F |
| T | T | F | T | T | T | T |

最容易错的是 $\Rightarrow$：它只在 premise 为 true、conclusion 为 false 时才是 false，premise 为 false 时整句自动为 true。

给每个 symbol 指定 true 或 false，叫一个 model（一个可能的世界）。这里 7 个 symbol，一共 $2^7=128$ 个 model。一个 sentence 在有的 model 里 true、有的里 false；KB 是 5 个 sentence 的 conjunction，在 128 个 model 里只有一部分让它为 true。

### Entailment 与 model checking

“从 KB 能推出 $\alpha$”的精确意思是：

> 在每一个让 KB 为 true 的 model 里，$\alpha$ 也为 true。

记作 $\mathrm{KB}\models\alpha$，读作 KB entails $\alpha$。用 $M(\cdot)$ 表示让一个 sentence 为 true 的 model 的集合，定义就是 $M(\mathrm{KB})\subseteq M(\alpha)$。

最直接的检查办法是把 model 一个个列出来，叫 model checking。这里不必真列 128 行，可以一条条用 sentence 去排除：

- $R_1$、$R_4$、$R_5$ 直接定下 $P_{11}=\mathrm F$、$B_{11}=\mathrm F$、$B_{21}=\mathrm T$。
- $R_2$ 要求 $B_{11}$ 和 $P_{12}\lor P_{21}$ 同真同假。$B_{11}$ 是 F，所以 $P_{12}\lor P_{21}$ 是 F，只能 $P_{12}=P_{21}=\mathrm F$。
- $R_3$ 要求 $P_{11}\lor P_{22}\lor P_{31}$ 和 $B_{21}$ 一样是 T。$P_{11}$ 已经是 F，所以 $P_{22}\lor P_{31}$ 是 T：$(P_{22},P_{31})$ 只能是 (T, F)、(F, T)、(T, T)。

七个 symbol 全部定下，KB 为 true 的 model 恰好 3 个，就是上图右边那三个。

拿定义检验两个 query。$\alpha=\lnot P_{12}$：三个 model 里 $P_{12}$ 都是 F，所以 $\mathrm{KB}\models\lnot P_{12}$，[1,2] 安全。$\alpha=P_{22}$：model 1 里 $P_{22}$ 是 F，所以 $\mathrm{KB}\not\models P_{22}$；反过来 $\alpha=\lnot P_{22}$ 在 model 2、3 里是 F，所以 $\mathrm{KB}\not\models\lnot P_{22}$ 也成立。KB 对 [2,2] 什么也说不出来，这是正确答案，不是 algorithm 的缺陷。

Model checking 一定对，但 $n$ 个 symbol 要查 $2^n$ 个 model。$4\times4$ 的 grid 有 16 个 $P$ 和 16 个 $B$，就是 $2^{32}\approx4.3\times10^9$ 个。CS188 指出 propositional entailment 是 co-NP-complete，最坏情况下逃不掉指数时间，但有的 algorithm 在实际问题上快得多。下面两条路都是这样：一条是只在 sentence 上做变形（inference rule），一条是聪明地做 model checking（DPLL）。

### Inference rule：只看 sentence 的形状

刚才排除 model 时，其实用的是 sentence 的形状：“$B_{11}$ 是 F，而 $B_{11}$ 和 $P_{12}\lor P_{21}$ 同真同假”。把这种推理写成规则，就可以完全不去碰 model。最常用的一条是 modus ponens：

$$\frac{\alpha\Rightarrow\beta,\qquad\alpha}{\beta}$$

横线上面是已有的 sentence，下面是可以加进 KB 的新 sentence。一条 rule 有用的前提是 sound：凡是让上面都为 true 的 model，也让下面为 true。拿 truth table 检验 modus ponens：$\alpha$ 和 $\alpha\Rightarrow\beta$ 同时为 T 的只有最后一行（$A$、$B$ 都是 T），那一行 $\beta$ 是 T。

用几条 sound 的 rule 走一遍 $\lnot P_{12}$：

1. 对 $R_2$ 做 biconditional elimination：$(B_{11}\Rightarrow(P_{12}\lor P_{21}))\land((P_{12}\lor P_{21})\Rightarrow B_{11})$。
2. And-elimination，取后半：$(P_{12}\lor P_{21})\Rightarrow B_{11}$。
3. 换成 contrapositive（等价变形）：$\lnot B_{11}\Rightarrow\lnot(P_{12}\lor P_{21})$。
4. 和 $R_4$ 做 modus ponens：$\lnot(P_{12}\lor P_{21})$。
5. De Morgan：$\lnot P_{12}\land\lnot P_{21}$。
6. And-elimination：$\lnot P_{12}$。

这样推有两个问题。一是每一步用哪条 rule、用在哪个 sentence 上，要自己挑，本身就是一个 search 问题。二是这几条 rule 合起来够不够，也就是是否 complete（凡是 entailed 的都能推出来）。看 $R_3$ 这一侧：modus ponens 能从 $B_{21}$ 和 $B_{21}\Rightarrow(P_{11}\lor P_{22}\lor P_{31})$ 推出 $P_{11}\lor P_{22}\lor P_{31}$，但接下来手里有 $\lnot P_{11}$，要得到 $P_{22}\lor P_{31}$ 就没有哪条能用了：modus ponens 需要 $\Rightarrow$ 的 premise 被单独确认，and-elimination 需要 $\land$。CS221 举的是同一类例子：KB 是 $\{\mathrm{Rain},\ \mathrm{Rain}\lor\mathrm{Snow}\Rightarrow\mathrm{Wet}\}$，semantics 上显然 entail Wet，但 modus ponens 推不出来，因为 $\mathrm{Rain}\lor\mathrm{Snow}$ 从来没有被单独确认过。

要一条 rule 单独就 complete，先得把 sentence 统一成一种形状。

### CNF：统一成 clause 的 conjunction

一个 symbol 或者它的否定叫 literal；几个 literal 用 $\lor$ 连起来叫 clause；几个 clause 用 $\land$ 连起来叫 conjunctive normal form（CNF）。每个 sentence 都能等价地化成 CNF，步骤固定：

1. 消去 $\Leftrightarrow$：$\alpha\Leftrightarrow\beta$ 换成 $(\alpha\Rightarrow\beta)\land(\beta\Rightarrow\alpha)$。
2. 消去 $\Rightarrow$：$\alpha\Rightarrow\beta$ 换成 $\lnot\alpha\lor\beta$。
3. 把 $\lnot$ 往里推（De Morgan，以及 $\lnot\lnot\alpha=\alpha$），直到 $\lnot$ 只贴在 symbol 上。
4. 用 distributivity $\alpha\lor(\beta\land\gamma)=(\alpha\lor\beta)\land(\alpha\lor\gamma)$ 把 $\lor$ 推到 $\land$ 里面。

第 2 步可以拿 truth table 核对：$\lnot A\lor B$ 只在 $\lnot A$、$B$ 都是 F，也就是 $A=\mathrm T$、$B=\mathrm F$ 时为 F，和 $A\Rightarrow B$ 的那一列一样。

对 $R_2$ 走一遍：

$$\begin{aligned}&B_{11}\Leftrightarrow(P_{12}\lor P_{21})\\\xrightarrow{1}\ &(B_{11}\Rightarrow(P_{12}\lor P_{21}))\land((P_{12}\lor P_{21})\Rightarrow B_{11})\\\xrightarrow{2}\ &(\lnot B_{11}\lor P_{12}\lor P_{21})\land(\lnot(P_{12}\lor P_{21})\lor B_{11})\\\xrightarrow{3}\ &(\lnot B_{11}\lor P_{12}\lor P_{21})\land((\lnot P_{12}\land\lnot P_{21})\lor B_{11})\\\xrightarrow{4}\ &(\lnot B_{11}\lor P_{12}\lor P_{21})\land(\lnot P_{12}\lor B_{11})\land(\lnot P_{21}\lor B_{11})\end{aligned}$$

$R_3$ 同样得到四个 clause：$(\lnot B_{21}\lor P_{11}\lor P_{22}\lor P_{31})$、$(\lnot P_{11}\lor B_{21})$、$(\lnot P_{22}\lor B_{21})$、$(\lnot P_{31}\lor B_{21})$。加上 $R_1$、$R_4$、$R_5$ 三个只有一个 literal 的 clause（unit clause），整个 KB 是 10 个 clause 的 conjunction，也就是 10 个 clause 组成的集合。

### Resolution

Resolution rule 只有一条：两个 clause 里，一个含 $p$、另一个含 $\lnot p$，就把这一对删掉，其余 literal 合成一个新 clause：

$$\frac{\ell_1\lor\cdots\lor\ell_k\lor p,\qquad\lnot p\lor m_1\lor\cdots\lor m_n}{\ell_1\lor\cdots\lor\ell_k\lor m_1\lor\cdots\lor m_n}$$

新 clause 叫 resolvent。Sound 的理由：任取一个让两个 premise 都为 true 的 model。若 $p$ 在这个 model 里是 T，第二个 clause 里的 $\lnot p$ 是 F，它要成立只能靠某个 $m_j$ 为 T；若 $p$ 是 F，第一个 clause 只能靠某个 $\ell_i$ 为 T。两种情况 resolvent 里都有一个 true 的 literal。

拿它重做 $\lnot P_{12}$：$R_2$ 的第二个 clause $\lnot P_{12}\lor B_{11}$ 和 $R_4$ 的 $\lnot B_{11}$ 一步 resolve，得到 $\lnot P_{12}$。前面六步的推导缩成了一步。Modus ponens 也是它的特例：$\alpha\Rightarrow\beta$ 写成 clause 是 $\lnot\alpha\lor\beta$，和 $\alpha$ resolve 得到 $\beta$。

Resolution 本身只能从 clause 推出 clause，要用它回答“KB 是否 entail $\alpha$”，需要换一个问法：

$$\mathrm{KB}\models\alpha\quad\Longleftrightarrow\quad\mathrm{KB}\land\lnot\alpha\ \text{unsatisfiable}$$

两边说的是同一件事：左边是“没有一个 model 让 KB 为 true 而 $\alpha$ 为 false”，右边是“没有一个 model 让 KB 和 $\lnot\alpha$ 同时为 true”。于是 algorithm 是：把 $\lnot\alpha$ 化成 CNF 加进 clause 的集合，反复 resolve，加入所有新的 resolvent。如果某一步两个 unit clause $p$ 和 $\lnot p$ 相消，resolvent 一个 literal 也不剩，叫 empty clause，记作 □。空的 disjunction 在任何 model 里都是 false；而每一步都 sound，一个能推出 false 的 clause 集合不可能有 model，所以 KB ∧ ¬α unsatisfiable，$\mathrm{KB}\models\alpha$。如果做到再也产生不出新 clause 还没有 □，就是 $\mathrm{KB}\not\models\alpha$。

用它证明 $\alpha=P_{22}\lor P_{31}$（“[2,2] 和 [3,1] 至少有一个 pit”）。$\lnot\alpha=\lnot P_{22}\land\lnot P_{31}$，拆成两个 unit clause。

::fig[cs3263-resolution] 动图，静止时显示的是整个 proof。每一步用粗框标出参与 resolve 的两个 clause，右边写的是这一步消去的 symbol。四步之后得到 empty clause。

四步分别是：$(\lnot B_{21}\lor P_{11}\lor P_{22}\lor P_{31})$ 和 $B_{21}$ 得 $P_{11}\lor P_{22}\lor P_{31}$；再和 $\lnot P_{11}$ 得 $P_{22}\lor P_{31}$；再和 $\lnot P_{22}$ 得 $P_{31}$；再和 $\lnot P_{31}$ 得 □。第二步正是上一节 modus ponens 做不到的那一步。和 model checking 对照：三个 model 里 $P_{22}\lor P_{31}$ 都是 T，结论一致。

:::wrong 推不出 □，就说明 query 是 false
推不出 □ 只说明 $\mathrm{KB}\not\models\alpha$，不说明 $\mathrm{KB}\models\lnot\alpha$。拿 $\alpha=P_{22}$ 试：加入 $\lnot P_{22}$ 之后，model 1（只有 [3,1] 有 pit）仍然满足全部 clause，集合 satisfiable，而 resolution 是 sound 的，所以永远推不出 □。再试 $\alpha=\lnot P_{22}$：加入 $P_{22}$，model 2 满足全部 clause，同样推不出 □。两个方向都推不出，正对应前面 model checking 的结论：KB 对 [2,2] 不知道。要判断 query 是 true、false 还是不知道，两个方向都要跑。
:::

### Resolution 为什么 complete

:::skip
这一小节证明 resolution 不会漏掉结论。跳过它不影响会用。
:::

要证的是：如果一个 clause 集合 $S$ unsatisfiable，那么反复 resolve 得到的全部 clause（记作 $RC(S)$）里一定有 □。证 contrapositive：假设 $RC(S)$ 里没有 □，构造一个 model 满足 $RC(S)$ 里每个 clause，从而 $S$ satisfiable。

把 symbol 排成 $P_1,\dots,P_k$，依次赋值：

> 如果 $RC(S)$ 里有某个 clause 含 $\lnot P_i$，而它其余的 literal 在 $P_1,\dots,P_{i-1}$ 已定的值下全是 false，就令 $P_i=\mathrm F$；否则令 $P_i=\mathrm T$。

假设在第 $i$ 步，第一次出现某个 clause $C\in RC(S)$ 所有 literal 都是 false。$C$ 在第 $i-1$ 步还没全 false，所以它含 $P_i$ 或 $\lnot P_i$（两个都含的 clause 恒为 true，不必管）。

- 若 $C$ 含 $\lnot P_i$：$C$ 的其余 literal 在前 $i-1$ 个值下全 false，正符合规则的条件，所以 $P_i$ 被设成 F，$\lnot P_i$ 为 true，$C$ 不会全 false。矛盾。
- 若 $C$ 含 $P_i$：$C$ 全 false 说明 $P_i=\mathrm F$，这是因为另有一个 clause $C'\in RC(S)$ 含 $\lnot P_i$、其余 literal 全 false。$C$ 和 $C'$ 对 $P_i$ resolve，resolvent 由两边“其余的 literal”组成，在前 $i-1$ 个值下全 false。它属于 $RC(S)$，而且不是 □（假设），所以它早在第 $i-1$ 步之前就全 false 了，和“第一次”矛盾。

两种情况都不可能，所以构造出的 model 满足 $RC(S)$，当然也满足 $S$。

Complete 不代表快。每次 resolve 可能产生更长的 clause，$n$ 个 symbol 能组成的不同 clause 有 $3^n$ 个（每个 symbol 可以正着出现、反着出现或不出现），最坏要全部生成。

### DPLL：聪明一点的 model checking

另一条路是回到 model checking，但不傻列。DPLL 判断一个 CNF 是否 satisfiable：按某个顺序给 symbol 赋值，depth-first 地试，配上三个技巧。

- **Early termination。** Clause 里只要有一个 literal 为 true，整个 clause 就为 true；只要有一个 clause 的 literal 全为 false，整个 CNF 就为 false，不必再往下赋值。
- **Pure symbol。** 一个 symbol 在所有还没满足的 clause 里只以一种符号出现（总是 $P$ 或总是 $\lnot P$），就把它设成让这些 literal 为 true 的值，不会错过 solution。
- **Unit clause。** 一个 clause 里只剩一个 literal 没赋值、其余都是 false，这个 literal 必须为 true，直接赋值。

拿它检查 $\mathrm{KB}\models P_{22}\lor P_{31}$，也就是检查 KB 的 10 个 clause 加上 $\lnot P_{22}$、$\lnot P_{31}$ 是否 satisfiable。一开始就有五个 unit clause：$\lnot P_{11}$、$\lnot B_{11}$、$B_{21}$、$\lnot P_{22}$、$\lnot P_{31}$，依次赋值。这时 clause $\lnot B_{21}\lor P_{11}\lor P_{22}\lor P_{31}$ 的四个 literal 全是 false，early termination：unsatisfiable，所以 entailed。一次分支都没有。

再检查 $\mathrm{KB}\models\lnot P_{22}$，即加入 $P_{22}$。Unit clause $\lnot P_{11}$、$\lnot B_{11}$、$B_{21}$、$P_{22}$ 赋值之后，clause $\lnot P_{12}\lor B_{11}$ 里 $B_{11}$ 是 false，成了 unit clause，得 $P_{12}=\mathrm F$；同理 $\lnot P_{21}\lor B_{11}$ 得 $P_{21}=\mathrm F$。这时 10 个 clause 加 $P_{22}$ 全部为 true，只剩 $P_{31}$ 没赋值也已经 early termination：satisfiable，找到的 model 就是一个反例（例如 $P_{31}=\mathrm F$，即 model 2），所以 $\mathrm{KB}\not\models\lnot P_{22}$。和 resolution 不同，DPLL 失败时会交出一个具体的 model。

DPLL 就是第 4 站的 backtracking search：symbol 是 variable，{T, F} 是 domain，clause 是 constraint；unit clause 规则就是“domain 只剩一个值就先赋它”。

:::back
Model checking 里“逐个试、一边试一边排除”的思路是 [CS2109S 第 1 站](CS2109S.html#search) 的 depth-first search。
:::

Entailment 的定义与 $M(\mathrm{KB})\subseteq M(\alpha)$、“$A\models B$ 当且仅当 $A\land\lnot B$ unsatisfiable”、model checking 是 $O(2^N)$ 而 entailment 是 co-NP-complete、DPLL 的三个技巧，跟的是 [CS188 textbook 10.4](https://inst.eecs.berkeley.edu/~cs188/textbook/logic/inference.html)（它的 DPLL 例子用的是另一个 7 个 symbol 的 CNF，这里换成了本站的 KB 重算）。CS188 [10.5](https://inst.eecs.berkeley.edu/~cs188/textbook/logic/theorem.html) 把 resolution 写成了“由 $A$ 和 $B$ 推出 $A\land B$”，那是 conjunction introduction，不是 resolution；这里的 rule、soundness 的论证、Rain/Snow/Wet 的例子和 CNF 的四步跟的是 Stanford CS221 [Logic II](https://stanford-cs221.github.io/spring2024-extra/modules/logic/logic2.pdf) 和 [propositional resolution](https://stanford-cs221.github.io/autumn2021-extra/modules/logic/propositional-resolution.pdf) 两个 module。Grid world 的 $R_1$ 到 $R_5$ 来自 AIMA 第 7 章，对照了 [aima-python](https://github.com/aimacode/aima-python) 的 `logic.py`（`wumpus_kb`）；3 个 model、四步 resolution、两次 DPLL 是为这一页算的。Completeness 的 proof 是 AIMA 里 ground resolution theorem 的证法。对照了 NUS 旧版 CS3243（Kan Min-Yen）讲义里[这一页 slide](https://www.comp.nus.edu.sg/~kanmy/courses/3243_2007/lectureNotes/w9-all_files/v3_slide0042.htm)：theorem 的陈述、证 contrapositive、逐个 symbol 构造 model 的思路一致；那页的公式是图片，抓不到具体的赋值规则，也没有写验证部分，所以赋值规则仍按记忆中的 AIMA 写法，两种情况的验证是这里补的。

## [horn] Horn clause、forward / backward chaining 与 first-order logic

:::skip
能判断一个 clause 是不是 definite clause，手跑 forward chaining 的 count 和 agenda，画出 backward chaining 的 AND-OR tree，并用 unification 做一次 first-order 的 modus ponens，就可以去第 4 站。
:::

### 很多 KB 只由“如果……就……”组成

第 2 站的 resolution 完整但可能指数级地慢。慢的根源是 resolvent 可以越来越长。可是专家系统、数据库规则、type checker 里的知识大多长这样：“$A$ 和 $B$ 都成立，就有 $C$”。写成 clause：

$$(A\land B)\Rightarrow C\quad\equiv\quad\lnot A\lor\lnot B\lor C$$

恰好有一个 positive literal 的 clause 叫 definite clause；单独一个 positive literal（比如 $A$）是没有 premise 的 definite clause，叫 fact。至多一个 positive literal 的 clause 叫 Horn clause，所以 Horn clause 除了 definite clause，还包括一个 positive literal 都没有的 goal clause，比如 $\lnot A\lor\lnot B\equiv(A\land B)\Rightarrow\mathrm{false}$。

拿第 2 站的 KB 检验：$\lnot P_{12}\lor B_{11}$ 是 definite clause，即 $P_{12}\Rightarrow B_{11}$（[1,2] 有 pit 就会让 [1,1] 有 breeze）；$\lnot B_{11}$ 是 goal clause；$\lnot B_{11}\lor P_{12}\lor P_{21}$ 有两个 positive literal，不是 Horn。“有 breeze 就说明某个邻居有 pit”这个方向的规则天生是 disjunction，Horn 写不下。

两个 Horn clause resolve，结果还是 Horn：第一个 clause 唯一的 positive literal $p$ 被消掉，resolvent 的 positive literal 只能来自第二个 clause，而它至多一个。所以 Horn clause 的世界在 resolution 下是封闭的，resolvent 不会变成长长的 disjunction。

### Forward chaining

对一个只含 definite clause 的 KB，回答“某个 symbol $q$ 是否 entailed”只要反复用 modus ponens。CS188 的例子，KB 有 6 个 clause，query 是 $Q$：

| ① | ② | ③ | ④ | ⑤ | ⑥ |
|---|---|---|---|---|---|
| $A\Rightarrow B$ | $A\Rightarrow C$ | $B\land C\Rightarrow D$ | $D\land E\Rightarrow Q$ | $A\land D\Rightarrow Q$ | $A$ |

做法是给每个 clause 记一个 count：它的 premise 里还有几个 symbol 没被确认为 true。Agenda 里放已确认为 true、但还没往下传的 symbol。

1. 初始：count 是各 clause 的 premise 个数 $[1,1,2,2,2,0]$；agenda 里放所有 fact，这里只有 $A$。
2. 从 agenda 取出一个 symbol $p$。如果 $p$ 就是 $q$，结束，$q$ 得证。
3. 如果 $p$ 已经处理过，跳过；否则把它标为 true，并对每个 premise 含 $p$ 的 clause，count 减 1；减到 0 的 clause，把它的 conclusion 放进 agenda。
4. Agenda 空了还没取到 $q$，就是 $q$ 不被 entailed。

::fig[cs3263-fc] 动图。圆是 symbol，方框是 clause，方框里的数是 count。静止时是最后的状态：$A$、$B$、$C$、$D$、$Q$ 都被推出，④ 的 count 停在 1，因为 $E$ 从来没有成立。

逐步核对：取出 $A$，① ② ⑤ 各减 1，变成 $[0,0,2,2,1,0]$，①② 归零，$B$、$C$ 进 agenda。取出 $B$，③ 变 1。取出 $C$，③ 归零，$D$ 进 agenda。取出 $D$，④ 变 1、⑤ 归零，$Q$ 进 agenda。取出 $Q$，得证。

每一步都是 modus ponens，所以 sound。它也 complete（对 definite KB 和单个 symbol 的 query），proof 很短。Agenda 空了之后，把推出过的 symbol 设为 T、其余设为 F，得到一个 model $m$。KB 里每个 clause 在 $m$ 里都成立：如果某个 clause 的 premise 在 $m$ 里全是 T，它们都被推出过，count 早就减到 0，conclusion 也被推出、在 $m$ 里是 T；如果 premise 里有 F，clause 自动为 T。所以 $m$ 是 KB 的一个 model。若 $\mathrm{KB}\models q$，$q$ 在 KB 的每个 model 里都是 T，包括 $m$，也就是说 $q$ 被推出过。拿例子核对：$m$ 让 $A$、$B$、$C$、$D$、$Q$ 为 T，$E$ 为 F；④ 的 premise $D\land E$ 是 F，clause 成立，其余五个的 premise 和 conclusion 都是 T。

时间是 linear 的：每个 symbol 至多被处理一次，处理时对每个含它的 premise 做一次减法，总的减法次数不超过 KB 里 premise 出现的总次数。和第 2 站对照：resolution 每步可能产生含很多 symbol 的 clause，这里每步只产生一个 symbol，而 symbol 只有 $n$ 个。

:::wrong Forward chaining 没推出 $E$，所以 $E$ 是 false
没推出只说明 $\mathrm{KB}\not\models E$。把上面的 $m$ 改成 $E$ 也为 T，得到 $m'$：① 到 ③、⑤、⑥ 和原来一样成立，④ 的 premise $D\land E$ 变成 T，conclusion $Q$ 也是 T，仍然成立。$m$ 和 $m'$ 都是 KB 的 model，$E$ 在一个里 F、一个里 T，KB 对 $E$ 不置可否。Forward chaining 给出的 $m$ 只是“推出的最少”的那个 model。Prolog 一类系统把推不出的当作 false，这是额外加的 closed-world assumption，不是 entailment。
:::

### Backward chaining

Forward chaining 会推出所有能推出的东西，哪怕和 query 无关。KB 里如果还有一千条由 $A$ 触发、和 $Q$ 毫无关系的 rule，它们都会被跑一遍。Backward chaining 从 query 出发往回找：要证 $Q$，就找 conclusion 是 $Q$ 的 clause，转而去证它的 premise。

::fig[cs3263-bc] 同一个 KB 的 backward chaining。方框之间是 OR（能推出 $Q$ 的 clause 有两个，一个成功就够），方框到圆之间是 AND（premise 要全部成立）。

走一遍：$Q$ 可以由 ④ 或 ⑤ 推出。先试 ④，要证 $D$ 和 $E$。$D$ 只能由 ③ 推出，要证 $B$ 和 $C$；$B$ 由 ①，要 $A$，是 fact；$C$ 由 ②，也要 $A$。所以 $D$ 成立。$E$ 既不是 fact，也没有 clause 以它为 conclusion，失败，④ 失败。换 ⑤：$A$ 是 fact，$D$ 刚才已经证过，记下来直接用。$Q$ 得证。

两点细节。证过的 goal 要记下来（上图右下的 $D$），否则同一个 subgoal 会被反复证。正在证的 goal 如果在自己的 subgoal 里又出现（比如 KB 里同时有 $P\Rightarrow R$ 和 $R\Rightarrow P$），这一支要直接判失败，否则会无限递归。

MIT 6.034 第 3 讲指出了这棵 AND-OR tree 的另一个用处：它就是系统做 inference 的完整记录。问“为什么要去查 $B$”，往上走一层回答“为了用 ③ 证 $D$”；问“$Q$ 是怎么知道的”，往下走一层回答“由 ⑤，$A$ 是 fact、$D$ 由 ③ 得到”。早期的 rule-based expert system（例如诊断 blood infection 的 MYCIN）就是靠这棵 tree 解释自己的结论。

:::exam AY23/24 midterm 第 5 题
一个 Magical Garden 的 KB，8 个 symbol：A（Apple tree blooms）、B（Butterfly visits）、C（Caterpillar emerges）、D（Dew falls）、E（Elf sings）、F（Flowers open）、G（Garden glows）、H（Honey is made）。规则按题目的编号：

| 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|
| $B\land C\Rightarrow A$ | $E\land F\Rightarrow A$ | $D\Rightarrow B$ | $F\land H\Rightarrow B$ | $E\Rightarrow C$ | $H\Rightarrow D$ | $G\Rightarrow F$ | $C\Rightarrow G$ | $E$（fact） |

全部是 definite clause，所以本站的两个算法都 complete。

**Forward chaining。** 初始 count 是 $[2,2,1,2,1,1,1,1]$（规则 1 到 8），agenda 是 $[E]$。取出 $E$：规则 2 变 1，规则 5 变 0，$C$ 进 agenda。取出 $C$：规则 1 变 1，规则 8 变 0，$G$ 进。取出 $G$：规则 7 变 0，$F$ 进。取出 $F$：规则 2 变 0，$A$ 进；规则 4 变 1。取出 $A$，得证。用到的规则依次是 9、5、8、7、2，和答案一致。

**Backward chaining，从规则 2 开始。** 要证 $A$，用规则 2，subgoal 是 $E$ 和 $F$。$E$ 由 fact 9 得到。$F$ 只有规则 7 能推出，要证 $G$；$G$ 只有规则 8，要证 $C$；$C$ 只有规则 5，要证 $E$，刚才已经证过，直接用。于是依次是 2、9、7、8、5，最后规则 2 成立，答案是 2, 9, 7, 8, 5, 2。选项里的 2, 9, 5, 8, 7, 2 是把 subgoal 的顺序倒过来了：backward chaining 是从 $F$ 往回找到 $C$，不是从 $C$ 往前推到 $F$。

**哪些是 KB 的 model。** (i) A、C、E、F、G 为 T，B、D、H 为 F：逐条检查，规则 1、3、4、6 的 premise 含 F 值，自动成立；规则 2、5、7、8 的 premise 和 conclusion 都是 T；fact $E$ 是 T。是 model。(ii) A 为 F、其余为 T：规则 2 的 premise $E\land F$ 是 T 而 $A$ 是 F，违反。(iii) 全 T：每条 clause 的 conclusion 都是 T，是 model。(iv) 全 F：违反 fact $E$。答案是 i 和 iii。

**$B$ 是否 entailed。** No。(i) 是一个 $B$ 为 F 的 model，这就够了。它正是 forward chaining 跑完之后“推出的设为 T、其余设为 F”得到的那个 model $m$，和本站“Forward chaining 没推出 $E$”那一条一样：forward chaining 没推出 $B$，KB 就不 entail $B$。（$A$ 在这个 KB 的 4 个 model 里都是 T，$B$ 在其中 3 个里是 T、1 个里是 F，枚举 $2^8$ 个 assignment 核对过。）
:::

### Propositional logic 写不下的规则

前面的 symbol 都是不可再分的。一旦规则涉及“所有学生”“任何一门课”，propositional logic 只能一个个对象写一遍。CS221 的例子：“学生修了一门课，这门课讲某个 concept，学生就会这个 concept”。如果有 alice、bob 两个学生，cs221 一门课，mdp、logic 两个 concept，要写成

$$\mathrm{Takes}_{\text{alice},\text{cs221}}\land\mathrm{Covers}_{\text{cs221},\text{mdp}}\Rightarrow\mathrm{Knows}_{\text{alice},\text{mdp}}$$

这样的 clause，每个（学生，课，concept）组合一条。

First-order logic 加了两样东西。一是 object 和 predicate：$\mathrm{Takes}(\text{alice},\text{cs221})$ 是 predicate Takes 作用在两个 term 上，term 可以是 constant（alice）、variable（$x$）或 function（$\mathrm{Sum}(3,x)$）。二是 quantifier：

$$\forall x\,\forall y\,\forall z\ \big(\mathrm{Takes}(x,y)\land\mathrm{Covers}(y,z)\big)\Rightarrow\mathrm{Knows}(x,z)$$

$\forall x\,P(x)$ 像是 $P(A)\land P(B)\land\cdots$，$\exists x\,P(x)$ 像是 $P(A)\lor P(B)\lor\cdots$。英语翻译时有一个固定的配对：“every student knows arithmetic” 是 $\forall x\ \mathrm{Student}(x)\Rightarrow\mathrm{Knows}(x,\text{arithmetic})$，用 $\Rightarrow$；“some student knows arithmetic” 是 $\exists x\ \mathrm{Student}(x)\land\mathrm{Knows}(x,\text{arithmetic})$，用 $\land$。把第二句写成 $\exists x\ \mathrm{Student}(x)\Rightarrow\cdots$ 是常见错误：只要有一个不是学生的 object，$\Rightarrow$ 的 premise 就是 false，整句自动成立，什么也没说。

如果每个 object 都恰好有一个 constant 的名字（unique names 与 domain closure 两个假设），first-order sentence 可以展开回 propositional：把每个 variable 换成每个 constant。上面那条规则有 3 个 variable，5 个 constant（alice、bob、cs221、mdp、logic），展开成 $5^3=125$ 条 propositional definite clause，其中绝大多数（例如 $\mathrm{Takes}(\text{mdp},\text{alice})$ 开头的）毫无意义。展开总是可行的，代价是规模随 constant 个数的 variable 个数次方增长。

### Unification 与 generalized modus ponens

直接在 first-order 的层面做 modus ponens，会遇到一个形式上的障碍：KB 里有 $\mathrm{Takes}(\text{alice},\text{cs221})$，rule 的 premise 是 $\mathrm{Takes}(x,y)$，两者字面上不一样，rule 是只看形状的 pattern matching，认不出它们能对上。需要先找一个 substitution $\theta$（把 variable 换成 term 的对应表）让两者相同。

$\mathrm{Unify}(f,g)$ 返回最一般的 $\theta$，使 $\mathrm{Subst}(\theta,f)=\mathrm{Subst}(\theta,g)$，找不到就 fail。CS221 的几个例子：

| $f$ | $g$ | $\mathrm{Unify}(f,g)$ |
|---|---|---|
| $\mathrm{Knows}(\text{alice},\text{arithmetic})$ | $\mathrm{Knows}(x,\text{arithmetic})$ | $\{x/\text{alice}\}$ |
| $\mathrm{Knows}(\text{alice},y)$ | $\mathrm{Knows}(x,z)$ | $\{x/\text{alice},\ y/z\}$ |
| $\mathrm{Knows}(\text{alice},y)$ | $\mathrm{Knows}(\text{bob},z)$ | fail（alice 和 bob 是不同的 constant） |
| $\mathrm{Knows}(\text{alice},y)$ | $\mathrm{Knows}(x,F(x))$ | $\{x/\text{alice},\ y/F(\text{alice})\}$ |

最后一行要注意顺序：先由第一个 argument 得到 $x/\text{alice}$，第二个 argument 的 $F(x)$ 随之成为 $F(\text{alice})$。

Generalized modus ponens：有 fact $a_1',\dots,a_k'$ 和 rule $\forall\cdots(a_1\land\cdots\land a_k)\Rightarrow b$，若 $\theta=\mathrm{Unify}(a_1'\land\cdots\land a_k',\ a_1\land\cdots\land a_k)$ 存在，就推出 $\mathrm{Subst}(\theta,b)$。

用它跑 forward chaining。Fact 是 $\mathrm{Takes}(\text{alice},\text{cs221})$、$\mathrm{Takes}(\text{bob},\text{cs221})$、$\mathrm{Covers}(\text{cs221},\text{mdp})$、$\mathrm{Covers}(\text{cs221},\text{logic})$，rule 是上面那条。

1. 第一个 premise $\mathrm{Takes}(x,y)$ 和 $\mathrm{Takes}(\text{alice},\text{cs221})$ unify，得 $\{x/\text{alice},y/\text{cs221}\}$。
2. 代入后第二个 premise 成了 $\mathrm{Covers}(\text{cs221},z)$，和 $\mathrm{Covers}(\text{cs221},\text{mdp})$ unify，再加 $z/\text{mdp}$；conclusion 是 $\mathrm{Knows}(\text{alice},\text{mdp})$。
3. 第二个 premise 改用 $\mathrm{Covers}(\text{cs221},\text{logic})$，得 $\mathrm{Knows}(\text{alice},\text{logic})$。
4. 第一个 premise 改用 bob 那条，同样得到 $\mathrm{Knows}(\text{bob},\text{mdp})$、$\mathrm{Knows}(\text{bob},\text{logic})$。

一共只试了 2 × 2 种组合，推出 4 个 fact；展开成 propositional 要面对 125 条 clause。

代价是 decidability。没有 function symbol 时，能推出的 atomic sentence 有限（不超过 constant 个数的 predicate arity 次方），forward chaining 一定停。有了 function symbol，$Q(a)$、$Q(F(a))$、$Q(F(F(a)))\dots$ 可以无穷无尽。CS221 总结为：first-order logic 哪怕只用 Horn clause，也只是 semi-decidable，$\mathrm{KB}\models f$ 时一定能在有限步内证出来，$\mathrm{KB}\not\models f$ 时可能永远停不下来。

## [csp] Constraint satisfaction：backtracking、arc consistency 与 structure

:::skip
能把一个问题写成 variable、domain、constraint，手跑 forward checking 和 AC-3，用 MRV 选 variable、用 LCV 选 value，并知道 tree-structured CSP 为什么能 linear 地解，就可以去第 5 站。
:::

### 把问题写成 variable、domain、constraint

给 Australia 的 7 个 region 涂红、绿、蓝（记 R、G、B），相邻的不能同色。

::fig[cs3263-map] 左边是示意的地图，右边把它抽象成 constraint graph：每个 region 一个 node，相邻就连一条 edge。

写成 constraint satisfaction problem（CSP）有三样东西：

- **Variable：** WA、NT、SA、Q、NSW、V、T。
- **Domain：** 每个 variable 都是 {R, G, B}。
- **Constraint：** 9 对相邻的 region 各一条，WA ≠ NT、WA ≠ SA、NT ≠ SA、NT ≠ Q、SA ≠ Q、SA ≠ NSW、SA ≠ V、Q ≠ NSW、NSW ≠ V。

所有 complete assignment 有 $3^7=2187$ 个，满足全部 constraint 的有多少？SA 和五个 region 相邻，先给它 3 种选择；剩下的 WA、NT、Q、NSW、V 沿着 WA–NT–Q–NSW–V 连成一条 path（WA 和 V 不相邻），每个都不能用 SA 的颜色，只剩两种，相邻的又要不同，只能交替，2 种；T 和谁都不相邻，3 种。一共 $3\times2\times3=18$ 个 solution。

CSP 和 [CS2109S 第 1 站](CS2109S.html#search) 的 search problem 不同的地方是：只要终点，不要 path；而且 assignment 的先后不影响结果（先 WA = R 再 NT = G，和反过来，是同一个 assignment）。所以可以固定 variable 的顺序，每层只给一个 variable 赋值，一个 constraint 的两端都赋了值就立刻检查，违反就退回。这叫 backtracking search。

### Backtracking 发现错误太晚

设已经赋了 WA = R、Q = G。两者不相邻，没有违反任何 constraint，但这个 partial assignment 已经注定失败：NT 同时和 WA、Q 相邻，只能是 B；SA 也同时和它们相邻，也只能是 B；而 NT 和 SA 相邻。

如果后面的顺序恰好是 T、V、NSW、NT、SA，backtracking 要一直走到 NT、SA 才撞墙，撞墙之后退回去改 NSW、V、T 的值，每改一次又重走一遍。实际数一下：在 WA = R、Q = G 之下穷尽这棵树，一共试了 111 次 value，才确定这个 partial assignment 没救。T 的 3 个值每个都把下面整棵树重走一遍，而 T 和问题毫无关系。

MIT 6.034 第 8 讲的开场是同一件事的放大版：给美国地图涂四色，如果先涂了 Texas 周围的 Arizona、Oklahoma、Arkansas、Louisiana，而且四个州用光了四种颜色，冲突在第 4 次选择时就已经造成，却要到第 48 个州左右轮到 Texas 时才发现。

### Forward checking

改进的第一步：每赋一个值，就把和它冲突的值从相邻的、未赋值的 variable 的 domain 里删掉。如果某个 domain 被删空，立刻退回。这叫 forward checking。

在例子上：WA = R 之后，NT、SA 的 domain 变成 {G, B}；Q = G 之后，NT、SA 都只剩 {B}，NSW 变成 {R, B}。没有哪个 domain 是空的，forward checking 不报错。它要等到 NT 被赋成 B，从 SA 里删掉 B、SA 变空时才发现。同样的顺序 T、V、NSW、NT、SA，试了 24 次 value，比 111 次少，但仍然先在 T、V、NSW 上白忙。

问题在于 forward checking 只看“刚赋值的 variable”和它的邻居，NT 和 SA 两个都还没赋值，它们之间的 constraint 没人检查。

### Arc consistency 与 AC-3

把每条 constraint 拆成两个方向的 arc。Arc $X\to Y$ 是 consistent 的，意思是：$X$ 的 domain 里每个值，在 $Y$ 的 domain 里都至少有一个值和它不冲突。不满足的值从 $X$ 的 domain 里删掉，因为 $X$ 取它时 $Y$ 无路可走。

删掉 $X$ 的一个值之后，之前检查过的 arc $Z\to X$ 可能不再 consistent（$Z$ 的某个值也许正靠刚删的那个值支撑），所以要把指向 $X$ 的 arc 重新放回 queue。这就是 AC-3：

1. 把所有 arc 放进一个 queue。
2. 取出一个 arc $X_i\to X_j$，删掉 $X_i$ 里在 $X_j$ 中找不到相容值的值。
3. 如果删了值，把所有 $X_k\to X_i$（$X_k$ 未赋值）中不在 queue 里的补进去。
4. Queue 空了就停；某个 domain 空了就说明当前 partial assignment 失败，要 backtrack。

在 WA = R、Q = G 做完 forward checking 的状态上跑 AC-3，queue 的初始顺序照 CS188 的例子：

::fig[cs3263-ac3] 动图。每个方框里是这个 region 当前的 domain，正在检查的 arc 用粗箭头标出，最下面一行是做完这一步之后的 queue。静止时是最后的状态：SA 的 domain 空了。

五步是：SA → V，SA 的 B 在 V 里有 R、G 可配，不删；V → SA，V 取 B 时 SA 无路可走，删掉 V 的 B，并把 SA → V 补回 queue；SA → NSW 不删；NSW → SA，删掉 NSW 的 B，NSW 只剩 R；SA → NT，SA 唯一的 B 在 NT（只剩 B）里找不到不同的值，SA 变空。还没有给第三个 variable 赋值，就知道 WA = R、Q = G 要撤回。

AC-3 要多久：设一共 $e$ 个 arc，domain 最大是 $d$。一个 arc $X_k\to X_i$ 只有在 $X_i$ 删掉一个值时才会重新入 queue，$X_i$ 最多删 $d$ 次，所以每个 arc 最多入 queue $d+1$ 次（包括最开始那次）；每次检查要比较 $X_k$ 的每个值和 $X_i$ 的每个值，$d^2$ 次。合起来是 $O(e\cdot d\cdot d^2)=O(ed^3)$。Australia 有 9 条 constraint、18 个 arc，$d=3$，$ed^3=18\times27=486$，远少于穷举。

Arc consistency 比 forward checking 删得多，回退少，但 search tree 的每个 node 上花的计算也多。值不值，要看问题；CS188 的建议是两者都列入选项，按问题取舍。

:::wrong 做完 arc consistency 每个 domain 都非空，就一定有 solution
只用两种颜色 R、G 给 WA、NT、SA 涂色，三者两两相邻。每个 arc 都 consistent：WA 取 R，NT 有 G 可配；取 G，NT 有 R。所有 domain 都还是 {R, G}。可是三个两两不同的值不可能从两种颜色里选出来，没有 solution。Arc consistency 一次只看一条 constraint，看不出三条 constraint 合起来的矛盾。更强的 k-consistency（任意 $k-1$ 个 variable 的相容 assignment 都能扩展到第 $k$ 个）能看出更多，arc consistency 就是 2-consistency，但越高越贵。
:::

:::exam AY23/24 midterm 第 6 题 (a)
$X\in\{1,\dots,6\}$，$Y\in\{1,3,7\}$，constraint 是 $X<Y$ 和 $X+Y>9$，问只对 arc $X\to Y$ 做 arc consistency 之后两个 domain 剩什么。按定义，对 $X$ 的每个值找 $Y$ 里能同时满足两条的值。按 $y$ 逐个看：$y=3$ 要 $x<3$ 且 $x>6$，没有；$y=1$ 同样没有；$y=7$ 要 $x<7$ 且 $x>2$，即 $x\in\{3,4,5,6\}$。所以 $X$ 剩 $\{3,4,5,6\}$，$Y$ 仍是 $\{1,3,7\}$：arc $X\to Y$ 只删 $X$ 的值。再做 $Y\to X$ 才会把 $Y$ 缩到 $\{7\}$，题目没有要。同一份卷子第 1 题问 Australia 的 NT = Red、NSW = Red 是否 consistent，答案是 True：两者不相邻，没有违反任何 constraint，而且还能完成（例如 SA = G、Q = B、WA = B、V = B）。
:::

### 先赋哪个 variable，先试哪个 value

**Minimum remaining values（MRV）：** 下一个赋值的 variable，选 domain 里剩下的值最少的那个。在 forward checking 之后的状态里，NT 和 SA 都只剩 1 个值，MRV 选 NT，赋 B，SA 立刻被删空：只试 1 次 value 就发现失败（对比前面同样做 forward checking、但顺序是 T、V、NSW、NT、SA 时的 24 次）。理由是：每个 variable 迟早要赋值，最可能失败的先赋，失败来得最早，剪掉的树最大。

Winston 在 6.034 第 8 讲里把这些办法放在美国地图上实测过：只检查刚赋值的 variable 的邻居时，撞了大约九千次 dead end；沿着 domain 缩到只剩一个值的 variable 继续 propagate，dead end 只剩几次，constraint check 不到一千次。他还指出，按 most constrained first 排顺序之后，连普通的 depth-first search 都够用，并称之为这一领域的 “dirty little secret”。

**Least constraining value（LCV）：** 选好 variable 之后，先试那个从邻居 domain 里删掉值最少的 value。设 WA = R 已赋，下一个是 Q。此时 NT、SA 是 {G, B}，NSW 是 {R, G, B}：

| Q 取 | NT 删掉 | SA 删掉 | NSW 删掉 | 一共 |
|---|---|---|---|---|
| R | 无 | 无 | R | 1 |
| G | G | G | G | 3 |
| B | B | B | B | 3 |

LCV 先试 Q = R，而 Q = G 正是上面那个注定失败的选择。WA = R、Q = R 可以完成（例如 NT = G、SA = B、NSW = G、V = R、T = R）。

两条 heuristic 方向相反并不矛盾：variable 是每个都必须赋的，所以先挑最难的、早点失败；value 只需要挑出一个能成功的，所以先挑最不碍事的。

### Tree-structured CSP 与 cutset conditioning

如果 constraint graph 没有 cycle（是一棵 tree），CSP 可以不用 backtracking，在 $O(nd^2)$ 时间内解出来，$n$ 是 variable 个数：

1. 任选一个 node 做 root，按 parent 在前、child 在后排成 $X_1,\dots,X_n$。
2. Backward pass：$i$ 从 $n$ 到 2，对 arc $\mathrm{Parent}(X_i)\to X_i$ 做一次 arc consistency。
3. Forward assignment：$X_1$ 随便取一个剩下的值；之后每个 $X_i$ 取一个和 parent 的值相容的值。

第 3 步不会卡住：parent 的每个剩下的值，在第 2 步时都确认过 child 里有相容的值；而 child 只和 parent 有 constraint（tree 里每个 node 只有一个 parent），不会被别的已赋值的 variable 挡住。第 2 步做 $n-1$ 次 arc consistency，每次 $d^2$，所以是 $O(nd^2)$，和 $n$ 成 linear，对比 $O(d^n)$。

Australia 的 graph 不是 tree，问题出在 SA：去掉 SA，剩下 WA–NT–Q–NSW–V 一条 path，加上孤立的 T。Cutset conditioning 就是：给 SA（cutset）赋一个值，从邻居 domain 里删掉它，剩下的用 tree algorithm 解；不行就换 SA 的值。

走一遍：SA = B。WA、NT、Q、NSW、V 的 domain 都变成 {R, G}，T 仍是 {R, G, B}。以 WA 为 root，顺序 WA、NT、Q、NSW、V。Backward pass 依次检查 NSW → V、Q → NSW、NT → Q、WA → NT：每个 parent 的 R 在 child 里有 G 相容，G 有 R 相容，什么都不删。Forward：WA = R，NT 取和 R 不同的 G，Q = R，NSW = G，V = R；T 随便取 R。九条 constraint 逐条检查都满足。

大小为 $c$ 的 cutset，要试 $d^c$ 种赋值，每种花 $O((n-c)d^2)$，合起来 $O(d^c(n-c)d^2)$。这里 $c=1$：$3\times6\times9=162$，对比 $3^7=2187$。

:::back
Backtracking 是 [CS2109S 第 1 站](CS2109S.html#search) 的 depth-first search 加上“立刻检查 constraint”。第 2 站的 DPLL 是同一个 algorithm 在 {T, F} 上的版本，它的 unit clause 规则就是 MRV 在 domain 只剩一个值时的特例。
:::

:::from
CSP 的三要素、Australia 的例子、forward checking 在 WA = red、Q = green 后的状态、arc 的定义、AC-3 的四步和那个 8 个 arc 的 queue、$O(ed^3)$、k-consistency、MRV 与 LCV 的理由、tree-structured algorithm 的 backward pass 与 forward assignment、以 SA 为 cutset 和 $O(d^c(n-c)d^2)$，跟的是 [CS188 textbook 2.3](https://inst.eecs.berkeley.edu/~cs188/textbook/csp/filtering.html)、[2.4](https://inst.eecs.berkeley.edu/~cs188/textbook/csp/ordering.html) 和 [Fa22 Note 3](https://inst.eecs.berkeley.edu/~cs188/fa22/assets/notes/cs188-fa22-note03.pdf)（它们陈述了 $O(ed^3)$ 但没有推导，也没有给 LCV、cutset 的数值例子）。Texas 的例子、几种 propagate 范围的实测对比和 most constrained first，来自 [MIT 6.034 第 8 讲](https://ocw.mit.edu/courses/6-034-artificial-intelligence-fall-2010/resources/lecture-8-constraints-search-domain-reduction/index.html) 的 transcript，其中的计数是 Winston 课上报的，transcript 里有几处自相矛盾，这里只取量级。18 个 solution 的数法、111/24/1 次的计数、$O(ed^3)$ 的推导、LCV 的表、三色变两色的反例、SA = B 之后的完整求解是为这一页写和算的。

## [bn] Bayesian network 与 conditional independence

:::skip
能从一个 Bayesian network 写出 joint 的 factorization、算出某个 full assignment 的 probability，并用三种 triple 和 d-separation 判断两个 variable 在给定 evidence 时是否 independent，就可以去第 6 站。
:::

### Joint table 存不下

五个 binary random variable：Burglary（$B$）、Earthquake（$E$）、Alarm（$A$）、JohnCalls（$J$）、MaryCalls（$M$）。被盗或地震会让 alarm 响，John 和 Mary 听到 alarm 会打电话，但 John 偶尔把电话铃当成 alarm，Mary 戴着耳机常常听不到。

所有问题的答案都在 joint distribution $P(B,E,A,J,M)$ 里。比如两个人都打来电话，被盗的 probability 是

$$P(+b\mid+j,+m)=\frac{P(+b,+j,+m)}{P(+j,+m)}=\frac{\sum_e\sum_aP(+b,e,a,+j,+m)}{\sum_b\sum_e\sum_aP(b,e,a,+j,+m)}$$

（$+b$ 表示 $B$ 为 true，$\lnot b$ 表示 false；conditional probability 的计算见 [ST2131 第 2 站](ST2131.html#bayes)。）问题是这张 table：$2^5=32$ 格，加起来等于 1，所以要 31 个数。$n$ 个 binary variable 要 $2^n-1$ 个，$n=30$ 时是 1,073,741,823 个，存不下，也没有 data 能把每一个数估准。

### Chain rule 加上 conditional independence

先用 chain rule 把 joint 拆开，这一步没有任何假设：

$$P(B,E,A,J,M)=P(B)\,P(E\mid B)\,P(A\mid B,E)\,P(J\mid B,E,A)\,P(M\mid B,E,A,J)$$

数一下要几个数：$P(B)$ 1 个；$P(E\mid B)$ 对 $B$ 的两个值各 1 个，2 个；$P(A\mid B,E)$ 4 个；$P(J\mid B,E,A)$ 8 个；$P(M\mid B,E,A,J)$ 16 个。合计 $1+2+4+8+16=31$，一个没省。

省下来靠的是关于这个世界的判断：

- 地震和被盗互不相干：$P(E\mid B)=P(E)$。
- John 打不打电话只取决于 alarm 响没响，知道了 alarm，再知道是被盗还是地震引起的，对 John 没有额外影响：$P(J\mid B,E,A)=P(J\mid A)$。
- Mary 同理，而且和 John 打没打无关：$P(M\mid B,E,A,J)=P(M\mid A)$。

代进去：

$$P(B,E,A,J,M)=P(B)\,P(E)\,P(A\mid B,E)\,P(J\mid A)\,P(M\mid A)$$

需要的数是 $1+1+4+2+2=10$ 个。

把这件事画成图就是 Bayesian network：一个 directed acyclic graph，每个 node 一个 variable；每个 node 带一张 conditional probability table（CPT），给出 $P(X\mid\mathrm{Parents}(X))$。Joint 定义为所有 CPT 的乘积：

$$P(X_1,\dots,X_n)=\prod_{i=1}^nP\big(X_i\mid\mathrm{Parents}(X_i)\big)$$

::fig[cs3263-alarm] Alarm network 和它的 10 个数。每张 CPT 只写 $+x$ 那一行，$\lnot x$ 那一行是 1 减去它。

马上用一次。两人都打电话、alarm 响了、但既没被盗也没地震，probability 是

$$P(+j,+m,+a,\lnot b,\lnot e)=P(\lnot b)\,P(\lnot e)\,P(+a\mid\lnot b,\lnot e)\,P(+j\mid+a)\,P(+m\mid+a)=0.999\times0.998\times0.001\times0.90\times0.70=0.000628$$

五个数相乘，不需要任何 table lookup 之外的东西。

:::note NUS 的 Assignment 1 用的就是这张 network
AY24/25 第 2 学期 Assignment 1 Problem 2 的 `persy_net` 是 rover 版本的 alarm network：EquipmentFailure（$E$，0.001）和 SolarFlare（$S$，0.002）指向 AlertOfSensor（$A$，CPT 是 0.95、0.94、0.29、0.001），$A$ 指向 CommandSignal（0.90 / 0.05）和 DataTransmission（0.70 / 0.01）。数字和这里一模一样，只是 $B$、$E$、$J$、$M$ 换了名字。这个 assignment 后半部分的内容在[第 7 站](#learn)。
:::

这个乘积确实是一个合法的 distribution（非负、加起来是 1），CS221 给的理由是从 leaf 开始求和：$M$ 没有 child，$\sum_mP(m\mid A)=1$，它从和式里消失；然后 $J$ 也成了 leaf，同样消失；再对 $A$ 求和，$\sum_aP(a\mid B,E)=1$；最后剩下 $\sum_bP(b)\sum_eP(e)=1$。

一般地，每个 node 的 parent 不超过 $k$ 个时，CPT 一共最多 $n\cdot2^k$ 个数。$n=30$、$k=5$ 是 960 个，对比 joint table 的十亿个。

Graph 里的每个 node 满足：给定它的 parents，它和所有 non-descendant independent。上面的 chain rule 推导正是这样用的：按 parent 在前的顺序展开，每个 variable 的 conditioning set 里除了 parents 都是 non-descendant（$P(M\mid B,E,A,J)$ 里的 $J$ 不是 $M$ 的 ancestor，但是 non-descendant），全部可以删掉。

:::edge 同一个 joint，换一个 variable 顺序，network 会变大
按 $M,J,A,B,E$ 的顺序建 network：$M$ 没有 parent，1 个数；$J$ 和 $M$ dependent（都由 alarm 引起），要以 $M$ 为 parent，2 个；$A$ 要以 $J$、$M$ 为 parent，4 个；给定 $A$，$B$ 和 $J$、$M$ 无关，只以 $A$ 为 parent，2 个；$E$ 给定 $A$ 之后还和 $B$ dependent（下一节的 explaining away），要以 $A$、$B$ 为 parent，4 个。合计 13 个数，比 10 个多，而且 $P(A\mid J,M)$ 这样的数很难凭常识填。按“原因在前、结果在后”的顺序建，通常最小。
:::

### Graph 说了哪些 independence

两个 variable 在 graph 上有一条 path 连着，并不总是意味着 dependent，要看 path 上中间那个 node 的形状和它有没有被观测。三种基本形状都在 alarm network 里，中间都是 $A$。

::fig[cs3263-triples] 三种 triple。上排 $A$ 没有观测，下排 $A$ 已观测。每格下面的数都在 alarm network 上实际算出，用来检验图上的判断。

**Causal chain $B\to A\to J$。** 不知道 $A$ 时，$B$ 和 $J$ dependent：$P(+j\mid+b)=0.849$，而 $P(+j)=0.052$。前者这样算：$P(+a\mid+b)=0.002\times0.95+0.998\times0.94=0.94002$，$P(+j\mid+b)=0.94002\times0.90+0.05998\times0.05=0.849$。知道 $A$ 之后，$B$ 对 $J$ 再没有影响。CS188 的 proof，对一般的 chain $X\to Y\to Z$：

$$P(X\mid Z,y)=\frac{P(X,Z,y)}{P(Z,y)}=\frac{P(Z\mid y)\,P(y\mid X)\,P(X)}{P(Z\mid y)\sum_xP(y\mid x)\,P(x)}=\frac{P(y\mid X)\,P(X)}{\sum_xP(y\mid x)\,P(x)}=P(X\mid y)$$

$P(Z\mid y)$ 上下约掉，$Z$ 从式子里消失。

**Common cause $J\leftarrow A\to M$。** 不知道 $A$ 时，John 打来电话让 alarm 响的可能性变大，于是 Mary 也更可能打来：$P(+m\mid+j)=0.040$，$P(+m)=0.012$，相差三倍多。知道 $A$ 之后：

$$P(J\mid M,a)=\frac{P(J\mid a)\,P(M\mid a)\,P(a)}{P(M\mid a)\,P(a)}=P(J\mid a)$$

两人各自只对 alarm 反应，互不影响。

**Common effect $B\to A\leftarrow E$。** 这一种反过来。不知道 $A$ 时，$B$ 和 $E$ independent，这是建模时假设的：$P(+b\mid+e)=P(+b)=0.001$。知道 alarm 响了之后，它们变得 dependent。先算 alarm 响的 probability，四种 $(b,e)$ 组合加起来：

$$P(+a)=0.001\cdot0.002\cdot0.95+0.001\cdot0.998\cdot0.94+0.999\cdot0.002\cdot0.29+0.999\cdot0.998\cdot0.001=0.0025164$$

其中前两项是被盗的部分，合计 0.00094002，所以 $P(+b\mid+a)=0.00094002/0.0025164=0.374$。再加上“确实地震了”：

$$P(+b\mid+a,+e)=\frac{P(+b)\,P(+e)\,P(+a\mid+b,+e)}{\sum_bP(b)\,P(+e)\,P(+a\mid b,+e)}=\frac{0.001\times0.95}{0.001\times0.95+0.999\times0.29}=0.0033$$

$P(+e)$ 上下约掉了。被盗的 probability 从 0.374 掉到 0.0033：alarm 已经被地震解释了，被盗这个解释就不需要了。这叫 explaining away。CS221 用一个更干净的版本：$B$、$E$ 的 prior 都是 $\varepsilon$，alarm 恰好在两者有其一时响，则 $P(+b)=\varepsilon$，$P(+b\mid+a)=\dfrac{1}{2-\varepsilon}$，$P(+b\mid+a,+e)=\varepsilon$，同样先升后降。

把三种合起来，triple 是 active（让两端 dependent）还是 blocked：

| triple | 中间没观测 | 中间已观测 |
|---|---|---|
| causal chain $X\to Y\to Z$ | active | blocked |
| common cause $X\leftarrow Y\to Z$ | active | blocked |
| common effect $X\to Y\leftarrow Z$ | blocked | active |

Common effect 还有一条：中间的 $Y$ 本身没观测、但它的某个 descendant 被观测了，也算 active。观测到 descendant 等于拿到了关于 $Y$ 的一部分信息。

### D-separation

Graph 更大时，两个 variable 之间可能有好几条 path，每条 path 由一串 triple 接成。规则是：

1. 把观测到的 node 标出来。
2. 列出 $X$ 到 $Y$ 的每一条 path（不管 edge 方向）。
3. 一条 path 上每个相邻的 triple 都 active，这条 path 才 active。
4. 只要有一条 active path，$X$ 和 $Y$ 就不保证 independent；一条都没有，就说给定这些 evidence，$X$ 和 $Y$ 被 d-separate，$X\perp Y$。

Alarm network 上试三个：

- $B$ 和 $M$，给定 $A$：唯一的 path 是 $B\to A\to M$，一个 chain，中间观测了，blocked，所以 $B\perp M\mid A$。
- $E$ 和 $J$，什么都不观测：$E\to A\to J$ 是 chain，中间没观测，active，所以地震会让 John 更可能打电话。
- $B$ 和 $E$，给定 $J$：path $B\to A\leftarrow E$ 是 common effect，$A$ 没观测，但它的 descendant $J$ 观测了，active。用数字核对：$P(+b\mid+j)=0.0163$，$P(+b\mid+j,+e)=0.0029$，确实 dependent，方向也和 explaining away 一样。

:::wrong $B$ 和 $E$ 之间没有 edge，所以它们永远 independent
没有 edge 只说明两者之间没有“直接”的依赖，independence 要看所有 path 和当前观测到了什么。$B$ 和 $E$ 只在什么都不观测时 independent；一旦观测了 $A$ 或 $A$ 的任何 descendant（$J$ 或 $M$），它们就 dependent：上面的 $P(+b\mid+j)=0.0163$ 在得知地震后变成 0.0029。反过来，有 edge 也不保证 dependent，CPT 的数完全可以让 child 不依赖 parent；d-separation 说的是“图保证 independent”，不说“图保证 dependent”。
:::

:::from
“Chain rule 每一项只保留 parents”的推导、三种 triple 的 independence proof（上面的两条 formula 照 CS188 的写法）、d-separation 的四步、descendant 的规则，跟的是 [CS188 textbook 6.3](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/representation.html)、[6.4](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/structure.html)、[6.5](https://inst.eecs.berkeley.edu/~cs188/textbook/bayes-nets/d-separation.html)。6.4 说的是“给定 parents 与 ancestors independent”，但它推导里 $P(M\mid B,E,A,J)$ 的 $J$ 并不是 $M$ 的 ancestor，这里改用 non-descendant 的说法。定义、“从 leaf 求和”说明乘积合法、$\varepsilon$ 版的 explaining away，来自 Stanford CS221 [Bayesian networks: Definitions](https://stanford-cs221.github.io/autumn2023-extra/modules/bayesian-networks/definitions.pdf)。CPT 的数是 AIMA 第 14 章的经典数字，对照了 [aima-python](https://github.com/aimacode/aima-python) 的 `probability.py`（CS188 的这几节没有给数）；John、Mary 的人设是 AIMA 的，凭记忆。文中所有 probability、13 个数的那个顺序是为这一页算的。
:::

## [ve] Inference：variable elimination 与 sampling

:::skip
能用 factor 的 join 与 sum out 手算 variable elimination，说出 elimination order 怎样决定最大 factor 的大小，并知道 rejection sampling 和 likelihood weighting 各自浪费在哪里，就可以去第 7 站。
:::

### Enumeration 在重复算

有了 network，$P(B\mid+j,+m)$ 可以直接写成 CPT 的和：

$$P(B\mid+j,+m)=\alpha\sum_e\sum_aP(B)\,P(e)\,P(a\mid B,e)\,P(+j\mid a)\,P(+m\mid a)$$

$\alpha$ 是最后让两个值加起来为 1 的 normalizing constant。逐项相加叫 inference by enumeration：对 $B$ 的每个值，$(e,a)$ 有 4 种组合，每种是 5 个数相乘（4 次乘法），一共 16 次乘法、3 次加法；$B$ 两个值，32 次乘法。一般地，hidden variable（既不是 query 也不是 evidence）有 $h$ 个时，和式有 $2^h$ 项。

把不依赖求和 variable 的项提到外面：

$$P(B\mid+j,+m)=\alpha\,P(B)\sum_eP(e)\sum_aP(a\mid B,e)\,P(+j\mid a)\,P(+m\mid a)$$

看最里面：对 $(B,e)$ 的每一种组合都要算一遍 $\sum_a$，而每一遍里 $P(+j\mid a)P(+m\mid a)$（$+a$ 时 $0.90\times0.70=0.63$，$\lnot a$ 时 $0.05\times0.01=0.0005$）都是同样两个数。$B$、$e$ 两层循环让它被重算 4 次。网络再大，这种重复会层层叠加。办法是把中间结果存成 table。

### Factor：join 与 sum out

一张以若干 variable 为 index 的 table 叫 factor。CPT 是 factor；evidence 代进去之后，$P(+j\mid A)$ 是只以 $A$ 为 index 的 factor：$+a$ 时 0.90，$\lnot a$ 时 0.05。它的两个数加起来是 0.95，不等于 1：factor 不必 normalize。

两种操作：

- **Join：** 几个 factor 逐格相乘，结果的 index 是它们 variable 的并集。$P(A\mid B,E)\times P(+j\mid A)\times P(+m\mid A)$ 的 index 是 $A,B,E$，8 格，例如 $(+a,+b,+e)$ 那一格是 $0.95\times0.90\times0.70=0.5985$。
- **Sum out：** 对一个 variable 的所有值求和，把它从 index 里去掉。上面那个 factor 对 $A$ 求和，$(+b,+e)$ 那一格是 $0.5985+0.05\times0.05\times0.01=0.598525$，得到一个以 $B,E$ 为 index 的 factor。

Variable elimination 就是：按某个顺序取 hidden variable，每取一个，把所有含它的 factor join 起来，再把它 sum out；hidden variable 都消完之后，把剩下的 factor join 起来，normalize。

::fig[cs3263-ve] 动图，逐行出现。每一行左边是做完这一步之后的 factor 列表（实心是新产生的），右边是新 factor 的每一格怎么算。静止时是全部四行。

最后一行：$f_3(+b)=0.000592$、$f_3(\lnot b)=0.001492$。它们分别是 $P(+b,+j,+m)$ 和 $P(\lnot b,+j,+m)$，相加 $0.002084$ 正是 $P(+j,+m)$，normalize 之后

$$P(+b\mid+j,+m)=\frac{0.000592}{0.002084}=0.284$$

两个人都打来电话，被盗的 probability 也只有 28%。拆开 $\lnot b$ 那一项能看出原因：$0.001492$ 由三部分组成，有地震的情形（不论 alarm 响没响）约 0.000366，没有原因的 false alarm 引来电话 0.000628（就是第 5 站算过的那个数），alarm 根本没响、两人却都打来 0.000498（$0.999\times0.998\times0.999\times0.05\times0.01$）。被盗本身的 prior 只有 0.001，三条“无辜”的路加起来是它的 2.5 倍。

### Elimination order 决定 factor 多大

上面先消 $A$ 再消 $E$，产生的最大 factor 是 8 格（$A,B,E$）。顺序不同，最大 factor 可以差得很远。

::fig[cs3263-veorder] 一个 $Z$ 有 $n$ 个 child $X_1,\dots,X_n$，每个 $X_i$ 有一个观测到的 child $Y_i$。Query 是 $P(X_n\mid y_1,\dots,y_n)$，hidden variable 是 $Z$ 和 $X_1,\dots,X_{n-1}$。

**先消 $Z$：** 含 $Z$ 的 factor 是 $P(Z)$ 和全部 $n$ 个 $P(X_i\mid Z)$，join 之后 index 是 $Z,X_1,\dots,X_n$，$2^{n+1}$ 格；sum out $Z$ 还剩 $2^n$ 格。$n=10$ 时 join 出 2048 格。

**先消 $X_1,\dots,X_{n-1}$：** 含 $X_i$ 的只有 $P(X_i\mid Z)$ 和 $P(y_i\mid X_i)$，join 之后 index 是 $Z,X_i$，4 格；sum out $X_i$ 得 $f_i(Z)$，2 格。最后消 $Z$：join $P(Z)$、$f_1,\dots,f_{n-1}$、$P(X_n\mid Z)$、$P(y_n\mid X_n)$，index 只有 $Z,X_n$，4 格。

所以 variable elimination 的时间由最大的那个 factor 决定。找最好的顺序本身是 NP-hard，常用 greedy 的办法：每次消“消掉它产生的 factor 最小”的那个 variable。在这个例子里，消 $Z$ 会产生 $n+1$ 个 variable 的 factor，消任一个 $X_i$ 只产生 2 个 variable 的 factor，greedy 正好选出第二种顺序。

:::wrong Variable elimination 总比 enumeration 快
它只是把重复计算存起来，省多少取决于 factor 能不能保持小。上面先消 $Z$ 的顺序，join 出的 factor 有 $2^{n+1}$ 格，和 enumeration 要加的 $2^n$ 项是同一个量级，几乎没省。CS188 的原话大意就是：variable elimination 只有在能限制最大 factor 的大小时才比 enumeration 好。有些图无论什么顺序都会产生大 factor，这时就要换 approximate 的办法（本站最后）。
:::

:::exam AY22/23 midterm 第 1、2 题
第 1 题：variable elimination 产生的 factor 至多是原 network 里最大 CPT 的两倍大。False。上面先消 $Z$ 的顺序就是反例：最大的 CPT 是 $P(X_i\mid Z)$，4 格，join 出的 factor 有 $2^{n+1}$ 格，$n=10$ 时是 2048 格，是 4 的 512 倍。第 2 题：elimination 的顺序不影响最后的答案。True，solution 的理由是这个 algorithm 总是 sound 的：每一步 join 和 sum out 都是对同一个和式的等价变形，顺序只改变中间 factor 的大小，也就是计算量。
:::

### 和 query 无关的 variable

问被盗时 John 打电话的 probability $P(+j\mid+b)$。照公式要对 $E$、$A$、$M$ 求和，但 $M$ 是 leaf，既不是 query 也不是 evidence：

$$\sum_mP(m\mid a)=1$$

它对任何 $a$ 都是 1，直接从和式里消失。于是 $P(+j\mid+b)=\sum_e\sum_aP(e)\,P(a\mid+b,e)\,P(+j\mid a)$，先对 $e$ 求和得 $P(+a\mid+b)=0.94002$，再得 $0.94002\times0.90+0.05998\times0.05=0.849$，和第 5 站一致。一般地，既不是 query、evidence 的 ancestor，也不是它们本身的 variable，都可以在开始前删掉。

### 精确算不动时：sampling

最大 factor 太大时，退一步，用 sample 估计。最直接的是 prior sampling：按 parent 在前的顺序，从每个 CPT 抽一个值（先抽 $B$，再抽 $E$，再按抽到的 $B,E$ 从 $P(A\mid B,E)$ 抽 $A$，以此类推），一个 sample 出现的 probability 恰好是 joint。估计 $P(+b\mid+j,+m)$，就只留下 $J$、$M$ 都是 true 的 sample，数其中 $B$ 为 true 的比例。这叫 rejection sampling。

它的浪费一眼可见：$P(+j,+m)=0.002084$，抽 10000 个 sample 平均只留下约 21 个。重复 200 次（互相 independent）、每次 10000 个，留下的平均 21.4 个，估计值的 standard deviation 是 0.095，而真值才 0.284。

Likelihood weighting 不再抽 evidence variable，直接把它们设成观测到的值，代价是给每个 sample 一个 weight：

$$w=\prod_{\text{evidence }E_j}P\big(e_j\mid\mathrm{Parents}(E_j)\big)$$

在 alarm network 上，抽 $B$、$E$、$A$，把 $J$、$M$ 固定为 true，weight 是 $P(+j\mid a)P(+m\mid a)$：抽到 $+a$ 时 0.63，$\lnot a$ 时 0.0005。估计值是 $B$ 为 true 的 sample 的 weight 之和除以全部 weight 之和。

为什么要乘这个 weight：固定了 evidence 之后，一个 sample $(z,e)$ 被抽到的 probability 只含 non-evidence variable 的 CPT，$S(z,e)=\prod_iP(z_i\mid\mathrm{Parents}(Z_i))$，少了 evidence 的那几个 CPT。乘上 weight 正好补齐：

$$S(z,e)\,w(z,e)=\prod_iP\big(z_i\mid\mathrm{Parents}(Z_i)\big)\prod_jP\big(e_j\mid\mathrm{Parents}(E_j)\big)=P(z,e)$$

所以 weighted count 的 expectation 和 $P(z,e)$ 成正比，sample 越多，比值越接近 $P(z\mid e)$。

同样 200 次、每次 10000 个，likelihood weighting 的 standard deviation 是 0.075，比 0.095 好，但好得有限。原因在 weight 的分布：$B$ 和 $A$ 仍然是从 prior 抽的，完全没理会“两人都打了电话”。10000 个 sample 里 $A$ 为 true 的平均只有 $10000\times0.0025=25$ 个左右，它们每个 weight 0.63，合计约 15.9；其余近一万个 sample 每个 0.0005，合计约 5.0。估计值实际上由二十几个 sample 决定，其中 $B$ 为 true 的只有约 10 个。Evidence 在 network 的下游时，likelihood weighting 仍然浪费；Gibbs sampling 一类方法让每个 variable 根据它周围所有 variable 的当前值反复重抽，可以绕开这一点，这一页不展开。

:::edge Factor 不是 probability distribution
中间产生的 factor（例如 $f_1(B,E)$ 的四个数 0.5985、0.5922、0.1831、0.00113）加起来不是 1，也不必是。$f_1(+b,+e)$ 的意思是 $P(+j,+m\mid+b,+e)$，是一个 likelihood。只有最后一步 normalize 之后才是 distribution。所以中途不必 normalize，normalize 只做一次。
:::

三种 triple 和 network 的 factorization 在[第 5 站](#bn)。用 sample 估 expectation、variance 随 sample 数下降的道理在 [ST2131 第 7 站](ST2131.html#limit)。
:::

## [learn] Parameter learning 与 naive Bayes

:::skip
能用 count 写出 CPT 的 maximum likelihood estimate 并说清它为什么能一张 CPT 一张 CPT 地分开估，会用 pseudo-count 做 smoothing，能写出 naive Bayes 的 factorization 并用它分类，并说出 naive Bayes 表示不了什么样的 conditional distribution，就可以去第 8 站。
:::

### CPT 的数从哪里来

第 5、6 站的 CPT 都是给定的。实际中手里只有 data：每一行是所有 variable 的一个完整取值。先看最简单的情形，一个 binary variable，$\theta=P(+b)$，$N$ 行 data 里有 $r$ 行是 $+b$。在 $\theta$ 下这份 data 出现的 probability（各行 independent）是

$$L(\theta)=\theta^r(1-\theta)^{N-r}$$

Maximum likelihood estimate（MLE）取让 $L$ 最大的 $\theta$。$\log$ 是单调的，最大化 $\log L=r\log\theta+(N-r)\log(1-\theta)$ 即可。对 $\theta$ 求 derivative 并令它为 0：

$$\frac{r}{\theta}-\frac{N-r}{1-\theta}=0\ \Longrightarrow\ r(1-\theta)=(N-r)\theta\ \Longrightarrow\ \theta=\frac rN$$

CS188 的例子：抽到 2 个红、1 个蓝，$L(\theta)=\theta^2(1-\theta)$，代进去 $\theta=2/3$，就是红的比例。

### 为什么可以一张 CPT 一张 CPT 地估

Bayesian network 的每一行 data $x^{(n)}$ 的 probability 是 CPT 的乘积，所以整份 data 的 log-likelihood 是

$$\log L=\sum_{n=1}^N\sum_{i}\log P\big(x_i^{(n)}\mid \mathrm{pa}_i^{(n)}\big)=\sum_i\Big[\sum_{n=1}^N\log P\big(x_i^{(n)}\mid \mathrm{pa}_i^{(n)}\big)\Big]$$

交换两个求和之后，方括号里只含 $X_i$ 自己那张 CPT。再往下分：CPT 里 parent 取值为 $u$ 的那一行，只出现在 data 中 $\mathrm{pa}_i=u$ 的那些行里。所以整个最大化拆成很多个互不相干的上面那种 coin 问题，每个的答案都是一个比例：

$$\hat P(x\mid u)=\frac{\#(x,u)}{\#(u)}$$

例如 $P(+j\mid+a)$ 只用 $A$ 为 true 的那些行来估：其中 $J$ 也为 true 的比例。

### 没出现过的组合：smoothing

Alarm 一年才响几次。从 alarm network 抽 50 行 data，很可能一行 $+a$ 都没有，于是 $\#(+a)=0$，$P(+j\mid+a)=0/0$ 没有定义；$P(+a\mid\lnot b,\lnot e)$ 估成 0，之后任何一行含 $+a$ 的 data 都被判为 probability 0，log-likelihood 是 $-\infty$。

Assignment 用的办法是给每个 count 先加一个 pseudo-count $\alpha$。Variable 有 $K$ 个取值时：

$$\hat P(x)=\frac{\#(x)+\alpha}{N+K\alpha},\qquad \hat P(x\mid u)=\frac{\#(x,u)+\alpha}{\#(u)+K\alpha}$$

$\alpha=1$ 叫 Laplace smoothing。$\#(u)=0$ 时它给出 $1/K$，也就是“没有 data 就当 uniform”；data 多了，$\alpha$ 的影响被冲淡。

### 同一份 data，两种 representation

AY24/25 第 2 学期 Assignment 1 Problem 2 做的就是这个比较，这里用自己抽的 data 走一遍。从 alarm network 抽 50 行 training data、50 行 test data（seed 3），$\alpha=0.1$。变量顺序 $B,E,A,J,M$，1 是 true。Training data 只有三种行：00000 有 45 行，00010（只有 John 打了电话）4 行，00011（两人都打、alarm 却没响）1 行。Test data 是 00000 48 行、00010 1 行，和 1 行 00001（只有 Mary 打电话），这一种在 training 里从没出现过。

**Atomic model。** 把一整行当成一个不可再分的 proposition，在 $2^5=32$ 种行上各估一个 probability：$(\text{count}+0.1)/(50+32\times0.1)$，分母是 53.2。00000 得 $45.1/53.2=0.848$；00001 没见过，只得 $0.1/53.2=0.00188$。

**Bayesian network。** 结构照 alarm network，每张 CPT 按上面的公式分开估，分母是 $\#(u)+0.2$：

- $\hat P(+b)=\hat P(+e)=(0+0.1)/50.2=0.00199$，$\hat P(+a\mid\lnot b,\lnot e)=0.1/50.2=0.00199$。$A$ 的另外三行 parent 组合一次都没出现，都是 $(0+0.1)/(0+0.2)=0.5$。
- $\hat P(+j\mid\lnot a)=(5+0.1)/50.2=0.1016$（4 行 00010 加 1 行 00011），$\hat P(+m\mid\lnot a)=(1+0.1)/50.2=0.0219$。$\hat P(+j\mid+a)=\hat P(+m\mid+a)=0.5$，同样没有 data。

00001 这一行：$0.998\times0.998\times0.998\times(1-0.1016)\times0.0219=0.0196$，是 atomic model 的 10 倍多。“只有 Mary 打电话”从没整行出现过，但“alarm 没响时 Mary 打电话”在 00011 那一行里出现过一次。Factored 的 representation 把这一次观测用到了所有含 $\lnot a,+m$ 的行上；atomic model 只认整行，00011 对 00001 毫无帮助。

用 test data 的 $-\log_2$ likelihood 比较（handout 指出它就是用这个 model 做最优压缩时 test data 的长度，单位是 bit，越小越好）：

::fig[cs3263-learn] 上面是 training 与 test data 的计数，下面是三个 model 在 test data 上的总 bits。深色段是 00001 这一行的贡献。

Atomic model 24.2 bits，学出来的 Bayesian network 18.4 bits，生成 data 的真实 network 15.6 bits。Atomic model 有 31 个自由的数要从 50 行里估，Bayesian network 只有 10 个，每个数都摊到更多行上。

### Naive Bayes

分类问题里，一个 class variable $Y$ 和若干 feature $F_1,\dots,F_n$。Naive Bayes 假设给定 $Y$ 之后 feature 两两 conditionally independent，network 是 $Y$ 指向每个 $F_i$：

$$P(Y,F_1,\dots,F_n)=P(Y)\prod_{i=1}^nP(F_i\mid Y)$$

Parameter 的个数随 $n$ linear 地增长。分类时对每个 $y$ 算 joint $P(y,f_1,\dots,f_n)$，再除以它们的和。训练就是上面的 counting，每张 $P(F_i\mid Y)$ 分开估。

CS188 的 spam filter：$P(\text{spam})=0.4$、$P(\text{ham})=0.6$；$F_1$ 是 sender 是否认识，$F_2$ 是 “free” 出现的次数。一封信 sender 认识、“free” 出现 1 次，表里的数是 $P(F_1=\text{yes}\mid\text{spam})=0.1$、$P(F_2=1\mid\text{spam})=0.12$、$P(F_1=\text{yes}\mid\text{ham})=0.7$、$P(F_2=1\mid\text{ham})=0.07$：

$$P(\text{spam},f_1,f_2)=0.4\times0.1\times0.12=0.0048,\qquad P(\text{ham},f_1,f_2)=0.6\times0.7\times0.07=0.0294$$

$$P(\text{spam}\mid f_1,f_2)=\frac{0.0048}{0.0048+0.0294}=0.140$$

判为 ham。$F_2$ 那张表在 CS188 里是从 4 封 spam 数出来的：“free” 出现 0、1、2 次的分别有 1、2、1 封，所以是 0.25、0.5、0.25。

:::wrong Naive Bayes 假设 feature 之间互相 independent
它假设的是给定 $Y$ 之后 conditionally independent，第 5 站的 common cause $F_1\leftarrow Y\to F_2$ 正是这个形状，不观测 $Y$ 时 path 是 active 的。拿 spam filter 的数核对：$P(F_1=\text{yes})=0.4\times0.1+0.6\times0.7=0.46$，$P(F_2=1)=0.4\times0.12+0.6\times0.07=0.09$，两者相乘是 0.0414；而 $P(F_1=\text{yes},F_2=1)=0.0048+0.0294=0.0342$。不相等，两个 feature 在 marginal 上是 dependent 的：认识的 sender 多半发 ham，ham 里 “free” 少。
:::

### Naive Bayes 表示不了的东西

$Y$ 是 binary 时，把 naive Bayes 的 posterior 写成 log odds：

$$\log\frac{P(+y\mid f)}{P(-y\mid f)}=\log\frac{P(+y)}{P(-y)}+\sum_{i=1}^n\log\frac{P(f_i\mid+y)}{P(f_i\mid-y)}$$

右边是每个 feature 各贡献一项、加起来。所以不管 parameter 怎么取，log odds 都是 feature 的“可加”function。设真实的 conditional 是：两个 binary feature 不同时 $P(+y\mid f_1,f_2)=0.9$，相同时 0.1，log odds 分别是 $\log9=2.197$ 和 $-2.197$。可加的 $g(f_1,f_2)=c+g_1(f_1)+g_2(f_2)$ 一定满足 $g(0,0)+g(1,1)=g(0,1)+g(1,0)$（两边都等于 $2c+g_1(0)+g_1(1)+g_2(0)+g_2(1)$），而这里左边是 $-4.39$、右边是 $4.39$。Naive Bayes 无论用多少 data 都学不出这个 conditional。

:::exam AY23/24 midterm 第 8 题 (e)
Persy 用 naive Bayes 判断一次采样是否成功：class 是 $S$，feature 是 dust storm（$D$）、采到的样本数（$C$，none/few/many）和高温（$H$）。最后一问：真实的 distribution 里还有一个看不见的 variable $X$（题图没有进入文字，只知道 $X$ 和这几个 variable 相连），naive Bayes 是否保证能表示真实的 $P(S\mid D,C,H)$。答案是 No。给定 $S$ 之后 feature 不再 conditionally independent，真实 conditional 的 log odds 一般就不再是 feature 的可加 function，上面的例子说明这样的 conditional naive Bayes 写不出来。本题前几问要按题给的 probability 算 posterior，那些数在文字版里丢了，solution 的答案是约 0.005 和约 0.444。

## [causal] Causal network：intervention、backdoor criterion 与 Markov blanket

:::skip
能区分 $P(y\mid x)$ 和 $P(y\mid do(x))$，用 truncated factorization 写出 intervention 之后的 distribution，判断一个 set 是否满足 backdoor criterion 并用 adjustment formula 算出 causal effect，写出一个 node 的 Markov blanket，就可以去第 9 站。
:::

### 看到和做到

在第 5 站的 alarm network 上，观测到 alarm 响了，$P(+b\mid+a)=0.374$。现在换一个问题：一个人走过去按响了 alarm，被盗的 probability 是多少？显然还是 0.001，按 alarm 不会招来小偷。可 John 打电话的 probability 和观测到 alarm 响时一样是 0.90：John 只对 alarm 声反应，不管它为什么响。

Conditional probability 回答的是“看到 $A=+a$ 之后我对别的 variable 怎么想”，它会顺着 edge 反过来推原因。按响 alarm 这种 intervention 记作 $do(A=+a)$，它要回答的是“让 $A=+a$ 之后世界会怎样”。要回答它，得把 network 的每条 edge 读成一个机制：$P(x\mid\mathrm{pa}(x))$ 描述 $X$ 怎样由它的 parents 产生，而且干预别的 variable 时这个机制不变。这样读的 Bayesian network 叫 causal network。

### Intervention 把指向 $X$ 的 edge 切掉

$do(X=x)$ 把 $X$ 自己的机制换成常数 $x$，其余机制不动。所以在 factorization 里删掉 $X$ 的那一项，其余各项里的 $X$ 都代成 $x$：

$$P(v\mid do(x))=\prod_{i:\,V_i\ne X}P(v_i\mid\mathrm{pa}_i)\Big|_{X=x}\qquad(v\text{ 与 }X=x\text{ 一致}；\text{否则为 }0)$$

这叫 truncated factorization。在 graph 上等于把所有指向 $X$ 的 edge 切掉。

::fig[cs3263-seedo] 左边是观测：$A$ 的 CPT 还在，看到 $+a$ 会反过来抬高 $B$。右边是 $do(A=+a)$：指向 $A$ 的两条 edge 被切断，$B$ 只剩 prior。

在 alarm network 上：

$$P(b,e,j,m\mid do(+a))=P(b)\,P(e)\,P(j\mid+a)\,P(m\mid+a)$$

对 $e,j,m$ 求和，$P(+b\mid do(+a))=P(+b)=0.001$；对 $b,e,m$ 求和，$P(+j\mid do(+a))=P(+j\mid+a)=0.90$。对比观测：

$$P(b,e,j,m\mid+a)=\frac{P(b)\,P(e)\,P(+a\mid b,e)\,P(j\mid+a)\,P(m\mid+a)}{P(+a)}$$

差别只在 $P(+a\mid b,e)$ 这一项：它还在，就会给“$b$ 为 true”的那些项加权，这正是从结果推原因；intervention 把它删了。

### John 打电话会让 Mary 打电话吗

第 5 站算过 $P(+m\mid+j)=0.040$，是 $P(+m)=0.012$ 的三倍多。但 John 打电话并不导致 Mary 打电话。用 truncated factorization 算 $do(J=+j)$：删掉 $P(j\mid a)$ 这一项，

$$P(+m\mid do(+j))=\sum_{b,e,a}P(b)\,P(e)\,P(a\mid b,e)\,P(+m\mid a)=P(+m)=0.012$$

（和第 5 站“从 leaf 求和”一样，$J$ 的项没了之后其余各项求和就是 $M$ 的 marginal。）观测到的 association 全部来自 path $J\leftarrow A\to M$：$A$ 是两者的 common cause，也就是 confounder。

### Backdoor criterion 与 adjustment formula

上面靠的是知道整个 network 的 CPT。只有 observational data、又只关心 $X$ 对 $Y$ 的 effect 时，能不能只用一部分 variable 把 $P(y\mid do(x))$ 算出来？先看最简单的 graph：$Z\to X$、$Z\to Y$、$X\to Y$。Truncated factorization 删掉 $P(x\mid z)$：

$$P(z,y\mid do(x))=P(z)\,P(y\mid x,z)\quad\Longrightarrow\quad P(y\mid do(x))=\sum_zP(y\mid x,z)\,P(z)$$

右边每一项都是观测得到的 probability。对比 conditioning：$P(y\mid x)=\sum_zP(y\mid x,z)\,P(z\mid x)$，两者只差在给 $z$ 的权重是 $P(z)$ 还是 $P(z\mid x)$。

一般的条件是 Pearl 的 backdoor criterion。从 $X$ 到 $Y$、第一条 edge 指向 $X$ 的 path 叫 backdoor path。一个 set $Z$ 相对于 $(X,Y)$ 满足 backdoor criterion，如果

1. $Z$ 里没有 $X$ 的 descendant；
2. $Z$ 挡住每一条 backdoor path（挡住按第 5 站 d-separation 的规则）。

这时就有 adjustment formula $P(y\mid do(x))=\sum_zP(y\mid x,z)\,P(z)$。

拿 John 和 Mary 检验。Backdoor path 只有 $J\leftarrow A\to M$；$Z=\{A\}$ 不是 $J$ 的 descendant，并且在 common cause 处挡住了它。代进去：

$$\sum_aP(+m\mid+j,a)\,P(a)=\sum_aP(+m\mid a)\,P(a)=0.70\times0.0025164+0.01\times0.9974836=0.0117$$

第一个等号用的是第 5 站的 $M\perp J\mid A$。结果就是 $P(+m)$，和 truncated factorization 一致。

条件 1 为什么要：问 Burglary 对 John 的 effect。$B$ 没有 parent，没有 backdoor path，空集就满足，$P(+j\mid do(+b))=P(+j\mid+b)=0.849$。如果错把 $A$（$B$ 的 descendant）放进 $Z$，adjustment 给出 $\sum_aP(+j\mid+b,a)P(a)=\sum_aP(+j\mid a)P(a)=P(+j)=0.052$：$A$ 正是 effect 经过的那条 causal path 的中间点，conditioning on 它把 effect 本身也挡掉了。

:::wrong 把能观测到的 variable 都放进 $Z$ 一起 adjust，总不会错
多放可能出错，有两种情形。一是放进了 $X$ 的 descendant：上面的 $A$ 让 Burglary 对 John 的 effect 从 0.849 变成 0.052 那样“消失”。二是放进了 collider：第 5 站的 common effect 在中间被观测时 path 变成 active，原本被挡住的 backdoor path 会被打开。Backdoor criterion 的两条都要检查，不是越多越好。
:::

### Markov blanket

给定哪些 variable，$X$ 就和其余所有 variable 无关？写出 $X$ 在其余全部 variable 下的 conditional：

$$P(x\mid\text{其余})=\frac{\prod_iP(v_i\mid\mathrm{pa}_i)}{\sum_{x'}\prod_iP(v_i\mid\mathrm{pa}_i)\big|_{X=x'}}$$

不含 $x$ 的因子上下约掉，剩下的只有 $P(x\mid\mathrm{pa}(x))$ 和每个 child $C$ 的 $P(c\mid\mathrm{pa}(c))$。它们涉及的 variable 是：$X$ 的 parents、children，以及 children 的其他 parents。这个 set 叫 $X$ 的 Markov blanket。给定它，$X$ 和 network 里其余 variable 都 independent。

在 alarm network 上，$B$ 的 Markov blanket 是 child $A$ 和 $A$ 的另一个 parent $E$，也就是 $\{A,E\}$。所以知道了 $A$ 和 $E$，$J$ 不再提供关于 $B$ 的信息：$P(+b\mid+a,+e,+j)$ 和第 5 站的 $P(+b\mid+a,+e)$ 都是 0.0033（$P(+j\mid+a)$ 在分子分母各出现一次，约掉了）。

::fig[cs3263-garden] 下面这道 midterm 题的 network，由题目的 8 条规则连成（每条规则的 premise 指向 conclusion）。动图：第一帧是 Butterfly 的 Markov blanket；之后逐条标出 $B$ 到 $A$ 的 backdoor path，最后一帧说明 $\{F\}$ 为什么够。

## [hmm] Reasoning over time：HMM、filtering 与 Viterbi

:::skip
能写出 HMM 的三张表，连续做几步 forward algorithm，用 backward message 做一次 smoothing，并用 Viterbi 回溯出最可能的 sequence，就可以去第 10 站。
:::

### 只往前推，belief 会忘掉一切

天气 $W_t\in\{\text{sun},\text{rain}\}$ 每天变一次。假设明天只取决于今天（Markov property：给定 $W_t$，$W_{t+1}$ 和更早的天气 independent），而且这个规律每天一样（stationary），只需要两张表。CS188 的数：

$$P(W_0)=(\underbrace{0.8}_{\text{sun}},\underbrace{0.2}_{\text{rain}}),\qquad P(W_{t+1}\mid W_t):\ \begin{array}{c|cc}&\text{sun}&\text{rain}\\\hline\text{sun}&0.6&0.4\\\text{rain}&0.1&0.9\end{array}$$

（行是今天，列是明天。）明天的 distribution 对今天求和：

$$P(W_{t+1}=s)=\sum_wP(W_{t+1}=s\mid w)\,P(W_t=w)$$

这叫 mini-forward algorithm。逐天算 sun 的 probability：

$$P(W_1=\text{sun})=0.6\times0.8+0.1\times0.2=0.5,\quad P(W_2=\text{sun})=0.6\times0.5+0.1\times0.5=0.35,\quad P(W_3=\text{sun})=0.6\times0.35+0.1\times0.65=0.275$$

第 10 天是 0.2006。它在往 0.2 靠。Stationary distribution 满足 $P(W_{t+1})=P(W_t)$，设 sun 的 probability 是 $x$：$x=0.6x+0.1(1-x)$，得 $0.5x=0.1$，$x=0.2$，rain 是 0.8。

靠拢的速度也能算：$P(W_{t+1}=\text{sun})-0.2=0.6x+0.1(1-x)-0.2=0.5(x-0.2)$，偏差每天减半（0.6、0.3、0.15、0.075……）。不管第 0 天知道多少，几天之后就只剩“这个地方平均八成下雨”。要知道今天的天气，必须有每天的 observation。

### Hidden Markov model

天气看不见，每天只有一份 forecast $F_t\in\{\text{good},\text{bad}\}$，它只取决于当天的天气。再加一张 sensor model：

$$P(F_t\mid W_t):\ \begin{array}{c|cc}&\text{good}&\text{bad}\\\hline\text{sun}&0.8&0.2\\\text{rain}&0.3&0.7\end{array}$$

Initial distribution、transition model、sensor model 三张表合起来就是一个 hidden Markov model（HMM）。它是一个按时间展开的 Bayesian network：$W_0\to W_1\to W_2\to\cdots$，每个 $W_t$ 下面挂一个 $F_t$，joint 是

$$P(W_0,W_1,F_1,\dots,W_t,F_t)=P(W_0)\prod_{k=1}^tP(W_k\mid W_{k-1})\,P(F_k\mid W_k)$$

由第 5 站的 d-separation 直接读出两条要用的 independence：给定 $W_k$，$W_{k+1}$ 和 $F_1,\dots,F_k$ independent（chain 被 $W_k$ 挡住）；给定 $W_k$，$F_k$ 和其余一切 independent。

能问的问题有四种（CMU 15-281 的分类）：filtering，$P(W_t\mid f_{1:t})$，现在的天气；prediction，$P(W_{t+k}\mid f_{1:t})$；smoothing，$P(W_k\mid f_{1:t})$，$k<t$，用后来的 forecast 回头修正过去；most likely explanation，$\arg\max_{w_{1:t}}P(w_{1:t}\mid f_{1:t})$，最可能的整条 sequence。

### Filtering：forward algorithm

记 $B(W_t)=P(W_t\mid f_{1:t})$ 为看完第 $t$ 天 forecast 之后的 belief，$B'(W_t)=P(W_t\mid f_{1:t-1})$ 为第 $t$ 天 forecast 到来之前的 belief。从 $B(W_t)$ 到 $B(W_{t+1})$ 分两步。

**Time elapse。** 对今天的天气求和，再用 Markov property：

$$B'(W_{t+1})=\sum_{w}P(W_{t+1},w\mid f_{1:t})=\sum_wP(W_{t+1}\mid w,f_{1:t})\,P(w\mid f_{1:t})=\sum_wP(W_{t+1}\mid w)\,B(w)$$

第二个等号是 chain rule；第三个等号把 $f_{1:t}$ 删掉，因为给定 $W_t=w$，$W_{t+1}$ 和过去的 forecast independent。这就是 mini-forward 那一步。

**Observation update。** 用 conditional probability 的定义，再用 sensor 的 independence：

$$B(W_{t+1})=P(W_{t+1}\mid f_{1:t+1})=\frac{P(W_{t+1},f_{t+1}\mid f_{1:t})}{P(f_{t+1}\mid f_{1:t})}=\frac{P(f_{t+1}\mid W_{t+1})\,B'(W_{t+1})}{P(f_{t+1}\mid f_{1:t})}\ \propto\ P(f_{t+1}\mid W_{t+1})\,B'(W_{t+1})$$

Denominator 对 $W_{t+1}$ 的各个值相同，乘完之后除以总和即可。

从 $B(W_0)=(0.8,0.2)$ 出发，forecast 依次是 good、bad、bad。第 1 天：time elapse 得 $B'(W_1)=(0.5,0.5)$，就是上面 mini-forward 的第一步；看到 good，乘 sensor model 的 good 那一列，得 $(0.8\times0.5,\ 0.3\times0.5)=(0.4,\ 0.15)$，除以和 0.55，

$$B(W_1)=\Big(\frac{0.4}{0.55},\ \frac{0.15}{0.55}\Big)=\Big(\frac{8}{11},\ \frac{3}{11}\Big)=(0.727,\ 0.273)$$

一份好的 forecast 把 sun 从 0.5 拉到 0.727。

::fig[cs3263-forward] 动图。上面是 HMM 的结构，深色的 $F_t$ 是观测到的 forecast。下面每个时刻两根柱子：虚线框是 time elapse 之后的 $B'$，实心柱是乘上 sensor model、normalize 之后的 $B$。最下面两行文字是这一步的算式。

第 2 天：$B'(\text{sun})=0.6\times0.727+0.1\times0.273=0.464$，rain 0.536；看到 bad，$(0.2\times0.464,\ 0.7\times0.536)=(0.093,\ 0.375)$，normalize 得 $(0.198,\ 0.802)$。第 3 天：$B'=(0.199,\ 0.801)$，再看到 bad，得 $(0.066,\ 0.934)$。

每一步的工作量：time elapse 对每个明天的 state 加 $|S|$ 项，$|S|^2$；observation update $|S|$。和 $t$ 无关，memory 也只存当前的 belief。对比把 $t$ 天的天气 sequence 全部列出来的 $|S|^t$。

这正是 [CS4246 第 4 站](CS4246.html#pomdp) 的 belief update，只是那里的 transition 还取决于 action。

### Smoothing：用后来的 forecast 修正过去

第 1 天的 belief 是 sun 0.727，可后面连着两份 bad。知道了这些，第 1 天是晴天的 probability 应该降低多少？把 $f_{1:3}$ 拆成 $f_1$ 和 $f_{2:3}$：

$$P(W_1\mid f_{1:3})\ \propto\ P(W_1\mid f_1)\,P(f_{2:3}\mid W_1,f_1)=B(W_1)\,P(f_{2:3}\mid W_1)$$

第二个因子删掉 $f_1$，因为给定 $W_1$，未来的 forecast 和过去的 forecast independent。$b_k(w)=P(f_{k+1:t}\mid W_k=w)$ 叫 backward message，从后往前算：

$$b_k(w)=\sum_{w'}P(w'\mid w)\,P(f_{k+1}\mid w')\,b_{k+1}(w'),\qquad b_t(w)=1$$

（对明天的天气 $w'$ 求和：从 $w$ 转到 $w'$，$w'$ 产生 $f_{k+1}$，$w'$ 再产生其余的 forecast。）

| | $b_3$ | $b_2$（$f_3=$ bad） | $b_1$（$f_2=$ bad） |
|---|---|---|---|
| sun | 1 | $0.6\times0.2+0.4\times0.7=0.40$ | $0.6\times0.2\times0.40+0.4\times0.7\times0.65=0.230$ |
| rain | 1 | $0.1\times0.2+0.9\times0.7=0.65$ | $0.1\times0.2\times0.40+0.9\times0.7\times0.65=0.4175$ |

$$P(W_1\mid f_{1:3})\ \propto\ (0.727\times0.230,\ 0.273\times0.4175)=(0.1673,\ 0.1139)\ \Rightarrow\ (0.595,\ 0.405)$$

第 1 天是晴天的 probability 从 0.727 修正到 0.595。对每个 $k$ 都这样算，是 forward-backward algorithm：一遍 forward 存下每个 $B$，一遍 backward 算每个 $b$，逐个相乘、normalize。

### Most likely explanation：Viterbi

要的是一整条最可能的 sequence $\arg\max_{w_{1:t}}P(w_{1:t}\mid f_{1:t})$。Evidence 固定，等价于最大化 joint $P(w_{1:t},f_{1:t})$。把 joint 写成每一步一个因子：从 $w_{k-1}$ 到 $w_k$ 的因子是 $P(w_k\mid w_{k-1})P(f_k\mid w_k)$，一条 sequence 的 probability 是沿途因子的乘积。这是一个 trellis（每个时刻一列 state）上找乘积最大的 path 的问题，用 dynamic programming：

$$m_t(w)=\max_{w_{1:t-1}}P(w_{1:t-1},W_t=w,f_{1:t})=P(f_t\mid w)\max_{w'}P(w\mid w')\,m_{t-1}(w')$$

第二个等号把只和 $w_t$ 有关的 $P(f_t\mid w)$ 提出 max，再把对更早 state 的 max 收进 $m_{t-1}$。同时记下 back pointer $a_t(w)=\arg\max_{w'}P(w\mid w')\,m_{t-1}(w')$。最后取 $m_t$ 最大的 state，顺着 back pointer 往回走。它和 forward algorithm 结构一样，只是把 $\sum$ 换成 $\max$。

同一组 forecast good、bad、bad。$P(W_1)$ 是 time elapse 之后的 $(0.5,0.5)$，$m_1=(0.5\times0.8,\ 0.5\times0.3)=(0.4,\ 0.15)$。

::fig[cs3263-viterbi] Trellis。每个方框是一个（时刻，state），里面是 $m$；粗线是每个方框记下的 back pointer，彩色的是最后回溯出的 path。

$t=2$ 的 rain：从 sun 来是 $0.4\times0.4=0.16$，从 rain 来是 $0.15\times0.9=0.135$，取 sun，乘 $P(\text{bad}\mid\text{rain})=0.7$ 得 0.112。其余三格同理（图下方的算式）。$t=3$ 最大的是 rain 的 0.07056，回溯 rain ← rain ← sun：最可能的 sequence 是 (sun, rain, rain)。它的 posterior 是 $0.07056/P(f_{1:3})$，而 $P(f_{1:3})$ 正是 forward algorithm 三次 normalize 的分母之积 $0.55\times0.468\times0.600=0.1546$，所以是 0.456。

:::wrong 把每一天各自最可能的天气串起来，就是最可能的 sequence
换一组 forecast：bad、good、good。用 smoothing 算每一天各自的 posterior，sun 的 probability 依次是 0.398、0.550、0.543，各取最可能的，得 (rain, sun, sun)。它的 posterior 只有 0.162。Viterbi 给出的是 (rain, rain, rain)，posterior 0.308，几乎是两倍；第二名是 (sun, sun, sun)，0.278。第 1 天 rain 的 0.602 里，(rain, rain, rain) 一条就占 0.308；第 2 天 sun 的 0.550 里，(sun, sun, sun) 一条就占 0.278。两天的结论各自来自不同的 sequence，拼在一起就需要一个 rain → sun 的转换，而 $P(\text{sun}\mid\text{rain})=0.1$ 很小。每天的 marginal 和整条 sequence 是两个不同的问题。

## [dec] Utility、decision network、value of information 与 human factors

:::skip
能用 utility 算 expected utility，在 decision network 里先求 posterior 再选 MEU 的 action，从头算出一次 VPI，并能用 base rate 说明 representativeness 一类的 bias 错在哪里、用 clarity test 检查一个 variable 定义得够不够清楚，就可以去第 11 站。

### 只有 probability 还不能决定

上一站能算出明天下雨的 probability，可带不带伞还要看每种结果有多好。CS188 的 umbrella 例子给四种结果打分：

| | sun | rain |
|---|---|---|
| leave | 100 | 0 |
| take | 20 | 70 |

$P(\text{sun})=0.7$ 时，按 probability 加权平均：

$$EU(\text{leave})=0.7\times100+0.3\times0=70,\qquad EU(\text{take})=0.7\times20+0.3\times70=35$$

选 leave。这些数是 utility，加权平均叫 expected utility（EU），选 EU 最大的 action 叫 maximum expected utility（MEU）原则。

马上会问：这些数只要排好顺序就行，还是大小本身也有意义？保持顺序（leave/sun > take/rain > take/sun > leave/rain），把它们换成 71、70、60、0：

$$EU(\text{leave})=0.7\times71+0.3\times0=49.7,\qquad EU(\text{take})=0.7\times60+0.3\times70=63$$

决定翻成了 take。在没有不确定性、或者像 minimax 那样只看最坏情况时，只有顺序要紧；一旦要做加权平均，大小就决定结果。所以必须说清楚 utility 的数从哪里来、为什么该按 expectation 去比。

### Lottery 与 rational preference

一个有不确定性的结果写成 lottery $L=[p,A;\ 1-p,B]$：probability $p$ 得到 $A$，$1-p$ 得到 $B$。$A\succ B$ 表示偏好 $A$，$A\sim B$ 表示无所谓。

CS188 先举了一个反例说明 preference 不能随便。设某个 agent 宁可付 1 美元把 $A$ 换成 $B$，宁可付 1 美元把 $B$ 换成 $C$，又宁可付 1 美元把 $C$ 换成 $A$。一个手里有 $B$ 和 $C$ 的商人连换三次，agent 回到原来的 $A$，少了 3 美元，而且可以一直换下去，直到它一分钱不剩。这叫 money pump，问题出在偏好是一个 cycle。

合理的 preference 应满足五条 axiom：

1. **Orderability：** $(A\succ B)\lor(B\succ A)\lor(A\sim B)$，任何两样都能比。
2. **Transitivity：** $(A\succ B)\land(B\succ C)\Rightarrow(A\succ C)$。上面的 money pump 违反的就是这条。
3. **Continuity：** $A\succ B\succ C\Rightarrow\exists p\ [p,A;\ 1-p,C]\sim B$。
4. **Substitutability：** $A\sim B\Rightarrow[p,A;\ 1-p,C]\sim[p,B;\ 1-p,C]$。
5. **Monotonicity：** $A\succ B\Rightarrow\big(p\ge q\Leftrightarrow[p,A;\ 1-p,B]\succeq[q,A;\ 1-q,B]\big)$。

MEU theorem（Ramsey 1931；von Neumann 与 Morgenstern 1944）说：preference 满足这五条，就存在一个 real-valued function $U$，使

$$U(A)\ge U(B)\iff A\succeq B,\qquad U([p_1,S_1;\dots;p_n,S_n])=\sum_ip_i\,U(S_i)$$

第二条正是“按 expectation 去比”的依据。这个 $U$ 不唯一：换成 $U'=aU+b$（$a>0$）不改变任何决定。拿 umbrella 检验 $U'=2U+10$：$EU'(\text{leave})=0.7\times210+0.3\times10=150$，$EU'(\text{take})=0.7\times50+0.3\times150=80$，仍然 leave，两者的差也只是乘了 2。上一节的 71、70、60、0 不是原来的 positive affine transformation，所以会改变决定。

Utility 的数可以这样定：取最好的结果 $S_\top$ 和最坏的 $S_\bot$，对一个结果 $A$，调整 $p$ 直到 $A\sim[p,S_\top;\ 1-p,S_\bot]$，这个 $p$ 就是 $A$ 在 0 到 1 尺度上的 utility。

### Money 不是 utility

CS188 的例子：lottery $L=[0.5,\ 0;\ 0.5,\ 1000]$（单位是美元，一半拿 0、一半拿 1000）和稳拿 500 美元比。Expected monetary value（EMV）都是 500，三个 agent 的 utility 不同：

| agent | $x$ 美元的 utility | $U(L)$ | 稳拿 500 的 utility | 选 |
|---|---|---|---|---|
| 1 | $x$ | $0.5\times1000=500$ | 500 | 无所谓（risk-neutral） |
| 2 | $\sqrt x$ | $0.5\times\sqrt{1000}=15.81$ | $\sqrt{500}=22.36$ | 稳拿（risk-averse） |
| 3 | $x^2$ | $0.5\times1000^2=500000$ | $500^2=250000$ | lottery（risk-seeking） |

Agent 2 的 $U$ 是 concave 的，钱越多，每多一块带来的 utility 越少，所以“一半拿 0、一半拿 1000”的平均 utility 低于拿中间值 500 的 utility。

跟 lottery 等价的稳定金额叫 certainty equivalent（CE），满足 $U(\mathrm{CE})=U(L)$。Agent 2：$\sqrt{\mathrm{CE}}=15.81$，$\mathrm{CE}=15.81^2=250$（精确地说 $(0.5\sqrt{1000})^2=0.25\times1000$）。只要给他 250 美元以上，他就愿意放弃这张 lottery。$\mathrm{EMV}-\mathrm{CE}=500-250=250$ 叫 insurance premium：risk-averse 的人愿意少拿这么多来换取确定性。保险公司能赚钱，是因为它同时承保很多独立的风险，对它来说接近 risk-neutral，而投保的人是 risk-averse 的，两边对同一个 lottery 的估价不同。

### Decision network

把 action 和 utility 加进 Bayesian network，就是 decision network。三种 node：chance node（oval，普通的 random variable）、action node（rectangle，agent 自己选）、utility node（diamond，它的 parents 决定 utility）。选 action 的步骤：

1. 代入所有 evidence，用第 6 站的 inference 求 utility node 的那些 chance parent 的 posterior。
2. 对每个 action $a$ 算 $EU(a\mid e)=\sum_xP(x\mid e)\,U(a,x)$。
3. 选 EU 最大的。

Umbrella 加上一个 forecast，用第 9 站的 sensor model：$P(\text{good}\mid\text{sun})=0.8$，$P(\text{good}\mid\text{rain})=0.3$。

::fig[cs3263-umbrella] 左边是 decision network：Forecast 依赖 Weather，U 依赖 Umbrella 和 Weather，Forecast 在决定之前能看到。右边是“先看 forecast 再决定”的 outcome tree，粗线是每种 forecast 下的最优 action。

看到 bad 时，先求 posterior：

$$P(\text{bad})=0.7\times0.2+0.3\times0.7=0.35,\qquad P(\text{sun}\mid\text{bad})=\frac{0.7\times0.2}{0.35}=0.4$$

$$EU(\text{leave}\mid\text{bad})=0.4\times100=40,\qquad EU(\text{take}\mid\text{bad})=0.4\times20+0.6\times70=50$$

改成 take。看到 good 时，$P(\text{good})=0.65$，$P(\text{sun}\mid\text{good})=0.56/0.65=0.8615$，$EU(\text{leave}\mid\text{good})=86.15$，$EU(\text{take}\mid\text{good})=0.8615\times20+0.1385\times70=26.92$，leave。

### Value of perfect information

Forecast 要不要看（如果看要付钱）？在看之前，不知道会是 good 还是 bad，只能按 probability 平均“看了之后能拿到的 MEU”：

$$MEU(F)=\sum_fP(f)\,MEU(f)=0.65\times86.15+0.35\times50=56+17.5=73.5$$

不看的话 MEU 是 70。差值就是这份 forecast 的价值：

$$VPI(F)=MEU(F)-MEU(\varnothing)=73.5-70=3.5$$

价格低于 3.5 就值得买。和直接知道天气比：sun 时 leave 得 100，rain 时 take 得 70，$MEU(W)=0.7\times100+0.3\times70=91$，$VPI(W)=21$。Forecast 有噪声，只值完全信息的六分之一。

VPI 不会是负的。设 $a^*$ 是现在的最优 action。看了 forecast 之后，在每个 $f$ 下最优 action 的 EU 至少不比 $a^*$ 差，所以

$$MEU(F)=\sum_fP(f)\max_aEU(a\mid f)\ \ge\ \sum_fP(f)\,EU(a^*\mid f)=EU(a^*)=MEU(\varnothing)$$

倒数第二个等号是 law of total expectation。拿数字核对：$a^*=$ leave，$0.65\times86.15+0.35\times40=56+14=70$，正是 $EU(\text{leave})$。等号成立当且仅当不管看到什么，最优 action 都不变：信息只有在可能改变决定时才有价值。把 $U(\text{take},\text{rain})$ 从 70 改成 30 试试：$EU(\text{take}\mid\text{bad})=0.4\times20+0.6\times30=26<40$，看到 bad 也照样 leave，看到 good 更是 leave，于是 $VPI(F)=0$。

两条性质 CS188 也列出了：VPI 一般不可相加，$VPI(E_j,E_k)\ne VPI(E_j)+VPI(E_k)$（两份 forecast 如果说的是同一件事，第二份几乎不值钱）；但与顺序无关，$VPI(E_j,E_k)=VPI(E_j)+VPI(E_k\mid E_j)=VPI(E_k)+VPI(E_j\mid E_k)$。

:::wrong 看到 bad 之后 MEU 从 70 掉到 50，所以 forecast 让人变差，VPI 可能是负的
50 小于 70，是因为 bad 这个消息本身是坏消息：它告诉你大概要下雨，而下雨时最好的结果也只有 70。即使不看 forecast，天也照样会下雨，只是你不知道，会照旧 leave，在这些日子拿 0。比较应该在“看之前”做：看之前，good 和 bad 各有 probability，平均起来 $MEU(F)=73.5\ge70$。单个 observation 之后的 MEU 可以比原来低，它们的平均不会。
:::

### 填进 network 的 probability 从哪里来：人的判断会偏在哪里

:::skip
这一小节和下一小节对应课程大纲里的 human factors 与 decision analysis。Midterm 出过判断题，只考概念；赶时间可以只看三道真题走读。
:::

Decision network 里的 probability 常常没有 data，只能请专家估。Tversky 与 Kahneman 1974 年在 *Science* 上的文章说明，人估 probability 时用几条省力的 heuristic，它们多数时候管用，但会系统性地偏到同一个方向。

**Representativeness：按“像不像”判断，忽略 base rate。** 实验给受试者看一些人物描述，说是从 100 个专业人士里随机抽的。一组被告知其中 70 个 engineer、30 个 lawyer，另一组是 30 个 engineer、70 个 lawyer，都要估“这个人是 engineer”的 probability。用 Bayes' rule 写成 odds：

$$\frac{P(\text{eng}\mid d)}{P(\text{law}\mid d)}=\frac{P(d\mid\text{eng})}{P(d\mid\text{law})}\cdot\frac{P(\text{eng})}{P(\text{law})}$$

同一段描述 $d$ 的 likelihood ratio 在两组里相同，所以两组的 posterior odds 之比就是 prior odds 之比：$\dfrac{0.7/0.3}{0.3/0.7}=\Big(\dfrac{0.7}{0.3}\Big)^2=5.44$。受试者在两组里给出的 probability 却基本一样。不给任何描述时，他们会正确地答 0.7 和 0.3；可一旦给了一段毫无信息的描述（“Dick 30 岁，已婚，没有孩子，能力强、有干劲，同事喜欢他”），两组都答 0.5。毫无信息的描述 likelihood ratio 是 1，posterior 应该等于 prior，0.7 或 0.3。

**Insensitivity to sample size。** 一个镇上大医院每天约生 45 个婴儿，小医院约 15 个。一年里，哪家医院“男婴超过 60%”的日子更多？95 个学生里，21 个选大医院，21 个选小医院，53 个选“差不多”。按 binomial 算（男婴 probability 0.5）：15 个里超过 60% 是至少 10 个，probability 0.151，一年约 55 天；45 个里超过 60% 是至少 28 个，probability 0.068，一年约 25 天。小样本离 50% 远的机会大得多，这正是[第 7 站](#learn)里 50 行 data 估不准 CPT 的原因。

**Availability：按“想起来容易不容易”判断。** 问英文里以 r 开头的词多，还是第三个字母是 r 的词多，人们会去回想，以 r 开头的更容易想到，于是判断它更多，而实际上 r 出现在第三位更常见。

**Anchoring：从一个起点出发往上下调，调得不够。** 当着受试者的面转一个 0 到 100 的轮盘，再问非洲国家占联合国会员国的百分比。转到 10 的一组，估计的 median 是 25；转到 65 的一组是 45。让高中生在 5 秒内估 $8\times7\times6\times5\times4\times3\times2\times1$，median 是 2250；估 $1\times2\times\cdots\times8$ 的一组是 512；真值是 40320。两组都只算了前几步就往上调，从大数开始的那组调得高一些。

:::exam AY22/23 midterm 第 4 题
Prof. Nut 一早喉咙痛、发烧、咳嗽，立刻认定自己得了 Covid-19。这可能是 availability heuristic 或 representativeness heuristic 造成的 cognitive bias：True。Covid 的病例在当时到处都是，最容易想起来（availability）；这三个症状和典型的 Covid 病人很“像”（representativeness）。两条都让人略过了 base rate：同样症状的普通感冒和 flu 也很多。按 Bayes' rule 要比较的是 $P(\text{症状}\mid\text{Covid})P(\text{Covid})$ 和其他病的同一个乘积，而不只是“像不像”。
:::

### Decision analysis：clarity test

把一个决策问题写成 decision network 之前，每个 chance node、每个 outcome、每个 alternative 都要定义得足够清楚。Ron Howard 1988 年提出 clarity test：设想一个 clairvoyant，他知道过去、现在和将来所有可以测量的事实，但没有任何判断力；如果他不需要再问任何问题就能说出这个 event 是否发生、这个 variable 取什么值，它就通过了 clarity test。

拿本站的 umbrella network 检验。“明天下雨”通不过：clairvoyant 会问，哪里下？下多少算？一整天还是任何时候？改成“明天 08:00 到 20:00 之间，NUS Kent Ridge 校园的气象站记录到的降雨量超过 1 mm”，他就能直接回答。Utility table 里的 4 个数也只有在 Weather 这样定义之后才有意义：同一个“rain”，毛毛雨和暴雨对 leave 的 utility 完全不同。

:::exam AY23/24 midterm 第 4 题
题目说：通过 clarity test，是指确认决策情境里所有相关的因素都已经放进了 decision model 的相应部分。False。那说的是 model 是否完整；clarity test 检验的是 model 里每个元素各自是否定义得没有歧义，标准是 clairvoyant 能否不经追问就给出它的值。一个漏掉了重要因素的 model，里面每个 variable 仍然可以都通过 clarity test。
:::

:::exam AY22/23 midterm 第 3 题
题目说：safe、fair、accountable 的 AI system 在所有情形下都能给出最准确的 prediction。False，solution 的理由是任何一个 responsible AI 的标准和技术上的 accuracy 之间都存在 trade-off。一个最简单的数值情形：两个人数相同的群体，真正应判 positive 的比例分别是 0.6 和 0.2。一个完全准确的 classifier 在两组的 positive rate 就是 0.6 和 0.2。如果要求 demographic parity（两组的 positive rate 相同，都等于 $r$），即使在组内把最该判 positive 的人排在前面，每组至少错 $|0.6-r|$ 和 $|r-0.2|$，平均 error 至少 $\frac12(|0.6-r|+|r-0.2|)\ge\frac12(0.6-0.2)=0.2$，accuracy 至多 0.8。在这个情形下，“fair”的约束直接让 accuracy 从 1 降到不超过 0.8。
:::

## [game] Game theory：mixed strategy 与 Nash equilibrium

:::skip
能算 pure strategy 的 max-min 与 min-max，用两条 line 求 2×2 zero-sum game 的 optimal mixed strategy，并在一般 game 里找出 Nash equilibrium（包括用 indifference 求 mixed 的那个），这一页就读完了。
:::

### 没有先后手的 game

[CS2109S 第 3 站](CS2109S.html#adv) 的 minimax 处理的是轮流走的 game：后走的人看得到先走的人做了什么。Two-finger Morra 里两个人同时出 1 根或 2 根手指：都出 1，B 付给 A 2 块；都出 2，B 付给 A 4 块；不一样，A 付给 B 3 块。A 的 payoff：

| | B 出 1 | B 出 2 |
|---|---|---|
| A 出 1 | 2 | −3 |
| A 出 2 | −3 | 4 |

B 的 payoff 是每格的相反数（zero-sum）。只出固定的一种叫 pure strategy。如果 A 必须先公开自己出什么，B 会选对 A 最坏的那一列，A 能保证的是

$$\max_a\min_bV(a,b)=\max\big(\min(2,-3),\ \min(-3,4)\big)=\max(-3,-3)=-3$$

反过来让 B 先公开，A 能拿到 $\min_b\max_aV(a,b)=\min(2,4)=2$。先公开的一方吃亏，差距从 −3 到 2。同时出手时谁也不先公开，这两个数都不是答案。

### Mixed strategy

让 A 以 probability $p$ 出 1、$1-p$ 出 2，这叫 mixed strategy。B 若出 1，A 的 expected payoff 是 $2p-3(1-p)=5p-3$；B 若出 2，是 $-3p+4(1-p)=4-7p$。

B 自己也可以 mix，以 $q$ 出 1，A 的 expected payoff 是 $q(5p-3)+(1-q)(4-7p)$。对固定的 $p$，它是 $q$ 的 linear function，最小值一定在 $q=0$ 或 $q=1$ 取到。所以对手知道你的 mixed strategy 时，他的 best response 总可以取 pure strategy，A 能保证的就是两条 line 中较低的那条：

$$F(p)=\min(5p-3,\ 4-7p)$$

::fig[cs3263-morra] 两条 line 和它们的下包络（粗线）。A 要在粗线上找最高点。右边是 payoff matrix。

一条随 $p$ 升，一条随 $p$ 降，下包络的最高点在交点：$5p-3=4-7p$，$12p=7$，$p=7/12$。Value 是 $5\times\frac{7}{12}-3=\frac{35-36}{12}=-\frac{1}{12}$，代进另一条 $4-\frac{49}{12}=-\frac{1}{12}$，一致。

对 B 做同样的事：B 以 $q$ 出 1，A 出 1 得 $5q-3$，出 2 得 $4-7q$；B 要让较高的那条尽量低，交点同样在 $q=7/12$，value 同样是 $-1/12$。两边算出同一个数，这不是巧合。

**Minimax theorem（von Neumann）：** 两人、有限个 action 的 zero-sum game，允许 mixed strategy 时

$$\max_{\pi_A}\min_{\pi_B}V(\pi_A,\pi_B)=\min_{\pi_B}\max_{\pi_A}V(\pi_A,\pi_B)$$

推论：公开自己的 optimal mixed strategy 不吃亏。A 宣布“我以 7/12 出 1”，B 怎么应对 A 都至少拿 $-1/12$。Pure strategy 下的 −3 与 2 之间的差距，在 mixed strategy 下消失了。

更大的 game 用 linear program 求：因为 best response 可以是 pure，“对 B 的每个 pure action，A 的 expected payoff 都不低于 $v$”这一组 linear constraint 就够了：

$$\max_{\pi,v}\ v\quad\text{s.t.}\quad\sum_a\pi(a)V(a,b)\ge v\ \ \text{对每个 }b,\qquad\sum_a\pi(a)=1,\ \ \pi\ge0$$

在 Morra 上这两条 constraint 就是 $5p-3\ge v$ 和 $4-7p\ge v$，又回到那两条 line。

:::wrong A 用 7/12 时 B 出什么都一样，所以 A 偏离一点也无所谓
B 无所谓，是因为 A 恰好选在了让两条 line 相等的那一点。A 一旦偏离，两条 line 就不再相等，B 会挑低的那条。比如 A 改成 $p=1/2$：$F(1/2)=\min(5\times0.5-3,\ 4-7\times0.5)=\min(-0.5,\ 0.5)=-0.5$，B 只要一直出 1，A 每局平均输 0.5，比 $-1/12\approx-0.083$ 差得多。“对手无所谓”是你选对了的结果，不是你可以随意的理由。
:::

### Non-zero-sum：prisoner's dilemma 与 Nash equilibrium

两个嫌犯被分开审问。都 testify（揭发对方），各判 5 年；都 refuse，各判 1 年；一个 testify 一个 refuse，testify 的放走，refuse 的判 10 年。Payoff 取负的年数，每格写（A，B）：

| | B testify | B refuse |
|---|---|---|
| A testify | (−5, −5) | (0, −10) |
| A refuse | (−10, 0) | (−1, −1) |

四格的和分别是 −10、−10、−10、−2，不是常数，不是 zero-sum，minimax theorem 用不上。

从 A 的角度逐列看：B testify 时，A testify 得 −5、refuse 得 −10，testify 好；B refuse 时，A testify 得 0、refuse 得 −1，还是 testify 好。不管 B 怎么做 testify 都更好，这叫 dominant strategy。B 对称。于是两人都 testify，各得 −5；而两人都 refuse 能各得 −1，对两个人都更好。

一般的 game 没有 dominant strategy，需要一个更弱的概念。**Nash equilibrium：** 一组 strategy $(\pi_A^*,\pi_B^*)$，任何一方单独改变自己的 strategy 都不能变好：

$$V_A(\pi_A^*,\pi_B^*)\ge V_A(\pi_A,\pi_B^*)\ \ \forall\pi_A,\qquad V_B(\pi_A^*,\pi_B^*)\ge V_B(\pi_A^*,\pi_B)\ \ \forall\pi_B$$

检验 (testify, testify)：A 单独改成 refuse，从 −5 变 −10；B 同理，所以是 equilibrium。检验 (refuse, refuse)：A 单独改成 testify，从 −1 变 0，变好了，所以不是。“双方都更好的结果”不稳定，因为每个人都有单独背叛的动机。

**Nash 的 existence theorem（1950）：** 有限个 player、有限个 action 的 game，至少有一个 Nash equilibrium（允许 mixed strategy），不要求 zero-sum。Zero-sum 时，minimax 的那对 strategy 就是 Nash equilibrium：Morra 里 B 用 $q=7/12$，A 出 1 得 $5\times\frac{7}{12}-3=-\frac1{12}$、出 2 得 $4-7\times\frac7{12}=-\frac1{12}$，A 怎么改都还是 $-1/12$，没有变好的余地；B 那边对称。

### 不止一个 equilibrium，也不一定好

Collaborative Morra：同样的 matrix，但两人拿到的都是 A 的那个数（利益完全一致）。Pure strategy 的 equilibrium 逐格检验：

- (1, 1)：两人各得 2。A 单独改出 2，变成 −3；B 同理。是 equilibrium。
- (2, 2)：各得 4。单独改都变成 −3。是 equilibrium。
- (1, 2) 和 (2, 1)：各得 −3，任一方单独改都变成 2 或 4，不是。

还有一个 mixed 的。在 mixed equilibrium 里，一方以正的 probability 使用的每个 action，expected payoff 必须相同：否则把 probability 挪到更好的那个上就能变好。设 B 以 $q$ 出 1，A 出 1 得 $2q-3(1-q)=5q-3$，出 2 得 $-3q+4(1-q)=4-7q$，相等得 $q=7/12$；对称地 A 也用 $7/12$。两人的期望 payoff 都是 $-1/12$。

三个 equilibrium，value 分别是 4、2、$-1/12$。Equilibrium 只保证“没人想单独改”，不保证结果好：两人完全利益一致，也可能卡在各得 2 甚至 $-1/12$，因为单独改变不了什么，要一起改才行。

:::edge Equilibrium 的个数和 value
Zero-sum game 可能有多个 minimax strategy，但它们的 value 全都相同（Morra 的 value 只能是 $-1/12$）。Non-zero-sum game 的多个 Nash equilibrium 可以有完全不同的 value，就像上面的 4、2、$-1/12$。所以 zero-sum 时“这个 game 值多少”有唯一答案，non-zero-sum 时没有。
:::
