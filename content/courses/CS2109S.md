先看三件做不下去的事。

**第一件。** 一张只有六个 state 的 graph，要找从 S 到 G 最便宜的 path。Breadth-first search 给出的 path 的 cost 是 11，depth-first search 给出的是 9，真正最便宜的是 8。两个 algorithm 都没有写错，它们只是没有在找“最便宜”。

::fig[cs2109s-threepaths] 动图，三条 path 轮流亮起。看 cost：BFS 的 S-C-G 步数最少但 cost 11，DFS 的 S-A-B-G cost 9，最便宜的 S-A-C-B-G 反而最长。这张 graph 第 1 站会一直用。

**第二件。** 下棋时照搬上面的做法，找一条从当前局面通到赢棋局面的 path。这条 path 上有一半的 action 是对手选的，对手不会照着走。就算改成把所有可能都看一遍，chess 的 game tree 大约有 $35^{100}\approx10^{154}$ 个 leaf。

**第三件。** 10 个带 noise 的点，用 degree-9 polynomial 去 fit，10 个点全部穿过，training error 是 0。拿新的点来检验，它的 mean squared error 是 0.860；degree-2 polynomial 在 training set 上的 error 是 0.103，在新的点上只有 0.095。

::fig[cs2109s-polyfit] 同一组 10 个点，三种 degree（第 6 站会细讲）。

这门课把 planning、game、learning 当成同一类问题：在一个大到不可能逐个看完的 space 里，找一个让某个 objective 最好的东西。前半门课（第 1 到 3 站）的 space 由规则给定，是所有的 path 或所有的局面；后半门课（第 4 到 10 站）的 space 是所有可能的 model，objective 由 data 给定。每一站都要回答同样的三个问题：在什么里面找，拿什么评价一个 candidate，靠什么信息可以不把整个 space 看一遍。后半门课还多一个问题：在 training data 上最好的那个，在没见过的 data 上还好不好。

## [search] Problem formulation 与 uninformed search

:::skip

### 把问题写成 search problem

Search algorithm 不认识“走迷宫”或“拼图”，它只认识五样东西：

- **state**：对当前情形的描述；
- **action**：在一个 state 里可以做的事；
- **transition model**：在 state $s$ 做 action $a$ 之后到达哪个 state；
- **action cost**：这一步花多少；
- **start state** 和 **goal test**：从哪里出发，怎样算到了。

一个 solution 是从 start state 到某个通过 goal test 的 state 的一串 action，它的 path cost 是各步 cost 之和。

五样里最需要动脑的是 state。State 只该保留“做决定需要的信息”，多一样，state space 就大一圈。CS188 用 Pacman 说明这一点。同一个迷宫，Pacman 有 120 个可站的位置，迷宫里有 30 个 food pellet：

| 问题 | goal test | state 里要记什么 | state 的个数 |
|---|---|---|---|
| 走到指定位置 | 位置等于终点 | 位置 | $120$ |
| 吃完所有 pellet | 30 个 pellet 都没了 | 位置，加上每个 pellet 还在不在 | $120\times2^{30}\approx1.3\times10^{11}$ |

第二个问题不能只记位置：站在同一格上，“还剩 3 个 pellet”和“已经吃完”是两种情形，goal test 对它们的回答不同。再把两个 ghost 的位置（各 12 种）和 Pacman 的朝向（4 种）也记进去，就是 $120\times4\times12^2\times2^{30}\approx7.4\times10^{13}$ 个 state，其中朝向对这两个问题都没有用。

State space 这么大，说明两件事。它不可能作为一张 graph 存在 memory 里，只能用到哪里、生成到哪里。逐个看完也不可能，所以 algorithm 之间的差别全在“先看哪里”。

这一站和下一站用同一张小 graph。

::fig[cs2109s-graph] 六个 state，九个 action，edge 上是 cost。从 S 到 G 一共有六条 path。

| path | cost |
|---|---|
| S-A-C-B-G | $1+2+2+3=8$ |
| S-A-B-G | $1+5+3=9$ |
| S-C-B-G | $4+2+3=9$ |
| S-A-C-G | $1+2+7=10$ |
| S-C-G | $4+7=11$ |
| S-D-G | $2+10=12$ |

人能列出这张表是因为看得见整张 graph。Algorithm 看不见，它手里只有 start state、一个“给我这个 state 的 successor”的 function，和 goal test。

### Search tree 与 frontier

从 S 出发，问出它的三个 successor，得到三条长度为 1 的 path；再选其中一条的末端继续问，得到更长的 path。Algorithm 实际保存的就是这些 path。每条 path 记成一个 **node**：末端的 state、parent node，以及从 start 到这里的 cost $g$。所有 node 连起来是一棵 **search tree**，root 是 start state。

已经生成、还没有被问过 successor 的 node 放在一个叫 **frontier** 的集合里。从 frontier 里取出一个 node、生成它的 successor，叫 **expand** 这个 node。整个 algorithm 只有一个循环：

```python
def tree_search(start, successors, is_goal, frontier):
    frontier.push(Node(state=start, parent=None, g=0))
    while not frontier.empty():
        node = frontier.pop()                      # 各种 algorithm 只在这一行不同
        if is_goal(node.state):
            return node
        for action, s2, cost in successors(node.state):
            frontier.push(Node(state=s2, parent=node, g=node.g + cost))
    return None
```

`pop` 取哪一个，决定了这是哪种 algorithm。

::fig[cs2109s-tree] 上面那张 graph 的 search tree。Graph 有 6 个 state，tree 有 14 个 node：一个 state 有几条 path 能到，它就在 tree 里出现几次。

State space graph 和 search tree 的差别在这张图里看得很清楚：B 出现了 3 次，G 出现了 6 次，每个 G 对应上面表里的一条 path。

### BFS 与 DFS

**Breadth-first search（BFS）** 的 frontier 是 FIFO queue，先放进去的先 pop。Successor 按字母顺序 push，过程是：

| 步 | pop | pop 并 expand 之后的 frontier（左边先出） |
|---|---|---|
| 1 | S | S-A，S-C，S-D |
| 2 | S-A | S-C，S-D，S-A-B，S-A-C |
| 3 | S-C | S-D，S-A-B，S-A-C，S-C-B，S-C-G |
| 4 | S-D | S-A-B，S-A-C，S-C-B，S-C-G，S-D-G |
| 5 | S-A-B | S-A-C，S-C-B，S-C-G，S-D-G，S-A-B-G |
| 6 | S-A-C | S-C-B，S-C-G，S-D-G，S-A-B-G，S-A-C-B，S-A-C-G |
| 7 | S-C-B | S-C-G，S-D-G，S-A-B-G，S-A-C-B，S-A-C-G，S-C-B-G |
| 8 | S-C-G | 通过 goal test，返回 |

BFS 一层一层地 pop，所以它返回的是 action 个数最少的 solution。S-C-G 只有两步，cost 是 11。只有当每个 action 的 cost 都相同时，“步数最少”才等于“cost 最小”。

**Depth-first search（DFS）** 的 frontier 是 stack，最后放进去的先 pop。它沿一条 path 一直走到底：pop S，pop S-A，pop S-A-B，pop S-A-B-G，返回。只 pop 了 4 次，cost 是 9。它返回的是它碰到的第一个 solution，和 cost 无关；换一个 push 的顺序，碰到的就是另一个。

### UCS：按 path cost 的顺序 pop

要 cost 最小，就让 frontier 按 $g$ 排序，每次 pop $g$ 最小的 node。Frontier 是 priority queue，这叫 **uniform-cost search（UCS）**。

| 步 | pop（它的 $g$） | 之后的 frontier（node 后面的数是 $g$，已排好） |
|---|---|---|
| 1 | S（0） | S-A 1，S-D 2，S-C 4 |
| 2 | S-A（1） | S-D 2，S-A-C 3，S-C 4，S-A-B 6 |
| 3 | S-D（2） | S-A-C 3，S-C 4，S-A-B 6，S-D-G 12 |
| 4 | S-A-C（3） | S-C 4，S-A-C-B 5，S-A-B 6，S-A-C-G 10，S-D-G 12 |
| 5 | S-C（4） | S-A-C-B 5，S-A-B 6，S-C-B 6，S-A-C-G 10，S-C-G 11，S-D-G 12 |
| 6 | S-A-C-B（5） | S-A-B 6，S-C-B 6，S-A-C-B-G 8，S-A-C-G 10，S-C-G 11，S-D-G 12 |
| 7 | S-A-B（6） | S-C-B 6，S-A-C-B-G 8，S-A-B-G 9，S-A-C-G 10，S-C-G 11，S-D-G 12 |
| 8 | S-C-B（6） | S-A-C-B-G 8，S-A-B-G 9，S-C-B-G 9，S-A-C-G 10，S-C-G 11，S-D-G 12 |
| 9 | S-A-C-B-G（8） | 通过 goal test，返回 cost 8 |

它为什么一定对？看“pop（它的 $g$）”那一列：0、1、2、3、4、5、6、6、8，从不下降。原因有两条。Pop 出来的是 frontier 里 $g$ 最小的；它的 child 的 $g$ 等于它的 $g$ 加上一个不为负的 cost，不会更小。所以之后 pop 出来的任何 node，$g$ 都不小于现在这个。

于是在第 9 步，任何别的通到 goal 的 path 只有两种可能：它已经在 frontier 里，$g\ge8$；或者它是 frontier 里某个 node 往下延伸出来的，那个 node 的 $g\ge8$，延伸之后只会更大。没有哪条 path 能比 8 小。

:::wrong Goal 一出现在 frontier 里，UCS 就可以返回了
第 3 步 expand S-D 时，S-D-G 被放进 frontier，这是第一个到达 G 的 node，cost 是 12。如果这时返回，答案比 optimal 的 8 贵了一半。第 4 步又出现 S-A-C-G，cost 10，还是不对。Optimal 的那个 node 直到第 6 步才生成。

放进 frontier 只说明“找到了一条到 G 的 path”。那一刻 frontier 里还有 $g=3$ 的 S-A-C，从它往下可能长出更便宜的 path，后来也确实长出来了。只有等 goal node 自己成为 frontier 里 $g$ 最小的那个，上面的论证才成立。所以 goal test 要放在 pop 之后，代码里正是这样写的。

MIT 6.034 的讲法是先假设有人直接告诉你答案是 8，问你怎么验证：把所有 cost 小于 8 的 path 都延伸到超过 8 为止。UCS 做的就是这件事。
:::

:::edge Cost 为负或为 0
论证里用到了“child 的 $g$ 不小于 parent 的 $g$”。有 negative cost 时这一条不成立，UCS 不再保证 optimal。Cost 可以为 0，但如果存在一串 cost 全是 0 的 action 可以无限走下去，UCS 会一直在里面 expand，永远轮不到别的 node。所以 completeness 需要每个 action 的 cost 至少是某个正数 $\varepsilon$。
:::

### 要算多久，占多少 memory

用三个数描述一棵 search tree：branching factor $b$（每个 node 有几个 successor），最浅的 solution 所在的 depth $d$，tree 的 maximum depth $m$。

BFS 要把 depth 不超过 $d$ 的 node 都生成出来，个数是 $1+b+b^2+\dots+b^d$，而且全部留在 memory 里。取 $b=10$，假设每秒生成 $10^6$ 个 node、每个 node 占 1 KB：

| $d$ | node 个数 | 时间 | memory |
|---|---|---|---|
| 4 | $1.1\times10^{4}$ | 0.011 秒 | 11 MB |
| 8 | $1.1\times10^{8}$ | 111 秒 | 111 GB |
| 12 | $1.1\times10^{12}$ | 12.9 天 | 1.1 PB |

先撑不住的是 memory。$d=8$ 时两分钟就能算完，但要 111 GB。

DFS 沿一条 path 往下走，frontier 里只有这条 path 上每个 node 的还没试过的 sibling，最多 $b\,m$ 个。$b=10$、$m=12$ 时是 120 个 node。代价是它可能一头扎进一条很深甚至无限深的 path，而 solution 就在旁边很浅的地方。

| | frontier | 一定能找到 solution 吗 | 找到的是 optimal 的吗 | time | memory |
|---|---|---|---|---|---|
| BFS | FIFO queue | 能 | 只在 cost 全相同时 | $O(b^d)$ | $O(b^d)$ |
| DFS | stack | tree 无限深时不能 | 不是 | $O(b^m)$ | $O(bm)$ |
| UCS | 按 $g$ 的 priority queue | 能（cost $\ge\varepsilon>0$） | 是 | $O(b^{C^*/\varepsilon})$ | $O(b^{C^*/\varepsilon})$ |
| Iterative deepening | stack | 能 | 只在 cost 全相同时 | $O(b^d)$ | $O(bd)$ |

UCS 那一行里 $C^*$ 是 optimal cost：它要把 $g<C^*$ 的 node 都 expand 掉，这些 node 的 depth 最多大约是 $C^*/\varepsilon$。最后一行是下面要讲的。

### Iterative deepening：用 DFS 的 memory 得到 BFS 的结果

给 DFS 加一个 depth limit $\ell$：depth 到了 $\ell$ 的 node 不再 expand，到了就回头。这叫 **depth-limited search（DLS）**。它的 memory 仍是 $O(b\ell)$，而且一定会停；但 $\ell$ 比最浅的 solution 浅时它找不到 solution，所以不 complete，作为 DFS 也不 optimal。事先知道 solution 有多深时，DLS 正合适：AY25/26 第 2 学期 Tutorial 1 的 Tower of Hanoi，$n$ 个 disc 的最短 solution 恰好是 $2^n-1$ 步，把 $\ell$ 设成它就行。

不知道深度时，让 $\ell=0,1,2,\dots$ 依次试，每次都从 root 重新开始，这叫 **iterative deepening search（IDS）**。第一次找到 solution 时，$\ell$ 恰好是最浅的 solution 的 depth，所以结果和 BFS 一样；每一轮都是 DFS，memory 只要 $O(bd)$。在上面的 graph 上：$\ell=0$ 只看 S；$\ell=1$ 看 S、A、C、D；$\ell=2$ 时在 S-C 下面碰到 G，返回 S-C-G。

每一轮都从头来，看起来很浪费。数一下。Depth 为 $i$ 的 node 有 $b^i$ 个，在 $\ell=i,i+1,\dots,d$ 这几轮里各被生成一次，共 $d-i+1$ 次。取 $b=10$、$d=5$：

$$\underbrace{5\times10+4\times10^2+3\times10^3+2\times10^4+1\times10^5}_{\text{iterative deepening}}=123{,}450,\qquad\underbrace{10+10^2+10^3+10^4+10^5}_{\text{BFS}}=111{,}110$$

只多了 11%。原因是最底下一层有 $10^5$ 个 node，上面所有层加起来才 $11{,}110$ 个；被重复得多的是浅层，而浅层的 node 很少。$b$ 越大，重复越不值一提；$b=2$、$d=5$ 时是 114 对 62，接近两倍，这是最坏的情形。

同一个 Tutorial 里有一道题把这几种 algorithm 放在一起选：一个 maze，最长的 path 有 100 步，而通常 10 步左右就能出去，要找最短的出口。BFS 能找到最短的，但要把 depth 10 以内的 node 全存着；DFS 省 memory，却可能先钻进 100 步深的 path；IDS 的 memory 是 $O(bd)$，找到的又是最浅的出口，所以选它。

:::edge 没有 visited memory 时怎样保证停下来
上面这张 graph 没有回头的 edge，tree search 总会停。很多问题的 action 可以撤销：PS1 的 Missionaries and Cannibals，船把两个人运过去，下一步又可以把同样两个人运回来，state 在两个之间来回，DFS 和 tree search 版的 BFS 都会在 search tree 里无限地往下长（BFS 仍会在有限的 depth 找到 solution，但如果 solution 不存在，它永远不停）。

办法是加一个 depth limit，而且这个 limit 可以从 state 的个数算出来。Action cost 都为正时，optimal 的 path 不会经过同一个 state 两次：如果经过了，把两次之间那一段剪掉，path 仍然通到 goal，cost 更小。所以 optimal 的 path 最多有 $|S|-1$ 个 action，$|S|$ 是 state 的个数（或者它的任何一个 upper bound）。把 DLS 或 IDS 的 limit 设到这里，search 一定会停，而且不会漏掉 optimal 的 solution。PS1 Task 1.5 要的就是对 $m$ 个 missionary、$c$ 个 cannibal 的情形给出这样一个 bound，再说明这样做是否 complete、是否 optimal。
:::

### Graph search：同一个 state 不 expand 两次

回到 UCS 的那张表。第 5 步 pop 的 S-C 和第 4 步的 S-A-C 末端都是 C；第 7、8 步又把 B expand 了两次。同一个 state 的 successor 被重复生成，后面跟着的整棵 subtree 也被重复搜索。

办法是记一个 `expanded` 集合：pop 出一个 node 时，如果它的 state 已经在集合里，直接丢掉；否则把 state 加进去再 expand。这叫 **graph search**，前面那种叫 tree search。CS2109S 的讲义和 problem set 把它们叫做 search **with visited memory** 和 search **without visited memory**，说的是同一件事。UCS 的 9 步里，第 5、7、8 步被丢掉。

丢掉的那些会不会恰好是更好的 path？对 UCS 不会。上面已经说明 pop 出来的 $g$ 从不下降，所以一个 state 第一次被 pop 时带着的就是到它的最小 cost：C 第一次被 pop 是经过 A 的那条，$g=3$；后来的 S-C 是 $g=4$。

重复的规模可以大得多。在一个没有墙的 grid 上，从一个 cell 出发走 10 步，不同的 path 有 $4^{10}\approx10^6$ 条，而 10 步之内能到的 cell 只有 $2\times10^2+2\times10+1=221$ 个。Tree search 面对的是前一个数，graph search 面对的是后一个。代价是 `expanded` 集合要占和 state 个数一样多的 memory，DFS 省 memory 的好处就没有了。

:::from
“search problem 由哪几样东西组成”、world state 与 search state 的区别、Pacman 的两个问题和 $120\times4\times12^2\times2^{30}$ 的数法，来自 [CS188 textbook 1.2](https://inst.eecs.berkeley.edu/~cs188/textbook/search/state.html)。“frontier 里放的是 partial plan，各种 strategy 只差在 pop 哪一个”、tree search 的 pseudocode、三种 algorithm 的 complexity，来自 [CS188 textbook 1.3](https://inst.eecs.berkeley.edu/~cs188/textbook/search/uninformed.html)；那一节没有讲 iterative deepening。“先假设有人告诉你答案，问怎么验证”和 goal test 要在 dequeue 时做，来自 [MIT 6.034 Lecture 5](https://ocw.mit.edu/courses/6-034-artificial-intelligence-fall-2010/resources/lecture-5-search-optimal-branch-and-bound-a/) 的 transcript。六个 state 的 graph 和三张过程表是为这一页构造并实际跑出来的。

和 NUS 的材料核过的部分：search problem 的六个组成（state、initial state、goal、action、transition model、action cost）、各 algorithm 的 completeness 与 optimality 条件（BFS 要求 cost 全相同，UCS 要求 cost 为正）、DLS 与 IDS、“with / without visited memory”的叫法，对得上 AY25/26 两个学期的 lecture 笔记（[第 2 学期 Week 2](https://github.com/Harjun751/CS2109S-notes)、[第 1 学期 L2](https://github.com/chongpig/CS2109S)）。Tower of Hanoi 与 maze 的两道题取自 [AY25/26 第 2 学期 Tutorial 1 的讲解](https://www.comp.nus.edu.sg/~mtyeung/cs2109s_2520/cs2109s_tut01_post.pdf)（只读到 WebFetch 转述的要点，原题的图没有读到；讲解里写的 Hanoi 深度是“2n − 1”，按 $T(n)=2T(n-1)+1$ 应为 $2^n-1$，这里用后者）。Missionaries and Cannibals 的要求取自 [AY26/27 第 1 学期 PS1 handout](https://github.com/kahei9299/cs2109s) 的 Task 1.4 到 1.8。

## [astar] A* 与 heuristic

:::skip
能在小 graph 上手动跑 A* 并写出每一步的 $f$；能造一个 heuristic 高估导致 A* 返回错误答案的例子，并指出 optimality 的 proof 是哪一步断了；能说出 graph search 为什么还需要 consistency，就可以去第 3 站。
:::

### UCS 的力气花在了哪里

上一站 UCS 的第 3 步 expand 了 S-D，因为它的 $g=2$ 很小。但 D 往后只有一条 cost 为 10 的 edge，经过它的 solution 的 cost 是 12。UCS 只知道已经花了多少，不知道还要花多少，所以它朝各个方向一视同仁地往外推。

::fig[cs2109s-grid] 动图，同一个 grid，每走一格 cost 为 1，从 S 到 G 要绕过中间的墙。两边每一拍各 expand 一格：看浅色区域往哪个方向长。左边 UCS 不分方向地一圈圈扩，pop 出 G 之前 expand 了 101 个空 cell 里的 98 个；右边 A* 一直朝 G 那边扩，49 个就停，返回的 path cost 相同。

右边多用的信息是一个对“还要花多少”的估计。记 $h(n)$ 为从 node $n$ 的 state 到 goal 的 cost 的估计值，叫 **heuristic**。那么

$$f(n)=g(n)+h(n)$$

估计的是“经过 $n$ 的最便宜的 solution 一共要花多少”。每次 pop $f$ 最小的 node，就是 **A\***。它和 UCS 只差在 priority 上：$h$ 恒为 0 时 A\* 就是 UCS。

只按 $h$ 排序行不行？那叫 greedy best-first search。在上一站的 graph 上（$h$ 的值标在图里每个 state 旁边）：S 的 successor 里 C 的 $h=5$ 最小，pop S-C；它的 successor 里 G 的 $h=0$ 最小，pop S-C-G，返回 cost 11。它完全不看已经花掉的 $g$，所以不保证 optimal。

### 走一遍 A\*

Heuristic 取图上标的值：$h(S)=7$，$h(A)=6$，$h(C)=5$，$h(B)=3$，$h(D)=9$，$h(G)=0$。

| 步 | pop | $g$ | $h$ | $f$ | 之后的 frontier（node 后面的数是 $f$） |
|---|---|---|---|---|---|
| 1 | S | 0 | 7 | 7 | S-A 7，S-C 9，S-D 11 |
| 2 | S-A | 1 | 6 | 7 | S-A-C 8，S-C 9，S-A-B 9，S-D 11 |
| 3 | S-A-C | 3 | 5 | 8 | S-A-C-B 8，S-C 9，S-A-B 9，S-A-C-G 10，S-D 11 |
| 4 | S-A-C-B | 5 | 3 | 8 | S-A-C-B-G 8，S-C 9，S-A-B 9，S-A-C-G 10，S-D 11 |
| 5 | S-A-C-B-G | 8 | 0 | 8 | 通过 goal test，返回 cost 8 |

5 次 pop，UCS 是 9 次。S-D 的 $f=2+9=11$，一直排在后面，始终没有被 expand。

### Admissible：凭什么 pop 出 goal 就能停

:::wrong 只要 $h$ 大体反映远近，A\* 找到的就是 optimal 的 path
把 $h(B)$ 从 3 改成 7，其余不变。B 到 G 的真实 cost 是 3，现在高估了。

前两步和上表相同。第 3 步 pop S-A-C 后，S-A-C-B 的 $f=5+7=12$，S-A-C-G 的 $f=10$。Frontier 是 S-C 9，S-A-C-G 10，S-D 11，S-A-C-B 12，S-A-B 13。第 4 步 pop S-C，生成 S-C-G（$f=11$）和 S-C-B（$f=13$）。第 5 步 pop S-A-C-G，它通过 goal test，A\* 返回 cost 10。

Optimal 的 path 上的 node S-A-C-B 就在 frontier 里，但它的 $f=12$ 排在 cost 为 10 的 goal node 后面。一次高估，让“正确的路”看起来比“一个不是最好的终点”还贵。
:::

要排除这种事，只需要一个条件。记 $h^*(n)$ 为从 $n$ 到 goal 的真实最小 cost。如果对每个 $n$ 都有

$$0\le h(n)\le h^*(n)$$

就说 $h$ 是 **admissible** 的：它从不高估。拿例子检验。真实值是 $h^*(S)=8$，$h^*(A)=7$，$h^*(C)=5$，$h^*(B)=3$，$h^*(D)=10$；图上的 $h$ 是 7、6、5、3、9，每个都不超过，admissible。改过的 $h(B)=7>3$，不 admissible。

**Admissible 的 $h$ 下，A\*（tree search）返回的一定是 optimal solution。** 设 optimal cost 是 $C^*$，假设 A\* 即将 pop 一个 cost 为 $C'>C^*$ 的 goal node $G'$。Optimal 的 path 从 root 出发，root 最先被 expand，所以这条 path 上总有一个 node $n$ 已经生成、还没被 expand，此刻在 frontier 里。对它：

$$f(n)=g(n)+h(n)\ \le\ g(n)+h^*(n)\ =\ C^*$$

不等号是 admissibility；最后的等号是因为 $n$ 在 optimal 的 path 上，到 $n$ 已经花的加上从 $n$ 到 goal 最少还要花的，正是 $C^*$。而 $G'$ 是 goal，$h(G')=0$，所以 $f(G')=C'>C^*\ge f(n)$。Frontier 里有 $f$ 更小的 node，A\* 不会 pop $G'$，矛盾。

对照例子：$n$ 是 S-A-C-B，$g=5$。$h(B)=3$ 时 $f=8\le C^*=8$，排在 S-A-C-G（$f=10$）前面。$h(B)=7$ 时 $f=12$，proof 里“$\le$”那一步不成立，后面就全错了。

Admissibility 给出的是“提前停下来”的权利：goal 一被 pop，不必再看 frontier 里剩下的东西。它没有免除的是：$f<C^*$ 的 node A\* 仍然都要 expand。$h$ 越接近 $h^*$，这样的 node 越少。

### Graph search 还要多一个条件

照上一站的办法加上 `expanded` 集合，已经 expand 过的 state 不再 expand。这回换一组 $h$：$h(A)=7$，$h(C)=0$，其余不变。它仍然 admissible（$7\le7$，$0\le5$）。

| 步 | pop | $g$ | $f$ | 发生了什么 |
|---|---|---|---|---|
| 1 | S | 0 | 7 | 生成 S-C（$f=4+0=4$），S-A（$f=1+7=8$），S-D（11） |
| 2 | S-C | 4 | 4 | C 记为已 expand；生成 S-C-B（$f=6+3=9$），S-C-G（11） |
| 3 | S-A | 1 | 8 | 生成 S-A-C，但 C 已 expand，丢掉；生成 S-A-B（9） |
| 4 | S-C-B | 6 | 9 | B 记为已 expand；生成 S-C-B-G（9） |
| 5 | S-C-B-G | 9 | 9 | 返回 cost 9 |

（第 4 步时 S-A-B 的 $f$ 也是 9，先 pop 哪一个结果都一样。）答案是 9，不是 8。出错在第 3 步：到 C 的好 path（经过 A，$g=3$）被丢掉了，因为 C 已经沿着差的那条 path（$g=4$）expand 过。而 C 之所以先沿差的 path 被 pop，是因为 $h(A)=7$ 让好 path 上的 S-A 排到了后面。

上一站 UCS 用 graph search 没有出事，靠的是“pop 出来的 $g$ 从不下降”。这里对应的量是 $f$，而这次 pop 出来的 $f$ 是 7、4、8、9、9，下降过。沿着 S→A→C 这条 path 看，$f$ 从 8 变成 $3+0=3$，一步掉了 5。

要 $f$ 沿任何 path 都不下降，需要对每一条 edge $n\to n'$ 都有

$$h(n)\le c(n,n')+h(n')$$

这叫 **consistent**。它说的是：走一步，估计值的下降不能超过这一步真实花掉的 cost。有了它，

$$f(n')=g(n)+c(n,n')+h(n')\ \ge\ g(n)+h(n)=f(n)$$

检验：这组 $h$ 在 edge A→C 上是 $7\le2+0$，不成立。图上原来那组 $h$，九条 edge 逐条看：S→A 是 $7\le1+6$，S→C 是 $7\le4+5$，S→D 是 $7\le2+9$，A→B 是 $6\le5+3$，A→C 是 $6\le2+5$，C→B 是 $5\le2+3$，C→G 是 $5\le7+0$，B→G 是 $3\le3+0$，D→G 是 $9\le10+0$，全部成立。前面那张 A\* 的表里 $f$ 那一列是 7、7、8、8、8，没有下降。

$h$ consistent 时，一个 state 第一次被 pop 时带着的 $g$ 就是到它的最小 cost，理由和 UCS 那里一样，只是把 $g$ 换成 $f$：假如 state $s$ 第一次被 pop 时走的不是最便宜的 path，那么最便宜的那条 path 上有某个 node $n$ 还在 frontier 里；沿这条 path $f$ 不下降，所以 $f(n)\le g^*(s)+h(s)<g(s)+h(s)$，$n$ 应该先被 pop，矛盾。所以丢掉后来的 path 是安全的，graph search 的 A\* 返回 optimal solution。

Consistent 的 $h$（且 $h(\text{goal})=0$）一定 admissible：沿着从 $n$ 到 goal 的最便宜的 path 把不等式一条条接起来，$h(n)\le c_1+h(n_1)\le c_1+c_2+h(n_2)\le\dots\le h^*(n)$。反过来不成立，上面那组 $h$ 就是 admissible 而不 consistent 的。

:::edge Tree search 不需要 consistency
同样用 $h(A)=7$、$h(C)=0$，但不设 `expanded` 集合。第 3 步生成的 S-A-C 留在 frontier 里，$f=3$，下一步就被 pop，C 被第二次 expand，之后得到 S-A-C-B（$f=8$）和 S-A-C-B-G（$f=8$），返回 cost 8。Tree search 靠重复 expand 把好的 path 找了回来，代价是上一站说的重复。

CS188 的 graph search 写法介于两者之间：`expanded` 里记下每个 state 被 expand 时的 $g$；pop 出一个 node 时，只有当它的 state 没出现过，或者这次的 $g$ 比记下的小，才 expand。在这组 $h$ 上，第 3 步之后 pop 出的 S-A-C 带着 $g=3<4$，C 被重新 expand，最后同样返回 cost 8。这样 admissible 就够了，代价是一个 state 可能被 expand 不止一次；consistent 时这种重新 expand 从不发生。PS1 Task 2.2 要求的是另一件事：一个 state 还在 frontier 里、没被 expand 时找到了更好的 path，就更新它在 priority queue 里的记录，这对已经 expand 过的 state 不起作用，所以那里仍然要 consistent 的 heuristic。
:::

### Heuristic 从哪里来，哪个更好

Admissible 的 heuristic 有一个通用的来源：把原问题的限制去掉一些，得到一个 **relaxed problem**，用它的 optimal cost 当 $h$。原问题的每个 solution 在 relaxed problem 里仍然是 solution，所以 relaxed problem 的 optimal cost 不会更大，$h\le h^*$ 自动成立。

- Grid 上假装没有墙：optimal cost 是 Manhattan distance $|x_1-x_2|+|y_1-y_2|$。上面那张图用的就是它。
- 8-puzzle（3×3 的盘上 8 块 tile 和一个空格，每步把一块相邻的 tile 滑进空格）：假装 tile 可以直接跳到任何位置，optimal cost 是不在原位的 tile 的块数，记作 $h_1$；假装 tile 可以滑到相邻的格子而不管那里有没有别的 tile，optimal cost 是每块 tile 到自己目标位置的 Manhattan distance 之和，记作 $h_2$。

一块不在原位的 tile 的 Manhattan distance 至少是 1，所以处处 $h_2\ge h_1$，这叫 $h_2$ **dominate** $h_1$。A\* 要 expand 的是 $g+h<C^*$ 的 node，$h$ 大了，满足这个条件的 node 只会变少。实际跑一个 instance：

$$\begin{array}{|c|c|c|}\hline7&2&4\\\hline5&&6\\\hline8&3&1\\\hline\end{array}\ \longrightarrow\ \begin{array}{|c|c|c|}\hline1&2&3\\\hline4&5&6\\\hline7&8&\\\hline\end{array}\qquad\text{optimal solution 是 20 步}$$

| heuristic | start state 上的值 | expand 的 state 个数 |
|---|---|---|
| $h=0$（UCS） | 0 | 47,875 |
| $h_1$：不在原位的 tile 数 | 6 | 3,666 |
| $h_2$：Manhattan distance 之和 | 14 | 282 |

三次返回的都是 20 步。手头有几个 admissible 的 heuristic 而谁也不 dominate 谁时，逐点取 maximum：每个都不超过 $h^*$，maximum 也不超过。

“不在原位的 tile 数”在 8-puzzle 上 admissible，是因为一步只挪一块 tile，最多让一块从“不在原位”变成“在原位”。这个前提换一个问题就不成立。PS1 的 2-D Rubik's cube 一步把一整行（或一整列）循环挪一格，一个 $3\times3$ 的 cube 上一步就能让 3 块同时归位。Handout 里那个例子的最后一步是从 $\begin{bmatrix}R&R&B\\G&G&R\\B&B&G\end{bmatrix}$ 把 column 2 往上挪一格，到达 goal $\begin{bmatrix}R&R&R\\G&G&G\\B&B&B\end{bmatrix}$：这一步之前 column 2 的 3 块都不在原位，数块数得 $h=3$，而真实的 $h^*=1$。所以直接数不在原位的块数会高估，不 admissible。Task 2.1 的提示正是让你先想清楚“一步最多能让几块归位”，再从这里得到一个既 admissible 又 consistent 的 heuristic（consistency 在那里写成 $h(n)\le1+h(n')$，因为每步 cost 是 1）。

:::back
A\* 是在[第 1 站](#search)的 UCS 上只改了 priority；“pop 时才做 goal test”和 graph search 的 `expanded` 集合都原样沿用。
:::

## [adv] Local search 与 adversarial search

:::skip
能解释 hill climbing 为什么会停在一个不是 solution 的 state 上，以及 simulated annealing 靠什么离开；能在两三层的 game tree 上手算 minimax value，指出 alpha-beta 会剪掉哪些 leaf，并说清剪掉它们为什么不影响结果，就可以去第 4 站。
:::

### 只要终点、不要 path 的问题

8-queens：在 8×8 的棋盘上放 8 个 queen，任何两个不在同一 row、同一 column、同一 diagonal 上。前两站的 formulation 在这里不合适：没有人关心 queen 是按什么顺序放上去的，要的只是最后那个摆法。每个 column 放一个 queen 的摆法有 $8^8=16{,}777{,}216$ 种，其中绝大多数不是 solution。

换一种 formulation。State 是一个完整的摆法，用每个 column 里 queen 所在的 row 表示。给每个 state 打一个分：互相 attack 的 queen 有几对。分数为 0 就是 solution。从某个 state 出发，每次只做一个小改动（把一个 queen 在它的 column 里挪到另一个 row），往分数低的地方走。这叫 **local search**：不记 path，不记 frontier，memory 里只有当前这一个 state。

CS2109S 的讲义把这个打分的 function 叫 **evaluation function**，并且约定越大越好：8-queens 用的是“safe 的 queen 有几个”，要 maximize。两种写法只差一个负号，任何 minimize $f$ 的问题都可以改成 maximize $-f$。下面沿用“互相 attack 的对数”，往小的方向走。

最直接的走法是 **hill climbing**：算出所有 neighbor 的分数，走到最好的那个；没有比现在更好的 neighbor 就停。讲义里的 pseudocode（越大越好的写法）是：

```python
current = initial_state
while True:
    best = max(successors(current), key=eval)
    if eval(best) <= eval(current):      # 没有严格更好的 neighbor
        return current
    current = best
```

（分数越低越好时，“climb”是往下走，名字不改。）它没有 goal test，停下来的那个 state 就是答案；跑得越久答案通常越好，讲义称之为 any-time property。

用 4-queens 走一遍，这时每个 state 有 $4\times3=12$ 个 neighbor。从 $(2,1,4,1)$ 出发，意思是四个 column 的 queen 分别在 row 2、1、4、1。互相 attack 的有 3 对：column 1 与 2（diagonal），column 1 与 3（diagonal），column 2 与 4（同一 row）。

::fig[cs2109s-queens] 左边是出发的 state。右边是另一个 state，它的 12 个 neighbor 没有一个比它好。

左图里最小的数是 1，在 column 1、row 3：把 column 1 的 queen 挪过去，得到 $(3,1,4,1)$，只剩 column 2 与 4 同在 row 1 这一对。再算它的 12 个 neighbor，把 column 4 的 queen 挪到 row 2 得到 $(3,1,4,2)$，分数为 0，是 solution。两步走完。

:::wrong 每一步都走到更好的 neighbor，最后一定停在 solution 上
右图的 $(3,1,2,4)$ 只有 1 对 queen 互相 attack（column 2 与 3，diagonal）。它的 12 个 neighbor 里最小的分数也是 1，没有比它更好的。Hill climbing 停在这里，而它不是 solution。这样的 state 叫 local minimum：在自己的 neighbor 里最好，在整个 state space 里不是。（讲义按 maximize 的写法叫 local maximum；一片分数都相同、走不出去的平地叫 shoulder。）

这不是 4-queens 的特例。对 8-queens 从随机的 state 出发跑 5000 次 hill climbing：解出来的只有 14.3%，其余 85.7% 都停在了 local minimum 上。成功的那些平均走 4.1 步，失败的平均 3.1 步就停了。
:::

出路有三条，都是在“只往好处走”上松一点口。

**允许 sideways move。** 没有更好的 neighbor 时，允许走到一样好的。$(3,1,2,4)$ 把 column 3 的 queen 挪到 row 4 得到 $(3,1,4,4)$，分数仍是 1；再把 column 4 的 queen 挪到 row 2，就到了 solution $(3,1,4,2)$。同一个 8-queens 实验里允许最多连续 100 次 sideways move，成功率从 14.3% 升到 93.6%，成功时平均走 18.6 步。要设上限，是因为一片分数全相同的 state 上可以无止境地来回走。

**Random restart。** 停住了就换一个随机的 state 重新开始。每次成功的 probability 是 $p=0.143$，平均要试 $1/p\approx7$ 次，其中约 6 次失败，总共大约 $6\times3.1+4.1\approx23$ 步。PS2 Task 1.6 要你给 TSP 的 hill climbing 加的就是这一条：跑 $R>1$ 次，返回最好的那个。

**有时接受变差。** 这是下一小节。

### Simulated annealing：按 probability 接受变差的一步

:::skip
AY25/26 两个学期的 lecture 笔记里都没有 simulated annealing，它只出现在 tutor 的一个 bonus lab 里。只为考试复习可以跳过；跳过之后少的是“怎样系统地离开 local minimum”的一个答案。
:::

每一步随机挑一个 neighbor，算分数的变化 $\Delta E=E(\text{neighbor})-E(\text{current})$，这里分数越低越好。

- $\Delta E\le0$（没有变差）：走过去。
- $\Delta E>0$（变差了）：以 probability $e^{-\Delta E/T}$ 走过去，否则留在原地。

$T$ 叫 temperature，是一个随时间慢慢降低的正数。这个 probability 的大小：

| $T$ | $\Delta E=1$ | $\Delta E=2$ | $\Delta E=3$ |
|---|---|---|---|
| 10 | 0.905 | 0.819 | 0.741 |
| 2 | 0.607 | 0.368 | 0.223 |
| 1 | 0.368 | 0.135 | 0.050 |
| 0.5 | 0.135 | 0.018 | 0.002 |
| 0.2 | 0.007 | $5\times10^{-5}$ | $3\times10^{-7}$ |

横着看：变差得越多，越不容易被接受。竖着看：$T$ 很高时几乎什么都接受，state 在四处乱走；$T$ 很低时几乎只接受不变差的，和 hill climbing 没有区别。Temperature 从高降到低，search 就从“到处看”逐渐变成“在当前这一片里往下走”。在右图的 $(3,1,2,4)$ 上，$T=1$ 时一个让分数变成 2 的 neighbor 有 0.368 的 probability 被接受，它不会被困住。

理论上的保证是：$T$ 降得足够慢，找到 global optimum 的 probability 趋于 1。“足够慢”在实际里往往慢得用不起，所以 temperature 怎么降是要调的。Bonus lab 的参考解法是越大越好的写法，接受条件写成 `delta > 0 or rand() < exp(delta / temp)`，$\Delta$ 为负时 $e^{\Delta/T}<1$，和上面的 $e^{-\Delta E/T}$ 是同一个式子换了 sign；它从 $T=0.1$ 开始，每步乘 0.9999。

### 有对手的时候

Game 里“找一条到赢的 path”不成立，因为 path 上一半的 action 由对手决定。要找的不是一条 path，是一个 strategy：对手每一种可能的走法，自己都准备好下一步。

两个 player 叫 MAX 和 MIN，轮流走。Game 结束的 state 叫 terminal state，带一个 utility，MAX 想让它大，MIN 想让它小。所有走法构成 game tree。假设双方都走得最好，每个 state 的 value 可以从下往上定义：

$$V(s)=\begin{cases}\text{utility}(s)&s\text{ 是 terminal state}\\[2pt]\max_{s'}V(s')&\text{轮到 MAX}\\[2pt]\min_{s'}V(s')&\text{轮到 MIN}\end{cases}$$

$s'$ 取遍 $s$ 的 successor。这叫 **minimax value**。MAX 在 root 选 value 最大的那个 successor。

::fig[cs2109s-alphabeta] 动图。Root 轮到 MAX，下面三个 node 轮到 MIN，九个 leaf 是 terminal state 的 utility。动起来时按 DFS 顺序一个个 evaluate leaf（实心的是正在看的那个），node 上的数是那一刻已知的 bound：看中间那个 MIN node 一出现“≤ 2”，后面两个 leaf 就被剪掉。

三个 MIN node 的 value 是 $\min(3,12,8)=3$，$\min(2,4,6)=2$，$\min(14,5,2)=2$。Root 的 value 是 $\max(3,2,2)=3$，MAX 走左边。

:::wrong MAX 应该朝 utility 最大的那个 leaf 走
九个 leaf 里最大的是 14，在右边那个 MIN node 下面。MAX 走右边之后轮到 MIN 选，MIN 选 2。MAX 拿到的是 2，不是 14。

Minimax value 说的是“对手走得最好时自己能保证拿到多少”。左边保证 3，中间和右边都只保证 2。Root 的 3 既不是 MAX 最想要的 14，也不是 MIN 最想要的 2，是双方互相牵制的结果。
:::

算 minimax value 是对 game tree 做一次 DFS，time 是 $O(b^m)$，memory 是 $O(bm)$。Chess 的 $b\approx35$，一局大约 $m\approx100$ 步，leaf 的个数是 $35^{100}\approx10^{154}$。MIT 6.034 给过一个对照：宇宙里大约有 $10^{80}$ 个 atom，从 Big Bang 到现在大约 $10^{26}$ nanosecond，就算每个 atom 每 nanosecond evaluate 一个 leaf，到现在也只做了 $10^{106}$ 次。所以需要两样东西：少看一些 node，以及不必走到 terminal state。

### Alpha-beta：剪掉不可能影响结果的部分

按 DFS 的顺序重走上面的例子，这次留意每一刻已经知道了什么。

1. 左边的 MIN node 看完 3、12、8，value 是 3。Root 现在知道：自己至少能拿到 3。
2. 中间的 MIN node 先看到 2。它是 MIN node，value 是几个 leaf 的 minimum，所以不管剩下两个 leaf 是多少，它的 value 不会超过 2。
3. Root 已经有一个 value 为 3 的选择。一个 value 不超过 2 的 node，root 不会选。剩下的两个 leaf 不用看了。
4. 右边的 MIN node 先看到 14：value 不超过 14，还可能比 3 好，继续。看到 5：不超过 5，还可能比 3 好，继续。看到 2：value 是 2。
5. Root 的 value 是 $\max(3,\ \text{不超过 }2,\ 2)=3$。

九个 leaf 只 evaluate 了 7 个，结果相同。

**为什么结果一定相同。** 把被剪掉的两个 leaf 换成任意的数 $x$、$y$。中间 MIN node 的 value 是 $\min(2,x,y)\le2$，root 的 value 是 $\max(3,\ \min(2,x,y),\ 2)$。第二个数不超过 2，小于第一个数 3，所以 maximum 始终是 3，和 $x$、$y$ 无关。Alpha-beta 没有做任何近似，它只是不去算那些已经知道不影响结果的数。

写成 algorithm，要沿着 DFS 往下带两个数：

- $\alpha$：从 root 到当前 node 的 path 上，MAX 已经能保证的最好的 value（一个 lower bound）；
- $\beta$：这条 path 上 MIN 已经能保证的最好的 value（一个 upper bound）。

在一个 MIN node 里，一旦它的 value 降到 $\alpha$ 或以下，上面的 MAX 不会走进这里，停。在一个 MAX node 里，一旦它的 value 升到 $\beta$ 或以上，上面的 MIN 不会让局面走到这里，停。

CS2109S 讲义的写法是两个互相调用的 function：

```python
def max_value(state, alpha, beta):
    if is_terminal(state):
        return utility(state)
    v = -inf
    for next_state in expand(state):
        v = max(v, min_value(next_state, alpha, beta))
        alpha = max(alpha, v)
        if v >= beta:            # 上面的 MIN 已有不超过 beta 的选择，不会放 MAX 走到这里
            return v
    return v

def min_value(state, alpha, beta):
    if is_terminal(state):
        return utility(state)
    v = +inf
    for next_state in expand(state):
        v = min(v, max_value(next_state, alpha, beta))
        beta = min(beta, v)
        if v <= alpha:           # 上面的 MAX 已有不低于 alpha 的选择，不会走进这里
            return v
    return v
```

去掉 `alpha`、`beta` 两个参数和两行 `if`，就是普通的 minimax。从 `max_value(root, -inf, +inf)` 开始，例子里各个 node 上的 $\alpha$、$\beta$ 是：

| 时刻 | 所在的 node | $\alpha$ | $\beta$ |
|---|---|---|---|
| 开始 | root | $-\infty$ | $+\infty$ |
| 看完 3、12、8 | 左 MIN node | $-\infty$ | 3，返回 3 |
| 左边返回之后 | root | 3 | $+\infty$ |
| 进入 | 中 MIN node | 3 | $+\infty$ |
| 看完 2 | 中 MIN node | 3 | 2，$v=2\le\alpha$，停，返回 2 |
| 进入，依次看完 14、5、2 | 右 MIN node | 3 | 14，5，2，返回 2 |
| 结束 | root | 3 | $+\infty$，返回 3 |

中间那个 node 返回的 2 只是它 value 的一个 upper bound（剩下的 leaf 如果是 1 和 0，它的真实 value 是 0）。Root 只需要知道它不超过 3，这就够了。

### 能剪多少，取决于先看哪个

右边的 MIN node 一个 leaf 也没剪掉，因为它的三个 leaf 排成了 14、5、2，决定它 value 的 2 排在最后。如果顺序是 2、5、14，看完 2 就能停，整棵 tree 只需 evaluate 5 个 leaf。反过来，把三个 subtree 的顺序换成中、右、左（root 最后才看到 value 为 3 的那个），实际跑出来 9 个 leaf 一个也剪不掉。

最好的顺序是每个 node 都先看对当前 player 最有利的 successor。这时需要 evaluate 的 leaf 个数是

$$b^{\lceil m/2\rceil}+b^{\lfloor m/2\rfloor}-1\ \approx\ 2\,b^{m/2}$$

例子里 $b=3$、$m=2$：$3+3-1=5$，和上面数的一样。Exponent 从 $m$ 变成 $m/2$，意思是同样的时间可以多看一倍的 depth。按 Deep Blue 的速度，每秒 $2\times10^8$ 次 evaluation、每步想 3 分钟，一共 $3.6\times10^{10}$ 次。$b=35$ 时，不剪只能看到 depth $\log_{35}(3.6\times10^{10})\approx6.8$；按最好的顺序剪，能看到 $2\log_{35}(1.8\times10^{10})\approx13.3$。

### 走不到 terminal state：evaluation function 与 cutoff

Depth 13 离一局棋的结束还很远。实际的程序在某个 depth 停下，把停下时的 state 当作 leaf，用一个 **evaluation function** 估计它的 value。常见的形式是若干 feature 的 weighted sum，$\text{Eval}(s)=w_1f_1(s)+\dots+w_nf_n(s)$。CS188 举的 checkers 的例子是：自己的 king 数乘 2，加自己的 pawn 数，减 2 倍对手的 king 数，减对手的 pawn 数。Minimax 和 alpha-beta 原样不变，只是 leaf 上的数从真实的 utility 换成了估计值，得到的 move 不再保证是最好的；看得越深，估计越靠谱。

讲义对这件事的说法很精确：带 cutoff 和 evaluation function 的 minimax 返回的 move，对“cutoff 处的 evaluation function”是 optimal 的，对真实的 minimax value 则可能不是。这里的 heuristic 和第 2 站的不是一回事，admissible、consistent 这两个概念在 adversarial search 里不适用；要求的是它的值落在最小和最大的 utility 之间（任何一个 terminal state 都比非 terminal 的估计更确定），并且算起来不贵。PS2 的 Breakthrough 正是这样设的：black 赢的 utility 是 `WIN` $=21092109$，white 赢是 $-$`WIN`，cutoff 处给出的 heuristic 是“black 的棋子数减 white 的棋子数”，$6\times6$ 的盘上它的绝对值不超过 36，远在 $\pm$`WIN` 之内。Task 2.6 要你换一个也考虑棋子离终点有多远的 heuristic。

事先并不知道规定的时间里能看到多深。办法是第 1 站的 iterative deepening：先做 depth 1 的完整 search，再做 depth 2，再做 depth 3，时间到了就用最后一次完成的结果，任何时刻手里都有一个可用的 move。代价和第 1 站算的一样小：depth $d-1$ 的 search 要 $b^{d-1}$ 次 evaluation，是 depth $d$ 的 $1/b$；之前所有层加起来是 $1+b+\dots+b^{d-1}=\frac{b^d-1}{b-1}$，也只是 depth $d$ 那一次的 $\frac{1}{b-1}$ 左右，$b=35$ 时约 3%。浅层 search 的结果还有一个用处：用它给 successor 排序，下一轮 alpha-beta 就更接近最好的顺序。

:::edge 对手走得不好时
Minimax 假设 MIN 每一步都走得最好。对手如果不是这样，MAX 拿到的只会不少于 minimax value，这是一个保证。但 minimax 不会去利用对手的弱点：例子里如果知道对手经常出错，走右边有机会拿到 14 或 5，minimax 仍然走左边拿稳的 3。
:::

:::back
Minimax 是[第 1 站](#search)的 DFS，memory 只要 $O(bm)$；按时间逐层加深就是那里的 iterative deepening，“重复的代价很小”是同一个算式。
:::

## [dt] Decision tree 与 information gain

:::skip
能对一个小 dataset 手算每个 feature 的 information gain 并选出 split；能说出 entropy 比 training error rate 好在哪里；能解释 training error 接近 0 的 tree 为什么在新 data 上更差，以及 validation set 和 test set 各自用来做什么，就可以去第 5 站。
:::

### 从 data 里找规则

前三站的规则是给定的。从这一站起，规则要从 example 里找。手头有 8 封已经标好的邮件，每封记了三个 feature：

| # | Link（含链接） | Known（发件人认识） | Long（正文长） | Spam |
|---|---|---|---|---|
| 1 | Y | N | Y | + |
| 2 | Y | N | N | + |
| 3 | Y | N | N | + |
| 4 | N | N | Y | + |
| 5 | N | N | N | − |
| 6 | N | N | N | − |
| 7 | Y | Y | Y | − |
| 8 | N | Y | Y | − |

要找一个 function $h$，输入三个 feature，输出 + 或 −，而且在没见过的邮件上也尽量对。这叫 supervised learning，这 8 行叫 training set。

先看两个最省事的做法，它们各错在一头。

**Majority vote**：不看 feature，永远回答 training set 里更多的那个 label。这里 4 个 + 对 4 个 −，怎么答 training error 都是 $4/8$。它什么都没学。

**Memorizer**：把 8 行背下来，来了一封邮件就查表。Training error 是 0。但三个 Y/N 的 feature 一共有 8 种组合，表里只出现了 6 种，$(Y,Y,N)$ 和 $(N,Y,N)$ 没有出现过，来了这样的邮件它无话可说。它也什么都没学，只是记住了。

Learning 要的是 generalization：从见过的推到没见过的。这不可能凭空做到，必须先限定 $h$ 长什么样。这一站的限定是：$h$ 是一棵不大的 **decision tree**，每个 internal node 问一个 feature，每个 leaf 给一个 label。

### 先问哪个 feature

能和 training set 完全吻合的 tree 有很多，要最小的那棵。把所有 tree 都试一遍不现实（MIT 6.034 提到这是 NP-hard 的），所以用 greedy：先挑一个“最好”的 feature 放在 root，把 data 按它的值分成几堆，对每一堆重复同样的事。

“最好”应该是：分完之后，每一堆里的 label 尽量一致。最容易想到的衡量办法是数 error：每一堆按自己的 majority 回答，一共错几个。

| 按哪个 feature 分 | 分成的两堆（+ 的个数，− 的个数） | 分完之后错几个 |
|---|---|---|
| Link | Y：(3, 1)；N：(1, 3) | $1+1=2$ |
| Known | Y：(0, 2)；N：(4, 2) | $0+2=2$ |
| Long | Y：(2, 2)；N：(2, 2) | $2+2=4$ |

Link 和 Known 都是错 2 个，error rate 分不出高下。但它们并不一样好。按 Known 分，Y 那一堆已经全是 −，这两封邮件处理完了，剩下的问题只有 6 封；按 Link 分，两堆都还是混的，8 封邮件一封也没处理完。需要一个能看出这种差别的量。

### Entropy

一堆 example 里 + 占的比例是 $p$。要一个 impurity $I(p)$：$p=0$ 或 $p=1$ 时为 0，$p=\tfrac12$ 时最大。Error rate $\min(p,1-p)$ 满足这两条，刚才已经看到它不够用。用的是

$$H(p)=-p\log_2p-(1-p)\log_2(1-p)\qquad(\text{约定 }0\log_20=0)$$

叫 **entropy**，单位是 bit。几个值：$H(\tfrac12)=1$，$H(\tfrac13)=H(\tfrac23)=0.918$，$H(\tfrac14)=H(\tfrac34)=0.811$，$H(0)=H(1)=0$。

按一个 feature 分完之后，各堆的 entropy 按堆的大小取 weighted average；分之前的 entropy 减去它，叫这个 feature 的 **information gain**：

$$\text{Gain}=H(\text{分之前})-\sum_v\frac{|S_v|}{|S|}\,H(S_v)$$

对 8 封邮件，分之前是 4 对 4，$H=1$。

- Link：两堆都是 3 对 1，$H=0.811$。Gain $=1-(\tfrac48\times0.811+\tfrac48\times0.811)=0.189$。
- Known：Y 堆 $H=0$；N 堆是 4 对 2，$H(\tfrac46)=0.918$。Gain $=1-(\tfrac28\times0+\tfrac68\times0.918)=1-0.689=0.311$。
- Long：两堆都是 2 对 2，$H=1$。Gain $=0$。

Known 的 gain 最大，放在 root。Error rate 看不出的差别，entropy 看出来了。

CS2109S 的讲义用 random variable 的语言写同一个量。把 label 看成 random variable $Y$，feature 看成 $X$。$H(Y\mid X=x)$ 叫 specific conditional entropy，就是 $X=x$ 那一堆的 entropy；按 $P(X=x)$ 取 expectation 得到 conditional entropy
$$H(Y\mid X)=\sum_xP(X=x)\,H(Y\mid X=x),\qquad IG(Y;X)=H(Y)-H(Y\mid X)$$
对 Known：$H(Y\mid\text{Known}=Y)=0$，$H(Y\mid\text{Known}=N)=0.918$，$H(Y\mid\text{Known})=\tfrac28\times0+\tfrac68\times0.918=0.689$，$IG=1-0.689=0.311$，和上面一样。

它凭什么能看出来？一次 split 把 parent 的比例 $p$ 换成几个 child 的比例 $p_v$，而 child 的比例按堆的大小取 weighted average 一定等于 $p$（+ 的总数没变）。分完之后的 impurity 是 $I(p_v)$ 的 weighted average，在图上就是连接各个 child 的 chord 在 $p$ 处的高度。

::fig[cs2109s-entropy] 拿 Known = N 那一堆（4 个 +，2 个 −）按 Long 来分：Y 堆是 (2, 0)，N 堆是 (2, 2)。

Entropy 的 curve 处处向下弯（strictly concave），chord 一定在 curve 下方，只要 child 的比例不全相同，gain 就严格大于 0。图里是 $0.918-(\tfrac13\times0+\tfrac23\times1)=0.252$。Error rate 的 curve 在 $p\ge\tfrac12$ 这一段是一条 line，chord 和它重合：分之前错 $\tfrac26$，分之后错 $\tfrac13\times0+\tfrac23\times\tfrac12=\tfrac13$，一点没变。只要各个 child 的 majority 和 parent 相同，error rate 就认为这次 split 毫无用处，而实际上有一堆已经变 pure 了。

### 把 tree 建完

讲义把这个 top-down、greedy、recursive 的过程叫 DTL（decision tree learning）：

```python
def DTL(rows, attributes, default):
    if not rows:                                   # 这个值在 parent 那一堆里没出现过
        return default
    if same_classification(rows):
        return classification(rows)
    if not attributes:                             # feature 用完了，label 还不一致
        return majority_decision(rows)
    best = choose_attribute(attributes, rows)      # information gain 最大的那个
    tree = Node(best)
    for value in values(best):
        subrows = [r for r in rows if r[best] == value]
        tree.child[value] = DTL(subrows, attributes - {best}, majority_decision(rows))
    return tree
```

`default` 是 parent 那一堆的 majority：一个 branch 上一个 example 都没有时，只能退回去按上一层的多数回答。

接着做例子。Root 是 Known。Known = Y 那一堆（#7、#8）全是 −，成为 leaf。Known = N 那一堆是 #1 到 #6，4 对 2，$H=0.918$，剩下 Link 和 Long 可选：

- Link：Y 堆是 #1、#2、#3，(3, 0)，$H=0$；N 堆是 #4、#5、#6，(1, 2)，$H=0.918$。Gain $=0.918-\tfrac36\times0.918=0.459$。
- Long：上面算过，gain $=0.252$。

选 Link。Link = Y 成为 leaf +。Link = N 那一堆是 #4（Long = Y，+）和 #5、#6（Long = N，−），按 Long 一分就全 pure 了，gain $=0.918$。

```
Known?
├─ Y → −
└─ N → Link?
        ├─ Y → +
        └─ N → Long?
                ├─ Y → +
                └─ N → −
```

4 个 leaf，training error 为 0。那两种没出现过的组合现在也有了答案：$(Y,Y,N)$ 和 $(N,Y,N)$ 的 Known 都是 Y，判为 −。

Long 在 root 上的 gain 是 0，到了第三层却成了决定性的一问。Gain 衡量的是一个 feature 在当前这一堆 data 上单独起的作用。这也是 greedy 的弱点：一个 feature 如果只有和别的 feature 合起来才有用，在它该被选的那一层它的 gain 可能是 0。

:::edge Feature 是数值时
把这一堆里出现的值排序，在每两个相邻的值中间取一个 threshold，每个 threshold 当作一个 Y/N 的 feature，照样算 gain。例如 7 个体温读数和 label：

$$36.5\,(-),\ 36.8\,(-),\ 37.1\,(-),\ 37.9\,(+),\ 38.4\,(-),\ 39.0\,(+),\ 39.6\,(+)$$

6 个候选的 threshold 是 36.65、36.95、37.5、38.15、38.7、39.3，gain 依次是 0.128、0.292、0.522、0.128、0.470、0.198。选“体温 $<37.5$”。数值 feature 用过之后还能在更深的 node 里换一个 threshold 再用。
:::

::fig[cs2109s-thresh] 体温的例子：7 个读数排在一条 line 上，6 个候选 threshold 各自的 gain。

:::edge 取值很多的 feature
给每封邮件加一个 feature“编号”，取值 1 到 8。按它分，8 堆各有一封邮件，全是 pure 的，gain $=1-0=1$，是可能的最大值。但它对新邮件毫无用处。Information gain 天然偏向取值多的 feature，因为堆分得越碎越容易 pure。常见的处理是只做二分的 split，或者把 gain 除以这次 split 本身的 entropy（gain ratio）。这两种处理讲义里都没有讲。
:::

### Training error 为 0 不是目标

:::wrong Tree 一直长到每个 leaf 都 pure，training error 最低，就是学得最好的
做一个知道正确答案的实验。每个 example 有 12 个 Y/N 的 feature；label 等于第一个 feature，但有 20% 的 probability 被翻转。其余 11 个 feature 和 label 无关。所以最好的 classifier 就是“只看第一个 feature”，它在新 data 上的 error 是 20%。取 200 个 example 做 training set，另取 5000 个检验，限制 tree 的 maximum depth：

| maximum depth | leaf 个数 | training error | 5000 个新 example 上的 error |
|---|---|---|---|
| 1 | 2 | 23.5% | 20.1% |
| 4 | 16 | 21.5% | 27.5% |
| 6 | 48 | 11.5% | 33.9% |
| 12 | 82 | 1.0% | 38.6% |

Depth 为 1 的 tree 问的正是第一个 feature。Training set 里恰好有 47 个 example 的 label 被翻转了，它在这 47 个上“错”了，所以 training error 是 23.5%。往下长的每一层，都是在用那 11 个无关的 feature 把这 47 个一个个凑对。凑对的每一条规则描述的都是这 200 个 example 里的 noise，换一批 data 就不成立，于是 training error 降到 1.0%，新 data 上的 error 却升到 38.6%。（剩下的 1.0% 是两对 feature 完全相同而 label 相反的 example，怎么分也分不开。）
:::

这叫 **overfitting**。讲义里有一条 theorem 说明它为什么总有机会发生：只要 example 互相不矛盾（feature 相同的 example label 也相同），feature 和 label 都是有限个 categorical 的值，就一定存在一棵和全部 example 吻合的 decision tree。Tree 足够大时 training error 总能做到 0，所以 training error 为 0 说明不了什么；讲义偏爱 compact 的 tree，理由是一棵很小的 tree 恰好凭运气和全部 example 吻合，可能性小得多。

Training error 随 depth 只降不升，所以不能拿它来决定 tree 长到多深。办法是从手头的 data 里留出一部分不参与建 tree，叫 **validation set**，用它上面的 error 来选。实验里另取 200 个 example 当 validation set，四种 depth 的 validation error 是 20.5%、27.5%、37.0%、39.0%，选 depth 1。

Validation set 一旦被用来做选择，它上面的 error 就偏乐观了（选的正是在它上面表现最好的那个）。要报告最终的 model 有多好，还得有第三份从头到尾没碰过的 data，叫 **test set**，只在最后用一次。

讲义把限制 tree 大小统称为 **pruning**，列出的两种都是建的时候就限制：**max depth**（上面的实验就是它），和 **min-sample leaves**（每个 leaf 至少要有几个 example，不够就不再分，直接取 majority）。另一类做法是先长满再剪：从下往上检查每个 internal node，如果把它换成一个 leaf 后 validation error 没有变差，就换掉。这一类不在讲义里。

:::from
引入的顺序（先数分完之后落在 homogeneous 的堆里的 example，data 大了数不动，再从 information theory 借来 disorder 的 formula，一个 test 的好坏是各堆 disorder 的 weighted average）、“找最小的 tree 是 NP-hard 的”、数值 feature 取相邻值中点做 threshold 且可以重复使用，来自 [MIT 6.034 Lecture 11](https://ocw.mit.edu/courses/6-034-artificial-intelligence-fall-2010/resources/lecture-11-learning-identification-trees-disorder/) 的 transcript。Majority vote 与 memorizer 两个对照、“error rate 分不出、mutual information 分得出”的对比，来自 [CMU 10-301/601 Lecture 2](https://www.cs.cmu.edu/~hchai2/courses/10601/lectures/Lecture2.pdf)；递归建 tree 的几个 base case 来自 [Lecture 3](https://www.cs.cmu.edu/~hchai2/courses/10601/lectures/Lecture3.pdf)。那两份 slides 没有讲 overfitting 和 pruning。8 封邮件的 dataset、用 concavity 解释 entropy 与 error rate 的差别、体温的例子、12 个 feature 的实验，是为这一页构造和实际算的；gain ratio、先长满再剪、validation set 与 test set 的分工是凭自己的知识写的。

## [linreg] Linear regression 与 gradient descent

:::skip
能从 squared error 推出 normal equation，并说出 gradient 为什么是 $w$ 的 linear function；能对一个小例子手算两步 gradient descent；能由 Hessian 的 eigenvalue 说出 step size 多大会 diverge，以及 feature scaling 为什么让 gradient descent 变快，就可以去第 6 站。
:::

### Loss 把 learning 变成 optimization

上一站的 $h$ 是一棵 tree，candidate 可以一个 feature 一个 feature 地挑。现在 label 是一个数，$h$ 取成 feature 的 linear function：

$$h_w(x)=w_0+w_1x_1+\dots+w_dx_d=w^\top x\qquad(\text{约定 }x_0=1)$$

Candidate 是所有的 weight vector $w$，有无穷多个，没法逐个比较。要先说清什么叫好：对 $n$ 个 example $(x^{(i)},y^{(i)})$，取

$$J(w)=\frac{1}{2n}\sum_{i=1}^n\big(w^\top x^{(i)}-y^{(i)}\big)^2$$

叫 mean squared error loss（前面的 $\tfrac12$ 只是为了求 derivative 时消掉 2）。找最好的 $h$ 变成了找让 $J$ 最小的 $w$。

这一站只用三个 example：$(1,1)$、$(2,2)$、$(3,2)$，也就是 [DSA2102 第 4 站](../courses/DSA2102.html#ls)的那三个点。Model 是 $h_w(x)=w_0+w_1x$。把 example 一行一行排成 matrix：

$$X=\begin{pmatrix}1&1\\1&2\\1&3\end{pmatrix},\qquad y=\begin{pmatrix}1\\2\\2\end{pmatrix},\qquad J(w)=\frac{1}{2n}\|Xw-y\|^2$$

在 $w=(0,0)$ 处三个 prediction 都是 0，$J=\tfrac16(1+4+4)=1.5$。

### Squared error 给出一个 linear system

对 $w_j$ 求 partial derivative。第 $i$ 个 example 的 error 记作 $e_i=w^\top x^{(i)}-y^{(i)}$，它对 $w_j$ 的 derivative 是 $x^{(i)}_j$；而 $\tfrac12e_i^2$ 对 $e_i$ 的 derivative 是 $e_i$。按 chain rule：

$$\frac{\partial J}{\partial w_j}=\frac1n\sum_ie_i\,x^{(i)}_j,\qquad\text{合起来}\qquad\nabla J(w)=\frac1nX^\top(Xw-y)=\frac1n\big(X^\top X\,w-X^\top y\big)$$

要紧的是最后一个式子的形状：$\nabla J$ 是 $w$ 的 linear function（加一个 constant）。所以“gradient 等于 0”是一个 linear system：

$$X^\top X\,w=X^\top y$$

这就是 **normal equation**。对三个点：

$$\begin{pmatrix}3&6\\6&14\end{pmatrix}\begin{pmatrix}w_0\\w_1\end{pmatrix}=\begin{pmatrix}5\\11\end{pmatrix}\quad\Longrightarrow\quad w_1=\tfrac12,\ w_0=\tfrac23,\qquad J=\tfrac1{36}\approx0.028$$

这是 linear 的，根源在 square：$\tfrac12e^2$ 的 derivative 是 $e$ 本身，而 $e$ 是 $w$ 的 linear function。换成 $|e|$，derivative 是 $e$ 的 sign，不再是 linear 的，就没有这样一个可以直接解的 system。DSA2102 第 4 站从另一头得到同一组 equation（error vector 与 $X$ 的每个 column perpendicular），那里还讲了它在数值上的毛病和用 QR 的解法，这里不重复。

::fig[cs2109s-fit3] 三个 example 和 normal equation 解出的 line。

Gradient 为 0 的点是 minimum 而不是别的，因为 $J$ 的 Hessian 是 $\tfrac1nX^\top X$，对任何 $v$ 有 $v^\top X^\top Xv=\|Xv\|^2\ge0$，$J$ 是 convex 的。讲义把这件事分成两条 theorem：MSE 加 linear model 是 convex 的，所以任何 local minimum 都是 global minimum；如果 feature 是 linearly independent 的（没有哪个 column 是其他 column 的 linear combination），它是 strictly convex 的，global minimum 只有一个。第二条也能从上面的式子读出来：column 线性无关时 $v\ne0$ 推出 $Xv\ne0$，$\|Xv\|^2>0$。这里两个 column $(1,1,1)$ 和 $(1,2,3)$ 线性无关，minimum 唯一。

### 为什么还需要 gradient descent

有了 closed form 还要 iterative method，原因有两个。第一是代价：形成 $X^\top X$ 要 $nd^2$ 次 operation，解 system 要 $\tfrac13d^3$，feature 有 $10^5$ 个时后者是 $3\times10^{14}$。第二个更根本：这门课后面的每一个 loss，gradient 都不是 $w$ 的 linear function，“gradient 等于 0”解不出来。Gradient descent 只要求能算 $\nabla J$。

想法是：站在当前的 $w$，$J$ 朝哪个方向降得最快？对很小的一步 $\Delta$，$J(w+\Delta)\approx J(w)+\nabla J(w)^\top\Delta$。步长固定时，inner product $\nabla J^\top\Delta$ 在 $\Delta$ 与 $\nabla J$ 方向相反时最小。所以

$$w\leftarrow w-\gamma\,\nabla J(w)$$

$\gamma>0$ 叫 learning rate 或 step size（CS2109S 的讲义和 PS3 都用 $\gamma$）。所有 $w_j$ 要用同一个旧的 $w$ 算出 gradient 之后再一起更新；先更新 $w_0$ 再拿新的 $w_0$ 去算 $w_1$ 的 gradient，算的就不是 gradient 了。什么时候停，PS3 Task 2.8 用的标准是相邻两个 epoch 的 loss 变化足够小，$|J_{t-1}-J_t|<\delta$。

从 $w=(0,0)$ 出发，取 $\gamma=0.1$，手算两步。$\nabla J=\tfrac13\big(\sum_ie_i,\ \sum_ie_ix^{(i)}\big)$。

**第 1 步。** $e=(-1,-2,-2)$。$\sum e_i=-5$，$\sum e_ix^{(i)}=-1-4-6=-11$。$\nabla J=(-1.667,\,-3.667)$。

$$w=(0,0)-0.1\times(-1.667,\,-3.667)=(0.167,\,0.367),\qquad J=0.328$$

**第 2 步。** 三个 prediction 是 $0.167+0.367x$：0.533、0.900、1.267。$e=(-0.467,-1.100,-0.733)$。$\sum e_i=-2.300$，$\sum e_ix^{(i)}=-0.467-2.200-2.200=-4.867$。$\nabla J=(-0.767,\,-1.622)$。

$$w=(0.167,\,0.367)-0.1\times(-0.767,\,-1.622)=(0.243,\,0.529),\qquad J=0.095$$

两步之内 $J$ 从 1.5 降到 0.095。但接下来慢得出奇：第 5 步 $J=0.0371$，第 10 步 0.0357，要到第 490 步，$w$ 的两个 component 才都进入 $(\tfrac23,\tfrac12)$ 的 $10^{-3}$ 以内。

::fig[cs2109s-gd] 动图，左边就是上面的计算，右边把 $\gamma$ 加大到 0.3，两边同一节拍每拍走一步。看左边的点：头两步横穿 contour 落到一条狭长的谷里，之后每步只挪一点；右边的点在谷的两壁之间来回跳。

### Step size：多大会 diverge，为什么先快后慢

先看只有一个 weight 的情形，$J(w)=\tfrac12aw^2$。$\nabla J=aw$，update 是 $w\leftarrow(1-\gamma a)\,w$：每一步乘同一个数。$|1-\gamma a|<1$ 时 converge，即 $0<\gamma<2/a$；超过 $2/a$，每一步都跳到对面更高的地方。

三个点的 $J$ 是 quadratic 的，可以精确地写成

$$J(w)=J(w^*)+\tfrac12(w-w^*)^\top H\,(w-w^*),\qquad H=\frac1nX^\top X=\begin{pmatrix}1&2\\2&\tfrac{14}{3}\end{pmatrix}$$

$w^*=(\tfrac23,\tfrac12)$ 是 minimum。于是 $\nabla J=H(w-w^*)$，代进 update：

$$w_{k+1}-w^*=(I-\gamma H)\,(w_k-w^*)$$

到 minimum 的偏差每一步被乘上同一个 matrix。把偏差按 $H$ 的 eigenvector 分开，沿第 $i$ 个 eigenvector 的 component 每一步乘 $1-\gamma\lambda_i$，这和 [DSA2102 第 3 站](../courses/DSA2102.html#cond)分析 iterative method 用的是同一个办法。$H$ 的 eigenvalue 满足 $\lambda^2-\tfrac{17}3\lambda+\tfrac23=0$，是 $\lambda_1=5.546$ 和 $\lambda_2=0.120$。

| $\gamma$ | $1-\gamma\lambda_1$ | $1-\gamma\lambda_2$ | 发生什么 |
|---|---|---|---|
| 0.1 | 0.445 | 0.988 | 一个方向几步就没了，另一个方向每步只缩 1.2%，490 步 |
| 0.3 | −0.664 | 0.964 | 第一个方向每步变号，左右来回跳；162 步 |
| 0.4 | −1.219 | 0.952 | 第一个方向每步放大 1.219 倍，diverge |

所以 $\gamma$ 的上限由最大的 eigenvalue 定：$\gamma<2/\lambda_1=0.361$。而 converge 的快慢由最小的 eigenvalue 定：$\gamma$ 不能大，$\gamma\lambda_2$ 就小，那个方向每步只缩一点点。两个 eigenvalue 之比 $\lambda_1/\lambda_2=46$ 是 $H$ 的 condition number，它越大，谷越狭长，gradient descent 越慢。

讲义用的例子是 $J(w)=w_1^2+(10w_2)^2$，gradient 是 $(2w_1,\,200w_2)$，update 是 $w_1\leftarrow(1-2\gamma)w_1$、$w_2\leftarrow(1-200\gamma)w_2$。它的 Hessian 是 $\operatorname{diag}(2,200)$，eigenvector 就是两个坐标轴，和上面的分析完全一样：$w_2$ 要求 $\gamma<2/200=0.01$，而 $\gamma=0.009$ 时 $w_1$ 每步只乘 $0.982$，要 127 步才缩到原来的十分之一。

:::wrong Learning rate 大一点，converge 就快一点
取 $\gamma=0.4$，同样从 $(0,0)$ 出发，前五步的 $J$ 是 2.21、3.26、4.82、7.14、10.59，每一步大约是上一步的 $1.219^2=1.49$ 倍。从 0.1 加到 0.3 确实快了（490 步变成 162 步），再从 0.3 加到 0.4 就越过了 $2/\lambda_1$，$J$ 不降反升。$\gamma$ 没有“越大越好”，它有一个由 loss 的形状决定的上限。
:::

### Feature scaling

Condition number 46 是哪来的？$X$ 的两个 column $(1,1,1)$ 和 $(1,2,3)$ 几乎指向同一个方向（夹角的 cosine 是 $6/\sqrt{3\times14}=0.93$），$X^\top X$ 就接近 singular。

把 feature 先 standardize：减去 mean，除以 standard deviation。这里 mean 是 2，standard deviation 是 $\sqrt{2/3}=0.816$，$x$ 变成 $x'=(-1.225,\,0,\,1.225)$。新的两个 column $(1,1,1)$ 和 $x'$ 互相 perpendicular，而且

$$H'=\frac13\begin{pmatrix}3&0\\0&3\end{pmatrix}=I$$

两个 eigenvalue 都是 1，contour 是 circle，gradient 正对着 minimum。在 $w'=(0,0)$ 处 $\nabla J=(-1.667,\,-0.408)$，取 $\gamma=1$，一步到 $w'=(1.667,\,0.408)$，$J=0.028$，已经是 minimum。换回原来的 feature：slope 是 $0.408/0.816=0.5$，intercept 是 $1.667-0.5\times2=0.667$，和 normal equation 的答案相同。

Feature 的单位差得越远，这件事越要紧。把三个 $x$ 换成 1000、2000、3000（比如以平方英尺计的面积），$H$ 的 eigenvalue 是 $4.67\times10^6$ 和 0.143，condition number 是 $3\times10^7$，$\gamma$ 必须小于 $4.3\times10^{-7}$。Standardize 之后仍然是上面的 $H'=I$。Mean 和 standard deviation 要从 training set 算，然后原样用在 validation set 和 test set 上。

讲义给了两种 scaling。**Standardization** 就是上面的 $x'=(x-\mu)/\sigma$；PS3 Task 2.7 的例子是一个 column $(1,4,5,8)$，$\mu=4.5$，$\sigma=2.5$（除以 $n$ 的 standard deviation，NumPy 的 `np.std` 默认如此），得到 $(-1.4,-0.2,0.2,1.4)$。**Min-max scaling** 是 $x'=\dfrac{x-\min x}{\max x-\min x}$，把 feature 压到 $[0,1]$；同一个 column 变成 $(0,\,0.429,\,0.571,\,1)$。对三个点的 $x=(1,2,3)$，min-max 给出 $(0,0.5,1)$，它和 $(1,1,1)$ 不 perpendicular，$H$ 不会变成 $I$，但 condition number 从 46 降到了 9.9。第三种办法是给每个 weight 用不同的 learning rate。

### Example 太多时：stochastic gradient descent

$\nabla J$ 是 $n$ 个 example 各自的 gradient 的平均。在 $w=(0,0)$ 处，三个 example 各自的 gradient $e_i\,x^{(i)}$ 是 $(-1,-1)$、$(-2,-4)$、$(-2,-6)$，平均正是 $(-1.667,-3.667)$。$n$ 是几百万时，为了走一步要把全部 example 过一遍（这叫 batch gradient descent）。

**Stochastic gradient descent（SGD）** 每一步只随机取一个 example，用它自己的 gradient 代替平均。单个的 gradient 方向不准（上面三个就各不相同），但它的 expectation 是真正的 gradient，而走一步的代价只有 $1/n$。同样把全部 data 过一遍，batch 走 1 步，SGD 走 $n$ 步。代价是 path 带着 noise，到了 minimum 附近不会停稳，要让 $\gamma$ 随步数逐渐减小。折中的做法是每步取一小批（mini-batch）来平均。

:::edge $X^\top X$ 是 singular 的
两个 feature 完全 linearly dependent（比如同一个量用两种单位各记一遍），或者 feature 比 example 还多，$X^\top X$ 就不 invertible，让 $J$ 最小的 $w$ 有无穷多个，normal equation 没有 unique solution。Gradient descent 仍然会 converge 到其中一个。常规的处理是去掉多余的 feature，或者加[第 6 站](#logreg)的 regularization。
:::

Normal equation 的几何意义、数值上的问题和 QR，见 [DSA2102 第 4 站](../courses/DSA2102.html#ls)；“偏差每一步乘同一个 matrix，快慢看 eigenvalue”见 [DSA2102 第 3 站](../courses/DSA2102.html#cond)。
:::

:::from
Loss 的定义、对单个 example 求 derivative 得到 $(h_w(x)-y)\,x_j$ 的步骤、batch 与 stochastic 两种 gradient descent 的对比、令 gradient 为 0 得到 normal equations 以及 $X^\top X$ 不 invertible 的两种情形，来自 [CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)第 1 章；那里的 $J$ 前面是 $\tfrac12$ 而不是 $\tfrac1{2n}$，只相当于把 $\gamma$ 换了个 scale。三个点来自 DSA2102 那一页（出自 MIT 18.06 第 16 讲）。用 Hessian 的 eigenvalue 分析 step size 的上限和快慢、feature scaling 把 $H$ 变成 $I$，是凭自己的知识写的，CS229 那一章没有这样讲；两步手算、490 步与 162 步、$\gamma=0.4$ 时的五个 $J$、1000 到 3000 的例子、min-max 之后的 condition number 都是这里实际算的。

和 NUS 的材料核过的部分：$J_{MSE}=\tfrac1{2n}\sum(h_w(x^{(i)})-y^{(i)})^2$ 的写法（PS3 Task 1.1 特地注明分母是 $2n$ 以和 lecture 一致）、learning rate 记作 $\gamma$、所有 weight 同时更新、convexity 与 linear independence 的两条 theorem、$J=w_1^2+(10w_2)^2$ 的例子、min-max scaling 与 standardization、normal equation 的三个缺点（$d^3$ 的代价、$X^\top X$ 可能不 invertible、不适用于 non-linear model）、batch / mini-batch / stochastic 三种 gradient descent，对得上 [AY25/26 第 2 学期 Week 5 的 lecture 笔记](https://github.com/Harjun751/CS2109S-notes) 和 [第 1 学期 L5 笔记](https://github.com/chongpig/CS2109S)。Standardization 的例子、epoch 与收敛条件取自 [AY26/27 PS3 handout](https://github.com/kahei9299/cs2109s) 的 Task 2.6 到 2.8。

### 直接用 linear regression 分两类

Label 只有 0 和 1 时，最省事的办法是照旧 fit 一条 line，prediction 超过 0.5 就判为 1。取 6 个点：$x=1,2,3$ 的 label 是 0，$x=4,5,6$ 的 label 是 1。Least squares 给出 $h(x)=-0.4+0.257x$，它在 $x=3.5$ 处等于 0.5，6 个点全部分对。

现在加一个点 $(20,\,1)$。它离 threshold 很远，任何合理的 classifier 都会把它分对。重新 fit，line 变成 $h(x)=0.301+0.046x$，等于 0.5 的位置移到了 $x=4.31$。$x=4$ 的 prediction 是 0.486，被判成 0。

::fig[cs2109s-lsclass] 多了一个本来就不成问题的点，原来分对的点反而分错了。

原因在 loss。原来那条 line 在 $x=20$ 处的值是 $-0.4+0.257\times20=4.74$，按 squared error 这是 $(4.74-1)^2\approx14$ 的巨大 error，尽管从 classification 看它“对得不能再对”。为了压低这一项，line 被拉平了。需要两处改动：output 限制在 0 和 1 之间；loss 不惩罚“对得太有把握”。

### Sigmoid 与 cross-entropy

把 $w^\top x$ 送进 **sigmoid** function：

$$\sigma(z)=\frac{1}{1+e^{-z}},\qquad h_w(x)=\sigma(w^\top x)$$

$\sigma(0)=0.5$，$\sigma(2)=0.881$，$\sigma(5)=0.993$，$\sigma(-5)=0.007$：$z$ 再大，output 也不超过 1。把 $h_w(x)$ 读作“label 是 1 的 probability”。后面要用它的 derivative：

$$\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}=\sigma(z)\,\big(1-\sigma(z)\big)$$

Loss 从“这组 $w$ 让观察到的 label 出现的 probability 有多大”来。一个 example 的 label 是 1 时这个 probability 是 $h$，是 0 时是 $1-h$，两种情况可以合写成 $h^y(1-h)^{1-y}$。各个 example independent，probability 相乘；取 logarithm 把乘变成加，再取负号和平均，得到要最小化的

$$J(w)=-\frac1n\sum_{i=1}^n\Big[y^{(i)}\ln h_w(x^{(i)})+(1-y^{(i)})\ln\big(1-h_w(x^{(i)})\big)\Big]$$

叫 **cross-entropy loss**。单看一个 $y=1$ 的 example，loss 是 $-\ln h$：$h=0.993$ 时是 0.007，$h=0.5$ 时是 0.693，$h=0.007$ 时是 5.0。有把握地对，几乎不罚；有把握地错，重罚。

:::wrong 沿用 squared error，把 $h$ 换成 sigmoid 就可以了
看一个错得很有把握的 example：$y=1$，$z=w^\top x=-5$，$h=\sigma(-5)=0.0067$。Gradient descent 靠 loss 对 $z$ 的 derivative 来纠正它。

Squared error $\tfrac12(h-y)^2$ 对 $z$ 的 derivative 是 $(h-y)\,\sigma'(z)=(h-y)\,h(1-h)=-0.9933\times0.00665=-0.0066$。Cross-entropy 的（下一小节推导）是 $h-y=-0.9933$，大了 150 倍。

Squared error 里多出来的 factor $\sigma'(z)$ 在 $|z|$ 很大时接近 0：错得越离谱，gradient 反而越小，几乎学不动。Cross-entropy 里 $\ln$ 的 derivative $1/h$ 恰好把这个 factor 消掉了。另外，squared error 套上 sigmoid 之后 $J$ 不再是 convex 的。
:::

### Gradient，以及为什么没有 closed form

对一个 example，$L=-y\ln h-(1-y)\ln(1-h)$，$h=\sigma(z)$，$z=w^\top x$。逐层求 derivative：

$$\frac{\partial L}{\partial h}=-\frac yh+\frac{1-y}{1-h},\qquad\frac{\partial h}{\partial z}=h(1-h),\qquad\frac{\partial z}{\partial w_j}=x_j$$

前两个相乘：

$$\frac{\partial L}{\partial z}=\Big(-\frac yh+\frac{1-y}{1-h}\Big)h(1-h)=-y(1-h)+(1-y)h=h-y$$

所以 $\dfrac{\partial L}{\partial w_j}=(h-y)\,x_j$，对全部 example 平均：

$$\nabla J(w)=\frac1nX^\top\big(\sigma(Xw)-y\big)$$

和上一站的 $\tfrac1nX^\top(Xw-y)$ 是同一个形状，只是 prediction 从 $Xw$ 换成了 $\sigma(Xw)$。差别就在这里：令它为 0，得到 $\sum_i\big(\sigma(w^\top x^{(i)})-y^{(i)}\big)x^{(i)}=0$，$w$ 被包在 $\sigma$ 里面，这不是 linear system，没有 formula 可以直接解出 $w$。只能 iterate。好在 $J$ 仍然是 convex 的（Hessian 是 $\tfrac1nX^\top DX$，$D$ 是 diagonal 上为 $h(1-h)>0$ 的 matrix），gradient descent 不会停在别处。

手算两步。四个 example：$x=0,1,2,3$，$y=0,1,0,1$，model 是 $h=\sigma(w_0+w_1x)$，从 $w=(0,0)$ 出发，$\gamma=0.5$。$\nabla J=\tfrac14\big(\sum(h_i-y_i),\ \sum(h_i-y_i)x_i\big)$。

**第 1 步。** $z$ 全是 0，$h$ 全是 0.5，$h-y=(0.5,-0.5,0.5,-0.5)$。$\sum(h_i-y_i)=0$，$\sum(h_i-y_i)x_i=-0.5+1.0-1.5=-1.0$。$\nabla J=(0,\,-0.25)$，$w=(0,\,0.125)$。$J$ 从 $\ln2=0.6931$ 降到 0.6687。

**第 2 步。** $z=0.125x=(0,\,0.125,\,0.25,\,0.375)$，$h=(0.5,\,0.5312,\,0.5622,\,0.5927)$，$h-y=(0.5,\,-0.4688,\,0.5622,\,-0.4073)$。$\sum(h_i-y_i)=0.1860$，$\sum(h_i-y_i)x_i=-0.4688+1.1244-1.2220=-0.5664$。$\nabla J=(0.0465,\,-0.1416)$，$w=(-0.0233,\,0.1958)$，$J=0.6592$。

一直做下去，converge 到 $w=(-1.362,\,0.908)$，$J=0.5869$。四个点的 probability 是 0.204、0.388、0.612、0.796。

Classifier 在 $h\ge0.5$ 时判为 1，也就是 $w^\top x\ge0$。分界 $w^\top x=0$ 叫 **decision boundary**，这里是 $x=1.362/0.908=1.5$；feature 有两个时它是一条 line，更多时是一个 hyperplane。Sigmoid 只管把到 boundary 的距离变成 probability，boundary 本身总是 linear 的。要弯的 boundary，就先把 feature 做变换（加上 $x_1^2$、$x_1x_2$ 这样的项），在新 feature 上它仍然是 linear 的。讲义的 theorem 说这样做不会破坏 convexity：$w$ 仍然只以 $w^\top\varphi(x)$ 的形式出现，上面那个 Hessian 的论证原样成立。

0.5 只是一个默认值。讲义把它写成 **decision threshold** $\tau$：$h_w(x)\ge\tau$ 时判为 1，boundary 是 $\sigma(w^\top x)=\tau$，即 $w^\top x=\ln\frac{\tau}{1-\tau}$。上面的例子取 $\tau=0.8$，boundary 移到 $w^\top x=\ln4=1.386$，即 $x=(1.362+1.386)/0.908=3.03$，四个点全被判为 0。$\tau$ 调高，判为 1 的更少、更有把握；调低则相反。PS3 Task 3.4 的 `prob_threshold` 就是它。什么时候该调，看下一小节。

:::edge Data 恰好能被完全分开时，minimum 不存在
把 label 换成 $y=0,0,1,1$，任何 1 和 2 之间的 threshold 都能全部分对。跑 gradient descent：100 步后 $w=(-3.44,\,2.53)$，1000 步后 $(-8.78,\,6.02)$，$10^5$ 步后 $(-22.5,\,15.2)$，$J$ 是 0.141、0.025、0.0003。Boundary 一直在 1.5 附近，$w$ 却越来越大，不会停。

原因是：一旦 $w$ 把 data 全分对了，把它整体放大 $c$ 倍，每个 $h$ 都更靠近自己的 label，$J$ 就更小。对 $w=c\times(-1.5,\,1)$，$c=1,2,5,10$ 时 $J=0.338,\,0.181,\,0.040,\,0.003$。$J$ 可以任意接近 0 而永远达不到。下面的 regularization 会让它有一个确定的 minimum：在 $J$ 上加 $0.05\,w_1^2$ 之后，minimum 在 $w=(-2.26,\,1.51)$。
:::

### Accuracy 不够用的时候

PS3 的信用卡数据有 284,807 笔交易，其中 492 笔是 fraud。一个什么都不学、永远回答“不是 fraud”的 classifier，accuracy 是
$$\frac{284{,}807-492}{284{,}807}=0.99827$$
看起来几乎完美，而它一笔 fraud 也没抓到。Class 极不平衡时，accuracy 主要反映的是多数那一类。

要分开看两种错，先把 prediction 和真实 label 交叉排成 **confusion matrix**：真实是 1、判成 1 的个数叫 TP（true positive），真实是 0、判成 1 的叫 FP，真实是 1、判成 0 的叫 FN，真实是 0、判成 0 的叫 TN。由它定义

$$\text{Precision}=\frac{TP}{TP+FP},\qquad\text{Recall}=\frac{TP}{TP+FN},\qquad F_1=\frac{2}{\frac1{\text{Precision}}+\frac1{\text{Recall}}}$$

Precision 问的是“判成 fraud 的里面有多少真是 fraud”，FP 代价高时看它；recall 问的是“真的 fraud 里抓到了多少”，FN 代价高时看它；$F_1$ 是两者的 harmonic mean，两个里只要有一个小，它就小。

设另一个 classifier 标出了 600 笔，其中 400 笔是真的 fraud：

| | 判为 fraud | 判为正常 |
|---|---|---|
| 真的是 fraud | TP = 400 | FN = 92 |
| 真的正常 | FP = 200 | TN = 284,115 |

Precision $=400/600=0.667$，recall $=400/492=0.813$，$F_1=2/(1.5+1.23)=0.733$。它的 accuracy 是 $(400+284{,}115)/284{,}807=0.99897$，和那个什么都不做的 0.99827 只差千分之一，precision 和 recall 却从 0 变成了 0.667 和 0.813。永远回答“不是 fraud”的那个，recall 是 $0/492=0$，precision 是 $0/0$，没有定义。

上一小节的 $\tau$ 就是在这两者之间换：$\tau$ 调低，判为 fraud 的变多，recall 升而 precision 降。PS3 Task 3.1 问的正是这个数据直接拿来训练会出什么问题、怎么补救（AY24/25 的 handout 介绍的补救是 undersampling 和 oversampling，即减少多数类或复制少数类，使两类的比例接近）。

### 多于两个 class

Label 是 $\{1,\dots,K\}$ 时，讲义的办法是拆成若干个 binary classification。

**One-vs-Rest**：每个 class 训练一个 classifier，把“是这个 class”当 1，其余全当 0，共 $K$ 个；预测时取 output 的 probability 最大的那个。**One-vs-One**：每两个 class 训练一个 classifier，只用这两个 class 的 data，共 $\frac{K(K-1)}{2}$ 个；预测时每个 classifier 投一票，票多的赢。

拿 $K=3$（cat、dog、bird）的一个 input 走一遍。One-vs-Rest 的三个 output 是 0.7、0.4、0.2，判为 cat。One-vs-One 的三个 classifier 中，cat 对 dog 判 cat，cat 对 bird 判 bird，dog 对 bird 判 bird：bird 两票，判为 bird。两种拆法对同一个 input 可以给出不同的答案，因为它们问的是不同的问题。$K=10$ 时 One-vs-Rest 要训练 10 个，One-vs-One 要 45 个，但后者每个只用两类的 data，大约是全部的五分之一。

**Multi-label** 是另一回事：一个 input 可以同时有好几个 label（一张图里既有 cat 又有 dog），target 是 $\{0,1\}^K$。讲义列了三种做法。Binary relevance 给每个 label 各训练一个 independent 的 binary classifier，共 $K$ 个，但它看不到 label 之间的关系，比如表达不了“这两个 label 互斥”。Classifier chain 照样每个 label 一个 classifier，但把前面几个 label 的 prediction 当作后面的 feature，能抓到 label 之间的依赖，结果和排列的顺序有关。Label powerset 把每一种 label 组合当成一个 class，变成 multi-class，能保留全部的关系，代价是 class 的个数最多 $2^K$（$K=10$ 时是 1024），很多组合在 data 里只出现几次甚至一次都没有。

### Model 太简单和太复杂

给 linear regression 加上 $x^2,x^3,\dots$ 作为 feature，它 fit 的就是 polynomial，而对 $w$ 来说仍然是上一站的 linear regression。Degree 该取多少？

做一个知道正确答案的实验。真实的 function 是 $h^*(x)=1+2x-3x^2$，在 $[-1,1]$ 上等距取 10 个 $x$，$y=h^*(x)+\text{noise}$，noise 的 standard deviation 是 0.3（variance 0.09）。

::fig[cs2109s-polyfit] 同一组 10 个点，三种 degree。Test error 是在大量新的点上算的 mean squared error；noise 的 variance 是 0.09，所以它不可能低于 0.09。

| degree | training error | test error |
|---|---|---|
| 1 | 1.380 | 0.949 |
| 2 | 0.103 | 0.095 |
| 5 | 0.077 | 0.123 |
| 9 | 0.000 | 0.860 |

Training error 随 degree 一路降到 0，test error 先降后升，和上一站 decision tree 的表是同一个形状。Degree 1 和 degree 9 的 test error 都很高，但错法完全不同。要把两种错法分开，设想把实验重做很多遍：每次 $x$ 不变，noise 重新抽，重新 fit，得到一条新的 curve $h_S$（$S$ 表示这一次的 training set）。在某个固定的 $x$ 上：

- 这些 curve 的平均记作 $h_{\text{avg}}(x)$。它和 $h^*(x)$ 的差的 square 叫 **bias²**：model 平均起来偏了多少。
- 各条 curve 围绕 $h_{\text{avg}}(x)$ 的 variance 叫 **variance**：换一批 data，结果变动多大。

Test error 恰好是三项之和。新的点 $y=h^*(x)+\xi$，所以 $y-h_S(x)=\xi+\big(h^*(x)-h_S(x)\big)$。$\xi$ 是新点自己的 noise，和 training set 无关，mean 为 0，所以 square 展开后 cross term 的 expectation 是 0：

$$E\big[(y-h_S(x))^2\big]=\sigma^2+E\big[(h^*(x)-h_S(x))^2\big]$$

再把后一项里的差拆成 $\big(h^*-h_{\text{avg}}\big)+\big(h_{\text{avg}}-h_S\big)$。第一个括号是 constant，第二个括号的 mean 按定义是 0，cross term 又消失：

$$E\big[(y-h_S(x))^2\big]=\underbrace{\sigma^2}_{\text{noise}}+\underbrace{\big(h^*(x)-h_{\text{avg}}(x)\big)^2}_{\text{bias}^2}+\underbrace{E\big[(h_{\text{avg}}(x)-h_S(x))^2\big]}_{\text{variance}}$$

把实验实际重做 5000 遍，对 $[-1,1]$ 上的 $x$ 取平均：

| degree | bias² | variance | 加上 noise 0.09 |
|---|---|---|---|
| 1 | 0.855 | 0.016 | 0.961 |
| 2 | 0.000 | 0.023 | 0.113 |
| 5 | 0.000 | 0.047 | 0.137 |
| 9 | 0.000 | 0.593 | 0.683 |

Degree 1 的 error 几乎全是 bias：line 弯不过来，data 再多、noise 再小也没用，这是 **underfitting**。Degree 9 没有 bias（它包含了所有 quadratic），error 全是 variance：10 个 coefficient 对 10 个点，它把 noise 也一起穿过去了，换一批 noise 就是另一条 curve，这是 **overfitting**。Variance 可以靠更多的 data 压下去，bias 不行。

### Regularization

不降 degree 也能压住 variance。Degree 9 那条 curve 的 coefficient 最大的到了 280，正负相抵才凑出那些剧烈的摆动；degree 2 的 coefficient 是 $(1.06,\,2.09,\,-3.15)$。所以在 loss 里加一项，惩罚大的 weight：

$$J_\lambda(w)=\|Xw-y\|^2+\lambda\sum_{j\ge1}w_j^2$$

（$w_0$ 不罚；loss 前面有没有 $\tfrac1{2n}$ 只影响 $\lambda$ 的 scale。）这叫 L2 regularization，用在 linear regression 上叫 ridge regression。它的 gradient 仍然是 $w$ 的 linear function，令其为 0 得到 $(X^\top X+\lambda I')\,w=X^\top y$，$I'$ 是把左上角改成 0 的 identity matrix。用在 gradient descent 上，就是 gradient 里多一项 $2\lambda w$，每一步先把 $w$ 往 0 缩一点。

讲义的一般写法是 $J_{\text{reg}}(w)=J(w)+\lambda R(w)$，$R$ 叫 regularizer，常用 $L_p$-norm $\|w\|_p=\big(\sum_j|w_j|^p\big)^{1/p}$ 来定义：$L_2$ 用 $\sum_jw_j^2$（省掉了根号），$L_1$ 用 $\sum_j|w_j|$，$L_\infty$ 用 $\max_j|w_j|$。Linear regression 加 $L_1$ 叫 Lasso，加 $L_2$ 叫 ridge，两个都加叫 elastic net。讲义的 $R$ 从 $j=0$ 开始求和，连 $w_0$ 一起罚，closed form 写成 $w=(X^\top X+\lambda I)^{-1}X^\top y$；上面的 $I'$ 只是不罚 $w_0$ 的版本，两种写法在别的书里都常见。

$\lambda>0$ 时 $X^\top X+\lambda I$ 一定 invertible：对任何 $v\ne0$，$v^\top(X^\top X+\lambda I)v=\|Xv\|^2+\lambda\|v\|^2>0$。所以[第 5 站](#linreg)那个 feature 线性相关、normal equation 没有唯一解的边界情况，加上一点 ridge 就有了唯一的 closed-form solution。讲义另一条 theorem 说，solution 不为 0 时，$\lambda>0$ 的 ridge solution 的 $L_2$-norm 严格小于不加 regularization 的。

对 degree 9、同一组 10 个点：

| $\lambda$ | $w_1$ 到 $w_9$ 的 norm | training error | test error | 5-fold CV error |
|---|---|---|---|---|
| 0 | 410.8 | 0.000 | 0.860 | |
| $10^{-4}$ | 26.4 | 0.052 | 0.135 | 54.4 |
| $10^{-2}$ | 4.43 | 0.078 | 0.113 | 0.245 |
| $10^{-1}$ | 3.14 | 0.111 | 0.103 | 0.309 |
| 1 | 1.91 | 0.330 | 0.234 | 0.746 |
| 10 | 0.80 | 1.325 | 1.026 | 2.19 |

$\lambda$ 从 0 加到 $10^{-1}$，training error 略升，test error 从 0.860 降到 0.103，接近 degree 2 的水平。再加大，$w$ 被压得太狠，curve 趋于一条水平的 line，bias 回来了。$\lambda$ 是在 variance 和 bias 之间调的一个旋钮。它为什么能压住 variance，[DSA2102 第 5 站](../courses/DSA2102.html#eig)最后一个边界情况用 SVD 给了精确的说法：$\lambda$ 只压低 $X$ 的 singular value 很小的那些方向，而 noise 正是在那些方向上被放大的。

### $L_1$ 把 weight 压成 0，$L_2$ 只是压小

两种 penalty 的差别要在一个能手算的情形里看。设 feature 已经 standardize，而且两个 feature 互相 perpendicular，$\tfrac1nX^\top X=I$。把 $J_{MSE}=\tfrac1{2n}\|Xw-y\|^2$ 展开：
$$J_{MSE}=\tfrac12w^\top\Big(\tfrac1nX^\top X\Big)w-w^\top\Big(\tfrac1nX^\top y\Big)+\tfrac1{2n}y^\top y=\tfrac12\|w-\hat w\|^2+\text{const}$$
其中 $\hat w=\tfrac1nX^\top y$ 正是不加 regularization 时的 solution。每个 weight 各管各的，可以分开解。取 $\hat w=(3,\,0.4)$，$\lambda=0.5$。

**$L_2$**：对 $w_j$ 求 derivative，$(w_j-\hat w_j)+2\lambda w_j=0$，$w_j=\hat w_j/(1+2\lambda)$。两个 weight 都除以 2，得到 $(1.5,\,0.2)$。不管 $\lambda$ 多大，$0.4$ 只会被除得越来越小，永远不等于 0。

**$L_1$**：$\tfrac12(w_j-\hat w_j)^2+\lambda|w_j|$ 在 $w_j=0$ 处不可导，分两边看。$w_j>0$ 时 derivative 是 $(w_j-\hat w_j)+\lambda$，为 0 得 $w_j=\hat w_j-\lambda$，这要求 $\hat w_j>\lambda$。$w_1$：$3-0.5=2.5>0$，成立。$w_2$：$0.4-0.5<0$，不在 $w_2>0$ 这一边；$w_2<0$ 那一边同理也无解。于是看 $w_2=0$ 是不是 minimum：从 0 往正方向挪一点 $t$，loss 部分变化约 $-\hat w_2t=-0.4t$，penalty 增加 $0.5t$，净增 $0.1t>0$；往负方向挪，loss 部分和 penalty 都增加。所以 $w_2=0$，结果是 $(2.5,\,0)$。

这正是讲义里那条 theorem 的意思：一个 feature 要留在 model 里（weight 不为 0），它对降低 MSE 的贡献（以 gradient 计）必须恰好等于 $\lambda$；贡献不到 $\lambda$，optimization 宁可把 weight 设成 0 也不付这个 penalty。$w_2=0$ 处 MSE 的 gradient 大小是 0.4，不到 $\lambda=0.5$；$w_1=2.5$ 处是 $|2.5-3|=0.5$，恰好等于 $\lambda$。$L_1$ 对每个不为 0 的 weight 收一个 gradient 大小恒为 $\lambda$ 的 penalty，不管 weight 多小；$L_2$ 的 penalty gradient 是 $2\lambda w_j$，weight 越小罚得越轻，所以压不到 0。$L_1$ 因此同时在做 feature selection。

### $\lambda$ 怎么选

Training error 那一列永远选 $\lambda=0$。Test error 那一列在实际中是看不到的（这里能列出来，是因为实验里知道 $h^*$）；而且按上一站说的，test set 只能在最后用一次。应该用 validation set。但只有 10 个点，再留出 3 个，剩下的更不够用。

**$k$-fold cross-validation** 让每个点都轮流当一次 validation data。把 data 分成 $k$ 份；每次拿 $k-1$ 份 fit，在剩下的一份上算 error；$k$ 次的 error 取平均。表的最后一列是 $k=5$ 的结果（每份 2 个点：第 $j$ 个和第 $j+5$ 个）。$\lambda=0$ 那一格空着，因为 8 个点定不出 10 个 coefficient。

CV error 最小的是 $\lambda=10^{-2}$，选它，然后用全部 10 个点、这个 $\lambda$ 重新 fit 一次。它的 test error 是 0.113，表里最好的是 $10^{-1}$ 的 0.103。只有 10 个点，CV 的估计本身带着 noise，没有选中最好的那个，但两头的坏选择（0 和 10）都被它排除了。Degree、tree 的 depth、下一站的 $C$，都是这样选的。

讲义把这类在 training 之前定下、不由 training 学出来的量叫 **hyperparameter**（learning rate、feature transformation、batch size、iteration 数、$\lambda$），和 training 学出来的 parameter（weight）相对。上表是把 $\lambda$ 在一组事先定好的值上逐个试，这叫 grid search；有两个 hyperparameter 时就试所有组合，例如 3 个 learning rate 乘 2 种 regularizer 是 6 组。Random search 从一个事先定好的 distribution 里随机抽若干组来试，不试遍所有组合。也可以把一组 hyperparameter 当作第 3 站的 state、validation error 当作 evaluation function，用 hill climbing 去找。每一种办法的评分都来自 validation data，不碰 test set。

:::back
Loss 的 gradient 与 [第 5 站](#linreg)同形，gradient descent 原样使用。Training error 与 test error 背离、validation set 与 test set 的分工，是[第 4 站](#dt)最后一节的继续。

## [svm] Kernel 与 SVM

:::skip
能从“点到 hyperplane 的 distance”推出 $\min\tfrac12\|w\|^2$ 这个 optimization problem；能对一个小 dataset 指出 support vector 并算出 margin；能写出 ridge regression 的 dual formulation 并说出 representer theorem 让什么成为可能；能验证一个 kernel 等于某个 feature map 的 inner product，就可以去第 8 站。
:::

CS2109S 的讲义（AY25/26）是先讲 kernel、再讲 SVM 的：从上一站的 ridge regression 出发，证明最好的 weight 一定是 training data 的 linear combination，于是 model 只依赖 inner product，可以换成 kernel；SVM 是在这个框架里“最有名的 kernel machine”。这一站先用几何把 SVM 讲清楚，因为它的例子最直观，再在 kernel 那一节回到讲义的这条路。

### 能分开的 line 很多，选哪一条

这一站的 label 记成 $y\in\{-1,+1\}$，classifier 是 $w^\top x+b$ 的 sign。取 8 个点：

$$+1:\ (2,2),\ (3,2),\ (2,3),\ (3,4)\qquad\qquad-1:\ (1,1),\ (0,0),\ (1,0),\ (0,1)$$

它们能被一条 line 完全分开，而且这样的 line 有无穷多条：$x_1+x_2=2.2$、$x_1+x_2=3.8$、$x_1=1.5$ 都行，training error 都是 0。上一站的边界情况说过，logistic regression 在这种 data 上没有 minimum，停在哪条 line 附近取决于什么时候停。

::fig[cs2109s-lines] 8 个点和其中三条能分开它们的 line。

这些 line 的差别在于离 data 有多近。$x_1+x_2=2.2$ 离 $(1,1)$ 只有 0.14，一个落在 $(1.2,1.2)$ 的新点就会被分到另一边。一个自然的标准是：让离 boundary 最近的那个点尽量远。这个最近的距离叫 **margin**。

### 把 margin 写成 formula

先要一个点 $x_0$ 到 hyperplane $w^\top x+b=0$ 的 distance。$w$ 与 hyperplane perpendicular：hyperplane 上任取两点 $x_a$、$x_b$，两式相减得 $w^\top(x_a-x_b)=0$。从 $x_0$ 沿 $w$ 的方向走到 hyperplane 上的点 $x_p$，设走了 $r$：$x_0=x_p+r\,\dfrac{w}{\|w\|}$。两边左乘 $w^\top$ 再加 $b$：

$$w^\top x_0+b=\underbrace{w^\top x_p+b}_{0}+r\,\frac{w^\top w}{\|w\|}=r\,\|w\|\qquad\Longrightarrow\qquad r=\frac{w^\top x_0+b}{\|w\|}$$

$r$ 带 sign，在 $w$ 指向的一侧为正。乘上 label，$y^{(i)}\,\dfrac{w^\top x^{(i)}+b}{\|w\|}$ 在分对时为正，就是第 $i$ 个点到 boundary 的距离。Margin 是其中最小的：

$$\rho=\min_i\ \frac{y^{(i)}\big(w^\top x^{(i)}+b\big)}{\|w\|}$$

要找让 $\rho$ 最大的 $(w,b)$。这里有一个多余的自由度：$(w,b)$ 和 $(2w,2b)$ 是同一个 hyperplane。用它来规定一个 scale：让最近的点恰好满足 $y^{(i)}(w^\top x^{(i)}+b)=1$。这时 $\rho=1/\|w\|$，最大化它等于最小化 $\|w\|$：

$$\min_{w,b}\ \tfrac12\|w\|^2\qquad\text{subject to}\qquad y^{(i)}\big(w^\top x^{(i)}+b\big)\ge1,\quad i=1,\dots,n$$

Objective 是 convex 的 quadratic，constraint 是 linear 的，solution 是唯一的。这就是 **support vector machine（SVM）**。

:::note 讲义的两处不同写法
一是没有单独的 $b$。讲义的 model 是 $h_w(x)=\operatorname{sign}(w^\top x)$，hyperplane 是过原点的 $w^\top u=0$（zero-offset hyperplane）；要 offset 就像第 5 站那样在 $x$ 里放一个 $x_0=1$，这时 $w_0$ 也进了 $\|w\|^2$ 被一起最小化，solution 和这里单独留出 $b$ 的版本会略有不同。Tutorial 的例子也说明是“assuming there is no bias”。二是 margin 指的是两条 margin boundary（$w^\top x=\pm1$）之间的宽度 $\frac2{\|w\|}$，这里的 $\rho=\frac1{\|w\|}$ 是 boundary 到最近的点的距离，正好是它的一半。最大化哪一个都得到同一个 $w$。
:::

:::wrong $w^\top x+b$ 的数值越大，classifier 越有把握；$\|w\|$ 越大，margin 越大
$(w,b)=(1,1,-3)$ 和 $(10,10,-30)$ 是同一条 line $x_1+x_2=3$。在点 $(2,2)$ 上前者给出 1，后者给出 10，而几何上什么都没变。$w^\top x+b$ 的大小本身没有意义，除以 $\|w\|$ 之后才是 distance。在上面那个规定了 scale 的问题里关系正好反过来：margin 是 $1/\|w\|$，$\|w\|$ 越小 margin 越大。
:::

### 手解一个

先找 margin 的 upper bound。两类之间离得最近的一对点是 $(1,1)$ 和 $(2,2)$，相距 $\sqrt2$。任何分开它们的 line 都从两者之间穿过，它到这两个点的距离之和不超过 $\sqrt2$，所以较小的那个不超过 $\tfrac{\sqrt2}{2}=0.707$。Margin 不可能比 0.707 大。

再找一条达到它的 line：这两个点连线的 perpendicular bisector。$w$ 沿连线方向，设 $w=(a,a)$。要求两个点恰好在 constraint 的边上：

$$(2,2):\ 4a+b=1,\qquad(1,1):\ -(2a+b)=1\qquad\Longrightarrow\qquad a=1,\ b=-3$$

检查另外 6 个点。$w^\top x+b=x_1+x_2-3$ 在四个 $+1$ 的点上是 1、2、2、4，在四个 $-1$ 的点上是 −1、−3、−2、−2，乘上 label 都不小于 1。Constraint 全部满足，margin 是 $1/\|w\|=1/\sqrt2=0.707$，等于 upper bound，所以这就是 solution。

::fig[cs2109s-svm] 左边是刚才的 solution。右边是下一小节：多加一个点之后的两种处理。

恰好让 constraint 取等号的点叫 **support vector**，这里是 $(2,2)$ 和 $(1,1)$。其余 6 个点可以删掉，或者在 margin 之外随意挪动，solution 一点不变。8 个点里起作用的只有 2 个。

这件事有一个更精确的写法。给每个 constraint 配一个 multiplier $\alpha_i\ge0$，写出 Lagrangian $\tfrac12\|w\|^2-\sum_i\alpha_i\big[y^{(i)}(w^\top x^{(i)}+b)-1\big]$，对 $w$ 和 $b$ 的 derivative 为 0 给出

$$w=\sum_i\alpha_i\,y^{(i)}x^{(i)},\qquad\sum_i\alpha_i\,y^{(i)}=0$$

而且只有 constraint 取等号的点 $\alpha_i$ 才可能不为 0。例子里只剩两个 $\alpha$，第二式说它们相等，第一式是 $\alpha(2,2)-\alpha(1,1)=(1,1)$，所以 $\alpha=1$。$w$ 是 support vector 的 combination，于是 prediction 可以写成

$$w^\top x+b=\sum_i\alpha_i\,y^{(i)}\,\langle x^{(i)},x\rangle+b$$

Data 只以 inner product 的形式出现。这一点到 kernel 那里要用。

加第 9 个点：$(1.5,\,1)$，label 是 $+1$。Data 仍然能分开，但最近的一对变成了 $(1,1)$ 和 $(1.5,1)$，相距 0.5。同样的做法得到 $w=(4,0)$，$b=-5$，boundary 是 $x_1=1.25$，margin 只有 0.25。一个点把 margin 从 0.707 挤到了 0.25；如果它落在 $(1,1)$ 的另一侧，就干脆没有 solution 了。

放宽 constraint：允许第 $i$ 个点欠 $\xi_i\ge0$，但欠的要付钱。

$$\min_{w,b,\xi}\ \tfrac12\|w\|^2+C\sum_i\xi_i\qquad\text{subject to}\qquad y^{(i)}\big(w^\top x^{(i)}+b\big)\ge1-\xi_i,\quad\xi_i\ge0$$

$\xi_i$ 取能满足 constraint 的最小值，所以 $\xi_i=\max\big(0,\ 1-y^{(i)}(w^\top x^{(i)}+b)\big)$：在 margin 之外的点为 0，进了 margin 或分错的点按欠的量算。这个量叫 hinge loss。于是 SVM 也是“loss 加 regularization”的形状，$\tfrac12\|w\|^2$ 是上一站的 L2 penalty，$C$ 相当于 $1/\lambda$。

对这 9 个点实际解出来：

| $C$ | $w$ | $b$ | margin $1/\|w\|$ | $\sum\xi_i$ | training set 上分错几个 |
|---|---|---|---|---|---|
| 0.01 | $(0.065,\,0.060)$ | 0.625 | 11.3 | 7.22 | 4 |
| 0.1 | $(0.4,\,0.4)$ | −1.0 | 1.77 | 3.0 | 1 |
| 1 | $(0.8,\,0.6)$ | −1.8 | 1.0 | 1.6 | 0 |
| 10 及以上 | $(4,\,0)$ | −5 | 0.25 | 0 | 0 |

$C=1$ 时 boundary 是 $0.8x_1+0.6x_2=1.8$，新加的点恰好压在 boundary 上（$\xi=1$），$(1,1)$ 进了 margin（$\xi=0.6$），换来的 margin 是 1.0。$C$ 很大时欠一点都嫌贵，回到 hard margin 的 0.25。$C$ 很小时 $\|w\|$ 几乎为 0，四个 $-1$ 的点全部分错，是 underfitting。$C$ 用上一站的 cross-validation 来选。

### Kernel：不把 feature 写出来

四个一维的点：$x=-3$ 和 $3$ 的 label 是 $+1$，$x=-1$ 和 $1$ 的 label 是 $-1$。一个 threshold 分不开。加一个 feature，$\varphi(x)=(x,\,x^2)$，四个点变成 $(-3,9)$、$(-1,1)$、$(1,1)$、$(3,9)$，一条水平的 line 就分开了。

::fig[cs2109s-lift] 在 $(x,x^2)$ 这个 plane 上的 maximum-margin solution 是 $w=(0,\tfrac14)$、$b=-\tfrac54$：$x^2=9$ 的点上值为 $+1$，$x^2=1$ 的点上值为 $-1$，margin 是 $1/\|w\|=4$。

所以对付不能 linearly 分开的 data，办法是把 $x$ 送到一个更高 dimension 的 feature space $\varphi(x)$ 里，在那里做 linear 的 SVM。麻烦是 dimension 涨得很快：$x$ 有 1000 个 component 时，所有 degree-2 的乘积 $x_ix_j$ 有 $\tfrac{1000\times1001}{2}=500{,}500$ 个，degree-3 的有 $1.7\times10^8$ 个。

上一小节的结论在这里起作用：SVM 的 training 和 prediction 都只用到 inner product。这件事不是 SVM 独有的，讲义是从 ridge regression 讲起的。

### Representer theorem 与 dual formulation

取上一站带 $L_2$ regularization 的 linear regression，按讲义的写法连 $w_0$ 一起罚，$J(w)=\|Xw-y\|^2+\lambda\|w\|^2$，solution 是 $w=(X^\top X+\lambda I)^{-1}X^\top y$。先验证一个 matrix 等式：
$$X^\top(XX^\top+\lambda I)=X^\top XX^\top+\lambda X^\top=(X^\top X+\lambda I)\,X^\top$$
两边左乘 $(X^\top X+\lambda I)^{-1}$、右乘 $(XX^\top+\lambda I)^{-1}$，得到 $(X^\top X+\lambda I)^{-1}X^\top=X^\top(XX^\top+\lambda I)^{-1}$。于是
$$w=X^\top\alpha=\sum_{j=1}^n\alpha_j\,x^{(j)},\qquad\alpha=(XX^\top+\lambda I)^{-1}y$$
最好的 $w$ 是 $n$ 个 training example 的 linear combination。讲义把它推广成 **representer theorem**（非正式版）：prediction 形如 $f(w^\top x)$、loss 带某些 regularization 的 model，最好的 $w$ 都能写成 $\sum_j\alpha_jx^{(j)}$；带 $L_2$ 的 logistic regression 和 SVM 都在其中（SVM 那里的 $\alpha_iy^{(i)}$ 就是这里的 $\alpha_j$）。

代回 model，$h(x)=w^\top x=\sum_j\alpha_j\,\langle x^{(j)},x\rangle$。用 $w$ 写的叫 **primal formulation**，用 $\alpha$ 写的叫 **dual formulation**，两者给出同一个 prediction。Dual 这边要解的 $XX^\top$ 是 $n\times n$ 的，第 $(i,j)$ 个 entry 是 $\langle x^{(i)},x^{(j)}\rangle$：data 只以 inner product 的形式出现。

拿第 5 站的三个点验证，$\lambda=1$。Primal：
$$X^\top X+I=\begin{pmatrix}4&6\\6&15\end{pmatrix},\quad X^\top y=\begin{pmatrix}5\\11\end{pmatrix},\quad w=\frac1{24}\begin{pmatrix}15&-6\\-6&4\end{pmatrix}\begin{pmatrix}5\\11\end{pmatrix}=\begin{pmatrix}3/8\\7/12\end{pmatrix}$$
Dual：
$$XX^\top+I=\begin{pmatrix}3&3&4\\3&6&7\\4&7&11\end{pmatrix},\qquad\alpha=\begin{pmatrix}1/24\\11/24\\-1/8\end{pmatrix}$$
核对 $w=X^\top\alpha$：第一个 component 是 $\tfrac1{24}+\tfrac{11}{24}-\tfrac3{24}=\tfrac9{24}=\tfrac38$，第二个是 $\tfrac1{24}\cdot1+\tfrac{11}{24}\cdot2-\tfrac18\cdot3=\tfrac{14}{24}=\tfrac7{12}$。在新的点 $x=(1,4)$ 上，primal 给出 $\tfrac38+\tfrac7{12}\times4=\tfrac{65}{24}=2.708$；dual 要三个 inner product $\langle x^{(j)},x\rangle=5,\,9,\,13$，给出 $\tfrac{5}{24}+\tfrac{11\times9}{24}-\tfrac{13}{8}=\tfrac{5+99-39}{24}=\tfrac{65}{24}$，相同。

Primal 解一个 $d\times d$ 的 system，dual 解一个 $n\times n$ 的。这里 $d=2<n=3$，dual 反而更贵；它的用处在 feature 的 dimension 远大于 example 个数的时候，下面就是。

### Kernel trick

如果 $\langle\varphi(x),\varphi(z)\rangle$ 能不经过 $\varphi$ 直接算出来，$\varphi$ 就不必写出来。对两个 component 的 $x$，取 $\varphi(x)=(x_1^2,\ \sqrt2\,x_1x_2,\ x_2^2)$：

$$\langle\varphi(x),\varphi(z)\rangle=x_1^2z_1^2+2x_1x_2z_1z_2+x_2^2z_2^2=(x_1z_1+x_2z_2)^2=(x^\top z)^2$$

用数核对：$x=(1,2)$，$z=(3,1)$。左边 $\varphi(x)=(1,\ 2.828,\ 4)$，$\varphi(z)=(9,\ 4.243,\ 1)$，inner product 是 $9+12+4=25$；右边 $x^\top z=5$，square 是 25。右边只做了 $d$ 次乘法，左边的 feature 有 $d^2$ 量级。

这样的 function $K(x,z)=\langle\varphi(x),\varphi(z)\rangle$ 叫 **kernel**。把 dual formulation 里所有的 $\langle x^{(i)},x\rangle$ 换成 $K(x^{(i)},x)$，就是在 $\varphi$ 的 space 里做同一个 model，而代价和 $\varphi$ 的 dimension 无关。这叫 **kernel trick**，用它的 model 叫 kernel machine。Ridge regression 的 prediction 变成 $\sum_j\alpha_jK(x^{(j)},x)$，$\alpha=(\mathbf K+\lambda I)^{-1}y$，$\mathbf K$ 是 entry 为 $K(x^{(i)},x^{(j)})$ 的 $n\times n$ matrix；SVM 的 prediction 是

$$f(x)=\sum_i\alpha_i\,y^{(i)}\,K(x^{(i)},x)+b$$

讲义列的 polynomial kernel 是 $K(u,v)=(u^\top v)^k$，对应全部 degree 为 $k$ 的乘积，上面 $k=2$ 的展开就是它；tutor 的 demo 用的是 $(u^\top v+1)^k$，多出来的 1 让 degree 低于 $k$ 的项也进来（$d=1$、$k=2$ 时 $(xz+1)^2=x^2z^2+2xz+1$，对应 $\varphi(x)=(x^2,\sqrt2x,1)$）。那个 demo 还用 dual formulation 跑 gradient descent，直接更新 $\alpha$。

最常用的是 Gaussian kernel（也叫 RBF kernel）$K(x,z)=\exp\!\big(-\tfrac{\|x-z\|^2}{2s^2}\big)$，它对应的 $\varphi$ 是 infinite-dimensional 的（一个 feature 时是 $x$ 的各次幂乘上递减的系数，无穷多项），只能通过 $K$ 来用；primal formulation 在这里根本写不出来。它的值只取决于两点的距离：

| $\|x-z\|$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| $s=0.5$ | 1 | 0.135 | 0.0003 | $1.5\times10^{-8}$ |
| $s=1$ | 1 | 0.607 | 0.135 | 0.011 |
| $s=2$ | 1 | 0.882 | 0.607 | 0.325 |

代进 $f(x)$ 读：每个 support vector 按自己的 label 投票，票的分量随距离衰减。$s$ 小，每个 support vector 只管自己附近一小块，boundary 可以绕着每个点弯，容易 overfitting；$s$ 大，boundary 平滑。$s$ 和 $C$ 一起用 cross-validation 选。

不是随便一个 function 都能当 kernel。它必须真的是某个 $\varphi$ 的 inner product；判别的条件是：对任意一组点，由 $K(x^{(i)},x^{(j)})$ 组成的 matrix 是 symmetric positive semidefinite 的（Mercer 的 theorem；讲义的说法是 continuous、symmetric、positive-definite 的 kernel 一定对应某个 feature space 和 $\varphi$）。

讲义关于 SVM 的 dual 还有一条 sparsity theorem：data 能 linearly 分开时，optimal 的 SVM 里 $\alpha_i>0$ 只发生在恰好落在 margin boundary 上的点，即 support vector；其余的点 $\alpha_i=0$，可以丢掉，trained model 只需要存 support vector 和它们的 $\alpha_i$。前面 8 个点的例子里只剩 2 个，就是这件事。

:::back
完全能分开的 data 上 logistic regression 没有 minimum，是[第 6 站](#logreg)的边界情况；$C$ 与 $\lambda$ 的关系、用 cross-validation 选 $C$ 和 $\sigma$，也接着那一站。
:::

## [unsup] Unsupervised learning：k-means 与 PCA

:::skip
能对一个小 dataset 手动跑 k-means 到 converge 并写出每一步的 distortion，能说出它为什么每一步都不变差、为什么会停在不好的 clustering 上；能对 centered data 做 SVD，写出 compression 和 reconstruction，并算出保留了多少 variance，就可以去第 9 站。

### 没有 label 的时候

前面几站的 data 都带着 label。很多时候没有：label 要人来标，代价很高，或者根本不知道该标什么。AY25/26 第 1 学期的 PS4 从一个具体的需要开始。一张彩色 image 每个 pixel 存 R、G、B 三个 0 到 255 的数，各 8 bit，共 24 bit。一张自然的照片里实际用到的颜色远没有 $2^{24}$ 种，相近的颜色人眼也分不出。如果只留 $k$ 种颜色，每个 pixel 只要记“是第几种”，$\lceil\log_2k\rceil$ bit。一张 $200\times200$ 的 image 原来是 $40{,}000\times24=960{,}000$ bit；留 16 种颜色，是 $40{,}000\times4$ 加上 16 种颜色本身的 $16\times24$，共 160,384 bit，约为原来的 17%。

问题是留哪 16 种。没有人告诉你哪些 pixel 该归为一种颜色，只能从 pixel 自己的 RGB 值里找出“扎堆”的地方：这叫 **clustering**。讲义里的 unsupervised learning 有两类，另一类是 dimensionality reduction，放在这一站后半。

### K-means

把 $n$ 个点分成 $K$ 个 cluster。每个 cluster 用它的 **centroid** 代表，即其中各点的平均 $\mu_j=\frac1{n_j}\sum x^{(i)}$。记 $c^{(i)}\in\{1,\dots,K\}$ 为第 $i$ 个点被分到哪个 cluster。好坏用 **distortion** 衡量，每个点到自己 centroid 的距离的 square 取平均：
$$J\big(c^{(1)},\dots,c^{(n)},\mu_1,\dots,\mu_K\big)=\frac1n\sum_{i=1}^n\big\|x^{(i)}-\mu_{c^{(i)}}\big\|^2$$

$J$ 里有两组未知量，centroid 和 assignment。同时最优化它们很难，但固定一组、求另一组都很容易。**K-means** 就是轮流做这两件事：

```python
mu = random_init(K)                       # 例如随机取 K 个 data point
repeat until assignments do not change:
    for i in range(n):                    # assignment step
        c[i] = argmin over k of ||x[i] - mu[k]||
    for k in range(K):                    # update step
        mu[k] = mean of x[i] with c[i] == k
```

六个点，$K=2$：$(1,1),(1,2),(2,1),(4,3),(5,4),(5,3)$。初始 centroid 取前两个 data point，$\mu_1=(1,1)$，$\mu_2=(1,2)$。

**第 1 轮 assignment。** 每个点到两个 centroid 的距离：

| 点 | 到 $\mu_1=(1,1)$ | 到 $\mu_2=(1,2)$ | 分到 |
|---|---|---|---|
| $(1,1)$ | 0 | 1 | 1 |
| $(1,2)$ | 1 | 0 | 2 |
| $(2,1)$ | 1 | 1.414 | 1 |
| $(4,3)$ | 3.606 | 3.162 | 2 |
| $(5,4)$ | 5 | 4.472 | 2 |
| $(5,3)$ | 4.472 | 4.123 | 2 |

$J=\frac16(0+0+1+10+20+17)=8.0$（括号里是每个点到自己 centroid 的距离的 square）。

**第 1 轮 update。** Cluster 1 是 $(1,1),(2,1)$，$\mu_1=(1.5,\,1)$；cluster 2 是另外四个，$\mu_2=\big(\tfrac{1+4+5+5}4,\tfrac{2+3+4+3}4\big)=(3.75,\,3)$。$J=\frac16(0.25+8.5625+0.25+0.0625+2.5625+1.5625)=2.208$。

**第 2 轮 assignment。** 只有 $(1,2)$ 改变了：它到 $\mu_1$ 是 1.118，到 $\mu_2$ 是 2.926，改分到 cluster 1。$J=0.990$。

**第 2 轮 update。** $\mu_1=(\tfrac43,\tfrac43)$，$\mu_2=(\tfrac{14}3,\tfrac{10}3)$，$J=0.444$。

**第 3 轮 assignment。** 没有点改变，停。

::fig[cs2109s-kmeans] 动图，就是上面的四步：每个点的颜色是它此刻属于的 cluster，叉号是 centroid。看 $(1,2)$ 在第 2 轮换了一边，centroid 随之移过去。

### 为什么每一步都不变差

$J$ 依次是 8.0、2.208、0.990、0.444，从不上升。讲义的 theorem 说 k-means 的每一步都不会增加 distortion，两种 step 分开看。

**Assignment step**：centroid 不动，每个点改投离自己最近的 centroid。$J$ 里属于这个点的那一项从 $\|x^{(i)}-\mu_{\text{旧}}\|^2$ 变成所有 centroid 里最小的那个，不会变大。

**Update step**：assignment 不动，每个 cluster 的 centroid 换成平均。对一个 cluster，$\sum_i\|x^{(i)}-\mu\|^2$ 对 $\mu$ 求 gradient，$-2\sum_i(x^{(i)}-\mu)$，令其为 0 得 $\mu=\frac1{n_j}\sum_ix^{(i)}$：平均正是让这个 cluster 的那部分 $J$ 最小的点，换成它不会变大。

所以 $J$ 单调不增。Assignment 一共只有 $K^n$ 种，只要约定距离相同时不改投，同一种 assignment 不会出现两次，k-means 一定在有限步内停下。这种“轮流固定一组变量、对另一组求最优”的做法叫 coordinate descent，它是第 3 站意义上的 local search：每一步都往好处走，所以也会停在 local optimum。

:::wrong K-means 停下来的结果就是最好的 clustering
四个点 $(0,0),(0,2),(6,0),(6,2)$，是一个宽 6、高 2 的长方形的四角。初始 centroid 取 $(0,0)$ 和 $(0,2)$。第一轮 assignment：$(6,0)$ 到 $(0,0)$ 是 6，到 $(0,2)$ 是 $\sqrt{40}=6.32$，分给前者；同理 $(6,2)$ 分给后者。Update 得 $\mu_1=(3,0)$，$\mu_2=(3,2)$，上下两条边各成一个 cluster。再 assignment：$(0,0)$ 到 $(3,0)$ 是 3，到 $(3,2)$ 是 $\sqrt{13}=3.61$，谁也不改投，停。$J=\frac14(4\times9)=9$。

左右两条边各成一个 cluster 时，centroid 是 $(0,1)$ 和 $(6,1)$，$J=\frac14(4\times1)=1$，只有前者的九分之一。K-means 只保证每一步不变差，不保证到达 global minimum。常规的办法是用不同的随机初始化跑好几次，留 $J$ 最小的那次；PS4 Task 1.1.3 “Finding Better Clusters” 做的就是这个。
:::

::fig[cs2109s-kmlocal] 同样四个点，两种初始化停在两个不同的 clustering 上。

### K 怎么选

对那六个点，每个 $K$ 都取能达到的最小 distortion：

| $K$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 最小的 $J$ | 4.222 | 0.444 | 0.306 | 0.167 | 0.083 | 0 |

不能挑 $J$ 最小的 $K$：$K=n$ 时每个点自己一个 cluster，$J=0$，什么也没学到，和第 4 站的 memorizer 是一回事。$K$ 从 1 到 2，$J$ 降了 3.78；从 2 到 3 只降 0.14，之后每多一个 cluster 都只省一点。把 $J$ 对 $K$ 画出来，curve 在 $K=2$ 处折了一下，像手肘，取这里，叫 **elbow method**。它只是一个 heuristic：data 本身没有明显的分组时，curve 可能平滑地下降，看不出 elbow，或者有好几个。

### Dimensionality reduction：为什么要降维

讲义引了一条非正式的 theorem：要学好一个 hypothesis class，需要的 example 个数随 feature 个数 $d$ 指数增长，$n=O(2^d)$，叫 curse of dimensionality。另一方面，很多 feature 携带的信息是重复的。PS4 举的例子是两张 $5\times5$ 的二值 image，一张是“0”、一张是“1”：外圈 16 个 pixel 在两张图里都是 0，对区分它们毫无用处，只留中间 $3\times3$ 的 9 个就够。这里能直接看出哪些 feature 没用。一般情况下，没用的往往是 feature 的某几个 linear combination（某几个方向），要换一组坐标才看得出来。

### PCA：用 SVD 找方向

五个点：$(2,2),(3,4),(4,3),(5,6),(6,5)$。它们大致沿着一条斜线排开。

**第一步，减去 mean。** Mean 是 $(4,4)$，centered 之后是
$$\hat x^{(1)},\dots,\hat x^{(5)}=(-2,-2),\ (-1,0),\ (0,-1),\ (1,2),\ (2,1)$$

**第二步，SVD。** 讲义把 data 排成 $d\times n$ 的 matrix $\hat X^\top$（每个 column 是一个点），做 SVD：$\hat X^\top=U\Sigma V^\top$，$U$ 是 $d\times d$、column orthonormal，$\Sigma$ 的 diagonal 上是 singular value $\sigma_1\ge\sigma_2\ge\dots\ge0$。$U$ 的 column 就是 $\hat X^\top\hat X$ 的 eigenvector（因为 $\hat X^\top\hat X=U\Sigma\Sigma^\top U^\top$），singular value 的 square 是对应的 eigenvalue。这里
$$\hat X^\top\hat X=\sum_i\hat x^{(i)}\hat x^{(i)\top}=\begin{pmatrix}10&8\\8&10\end{pmatrix}$$
（左上角 $4+1+0+1+4=10$，右上角 $4+0+0+2+2=8$。）Eigenvalue 是 $10\pm8$，即 18 和 2，eigenvector 是 $u_1=\tfrac1{\sqrt2}(1,1)$ 和 $u_2=\tfrac1{\sqrt2}(-1,1)$。所以 $\sigma_1=\sqrt{18}=4.243$，$\sigma_2=\sqrt2=1.414$。

为什么是这个方向：沿一个 unit vector $u$ 看，data 的 variance 是 $\frac1n\sum_i(u^\top\hat x^{(i)})^2=\frac1nu^\top\hat X^\top\hat Xu$，在 $u$ 取最大 eigenvalue 的 eigenvector 时最大。沿 $u_1$ 是 $\frac{18}5=3.6$；沿原来的 $x_1$ 轴，$u=(1,0)$，只有 $\frac{10}5=2$。

**第三步，只留前 $r$ 个方向。** 取 $r=1$，$\tilde U=u_1$。**Compression**：每个点只记一个数 $z=\tilde U^\top\hat x$，
$$z=\tfrac1{\sqrt2}(-4,\,-1,\,-1,\,3,\,3)=(-2.828,\,-0.707,\,-0.707,\,2.121,\,2.121)$$
**Reconstruction**：$\tilde x=\tilde Uz+\bar x$，得到 $(2,2),(3.5,3.5),(3.5,3.5),(5.5,5.5),(5.5,5.5)$，都落在过 mean、沿 $u_1$ 的 line 上。

::fig[cs2109s-pca] 五个点、它们的 mean、$u_1$ 方向的 line，以及每个点投到 line 上的位置（虚线是被丢掉的那部分）。

丢掉的是每个点沿 $u_2$ 的 component。Reconstruction error 的 square 和是 $0+0.5+0.5+0.5+0.5=2$，恰好等于 $\sigma_2^2$。这不是巧合：$\hat x$ 在 orthonormal basis $u_1,u_2$ 下的两个 coordinate 各自的 square 和就是 $\sigma_1^2$ 和 $\sigma_2^2$，丢掉哪几个方向，error 就是那几个 $\sigma^2$ 之和。保留的 variance 的比例是
$$\frac{\sum_{i\le r}\sigma_i^2}{\sum_i\sigma_i^2}=\frac{18}{18+2}=90\%$$
实际中先定一个比例（例如 95%），取能达到它的最小的 $r$。讲义说 $\tilde U\tilde U^\top\approx I$，approximation error 取决于 $r$，说的就是这件事：$r=d$ 时 reconstruction 是精确的。PS4 Part 2 用 scikit-learn 的 `PCA` 把 digit image 降维后再跑 k-means，`explained_variance_ratio_` 给出的就是每个方向的 $\sigma_i^2/\sum\sigma_j^2$。

:::wrong 直接对 data 做 SVD 就行，不必先减 mean
把同样的五个点整体平移到 $(6,0),(7,2),(8,1),(9,4),(10,3)$，形状完全没变，最大 variance 的方向仍是 $\tfrac1{\sqrt2}(1,1)$。不减 mean 直接做 SVD，第一个 singular vector 是 $(0.965,\,0.262)$，和它差了 $29.8^\circ$，倒是几乎正对着 mean 的方向 $(0.970,\,0.243)$：没有 center 时，离原点最远的那个“方向”就是 mean 本身，SVD 先去解释它。只留这一个方向时，reconstruction error 的 square 和是 6.09；先减 mean 再做，是 2.0。
:::

### Linear 的 boundary 画不出来的东西

讲义里的 **neuron** 就是第 6 站的 logistic model 换了个名字：先算 $z=\sum_{j=0}^dw_jx_j$（$x_0=1$），再过一个 activation function，$\hat y=g(z)$。一个 neuron 能做 OR：取 $w=(-0.5,\,1,\,1)$，$z=x_1+x_2-0.5$，四个 input 的 $z$ 是 $-0.5,\,0.5,\,0.5,\,1.5$，过 sigmoid 后只有 $(0,0)$ 低于 0.5。把 $w_0$ 改成 $-1.5$ 就是 AND，$z$ 是 $-1.5,\,-0.5,\,-0.5,\,0.5$。两者的 decision boundary 都是一条 line。

XOR（讲义用的是它的反面 XNOR，论证一样）：$(0,0)\to0$，$(0,1)\to1$，$(1,0)\to1$，$(1,1)\to0$。设一个 linear classifier 在 $w_1x_1+w_2x_2+b>0$ 时判为 1。四个点给出四个条件：

$$b\le0,\qquad w_2+b>0,\qquad w_1+b>0,\qquad w_1+w_2+b\le0$$

中间两个相加得 $w_1+w_2+2b>0$；减去第四个（它 $\le0$），得 $b>0$，和第一个矛盾。没有任何 linear classifier 能做到，logistic regression 和不带 kernel 的 SVM 都不行。

上一站的办法是人来挑一个 feature map。这一站让 feature map 自己从 data 里学出来。先手工造一个看它长什么样：两个中间量，再对它们做 linear 的 combination。

$$h_1=\max(0,\ x_1+x_2),\qquad h_2=\max(0,\ x_1+x_2-1),\qquad\hat y=h_1-2h_2$$

| $(x_1,x_2)$ | $(h_1,h_2)$ | $\hat y=h_1-2h_2$ |
|---|---|---|
| $(0,0)$ | $(0,0)$ | 0 |
| $(0,1)$、$(1,0)$ | $(1,0)$ | 1 |
| $(1,1)$ | $(2,1)$ | 0 |

四个点全对。$h_1$、$h_2$ 叫 hidden unit，$\max(0,z)$ 叫 ReLU，是一种 **activation function**。在 $(h_1,h_2)$ 这个新的 space 里，$\hat y$ 是 linear 的：hidden layer 就是一个 feature map，只不过它里面的 weight 也是可以调的 parameter。这就是 **neural network**。

::fig[cs2109s-xor] 同样四个点，在 input 的 plane 上和在 hidden unit 的 plane 上。

:::wrong 多叠几层 linear layer，model 就更强
不加 activation function 时，两层是 $W_2(W_1x)=(W_2W_1)\,x$，还是一个 matrix 乘 $x$。比如

$$W_1=\begin{pmatrix}1&2\\0&1\end{pmatrix},\quad W_2=\begin{pmatrix}2&0\\1&1\end{pmatrix}\quad\Longrightarrow\quad W_2W_1=\begin{pmatrix}2&4\\1&3\end{pmatrix}$$

叠 100 层也只等于一层。上面的 XOR network 去掉两个 $\max$ 之后是 $\hat y=(x_1+x_2)-2(x_1+x_2-1)=2-x_1-x_2$，一个 linear function，又分不开了。让多层有意义的是层与层之间的 nonlinearity。
:::

### 一个走得完的小 network

一般的写法：第 $l$ 层先做 linear 的一步，再过 activation function $g$，

$$z^{[l]}=W^{[l]}a^{[l-1]}+b^{[l]},\qquad a^{[l]}=g\big(z^{[l]}\big),\qquad a^{[0]}=x$$

这一站用一个能手算到底的 network：2 个 input，2 个 hidden unit，1 个 output；activation function 都取 sigmoid，loss 取 cross-entropy。所以最后一层就是在 $(a_1,a_2)$ 上做 [第 6 站](#logreg)的 logistic regression。一共 9 个 parameter：

$$W^{[1]}=\begin{pmatrix}0.3&0.2\\-0.4&0.1\end{pmatrix},\quad b^{[1]}=\begin{pmatrix}0.1\\0.2\end{pmatrix},\qquad W^{[2]}=\begin{pmatrix}0.5&-0.6\end{pmatrix},\quad b^{[2]}=0.1$$

一个 example：$x=(1,2)$，$y=1$。**Forward pass** 从前往后算：

$$\begin{aligned}z_1&=0.3\times1+0.2\times2+0.1=0.8,&a_1&=\sigma(0.8)=0.6900\\z_2&=-0.4\times1+0.1\times2+0.2=0,&a_2&=\sigma(0)=0.5\\z_3&=0.5\times0.6900-0.6\times0.5+0.1=0.1450,&\hat y&=\sigma(0.1450)=0.5362\end{aligned}$$

$$L=-\ln\hat y=-\ln0.5362=0.6233$$

### 为什么不用 numerical differentiation

要做 gradient descent，需要 $L$ 对 9 个 parameter 各自的 partial derivative。最直接的办法是把某个 parameter 加一点点，重算一遍 $L$，看变了多少。把 $W^{[1]}_{11}$ 从 0.3 改成 0.3001，重做 forward pass，$L$ 从 0.62327892 变成 0.62327396：

$$\frac{\partial L}{\partial W^{[1]}_{11}}\approx\frac{0.62327396-0.62327892}{0.0001}=-0.0496$$

数是对的。问题在代价。一次 forward pass 里每个 weight 恰好被乘一次，所以它大约要 $P$ 次运算，$P$ 是 parameter 的个数。每个 parameter 都要单独重做一次 forward pass，一共 $P+1$ 次，合计约 $P^2$ 次运算，而且这只是一个 example、一步 gradient descent：

| parameter 个数 $P$ | numerical differentiation：约 $P^2$ | backpropagation：约 $3P$ |
|---|---|---|
| 9 | 90 | 27 |
| $10^6$ | $10^{12}$ | $3\times10^6$ |
| $10^8$ | $10^{16}$ | $3\times10^8$ |

右边一列是下面要讲的办法：一次 forward pass 加一次差不多同样代价的 backward pass，得到全部 $P$ 个 derivative。（另外，[DSA2102 第 7 站](../courses/DSA2102.html#quad)说明了 difference formula 的 accuracy 有上限，所以 numerical differentiation 只适合拿来核对。）

能省下一个 factor $P$，是因为那 $P$ 次 forward pass 里绝大部分计算是重复的。改 $W^{[1]}_{11}$ 和改 $W^{[1]}_{12}$，都是先改变 $z_1$，之后 $z_1$ 怎样一路影响到 $L$，两次完全一样。把“$z_1$ 对 $L$ 的影响”只算一次，存下来，两个 weight 都能用。

### Backward pass：从后往前，每个量算一次

对 forward pass 里的每一个中间量 $q$，算 $\dfrac{\partial L}{\partial q}$。Chain rule 说：$q$ 通过它直接影响的下一个量 $r$ 影响 $L$，所以

$$\frac{\partial L}{\partial q}=\frac{\partial L}{\partial r}\cdot\frac{\partial r}{\partial q}$$

前一个 factor 是从后面传回来的，已经算好；后一个 factor 只和 $q\to r$ 这一步有关。从 $L$ 开始往回走。

**第 1 步，$\hat y$。** $L=-\ln\hat y$，所以 $\dfrac{\partial L}{\partial\hat y}=-\dfrac1{\hat y}=-1.8650$。

**第 2 步，$z_3$。** $\hat y=\sigma(z_3)$，$\dfrac{\partial\hat y}{\partial z_3}=\hat y(1-\hat y)=0.2487$。所以 $\dfrac{\partial L}{\partial z_3}=-1.8650\times0.2487=-0.4638$。这正是第 6 站的 $\hat y-y=0.5362-1$。

**第 3 步，第二层的 parameter 和 $a_1$、$a_2$。** $z_3=W^{[2]}_1a_1+W^{[2]}_2a_2+b^{[2]}$，它对每个量的 derivative 就是和这个量相乘的那个数。

$$\frac{\partial L}{\partial W^{[2]}_1}=-0.4638\times a_1=-0.3200,\qquad\frac{\partial L}{\partial W^{[2]}_2}=-0.4638\times a_2=-0.2319,\qquad\frac{\partial L}{\partial b^{[2]}}=-0.4638$$

$$\frac{\partial L}{\partial a_1}=-0.4638\times0.5=-0.2319,\qquad\frac{\partial L}{\partial a_2}=-0.4638\times(-0.6)=0.2783$$

**第 4 步，$z_1$、$z_2$。** $a=\sigma(z)$，$\sigma'(z_1)=a_1(1-a_1)=0.2139$，$\sigma'(z_2)=0.25$。

$$\frac{\partial L}{\partial z_1}=-0.2319\times0.2139=-0.0496,\qquad\frac{\partial L}{\partial z_2}=0.2783\times0.25=0.0696$$

**第 5 步，第一层的 parameter。** $z_1=W^{[1]}_{11}x_1+W^{[1]}_{12}x_2+b^{[1]}_1$，同第 3 步。

$$\frac{\partial L}{\partial W^{[1]}}=\begin{pmatrix}-0.0496\times1&-0.0496\times2\\0.0696\times1&0.0696\times2\end{pmatrix}=\begin{pmatrix}-0.0496&-0.0992\\0.0696&0.1391\end{pmatrix},\qquad\frac{\partial L}{\partial b^{[1]}}=\begin{pmatrix}-0.0496\\0.0696\end{pmatrix}$$

::fig[cs2109s-backprop] 同一次计算画成 graph。每个量只被访问两次：forward 时算它的值，backward 时算 $L$ 对它的 derivative。

$\partial L/\partial W^{[1]}_{11}=-0.0496$，和上一小节用 numerical differentiation 得到的相同（9 个 derivative 全部核对过，相差不到 $10^{-9}$）。第 4 步算出的 $\partial L/\partial z_1$ 在第 5 步被 $W^{[1]}_{11}$、$W^{[1]}_{12}$、$b^{[1]}_1$ 三个 parameter 共用，这就是省下来的地方。

拿这组 gradient 走一步 gradient descent，$\gamma=1$：每个 parameter 减去自己的 derivative，例如 $W^{[2]}=(0.5+0.3200,\ -0.6+0.2319)=(0.8200,\ -0.3681)$。用新的 parameter 重做 forward pass，$\hat y$ 从 0.5362 升到 0.7374，$L$ 从 0.6233 降到 0.3046。

### 写成每一层通用的形式

把 $\partial L/\partial z^{[l]}$ 记作 $\delta^{[l]}$。上面五步就是三条规则：

$$\delta^{[\text{last}]}=\hat y-y,\qquad\delta^{[l]}=\Big(W^{[l+1]\top}\delta^{[l+1]}\Big)\odot g'\big(z^{[l]}\big),\qquad\frac{\partial L}{\partial W^{[l]}}=\delta^{[l]}\,a^{[l-1]\top},\quad\frac{\partial L}{\partial b^{[l]}}=\delta^{[l]}$$

$\odot$ 是逐个 component 相乘。第一条是第 1、2 步（sigmoid 配 cross-entropy 时成立）；第二条是第 3 步后半加第 4 步，$W^{[l+1]\top}$ 把后一层的 $\delta$ 按 weight 分回给前一层的每个 unit；第三条是第 3 步前半和第 5 步。用例子核对第二条：

$$W^{[2]\top}\delta^{[2]}=\begin{pmatrix}0.5\\-0.6\end{pmatrix}(-0.4638)=\begin{pmatrix}-0.2319\\0.2783\end{pmatrix},\qquad\begin{pmatrix}-0.2319\\0.2783\end{pmatrix}\odot\begin{pmatrix}0.2139\\0.25\end{pmatrix}=\begin{pmatrix}-0.0496\\0.0696\end{pmatrix}$$

一个 hidden unit 如果同时影响后一层的好几个 unit，$W^{[l+1]\top}\delta^{[l+1]}$ 里的 sum 就把各条路传回来的影响加在一起。检查自己推的式子，最快的办法是看 shape：$\partial L/\partial W^{[l]}$ 必须和 $W^{[l]}$ 一样大。

:::wrong 把所有 weight 初始化成同一个数最稳妥
把 $W^{[1]}$ 的四个 entry 和 $W^{[2]}$ 的两个 entry 都设成 0.5，bias 设成 0。Forward：$z_1=z_2=1.5$，$a_1=a_2=0.8176$，两个 hidden unit 算出的东西一模一样。Backward：$\delta^{[1]}=(-0.0228,\,-0.0228)$，$\partial L/\partial W^{[1]}$ 的两个 row 都是 $(-0.0228,\,-0.0457)$。两个 unit 得到相同的 update，下一步仍然相同，永远相同：这个 network 实际上只有一个 hidden unit。

全设成 0 更糟：$\delta^{[1]}=W^{[2]\top}\delta^{[2]}\odot g'=0$，第一层的 gradient 是 0。所以 weight 要用小的随机数初始化，让各个 unit 一开始就不一样。
:::

:::edge Vanishing gradient
第二条规则里每往回走一层，$\delta$ 就乘一次 $g'(z)$。Sigmoid 的 $\sigma'(z)=\sigma(1-\sigma)$ 最大只有 0.25（例子里是 0.2139 和 0.25）。10 层之后这个 factor 不超过 $0.25^{10}\approx10^{-6}$，靠前的层几乎收不到 gradient，学不动。ReLU 在 $z>0$ 时的 derivative 是 1，没有这种逐层缩小，这是它成为默认选择的原因之一。讲义对它的处理正是换 activation function；反过来 factor 大于 1、逐层放大的情形叫 exploding gradient，第 10 站的 RNN 上会算到它和它的处理办法。
:::

### Output layer 跟着 task 走

Hidden layer 学 feature transformation，各种 task 都一样；不同的只是最后一层有几个 neuron、用什么 activation、配什么 loss。

| task | target | output layer | loss |
|---|---|---|---|
| binary classification | $\{0,1\}$ | 1 个 neuron，sigmoid | binary cross-entropy |
| multi-class classification | $C$ 个 class 之一，写成 one-hot vector | $C$ 个 neuron，softmax | cross-entropy |
| regression | 一个实数 | 1 个 neuron，不加 activation（identity） | MSE |
| multi-output regression | $K$ 个实数 | $K$ 个 neuron，identity | MSE |

**One-hot encoding** 把第 $i$ 个 class 写成一个长度为 $C$、只有第 $i$ 个位置是 1 的 vector；$C=3$ 时 class 1 是 $(1,0,0)$。**Softmax** 把 $C$ 个 $z_i$ 变成一个 probability distribution：
$$\hat y_i=\frac{e^{z_i}}{\sum_{j=1}^Ce^{z_j}}$$
取 $z=(2,\,1,\,0.1)$：$e^z=(7.389,\,2.718,\,1.105)$，和是 11.212，$\hat y=(0.659,\,0.242,\,0.099)$，三个数都在 0 和 1 之间，加起来是 1。预测时取最大的那个，这里是 class 1。

Loss 是 cross-entropy $L=-\sum_{j=1}^Cy_j\ln\hat y_j$。$y$ 是 one-hot，sum 里只剩真实 class 那一项：真实是 class 1 时 $L=-\ln0.659=0.417$。它对 $z$ 的 derivative 和 sigmoid 配 binary cross-entropy 时一样干净，$\partial L/\partial z=\hat y-y=(-0.341,\,0.242,\,0.099)$，所以上面三条规则的第一条原样适用。$C=2$ 时 softmax 退化成 sigmoid：$\hat y_1=\frac{e^{z_1}}{e^{z_1}+e^{z_2}}=\sigma(z_1-z_2)$。

### Image：为什么要 convolution

一张 $200\times200$ 的彩色 image 有 $200\times200\times3=120{,}000$ 个 input。一个 fully connected 的 hidden unit 就要 120,000 个 weight，1000 个 hidden unit 是 $1.2\times10^8$ 个。而且这些 weight 各管各的位置：在左上角学会认一条 edge，对右下角毫无帮助。

**Convolution layer** 做两个限制。每个 output 只看 input 上的一小块（local connectivity）；所有位置用同一组 weight（parameter sharing）。这组 weight 叫 filter。把一个 $3\times3$ 的 filter 在 $5\times5$ 的 image 上逐格滑动，每个位置把 filter 和它盖住的那一块逐个 entry 相乘再求和：

$$\begin{pmatrix}1&1&1&0&0\\1&1&1&0&0\\1&1&1&0&0\\1&1&1&0&0\\1&1&1&0&0\end{pmatrix}\ *\ \begin{pmatrix}1&0&-1\\1&0&-1\\1&0&-1\end{pmatrix}\ =\ \begin{pmatrix}0&3&3\\0&3&3\\0&3&3\end{pmatrix}$$

这个 filter 算的是“一块里左边一个 column 的 sum 减右边一个 column 的 sum”。盖住 column 1 到 3 时两边都是 3，得 0；盖住 column 2 到 4 时是 $3-0=3$；盖住 column 3 到 5 时也是 $3-0=3$。它在 image 由亮变暗的地方有 response，在一片均匀的地方没有，而且不管这条 edge 出现在哪一个 row。在 CNN 里 filter 的 9 个数不是人定的，是 parameter，由 backpropagation 来学；一个 weight 被许多位置共用，它的 gradient 就是各个位置传回来的 gradient 之和。

::fig[cs2109s-conv] Filter 在 image 上逐格滑动，每个位置算出 output 的一格。

Output 的大小：input 宽 $W$，filter 宽 $F$，四周补 $P$ 圈 0（padding），每次滑 $S$ 格（stride），output 宽

$$\frac{W-F+2P}{S}+1$$

上面是 $(5-3+0)/1+1=3$。同样的 input 取 $P=1$ 得 5，大小不变；$7\times7$ 的 input、$3\times3$ 的 filter，stride 1 得 5，stride 2 得 3。

Parameter 的个数只和 filter 有关：input 有 $D$ 个 channel、用 $K$ 个 $F\times F$ 的 filter 时是 $K\,(F\cdot F\cdot D+1)$。对彩色 image 用 16 个 $3\times3$ 的 filter 是 $16\times(27+1)=448$ 个，和 image 多大无关。CS231n 给的例子是 AlexNet 的第一层：96 个 $11\times11\times3$ 的 filter，共用时是 34,944 个 parameter，不共用是 105,705,600 个。

公式里的 $D$ 来自讲义说的规则：filter 的 channel 数必须和 input 一样，一个 filter 在每个位置把所有 channel 的乘积加在一起，只给出一个数，所以一个 filter 产生一个 single-channel 的 feature map，用几个 filter 就有几个 output channel。AY25/26 第 2 学期 Tutorial 10 的一道题：$3\times3$、3 个 channel 的 input，用 $2\times2$ 的 kernel 得到 5 个 output channel，weight 有 $2\times2\times3\times5=60$ 个（题目只数 weight；加上每个 filter 一个 bias 是 $5\times(4\cdot3+1)=65$）。同一题问怎样得到一个 $3\times3$ 的 output、每个 entry 是三个 channel 在同一位置的平均：用一个 $1\times1\times3$ 的 filter，三个 weight 都是 $\tfrac13$，stride 1，不加 padding。$1\times1$ 的 filter 不看邻居，只在 channel 之间做 linear combination。

Convolution layer 之间通常插入 **pooling layer**：把每个 $2\times2$ 的小块换成其中的 maximum，stride 取 2。宽和高各减半，丢掉 75% 的数，没有 parameter。留下的是“这一小块里有没有出现过强的 response”，位置的细微移动不再影响结果。另一种是 average pooling，取平均而不是 maximum。几组 convolution、ReLU、pooling 之后，再接 fully connected layer 给出最后的 output。

### Overfitting：dropout 与 early stopping

Network 的 parameter 动辄几百万，比 example 还多，第 6 站的 overfitting 在这里更容易发生。L2 regularization 照样能用，讲义另外讲了两种 network 专用的办法。

**Dropout**：training 时每一步把每个 neuron 的 output 以 probability $p$ 设成 0，每一步关掉的是不同的一批。拿上面 2-2-1 network 的 hidden layer 说，$a=(0.6900,\,0.5)$，$p=0.5$，这一步抽到关掉第二个，传给下一层的是 $(0.6900,\,0)$，$z_3$ 只剩 $0.5\times0.69+0.1$；下一步可能关掉的是第一个。任何一个 neuron 都可能缺席，network 就不能把结果押在某一个 neuron 上，必须让好几条 path 都能给出对的答案。PS4 handout 的说法是这相当于同时训练许多个更稀疏的 network 的 ensemble。预测时不再关掉任何 neuron。（PyTorch 的 `nn.Dropout` 在 training 时还把留下来的 output 乘上 $\frac1{1-p}$，上例里是 $(1.38,\,0)$，这样 output 的 expectation 和预测时一致：$0.5\times1.38+0.5\times0=0.69$。）$p$ 是一个 hyperparameter：$p=0$ 就是没有 dropout，$p$ 越接近 1，每一步留下的 neuron 越少。PS4 Task 2.2 让你分别用 $p=0.1$ 和 $p=0.95$ 训练，对照每个 epoch 的 training loss 解释为什么两头都不好。

**Early stopping**：每个 epoch 之后在 validation set 上算一次 loss。Training loss 一路下降，validation loss 先降后升，和第 4 站 decision tree 的 depth、第 6 站 polynomial 的 degree 是同一个形状，只是横轴换成了 epoch。在 validation loss 最低的那个 epoch 停下，用那时的 weight。

:::back
Training 用的是[第 5 站](#linreg)的 gradient descent 和 SGD，backpropagation 只负责提供 gradient。Binary classification 时最后一层是[第 6 站](#logreg)的 logistic regression，regularization 和 validation 照旧。Hidden layer 是[第 7 站](#svm)的 feature map，区别在于它是学出来的。
:::

### 同一个词，两个 label

讲义用 word tagging 引入：给句子里的每个词判断它是不是 verb。句子是 “I saw a saw”，第 2 个词是 verb，第 4 个是 noun。每个词用 one-hot encoding 表示：vocabulary 是 {I, saw, a}，大小为 3，I 是 $(1,0,0)$，saw 是 $(0,1,0)$，a 是 $(0,0,1)$。

用上一站的 MLP 一个词一个词地判断，第 2 个和第 4 个词的 input 都是 $(0,1,0)$，output 一定相同，两个里至少错一个。错不在 network 不够大，而在于它看不到上下文：一个词是不是 verb，取决于它前面是什么。

### Hidden state

办法是让 network 带一份 memory。每个 time step $t$ 读入一个词 $x^{[t]}$，同时读入上一步留下的 **hidden state** $h^{[t-1]}$，算出新的 hidden state 和这一步的 output：
$$h^{[t]}=g^{[h]}\Big(\big(W^{[xh]}\big)^\top x^{[t]}+\big(W^{[hh]}\big)^\top h^{[t-1]}\Big),\qquad\hat y^{[t]}=g^{[y]}\Big(\big(W^{[hy]}\big)^\top h^{[t]}+b^{[y]}\Big)$$
（讲义的式子没有写 bias；这里 output 加了一个，否则判不出例子里的结果。）这叫 **recurrent neural network（RNN）**。三组 weight 在每个 time step 都是同一组，所以同一个 network 能处理任意长度的 sequence。

为了能手算，取一维的 hidden state，$g^{[h]}=\tanh$，$g^{[y]}=\sigma$，$h^{[0]}=0$：
$$W^{[xh]}=\begin{pmatrix}0.2\\0.6\\-2.0\end{pmatrix},\qquad W^{[hh]}=1,\qquad W^{[hy]}=4,\qquad b^{[y]}=-2$$
$x^{[t]}$ 是 one-hot，$(W^{[xh]})^\top x^{[t]}$ 就是取出这个词对应的那个数：I 是 0.2，saw 是 0.6，a 是 $-2.0$。

| $t$ | 词 | $z=(W^{[xh]})^\top x^{[t]}+h^{[t-1]}$ | $h^{[t]}=\tanh z$ | $4h^{[t]}-2$ | $\hat y^{[t]}$ |
|---|---|---|---|---|---|
| 1 | I | $0.2+0=0.2$ | 0.1974 | $-1.2105$ | 0.230 |
| 2 | saw | $0.6+0.1974=0.7974$ | 0.6626 | 0.6503 | 0.657 |
| 3 | a | $-2.0+0.6626=-1.3374$ | $-0.8711$ | $-5.484$ | 0.004 |
| 4 | saw | $0.6-0.8711=-0.2711$ | $-0.2646$ | $-3.058$ | 0.045 |

按 0.5 判，只有第 2 个词是 verb，四个全对。两个 saw 的 input 一样，不同的是带进来的 $h^{[t-1]}$：I 之后是 0.1974，a 之后是 $-0.8711$。把 $W^{[hh]}$ 设成 0（没有 memory），两个 saw 的 $h$ 都是 $\tanh0.6=0.537$，$\hat y$ 都是 $\sigma(0.148)=0.537$，又回到 MLP 的处境。

::fig[cs2109s-rnn] 同一个 RNN cell 沿 time step 展开：四个 box 用的是同一组 weight，横向的箭头把 hidden state 往后传。

Input 和 output 的个数不必相同。讲义列了四种：

| 形状 | input | output | 讲义的例子 |
|---|---|---|---|
| many-to-many（等长） | 每个词 | 每个词一个 label | word tagging |
| many-to-one | 一个句子 | 最后一步一个 label | sentiment analysis |
| one-to-many | 一个 vector | 一串词 | image captioning（CNN 给出的 image feature vector 生成一句描述） |
| many-to-many（不等长） | 一个问题 | 一个回答 | question answering |

PS4 Part 3 是 many-to-one：把 sine wave 切成重叠的窗口，例如 $[x^{[1]},x^{[2]},x^{[3]}]\mapsto x^{[4]}$、$[x^{[2]},x^{[3]},x^{[4]}]\mapsto x^{[5]}$，每个窗口预测下一个值，用 `nn.RNN` 读完 sequence，把最后的 hidden state 送进一个 `nn.Linear` 给出 prediction。

### Gradient 沿 time step 传回去

Training 时 loss 要对每个 time step 的 weight 求 gradient，chain rule 从最后一步一路往回乘。$h^{[t]}=\tanh(\dots+W^{[hh]}h^{[t-1]})$，所以
$$\frac{\partial h^{[t]}}{\partial h^{[t-1]}}=W^{[hh]}\big(1-(h^{[t]})^2\big)$$
例子里从第 4 步传回第 1 步：
$$\frac{\partial h^{[4]}}{\partial h^{[1]}}=\prod_{t=2}^{4}\big(1-(h^{[t]})^2\big)=(1-0.6626^2)(1-0.8711^2)(1-0.2646^2)=0.561\times0.241\times0.930=0.126$$
才三步，第 1 步对第 4 步的影响就只剩八分之一。$\tanh$ 的 derivative 不超过 1，每个 factor 的大小不超过 $|W^{[hh]}|$。$|W^{[hh]}|$ 小于 1、或者 $h$ 常落在 $\tanh$ 平坦的两端时，factor 小于 1：每步是 0.5，20 步之后是 $0.5^{20}=9.5\times10^{-7}$，开头的词对 gradient 几乎没有贡献，这是 **vanishing gradient**。反过来 $W^{[hh]}=3$ 而 $h$ 在 0 附近时，factor 接近 3，20 步之后是 $3^{20}=3.5\times10^9$，gradient 溢出，这是 **exploding gradient**。PS4 Demo 3.4 在 sine wave 后面接上越来越长的 noise，RNN 越来越难记住前面的 pattern，就是这件事。

讲义对两种情形的处理不同。Vanishing 靠换 activation function（以及下面的 attention 绕开它）；exploding 靠 **gradient clipping**：gradient 的 norm 超过一个上限 $c$ 时，把它按比例缩到 $c$，
$$g\leftarrow c\cdot\frac{g}{\|g\|}\qquad\text{if }\|g\|>c$$
$g=(30,\,40)$、$c=5$ 时 $\|g\|=50$，clip 成 $(3,\,4)$：方向不变，只是步子变小。

### Attention：每个词直接看所有的词

RNN 里第 1 个词的信息要经过中间每一步才能到达最后，越传越弱，而且必须一步一步按顺序算，不能并行。**Attention** 让每个位置直接去看 sequence 里的所有位置，自己决定看谁。

每个 input $x_i$ 用三个可以学的 matrix（所有位置共用）变出三个 vector：query $q_i=x_iW_Q$（“我在找什么”），key $k_i=x_iW_K$（“我这里有什么”），value $v_i=x_iW_V$（“我实际提供的内容”）。位置 $i$ 拿自己的 query 和每个位置的 key 做 dot product 得到 attention score，过 softmax 变成 weight，再对所有 value 取 weighted sum：
$$a_{ij}=\frac{e^{q_i\cdot k_j}}{\sum_{j'}e^{q_i\cdot k_{j'}}},\qquad o_i=\sum_ja_{ij}\,v_j$$
Query 和 key 都来自同一个 sequence，叫 **self-attention**。

句子 “dog bites man”，三个词的 embedding 取 $\text{dog}=(1,0)$，$\text{bites}=(0,1)$，$\text{man}=(1,1)$；$W_Q=\begin{pmatrix}1&0\\0&2\end{pmatrix}$，$W_K=\begin{pmatrix}2&0\\0&1\end{pmatrix}$，$W_V=I$。于是

| 词 | $q$ | $k$ | $v$ |
|---|---|---|---|
| dog | $(1,0)$ | $(2,0)$ | $(1,0)$ |
| bites | $(0,2)$ | $(0,1)$ | $(0,1)$ |
| man | $(1,2)$ | $(2,1)$ | $(1,1)$ |

算 bites 的 output。它的 $q=(0,2)$ 和三个 key 的 dot product 是 $0,\ 2,\ 2$；softmax 之后是 $\frac{(1,\,e^2,\,e^2)}{1+2e^2}=(0.063,\,0.468,\,0.468)$；
$$o_{\text{bites}}=0.063\,(1,0)+0.468\,(0,1)+0.468\,(1,1)=(0.532,\,0.937)$$
bites 主要看它自己和 man。三个位置一起写成 matrix：$Q$、$K$、$V$ 各是 $3\times2$，score matrix 是 $QK^\top=\begin{pmatrix}2&0&2\\0&2&2\\2&2&4\end{pmatrix}$，对每一行做 softmax 再乘 $V$，三个 output 一次算完。每一行之间互不依赖，这正是它能并行、而 RNN 不能的原因。（实际的 transformer 还把 score 除以 $\sqrt{d_k}$，$d_k$ 是 key 的 dimension，免得 dimension 大时 softmax 过于尖锐；讲义的式子里没有这一步。）

::fig[cs2109s-attn] 两个句子里 bites 的 attention weight。三个词换了位置，三条连线的粗细跟着词走，bites 得到的 output 一模一样。

:::wrong Self-attention 能看到整个句子，自然也知道词的顺序
把句子换成 “man bites dog”，三个 vector 不变，只是排列变了。bites 的 $q$ 仍是 $(0,2)$，它和 man、bites、dog 的 key 的 dot product 是 $2,\ 2,\ 0$，softmax 是 $(0.468,\,0.468,\,0.063)$，weighted sum 仍是 $0.468(1,1)+0.468(0,1)+0.063(1,0)=(0.532,\,0.937)$。Dog 的 output 在两个句子里也都是 $(0.937,\,0.532)$，只是从第 1 行挪到了第 3 行。

原因在式子里：$o_i$ 只取决于 $q_i$ 和 $\{(k_j,v_j)\}$ 这个集合，sum 和顺序无关。把 input 换个排列，output 就跟着换同一个排列，每个词得到的东西完全不变。“狗咬人”和“人咬狗”在 self-attention 看来是同一件事。
:::

### Positional encoding

所以要把位置信息直接加进 input。PS4 Task 4.1 用的是讲义里的 sinusoidal positional encoding：位置 $i$、dimension $d$ 的 vector，第 $2k$ 和 $2k+1$ 个 component 是
$$PE(i,2k)=\sin\Big(\frac{i}{10000^{2k/d}}\Big),\qquad PE(i,2k+1)=\cos\Big(\frac{i}{10000^{2k/d}}\Big)$$
$d=4$ 时前四个位置是：

| 位置 $i$ | $\sin i$ | $\cos i$ | $\sin\frac{i}{100}$ | $\cos\frac{i}{100}$ |
|---|---|---|---|---|
| 0 | 0 | 1 | 0 | 1 |
| 1 | 0.841 | 0.540 | 0.010 | 1.000 |
| 2 | 0.909 | $-0.416$ | 0.020 | 1.000 |
| 3 | 0.141 | $-0.990$ | 0.030 | 1.000 |

前两个 component 转得快，后两个转得慢，合起来每个位置得到一个不同的 vector；$d$ 越大，越慢的 component 越多，能分开的位置越多。

在例子里（$d=2$，$PE(i)=(\sin i,\cos i)$）把它加到 embedding 上再做 self-attention。“dog bites man”里 bites 的 attention weight 变成 $(0.158,\,0.639,\,0.203)$，output 是 $(1.083,\,1.261)$；“man bites dog”里是 $(0.841,\,0.156,\,0.002)$，output 是 $(0.977,\,1.923)$。两个句子终于分开了。PS4 Task 4.3 让你去掉 positional encoding 重新训练 transformer，再比较 sine wave 上的预测，看到的就是这里的差别。

**Transformer** 的一个 encoder layer 由一个 self-attention 加一个对每个位置分别作用的 feed-forward network 组成，可以叠很多层；同时用几组独立的 $W_Q,W_K,W_V$ 叫 multi-head attention（PS4 的 `nn.TransformerEncoderLayer(d_model, nhead, dim_feedforward)` 里 `nhead` 就是 head 的个数，那里设成 1）。Attention 能并行，使 transformer 能在大得多的 data 和 model 上训练，成为 GPT 一类 large language model 的基础。

:::back
Hidden state 的更新和 output 都是[第 9 站](#nn)的 layer，training 仍是 backpropagation，只是要沿 time step 往回传；vanishing gradient 和第 9 站那个边界情况是同一个乘积。Attention weight 用的 softmax 也在第 9 站。
:::
