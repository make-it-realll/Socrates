先看三件事。前两件用的是同一个 system：一个 RC circuit，input $x(t)$ 和 output $y(t)$ 满足 $y'(t)+y(t)=x(t)$。

**第一件。** 往里送一个 width 为 1 的 rect pulse，出来的是一条先升后降的 curve，和 input 的形状完全不同；要知道它长什么样，得算一个 integral。把 input 换成 $\cos t$，出来的是 $0.707\cos(t-45^\circ)$：还是 $\cos$，frequency 没变，只是 amplitude 小了一点、phase 晚了一点。这一次不用算 integral，只要算一个 complex number。

::fig[ee2023-eigen] 同一个 system，两种 input。上面一行的 output 要靠第 1 站的 convolution 才算得出来；下面一行只要把 $s=j$ 代进 $\dfrac{1}{s+1}$。

**第二件。** 还是 $\cos t$，但在 $t=0$ 才接上。Output 是 $0.707\cos(t-45^\circ)-0.5\,e^{-t}$，多出来一项 $-0.5\,e^{-t}$。它不是任何 frequency 的 sinusoid，只谈 frequency 的语言说不出它是从哪来的。

::fig[ee2023-switchon] 第二件事：左边是这个 RC circuit，$t=0$ 时接上 $\cos t$，capacitor 上的 voltage 就是 $y(t)$。右边随时间画出 output：看黑色竖线，它是 output 和 $0.707\cos(t-45^\circ)$ 之差 $-0.5\,e^{-t}$，前几秒明显，之后缩到看不见，两者重合。

**第三件。** 一个 6 kHz 的 $\cos$，每秒取 10000 个 sample 存下来，再还原成 continuous-time signal，得到的是 4 kHz 的 $\cos$。

::fig[ee2023-samples] 第三件事。右边灰线是 6 kHz，彩线是 4 kHz，圆点是每 0.1 ms 取的 sample。左边把两个 $\cos$ 画成转动的 spoke（spoke 的高度就是 $\cos$ 的值），只在 sample 的时刻看一眼：看两根 spoke 怎样始终左右对称、高度相同，所以每个 sample 上两条 curve 取同一个值。第 7 站会再用这张图。

这门课的全部内容都从一个事实展开：linear time-invariant（LTI）system 遇到 complex exponential $e^{st}$ 时，只把它乘上一个 complex number $H(s)$，不改变它的形状。所以只要能把 signal 拆成 complex exponential 的和，system 的作用就从“算 integral”变成“做乘法”。第一件事是这个事实本身（第 1 站）。拆法有三种，一种比一种管得宽：

| 拆法 | 用哪些 exponential | 适用的 signal | System 的作用 | 站 |
|---|---|---|---|---|
| Fourier series | $e^{j2\pi kf_0t}$，$k$ 是 integer | periodic | 每个 coefficient 乘 $H$ | 2 |
| Fourier transform | $e^{j2\pi ft}$，$f$ 取所有 real number | energy 有限的 aperiodic signal | $Y(f)=H(f)\,X(f)$ | 3 |
| Laplace transform | $e^{st}$，$s$ 取 complex number | 从某一刻才开始、可以增长的 signal | $Y(s)=H(s)\,X(s)$ | 4 |

第二件事里多出来的 $e^{-t}$ 要到第三种拆法才说得清：它是 system 自己的 mode，由 $H(s)$ 的 pole 决定（第 4、5 站）。把 $|H(j\omega)|$ 和 $\angle H(j\omega)$ 对 $\omega$ 画出来就是 Bode plot（第 6 站）。第三件事是 sampling：frequency domain 里的一次复制，复制出来的 replica 互不 overlap 时什么都没丢，overlap 了就出现上面的 6 kHz 变 4 kHz（第 7 站）。

Notation 跟卷子走：Fourier series 和 Fourier transform 用以 Hz 为单位的 $f$，$\mathrm{sinc}(x)=\dfrac{\sin\pi x}{\pi x}$；Laplace transform 和 Bode plot 用以 rad/s 为单位的 $\omega=2\pi f$。公开课（Oppenheim）通篇用 $\omega$，coefficient 记作 $a_k$，同一个 formula 会多出或少掉一个 $2\pi$。NUS 这边的学生 cheat-sheet 里，periodic signal 的 period 和 fundamental frequency 记作 $T_p$、$f_p$，$s$-domain 的 transfer function 记作 $\tilde H(s)$，和 $f$ 的 function $H(f)$ 区分开；这一页写成 $T_0$、$f_0$ 和 $H(s)$，看讲义时对应一下。

## [lti] LTI system 与 convolution

:::skip
能从 linearity 和 time invariance 两条性质推出 convolution integral，能对着图做一次 flip and slide，并能解释为什么 $\cos$ 进去、出来的还是同一个 frequency 的 $\cos$，就可以去第 2 站。

### 一个 system 要做多少次实验才算知道

一个 system 把 input signal $x(t)$ 变成 output signal $y(t)$。想预测它对任意 input 的 output，最笨的办法是每种 input 都试一次，而 input 有无穷多种。如果 system 满足下面两条，试一次就够。

**Linearity。** Input 是几个 signal 的 weighted sum，output 就是各自 output 的同一个 weighted sum：$a\,x_1+b\,x_2\ \to\ a\,y_1+b\,y_2$。

**Time invariance。** Input 晚 $t_0$ 到，output 就原样晚 $t_0$：$x(t-t_0)\ \to\ y(t-t_0)$。

两条都满足的叫 LTI system。拿三个 system 检验这两个定义：

| System | Linear | Time-invariant | 理由 |
|---|---|---|---|
| $y(t)=x(t)^2$ | 否 | 是 | Input 乘 2，output 乘了 4 |
| $y(t)=t\,x(t)$ | 是 | 否 | 见下 |
| $y'(t)+y(t)=x(t)$，input 到来之前 $y=0$ | 是 | 是 | Equation 对 $x$、$y$ 是 linear 的，coefficient 是 constant |

第二个 system：input 取 unit step $u(t)$（$t\ge0$ 时为 1，否则为 0），output 是 $t\,u(t)$。把 input 推迟 1 秒变成 $u(t-1)$，output 是 $t\,u(t-1)$，在 $t=3$ 时等于 3；而“原来的 output 推迟 1 秒”是 $(t-1)\,u(t-1)$，在 $t=3$ 时等于 2。System 的规则随时间变了，所以它不是 time-invariant 的，这一站的工具对它都不适用。

第三个就是开头的 RC circuit，这一站一直用它。

### 一次实验为什么够

要做的那一次实验是：送进去一个 width 为 $\Delta$、height 为 $1/\Delta$ 的窄 pulse（area 是 1），记下 output。$\Delta\to0$ 时这个 pulse 叫 unit impulse $\delta(t)$，对应的 output 叫 impulse response $h(t)$。RC circuit 的 $h(t)=e^{-t}u(t)$（第 4 站从 equation 求出，这里先当作测得的结果）。

现在来一个任意的 input $x(t)$。把时间轴切成 width 为 $\Delta$ 的小段，$x(t)$ 就近似成一排窄 pulse。位于 $\tau=k\Delta$ 的那一个，height 是 $x(k\Delta)$，也就是“area 为 1 的窄 pulse”乘上 $x(k\Delta)\,\Delta$ 再 shift 到 $k\Delta$。两条性质各用一次：

- Time invariance：area 为 1 的窄 pulse shift 到 $k\Delta$，output 是 $h(t-k\Delta)$。
- Linearity：乘上 $x(k\Delta)\,\Delta$ 再把所有小段加起来，output 是

$$y(t)\approx\sum_k x(k\Delta)\,h(t-k\Delta)\,\Delta$$

$\Delta\to0$ 时 $k\Delta$ 变成 continuous 的 $\tau$，$\Delta$ 变成 $d\tau$，sum 变成 integral：

$$y(t)=\int_{-\infty}^{\infty}x(\tau)\,h(t-\tau)\,d\tau\ \equiv\ (x*h)(t)$$

这个运算叫 convolution。它说的是：$\tau$ 时刻的 input 留下一条从 $\tau$ 开始的 $h$，大小是 $x(\tau)\,d\tau$；$t$ 时刻的 output 是所有这些 $h$ 在 $t$ 处的值之和。

用开头的例子核对这个 limit。Input 是 $0\le t<1$ 上 height 为 1 的 rect pulse，$h(t)=e^{-t}u(t)$，求 $y(2)$。位于 $k\Delta$ 的小段贡献 $\Delta\,e^{-(2-k\Delta)}$。取 $\Delta=0.25$，只有 $k=0,1,2,3$ 四段：

$$0.25\,(e^{-2}+e^{-1.75}+e^{-1.5}+e^{-1.25})=0.25\times(0.1353+0.1738+0.2231+0.2865)=0.2047$$

| $\Delta$ | 0.25 | 0.05 | 0.01 | $\to0$ |
|---|---|---|---|---|
| sum | 0.2047 | 0.2268 | 0.2314 | $\displaystyle\int_0^1e^{-(2-\tau)}\,d\tau=e^{-1}-e^{-2}=0.2325$ |

::fig[ee2023-strips] $\Delta=0.25$ 的那一列画出来。上面是切成四段的 input，下面每条灰线是一段留下的 $0.25\,h(t-k\Delta)$；$t=2$ 处的竖条把四个值叠在一起。

### Flip and slide：把 integral 算出来

Integral 里的 $h(t-\tau)$ 要当作 $\tau$ 的 function 来看。$\tau=t$ 时它是 $h(0)$；$\tau$ 从 $t$ 往左走，它依次取 $h$ 在正方向上的值。所以它是把 $h$ 左右 flip，再把原来的 origin 放到 $\tau=t$。算 $y(t)$ 分四步：flip，shift 到 $t$，和 $x(\tau)$ 相乘，求乘积下面的 area。$t$ 每变一次，flip 过的 $h$ 就滑到新的位置，重算一次。

把上面的例子对所有 $t$ 算完。$x(\tau)$ 只在 $0\le\tau<1$ 上不为零；$h(t-\tau)=e^{-(t-\tau)}$ 只在 $\tau\le t$ 时不为零。两者 overlap 的范围随 $t$ 分三种情形：

- $t<0$：没有 overlap，$y(t)=0$。
- $0\le t\le1$：overlap 是 $0\le\tau\le t$，

$$y(t)=\int_0^te^{-(t-\tau)}\,d\tau=e^{-t}\Big[e^{\tau}\Big]_0^t=e^{-t}(e^t-1)=1-e^{-t}$$

- $t>1$：overlap 是整个 pulse $0\le\tau\le1$，

$$y(t)=\int_0^1e^{-(t-\tau)}\,d\tau=e^{-t}(e-1)=e^{-(t-1)}-e^{-t}$$

所以 $y(0.5)=0.393$，在 $t=1$ 升到最高的 $1-e^{-1}=0.632$，之后 decay，$y(2)=0.233$，就是上面那张表的 limit。

::fig[ee2023-conv] 上面是 $x(\tau)$（黑线）和 flip 之后滑到 $t$ 的 $h(t-\tau)$（彩线），阴影的 area 就是 $y(t)$。看 $h(t-\tau)$ 从左往右滑：重叠从无到有，$t=1$ 时整个 pulse 都被盖住，之后 $h$ 在 pulse 上的部分越来越低。下面的点同步画出 $y(t)$；动图在 $t=0.5$ 和 $t=2$ 各停一下，对应正文的 0.393 和 0.233。

:::wrong Output 等于 input 乘以 impulse response
按 $y(t)=x(t)\,h(t)$ 算，$t=2$ 时 $x(2)=0$，output 应当是 0。实际 $y(2)=0.233$：input 已经结束了，$0$ 到 $1$ 之间送进去的东西留下的 $h$ 还没有 decay 完。Time domain 里 system 对 input 做的是 convolution，$t$ 时刻的 output 取决于 $t$ 之前所有时刻的 input。相乘的关系要到 frequency domain 才成立（第 3 站的 $Y(f)=H(f)X(f)$），整门课学 transform 就是为了把这个 integral 换成乘法。
:::

### 只看 $h(t)$ 就能回答的两个问题

**System 是不是 causal。** Causal 的意思是 output 不会早于 input。在 $y(t)=\int x(\tau)h(t-\tau)\,d\tau$ 里，$\tau>t$ 的那些 input 是“未来”的，它们的 weight 是 $h(t-\tau)$，argument 为负。所以 causal 当且仅当 $t<0$ 时 $h(t)=0$。$e^{-t}u(t)$ 满足。

**System 是不是 BIBO stable。** BIBO（bounded-input bounded-output）stable 的意思是 bounded 的 input 一定得到 bounded 的 output。设 $|x(t)|\le B$，对 convolution integral 取 absolute value：

$$|y(t)|\le\int|x(\tau)|\,|h(t-\tau)|\,d\tau\le B\int_{-\infty}^{\infty}|h(\tau)|\,d\tau$$

所以只要 $\int|h(t)|\,dt<\infty$，output 就 bounded。RC circuit：$\int_0^\infty e^{-t}\,dt=1$，于是 $|y|\le B$；上面 pulse 的例子里 $B=1$，output 最高 0.632，在界内。

这个条件不满足时确实会出事。Integrator 的 $h(t)=u(t)$，$\int|h|$ 是 infinity；给它 bounded 的 input $u(t)$，output 是 $\int_0^t1\,d\tau=t$，一直增长。卷子第 4 题的 system 在 origin 处有一个 pole，里面就藏着一个 integrator（第 5 站）。

### 有一类 input 不用算 integral

先把 convolution 换一个写法。令 $\sigma=t-\tau$，则 $\tau=t-\sigma$，$d\tau=-d\sigma$，上下限对调：

$$\int_{-\infty}^{\infty}x(\tau)\,h(t-\tau)\,d\tau=\int_{\infty}^{-\infty}x(t-\sigma)\,h(\sigma)\,(-d\sigma)=\int_{-\infty}^{\infty}h(\sigma)\,x(t-\sigma)\,d\sigma$$

现在让 input 是 $x(t)=e^{st}$，$s$ 是任意一个 complex number：

$$y(t)=\int_{-\infty}^{\infty}h(\sigma)\,e^{s(t-\sigma)}\,d\sigma=e^{st}\underbrace{\int_{-\infty}^{\infty}h(\sigma)\,e^{-s\sigma}\,d\sigma}_{H(s)}$$

$e^{st}$ 能提到 integral 外面，靠的是 $e^{s(t-\sigma)}=e^{st}\,e^{-s\sigma}$：exponential 被 shift 之后只是乘了一个 constant。剩下的 integral 里没有 $t$，是一个只取决于 $s$ 的 complex number。所以

$$e^{st}\ \longrightarrow\ H(s)\,e^{st}$$

Input 原样出来，只是乘了一个数。这和 linear algebra 里的 $Av=\lambda v$ 是同一种关系，所以 $e^{st}$ 叫 LTI system 的 eigenfunction，$H(s)$ 是对应的 eigenvalue。

对 RC circuit 算出这个 eigenvalue：

$$H(s)=\int_0^\infty e^{-\sigma}e^{-s\sigma}\,d\sigma=\int_0^\infty e^{-(s+1)\sigma}\,d\sigma=\frac{1}{s+1}\qquad(\mathrm{Re}\,s>-1)$$

再回到开头的 $\cos t$。它不是 exponential，但由 Euler's formula 它是两个 exponential 之和，$\cos\omega t=\tfrac12e^{j\omega t}+\tfrac12e^{-j\omega t}$。由 linearity，

$$y(t)=\tfrac12H(j\omega)\,e^{j\omega t}+\tfrac12H(-j\omega)\,e^{-j\omega t}$$

$h(t)$ 是 real 的时候，把 $H$ 的定义取 conjugate 得 $H(-j\omega)=H(j\omega)^*$，所以第二项是第一项的 conjugate，两项之和是第一项 real part 的两倍。写 $H(j\omega)=|H(j\omega)|\,e^{j\angle H(j\omega)}$：

$$y(t)=\mathrm{Re}\big\{H(j\omega)\,e^{j\omega t}\big\}=|H(j\omega)|\cos\big(\omega t+\angle H(j\omega)\big)$$

Sinusoid 进去，出来的是同一个 frequency 的 sinusoid，amplitude 乘 $|H(j\omega)|$，phase 加 $\angle H(j\omega)$。对 $\cos t$：

$$H(j)=\frac{1}{1+j}=\frac{1-j}{2}=0.707\,e^{-j45^\circ}\qquad\Longrightarrow\qquad y(t)=0.707\cos(t-45^\circ)$$

:::wrong $\cos$ 进去 $\cos$ 出来，所以 $\cos t$ 也是 eigenfunction
Eigenfunction 要求 output 等于 input 乘一个 constant。拿 $0.707\cos(t-45^\circ)$ 去除以 $\cos t$：$t=0$ 时是 $0.5/1=0.5$，$t=45^\circ$ 时是 $0.707/0.707=1$，比值随 $t$ 变。原因是 $\cos t$ 里的两个 eigenfunction $e^{jt}$ 和 $e^{-jt}$ 各有各的 eigenvalue，$H(j)\ne H(-j)$，加起来就不再是原来的 function 乘一个数。全课用 complex exponential 而不用 $\cos$、$\sin$ 去拆 signal，理由在这里：用 $\cos$ 要同时跟踪 amplitude 和 phase 两个量怎么变，用 $e^{j\omega t}$ 只需要乘一个 complex number。
:::

:::edge Zero input 必须得到 zero output
在 linearity 的定义里取 $a=b=0$，可见 linear system 对 zero input 的 output 一定是 zero。RC circuit 如果在 $t=0$ 时 capacitor 上已有电压，$y(0)=1$，那么不给任何 input，output 也是 $e^{-t}$。带着 nonzero initial condition 时它就不是一个 linear 的 input–output 关系，$h(t)$ 和 convolution 都默认 input 到来之前 output 为零。带 initial condition 的问题留给第 4 站的 Laplace transform。
:::

:::back
Probability 里两个 independent random variable 之和的 density 也是 convolution，是同一个运算，见 [ST2131 第 6 站](ST2131.html#transform)。Eigenfunction 这个词借自 linear algebra，matrix 的版本见 [DSA2102 第 5 站](DSA2102.html#eig)。
:::

## [fs] Fourier series 与 power

:::skip
看到 $\cos(4\pi t+\pi/3)$ 能立刻说出它在哪两个 frequency 上、coefficient 各是多少、power 是多少，就可以去第 3 站。
:::

### 为什么拿 complex exponential 去拆 signal

上一站最后的结论是 $e^{st}\to H(s)e^{st}$。配上 linearity：如果 input 能写成 $x(t)=\sum_kc_k\,e^{s_kt}$，output 立刻就是 $y(t)=\sum_kc_k\,H(s_k)\,e^{s_kt}$，不用算 convolution。于是问题变成：哪些 signal 能这样写，coefficient 怎么求。

先看 periodic signal，period 记作 $T_0$。$e^{j2\pi ft}$ 是 unit circle 上每秒转 $f$ 圈的一个点。它要有 period $T_0$，需要 $e^{j2\pi f(t+T_0)}=e^{j2\pi ft}$，即 $e^{j2\pi fT_0}=1$，即 $fT_0$ 是 integer。所以能用的只有

$$f=\frac{k}{T_0}=kf_0,\qquad k=0,\pm1,\pm2,\dots$$

$f_0=1/T_0$ 叫 fundamental frequency，$kf_0$ 处的那一项叫第 $k$ 个 harmonic。Fourier series 说的是：period 为 $T_0$ 的 signal 可以写成

$$x(t)=\sum_{k=-\infty}^{\infty}c_k\,e^{j2\pi kf_0t}$$

$k$ 为负的项是反方向转的。Real 的 $\cos$ 需要一正一负两项配成一对：$\cos\theta=\tfrac12e^{j\theta}+\tfrac12e^{-j\theta}$。

### Coefficient 怎么求

需要一个事实：$e^{j2\pi mf_0t}$ 在一个 period 上的 average，$m=0$ 时是 1，$m\ne0$ 时是 0。$m=0$ 时它恒等于 1；$m\ne0$ 时

$$\frac{1}{T_0}\int_0^{T_0}e^{j2\pi mf_0t}\,dt=\frac{1}{T_0}\left[\frac{e^{j2\pi mf_0t}}{j2\pi mf_0}\right]_0^{T_0}=\frac{e^{j2\pi m}-1}{j2\pi m}=0$$

用到了 $f_0T_0=1$。几何上，这个点在一个 period 里正好转了 $m$ 整圈，各个方向互相抵消。

要取出 $c_n$，把 $x(t)$ 乘上 $e^{-j2\pi nf_0t}$。第 $k$ 项变成 $c_k\,e^{j2\pi(k-n)f_0t}$：原来转 $k$ 圈的现在转 $k-n$ 圈，只有 $k=n$ 那一项停住不转。再对一个 period 取 average，转着的项全部是 0，剩下的就是 $c_n$：

$$c_n=\frac{1}{T_0}\int_{T_0}x(t)\,e^{-j2\pi nf_0t}\,dt$$

$\int_{T_0}$ 表示在任意一个完整的 period 上 integrate。$n=0$ 时它就是 $x(t)$ 的 average，叫 DC component。这个操作和求一个 vector 在 orthonormal basis 的某个方向上的 component 是同一件事：$c_n$ 是 $x$ 与第 $n$ 个 harmonic 的 inner product，上面那个“average 是 1 或 0”就是 harmonic 之间的 orthogonality。

### 从头算一个：square wave

取 $T_0=1$ s（$f_0=1$ Hz）的 square wave：一个 period 内 $|t|<\tfrac14$ 时 $x(t)=1$，其余为 0。

$c_0$ 是 average，等于 $\tfrac12$。$k\ne0$ 时，在 $-\tfrac12$ 到 $\tfrac12$ 这个 period 上 integrate，$x$ 只在 $|t|<\tfrac14$ 上不为零：

$$c_k=\int_{-1/4}^{1/4}e^{-j2\pi kt}\,dt=\left[\frac{e^{-j2\pi kt}}{-j2\pi k}\right]_{-1/4}^{1/4}=\frac{e^{j\pi k/2}-e^{-j\pi k/2}}{j2\pi k}=\frac{\sin(\pi k/2)}{\pi k}$$

| $k$ | 0 | $\pm1$ | $\pm2$ | $\pm3$ | $\pm4$ | $\pm5$ |
|---|---|---|---|---|---|---|
| $c_k$ | $\tfrac12$ | $\tfrac1\pi=0.318$ | 0 | $-\tfrac1{3\pi}=-0.106$ | 0 | $\tfrac1{5\pi}=0.064$ |

$c_{-k}=c_k$，所以 $\pm k$ 两项合成 $c_k\,(e^{j2\pi kt}+e^{-j2\pi kt})=2c_k\cos2\pi kt$：

$$x(t)=\frac12+\frac2\pi\Big(\cos2\pi t-\frac13\cos6\pi t+\frac15\cos10\pi t-\cdots\Big)$$

在 $t=0$ 核对：$\tfrac12+\tfrac2\pi\big(1-\tfrac13+\tfrac15-\cdots\big)=\tfrac12+\tfrac2\pi\cdot\tfrac\pi4=1$，是 square wave 在那里的值。

这张表里有两件对所有 signal 都成立的事。第一，$x(t)$ 是 real 的时候 $c_{-k}=c_k^*$（把 $c_k$ 的 formula 取 conjugate 就得到 $c_{-k}$ 的 formula），所以 $|c_k|$ 关于 $k=0$ symmetric；这里 $x$ 还是 even function，coefficient 干脆都是 real 的。第二，coefficient 按 $1/k$ 变小，很慢。Signal 里有 jump 时总是这样：要拼出一条竖直的边，需要很多 high-frequency 的项。

::fig[ee2023-partial] 只保留 $|k|\le N$ 的项，$N$ 从 1 一路加到 49。$N=1$ 时只有 average 和一个 $\cos$，已经有了大致的形状；看项数增加时平的部分越来越平、边越来越陡，而 jump 旁的最高点（黑点）停在约 1.09 不再下降。

:::edge Jump 处的 overshoot 不会消失
在 jump 的位置 $t=\tfrac14$，每一项 $\cos(2\pi k\cdot\tfrac14)=\cos\tfrac{k\pi}{2}$ 在 $k$ 为 odd 时都是 0，所以不论 $N$ 取多少，partial sum 在那里恒等于 $\tfrac12$，是 jump 两侧的中点。Jump 旁边则有一个冲过头的 peak：$N=9$ 时是 1.091，$N=49$ 时是 1.090，$N=199$ 时是 1.089，始终比 1 高出 jump 高度的 9% 左右。变的只是位置，它离 jump 的距离分别是 0.05、0.01、0.0025，越来越近。这叫 Gibbs phenomenon。Partial sum 与 $x(t)$ 之差的 power 确实趋于零（下面用 Parseval's relation 算），但 jump 附近逐点的 maximum error 不趋于零。
:::

### Signal 本来就是几个 sinusoid 之和时，直接读

:::wrong 求 coefficient 就得做那个 integral
对 square wave 这样的 signal 确实要 integrate。但如果 signal 本来就写成几个 sinusoid 和 complex exponential 之和，coefficient 已经在式子里了，用 Euler's formula 拆开就能读出来，integrate 是白费功夫。

相伴的另一个错是以为 $\cos$ 的 coefficient 是 1。$\cos\theta=\tfrac12e^{j\theta}+\tfrac12e^{-j\theta}$，它在正负两个 frequency 上各占 $\tfrac12$。
:::

例如 $x(t)=1+4\cos(6\pi t-\tfrac\pi4)+2\sin(10\pi t)$。三项的 frequency 是 0、3 Hz、5 Hz。$f_0$ 必须让每个出现的 frequency 都是它的 integer 倍，所以 $f_0=1$ Hz，3 Hz 和 5 Hz 分别是 $k=\pm3$ 和 $k=\pm5$。逐项拆：

$$4\cos(6\pi t-\tfrac\pi4)=2e^{-j\pi/4}\,e^{j6\pi t}+2e^{j\pi/4}\,e^{-j6\pi t},\qquad2\sin(10\pi t)=\frac{2}{2j}\big(e^{j10\pi t}-e^{-j10\pi t}\big)=-j\,e^{j10\pi t}+j\,e^{-j10\pi t}$$

| $k$ | 0 | 3 | $-3$ | 5 | $-5$ |
|---|---|---|---|---|---|
| $c_k$ | 1 | $2e^{-j\pi/4}$ | $2e^{j\pi/4}$ | $-j=e^{-j\pi/2}$ | $j=e^{j\pi/2}$ |

$|c_k|$ 是那个 harmonic 的大小，$\angle c_k$ 是它的 phase。

:::edge Fundamental frequency 不一定是出现的最低 frequency
上面的 signal 里最低的 nonzero frequency 是 3 Hz，但 5 不是 3 的 integer 倍，$f_0$ 不能取 3 Hz。直接看 period 也一样：3 Hz 那一项每 $\tfrac13$ 秒重复一次，可是过了 $\tfrac13$ 秒，5 Hz 那一项才走了 $\tfrac53$ 圈，没有回到原处；两项同时回到原处要等 1 秒。$f_0$ 是各个 frequency 的 greatest common divisor。
:::

### Power 在两边都能算

Periodic signal 的 average power 定义为 $P=\dfrac{1}{T_0}\displaystyle\int_{T_0}|x(t)|^2\,dt$。把 $|x|^2=x\,x^*$ 里的两个 $x$ 都换成 series：

$$P=\frac{1}{T_0}\int_{T_0}\Big(\sum_kc_k\,e^{j2\pi kf_0t}\Big)\Big(\sum_nc_n^*\,e^{-j2\pi nf_0t}\Big)dt=\sum_k\sum_nc_k\,c_n^*\;\underbrace{\frac{1}{T_0}\int_{T_0}e^{j2\pi(k-n)f_0t}\,dt}_{k=n\text{ 时为 }1\text{，否则为 }0}=\sum_k|c_k|^2$$

这叫 Parseval's relation：total power 等于各个 harmonic 的 power 之和，不同的 harmonic 之间没有 cross term。在每个 $kf_0$ 处立一根 height 为 $|c_k|^2$ 的 line，就是 power spectrum。

拿两个例子核对。

Square wave：time domain 里 $x^2$ 有一半时间是 1，$P=\tfrac12$。Frequency domain 里

$$\frac14+2\sum_{k\text{ odd}}\frac{1}{\pi^2k^2}=\frac14+\frac{2}{\pi^2}\Big(1+\frac19+\frac1{25}+\cdots\Big)=\frac14+\frac{2}{\pi^2}\cdot\frac{\pi^2}{8}=\frac12$$

逐项加能看出 power 集中在哪里：只算 DC 和 $k=\pm1$ 是 $0.25+2\times0.1013=0.4526$，已经是全部的 90.5%；加到 $k=\pm3$ 是 95.0%，加到 $k=\pm9$ 是 98.0%。所以上图里 $N=9$ 的 partial sum，error 的 power 只剩 2.0%，尽管 jump 旁边那个 peak 还在。

上一小节的 signal：frequency domain 里 $1+4+4+1+1=11$。Time domain 里 amplitude 为 $A$ 的 sinusoid 的 power 是 $A^2/2$，$1^2+\tfrac{4^2}{2}+\tfrac{2^2}{2}=11$。

:::exam 第 2 题
Signal 是三项之和：constant $4e^{j\pi/4}$，$\cos(4\pi t+\pi/3)$，以及 $(3+j3)\,e^{-j\pi/3}\,e^{j20\pi t}$。

三项的 frequency 是 0、2 Hz、10 Hz，都是 2 的 integer 倍，$f_0=2$ Hz，对应 $k=0$、$\pm1$、$5$。逐项读 coefficient：

- $\cos(4\pi t+\pi/3)=\tfrac12e^{j\pi/3}\,e^{j4\pi t}+\tfrac12e^{-j\pi/3}\,e^{-j4\pi t}$。
- $3+j3=3\sqrt2\,e^{j\pi/4}$，再乘 $e^{-j\pi/3}$，phase 是 $\tfrac\pi4-\tfrac\pi3=-\tfrac\pi{12}$。

| Frequency | $k$ | $c_k$ | $\lvert c_k\rvert^2$ |
|---|---|---|---|
| 0 | 0 | $4e^{j\pi/4}$ | 16 |
| $+2$ Hz | 1 | $\tfrac12e^{j\pi/3}$ | 0.25 |
| $-2$ Hz | $-1$ | $\tfrac12e^{-j\pi/3}$ | 0.25 |
| $+10$ Hz | 5 | $(3+j3)e^{-j\pi/3}=3\sqrt2\,e^{-j\pi/12}$ | 18 |

Power spectrum 是四根 line，total power $16+0.25+0.25+18=34.5$。Time domain 里核对：constant 的 power 是 $4^2=16$，amplitude 为 1 的 $\cos$ 是 $\tfrac12$，magnitude 为 $3\sqrt2$ 的 complex exponential 是 $18$，合计 34.5。
:::

::fig[ee2023-q2power] 第 2 题的 power spectrum。

:::edge Complex-valued signal 的 spectrum 不 symmetric
Real signal 一定有 $c_{-k}=c_k^*$，power spectrum 左右 symmetric。上面这道题的 signal 是 complex 的：$+10$ Hz 处有一根 line，$-10$ Hz 处什么都没有。画图时如果习惯性地补上 symmetric 的那一根，power 就多算了 18。
:::

### Periodic signal 通过 LTI system

现在可以兑现这一站开头的打算。Input 是 $\sum_kc_k\,e^{j2\pi kf_0t}$，每一项都是 eigenfunction，$s=j2\pi kf_0$，所以

$$y(t)=\sum_kc_k\,H(j2\pi kf_0)\,e^{j2\pi kf_0t}$$

Output 的 coefficient 是 $c_k\,H(j2\pi kf_0)$。LTI system 不产生新的 frequency，只改每个 harmonic 的大小和 phase。

把 1 Hz 的 square wave 送进 RC circuit，$H(s)=\dfrac{1}{s+1}$：

| $k$ | $c_k$ | $H(j2\pi k)=\dfrac{1}{1+j2\pi k}$ | Output 里这个 harmonic 的 amplitude $2\lvert c_k\rvert\lvert H\rvert$ |
|---|---|---|---|
| 0 | 0.5 | 1 | 0.5（DC，不乘 2） |
| $\pm1$ | 0.318 | $0.157\,\angle{-81.0^\circ}$ | 0.100 |
| $\pm3$ | $-0.106$ | $0.053\,\angle{-87.0^\circ}$ | 0.011 |

DC 原样通过，1 Hz 的 harmonic 只剩 16%，3 Hz 的只剩 5%。Output 几乎就是 average 0.5 上叠了一个 amplitude 约 0.1 的 ripple；在 time domain 里直接算（pulse 期间朝 1 升、间歇期间 decay），它在 0.378 和 0.622 之间摆动，对得上。这个 circuit 对 input 做的事可以一句话说完：留下慢的，压掉快的。它是一个 lowpass filter。

::fig[ee2023-sqrc] 同一件事在 time domain 里的样子。

:::back
用到[第 1 站](#lti)的 eigenfunction 性质。这里的 inner product、orthogonality 和 [DSA2102 第 4 站](DSA2102.html#ls)的 projection 是同一套想法，只是 vector 换成了 function。
:::

“好的 building block 要满足两条：system 对它的 response 容易算，而且它能拼出足够多的 signal”、只取 harmonic、乘上 $e^{-j2\pi nf_0t}$ 再在一个 period 上 integrate 的推导、拿 square wave 做例子、“error 的 energy 趋于零但 jump 旁的 ripple 不消失”，来自 [RES.6-007 第 7 讲](https://ocw.mit.edu/courses/res-6-007-signals-and-systems-spring-2011/resources/lecture-7-continuous-time-fourier-series/)；逐字稿里没有板书，square wave 的 coefficient、partial sum 的 peak 值和 power 的百分比是自己算的。“乘上反向旋转的 exponential，让第 $n$ 项停住，其余各项转整圈、average 为零”的图像，以及用 $1-\tfrac13+\tfrac15-\cdots=\tfrac\pi4$ 核对，来自 [3Blue1Brown 的 Fourier series 一课](https://www.3blue1brown.com/lessons/fourier-series)。“coefficient 是 inner product”和“LTI system 不产生新的 frequency”，以及让 square wave 通过 RC lowpass filter 的想法，来自 [6.003 第 15 讲](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/resources/mit6_003f11_lec15/)的 slides，数字是这里另算的。

## [ft] Fourier transform 及其 properties

:::skip
能不查表写出 $4\cos(2000\pi t)\,\mathrm{rect}(2t)$ 的 spectrum，并说出为什么 pulse 越短 spectrum 越宽，就可以去第 4 站。
:::

### Aperiodic signal：让 period 趋于无穷

只出现一次的 pulse 不是 periodic 的，上一站的 series 用不上。办法是先让它每隔 $T_0$ 重复一次，做 Fourier series，再让 $T_0\to\infty$，把相邻的 pulse 推到无穷远。

取 width 为 $\tfrac12$ 的 pulse：$|t|<\tfrac14$ 时为 1，其余为 0。让它以 period $T_0$ 重复（$T_0=1$ 就是上一站的 square wave）。和上一站同样的计算，只是 $f_0=1/T_0$ 不再等于 1：

$$c_k=\frac{1}{T_0}\int_{-1/4}^{1/4}e^{-j2\pi kf_0t}\,dt=\frac{1}{T_0}\cdot\frac{\sin(\pi kf_0/2)}{\pi kf_0}=\frac{1}{T_0}\cdot\frac12\,\mathrm{sinc}\Big(\frac{kf_0}{2}\Big)$$

$T_0$ 越大，每个 $c_k$ 越小，因为同一个 pulse 被摊到了越来越长的 period 上。直接取 limit 得到的全是 0。但 $T_0\,c_k$ 不随 $T_0$ 变小：它等于 function $\tfrac12\mathrm{sinc}(f/2)$ 在 $f=kf_0$ 处的值。$T_0$ 变大改变的只是这些点的间隔 $f_0=1/T_0$。

::fig[ee2023-ftlimit] 同一个 pulse，period 取 1、2、4 秒。$T_0\,c_k$ 始终落在同一条 curve 上，period 每加倍一次，点密一倍。

所以定义不除以 $T_0$ 的那个量：

$$X(f)=\int_{-\infty}^{\infty}x(t)\,e^{-j2\pi ft}\,dt$$

叫 $x(t)$ 的 Fourier transform，也叫 spectrum。有了它，$c_k=\dfrac{1}{T_0}X(kf_0)=X(kf_0)\,f_0$，series 写成

$$\sum_kc_k\,e^{j2\pi kf_0t}=\sum_kX(kf_0)\,e^{j2\pi kf_0t}\,f_0$$

这是一个 step 为 $f_0$ 的 Riemann sum。$T_0\to\infty$ 时 $f_0\to df$，$kf_0\to f$：

$$x(t)=\int_{-\infty}^{\infty}X(f)\,e^{j2\pi ft}\,df$$

两个式子一个把 signal 拆开，一个把它拼回去。拼回去的式子说明 $X(f)$ 是什么：$x(t)$ 是所有 frequency 的 $e^{j2\pi ft}$ 之和，$f$ 附近 $df$ 宽的一小段贡献 $X(f)\,df$。$X(f)$ 是每 Hz 的 density，不再是某个 harmonic 的 amplitude。

定义之后立刻能读出一件事：$X(0)=\int x(t)\,dt$，是 signal 下面的 area。上面的 pulse 的 area 是 $\tfrac12$，$\tfrac12\mathrm{sinc}(0)=\tfrac12$。

不除以长度还有一个后果。算一段持续 $D$ 秒、amplitude 为 4 的 1000 Hz 的 $\cos$ 在 $f=1000$ 处的 transform（$D$ 含 integer 个 period）：

$$\int_{-D/2}^{D/2}4\cos(2\pi\,1000\,t)\,e^{-j2\pi\,1000\,t}\,dt=\int_{-D/2}^{D/2}\big(2+2e^{-j4\pi\,1000\,t}\big)\,dt=2D$$

第二项转了整圈，integrate 为 0。持续得越久，这个值越大，和 $D$ 成正比；而在别的 frequency 上，乘积一直在转，integral 不会跟着长。$D\to\infty$ 时 $f=\pm1000$ 处的值趋于 infinity，其余地方有限，所以永远持续的 $\cos(2\pi f_0t)$ 的 spectrum 只能用 impulse 写：$\tfrac12\delta(f-f_0)+\tfrac12\delta(f+f_0)$，两个 impulse 的 area 正是上一站的两个 coefficient $\tfrac12$。$D=\tfrac12$ 时这个值是 1，下面卷子第 1 题会再遇到。

### 最基本的一对：rect 与 sinc

$\mathrm{rect}(t)$ 在 $|t|<\tfrac12$ 时为 1，其余为 0。Width 为 $T$ 的 pulse 是 $\mathrm{rect}(t/T)$：

$$\int_{-T/2}^{T/2}e^{-j2\pi ft}\,dt=\frac{e^{j\pi fT}-e^{-j\pi fT}}{j2\pi f}=\frac{\sin(\pi fT)}{\pi f}=T\,\mathrm{sinc}(fT)$$

$$\mathrm{rect}(t/T)\ \longleftrightarrow\ T\,\mathrm{sinc}(fT)$$

$\mathrm{sinc}$ 在 nonzero integer 上为 0，所以这个 spectrum 的 zero 在 $f=\pm\tfrac1T,\pm\tfrac2T,\dots$。$T=\tfrac12$ 就是上面的 pulse，写成 $\mathrm{rect}(2t)$。

::fig[ee2023-rectsinc] Width 为 ½ 秒的 pulse，spectrum 的 main lobe 在 ±2 Hz 处第一次到零。把 pulse 再缩短一半，这些 zero 会移到 ±4 Hz。

### Property：每一条都是一行 substitution

卷子附了 transform 表，要练的是把复杂的 signal 用 property 拆成表里有的东西。每条 property 都只是在定义的 integral 里换一次 variable。

**Time shift。** 求 $x(t-t_0)$ 的 transform，令 $u=t-t_0$：

$$\int x(t-t_0)\,e^{-j2\pi ft}\,dt=\int x(u)\,e^{-j2\pi f(u+t_0)}\,du=e^{-j2\pi ft_0}\,X(f)$$

只多一个 magnitude 为 1 的 factor：$|X(f)|$ 不变，phase 加上 $-2\pi ft_0$。第 1 站的 input（$0$ 到 $1$ 上的 pulse）是 $\mathrm{rect}(t-\tfrac12)$，spectrum 是 $\mathrm{sinc}(f)\,e^{-j\pi f}$。

**Scaling。** 求 $x(\beta t)$ 的 transform（$\beta>0$），令 $u=\beta t$，$dt=du/\beta$：

$$\int x(\beta t)\,e^{-j2\pi ft}\,dt=\frac1\beta\int x(u)\,e^{-j2\pi(f/\beta)u}\,du=\frac1\beta\,X\Big(\frac f\beta\Big)$$

$\beta<0$ 时上下限对调多出一个负号，合起来是 $\dfrac{1}{|\beta|}X(f/\beta)$。用它从 $\mathrm{rect}(t)\leftrightarrow\mathrm{sinc}(f)$ 得到 $\mathrm{rect}(2t)\leftrightarrow\tfrac12\mathrm{sinc}(f/2)$，和直接 integrate 的结果一致。

:::wrong Signal 在 time 上压缩，spectrum 也跟着压缩
$\mathrm{rect}(t)$ 的第一个 zero 在 1 Hz；压缩成 $\mathrm{rect}(2t)$，第一个 zero 到了 2 Hz，spectrum 宽了一倍、矮了一半。Scaling property 里 $t$ 乘 $\beta$、$f$ 除以 $\beta$，两边是反着来的。把一段录音用两倍速度放，每个音都高一个 octave，是同一条 property。一个 signal 在 time 上越集中，在 frequency 上就越分散，不可能两边都很窄。
:::

**Frequency shift（modulation）。** 求 $x(t)\,e^{j2\pi f_0t}$ 的 transform：

$$\int x(t)\,e^{j2\pi f_0t}\,e^{-j2\pi ft}\,dt=\int x(t)\,e^{-j2\pi(f-f_0)t}\,dt=X(f-f_0)$$

乘一个 exponential，spectrum 整个搬到 $f_0$。$\cos$ 是两个 exponential，所以

$$x(t)\cos(2\pi f_0t)\ \longleftrightarrow\ \tfrac12X(f-f_0)+\tfrac12X(f+f_0)$$

Spectrum 被搬到 $\pm f_0$ 两处，height 各减半。

**Convolution 变成乘法。** 把 $x(t)=\int X(f)\,e^{j2\pi ft}\,df$ 送进 LTI system。每个 $e^{j2\pi ft}$ 都是 eigenfunction，被乘上 $H(j2\pi f)$，简记为 $H(f)$。由 linearity，

$$y(t)=\int X(f)\,H(f)\,e^{j2\pi ft}\,df$$

对照拼回去的那个式子，$y$ 的 spectrum 就是 $Y(f)=X(f)\,H(f)$。而 $H(f)=\int h(t)\,e^{-j2\pi ft}\,dt$ 正是 $h(t)$ 的 Fourier transform，叫 frequency response。所以

$$y=x*h\ \longleftrightarrow\ Y(f)=X(f)\,H(f)$$

拿第 1 站的例子核对。$X(f)=\mathrm{sinc}(f)\,e^{-j\pi f}$，$H(f)=\dfrac{1}{1+j2\pi f}$（第 1 站的 $\tfrac{1}{s+1}$ 代入 $s=j2\pi f$），所以 $Y(f)=\dfrac{\mathrm{sinc}(f)\,e^{-j\pi f}}{1+j2\pi f}$。$Y(0)=1$ 应当等于 $y(t)$ 下面的 area：

$$\int_0^1(1-e^{-t})\,dt+\int_1^\infty(e-1)\,e^{-t}\,dt=e^{-1}+(e-1)\,e^{-1}=1$$

**Time domain 里相乘。** 反过来，$x_1(t)\,x_2(t)$ 的 spectrum 是 $X_1*X_2$（对 $f$ 做 convolution）。理由和 modulation 一样：把 $x_2$ 写成各个 frequency 的 exponential 之和，每个 exponential 把 $X_1$ 搬到自己的 frequency 上，再按 $X_2$ 的 weight 加起来。Modulation 是 $X_2$ 只有两个 impulse 的特例。

**Duality。** 拆开和拼回去的两个式子只差 exponent 的正负号。把 $x(t)=\int X(f)e^{j2\pi ft}df$ 里的 $t$ 和 $f$ 两个名字对调，再把 $f$ 换成 $-f$，得 $x(-f)=\int X(t)\,e^{-j2\pi ft}\,dt$，右边是 $X(t)$ 的 transform。所以每一对 transform 都可以倒过来用：$\mathrm{rect}(t)\leftrightarrow\mathrm{sinc}(f)$ 给出 $\mathrm{sinc}(t)\leftrightarrow\mathrm{rect}(-f)=\mathrm{rect}(f)$，再用 scaling，

$$B\,\mathrm{sinc}(Bt)\ \longleftrightarrow\ \mathrm{rect}(f/B)$$

Frequency response 是 rect 的 system，对 $|f|<B/2$ 原样通过、其余全部挡掉，是 ideal lowpass filter；它的 impulse response 是 sinc。第 7 站用它做 reconstruction。

Ideal bandpass filter 只让 $f_0$ 附近宽 $B$ 的一段通过，frequency response 是 $\mathrm{rect}\big(\frac{f-f_0}{B}\big)+\mathrm{rect}\big(\frac{f+f_0}{B}\big)$。它正好是 $\mathrm{rect}(f/B)$ 被搬到 $\pm f_0$，所以不用再 integrate，倒着用 modulation property：$B\,\mathrm{sinc}(Bt)\cos(2\pi f_0t)\leftrightarrow\tfrac12\big[\mathrm{rect}\big(\frac{f-f_0}{B}\big)+\mathrm{rect}\big(\frac{f+f_0}{B}\big)\big]$，乘 2 得

$$h_{\mathrm{BP}}(t)=2B\,\mathrm{sinc}(Bt)\cos(2\pi f_0t)$$

:::edge Ideal filter 做不出来
用第 1 站的 causality 条件检验 ideal lowpass filter 的 $h(t)=B\,\mathrm{sinc}(Bt)$：在 $t=-\frac{1}{2B}$ 处它等于 $B\,\mathrm{sinc}(-\tfrac12)=B\cdot\frac{\sin(-\pi/2)}{-\pi/2}=0.637B\ne0$。$t<0$ 时 $h$ 不为零，所以它不是 causal 的：$t$ 时刻的 output 要用到 $t$ 之后的 input。Bandpass 的 $h_{\mathrm{BP}}$ 里也有同一个 sinc，同样不 causal。实际的 filter（Butterworth、Chebyshev 等）只能逼近 rect 的形状，passband 的边缘是斜的。所以第 7 站说的 reconstruction 是理论上的极限，实际做 sampling 时 replica 之间要留出空隙，让不陡的 filter 也能把它们分开。
:::

**Energy。** $E=\int|x(t)|^2dt$。把其中一个 $x^*(t)$ 换成 $\int X^*(f)e^{-j2\pi ft}df$，交换 integral 的次序：

$$E=\int x(t)\int X^*(f)\,e^{-j2\pi ft}\,df\,dt=\int X^*(f)\int x(t)\,e^{-j2\pi ft}\,dt\,df=\int|X(f)|^2\,df$$

$|X(f)|^2$ 是 energy 在 frequency 上的 density。对 $\mathrm{rect}(2t)$：time domain 里 $E=\tfrac12$；frequency domain 里 $\int\tfrac14\mathrm{sinc}^2(f/2)\,df=\tfrac14\times2=\tfrac12$。只在 main lobe $|f|<2$ 上 integrate，得到全部 energy 的 90.3%。这是用 main lobe 的 width 来定义 bandwidth 的理由：从 0 到第一个 zero 的距离叫 first-null bandwidth，width 为 $T$ 的 pulse 是 $1/T$。

| Property | Time domain | Frequency domain |
|---|---|---|
| Time shift | $x(t-t_0)$ | $X(f)\,e^{-j2\pi ft_0}$ |
| Scaling | $x(\beta t)$ | $\dfrac{1}{\lvert\beta\rvert}X(f/\beta)$ |
| Modulation | $x(t)\cos(2\pi f_0t)$ | $\tfrac12[X(f-f_0)+X(f+f_0)]$ |
| Convolution | $x_1*x_2$ | $X_1X_2$ |
| Multiplication | $x_1x_2$ | $X_1*X_2$ |
| Duality | $X(t)$ | $x(-f)$ |
| Energy | $\int\lvert x(t)\rvert^2dt$ | $\int\lvert X(f)\rvert^2df$ |

### Periodic signal 的 transform：replication

这一站开头用 $T_0\to\infty$ 的 limit 得到 $c_k=f_0X(kf_0)$。Period 有限时这个关系也是精确成立的，用 impulse 的两条性质加上 convolution property 就能看出来。学生点评里说 replication、convolution 和 sampling 这几条 property 几乎每次都考，下面这条推导三者都用到。

Impulse 只在 $t=\lambda$ 处有 area 1，所以 $x(t)\,\delta(t-\lambda)=x(\lambda)\,\delta(t-\lambda)$（sampling property），对它 integrate 得 $\int x(t)\,\delta(t-\lambda)\,dt=x(\lambda)$（sifting property）。拿 $x$ 和 shift 过的 impulse 做 convolution，用 $\delta$ 是 even function 把它改写成 sifting 的形状：

$$x(t)*\delta(t-\xi)=\int x(\tau)\,\delta(t-\xi-\tau)\,d\tau=\int x(\tau)\,\delta\big(\tau-(t-\xi)\big)\,d\tau=x(t-\xi)$$

和 shift 过的 impulse 做 convolution，就是把 $x$ 搬过去复制一份，这叫 replication。一个 period 里的形状记作 $g(t)$（generating function），periodic signal 就是它的无数份 copy：

$$x_p(t)=\sum_ng(t-nT_0)=g(t)*\sum_n\delta(t-nT_0)$$

右边那串 impulse 本身是 period 为 $T_0$ 的 signal，一个 period 里只有 $t=0$ 处一个 impulse，它的 Fourier series coefficient 全都一样：

$$c_k=\frac{1}{T_0}\int_{-T_0/2}^{T_0/2}\delta(t)\,e^{-j2\pi kf_0t}\,dt=\frac{1}{T_0}e^{0}=f_0$$

$\delta(t)$ 的 transform 是 $\int\delta(t)\,e^{-j2\pi ft}\,dt=1$；由 duality，$1\leftrightarrow\delta(f)$；再用 frequency shift，$e^{j2\pi kf_0t}\leftrightarrow\delta(f-kf_0)$。所以 impulse train 的 transform 是 frequency 上的 impulse train：

$$\sum_n\delta(t-nT_0)=f_0\sum_ke^{j2\pi kf_0t}\ \longleftrightarrow\ f_0\sum_k\delta(f-kf_0)$$

Time domain 的 convolution 变成 frequency domain 的乘法，再用 sampling property 把 $G(f)$ 换成它在每个 impulse 处的值：

$$X_p(f)=G(f)\cdot f_0\sum_k\delta(f-kf_0)=\sum_kf_0\,G(kf_0)\,\delta(f-kf_0)$$

$k$ 处那个 impulse 的 area 就是第 $k$ 个 coefficient，所以 $c_k=f_0\,G(kf_0)$。拿第 2 站的 square wave 核对：$g(t)=\mathrm{rect}(2t)$，$G(f)=\tfrac12\mathrm{sinc}(f/2)$，$f_0=1$。$c_1=\tfrac12\mathrm{sinc}(\tfrac12)=\tfrac12\cdot\frac{\sin(\pi/2)}{\pi/2}=\frac1\pi$，$c_2=\tfrac12\mathrm{sinc}(1)=0$，和第 2 站 integrate 出来的表一致，这次没有做任何 integral。第 7 站的 sampling 用的是同一串 impulse，只是那里和它相乘，这里和它做 convolution。

:::exam 第 1 题
Signal 是 $4\cos(2000\pi t)\cdot\mathrm{rect}(2t)$，即一段 width 为 ½ 秒、frequency 为 1000 Hz、amplitude 为 4 的 $\cos$。

**Spectrum。** $\mathrm{rect}(2t)\leftrightarrow\tfrac12\mathrm{sinc}(f/2)$（scaling）。再乘 $4\cos(2\pi\cdot1000\,t)$，用 modulation property：

$$X(f)=4\cdot\tfrac12\Big[\tfrac12\mathrm{sinc}\Big(\frac{f-1000}{2}\Big)+\tfrac12\mathrm{sinc}\Big(\frac{f+1000}{2}\Big)\Big]=\mathrm{sinc}\Big(\frac{f-1000}{2}\Big)+\mathrm{sinc}\Big(\frac{f+1000}{2}\Big)$$

$f=1000$ 处的值是 1，就是上面算过的 $2D$ 在 $D=\tfrac12$ 时的值。

**Energy。** 在 time domain 算更快：$E=\int_{-1/4}^{1/4}16\cos^2(2000\pi t)\,dt$。½ 秒里正好是 $1000\times\tfrac12=500$ 个完整的 period，$\cos^2$ 的 average 是 ½，所以 $E=16\times\tfrac12\times\tfrac12=4$。Frequency domain 里核对：每个 sinc 贡献 $\int\mathrm{sinc}^2(f/2)\,df=2$，两个 sinc 相距 2000 Hz，乘积的 integral 是 0，合计 4。

**First-null bandwidth。** 每个 sinc 以 $\pm1000$ Hz 为中心，向两边各 2 Hz 第一次到零，所以正 frequency 一侧占 998 到 1002 Hz，bandwidth 是 4 Hz。
:::

## [laplace] Laplace transform 与 transfer function

:::skip
能由 $H(s)=\dfrac{40}{s^2+40s+2000}$ 直接写出 differential equation 和 impulse response，并且知道求 sinusoidal input 的 steady-state output 不需要做 inverse transform，就可以去第 5 站。
:::

### Fourier transform 走不下去的地方

- 最常用的测试 input 是 unit step $u(t)$。它的 Fourier transform 是 $\int_0^\infty e^{-j2\pi ft}\,dt$，被积的是 unit circle 上一直转的一个点，integral 没有 limit。
- 会增长的 signal，例如 $e^{t}u(t)$，更不用说。Impulse response 是它的 system 没有 frequency response，可这样的 system 是存在的，而且正是需要分析的对象。
- 开头的第二件事：$\cos t$ 在 $t=0$ 才接上，output 里多出一项 $-0.5\,e^{-t}$，它会 decay，不是任何 frequency 的 sinusoid。

三处的原因相同：Fourier transform 只用 magnitude 恒为 1 的 $e^{j2\pi ft}$ 去拆 signal。第 1 站已经知道，任何 $e^{st}$ 都是 eigenfunction，$s$ 不必是纯 imaginary 的。所以把 exponential 放宽成 $e^{st}$，$s=\sigma+j\omega$，并且只管 $t\ge0$：

$$X(s)=\int_{0^-}^{\infty}x(t)\,e^{-st}\,dt$$

叫 Laplace transform。下限写 $0^-$ 是为了把恰好位于 $t=0$ 的 impulse 包括进去。把 $e^{-st}$ 拆成 $e^{-\sigma t}\,e^{-j\omega t}$ 看：$X(\sigma+j\omega)$ 就是 $x(t)\,e^{-\sigma t}$ 的 Fourier transform。原来不 converge 的 integral，乘上一个 decay 得足够快的 $e^{-\sigma t}$ 就 converge 了。

用刚才卡住的 $u(t)$ 试：

$$\int_0^\infty e^{-st}\,dt=\left[\frac{e^{-st}}{-s}\right]_0^\infty=\frac1s,\qquad\text{前提是 }|e^{-st}|=e^{-\sigma t}\to0\text{，即 }\mathrm{Re}\,s>0$$

让 integral converge 的那些 $s$ 叫 region of convergence（ROC）。同样的计算给出

$$e^{-at}u(t)\ \longleftrightarrow\ \frac{1}{s+a},\qquad\mathrm{Re}\,s>-a$$

取 $a=-1$，$e^{t}u(t)$ 也有了 transform $\dfrac{1}{s-1}$，只是 ROC 退到 $\mathrm{Re}\,s>1$。卷子附的表里其余几对都能从这一对得到：

| $x(t)$，$t\ge0$ | $X(s)$ | 怎么来的 |
|---|---|---|
| $\delta(t)$ | 1 | $\int\delta(t)e^{-st}dt=e^{0}$ |
| $u(t)$ | $\dfrac1s$ | 上面取 $a=0$ |
| $\cos\omega_0t$ | $\dfrac{s}{s^2+\omega_0^2}$ | $\tfrac12\Big[\dfrac{1}{s-j\omega_0}+\dfrac{1}{s+j\omega_0}\Big]$ |
| $\sin\omega_0t$ | $\dfrac{\omega_0}{s^2+\omega_0^2}$ | $\tfrac{1}{2j}\Big[\dfrac{1}{s-j\omega_0}-\dfrac{1}{s+j\omega_0}\Big]$ |
| $e^{-\alpha t}x(t)$ | $X(s+\alpha)$ | $\int x(t)e^{-\alpha t}e^{-st}dt=\int x(t)e^{-(s+\alpha)t}dt$ |
| $e^{-\alpha t}\sin\omega_0t$ | $\dfrac{\omega_0}{(s+\alpha)^2+\omega_0^2}$ | 上面两行合起来 |

和 Fourier transform 的关系：$\sigma=0$ 那条竖线（imaginary axis）在 ROC 里时，代入 $s=j2\pi f$ 就得到 Fourier transform。$e^{-t}u(t)$ 的 ROC 是 $\mathrm{Re}\,s>-1$，包含 imaginary axis，$\tfrac{1}{s+1}$ 代入后是 $\tfrac{1}{1+j2\pi f}$，就是第 3 站用过的 $H(f)$。$u(t)$ 的 ROC 是 $\mathrm{Re}\,s>0$，不含 imaginary axis，和它没有普通的 Fourier transform 一致。

:::edge 同一个式子可以对应两个 signal
如果允许 signal 在 $t<0$ 时不为零，把 integral 的下限改成 $-\infty$，那么 $-e^{-at}u(-t)$ 的 transform 是

$$\int_{-\infty}^{0}-e^{-at}e^{-st}\,dt=\left[\frac{e^{-(s+a)t}}{s+a}\right]_{-\infty}^{0}=\frac{1}{s+a},\qquad\text{前提是 }\mathrm{Re}\,s<-a$$

式子和 $e^{-at}u(t)$ 的一模一样，只有 ROC 不同。所以单凭一个 $X(s)$ 的式子定不了 signal，还要知道 ROC。这门课的 signal 和 impulse response 都从 $t=0$ 开始，ROC 总是最右边那个 pole 的右侧，这个歧义不会出现；查表做 inverse transform 时默认的就是这个约定。
:::

### Derivative 变成乘 $s$

Laplace transform 最有用的一条 property。对 $x'(t)$ 的 transform 做 integration by parts：

$$\int_{0^-}^\infty x'(t)\,e^{-st}\,dt=\Big[x(t)\,e^{-st}\Big]_{0^-}^{\infty}+s\int_{0^-}^\infty x(t)\,e^{-st}\,dt=s\,X(s)-x(0^-)$$

（$\mathrm{Re}\,s$ 足够大时 $x(t)e^{-st}$ 在 infinity 处为 0。）再用一次，$x''\leftrightarrow s^2X(s)-s\,x(0^-)-x'(0^-)$。Differentiate 变成乘 $s$，initial condition 自动作为多出来的项带进来。Differential equation 于是变成 algebraic equation。拿 RC circuit $y'+y=x$ 用三次：

**Impulse response。** $x=\delta$，$y(0^-)=0$。两边取 transform：$sY+Y=1$，$Y=\dfrac{1}{s+1}$，查表得 $h(t)=e^{-t}u(t)$。第 1 站当作“测得的结果”用的就是它。

**Step response。** $x=u(t)$，$y(0^-)=0$：$sY+Y=\dfrac1s$，

$$Y=\frac{1}{s(s+1)}=\frac1s-\frac{1}{s+1}\qquad\Longrightarrow\qquad y(t)=1-e^{-t}$$

第 1 站用 convolution 算 rect pulse 的 response，在 pulse 还没结束的 $0\le t\le1$ 上得到的正是它。

把 RC circuit 换成一般的 first-order system $T\,y'+y=K\,x$，同样两边取 transform：$(Ts+1)\,Y=K\,X$，$H(s)=\dfrac{K}{Ts+1}$，pole 在 $-1/T$。Step response：

$$Y(s)=\frac{K}{s\,(Ts+1)}=K\Big[\frac1s-\frac{T}{Ts+1}\Big]=K\Big[\frac1s-\frac{1}{s+1/T}\Big]\qquad\Longrightarrow\qquad y(t)=K\big(1-e^{-t/T}\big)$$

$t=T$ 时 $y=K(1-e^{-1})=0.632K$：每过一个 $T$，离 final value $K$ 的距离乘 $e^{-1}=0.368$。$T$ 叫 time constant。RC circuit 是 $T=1$ s、$K=1$，$y(1)=0.632$ 就是第 1 站 pulse response 的最高点。

**没有 input，只有 initial condition。** $x=0$，$y(0^-)=1$：$(sY-1)+Y=0$，$Y=\dfrac{1}{s+1}$，$y(t)=e^{-t}$。这是第 1 站那个“zero input 却有 output”的情形。

### Transfer function：同一个 $H(s)$ 的三个来历

Initial condition 全为零时，对一般的 equation $a_2y''+a_1y'+a_0y=b_1x'+b_0x$ 两边取 transform：

$$(a_2s^2+a_1s+a_0)\,Y(s)=(b_1s+b_0)\,X(s)\qquad\Longrightarrow\qquad H(s)=\frac{Y(s)}{X(s)}=\frac{b_1s+b_0}{a_2s^2+a_1s+a_0}$$

这个比值叫 transfer function。它和前面出现过的两个东西是同一个：

- 取 $x=\delta$，$X(s)=1$，于是 $Y(s)=H(s)$：$H(s)$ 是 impulse response 的 Laplace transform。
- 第 1 站的 eigenvalue $\int h(\sigma)e^{-s\sigma}d\sigma$，写出来就是 $h$ 的 Laplace transform。

对 RC circuit，三条路都给出 $\dfrac{1}{s+1}$。$Y(s)=H(s)X(s)$ 是 $y=x*h$ 在 $s$-domain 里的写法，理由和第 3 站的 $Y(f)=H(f)X(f)$ 相同。

Equation 和 transfer function 可以直接互相读：denominator 的 coefficient 是 $y$ 各 order derivative 的 coefficient，numerator 的是 $x$ 的。

### 回到 time domain：partial fractions

$Y(s)$ 是两个 polynomial 之比时，把它拆成表里有的简单项之和，逐项查表。

例：system $y'+2y=x$，input $x(t)=e^{-t}u(t)$，initial condition 为零。$H(s)=\dfrac{1}{s+2}$，$X(s)=\dfrac{1}{s+1}$，

$$Y(s)=\frac{1}{(s+1)(s+2)}=\frac{A}{s+1}+\frac{B}{s+2}$$

求 $A$：两边乘 $(s+1)$，得 $\dfrac{1}{s+2}=A+\dfrac{B\,(s+1)}{s+2}$，再令 $s=-1$，右边第二项消失，$A=\dfrac{1}{-1+2}=1$。同样，两边乘 $(s+2)$ 再令 $s=-2$，$B=\dfrac{1}{-2+1}=-1$。

$$y(t)=\big(e^{-t}-e^{-2t}\big)\,u(t)$$

代回 equation 核对：$y'+2y=(-e^{-t}+2e^{-2t})+(2e^{-t}-2e^{-2t})=e^{-t}$，$y(0)=0$。

Denominator 是没有 real root 的 quadratic 时，不必拆成 complex 的项。Complete the square，把它写成 $(s+\alpha)^2+\omega_0^2$，对上表里最后一行。

:::exam 第 5 题 (a)(b)
$H_1(s)=\dfrac{40}{s^2+40s+2000}$。

(a) Complete the square：$s^2+40s+2000=(s+20)^2+(2000-400)=(s+20)^2+40^2$。$\alpha=20$，$\omega_0=40$，numerator 正好是 $\omega_0=40$，所以 $h(t)=e^{-20t}\sin(40t)\,u(t)$。

(b) $H_1=Y/X$ 交叉相乘：$(s^2+40s+2000)\,Y=40\,X$，把 $s$ 换回 differentiate：$y''+40y'+2000y=40x$。
:::

### Sinusoidal input：steady state 不用做 inverse transform

先把开头第二件事算完。RC circuit，input 是 $t=0$ 接上的 $\cos t$，$X(s)=\dfrac{s}{s^2+1}$：

$$Y(s)=\frac{s}{(s+1)(s^2+1)}=\frac{A}{s+1}+\frac{Bs+C}{s^2+1}$$

$A=\Big[\dfrac{s}{s^2+1}\Big]_{s=-1}=-\dfrac12$。通分后比较 numerator：$s=A(s^2+1)+(Bs+C)(s+1)$，$s^2$ 的 coefficient 给 $0=A+B$，constant 给 $0=A+C$，所以 $B=C=\tfrac12$（$s$ 的 coefficient $1=B+C$ 也对）。

$$y(t)=-\tfrac12e^{-t}+\tfrac12\cos t+\tfrac12\sin t=\underbrace{0.707\cos(t-45^\circ)}_{\text{steady state}}\ \underbrace{-\,0.5\,e^{-t}}_{\text{transient}}$$

两部分的来历在 partial fractions 里看得很清楚。$Y=HX$ 的 pole 分两批：$H$ 的 pole（$-1$）给出 $e^{-t}$，这是 system 自己的 mode，叫 transient，它会 decay；$X$ 的 pole（$\pm j$）给出 frequency 与 input 相同的 sinusoid，留到最后，叫 steady state。而 steady state 那一项正是第 1 站不做任何 integral 就得到的 $|H(j)|\cos(t+\angle H(j))$。

对一般的 stable system 和 input $\cos\omega t$ 也一样。$\dfrac{s}{s^2+\omega^2}=\dfrac{s}{(s-j\omega)(s+j\omega)}$，$Y$ 在 $s=j\omega$ 处那一项的 coefficient 是

$$\Big[(s-j\omega)\,H(s)\,\frac{s}{(s-j\omega)(s+j\omega)}\Big]_{s=j\omega}=H(j\omega)\,\frac{j\omega}{2j\omega}=\frac{H(j\omega)}{2}$$

对应 time domain 里的 $\tfrac12H(j\omega)e^{j\omega t}$；$s=-j\omega$ 处是它的 conjugate。两项合起来是 $|H(j\omega)|\cos(\omega t+\angle H(j\omega))$，其余各项来自 $H$ 的 pole，全部 decay。所以：

> Stable system 的 steady state 里，每个 frequency 各走各的：frequency 为 $\omega$ 的 sinusoid，amplitude 乘 $|H(j\omega)|$，phase 加 $\angle H(j\omega)$。

Constant（DC）是 $\omega=0$ 的情形，乘的是 $H(0)$，叫 DC gain。

:::wrong 求 steady-state output，要先乘出 $Y(s)$ 再做 inverse transform
Input 是 $4+5\sin t$ 时，老老实实算 $Y(s)=H(s)X(s)$ 再做 partial fractions，能做出来，但得到的是含 transient 的 complete response，题目并不要。只需要在 input 含有的每个 frequency 上算一次 $H$。下面这道题两种做法都走一遍。
:::

:::exam 第 3 题
$h(t)=(e^{-t}+e^{-2t})\,u(t)$，所以 $H(s)=\dfrac1{s+1}+\dfrac1{s+2}$。Input $4+5\sin t$ 有两个 frequency：

- $\omega=0$：$H(0)=1+\tfrac12=1.5$，DC 那一部分变成 $4\times1.5=6$。
- $\omega=1$：$H(j)=\dfrac1{1+j}+\dfrac1{2+j}=\dfrac{1-j}{2}+\dfrac{2-j}{5}=0.9-j0.7$。Magnitude $\sqrt{0.9^2+0.7^2}=\sqrt{1.3}\approx1.140$，phase $-\arctan(0.7/0.9)\approx-37.9^\circ$。Amplitude 变成 $5\times1.140=5.70$。

$$y_{ss}(t)=6+5.70\,\sin(t-37.9^\circ)$$
:::

走长路核对。设 input 在 $t=0$ 接上，$X(s)=\dfrac4s+\dfrac{5}{s^2+1}$，$Y=HX$ 做 partial fractions 得

$$y(t)=6-1.5\,e^{-t}-e^{-2t}-3.5\cos t+4.5\sin t$$

后两项合成 $\sqrt{3.5^2+4.5^2}\,\sin\!\big(t-\arctan\tfrac{3.5}{4.5}\big)=5.70\sin(t-37.9^\circ)$，和上面一致；多出来的 $-1.5e^{-t}-e^{-2t}$ 是 transient。

::fig[ee2023-sss] 上面那个 complete response（彩线）和 steady state（虚线）。$y(0)=0$，三四秒之后 transient 已经看不出来，两条线重合。

### Final value theorem

问一个 signal 最后停在哪，也可以不做 inverse transform。如果 $f(t)$ 在 $t\to\infty$ 时有 limit，那么

$$\lim_{t\to\infty}f(t)=\lim_{s\to0}s\,F(s)$$

理由还是 partial fractions。$f(t)$ 要有 limit，$F(s)$ 只能是 $\dfrac As$ 加上若干 pole 在 left half-plane 的项。前者对应 constant $A$，后者全部 decay，所以 limit 是 $A$；另一边 $sF(s)=A+s\times(\text{在 }s=0\text{ 处有限的项})\to A$。

用一次：卷子第 3 题的 system 的 step response 是 $Y(s)=\dfrac{H(s)}{s}$，$\lim_{s\to0}sY(s)=H(0)=1.5$。Step response 最后停在 DC gain 上。

:::edge 这两条捷径都要求 pole 在 left half-plane
“代入 $s=j\omega$ 求 steady state”默认 transient 会 decay。取 $H(s)=\dfrac{1}{s-1}$，照样能算出 $H(j)=\dfrac{1}{j-1}$，但 input $\cos t$ 的 output 是 $Y=\dfrac{s}{(s-1)(s^2+1)}$，它在 $s=1$ 处那一项是 $\dfrac{1/2}{s-1}$，对应 $\tfrac12e^{t}$，一直增长，output 根本不会进入 steady state，$H(j)$ 这个数没有意义。

Final value theorem 同理，只在 $sF(s)$ 的 pole 全在 left half-plane 时成立。对 $F(s)=\dfrac{1}{s^2+1}$ 套用它得到 $\lim_{s\to0}\dfrac{s}{s^2+1}=0$，而这个 signal 是 $\sin t$，没有 limit。
:::

:::back
$H(s)$ 就是[第 1 站](#lti)里 $e^{st}$ 被乘上的那个 eigenvalue。Steady state 的规则是[第 6 站](#bode) Bode plot 的出发点：Bode plot 画的就是 $|H(j\omega)|$ 和 $\angle H(j\omega)$。
:::

## [pz] Pole、zero、stability、second-order system 与 feedback

:::skip
看到 transfer function 的 denominator 里单独有一个 factor $s$，能立刻说出 system 是否 BIBO stable 以及为什么；能由 $\zeta=0.45$ 说出 step response 大概的样子；能求出 $1+\dfrac{K(s+3)}{s^2-1}=0$ 的 root 全在 left half-plane 时 $K$ 的范围，就可以去第 6 站。
:::

### Pole 决定 system 自己的 mode

把 transfer function 的 numerator 和 denominator 都 factor 开：

$$H(s)=K\,\frac{(s-z_1)(s-z_2)\cdots}{(s-p_1)(s-p_2)\cdots}$$

Numerator 的 root $z_i$ 叫 zero，denominator 的 root $p_k$ 叫 pole。上一站的 partial fractions 说明，pole 各不相同时

$$H(s)=\sum_k\frac{r_k}{s-p_k}\qquad\Longleftrightarrow\qquad h(t)=\sum_kr_k\,e^{p_kt}\,u(t)$$

每个 pole $p$ 贡献一项 $e^{pt}$，叫 system 的一个 mode。Mode 长什么样只看 $p$ 在 complex plane 上的位置。写 $p=\sigma+j\omega$，$e^{pt}=e^{\sigma t}\,e^{j\omega t}$：$\sigma$ 管 magnitude 的增减，$\omega$ 管转得多快。$h(t)$ 是 real 的时候，complex pole 成 conjugate 对出现，coefficient 也互为 conjugate，两项合成一个 real 的 signal：

$$r\,e^{pt}+r^*e^{p^*t}=2\,\mathrm{Re}\{r\,e^{pt}\}=2|r|\,e^{\sigma t}\cos(\omega t+\angle r)$$

| Pole 的位置 | Mode |
|---|---|
| 负 real axis 上，$p=-a$ | $e^{-at}$：单调 decay，离 origin 越远越快 |
| Left half-plane 的 conjugate 对 $-\alpha\pm j\omega_0$ | $e^{-\alpha t}\cos(\omega_0t+\phi)$：边 oscillate 边 decay |
| Imaginary axis 上 $\pm j\omega_0$ | $\cos(\omega_0t+\phi)$：不 decay |
| Origin | constant |
| Right half-plane | $e^{\sigma t}$，$\sigma>0$：增长 |

拿见过的两个 system 核对。RC circuit 的 pole 在 $-1$，mode 是 $e^{-t}$。卷子第 5 题的 $H_1$：$s^2+40s+2000=0$ 的 root 是 $\dfrac{-40\pm\sqrt{1600-8000}}{2}=-20\pm j40$，mode 是以 $e^{-20t}$ decay、以 40 rad/s oscillate 的 sinusoid，和上一站求出的 $h(t)=e^{-20t}\sin40t$ 一致。

同一个 pole 出现两次时多出一个 factor $t$：把 $e^{pt}\leftrightarrow\dfrac{1}{s-p}$ 两边对 $p$ differentiate，得 $t\,e^{pt}\leftrightarrow\dfrac{1}{(s-p)^2}$。

**Stability。** 第 1 站的条件是 $\int|h(t)|\,dt<\infty$。$h$ 是若干 mode 之和，每个 mode 都 decay 时 integral 有限；只要有一个 mode 不 decay（$\mathrm{Re}\,p\ge0$），integral 就是 infinity。所以

> Causal 的 system 是 BIBO stable 的，当且仅当所有 pole 都严格在 left half-plane。

Imaginary axis 上的 pole 也不行：它的 mode 不增长，但也不 decay。

::fig[ee2023-pz] 卷子第 4 题的 system。四个 pole 里三个在 left half-plane，但 origin 上还有一个。

:::exam 第 4 题 (a)(b)
$H(s)=\dfrac{(s-4)(s+20)}{s\,(s^2+10s+100)(s+3)}$。

Zero：$4$ 和 $-20$。Pole：$0$、$-3$，以及 $s^2+10s+100=0$ 的 root $\dfrac{-10\pm\sqrt{100-400}}{2}=-5\pm j8.66$。

Stability：origin 处的 pole 对应 $\dfrac1s$，也就是一个 integrator。给它一个 bounded 的 step input，$Y(s)$ 里出现 $\dfrac{1}{s^2}$，output 里有一项和 $t$ 成正比地增长，所以 system 不是 BIBO stable 的。它没有 diverge 的 mode，通常称为 marginally stable。
:::

用上面的条件核对：$H$ 在 $s=0$ 处那一项的 coefficient 是 $\Big[\dfrac{(s-4)(s+20)}{(s^2+10s+100)(s+3)}\Big]_{s=0}=\dfrac{-80}{300}=-0.267$，所以 $h(t)$ 里有一项 $-0.267\,u(t)$，永不 decay，$\int|h|$ 是 infinity。

### Zero 改变 weight，不改变 mode

Zero 是让 $H(s)=0$ 的 $s$：input $e^{zt}$ 的 eigenvalue 是 0，被 system 完全挡掉。Zero 不在 denominator 里，不产生 mode；它改变的是 partial fractions 里各个 $r_k$，也就是每个 mode 的 weight 和 phase。

:::wrong Right half-plane 有 zero，所以 system 不 stable
第 4 题的 system 在 $s=4$ 有一个 zero，但它不 stable 的原因是 origin 的 pole，和这个 zero 无关。比较两个 pole 相同（$-1$ 和 $-2$）、DC gain 都是 1 的 system 的 step response：

$$\frac{2}{(s+1)(s+2)}:\quad y(t)=1-2e^{-t}+e^{-2t};\qquad\frac{2\,(1-s)}{(s+1)(s+2)}:\quad y(t)=1-4e^{-t}+3e^{-2t}$$

（第二个：$Y=\dfrac{2(1-s)}{s(s+1)(s+2)}$，三个 coefficient 分别是 $\dfrac{2}{1\cdot2}=1$、$\dfrac{2\cdot2}{(-1)(1)}=-4$、$\dfrac{2\cdot3}{(-2)(-1)}=3$。）两者的 mode 都是 $e^{-t}$ 和 $e^{-2t}$，都停在 1，都 stable。差别只在 weight：第二个在 $t=0$ 的 slope 是 $4-6=-2$，先往反方向走，在 $t=\ln1.5=0.41$ 时低到 $-\tfrac13$，然后才回头。Right half-plane 的 zero 带来的是这种“先反向”的 response，不是 instability。
:::

::fig[ee2023-rhpzero] 上面两个 system 的 step response。

### 从 pole–zero plot 读 frequency response

Frequency response 是 $H(s)$ 在 imaginary axis 上的值。把 $s=j\omega$ 代进 factor 过的式子，每个 $(j\omega-p_k)$ 是从 pole $p_k$ 指向点 $j\omega$ 的 vector，所以

$$|H(j\omega)|=|K|\,\frac{\text{到各个 zero 的距离之积}}{\text{到各个 pole 的距离之积}},\qquad\angle H(j\omega)=\angle K+\sum\text{zero 的 vector 的 angle}-\sum\text{pole 的 vector 的 angle}$$

用它重算 RC circuit 在 $\omega=1$ 的值：从 pole $-1$ 到点 $j$ 的 vector 是 $1+j$，length $\sqrt2$，angle $45^\circ$，所以 $|H(j)|=\tfrac{1}{\sqrt2}=0.707$，$\angle H(j)=-45^\circ$，和第 1 站一致。

这个读法让两件事一眼可见。点 $j\omega$ 沿 imaginary axis 往上走，经过某个 pole 附近时，到它的距离最短，$|H|$ 在那里鼓起来；pole 离 imaginary axis 越近，鼓得越高越窄。对 $H_1$，$\omega=34.6$ 时到两个 pole $-20\pm j40$ 的距离是 20.7 和 77.3，$|H_1|=\dfrac{40}{20.7\times77.3}=0.0250$，比 $H_1(0)=0.02$ 高 25%。而 origin 上的 pole 让 $\omega\to0$ 时距离趋于 0，$|H|\to\infty$。下一站的 Bode plot 是把这些距离取 log 之后画出来。

::fig[ee2023-vectors] 左边是 $H_1$ 的两个 pole 和 imaginary axis 上的点 $j34.6$（实际比例）；右边是 $|H_1(j\omega)|$，那个点正好在鼓包附近。

### Second-order system

两个 pole 的 system 是所有 oscillation 的原型，统一写成

$$H(s)=\frac{K\omega_n^2}{s^2+2\zeta\omega_ns+\omega_n^2}$$

$K$ 是 DC gain（$H(0)=K$），$\omega_n$ 叫 natural frequency，$\zeta$ 叫 damping ratio。解 denominator：

$$s=-\zeta\omega_n\pm\omega_n\sqrt{\zeta^2-1}$$

| $\zeta$ | Pole | 名称 |
|---|---|---|
| $\zeta>1$ | 两个不同的负 real pole | overdamped |
| $\zeta=1$ | $-\omega_n$ 处的 double pole | critically damped |
| $0<\zeta<1$ | $-\zeta\omega_n\pm j\,\omega_n\sqrt{1-\zeta^2}$ | underdamped |
| $\zeta=0$ | $\pm j\omega_n$ | undamped |

Underdamped 时 pole 到 origin 的距离是 $\sqrt{\zeta^2\omega_n^2+\omega_n^2(1-\zeta^2)}=\omega_n$，与 $\zeta$ 无关。所以固定 $\omega_n$、改变 $\zeta$，pole 沿着 radius 为 $\omega_n$ 的 circle 走：$\zeta=0$ 时在 imaginary axis 上，$\zeta$ 增大就向负 real axis 靠拢，$\zeta=1$ 时两个 pole 在 $-\omega_n$ 相遇，再大就沿 real axis 一个往左、一个往右分开。Real part 的大小 $\zeta\omega_n$ 是 decay rate，imaginary part $\omega_d=\omega_n\sqrt{1-\zeta^2}$ 是实际的 oscillation frequency。$\omega_n$ 定快慢，$\zeta$ 定形状。

::fig[ee2023-zeta] 左边是四个 $\zeta$ 对应的 pole，右边是它们的 step response。横轴用 $\omega_nt$，所以四条 curve 只差在 $\zeta$ 上。

Underdamped 的 step response 可以完整写出来。$Y(s)=\dfrac{K\omega_n^2}{s\,(s^2+2\zeta\omega_ns+\omega_n^2)}$，先拆出 $\dfrac1s$：

$$Y(s)=K\Big[\frac1s-\frac{s+2\zeta\omega_n}{s^2+2\zeta\omega_ns+\omega_n^2}\Big]$$

（通分核对：$(s^2+2\zeta\omega_ns+\omega_n^2)-s\,(s+2\zeta\omega_n)=\omega_n^2$。）第二项的 denominator 是 $(s+\zeta\omega_n)^2+\omega_d^2$，把 numerator 写成 $(s+\zeta\omega_n)+\dfrac{\zeta\omega_n}{\omega_d}\,\omega_d$，对上表里的 $e^{-\alpha t}\cos$ 和 $e^{-\alpha t}\sin$：

$$y(t)=K\Big[1-e^{-\zeta\omega_nt}\Big(\cos\omega_dt+\frac{\zeta}{\sqrt{1-\zeta^2}}\sin\omega_dt\Big)\Big]$$

它最高冲到哪里？Step response 的 derivative 是 impulse response（$sY(s)=H(s)$），而 $H(s)=\dfrac{K\omega_n^2}{\omega_d}\cdot\dfrac{\omega_d}{(s+\zeta\omega_n)^2+\omega_d^2}$ 给出 $h(t)=\dfrac{K\omega_n^2}{\omega_d}\,e^{-\zeta\omega_nt}\sin\omega_dt$。它第一次回到 0 是在 $\omega_dt=\pi$，此时 $\cos=-1$、$\sin=0$：

$$y_{\max}=K\Big[1+e^{-\zeta\omega_n\pi/\omega_d}\Big],\qquad\text{overshoot}=e^{-\pi\zeta/\sqrt{1-\zeta^2}}$$

| $\zeta$ | 0.2 | 0.447 | 0.5 | 0.707 |
|---|---|---|---|---|
| Overshoot | 52.7% | 20.8% | 16.3% | 4.3% |

对卷子第 5 题的 $H_1=\dfrac{40}{s^2+40s+2000}$：$\omega_n=\sqrt{2000}=44.7$ rad/s；$2\zeta\omega_n=40$ 得 $\zeta=0.447$；$K\omega_n^2=40$ 得 $K=0.02$；$\zeta\omega_n=20$，$\omega_d=44.7\times\sqrt{1-0.2}=40$，pole 在 $-20\pm j40$。它是 underdamped 的，impulse response 是 $\dfrac{K\omega_n^2}{\omega_d}e^{-20t}\sin40t=e^{-20t}\sin40t$，和上一站的结果一致；给它一个 unit step，output 会在 $t=\pi/40=0.079$ s 冲到 $0.02\times1.208=0.0242$，再绕回 0.02。

$\zeta\ge1$ 时没有 overshoot。$\zeta=2$ 的两个 pole 在 $-0.268\,\omega_n$ 和 $-3.73\,\omega_n$，快的那个 mode 很快消失，剩下 $e^{-0.268\omega_nt}$ 慢慢拖着。Output 进入 final value 的 $\pm2\%$ 之内并不再出去所需的时间，按图上四条 curve 算出来是

| $\zeta$ | 0.2 | 0.5 | 1 | 2 |
|---|---|---|---|---|
| $\omega_nt$ | 19.6 | 8.1 | 5.8 | 14.9 |

$\zeta$ 太小，oscillation 迟迟不停；太大，被慢的 pole 拖住。$\zeta=1$ 是没有 overshoot 的 response 里最快的。

:::edge $\zeta$ 和 $\omega_n$ 只从 denominator 读
$H_1$ 的 numerator 是 40，不是 $\omega_n^2=2000$。这只说明 DC gain $K=0.02$，不影响 $\zeta$、$\omega_n$ 和 pole。读的时候先把 denominator 的 $s^2$ 的 coefficient 化成 1，constant 是 $\omega_n^2$，$s$ 的 coefficient 是 $2\zeta\omega_n$，numerator 最后再看。
:::

### Feedback：把 pole 搬进 left half-plane

上一站最后那个 $G(s)=\dfrac{1}{s-1}$ 的 pole 在 $+1$，impulse response 是 $e^{t}u(t)$，一直增长。Magnetic levitation 和 inverted pendulum 都是这样的 plant：离开平衡点一点，就被推得更远。Plant 本身改不了。能做的是用 sensor 量出 output $y$，和想要的值 $x$ 相减，按这个 error 去驱动 plant。

::fig[ee2023-feedback] 上面是 block diagram：error $e=x-y$ 经过 controller $C(s)$ 再进入 plant $G(s)=\dfrac{1}{s^2-1}$。下面两张 $s$-plane 画 closed-loop 的两个 pole 随 gain $K$ 怎样移动（叉是 $K=0$ 时的位置，也就是 $G$ 自己的 pole）。左边 controller 只是 gain $K$，右边是 $K(s+3)$。看左边的两个 pole 在 origin 相遇后沿 imaginary axis 分开，始终进不了 left half-plane；右边 $K$ 过了 $\tfrac13$，两个 pole 就都在 left half-plane 里。

**Closed-loop transfer function。** 按图写两个关系：$E=X-Y$，$Y=C\,G\,E$。把第一个代进第二个：

$$Y=CG\,(X-Y)\ \Longrightarrow\ Y\,(1+CG)=CG\,X\ \Longrightarrow\ \frac{Y}{X}=\frac{CG}{1+CG}$$

Sensor 自己有 transfer function $H(s)$ 时 $E=X-HY$，同样两步得 $\dfrac{CG}{1+CGH}$。Closed-loop system 的 pole 是 $1+CGH=0$ 的 root，已经不是 $G$ 的 pole 了。Stability 的判断和前面一样，只是对象换成 closed-loop 的 transfer function：这些 root 要全部严格在 left half-plane。

先对 $G=\dfrac{1}{s-1}$ 用最简单的 controller，$C=K$：

$$\frac{Y}{X}=\frac{K/(s-1)}{1+K/(s-1)}=\frac{K}{s-1+K}$$

Closed-loop 的 pole 在 $1-K$。$K>1$ 时它在 left half-plane，system stable。取 $K=3$，pole 在 $-2$，step response 是

$$Y(s)=\frac{3}{s\,(s+2)}=\frac{1.5}{s}-\frac{1.5}{s+2}\qquad\Longrightarrow\qquad y(t)=1.5\,\big(1-e^{-2t}\big)$$

原来往外跑的 $e^{t}$ 不见了，换成以 $e^{-2t}$ decay 的 mode。代价是 output 停在 $1.5$ 而不是想要的 $1$：final value 是 closed-loop 的 DC gain $\dfrac{K}{K-1}$，$K$ 越大越接近 1。

**只加 gain 不够的 plant。** Magnetic levitation 和 inverted pendulum 线性化之后是 $s^2-a^2$ 这种 denominator（6.003 第 13 讲：inverted pendulum 是 $s^2-g/l$），pole 在 $\pm a$。取 $a=1$，$G=\dfrac{1}{s^2-1}$，$C=K$：

$$1+\frac{K}{s^2-1}=0\ \Longrightarrow\ s^2+(K-1)=0\ \Longrightarrow\ s=\pm\sqrt{1-K}$$

| $K$ | 0 | 0.5 | 1 | 2 | 5 |
|---|---|---|---|---|---|
| Closed-loop pole | $\pm1$ | $\pm0.707$ | $0,\ 0$ | $\pm j$ | $\pm j2$ |

$K<1$ 时总有一个 pole 在 right half-plane；$K>1$ 时两个 pole 都在 imaginary axis 上，output 一直 oscillate，不 decay，还是不 stable。$K$ 取多少都没用。

原因在 denominator 的形状上。对 $s^2+a_1s+a_0$，两个 root $p_1,p_2$ 满足 $p_1+p_2=-a_1$、$p_1p_2=a_0$：

- Root 是 complex 的：real part 都是 $-\tfrac{a_1}{2}$，在 left half-plane 当且仅当 $a_1>0$；此时 $a_0=|p_1|^2>0$ 自动成立。
- Root 是 real 的：两个都为负，当且仅当和为负、积为正，即 $a_1>0$ 且 $a_0>0$。

所以 second-order 的 denominator stable 当且仅当 $a_1>0$ 且 $a_0>0$。$s^2+(K-1)$ 的 $a_1$ 恒为 0，只调 $K$ 永远做不到。要让 $s$ 那一项出现，controller 得对 error 的 derivative 也起反应，也就是在 controller 里放一个 zero。取 $C=K(s+3)$：

$$1+\frac{K(s+3)}{s^2-1}=0\ \Longrightarrow\ s^2+K\,s+(3K-1)=0$$

$a_1=K>0$，$a_0=3K-1>0$，所以 $K>\tfrac13$ 时 stable。$K=\tfrac13$ 时 root 是 $0$ 和 $-\tfrac13$，正好有一个在 origin，是边界。取 $K=2$：

$$s^2+2s+5=(s+1)^2+2^2,\qquad s=-1\pm j2$$

用上一小节的读法，$\omega_n=\sqrt5=2.24$，$\zeta=\dfrac{2}{2\sqrt5}=0.447$，和卷子第 5 题的 $H_1$ 是同一个 $\zeta$。Closed-loop 的 transfer function 是 $\dfrac{2(s+3)}{s^2+2s+5}$，DC gain $\tfrac65=1.2$。$K$ 再加大，两个 pole 沿一个以 zero $-3$ 为中心的 circle 往左绕（$K=6$ 时在 $-3\pm j2.83$），$K=12$ 时 denominator 是 $(s+5)(s+7)$，变成两个 real pole。

:::wrong 用 controller 的 zero 抵掉 plant 在 right half-plane 的 pole
对 $G=\dfrac{1}{(s-1)(s+1)}$ 取 $C=K(s-1)$，乘出来 $CG=\dfrac{K}{s+1}$，closed loop 是 $\dfrac{K}{s+1+K}$，看上去任何 $K>0$ 都 stable。可是 $(s-1)$ 只是在纸上约掉了，plant 里那个 $e^{t}$ 的 mode 还在。Zero 和 pole 只要差一点就会露出来：设 plant 的 pole 实际在 $1.01$，$K=2$，

$$(s-1.01)(s+1)+2(s-1)=s^2+1.99\,s-3.01=0\ \Longrightarrow\ s=-2.995,\ 1.005$$

$a_0=-3.01<0$，有一个 pole 在 right half-plane，closed loop 不 stable。Plant 的 parameter 永远不会精确等于设计值，靠约掉来消除 right half-plane 的 pole 是做不到的；要像上面那样把 pole 真正移走。
:::

## [bode] Bode plot

:::skip
能在两分钟内徒手画出 $\dfrac{40000\,s}{(s+1)(s^2+40s+2000)}$ 的 magnitude asymptote，标对两处 corner frequency 和平台的高度，就可以去第 7 站。
:::

### 为什么两根轴都取 log

第 4 站的结论是：stable system 对 frequency 为 $\omega$ 的 sinusoid 的作用，完全由 complex number $H(j\omega)$ 描述。把 $|H(j\omega)|$ 和 $\angle H(j\omega)$ 对 $\omega$ 画出来，system 对所有 frequency 的态度就一目了然。直接画有两个麻烦。

第一，范围太大。RC circuit 的 $|H(j\omega)|=\dfrac{1}{\sqrt{1+\omega^2}}$，$\omega$ 从 0.01 到 100，它从 1 降到 0.01；linear 的轴上看不清两头。

第二，看不出结构。上一站把 $H$ 写成 factor 之积，$|H|$ 是各个 factor 的 magnitude 之积。取 log，乘积变成和：

$$20\log_{10}|H(j\omega)|=20\log_{10}|K|+\sum_i20\log_{10}|j\omega-z_i|-\sum_k20\log_{10}|j\omega-p_k|$$

Phase 本来就是相加的。所以一张复杂的图等于若干张简单的图叠起来，每种 factor 只需要画一次。

Bode plot 的约定：横轴是 $\omega$ 的 log scale，$\omega$ 每乘 10 叫一个 decade；magnitude 用 decibel，$20\log_{10}|H|$，单位 dB。

| $\lvert H\rvert$ | 1 | $\sqrt2$ | 2 | 10 | 0.1 | $\tfrac{1}{\sqrt2}$ |
|---|---|---|---|---|---|---|
| dB | 0 | 3.01 | 6.02 | 20 | $-20$ | $-3.01$ |

RC circuit 在 $\omega=1$ 的 $|H|=0.707$，是 $-3$ dB。

### 四种 factor，每种只画一次

先把每个 factor 写成 constant 项为 1 的形式，$s+a=a\,(1+s/a)$，提出来的 constant 全部并进 $K$。这样每个 factor 在 low frequency 都是 1，也就是 0 dB，相加时互不干扰。

**Constant $K$。** Height 为 $20\log_{10}|K|$ 的水平线。Phase 是 $0^\circ$，$K<0$ 时是 $180^\circ$。

**$s$。** $|j\omega|=\omega$，magnitude 是 $20\log_{10}\omega$ dB。横轴是 $\log\omega$，所以这是一条 line：$\omega$ 每乘 10 升 20 dB，slope 记作 $+20$ dB/dec，在 $\omega=1$ 处过 0 dB。Phase 恒为 $+90^\circ$。$\dfrac1s$ 上下颠倒：$-20$ dB/dec，$-90^\circ$。

**Real pole $\dfrac{1}{1+s/\omega_c}$。** $|\cdot|=\dfrac{1}{\sqrt{1+(\omega/\omega_c)^2}}$。两头各有一条 asymptote：

- $\omega\ll\omega_c$：root 里只剩 1，magnitude 约为 1，即 0 dB。
- $\omega\gg\omega_c$：root 里只剩 $(\omega/\omega_c)^2$，magnitude 约为 $\omega_c/\omega$，即 $-20\log_{10}(\omega/\omega_c)$ dB，一条 $-20$ dB/dec 的 line，在 $\omega=\omega_c$ 处过 0 dB。

两条 asymptote 在 $\omega_c$ 相接，$\omega_c$ 叫 corner frequency。真实的 curve 和 asymptote 差多少，算出来：

| $\omega/\omega_c$ | 0.1 | 0.5 | 1 | 2 | 10 |
|---|---|---|---|---|---|
| 真实值（dB） | $-0.04$ | $-0.97$ | $-3.01$ | $-6.99$ | $-20.04$ |
| Asymptote（dB） | 0 | 0 | 0 | $-6.02$ | $-20$ |
| Phase | $-5.7^\circ$ | $-26.6^\circ$ | $-45^\circ$ | $-63.4^\circ$ | $-84.3^\circ$ |

Error 最大在 corner 处，3 dB；离开一倍（一个 octave）只剩 1 dB。Phase 是 $-\arctan(\omega/\omega_c)$，从 $0^\circ$ 降到 $-90^\circ$，在 $\omega_c$ 处是 $-45^\circ$；手画时用一条从 $0.1\,\omega_c$ 处的 $0^\circ$ 到 $10\,\omega_c$ 处的 $-90^\circ$ 的 line 代替，最多差 $5.7^\circ$。

**Real zero $1+s/\omega_c$。** 上面的图上下颠倒：$\omega_c$ 之后 $+20$ dB/dec，phase 从 $0^\circ$ 升到 $+90^\circ$。

**Complex pole 对 $\dfrac{1}{1+2\zeta\,(s/\omega_n)+(s/\omega_n)^2}$。** 记 $u=\omega/\omega_n$，代入 $s=j\omega$：

$$|\cdot|=\frac{1}{\sqrt{(1-u^2)^2+4\zeta^2u^2}}$$

$u\ll1$ 时是 1，0 dB；$u\gg1$ 时 root 里只剩 $u^4$，magnitude 约为 $1/u^2$，即 $-40\log_{10}u$ dB，slope 是 $-40$ dB/dec。Corner 在 $\omega_n$。Phase 从 $0^\circ$ 降到 $-180^\circ$，在 $\omega_n$ 处 denominator 是 $j2\zeta$，phase 是 $-90^\circ$。

Asymptote 和 $\zeta$ 无关，corner 附近的真实值却全看 $\zeta$。在 $u=1$ 处 magnitude 是 $\dfrac{1}{2\zeta}$：$\zeta=1$ 时是 $-6$ dB，$\zeta=0.5$ 时是 0 dB，$\zeta=0.2$ 时是 $+8$ dB。最高点在哪：让 root 里的量最小，对 $v=u^2$ differentiate，$-2(1-v)+4\zeta^2=0$，得 $v=1-2\zeta^2$，代回去 root 里是 $4\zeta^4+4\zeta^2(1-2\zeta^2)=4\zeta^2(1-\zeta^2)$。所以 $\zeta<\tfrac{1}{\sqrt2}$ 时 curve 有一个 peak：

$$\omega_r=\omega_n\sqrt{1-2\zeta^2},\qquad\text{peak 比 asymptote 高出 }\ 20\log_{10}\frac{1}{2\zeta\sqrt{1-\zeta^2}}\ \text{dB}$$

这就是上一站从 pole–zero plot 看到的事：$\zeta$ 小，pole 靠近 imaginary axis，$j\omega$ 经过它附近时距离很短。

| Factor | Magnitude 的 asymptote | Phase |
|---|---|---|
| $K$ | Height $20\log\lvert K\rvert$ 的水平线 | $0^\circ$（$K<0$ 时 $180^\circ$） |
| $s$ | $+20$ dB/dec，在 $\omega=1$ 处过 0 dB | $+90^\circ$ |
| $1/s$ | $-20$ dB/dec，在 $\omega=1$ 处过 0 dB | $-90^\circ$ |
| $\dfrac{1}{1+s/\omega_c}$ | $\omega_c$ 之前 0 dB，之后 $-20$ dB/dec | $0^\circ$ 到 $-90^\circ$，$\omega_c$ 处 $-45^\circ$ |
| $1+s/\omega_c$ | $\omega_c$ 之前 0 dB，之后 $+20$ dB/dec | $0^\circ$ 到 $+90^\circ$，$\omega_c$ 处 $+45^\circ$ |
| Complex pole 对 | $\omega_n$ 之前 0 dB，之后 $-40$ dB/dec | $0^\circ$ 到 $-180^\circ$，$\omega_n$ 处 $-90^\circ$ |

### 把各个 factor 加起来

步骤是固定的：写成标准形式，把 constant 并成 $K$；把 corner frequency 从小到大排好；从最左边出发，每过一个 corner 改一次 slope；phase 逐项相加。

先做一个只有 real pole 的：$H(s)=\dfrac{10\,s}{(s+1)(s+10)}$。Denominator 提出 10：

$$H(s)=\frac{s}{(1+s)(1+s/10)}$$

$K=1$，一个 $s$，corner 在 1 和 10。

- $\omega<1$：只有 $s$ 在起作用，$+20$ dB/dec，朝着“$\omega=1$ 处 0 dB”这一点升上去。
- $1<\omega<10$：第一个 pole 加进来 $-20$，slope 是 0，停在 0 dB。
- $\omega>10$：第二个 pole 再加 $-20$，slope 是 $-20$ dB/dec。

Phase 从 $+90^\circ$ 开始，过第一个 corner 降到 $0^\circ$ 附近，过第二个再降到 $-90^\circ$。形状是 bandpass：很低和很高的 frequency 都被压掉。用真实值核对：$\omega=1$ 和 $\omega=10$ 处都是 $-3.05$ dB（各自 corner 的 3 dB，再加上另一个 pole 的 0.04 dB），正中间 $\omega=\sqrt{10}$ 处是 $-0.83$ dB，phase 是 $0^\circ$。

:::exam 第 5 题 (c)
$H(s)=H_1H_2=\dfrac{40}{s^2+40s+2000}\cdot\dfrac{1000\,s}{s+1}$。

标准形式：numerator 是 $40000\,s$，denominator 的 quadratic 提出 2000，

$$H(s)=\frac{20\,s}{(1+s)\Big(1+\dfrac{40}{2000}s+\dfrac{s^2}{2000}\Big)}$$

三个部分：$20s$（slope $+20$，在 $\omega=1$ 处高 $20\log_{10}20\approx26$ dB）；$\omega=1$ 处的 real pole；$\omega_n=\sqrt{2000}\approx44.7$ 处的 complex pole 对。

- $\omega<1$：slope $+20$ dB/dec。
- $1<\omega<44.7$：$+20$ 被 pole 的 $-20$ 抵消，持平在 26 dB。
- $\omega>44.7$：slope $-40$ dB/dec。

Phase 从 $+90^\circ$ 出发，过 $\omega=1$ 降到约 $0^\circ$，过 44.7 再降 $180^\circ$，最后趋于 $-180^\circ$。这是一个 bandpass 的形状。
:::

### 反过来：由 asymptote 读 transfer function

把画图的步骤倒着走。设量到的 magnitude asymptote 是：最左边 $+20$ dB/dec，$\omega=1$ 起持平在 26 dB，$\omega=44.7$ 起 $-40$ dB/dec。

- 最左边的 slope 是 $+20$：有一个 factor $s$。
- 在 $\omega=1$ slope 变化 $-20$：一个 real pole，$\dfrac{1}{1+s}$。
- 在 $\omega=44.7$ slope 变化 $-40$：两个 pole，$\dfrac{1}{1+2\zeta\,s/44.7+s^2/2000}$。
- $K$：最左边那一段是 $20\log_{10}(K\omega)$，它在 $\omega=1$ 处到达 26 dB，所以 $K=10^{26/20}=20$。

这样就得到第 5 题 (c) 的 $H(s)$，只差 $\zeta$。Asymptote 里没有 $\zeta$ 的信息，要看真实的 curve：它在 $\omega_n$ 处是 27.0 dB，比平台高 0.97 dB，由 $\dfrac{1}{2\zeta}=10^{0.97/20}=1.118$ 得 $\zeta=0.447$。$K$ 的正负号、zero 在哪个 half-plane，要另看 phase plot。

:::back
Bode plot 画的是[第 4 站](#laplace)的 $H(j\omega)$；complex pole 对的 $\zeta$、$\omega_n$ 和“pole 靠近 imaginary axis 就出 peak”来自[第 5 站](#pz)。
:::

:::from
“单个 zero、单个 pole 各有两条 asymptote，在 corner 相接”、“取 log 之后乘积变成和，phase 本来就相加”、逐个 corner 改 slope 的画法、$\dfrac{s}{(s+1)(s+10)}$ 和它乘 10 的 dB 版本、corner 处差 3 dB 而一个 octave 之外差 1 dB、phase 的 straight-line 近似差不到 0.1 rad，来自 [6.003 第 11 讲](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/resources/mit6_003f11_lec11/)的 slides；那一讲用 $Q$ 描述 complex pole 对，这里换成了 $\zeta$（$Q=\tfrac{1}{2\zeta}$）。dB、decade、octave 的约定，$s^k$ 这一项的画法，high frequency 的 slope 等于 $-20$ 乘 pole 与 zero 的个数差，以及 pole 或 zero 换到 right half-plane 时 magnitude 不变、phase 改变，来自 [EE102 讲义 Sinusoidal steady-state and frequency response](https://stanford.edu/~boyd/ee102/freq.pdf)。Peak 的位置和高度的推导、几张数表和“反过来读”那一小节是自己推和算的。
:::

## [sampling] Sampling 与 modulation

:::skip
能解释为什么占据 11 到 19 Hz 的 signal 可以用 19 Hz 做 sampling、却不能用 18 Hz，就读完这门课了。
:::

### 同一组 sample，不止一个 signal

计算机只能存离散的数。每隔 $T_s$ 秒取 $x(t)$ 的一个值，$x(nT_s)$，叫 sampling，$f_s=1/T_s$ 是 sampling rate。问题是 sample 之间的那些值还找得回来吗。

开头的第三件事说明一般找不回来。取 $f_s=10$ kHz。6 kHz 的 $\cos$ 在第 $n$ 个 sample 上的值是

$$\cos\Big(2\pi\cdot6000\cdot\frac{n}{10000}\Big)=\cos(1.2\pi n)=\cos(2\pi n-0.8\pi n)=\cos(0.8\pi n)=\cos\Big(2\pi\cdot4000\cdot\frac{n}{10000}\Big)$$

和 4 kHz 的 $\cos$ 在每一个 sample 上都相等。

::fig[ee2023-samples] 开头那张图。看左边的轮子：6 kHz 每个 sample 转 216°，等于倒着转 144°，和 4 kHz 的 spoke 左右对称、高度相同，所以两条 curve 在所有圆点上重合。

穿过同一组点的 curve 有无穷多条，它们的差别在于两个 sample 之间扭动得多厉害，也就是含有多高的 frequency。所以要让 sample 唯一地确定 signal，得另加一条假设来限制 high frequency：$|f|>B$ 时 $X(f)=0$。这样的 signal 叫 band-limited，$B$ 是它的 bandwidth。接下来要回答，在这条假设下 $f_s$ 取多大才够。

### Sampling 在 frequency domain 里做了什么

把取 sample 这件事写成一个能做 Fourier transform 的 signal：让 $x(t)$ 乘上一串间隔为 $T_s$ 的 unit impulse，

$$x_s(t)=x(t)\,p(t),\qquad p(t)=\sum_{n=-\infty}^{\infty}\delta(t-nT_s)$$

$x(t)\,\delta(t-nT_s)=x(nT_s)\,\delta(t-nT_s)$，所以 $x_s(t)$ 里恰好只有那些 sample，不多也不少。

$p(t)$ 是 period 为 $T_s$ 的 periodic signal，可以按第 2 站展开成 Fourier series。一个 period 里只有一个位于 $t=0$ 的 impulse：

$$c_k=\frac{1}{T_s}\int_{-T_s/2}^{T_s/2}\delta(t)\,e^{-j2\pi kf_st}\,dt=\frac{1}{T_s}=f_s\qquad\text{对每个 }k$$

所以 $p(t)=f_s\sum_ke^{j2\pi kf_st}$，于是

$$x_s(t)=f_s\sum_kx(t)\,e^{j2\pi kf_st}$$

每一项是 $x(t)$ 乘一个 exponential。按第 3 站的 frequency shift property，它的 spectrum 是 $X(f)$ 搬到 $kf_s$：

$$X_s(f)=f_s\sum_{k=-\infty}^{\infty}X(f-kf_s)$$

Sampling 在 frequency domain 里的全部效果是：把原来的 spectrum 每隔 $f_s$ 复制一份，height 乘 $f_s$。

### Replica 不 overlap，就什么都没丢

$X(f)$ 占据 $-B$ 到 $B$。$k=1$ 的 replica 占据 $f_s-B$ 到 $f_s+B$。两者不 overlap 的条件是 $f_s-B>B$：

$$f_s>2B$$

$2B$ 叫 Nyquist rate。条件满足时，$X_s(f)$ 在 $|f|<f_s/2$ 这一段上就是 $f_s\,X(f)$，原样的一份。用一个 ideal lowpass filter 取出这一段，gain 取 $T_s=1/f_s$ 把 height 还原，cutoff 取 $f_s/2$，output 的 spectrum 就是 $X(f)$，output 就是 $x(t)$ 本身。没有近似：sample 之间的每一个值都拿了回来。

这个 filter 的 frequency response 是 $T_s\,\mathrm{rect}(f/f_s)$。按第 3 站 duality 那一条，$f_s\,\mathrm{sinc}(f_st)\leftrightarrow\mathrm{rect}(f/f_s)$，所以它的 impulse response 是 $T_sf_s\,\mathrm{sinc}(f_st)=\mathrm{sinc}(f_st)$。$x_s(t)$ 里位于 $nT_s$ 的 impulse 经过它，变成一个中心在 $nT_s$、height 为 $x(nT_s)$ 的 sinc：

$$x(t)=\sum_{n=-\infty}^{\infty}x(nT_s)\,\mathrm{sinc}\Big(\frac{t-nT_s}{T_s}\Big)$$

在 $t=mT_s$ 核对：$\mathrm{sinc}(m-n)$ 只在 $n=m$ 时不为零，右边只剩 $x(mT_s)$。每个 sinc 在自己的 sample 上是 1，在别的 sample 上是 0，sample 之间的值由所有 sinc 一起填出来。

:::exam 第 6 题 (a)
$X(f)=10\cos(\pi f/8)$，$|f|\le4$，其余为 0。$B=4$ Hz，Nyquist rate 是 8 Hz。

以 10 Hz 做 sampling：$X_s(f)=10\sum_kX(f-10k)$。Replica 的中心在 $0,\pm10,\pm20,\dots$，每份宽 8 Hz，相邻两份之间留有 2 Hz 的空隙（例如 4 到 6 Hz），没有 aliasing。Height 乘 $f_s=10$，peak 是 100。
:::

::fig[ee2023-alias] 第一行是第 6 题的 $X(f)$。第二行是以 10 Hz 做 sampling 之后的 spectrum，就是上面这一问。第三行把 sampling rate 降到 6 Hz，低于 Nyquist rate。

### Overlap 了会出什么事

图的第三行：$f_s=6$ Hz，$k=1$ 的 replica 占据 2 到 10 Hz，和原来的 $-4$ 到 4 Hz 在 2 到 4 Hz 之间 overlap。在这一段里

$$X_s(f)=6\,\big[X(f)+X(f-6)\big]$$

是两份之和。$f=3$ 处：$X(3)=10\cos\tfrac{3\pi}{8}=3.83$，$X(3-6)=X(-3)=3.83$，$X_s(3)=6\times7.65=45.9$，而没有 overlap 时应当是 $6\times3.83=23.0$。只量得到这个和，量不到两个 term 各是多少；一个数解不出两个 unknown，信息在这里丢了。这叫 aliasing。

对单个 sinusoid 看得更清楚。Frequency 为 $f_1$ 的 $\cos$，spectrum 是 $\pm f_1$ 处的两个 impulse，sampling 之后在所有 $\pm f_1+kf_s$ 处都有。Reconstruction filter 只留 $|f|<f_s/2$，落在这个范围里的那一对在

$$f_{\text{alias}}=|f_1-kf_s|,\qquad k\text{ 取离 }f_1/f_s\text{ 最近的 integer}$$

$f_1<f_s/2$ 时 $k=0$，还原出的就是 $f_1$。否则还原出的是另一个 frequency：

| $f_s$ | $f_1$ | $k$ | 还原出的 frequency |
|---|---|---|---|
| 10 kHz | 6 kHz | 1 | 4 kHz |
| 10 kHz | 7 kHz | 1 | 3 kHz |
| 44 kHz | 30 kHz | 1 | 14 kHz |
| 44 kHz | 50 kHz | 1 | 6 kHz |
| 1 Hz | 2.25 Hz | 2 | 0.25 Hz |

第一行就是开头的第三件事。Input 的 frequency 从 0 升到 $f_s/2$，还原出的 frequency 跟着升；再往上，它掉头往下，到 $f_s$ 时回到 0，然后再升：像把 frequency 轴在 $f_s/2$ 的 integer 倍处来回折叠。拿上一小节的 formula 直接验证：把 6 kHz 的 $\cos$ 的 sample 代进去，在两个 sample 的正中间 $t=0.05$ ms 得到 $0.309$，是 $\cos(2\pi\cdot4\cdot0.05)$；6 kHz 的 $\cos$ 在那里的真实值是 $-0.309$。

:::wrong Sampling 太慢，只是丢掉了 $f_s/2$ 以上的那部分
如果只是丢掉，剩下的 low-frequency 部分还是准的。实际情况更糟：$f_s/2$ 以上的成分没有消失，它们换了一个 frequency 混进来，把原本准确的部分也弄坏了。上面的例子里 $f_s=6$，还原时 2.5 Hz 处的值是 $X(2.5)+X(-3.5)=5.56+1.95=7.51$，比真实的 5.56 大了 35%；多出来的 1.95 是原来 3.5 Hz 的成分。

所以要在 sampling 之前先用一个 lowpass filter 把 $f_s/2$ 以上的成分去掉（anti-aliasing filter）。对这个例子，先把 $X(f)$ 截到 $|f|<3$ 再以 6 Hz 做 sampling，3 到 4 Hz 的内容确实丢了，但 0 到 3 Hz 完整无损。Sampling 之后再补救是来不及的，因为那时两个 term 已经加在一起。
:::

### Modulation：把 spectrum 搬到别处

Sampling 是把 spectrum 复制到所有 $kf_s$。只复制到一处的操作更简单：乘 $\cos(2\pi f_ct)$。按第 3 站的 modulation property，spectrum 被搬到 $\pm f_c$，height 减半。$f_c$ 叫 carrier frequency。这样做是为了把 signal 送到传输介质走得通的 frequency 范围里，也为了让几路 signal 各占一段互不 overlap 的 frequency，共用一个 channel。

:::exam 第 6 题 (b)
$y(t)=x(t)\cos(30\pi t)$，$f_c=15$ Hz。

$$Y(f)=\tfrac12\big[X(f-15)+X(f+15)\big]$$

占据 $11\le|f|\le19$，peak 是 $\tfrac12\times10=5$。
:::

::fig[ee2023-modulation] 上面是原来的 spectrum，只占 ±4 Hz。乘以 $\cos(30\pi t)$ 之后，它被搬到 11 至 19 Hz 和 symmetric 的负 frequency 处，height 减半。

搬回来用同一个办法：再乘一次 $\cos(30\pi t)$。$\cos^2\theta=\tfrac12+\tfrac12\cos2\theta$，所以

$$y(t)\cos(30\pi t)=\tfrac12x(t)+\tfrac12x(t)\cos(60\pi t)\qquad\longleftrightarrow\qquad\tfrac12X(f)+\tfrac14X(f-30)+\tfrac14X(f+30)$$

中间一份是 $\tfrac12X(f)$，另外两份在 $\pm30$ Hz 附近（26 到 34 Hz）。用 gain 为 2、cutoff 在 4 和 26 Hz 之间的 lowpass filter，取回 $X(f)$。

:::edge Carrier frequency 要大于 bandwidth
搬到 $+f_c$ 的那一份占 $f_c-B$ 到 $f_c+B$，搬到 $-f_c$ 的占 $-f_c-B$ 到 $-f_c+B$。$f_c<B$ 时两份在 0 附近 overlap，和 aliasing 一样分不开。这道题 $15>4$，没有问题。
:::

### Bandpass signal 的 sampling

现在问：对 $y(t)$ 做 sampling，最低要多快。

:::wrong 最高 frequency 是 19 Hz，所以至少要 38 Hz
$f_s>2f_{\max}$ 是从“$X(f)$ 占满 $-B$ 到 $B$”推出来的，它对 bandpass signal 仍然够用，但太浪费。$Y(f)$ 在 $-11$ 到 11 Hz 之间是空的，replica 可以落进这些空隙里。真正要满足的只是“replica 之间不 overlap”。
:::

:::wrong Bandwidth 是 8 Hz，所以任何高于 16 Hz 的 sampling rate 都行
这是从上一个错误矫枉过正。两个 band 各宽 8 Hz，每隔 $f_s$ 要放下一正一负两个 band，$f_s\ge16$ 是必要的，但不充分。取 $f_s=17$：negative band $[-19,-11]$ 向右搬 $2\times17=34$，落在 $[15,23]$，和 positive band $[11,19]$ 在 15 到 19 Hz 之间叠在一起。叠上来的还是左右颠倒的一份：real signal 有 $Y(-f)=Y(f)^*$，搬过来之后 $f$ 处的值是 $Y(f-34)=Y(34-f)^*$，原来 19 Hz 处的内容落在 15 Hz。Replica 要恰好落进空隙，或者恰好和自己重合（后面一小节），对 $f_s$ 有要求。
:::

把这个要求推出来。设 positive band 是 $[f_L,f_H]$，bandwidth $B=f_H-f_L$，negative band 是 $[-f_H,-f_L]$。Positive band 自己的各个 replica 相距 $f_s\ge B$，互不相碰；要防的是 negative band 的 replica 压到 positive band 上。Negative band 向右搬 $kf_s$ 之后占据

$$[\,kf_s-f_H,\ kf_s-f_L\,]$$

$k$ 每加 1，它向右挪 $f_s$。Positive band 必须正好夹在相邻的两个之间：第 $n-1$ 个整个在它左边，第 $n$ 个整个在它右边。

$$(n-1)f_s-f_L\le f_L\qquad\text{且}\qquad nf_s-f_H\ge f_H$$

$$\frac{2f_H}{n}\le f_s\le\frac{2f_L}{n-1}$$

这个区间不是空的，需要 $\dfrac{2f_H}{n}\le\dfrac{2f_L}{n-1}$，即 $(n-1)f_H\le nf_L$，即 $n\le\dfrac{f_H}{f_H-f_L}$。所以 $n$ 可以取 $1,2,\dots,\Big\lfloor\dfrac{f_H}{B}\Big\rfloor$，每个 $n$ 给出一段允许的 $f_s$，$n$ 越大 $f_s$ 越低。$n=1$ 时右边没有限制，就是普通的 $f_s\ge2f_H$。

:::exam 第 6 题 (c)(d)
$f_L=11$，$f_H=19$，$B=8$，$\lfloor19/8\rfloor=2$。

- $n=1$：$f_s\ge38$，就是普通的 Nyquist 条件。
- $n=2$：$\dfrac{2\times19}{2}\le f_s\le\dfrac{2\times11}{1}$，即 $19\le f_s\le22$。

所以在“replica 互不重叠”这一类 sampling rate 里，最低的是 19 Hz。Reconstruction 用 passband 为 $11\le|f|\le19$ 的 ideal bandpass filter，gain 为 $1/f_s$，把原来那两个 band 取出来。18 Hz 不在任何一个区间里。

这一页原稿对着卷子写的答案是 19 Hz。下面“replica 完全重合”一小节还有一类 sampling rate，对这道题给出更低的 10 Hz；题面有没有限定 replica 不许重叠，这次修订没有重新读到卷子，核对不了，答题时按题面措辞选用哪一类。
:::

::fig[ee2023-sampling] 深色是原来的两个 band，浅色是 sampling 产生的 replica。$f_s=19$ 时 negative band 的 replica 落在 $[0,8]$ 和 $[19,27]$，正好把 positive band $[11,19]$ 夹在中间。$f_s=18$ 时它们落在 $[-1,7]$ 和 $[17,25]$，后一个和 positive band 在 17 到 19 Hz 之间叠在一起；在 0 附近和 $-19$ 到 $-17$ Hz 也各有一处。第三行是后面“Replica 完全重合”一小节的 $f_s=10$：每个位置上叠着两份（上下各画一层），两份内容相同。

把图里的数代进不等式：$f_s=19$，$n=2$，$(n-1)f_s-f_L=8\le11$，$nf_s-f_H=19\ge19$，两个都满足，第二个恰好取等号。$f_s=18$，$nf_s-f_H=17<19$，不满足。$f_s=20$ 在区间中间，replica 落在 $[1,9]$ 和 $[21,29]$，两边各留 2 Hz 的空隙。

:::edge 恰好等于临界值
$f_s=19$ 时 replica 只是首尾相接，band 边缘的那一个 frequency 上会碰到一起。这道题的 spectrum 在边缘处正好是 0（$X(\pm4)=10\cos\tfrac\pi2=0$），所以没有问题。如果 spectrum 在边缘不为零，实际应用里要留一点余量，例如取 20 Hz。
:::

### Replica 完全重合

上面的推导要求 negative band 的 replica 整个落在 positive band 的旁边。还有一种情形：它不偏不倚地落在 positive band 上，两份完全重合。

Band 的中心记作 $f_c=\frac{f_L+f_H}{2}$，这道题是 15 Hz。Negative band 的中心是 $-f_c$，向右搬 $kf_s$ 之后中心在 $kf_s-f_c$。让它等于 $f_c$：

$$f_s=\frac{2f_c}{k}$$

重合本身不一定是坏事，要看叠上来的内容。$y(t)=x(t)\cos(2\pi f_ct)$ 的 spectrum 是 $\tfrac12X(f-f_c)+\tfrac12X(f+f_c)$：positive band 那一份是 $\tfrac12X(f-f_c)$，negative band 那一份是 $\tfrac12X(f+f_c)$，后者向右搬 $kf_s=2f_c$ 变成 $\tfrac12X(f+f_c-2f_c)=\tfrac12X(f-f_c)$，和 positive band 一模一样。两份相加只是 height 加倍，没有混进别的内容，reconstruction filter 的 gain 多除以 2 就行。

还要防这一对和别的 replica 相碰。Positive band 的 replica 中心在 $f_c+mf_s$；negative band 的在 $-f_c+mf_s=f_c+(m-k)f_s$，也落在同一组位置上。所以 sampling 之后所有 band 的中心正好相距 $f_s$，每个宽 $B$，不碰的条件是 $f_s\ge B$，即 $k\le\dfrac{2f_c}{B}$。

对这道题，$\dfrac{2f_c}{B}=\dfrac{30}{8}=3.75$，$k=1,2,3$，$f_s=30$、15、10 Hz。取 $f_s=10$：band 的中心在 $\dots,-5,5,15,25,\dots$，每个占 $\pm4$ Hz，相邻两个之间空 2 Hz；positive band $[11,19]$ 上叠着它自己和 negative band 搬过来的一份（$k=3$，$-19+30=11$ 到 $-11+30=19$），在 $[11,19]$ 上 $X_s(f)=10\times2\times\tfrac12X(f-15)$。用 passband 为 $11\le|f|\le19$、gain 为 $\dfrac{1}{2f_s}=\dfrac{1}{20}$ 的 bandpass filter，取回 $Y(f)=\tfrac12X(f-15)$。18 Hz 不是 $30/k$，也不在这一类里。

这一类只对“band 关于 $f_c$ 对称”的 signal 成立。前面的 wrong 里已经看到，real signal 的 negative band 搬过来时是左右颠倒的一份，$f$ 处的值是 $Y(2f_c-f)^*$。它等于 $Y(f)$，要求 band 的内容关于 $f_c$ conjugate symmetric；$x(t)\cos(2\pi f_ct)$ 满足（$Y(2f_c-f)^*=\tfrac12X(f_c-f)^*=\tfrac12X(f-f_c)=Y(f)$，用了 $x$ 是 real），一般的 bandpass signal 不满足。

两类条件可以合起来写成课程讲义（据 CG2023 学生 cheat-sheet 里抄下的形式）的样子。代入 $f_H=f_c+\tfrac B2$、$f_L=f_c-\tfrac B2$，再令 $n=k+1$，上面的区间 $\dfrac{2f_H}{n}\le f_s\le\dfrac{2f_L}{n-1}$ 变成

$$\frac{2f_c+B}{k+1}\le f_s\le\frac{2f_c-B}{k},\qquad k=1,2,\dots,\Big\lfloor\frac{2f_c-B}{2B}\Big\rfloor$$

（$n\le\frac{f_H}{B}$ 即 $k+1\le\frac{f_c+B/2}{B}$，即 $k\le\frac{2f_c-B}{2B}$。）这是 replica 互不重叠的一类；replica 完全重合的一类是 $f_s=\dfrac{2f_c}{k}$，$k=1,\dots,\big\lfloor\frac{2f_c}{B}\big\rfloor$。这道题 $\lfloor\frac{22}{16}\rfloor=1$，只有 $k=1$：$19\le f_s\le22$，和上面一致。

:::back
Sampling 的推导用了[第 2 站](#fs)的 Fourier series（impulse train 的 coefficient）和[第 3 站](#ft)的 frequency shift property、duality；modulation 是 frequency shift property 的直接应用。

## 综合走读：第 5 题从头到尾

第 5 题 20 分，把第 4、5、6 站连在一起，适合检查三站是否真的通了。

**读 system。** $H_1(s)=\dfrac{40}{s^2+40s+2000}$。先不动笔，看 denominator：$\omega_n=\sqrt{2000}\approx44.7$，$\zeta=\dfrac{40}{2\times44.7}\approx0.447$。Underdamped，所以 impulse response 一定是边 oscillate 边 decay 的，magnitude plot 在 44.7 之前一点会鼓起一个小 peak。先有这个预期，后面每一步都可以拿它核对。

**(a) Impulse response。** Complete the square 得 $(s+20)^2+40^2$，查表得 $h(t)=e^{-20t}\sin(40t)\,u(t)$。核对：decay rate 20 等于 $\zeta\omega_n=0.447\times44.7$，oscillation frequency 40 等于 $\omega_n\sqrt{1-\zeta^2}=44.7\times0.894$，pole 在 $-20\pm j40$。

**(b) Differential equation。** $y''+40y'+2000y=40x$。核对：令所有 derivative 为零，$2000y=40x$，DC gain 是 0.02，等于 $H_1(0)$。

**(c) Cascade 之后的 Bode plot。** 第二个 system $H_2=\dfrac{1000\,s}{s+1}$ 是 highpass：low frequency 时近似 $1000s$，high frequency 时趋于 constant 1000。Cascade 的 transfer function 是两者之积（$Y=H_2\,(H_1X)$）。标准形式、三段 slope 和 phase 的走向见第 6 站。核对：$H_1$ 是 lowpass，$H_2$ 是 highpass，乘起来应当是 bandpass，和画出的形状一致；平台的高度是 $H_2$ 在 high frequency 的 1000 乘 $H_1$ 在 low frequency 的 0.02，$20\log_{10}(1000\times0.02)=20\log_{10}20\approx26$ dB，也对得上。

三问各自都不难。这道题检查的是能不能在三种表示之间来回核对：pole 的位置、time domain 的 waveform、frequency response，说的是同一个 system。
