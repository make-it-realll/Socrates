先看四次失败。每一次的设定都很小，每一次直觉给出的做法都走不通。

**第一次。** 一个 agent 在 state A，可以每步拿 1 分原地不动，也可以先拿 0 分去 state B，然后每步拿 2 分。两种做法拿到的 reward 加起来都是 infinity，“哪个更好”这个问题连定义都没有。

**第二次。** 三台 slot machine，中奖 probability 是 0.3、0.5、0.7，你不知道哪台是哪台。每台先试一次，都没中；再试第一台，中了。从此第一台的 sample mean 是正的，另外两台是 0，“总选 sample mean 最大的”这个规则会让你永远守着最差的那一台。

::fig[cs4246-greedy] 动图，按 greedy 规则一次次拉。看第 4 次之后：第一台中过一次，sample mean 停在 0 以上，另外两台各只试过一次、mean 是 0，所以每一次都轮不到它们，哪怕 machine 3 的真实 p 是 0.7。

**第三次。** 两个 state 共用一个 parameter $w$，value 分别是 $w$ 和 $2w$，true value 都是 0。用最标准的 TD update 只更新第一个 state，$w$ 每一步乘 1.098，越学越离谱。

::fig[cs4246-tdblow] 动图，$\gamma=0.99$、$\alpha=0.1$，从 $w=10$ 出发。看左边：每次 update 把 $s_1$ 的柱子往虚线（TD target）拉，可虚线是 $2\gamma w$，柱子一涨它涨得更多，永远追不上。第 7 站细讲。

**第四次。** 一个两 action 的问题，把所有 reward 都加上 100，optimal policy 当然不变。但同样的 learning rate 下，policy gradient 在 20 个 random seed 里有 11 个最后几乎只选那个差的 action，另外 9 个几乎只选好的，学习变成了掷硬币。

这门课把这四件事放进同一个框架。框架的核心是一个 equation：一个 state 的 value 等于“走一步拿到的 reward”加上“下一个 state 的 value 打个折”。整门课就是在越来越弱的假设下求解它：

| 站 | 什么是未知的或太大的 | 用什么顶替 |
|---|---|---|
| 第 1 站 | 一切都是 deterministic 的，只要到达一个 goal，但 state 由很多 fact 拼成，个数按 exponential 增长 | 用 action schema 描述 transition，用 search 加 heuristic 找 plan |
| 第 2、3 站 | 什么都知道，只是要解一个 nonlinear equation | Iteration，靠 contraction 保证 converge |
| 第 4 站 | State 看不见 | 对 state 的 probability distribution（belief） |
| 第 5 站 | Reward 的 distribution 不知道，只有一个 state | 给不确定的 action 加 bonus |
| 第 6 站 | Transition 和 reward 都不知道 | 用 sample 代替 expectation |
| 第 7 站 | State 太多，table 存不下 | 用 parameter 化的 function，代价是可能 diverge |
| 第 8 站 | Action 连续，或者想要 stochastic policy | 直接对 policy 求 gradient |
| 第 9 站 | 全局的 policy 算不出来 | 只为当前这个 state 做 search |

第一次失败在第 2 站解决，第二次在第 5 站，第三次在第 7 站，第四次在第 8 站。

### 一部电梯，状态多到列不出来

Assignment 1 的设定：一栋楼有若干层，一部电梯，门可以开关，乘客在某层等着要去另一层。电梯只能在关门时上下一层，乘客只能在开门时进出。最小的例子是 handout 里的 `config_1`：3 层（level0 到 level2），电梯在 level0，一个乘客 p1 在 level2，要去 level0。这里没有 randomness，也没有 reward，只要找到一串 action 让 p1 到达 level0。

第 2、3 站的办法是把每个 state 编号，给出 transition table。这里先数一数有多少个 state。Handout 里稍大的 `config_3` 是 5 层、电梯在 level2、4 个乘客，request 是 $(0,4)$、$(4,1)$、$(2,2)$、$(4,0)$。一个 state 要说清电梯在哪一层（5 种）、门开着还是关着（2 种）、每个乘客在 5 层中的某一层还是在电梯里，而第一版 model 里电梯一次只装一个人：

$$5\times2\times\big(5^4+4\times5^3\big)=10\times1125=11250$$

括号里 $5^4$ 是没人在电梯里的情形（4 个人各在 5 层之一），$4\times5^3$ 是恰有一人在电梯里的情形（先选是谁，其余 3 人各在 5 层之一）。

一般地，$n$ 层、$k$ 个乘客是 $2n\,(n^k+k\,n^{k-1})$。Assignment 1 的 bonus 题到 20 层、18 个乘客，这个数是 $2\times20\times(20^{18}+18\times20^{17})\approx2.0\times10^{25}$。Transition table 写不出来，但每一种 transition 都是同一条规则：“关着门的电梯可以上一层”对每一层都一样。

### 把 state 写成一组 fact

PDDL（Planning Domain Definition Language）的做法是 factored representation：state 是一组为真的 ground atom，没写出来的 atom 一律为假（closed-world assumption，也叫 database semantics）。Assignment 1 第一版 model 的 predicate 是 `elevator_at(?l)`、`person_at(?p, ?l)`、`person_in_elevator(?p)`、`elevator_empty`、`door_open(?l)`，以及两个不变的 `adjacent_up`、`adjacent_down`。`config_1` 的初始 state 是

$$\begin{aligned}s_0=\{&\texttt{elevator\_at(level0)},\ \texttt{elevator\_empty},\\&\texttt{person\_at(p1, level2)}\}\end{aligned}$$

（再加上 `adjacent_up(level0, level1)` 等四个不变的 fact，下面省略。）Goal 是一组 atom 的 conjunction，这里是 $g=\{\texttt{person\_at(p1, level0)}\}$；state $s$ 满足 goal 当且仅当 $g\subseteq s$。

Transition 用 action schema 描述：一个带变量的 action，写明 precondition 和 effect。Handout 在 capacity 版本的 domain 里直接给出了 `move_up`：

```lisp
(:action move_up
  :parameters (?from ?to - level)
  :precondition (and (elevator_at ?from) (adjacent_up ?from ?to)
                     (not (door_open ?from)))
  :effect (and (not (elevator_at ?from)) (elevator_at ?to)))
```

把 precondition 分成正的 $\text{PRE}^+(a)$ 和取反的 $\text{PRE}^-(a)$，effect 分成加入的 $\text{ADD}(a)$ 和删去的 $\text{DEL}(a)$。Action $a$ 在 $s$ 上 applicable 当且仅当 $\text{PRE}^+(a)\subseteq s$ 且 $\text{PRE}^-(a)\cap s=\varnothing$，结果是

$$\text{RESULT}(s,a)=\big(s-\text{DEL}(a)\big)\cup\text{ADD}(a)$$

用一次。把 `?from`、`?to` 代成 level0、level1，得到 ground action `move_up(level0, level1)`。在 $s_0$ 上：`elevator_at(level0)` 在 $s_0$ 里，`adjacent_up(level0, level1)` 是不变的 fact，`door_open(level0)` 不在 $s_0$ 里，所以 applicable。删去 `elevator_at(level0)`，加入 `elevator_at(level1)`：

$$\begin{aligned}s_1=\{&\texttt{elevator\_at(level1)},\ \texttt{elevator\_empty},\\&\texttt{person\_at(p1, level2)}\}\end{aligned}$$

Schema 写在 domain 文件里，和具体有几层、几个人无关；objects、初始 state 和 goal 写在 problem 文件里。Assignment 1 要写的就是这两部分：domain 的 precondition 和 effect，以及一个从 config 生成 problem 文件的 Python function。一个 domain 配上不同的 problem，对每栋楼都能用。`config_1` 有 3 层、1 个人，6 个 schema 代进所有 object，再去掉 adjacent 关系不成立的组合，剩下 16 个 ground action：4 个 move（上下各 2）、3 个 `open_door`、3 个 `close_door`、3 个 `load`、3 个 `unload`。

### Forward search：在 state space 上找 shortest path

每个 action 算 1 步，要找最短的 plan。记 $h^*(s)$ 为从 $s$ 到满足 goal 的最少 action 数，它满足

$$h^*(s)=\begin{cases}0,&g\subseteq s\\ \min_{a\text{ applicable}}\big[1+h^*(\text{RESULT}(s,a))\big],&\text{否则}\end{cases}$$

这是第 2 站 Bellman optimality equation 的特例：transition 是 deterministic 的，每步 cost 是 1，没有 discount。在 deterministic、cost 相同的情况下，从 $s_0$ 做 breadth-first search（BFS）就按 $h^*$ 由小到大展开，第一次碰到 goal 时的深度就是 $h^*(s_0)$。这叫 forward（progression）search：从初始 state 出发，每一步对当前 state 找出所有 applicable 的 ground action，用 RESULT 生成下一层。

`config_1` 上 BFS 展开 14 个 state 后找到 9 步的 plan，就是下图右边列出的 9 步。

::fig[cs4246-liftplan] 动图，`config_1` 的 9 步 plan，左边是电梯，中间是 plan（当前一步高亮），右边是这一步之后 state 里为真的 fact。看第 5 步 `close_door(level2)`：它不让 goal 更近，但第 6 步 `move_down` 要求门关着。

可达的 state 一共 24 个（$2\times3\times(3+1)$），BFS 看了其中 14 个。换成 `config_3`，可达 state 有 11250 个，BFS 要展开 4111 个才找到 26 步的 plan。层数和人数再多一点，盲目的 search 就走不动了。（这些数是用这一页自己写的 STRIPS search 程序数的，规则按 handout 对六个 action 的文字说明；不是课程的 planner。）

### Heuristic：先解一个更容易的问题

A* search 按 $f(s)=\text{已走的步数}+h(s)$ 的顺序展开。只要 $h$ 是 admissible 的，即对每个 $s$ 都有 $h(s)\le h^*(s)$，A* 找到的 plan 仍然最短。好的 $h$ 来自把问题放宽（relaxation）：放宽后的问题更容易解，而原问题的每个 plan 在放宽后的问题里仍然是 plan，所以放宽后的最优步数不会超过 $h^*$。

**Ignore delete lists。** 去掉所有 action 的 DEL，也不再检查 $\text{PRE}^-$。Fact 只增不减。在 `config_1` 的 $s_0$ 上，放宽后的最短 plan 是

`move_up(level0, level1)`、`move_up(level1, level2)`、`open_door(level2)`、`load(p1, level2)`、`open_door(level0)`、`unload(p1, level0)`

共 6 步。电梯上到 level2 之后 `elevator_at(level0)` 没有被删，电梯同时“在” level0 和 level2，所以不用关门、不用下楼，直接在 level0 开门放人。这个最优放宽步数记作 $h^+(s_0)=6$，确实不超过 $h^*(s_0)=9$。

为什么一般成立：设 $a_1,\dots,a_m$ 是原问题里一个合法的 plan，$s_i$ 是原问题里第 $i$ 步之后的 state，$s_i^+$ 是放宽后执行同样 action 得到的 state。$s_0^+=s_0$。若 $s_{i-1}\subseteq s_{i-1}^+$，那么 $a_i$ 的 $\text{PRE}^+$ 在 $s_{i-1}$ 里成立，也就在 $s_{i-1}^+$ 里成立，放宽问题又不查 $\text{PRE}^-$，所以 $a_i$ 在放宽问题里 applicable；而 $s_i=(s_{i-1}-\text{DEL})\cup\text{ADD}\subseteq s_{i-1}^+\cup\text{ADD}=s_i^+$。归纳下去，$g\subseteq s_m\subseteq s_m^+$，原 plan 也是放宽问题的 plan，所以 $h^+\le h^*$。

**Ignore preconditions。** 所有 action 在任何 state 都 applicable。Goal 只有一个 atom `person_at(p1, level0)`，`unload(p1, level0)` 一步就把它加进来，$h=1$。同样 admissible，但几乎没有信息。

在 `config_3` 上比一比展开的 state 数（三种都找到 26 步的 plan）：

| search | 展开的 state |
|---|---|
| BFS（相当于 $h=0$） | 4111 |
| A*，$h$ = 还没满足的 goal atom 个数 | 2446 |
| A*，$h=h^+$ | 279 |

第二行的 $h$ 在这个 domain 里 admissible，因为每个 action 最多加入一个 goal atom；一般的 domain 里一个 action 可能同时满足几个 goal，它就不再 admissible。$h^+$ 本身求最优也是 NP-hard 的（这一点是这一页凭知识补充的，没有在课程材料里读到），实际的 planner 用 greedy 的办法找一个放宽后的 plan，拿它的长度当 heuristic，这样快，但不再保证 admissible。

### Backward search：从 goal 往回推

也可以从 goal 出发往回找。一个 action $a$ 对 goal $g$ 是 relevant 的，当且仅当它的 ADD 里有 $g$ 的某个 atom，而且它的 DEL 不删 $g$ 里的任何 atom。从 $g$ regress 过 $a$ 得到新的子 goal

$$g'=\big(g-\text{ADD}(a)\big)\cup\text{PRE}^+(a)$$

`config_1` 里 $g=\{\texttt{person\_at(p1, level0)}\}$，relevant 的只有 `unload(p1, level0)`。按 handout 对 unload 的说明（电梯在这一层、乘客在电梯里、门开着），

$$\begin{aligned}g'=\{&\texttt{elevator\_at(level0)},\\&\texttt{person\_in\_elevator(p1)},\\&\texttt{door\_open(level0)}\}\end{aligned}$$

Backward search 只考虑和 goal 有关的 action，branching factor 往往比 forward 小；代价是 $g'$ 描述的是一组 state，不是一个 state。

:::wrong Planner 找到了 plan，domain 和 problem 就写对了
Handout 专门提醒过：planner 成功不能当正确性的证明。拿 `config_1` 试一下：把两个 move action 的 precondition 里 `(not (door_open ?from))` 漏掉，BFS 仍然很快返回一个 plan，而且只有 8 步，比正确的 9 步还短。它把第 5 步 `close_door(level2)` 省了，电梯开着门下了两层。Planner 只按 action 个数找最短，漏掉一个 precondition 就等于多给了它一条捷径，它会优先用这条捷径。检查 model 要逐步追踪 plan 里每个 state，看有没有违反你心里的 invariant（门开着时电梯不动、一个人不会同时在两个地方），而不是只看有没有 plan。
:::

### HTN：把“怎么做”写进 domain

Assignment 1 的 Problem 2 把问题换了：乘客有 deadline 和 utility，电梯有 capacity，目标是总 utility 最大，不再是 action 最少。这时直接在 primitive action 上 search 有两个麻烦。第一，plan 的结构其实是固定的：接一个人永远是“开到那层、开门、进、关门”，送一个人永远是“开到那层、开门、出、关门”，planner 却要在几十万个 state 里把这个结构重新找出来。第二，planner 的 objective 是步数，表达不了“晚到几分钟扣多少分”。

Hierarchical Task Network（HTN）planning 把这类结构直接写进 domain。除了 primitive action，还有 abstract task；每个 abstract task 有一个或几个 method，每个 method 有自己的 precondition，并把 task 拆成一串 subtask。Planner 从一个初始 task network 出发，反复把 abstract task 按某个 applicable 的 method 拆开，直到全是 primitive action，而且这串 primitive action 在 state 上依次 applicable。

::fig[cs4246-htn] Assignment 1 的 HTN 怎样把一个乘客的接送拆成 primitive action。每个 abstract task 有两个 method，按“电梯是否已经在那一层”选一个。

Handout 固定了这个结构：5 个 primitive action（`move_elevator`、`load`、`unload`、`open_door`、`close_door`，其中 `move_elevator` 一次可以跨好几层），3 个 abstract task（`pickup_person`、`deliver_person`、`confirm_reached`），5 个 method。`pickup_person` 在电梯不在那一层时拆成 move、open、load、close，已经在那一层时拆成 open、load、close；`deliver_person` 同理；`confirm_reached` 给一开始就在目的地的乘客用，拆成空的。初始 task network 是一串全序的 task：按 service order 每 capacity 个人一批，一批之内先依次接完，再按同样的顺序依次送完。

这样一来，task network 一旦定下，plan 几乎就定了，planner 只需要在每个 task 上挑 method。真正的决定挪到了 task network 外面：**service order**。

### 同一个 HTN，不同的 order

Handout 给 utility 的计算规则：从 $a$ 层到 $b$ 层花 $|a-b|$ 个时间单位，开门、关门、进、出各花 1；一个乘客的 completion time 记在他出电梯的那一刻；

$$\text{lateness}=\max(0,\ \text{completion}-\text{deadline}),\qquad\text{utility}=\max(0,\ \text{base}-\text{penalty}\times\text{lateness})$$

用 handout notebook 里的例子：5 层，电梯在 2 层，capacity 2。乘客 0 从 0 层到 4 层，deadline 16，base 100，penalty 8；乘客 1 从 3 层到 1 层，deadline 12，base 80，penalty 12；乘客 2 本来就在目的地 2 层，completion 记为 0，拿满 30。两个活动乘客正好一批，只有两种 order。

|---|---|---|---|---|---|---|

| 送 1 | 4→1（3），开、出（2） | **20** | | 送 0 | 1→4（3），开、出（2） | **19** |

### 两个 policy 比不出好坏

把第一次失败写清楚。这一站和后面几站都用这个例子。

::fig[cs4246-twostate] 两个 state 的 MDP。在 A 可以 stay 或 go；在 B 只能继续，每步拿 2，偶尔被送回 A。

这里一共只有两个 deterministic policy：在 A 选 stay（记作 $\pi_{\text{stay}}$），或者在 A 选 go（记作 $\pi_{\text{go}}$）。从 A 出发，$\pi_{\text{stay}}$ 的 reward sequence 是 $1,1,1,\dots$；$\pi_{\text{go}}$ 的是 $0,2,2,\dots$，偶尔回到 A 又是一个 0。两个 sum 都是 infinity。

要比较，必须让 infinite sum 变成有限的数。办法是给第 $k$ 步之后的 reward 乘上 $\gamma^k$，$0\le\gamma<1$，定义 return

$$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}$$

只要每步 reward 的 absolute value 不超过 $r_{\max}$，就有 $|G_t|\le r_{\max}(1+\gamma+\gamma^2+\cdots)=\dfrac{r_{\max}}{1-\gamma}$。用一次：$\pi_{\text{stay}}$ 从 A 出发的 return 是 $1+0.9+0.81+\cdots=\dfrac{1}{1-0.9}=10$。

$\gamma$ 还有一个不靠“打折”这种说法的解释。设想每走一步，过程以 probability $1-\gamma$ 突然结束。第 $k$ 步的 reward 要被拿到，前 $k$ 步都不能结束，probability 是 $\gamma^k$，所以拿到的 reward 总和的 expectation 正好是 $\sum_k\gamma^k\,\mathbb E[R_{t+k+1}]$。Discounted return 就是一个“随时可能结束”的问题的 undiscounted return。

### State 必须是 Markov 的

后面的一切都依赖一个假设：下一步的 state 和 reward 只取决于当前的 state 和 action，和更早的 history 无关，

$$P(S_{t+1}=s',R_{t+1}=r\mid S_t,A_t,S_{t-1},A_{t-1},\dots)=P(S_{t+1}=s',R_{t+1}=r\mid S_t,A_t)$$

这叫 Markov property。满足它的 state、action、transition probability $P(s'\mid s,a)$、reward、discount $\gamma$ 合起来叫 Markov decision process（MDP）。它的作用是：从某个 state 出发将来会发生什么，只取决于这个 state，所以“这个 state 有多好”是一个只以 state 为 argument 的 function。如果 state 不是 Markov 的，同一个 state 背后的未来可以完全不同，这个 function 就没有定义。第 4 站专门处理这种情况。

Reward 的写法有 $R(s)$、$R(s,a)$、$R(s,a,s')$ 几种。它们可以互相转换：对 $s'$ 取 expectation，$r(s,a)=\sum_{s'}P(s'\mid s,a)R(s,a,s')$。下面统一用 $r(s,a)$ 表示在 $s$ 做 $a$ 的 expected reward。

:::note 2020 年的 NUS 笔记用的是 AIMA 的记号
2020 年的学生笔记和 cheatsheet 用 $U(s)$ 表示 value（叫 utility），transition 写作 $T(s,a,s')$，reward 多用只看 state 的 $R(s)$，Bellman optimality equation 写成 $U(s)=R(s)+\gamma\max_a\sum_{s'}T(s,a,s')\,U(s')$。它和下面的写法是同一件事：取 $r(s,a)=R(s)$ 对每个 $a$ 都一样，$R(s)$ 就可以从 max 里提出来。笔记还写了反方向的换算：$R(s,a,s')$ 形式的 reward 可以引入一个只表示“刚在 $s$ 做完 $a$”的 post-state 来改写成 $R(s)$ 的形式。AY25/26 的 Assignment 2 用的是 $V$、$Q$、$\pi$ 这一套。考试用哪套记号，以当学期讲义为准。
:::

### Value function 与 Bellman expectation equation

固定一个 policy $\pi$（在每个 state 选 action 的规则，可以是 random 的，记作 $\pi(a\mid s)$），定义它的 value function

$$v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$$

直接按定义算要对无穷多条 trajectory 求 expectation。办法是把 return 拆成第一步和其余部分。由定义，

$$G_t=R_{t+1}+\gamma\big(R_{t+2}+\gamma R_{t+3}+\cdots\big)=R_{t+1}+\gamma G_{t+1}$$

两边在 $S_t=s$ 的条件下取 expectation。第一项是 $\sum_a\pi(a\mid s)\,r(s,a)$。第二项先对下一个 state $S_{t+1}=s'$ 分情况，再用 Markov property：已知 $S_{t+1}=s'$ 时，$G_{t+1}$ 的 distribution 和 $S_t$ 是什么无关，所以 $\mathbb E[G_{t+1}\mid S_t=s,S_{t+1}=s']=v_\pi(s')$。合起来：

$$v_\pi(s)=\sum_a\pi(a\mid s)\Big[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\,v_\pi(s')\Big]$$

这叫 Bellman expectation equation。每个 state 一个 equation，unknown 就是各个 state 的 value，而且是 linear 的。

对 $\pi_{\text{go}}$、$\gamma=0.9$ 写出来：

$$\begin{aligned}v(A)&=0+0.9\,v(B)\\v(B)&=2+0.9\big(0.1\,v(A)+0.9\,v(B)\big)\end{aligned}$$

把第一式代入第二式：$v(B)=2+0.081\,v(B)+0.81\,v(B)$，即 $0.109\,v(B)=2$，所以 $v(B)=18.349$，$v(A)=0.9\times18.349=16.514$。

写成 matrix，$v_\pi=r_\pi+\gamma P_\pi v_\pi$，其中 $P_\pi$ 的 row $s$ 是在 $s$ 按 $\pi$ 行动时下一个 state 的 distribution：

$$\begin{pmatrix}v(A)\\v(B)\end{pmatrix}=\begin{pmatrix}0\\2\end{pmatrix}+0.9\begin{pmatrix}0&1\\0.1&0.9\end{pmatrix}\begin{pmatrix}v(A)\\v(B)\end{pmatrix}\quad\Longrightarrow\quad v_\pi=(I-\gamma P_\pi)^{-1}r_\pi$$

$I-\gamma P_\pi$ 一定 invertible。$P_\pi x$ 的每个 entry 是 $x$ 的 entry 的 weighted average（每个 row 是 non-negative 的、加起来是 1），所以 $\|P_\pi x\|_\infty\le\|x\|_\infty$。若 $(I-\gamma P_\pi)x=0$，则 $x=\gamma P_\pi x$，$\|x\|_\infty\le\gamma\|x\|_\infty$，只能 $x=0$。

同样的办法算 $\pi_{\text{stay}}$：$v(A)=1+0.9\,v(A)$，得 $v(A)=10$；$v(B)=2+0.9(0.1\times10+0.9\,v(B))$，得 $0.19\,v(B)=2.9$，$v(B)=15.263$。两个 state 上 $\pi_{\text{go}}$ 都更好。

和 $v_\pi$ 配套的是 action-value function：先在 $s$ 做 $a$，之后按 $\pi$ 走，

$$q_\pi(s,a)=r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\,v_\pi(s')$$

### Optimal value 与 Bellman optimality equation

定义 $v^*(s)=\max_\pi v_\pi(s)$。问题是：每个 state 上取 max 的可能是不同的 policy，有没有一个 policy 在所有 state 上同时达到它？怎么找到它？

先猜它应该满足什么。在 $s$ 选 action 时，如果之后一直 optimal，选 $a$ 的价值是 $r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)v^*(s')$，那就该选最大的那个：

$$v^*(s)=\max_a\Big[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\,v^*(s')\Big]$$

这叫 Bellman optimality equation。多了一个 max，它不再是 linear 的。

现在证明这个猜测给出的东西确实是 optimal。设 $v$ 是 Bellman optimality equation 的一个 solution（存在且唯一，第 3 站证明），$\pi$ 是对 $v$ greedy 的 policy，即在每个 $s$ 选让方括号最大的 $a$。要证两件事：$v_\pi=v$，以及任何 policy $\pi'$ 都有 $v_{\pi'}\le v$。两件事用的是同一个办法：把 equation 展开 $k$ 次。

**$\pi$ 达到 $v$。** 对 greedy 的 $\pi$，max 正好在 $\pi(s)$ 处取到，所以 $v(s)=r(s,\pi(s))+\gamma\,\mathbb E_\pi[v(S_1)\mid S_0=s]$。右边的 $v(S_1)$ 再用同一个 equation 换掉，得到

$$v(s)=\mathbb E_\pi\big[R_1+\gamma R_2\big]+\gamma^2\,\mathbb E_\pi[v(S_2)]$$

换 $k$ 次：

$$v(s)=\mathbb E_\pi\Big[\sum_{t=0}^{k-1}\gamma^tR_{t+1}\Big]+\gamma^k\,\mathbb E_\pi[v(S_k)]$$

最后一项的 absolute value 不超过 $\gamma^k\max_{s}|v(s)|$，$k\to\infty$ 时趋于 0，前一项趋于 $v_\pi(s)$。所以 $v=v_\pi$。

**没有 policy 超过 $v$。** 对任意 $\pi'$，它在 $s$ 选的 action 未必是 max，所以 $v(s)\ge r(s,\pi'(s))+\gamma\,\mathbb E_{\pi'}[v(S_1)]$。把右边的 $v(S_1)$ 也用这个 inequality 换掉，inequality 方向不变；换 $k$ 次再令 $k\to\infty$，得 $v(s)\ge v_{\pi'}(s)$。

两件事合起来：$v=v^*$，greedy policy 在每个 state 上同时 optimal。为什么只看一步就够了？因为 $v^*$ 已经把选完这一步之后的全部未来压缩进了一个数，一步 lookahead 用的是“之后 optimal 地走”的 value，所以眼前这一步的比较已经是全局的比较。前提是 $v^*$ 是对的；第 3 站会看到 value 有 error 时 greedy policy 会损失多少。

拿例子检验。$v^*=(16.514,\,18.349)$，在 A 比较两个 action：

$$q^*(A,\text{stay})=1+0.9\times16.514=15.862,\qquad q^*(A,\text{go})=0+0.9\times18.349=16.514$$

go 更大，greedy policy 就是 $\pi_{\text{go}}$；而且 $q^*(A,\text{go})$ 恰好等于 $v^*(A)$，equation 成立。

:::wrong $\gamma$ 只是让 infinite sum converge 的技术手段，取 0.9 还是 0.5 不影响答案
在这个例子里，$\gamma$ 决定了哪个 policy 是 optimal。一般地，$\pi_{\text{stay}}$ 在 A 的 value 是 $\dfrac{1}{1-\gamma}$。$\pi_{\text{go}}$ 的两个 equation 是 $v(A)=\gamma v(B)$、$v(B)=2+\gamma(0.1\,v(A)+0.9\,v(B))$，代入得 $v(B)\,(1-0.9\gamma-0.1\gamma^2)=2$。左边的 factor 可以分解成 $(1-\gamma)(1+0.1\gamma)$，所以

$$v_{\pi_{\text{go}}}(A)=\frac{2\gamma}{(1-\gamma)(1+0.1\gamma)}$$

和 $\dfrac1{1-\gamma}$ 比，go 更好当且仅当 $2\gamma>1+0.1\gamma$，即 $\gamma>\tfrac{10}{19}\approx0.526$。$\gamma=0.5$ 时，stay 的 value 是 2，go 的是 1.905，optimal policy 是 stay。$\gamma$ 是问题定义的一部分：它规定了将来的 reward 和眼前的 reward 怎么换算。
:::

:::edge $\gamma=1$ 什么时候可以
如果不管怎么走，episode 都以 probability 1 在有限步内结束（下一站的 gridworld 进入 $\pm1$ 的格子就结束），sum 本来就是有限的，可以取 $\gamma=1$。上面“展开 $k$ 次”的证明里，余项 $\gamma^k\mathbb E[v(S_k)]$ 这时靠“$S_k$ 已经是 terminal、value 为 0”趋于 0。
:::

Return、discount 的几种理由、Markov property、Bellman expectation equation 的 matrix 形式与 $(I-\gamma P)^{-1}$、optimality equation 的顺序，跟的是 [Silver 第 2 讲](https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-2-mdp.pdf)；那一讲用的是 Student MDP，这里换成了一个两个 state 的例子，好让每个 equation 都能手解。“greedy w.r.t. $v^*$ 为什么只需要一步”的说法来自 [Sutton & Barto 第 3.6 节](https://people.engr.tamu.edu/guni/csce421/files/RLbook2018.pdf)。“随时可能结束”的解释、$\gamma>10/19$ 的计算和展开 $k$ 次的两半证明是这一页自己写的。NUS 记号那一段来自 2020 年的[学生笔记](https://crazoter.github.io/My-Docs/docs/markdown/ai_planning)和 [cheatsheet](https://crazoter.github.io/My-Docs/docs/markdown/CS4246_summary)，只说明当年的写法，AY26/27 的讲义没有读到。

## [dp] Value iteration、policy iteration 与 contraction

:::skip
能证明 Bellman optimality operator 是 $\gamma$-contraction，并由此说出 value iteration 的 error bound 和停机条件；能做 policy iteration 并证明它每轮不变差，就可以去第 4 站。
:::

### Max 让 equation 解不出来

上一站的两个 state 只有两个 policy，逐个解 linear system 再比较就行了。一般地，$|S|$ 个 state、每个 state $|A|$ 个 action，deterministic policy 有 $|A|^{|S|}$ 个。下面的 gridworld 有 9 个非 terminal 的格子、4 个 action，就是 $4^9=262144$ 个。逐个试不可行；Bellman optimality equation 里的 max 又让它不能当 linear system 解。

办法是把 equation 当成一个 iteration。把 equation 右边看成一个把 vector 映到 vector 的 operator：

$$(T^*V)(s)=\max_a\Big[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\,V(s')\Big]$$

$v^*$ 就是满足 $T^*v^*=v^*$ 的那个 vector，叫 $T^*$ 的 fixed point。Value iteration 就是从 $V_0=0$ 出发反复做 $V_{k+1}=T^*V_k$。

### 为什么一定 converge：contraction

先证一个关于 max 的小事实：对任意两个 function $f,g$，

$$\big|\max_af(a)-\max_ag(a)\big|\le\max_a|f(a)-g(a)|$$

设 $f$ 在 $a_1$ 取 max，那么 $\max f-\max g\le f(a_1)-g(a_1)\le\max_a|f(a)-g(a)|$；交换 $f$、$g$ 得到另一个方向。

现在比较 $T^*$ 作用在两个任意 vector $U$、$V$ 上的结果。在每个 state $s$，两个 max 里的方括号只差 $\gamma\sum_{s'}P(s'\mid s,a)(U(s')-V(s'))$，所以

$$|(T^*U)(s)-(T^*V)(s)|\le\max_a\gamma\sum_{s'}P(s'\mid s,a)\,|U(s')-V(s')|\le\gamma\max_{s'}|U(s')-V(s')|$$

最后一步是因为 $P(\cdot\mid s,a)$ 加起来等于 1，weighted average 不超过最大值。对所有 $s$ 取 max：

$$\|T^*U-T^*V\|_\infty\le\gamma\,\|U-V\|_\infty$$

$T^*$ 把任意两个 vector 的距离至少缩小到 $\gamma$ 倍，这叫 $\gamma$-contraction。三个结论都从这一行出来。

**Fixed point 唯一。** 若 $U$、$V$ 都是 fixed point，$\|U-V\|_\infty=\|T^*U-T^*V\|_\infty\le\gamma\|U-V\|_\infty$，只能 $\|U-V\|_\infty=0$。

**Fixed point 存在。** 相邻两次 iterate 的距离 $\|V_{k+1}-V_k\|_\infty\le\gamma^k\|V_1-V_0\|_\infty$，加起来是一个 converge 的 geometric series，所以 $V_k$ 是 Cauchy sequence，在 $\mathbb R^{|S|}$ 里有 limit $V_\infty$。$T^*$ 是 continuous 的（contraction 就是 Lipschitz），在 $V_{k+1}=T^*V_k$ 两边取 limit 得 $V_\infty=T^*V_\infty$。

**Error 至少按 $\gamma^k$ 缩小。** 把 $v^*=T^*v^*$ 代进去：

$$\|V_k-v^*\|_\infty=\|T^*V_{k-1}-T^*v^*\|_\infty\le\gamma\|V_{k-1}-v^*\|_\infty\le\cdots\le\gamma^k\|V_0-v^*\|_\infty$$

同一个论证用在固定 policy 的 $T^\pi V=r_\pi+\gamma P_\pi V$ 上（没有 max，更简单），说明 iterative policy evaluation converge 到 $v_\pi$。

::fig[cs4246-vierr] 两个 MDP 上 value iteration 的 error。两个 state 的 MDP 每轮恰好乘 0.9，和 bound 重合；gridworld 比 bound 快得多。

两个 state 的 MDP 上，$\|V_0-v^*\|_\infty=18.349$，要 error 小于 0.01，bound 要求 $0.9^k\times18.349<0.01$，即 $k>\dfrac{\ln(0.01/18.349)}{\ln0.9}=71.3$。实际正好在第 72 轮第一次小于 0.01：这里的 bound 是 tight 的。

:::edge 有 terminal state 时比 $\gamma^k$ 快
Gridworld 只要 11 轮 error 就小于 0.01，bound 要 44 轮。原因在 error 的传播路径上：$V_k-v^*$ 每过一轮被乘上 $\gamma$ 和“留在非 terminal 格子里的 probability”。从 (3,3) 选 E，0.8 的 probability 直接进入 terminal，那部分 error 就再也传不回来。把 optimal policy 的 transition matrix 限制在 9 个非 terminal 格子上，它的 spectral radius 是 0.437，$0.9\times0.437=0.39$；图里后期每轮的比值在 0.41 左右，并且还在往 0.39 靠。两个 state 的 MDP 永远不会结束，没有 probability 漏出去，于是恰好是 0.9。
:::

### 什么时候停

真正运行时不知道 $v^*$，只能看到相邻两次 iterate 的差。用 triangle inequality 把未知的量换成看得见的量：

$$\|V_{k+1}-v^*\|_\infty\le\gamma\|V_k-v^*\|_\infty\le\gamma\big(\|V_k-V_{k+1}\|_\infty+\|V_{k+1}-v^*\|_\infty\big)$$

把含 $\|V_{k+1}-v^*\|_\infty$ 的两项移到同一边：

$$\|V_{k+1}-v^*\|_\infty\le\frac{\gamma}{1-\gamma}\,\|V_{k+1}-V_k\|_\infty$$

所以要保证 error 小于 $\epsilon$，只要等到 $\|V_{k+1}-V_k\|_\infty<\epsilon(1-\gamma)/\gamma$。$\gamma=0.9$、$\epsilon=0.01$ 时门槛是 0.00111。两个 state 的 MDP 在第 72 轮时 $\|V_{72}-V_{71}\|_\infty=0.00102$，右边算出 0.00917，实际 error 也是 0.00917。

:::wrong 要等 value converge 了，greedy policy 才是 optimal 的
Policy 只取决于各个 action 之间谁大，value 只需要把顺序排对。Gridworld 上，对 $V_9$ greedy 得到的 policy 已经和最终的完全一样，而这时 value 的 error 还有 0.022。反过来，value 的 error 较小也不保证 policy 对：$V_8$（error 0.036）读出的 policy 在 (2,1) 选 E，按 $v^*$ 算，E 是 0.4665，W 是 0.4787，两者只差 0.012，一点 error 就能把顺序颠倒；用这个 policy 实际走，(2,1) 的 value 比 optimal 低 0.016。所以 value iteration converge 前得到的 policy 可能已经是 optimal 的，也可能有小的损失；要的是 policy，就有理由换一个直接在 policy 上 iterate 的 algorithm。
:::

### Policy iteration

既然 policy 往往先稳定，就直接在 policy 上 iterate：

1. **Evaluation。** 对当前 $\pi$ 解 linear system，得到 $v_\pi$。
2. **Improvement。** 在每个 state 选让 $q_\pi(s,a)$ 最大的 action，得到新的 $\pi'$。
3. $\pi'=\pi$ 就停，否则回到第 1 步。

在两个 state 的 MDP 上，从 $\pi_{\text{stay}}$ 开始。上一站已经解出 $v_{\pi_{\text{stay}}}=(10,\ 15.263)$。在 A 比较：stay 是 $1+0.9\times10=10$，go 是 $0.9\times15.263=13.737$，换成 go。再 evaluate，$v_{\pi_{\text{go}}}=(16.514,\ 18.349)$；比较：stay 是 15.862，go 是 16.514，不再改变。两轮结束，得到 optimal policy。Value iteration 要 72 轮才把 error 压到 0.01，但 policy iteration 的每一轮都要解一个 $|S|\times|S|$ 的 linear system。

为什么 improvement 不会变差？按构造，$q_\pi(s,\pi'(s))=\max_aq_\pi(s,a)\ge q_\pi(s,\pi(s))=v_\pi(s)$。也就是说，“这一步按 $\pi'$、之后按 $\pi$”不比一直按 $\pi$ 差。把这个 inequality 在下一步再用一次：

$$v_\pi(s)\le q_\pi(s,\pi'(s))=\mathbb E_{\pi'}\big[R_1+\gamma v_\pi(S_1)\big]\le\mathbb E_{\pi'}\big[R_1+\gamma q_\pi(S_1,\pi'(S_1))\big]=\mathbb E_{\pi'}\big[R_1+\gamma R_2+\gamma^2v_\pi(S_2)\big]$$

和上一站一样展开 $k$ 次、令 $k\to\infty$，得 $v_\pi\le v_{\pi'}$。如果 improvement 不再改变 policy，$v_\pi(s)=\max_aq_\pi(s,a)$ 对所有 $s$ 成立，这正是 Bellman optimality equation，由唯一性 $v_\pi=v^*$。Deterministic policy 只有有限个，value 每轮不降，而且没到 optimal 时至少在一个 state 严格上升，所以同一个 policy 不会出现两次，algorithm 在有限轮内停下。

:::back
“展开 $k$ 次”的论证和[第 2 站](#mdp)的证明是同一个。Contraction 的证明会在[第 6 站](#td)再用一次，那时作用对象换成 $Q$。
:::

:::from
Policy evaluation、policy improvement 的展开式证明、value iteration、$\infty$-norm 下的 contraction 论证和 contraction mapping theorem 的三个推论，跟的是 [Silver 第 3 讲](https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-3-planning-by-dynamic-programming-.pdf)；“$V_k$ 是剩 $k$ 步时的 optimal value”和 $|A|^{|S|}$ 个 policy 的数法来自 [CS234 Lecture 2](https://web.stanford.edu/class/archive/cs/cs234/cs234.1224/CS234Win2020/slides/lecture2.pdf)；4×3 gridworld（noise 0.2）是 [CS188 Lecture 9](https://inst.eecs.berkeley.edu/~cs188/fa24/assets/lectures/cs188-fa24-lec09.pdf) 和 AIMA 的标准例子，这里的 reward 设定（进入 terminal 时拿 ±1、$\gamma=0.9$）和全部数表是为这一页算的。停机条件的推导、terminal state 让 converge 变快的解释是这一页加的。
:::

## [pomdp] POMDP 与 belief state

:::skip
能对 Tiger 问题做 belief update，能说明 belief 上的 value function 为什么是 piecewise linear convex，并能从 value function 的图上读出 policy，就可以去第 5 站。
:::

### 看不见 state 时，state 是什么

两扇门，一扇后面是老虎，一扇后面是宝物。三个 action：listen（花费 1，即 reward −1）、open-left、open-right。开对门拿 +10，开到老虎 −100；开门之后问题重置，老虎重新以 0.5、0.5 的 probability 放到某一扇后面。Listen 会听到老虎在哪边，但只有 0.85 的 probability 听对。$\gamma=0.75$。

真正的 state（老虎在左或右）agent 看不见，只能看到 observation。如果把 observation 当 state，“听到左边”之后该怎么做？听到一次左边和连续听到三次左边，应该做的事不同；听到左、右、左和只听到一次左，又应该一样。该怎么做取决于整个 history，最近的一个 observation 不够。所以 observation 不是 Markov 的，第 2 站的框架不能直接用。

History 是 Markov 的，但它越来越长。要找一个和 history 一样有用、但大小固定的东西。这个东西是对真实 state 的 probability distribution：

$$b(s)=P(S_t=s\mid\text{到目前为止的全部 action 和 observation})$$

叫 belief。Tiger 只有两个 state，belief 可以用一个数 $b=P(\text{tiger-left})$ 表示。

### Belief update 就是 Bayes rule

做了 action $a$、看到 observation $o$ 之后，新的 belief 怎么算？分两步。先按 transition 往前推一步，得到“还没看 observation 时”下一个 state 的 distribution：$\sum_sP(s'\mid s,a)\,b(s)$。再用 Bayes rule 结合 observation 的 likelihood $O(o\mid s',a)$：

$$b'(s')=\frac{O(o\mid s',a)\sum_sP(s'\mid s,a)\,b(s)}{P(o\mid b,a)},\qquad P(o\mid b,a)=\sum_{s'}O(o\mid s',a)\sum_sP(s'\mid s,a)\,b(s)$$

Denominator 只是让各个 $b'(s')$ 加起来等于 1。

Tiger 里 listen 不改变老虎的位置，所以第一步什么都不做。从 $b=0.5$ 开始 listen，听到左边：

$$b'=\frac{0.85\times0.5}{0.85\times0.5+0.15\times0.5}=0.85,\qquad P(\text{听到左})=0.5$$

再 listen，又听到左边：

$$b''=\frac{0.85\times0.85}{0.85\times0.85+0.15\times0.15}=\frac{0.7225}{0.745}=0.9698,\qquad P(\text{听到左})=0.745$$

如果第二次听到的是右边，$b''=\dfrac{0.15\times0.85}{0.15\times0.85+0.85\times0.15}=0.5$，回到原点。Belief 只取决于“听到左”和“听到右”的次数之差，这正是前面说的“history 里真正有用的部分”。

::fig[cs4246-tigerchain] Listen 时 belief 只在这条链上左右移动。两端的 threshold 0.0525、0.9475 在下一节算出。

### Belief MDP 与它的 Bellman equation

把 belief 当成 state，就又得到一个 MDP：在 belief $b$ 做 $a$ 的 expected reward 是 $\sum_sb(s)R(s,a)$；以 probability $P(o\mid b,a)$ 看到 $o$，然后 deterministic 地走到 belief $b'_{a,o}$。它的 Bellman optimality equation 是

$$V(b)=\max_a\Big[\sum_sb(s)R(s,a)+\gamma\sum_oP(o\mid b,a)\,V(b'_{a,o})\Big]$$

麻烦在于 belief 是连续的，第 3 站的 table 存不下。好在 $V$ 有一个特别的形状。

**Horizon 1。** 只剩一步，只看 reward。每个 action 的 expected reward 是 $b$ 的 linear function：

$$\text{listen}:\ -1,\qquad\text{open-left}:\ -100\,b+10\,(1-b),\qquad\text{open-right}:\ 10\,b-100\,(1-b)$$

在 $b=0.5$ 处分别是 −1、−45、−45。把每个 action 的 reward 写成一个 vector $\alpha_a=(R(\text{TL},a),R(\text{TR},a))$，就有 $V_1(b)=\max_a\,b\cdot\alpha_a$：几条直线的 upper envelope。

**一般的 horizon。** 设 $V_k(b)=\max_i\,b\cdot\alpha_i$。看 Bellman equation 里的一项 $P(o\mid b,a)\,V_k(b'_{a,o})$。把 $b'$ 的 formula 代进去，denominator 正好是 $P(o\mid b,a)$，和前面的 factor 消掉：

$$P(o\mid b,a)\max_i\sum_{s'}b'_{a,o}(s')\,\alpha_i(s')=\max_i\sum_{s'}\alpha_i(s')\,O(o\mid s',a)\sum_sP(s'\mid s,a)\,b(s)=\max_i\ b\cdot g_{a,o,i}$$

其中 $g_{a,o,i}(s)=\sum_{s'}P(s'\mid s,a)\,O(o\mid s',a)\,\alpha_i(s')$ 和 $b$ 无关。所以每一项都是若干个 linear function 的 max。对 $o$ 求和时，“几个 max 的和”等于“对每个 $o$ 各挑一个 $i$、所有挑法里的 max”，仍然是 linear function 的 max；再对 $a$ 取 max 也一样。于是 $V_{k+1}$ 也是有限条直线（高维时是 hyperplane）的 upper envelope：piecewise linear 而且 convex。

每个 $\alpha$-vector 对应一个 conditional plan：先做哪个 action，看到每种 observation 之后执行哪个下一层的 plan。$b\cdot\alpha$ 是从 belief $b$ 开始执行这个 plan 的 expected return。Convex 也有直接的意思：belief 越确定（靠近 0 或 1），value 越高，信息本身有价值。

::fig[cs4246-belief] Tiger 的 $V^*(b)$，由对 belief 的 value iteration 算到 converge（76 轮）。中间的 listen 区间由 7 条直线拼成，两端各一条开门的直线。

Converge 后共有 9 个 $\alpha$-vector。读图得到 policy：$b\le0.0525$ 时 open-left，$b\ge0.9475$ 时 open-right，其余 listen。和 belief update 的数字对一下：听到一次左边，$b=0.85$，还不够开门；同方向听到两次，$b=0.9698>0.9475$，开右门。也就是“听到的左右次数之差到 2 就开门”。$V^*(0.5)=1.933$，和 R package pomdp 的 vignette 对同一个问题给出的值一致。

:::wrong 把最可能的 state 当成真的，按 MDP 的 optimal policy 去做
听到一次左边后，$b=0.85$，最可能的 state 是老虎在左，知道 state 的话就该开右门。现在开右门，expected reward 是 $0.85\times10+0.15\times(-100)=-6.5$；开门后问题重置到 $b=0.5$，再加上 $0.75\times V^*(0.5)=0.75\times1.933=1.45$，合计 −5.05。而继续 listen 的 value 是 $V^*(0.85)=3.91$。错在 0.15 的 probability 乘的是 −100：最可能的 state 只告诉你哪边更可能，不告诉你猜错的代价有多大，更不会让你为了减少不确定性而花钱 listen。这类 heuristic 永远不会主动去收集信息。
:::

:::edge 为什么 exact solution 只适合很小的问题
每做一轮 backup，$\alpha$-vector 的个数在 prune 之前变成 $|A|\cdot|\Gamma_k|^{|O|}$：Tiger 里 9 个 vector 下一轮是 $3\times9^2=243$ 个候选，留下的只是在某个 belief 上取到 max 的那些。State 一多，候选的个数按 doubly exponential 增长。实际用的 solver 只在一些有代表性的 belief 点上做 backup（2020 年的课程笔记提到了 SARSOP），或者干脆不算全局的 value function，只从当前 belief 往前 search，这正是[第 9 站](#mcts)的做法。
:::

## [bandit] Bandits、exploration 与 regret

:::skip
能说出 greedy 为什么会永远锁死在差的 arm 上，能从 Hoeffding inequality 推出 UCB1 的 bonus，并证明它的 regret 是 $\log T$ 量级，就可以去第 6 站。
:::

### 只有一个 state 也学不好

前四站假设 model 已知。现在去掉这个假设，并且先把问题缩到最小：只有一个 state，每一步选一个 action（叫 arm），拿到一个 random 的 reward，distribution 不知道。这叫 multi-armed bandit。三个 arm 的 reward 是 Bernoulli 的，mean 分别是 $\mu_1=0.3$、$\mu_2=0.5$、$\mu_3=0.7$。

最自然的做法：每个 arm 先拉一次，之后总拉 sample mean 最大的那个（greedy）。拿一个实际的 random sequence 走一遍（seed 7）：前三次分别拉 arm 1、2、3，全都是 0；三个 sample mean 都是 0，按编号选 arm 1，这次中了。现在 arm 1 的 sample mean 是 $\tfrac12$，另外两个是 0。之后不管 arm 1 再输多少次，它的 sample mean 至少是 $1/N_1>0$，另外两个 arm 不再被拉，sample mean 永远是 0。Greedy 从此只拉最差的 arm。

它的毛病是：一个 arm 的估计偏低时，greedy 不再拉它，估计就没有机会被纠正。要学到东西，必须有时去拉看起来不是最好的 arm，这叫 exploration；但每次 exploration 都有代价。这一站要把“代价”量化，再找到代价增长最慢的办法。

### Regret 和它的分解

最好的 arm 的 mean 记作 $\mu^*$，arm $a$ 的 gap 是 $\Delta_a=\mu^*-\mu_a$。前 $T$ 步的 regret 定义为“一直拉最好的 arm”比实际做法少拿的 expected reward：

$$L_T=\mathbb E\Big[\sum_{t=1}^{T}\big(\mu^*-\mu_{a_t}\big)\Big]=\mathbb E\Big[\sum_{t=1}^{T}\Delta_{a_t}\Big]$$

按 arm 归类：sum 里 $\Delta_a$ 出现的次数就是 arm $a$ 被拉的次数 $N_T(a)$，所以

$$L_T=\sum_a\Delta_a\,\mathbb E[N_T(a)]$$

好的 algorithm 就是让 gap 大的 arm 被拉得少。困难在于 gap 不知道。

用这个分解看两种简单做法：

- **Greedy。** 上面那种锁死以一个固定的正 probability 发生，一旦发生，之后每一步都付出 $\Delta_1=0.4$，所以 $L_T$ 随 $T$ linear 增长。
- **$\varepsilon$-greedy。** 每步以 probability $\varepsilon$ uniformly random 地选一个 arm，否则 greedy。每个 arm 每步至少有 $\varepsilon/3$ 的 probability 被选中，$\mathbb E[N_T(a)]\ge\varepsilon T/3$，于是 $L_T\ge\tfrac{\varepsilon T}{3}(0.4+0.2)=0.02\,T$（$\varepsilon=0.1$）。不会锁死，但为了 exploration 付出的代价永远不停，还是线性。

能不能比 linear 好？Lai 和 Robbins 证明了任何 algorithm 的 regret 至少按 $\log T$ 增长，constant 取决于各个 arm 的 distribution 有多难区分。下面的 UCB1 达到这个量级。

### Optimism：给不确定的 arm 加 bonus

Greedy 的错是把 sample mean 当成 true mean。换一个问法：根据已有的 data，arm $a$ 的 true mean 最高可能是多少？选这个“最高可能值”最大的 arm。被拉得少的 arm 不确定性大，最高可能值高，自然会被拉；被拉多了，最高可能值收缩到 sample mean 附近，只有真的好才会继续被选。

“最高可能”要量化。Hoeffding inequality：$N$ 个取值在 $[0,1]$ 的 independent sample，true mean 比 sample mean 高出 $u$ 以上的 probability 不超过 $e^{-2Nu^2}$。让这个 probability 等于一个随时间变小的 $p$，解出 $u$：

$$e^{-2Nu^2}=p\quad\Longrightarrow\quad u=\sqrt{\frac{-\ln p}{2N}}$$

取 $p=t^{-4}$（$t$ 是到目前为止总共拉了多少次），得到 UCB1 的 index：

$$\text{UCB}_a=\hat\mu_a+\sqrt{\frac{2\ln t}{N_a}}$$

$p$ 随 $t$ 变小，是为了让“true mean 落在 bound 之外”的总 probability 加起来有限；代价是 bonus 里的 $\ln t$ 会慢慢增长，一个很久没被拉的 arm 的 bonus 会一直涨，迟早被再拉一次。

用同一个 random sequence（seed 7）走 12 步。前三步每个 arm 拉一次：

| 步 | $N=(N_1,N_2,N_3)$ | sample mean | index | 拉 | reward |
|---|---|---|---|---|---|
| 4 | (1, 1, 1) | (0, 0, 0) | (1.482, 1.482, 1.482) | 1 | 1 |
| 5 | (2, 1, 1) | (0.5, 0, 0) | (1.677, 1.665, 1.665) | 1 | 0 |
| 6 | (3, 1, 1) | (0.333, 0, 0) | (1.369, 1.794, 1.794) | 2 | 0 |
| 7 | (3, 2, 1) | (0.333, 0, 0) | (1.426, 1.339, 1.893) | 3 | 1 |
| 8 | (3, 2, 2) | (0.333, 0, 0.5) | (1.472, 1.395, 1.895) | 3 | 0 |
| 9 | (3, 2, 3) | (0.333, 0, 0.333) | (1.511, 1.442, 1.511) | 1 | 0 |
| 10 | (4, 2, 3) | (0.25, 0, 0.333) | (1.298, 1.482, 1.544) | 3 | 1 |
| 11 | (4, 2, 4) | (0.25, 0, 0.5) | (1.323, 1.517, 1.573) | 3 | 1 |
| 12 | (4, 2, 5) | (0.25, 0, 0.6) | (1.345, 1.549, 1.579) | 3 | 1 |

（index 相等时按编号选。）

核对第 6 步：已经拉了 $t=5$ 次，$2\ln5=3.219$。Arm 1 是 $0.333+\sqrt{3.219/3}=0.333+1.036=1.369$；arm 2 是 $0+\sqrt{3.219/1}=1.794$。第 4 步和 greedy 遇到的是完全一样的结果，arm 1 中了；但 arm 1 的 bonus 随 $N_1$ 增大而缩小，另外两个 arm 的 bonus 保持不变还随 $t$ 增长，到第 6 步 arm 2、3 重新领先。第 12 步 arm 2 的 sample mean 还是 0，index 却仍是 1.549，它还会被再拉。

### 为什么是 $\log T$

看一个 suboptimal arm $a$，最好的 arm 记作 $*$。记 $c_{t,n}=\sqrt{2\ln t/n}$，即被拉了 $n$ 次的 arm 在第 $t$ 步拿到的 bonus。目标是给 $\mathbb E[N_T(a)]$ 一个上界。取一个门槛

$$\ell=\Big\lceil\frac{8\ln T}{\Delta_a^2}\Big\rceil$$

Arm $a$ 的前 $\ell$ 次全都算上，剩下要数的是：arm $a$ 已经被拉了至少 $\ell$ 次之后，还会被选中几次。

**一次选错意味着三件事之一。** 设第 $t$ 步选了 $a$，这时最好的 arm 被拉过 $n$ 次、$a$ 被拉过 $n_a\ge\ell$ 次。选中 $a$ 说明 $\hat\mu_*+c_{t,n}\le\hat\mu_a+c_{t,n_a}$。这时下面三件事至少有一件成立：

1. $\hat\mu_*\le\mu^*-c_{t,n}$：最好的 arm 被低估了一个 bonus 以上；
2. $\hat\mu_a\ge\mu_a+c_{t,n_a}$：arm $a$ 被高估了一个 bonus 以上；
3. $\mu^*<\mu_a+2c_{t,n_a}$：arm $a$ 的 bonus 还大到能盖过 gap。

理由：如果 1、2 都不成立，就有 $\mu^*<\hat\mu_*+c_{t,n}\le\hat\mu_a+c_{t,n_a}<\mu_a+2c_{t,n_a}$，这正是 3。

**第 3 件不会发生。** $n_a\ge\ell\ge8\ln T/\Delta_a^2\ge8\ln t/\Delta_a^2$（因为 $t\le T$），所以

$$2c_{t,n_a}=2\sqrt{\frac{2\ln t}{n_a}}\le2\sqrt{\frac{2\ln t\cdot\Delta_a^2}{8\ln t}}=\Delta_a$$

即 $\mu_a+2c_{t,n_a}\le\mu^*$，和 3 矛盾。

**第 1、2 件的 probability。** 对固定的 $n$，Hoeffding inequality 取 $u=c_{t,n}$：

$$P\big(\hat\mu_*\le\mu^*-c_{t,n}\big)\le e^{-2n\,c_{t,n}^2}=e^{-2n\cdot2\ln t/n}=e^{-4\ln t}=t^{-4}$$

第 2 件同理也是 $t^{-4}$。麻烦在于 $n$ 和 $n_a$ 是 random 的，取决于之前的全部 history，不能当成固定的数代进去。办法是对所有可能的取值都算上：两者都小于 $t$，至多 $t^2$ 对，每一对上两件事加起来至多 $2t^{-4}$，所以第 $t$ 步“已经拉够 $\ell$ 次还被选中”的 probability 至多 $t^2\cdot2t^{-4}=2t^{-2}$。对所有 $t$ 加起来：

$$\sum_{t=1}^{\infty}\frac{2}{t^2}=2\cdot\frac{\pi^2}{6}=\frac{\pi^2}{3}$$

这就是 $p=t^{-4}$ 取得这么小的原因：union 掉 $t^2$ 对取值之后还剩 $t^{-2}$，加起来仍然有限。

**合起来。** 门槛 $\ell$ 不超过 $8\ln T/\Delta_a^2+1$，所以

$$\mathbb E[N_T(a)]\le\frac{8\ln T}{\Delta_a^2}+1+\frac{\pi^2}{3}$$

代回 regret 的分解：

$$L_T\le\sum_{a:\Delta_a>0}\frac{8\ln T}{\Delta_a}+\Big(1+\frac{\pi^2}{3}\Big)\sum_a\Delta_a$$

这是 Auer、Cesa-Bianchi 与 Fischer（2002）的 Theorem 1。Gap 越小，越难区分，需要的 sample 越多（$1/\Delta_a^2$）；但每次拉错的代价也越小（$\Delta_a$），两者一乘是 $1/\Delta_a$。

用到这个例子上，$T=20000$，$8\ln20000=79.23$，$1+\pi^2/3=4.29$。Arm 1 的 bound 是 $79.23/0.16+4.29=499.5$ 次，arm 2 是 $79.23/0.04+4.29=1985.0$ 次；regret 的 bound 是 $79.23\times(\tfrac1{0.4}+\tfrac1{0.2})+4.29\times(0.4+0.2)=594.2+2.6=596.8$。

::fig[cs4246-regret] 同一个 3-armed bandit，2000 次独立 run 的平均（seed 0）。Greedy 和 $\varepsilon$-greedy 都是直线，UCB1 越来越平。

实测 UCB1 在 $T=20000$ 时 regret 是 116，比 596.8 的 bound 小得多（arm 1、2 实际平均只被拉了 107 次和 368 次，bound 是 499.5 和 1985.0），但增长的形状一样：从 $t=10000$ 到 $20000$ 只增加了 17。$\varepsilon$-greedy 是 410，和上面的 $0.02T=400$ 吻合；greedy 是 1968。

:::wrong Greedy 偶尔会选错，但 sample 多了，sample mean 会自己把错误纠正过来
纠正需要继续拉那个被低估的 arm，而 greedy 恰恰不再拉它。上面的 sequence 里 arm 3 的第一次是 0，之后 greedy 一次也不会再碰它。2000 次 run 里，15% 最后锁在 arm 1（每步损失 0.4），19% 锁在 arm 2（每步损失 0.2），平均每步损失 $0.15\times0.4+0.19\times0.2\approx0.098$，正是图里 greedy 那条直线的 slope。Sample 多了只会让被拉的那个 arm 的估计更准，对没被拉的 arm 没有任何帮助。
:::

:::edge UCB1 在前期反而比 $\varepsilon$-greedy 差
图里 $t\approx3035$ 之前，UCB1 的 regret 高于 $\varepsilon$-greedy。看两者在 $t=3000$ 时平均把每个 arm 拉了多少次：UCB1 是 71、210、2719，$\varepsilon$-greedy 是 107、137、2756。差别在 arm 2：它和 arm 3 只差 0.2，要很多 sample 才能区分，而 $\sqrt{2\ln t/N_a}$ 这个为 worst case 保证取的 bonus 很保守，UCB1 在它上面花得比 $\varepsilon$-greedy 多。$\varepsilon$-greedy 的浪费则是固定比例的：每步 $\varepsilon/3$ 的 probability 拉 arm 1，不管已经多确定它差。到 $t=20000$，UCB1 对 arm 1、2 一共只拉了 107 次和 368 次，$\varepsilon$-greedy 是 673 次和 704 次。Logarithmic 和 linear 的差别要 $T$ 足够大才显现。Sutton 与 Barto 也指出，UCB 难以推广到 nonstationary 的问题和需要 function approximation 的大 state space，在那些场合实际中多用 $\varepsilon$-greedy。
:::

:::

Regret 的定义与按 gap 和 count 的分解、greedy 与 $\varepsilon$-greedy 为什么是 linear、Lai–Robbins lower bound、optimism、由 Hoeffding inequality 取 $p=t^{-4}$ 推出 UCB1，跟的是 [Silver 第 9 讲](https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-9-exploration-and-exploitation.pdf)。“UCB 难以推广到 nonstationary 问题和 function approximation”来自 [Sutton & Barto 第 2.7 节](https://people.engr.tamu.edu/guni/csce421/files/RLbook2018.pdf)。$\log T$ 的证明跟的是 [Auer、Cesa-Bianchi 与 Fischer（2002）](https://homes.di.unimi.it/%7Ecesabian/Pubblicazioni/ml-02.pdf) Theorem 1 的原证明：门槛 $\ell$ 的取法、三件事的分解、对 $(n,n_a)$ 取 union 得到 $2t^{-2}$、$\pi^2/3$。原文没有逐行交代常数里的 1，这里按“$\ell$ 取整”解释，是自己的读法。3-armed bandit 的手算表和 regret 曲线是为这一页模拟的。

## [td] Monte Carlo、TD、SARSA 与 Q-learning

:::skip
能说出 TD target 的 bias 从哪里来、MC 和 TD 在同一批 data 上为什么给出不同的答案，能手算 Q-learning 的 update，并能解释 Q-learning 为什么 off-policy 也 converge 到 $q^*$，而 SARSA converge 到别的东西，就可以去第 7 站。
:::

### 没有 model，就用 sample 代替 expectation

第 3 站的每一次 backup 都要用 $P(s'\mid s,a)$ 和 $r(s,a)$。现在它们不知道，只能和环境交互，得到一条条 trajectory。第一个问题（prediction）：固定一个 policy $\pi$，从 trajectory 里估计 $v_\pi$。

$v_\pi(s)$ 的定义是 return 的 expectation，那就从 $s$ 出发跑很多次，把看到的 return 取平均。这叫 Monte Carlo（MC）。写成 incremental 的形式，每看到一个 return $G_t$ 就把估计往它挪一点：

$$V(S_t)\leftarrow V(S_t)+\alpha\big(G_t-V(S_t)\big)$$

$G_t$ 是 $v_\pi(S_t)$ 的 unbiased sample，所以 MC 的 target 没有 bias。代价有两个：要等 episode 结束才知道 $G_t$；$G_t$ 是之后所有 random 的 action、transition、reward 的总和，variance 大。

另一条路从 Bellman expectation equation 出发：$v_\pi(s)=\mathbb E_\pi[R_{t+1}+\gamma v_\pi(S_{t+1})\mid S_t=s]$。把 expectation 换成一个 sample，把不知道的 $v_\pi$ 换成当前的估计 $V$：

$$V(S_t)\leftarrow V(S_t)+\alpha\big(\underbrace{R_{t+1}+\gamma V(S_{t+1})}_{\text{TD target}}-V(S_t)\big)$$

这叫 TD(0)，括号里的差叫 TD error $\delta_t$。它走一步就能 update，不必等 episode 结束。用自己的估计去构造 target，叫 bootstrapping。

两者的关系：设 $V$ 在一个 episode 内不变，$G_t-V(S_t)=\big(R_{t+1}+\gamma V(S_{t+1})-V(S_t)\big)+\gamma\big(G_{t+1}-V(S_{t+1})\big)=\delta_t+\gamma\big(G_{t+1}-V(S_{t+1})\big)$，反复代入：

$$G_t-V(S_t)=\delta_t+\gamma\delta_{t+1}+\gamma^2\delta_{t+2}+\cdots$$

MC 的 error 就是之后所有 TD error 的 discounted sum。TD 每步只用其中第一项。

::fig[cs4246-backup] 三种 backup。DP 对所有可能的下一步取 expectation，需要 model；TD 只 sample 一步；MC sample 到 episode 结束。

### Bias 和 variance 各在哪里

用第 2 站的 MDP，policy 取 $\pi_{\text{go}}$，看从 B 出发的两种 target。

**MC target。** 模拟 100000 次（seed 0，每次截断在 300 步，$0.9^{300}$ 可以忽略），return 的 mean 是 18.350，和 $v(B)=18.349$ 吻合；standard deviation 是 1.09。

**TD target。** 从 B 出发，reward 一定是 2；以 0.9 的 probability 留在 B，以 0.1 回到 A。假如 $V$ 已经等于 true value，target 是 $2+0.9\times18.349=18.514$ 或 $2+0.9\times16.514=16.862$，mean 正好是 18.349，standard deviation 是 0.50，不到 MC 的一半：它只含一步的 randomness。

但“假如 $V$ 已经等于 true value”是关键。学习开始时 $V=0$，从 B 出发的 TD target 不管走到哪里都是 $2+0.9\times0=2$，而 true value 是 18.349。TD target 的 expectation 是 $r+\gamma\,\mathbb E[V(S')]$，只有在 $V$ 正确时才等于 $v_\pi$；$V$ 有多错，target 就带着多少 bias。TD 的 bias 来自 bootstrapping，并且随着 $V$ 变准而消失；MC 的 variance 来自整条 trajectory，不会因为学得更好而消失。

### 同一批 data，两个答案

Bias 之外，MC 和 TD 对 data 的理解也不同。只有两个 state A、B，$\gamma=1$，观察到 8 个 episode：

- A, 0, B, 0（1 次）
- B, 1（6 次）
- B, 0（1 次）

B 出现了 8 次，6 次的 return 是 1，所以两种方法都给 $V(B)=\tfrac68=0.75$。分歧在 A。MC 只看从 A 出发的 return：唯一一次是 0，所以 $V(A)=0$。TD 把 data 反复用到 converge：A 的 target 是 $0+V(B)$，所以 $V(A)=0.75$。

::fig[cs4246-batch] 同一批 data 的两种读法。

哪个对？MC 的答案让 training data 上的 squared error 最小。TD 的答案等于先从 data 估计一个 Markov model（A 总是以 reward 0 转到 B，B 以 $\tfrac34$ 的 probability 拿到 1），再精确解这个 model。这叫 certainty-equivalence estimate。如果环境确实是 Markov 的，“A 之后 B 只出现过一次而且结果是 0”只是 B 的 randomness，TD 用上了其余 7 次关于 B 的经验，所以 TD 通常更 data-efficient。如果环境不是 Markov 的，这个优势就不成立。

### Control：用 Q，不用 V

第二个问题（control）：找 optimal policy。第 3 站的 policy improvement 是在每个 state 选 $\arg\max_a\big[r(s,a)+\gamma\sum P(s'\mid s,a)V(s')\big]$，这一步要 model。改为直接学 $Q(s,a)$，improvement 就只需要 $\arg\max_aQ(s,a)$，不再需要 model。

把 TD 的思路用到 $Q$ 上，有两种 target：

$$\text{SARSA}:\ R+\gamma\,Q(S',A'),\qquad\text{Q-learning}:\ R+\gamma\max_{a'}Q(S',a')$$

SARSA 的 $A'$ 是下一步实际要执行的 action（名字就是 $S,A,R,S',A'$ 五个字母）；Q-learning 不管下一步实际做什么，都用下一个 state 上最大的 $Q$。

在第 2 站的 MDP 上手算 Q-learning。$\alpha=0.5$，$\gamma=0.9$，三个 $Q$ 都从 0 开始；behavior policy 在 A uniformly random 地选 stay 或 go（seed 1）：

| 步 | transition | target | 更新 | $Q(A,\text{stay})$ | $Q(A,\text{go})$ | $Q(B)$ |
|---|---|---|---|---|---|---|
| 1 | A, stay, 1, A | $1+0.9\times0=1$ | $0+0.5(1-0)$ | 0.5 | 0 | 0 |
| 2 | A, go, 0, B | $0+0.9\times0=0$ | 不变 | 0.5 | 0 | 0 |
| 3 | B, 2, A | $2+0.9\times\max(0.5,0)=2.45$ | $0+0.5\times2.45$ | 0.5 | 0 | 1.225 |
| 4 | A, stay, 1, A | $1+0.9\times0.5=1.45$ | $0.5+0.5\times0.95$ | 0.975 | 0 | 1.225 |
| 5 | A, stay, 1, A | $1+0.9\times0.975=1.8775$ | $0.975+0.5\times0.9025$ | 1.426 | 0 | 1.225 |
| 6 | A, go, 0, B | $0+0.9\times1.225=1.1025$ | $0+0.5\times1.1025$ | 1.426 | 0.551 | 1.225 |
| 7 | B, 2, B | $2+0.9\times1.225=3.1025$ | $1.225+0.5\times1.8775$ | 1.426 | 0.551 | 2.164 |
| 8 | B, 2, B | $2+0.9\times2.164=3.947$ | $2.164+0.5\times1.784$ | 1.426 | 0.551 | 3.056 |

第 3 步从 B 回到 A，target 里用的是 A 上两个 $Q$ 的 max（0.5），和下一步实际会做什么无关。8 步之后 $Q(A,\text{stay})>Q(A,\text{go})$，greedy 会选错：value 从 reward 往回传需要时间，go 的好处要等 $Q(B)$ 涨上来之后才传到 $Q(A,\text{go})$。

### Q-learning 为什么 converge 到 $q^*$

把 Q-learning 的 target 对下一个 state 取 conditional expectation：

$$\mathbb E\Big[R+\gamma\max_{a'}Q(S',a')\ \Big|\ S=s,A=a\Big]=r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\max_{a'}Q(s',a')=:(T^*Q)(s,a)$$

右边是 Bellman optimality operator 作用在 $Q$ 上，它的 fixed point 是 $q^*$。第 3 站的证明原样搬过来（max 的那个小事实用在 $\max_{a'}$ 上）：$\|T^*Q_1-T^*Q_2\|_\infty\le\gamma\|Q_1-Q_2\|_\infty$。所以 Q-learning 的 update 可以写成

$$Q(s,a)\leftarrow Q(s,a)+\alpha\big[(T^*Q)(s,a)-Q(s,a)+\text{noise}\big]$$

其中 noise 的 expectation 为 0。这是一个带 noise 的 value iteration，每次只更新一个 entry、只走一小步。Stochastic approximation 的理论说：只要每个 $(s,a)$ 被更新无穷多次，并且 step size 满足 $\sum_t\alpha_t=\infty$（走得够远）、$\sum_t\alpha_t^2<\infty$（noise 最终被平均掉），它就以 probability 1 converge 到 fixed point $q^*$。

关键在于：behavior policy 出现在哪里？它只决定哪些 $(s,a)$ 被更新、多频繁，不出现在 target 的 expectation 里。所以 behavior 可以是任何保证“每个 $(s,a)$ 都被试到”的 policy，比如完全 random 的，这叫 off-policy。

SARSA 的 target 取 expectation 是 $r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\sum_{a'}\pi(a'\mid s')Q(s',a')$，里面的 $\pi$ 是 behavior policy 本身。它是 $T^\pi$，fixed point 是 $q_\pi$。SARSA 学的是自己正在执行的 policy 的 value，这叫 on-policy。

:::wrong SARSA 和 Q-learning 只是 target 写法不同，最后学到同一个东西
在第 2 站的 MDP 上各跑 400000 步（seed 0，step size $\alpha=1/n(s,a)^{0.7}$）。Q-learning 的 behavior 在 A uniformly random 地；SARSA 用 $\varepsilon=0.2$ 的 $\varepsilon$-greedy：

| | $Q(A,\text{stay})$ | $Q(A,\text{go})$ | $Q(B)$ |
|---|---|---|---|
| $q^*$ | 15.862 | 16.514 | 18.349 |
| Q-learning（random behavior） | 15.864 | 16.510 | 18.338 |
| SARSA（$\varepsilon=0.2$） | 15.746 | 16.451 | 18.278 |
| $\varepsilon$-greedy policy 的 $q_\pi$ | 15.751 | 16.461 | 18.290 |

Q-learning 的 behavior 一半时间在乱走，学到的仍是 $q^*$。SARSA 学到的是 $\varepsilon$-greedy policy 自己的 value：在 A 有 0.1 的 probability 选 stay，所以 value 都低一点。$\varepsilon$ 固定不变时它永远到不了 $q^*$；要 converge 到 $q^*$，$\varepsilon$ 必须随时间趋于 0（Silver 称为 GLIE）。Sutton 与 Barto 的 cliff walking 例子把这个差别变成了行为上的差别：Q-learning 学到贴着悬崖走的 optimal path，但执行时 $\varepsilon$-greedy 的随机一步会掉下去；SARSA 把这个风险算进了 value，学到一条离悬崖远一点的路，执行时拿到的 reward 反而更多。
:::

:::edge Max 带来的 bias
Q-learning 的 target 用 $\max_{a'}Q(S',a')$，而 $Q$ 是 noisy 的估计。即使所有 action 的 true value 都是 0，只要估计有 noise，max 的 expectation 就是正的：$k$ 个独立 $N(0,1)$ 的 max，expectation 在 $k=2,4,10$ 时分别是 0.56、1.03、1.54（模拟 $10^6$ 次，seed 0）。这个 bias 会通过 bootstrapping 一路往回传。Sutton 与 Barto 第 6.7 节的例子里，一个 reward mean 为 −0.1 的分支因此被 Q-learning 系统性地高估。Double Q-learning 用两套独立的估计，一套选 $\arg\max$，另一套给这个 action 估值，选择和估值的 noise 不再相关，bias 就消失了。
:::

:::back
Q-learning 的 converge 靠的是[第 3 站](#dp)的 contraction；SARSA 和 Q-learning 的 exploration 用的是[第 5 站](#bandit)的 $\varepsilon$-greedy。
:::

## [fa] Function approximation、deadly triad 与 DQN

:::skip
能算出 $w\to2w$ 例子为什么 diverge，说出 deadly triad 的三个因素、在这个例子里去掉任何一个为什么就 converge，并说清 experience replay 和 target network 各自治的是什么、没治什么，就可以去第 8 站。
:::

### Table 存不下

到目前为止每个 state（或 $(s,a)$）都有自己的一个格子。Backgammon 大约有 $10^{20}$ 个 state；机器人的 state 是连续的 joint angle 和图像，根本没法列表。更重要的是，table 里每个格子只能从访问它自己的经验里学，从没见过的 state 一无所知。

办法是用一个带 parameter $w$ 的 function $\hat v(s;w)$ 去 approximate value，parameter 远比 state 少。最简单的是 linear 的：给每个 state 一个 feature vector $x(s)$，$\hat v(s;w)=x(s)^\top w$。代价是：update 一个 state，所有共享 parameter 的 state 的 value 都跟着变。泛化能力和下面要看到的麻烦是同一件事的两面。

### Semi-gradient TD

如果知道 true value，就是一个 regression：最小化 $\tfrac12\big(v_\pi(s)-\hat v(s;w)\big)^2$，gradient descent 给出 $w\leftarrow w+\alpha\big(v_\pi(s)-\hat v(s;w)\big)\nabla_w\hat v(s;w)$。不知道 $v_\pi$，就像上一站那样用 TD target 顶替：

$$w\leftarrow w+\alpha\big(R+\gamma\hat v(S';w)-\hat v(S;w)\big)\nabla_w\hat v(S;w)$$

注意 target 里也有 $w$，这个 update 却只对 $\hat v(S;w)$ 求了 derivative，假装 target 是 constant。它不是任何 objective function 的 gradient，所以叫 semi-gradient。“假装 target 不动”在 table 的情形下无害，因为改 $S$ 的格子不会动 $S'$ 的格子；有了共享的 parameter，它就动了。

### 最小的 divergence

两个 state，feature 分别是 1 和 2，共用一个 scalar parameter $w$，所以 value 是 $w$ 和 $2w$。从第一个 state 一定转到第二个，reward 0；第二个之后进入 terminal，reward 0。两个 state 的 true value 都是 0，$w=0$ 就是完美的答案。

::fig[cs4246-triad] 左边是例子的结构，右边是 $w$ 随 update 的变化（log scale）：只 update 第一个 state 时exponential 增长，两个都 update 时exponential 衰减。

假设 data 只来自第一个 state 的 transition（比如 behavior policy 很少走到第二个 state，而我们在学的是另一个 policy 的 value，这就是 off-policy）。在第一个 state 上，TD error 是 $0+\gamma\cdot2w-w=(2\gamma-1)w$，gradient $\nabla_w\hat v=1$，所以

$$w\leftarrow w+\alpha(2\gamma-1)w=\big(1+\alpha(2\gamma-1)\big)w$$

$\gamma=0.99$、$\alpha=0.1$ 时 factor 是 1.098。从 $w=10$ 出发：10.98，12.06，13.24……100 次之后是 114877。$\gamma>\tfrac12$ 时 factor 大于 1，$\alpha$ 取多小都没用，只是增长慢一些。

机制是：为了让第一个 state 的 value $w$ 追上 target $2\gamma w$，把 $w$ 调大；可 target 也是 $w$ 的 function，而且涨得更快（$2\gamma>1$），越追越远。

### Deadly triad：三样齐了才会出事

上面的例子同时有三样东西：function approximation、bootstrapping、off-policy 的 data distribution。逐个拿掉：

**拿掉 function approximation。** 两个 state 各有自己的 value $V_1$、$V_2$。Update $V_1$ 不改变 $V_2$，target $\gamma V_2$ 是一个固定的数，$V_1$ converge 过去。

**拿掉 bootstrapping。** 用 MC target：从第一个 state 出发的 return 就是 0。$w\leftarrow w+\alpha(0-w)$，每步乘 0.9，converge 到 0。

**拿掉 off-policy。** 按 policy 自己的 distribution，第二个 state 也会被访问，它的 update 是 TD error $0-2w$ 乘 gradient 2：$w\leftarrow w-4\alpha w$。两个 state 各 update 一次，factor 是 $1.098\times(1-0.4)=0.659$：从 10 出发是 6.59，4.34，2.86…… converge 到 0。第二个 state 的 update 恰好把第一个 state 那边“推高 target”的效应拉回来。

所以 divergence 不是 sampling noise、不是 exploration、也不需要 nonlinear 的 neural network，三样都在时，连 linear 的、没有 noise 的 expected update 都会 diverge。Sutton 称之为 deadly triad。Q-learning 的 target 用 max，学的是 greedy policy，而 data 来自 $\varepsilon$-greedy，所以它天生是 off-policy 的；再加上 bootstrapping 和 neural network，三样齐了。Silver 第 6 讲的表也写着：Q-learning 在 table 上 converge，用 linear 或 nonlinear function approximation 时都可能 diverge。同一张表也说明“缺一个就安全”有前提：on-policy 的 TD 在 linear function approximation 下 converge，换成 nonlinear 的就不再有保证；MC 不 bootstrap，table、linear、nonlinear 三种情况都 converge。

### DQN 做了什么

直接把 Q-learning 套上 neural network，除了 deadly triad 还有两个问题。第一，相邻的 transition 高度相关，连续几百步 gradient 都朝着最近经过的那一小片 state 推，网络会忘掉别处。第二，target $r+\gamma\max_{a'}Q(s',a';w)$ 随每一步 update 变化，regression 的目标一直在动。

DQN 的两个改动分别对着这两个问题：

- **Experience replay。** 把 transition 存进一个大 buffer，每次 update 从里面random 地抽一个 minibatch。抽出来的 sample 之间几乎不相关，像 supervised learning 的 i.i.d. data；每条 transition 也能被重复使用。
- **Target network。** 算 target 用一份旧的 parameter $w^-$：$y=r+\gamma\max_{a'}Q(s',a';w^-)$，每隔若干步（CS285 说的是 10000 步）才把 $w^-$ 更新成当前的 $w$。在两次更新之间，target 是固定的，问题变回一个定义清楚的 regression。

两者都有用。Silver 第 6 讲引用的 DQN 消融实验里，Breakout 的分数是：

| | 有 target network | 没有 target network |
|---|---|---|
| 有 replay | 316.81 | 240.73 |
| 没有 replay | 10.16 | 3.17 |

:::wrong 加了 target network，Q-learning 就不会 diverge 了
回到 $w\to2w$ 的例子，加上 target network，每个阶段把 $w$ 在第一个 state 上 regress 到固定的 target $2\gamma w^-$，regress 到底就是 $w=2\gamma w^-=1.98\,w^-$。从 10 出发，每更新一次 target network：19.8，39.2，77.6……照样 diverge，只是变成一段一段地涨。如果 data 也覆盖第二个 state（on-policy），每个阶段最小化 $(w-2\gamma w^-)^2+(2w-0)^2$，令 derivative 为 0 得 $5w=2\gamma w^-$，即 $w=0.396\,w^-$，converge。Target network 让每个阶段的优化稳定，但阶段与阶段之间的映射是否 contraction，仍然取决于 data distribution 和 function class。Replay 甚至让 data 更 off-policy：buffer 里大多是旧 policy 产生的。DQN 在 Atari 上能工作是经验事实，没有 converge 保证。
:::

:::back
Q-learning 天生 off-policy 的原因见[第 6 站](#td)；Double DQN 用的是第 6 站末尾 double Q-learning 的想法。
:::

:::from
$w\to2w$ 的例子、数字 10.98、12.06、13.24、deadly triad 和“divergence 与 sampling、exploration、nonlinearity 无关”来自 [Sutton 的 off-policy 幻灯片](https://web.stanford.edu/class/cme241/lecture_slides/rich_sutton_slides/26-offpolicy.pdf)。Function approximation 的动机、semi-gradient、converge 性表格、DQN 的两个改动和消融实验的数字来自 [Silver 第 6 讲](https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-6-value-function-approximation-.pdf)。Online Q-learning 的两个问题（相关的 sample、不是 gradient descent）和 target network 的更新间隔来自 [CS285 Lecture 8](https://rail.eecs.berkeley.edu/deeprlcourse/static/slides/lec-8.pdf)。教材第 11.2 节的原例（$w=10$、$\alpha=0.5$、$\gamma=0.9$，factor 是 1.4，一次 update 后 $w=14$）和“三样同时出现才可能 diverge”的说法，是对着 [Peter Stone 根据第 11 章做的幻灯片](https://cs.utexas.edu/~pstone/Courses/394Rspring24/resources/Ch11Slides.pdf)核对的；教材 PDF 本身在第 50 万个字符之后抓不到。幻灯片只说三样同时出现时可能 diverge，没有写“缺一个就一定 converge”；这一页的三段计算只说明在这个例子里各缺一个都 converge。逐个拿掉三因素的计算、target network 版本的 1.98 和 0.396 是这一页自己算的。

## [pg] Policy gradient、actor-critic、GAE 与 PPO

:::skip
能从 $\nabla_\theta\mathbb E_{\tau\sim\pi_\theta}[R(\tau)]$ 推出 REINFORCE、证明 baseline 不改变 expectation 并算出 optimal 的 baseline，能解释为什么把所有 reward 加一个 constant 会让学习变差，能按 recursion 算 GAE，并说清 PPO 的 clip 截掉的是哪一侧，就可以去第 9 站。GAE 和 PPO 两节是 Assignment 2（AY25/26）的全部背景。
:::

### 为什么要直接学 policy

前面的方法都是先学 value，再对它 greedy。这条路在两种情况下走不通。第一，action 是连续的：机器人的 action 是一组 joint torque，“对 $Q(s,a)$ 取 $\arg\max_a$”本身就是每一步都要解的 optimization problem。第二，optimal policy 可能是 stochastic 的：Silver 第 7 讲的 aliased gridworld 里，两个格子的 observation 完全一样，但一个该往左、一个该往右，任何 deterministic policy 都会在其中一个格子里来回打转，而以 0.5 的 probability 左右随机走能很快到达终点。Greedy 出来的 policy 永远是 deterministic 的。

所以换一个 parameterization：直接用 $\theta$ 表示 policy $\pi_\theta(a\mid s)$，最大化

$$J(\theta)=\mathbb E_{\tau\sim\pi_\theta}\big[R(\tau)\big]$$

$\tau=(s_0,a_0,r_1,s_1,a_1,\dots)$ 是一条 trajectory，$R(\tau)$ 是它的 return。

### 为什么需要 log-derivative trick

$J$ 是对 trajectory 的 expectation，$\theta$ 只通过 trajectory 的 probability 影响它：

$$J(\theta)=\sum_\tau P(\tau;\theta)\,R(\tau),\qquad P(\tau;\theta)=\rho_0(s_0)\prod_t\pi_\theta(a_t\mid s_t)\,P(s_{t+1}\mid s_t,a_t)$$

直接求 $\nabla_\theta$，得到 $\sum_\tau\nabla_\theta P(\tau;\theta)\,R(\tau)$。这个 sum 没法算：要对所有 trajectory 求和，而 $P(\tau;\theta)$ 里有不知道的 transition probability。能做的只有一件事，就是按 $\pi_\theta$ 去跑，得到 trajectory 的 sample。可 sample 只能估计“某个量在 $P(\tau;\theta)$ 下的 expectation”，而 $\sum_\tau\nabla_\theta P\cdot R$ 不是这种形式。也不能对 $R(\tau)$ 关于 $\theta$ 求 derivative：reward 是环境给的一个数，环境不是 differentiable 的，action 又是 sample 出来的离散结果。

把它凑成 expectation 的办法是一个恒等式：$\nabla_\theta\log P=\dfrac{\nabla_\theta P}{P}$，所以 $\nabla_\theta P=P\,\nabla_\theta\log P$。代进去：

$$\nabla_\theta J=\sum_\tau P(\tau;\theta)\,\nabla_\theta\log P(\tau;\theta)\,R(\tau)=\mathbb E_{\tau\sim\pi_\theta}\big[\nabla_\theta\log P(\tau;\theta)\,R(\tau)\big]$$

现在是一个 expectation，可以用 sample 的平均来估计。剩下的 $\nabla_\theta\log P(\tau;\theta)$ 看起来仍然要 model，但 log 把 product 变成 sum：

$$\log P(\tau;\theta)=\log\rho_0(s_0)+\sum_t\log\pi_\theta(a_t\mid s_t)+\sum_t\log P(s_{t+1}\mid s_t,a_t)$$

第一项和第三项与 $\theta$ 无关，gradient 是 0。不知道的 dynamics 恰好全部消失：

$$\nabla_\theta J=\mathbb E_{\tau\sim\pi_\theta}\Big[\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,R(\tau)\Big]$$

用 $N$ 条 trajectory 的平均估计它，再做 gradient ascent，就是 REINFORCE。它的读法很直接：$\nabla_\theta\log\pi_\theta(a\mid s)$ 是“让这个 action 更可能”的方向，按这条 trajectory 的 return 加权。和 supervised learning 的 maximum likelihood 比，区别只在每个 sample 多了一个 weight。

### 在两个 action 的问题上算一遍

只有一个 state，两个 action L、R，一步结束。$r(L)=1$，$r(R)=2$。Policy 是 $\pi_\theta(R)=\sigma(\theta)=\dfrac{1}{1+e^{-\theta}}$，$\pi_\theta(L)=1-\sigma(\theta)$。

**True gradient。** $J(\theta)=1\cdot(1-\sigma)+2\sigma=1+\sigma(\theta)$，用 $\sigma'=\sigma(1-\sigma)$ 得 $\nabla_\theta J=\sigma(1-\sigma)$。在 $\theta=0$：$\sigma=\tfrac12$，$\nabla_\theta J=0.25$。

**Score。** $\dfrac{d}{d\theta}\log\sigma=\dfrac{\sigma(1-\sigma)}{\sigma}=1-\sigma$，$\dfrac{d}{d\theta}\log(1-\sigma)=\dfrac{-\sigma(1-\sigma)}{1-\sigma}=-\sigma$。在 $\theta=0$ 分别是 $\tfrac12$ 和 $-\tfrac12$。

**单个 episode 的 REINFORCE estimate** $g=\nabla_\theta\log\pi_\theta(a)\cdot r(a)$：

| sample 到的 action | probability | $g$ |
|---|---|---|
| R | 0.5 | $\tfrac12\times2=1$ |
| L | 0.5 | $-\tfrac12\times1=-0.5$ |

Expectation 是 $0.5\times1+0.5\times(-0.5)=0.25$，等于 true gradient，unbiased。但单个 estimate 要么是 1 要么是 −0.5，variance 是 $0.5\times1^2+0.5\times0.5^2-0.25^2=0.5625$，standard deviation 0.75，是 gradient 本身的 3 倍。

注意 sample 到 L 时 estimate 是负的：L 的 reward 是正的 1，却被“惩罚”了。这是因为 score 的 expectation 为 0（下面证明），L 被 sample 到时 score 必然是负的，乘上正的 reward 就把 L 的 probability 往下压。L 只是“比 R 差”，REINFORCE 却要靠两个 sample 互相抵消才知道这一点。

### Baseline：不改变 expectation，只改变 variance

**Score 的 expectation 是 0。** 对任意 parameterized distribution，$\sum_a\pi_\theta(a)=1$ 对所有 $\theta$ 成立，两边求 gradient：

$$0=\nabla_\theta\sum_a\pi_\theta(a)=\sum_a\pi_\theta(a)\,\nabla_\theta\log\pi_\theta(a)=\mathbb E_{a\sim\pi_\theta}\big[\nabla_\theta\log\pi_\theta(a)\big]$$

（Spinning Up 叫它 EGLP lemma。）所以对任意不依赖于 action $a$ 的数 $b$（可以依赖于 state），

$$\mathbb E\big[\nabla_\theta\log\pi_\theta(a)\,(r-b)\big]=\mathbb E\big[\nabla_\theta\log\pi_\theta(a)\,r\big]-b\cdot0$$

从 reward 里减掉 $b$ 不改变 expectation。同一个 lemma 也说明 trajectory 里 $a_t$ 之前的 reward 可以从 $a_t$ 的 weight 里拿掉：它们在给定 $s_t$ 时是已经确定的数，作用和 $b$ 一样，只贡献 variance。这就是 reward-to-go，$a_t$ 只用 $\sum_{t'\ge t}r_{t'}$ 加权。

**Variance 最小的 $b$。** 记 $g=\nabla_\theta\log\pi_\theta(a)$（一个 scalar parameter 的情形）。Estimate 的 variance 是

$$\mathrm{Var}\big[g(r-b)\big]=\mathbb E\big[g^2(r-b)^2\big]-(\nabla_\theta J)^2$$

第二项和 $b$ 无关。第一项是 $b$ 的 quadratic function，对 $b$ 求 derivative 令其为 0：$-2\,\mathbb E[g^2(r-b)]=0$，所以

$$b^*=\frac{\mathbb E[g^2\,r]}{\mathbb E[g^2]}$$

即按 $g^2$ 加权的平均 reward。实际中常用 $b(s)=V(s)$，也就是不加权的平均。

在例子里，$\theta=0$ 时两个 action 的 $g^2$ 都是 $\tfrac14$，$b^*=\mathbb E[r]=1.5$。减掉 baseline 后：sample 到 R，$g=\tfrac12\times(2-1.5)=0.25$；sample 到 L，$g=-\tfrac12\times(1-1.5)=0.25$。两种结果都正好是 true gradient，variance 变成 0。现在 sample 到 L 时，L 被正确地看成“比平均差”。

:::wrong 所有 reward 加上同一个 constant，optimal policy 不变，所以对 policy gradient 没有影响
Expectation 确实不变，但 estimate 的 variance 变了。把两个 reward 都加上 $c$：sample 到 R 时 estimate 是 $\tfrac12(2+c)$，L 时是 $-\tfrac12(1+c)$。Mean 还是 0.25，standard deviation 却随 $c$ linear 增长：$c=100$ 时两种结果是 51 和 −50.5，standard deviation 50.75，是 gradient 的 200 倍。

用同一个 $\alpha=0.1$、每次 10 个 episode、reward 再加上 $N(0,1)$ 的 noise，做 200 次 update，20 个 seed（0 到 19）的结果：

| 做法 | 200 次 update 后 $\pi(R)$ 的 median | 最后 $\pi(R)<0.5$ 的 seed |
|---|---|---|
| 不用 baseline，$\alpha=0.1$ | 0.005 | 11 / 20 |
| 不用 baseline，$\alpha=0.01$ | 0.653 | 6 / 20 |
| 不用 baseline，$\alpha=0.002$ | 0.545 | 4 / 20 |
| baseline $b=\mathbb E[r]$，$\alpha=0.1$ | 0.935 | 0 / 20 |

$\alpha=0.1$ 不用 baseline 时，11 个 seed 的 $\pi(R)$ 最后都在 0.008 以下，另外 9 个都在 0.993 以上。每一步大约是在强化刚好被 sample 到的那个 action：所有 reward 都在 100 左右，被选中的 action 总被大幅推高，哪个 action 先被多 sample 几次就赢了。Step size 小到不再乱跳时，又几乎学不动。
:::

::fig[cs4246-pgvar] 单个 episode 的 estimate 的 standard deviation（reward 带 $N(0,1)$ 的 noise，$\theta=0$）。曲线是公式，点是每个 $c$ 模拟 20000 次的结果（seed 0）。

### Actor-critic：用 TD error 当 weight

Baseline 取 $V^\pi(s_t)$ 时，weight 变成 $G_t-V^\pi(s_t)$，它是 advantage $A^\pi(s_t,a_t)=Q^\pi(s_t,a_t)-V^\pi(s_t)$ 的 sample：这个 action 比这个 state 的平均好多少。$G_t$ 仍然是 MC 的 return，带着整条 trajectory 的 variance。

第 6 站的办法又能用上：用一步 reward 加下一个 state 的 value 代替 return。TD error $\delta_t=r_{t+1}+\gamma V^\pi(s_{t+1})-V^\pi(s_t)$ 在给定 $(s_t,a_t)$ 时的 expectation 是

$$\mathbb E[\delta_t\mid s_t,a_t]=\mathbb E[r_{t+1}+\gamma V^\pi(s_{t+1})\mid s_t,a_t]-V^\pi(s_t)=Q^\pi(s_t,a_t)-V^\pi(s_t)=A^\pi(s_t,a_t)$$

所以用 $\delta_t$ 当 weight，在 $V^\pi$ 准确时仍是 unbiased 的，而 variance 只来自一步。实际中 $V^\pi$ 要另外学一个 $V_\phi$（叫 critic，policy 叫 actor），critic 不准时 gradient 就带上 bias。这和第 6 站 MC 与 TD 的交换完全一样：用自己的估计换来更小的 variance，代价是估计不准时的 bias。

:::edge 那个“loss”不是 loss
实现 REINFORCE 时，通常写一个 $L(\theta)=-\frac1N\sum\log\pi_\theta(a_t\mid s_t)\,\hat A_t$ 交给 autodiff。它在当前 $\theta$ 处的 gradient 等于 $-\nabla_\theta J$，但它本身不衡量 performance：data 是当前 policy 产生的，换了 $\theta$ 就该换 data。在同一批 data 上把它一直 minimize 下去，它可以趋向 $-\infty$，policy 却变差。监控训练只能看 average return。
:::

### GAE：在一步 TD error 和整条 return 之间连续地调

Actor-critic 用 $\delta_t$ 当 weight，critic 不准时有 bias；REINFORCE 加 baseline 用 $G_t-V(s_t)$，没有这个 bias，但 variance 大。中间有一整排选择：先走 $k$ 步真的 reward，再用 critic 接上。

$$\hat A_t^{(k)}=r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{k-1}r_{t+k}+\gamma^kV(s_{t+k})-V(s_t)$$

它可以写成 $k$ 个 TD error 的和。以 $k=2$ 为例，把 $\delta_t+\gamma\delta_{t+1}$ 展开：

$$\big(r_{t+1}+\gamma V(s_{t+1})-V(s_t)\big)+\gamma\big(r_{t+2}+\gamma V(s_{t+2})-V(s_{t+1})\big)=r_{t+1}+\gamma r_{t+2}+\gamma^2V(s_{t+2})-V(s_t)$$

中间的 $\gamma V(s_{t+1})$ 正负抵消。一般地 $\hat A_t^{(k)}=\sum_{l=0}^{k-1}\gamma^l\delta_{t+l}$（和[第 6 站](#td)“MC error 是 TD error 之和”是同一个 telescoping）。$k=1$ 是 actor-critic 的 $\delta_t$，$k\to\infty$ 是 $G_t-V(s_t)$。

Generalized advantage estimation（GAE）不挑一个 $k$，而是把所有 $k$ 按 $\lambda\in[0,1]$ 做指数加权平均：

$$\hat A_t^{\text{GAE}(\gamma,\lambda)}=(1-\lambda)\big(\hat A_t^{(1)}+\lambda\hat A_t^{(2)}+\lambda^2\hat A_t^{(3)}+\cdots\big)$$

把每个 $\hat A_t^{(k)}$ 换成 TD error 的和，再按 $\delta_{t+l}$ 合并。$\delta_t$ 出现在每一个 $\hat A^{(k)}$ 里，系数是 $1+\lambda+\lambda^2+\cdots=\frac1{1-\lambda}$；$\gamma\delta_{t+1}$ 从 $k=2$ 开始出现，系数是 $\lambda+\lambda^2+\cdots=\frac{\lambda}{1-\lambda}$；$\gamma^l\delta_{t+l}$ 的系数是 $\frac{\lambda^l}{1-\lambda}$。乘上前面的 $1-\lambda$：

$$\hat A_t^{\text{GAE}(\gamma,\lambda)}=\sum_{l=0}^{\infty}(\gamma\lambda)^l\,\delta_{t+l}$$

$\lambda=0$ 只剩 $\delta_t$；$\lambda=1$ 是 $\sum_l\gamma^l\delta_{t+l}=G_t-V(s_t)$。实际算的时候不用这个 sum，而是从一段 trajectory 的末尾往回递推：

$$\hat A_t=\delta_t+\gamma\lambda\,\hat A_{t+1}$$

Episode 在 $t+1$ 结束时，$s_{t+1}$ 之后没有将来，$\delta_t$ 里不加 $\gamma V(s_{t+1})$，递推也在这里断开。一段 rollout 在 episode 中间截断时，最后一步照常用 $V(s_T)$ bootstrap。

**手算一段。** 用第 2 站的 MDP，critic 估得不准：$V(A)=10$、$V(B)=15$（true value 在下面）。$\gamma=0.9$，一段 3 步的 rollout 是 A 选 go 拿 0 到 B，B 拿 2 留在 B，B 拿 2 回到 A，截断在 A：

$$\delta_0=0+0.9\times15-10=3.5,\qquad\delta_1=2+0.9\times15-15=0.5,\qquad\delta_2=2+0.9\times10-15=-4$$

$\lambda=0.95$，$\gamma\lambda=0.855$，从后往前：$\hat A_2=-4$，$\hat A_1=0.5+0.855\times(-4)=-2.92$，$\hat A_0=3.5+0.855\times(-2.92)=1.003$。$\lambda=1$ 时 $\hat A_0=3.5+0.9\times0.5+0.81\times(-4)=0.71$，和直接算 $0+0.9\times2+0.81\times2+0.729\times10-10=0.71$ 一致。

**$\lambda$ 交换的是什么。** 让 A 上的 policy 以 0.5、0.5 选 stay 和 go（$\pi(\text{go})=\sigma(\theta)$，$\theta=0$），其余不变。解 Bellman expectation equation 得 $v_\pi(A)=15.547$、$v_\pi(B)=17.891$，于是 $A^\pi(A,\text{go})=0.9\times17.891-15.547=0.555$，$A^\pi(A,\text{stay})=1+0.9\times15.547-15.547=-0.555$。在 A 上对 $\theta$ 的 true gradient 是 $0.5\times0.5\times0.555+0.5\times(-0.5)\times(-0.555)=0.277$。从 A 出发、每段 30 步，模拟 400000 段（seed 0），看单个 estimate $\nabla_\theta\log\pi(a_0)\,\hat A_0$：

| $\lambda$ | critic 准确：mean | std | critic 是 (10, 15)：mean | std |
|---|---|---|---|---|
| 0 | 0.277 | 0.000 | 0.876 | 0.875 |
| 0.5 | 0.277 | 0.151 | 0.643 | 1.204 |
| 0.95 | 0.278 | 0.504 | 0.326 | 2.284 |
| 1 | 0.278 | 0.633 | 0.282 | 2.776 |

Critic 准确时每一行都 unbiased，$\lambda$ 越大 std 越大，$\lambda=0$ 连 std 都是 0（和上面 baseline 取 $\mathbb E[r]$ 时一样）。Critic 不准时，$\lambda=0$ 的 mean 是 true gradient 的 3 倍多，$\lambda$ 增大 bias 迅速变小，std 跟着变大；$\lambda=1$ 剩下的一点偏差来自第 30 步用不准的 $V$ bootstrap。GAE 论文的结论正是这样：$\lambda<1$ 只在 $V$ 不准时引入 bias，$\gamma<1$ 不管 $V$ 准不准都改变 objective，所以实践中 $\lambda$ 取得比 $\gamma$ 小（Assignment 2 用 $\gamma=0.99$、$\lambda=0.95$）。

### PPO：一批 data 用很多次

REINFORCE 和 actor-critic 每收一批 data，只做一步 gradient ascent 就扔掉，因为 gradient 的 formula 要求 data 来自当前的 $\pi_\theta$，走一步之后就不是了。上面“loss 不是 loss”说的也是这件事。和环境交互通常比算 gradient 贵得多（Assignment 2 一共要 800000 步交互），想在同一批 data 上多走几步。

**Importance sampling。** 对任意 $f$，

$$\mathbb E_{a\sim\pi_\theta}[f(a)]=\sum_a\pi_\theta(a)f(a)=\sum_a\pi_{\text{old}}(a)\frac{\pi_\theta(a)}{\pi_{\text{old}}(a)}f(a)=\mathbb E_{a\sim\pi_{\text{old}}}\Big[\frac{\pi_\theta(a)}{\pi_{\text{old}}(a)}f(a)\Big]$$

用旧 policy 的 data 估计新 policy 下的 expectation，只要乘上 probability ratio $r_t(\theta)=\pi_\theta(a_t\mid s_t)/\pi_{\theta_{\text{old}}}(a_t\mid s_t)$。把它用在每一步的 advantage 上，得到 surrogate objective

$$L^{CPI}(\theta)=\hat{\mathbb E}_t\big[r_t(\theta)\,\hat A_t\big]$$

在 $\theta=\theta_{\text{old}}$ 处，$\nabla_\theta r_t=\nabla_\theta\pi_\theta/\pi_{\theta_{\text{old}}}=\nabla_\theta\log\pi_\theta$（因为这时 $\pi_\theta=\pi_{\theta_{\text{old}}}$），所以 $\nabla L^{CPI}$ 正好是 policy gradient。离开 $\theta_{\text{old}}$ 之后它只是近似：严格的 importance sampling 还要乘上 state distribution 的 ratio $p_\theta(s_t)/p_{\theta_{\text{old}}}(s_t)$，那一项被丢掉了（CS285 Lecture 5 说可以忽略它，由此带来多大的 error 留到后面的 lecture 再界定）；而且 $\hat A_t$ 只是几个 sample。

**不加限制会怎样。** 回到两个 action 的例子，$\theta_{\text{old}}=0$，baseline 1.5，reward 带 $N(0,1)$ 的 noise。假设这一批只有一个 episode，选了 L，reward 碰巧是 2.3，$\hat A=2.3-1.5=+0.8$。这时 $r_L(\theta)=(1-\sigma(\theta))/0.5$，$L^{CPI}(\theta)=0.8\times(1-\sigma(\theta))/0.5$，对 $\theta$ 单调递减，一直 maximize 下去 $\theta\to-\infty$，$\pi(R)\to0$：一个运气好的 sample 让 policy 确定地选了差的那个 action。

**Clip。** PPO 把 objective 换成

$$L^{CLIP}(\theta)=\hat{\mathbb E}_t\Big[\min\big(r_t(\theta)\hat A_t,\ \text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\,\hat A_t\big)\Big]$$

论文和 Assignment 2 都取 $\epsilon=0.2$。上面那个 sample：$r_L\le1.2$ 时两项里小的是 $0.8\,r_L$，随 $r_L$ 增大而增大；$r_L>1.2$ 时小的是 $1.2\times0.8=0.96$，是常数，gradient 为 0。所以这一批最多把 $r_L$ 推到 1.2，即 $\pi(L)=0.6$、$\pi(R)=0.4$，$\theta=\ln(0.4/0.6)=-0.405$。下一批 data 由新的 policy 收集，错误还有机会被纠正。

::fig[cs4246-clip] 单个 sample 的 $L^{CLIP}$ 随 ratio $r$ 变化，$\epsilon=0.2$。左边 $\hat A>0$，右边 $\hat A<0$；虚线是没有 clip 的 $r\hat A$。看平的那一段只出现在“继续走下去看起来会更好”的那一侧。

**为什么取 min。** Clip 只截掉“看起来变好”的那一侧。设经过几个 epoch 之后，因为别的 sample 的拉动，某个 $\hat A=-0.5$ 的 sample 的 ratio 已经变成 1.5，也就是一个“比平均差”的 action 反而变得更可能了。这时 $\min(1.5\times(-0.5),\ 1.2\times(-0.5))=\min(-0.75,-0.6)=-0.75$，取的是没有 clip 的那一项，gradient 照常把 ratio 往回拉。如果同样 ratio 1.5 的 sample 的 $\hat A=+0.5$，$\min(0.75,0.6)=0.6$，取的是 clip 后的常数，不再往前推。PPO 论文把这叫 pessimistic bound：objective 永远不高于没有 clip 的 $L^{CPI}$，改进只算到 $1\pm\epsilon$ 为止，变差则全额计入。

**完整的 loss。** Assignment 2 和论文一样，把三部分合成一个交给 optimizer minimize 的量：

$$J^{PPO}(\theta)=-L^{CLIP}(\theta)+c_1L^{VF}(\theta)-c_2H(\theta),\qquad H(\theta)=-\hat{\mathbb E}_{s_t}\Big[\sum_a\pi_\theta(a\mid s_t)\log\pi_\theta(a\mid s_t)\Big]$$

$L^{VF}$ 是 critic 对 return 的 squared error（Assignment 2 还用了 clip 过的版本，取两者中大的），$H$ 是 policy 的 entropy。两个 action 的 policy 在 $\pi(R)=0.5$ 时 $H=\ln2=0.693$，在 0.4 时是 $-(0.4\ln0.4+0.6\ln0.6)=0.673$，越确定越小；减去 $c_2H$ 等于奖励 policy 保持随机，延缓它过早收缩到一个 action 上，作用和第 5 站的 exploration 一样。Assignment 2 取 $c_1=0.5$、$c_2=0.01$。

**一轮 iteration。** 按论文的 Algorithm 1：$N$ 个环境并行，各用 $\pi_{\theta_{\text{old}}}$ 跑 $T$ 步；对这 $NT$ 个 transition 用 GAE 算 $\hat A_t$；把它们打乱分成 minibatch，在 $J^{PPO}$ 上做 $K$ 个 epoch 的 gradient step；然后 $\theta_{\text{old}}\leftarrow\theta$。Assignment 2 是 $N=4$、$T=128$，每批 512 个 transition，分 4 个 minibatch、做 4 个 epoch，800000 步一共 $\lfloor800000/512\rfloor=1562$ 轮。

:::back
Actor-critic 和 GAE 的 bias 与 variance 的交换就是[第 6 站](#td)的 MC 对 TD，GAE 的 telescoping 也和那里“MC error 是 TD error 之和”相同。Critic 用 neural network 时，[第 7 站](#fa)的稳定性问题同样存在；PPO 的 rollout buffer 用完就扔，和 DQN 的 replay buffer 反复使用旧 data 正好相反。
:::

## [mcts] Monte Carlo tree search 与 UCT

:::skip
能按 UCT 手算几轮 iteration，说明 flat Monte Carlo search 为什么会选错，并解释 UCT 的 node value 为什么趋向 max，就读完这门课了。
:::

### 只为眼前这个 state 做决定

前面的方法都试图算出全局的东西：每个 state 的 value，或者在所有 state 上都好的 policy。围棋大约有 $10^{170}$ 个 state，这做不到。但下棋的时候只需要知道“现在这一步走哪里”。如果有一个 model（至少能 sample：给定 $s,a$ 返回一个 $s'$ 和 $r$），可以从当前 state 往前看。

最直接的往前看是 expectimax：把从当前 state 出发、深度 $H$ 以内的所有 action 和 transition 展开成一棵 tree，从 leaf 往上取 expectation 和 max。树的大小是 $(|S||A|)^H$ 量级，深一点就不可能。需要一种只展开“值得展开”的部分的 search。

### Flat Monte Carlo search 会选错

一个两层的例子。在 root 选 a 或 b；选了 a 之后再选 a1 或 a2，选了 b 之后再选 b1 或 b2；然后 episode 结束，拿到一个 Bernoulli 的 reward，各自的 probability 是

$$a1:0.2,\qquad a2:0.9,\qquad b1:0.6,\qquad b2:0.6$$

Optimal 是先 a 再 a2，value 0.9；b 那边最好也只有 0.6。

最简单的 search：对 root 的每个 action，用 random 的第二步（rollout policy）跑 $K$ 次，取平均 return，选平均最大的。它估计的是“选 a 之后 random 地走”的 value：$\tfrac12\times0.2+\tfrac12\times0.9=0.55$；b 是 0.6。所以 $K$ 再大也会选 b。实际跑 $K=1000$（seed 3）：a 是 0.58，b 是 0.60。

::fig[cs4246-flatmc] 两层的例子。Flat MC 给 a 的估计是 random 第二步的平均，不是第二步选对之后的 value。

问题在于 rollout 后面的决策是 random 的，而真正执行时第二步会选好的那个。要估计 a 的 value，第二步也得逐渐变成 optimal 的。

### UCT：每个 node 都是一个 bandit

Monte Carlo tree search（MCTS）维护一棵从当前 state 长出来的树，每个 node 记录被经过的次数 $N$ 和 return 的总和 $W$。每次 iteration 做四件事：

1. **Selection。** 从 root 往下，在每个已经展开的 node 选一个 child，直到遇到还有 action 没展开的 node。
2. **Expansion。** 给它加一个新的 child。
3. **Simulation。** 从新 child 用 rollout policy（这里是 random）走到结束，得到 return。
4. **Backup。** 把 return 加到 path 上每个 node 的 $W$，$N$ 加 1。

Selection 时在 child 之间怎么选，就是第 5 站的问题：每个 node 的 child 是 arm，经过它的 return 是 reward。UCT 在每个 node 上用 UCB1：

$$\text{UCT}(\text{child})=\frac{W_{\text{child}}}{N_{\text{child}}}+c\sqrt{\frac{\ln N_{\text{parent}}}{N_{\text{child}}}}$$

这里 reward 在 $[0,1]$ 之间，取 $c=\sqrt2$，正好是第 5 站的 $\sqrt{2\ln t/N}$。

在上面的例子上跑 12 次 iteration（seed 3）。前两次分别展开 a、b 并 rollout；之后：

| iteration | root 上 UCT（a，b） | 第二层 | reward |
|---|---|---|---|
| 1 | | 展开 a，rollout 走 a2 | 1 |
| 2 | | 展开 b，rollout 走 b1 | 0 |
| 3 | 2.177，1.177 → a | 展开 a1 | 0 |
| 4 | 1.548，1.482 → a | 展开 a2 | 1 |
| 5 | 1.628，1.665 → b | 展开 b1 | 1 |
| 6 | 1.703，1.769 → b | 展开 b2 | 1 |
| 7 | 1.760，1.760 → a | a1：1.482，a2：2.482 → a2 | 1 |
| 8 | 1.736，1.806 → b | b1：2.482，b2：2.482 → b1 | 0 |
| 9 | 1.770，1.520 → a | a1：1.665，a2：2.177 → a2 | 1 |
| 10 | 1.737，1.548 → a | a1：1.794，a2：2.036 → a2 | 1 |
| 11 | 1.709，1.573 → a | a1：1.893，a2：1.947 → a2 | 1 |
| 12 | 1.685，1.595 → a | a1：1.973，a2：1.882 → a1 | 0 |

核对第 4 次：root 已经被经过 3 次。a 被经过 2 次、return 总和 1，$\tfrac12+\sqrt2\sqrt{\ln3/2}=0.5+1.048=1.548$；b 被经过 1 次、总和 0，$0+\sqrt2\sqrt{\ln3}=1.482$。第 12 次，a1 的 mean 是 0，但它只被试过 1 次，bonus $\sqrt2\sqrt{\ln7}=1.973$ 超过了 a2 的 $1+\sqrt2\sqrt{\ln7/5}=1.882$，又被试一次：和第 5 站一样，没被试够的 arm 迟早会被再看一眼。

::fig[cs4246-mcts] 50 次 iteration 之后的树。

### 为什么 node 的 value 趋向 max

Flat search 的错在于 a 的估计是两个 child 的平均。看 UCT 里 a 这个 node：它的 $W/N$ 是经过它的所有 return 的平均，而经过它之后选 a1 还是 a2，由 a 上的 bandit 决定。第 5 站证明了 suboptimal arm 只被拉 $O(\log n)$ 次，所以 $n$ 次经过 a 之后，几乎全部来自 a2，a 的平均趋向 $\max(0.2,0.9)=0.9$，而不是 0.55。Root 上的 bandit 看到的就是这个越来越准的 0.9 对 b 的 0.6。

同一个 seed 继续跑：

| iteration | a：$N$，mean | a2：$N$，mean | b：$N$，mean |
|---|---|---|---|
| 50 | 37，0.811 | 32，0.906 | 13，0.462 |
| 200 | 174，0.874 | 162，0.920 | 26，0.462 |
| 1000 | 937，0.895 | 917，0.911 | 63，0.540 |

a 的 mean 从 0.81 往 0.9 靠，b 只占 6% 的 simulation。树越深，这个论证一层一层往上套：每一层的 bandit 让自己的 node 的 value 趋向“下面 optimal 地走”的 value。Silver 第 8 讲的说法是 tree policy 随 simulation 不断改进，tree 内的 $Q$ converge 到 $q^*$。

:::wrong 多跑 rollout，平均 return 高的 action 就是好的
平均 return 估计的是“这一步之后按 rollout policy 走”的 value。Rollout policy 越差，这个估计离 optimal 越远，而且多跑只会让它更准地 converge 到那个错的值：上面 $K=1000$ 时仍然选 b。要让估计趋向 optimal 的 value，rollout 之前的那部分（tree policy）必须随 simulation 改进，这就是 MCTS 比 flat search 多出来的东西。更好的 rollout policy 也有帮助：AlphaGo 一类的系统用学出来的 policy 和 value network 代替 random rollout。
:::

:::edge 最后选哪个 action
Search 结束后，root 上选哪个 child？CS188 的做法是选 $N$ 最大的，而不是 mean 最大的。$N$ 最大的 child 是 UCT 反复确认过的；mean 最大的可能只是被试了一两次、运气好。上面 50 次之后两种选法一致（a：37 次、0.811），iteration 少时可能不一致。
:::

:::back
Selection 用的是[第 5 站](#bandit)的 UCB1；“tree 内的 value 趋向 max”是[第 3 站](#dp) value iteration 的 sample 版本，只在当前 state 附近做。
:::

:::from
“只为当前 state 计算”的动机、expectimax 树的大小、UCT 把每个 node 当成 bandit，跟的是 [CS234 Lecture 13](https://web.stanford.edu/class/cs234/slides/lecture13post.pdf)；simple Monte Carlo search、in-tree 与 out-of-tree 的两段、MCTS 的优点，来自 [Silver 第 8 讲](https://davidstarsilver.wordpress.com/wp-content/uploads/2025/04/lecture-8-integrating-learning-and-planning.pdf)（那一讲没有写 UCT 的 formula）；selection、expansion、simulation、backup 四步、UCB1 的写法和“最后选 $N$ 最大的 child”来自 [CS188 Lecture 7](https://inst.eecs.berkeley.edu/~cs188/archive/fa23/assets/lectures/cs188-fa23-lec07.pdf)。两层的例子、flat search 选错的计算、12 次 iteration 的手算表和后续的数字是为这一页算的。

### Assignment 2（AY25/26）：用 PPO 训练 actor-critic 控制电梯

**要做的**：环境是 pyRDDLGym 里的 Elevator domain（`selfDefinedEnvs/domain.rddl` 和 `instance5.rddl`）：5 层、1 部电梯，乘客按 Poisson process 在各层出现、都要去最底层，horizon 200 步；电梯里每有一个人每步扣 0.75，每层每个等待的人每步扣 3，送到一个人加 30（RDDL 文件）。Notebook 要你补完：actor 和 critic network 的 input、output 维度，`get_value`、`get_probs`（用 `Categorical`）、`get_action`、`get_action_logprob`（Task 1）；TD error $\delta_t$（Task 2）；probability ratio、clipped surrogate objective、带 clip 的 value loss、total loss（Task 3）。然后用固定的 hyperparameter 训练 800000 步并保存 `model.pth`。**对应的站**：[第 8 站](#pg)的 actor-critic、GAE、PPO 三节。**算力**：notebook 鼓励用 Colab；network 只有几层 64 到 128 宽的 MLP，环境步进在 CPU 上跑（经验）。

- 每个 task 后面都有带具体数字的 assert，`run_all_checks` 会把它们集中跑一遍；先让这些 check 全过再开始训练（notebook）。
- $\delta_t$ 要用 `next_nonterminal` 处理 episode 结束：结束的那一步不加 $\gamma V(s_{t+1})$（notebook 的 hint）。第 8 站 GAE 一节讲了为什么。
- Ratio 按 $\exp(\log\pi_\theta-\log\pi_{\text{old}})$ 算，不要直接除两个 probability，后者在 probability 很小时数值不稳（notebook）。
- Notebook 的 total loss 是 $-J^{CLIP}+c_1L^{VF}-c_2H$，交给 optimizer 去 minimize；符号写反，训练会朝着变差的方向走（notebook、经验）。
- Reward 在存进 buffer 前按环境的最小、最大 reward 做了 min-max 缩放，最小值 $-0.75\times10-3\times3\times5=-52.5$，最大值 $10\times30=300$，这段代码是给定的，不要改（notebook）。
- 训练是否正常的参照：第 300 个 episode 左右总 reward 约 −4000，第 1500 个左右约 −3000；明显差得多就回头查实现（notebook）。
- Hyperparameter 和 random seed（2048）标着不要改；learning rate 从 $2.5\times10^{-4}$ 线性降到接近 0，是训练循环里给定的（notebook）。
