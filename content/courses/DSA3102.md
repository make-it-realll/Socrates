## [convex] Convex set、convex function 与 modelling

:::skip
能说清 convex problem 的 local minimum 为什么一定是 global minimum，会用 Hessian 和三条组合规则判断 lasso、logistic regression、SVM 的 objective 是 convex 的，就可以去第 2 站。
:::

### 局部的信息什么时候够用

开头第一次计算的 function 是 $f(x)=x^4-50x^2+100x$。它的 derivative $f'(x)=4x^3-100x+100$ 有三个 root：

| $x$ | $f(x)$ | $f''(x)=12x^2-100$ | 是什么 |
|---|---|---|---|
| $-5.440$ | $-1147.9$ | 255 | global minimum |
| $1.046$ | 51.1 | $-87$ | local maximum |
| $4.394$ | $-153.2$ | 132 | local minimum |

Gradient descent（这里 step size 取 0.001）每一步只看当前点的 derivative。到了 $x=4.394$，derivative 是 0，algorithm 停下；second derivative 是正的，附近每个点都比它高。站在这一点上能得到的所有局部信息，和站在 $-5.440$ 上完全一样。

::fig[dsa3102-quartic] 从 $x=3$ 和 $x=-3$ 出发的 gradient descent，各自停在一个 $f'=0$ 的点。只看局部，两个点无法区分。

要让“gradient 为 0”成为全局的结论，function 必须满足某种全局的条件。这个条件就是 convexity。

### Convex set 与 convex function

一个 set $C$ 是 convex 的，如果其中任意两点之间的 segment 都在 $C$ 里：$x,y\in C$、$0\le\theta\le1$ 时，$\theta x+(1-\theta)y\in C$。Halfspace $\{x:a^\top x\le b\}$、ball $\{x:\|x\|\le1\}$、它们的 intersection 都是 convex 的；sphere $\{x:\|x\|=1\}$ 不是，两个 antipodal 点的 midpoint 是 0，不在 sphere 上。

一个 function $f$ 是 convex 的，如果它的 domain 是 convex set，并且任意两点之间，graph 都在 chord 的下方：

$$f\big(\theta x+(1-\theta)y\big)\le\theta f(x)+(1-\theta)f(y),\qquad0\le\theta\le1$$

拿开头的 quartic 检验，取那两个 local minimum 和 $\theta=\tfrac12$。Midpoint 是 $-0.523$，$f(-0.523)=-65.9$；两端 function value 的平均是 $\tfrac12(-1147.9-153.2)=-650.5$。Graph 在 chord 上方 585，不满足定义。

一个 optimization problem

$$\min_x\ f_0(x)\quad\text{subject to}\quad f_i(x)\le0\ (i=1,\dots,m),\qquad Ax=b$$

叫 convex problem，如果 $f_0$ 和每个 $f_i$ 都是 convex function。这时 feasible set 是 convex 的：$f_i$ convex 推出 $\{x:f_i(x)\le0\}$ convex（$f_i(x)\le0$、$f_i(y)\le0$ 时，由定义 $f_i(\theta x+(1-\theta)y)\le0$），affine 的 equality 给出的是 hyperplane，convex set 的 intersection 仍是 convex 的。

### 为什么 local minimum 就是 global minimum

设 $x$ 是 convex problem 的 feasible point，并且是 local minimum：存在 $R>0$，凡是与 $x$ 距离小于 $R$ 的 feasible point $z$，都有 $f_0(z)\ge f_0(x)$。假设它不是 global minimum，即存在 feasible 的 $y$，$f_0(y)<f_0(x)$。

$y$ 一定离 $x$ 至少 $R$，否则直接和 local minimum 矛盾。在 $x$ 到 $y$ 的 segment 上取一点，让它离 $x$ 恰好 $R/2$：

$$z=(1-\theta)x+\theta y,\qquad\theta=\frac{R}{2\|y-x\|}\in\big(0,\tfrac12\big]$$

$z-x=\theta(y-x)$，所以 $\|z-x\|=R/2<R$。Feasible set 是 convex 的，$z$ feasible。由 $f_0$ 的 convexity，

$$f_0(z)\le(1-\theta)f_0(x)+\theta f_0(y)<(1-\theta)f_0(x)+\theta f_0(x)=f_0(x)$$

第二个不等号用了 $\theta>0$ 和 $f_0(y)<f_0(x)$。于是在 $x$ 的 $R$ 范围内找到了一个更小的 feasible point，矛盾。

Proof 里真正起作用的是：从 $x$ 朝更好的点 $y$ 走，function value 沿路不会先升后降。Quartic 在两个 local minimum 之间正是先升（越过 $x=1.046$ 处的 local maximum）后降，所以从 $4.394$ 出发，往左走一小步只会变大。

### 用 derivative 判断 convexity

按定义检验要对所有 $x,y,\theta$ 成立，不好用。可 differentiate 的时候有两个等价的条件。

**First-order condition。** $f$ 是 convex 的，当且仅当对所有 $x,y$，

$$f(y)\ge f(x)+\nabla f(x)^\top(y-x)$$

右边是 $f$ 在 $x$ 处的 tangent（多元时是 tangent plane）。这个条件说的是 tangent 处处在 graph 下方，是 $f$ 的 global underestimator。从定义推出它只要一行：把定义改写成 $f\big(x+\theta(y-x)\big)\le f(x)+\theta\big(f(y)-f(x)\big)$，移项除以 $\theta$，

$$\frac{f\big(x+\theta(y-x)\big)-f(x)}{\theta}\le f(y)-f(x)$$

令 $\theta\to0$，左边是 directional derivative $\nabla f(x)^\top(y-x)$。

它的推论正是开头要的东西：如果 $\nabla f(x)=0$，那么对所有 $y$ 都有 $f(y)\ge f(x)$，$x$ 是 global minimum。一个点上的 value 和 gradient，给出了整个 function 的 lower bound。

::fig[dsa3102-tangent] 左边是 convex 的 logistic loss，tangent 处处在 graph 下方；右边是 quartic，$x=1$ 处的 tangent 在 $x=-5.44$ 处比 graph 高出 1173。

左图的数：logistic loss $\ell(z)=\log(1+e^{-z})$，$\ell(0)=\log2=0.693$，$\ell'(z)=-\dfrac{1}{1+e^{z}}$，$\ell'(0)=-\tfrac12$，tangent 是 $0.693-\tfrac12z$。在 $z=-4$，$\ell=4.018$，tangent 是 2.693；在 $z=4$，$\ell=0.018$，tangent 是 $-1.307$。两处都在下方。右图：$f(1)=51$，$f'(1)=4$，tangent $51+4(x-1)$ 在 $x=-5.44$ 处是 25.2，而 $f(-5.44)=-1147.9$。

**Second-order condition。** Twice differentiable 时，$f$ convex 当且仅当 Hessian 处处 positive semidefinite：$\nabla^2f(x)\succeq0$。一元时就是 $f''\ge0$。用三次：

- Quartic：$f''(x)=12x^2-100$，在 $|x|<2.89$ 时为负，不是 convex。
- Least squares $f(\beta)=\tfrac12\|X\beta-y\|^2$：$\nabla f=X^\top(X\beta-y)$，$\nabla^2f=X^\top X$。对任何 $v$，$v^\top X^\top Xv=\|Xv\|^2\ge0$，所以是 convex。
- Logistic loss：$\ell''(z)=\sigma(z)\big(1-\sigma(z)\big)>0$，$\sigma$ 是 sigmoid，是 convex。

### 不求 derivative 的三条规则

很多 objective 有 kink，没有 Hessian。下面三条规则只用定义就能 prove，组合起来能处理这门课里几乎所有的 model。

1. **Nonnegative weighted sum。** $f_1,f_2$ convex、$w_1,w_2\ge0$，则 $w_1f_1+w_2f_2$ convex。把两个定义里的 inequality 分别乘 $w_i$ 相加即可。
2. **Affine composition。** $f$ convex，则 $g(x)=f(Ax+b)$ convex。因为 $A(\theta x+(1-\theta)y)+b=\theta(Ax+b)+(1-\theta)(Ay+b)$，affine map 把 segment 送到 segment。
3. **Pointwise maximum。** $f_1,\dots,f_m$ convex，则 $\max_if_i$ convex。对每个 $i$，$f_i(\theta x+(1-\theta)y)\le\theta f_i(x)+(1-\theta)f_i(y)\le\theta\max_jf_j(x)+(1-\theta)\max_jf_j(y)$，右边与 $i$ 无关，左边对 $i$ 取 max 即得。

再加一个基本的事实：每个 norm 都是 convex 的，由 triangle inequality 和 homogeneity，$\|\theta x+(1-\theta)y\|\le\theta\|x\|+(1-\theta)\|y\|$。

用这几条检验三个 data science 里的 model：

| Model | Objective | 为什么 convex |
|---|---|---|
| Lasso | $\tfrac12\lVert X\beta-y\rVert^2+\lambda\lVert\beta\rVert_1$ | 第一项 Hessian 为 $X^\top X\succeq0$；第二项是 norm；规则 1 |
| $\ell_1$-regularized logistic regression | $\sum_i\ell\big(y_ix_i^\top\beta\big)+\lambda\lVert\beta\rVert_1$，$y_i\in\{\pm1\}$ | $\ell$ convex，规则 2 处理 $y_ix_i^\top\beta$，再用规则 1 |
| Soft-margin SVM | $\tfrac12\lVert w\rVert^2+C\sum_i\max\big(0,\ 1-y_i(w^\top x_i+b)\big)$ | Hinge loss 是两个 affine function 的 max（规则 3），规则 1 |

Logistic regression 和 SVM 的 model 本身是怎么来的，见 [CS2109S 的 logistic regression](../courses/CS2109S.html#logreg) 和 [SVM](../courses/CS2109S.html#svm) 两站，这里只关心它们作为 optimization problem 的性质。

拿开头那组 data 写出两个具体的问题。Least squares：

$$f(\beta)=\tfrac12\|X\beta-y\|^2,\qquad X^\top X=\begin{pmatrix}6&5\\5&6\end{pmatrix},\qquad X^\top y=\begin{pmatrix}17\\16\end{pmatrix}$$

Normal equations $X^\top X\beta=X^\top y$（见 [DSA2102 第 4 站](../courses/DSA2102.html#ls)）给出 $\beta^\star=(2,1)$，residual $y-X\beta^\star=(1,1,-3)$，$f^\star=\tfrac12\times11=5.5$。Lasso 取 $\lambda=14$：

$$F(\beta)=\tfrac12\|X\beta-y\|^2+14\,\|\beta\|_1$$

第 2 站会 prove 它的 minimum 在 $\beta=(\tfrac12,0)$，$F^\star=29.75$。

:::wrong 两个 convex function 套在一起还是 convex 的
$g(x)=x^2-1$ 和 $h(u)=u^2$ 都是 convex 的，$h(g(x))=(x^2-1)^2$ 却不是：$x=\pm1$ 处等于 0，midpoint $x=0$ 处等于 1，graph 跑到了 chord 上方。它有两个 global minimum，中间夹着一个 local maximum。

Composition 只在外层 function monotone 的配合下才保持 convexity：$h$ convex 且 nondecreasing、$g$ convex 时，$h\circ g$ convex（一元时 $(h\circ g)''=h''(g)\,g'^2+h'(g)\,g''$，两项都 $\ge0$）。这里 $h(u)=u^2$ 在 $u<0$ 上是 decreasing 的，而 $g$ 在 $|x|<1$ 时取负值，规则不适用。$\|X\beta-y\|^2$ 没有这个问题，它是 convex function $\|\cdot\|^2$ 与 affine map 的 composition，用的是规则 2。
:::

:::edge Convex 不保证 minimum 存在，也不保证唯一
$e^x$ 是 convex 的，但没有 minimum，只有 infimum 0。$\tfrac12(\beta_1+\beta_2-1)^2$ 是 convex 的，它的 minimum 是整条 line $\beta_1+\beta_2=1$。Convexity 保证的是：所有 local minimum 的 value 相同，并且 minimizer 组成一个 convex set。Strictly convex（定义里的 $\le$ 换成 $<$）才保证至多一个 minimizer；least squares 在 $X$ 的 column linearly independent 时就是 strictly convex 的。
:::

## [subgrad] Subgradient 与 optimality condition

:::skip
能写出 $|x|$ 在 0 处的 subdifferential，由 $0\in\partial f$ 推出 soft-thresholding，并用 lasso 的 optimality condition 验证 $\beta=(\tfrac12,0)$ 是 optimal 的，就可以去第 3 站。
:::

### 令 derivative 等于 0 走不通

Lasso 的 $\|\beta\|_1$ 在任何一个 coordinate 等于 0 的地方都没有 derivative。先看只有一个 parameter 的情形：

$$\varphi(\beta)=\tfrac12(\beta-v)^2+\lambda|\beta|,\qquad v=0.8,\quad\lambda=1$$

$\beta>0$ 时 $\varphi'(\beta)=\beta-0.8+1=\beta+0.2>0$；$\beta<0$ 时 $\varphi'(\beta)=\beta-0.8-1=\beta-1.8<0$。Derivative 在哪里都不等于 0，minimum 却明明存在：左边一直下降、右边一直上升，minimum 在 $\beta=0$，恰好是没有 derivative 的那一点。

::fig[dsa3102-kink] $\varphi$ 的 graph。黑色短线是 kink 两侧的 slope，一个是 $-1.8$，一个是 $0.2$。

Lasso 之所以能做 feature selection，就是因为 minimum 常常落在这种 kink 上。所以需要一个在 kink 处也能用的 optimality condition。

### Subgradient 的定义

上一站说，convex function 的 tangent 是 global underestimator。Kink 处没有 tangent，但仍然有很多条过这一点、整体在 graph 下方的 line。把它们的 slope 都收集起来：$g$ 叫 $f$ 在 $x$ 处的 **subgradient**，如果

$$f(y)\ge f(x)+g^\top(y-x)\qquad\text{对所有 }y$$

所有 subgradient 组成的 set 记作 $\partial f(x)$，叫 subdifferential。$f$ 在 $x$ 处 differentiable 时，$\partial f(x)=\{\nabla f(x)\}$。

用在 $|x|$ 的 $x=0$ 处：要求 $|y|\ge g\,y$ 对所有 $y$ 成立。取 $y=1$ 得 $g\le1$，取 $y=-1$ 得 $g\ge-1$；反过来 $|g|\le1$ 时 $g\,y\le|g||y|\le|y|$。所以

$$\partial|x|\,(0)=[-1,1],\qquad\partial|x|\,(x)=\{\operatorname{sign}(x)\}\ \ (x\ne0)$$

::fig[dsa3102-subgrad] 左边：过 $|x|$ 的 kink、slope 在 $[-1,1]$ 里的 line 都在 graph 下方。右边：由此推出的 soft-thresholding。

### $0\in\partial f$：一个在 kink 上也成立的 optimality condition

由定义，$0\in\partial f(x^\star)$ 就是 $f(y)\ge f(x^\star)+0$ 对所有 $y$ 成立，也就是 $x^\star$ 是 global minimum。两个方向都是定义本身，所以

$$x^\star\text{ 是 minimizer}\iff0\in\partial f(x^\star)$$

$f$ differentiable 时它就是 $\nabla f(x^\star)=0$。

要用它还需要一条计算规则：convex function 相加时，subdifferential 相加，$\partial(f_1+f_2)(x)=\partial f_1(x)+\partial f_2(x)$（右边是两个 set 里各取一个相加得到的 set）。

回到 $\varphi(\beta)=\tfrac12(\beta-v)^2+\lambda|\beta|$。Optimality condition 是

$$0\in\beta-v+\lambda\,\partial|\beta|$$

分三种情形：

- $\beta>0$：$0=\beta-v+\lambda$，$\beta=v-\lambda$，要求 $v>\lambda$。
- $\beta<0$：$0=\beta-v-\lambda$，$\beta=v+\lambda$，要求 $v<-\lambda$。
- $\beta=0$：$0\in-v+[-\lambda,\lambda]$，即 $|v|\le\lambda$。

三种情形恰好覆盖所有 $v$，合起来叫 **soft-thresholding**：

$$S_\lambda(v)=\begin{cases}v-\lambda,&v>\lambda\\0,&|v|\le\lambda\\v+\lambda,&v<-\lambda\end{cases}$$

$|v|$ 不超过 $\lambda$ 时直接压成 0，超过时向 0 收缩 $\lambda$。刚才的 $v=0.8$、$\lambda=1$ 落在中间一段，$\beta=0$；若 $v=2.5$，$\beta=1.5$，代回去 $1.5-2.5+1=0$。

### 更多 rule：affine composition 与 max

还有两条 rule，对应上一站的规则 2、3：

- $\partial\big(f(Ax+b)\big)=A^\top\,\partial f(Ax+b)$；
- $\partial\max(f_1,f_2)(x)$：只有 $f_1$ 达到 max 时是 $\partial f_1(x)$；两个都达到时，是两者所有 subgradient 的 convex combination。

Hinge loss $\max(0,1-z)$ 在 $z=1$ 处两个 piece 相等，slope 分别是 0 和 $-1$，所以 $\partial=[-1,0]$。

### 检验 lasso 的解，不用跑任何 algorithm

对 $F(\beta)=\tfrac12\|X\beta-y\|^2+\lambda\|\beta\|_1$，第一项的 gradient 是 $X^\top(X\beta-y)$，第二项的 subdifferential 按 coordinate 分开。$0\in\partial F$ 写开是

$$X^\top(y-X\beta)=\lambda s,\qquad s_i\begin{cases}=\operatorname{sign}(\beta_i),&\beta_i\ne0\\\in[-1,1],&\beta_i=0\end{cases}$$

逐个 coordinate 读：$X_i$ 是 $X$ 的 column $i$，$X_i^\top(y-X\beta)$ 是 feature $i$ 与 residual 的 inner product。Nonzero 的 coefficient，这个 inner product 必须恰好是 $\pm\lambda$；为 0 的 coefficient，它的 absolute value 不超过 $\lambda$。

拿开头那组 data、$\lambda=14$ 和候选解 $\beta=(\tfrac12,0)$ 检验。$X\beta=(1,\tfrac12,\tfrac12)$，residual $y-X\beta=(5,\ 4.5,\ -0.5)$，

$$X^\top(y-X\beta)=\begin{pmatrix}2\cdot5+4.5-0.5\\5+2\cdot4.5-0.5\end{pmatrix}=\begin{pmatrix}14\\13.5\end{pmatrix}$$

第一个 coordinate 不为 0，inner product 恰好是 $\lambda\cdot\operatorname{sign}(\tfrac12)=14$；第二个 coordinate 为 0，$|13.5|\le14$。条件成立，$\beta=(\tfrac12,0)$ 是 optimal 的。

同一个条件还能把整条 solution path 解出来。$X^\top X=\begin{pmatrix}6&5\\5&6\end{pmatrix}$ 的 determinant 是 11，inverse 是 $\tfrac1{11}\begin{pmatrix}6&-5\\-5&6\end{pmatrix}$。

- 设两个 coefficient 都为正，condition 变成 $X^\top X\beta=X^\top y-\lambda(1,1)^\top=(17-\lambda,\ 16-\lambda)^\top$，解得 $\beta=\big(\tfrac{22-\lambda}{11},\ \tfrac{11-\lambda}{11}\big)$。它要求 $\beta_2>0$，即 $\lambda<11$。
- 设 $\beta_2=0$、$\beta_1>0$。第一行 $17-6\beta_1=\lambda$，$\beta_1=\tfrac{17-\lambda}{6}$；第二行要求 $|16-5\beta_1|\le\lambda$，$16-5\cdot\tfrac{17-\lambda}{6}=\tfrac{11+5\lambda}{6}\le\lambda$ 等价于 $\lambda\ge11$。所以 $11\le\lambda\le17$ 时是这一段。
- $\beta=0$ 要求 $\|X^\top y\|_\infty=17\le\lambda$。

| $\lambda$ | 0 | 5 | 11 | 14 | 17 以上 |
|---|---|---|---|---|---|
| $\beta$ | $(2,\ 1)$ | $(1.545,\ 0.545)$ | $(1,\ 0)$ | $(0.5,\ 0)$ | $(0,\ 0)$ |

$\lambda$ 从 0 增大，两个 coefficient 同时向 0 收缩；$\beta_2$ 本来就小，在 $\lambda=11$ 先到 0 并停在那里；$\lambda=17$ 时全部为 0。最后这个 threshold $\lambda_{\max}=\|X^\top y\|_\infty$ 对任何 lasso 都成立：$\beta=0$ 时 residual 就是 $y$。

:::wrong 沿着 negative subgradient 走一小步，objective 一定下降
Differentiable 时 $-\nabla f$ 是 descent direction，于是很容易以为任何 subgradient 都一样。取 $f(x)=|x_1|+2|x_2|$ 和点 $x=(1,0)$。第二个 coordinate 在 kink 上，$\partial f(x)=\{1\}\times[-2,2]$，$g=(1,2)$ 是一个合法的 subgradient。沿 $-g$ 走 $t$：

$$f\big((1,0)-t(1,2)\big)=|1-t|+2|{-2t}|=1-t+4t=1+3t\qquad(0<t\le1)$$

无论 step 多小，objective 都变大。Subgradient 只保证一件更弱的事：$-g$ 与“指向 minimizer 的方向”成锐角，所以小步走下去，到 minimizer 的 distance 会变小（下一站的 basic inequality 就是这个）。Objective 本身可以上升，所以 subgradient method 要记录目前为止最好的那个点。
:::

::fig[dsa3102-badsubgrad] 上面这个 counterexample 的 contour。

:::edge Nonconvex function 可能没有 subgradient
$f(x)=-|x|$ 在 0 处：要 $-|y|\ge g\,y$ 对所有 $y$，取 $y=\pm1$ 得 $-1\ge g$ 和 $-1\ge-g$，不可能同时成立。Subgradient 是 global underestimator，只有 convex function 处处有。这也是 $0\in\partial f$ 只用于 convex problem 的原因。
:::

:::from
Subgradient 作为“kink 处的 global underestimator”、$|x|$ 和 $\|x\|_1$ 的例子、相加与 affine composition 和 max 的 rule、$0\in\partial f$ 的两个方向都直接来自定义、lasso 的 optimality condition 和 $X=I$ 时推出 soft-thresholding 的三个 case，都跟着 [10-725 Subgradients 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/lectures/subgrad.pdf)。那一讲没有数值例子；$v=0.8$ 的一元例子、$\beta=(\tfrac12,0)$ 的检验、整条 solution path、$|x_1|+2|x_2|$ 的 counterexample 是为这一页算的。
:::

## [gd] Gradient descent、step size 与 subgradient method

:::skip
能由 $L$ 和 eigenvalue 说出 step size 为什么不能超过 $2/L$、condition number 为什么决定 gradient descent 的速度，会做 backtracking line search，并说出 subgradient method 的 step size 为什么必须趋于 0，就可以去第 4 站。
:::

### 为什么要 iterate

Least squares 有 normal equations，可是 logistic regression（label 取 0、1）令 gradient 为 0 得到的 $\sum_i\big(\sigma(x_i^\top\beta)-y_i\big)x_i=0$ 里 $\beta$ 被包在 sigmoid 里，没有 closed form（[CS2109S 那一站](../courses/CS2109S.html#logreg)）。即使是 least squares，parameter 有 $p=10^5$ 个时，解 normal equations 要大约 $p^3/3$ 次运算（[DSA2102 第 2 站](../courses/DSA2102.html#lu)），而算一次 gradient $X^\top(X\beta-y)$ 只要 $np$ 量级。所以要一个只用 gradient、一步一步逼近的办法。

### Gradient descent 是在最小化一个 quadratic model

在当前点 $x$，用 quadratic 去近似 $f$：

$$f(z)\approx f(x)+\nabla f(x)^\top(z-x)+\frac1{2t}\|z-x\|^2$$

前两项是 tangent，最后一项惩罚走得太远。对 $z$ 求 gradient 令其为 0：$\nabla f(x)+\tfrac1t(z-x)=0$，得

$$x^+=x-t\,\nabla f(x)$$

这就是 gradient descent，$t$ 是 step size。如果这个 quadratic model 处处在 $f$ 上方，那么 $f(x^+)\le\text{model}(x^+)\le\text{model}(x)=f(x)$，每一步都保证下降。什么时候它在上方，取决于 $f$ 弯得有多厉害。

$f$ 的 gradient 叫 $L$-Lipschitz（也说 $f$ 是 $L$-smooth），如果 $\|\nabla f(x)-\nabla f(y)\|\le L\|x-y\|$。这时有 **descent lemma**：

$$f(z)\le f(x)+\nabla f(x)^\top(z-x)+\frac L2\|z-x\|^2$$

所以只要 $\tfrac1t\ge L$，即 $t\le1/L$，quadratic model 就在上方。把 $z=x-t\nabla f(x)$ 代进 descent lemma：

$$f(x^+)\le f(x)-t\|\nabla f(x)\|^2+\frac{Lt^2}2\|\nabla f(x)\|^2=f(x)-t\Big(1-\frac{Lt}2\Big)\|\nabla f(x)\|^2$$

只要 $t<2/L$，括号是正的，objective 严格下降。$t=1/L$ 时保证的下降量 $\tfrac1{2L}\|\nabla f\|^2$ 最大。

Least squares 的 $L$ 可以直接读出来。$f(z)=f(x)+\nabla f(x)^\top(z-x)+\tfrac12(z-x)^\top X^\top X(z-x)$ 是 exact 的（quadratic 的 Taylor expansion 到第二项为止），而 $v^\top X^\top Xv\le\lambda_{\max}(X^\top X)\|v\|^2$，所以 $L=\lambda_{\max}(X^\top X)$。开头那组 data 的 $X^\top X=\begin{pmatrix}6&5\\5&6\end{pmatrix}$，eigenvector 是 $(1,1)$ 和 $(1,-1)$，eigenvalue 分别是 11 和 1（$6\pm5$）。$L=11$，$2/L=0.1818$。

:::skip
下面这一小节是 descent lemma 的 proof，跳过不影响后面的使用。
:::

### Descent lemma 的 proof

沿 segment integrate：$f(z)-f(x)=\displaystyle\int_0^1\nabla f\big(x+s(z-x)\big)^\top(z-x)\,ds$。两边减去 $\nabla f(x)^\top(z-x)=\displaystyle\int_0^1\nabla f(x)^\top(z-x)\,ds$：

$$f(z)-f(x)-\nabla f(x)^\top(z-x)=\int_0^1\Big(\nabla f\big(x+s(z-x)\big)-\nabla f(x)\Big)^\top(z-x)\,ds$$

被积的 inner product 用 Cauchy–Schwarz 放大，gradient 之差用 Lipschitz 条件放大：它不超过 $L\,s\|z-x\|\cdot\|z-x\|$。Integral $\int_0^1Ls\,ds=\tfrac L2$，得证。

### $2/L$ 这条线：用数字看

对 least squares 可以把每一步精确写出来。$\nabla f(\beta)=X^\top X(\beta-\beta^\star)$（因为 $X^\top X\beta^\star=X^\top y$），所以 error $e_k=\beta_k-\beta^\star$ 满足

$$e_{k+1}=e_k-t\,X^\top Xe_k=(I-tX^\top X)\,e_k$$

把 $e_k$ 按 eigenvector 分解，沿 $(1,1)$ 的 component 每步乘 $1-11t$，沿 $(1,-1)$ 的乘 $1-t$。两个 factor 的 absolute value 都小于 1 才 converge：$|1-11t|<1$ 就是 $t<2/11$。

从 $\beta_0=(0,0)$ 出发（$f(\beta_0)-f^\star=30.5-5.5=25$），实际跑一遍，表里是 $f(\beta_k)-f^\star$：

| $t$ | 沿 $(1,1)$ 的 factor | $k=1$ | $k=10$ | $k=50$ | $k=100$ |
|---|---|---|---|---|---|
| 0.05 | 0.45 | 5.24 | 0.0896 | $1.5\times10^{-3}$ | $8.8\times10^{-6}$ |
| $1/11$ | 0 | 0.207 | 0.0372 | $1.8\times10^{-5}$ | $1.3\times10^{-9}$ |
| 0.15 | $-0.65$ | 10.6 | 0.0142 | $2.2\times10^{-8}$ | $3.6\times10^{-15}$ |
| 0.17 | $-0.87$ | 18.9 | 1.53 | $2.2\times10^{-5}$ | $2.0\times10^{-11}$ |
| 0.18 | $-0.98$ | 23.9 | 16.5 | 3.28 | 0.435 |
| 0.19 | $-1.09$ | 29.6 | 139 | $1.4\times10^{5}$ | $7.6\times10^{8}$ |

$t=0.19$ 时沿 $(1,1)$ 的 error 每步翻转 sign 并放大 9%，objective 的 error 正比于它的 square，每步乘 $1.09^2=1.19$。$t=0.18$ 还在 $2/L$ 以内，但 factor $-0.98$ 几乎不缩小，100 步才降到 0.435。

$t=1/11$ 第一步就把 $(1,1)$ 方向的 error 消掉了，此后只剩 $(1,-1)$ 方向，每步乘 $10/11$。两个方向的 factor 一个由最大的 eigenvalue $L$ 定、一个由最小的 eigenvalue $m$ 定：

$$\max\big(|1-tL|,\ |1-tm|\big)$$

$t$ 大了 $|1-tL|$ 超过 1，$t$ 小了 $1-tm$ 接近 1。两者相等时最好：$tL-1=1-tm$，$t=\dfrac{2}{L+m}=\dfrac16$，factor 是 $\dfrac{L-m}{L+m}=\dfrac{\kappa-1}{\kappa+1}=\dfrac56$，其中 $\kappa=L/m=11$ 是 $X^\top X$ 的 condition number（[DSA2102 第 3 站](../courses/DSA2102.html#cond)）。表里 $t=0.15$ 最接近 $1/6$，也最快。

::fig[dsa3102-gdpath] 从 $(0.5,2)$ 出发各走 12 步。左边 $t=1/11$：先沿 steep 的方向一步到 valley 底，再沿 valley 慢慢走。右边 $t=0.17$：在 valley 两壁之间来回跳。

这和 [CS2109S 用 Hessian eigenvalue 分析 learning rate](../courses/CS2109S.html#linreg) 是同一件事。一般的 smooth convex function 没有固定的 eigenvalue，$L$ 和 $m$ 换成 Hessian 的 eigenvalue 的 upper bound 和 lower bound。

:::wrong 只要 objective 每一步都在下降，step size 就选对了
$t=0.18$ 时 objective 每一步都下降（25、23.9、22.9、22、……），却是表里 converge 的 step size 中最慢的一个，100 步后还差 0.435，而 $t=1/11$ 已经到了 $10^{-9}$。“每步下降”只排除了 diverge，速度取决于 $\max(|1-tL|,|1-tm|)$ 离 1 有多远。$t=0.18$ 让 $|1-tL|=0.98$，那个方向几乎不动。
:::

### Converge 有多快

**一般的 convex、$L$-smooth 的 $f$，$t\le1/L$：**

$$f(x_k)-f^\star\le\frac{\|x_0-x^\star\|^2}{2tk}$$

推导分三步，每步都用到前面的一个 inequality，记 $g=\nabla f(x)$。

1. Descent lemma，$t\le1/L$ 时 $1-\tfrac{Lt}2\ge\tfrac12$：$f(x^+)\le f(x)-\tfrac t2\|g\|^2$。
2. First-order condition（convexity）在 $x$ 处对 $x^\star$ 用：$f^\star\ge f(x)+g^\top(x^\star-x)$，即 $f(x)\le f^\star+g^\top(x-x^\star)$。代进第 1 步：$f(x^+)\le f^\star+g^\top(x-x^\star)-\tfrac t2\|g\|^2$。
3. 把右边写成 distance 的差。$\|x^+-x^\star\|^2=\|x-x^\star-tg\|^2=\|x-x^\star\|^2-2t\,g^\top(x-x^\star)+t^2\|g\|^2$，所以 $g^\top(x-x^\star)-\tfrac t2\|g\|^2=\tfrac1{2t}\big(\|x-x^\star\|^2-\|x^+-x^\star\|^2\big)$。

于是每一步

$$f(x_{i})-f^\star\le\frac1{2t}\Big(\|x_{i-1}-x^\star\|^2-\|x_{i}-x^\star\|^2\Big)$$

对 $i=1,\dots,k$ 相加，右边前后相消，只剩 $\tfrac1{2t}\big(\|x_0-x^\star\|^2-\|x_k-x^\star\|^2\big)\le\tfrac1{2t}\|x_0-x^\star\|^2$。左边 $k$ 项里最小的是最后一项（第 1 步说明 objective monotone 下降），所以 $k\big(f(x_k)-f^\star\big)$ 不超过这个和。

在例子上核对：$\|\beta_0-\beta^\star\|^2=\|(2,1)\|^2=5$，$t=1/11$，$k=10$ 时 bound 是 $\tfrac{5\times11}{2\times10}=2.75$，实际是 0.0372。Bound 对，但很松，因为它没用到 $m>0$。

**再加 $m$-strongly convex**（$f(z)\ge f(x)+\nabla f(x)^\top(z-x)+\tfrac m2\|z-x\|^2$；least squares 里 $m=\lambda_{\min}(X^\top X)=1$）：error 按 geometric sequence 下降，这叫 linear convergence。$t=1/L$ 时 objective 的 error 每步至少乘 $1-m/L$。例子里 $(1,-1)$ 方向每步乘 $10/11$，objective error 每步乘 $(10/11)^2=0.826$，10 步乘 0.148；表中 $k=10$ 到 $k=20$ 是 0.0372 到 0.00552，比值 0.148。在这个例子里，error 缩小到原来的 $\varepsilon$ 倍大约需要 $\tfrac\kappa2\ln(1/\varepsilon)$ 步，condition number 直接决定步数。

### 不知道 $L$ 时：backtracking line search

实际问题里 $L$ 往往算不出来。办法是试：从 $t=1$ 开始，只要

$$f\big(x-t\nabla f(x)\big)>f(x)-\frac t2\|\nabla f(x)\|^2$$

就把 $t$ 减半。右边正是 $t\le1/L$ 时 descent lemma 保证的下降量，所以 $t$ 一旦减到 $1/L$ 以下，条件必然满足，循环必然停下，而且停下时 $t\ge\tfrac1{2L}$。

例子的第一步。$\beta_0=0$，$\nabla f=-X^\top y=(-17,-16)$，$\|\nabla f\|^2=545$，$f(\beta_0)=30.5$：

| $t$ | 试探点 | $f$（试探点） | $30.5-\tfrac t2\cdot545$ | 接受？ |
|---|---|---|---|---|
| 1 | $(17,\ 16)$ | 2480.5 | $-242.0$ | 否 |
| 0.5 | $(8.5,\ 8)$ | 506.75 | $-105.75$ | 否 |
| 0.25 | $(4.25,\ 4)$ | 81.44 | $-37.63$ | 否 |
| 0.125 | $(2.125,\ 2)$ | 9.17 | $-3.56$ | 否 |
| 0.0625 | $(1.0625,\ 1)$ | 8.14 | 13.47 | 是 |

接受的 $0.0625$ 落在 $\tfrac1{2L}=0.045$ 和 $\tfrac1L=0.091$ 之间。之后每一步重新从 $t=1$ 试，这个例子里后面接受的 $t$ 有 0.25 和 0.125，都比 $1/L$ 大：远离 minimum 的地方 function 弯得没有 $L$ 说的那么厉害。40 步后 $f-f^\star=3.5\times10^{-8}$，fixed $t=1/11$ 是 $1.2\times10^{-4}$。

### Subgradient method

Nonsmooth 的 $f$ 没有 gradient，把它换成任意一个 subgradient：$x_{k+1}=x_k-t_kg_k$，$g_k\in\partial f(x_k)$。上一站说过这一步可能让 objective 上升，所以记录 $f_{\text{best}}=\min_{i\le k}f(x_i)$。

Fixed step size 不行。对 $f(x)=|x|$ 从 $0.35$ 出发、$t=0.1$：subgradient 是 $\operatorname{sign}(x)$，absolute value 永远是 1，于是

$$0.35\to0.25\to0.15\to0.05\to-0.05\to0.05\to-0.05\to\cdots$$

永远停在离 minimum 0.05 的地方来回跳。Gradient descent 没有这个问题，因为 smooth function 的 gradient 在 minimum 附近自己会变小；subgradient 不会。所以 $t_k$ 必须趋于 0。但不能太快：$t_k=0.1/k^2$ 时总共能走的路程是 $0.1\sum1/k^2=0.1\cdot\pi^2/6=0.164$，比到 minimum 的 0.35 还短，永远走不到。标准的要求是

$$\sum_kt_k=\infty,\qquad\sum_kt_k^2<\infty$$

例如 $t_k=c/k$。

这两个条件和 rate 都来自一个 inequality。设 $f$ 是 $G$-Lipschitz（所有 subgradient 的 norm 不超过 $G$），$R=\|x_0-x^\star\|$。展开 distance：

$$\|x_{k+1}-x^\star\|^2=\|x_k-x^\star\|^2-2t_k\,g_k^\top(x_k-x^\star)+t_k^2\|g_k\|^2$$

Subgradient 的定义在 $x_k$ 处对 $x^\star$ 用：$f^\star\ge f(x_k)+g_k^\top(x^\star-x_k)$，即 $g_k^\top(x_k-x^\star)\ge f(x_k)-f^\star$。代入：

$$\|x_{k+1}-x^\star\|^2\le\|x_k-x^\star\|^2-2t_k\big(f(x_k)-f^\star\big)+t_k^2G^2$$

这叫 basic inequality。它说的正是上一站那个错误想法里提到的事：$t_k$ 足够小时 distance 下降，即使 objective 不降。对 $k$ 步相加，distance 的项相消，$f(x_i)-f^\star$ 都换成更小的 $f_{\text{best}}-f^\star$：

$$f_{\text{best}}-f^\star\le\frac{R^2+G^2\sum_it_i^2}{2\sum_it_i}$$

两个条件让 numerator 有界、denominator 趋于 infinity。Fixed $t$ 时右边是 $\tfrac{R^2}{2kt}+\tfrac{G^2t}{2}$，$k\to\infty$ 后剩下 $\tfrac{G^2t}2$。拿 $|x|$ 核对：$G=1$，$t=0.1$，floor 是 0.05，正是上面停住的距离。

给定步数 $k$，最好的 fixed $t=\tfrac{R}{G\sqrt k}$，bound 是 $\tfrac{RG}{\sqrt k}$。要 $\varepsilon$ 的 accuracy 需要 $(RG/\varepsilon)^2$ 步：accuracy 提高 10 倍，步数乘 100。Gradient descent 的 $O(1/k)$ 只乘 10。

在 lasso 上，$t_k=0.05/\sqrt k$ 跑出来 $F_{\text{best}}-F^\star$ 在 20 步、1000 步、$10^4$ 步、$10^5$ 步时分别是 0.049、$1.0\times10^{-3}$、$9.3\times10^{-5}$、$9.4\times10^{-6}$。这就是开头第三次计算的前一半。

:::back
Condition number 和 eigenvalue 决定 iteration 快慢，与 [DSA2102 第 3 站](../courses/DSA2102.html#cond) Jacobi iteration 的分析是同一个结构：error 每步乘同一个 matrix。Subgradient 和它“不一定下降”的性质来自[第 2 站](#subgrad)。
:::

:::from
Gradient descent 作为最小化 quadratic model、step size 太大会 diverge 而太小会慢、backtracking 的规则、$O(1/k)$ 的 proof 步骤（descent lemma、convexity、telescoping）、strong convexity 下的 linear rate 与 condition number、least squares 的 $L=\sigma_{\max}^2(X)$，都跟着 [10-725 Gradient Descent 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/lectures/grad-descent.pdf)；那一讲用 $\alpha$ 一般化 backtracking 的条件，这里取了它说的常用简化 $\alpha=\tfrac12$。Subgradient method 记录 best iterate、两个 step size 条件、basic inequality 与 $\tfrac{R^2+G^2\sum t_i^2}{2\sum t_i}$ 的 bound、fixed $t$ 的 floor $G^2t/2$，跟着 [Subgradient Method 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/lectures/sg-method.pdf)。Descent lemma 的 integral proof、eigenvector 分解下的 step size 分析、$t=2/(L+m)$ 的推导、所有数表、$|x|$ 的例子和 $0.1/k^2$ 走不到的论证，是为这一页写和算的。
:::

## [prox] Proximal gradient 与 acceleration

:::skip
能写出 $\ell_1$ norm 的 prox，对小 lasso 手算两步 ISTA，写出 FISTA 的 momentum step，并说出 subgradient method、ISTA、FISTA 各自的 rate，就可以去第 5 站。
:::

### 把 smooth 的部分和 nonsmooth 的部分分开

上一站的 subgradient method 在 lasso 上 1000 步才到 $10^{-3}$，因为它把整个 $F$ 当成一个只能问 subgradient 的黑箱。可是 lasso 的结构很清楚：

$$F(x)=g(x)+h(x),\qquad g=\tfrac12\|Xx-y\|^2\ \text{（smooth）},\qquad h=\lambda\|x\|_1\ \text{（nonsmooth，但简单）}$$

Gradient descent 是“在 $x$ 处用 quadratic model 代替 $f$，再最小化 model”。现在只把 $g$ 换成 quadratic，$h$ 原封不动保留：

$$x^+=\arg\min_z\ g(x)+\nabla g(x)^\top(z-x)+\frac1{2t}\|z-x\|^2+h(z)$$

前三项 complete the square。$\nabla g(x)^\top(z-x)+\tfrac1{2t}\|z-x\|^2=\tfrac1{2t}\|z-x+t\nabla g(x)\|^2-\tfrac t2\|\nabla g(x)\|^2$，后一项和 $z$ 无关。所以

$$x^+=\arg\min_z\ \frac1{2t}\big\|z-\big(x-t\nabla g(x)\big)\big\|^2+h(z)$$

读法：先对 $g$ 做一步普通的 gradient descent，得到 $x-t\nabla g(x)$；然后在它附近找一个让 $h$ 也小的点。第二步的 operation 叫 **proximal mapping**：

$$\operatorname{prox}_{th}(v)=\arg\min_z\ \frac1{2t}\|z-v\|^2+h(z)$$

这个 algorithm 叫 proximal gradient descent。它只要求 $\operatorname{prox}_{th}$ 好算，$g$ 可以任意复杂，只要能求 gradient。

### 两个好算的 prox

**$h=\lambda\|\cdot\|_1$。** $\tfrac1{2t}\|z-v\|^2+\lambda\|z\|_1=\sum_i\Big(\tfrac1{2t}(z_i-v_i)^2+\lambda|z_i|\Big)$，各个 coordinate 互不相干。乘 $t$ 之后每一项正是第 2 站的一元 lasso $\tfrac12(z_i-v_i)^2+\lambda t|z_i|$，答案是 soft-thresholding：

$$\operatorname{prox}_{t\lambda\|\cdot\|_1}(v)=S_{\lambda t}(v)\quad\text{（逐个 coordinate）}$$

Lasso 上的 proximal gradient 因此叫 ISTA（iterative soft-thresholding algorithm）：

$$\beta^+=S_{\lambda t}\big(\beta-t\,X^\top(X\beta-y)\big)$$

**$h$ 是 convex set $C$ 的 indicator**（$C$ 内为 0，$C$ 外为 $+\infty$，把 constraint $x\in C$ 写进 objective）。这时 prox 是 $\arg\min_{z\in C}\|z-v\|^2$，即 projection $P_C(v)$。Proximal gradient 变成 projected gradient descent：先走一步 gradient，再 project 回 feasible set。$C=\{x:x\ge0\}$ 时 $P_C(v)=\max(v,0)$ 逐个 coordinate 取。

### 在 lasso 上走一遍 ISTA

用开头的 lasso，$\lambda=14$，$L=11$，$t=1/11$，threshold $\lambda t=14/11$。从 $\beta_0=0$ 出发。

**第 1 步。** $\nabla g(0)=-X^\top y=(-17,-16)$，gradient step 得 $v=(\tfrac{17}{11},\tfrac{16}{11})=(1.545,\ 1.455)$。每个 coordinate 减去 $\tfrac{14}{11}$：$\beta_1=(\tfrac3{11},\tfrac2{11})=(0.2727,\ 0.1818)$。

**第 2 步。** $\nabla g(\beta_1)=X^\top X\beta_1-X^\top y=\big(\tfrac{28}{11}-17,\ \tfrac{27}{11}-16\big)=\big(-\tfrac{159}{11},-\tfrac{149}{11}\big)$。Gradient step：$v=\big(\tfrac3{11}+\tfrac{159}{121},\ \tfrac2{11}+\tfrac{149}{121}\big)=\big(\tfrac{192}{121},\tfrac{171}{121}\big)$。减去 $\tfrac{14}{11}=\tfrac{154}{121}$：$\beta_2=\big(\tfrac{38}{121},\tfrac{17}{121}\big)=(0.3140,\ 0.1405)$。

继续跑：

| $k$ | $\beta_k$ | $F(\beta_k)-F^\star$ |
|---|---|---|
| 0 | $(0,\ 0)$ | 0.75 |
| 1 | $(0.2727,\ 0.1818)$ | 0.138 |
| 2 | $(0.3140,\ 0.1405)$ | 0.103 |
| 4 | $(0.3858,\ 0.0688)$ | 0.0484 |
| 6 | $(0.4450,\ 0.0095)$ | 0.0115 |
| 7 | $(0.4707,\ 0)$ | 0.00258 |
| 10 | $(0.4972,\ 0)$ | $2.3\times10^{-5}$ |
| 20 | $(0.499999,\ 0)$ | $3.2\times10^{-12}$ |

第 7 步 $\beta_2$ 被 soft-thresholding 精确地压成 0，此后一直是 0。Subgradient method 做不到这一点：它的 $\beta_2$ 慢慢降向 0，第 46 步越过 0 变成 $-0.0016$，subgradient 里的 $\lambda\operatorname{sign}(\beta_2)$ 随之变号，下一步就被推回 0.20，然后再慢慢降，如此反复。ISTA 的 prox step 则把落进 threshold 以内的 coordinate 直接放到 kink 上。

$\beta_2=0$ 之后只剩 $\beta_1$：gradient step 得 $\beta_1-\tfrac1{11}(6\beta_1-17)$（$\beta_2=0$ 时 $\nabla g$ 的第一个 component 是 $6\beta_1-17$），再减 $\tfrac{14}{11}$：

$$\beta_1\ \leftarrow\ \tfrac5{11}\beta_1+\tfrac3{11}$$

Fixed point 是 $\tfrac12$，error 每步乘 $\tfrac5{11}$。这解释了后半段为什么那么快。

::fig[dsa3102-ista] Lasso 的 contour 上，ISTA（彩色）在第 7 步落到 $\beta_2=0$ 这条 axis 上，然后沿 axis 走到 minimizer；subgradient method（灰色，300 步）一次次降到 axis，越过后又被推回上方。

ISTA 每一步 objective 都不升，理由和 gradient descent 一样：$t\le1/L$ 时 quadratic model 加上 $h$ 是 $F$ 的 upper bound，$x^+$ 最小化这个 upper bound，所以 $F(x^+)\le\text{upper bound}(x^+)\le\text{upper bound}(x)=F(x)$。上一站 $O(1/k)$ 的 proof 几乎原样适用：

$$F(x_k)-F^\star\le\frac{\|x_0-x^\star\|^2}{2tk}$$

Nonsmooth 的 term 没有拖慢速度，因为它从来没有被近似。

### Acceleration：让 step 记住上一步的方向

上一站的分析说，gradient descent 的速度由 condition number 决定。把 valley 变得更狭长：

$$f(x)=\tfrac12\big(100x_1^2+x_2^2\big),\qquad L=100,\ m=1,\ x_0=(1,1)$$

$t=1/L=0.01$ 时，$x_1$ 方向第一步就到 0，$x_2$ 方向每步乘 0.99，objective 的 error（起初是 $\tfrac12\cdot1^2=0.5$）每步乘 $0.99^2=0.9801$。降到 $10^{-6}$ 要解 $0.5\times0.9801^k=10^{-6}$，$k=653$。

慢的原因是：沿 valley 方向每一步都走得很短，但每一步的方向都相同。如果让这一步带上上一步的一部分，同方向的小步就会积累起来；而在 valley 两壁之间来回的那个方向，相邻两步 sign 相反，叠加后互相抵消。这就是 momentum。Nesterov 的版本（用于 proximal gradient 时叫 FISTA）：

$$v=x_{k-1}+\frac{k-2}{k+1}\,(x_{k-1}-x_{k-2}),\qquad x_k=\operatorname{prox}_{th}\big(v-t\nabla g(v)\big)$$

第一步 $v=x_0$，就是普通的一步。之后 momentum 的 weight $\tfrac{k-2}{k+1}$ 从 0 逐渐增大到接近 1。Gradient 在外推出去的点 $v$ 处计算。

同一个 $f$、同样的 $t=0.01$：

| $k$ | 10 | 50 | 100 | 200 | 500 |
|---|---|---|---|---|---|
| gradient descent | 0.409 | 0.183 | 0.067 | $9.0\times10^{-3}$ | $2.2\times10^{-5}$ |
| Nesterov | 0.339 | $5.2\times10^{-3}$ | $5.1\times10^{-6}$ | $4.3\times10^{-6}$ | $4.1\times10^{-8}$ |

第一次降到 $10^{-6}$ 以下，gradient descent 要 653 步，Nesterov 要 101 步。一般的 bound 是（$t\le1/L$）

$$f(x_k)-f^\star\le\frac{2\|x_0-x^\star\|^2}{t\,(k+1)^2}$$

从 $1/k$ 变成 $1/k^2$。Nesterov 还 prove 了，只用 gradient 信息、每步沿已见过的 gradient 的 linear combination 走的 method，worst case 不可能比 $1/k^2$ 更快，所以这已经是这一类 method 的 optimal rate。

::fig[dsa3102-accel] $\tfrac12(100x_1^2+x_2^2)$ 上的 objective error，log scale。Nesterov 快得多，但 curve 有起伏。

:::wrong FISTA 也是每一步 objective 都下降
表里 Nesterov 从 $k=100$ 到 $k=200$ 只从 $5.1\times10^{-6}$ 降到 $4.3\times10^{-6}$，中间其实升上去过：$k=101$ 时第一次低于 $10^{-6}$，接着从 $k=102$ 到 115 连续上升，到 $2.5\times10^{-4}$ 才回落。这样的上升段大约每 31 步出现一次（$k=39$ 到 50、71 到 83、102 到 115、……）。Momentum 让 iterate 冲过了 minimum，再被拉回来。所以 FISTA 不是 descent method，上一站“每步下降”的论证对它不成立；它的 $1/k^2$ 是靠另一个更精细的 potential function 来 prove 的。实现时如果用 objective 是否下降来判断 step size 或停止，会被这些起伏误导。
:::

:::edge 在开头的 lasso 上，FISTA 并不更快
同一个 lasso、同样 $t=1/11$，ISTA 第 12 步 error 降到 $10^{-6}$ 以下，FISTA 要 13 步。这个问题的 condition number 只有 11，而且 $\beta_2$ 一旦变成 0，剩下的是 error 每步乘 $\tfrac5{11}$ 的一元问题，linear convergence 已经很快，momentum 反而带来 overshoot。$1/k^2$ 是 worst case 的保证，condition number 大、没有 strong convexity 时 acceleration 的好处最明显。
:::

### 实现

```python
import numpy as np

def soft(v, k):
    return np.sign(v) * np.maximum(np.abs(v) - k, 0)

def fista(X, y, lam, iters=100):
    L = np.linalg.eigvalsh(X.T @ X).max()   # Lipschitz constant of the gradient
    t = 1 / L
    b = b_prev = np.zeros(X.shape[1])
    for k in range(1, iters + 1):
        v = b + (k - 2) / (k + 1) * (b - b_prev) if k > 1 else b
        b_prev, b = b, soft(v - t * X.T @ (X @ v - y), lam * t)
    return b

X = np.array([[2., 1], [1, 2], [1, 1]])
y = np.array([6., 5, 0])
print(fista(X, y, 14))   # [0.5 0. ]
```

把 `v` 那一行换成 `v = b`，就是 ISTA。

到这里四种方法的 rate 可以放在一起（$R=\lVert x_0-x^\star\rVert$）：

| Method | 用到的条件 | $k$ 步后的 bound | accuracy $\varepsilon$ 需要的步数 |
|---|---|---|---|
| Subgradient method | convex，$G$-Lipschitz | $RG/\sqrt k$ | $O(1/\varepsilon^2)$ |
| Gradient descent，proximal gradient | smooth part $L$-smooth，prox 好算 | $LR^2/(2k)$ | $O(1/\varepsilon)$ |
| Nesterov，FISTA | 同上 | $2LR^2/(k+1)^2$ | $O(1/\sqrt\varepsilon)$ |
| Gradient descent，再加 $m$-strongly convex | 同上 | 每步乘 $1-m/L$ | $O(\kappa\log(1/\varepsilon))$ |

:::back
Prox 的计算就是[第 2 站](#subgrad)的一元 lasso；upper bound 的论证和 $O(1/k)$ 的 proof 来自[第 3 站](#gd)。
:::

:::from
“只把 $g$ 换成 quadratic、保留 $h$”的推导和 complete the square、prox 只依赖 $h$、lasso 的 prox 是 soft-thresholding、indicator 的 prox 是 projection、$O(1/k)$ 与 $O(1/k^2)$ 的 bound、FISTA 的 $\tfrac{k-2}{k+1}$ 写法、“不是 descent method”（那一讲叫 Nesterov ripples），都跟着 [10-725 Proximal Gradient Descent and Acceleration 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/lectures/prox-grad.pdf)。Nesterov 的 lower bound 在 [Subgradient Method 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/lectures/sg-method.pdf)和 Gradient Descent 一讲的末尾提到。ISTA 的手算、一元 recursion $\tfrac5{11}\beta_1+\tfrac3{11}$、$\tfrac12(100x_1^2+x_2^2)$ 上的对比和上升区间、lasso 上 FISTA 不更快的数字（那一讲举的 acceleration 不起作用的例子是 warm start 和 matrix completion）、代码，是为这一页算和写的；momentum 为什么帮助狭长 valley 的解释是凭自己的知识写的，那一讲没有展开。
:::

## [scd] Stochastic gradient 与 block coordinate descent

:::skip
能算出 fixed step size 的 SGD 最后停在多大的 noise 里，能对 lasso 做一轮 coordinate descent，并能举出 coordinatewise minimum 不是 global minimum 的例子，就可以去第 6 站。
:::

### 每一步都要扫一遍全部 data

Machine learning 的 objective 几乎都是 average：

$$f(x)=\frac1n\sum_{i=1}^nf_i(x)$$

$f_i$ 是第 $i$ 个 sample 的 loss。一次 gradient 要算 $n$ 个 $\nabla f_i$；$n=10^8$ 时，走一步就要把全部 data 读一遍。**Stochastic gradient descent（SGD）** 每步随机取一个 index $i_k$（uniform），只用它：

$$x_k=x_{k-1}-t_k\,\nabla f_{i_k}(x_{k-1})$$

单个 $\nabla f_{i_k}$ 方向不准，但它的 expectation 正是真正的 gradient：$\mathbb E\big[\nabla f_{i_k}(x)\big]=\tfrac1n\sum_i\nabla f_i(x)=\nabla f(x)$。每步代价只有原来的 $1/n$。

### 一个能完全算清的例子：用 SGD 求 mean

取 5 个数 $a=(1,2,4,7,11)$，

$$f(x)=\frac15\sum_{i=1}^5\tfrac12(x-a_i)^2,\qquad\nabla f_i(x)=x-a_i$$

Minimizer 是 mean $\bar a=5$，variance $\sigma^2=\tfrac15\sum(a_i-5)^2=13.2$。

**$t_k=1/k$。** Update 是 $x_k=x_{k-1}-\tfrac1k(x_{k-1}-a_{i_k})=\tfrac{k-1}k\,x_{k-1}+\tfrac1k\,a_{i_k}$。$k=1$ 时 $x_1=a_{i_1}$；如果 $x_{k-1}$ 是前 $k-1$ 个抽到的数的平均，那么 $x_k=\tfrac{(k-1)x_{k-1}+a_{i_k}}{k}$ 是前 $k$ 个的平均。所以 SGD 在这里就是 sample mean，error 的 variance 是 $\sigma^2/k$：会 converge，但很慢，distance 按 $1/\sqrt k$ 缩小。

**Fixed $t$。** 记 $e_k=x_k-5$，update 变成 $e_k=(1-t)\,e_{k-1}+t\,(a_{i_k}-5)$。后一项是 mean 为 0、variance 为 $\sigma^2$ 的 noise，与 $e_{k-1}$ independent。两边取 variance，长期稳定时左右相等，$V=(1-t)^2V+t^2\sigma^2$，解得

$$V=\frac{t\,\sigma^2}{2-t}$$

$t=0.5$ 时 standard deviation 是 $\sqrt{13.2/3}=2.10$，$t=0.1$ 时是 $\sqrt{0.1\times13.2/1.9}=0.83$。Fixed step size 永远停在一团 noise 里，团的大小和 $t$ 成正比地缩小，但不会到 0。

用同一串随机 index 实际跑：

| $k$ | 抽到的 $a_{i_k}$ | $x_k$（$t_k=1/k$） | $x_k$（$t=0.5$） |
|---|---|---|---|
| 1 | 7 | 7.000 | 3.500 |
| 2 | 11 | 9.000 | 7.250 |
| 3 | 4 | 7.333 | 5.625 |
| 4 | 2 | 6.000 | 3.812 |
| 5 | 1 | 5.000 | 2.406 |
| 100 | 2 | 5.390 | 4.789 |
| 200 | 4 | 5.020 | 3.049 |

$t=0.5$ 那一列在第 100 到 200 步的 standard deviation 是 2.09，与上面算出的 2.10 一致。

::fig[dsa3102-sgd] 同一串随机 sample 上的 SGD。$t_k=1/k$ 越来越稳地靠近 5；$t=0.5$ 一直在 5 附近大幅摆动。

这个例子说明了 SGD 的全部规律。离 minimum 远时，noise 相对于 gradient 不重要，SGD 用 $1/n$ 的代价走出和 gradient descent 差不多的一步；离 minimum 近时，真正的 gradient 趋于 0 而 noise 不变，必须靠缩小 $t_k$ 来压 noise。

### Rate、mini-batch 与每步代价

| | 每步代价 | convex | strongly convex |
|---|---|---|---|
| Gradient descent | $n$ 个 gradient | $O(1/k)$ | linear |
| SGD（$t_k$ 递减） | 1 个 gradient | $O(1/\sqrt k)$ | $O(1/k)$ |

SGD 的 rate 是 expectation 意义下的，而且加上 smoothness 也不能改进：限制它的是 noise，不是 function 的 curvature。Mean 的例子是 strongly convex 的，$t_k=1/k$ 时 $\mathbb E(x_k-5)^2=\sigma^2/k$，正是 $O(1/k)$。

折中的做法是 mini-batch：每步随机取 $b$ 个 sample 求 gradient 的平均。仍然 unbiased，variance 降为 $1/b$（$b$ 个 independent noise 的平均），代价乘 $b$。

Data science 里常常不需要很高的 accuracy，model 本身的 statistical error 远大于 $10^{-6}$，所以实践中 fixed step size 的 SGD 很常见：它停在的那团 noise 已经足够小。

### Coordinate descent

另一个方向是每步只动一部分 parameter。最简单的是 **coordinate descent**：依次对每个 coordinate 精确地求一元 minimum，其他 coordinate 固定。

Least squares 的一元 minimum 有 formula。对 $\beta_i$ 求 partial derivative 令其为 0：$X_i^\top(X\beta-y)=0$，把 $X\beta$ 中含 $\beta_i$ 的项分出来：

$$\beta_i=\frac{X_i^\top\big(y-\sum_{j\ne i}X_j\beta_j\big)}{\|X_i\|^2}$$

在开头那组 data 上（$\|X_1\|^2=\|X_2\|^2=6$），从 $(0,0)$ 出发，第一轮：$\beta_1=\tfrac{17}6=2.833$；$\beta_2=\tfrac{16-5\times2.833}{6}=0.306$。

| 轮数 | $\beta$ | 与 $(2,1)$ 的最大偏差 |
|---|---|---|
| 1 | $(2.833,\ 0.306)$ | 0.833 |
| 2 | $(2.579,\ 0.518)$ | 0.579 |
| 3 | $(2.402,\ 0.665)$ | 0.402 |
| 8 | $(2.065,\ 0.946)$ | 0.065 |

每轮偏差乘 0.694。这其实就是对 normal equations $X^\top X\beta=X^\top y$ 做 Gauss–Seidel iteration（[DSA2102 第 3 站](../courses/DSA2102.html#cond)）：第 $i$ 个 equation 解出第 $i$ 个 unknown，用上刚更新的值。它的 iteration matrix 的 eigenvalue 是 0 和 $(5/6)^2=0.694$。一轮的代价和一次 gradient 相当（都是 $O(np)$），而 gradient descent 每步只乘 $10/11=0.909$。

Coordinate descent 每步能比 gradient descent 走得更远，原因是每个 coordinate 有自己的 curvature。沿 $\beta_1$ 一个方向，second derivative 是 $(X^\top X)_{11}=6$，exact minimization 相当于 step size $1/6$；gradient descent 要照顾所有方向，只能用 $1/L=1/11$。

Lasso 上，一元问题是 $\tfrac{\|X_i\|^2}2\beta_i^2-\beta_iX_i^\top r_i+\lambda|\beta_i|+\text{const}$（$r_i=y-\sum_{j\ne i}X_j\beta_j$），除以 $\|X_i\|^2$ 就是第 2 站的一元 lasso：

$$\beta_i=S_{\lambda/\|X_i\|^2}\Big(\frac{X_i^\top r_i}{\|X_i\|^2}\Big)$$

$\lambda=14$，threshold 是 $\tfrac{14}6=2.333$。从 $(0,0)$ 出发：$\beta_1=S_{2.333}\big(\tfrac{17}6\big)=2.833-2.333=0.5$；$\beta_2=S_{2.333}\big(\tfrac{16-5\times0.5}{6}\big)=S_{2.333}(2.25)=0$。一轮就到了 $(\tfrac12,0)$，第二轮两个值都不再变。

### Coordinatewise minimum 什么时候是 global minimum

上面停在 $(\tfrac12,0)$，意思是沿每个 coordinate 单独动都不能再降。这能推出它是 global minimum 吗？要分情况。

**$f$ smooth、convex：能。** 沿每个 coordinate 都是 minimum，所以每个 partial derivative 为 0，$\nabla f=0$，由第 1 站是 global minimum。

**$f=g+\sum_ih_i(x_i)$，$g$ smooth convex，每个 $h_i$ convex（nonsmooth 的部分 separable）：能。** 设 $x$ 是 coordinatewise minimum，对任意 $y$，

$$f(y)-f(x)\ge\nabla g(x)^\top(y-x)+\sum_i\big(h_i(y_i)-h_i(x_i)\big)=\sum_i\Big(\partial_ig(x)\,(y_i-x_i)+h_i(y_i)-h_i(x_i)\Big)$$

第一个不等号是 $g$ 的 first-order condition。右边第 $i$ 项只涉及 coordinate $i$：它是“只把 $x_i$ 换成 $y_i$”时 $f$ 的变化量的 linear approximation，而 $x_i$ 是这个一元 convex problem 的 minimum，所以每一项 $\ge0$。Lasso 的 $\lambda\sum|\beta_i|$ 正是这种形式，所以 $(\tfrac12,0)$ 是 global minimum，和第 2 站的检验一致。

:::wrong 沿每个 coordinate 都降不下去，就是 minimum 了
Nonsmooth 的部分不 separable 时不成立。取

$$f(x_1,x_2)=3|x_1-x_2|+\tfrac12(x_1+x_2-2)^2$$

在 $(0,0)$ 处 $f=2$。只动 $x_1$：$f(s,0)=3|s|+\tfrac12(s-2)^2$，$s>0$ 一侧的 derivative 在 0 处是 $3-2=1>0$，$s<0$ 一侧是 $-3-2=-5<0$，所以 $s=0$ 是一元 minimum；具体数字 $f(\pm0.1,0)=2.105,\ 2.505$。由 symmetry，只动 $x_2$ 也一样。Coordinate descent 停在 $(0,0)$，可是沿 $(1,1)$ 方向走，$f(t,t)=\tfrac12(2t-2)^2$，到 $(1,1)$ 时是 0。

问题出在 kink 沿着 diagonal $x_1=x_2$，而两个 coordinate direction 都斜着穿过它；要下降必须两个 coordinate 一起动。第 7 站的 total variation 就是这种 $|x_{i+1}-x_i|$ 形式的 penalty，那里改用 ADMM。
:::

::fig[dsa3102-stuck] $3|x_1-x_2|+\tfrac12(x_1+x_2-2)^2$ 的 contour。在 $(0,0)$ 沿两个 coordinate 方向走都会上升，沿 diagonal 才能下降到 $(1,1)$。

### Block 与 stochastic block coordinate descent

把 coordinate 分成若干 block，每步对一个 block 做 update，叫 block coordinate descent；block 内部可以做 exact minimization，也可以只做一步 gradient（或 prox-gradient）step，step size 用这个 block 自己的 Lipschitz constant $L_b$。$L_b\le L$，所以 block 的 step 比全局的 step 大，上面 $1/6$ 对 $1/11$ 就是一例。

依次轮流叫 cyclic，每步 uniform 随机选一个 block 叫 stochastic（randomized）block coordinate descent。随机选的好处是分析简单：一次 update 的 expected 进展，恰好是“对每个 block 都做一次”的平均，可以 prove smooth convex 时 $O(1/k)$、strongly convex 时 linear 的 rate。和 SGD 对比：SGD 每步用一部分 sample、动全部 parameter，block coordinate descent 每步用全部 sample、动一部分 parameter。前者适合 $n$ 大，后者适合 $p$ 大。

:::edge 不能把所有 coordinate 同时更新
Coordinate descent 的每一步都用了刚更新过的值。如果每个 coordinate 都用上一轮的值同时做 exact minimization，就成了 Jacobi iteration，可能 diverge。取 SPD 的
$$A=\begin{pmatrix}1&0.9&0.9\\0.9&1&0.9\\0.9&0.9&1\end{pmatrix}$$
最小化 $\tfrac12x^\top Ax-b^\top x$，$b=A(1,1,1)^\top$。同时更新得到 $(2.8,2.8,2.8)$、$(-2.24,\dots)$、$(6.83,\dots)$、$(-9.50,\dots)$，每轮乘 $-1.8$；依次更新（Gauss–Seidel）则稳定地靠近 $(1,1,1)$。$A$ 的 eigenvalue 是 2.8、0.1、0.1，Jacobi 的 iteration matrix $I-A$ 有 eigenvalue $-1.8$。
:::

:::back
Coordinate descent 在 least squares 上就是 [DSA2102 第 3 站](../courses/DSA2102.html#cond)的 Gauss–Seidel。Lasso 的一元 update 是[第 2 站](#subgrad)的 soft-thresholding；rate 对照[第 4 站](#prox)的表。
:::

:::from
SGD 的写法、randomized 与 cyclic、unbiasedness、fixed step size 下 discrepancy 不消失的论证、SGD 与 GD 在 convex 和 strongly convex 下的 rate 表、mini-batch 降低 variance、“远处快、近处慢”的经验规则、ML 里常用 fixed step size，跟着 [10-725 Stochastic Gradient Descent 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt/lectures/stochastic-gd.pdf)。Coordinatewise minimum 的三种情形、separable 时的 proof、least squares 与 lasso 的 coordinate update、与 Gauss–Seidel 和 Jacobi 的对比，跟着 [Coordinate Descent 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-S15/lectures/22-coord-desc.pdf)；那一讲的 counterexample 只给了 contour 图，$3|x_1-x_2|+\tfrac12(x_1+x_2-2)^2$ 是这里构造的。Mean 的例子、$V=t\sigma^2/(2-t)$ 的推导、数表、Jacobi diverge 的 3×3 例子是为这一页算的。Stochastic block coordinate descent 那一段（block Lipschitz constant、随机选择的 rate）是凭自己的知识写的，没有找到专门的讲义核对。

## [dual] Lagrangian duality 与 KKT

:::skip
能写出一个 constrained problem 的 Lagrangian 和 dual function，用 duality gap 判断 lasso 的 iterate 离 optimal 还有多远，用 KKT 解一个小 QP，并由 KKT 读出 SVM 的 support vector，就可以去第 7 站。
:::

### 不知道 $F^\star$，怎么知道该停

第 4 站 ISTA 的数表里那一列 $F(\beta_k)-F^\star$，是因为第 2 站手算出了 $F^\star=29.75$ 才写得出来。实际问题里 $F^\star$ 未知，看到 $F(\beta_{10})=29.75002$，无法判断它离 optimal 还差 $10^{-5}$ 还是差 1。

需要的是一个 **lower bound**：一个算得出来、保证不超过 $F^\star$ 的数。手里的 objective value 是 upper bound，两者之差就是 error 的上限。Duality 就是系统地制造 lower bound 的办法。

### 用 multiplier 把 constraint 搬进 objective

先看最小的例子：

$$\min_x\ x^2\quad\text{subject to}\quad1-x\le0$$

答案是 $x^\star=1$，$f^\star=1$。对 constraint 配一个 multiplier $u\ge0$，写出 Lagrangian

$$L(x,u)=x^2+u\,(1-x)$$

对 feasible 的 $x$（$1-x\le0$），$u(1-x)\le0$，所以 $L(x,u)\le f(x)$。于是

$$f^\star=\min_{x\text{ feasible}}f(x)\ \ge\ \min_{x\text{ feasible}}L(x,u)\ \ge\ \min_{\text{所有 }x}L(x,u)=:g(u)$$

最后一步去掉了 constraint，变成 unconstrained 的问题，通常好解。这里对 $x$ 求 derivative：$2x-u=0$，$x=u/2$，

$$g(u)=\frac{u^2}4+u\Big(1-\frac u2\Big)=u-\frac{u^2}4$$

$g(u)$ 叫 dual function。每个 $u\ge0$ 都给出一个 lower bound：$g(1)=0.75$，$g(2)=1$，$g(3)=0.75$。最好的 lower bound 是 $\max_ug(u)$，在 $u=2$ 达到 1，恰好等于 $f^\star$。

::fig[dsa3102-dual] 左边：每条 curve 是一个 $u$ 的 $L(x,u)$，它的 minimum 都不超过 $f^\star=1$。右边：这些 minimum 连成 dual function $g(u)$，最高点碰到 $f^\star$。

一般的 problem $\min f(x)$ subject to $h_i(x)\le0$、$\ell_j(x)=0$，Lagrangian 是 $L(x,u,v)=f(x)+\sum_iu_ih_i(x)+\sum_jv_j\ell_j(x)$，$u\ge0$，$v$ 任意。同样的论证给出 **weak duality**：

$$g(u,v)=\min_xL(x,u,v)\ \le\ f^\star\qquad\text{对所有 }u\ge0,\ v$$

它不要求任何 convexity。$g$ 总是 concave 的：对每个固定的 $x$，$L$ 是 $(u,v)$ 的 affine function，$g$ 是一族 affine function 的 minimum。所以 dual problem $\max_{u\ge0,v}g(u,v)$ 总是一个 convex problem。

两者相等（$\max g=f^\star$）叫 **strong duality**。一个常用的充分条件是 **Slater's condition**：problem 是 convex 的，并且存在 strictly feasible 的点（所有 nonaffine 的 $h_i(x)<0$）。上面的例子里 $x=2$ 满足 $1-2<0$。

:::wrong 写出 dual 就能得到一个有用的 lower bound
Weak duality 永远成立，但 bound 可以毫无用处。$\min-x^2$ subject to $-1\le x\le1$ 的答案是 $f^\star=-1$。Lagrangian 是 $-x^2+u_1(x-1)+u_2(-x-1)$，对固定的 $u$，$x\to\infty$ 时 $-x^2$ 压倒一切，$\min_xL=-\infty$。每个 $u$ 给出的 bound 都是 $-\infty$。这个 problem 不是 convex 的（objective 是 concave 的），Slater's condition 不适用，duality gap 是 infinity。
:::

### Duality gap 是一张证书

回到 lasso。把 residual 写成一个新的 variable：

$$\min_{\beta,r}\ \tfrac12\|r\|^2+\lambda\|\beta\|_1\quad\text{subject to}\quad r=y-X\beta$$

Equality constraint 配 multiplier $u\in\mathbb R^n$：$L=\tfrac12\|r\|^2+\lambda\|\beta\|_1+u^\top(y-X\beta-r)$。分别对 $r$ 和 $\beta$ 求 minimum。

- 对 $r$：$\tfrac12\|r\|^2-u^\top r$ 在 $r=u$ 处最小，值为 $-\tfrac12\|u\|^2$。
- 对 $\beta$：$\lambda\|\beta\|_1-(X^\top u)^\top\beta$。如果某个 $|X_i^\top u|>\lambda$，让 $\beta_i$ 沿那个 sign 趋于 infinity，值趋于 $-\infty$；如果 $\|X^\top u\|_\infty\le\lambda$，每一项 $\lambda|\beta_i|-(X_i^\top u)\beta_i\ge0$，minimum 是 0。

所以

$$g(u)=u^\top y-\tfrac12\|u\|^2=\tfrac12\|y\|^2-\tfrac12\|y-u\|^2,\qquad\text{要求}\ \|X^\top u\|_\infty\le\lambda$$

任何满足 constraint 的 $u$ 都给出 $F^\star\ge g(u)$。从当前的 $\beta$ 造一个 $u$：取 residual $y-X\beta$，如果 $\|X^\top(y-X\beta)\|_\infty$ 超过 $\lambda$，就缩小到正好满足。在 $\beta_0=0$：residual 是 $y=(6,5,0)$，$X^\top y=(17,16)$，缩小倍数 $s=\tfrac{14}{17}$，

$$g(sy)=\tfrac12\|y\|^2-\tfrac12(1-s)^2\|y\|^2=30.5-\tfrac12\Big(\tfrac3{17}\Big)^2\times61=30.5-0.950=29.550$$

所以 $F^\star\in[29.550,\ 30.5]$，不知道 $F^\star$ 也能说 error 不超过 0.95。沿 ISTA 的 iterate 都这样做：

| $k$ | $F(\beta_k)$ | $g(u_k)$ | gap | 真实的 $F(\beta_k)-F^\star$ |
|---|---|---|---|---|
| 0 | 30.50000 | 29.55017 | 0.950 | 0.750 |
| 3 | 29.82294 | 29.73161 | 0.0913 | 0.0729 |
| 6 | 29.76148 | 29.74708 | 0.0144 | 0.0115 |
| 9 | 29.75011 | 29.74996 | $1.5\times10^{-4}$ | $1.1\times10^{-4}$ |
| 12 | 29.7500010 | 29.7499996 | $1.4\times10^{-6}$ | $9.7\times10^{-7}$ |

由 weak duality，gap 永远不小于真实 error；这里它只比真实 error 大 25% 到 40%，并且和它一起下降。停止规则就是：gap 小于想要的 accuracy。

在 $\beta^\star=(\tfrac12,0)$，residual $(5,4.5,-0.5)$ 已经满足 $\|X^\top u\|_\infty=14\le\lambda$，不用缩小：$g=30.5-\tfrac12\|(1,0.5,0.5)\|^2=30.5-0.75=29.75=F(\beta^\star)$。Gap 为 0，这是 $\beta^\star$ optimal 的第二个 proof。

### KKT conditions

设 strong duality 成立，$x^\star$ 和 $(u^\star,v^\star)$ 分别是 primal 和 dual 的 solution。把上面那串 inequality 在它们身上写一遍：

$$f(x^\star)=g(u^\star,v^\star)=\min_xL(x,u^\star,v^\star)\le L(x^\star,u^\star,v^\star)=f(x^\star)+\sum_iu_i^\star h_i(x^\star)+\sum_jv_j^\star\ell_j(x^\star)\le f(x^\star)$$

最后一步用了 $u_i^\star\ge0$、$h_i(x^\star)\le0$、$\ell_j(x^\star)=0$。两头相等，中间两个 $\le$ 都必须是等号：

- 第一个等号：$x^\star$ 是 $L(\cdot,u^\star,v^\star)$ 的 minimizer，所以 $0\in\partial f(x^\star)+\sum_iu_i^\star\partial h_i(x^\star)+\sum_jv_j^\star\partial\ell_j(x^\star)$。这叫 **stationarity**。
- 第二个等号：$\sum_iu_i^\star h_i(x^\star)=0$，每一项都 $\le0$，所以每一项都是 0：$u_i^\star h_i(x^\star)=0$。这叫 **complementary slackness**。

再加上 primal feasibility 和 dual feasibility（$u^\star\ge0$），合称 **KKT conditions**。反过来，convex problem 里任何满足 KKT 的点，把上面的链倒着读，gap 为 0，因而是 optimal 的。所以 convex problem 加 Slater's condition 时，KKT 是 optimality 的充要条件。

Complementary slackness 的读法：一个 constraint 如果没有起作用（$h_i(x^\star)<0$），它的 multiplier 必须是 0；multiplier 不为 0 的 constraint 一定是 active 的。

**例。** 求离点 $p=(3,2)$ 最近、满足 $x_1+x_2\le2$ 和 $x_2\ge0$ 的点：

$$\min\ (x_1-3)^2+(x_2-2)^2\quad\text{s.t.}\quad x_1+x_2-2\le0,\quad-x_2\le0$$

Stationarity：$2(x-p)+u_1(1,1)+u_2(0,-1)=0$。按“哪些 constraint active”试：

- 都不 active：$u=0$，$x=p=(3,2)$，但 $3+2>2$，不 feasible。
- 只有第一个 active（$u_2=0$）：$x=p-\tfrac{u_1}2(1,1)$，代入 $x_1+x_2=2$ 得 $5-u_1=2$，$u_1=3$，$x=(1.5,\ 0.5)$。检查：$x_2=0.5\ge0$ 成立，$u_1=3\ge0$ 成立，$u_2=0$ 而第二个 constraint 不 active，complementary slackness 成立。

四个 condition 都满足，$x^\star=(1.5,0.5)$，$f^\star=4.5$。

::fig[dsa3102-kkt] 在 $x^\star$ 处，$-\nabla f$ 指向 $p$，恰好是 active constraint 的 normal $(1,1)$ 的 3 倍：objective 想往外走，constraint 用大小为 $u_1=3$ 的“力”挡住。

$u_1=3$ 还有一个可以直接验证的意思。把 constraint 放松成 $x_1+x_2\le2+\delta$，同样的计算给出 $x^\star=p-\tfrac{3-\delta}{2}(1,1)$，$f^\star(\delta)=\tfrac{(3-\delta)^2}2$。$\delta=0.1$ 时 $f^\star=4.205$，比 4.5 少 0.295，约等于 $u_1\delta=0.3$。一般地 $\partial f^\star/\partial\delta=-u_i^\star$：multiplier 是放松这个 constraint 的边际收益，经济学里叫 shadow price。没起作用的 constraint，放松一点什么也得不到，multiplier 自然是 0。

### SVM 的 dual：support vector 是 complementary slackness 读出来的

Hard-margin SVM（[CS2109S 那一站](../courses/CS2109S.html#svm)推导过它的来历）：

$$\min_{w,b}\ \tfrac12\|w\|^2\quad\text{s.t.}\quad1-y_i(w^\top x_i+b)\le0,\quad i=1,\dots,n$$

Lagrangian $L=\tfrac12\|w\|^2+\sum_i\alpha_i\big(1-y_i(w^\top x_i+b)\big)$，$\alpha_i\ge0$。对 $w$ 求 gradient 令其为 0：$w=\sum_i\alpha_iy_ix_i$。对 $b$：$L$ 中含 $b$ 的项是 $-b\sum_i\alpha_iy_i$，若 $\sum_i\alpha_iy_i\ne0$，$b$ 可以让 $L\to-\infty$，所以 dual 要求 $\sum_i\alpha_iy_i=0$。代回去：

$$g(\alpha)=\sum_i\alpha_i-\tfrac12\Big\|\sum_i\alpha_iy_ix_i\Big\|^2=\sum_i\alpha_i-\tfrac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\,x_i^\top x_j$$

Data 只以 inner product $x_i^\top x_j$ 的形式出现，这是 kernel trick 的出发点。

用 CS2109S 那一站的 8 个点：$+1$ 类 $(2,2),(3,2),(2,3),(3,4)$，$-1$ 类 $(1,1),(0,0),(1,0),(0,1)$。候选的 primal solution 是 $w=(1,1)$、$b=-3$：8 个点的 $y_i(w^\top x_i+b)$ 依次是 $1,2,2,4,1,3,2,2$，都 $\ge1$，feasible，$\tfrac12\|w\|^2=1$。Complementary slackness 要求只有 $y_i(w^\top x_i+b)=1$ 的点（$(2,2)$ 和 $(1,1)$）可以有 $\alpha_i>0$。设这两个 $\alpha$ 相等（$\sum\alpha_iy_i=0$ 要求如此），记为 $\alpha$：

$$w=\alpha(2,2)-\alpha(1,1)=\alpha(1,1)\quad\Rightarrow\quad\alpha=1$$

Dual value $g=\sum\alpha_i-\tfrac12\|w\|^2=2-1=1$，等于 primal value。Gap 为 0，$w=(1,1)$、$b=-3$ 是 optimal 的，support vector 就是 $\alpha_i>0$ 的这两个点；其余 6 个点的 $\alpha_i=0$，删掉它们，solution 不变。

::fig[dsa3102-svm] 这 8 个点和 $w=(1,1)$、$b=-3$ 给出的分界线。

:::edge Slater's condition 不成立时，dual 的 maximum 可能取不到
$\min x$ subject to $x^2\le0$。Feasible set 只有 $\{0\}$，$f^\star=0$，没有 strictly feasible 的点。$L=x+ux^2$，$u>0$ 时 minimum 在 $x=-\tfrac1{2u}$，$g(u)=-\tfrac1{4u}$。$u\to\infty$ 时 $g\to0$，但没有哪个 $u$ 达到 0。没有 dual solution，KKT 也就无从成立：stationarity $1+2ux=0$ 在 $x=0$ 处不可能满足。
:::

:::back
Stationarity 里的 $0\in\partial(\cdots)$ 就是[第 2 站](#subgrad)的 optimality condition；lasso 的 dual constraint $\|X^\top u\|_\infty\le\lambda$ 与那里的 $|X_i^\top(y-X\beta)|\le\lambda$ 是同一件事，optimal 时 $u^\star$ 就是 residual。
:::

:::from
Lagrangian 对 feasible 点不超过 objective、dual function 作为 lower bound、dual 总是 concave、weak duality 不需要 convexity、Slater's condition、duality gap 作为 certificate 和停止规则、SVM 的 dual，跟着 [10-725 Duality in General Programs 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt-F16/lectures/dual-gen.pdf)；KKT 由 zero gap 的那串 inequality 推出（necessity 与 sufficiency）、complementary slackness 的读法、SVM 的 support vector 跟着 [KKT Conditions 一讲](https://www.stat.cmu.edu/~ryantibs/convexopt/lectures/kkt.pdf)。Multiplier 作为 sensitivity 和 shadow price 来自 [Boyd 与 Vandenberghe](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf) §5.6；lasso 的 dual 的形式在 10-725 Coordinate Descent 一讲推导 SAFE rule 时出现过，这里引入 $r$ 的推导是自己写的。$x^2$ 的例子、lasso 的 gap 数表、projection 的 QP、8 个点上的 SVM 验证、$-x^2$ 和 $x^2\le0$ 两个 counterexample 是为这一页算的。
:::

## [admm] Augmented Lagrangian 与 ADMM

:::skip
能写出 scaled ADMM 的三步，手算 $\tfrac12(x-3)^2+|z|$ 的前几步，说出 dual update 去掉之后会 converge 到哪里，并用 primal residual 和 dual residual 判断停止，就读完了这一页。
:::

### 一个 prox 算不出来的问题

一个 sensor 读出 8 个数，真实信号是 piecewise constant 的（中途跳了一次），读数带 noise：

$$y=(1.0,\ 1.4,\ 0.7,\ 1.1,\ 3.2,\ 2.6,\ 3.1,\ 2.9)$$

想要一个接近 $y$、但相邻值尽量相同的 $\theta$：

$$\min_\theta\ \tfrac12\|\theta-y\|^2+\lambda\sum_{j=1}^{7}|\theta_{j+1}-\theta_j|=\tfrac12\|\theta-y\|^2+\lambda\|D\theta\|_1$$

$D$ 是 $7\times8$ 的 difference matrix，$(D\theta)_j=\theta_{j+1}-\theta_j$。这叫 total variation denoising（1D 的 fused lasso）。$\|\cdot\|_1$ 让 $D\theta$ 的大部分 entry 变成 0，即 $\theta$ 的大部分相邻值相等。

第 4 站的 proximal gradient 需要 $\lambda\|D\theta\|_1$ 的 prox，而它的各个 coordinate 通过 $D$ 互相纠缠，没有 soft-thresholding 那样的 closed form。第 5 站的 coordinate descent 会被卡住，这个 penalty 正是那里 counterexample 的形式。$\|z\|_1$ 本身的 prox 是好算的，麻烦只在 $z=D\theta$ 这一层 linear map。所以把它拆开：

$$\min_{\theta,z}\ \tfrac12\|\theta-y\|^2+\lambda\|z\|_1\quad\text{s.t.}\quad D\theta-z=0$$

两个 term 各管一个 variable，代价是多了一个 equality constraint。这一站解决的就是“$f(x)+g(z)$ subject to $Ax+Bz=c$”这种形式。

### Dual ascent，以及它在哪里失败

$\min f(x)$ subject to $Ax=b$ 的 dual function 是 $g(u)=\min_xL(x,u)$，$L=f(x)+u^\top(Ax-b)$。如果 $x(u)$ 是这个 minimizer，那么 $g$ 在 $u$ 处的 gradient 是 $Ax(u)-b$：$g(u)=f(x(u))+u^\top(Ax(u)-b)$，$u$ 变化时 $x(u)$ 也变，但 $x(u)$ 是 minimizer，它的变化对 $L$ 的一阶影响是 0，只剩 $u$ 直接出现的那一项。Dual 的 gradient 就是 constraint 的 residual。对 dual 做 gradient ascent：

$$x_k=\arg\min_xL(x,u_{k-1}),\qquad u_k=u_{k-1}+t\,(Ax_k-b)$$

Constraint 被违反多少，multiplier（价格）就调整多少。

拿一个能手算的小问题试：

$$\min_{x,z}\ \tfrac12(x-3)^2+|z|\quad\text{s.t.}\quad x-z=0$$

答案显然是 $\min_x\tfrac12(x-3)^2+|x|$，即 $S_1(3)=2$。Lagrangian 是 $\tfrac12(x-3)^2+|z|+u(x-z)$。对 $z$ 求 minimum：$|z|-uz$。$|u|<1$ 时最小在 $z=0$；$|u|>1$ 时 $\to-\infty$；$u=1$ 时 $|z|-z$ 对所有 $z\ge0$ 都是 0，minimizer 不唯一。而 dual 的 solution 恰好是 $u^\star=1$（第 2 站：$x^\star=2$ 时 $|x|$ 的 subgradient 是 1）。Dual ascent 越接近 $u^\star$，$z$ 的 update 越说不清该取什么：$|z|$ 不是 strictly convex，$\arg\min$ 在 optimal multiplier 处不唯一。Dual ascent 一般要求 $f$ strictly convex 才行。

### Augmented Lagrangian：$\rho$ 正好是 step size

在 objective 上加一个在 feasible 点处为 0 的 penalty，problem 不变：

$$\min_x\ f(x)+\frac\rho2\|Ax-b\|^2\quad\text{s.t.}\quad Ax=b$$

它的 Lagrangian 叫 augmented Lagrangian $L_\rho=f(x)+u^\top(Ax-b)+\tfrac\rho2\|Ax-b\|^2$。Quadratic penalty 让 $\arg\min_x$ 变得确定。对它做 dual ascent，step size 取 $\rho$，叫 method of multipliers：

$$x_k=\arg\min_xL_\rho(x,u_{k-1}),\qquad u_k=u_{k-1}+\rho\,(Ax_k-b)$$

为什么 step size 恰好取 $\rho$：$x_k$ 是 minimizer，所以

$$0\in\partial f(x_k)+A^\top u_{k-1}+\rho A^\top(Ax_k-b)=\partial f(x_k)+A^\top\big(u_{k-1}+\rho(Ax_k-b)\big)=\partial f(x_k)+A^\top u_k$$

这正是原 problem 的 stationarity condition（第 6 站），用的是更新后的 $u_k$。所以每一步之后 stationarity 自动成立，只差 primal feasibility $Ax_k=b$，而它在 iteration 中趋于满足。

代价是：$\tfrac\rho2\|Ax+Bz-c\|^2$ 把 $x$ 和 $z$ 耦合在一起，联合求 $\arg\min_{x,z}$ 又回到了一个难问题。

### ADMM：轮流最小化

ADMM（alternating direction method of multipliers）把联合的 minimization 拆成两步：$x$、$z$ 各最小化一次，再更新 multiplier。写成 scaled form（$w=u/\rho$，complete the square 后更简洁）：

$$\begin{aligned}x_k&=\arg\min_x\ f(x)+\frac\rho2\|Ax+Bz_{k-1}-c+w_{k-1}\|^2\\z_k&=\arg\min_z\ g(z)+\frac\rho2\|Ax_k+Bz-c+w_{k-1}\|^2\\w_k&=w_{k-1}+Ax_k+Bz_k-c\end{aligned}$$

$w$ 是 residual 的累加。$z$ 那一步只涉及 $g$，往往就是一个 prox。

在 $\tfrac12(x-3)^2+|z|$、$x-z=0$ 上，$\rho=1$：

- $x$-step：$\tfrac12(x-3)^2+\tfrac12(x-z+w)^2$ 对 $x$ 求 derivative，$x-3+x-z+w=0$，$x=\tfrac{3+z-w}2$。
- $z$-step：$|z|+\tfrac12(x+w-z)^2$，第 2 站的一元 lasso，$z=S_1(x+w)$。
- $w\leftarrow w+x-z$。

从 $z=w=0$ 出发：

| $k$ | $x_k$ | $z_k$ | $w_k$ |
|---|---|---|---|
| 1 | $\tfrac{3}{2}=1.5$ | $S_1(1.5)=0.5$ | $0+1.5-0.5=1$ |
| 2 | $\tfrac{3+0.5-1}2=1.25$ | $S_1(2.25)=1.25$ | 1 |
| 3 | 1.625 | 1.625 | 1 |
| 4 | 1.8125 | 1.8125 | 1 |
| 10 | 1.99707 | 1.99707 | 1 |

第 1 步之后 $w$ 就等于 1，$u=\rho w=1=u^\star$，multiplier 已经找到。从第 2 步起 $x_k+w>1$，$z_k=S_1(x_k+1)=x_k$，于是 $x_{k+1}=\tfrac{3+x_k-1}{2}=1+\tfrac{x_k}2$，fixed point 2，error 每步减半。

:::wrong ADMM 就是对 penalty problem 轮流做 coordinate minimization
把 $w$ 的 update 去掉（一直是 0），只轮流最小化 $\tfrac12(x-3)^2+|z|+\tfrac12(x-z)^2$：$x=\tfrac{3+z}2$，$z=S_1(x)$。Fixed point 满足 $x=\tfrac{3+x-1}2$，即 $x=2$、$z=1$，实际 iteration 也 converge 到这里。$x\ne z$，constraint 不满足。它最小化的是加了 penalty 的另一个 problem，penalty 只惩罚 $x-z$，不强制它为 0。

$w$ 的作用是把 residual 累加起来，持续把 $x$、$z$ 往一起推，直到 residual 为 0；那时 $w$ 停止变化，$\rho w$ 就是 multiplier。上面那张表里 $w=1$ 正是把 $z$ 从 1 推到 2 的那份“价格”。
:::

### 什么时候停，$\rho$ 怎么选

ADMM 在很弱的条件下（$f$、$g$ closed convex，有 solution，不要求 $A$、$B$ full rank），对任何 $\rho>0$ 都有：residual $Ax_k+Bz_k-c\to0$，objective $\to$ optimal value，$u_k\to u^\star$。速度没有一般的 rate，经验上和 first-order method 相当：几十步得到中等 accuracy，高 accuracy 要很多步。

停止看两个 residual：

- primal residual $r_k=Ax_k+Bz_k-c$，衡量 feasibility；
- dual residual $s_k=\rho A^\top B(z_k-z_{k-1})$，衡量 stationarity（$x$-step 的 optimality condition 里，用 $z_k$ 代替 $z_{k-1}$ 时差出来的正是这一项）。

两者都小于 tolerance 时停。$\rho$ 大，更重视 feasibility，$r$ 降得快、$s$ 降得慢；$\rho$ 小则相反。实际跑出来的 iteration 数（两个 residual 都小于 $10^{-6}$）：

| $\rho$ | 0.1 | 0.3 | 1 | 3 | 10 |
|---|---|---|---|---|---|
| $\tfrac12(x-3)^2+\lvert z\rvert$ | 11 | 12 | 22 | 51 | 153 |

不同 problem 的最佳 $\rho$ 不同，下面的 total variation 例子里 $\rho=1$ 最快。

### 回到 total variation denoising

$f(\theta)=\tfrac12\|\theta-y\|^2$，$g(z)=\lambda\|z\|_1$，constraint $D\theta-z=0$（$A=D$，$B=-I$，$c=0$）：

- $\theta$-step：$\tfrac12\|\theta-y\|^2+\tfrac\rho2\|D\theta-z+w\|^2$ 的 gradient 为 0，$(I+\rho D^\top D)\,\theta=y+\rho D^\top(z-w)$。每一步解同一个 matrix 的 linear system，它是 SPD 且 tridiagonal 的，用 [DSA2102 第 2 站](../courses/DSA2102.html#lu)的 Cholesky 分解一次即可反复用。
- $z$-step：$\lambda\|z\|_1+\tfrac\rho2\|D\theta+w-z\|^2$，逐个 coordinate 的 soft-thresholding，$z=S_{\lambda/\rho}(D\theta+w)$。
- $w\leftarrow w+D\theta-z$。

```python
import numpy as np

def soft(v, k):
    return np.sign(v) * np.maximum(np.abs(v) - k, 0)

def tv_admm(y, lam, rho=1.0, tol=1e-8, max_iter=5000):
    n = len(y)
    D = np.diff(np.eye(n), axis=0)            # (D @ theta)[j] = theta[j+1] - theta[j]
    M = np.eye(n) + rho * D.T @ D             # same matrix in every theta-step
    z = D @ y
    w = np.zeros(n - 1)
    for k in range(1, max_iter + 1):
        theta = np.linalg.solve(M, y + rho * D.T @ (z - w))
        z_old = z
        z = soft(D @ theta + w, lam / rho)
        w = w + D @ theta - z
        r = np.linalg.norm(D @ theta - z)              # primal residual
        s = np.linalg.norm(rho * D.T @ (z - z_old))    # dual residual
        if r < tol and s < tol:
            break
    return theta, k

y = np.array([1.0, 1.4, 0.7, 1.1, 3.2, 2.6, 3.1, 2.9])
print(tv_admm(y, 0.5))
```

$\lambda=0.5$、$\rho=1$ 时 43 步停下（$\rho=0.1$ 要 300 步，$\rho=10$ 要 100 步），得到

$$\theta^\star=(1.175,\ 1.175,\ 1.175,\ 1.175,\ 2.825,\ 2.825,\ 2.825,\ 2.825)$$

::fig[dsa3102-tv] 圆点是读数，彩色 step 是 total variation denoising 的结果：只在第 4、5 个点之间跳一次。

这两个值可以直接解释：前四个读数的 mean 是 1.05，后四个是 2.95。只剩一次跳跃时，objective 是 $\tfrac12\sum(\theta_a-y_i)^2+\tfrac12\sum(\theta_b-y_i)^2+\lambda(\theta_b-\theta_a)$，对 $\theta_a$ 求 derivative：$4\theta_a-\sum_{i\le4}y_i-\lambda=0$，$\theta_a=1.05+\tfrac\lambda4=1.175$；同理 $\theta_b=2.95-0.125=2.825$。Penalty 把两段各自往对方拉近 $\lambda/4$。

它是 optimal 的，用第 2 站的 optimality condition 验证。$0\in\theta-y+D^\top v$，$v_j\in\lambda\,\partial|(D\theta)_j|$。$(D^\top v)_i=v_{i-1}-v_i$（约定 $v_0=v_8=0$），所以 condition 逐个写开是 $v_i=v_{i-1}+(\theta_i-y_i)$，即 $v_i$ 是 $\theta-y$ 的 cumulative sum：

$$\theta-y=(0.175,\ -0.225,\ 0.475,\ 0.075,\ -0.375,\ 0.225,\ -0.275,\ -0.075)$$

$$v=(0.175,\ -0.05,\ 0.425,\ 0.5,\ 0.125,\ 0.35,\ 0.075),\qquad v_8=0$$

没有跳跃的位置，$(D\theta)_j=0$，要求 $|v_j|\le0.5$；跳跃的位置 $j=4$，$(D\theta)_4>0$，要求 $v_4=\lambda=0.5$。全部满足，最后的 $v_8=0$ 也对上了。

:::back
$z$-step 是[第 2 站](#subgrad)的 soft-thresholding；stationarity 和 multiplier 来自[第 6 站](#dual)；这个 penalty 为什么不能用 coordinate descent，见[第 5 站](#scd)的 counterexample。
:::
