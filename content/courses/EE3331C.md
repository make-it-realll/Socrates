先看三件事。三件事都发生在同一个 DC motor 上，第 1 站会把它的 model 推出来。

**第一件。** 要让 motor 以 1 rad/s 转，查 model：每 1 V 的 voltage 在 steady state 下给 0.5 rad/s，于是加 2 V。Motor 带上一个更重的 load、或者发热之后，这个 0.5 变成了 0.4，speed 就跟着少了 20%，而 controller 完全不知道。

::fig[ee3331c-openloop] 上一行是 model 说的情形，下一行是 plant 变了之后；右边的圆盘是 motor 的 rotor（3 倍速）。看下一行：虚线按 1 rad/s 转，彩色标记线每圈都落后一点，转完 5 圈的时间里它只转了 4 圈，而 controller 一直不知道。

**第二件。** 改成量 position、用 error 乘一个 gain $K$ 去驱动 motor。照简化后的 second-order model，$K$ 取多大 closed loop 都 stable；为了让 ramp input 的 error 小，把 $K$ 提到 50。实际的 motor 开始 oscillate，而且 amplitude 一圈比一圈大。

::fig[ee3331c-k50] 同一个 gain 放在两个 model 上。右边是两根 motor shaft，按真实时间转向 1 rad 的目标，左边曲线上的点同步走：简化 model 的 shaft 甩几下就停在目标上，真实 plant 的那根每一下都比上一下甩得更远。第 3 站会算出真实 plant 在 $K>44$ 时 unstable。

**第三件。** 退回到 $K=4$，response 不再 oscillate 了，可 settling time 要 4 秒。把 $K$ 从 1 加到 100，settling time 始终在 2.8 到 5.8 秒之间，怎么调都快不起来。

::fig[ee3331c-tsk] 每个 $K$ 都实算一次 step response。曲线是锯齿状的，因为每多一个 peak 越出 ±2% band，settling time 就跳一下。

第一件说明为什么要 feedback：model 永远不准，只有量 output 才能纠正 model 的 error（第 1 站）。第二件说明 feedback 的代价：gain 一高，system 可能 unstable，而且简化的 model 看不出来（第 3、6 站）。第三件说明只有一个 gain 可调是不够的，要给 controller 加上 zero 和 pole（第 7、8 站）。

这门课的工具都是为了回答同一个问题：给定 plant $G(s)$，选一个 controller $C(s)$，closed loop 会怎样。回答有两套语言。一套看 closed-loop pole 在 s-plane 上的位置（第 2、3、5 站），它直接对应 time response；一套看 loop transfer function $L(j\omega)=C(j\omega)G(j\omega)$ 的 frequency response（第 6 站），它可以直接测量，也能处理 time delay。第 7、8 站用两套语言各设计一遍 controller，并在同一个 motor 上比较结果。

整页只用一个 plant：

$$G(s)=\frac{20}{s(s+2)(s+20)}\qquad\text{以及它的简化版}\qquad G(s)\approx\frac{1}{s(s+2)}$$

前提知识是 [EE2023](../courses/EE2023.html) 的 Laplace transform、pole 与 second-order system、Bode plot，用到时会链接过去，不再重讲。

## [feedback] Modelling、block diagram 与 feedback 的作用

:::skip
能从 motor 的两条物理定律推出 $G(s)$，能把一个带 inner loop 的 block diagram 化简，能说出 sensitivity function 是怎么推出来的、$S+T=1$ 限制了什么，就可以去第 2 站。
:::

### 从物理定律到 transfer function

DC motor 有两条 equation。Armature circuit 里，voltage $V$ 要克服 resistance $R$、inductance $L$ 和 back-emf（与 speed $\omega$ 成正比，constant 为 $K$）：

$$L\frac{di}{dt}+Ri+K\omega=V$$

Rotor 上，current 产生的 torque $Ki$ 推动 inertia $J$（friction 忽略）：

$$J\frac{d\omega}{dt}=Ki$$

Initial condition 取 0，两边做 Laplace transform，derivative 变成乘 $s$（[EE2023 第 4 站](../courses/EE2023.html#laplace)）：

$$(Ls+R)\,I(s)=V(s)-K\,\Omega(s),\qquad Js\,\Omega(s)=K\,I(s)$$

由第二式 $I=\dfrac{Js}{K}\Omega$，代入第一式：

$$(Ls+R)\frac{Js}{K}\Omega+K\Omega=V\quad\Longrightarrow\quad\frac{\Omega(s)}{V(s)}=\frac{K}{LJs^2+RJs+K^2}$$

这一页取 $R=2.2\ \Omega$，$L=0.1$ H，$K=2$ V·s/rad，$J=1$ kg·m²（折算到 motor 轴上的 load 的 inertia）。代进去：

$$\frac{\Omega(s)}{V(s)}=\frac{2}{0.1s^2+2.2s+4}=\frac{20}{s^2+22s+40}=\frac{20}{(s+2)(s+20)}$$

Position 是 speed 的 integral，$\Theta(s)=\Omega(s)/s$，所以从 voltage 到 position：

$$G(s)=\frac{\Theta(s)}{V(s)}=\frac{20}{s(s+2)(s+20)}$$

三个 pole 各有来历：$0$ 来自“position 是 speed 的 integral”；$-2$ 是 mechanical 的 time constant（0.5 s）；$-20$ 主要来自 inductance，electrical 的变化快得多。DC 时 speed 与 voltage 之比是 $\dfrac{20}{2\times20}=0.5$ rad/s per V，正是开头第一件事里的 0.5。

Factor $\dfrac{20}{s+20}$ 在低 frequency 时接近 1。在 $s=j\omega$ 上算几个值：

| $\omega$（rad/s） | 2 | 5 | 10 |
|---|---|---|---|
| $\left\vert\dfrac{20}{j\omega+20}\right\vert$ | 0.995 | 0.970 | 0.894 |
| phase | $-5.7^\circ$ | $-14.0^\circ$ | $-26.6^\circ$ |

所以只关心几 rad/s 以下的行为时，可以把它当成 1，得到简化的 model $G(s)\approx\dfrac{1}{s(s+2)}$。这个近似在第 2 站让 formula 变得干净；但 controller 一旦想让 loop 快到 5 rad/s 左右，被丢掉的 $-14^\circ$ 就会出来算账（第 3、7 站）。

### Block diagram 是 algebra

每个 block 是一个 transfer function，output 等于 input 乘上它，所以 block diagram 的化简就是解 linear equation。串联的 block 相乘，并联的相加。最重要的是 feedback loop：

::fig[ee3331c-loop] Unity feedback 的标准形式。$r$ 是 reference，$e=r-(y+n)$ 是 controller 看到的 error，$d$ 是 disturbance（例如 load torque，折算成 plant input 处的等效 voltage），$n$ 是 sensor noise。

先只看 $r$（令 $d=n=0$）。三个关系 $y=Gu$、$u=Ce$、$e=r-y$ 连起来：

$$y=CG\,(r-y)\quad\Longrightarrow\quad(1+CG)\,y=CG\,r\quad\Longrightarrow\quad\frac{y}{r}=\frac{CG}{1+CG}$$

$L=CG$ 叫 loop transfer function（沿 loop 走一圈经过的所有 block 的乘积），closed-loop transfer function 的 denominator 永远是 $1+L$。

用一个带 inner loop 的例子练一次。给 motor 装一个 tachometer 量 speed，controller 是 $u=K(r-\theta)-k_t\,\omega$，plant 用简化 model $\theta=\dfrac{1}{s(s+2)}u$，$\omega=s\theta$。不用画图移动 block，直接代：

$$s(s+2)\,\theta=Kr-K\theta-k_ts\,\theta\quad\Longrightarrow\quad\frac{\theta}{r}=\frac{K}{s^2+(2+k_t)s+K}$$

没有 tachometer 时 denominator 是 $s^2+2s+K$；有了它，$s$ 的 coefficient 从 2 变成 $2+k_t$。取 $K=16$：没有 tachometer 时 $\omega_n=4$，$2\zeta\omega_n=2$，$\zeta=0.25$；$k_t=2$ 时 $2\zeta\omega_n=4$，$\zeta=0.5$。Speed feedback 只加 damping，不改 $\omega_n$，也不在 numerator 里加 zero。第 8 站会看到，这正是 PID 里 derivative 应该作用在 output 上的原因。

::fig[ee3331c-tacho] 两个 loop 套在一起。$u=K(r-\theta)-k_t\omega$ 就是从图上读出来的。

### 为什么要 feedback：对 plant 变化的 sensitivity

回到开头第一件事，用 speed loop 把两种做法算一遍。Plant 是 $\dfrac{20}{(s+2)(s+20)}$，DC gain 记作 $g$，名义值 0.5。

**Open loop。** 按名义 model 加 $V=2r$。Steady-state speed 是 $2g\,r$：$g=0.5$ 时恰好是 $r$，$g=0.4$ 时是 $0.8r$。Plant 变 20%，output 就变 20%。

**Closed loop。** $V=50\,(r-\omega)$。Steady state 时 $s=0$，loop gain 是 $50g$，按上面的 formula

$$\frac{\omega}{r}=\frac{50g}{1+50g}:\qquad g=0.5\ \text{时}\ \frac{25}{26}=0.9615,\qquad g=0.4\ \text{时}\ \frac{20}{21}=0.9524$$

Plant 同样变了 20%，output 只变了 $\dfrac{0.9524-0.9615}{0.9615}=-0.95\%$。

::fig[ee3331c-sens] 横轴是 plant 的真实 DC gain，纵轴是 steady-state speed 与 reference 之比。Open loop 的 output 和 plant gain 成正比；closed loop 的几乎是平的。

这个缩小的倍数可以一般地算出来。Closed-loop transfer function $T=\dfrac{CG}{1+CG}$，把它看成 $G$ 的 function，对 $G$ 求 derivative：

$$\frac{dT}{dG}=\frac{C(1+CG)-CG\cdot C}{(1+CG)^2}=\frac{C}{(1+CG)^2}$$

问的是 relative change 之比，所以乘上 $\dfrac{G}{T}=\dfrac{G(1+CG)}{CG}=\dfrac{1+CG}{C}$：

$$\frac{dT/T}{dG/G}=\frac{C}{(1+CG)^2}\cdot\frac{1+CG}{C}=\frac{1}{1+CG}\equiv S$$

$S$ 叫 sensitivity function。Speed loop 在 DC 的 $L=50\times0.5=25$，$S=\tfrac1{26}=0.038$：plant 变 20%，output 大约变 $20\%\times0.038=0.77\%$。实际算出来是 0.95%，差别来自 20% 不是一个无穷小的变化，$S$ 本身也随 $g$ 变了；量级是对的。Loop gain 越高，$S$ 越小，closed loop 越不在乎 plant 准不准。

> Feedback 用一个精确的东西（sensor 和 controller 里的 gain）去代替一个不精确的东西（plant 的 model）。

### Disturbance 和 noise：$S+T=1$

把三个 input 都放进来。由图，$y=G(u+d)$，$u=C(r-y-n)$。代入：

$$y=CG\,r-CG\,y-CG\,n+G\,d\quad\Longrightarrow\quad y=\underbrace{\frac{CG}{1+CG}}_{T}\,r+\underbrace{\frac{1}{1+CG}}_{S}\,G\,d-\underbrace{\frac{CG}{1+CG}}_{T}\,n$$

Disturbance 先经过 plant 变成 $Gd$，feedback 再把它乘上 $S$：open loop 时 load 造成的 speed 下降，closed loop 时只剩 $\tfrac1{26}$。这和对 plant 变化的 sensitivity 是同一个 $S$。

麻烦在于

$$S+T=\frac{1}{1+L}+\frac{L}{1+L}=1$$

想让 disturbance 和 plant 变化的影响小，要 $S$ 小，于是 $T\approx1$，sensor noise 会原样进入 output；想让 noise 进不来，要 $T$ 小，于是 $S\approx1$，feedback 的好处全没了。在同一个 frequency 上两者不可兼得。出路是按 frequency 分工：reference 和 disturbance 通常是慢的，noise 通常是快的，所以让 $\lvert L\rvert$ 在低 frequency 很大（$S$ 小）、在高 frequency 很小（$T$ 小）。第 6、7 站在 Bode plot 上做的事，就是在两段之间安排 $\lvert L\rvert$ 怎样从大变小。

:::wrong Open loop 只要把 gain 算准，效果和 feedback 一样，甚至更好
名义情况下确实如此：open loop 的 output 恰好是 1.000，closed loop 只有 0.962。但 open loop 的准确完全建立在“plant 恰好是 model 说的样子”上。Plant gain 偏 20%，open loop 偏 20%，closed loop 偏 0.95%。Disturbance 更糟：open loop 不量 output，load 加上去它根本不知道，影响一点也不会被纠正。而 closed loop 剩下的那 3.8% 的 steady-state error，第 4 站有办法消掉。
:::

:::edge High gain 的代价
上面一切好处都来自“loop gain 大”。可 gain 不能随便加：position loop 用真实的 third-order plant、取 $K=50$，closed-loop pole 是 $-22.22$ 和 $0.112\pm j6.71$，real part 是正的，oscillation 越来越大。这就是开头的第二件事。简化 model $\dfrac{1}{s(s+2)}$ 的 closed loop $s^2+2s+K$ 对任何 $K>0$ 都 stable，它看不到这个问题。第 3 站给出判断 stability 的方法。
:::

:::from
“open loop 用 $1/10$ 对付 gain 为 10 的 plant、closed loop 用 $K=5$，plant 变 50% 时 closed loop 只变 0.66%”的对比、sensitivity $S=1/(1+KG)$、disturbance 被乘上 $1/(1+KG)$，来自 [16.06 第 2 讲](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/resources/mit16_06f12_lecture_2/)；这里换成 motor 的 speed loop 重算。$S+T=1$ 的 trade-off 和“按 frequency 分工”来自 [16.06 第 9 讲](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/resources/mit16_06f12_lecture_9/)。“feedback 把 sensitivity 和 disturbance 都缩小 $k+1$ 倍”来自 [Åström 与 Murray 第 2 章](http://www.cds.caltech.edu/~murray/books/AM08/pdf/fbs-principles_24Jul2020.pdf)。Motor 的 model、parameter、tachometer 的例子是为这一页写的，没有对着某一讲。
:::

## [tresp] Time response 与 performance specification

:::skip
能把“overshoot 不超过 25%、settling time 不超过 2 s”翻译成 s-plane 上的一个区域，能说明 P control 为什么进不了这个区域，能解释 zero 为什么让 overshoot 变大，就可以去第 3 站。
:::

### 把“好”写成数字

Second-order system $\dfrac{\omega_n^2}{s^2+2\zeta\omega_ns+\omega_n^2}$ 的 step response 和 overshoot formula 在 [EE2023 第 5 站](../courses/EE2023.html#pz)推过：pole 在 $-\zeta\omega_n\pm j\omega_d$，$\omega_d=\omega_n\sqrt{1-\zeta^2}$，

$$y(t)=1-e^{-\zeta\omega_nt}\Big(\cos\omega_dt+\frac{\zeta}{\sqrt{1-\zeta^2}}\sin\omega_dt\Big)$$

Control 课用四个数描述这条 curve，每个都对应 pole 的一个几何量。

| Specification | 定义 | 与 pole 的关系 |
|---|---|---|
| Peak overshoot $M_p$ | 最高点超出 final value 的比例 | $M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}$，只由 $\zeta$ 决定 |
| Peak time $t_p$ | 到达最高点的时刻 | $t_p=\pi/\omega_d$，由 imaginary part 决定 |
| Rise time $t_r$ | 从 10% 升到 90% 的时间 | 约 $1.8/\omega_n$，由 pole 到 origin 的距离决定 |
| Settling time $t_s$ | 进入 final value 的 ±2% 后不再出来 | 约 $4/(\zeta\omega_n)$，由 real part 决定 |

Settling time 的来历：括号里的 oscillation 的 amplitude 不超过 $1/\sqrt{1-\zeta^2}$，在 $\zeta$ 不太大时接近 1，所以 error 的 envelope 大约是 $e^{-\zeta\omega_nt}$。令它等于 0.02：

$$e^{-\zeta\omega_nt_s}=0.02\quad\Longrightarrow\quad t_s=\frac{\ln50}{\zeta\omega_n}=\frac{3.9}{\zeta\omega_n}\approx\frac{4}{\zeta\omega_n}$$

这四个 formula 里，$M_p$ 和 $t_p$ 是 exact 的，$t_r$ 和 $t_s$ 是近似。

现在反过来用：给定要求，pole 能放在哪里？这一页给 motor 定的要求是：overshoot 不超过 25%，settling time 不超过 2 s。

- $M_p\le25\%$：解 $e^{-\pi\zeta/\sqrt{1-\zeta^2}}=0.25$，得 $\zeta\ge0.40$。$\zeta$ 是 pole 与 negative real axis 所成 angle 的 $\cos$（pole 到 origin 的距离是 $\omega_n$，real part 是 $-\zeta\omega_n$），所以要求 pole 落在与 negative real axis 所成 angle 不超过 $\arccos0.4=66.4^\circ$ 的 wedge 里。
- $t_s\le2$ s：$\zeta\omega_n\ge4/2=2$，即 pole 的 real part 在 $-2$ 左边。

::fig[ee3331c-region] 两条要求在 s-plane 上划出的允许区域（浅色）。图里彩色的路线是下一节 P control 的 closed-loop pole。

### P control 能做到什么

用简化 model，controller 就是一个 gain $K$。Closed loop 是

$$\frac{\theta}{r}=\frac{K}{s^2+2s+K},\qquad\omega_n=\sqrt K,\qquad2\zeta\omega_n=2\ \Rightarrow\ \zeta=\frac{1}{\sqrt K}$$

Pole 是 $-1\pm\sqrt{1-K}$。$K<1$ 时两个 real pole，从 $0$ 和 $-2$ 出发相向而行；$K=1$ 时在 $-1$ 相遇；$K>1$ 时变成 $-1\pm j\sqrt{K-1}$，沿 $\mathrm{Re}\,s=-1$ 的竖线上下分开。Real part 永远是 $-1$，图里这条竖线完全在允许区域之外。

逐个算出来（simulation 实测，不是 formula 估计）：

| $K$ | $\zeta$ | $\omega_n$ | $M_p$ | $t_r$（s） | $t_s$（2%，s） |
|---|---|---|---|---|---|
| 1 | 1 | 1 | 0 | 3.36 | 5.83 |
| 4 | 0.5 | 2 | 16.3% | 0.82 | 4.04 |
| 6.25 | 0.4 | 2.5 | 25.4% | 0.59 | 3.36 |
| 10 | 0.316 | 3.16 | 35.1% | 0.43 | 3.54 |
| 40 | 0.158 | 6.32 | 60.5% | 0.18 | 3.66 |
| 100 | 0.1 | 10 | 72.9% | 0.11 | 3.84 |

$K$ 加到 100 倍，rise time 快了 30 倍，settling time 几乎不动，overshoot 越来越大。

::fig[ee3331c-pstep] 三个 gain 的 step response。$K$ 越大越早冲过头，但都被同一条 envelope $1\pm e^{-t}$ 关着，要 4 秒左右才能安定下来。

原因就是那条竖线：settling 快慢由 real part 决定，而一个 gain 只能把 pole 沿竖线推，推不动 real part。要让 pole 往左走，必须改变 locus 的形状，也就是给 controller 加 dynamics（第 7 站）。第 5 站会把“pole 随 gain 走的路线”变成一般的作图方法。

### 第三个 pole 会改变这些数

上面的表用的是简化 model。换成真实的 third-order plant、同样取 $K=4$，closed-loop characteristic polynomial 是 $s(s+2)(s+20)+80=s^3+22s^2+40s+80$，三个 root 是 $-20.22$ 和 $-0.891\pm j1.778$。Simulation 给出 overshoot 20.6%，而不是 16.3%。

是 $-20.22$ 这个 pole 让 overshoot 变大了吗？不是它本身：它对应的 mode $e^{-20t}$ 在 0.2 秒内就 decay 完了。变化来自它把另外两个 pole 推动了。那对 pole 的 $\zeta=\dfrac{0.891}{\sqrt{0.891^2+1.778^2}}=0.448$，代进 overshoot formula 得 $e^{-\pi\times0.448/0.894}=20.7\%$，正好对上。

所以 dominant pole 的近似有两层意思：离 imaginary axis 远得多的 pole 自己的 mode 可以忽略；但设计时要用真实 plant 去算那对 dominant pole 落在哪里。前者通常成立，后者常被忘掉。

### Zero 会改变这些数

Closed loop 里常常还有 zero（第 7、8 站的 controller 都会带来 zero）。给上面 $\zeta=0.5$ 的 system 乘一个 factor $\big(\tfrac sa+1\big)$，DC gain 不变：

$$T(s)=\Big(\frac sa+1\Big)T_0(s),\qquad T_0(s)=\frac{4}{s^2+2s+4}$$

乘 $s$ 在 time domain 是求 derivative，所以 step response 是

$$y(t)=y_0(t)+\frac1a\,\dot y_0(t)$$

$y_0$ 是没有 zero 时的 response。$\dot y_0$ 在 $y_0$ 上升最陡的时候最大，正好在第一个峰之前，于是两者叠加让峰值更高、来得更早。$a$ 越小（zero 越靠近 origin），加上去的 derivative 越多。

| zero 的位置 | $-0.5$ | $-1$ | $-2$ | $-4$ | $-10$ | 没有 zero |
|---|---|---|---|---|---|---|
| $M_p$ | 171% | 69.9% | 29.8% | 19.1% | 16.7% | 16.3% |
| $t_p$（s） | 0.74 | 0.91 | 1.21 | 1.51 | 1.70 | 1.81 |

::fig[ee3331c-zero] 同一对 pole，不同位置的 zero。Zero 离 dominant pole 的 real part（这里是 $-1$）越近，影响越大；在 $-10$ 时已经几乎看不出来。

额外的 closed-loop pole 作用相反。把 $T_0$ 乘上 $\dfrac{p}{s+p}$，相当于让 response 先经过一个 lowpass，overshoot 变小、response 变慢：

| 额外 pole 的位置 | $-1$ | $-2$ | $-4$ | $-10$ | $-20$ |
|---|---|---|---|---|---|
| $M_p$ | 0 | 8.1% | 13.9% | 15.9% | 16.2% |

:::wrong Overshoot 只由 $\zeta$ 决定，所以看 dominant pole 的 $\zeta$ 就能预测 overshoot
只有在 closed loop 恰好是两个 pole、没有 zero 时才对。上面的表里，$-1$ 处一个 zero 让 $\zeta=0.5$ 的 system 冲出 70%，是 formula 预测的四倍多。设计时 $\zeta$ 是起点，最后要用 simulation 核对；第 7 站的两个 design 都因为 controller 的 zero 比 formula 多出几个百分点。
:::

:::edge Settling time 的另一种约定
有的教材（包括 16.06 和 Franklin 等人的教材）用 ±1% 的 band，相应的近似是 $t_s\approx4.6/(\zeta\omega_n)$，因为 $\ln100=4.6$。Rise time 也有 0% 到 100% 的定义。考试按课上用的那一种，这一页一律用 ±2% 和 10% 到 90%。
:::

:::back
Second-order system 的 step response 与 overshoot 的推导见 [EE2023 第 5 站](../courses/EE2023.html#pz)。
:::

## [routh] Stability 与 Routh–Hurwitz

:::skip
能对任意一个带 $K$ 的 characteristic polynomial 列出 Routh array、解出 stable 的 $K$ 范围和临界时的 oscillation frequency，能处理两种特殊情况，就可以去第 4 站。
:::

### 不解 equation，怎么知道 root 在哪一边

Closed loop stable，当且仅当 characteristic polynomial $1+L=0$ 的 root 全在 left half-plane（[EE2023 第 5 站](../courses/EE2023.html#pz)）。Position loop 用真实 plant、P control：

$$s(s+2)(s+20)+20K=s^3+22s^2+40s+20K=0$$

$K=50$ 时 root 是 $-22.22$ 和 $0.112\pm j6.71$，unstable。想知道的是哪些 $K$ 可以用。对每个 $K$ 都解一次 cubic 是不现实的，而且得不到一个 formula。需要一个只看 coefficient 的办法。

### 一个必要条件

如果所有 root 都在 left half-plane，polynomial 可以拆成 $(s+a)$（real root $-a$，$a>0$）和 $(s^2+bs+c)$（一对 complex root $-\sigma\pm j\omega$，$b=2\sigma>0$，$c=\sigma^2+\omega^2>0$）的 product。这些 factor 的 coefficient 全是正的，乘起来不会出现负号，也不会有哪一项被抵消成 0。所以：

> Stable 的必要条件：characteristic polynomial 的 coefficient 全部同号，而且没有缺项。

Motor 的 polynomial 在 $K>0$ 时四个 coefficient 都是正的，这个条件通过了，却说明不了什么：$K=50$ 时它同样通过。还需要一个充分的条件。

### Third order：看 root 在什么时候穿过 imaginary axis

$K$ 从 0 开始连续增大，root 连续移动。$K$ 很小时，三个 root 分别在 0、$-2$、$-20$ 附近，靠近 0 的那个是一个很小的负数，都在 left half-plane。要变成 unstable，某个 root 必须穿过 imaginary axis。穿过 origin 不可能（constant term $20K\ne0$），所以只能是一对 root 恰好落在 $\pm j\omega$ 上。

对一般的 $s^3+a_1s^2+a_2s+a_3$，把 $s=j\omega$ 代进去，用 $j^2=-1$、$j^3=-j$：

$$-j\omega^3-a_1\omega^2+ja_2\omega+a_3=(a_3-a_1\omega^2)+j\,\omega(a_2-\omega^2)=0$$

Real part 和 imaginary part 都要为 0：$\omega^2=a_2$，并且 $a_3=a_1\omega^2=a_1a_2$。所以 stability 的边界是 $a_1a_2=a_3$。$a_3$ 很小时 stable，于是在 coefficient 都为正的前提下：

$$s^3+a_1s^2+a_2s+a_3\ \text{stable}\iff a_1a_2>a_3$$

对 motor：$22\times40>20K$，即 $K<44$。临界时 $\omega=\sqrt{a_2}=\sqrt{40}=6.32$ rad/s，oscillation 的 period 是 $2\pi/6.32=0.99$ s。$K=50$ 时实际的 imaginary part 是 6.71，在它附近，说得通。

### Routh array：任意阶

更高阶的 polynomial 不能这样一对一对地找，Routh array 把这个检查做成了一张表。对 $s^n+a_1s^{n-1}+\dots+a_n$：

- 第一行放 $1,\ a_2,\ a_4,\dots$，第二行放 $a_1,\ a_3,\ a_5,\dots$。
- 以后每一行由紧挨在上面的两行算出。把那两行记作 $x_1,x_2,x_3,\dots$（上上行）和 $y_1,y_2,y_3,\dots$（上一行），新的一行的第 $k$ 个 entry 是

$$\frac{y_1\,x_{k+1}-x_1\,y_{k+1}}{y_1}$$

  缺的 entry 当作 0。

结论：**first column 的 sign change 的次数，等于 right half-plane 里 root 的个数。** 全为正就 stable。

先对 third order 列一次，看它和上面的推导是否一致：

$${\def\arraystretch{1.7}\begin{array}{c|cc}s^3&1&a_2\\s^2&a_1&a_3\\s^1&b_1&0\\s^0&a_3&\end{array}}$$

$s^1$ 行是 $b_1=\dfrac{a_1a_2-1\times a_3}{a_1}$，$s^0$ 行是 $\dfrac{b_1a_3-a_1\times0}{b_1}=a_3$。

First column 全正就是 $a_1>0$、$a_1a_2>a_3$、$a_3>0$，和上一节一样。一般情形的 proof 超出这门课，但每一行做的事情都是这里的推广。

Motor 的 array：

$${\def\arraystretch{1.7}\begin{array}{c|cc}s^3&1&40\\s^2&22&20K\\s^1&b_1&0\\s^0&20K&\end{array}}$$

$s^1$ 行是 $b_1=\dfrac{22\times40-1\times20K}{22}=\dfrac{880-20K}{22}$。

$K>44$ 时 $s^1$ 行变负，first column 的 sign 是 $+,+,-,+$，两次 sign change，两个 root 在 right half-plane。$K=50$ 正是这样。

再看一个 coefficient 全正却 unstable 的例子（16.06 第 8 讲）：$s^3+2s^2+3s+8$。

$${\def\arraystretch{1.7}\begin{array}{c|cc}s^3&1&3\\s^2&2&8\\s^1&-1&0\\s^0&8&\end{array}}$$

$s^1$ 行是 $\dfrac{2\times3-1\times8}{2}=-1$。

First column $1,2,-1,8$，两次 sign change。Root 是 $-2.25$ 和 $0.124\pm j1.882$，确实有两个在右边。

Fourth order 的例子留给第 8 站会用到的 polynomial $s^4+22s^3+192s^2+768s+1280$：

$${\def\arraystretch{1.7}\begin{array}{c|ccc}s^4&1&192&1280\\s^3&22&768&\\s^2&157.1&1280&\\s^1&588.7&&\\s^0&1280&&\end{array}}$$

其中 $s^2$ 行的首项是 $\dfrac{22\times192-1\times768}{22}=157.1$，第二项是 $\dfrac{22\times1280-1\times0}{22}=1280$；$s^1$ 行是 $\dfrac{157.1\times768-22\times1280}{157.1}=588.7$。

全部为正，stable。

:::wrong Coefficient 全是正的，system 就 stable
这只是必要条件。$s^3+2s^2+3s+8$ 四个 coefficient 都是正的，却有两个 root 在 right half-plane，因为 $a_1a_2=6<8=a_3$。对 second order 它恰好也是充分条件（$s^2+bs+c$ 的 root 之和是 $-b$、之积是 $c$，两者都满足时 root 一定都在左边），third order 起就不是了。
:::

### 两种特殊情况

**First column 出现 0，但那一行不全是 0。** 下一行要除以它，算不下去。办法是用一个很小的正数 $\varepsilon$ 代替这个 0，继续算，最后看 $\varepsilon\to0^+$ 时的 sign。例子：$s^4+s^3+2s^2+2s+3$。

$${\def\arraystretch{1.7}\begin{array}{c|ccc}s^4&1&2&3\\s^3&1&2&\\s^2&0\to\varepsilon&3&\\s^1&2-3/\varepsilon&&\\s^0&3&&\end{array}}$$

$s^2$ 行的首项是 $\dfrac{1\times2-1\times2}{1}=0$，换成 $\varepsilon$；$s^1$ 行是 $\dfrac{\varepsilon\times2-1\times3}{\varepsilon}=2-\dfrac3\varepsilon$，$\varepsilon\to0^+$ 时趋于 $-\infty$。First column 是 $+,+,+,-,+$，两次 sign change。实际的 root 是 $0.406\pm j1.293$ 和 $-0.906\pm j0.902$，两个在右边。

**整行都是 0。** 这说明有关于 origin 对称的一对 root，最常见的是一对 purely imaginary root，也就是恰好在 stability 的边界上。Motor 取 $K=44$：

$${\def\arraystretch{1.7}\begin{array}{c|cc}s^3&1&40\\s^2&22&880\\s^1&0&0\end{array}}$$

$s^1$ 行是 $\dfrac{22\times40-1\times880}{22}=0$，第二项也是 0，整行为 0。用它上面一行的 entry 组成 auxiliary polynomial $A(s)=22s^2+880$，它的 root 就是那对对称的 root：$s^2=-40$，$s=\pm j6.32$。然后用 $A'(s)=44s$ 的 coefficient 代替全 0 的那一行，继续：

$${\def\arraystretch{1.7}\begin{array}{c|cc}s^1&44&\\s^0&880&\end{array}}$$

First column 没有 sign change，没有 root 在 right half-plane；加上 $\pm j6.32$ 在 imaginary axis 上，system 是 marginally stable，response 里有一个不 decay 的 $6.32$ rad/s 的 oscillation。这正是 $K$ 的临界值。

:::back
“pole 在 left half-plane 等价于 stable”来自 [EE2023 第 5 站](../courses/EE2023.html#pz)。临界 gain 和 oscillation frequency 在[第 5 站](#rlocus)是 root locus 穿过 imaginary axis 的点，在[第 6 站](#nyquist)是 Nyquist plot 穿过 negative real axis 的点，三种方法给出同一组数。
:::

:::from
Coefficient 同号的必要条件、array 的构造与 sign change 的规则、$s^3+2s^2+3s+8$ 的例子、用 $\varepsilon$ 代替 0、“整行为 0 意味着 imaginary axis 上有一对 root”，来自 [16.06 第 8 讲](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/resources/mit16_06f12_lecture_8/)；那一讲求 gain 范围的例子是 $1/(s+1)^3$（$-1<K<8$），整行为 0 的处理只说“见教材”，auxiliary polynomial 的做法是标准做法，按我自己的知识写。Third order 由 $s=j\omega$ 推出 $a_1a_2>a_3$、motor 和 $\varepsilon$ 的两个例子是为这一页算的。

## [sse] Steady-state error 与 system type

:::skip
能由 loop transfer function 数出 integrator 的个数并直接写出 step、ramp 的 steady-state error，能算出 disturbance 造成的 error，并知道 final value theorem 什么时候不能用，就可以去第 5 站。
:::

### Error 由 $S$ 在 $s=0$ 附近的样子决定

Unity feedback、不计 $d$ 和 $n$ 时，$e=r-y=(1-T)\,r=S\,r$：

$$E(s)=\frac{R(s)}{1+L(s)}$$

Steady-state error 用 final value theorem（[EE2023 第 4 站](../courses/EE2023.html#laplace)）：

$$e_{ss}=\lim_{t\to\infty}e(t)=\lim_{s\to0}s\,E(s)$$

这个 theorem 有前提：$sE(s)$ 的 pole 全在 left half-plane，也就是 closed loop 必须 stable。这是这一站排在 Routh 之后的原因。

**Step input**，$R=1/s$：

$$e_{ss}=\lim_{s\to0}\frac{1}{1+L(s)}=\frac{1}{1+L(0)}$$

第 1 站的 speed loop，$L(0)=50\times0.5=25$，$e_{ss}=\tfrac1{26}=3.8\%$，正是那里 output 只有 0.962 的原因。$L(0)$ 有限，error 就不为 0，gain 越大越小。

### System type：数 integrator

如果 $L(s)$ 在 $s=0$ 有 pole，$L(0)=\infty$，step 的 error 就是 0。把 $L(s)$ 写成 $\dfrac{L_0(s)}{s^N}$，$L_0(0)$ 有限且不为 0，$N$ 叫 system type，就是 loop 里 integrator 的个数。

**Ramp input** $r=t$，$R=1/s^2$：

$$e_{ss}=\lim_{s\to0}\frac{1}{s\,(1+L(s))}=\lim_{s\to0}\frac{1}{s+sL(s)}$$

Type 0 时 $sL(s)\to0$，error 是 $\infty$；type 1 时 $sL(s)\to L_0(0)$，error 是 $1/L_0(0)$；type 2 时 $sL(s)\to\infty$，error 是 0。对 parabola $r=t^2/2$ 做同样的事，要再多乘一个 $s$。把三个极限起了名字：

$$K_p=\lim_{s\to0}L(s),\qquad K_v=\lim_{s\to0}sL(s),\qquad K_a=\lim_{s\to0}s^2L(s)$$

| | step | ramp | parabola |
|---|---|---|---|
| Type 0 | $\dfrac{1}{1+K_p}$ | $\infty$ | $\infty$ |
| Type 1 | 0 | $\dfrac{1}{K_v}$ | $\infty$ |
| Type 2 | 0 | 0 | $\dfrac{1}{K_a}$ |

Position loop 天生是 type 1：$G(s)$ 里的 $\dfrac1s$ 来自 position 是 speed 的 integral。P control 时

$$K_v=\lim_{s\to0}s\cdot\frac{20K}{s(s+2)(s+20)}=\frac{20K}{40}=\frac K2$$

第 5 站会算出，让 dominant pole 的 $\zeta=0.5$ 的 gain 是 $K=3.34$，此时 $K_v=1.67$：reference 以 1 rad/s 匀速转动时，motor 落后 $1/1.67=0.60$ rad。这一页给 motor 的第三条要求是 $K_v\ge10$（落后不超过 0.1 rad），P control 要 $K\ge20$。而 $K=20$ 时 overshoot 是 68%、settling time 7.5 s。Transient 要 gain 小，steady state 要 gain 大，一个 gain 两头顾不上。第 7 站的 lag compensator 就是为这个矛盾准备的。

### Disturbance：要看 integrator 在 disturbance 的哪一边

第 1 站推过，$d$ 到 $y$ 的 transfer function 是 $\dfrac{G}{1+CG}$。Load torque 是 constant，取 $d=1/s$，P control：

$$y_{ss}=\lim_{s\to0}s\cdot\frac{G}{1+KG}\cdot\frac1s=\lim_{s\to0}\frac{1}{1/G+K}=\frac1K$$

最后一步用了 $G(0)=\infty$，即 $1/G(0)=0$。$K=3.34$ 时 position 偏 0.30 rad，而且永远不回来。

:::wrong Position loop 是 type 1，所以 step 的 steady-state error 一定是 0
对 reference 的 step 是这样，对 disturbance 的 step 不是：刚才算出偏 0.30 rad。区别在 integrator 的位置。Reference 的 error 要经过 controller 和 plant 里的 integrator 才到 output，任何 constant 的 $e$ 都会让 $y$ 无限增长，所以 steady state 时 $e$ 只能是 0。Disturbance 加在 plant input 处，要抵消一个 constant 的 $d$，controller 的 output 必须是一个 constant 的 $u=-d$；P controller 的 output 要是 constant，只能靠 constant 的 error，$e=-u/K=d/K$。Plant 里的 integrator 在 disturbance 下游，帮不上忙。要消掉它，integrator 必须放在 controller 里，即 disturbance 的上游（第 8 站）。
:::

:::edge Final value theorem 不检查 stability
真实 plant 取 $K=50$，套公式得 step error $=\dfrac{1}{1+\infty}=0$。可这个 closed loop 是 unstable 的（第 3 站），$e(t)$ 是一个越来越大的 oscillation，根本没有 final value。先用 Routh 确认 stable，再用 final value theorem。
:::

:::back
Final value theorem 见 [EE2023 第 4 站](../courses/EE2023.html#laplace)；它的前提要用[第 3 站](#routh)检查。$e=Sr$ 和 disturbance 的 transfer function 来自[第 1 站](#feedback)。
:::

:::from
$E=R/(1+L)$、type 的定义、$K_p$、$K_v$、$K_a$ 的表，以及例子 $L=10/(s+2)$（$e_{ss}=1/6$）和 $L=4/(s(s+1))$（$K_v=4$），来自 [16.06 第 9 讲](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/resources/mit16_06f12_lecture_9/)；这里换成 motor 重算。Disturbance 的那一段（integrator 在 disturbance 哪一边）和 final value theorem 误用的例子是为这一页写的；“PI control 让 constant disturbance 的 steady-state output 为 0”在 [Åström 与 Murray 第 2 章](http://www.cds.caltech.edu/~murray/books/AM08/pdf/fbs-principles_24Jul2020.pdf)里有，用在第 8 站。
:::

## [rlocus] Root locus

:::skip
能从 $1+KL=0$ 推出 angle condition 和 magnitude condition，能对 $L=\dfrac{20}{s(s+2)(s+20)}$ 画出 real-axis segment、asymptote、breakaway point、imaginary axis crossing，并在上面找出 $\zeta=0.5$ 对应的 $K$，就可以去第 6 站。
:::

### 一个 knob，pole 往哪里走

第 2 站的简化 model 可以把 pole 写成 $K$ 的 explicit function：$-1\pm\sqrt{1-K}$，于是整条路线一目了然。真实 plant 的 characteristic equation 是 cubic，每个 $K$ 都要解一次，没有 formula，第 3 站也只回答了“哪些 $K$ stable”。设计时想知道的更多：$K$ 变化时 pole 整体往哪里走，能不能走到想要的位置；如果走不到，加一个 zero 或 pole 能不能改变路线。Root locus 就是把所有 $K>0$ 时的 closed-loop pole 画在一张图上，而且要不解 equation 就能画出它的形状。

### 两个 condition

把 loop transfer function 写成 $KL(s)$，$K$ 是要调的 gain，$L(s)=\dfrac{n(s)}{d(s)}$ 的 zero 是 $z_i$、pole 是 $p_i$。Closed-loop pole 满足

$$1+KL(s)=0\quad\Longleftrightarrow\quad L(s)=-\frac1K$$

$-1/K$ 是一个负的 real number。一个 complex number 等于它，要求 angle 是 $180^\circ$、magnitude 是 $1/K$：

$$\angle L(s)=\sum\angle(s-z_i)-\sum\angle(s-p_i)=180^\circ+k\cdot360^\circ,\qquad K=\frac{1}{\lvert L(s)\rvert}$$

第一条（angle condition）决定哪些点在 locus 上，和 $K$ 无关；第二条（magnitude condition）给出那个点对应的 $K$。$\angle(s-p_i)$ 就是从 pole $p_i$ 指向 $s$ 的 vector 的 angle，可以在图上直接量。

拿 motor 试两个点。$L=\dfrac{20}{s(s+2)(s+20)}$，没有 zero。

**$s=-1+j$。** 三个 pole 指向它的 vector 的 angle：从 0 是 $135^\circ$，从 $-2$ 是 $45^\circ$，从 $-20$ 是 $\arctan\tfrac1{19}=3.0^\circ$。$\angle L=-(135+45+3.0)=-183.0^\circ$，不是 $-180^\circ$，这个点不在 locus 上，但离得不远。

**$\zeta=0.5$ 那条 ray 上的 $s=-0.909+j1.575$。** Angle 是 $120.0^\circ$、$55.3^\circ$、$4.7^\circ$，合计 $180.0^\circ$，在 locus 上。$\lvert s\rvert=1.818$，$\lvert s+2\rvert=1.916$，$\lvert s+20\rvert=19.16$，所以

$$K=\frac{1}{\lvert L(s)\rvert}=\frac{1.818\times1.916\times19.16}{20}=3.34$$

这就是第 4 站用过的 $K=3.34$。Closed-loop 的第三个 pole 是 $-20.18$。

### 规则：每一条都从这两个 condition 来

**起点和终点。** $1+KL=0$ 写成 $d(s)+K\,n(s)=0$。$K\to0$ 时它变成 $d(s)=0$：locus 从 open-loop pole 出发。$K\to\infty$ 时除以 $K$ 得 $n(s)=0$：locus 终止于 zero。$n$ 个 pole、$m$ 个 zero，就有 $n$ 个 branch，$m$ 个终止于 zero，其余 $n-m$ 个跑到无穷远。

**Real axis 上哪些段属于 locus。** 在 real axis 上的一个点 $s$，一对 complex 的 pole（或 zero）贡献的 angle 一正一负，相互抵消；它左边的 real pole、zero 贡献 $0^\circ$；它右边的每个贡献 $180^\circ$。所以 angle condition 成立，当且仅当这个点右边的 real pole 与 zero 一共有奇数个。

**Asymptote。** $s$ 很大时，$L(s)\approx\dfrac{1}{s^{n-m}}$，equation 变成 $s^{n-m}\approx-K$。$-K$ 的 $n-m$ 个 root 均匀分布，angle 是

$$\theta_l=\frac{180^\circ+360^\circ\,l}{n-m},\qquad l=0,1,\dots,n-m-1$$

这些 asymptote 从 real axis 上同一个点出发。这个点（centroid）可以这样找：$n-m\ge2$ 时，加上 $K\,n(s)$ 不改变 $d(s)$ 里 $s^{n-1}$ 的 coefficient，而这个 coefficient 是所有 root 之和的相反数，所以 closed-loop pole 之和永远等于 open-loop pole 之和。$K\to\infty$ 时 $m$ 个 pole 到了 zero，剩下 $n-m$ 个对称地分布在 asymptote 上，它们的平均就是 centroid：

$$\sigma_a=\frac{\sum p_i-\sum z_i}{n-m}$$

**Breakaway point。** 两个 branch 在 real axis 上相遇再分开的地方，是 $K$ 作为 $s$ 的 function 的 stationary point。由 $K=-\dfrac{d(s)}{n(s)}$，令

$$\frac{dK}{ds}=0$$

**Imaginary axis crossing。** 用第 3 站的 Routh array 求临界 $K$ 和 $\omega$。

### 对 motor 画出来

$L=\dfrac{20}{s(s+2)(s+20)}$：$n=3$，$m=0$，三个 branch 都跑到无穷远。

- Real axis：$[-2,0]$ 右边有一个 pole（0），属于 locus；$(-20,-2)$ 右边有两个，不属于；$(-\infty,-20]$ 右边有三个，属于。
- Asymptote：$\theta=60^\circ,180^\circ,300^\circ$；centroid $\sigma_a=\dfrac{0-2-20}{3}=-7.33$。
- Breakaway：$K=-\dfrac{s^3+22s^2+40s}{20}$，$\dfrac{dK}{ds}=-\dfrac{3s^2+44s+40}{20}=0$，

$$s=\frac{-44\pm\sqrt{44^2-480}}{6}=\frac{-44\pm38.16}{6}=-0.974\ \text{或}\ -13.69$$

  $-13.69$ 不在 locus 的 real-axis segment 上（对应 $K=-50.5<0$），舍去。$-0.974$ 处 $K=0.951$：从 0 和 $-2$ 出发的两个 branch 在这里相遇，然后离开 real axis。
- Imaginary axis：第 3 站已算出 $K=44$、$s=\pm j6.32$。

核对 centroid 的那条性质：$K=44$ 时三个 pole 是 $-22$、$\pm j6.32$，和是 $-22$，等于 $0-2-20$。

::fig[ee3331c-rlocus] 实算的 root locus。彩色圆点是三个 closed-loop pole，随左上角的 $K$ 从 0 加到 60 沿 locus 走。两个 branch 在 $-0.97$ 相遇后上下分开，起初几乎竖直（像简化 model 那样贴着 $\mathrm{Re}\,s\approx-1$），随后向 $60^\circ$ 的 asymptote 弯过去，在 $K=44$ 时穿过 imaginary axis。空心圆是 $\zeta=0.5$ 的点。

:::wrong $K$ 越大，closed-loop pole 越往左，response 越快
图里那两个 dominant 的 branch，离开 real axis 之后一路往右弯。实际的 real part：$K=4$ 时 $-0.891$，$K=10$ 时 $-0.737$，$K=40$ 时 $-0.077$，$K=50$ 时 $+0.112$。Gain 越大 decay 越慢，最后 unstable。这是 $n-m=3$ 的 asymptote 指向右半边的直接后果：只要 pole 比 zero 多两个以上，high gain 必然把某些 branch 拉向 imaginary axis 甚至越过它。
:::

:::edge Complex pole 的 departure angle
Open-loop pole 是 complex 的时候，branch 离开它的方向也由 angle condition 决定。在这个 pole 旁边取一个极近的点 $s$，其余 pole 和 zero 指向 $s$ 的 angle 和指向这个 pole 的几乎一样，只有它自己指向 $s$ 的 angle $\phi$ 未知，所以

$$\phi_{\text{dep}}=180^\circ+\sum\psi_i-\sum_{\text{其余 pole}}\phi_i$$

例子：$L=\dfrac{1}{s(s^2+2s+2)}$，pole 在 $0$、$-1\pm j$。在 $-1+j$：从 0 来的 vector angle 是 $135^\circ$，从 $-1-j$ 来的是 $90^\circ$，于是 $\phi_{\text{dep}}=180^\circ-135^\circ-90^\circ=-45^\circ$，branch 朝右下方离开。数值核对：$K=0.001$ 时这个 root 是 $-0.99975+j0.99975$，相对 $-1+j$ 移动了 $(+0.00025,-0.00025)$，正是 $-45^\circ$。
:::

### 用它选 gain，以及它告诉我们 P control 的 limitation

Specification 要求 $\zeta\ge0.4$、real part 在 $-2$ 左边。整条 locus 在 $\zeta$ 合格的部分，real part 都在 $-1$ 附近；离开 real axis 以后 real part 只会更靠右。所以没有任何 $K$ 能满足 settling time，这和第 2 站对简化 model 的结论一样，只是现在对真实 plant 也成立了。

要把 locus 往左拉，得改变 angle condition：在某个位置加一个 zero，它对左上方的点贡献正的 angle，抵消一部分 pole 的 angle，原本 angle 不够 $180^\circ$ 的点就可能落到 locus 上。第 7 站沿着这个思路设计 lead compensator，到时 angle condition 和 magnitude condition 就是设计的计算本身。

Imaginary axis crossing 用[第 3 站](#routh)的 Routh array。$\zeta$ 与 pole 的 angle 的关系来自[第 2 站](#tresp)。
:::

## [nyquist] Frequency response、Nyquist criterion 与 stability margin

:::skip
能画出 motor 的 Nyquist plot（包括 origin 处 pole 的 indentation）、用 $Z=N+P$ 数出 unstable pole，能从 Bode plot 读出 gain margin、phase margin 并换算成 delay margin，能说出 phase margin 和 overshoot 的数量关系，就可以去第 7 站。
:::

### 为什么还需要另一种 stability test

Routh 和 root locus 都要一个 polynomial。两种情况下没有它。

- **Plant 只有测量数据。** 给 motor 加不同 frequency 的 sinusoid、记下 output 的 amplitude 和 phase，得到的是一张 frequency response 的表，没有 transfer function。
- **Loop 里有 time delay。** Sensor 或计算带来 $\tau$ 秒的 delay，transfer function 里多出 $e^{-s\tau}$，characteristic equation 不再是 polynomial，Routh 用不了。

另外，Routh 只回答 stable 或不 stable。设计时更想知道离 unstable 还有多远：plant 的 gain 再偏多少、delay 再大多少就会出事。Frequency response 能回答这几个问题。Bode plot 怎么画见 [EE2023 第 6 站](../courses/EE2023.html#bode)。

### 断开 loop，送一个 sinusoid

设想把 loop 在 controller 前面断开，从断口送进 $\sin\omega_0t$，绕 loop 一圈回到断口时，信号被乘上 $L(j\omega_0)$，再经过 feedback 的减号，成了 $-L(j\omega_0)$ 倍。如果 $L(j\omega_0)=-1$，回来的信号和送进去的完全一样；这时把断口接上，不需要任何 input，这个 sinusoid 也能自己维持下去。这就是 marginal stability。$-1$ 叫 critical point。

用 motor 核对。$L(j\omega)=\dfrac{20K}{j\omega(j\omega+2)(j\omega+20)}$，把 denominator 乘开：

$$j\omega\,(j\omega+2)(j\omega+20)=j\omega\,(40-\omega^2+j22\omega)=-22\omega^2+j\,(40\omega-\omega^3)$$

$\omega^2=40$ 时 imaginary part 为 0，denominator 是 $-880$，所以 $L(j6.32)=-\dfrac{20K}{880}=-\dfrac{K}{44}$。$K=44$ 时恰好是 $-1$，和 Routh 给出的临界 gain、oscillation frequency 完全一致。

由此容易猜一个规则：在 phase 为 $-180^\circ$ 的 frequency 上，$\lvert L\rvert<1$ 就 stable，$>1$ 就 unstable。前一半在 open loop stable、phase 只穿过 $-180^\circ$ 一次时成立，后一半一般不成立。

:::wrong 在 phase 为 $-180^\circ$ 的 frequency 上 $\lvert L\rvert>1$，closed loop 就一定 unstable
Åström 与 Murray 的例子：$L=\dfrac{3k(s+6)^2}{s(s+1)^2}$，取 $k=1$。实算 phase 在 $\omega=2$ 和 $\omega=3$ 两次穿过 $-180^\circ$，那里 $L$ 分别是 $-12.0$ 和 $-4.5$，magnitude 都远大于 1。可 closed-loop polynomial $s(s+1)^2+3(s+6)^2=s^3+5s^2+37s+108$ 满足 $5\times37=185>108$，是 stable 的（root 是 $-3.42$、$-0.79\pm j5.56$）。用 Routh 对一般的 $k$ 做：polynomial 是 $s^3+(2+3k)s^2+(1+36k)s+108k$，条件 $(2+3k)(1+36k)>108k$ 化成 $108k^2-33k+2>0$，root 是 $k=\tfrac1{12}$ 和 $\tfrac29$。所以 $k<\tfrac1{12}$ 或 $k>\tfrac29$ stable，中间 unstable：gain 增大反而让它恢复 stable。这样的 system 叫 conditionally stable。只看一个 frequency 的 magnitude 判断不了，需要数 encirclement。
:::

### Argument principle

取一个 rational function $F(s)$ 和 s-plane 里一条 clockwise 的闭合 curve $\Gamma$。让 $s$ 沿 $\Gamma$ 走一圈，看 $F(s)$ 的 angle 怎样变化。$\angle F(s)=\sum\angle(s-z_i)-\sum\angle(s-p_i)$，每一项是从一个 zero 或 pole 指向 $s$ 的 vector 的 angle。

- 在 $\Gamma$ 外面的 zero 或 pole：$s$ 绕一圈，vector 左右摆动后回到原位，angle 净变化 0。
- 在 $\Gamma$ 里面的：$s$ 绕着它 clockwise 转一整圈，vector 的 angle 净变化 $-360^\circ$。

所以 $\angle F$ 的净变化是 $-360^\circ\times(Z-P)$，$Z$、$P$ 是 $\Gamma$ 内 zero、pole 的个数。$F(\Gamma)$ 这条 curve 每 clockwise 绕 origin 一圈，angle 就减少 $360^\circ$：

$$N=F(\Gamma)\ \text{clockwise 包围 origin 的圈数}=Z-P$$

现在选 $F=1+L$，$\Gamma$ 取包住整个 right half-plane 的 D 形 contour（沿 imaginary axis 从 $-j\infty$ 到 $+j\infty$，再沿 radius 无穷大的 semicircle clockwise 回来）。

- $1+L$ 的 zero 是 closed-loop pole，$Z$ 就是 right half-plane 里 closed-loop pole 的个数，要它为 0。
- $1+L=1+\dfrac{n_L}{d_L}=\dfrac{d_L+n_L}{d_L}$ 的 pole 就是 $L$ 的 pole，$P$ 是 right half-plane 里 open-loop pole 的个数，已知。
- $1+L$ 包围 origin，等于 $L$ 包围 $-1$。

于是 Nyquist criterion：

$$Z=N+P$$

$N$ 是 $L(\Gamma)$ clockwise 包围 $-1$ 的圈数（counter-clockwise 算负）。Open loop stable（$P=0$）时，closed loop stable 当且仅当 Nyquist plot 不包围 $-1$。

$\Gamma$ 不能经过 $L$ 的 pole。$L$ 在 imaginary axis 上有 pole 时（motor 在 origin 有一个），contour 在那里绕一个 radius $\varepsilon\to0$ 的小 semicircle，从右边绕过去，把这个 pole 留在 contour 外面，所以它不计入 $P$。

### 对 motor 画出来

分四段走 $\Gamma$。

**$\omega$ 从 $0^+$ 到 $\infty$。** 用上面乘开的 denominator，记 $D=(22\omega^2)^2+(40\omega-\omega^3)^2$：

$$\mathrm{Re}\,L=\frac{-440K\omega^2}{D},\qquad\mathrm{Im}\,L=\frac{-20K(40\omega-\omega^3)}{D}$$

$\omega\to0$ 时 $D\approx1600\omega^2$，real part 趋于 $-\dfrac{440K}{1600}=-0.275K$，imaginary part 趋于 $-\infty$：curve 从下方无穷远处、沿着 $\mathrm{Re}=-0.275K$ 这条竖线进来。$\omega<\sqrt{40}$ 时 imaginary part 为负，在 $\omega=\sqrt{40}$ 穿过 negative real axis，crossing 是 $-K/44$；之后 imaginary part 变正，$\omega\to\infty$ 时 $L\approx\dfrac{20K}{(j\omega)^3}$，从上方以 $-270^\circ$ 的方向趋于 0。

**$\omega$ 从 $-\infty$ 到 $0^-$。** $L(-j\omega)$ 是 $L(j\omega)$ 的 complex conjugate，curve 关于 real axis 的 mirror image。

**大 semicircle。** $\lvert s\rvert\to\infty$ 时 $L\to0$，整段映到 origin。

**Origin 处的小 semicircle。** $s=\varepsilon e^{j\theta}$，$\theta$ 从 $-90^\circ$ 到 $+90^\circ$。这里 $L\approx\dfrac{K/2}{s}=\dfrac{K}{2\varepsilon}e^{-j\theta}$：magnitude 无穷大，angle 从 $+90^\circ$ 经过 $0^\circ$ 到 $-90^\circ$，是右半边一个无穷大的 semicircle，clockwise，把 $\omega=0^-$ 的上端和 $\omega=0^+$ 的下端接起来。

::fig[ee3331c-nyquist] 两个 gain 下的 Nyquist plot，只画了有限的部分。$K=20$ 时 curve 在 $-0.45$ 穿过 negative real axis，$-1$ 在 curve 外面；$K=60$ 时 crossing $-1.36$ 越过了 $-1$，curve 绕着 $-1$ 走了两圈。

数圈数的办法：从 $-1$ 出发向左画一条 ray，看 curve 从哪个方向穿过它。在 $-1$ 的左边，从下往上穿过就是绕 $-1$ clockwise 走，从上往下就是 counter-clockwise。$K=20$：curve 只在 $-0.45$ 穿过 negative real axis，在 $-1$ 的右边，左边的 ray 一次也没被穿过，$N=0$；又 $P=0$，所以 $Z=0$，stable。$K=60$：crossing $-1.36$ 在 $-1$ 的左边，实线（$\omega$ 增大时 imaginary part 由负变正）从下往上穿过一次，虚线（mirror image 按 $\omega$ 从 $-\infty$ 到 $0^-$ 的方向走，imaginary part 同样由负变正）又从下往上穿过一次，$N=2$，$Z=2$：两个 closed-loop pole 在 right half-plane，和第 3 站 Routh 在 $K>44$ 时数出的两次 sign change 一致。

:::edge Open loop 本身 unstable 时，必须 counter-clockwise 包围
Åström 与 Murray 的 inverted pendulum：$P(s)=\dfrac{1}{s^2-1}$，$C=k(s+2)$。Open-loop pole 在 $+1$，$P=1$。要 $Z=0$，就要 $N=-1$：Nyquist plot 必须 counter-clockwise 包围 $-1$ 一圈。书里的 plot 在 $k>0.5$ 时做到了。用 Routh 核对：closed-loop polynomial $s^2-1+k(s+2)=s^2+ks+(2k-1)$，second order 只要 coefficient 全正，即 $k>0.5$。取 $k=0.4$，root 是 $0.29$ 和 $-0.69$，unstable；$k=1$，root 是 $-0.5\pm j0.87$，stable。这种情况下“不包围 $-1$”反而说明 unstable，只看 margin 的习惯做法会给出错误的结论。
:::

### Stability margin：离 $-1$ 有多远

Open loop stable、Nyquist plot 只穿过 negative real axis 一次时，closed loop 是否 stable 只取决于这个 crossing 在 $-1$ 的哪一边，而 curve 离 $-1$ 的远近就是 robustness 的量度。两个最常用的量：

- **Gain margin（GM）。** Phase 为 $-180^\circ$ 的 frequency $\omega_{pc}$ 上，$\mathrm{GM}=\dfrac{1}{\lvert L(j\omega_{pc})\rvert}$。Loop gain 再乘上这个倍数就到 $-1$。
- **Phase margin（PM）。** $\lvert L\rvert=1$ 的 frequency $\omega_c$（crossover frequency）上，$\mathrm{PM}=180^\circ+\angle L(j\omega_c)$。Loop 再多这么多 phase lag 就到 $-1$。

在 Bode plot 上，GM 在 phase curve 穿过 $-180^\circ$ 的地方读 magnitude，PM 在 magnitude curve 穿过 0 dB 的地方读 phase。

Motor 的 P control：

| $K$ | $\omega_c$（rad/s） | PM | $\omega_{pc}$ | GM |
|---|---|---|---|---|
| 3.34 | 1.37 | $51.6^\circ$ | 6.32 | 13.2 |
| 20 | 4.20 | $13.6^\circ$ | 6.32 | 2.2 |

GM 也可以直接由前面的 crossing 得到：$\dfrac{1}{K/44}=\dfrac{44}{K}$，$K=20$ 时是 2.2，正是 Routh 说的“$K$ 再大 2.2 倍就 unstable”。

**Delay margin。** $e^{-j\omega\tau}$ 的 magnitude 是 1、phase 是 $-\omega\tau$，所以 delay 不改变 $\lvert L\rvert$，只在 crossover 处吃掉 $\omega_c\tau$ 的 phase。吃完 PM 就到 $-1$，能容忍的最大 delay 是

$$\tau_{\max}=\frac{\mathrm{PM}\ (\text{rad})}{\omega_c}$$

$K=3.34$ 时 $\tau_{\max}=\dfrac{51.6\times\pi/180}{1.37}=0.66$ s。第 7 站的 design 把 $\omega_c$ 提到 3.7 到 5 rad/s，PM 差不多，delay margin 就缩到 0.17 到 0.22 s：loop 越快，越怕 delay。

### Phase margin 为什么能预告 overshoot

把简化 model 的 P control 一般地写成

$$L(s)=\frac{\omega_n^2}{s\,(s+2\zeta\omega_n)},\qquad T(s)=\frac{\omega_n^2}{s^2+2\zeta\omega_ns+\omega_n^2}$$

Closed loop 正好是标准的 second order，所以 $\zeta$ 同时决定 overshoot 和 PM。先求 crossover：$\lvert L(j\omega)\rvert=1$ 即

$$\omega^2\,(\omega^2+4\zeta^2\omega_n^2)=\omega_n^4\quad\Longrightarrow\quad\Big(\frac{\omega_c}{\omega_n}\Big)^2=\sqrt{1+4\zeta^4}-2\zeta^2$$

（把 $x=(\omega/\omega_n)^2$ 代入得 $x^2+4\zeta^2x-1=0$，取正 root。）$\angle L=-90^\circ-\arctan\dfrac{\omega}{2\zeta\omega_n}$，所以

$$\mathrm{PM}=90^\circ-\arctan\frac{\omega_c}{2\zeta\omega_n}=\arctan\frac{2\zeta\omega_n}{\omega_c}=\arctan\frac{2\zeta}{\sqrt{\sqrt{1+4\zeta^4}-2\zeta^2}}$$

PM 只是 $\zeta$ 的 function。逐个算出来：

| $\zeta$ | 0.2 | 0.3 | 0.4 | 0.45 | 0.5 | 0.6 | 0.7 |
|---|---|---|---|---|---|---|---|
| PM | $22.6^\circ$ | $33.3^\circ$ | $43.1^\circ$ | $47.6^\circ$ | $51.8^\circ$ | $59.2^\circ$ | $65.2^\circ$ |
| $M_p$ | 52.7% | 37.2% | 25.4% | 20.5% | 16.3% | 9.5% | 4.6% |

到 $\zeta=0.6$ 为止，PM 差不多是 $100\zeta$ 度，这就是常用的 rule of thumb $\zeta\approx\mathrm{PM}/100$。把两行连起来，PM 直接对应 overshoot：要 overshoot 不超过 25%，PM 大约要 $43^\circ$ 以上。

这个推导只对这一种 loop 成立。真实 plant 是 third-order 的，加了 controller 还有 zero。可 overshoot 主要由 Nyquist plot 在 crossover 附近离 $-1$ 有多远决定，这和 loop 的阶数关系不大。把这一页所有 design 的实算结果点上去：

::fig[ee3331c-pm] 左图：second-order loop 的 PM 与 $\zeta$，虚线是 $\mathrm{PM}=100\zeta$。右图：curve 是上表的 second-order 的关系，黑点是真实 motor 上六个 design 实算的 (PM, overshoot)，都落在 curve 附近。

例如 $K=20$ 的 PM 是 $13.6^\circ$，按 curve 对应 $\zeta=0.12$、overshoot 69%，实测 68%。这是第 7 站可以把 overshoot 要求换成 PM 要求、在 Bode plot 上做设计的根据。

:::back
Bode plot 的画法见 [EE2023 第 6 站](../courses/EE2023.html#bode)。临界 gain 和 frequency 与[第 3 站](#routh)的 Routh、[第 5 站](#rlocus)的 imaginary axis crossing 是同一组数。
:::

:::from
“Bode 只能给出充分条件，反过来不成立”、motor 式的 $1/(s(s+1)^2)$ 在 $k=2$ 临界、argument principle 里每个 pole 和 zero 的 angle 怎样随 contour 变化、“clockwise encirclement $=Z-P$”，来自 [16.06 第 20 讲](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/resources/mit16_06f12_lecture_20/)；这一讲的 PDF 停在 $Z=N+P$ 之前，最后一步按 Åström 与 Murray 补全。GM、PM 的定义、second-order loop 的 PM formula 和 $\zeta\approx\mathrm{PM}/100$ 来自 [16.06 第 23 讲](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/resources/mit16_06f12_lecture_23/)，那一讲没有给 PM 与 overshoot 的数表。“断开 loop 送 sinusoid”的引入、critical point、inverted pendulum 与 conditionally stable 两个例子来自 [Åström 与 Murray 第 10 章](http://www.cds.caltech.edu/~murray/books/AM08/pdf/fbs-loopanal_24Jul2020.pdf)，两个例子的 Routh 核对是我做的。Motor 的 Nyquist plot、margin、delay margin、两张数表和右图的实算点是为这一页算的。

## [comp] Lead 与 lag compensation

:::skip
能在 root locus 上用 angle deficiency 把 lead 的 zero 和 pole 定下来、用 magnitude condition 定 gain，能在 Bode plot 上按 phase margin 设计 lead，能说出 lag 为什么几乎不改变 transient，并能说出“先定 $K$ 再补 phase”为什么常补不够，就可以去第 8 站。
:::

### 要求和差距

Motor 的三条要求：overshoot $\le25\%$，settling time（2%）$\le2$ s，$K_v\ge10$。P control 的两个极端：

| | $M_p$ | $t_s$（s） | $K_v$ |
|---|---|---|---|
| $K=3.34$ | 16.2% ✓ | 4.49 ✗ | 1.67 ✗ |
| $K=20$ | 68.2% ✗ | 7.46 ✗ | 10 ✓ |

缺的是两样不同的东西。Transient 要求 dominant pole 往左移，第 5 站说过这要改变 angle condition，需要一个 zero。Steady state 要求 $K_v=\lim sL$ 变大，也就是低 frequency 的 loop gain 变大，而不动 crossover 附近。两样各用一种 compensator：

$$C(s)=K_c\frac{s+z}{s+p}:\qquad z<p\ \text{叫 lead},\qquad z>p\ \text{叫 lag}$$

Lead 的 zero 离 origin 更近，在 upper half-plane 的点上 zero 贡献的 angle 大于 pole 的，净 angle 为正，phase 是“超前”的。Lag 反过来。

### Root locus 上设计 lead

**第一步：选目标 pole。** Overshoot $\le25\%$ 要 $\zeta\ge0.4$；第 2 站说过 controller 的 zero 会让 overshoot 高出 formula，所以目标取 $\zeta=0.5$ 留出余量。Settling time 要 real part $\le-2$，取 $\omega_n=5$，real part $-2.5$，$t_s\approx4/2.5=1.6$ s。目标是

$$s^*=-2.5+j4.33$$

**第二步：算 angle deficiency。** Plant 的三个 pole 指向 $s^*$ 的 vector：

$$\angle s^*=120.0^\circ,\qquad\angle(s^*+2)=\arctan\frac{4.33}{-0.5}=96.6^\circ,\qquad\angle(s^*+20)=\arctan\frac{4.33}{17.5}=13.9^\circ$$

$\angle G(s^*)=-(120.0+96.6+13.9)=-230.5^\circ$，离 $-180^\circ$ 差 $50.5^\circ$。Lead 要在 $s^*$ 处补上 $+50.5^\circ$：zero 的 angle 减 pole 的 angle 等于 $50.5^\circ$。

**第三步：放 zero 和 pole。** 一个 condition，两个 unknown，要再选一个。常用做法是把 zero 放在 $s^*$ 正下方，$z=2.5$，它贡献 $90^\circ$；pole 就要贡献 $90^\circ-50.5^\circ=39.5^\circ$：

$$\tan39.5^\circ=\frac{4.33}{p-2.5}\quad\Longrightarrow\quad p=2.5+\frac{4.33}{0.825}=7.75$$

::fig[ee3331c-angle] 在 $s^*$ 上数 angle。Zero 的 $90^\circ$ 减去四个 pole 的 angle，正好 $-180^\circ$，$s^*$ 落到了新的 root locus 上。

**第四步：magnitude condition 定 gain。** Loop 是 $K_c\dfrac{s+2.5}{s+7.75}\cdot\dfrac{20}{s(s+2)(s+20)}$，在 $s^*$ 处 magnitude 要为 1。各段长度：$\lvert s^*\rvert=5.00$，$\lvert s^*+2\rvert=4.36$，$\lvert s^*+20\rvert=18.03$，$\lvert s^*+7.75\rvert=6.81$，$\lvert s^*+2.5\rvert=4.33$。

$$K_c=\frac{5.00\times4.36\times18.03\times6.81}{20\times4.33}=30.9$$

**第五步：核对。** Closed-loop pole 是 $-2.5\pm j4.33$（正是目标）、$-2.82$、$-21.9$。Simulation：overshoot 20.8%，settling time 1.66 s。前两条满足。第三个 pole $-2.82$ 离 zero $-2.5$ 很近，两者的作用大部分抵消，否则 overshoot 会更高。

$K_v$ 呢？

$$K_v=\lim_{s\to0}s\cdot30.9\frac{s+2.5}{s+7.75}\cdot\frac{20}{s(s+2)(s+20)}=30.9\times\frac{2.5}{7.75}\times\frac{20}{40}=4.98$$

不够 10。Lead 的 DC gain $z/p<1$，它在改善 transient 的同时把低频 gain 拉低了。

Zero 也可以不放在正下方。同一个 $s^*$，换几个位置：

| $z$ | 需要的 $p$ | $K_c$ | $M_p$ | $K_v$ |
|---|---|---|---|---|
| 2（抵消 plant 的 pole） | 6.67 | 27.1 | 15.8% | 4.06 |
| 2.5（正下方） | 7.75 | 30.9 | 20.8% | 4.98 |
| 3 | 9.19 | 35.9 | 24.4% | 5.86 |

Zero 越往左，需要的 pole 越远、$K_v$ 越高，但 closed loop 的第三个 pole 和 zero 离得越开，抵消越不完全，overshoot 越高。

### 加 lag：只抬低频 gain

$K_v$ 要从 4.98 提到 10 以上，要乘一个至少 2.01 倍的 DC gain，又不能动 $s^*$ 附近的 locus。Lag

$$\frac{s+z_l}{s+p_l},\qquad\frac{z_l}{p_l}=\beta>1$$

DC 时等于 $\beta$；在离 origin 远的 $s^*$ 处，$s+z_l$ 和 $s+p_l$ 几乎是同一个 vector，比值接近 1、angle 接近 0。只要 $z_l$、$p_l$ 比 $s^*$ 的 real part 小得多。取 $\beta=2.5$，$z_l=0.1$，$p_l=0.04$：

$$\angle\frac{s^*+0.1}{s^*+0.04}=-0.60^\circ,\qquad\left\lvert\frac{s^*+0.1}{s^*+0.04}\right\rvert=0.994$$

Locus 在 $s^*$ 附近几乎不动，dominant pole 从 $-2.5\pm j4.33$ 变成 $-2.47\pm j4.30$。$K_v=4.98\times2.5=12.45$。

代价是 origin 附近多出一个 closed-loop pole，在 $-0.101$，紧挨着 lag 的 zero $-0.1$。两者几乎抵消，所以它在 step response 里的 residue 很小，但它的 time constant 是 10 s，留下一条又小又慢的尾巴。Lag 放得太靠右，尾巴就超出 2% 的 band：

| Lag | $M_p$ | $t_s$（s） | $K_v$ |
|---|---|---|---|
| 没有 | 20.8% | 1.66 | 4.98 |
| $(s+0.1)/(s+0.04)$ | 22.6% | 1.24 | 12.45 |
| $(s+0.2)/(s+0.08)$ | 24.4% | 2.39 | 12.45 |
| $(s+0.25)/(s+0.1)$ | 25.2% | 2.49 | 12.45 |

第一种 lag-lead 三条要求都满足。（$t_s$ 比没有 lag 时还短，是因为 overshoot 后的那次回落刚好没有跌出 2% band，这种比较对 band 的边界很敏感。）

### Bode plot 上设计 lead

第 6 站的结论让 overshoot 的要求可以换成 PM 的要求：overshoot $\le25\%$ 大约要 PM $\ge43^\circ$，后面加 lag 还会再吃掉一两度，目标定为 PM $=50^\circ$。在 Bode plot 上设计，需要知道 lead 在每个 frequency 提供多少 phase。

把 lead 写成 $C(s)=K_c\dfrac{s+z}{s+p}$，$\alpha=z/p<1$。它的 phase 是

$$\phi(\omega)=\arctan\frac\omega z-\arctan\frac\omega p$$

用 $\tan(a-b)=\dfrac{\tan a-\tan b}{1+\tan a\tan b}$：

$$\tan\phi=\frac{\omega/z-\omega/p}{1+\omega^2/(zp)}=\frac{\omega\,(p-z)}{zp+\omega^2}$$

对 $\omega$ 求 derivative 令其为 0：$(p-z)(zp+\omega^2)-\omega(p-z)\cdot2\omega=0$，得 $\omega^2=zp$。所以 phase 最大的地方在 zero 和 pole 的 geometric mean，log 轴上正中间：

$$\omega_m=\sqrt{zp},\qquad\tan\phi_{\max}=\frac{\sqrt{zp}\,(p-z)}{2zp}=\frac{p-z}{2\sqrt{zp}}$$

由 $\tan$ 换成 $\sin$：$\sin\phi=\dfrac{\tan\phi}{\sqrt{1+\tan^2\phi}}$，而 $1+\dfrac{(p-z)^2}{4zp}=\dfrac{(p+z)^2}{4zp}$，所以

$$\sin\phi_{\max}=\frac{p-z}{p+z}=\frac{1-\alpha}{1+\alpha}$$

在 $\omega_m$ 处 lead 的 magnitude：$\lvert j\omega_m+z\rvert^2=zp+z^2=z(p+z)$，$\lvert j\omega_m+p\rvert^2=p(z+p)$，所以 $\lvert C(j\omega_m)\rvert=K_c\sqrt{z/p}=K_c\sqrt\alpha$。

**第一步：选 crossover。** Crossover 越高 response 越快，但 plant 的 phase 越低，要补的越多。取 $\omega_c=5$ rad/s。Plant 在这里：

$$\angle G(j5)=-90^\circ-\arctan\frac52-\arctan\frac5{20}=-90-68.2-14.0=-172.2^\circ,\qquad\lvert G(j5)\rvert=\frac{20}{5\sqrt{29}\sqrt{425}}=0.0360$$

**第二步：需要的 phase。** PM $=50^\circ$ 要求 loop 的 phase 是 $-130^\circ$，lead 要在 5 rad/s 提供 $172.2-130=42.2^\circ$。

**第三步：$\alpha$、zero、pole。** $\dfrac{1-\alpha}{1+\alpha}=\sin42.2^\circ=0.672$，得 $\alpha=0.196$。让 $\omega_m$ 正好落在 $\omega_c$：$z=\omega_c\sqrt\alpha=5\times0.443=2.21$，$p=\omega_c/\sqrt\alpha=11.29$。

**第四步：gain。** 要 $\lvert C(j5)G(j5)\rvert=1$：$K_c\times0.443\times0.0360=1$，$K_c=62.7$。

结果：$C(s)=62.7\dfrac{s+2.21}{s+11.29}$，PM 正好 $50.0^\circ$，GM 5.5。Simulation：overshoot 18.6%，settling time 1.16 s。$K_v=62.7\times\dfrac{2.21}{11.29}\times\dfrac12=6.15$，不够。和 root locus 的做法一样，再乘一个 lag：$\beta\ge10/6.15=1.63$，取 $\dfrac{s+0.1}{s+0.05}$，$\beta=2$，$K_v=12.3$。它在 5 rad/s 处只吃掉 $0.6^\circ$，PM 变成 $49.4^\circ$，overshoot 19.7%，settling time 0.88 s。

::fig[ee3331c-bode] P control（$K=20$）和 lead-lag 的 loop。两者低 frequency 的 gain 接近（$K_v$ 分别是 10 和 12.3），lead 把 crossover 附近的 phase 抬起来，PM 从 $13.6^\circ$ 变成 $49.4^\circ$。

:::wrong 先按 $K_v$ 定好 $K$，再让 lead 补上“目标 PM 减去现有 PM”就行
这是很多教材的标准步骤，但要知道它为什么常常补不够。$K_v=10$ 要 $K=20$，此时 PM $=13.6^\circ$，crossover 在 4.20 rad/s。目标 $45^\circ$，加 $5^\circ$ 余量，lead 要提供 $\phi_{\max}=45-13.6+5=36.4^\circ$，$\alpha=0.255$。Lead 在 $\omega_m$ 处会把 magnitude 抬高 $1/\sqrt\alpha$ 倍，所以把 $\omega_m$ 放在原 loop magnitude 等于 $\sqrt\alpha$ 的地方，即 6.00 rad/s，那里正好成为新的 crossover。实际得到的 PM 只有 $38.2^\circ$。原因是 crossover 从 4.20 移到了 6.00，plant 在这两点的 phase 分别是 $-166.4^\circ$ 和 $-178.3^\circ$，多掉了 $11.9^\circ$，比预留的 $5^\circ$ 多得多。Plant 的 phase 在 crossover 附近掉得越快（这里有 $-20$ 那个 pole），这种做法越要反复加大余量，每加一次 crossover 又往右移一点。先选 crossover、在那里算 plant 的 phase，就没有这个问题，代价是 $K_v$ 要事后用 lag 补。
:::

### 两种方法的结果

全部在真实 third-order plant 上实算：

|---|---|---|---|---|---|---|
| P，$K=3.34$ | 16.2% | 4.49 | 1.67 | $51.6^\circ$ | 1.37 | 0.66 |
| P，$K=20$ | 68.2% | 7.46 | 10 | $13.6^\circ$ | 4.20 | 0.06 |
| Root locus lead | 20.8% | 1.66 | 4.98 | $48.0^\circ$ | 3.74 | 0.22 |
| Root locus lead-lag | 22.6% | 1.24 | 12.45 | $47.1^\circ$ | 3.74 | 0.22 |
| Bode lead | 18.6% | 1.16 | 6.15 | $50.0^\circ$ | 5.00 | 0.17 |
| Bode lead-lag | 19.7% | 0.88 | 12.3 | $49.4^\circ$ | 5.00 | 0.17 |

::fig[ee3331c-designs] 真实 plant 上三个 design 的 step response。两个 lead-lag 都在 2 s 内进入 ±2% band，overshoot 在 25% 以内。

两种方法最后得到的 controller 相似：zero 都在 2.2 到 2.5，pole 在 7.75 到 11.3，再加一个靠近 origin 的 lag。差别在于 root locus 的做法直接控制 closed-loop pole，Bode 的做法直接控制 PM 和 crossover。

:::edge 更快的 design 要付出什么
Bode lead-lag 比 root locus 的快，因为 crossover 更高（5 对 3.74）。代价有三。其一，delay margin 更小（0.17 s 对 0.22 s）。其二，controller 在高 frequency 的 gain 是 $K_c$（$s\to\infty$ 时 $\frac{s+z}{s+p}\to1$），62.7 对 30.9，sensor noise 被放大的倍数多了一倍，这是第 1 站 $S+T=1$ 的具体表现。其三，crossover 越接近被忽略的 dynamics，model 不准的后果越大：如果在简化 model 上设计同样的 $\omega_n=8$ 的 lead（zero 2、pole 8、$K_c=64$），简化 model 上 overshoot 16%，放到真实 plant 上变成 35%，因为 8 rad/s 处那个 $-20$ 的 pole 已经贡献了 $-22^\circ$。
:::

## [pid] PID control

:::skip
能说出 P、I、D 各补哪个缺口，能用 pole placement 定三个 gain，能解释为什么 derivative 和 proportional 常常作用在 output 而不是 error 上，并知道 Ziegler–Nichols 对这个 motor 为什么不好用，这门课就读完了。
:::

### 三个 term 各补一个缺口

$$u(t)=K_p\,e(t)+K_i\int_0^te(\tau)\,d\tau+K_d\,\frac{de}{dt},\qquad C(s)=K_p+\frac{K_i}{s}+K_ds$$

**P 的缺口。** 第 4 站：load torque 是 constant 时，P control 的 position 偏 $1/K$，lead-lag 也只能把它缩小到 $1/(K_c\cdot z/p\cdot\beta)$。第 7 站的 root locus lead-lag 在 DC 的 gain 是 $30.9\times\frac{2.5}{7.75}\times2.5=24.9$，偏 0.040 rad。只要 controller 的 DC gain 有限，就消不掉。

**I 为什么能消掉。** 不需要知道 plant 是什么。假设 closed loop 最终进入 steady state，$u$ 和 $e$ 都趋于 constant。如果 $e$ 的 limit $e_0\ne0$，$\int e$ 会像 $e_0t$ 一样无限增长，$u$ 就不可能是 constant。所以只要有 steady state，$e_0$ 必须是 0。这个论证没有用到 plant 的任何性质，plant 是 nonlinear 的、parameter 漂移的都成立。用第 4 站的话说，integrator 放进了 controller，就在 disturbance 的上游了。

**D 的作用。** $K_pe+K_d\dot e=K_p\big(e+T_d\dot e\big)$，$T_d=K_d/K_p$，括号里是 error 按当前 slope 外推 $T_d$ 秒后的值。Controller 根据“快要发生的 error”提前动作，效果是 damping。第 1 站的 tachometer 就是 derivative 作用在 output 上：$k_t\omega=k_t\dot\theta$。

### 只加 I 为什么不行

只用 $C=K_i/s$，closed-loop polynomial 是

$$s\cdot s(s+2)(s+20)+20K_i=s^4+22s^3+40s^2+0\cdot s+20K_i$$

$s$ 的 coefficient 是 0，第 3 站的必要条件就不满足：任何 $K_i$ 都 unstable（$K_i=1$ 时有一对 root 在 $0.112\pm j0.661$）。在 frequency domain 看，integrator 在所有 frequency 上贡献 $-90^\circ$，plant 本来就有一个 integrator，phase 从 $-180^\circ$ 起步往下掉，PM 一开始就是负的。Integral action 必须和让 phase 回升的东西（P 和 D）一起用。

### 三个 gain 摆三个 pole

在简化 model $\dfrac{1}{s(s+2)}$ 上，PID 的 closed-loop polynomial 是

$$s\cdot s(s+2)+K_ds^2+K_ps+K_i=s^3+(2+K_d)s^2+K_ps+K_i$$

三个 gain 恰好对应三个 coefficient，可以把三个 pole 放在任何位置。目标：一对 $\zeta=0.7$、$\omega_n=4$ 的 dominant pole，第三个 pole 在 $-4$：

$$(s^2+5.6s+16)(s+4)=s^3+9.6s^2+38.4s+64$$

对 coefficient：$K_d=7.6$，$K_p=38.4$，$K_i=64$。

放到真实 plant 上，polynomial 变成 fourth order：$s^4+22s^3+(40+20K_d)s^2+20K_ps+20K_i=s^4+22s^3+192s^2+768s+1280$。第 3 站已经对它列过 Routh array，stable。Root 是 $-3.79\pm j2.50$ 和 $-7.21\pm j3.17$，和设计的 $-2.8\pm j2.86$、$-4$ 差得不少：简化 model 丢掉的 $-20$ 又起了作用，而三个 gain 没有办法摆四个 pole。PM $46.0^\circ$，crossover 7.47 rad/s。

Reference 的 step response 却令人失望：

| | 简化 model | 真实 plant |
|---|---|---|
| PID 全部作用在 error 上 | 21.1% | 34.3% |

Closed-loop pole 的 $\zeta$ 不小，overshoot 却超过 30%。原因在第 2 站：$T(s)=\dfrac{20(K_ds^2+K_ps+K_i)}{\cdots}$，numerator 是 PID 自己的两个 zero，$7.6s^2+38.4s+64=0$ 的 root 是 $-2.53\pm j1.43$，比 dominant pole 还靠近 origin。

### 换一个 structure：让 reference 不经过 zero

Zero 来自 reference 经过了 $K_ds+K_p$。Disturbance 和 stability 只由 loop 决定，和 reference 从哪里进来无关，所以可以只让 integral term 看 error，P 和 D 只作用在 output 上：

$$u=K_i\int(r-y)\,dt-K_p\,y-K_d\,\dot y$$

这叫 I-PD structure。Loop 还是同一个，closed-loop pole 不变，disturbance 的 response 不变；从 $r$ 到 $y$ 的 transfer function 变成 $\dfrac{20K_i}{\cdots}$，没有 zero 了。

| Structure | Reference 经过的部分 | 真实 plant 上的 $M_p$ | $t_s$（s） |
|---|---|---|---|
| PID | $K_p+K_i/s+K_ds$ | 34.3% | 1.37 |
| PI-D（只有 D 在 output 上） | $K_p+K_i/s$ | 39.5% | 1.47 |
| I-PD | $K_i/s$ | 0.6% | 1.20 |

PI-D 反而更糟：留下的 zero $-K_i/K_p=-1.67$ 离 origin 更近了。

::fig[ee3331c-ipd] 三条 curve 的 closed-loop pole 完全相同，差别只来自 numerator 里的 zero。

::fig[ee3331c-dist] Plant input 上一个 unit step 的 load disturbance。P control 最后停在 0.30 rad，lead-lag 小一些但停在 0.040（图里还在慢慢下降），PID 在 0.5 s 时达到 0.023 的峰值，0.93 s 后回到 0.01 以内，最后是 0。

:::edge I-PD 的代价：ramp 跟不紧
I-PD 的 loop 是 type 2（plant 一个 integrator，controller 一个），可 reference 绕开了 $K_p$ 和 $K_d$，ramp 的 error 并不是 0。$E=R-Y$，$1-T=\dfrac{\text{polynomial}-20K_i}{\text{polynomial}}=\dfrac{s^4+22s^3+192s^2+768s}{s^4+22s^3+192s^2+768s+1280}$，ramp 时 $e_{ss}=\lim\limits_{s\to0}\dfrac{1}{s}(1-T)=\dfrac{768}{1280}=0.6$（就是 $K_p/K_i$）。全部作用在 error 上的 PID，$1-T$ 的 numerator 是 $s^4+22s^3+40s^2$，ramp error 为 0。Step 要漂亮还是 ramp 要跟紧，取决于 reference 是什么样的；Åström 与 Murray 把这推广成 setpoint weighting，让 P 和 D 只看 reference 的一部分。
:::

### PID 和 lead-lag 是同一类东西

PD 是 $K_p+K_ds=K_p\big(1+\tfrac{s}{K_p/K_d}\big)$，一个 zero 在 $-K_p/K_d$、没有 pole。Lead $K_c\dfrac{s+z}{s+p}=\dfrac{K_cz}{p}\cdot\dfrac{1+s/z}{1+s/p}$，让 $p\to\infty$ 就是 PD。反过来，lead 就是 high frequency gain 被限制住的 PD。

PI 是 $K_p+\dfrac{K_i}{s}=K_p\dfrac{s+K_i/K_p}{s}$，一个 zero 加一个在 origin 的 pole。Lag $\dfrac{s+z_l}{s+p_l}$ 让 $p_l\to0$ 就是 PI，DC gain 从 $\beta$ 变成无穷大，于是 steady-state error 从“缩小 $\beta$ 倍”变成“消失”。

所以 ideal derivative 实际上不会被直接实现：$K_ds$ 的 magnitude 随 frequency 无限增长，sensor noise 会被无限放大。实际用的是 filtered derivative $\dfrac{K_ds}{T_fs+1}$，$T_f=T_d/N$，$N$ 一般取 5 到 20，也就是把 PD 变回 lead。上面的 I-PD 取 $N=10$（$T_f=0.0198$ s），真实 plant 上 overshoot 0.9%、settling time 1.26 s，和 ideal 的几乎一样。

:::wrong Ziegler–Nichols 给出的 gain 拿来就能用
Ziegler–Nichols 的 frequency response 方法：只用 P control，加大 gain 直到 loop 恰好持续 oscillate，记下这时的 gain $K_{cu}$ 和 period $T_{cu}$，再查表。对 motor，第 3 站已经算出 $K_{cu}=44$、$T_{cu}=2\pi/6.32=0.993$ s。查表并实算：

| | 表给的 gain | 真实 plant 上的结果 |
|---|---|---|
| P | $K_p=0.5K_{cu}=22$ | overshoot 71% |
| PI | $K_p=0.4K_{cu}=17.6$，$T_i=0.8T_{cu}=0.79$ s | unstable（pole 在 $0.082\pm j4.01$） |
| PID | $K_p=0.6K_{cu}=26.4$，$T_i=0.5T_{cu}=0.50$ s，$T_d=0.125T_{cu}=0.124$ s | overshoot 64% |

这些规则是为 type 0、response 迟缓的 process（温度、液位）凑出来的，只用了 process 的两个数，目标本来就是 quarter-decay 那样很激进的 response。Motor 自带一个 integrator，PI 再加一个，phase 掉得太多，直接 unstable。Åström 与 Murray 也指出，原始规则给出的 loop 的 robustness 普遍偏差。它适合在没有 model 时给出起点，不是答案。
:::

:::edge Actuator saturation 与 integrator windup
Motor 的 voltage 有上限。大的 reference step 让 $u$ 撞到上限后，loop 实际上断开了：output 不再随 $u$ 变化，可 error 还在，integrator 继续累积。等 output 终于追上 reference、error 变号，integrator 里存的大数要很久才放完，$u$ 一直贴着上限，造成很大的 overshoot。治法（anti-windup）是把“controller 想要的 $u$”和“实际送出去的、经过 saturation 的 $u$”之差，乘一个 gain $k_{aw}$ feed back 到 integrator 的 input：saturation 时这个差不为 0，它把 integrator 往回拉，让 controller 的 output 停在上限附近，不再无限累积。Åström 与 Murray 的 cruise control 例子里，$k_{aw}$ 取到 $K_i$ 的十倍左右效果就很好。
:::

Integrator 要放在 disturbance 上游的理由来自[第 4 站](#sse)；只加 I 不行用的是[第 3 站](#routh)的必要条件；zero 让 overshoot 增大来自[第 2 站](#tresp)；PD 和 PI 分别是[第 7 站](#comp)的 lead 与 lag 的极限。
:::
