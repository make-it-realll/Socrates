## [proj] Projective geometry：P² 与 P³

:::skip
能用 cross product 求 vanishing point 和 vanishing line，能由一张斜拍的 plane 先做 affine、再做 metric rectification，并说出两步各自用了什么信息，就可以去第 2 站。
:::

### Line 也是一个 3-vector

[CS4243 第 3 站](CS4243.html#camera)用 homogeneous coordinates 表示点：$(x,y)$ 写成 $(x,y,1)$，并且 $(kx,ky,k)$ 代表同一个点。Line $ax+by+c=0$ 同样只由比例决定，写成 $l=(a,b,c)^\top$。点 $x$ 在 line $l$ 上，就是

$$l^\top x=ax+by+c=0$$

这个式子对 $x$ 和 $l$ 是对称的。过两个点 $x$、$y$ 的 line 要同时满足 $l^\top x=0$、$l^\top y=0$，也就是 $l$ 和两个 vector 都 perpendicular，所以 $l=x\times y$。同理两条 line 的 intersection 是 $x=l\times m$。

用在两条 parallel 的 line 上：$x=1$ 是 $(1,0,-1)$，$x=2$ 是 $(1,0,-2)$，

$$\begin{pmatrix}1\\0\\-1\end{pmatrix}\times\begin{pmatrix}1\\0\\-2\end{pmatrix}=\begin{pmatrix}0\cdot(-2)-(-1)\cdot0\\(-1)\cdot1-1\cdot(-2)\\1\cdot0-0\cdot1\end{pmatrix}=\begin{pmatrix}0\\1\\0\end{pmatrix}$$

得到一个第三个 coordinate 为 0 的点。它不对应任何 $(x,y)$，代表 $y$ 方向的无穷远处，叫 point at infinity（ideal point）。所有 parallel line 都交于同一个 ideal point，所有 ideal point $(x_1,x_2,0)$ 都满足 $(0,0,1)\,x=0$，在同一条 line $l_\infty=(0,0,1)^\top$ 上，叫 line at infinity。加上这些点之后的 plane 叫 projective plane $\mathbb P^2$：任意两条 line 恰好交于一点，没有例外。

现在可以求图里的交点。Image 里 $X=0$ 那条 tile 边经过 pixel $(127.8,298.5)$ 和 $(108.1,78.9)$，$X=1$ 那条经过 $(326.6,275.0)$ 和 $(201.0,81.9)$。各做一次 cross product 得到两条 line，再做一次：

$$l_0=(219.57,\,-19.69,\,-22186.5),\quad l_1=(193.14,\,-125.57,\,-28536.6),\quad l_0\times l_1\sim(93.57,\,-83.33,\,1)$$

这就是图里那个 vanishing point：world 里 $Z$ 方向的 ideal point 在 image 里的位置。

### Homography 把 line at infinity 送到哪里

[CS4243 第 4 站](CS4243.html#homography)说过，一个 plane 被拍成 image，plane 上的点和 pixel 之间差一个 3×3 的 homography $x'=Hx$。图里这块地面（用 $(X,Z,1)$ 作 coordinate）的 $H$ 由 camera 算出来是

$$H=\begin{pmatrix}774.09&97.93&199.47\\61.71&-87.21&1097.60\\0.488&1.0465&1\end{pmatrix}$$

Point 怎么变已经知道了，line 怎么变？$l^\top x=0$ 中间插一个 $H^{-1}H$：

$$l^\top x=l^\top H^{-1}(Hx)=(H^{-\top}l)^\top x'=0$$

所以 $l'=H^{-\top}l$。把 $l_\infty=(0,0,1)^\top$ 代进去，得到地面的 line at infinity 在 image 里的位置，叫 vanishing line：

$$l'_\infty=H^{-\top}(0,0,1)^\top\sim(-0.00146,\ 0.01036,\ 1)^\top$$

它应该经过两个 vanishing point。$X$ 方向那个是 $H$ 的第一个 column，$(774.09,61.71,0.488)\sim(1586.26,126.45,1)$；代入 $-0.00146\times1586.26+0.01036\times126.45+1$，不取整时恰好是 0。$Z$ 方向的 $(93.57,-83.33,1)$ 同样。实际做的时候顺序反过来：在 image 里找两组 parallel 的边，交出两个 vanishing point，连成 $l'_\infty$。

### 每一级 transformation 保留什么

Homography 有 8 个 degree of freedom（9 个 entry 减去 scale）。把它限制得越来越严，就得到一串越来越小的 group：

| transformation | matrix 的形状 | degree of freedom | 保留的 invariant |
|---|---|---|---|
| Euclidean | $\begin{pmatrix}R&t\\0^\top&1\end{pmatrix}$ | 3 | length、area |
| similarity | $\begin{pmatrix}sR&t\\0^\top&1\end{pmatrix}$ | 4 | angle、length 之比 |
| affine | $\begin{pmatrix}A&t\\0^\top&1\end{pmatrix}$ | 6 | parallel、同一方向上 length 之比、area 之比 |
| projective | $\begin{pmatrix}A&t\\v^\top&b\end{pmatrix}$ | 8 | collinear、incidence、cross ratio |

下面一级保留上面各级的 invariant 中的一部分。区分 affine 和 projective 的是最后一个 row：affine 的最后一个 row 是 $(0,0,1)$，它把 ideal point $(x_1,x_2,0)$ 仍然送到第三个 coordinate 为 0 的点。所以“affine transformation 保持 parallel”和“affine transformation 把 $l_\infty$ 送回 $l_\infty$”是同一件事。

Projective transformation 下 length 之比不保留，但四个 collinear 点的 cross ratio 保留：

$$\mathrm{Cr}(A,B,C,D)=\frac{|AC|\,|BD|}{|BC|\,|AD|}$$

拿图里 $X=1$ 那条边上 $Z=2,3,4,5$ 的四个角检验。World 里 $|AC|=2$、$|BD|=2$、$|BC|=1$、$|AD|=3$，cross ratio 是 $\tfrac43$。Image 里相邻两点的距离是 96.67、61.01、42.01 pixel，length 之比完全变了；但 $|AC|=157.67$、$|BD|=103.02$、$|AD|=199.68$，

$$\frac{157.67\times103.02}{61.01\times199.68}=1.3333$$

### Affine rectification：把 vanishing line 送回无穷远

既然 affine 就是“$l_\infty$ 不动”，那么只要找一个 $H_A$ 把 $l'_\infty=(l_1,l_2,l_3)$ 送回 $(0,0,1)$，照片就只剩 affine 的 distortion。取

$$H_A=\begin{pmatrix}1&0&0\\0&1&0\\l_1&l_2&l_3\end{pmatrix}$$

检验：line 按 $H_A^{-\top}$ 变换，而 $H_A^\top(0,0,1)^\top=(l_1,l_2,l_3)^\top$，所以 $H_A^{-\top}l'_\infty=(0,0,1)^\top$。把它乘在 $H$ 前面：

$$H_AH\sim\begin{pmatrix}64.05&8.10&16.51\\5.11&-7.22&90.82\\0&0&1\end{pmatrix}$$

最后一个 row 成了 $(0,0,1)$，地面到新 image 之间是 affine 的。

::fig[cs4277-rectify] 同一块地面的三步。中间那一步只用了 vanishing line；右边那一步又用了两对 perpendicular 的 line。

:::wrong Parallel 恢复了，形状也就对了
中间那张图里每组 parallel 的边都 parallel 了，但 tile 不是 square。上面 $H_AH$ 的左上角 2×2 把 $X$ 方向的一格送到 $(64.05,5.11)$，把 $Z$ 方向的一格送到 $(8.10,-7.22)$，两者的 angle 是 $46.2°$，length 之比是 $1:5.9$。Affine 有 6 个 degree of freedom，similarity 有 4 个，多出的 2 个正好能把 square 压扁、拉斜，而 vanishing line 管不到它们。要恢复 angle，需要关于 angle 的信息。
:::

### Metric rectification：circular point 记住了 angle

Similarity 保留 angle，它在 $l_\infty$ 上应该也固定着什么。试 $I=(1,i,0)^\top$、$J=(1,-i,0)^\top$ 这两个 complex 的 ideal point。用 similarity 去乘 $I$：

$$\begin{pmatrix}s\cos\theta&-s\sin\theta&t_x\\s\sin\theta&s\cos\theta&t_y\\0&0&1\end{pmatrix}\begin{pmatrix}1\\i\\0\end{pmatrix}=s\begin{pmatrix}\cos\theta-i\sin\theta\\\sin\theta+i\cos\theta\\0\end{pmatrix}=s\,e^{-i\theta}\begin{pmatrix}1\\i\\0\end{pmatrix}$$

$I$ 被送回它自己（乘一个数不改变 homogeneous 的点），$J$ 同理。一般的 affine transformation 做不到这一点。这两个点叫 circular point。把它们合成一个 real 的对象：

$$C^*_\infty=IJ^\top+JI^\top=\begin{pmatrix}1&-i&0\\i&1&0\\0&0&0\end{pmatrix}+\begin{pmatrix}1&i&0\\-i&1&0\\0&0&0\end{pmatrix}=2\begin{pmatrix}1&0&0\\0&1&0\\0&0&0\end{pmatrix}$$

叫 dual conic of the circular points。两条 line $l$、$m$ 的 angle 本来是 $\cos\theta=\dfrac{l_1m_1+l_2m_2}{\sqrt{(l_1^2+l_2^2)(m_1^2+m_2^2)}}$，用它写就是

$$\cos\theta=\frac{l^\top C^*_\infty m}{\sqrt{(l^\top C^*_\infty l)(m^\top C^*_\infty m)}}$$

这个式子在 transformation 下是 invariant 的：line 变成 $H^{-\top}l$，dual conic 变成 $HC^*_\infty H^\top$，两者一起变时中间的 $H$ 全部消掉。所以只要知道 $C^*_\infty$ 在 image 里的样子 $C^{*\prime}_\infty$，就能在 image 里直接量 angle。特别地，perpendicular 就是

$$l'^\top C^{*\prime}_\infty\,m'=0$$

Affine rectification 之后 image 和地面差一个 affine 的 $\begin{pmatrix}A&t\\0^\top&1\end{pmatrix}$，代进 $HC^*_\infty H^\top$：

$$C^{*\prime}_\infty=\begin{pmatrix}A&t\\0^\top&1\end{pmatrix}\begin{pmatrix}I&0\\0^\top&0\end{pmatrix}\begin{pmatrix}A^\top&0\\t^\top&1\end{pmatrix}=\begin{pmatrix}AA^\top&0\\0^\top&0\end{pmatrix}$$

只剩 symmetric 的 $S=AA^\top=\begin{pmatrix}s_{11}&s_{12}\\s_{12}&s_{22}\end{pmatrix}$，3 个 entry，去掉 scale 是 2 个 unknown。每对 perpendicular 的 line 给一个 linear equation：

$$l_1m_1\,s_{11}+(l_1m_2+l_2m_1)\,s_{12}+l_2m_2\,s_{22}=0$$

两对就够。在中间那张图里取深色那格的两条边（它们在地面上 perpendicular）和它的两条 diagonal（square 的 diagonal 也 perpendicular），算出两条 equation：

$$\begin{aligned}-36.85\,s_{11}+420.85\,s_{12}+519.01\,s_{22}&=0\\-26.00\,s_{11}-771.04\,s_{12}+4037.05\,s_{22}&=0\end{aligned}$$

令 $s_{11}=1$，解得 $s_{12}=0.06443$、$s_{22}=0.01875$。代回第一式：$-36.85+27.11+9.73=-0.01$，四舍五入的误差。$S$ 的两个 eigenvalue 都是正的，做 Cholesky：

$$S=LL^\top,\qquad L=\begin{pmatrix}1&0\\0.06443&0.12081\end{pmatrix}$$

$AA^\top=LL^\top$ 说明 $L^{-1}A$ 是 orthogonal 的，所以用 $\begin{pmatrix}L^{-1}&0\\0^\top&1\end{pmatrix}$ 去乘中间那张图，剩下的只是 rotation 和 scale。结果是右边那张：angle $90.0°$，两边之比 $1:1$。

核对一下来源：$H_AH$ 左上角的 $A$ 算出来的 $AA^\top$，按 $s_{11}=1$ 归一化后正是 $\begin{pmatrix}1&0.06443\\0.06443&0.01875\end{pmatrix}$。

:::edge Camera 正对着 plane
Image plane 和地面 parallel 时，$H$ 的最后一个 row 本来就是 $(0,0,1)$，parallel 的边在 image 里仍然 parallel，没有有限远的 vanishing point，也就无从求 $l'_\infty$；这时 image 已经是 affine 的，直接做 metric 那一步。若 pixel 是 square 的、没有 skew，它甚至已经是 similarity。
:::

### 搬到三维：plane at infinity 与 absolute conic

$\mathbb P^3$ 里点是 $(X,Y,Z,W)$，plane 是 $\pi=(\pi_1,\pi_2,\pi_3,\pi_4)^\top$，点在 plane 上就是 $\pi^\top X=0$。$W=0$ 的点是三维的方向，它们都在 plane at infinity $\pi_\infty=(0,0,0,1)^\top$ 上。和二维一样，affine transformation（4×4，最后一个 row 是 $(0,0,0,1)$）就是保持 $\pi_\infty$ 不动的 transformation。

Circular point 的对应物是 $\pi_\infty$ 上的一个 conic，叫 absolute conic $\Omega_\infty$：满足 $W=0$ 且

$$X^2+Y^2+Z^2=0$$

的 complex 点。Euclidean transformation 把方向 $d$ 变成 $Rd$，$(Rd)^\top(Rd)=d^\top d$，所以 $\Omega_\infty$ 被送回它自己；scale 也不改变 $d^\top d=0$。所以 similarity 保持 $\Omega_\infty$，而保持它的 projective transformation 也只有 similarity。第 1 站在一张 plane 上做的“先找 $l_\infty$、再找 circular point”，在 space 里变成“先找 $\pi_\infty$、再找 $\Omega_\infty$”，这是第 3 站 stratification 的骨架。下一站先看 $\Omega_\infty$ 在一张 image 里是什么样子。

:::from
Transformation 的 hierarchy、line 的变换 $l'=H^{-\top}l$、vanishing line 是 $H^{-\top}l_\infty$、cross ratio 是 projective invariant、plane at infinity $\Pi_\infty=(0,0,0,1)$ 来自 [CS231A Course Notes 2](https://web.stanford.edu/class/cs231a/course_notes/02-single-view-metrology.pdf)（那份讲义把 cross ratio 的证明留作练习）。Affine rectification 用 $\begin{pmatrix}I&0\\l^\top\end{pmatrix}$、metric rectification 由 perpendicular line 的 constraint $l'^\top C^{*\prime}_\infty m'=0$ 对 $(a,b,c)$ 解 null vector、affine 之后 $C^{*\prime}_\infty$ 的右下部分为 0，来自 CMU 16-822 Assignment 1 的[一份学生报告](https://www.andrew.cmu.edu/course/16-822/projects/dprince/proj1)；16-822 自己的 L02、L03 slides 抓取被拒，没有读到。Circular point 在 similarity 下不动的计算、$C^*_\infty$ 与 angle 的公式、absolute conic 的定义是按 Hartley 和 Zisserman 的 *Multiple View Geometry* 第 2、3 章的结构凭自己的知识写的，没有对照原文。Tile 地面的 camera、$H$、全部数字是为这一页实际算的。
:::

:::

### $P$ 的每一部分都有几何意义

[CS4243 第 3 站](CS4243.html#camera)用 $P=K[R\,|\,t]$ 把 3D point 投到 pixel，也讲了怎样用 DLT 或 checkerboard 求 $P$。这里反过来问：手里只有一个 $P$，能读出什么？

拿上面拍地面的 camera 来读。它的 center 在 $C=(0,-1.5,0)$（这一页的 world coordinate 里 $Y$ 朝下，地面是 $Y=0$），

$$P=KR\,[\,I\mid -C\,]=\begin{pmatrix}580.57&99.74&73.44&149.60\\46.28&548.80&-65.41&823.20\\0.366&0.5&0.785&0.75\end{pmatrix}$$

**Center 是 null vector。** $P\begin{pmatrix}C\\1\end{pmatrix}=KR(C-C)=0$。Center 是唯一一个不被投到任何 pixel 的点，它的 ray 退化了。对上面的 $P$ 做 SVD，最小 singular value 对应的 right singular vector 归一化后正是 $(0,-1.5,0,1)$。写成 $P=[M\mid p_4]$，也可以直接算 $C=-M^{-1}p_4$。

**一个方向的 vanishing point 是 $M$ 乘它。** 方向 $d$ 是 point at infinity $(d,0)$，

$$P\begin{pmatrix}d\\0\end{pmatrix}=Md=KRd$$

所以 $M$ 的三个 column 就是 world 三个坐标轴方向的 vanishing point。第一个 column $(580.57,46.28,0.366)$ 归一化是 $(1586.26,126.45)$，和第 1 站用 cross product 交出来的一样。

**Principal axis 是 $M$ 的第三个 row。** $P$ 的第三个 row 是 depth，$M$ 的第三个 row $(0.366,0.5,0.785)$ 就是 $R$ 的第三个 row，即 camera 的 $z$ 轴在 world 里的方向（$\det M>0$ 时朝前）。它向下 30°：$\arcsin0.5=30°$。

**Pixel 的 ray 方向是 $M^{-1}x$。** 由 $x\sim Md$ 反解。

### 两条 ray 的 angle 只依赖 $K$

两个 pixel $x_1$、$x_2$ 对应的 ray 方向是 $d_k=R^\top K^{-1}x_k$。它们的 angle：

$$\cos\theta=\frac{d_1^\top d_2}{\|d_1\|\,\|d_2\|},\qquad d_1^\top d_2=x_1^\top K^{-\top}RR^\top K^{-1}x_2=x_1^\top(KK^\top)^{-1}x_2$$

$R$ 消掉了。记 $\omega=(KK^\top)^{-1}$，

$$\cos\theta=\frac{x_1^\top\omega\,x_2}{\sqrt{x_1^\top\omega\,x_1}\sqrt{x_2^\top\omega\,x_2}}$$

马上用一次。$f=500$、$c=(320,240)$ 时

$$f^2\omega=\begin{pmatrix}1&0&-320\\0&1&-240\\-320&-240&410000\end{pmatrix}$$

地上 $(0,0,2)$ 和 $(3,0,2)$ 两个角的 pixel 是 $(127.81,298.47)$ 和 $(596.35,243.21)$，代进去得 $\theta=50.19°$。直接用 world 里的两个 vector $(0,1.5,2)$、$(3,1.5,2)$ 算，也是 $50.19°$。

### $\omega$ 是 absolute conic 的 image

$\omega$ 为什么和 $R$、$C$ 无关，第 1 站末尾已经给了答案。Absolute conic 上的点是 $(d,0)$，$d^\top d=0$，它投到 $x=KRd$。反解 $d=R^\top K^{-1}x$ 代回：

$$d^\top d=x^\top K^{-\top}RR^\top K^{-1}x=x^\top\omega\,x=0$$

所以 absolute conic 在 image 里是 conic $\omega$，叫 image of the absolute conic（IAC）。$\Omega_\infty$ 在无穷远，camera 怎么移动、怎么转，它都只感受到 $K$。这就是“不需要 checkerboard 的 calibration”的来源：任何能告诉我们 $\omega$ 的东西都能给出 $K$，最后由 $\omega^{-1}=KK^\top$ 做 Cholesky 拿回 $K$。

最常用的信息是两个 perpendicular 的方向。$\cos\theta=0$ 就是

$$v_1^\top\omega\,v_2=0$$

每对 orthogonal 方向的 vanishing point 给 $\omega$ 一个 linear equation。

### 三个 vanishing point 求 $K$

地上放一个 1 m 的 box，它的 edge 有三个互相 orthogonal 的方向。

::fig[cs4277-vp3] 三组 parallel 的 edge 各自交出一个 vanishing point。$X$ 方向的在右边很远，竖直方向的在 image 下方很远。

$\omega$ 是 symmetric 的 3×3，去掉 scale 有 5 个 unknown，三对 orthogonal 只给 3 个 equation。再假设 skew 为 0、pixel 是 square 的（$f_x=f_y$），$K=\begin{pmatrix}f&0&c_x\\0&f&c_y\\0&0&1\end{pmatrix}$，算一下 $\omega$ 的形状：

$$K^{-1}=\frac1f\begin{pmatrix}1&0&-c_x\\0&1&-c_y\\0&0&f\end{pmatrix},\qquad f^2\omega=f^2K^{-\top}K^{-1}=\begin{pmatrix}1&0&-c_x\\0&1&-c_y\\-c_x&-c_y&f^2+c_x^2+c_y^2\end{pmatrix}$$

（上面 $f=500$ 的那个 $f^2\omega$ 正是这个形状。）所以 $\omega\sim\begin{pmatrix}w_1&0&w_2\\0&w_1&w_3\\w_2&w_3&w_4\end{pmatrix}$，4 个 unknown 去掉 scale 是 3 个，正好。$v^\top\omega u=0$ 展开：

$$(v_1u_1+v_2u_2)\,w_1+(v_1u_3+v_3u_1)\,w_2+(v_2u_3+v_3u_2)\,w_3+v_3u_3\,w_4=0$$

三个 vanishing point 是 $v_X=(1586.26,126.45,1)$、$v_Z=(93.57,-83.33,1)$、$v_Y=(199.47,1097.60,1)$。三对代进去：

$$\begin{pmatrix}137893.42&1679.83&43.11&1\\455204.87&1785.73&1224.05&1\\-72802.31&293.05&1014.26&1\end{pmatrix}\begin{pmatrix}w_1\\w_2\\w_3\\w_4\end{pmatrix}=0$$

取 null vector 并令 $w_1=1$：$w=(1,-320,-240,410000)$。和上面的形状对照，$c_x=-w_2=320$，$c_y=-w_3=240$，$f^2=w_4-c_x^2-c_y^2=410000-102400-57600=250000$，$f=500$。只用一张照片就把 $K$ 拿回来了。

### Principal point 是 orthocenter

把 $\omega$ 的形状代回 $v^\top\omega u$，按上面 $f^2\omega$ 的 entry 逐项乘开（$v$、$u$ 的第三个 coordinate 是 1）：

$$f^2\,v^\top\omega u=v_1u_1+v_2u_2-c_x(v_1+u_1)-c_y(v_2+u_2)+f^2+c_x^2+c_y^2=(v-c)\cdot(u-c)+f^2$$

所以 orthogonality 就是 $(v-c)\cdot(u-c)=-f^2$。三对都成立，拿 $(v_X,v_Z)$ 和 $(v_X,v_Y)$ 两式相减：

$$(v_X-c)\cdot(v_Z-v_Y)=0$$

$c$ 到 $v_X$ 的连线 perpendicular 于对边 $v_Zv_Y$，$c$ 在 $v_X$ 出发的 altitude 上。另外两条 altitude 同理。所以 principal point 是 vanishing point triangle 的 orthocenter，图里三条彩色虚线交于 $(320,240)$。

:::wrong 两个 orthogonal 的 vanishing point 就能求出 focal length
$(v_1-c)\cdot(v_2-c)=-f^2$ 只有一个 equation，unknown 有 $f$、$c_x$、$c_y$ 三个。$c$ 已知时它确实给出 $f$：用 $v_X$、$v_Z$ 和 $c=(320,240)$，$(1266.26)(-226.43)+(-113.55)(-323.33)=-250008$，$f=500.0$。但若 principal point 猜成 $(400,200)$，同一个式子给出 $f=585.4$；猜成 $(250,300)$，给出 $f=377.5$。凡是在以 $v_1v_2$ 为直径的 circle 里面的 $c$，都能给出一个看起来合理的 $f$。只有两个 vanishing point 时，必须另外知道 principal point（常见做法是假设它在 image center，这对裁剪过的照片不成立）。
:::

:::edge 有一个方向和 image plane parallel
若 camera 不 pitch，竖直的 edge 在 image 里仍然 parallel，$v_Y=(w,0)$ 在无穷远。这时 $v^\top\omega v_Y$ 展开只剩 $(v-c)\cdot w=0$。$v_X$、$v_Z$ 两式相减得 $(v_X-v_Z)\cdot w=0$，这是一个关于 data 的条件，不含 unknown，于是 independent 的 equation 只剩两个：$c$ 被限制在一条 line 上，$f$ 跟着 $c$ 变，求不出来。用 vanishing point 做 calibration 时，三个方向都要明显地 converge。
:::

:::from
$v=Kd$、由 vanishing point 拿回方向 $d=K^{-1}v/\|K^{-1}v\|$、用 $\omega$ 算 angle、$\omega$ 只依赖 $K$、zero skew 与 square pixel 下 $\omega$ 的形状（4 个 entry、去掉 scale 3 个 unknown）、三个 orthogonal vanishing point 再用 Cholesky 求 $K$，来自 [CS231A Course Notes 2](https://web.stanford.edu/class/cs231a/course_notes/02-single-view-metrology.pdf) 第 4 到第 7 节。那份讲义把 $v=Kd$ 写在 camera coordinate 里，这里带上了 $R$。由 $P$ 读 center、principal axis、ray 方向，$\omega$ 是 absolute conic 的 image 的推导，以及 orthocenter 的推导和“方向 parallel 于 image plane 时退化”的分析，是凭自己的知识写的（Hartley 和 Zisserman 第 6、8 章有对应内容，没有对照原文）。Box 的数字为这一页实际算过。
:::

## [twoview] Two-view geometry：projective ambiguity、stratification 与 generalized camera

:::skip
能由两个 camera 写出 $F$，由 $F$ 写出 canonical camera，说清 projective reconstruction 差一个 4×4 的 $H$，知道 affine 和 metric 两步各要补什么信息，并能写出 generalized epipolar constraint，就可以去第 4 站。
:::

[CS4243 第 6 站](CS4243.html#epipolar)推出了 $E=[t]_\times R$、$F=K^{-\top}EK^{-1}$、8-point algorithm 和由 $E$ 拆 $R$、$t$。那里 $K$ 都是已知的。这一站问：$K$ 不知道时，两张 image 到底能重建出什么？

### 从两个 camera 写出 $F$

设 $P$、$P'$ 是两个 camera，$P^+=P^\top(PP^\top)^{-1}$ 是 $P$ 的 pseudo-inverse，满足 $PP^+=I$。Image 1 里的 pixel $x$ 对应一条 ray，ray 上有两个已知的点：camera center $C$，以及 $P^+x$（因为 $P(P^+x)=x$）。这两个点在 image 2 里的位置是 $e'=P'C$（epipole）和 $P'P^+x$。Epipolar line 是过这两点的 line，第 1 站说过就是 cross product：

$$l'=e'\times(P'P^+x)=[e']_\times P'P^+\,x,\qquad F=[e']_\times P'P^+$$

拿第 1 站的 camera 当 camera 1，camera 2 向右平移 0.8 m 并多向左转 10°。算出 $e'=(2493.9,\ 254.0)$，在 image 右边很远；$F$ 的三个 singular value 之比是 $0.998:0.0629:0$，rank 是 2；box 的一个角 $x_1=(273.9,194.0)$、$x_2=(236.3,201.4)$ 代进去，$x_2^\top Fx_1=2.8\times10^{-14}$。

### 反过来，$F$ 只把 camera 定到一个 $H$ 为止

对任意可逆的 4×4 matrix $H$，

$$(PH^{-1})(HX)=PX$$

把所有 camera 右乘 $H^{-1}$、所有点左乘 $H$，每一个 pixel 都不变，所以 $F$ 也不变。只看 image，不可能区分这两套 camera 和点。$H$ 有 16 个 entry，去掉 scale 是 15 个 degree of freedom：uncalibrated 的 reconstruction 只能定到一个 projective transformation 为止。

既然如此，挑一对最简单的 camera。可以证明 $P=[I\mid0]$、$P'=[\,[e']_\times F\mid e'\,]$ 的 fundamental matrix 正是 $F$：$P$ 的 center 是 $(0,0,0,1)$，$P'$ 把它送到 $e'$；$P^+=\begin{pmatrix}I\\0^\top\end{pmatrix}$，$P'P^+=[e']_\times F$；于是这对 camera 的 fundamental matrix 是

$$[e']_\times[e']_\times F=(e'e'^\top-\|e'\|^2I)F=e'(e'^\top F)-\|e'\|^2F=-\|e'\|^2F$$

最后一步用了 $e'^\top F=0$（$e'$ 是 $F^\top$ 的 null vector）。差一个 scale，就是 $F$。这对 camera 叫 canonical camera。

用它们 triangulate box 的 8 个角，得到的 coordinate 是 $(4.575,3.241,0.0167)$、$(4.117,2.444,0.0171)$……重新投回两张 image，和原来的 pixel 差 $1.9\times10^{-10}$，完全吻合。但这些点画出来是这样的：

::fig[cs4277-projrecon] 同一组两张 image、同一组 pixel，三个阶段的 reconstruction。每个 panel 都换了视角和 scale，形状本身没有改。

:::wrong Reprojection error 是 0，reconstruction 就是对的
左边那个“cube”在两张 image 里的 reprojection error 是 $10^{-10}$ pixel，可它的四条 $X$ 方向的 edge 互相成 $9.6°$、$56.6°$、$81.4°$。它和真实的 cube 差一个 4×4 的 $H$，两者给出的 image 完全一样。Reprojection error 只能检验 reconstruction 和 image 是否一致，不能检验它是否 Euclidean。要得到真实的形状，必须从 image 以外补信息。
:::

### Stratification：先找 $\pi_\infty$，再找 $\Omega_\infty$

第 1 站在 plane 上分两步：先把 $l_\infty$ 放回原位，再用 circular point 恢复 angle。空间里同样分两步。

**Projective 到 affine：找 plane at infinity。** 真实空间里 $\pi_\infty=(0,0,0,1)$，在 projective 的 reconstruction 里它被搬到了某个 $\pi=(p^\top,1)$，3 个 unknown。三组本来 parallel 的 edge 在 reconstruction 里各自交于一点（方向的 point at infinity 被搬到了有限远），这三点确定 $\pi$。左图里三组 edge 交出的点是

$$(4.199,0.335,0.0027),\quad(2.618,14.404,0.0131),\quad(1.792,-1.596,0.0192)$$

令 $p^\top X+1=0$ 对三点都成立，解得 $\pi=(-0.218,\,-0.00076,\,-31.877,\,1)$。用

$$H_A=\begin{pmatrix}I&0\\p^\top&1\end{pmatrix}$$

去乘所有点：plane 按 $H_A^{-\top}$ 变换，$H_A^\top(0,0,0,1)^\top=(p,1)^\top=\pi$，所以 $\pi$ 被送回 $(0,0,0,1)$。中间那个 panel 的四条 $X$ 方向 edge 的 angle 都变成了 $0°$。但 $X$ edge 和 $Z$ edge 之间是 $46.2°$，$X$ 和 $Y$ 之间是 $75.1°$，三条 edge 的 length 是 5.27、5.04、0.889：affine 的 12 个 degree of freedom 里还剩 5 个（12 减去 similarity 的 7 个）没定。

**Affine 到 metric：找 absolute conic。** 剩下的 5 个正好是 $\omega$ 的 5 个 unknown，也就是 $K$。$K$ 已知时可以一步到位：取

$$H=\begin{pmatrix}K&0\\-p^\top K&1\end{pmatrix},\qquad X_{\text{metric}}=H^{-1}X_{\text{proj}}$$

检验两件事。Camera 1 变成 $[I\mid0]\,H=[K\mid0]$，正是一个 center 在原点、内参为 $K$ 的 calibrated camera；plane 按 $H^\top$ 变换，$H^\top\begin{pmatrix}p\\1\end{pmatrix}=\begin{pmatrix}K^\top p-K^\top p\\1\end{pmatrix}=\begin{pmatrix}0\\1\end{pmatrix}$，$\pi$ 被送回无穷远。右边 panel 三个 angle 都是 $90.0°$，三条 edge 等长（都是 0.00904，绝对 scale 仍然定不了）。

$K$ 不知道时，第 2 站的办法（orthogonal 方向的 vanishing point、square pixel、zero skew）在 reconstruction 里同样适用，这叫 self-calibration。

### 估计 $F$：用什么 error

8-point algorithm 最小化的是 $\sum(x_2^\top Fx_1)^2$，叫 algebraic error。它没有单位：$F$ 换一种归一化，同一个 correspondence 的值就变。真正想要的是 geometric error：把 $x_1$、$x_2$ 各挪一点，使它们 exactly 满足 constraint，挪动的总距离最小。这等价于对两个 view 做最优的 triangulation（第 4 站），每个点要解一个小优化。

Sampson error 是它的 first-order 近似。记 $\varepsilon=x_2^\top Fx_1$，它对四个 pixel coordinate $(u_1,v_1,u_2,v_2)$ 的 derivative 是

$$J=\big((F^\top x_2)_1,\ (F^\top x_2)_2,\ (Fx_1)_1,\ (Fx_1)_2\big)$$

要找最短的 correction $\delta$，使 $\varepsilon+J\delta=0$。一个 equation 时最短的解在 $J^\top$ 方向上：$\delta=-J^\top\varepsilon/(JJ^\top)$，长度的平方是

$$\|\delta\|^2=\frac{\varepsilon^2}{JJ^\top}=\frac{(x_2^\top Fx_1)^2}{(Fx_1)_1^2+(Fx_1)_2^2+(F^\top x_2)_1^2+(F^\top x_2)_2^2}$$

算一次。Box 的角 $(1,0,3)$，image 2 里的 pixel 在 $v$ 方向偏 1 pixel。它到 epipolar line $Fx_1$ 的距离是 0.9997 pixel；Sampson error 的平方根是 0.6901；真的去解 triangulation 得到的 geometric error 是 0.6901（差在第 5 位）。Geometric error 比“到 epipolar line 的距离”小，是因为最优的 correction 把这 1 pixel 分摊到了两张 image 上。另一个角 $(2,-1,4)$ 同样偏 1 pixel：距离 0.9945，Sampson 0.68141，geometric 0.68141。Sampson error 几乎不费计算就达到了 geometric error 的精度，RANSAC 里判断 inlier 用的就是它。

### 7-point algorithm

$F$ 有 7 个 degree of freedom（9 个 entry、去掉 scale、再加 $\det F=0$），8 个点用来解 linear system 多用了一个。只有 7 个点时，$Af=0$ 的 null space 是二维的，$F=\alpha F_1+(1-\alpha)F_2$。再要求 rank 2：

$$\det(\alpha F_1+(1-\alpha)F_2)=0$$

是 $\alpha$ 的 cubic，有 1 个或 3 个 real root。随机取 7 个点试一次，三个 real root 是 $\alpha=1.638$、$1.274$、$1.048$，第一个给出的 $F$ 与真值的最大 entry 差 $1.8\times10^{-14}$，另两个差 0.13 和 0.26，要用第 8 个点或 RANSAC 的 inlier 数挑出来。数一数和 projective ambiguity 是否一致：$m$ 个 camera 各 11 个 degree of freedom，$n$ 个点各 3 个，减去 $H$ 的 15 个；每个点在每张 image 里给 2 个 equation。$m=2$ 时 $4n\ge22+3n-15$，$n\ge7$。

### Generalized camera：一辆车上的几个 camera

自动驾驶的车上常装 4 到 6 个朝向不同的 camera，视野几乎不重叠。每个 camera 单独做 visual odometry 都有 [CS4243](CS4243.html#epipolar) 说的 scale ambiguity，而且看不到彼此的点。但几个 camera 固定在同一个 rig 上，它们之间的距离是知道的。能不能把整个 rig 当成一个 camera？

::fig[cs4277-rig] 同一个点，时刻 1 被 camera a 看到，时刻 2 被 camera b 看到。

这样的 “camera” 的 ray 不再从同一个 center 出发，$y_2^\top Ey_1=0$ 的推导（[CS4243](CS4243.html#epipolar) 里用 $d_2y_2=d_1Ry_1+t$）不再成立。每条 ray 要同时记方向和位置。Plücker 坐标把经过点 $c$、方向为 $q$ 的 line 写成 $(q,\,q')$，$q'=c\times q$；沿 line 换一个 $c$，$q'$ 不变。两条 line 相交（或 parallel）的条件是

$$q_1\cdot q_2'+q_1'\cdot q_2=0$$

（两条 line 的公共 perpendicular 的长度乘 $\|q_1\times q_2\|$ 正是左边，所以为 0 当且仅当它们共面。）

Rig 从时刻 1 到时刻 2，coordinate 变换和 CS4243 一样是 $X_2=RX_1+t$。时刻 2 的 ray $(q_2,q_2')$ 搬到时刻 1 的 coordinate：方向变成 $R^\top q_2$；它经过的点 $c_2$ 变成 $R^\top(c_2-t)$，所以 moment 变成

$$R^\top(c_2-t)\times R^\top q_2=R^\top\big((c_2-t)\times q_2\big)=R^\top(q_2'-t\times q_2)$$

代进相交条件：$q_1^\top R^\top(q_2'-[t]_\times q_2)+q_1'^\top R^\top q_2=0$。逐项转置（一个数的转置是它自己），并用 $[t]_\times^\top=-[t]_\times$：

$$q_2^\top\underbrace{[t]_\times R}_{E}\,q_1+q_2^\top R\,q_1'+q_2'^\top R\,q_1=0$$

这就是 generalized epipolar constraint。所有 camera 都在原点时 $q_1'=q_2'=0$，它退回 $q_2^\top Eq_1=0$。

**算一个。** Rig 上两个 camera 在 $(\pm0.35,0,0)$，rig 转 12°（绕 $y$ 轴）并移动 $t=(0.5,0,1.2)$。点在时刻 1 的 coordinate 是 $(1.0,-0.3,3.5)$，被 camera a 看到；时刻 2 被 camera b 看到。三项分别是

$$q_2^\top Eq_1=-0.01440,\quad q_2^\top Rq_1'=0.00701,\quad q_2'^\top Rq_1=0.00740$$

和为 0。把 $t$ 换成 $2t$，第一项变成 $-0.02881$，后两项不含 $t$，不变，和变成 $-0.01440\ne0$。Central camera 的 constraint 对 $t$ 是 homogeneous 的，scale 消掉了；这里后两项不含 $t$，scale 消不掉，所以 rig 的 motion 连长度都能定下来。

**Linear 解法。** Constraint 对 $E$ 的 9 个 entry 和 $R$ 的 9 个 entry 是 linear 的，写成 6×6 的 $\begin{pmatrix}E&R\\R&0\end{pmatrix}$ 夹在两个 Plücker vector 之间，18 个 unknown 去掉 scale 要 17 个 correspondence。但 Li、Hartley 和 Kim 指出这个 linear system 在最常见的情形下 rank 不够：camera 视野不重叠、每个 correspondence 都来自同一个 camera 时（locally central），rank 只有 16，$(\lambda E,\lambda R+\mu I)$ 都是解；ambiguity 全在 $R$ 上，$E$ 仍然定得下来。他们的办法是只对 $E$ 求 null vector，再由 $E$ 拆出 $R$，最后用 least squares 求 $t$ 的长度。

由 $F$ 求 canonical camera（$\tilde M_2=[-[e]_\times F\mid e]$，和这里的 $[[e']_\times F\mid e']$ 差一个符号，对 projective camera 没有区别）、perspective SfM 有 15 个 degree of freedom 的 ambiguity 与 $11m+3n-15$ 的计数来自 [CS231A Course Notes 4](https://web.stanford.edu/class/cs231a/course_notes/Course_Notes_4.pdf) 第 4 节。Generalized camera 的 Plücker 表示、constraint 的形式、6×6 matrix、17 点、locally central 与 axial 时 rank 16 以及他们的修正办法来自 [Li、Hartley、Kim（CVPR 2008）](https://users.cecs.anu.edu.au/~hartley/Papers/PDF/LiHartleyKim:CVPR08.pdf)；这里用 CS4243 的 $X_2=RX_1+t$ 约定重新推了一遍。$F=[e']_\times P'P^+$ 的推导、stratification 的两步和 $H$ 的形式、Sampson error 的推导、7-point algorithm 是按 Hartley 和 Zisserman 第 9 到第 11 章、第 19 章的结构凭自己的知识写的，没有对照原文；CMU 16-822 的 L09 到 L13（two-view geometry 到 auto-calibration）抓取被拒。Box 的三阶段 reconstruction、Sampson 与 geometric error 的比较、7-point 的 root、rig 的例子都是为这一页实际算的。

## [tri] Triangulation 与 uncertainty

:::skip
能写出 linear triangulation 的 $AX=0$，知道三种 triangulation 的差别在哪里，能由 Jacobian 算出 3D point 的 covariance，并用 parallax 解释 uncertainty 为什么沿 ray 拉长，就可以去第 5 站。
:::

### 两条 ray 不相交

Camera 已知、一对 correspondence 已知，求 3D point。没有 noise 时两条 ray 交于这个点。有 noise 时它们一般是 skew 的。

继续用第 3 站的两个 camera 和 box 的角 $(2,-1,4)$。真实 pixel 是 $(365.10,25.56)$、$(365.65,30.33)$，各加一点 noise，观测到 $x_1=(365.70,25.16)$、$x_2=(365.15,31.03)$。两条 ray 的最近距离是 8.6 mm。

**Midpoint。** 求两条 ray 上最近的两点 $C_1+s\,d_1$、$C_2+t\,d_2$（$s$、$t$ 满足连线 perpendicular 于两条 ray，一个 2×2 的 least squares），取中点：$(1.9840,\,-1.0043,\,3.9577)$。

**Linear（DLT）。** $x\sim PX$ 等价于 $x\times PX=0$。记 $p_k^\top$ 是 $P$ 的第 $k$ 个 row，展开前两个 component：

$$u\,(p_3^\top X)-p_1^\top X=0,\qquad v\,(p_3^\top X)-p_2^\top X=0$$

（第三个 component 是前两个的 linear combination。）每个 view 2 个 equation，叠成 $AX=0$，$A$ 是 4×4。有 noise 时 $A$ 是 full rank 的，取最小 singular value 对应的 right singular vector。这次 $A$ 的 singular value 是 1437.96、706.51、151.94、0.714，得 $X=(1.9838,\,-1.0044,\,3.9572)$。View 更多就继续往 $A$ 里加 row。

**最小化 reprojection error。** 每个 pixel 的 noise 是 Gaussian 时，maximum likelihood 的点是

$$\hat X=\arg\min_X\ \|\pi(P_1X)-x_1\|^2+\|\pi(P_2X)-x_2\|^2$$

$\pi$ 是除以第三个 coordinate。这是 3 个 unknown 的 nonlinear least squares，从 DLT 的结果出发做几步 Gauss–Newton（第 7 站）就收敛：$(1.9839,\,-1.0041,\,3.9572)$。

| 做法 | 两张 image 的 reprojection error（合计，pixel） | 离真值（cm） |
|---|---|---|
| midpoint | 0.8407 | 4.55 |
| DLT | 0.8409 | 4.60 |
| 最小化 reprojection error | 0.8391 | 4.59 |
| 真实的点 | 1.1225 | 0 |

三种做法的差别在 0.1 mm 量级。真实的点 reprojection error 反而最大，因为 noise 本身就有 1.12 pixel。这一次决定误差的不是用哪种 algorithm，是 4.6 cm 这个量本身从哪里来。

### 误差的大小和形状

把 projection 在 $\hat X$ 附近 linearize：pixel 的 noise $\delta x$ 造成的 3D 偏差 $\delta X$ 满足 $\delta x\approx J\,\delta X$，$J$ 是 4×3 的 Jacobian（两个 view、每个 view 两个 coordinate 对 $X$ 的 derivative）。$\delta X$ 是这个 least squares 的解：

$$\delta X=(J^\top J)^{-1}J^\top\delta x$$

$\delta x$ 的 covariance 是 $\sigma^2I$，代进 $\mathrm{Cov}(\delta X)=(J^\top J)^{-1}J^\top\,\mathrm{Cov}(\delta x)\,J(J^\top J)^{-1}$：

$$\mathrm{Cov}(\delta X)=\sigma^2(J^\top J)^{-1}J^\top J(J^\top J)^{-1}=\sigma^2(J^\top J)^{-1}$$

对 $(2,-1,4)$、$\sigma=1$ pixel 算出来，$(J^\top J)^{-1}$ 三个 eigenvalue 的平方根是 0.52 cm、0.57 cm、6.60 cm，最长的 axis 和从 camera 1 指向这个点的方向只差 $6°$。

::fig[cs4277-triunc] 同一个点、同样的 pixel noise，只改 camera 2 的位置。

:::wrong 两张 image 的 pixel noise 都只有 1 pixel，triangulate 出来的点各个方向一样准
Pixel noise 是 isotropic 的，3D 的误差不是。上面算出横向 0.5 cm、沿 ray 方向 6.6 cm，差 12 倍。原因在几何：横向移动 $X$，两张 image 里的 pixel 都明显移动；沿 ray 移动 $X$，camera 1 的 pixel 完全不动，camera 2 的 pixel 只移动 $\sin(\text{parallax})$ 那么一点。Parallax 是两条 ray 的夹角，这里 $9.8°$。把 baseline 从 0.8 m 缩到 0.1 m，parallax 变成 $1.15°$，沿 ray 的 $\sigma$ 从 6.6 cm 变成 56.8 cm，横向仍然是 0.5 cm。用同样的 noise 重做上面的例子，三种做法的误差都变成 36 到 38 cm。
:::

:::edge 很远的点
Parallax 趋于 0 时，DLT 的 solution $X=(X_1,X_2,X_3,X_4)$ 里 $X_4$ 趋于 0，除以它就爆掉。Homogeneous 的 $X$ 本身没有问题，它表示一个方向：天上的星星对 rotation 有贡献，对 translation 没有。Bundle adjustment 里常把远处的点参数化成方向加 inverse depth $\rho=1/Z$，$\rho=0$ 就是无穷远，不会出现除以 0。
:::

:::edge 两条 ray 交在 camera 后面
DLT 的 $AX=0$ 不知道 camera 有前后，可能给出一个在 camera 后面的点（depth 为负）。[CS4243](CS4243.html#epipolar) 用这一点（cheirality）从 $E$ 的四组分解里挑出正确的一组；triangulation 的结果也要检查两个 depth 都为正。
:::

:::back
两个 camera 的设定来自[第 3 站](#twoview)。
:::

:::from
Linear triangulation 由 $p\times MP=0$ 每个 view 取 2 个 constraint、叠成 $AP=0$ 用 SVD、更多 view 加 row，nonlinear triangulation 最小化 reprojection error、用 Gauss–Newton 并由 linear 的结果初始化，来自 [CS231A Course Notes 4](https://web.stanford.edu/class/cs231a/course_notes/Course_Notes_4.pdf) 第 2 节。那份讲义还指出 linear 方法不是 projective invariant；这一页在这组数据上试了两个 $H$，结果只差 0.006 mm 和 0.027 mm，影响很小，所以正文没有展开。Midpoint 的做法、covariance $\sigma^2(J^\top J)^{-1}$ 的推导、parallax 的解释、inverse depth 是凭自己的知识写的；表里和图里的数字都是实际算的。

## [trifocal] Three-view geometry 与 trifocal tensor

:::skip
能说出两张 image 为什么对 line 没有 constraint，能由三个 camera 写出 trifocal tensor 并用它做 point transfer，知道 epipolar transfer 在哪里失效，就可以去第 6 站。
:::

### 两张 image 不够用的两个地方

**Line。** Image 1 里一条 line 反投影成一个过 $C_1$ 的 plane，image 2 里一条 line 反投影成一个过 $C_2$ 的 plane。两个 plane 总是相交于一条 3D line。所以任何两条 image line 都可以是同一条 3D line 的 image，两个 view 对 line 的 correspondence 没有任何 constraint。建筑、走廊这类场景里 line 比点多得多，这是很大的浪费。

**Point transfer。** 已知一个点在 image 1、2 里的位置，想知道它在 image 3 的什么地方（用来检验第三张 image 里的 match，或者在第三张里预测去哪里找）。只用 fundamental matrix，它在 image 3 里要同时在 $F_{13}x_1$ 和 $F_{23}x_2$ 两条 epipolar line 上：

$$x_3=(F_{13}x_1)\times(F_{23}x_2)$$

这叫 epipolar transfer。

::fig[cs4277-trifocal] 三个 camera 的 center 都在 $y=0$ 上，这个 plane 叫 trifocal plane。点 A 离它只有 3 cm。

问题在于：点 $X$ 的 epipolar line 在 image 3 里是 plane $(C_1,C_3,X)$ 的 image，另一条是 plane $(C_2,C_3,X)$ 的 image。$X$ 在 trifocal plane 上时，这两个 plane 都是 trifocal plane，两条 line 重合，交点没有定义。$X$ 离 trifocal plane 很近时，两条 line 只差 $1.6°$，pixel 上 0.5 的 noise 就能把交点推到 28.4 pixel 之外。$X$ 离得远（点 B，$y=0.8$），两条 line 交成 $41.8°$，误差 1.07 pixel。三个 camera 在同一高度水平地排开是 robot 和车上最常见的布置，场景里和 camera 一样高的点都落在这个 plane 附近。

### 三个 plane 交于一条 line

三个 view 里各有一条 line $l$、$l'$、$l''$，它们来自同一条 3D line $L$。三条 line 反投影出三个 plane：$P^\top l$、$P'^\top l'$、$P''^\top l''$（第 1 站说过 plane 和 line 是 dual 的：点 $X$ 在 plane $P^\top l$ 上，等价于 $l^\top(PX)=0$，即 $X$ 的 image 在 $l$ 上）。三个 plane 都包含 $L$。

取 $P=[I\mid0]$、$P'=[A\mid a_4]$、$P''=[B\mid b_4]$（第 3 站说过总可以这样取）。三个 plane 并排写成一个 4×3 matrix：

$$\begin{pmatrix}l&A^\top l'&B^\top l''\\0&a_4^\top l'&b_4^\top l''\end{pmatrix}$$

三个 plane 交于一条 line 而不只是一个点，意味着它们的 null space 是二维的，这个 matrix 的 rank 是 2，三个 column linearly dependent：第一个 column $=\alpha\,(\text{第二个})+\beta\,(\text{第三个})$。看最后一个 row：$0=\alpha\,a_4^\top l'+\beta\,b_4^\top l''$，取 $\alpha=b_4^\top l''$、$\beta=-a_4^\top l'$。代回前三个 row：

$$l=(b_4^\top l'')A^\top l'-(a_4^\top l')B^\top l''$$

取第 $i$ 个 component，$A^\top l'$ 的第 $i$ 个 component 是 $a_i^\top l'$（$a_i$ 是 $A$ 的第 $i$ 个 column）：

$$l_i=l'^\top\big(a_ib_4^\top-a_4b_i^\top\big)\,l''=l'^\top T_i\,l''$$

三个 3×3 的 $T_1,T_2,T_3$ 合起来是一个 $3\times3\times3$ 的 trifocal tensor $\mathcal T$。给定 image 2、3 里的 line，它直接算出 image 1 里的 line（line transfer）。在上面三个 camera 上验证：一条经过 $(0.2,0.5,4)$ 和 $(1.0,-0.3,5)$ 的 3D line，用 $\mathcal T$ 由 $l'$、$l''$ 算出的 $l$ 和直接投影得到的 $l$ 都是 $(-0.00169,-0.00137,1)$。

### Point transfer

上面的 $l$ 是 3D line $L$ 的 image。如果 image 1 的点 $x$、image 2 里一条过 $x'$ 的 line $l'$、image 3 里一条过 $x''$ 的 line $l''$ 都来自同一个 3D point $X$：$X$ 在 plane $P'^\top l'$ 上，也在 $P''^\top l''$ 上，所以在它们的交线 $L$ 上，$x$ 在 $L$ 的 image $l$ 上：

$$x^\top l=\sum_ix_i\,l'^\top T_il''=0$$

这叫 point-line-line incidence。固定 $x$ 和 $l'$，这个式子对每一条过 $x''$ 的 $l''$ 都成立，即 vector $\big(\sum_ix_iT_i\big)^\top l'$ 和所有过 $x''$ 的 line 都 orthogonal。和所有过一点的 line orthogonal 的 vector 只有那个点本身，所以

$$x''\sim\Big(\sum_ix_iT_i\Big)^\top l'$$

$l'$ 取任何一条过 $x'$ 的 line 都行，只有 epipolar line $F_{12}x$ 不行：它反投影出的 plane 包含 $x$ 的整条 ray，和 ray 交不出一个点。实际取过 $x'$、perpendicular 于 epipolar line 的那条。

对点 A：真实位置 $(316.83,244.28)$，epipolar transfer 给出 $(288.45,244.22)$，trifocal transfer 给出 $(316.79,243.83)$，误差从 28.4 pixel 降到 0.45 pixel。点 B 上从 1.07 降到 0.31。$\mathcal T$ 不需要两个 plane 交出一个点，它用的 plane 是 $l'$ 反投影的那个，和 trifocal plane 无关。

### 数 degree of freedom

$\mathcal T$ 有 27 个 entry。三个 camera 各 11 个 degree of freedom，减去 projective ambiguity 的 15 个，是 18 个；27 个 entry 去掉 scale 剩 26 个，说明 entry 之间还有 8 个 constraint。估计 $\mathcal T$ 时，每组三张 image 里的 point correspondence 给出 4 个 independent 的 linear equation，$n$ 个点叠成 $4n\times27$ 的 system，至少 7 个点；和 8-point algorithm 一样要先 normalize 坐标。最少的 minimal solver 用 6 个点。

:::wrong 三张 image 的几何就是三个 fundamental matrix
三个 $F$ 一共 21 个 degree of freedom，三个 camera 的几何只有 18 个，它们之间有 constraint，单独估计的三个 $F$ 一般互相不一致。更重要的是上面的数字：即使三个 $F$ 都 exact，用它们做 point transfer，在 trifocal plane 附近也会失效（28.4 pixel）；$\mathcal T$ 在同样的地方给出 0.45 pixel。
:::

:::back
Line、plane 的 duality 来自[第 1 站](#proj)；canonical camera $[I\mid0]$ 和 projective ambiguity 来自[第 3 站](#twoview)。
:::

:::from
Degree of freedom 的整张表（单 view 11、$F$ 7、$E$ 5、uncalibrated trifocal tensor 27 个 entry 18 个 degree of freedom、calibrated 11）、trifocal tensor 是“一个 view 的 line 反投影出的 plane 在另两个 view 之间诱导的 homography”、各种 incidence relation 的分类、DLT 的 $4n\times27$ system 和 normalization、6 点 minimal solution，来自 [UCSD CSE 252B Lecture 16](https://cseweb.ucsd.edu/classes/wi26/cse252B-a/lec16.pdf)；那份 slides 的公式是图片，抓取时只得到文字，所以 $T_i=a_ib_4^\top-a_4b_i^\top$ 的推导、point transfer 的推导、epipolar transfer 在 trifocal plane 上失效的分析是按 Hartley 和 Zisserman 第 15、16 章的结构凭自己的知识写的。CMU 16-822 的 L14b（three-view geometry）抓取被拒。三个 camera 和 A、B 两点的数字是为这一页实际算的。

## [sfm] N-view：factorization、non-rigid SfM 与 incremental SfM

:::skip
能对 affine camera 做 Tomasi–Kanade factorization 并做 metric upgrade，知道 non-rigid 时 rank 变成多少，能说出 incremental SfM 每加一张 image 要做的三件事，就可以去第 7 站。
:::

### Affine camera：rank 3

很多张 image、很多个点，能不能一次全部解出来？Perspective 的 division 让问题 nonlinear。物体离 camera 很远、深度变化相对很小时，可以用 affine camera 近似：

$$x_{ij}=A_iX_j+b_i$$

$A_i$ 是 2×3，$b_i$ 是 2-vector（camera $i$、点 $j$）。先消掉 $b_i$：对每张 image 减去它所有点的 centroid $\bar x_i$，同时把 3D 的 centroid 放在原点，

$$\hat x_{ij}=x_{ij}-\bar x_i=A_i\Big(X_j-\frac1n\sum_kX_k\Big)=A_i\hat X_j$$

把 $m$ 张 image 的 $\hat x_{ij}$ 排成一个 $2m\times n$ 的 measurement matrix：

$$W=\begin{pmatrix}\hat x_{11}&\cdots&\hat x_{1n}\\\vdots&&\vdots\\\hat x_{m1}&\cdots&\hat x_{mn}\end{pmatrix}=\underbrace{\begin{pmatrix}A_1\\\vdots\\A_m\end{pmatrix}}_{2m\times3}\underbrace{\begin{pmatrix}\hat X_1&\cdots&\hat X_n\end{pmatrix}}_{3\times n}$$

两个 factor 的 inner dimension 是 3，所以不管有多少 camera、多少点，$W$ 的 rank 至多是 3。

**算一个。** 一个“房子”：1 m 的 cube 加两个屋脊点，共 10 个点；camera 从 4 个方向（绕竖直轴 0°、15°、30°、45°，都向下 20°）做 orthographic 投影，1 m 对应 100 pixel，每个 pixel 加约 0.5 的 noise。

::fig[cs4277-factor] 上排是四张 image；左下是 $W$（8×10）的 singular value；右下是 reconstruction。

$W$ 的 8 个 singular value 是 372.21、277.93、84.73、1.88、1.42、1.22、0.25、0.19。前 3 个和后 5 个差两个数量级，后面那些只是 noise。做 SVD $W=U\Sigma V^\top$，只留前三个：$W\approx U_3\Sigma_3V_3^\top$。这是 Frobenius norm 下最好的 rank-3 approximation，有 noise 时正好用来压掉 noise。Tomasi 和 Kanade 取

$$M=U_3\Sigma_3^{1/2},\qquad S=\Sigma_3^{1/2}V_3^\top$$

### Affine ambiguity 与 metric upgrade

对任何可逆的 3×3 matrix $Q$，$W=(MQ)(Q^{-1}S)$，所以 $S$ 只定到一个 affine transformation 为止。右下左边那个就是直接取 $S$ 的结果：cube 的三个 angle 是 $84.8°$、$68.7°$、$70.1°$，三条 edge 的 length 是 11.12、9.84、7.48。

要找到正确的 $Q$，用 camera 的结构：orthographic camera 的 $A_i$ 是 rotation 的前两个 row 乘一个 scale，两个 row 等长且 orthogonal。记 $M$ 的第 $i$ 个 camera 的两个 row 是 $m_{i1}^\top$、$m_{i2}^\top$，修正后的 row 是 $m^\top Q$，记 $L=QQ^\top$：

$$m_{i1}^\top Lm_{i1}=m_{i2}^\top Lm_{i2},\qquad m_{i1}^\top Lm_{i2}=0$$

$L$ 是 symmetric 的，6 个 unknown，每张 image 给 2 个 linear equation；再加 $m_{11}^\top Lm_{11}=1$ 定下 scale。4 张 image 共 9 个 equation，用 least squares 解出 $L$，Cholesky 得 $Q$，$S\leftarrow Q^{-1}S$。结果（右下右边）：三个 angle $89.5°$、$89.1°$、$88.3°$，length 100.4、99.3、96.2（真值 90° 和 100），剩下的偏差来自 0.5 pixel 的 noise。

$L$ 只决定 $Q$ 到一个 orthogonal 的 factor 为止，包括 reflection：orthographic 的 image 分不清一个形状和它的 mirror image（深度整体反过来），这是 orthographic 投影固有的，perspective 的 image 才能区分。

:::wrong SVD 给出了最好的 rank-3 factorization，structure 就求出来了
SVD 给出的 $S$ 和真实形状差一个任意的 3×3 matrix。上面那个 cube 的 angle 是 $84.8°$、$68.7°$、$70.1°$，edge 的 length 之比是 $11.1:9.8:7.5$。Factorization 本身只用到“rank 是 3”，没有用到“camera 是 rotation”；后者要靠 metric upgrade 那一步才进来。
:::

### Non-rigid：rank $3K$

人脸在说话、布在飘，每张 image 里的形状都不同，$W=MS$ 的前提没有了。Bregler 等人的假设是：形状是 $K$ 个固定的 basis shape 的 linear combination，

$$S_i=\sum_{k=1}^Kc_{ik}B_k$$

于是第 $i$ 张 image 是 $A_iS_i=\big(c_{i1}A_i\ \cdots\ c_{iK}A_i\big)\begin{pmatrix}B_1\\\vdots\\B_K\end{pmatrix}$，整个 $W$ 是一个 $2m\times3K$ 乘 $3K\times n$，rank 至多 $3K$。

用同一个房子验证：6 张 image（转 0° 到 50°），没有 noise。Rigid 时 singular value 是 455.34、340.50、105.72，之后全是 0。让每个点再加上一个 random 的 basis 位移 $B_1$（rms 0.24 m），6 张 image 的系数 $c_i$ 取 0、0.6、−0.4、1.0、0.3、−0.8，singular value 变成 468.10、342.72、102.12、33.80、28.00、10.65，第 7 个起是 0：rank 6，正好 $3K$。

Factorization 的步骤照旧，只是 $Q$ 现在是 $3K\times3K$ 的，而且 $M$ 的每个 $2\times3K$ 的 block 要能写成“系数乘 rotation”的形状，这个 constraint 不再是 linear 的，non-rigid 的 metric upgrade 因此比 rigid 难得多。

### Perspective：incremental SfM

Factorization 要求每个点在每张 image 里都看得到，$W$ 才是完整的 matrix；几千张 image 的场景里一个点通常只出现在几张里。实际的 structure from motion（例如 COLMAP）是 incremental 的：

1. **Initialization。** 选两张 match 多、parallax 足够的 image，用 5-point algorithm 加 RANSAC 求 $E$，拆出 $R$、$t$（[CS4243 第 6 站](CS4243.html#epipolar)），triangulate（第 4 站）。
2. **Registration。** 新的一张 image 里，有些 feature 对应已经 triangulate 的 3D point。由这些 2D–3D 对应求新 camera 的 pose，叫 Perspective-n-Point（PnP）。Pose 有 6 个 degree of freedom，每个点 2 个 equation，最少 3 个点（P3P，最多 4 个解）；不知道 $K$ 时用 [CS4243](CS4243.html#camera) 的 DLT，至少 6 个点。都放在 RANSAC 里。
3. **Triangulation。** 新 camera 和已有 camera 之间的 match 中，还没有 3D point 的那些 triangulate 出来。
4. **Bundle adjustment。** 每加几张 image，对所有 camera 和点一起最小化 reprojection error（第 7 站），防止误差累积。

数一下 perspective 时要多少点：已知 $K$ 时 unknown 是 $6m+3n-7$（减去 similarity 的 7 个），uncalibrated 时是 $11m+3n-15$，equation 都是 $2mn$。$m=2$ 时分别要 $n\ge5$ 和 $n\ge7$，对应 5-point 和 7-point algorithm。

:::back
Projective ambiguity 和 canonical camera 来自[第 3 站](#twoview)；triangulation 来自[第 4 站](#tri)。

## [ba] Bundle adjustment

:::skip
能写出 Gauss–Newton 的 normal equations，知道 Levenberg–Marquardt 在什么时候必须用、damping 怎么调，能画出 Jacobian 的 sparsity 并说明 Schur complement 省在哪里，知道 gauge freedom 怎么处理，就可以去第 8 站。
:::

### Cost 与 Gauss–Newton

所有 camera 的 pose $c_i$ 和所有点 $X_j$ 放进一个 vector $x$，residual 是每个观测的 reprojection error：

$$r_{ij}(x)=\pi(c_i,X_j)-x_{ij},\qquad \min_x\ \tfrac12\sum_{(i,j)\text{ 可见}}\|r_{ij}(x)\|^2$$

只对真正观测到的 $(i,j)$ 求和。这是 nonlinear least squares，没有 closed form，只能从一个初值出发反复改进。在当前的 $x$ 附近把每个 residual 换成它的 linear approximation：

$$r(x+\delta)\approx r(x)+J\delta,\qquad J=\frac{\partial r}{\partial x}$$

于是要最小化的变成 $\tfrac12\|r+J\delta\|^2$，一个 linear least squares。对 $\delta$ 求 gradient 令其为 0：

$$J^\top(r+J\delta)=0\qquad\Longrightarrow\qquad J^\top J\,\delta=-J^\top r$$

解出 $\delta$，$x\leftarrow x+\delta$，重复。这就是 Gauss–Newton。和 Newton's method 比较：cost 的 Hessian 是 $J^\top J+\sum_kr_k\nabla^2r_k$，Gauss–Newton 丢掉了第二项，只需要一阶 derivative。Residual 小（初值好）时丢掉的部分本来就小。

### 一个能画出来的 toy problem

为了把整个过程画出来，把世界压成二维：world 是 $(x,z)$ plane，camera 是“一维”的，pose 是 $(p_x,p_z,\theta)$，image 只有一个 coordinate

$$u=f\,\frac{\cos\theta\,(x-p_x)-\sin\theta\,(z-p_z)}{\sin\theta\,(x-p_x)+\cos\theta\,(z-p_z)},\qquad f=500$$

4 个 camera、12 个点，每个观测加 $\pm0.3$ pixel 的 noise。Camera 1 的 pose 固定，camera 2 的 $p_x$ 也固定（原因在下面的 gauge 一节），unknown 是 $2+3+3=8$ 个 camera parameter 加 24 个 point coordinate，共 32 个；residual 有 $4\times12=48$ 个。初值：每个点偏 0.17 到 0.33 m，camera 偏 10 到 16 cm、1.2° 到 2.0°。

::fig[cs4277-ba] 每一次 iteration 解一次 $J^\top J\delta=-J^\top r$。

RMS reprojection error 依次是 35.814、1.144、0.206、0.101、0.101 pixel。第二步到第三步从 1.144 降到 0.206，误差大约按平方缩小，这是 Gauss–Newton 在 residual 小的问题上接近 Newton's method 的表现。

### Gauss–Newton 会走过头：Levenberg–Marquardt

把初值的偏差放大到 2.5 倍（点平均偏 1.08 m，camera 偏到 8°）。Gauss–Newton 的 RMS：

$$166.79\to324.74\to275.99\to3937.07\to2866.71\to1778.54\to\cdots$$

第一步就让 cost 变大了。Linear approximation 只在 $x$ 附近可信，$\delta$ 却可能很长，走到 approximation 完全失效的地方。

Levenberg–Marquardt 在 normal equations 的 diagonal 上加一个 damping：

$$(J^\top J+\lambda\,\mathrm{diag}(J^\top J))\,\delta=-J^\top r$$

$\lambda$ 很小时就是 Gauss–Newton；$\lambda$ 很大时 diagonal 占主导，$\delta\approx-J^\top r/(\lambda\,\mathrm{diag})$，是沿 gradient 方向的一小步，cost 一定下降。规则是：试走一步，cost 下降就接受并把 $\lambda$ 除以 10，cost 上升就拒绝并把 $\lambda$ 乘以 10 重试。从 $\lambda=10^{-3}$ 开始，同样的初值：

$$166.79\to26.82\to4.126\to2.471\to0.273\to0.102\to0.101$$

每一步都被接受，六步收敛到和上面同一个 solution。这就是 bundle adjustment 的标准 solver 是 Levenberg–Marquardt 的原因。但它也只保证 cost 不升，不保证找到 global minimum：初值差到一定程度，会停在 local minimum，所以 SfM 才要先用第 3、6 站的方法给出好的初值。

### Sparsity：Schur complement

每个 residual $r_{ij}$ 只依赖一个 camera 和一个点，Jacobian 的每个 row 只有很少几个非零 entry。

::fig[cs4277-sparsity] Toy problem 的 $J$（48×32）和 $J^\top J$（32×32），深灰是 camera 的列，彩色是 point 的列。

$J$ 的 1536 个 entry 里只有 192 个非零。把 unknown 分成 camera 部分 $\delta_c$ 和 point 部分 $\delta_p$，normal equations 是

$$\begin{pmatrix}U&W\\W^\top&V\end{pmatrix}\begin{pmatrix}\delta_c\\\delta_p\end{pmatrix}=\begin{pmatrix}g_c\\g_p\end{pmatrix}$$

$V$ 是 block diagonal：两个不同的点之间没有共同的 residual，交叉项全是 0。所以 $V^{-1}$ 只要对每个点各求一个小 block 的 inverse（三维里是 3×3）。由第二行 $\delta_p=V^{-1}(g_p-W^\top\delta_c)$，代入第一行：

$$(U-WV^{-1}W^\top)\,\delta_c=g_c-WV^{-1}g_p$$

左边的 matrix 叫 Schur complement，大小只是 camera parameter 的个数。先解它，再逐个点代回求 $\delta_p$。规模感：1000 个 camera（每个 6 个 parameter）、$10^6$ 个点，unknown 有 $3\,006\,000$ 个，dense 的 Cholesky 大约要 $(3.006\times10^6)^3/3\approx9\times10^{18}$ 次 operation；消去点之后只剩 6000×6000 的 system，Cholesky 约 $6000^3/3=7.2\times10^{10}$ 次，再加上 $10^6$ 个 3×3 的 inverse。

### Gauge freedom

如果不固定任何东西，所有 camera 和点一起平移、转动、放大，image 完全不变，cost 也不变。Cost 在这些方向上是平的，$J^\top J$ 在这些方向上的 eigenvalue 是 0，normal equations 没有唯一解。Toy problem 里（二维的 similarity 有 2 个 translation、1 个 rotation、1 个 scale）不固定任何 camera 时，36×36 的 $J^\top J$ 恰好有 4 个 eigenvalue 是 0，下一个是 7.38。三维里是 7 个（monocular 时；有 stereo baseline 或 IMU 时 scale 可观测，是 6 个）。

处理办法有三种：固定足够多的 parameter（上面固定了 camera 1 的 pose 和 camera 2 的 $p_x$，正好 4 个）；加一个 prior（比如 camera 1 的 pose 有一个很强的 prior）；或者依赖 Levenberg–Marquardt 的 damping，它让 $J^\top J+\lambda\,\mathrm{diag}$ 总是可逆的，但 solution 会在 gauge 方向上随意漂移，比较不同的 run 时要先对齐。

:::wrong 最后的 RMS 比真值处还低，说明 estimate 比真值还准
收敛后 RMS 是 0.101 pixel，把真实的 camera 和点代进去，RMS 是 0.167 pixel。但 estimate 的点离真值最远 5.3 cm，camera 4 的角度偏了 0.42°。48 个 residual、32 个 unknown，optimizer 有 32 个方向可以去“解释”noise，它把一部分 noise 当成了几何；真值反而不会迁就 noise。Cost 低只说明 fit 得好，误差的大小要看第 4 站那样的 covariance $(J^\top J)^{-1}$，或者和独立的 ground truth 比。
:::

:::edge 三维的 rotation 不能直接当成三个数来加
二维里 $\theta+\delta\theta$ 没有问题。三维里如果用 Euler angle，在 gimbal lock 附近 Jacobian 会退化；如果直接更新 rotation matrix 的 9 个 entry，结果不再是 rotation。标准做法是在当前的 $R$ 附近用一个小的 axis-angle $\delta\phi$ 去乘：$R\leftarrow R\exp([\delta\phi]_\times)$，每一步都只在三个 parameter 上求 derivative，乘完仍然是 rotation。
:::

:::back
Reprojection error 的形式和 nonlinear triangulation 来自[第 4 站](#tri)；初值来自[第 3 站](#twoview)和[第 6 站](#sfm)。
:::

:::from
Nonlinear least squares 的 setup、Newton 与 Gauss–Newton 的关系（丢掉 $r\nabla^2r$ 一项、residual 小时合理）、Gauss–Newton 等价于把每个 residual linearize 后解 linear least squares、Gauss–Newton 不保证收敛、Levenberg–Marquardt 是 trust region 方法、$\lambda$ 大时像 gradient descent、按“好就减、不好就加”调 $\lambda$、monocular bundle adjustment 的 scale 与整体 pose 不可观测以及用 prior 或 LM 处理，来自 [MIT 16.485 VNAV 的 lecture 17–18 notes](https://vnav.mit.edu/material/17-18-NonLinearLeastSquares-notes.pdf)（那份 notes 从 $\lambda=10^{-3}$ 开始、成功时减半、失败时加倍；这里用的是乘除 10，并且把 damping 加在 diagonal 上）。Bundle adjustment 只用可见的观测、用 Gauss–Newton 或 LM、需要好的初值，来自 [CS231A Course Notes 4](https://web.stanford.edu/class/cs231a/course_notes/Course_Notes_4.pdf) 第 5.1 节。Sparsity、Schur complement、gauge 的个数、rotation 的 local parameterization 那两份 notes 都没有讲，是凭自己的知识写的（对应 Triggs 等人的 *Bundle Adjustment: A Modern Synthesis*，没有对照原文）。二维 toy problem 和所有数字是为这一页实际算的。

## [mvs] Multi-view stereo：plane sweep

:::skip
能写出 plane-induced homography，能解释为什么把几个 baseline 的 cost 加起来能去掉 repetitive texture 的 ambiguity，并说清 NCC 比 SSD 多防了什么，就可以结束了。
:::

### 稀疏的点不够

SfM 给出 camera 和几千到几百万个 feature point，但一面墙、一张桌子在 feature 之间是空的。Multi-view stereo（MVS）在 camera 已知的前提下，为 reference image 的每个 pixel 求 depth。[CS4243 第 6 站](CS4243.html#epipolar)讲了 rectified 的两张 image 沿 row 找 correspondence；这一站看为什么两张常常不够，以及多张 image 怎样一起用。

### 一面有条纹的墙

二维的设定：reference camera 在原点，$f=500$；正前方 3 m 处一面墙，上面是周期 15 cm 的条纹（intensity $\sin(2\pi X/0.15)$）。另外两个 camera 在 reference 右边 0.3 m 和 0.75 m，朝向相同。对 reference 的中心 pixel，在每个候选 depth $z$ 上把 $\pm12$ pixel 的 window 搬到 neighbor image 里，算 SSD 的平均。

::fig[cs4277-sweep] 彩色虚线是当前假设的 depth plane，两条灰线是 neighbor 看向假设点的 ray。

只用 0.3 m 那个 neighbor，cost 在 $z=2$、$3$、$6$ 都是 0：假设的点不在墙上，但 neighbor 在那里看到的条纹恰好和 reference 一样。条件是 neighbor 看到的位置差了整数个周期：

$$b\Big(1-\frac{Z_s}{z}\Big)=kp,\qquad z=\frac{Z_s}{1-kp/b}$$

$b=0.3$、$p=0.15$、$Z_s=3$：$k=-1,0,1$ 给出 $z=2,3,6$。只用 0.75 m 那个，$kp/b=0.2k$，在 1.6 到 7 m 之间的 0 有 $z=1.667$、$1.875$、$2.143$、$2.5$、$3$、$3.75$、$5$。两组只在 $z=3$ 重合。两个 cost 相加（Okutomi 和 Kanade 的 SSSD），只有 $z=3$ 是 0；例如 $z=2$ 处 0.3 m 的 cost 是 0，0.75 m 的是 2.0。

写成 inverse depth 看得更清楚：$\dfrac1z=\dfrac1{Z_s}\Big(1-\dfrac{kp}{b}\Big)$，false minimum 在 $1/z$ 上等间隔，间隔是 $p/(bZ_s)$，$b=0.3$ 时 $0.167\ \mathrm{m}^{-1}$，$b=0.75$ 时 $0.0667\ \mathrm{m}^{-1}$。不同 baseline 的间隔不同，只有真正的 depth 对所有 baseline 都是 minimum。这也是 MVS 常在 inverse depth 上均匀取样的原因。

:::wrong Baseline 越大越好，因为 depth 越准
第 4 站说过，baseline 大则 parallax 大、depth 的 uncertainty 小。但上面同一段 depth 范围里，0.3 m 有 3 个 0，0.75 m 有 7 个 0：baseline 越大，同样的 depth 范围在 neighbor image 里对应的搜索范围越长，碰上 false match 的机会越多；视角差大了，同一块 surface 的 appearance 和 occlusion 也变得更多。小 baseline 容易找对、大 baseline 找得准，multiple baseline 把两者结合起来。
:::

### Plane-induced homography

一般的 camera 不一定 rectified，搬 window 要怎么搬？假设 reference coordinate 里 surface 局部是一个 plane $n^\top X=d$，即 $n^\top X/d=1$。Neighbor 的 coordinate 是 $X'=RX+t$，把 $t$ 乘上这个等于 1 的数：

$$X'=RX+t\,\frac{n^\top X}{d}=\Big(R+\frac{t\,n^\top}{d}\Big)X$$

两边各乘 $K'$ 和 $K$，pixel 之间就是

$$x'\sim K'\Big(R+\frac{t\,n^\top}{d}\Big)K^{-1}x$$

对一族 plane（例如 parallel 于 reference image plane 的 $n=(0,0,1)$，$d=z$）逐个计算这个 homography，把每个 neighbor image warp 到 reference 上，比较每个 pixel 的 photo-consistency，这就是 plane sweep。上面二维的例子里 $R=I$、$t=(-b,0,0)$、$n=(0,0,1)$：$u'=u-fb/z$，正是每个 pixel 在 depth $z$ 处的 disparity。

对每个 pixel 和每个 depth 都算一个 cost，得到一个三维的 cost volume；对每个 pixel 取 cost 最小的 depth 就是一张 depth map。Cost volume 很 noisy 时，再用 graph cut、belief propagation 等方法加上相邻 pixel depth 相近的 smoothness。每张 image 都当一次 reference 求出 depth map，再把它们 fuse 成一个 3D model。

### NCC：camera 之间亮度不一样

两个 camera 的 exposure 不同，或 surface 不是 Lambertian，同一个点的 intensity 会差一个 gain 和 offset：$I'=aI+b$。把上面 0.3 m 那个 neighbor 改成 $1.3I+0.1$，SSD 在正确的 $z=3$ 处不再是 0，变成 0.055，而且和三个 false minimum 处一样大。Normalized cross-correlation 把每个 window 先减去 mean、再除以 standard deviation：

$$\mathrm{NCC}=\frac{\sum_u(I(u)-\bar I)(I'(u)-\bar I')}{\sqrt{\sum_u(I(u)-\bar I)^2\sum_u(I'(u)-\bar I')^2}}$$

$I'=aI+b$（$a>0$）时，$I'-\bar I'=a(I-\bar I)$，numerator 和 denominator 都多一个 $a$，NCC 和原来的一样。在这个例子里，NCC 在 $z=3$ 处是 1.000，正好是它的最大值。

:::edge Occlusion
某个 neighbor 被前面的物体挡住时，它在正确 depth 上的 cost 也很大，把所有 neighbor 的 cost 加起来会把正确的 depth 拉高。常用的处理是每个 pixel 只用 cost 最小的那几个 neighbor，或者只比较视角相近的 image。没有 texture 的 surface（白墙）上所有 depth 的 cost 都差不多，单个 pixel 没法决定，只能靠 smoothness 从边缘传进来。
:::

:::back
多 baseline 的思路接着[第 4 站](#tri)的 parallax；camera 来自[第 6 站](#sfm)和[第 7 站](#ba)。
:::

:::from
MVS 的问题表述（calibrated image、为 reference 求 depth map、depth map fusion）、每个 depth 比较 reference patch 与 neighbor patch、baseline 的 tradeoff、Okutomi 与 Kanade 的 multiple-baseline 把 SSD 换成跨 baseline 求和的 SSSD、SSD/SAD/ZNCC 三种 matching score、plane sweep 用 homography 把 neighbor 投到每个 plane 上、cost volume 与用 graph cut 等方法提取 depth map，来自 [Cornell CS5670 Lecture 16](https://www.cs.cornell.edu/courses/cs5670/2020sp/lectures/lec16_mvs_web.pdf)。那份 slides 只把 “NCC 的好处是什么”作为问题提出，没有回答；NCC 对 gain 和 offset invariant 的推导、plane-induced homography 的推导、inverse depth 上 false minimum 等间隔的分析、occlusion 的处理是凭自己的知识写的。条纹墙的设定和所有数字是为这一页实际算的。
