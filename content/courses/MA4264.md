先看三个场面。每一个的目标都能用一句话说清，可是“把自己的 payoff 做到最大”这句话在三个场面里都不够用。

**第一个。** Venus Williams 打 passing shot，可以打向 Serena 的 backhand 一侧（记作 L）或 forehand 一侧（R）；Serena 必须在球出手前先 lean 向一边（l 或 r）。下表是 Venus 赢下这一分的 percentage，取自 Yale ECON 159 第 9 讲：

| | Serena lean l | Serena lean r |
|---|---|---|
| **Venus 打 L** | 50 | 80 |
| **Venus 打 R** | 90 | 20 |

Serena lean l 时 Venus 打 R 好（90 > 50），lean r 时打 L 好（80 > 20）。Venus 的最好选择取决于 Serena 怎么 lean，Serena 也在猜 Venus。单人的 optimization 是“给定环境，选最好的 action”，这里的环境就是对方的选择，而对方的选择又取决于你。问题本身需要一种新的写法。

**第二个。** 一个 market 里有一家 incumbent firm，一家 entrant 考虑进入。Incumbent 放话：你进来我就打 price war。Price war 让双方都得 0；进入后相安无事，entrant 得 2、incumbent 得 1；不进入，entrant 得 1、incumbent 得 2。如果 entrant 信这句话，它就不进来，incumbent 保住 2，这句话很值钱。可是 entrant 真进来以后，incumbent 打 price war 得 0、相安无事得 1，它没有理由兑现。Entrant 该不该信？

**第三个。** 两家 firm 每个季度各自决定守约（Cooperate）还是偷偷多卖（Defect），每个季度的 payoff 是一个 prisoner's dilemma，只玩一次的话 Defect 是 dominant strategy。如果事先知道要玩 10 个季度呢？玩无限期呢？“关系越长越容易合作”听起来对，第 6 站会看到 10 个季度和无限期给出完全不同的答案。

这门课研究的就是这类情形：几个人各自 optimize，每个人的结果又依赖别人的选择。核心概念是 equilibrium，一组谁都不想单方面改变的选择。全课的线索是一步步改变“谁在什么时候知道什么”：

| 站 | 结构 | 新的问题 |
|---|---|---|
| 1、2 | 同时行动，payoff 公开 | 哪些选择可以直接排除，剩下的怎样定下来 |
| 3、4 | 同上，允许随机化 | 没有 pure equilibrium 时怎么办；纯对抗时能保证多少 |
| 5 | 行动有先后 | 哪些 threat 可信 |
| 6 | 同一个 game 反复玩 | 未来能不能约束现在 |
| 7 | 有人知道别人不知道的事 | 对不知道的东西怎样做 best response |
| 8 | 同上，而且行动有先后 | 后动的人怎样从先动者的行动推测他的 type |
| 9 | 允许签 binding agreement | 合作创造的 value 怎么分 |

三个场面分别在第 3 站、第 5 站、第 6 站得到回答。读到的 NUS tutorial 和期末 cheatsheet 把课分成四块：static games of complete information（第 1–4 站）、dynamic games of complete information（第 5、6 站）、static games of incomplete information（第 7 站）、dynamic games of incomplete information（第 8 站）；AY2012/13 的最后一次 tutorial 还有 bargaining solution 和 core（第 9 站）。

## [dom] Strategic form 与 dominance

:::skip
能写出一个 game 的 strategic form，在 matrix 里做 iterated elimination of strictly dominated strategies，能判断一个 strategy 是否被某个 mixed strategy dominate，并说出 weak dominance 为什么不能随便删，就可以去第 2 站。
:::

### Strategic form game

一个 strategic form game（也叫 normal form game）由三样东西组成：

- 一组 player $N=\{1,\dots,n\}$；
- 每个 player 的 strategy set $S_i$；
- 每个 player 的 payoff function $u_i:S_1\times\cdots\times S_n\to\mathbb R$。

课程的 cheatsheet 把它记作 $G=\{S_1,\dots,S_n;u_1,\dots,u_n\}$。所有 player 同时选，各人只关心自己的 payoff，而且这三样东西所有人都知道。一组选择 $s=(s_1,\dots,s_n)$ 叫 strategy profile。记号 $s_{-i}$ 表示除 $i$ 以外所有人的选择，于是 $u_i(s_i,s_{-i})$ 读作“我选 $s_i$、别人选 $s_{-i}$ 时我的 payoff”。

开头的 tennis 就是一个例子：两个 player，$S_1=\{L,R\}$，$S_2=\{l,r\}$，$u_1(L,l)=50$，$u_2(L,l)=100-50=50$。两个 player、strategy 有限时，把 $u_1$、$u_2$ 并排写进同一张 matrix，每一格写成 $(u_1,u_2)$，row 是 player 1 的 strategy，column 是 player 2 的。

### 一定不会选的 strategy

最弱的 rationality 假设是：一个 player 不会选一个“不管别人怎么做都更差”的 strategy。

**Definition.** 若存在 $t_i\in S_i$，使对所有 $s_{-i}$ 都有 $u_i(t_i,s_{-i})>u_i(s_i,s_{-i})$，就说 $s_i$ 被 $t_i$ strictly dominate。

拿 MIT 6.254 第 2 讲的一个 game 来用这个定义。它是 prisoner's dilemma 加上第三个选择 Suicide：

| P1 \ P2 | Confess | Don't confess | Suicide |
|---|---|---|---|
| **Confess** | (−2, −2) | (0, −3) | (−2, −10) |
| **Don't confess** | (−3, 0) | (−1, −1) | (0, −10) |
| **Suicide** | (−10, −2) | (−10, 0) | (−10, −10) |

先比较 P1 的 Confess 和 Don't confess。P2 选 Confess 时，P1 选 Confess 得 −2、选 Don't confess 得 −3；P2 选 Don't confess 时是 0 对 −1；P2 选 Suicide 时是 −2 对 0。前两列 Confess 好，第三列 Don't confess 好，所以 Confess 并不 dominate Don't confess。再比较 Confess 和 Suicide：三列分别是 −2 > −10、0 > −10、−2 > −10，Confess strictly dominate Suicide。P2 的 payoff 是对称的，结论一样。

### Iterated elimination

两个人都不会选 Suicide。如果 P1 知道 P2 是 rational 的，他就知道第三列不会出现，可以只看前两列。在前两列里，Confess 对 Don't confess 是 −2 > −3、0 > −1，现在 Confess strictly dominate Don't confess 了。P2 同理。最后只剩 (Confess, Confess)。

::fig[ma4264-iesds] 第 1 轮两人都删掉 Suicide（浅色的 row 和 column）；第 2 轮在剩下的 2×2 里删掉 Don't confess。第 2 轮能删，是因为第 1 轮先去掉了让 Don't confess 占优的那一列。

这个过程叫 iterated elimination of strictly dominated strategies（IESDS）。写成 formula：$S_i^0=S_i$，第 $k$ 轮留下

$$S_i^k=\Big\{s_i\in S_i^{k-1}:\ \text{不存在 } t_i\in S_i^{k-1}\text{ 使 } u_i(t_i,s_{-i})>u_i(s_i,s_{-i})\text{ 对所有 } s_{-i}\in S_{-i}^{k-1}\Big\}$$

一直做到不能再删为止。如果最后每人只剩一个 strategy，这个 game 叫 dominance solvable。

每多一轮，就多用一层知识。第 1 轮只用到“P2 是 rational 的”。第 2 轮 P1 删 Don't confess，用到的是“P1 知道 P2 是 rational 的”。如果还有第 3 轮，就要用到“P2 知道 P1 知道 P2 是 rational 的”。轮数没有上限，所以 IESDS 背后的假设是 rationality 是 common knowledge：每个人都 rational，每个人都知道每个人都 rational，每个人都知道每个人都知道每个人都 rational，一直下去。

这一小节是证明。跳过它只会少掉“为什么可以按任意顺序删”的理由，结论照用。
:::

一次删一个还是一次删一批、先删 P1 的还是先删 P2 的，只要 strategy 有限、每种删法都删到不能再删，最后剩下的 strategy set 都一样。6.254 把它留作 homework，这里补上证明。

设 A、B 是两种删法，A 最后剩下 $F^A=(F_1^A,\dots,F_n^A)$，在 $F^A$ 里已经没有 strictly dominated strategy。证明 B 删掉的每个 strategy 都不在 $F^A$ 里。

沿着 B 的顺序做 induction。设 B 在第 $m$ 步之前删掉的都不在 $F^A$ 里，于是 B 在第 $m$ 步时剩下的 set $C_1,\dots,C_n$ 各自包含 $F^A$ 里对应的 set。B 在第 $m$ 步删掉 $s_i$，是因为某个 $t_i\in C_i$ 对所有 $s_{-i}\in C_{-i}$ 都比 $s_i$ 好；$F^A_{-i}\subseteq C_{-i}$，所以对所有 $s_{-i}\in F^A_{-i}$ 也有

$$u_i(t_i,s_{-i})>u_i(s_i,s_{-i})$$

假设 $s_i\in F^A_i$。若 $t_i\in F^A_i$，那么在 $F^A$ 里 $s_i$ 仍被 $t_i$ strictly dominate，A 还能删，矛盾。若 $t_i\notin F^A_i$，它在 A 的某一步被某个 $t_i'$ 删掉，那一步的 opponent strategy set 也包含 $F^A_{-i}$，所以在 $F^A_{-i}$ 上 $t_i'$ 比 $t_i$ 好，从而比 $s_i$ 好。$t_i'$ 若也不在 $F^A_i$，再找删掉它的那个。这条链上每一步在 $F^A_{-i}$ 上的 payoff 都严格变大，不会回到用过的 strategy，而 $S_i$ 有限，所以链一定停在 $F^A_i$ 里的某个 strategy 上，它在 $F^A_{-i}$ 上 strictly dominate $s_i$，A 还能删，矛盾。所以 $s_i\notin F^A_i$。

于是 B 删掉的都不在 $F^A$ 里，$F^A\subseteq F^B$；把 A、B 对调得 $F^B\subseteq F^A$。∎

### 被 mixed strategy dominate

有时单个 strategy 压不住，几个 strategy 按 probability 混在一起才压得住。6.254 第 3 讲的例子（P2 的 payoff 全是 0，只看 P1 的）：

| P1 | P2 选 Left | P2 选 Right |
|---|---|---|
| **U** | 2 | −1 |
| **M** | 0 | 0 |
| **D** | −1 | 2 |

U 不 dominate M（Right 时 −1 < 0），D 也不 dominate M（Left 时 −1 < 0）。现在让 P1 以 ½ 的 probability 选 U、½ 选 D，这种按 probability 选 strategy 的做法叫 mixed strategy（第 3 站正式定义）。它对 Left 的 expected payoff 是 $\tfrac12\cdot2+\tfrac12\cdot(-1)=\tfrac12$，对 Right 是 $\tfrac12\cdot(-1)+\tfrac12\cdot2=\tfrac12$，两边都大于 M 的 0。所以 M 被 $\tfrac12U+\tfrac12D$ strictly dominate。

::fig[ma4264-mixdom] 横轴是 P1 认为 P2 选 Left 的 probability。U、D 两条 line 各有一段跑到 M 的下面，它们的平均却整条在 M 上方。

图里还能读出另一件事。设 P2 选 Left 的 probability 是 $q$，U 的 expected payoff 是 $2q-(1-q)=3q-1$，D 的是 $-q+2(1-q)=2-3q$。两者中较大的那个在 $q=\tfrac12$ 时最小，等于 ½，所以永远大于 0。不管 P1 怎样猜 P2，M 都不是 best response。一般地，被某个 mixed strategy strictly dominate 的 strategy，在任何 belief 下都不是 best response：对每个 $s_{-i}$ 都成立的 strict inequality，按 belief 的 probability 加权平均以后仍是 strict inequality。所以 IESDS 的每一轮也要检查 mixed strategy 的 dominance，6.254 的定义就是这样写的。

### Weak dominance

**Definition.** 若对所有 $s_{-i}$ 都有 $u_i(t_i,s_{-i})\ge u_i(s_i,s_{-i})$，且至少对一个 $s_{-i}$ 是 strict 的，就说 $s_i$ 被 $t_i$ weakly dominate。

一个重要的例子是 second-price sealed-bid auction：几个人各自写下 bid，出价最高的人得到东西，付的是第二高的 bid。设我的 value 是 $v$，别人 bid 中最高的是 $m$。

- 我 bid $v$：$v>m$ 时赢，得 $v-m>0$；$v<m$ 时输，得 0。
- 我 bid $b>v$：$m<v$ 或 $m>b$ 时结果和 bid $v$ 一样；$v<m<b$ 时我赢了，付 $m$，得 $v-m<0$，而 bid $v$ 在这里得 0。
- 我 bid $b<v$：$m<b$ 或 $m>v$ 时结果一样；$b<m<v$ 时我输了，得 0，而 bid $v$ 在这里得 $v-m>0$。

所以 bid 自己的 value weakly dominate 其他任何 bid（$m$ 恰好等于某个 bid 的平局按规则处理，不改变结论）。第 7 站算 auction 的 revenue 时要用到这一点。

:::wrong Weakly dominated strategy 和 strictly dominated strategy 一样，可以放心地一轮一轮删
删 weakly dominated strategy 时，删的顺序会改变结果。看这个 game（为这一页构造的）：

| P1 \ P2 | L | R |
|---|---|---|
| **T** | (1, 1) | (0, 0) |
| **M** | (1, 1) | (2, 1) |
| **B** | (0, 0) | (2, 1) |

先删 T（被 M weakly dominate：1 ≥ 1，2 > 0）。剩下 M、B 两行，P2 选 L 得 1、0，选 R 得 1、1，L 被 R weakly dominate，删掉 L。剩下 R 这一列，M、B 都给 P1 2，结果是 payoff (2, 1)。

换个顺序，先删 B（被 M weakly dominate：1 > 0，2 ≥ 2）。剩下 T、M 两行，P2 选 L 得 1、1，选 R 得 0、1，R 被 L weakly dominate，删掉 R。剩下 L 这一列，结果是 payoff (1, 1)。

同一个 game，两种顺序，两个结果。上一小节的证明用到“在更小的 opponent strategy set 上 inequality 仍然 strict”；weak dominance 里那个 strict 的位置可能已经被删掉了，证明就断在这里。另外 weakly dominated strategy 可以出现在 equilibrium 里：6.254 第 3 讲指出，second-price auction 中 value 最高的人 bid 自己的 value、其他人都 bid 0 也是一个 Nash equilibrium（第 2 站的定义），其他人用的都是 weakly dominated 的 bid。
:::

### Dominance 用完了，问题还在

6.254 第 2 讲的 partnership game：两人合伙，各自选 Work hard 或 Shirk。

| P1 \ P2 | Work hard | Shirk |
|---|---|---|
| **Work hard** | (2, 2) | (−1, 1) |
| **Shirk** | (1, −1) | (0, 0) |

P2 选 Work hard 时 P1 选 Work hard 好（2 > 1），P2 选 Shirk 时 P1 选 Shirk 好（0 > −1）。没有哪个 strategy dominate 另一个，IESDS 一个都删不掉。Dominance 只能排除“无论如何都不会选”的东西；剩下的 strategy 好不好，取决于对方选什么。需要一个把“对方选什么”和“我选什么”同时定下来的概念。

### Best response 与 Nash equilibrium

**Definition.** 给定别人的选择 $s_{-i}$，player $i$ 的 best response 是让自己 payoff 最大的那些 strategy：

$$B_i(s_{-i})=\arg\max_{s_i\in S_i}u_i(s_i,s_{-i})$$

**Definition.** Strategy profile $s^*$ 是 Nash equilibrium，如果每个人的选择都是对别人选择的 best response：

$$u_i(s_i^*,s_{-i}^*)\ge u_i(s_i,s_{-i}^*)\qquad\text{对所有 } i\text{ 和所有 } s_i\in S_i$$

也就是对每个 $i$ 都有 $s_i^*\in B_i(s_{-i}^*)$。课程（tutorial 和 cheatsheet）把 best response 记作 $R_i(s_{-i})$，这一页沿用 $B_i$。把所有人的 best response 拼成一个 map $B(s)=B_1(s_{-1})\times\cdots\times B_n(s_{-n})$，Nash equilibrium 就是它的 fixed point：$s^*\in B(s^*)$。

这个定义只要求“没有人能靠单方面改变而变好”。它不要求结果对大家都好，也不要求每个人的选择在对方怎样做时都好。

拿 partnership game 逐格检查：

- (Work hard, Work hard)：P1 改成 Shirk，从 2 变成 1；P2 同理。没人想动，是 Nash equilibrium。
- (Shirk, Shirk)：任何一方改成 Work hard，从 0 变成 −1。也是。
- (Work hard, Shirk)：P1 得 −1，改成 Shirk 得 0，P1 想动，不是。(Shirk, Work hard) 同理不是。

两个 equilibrium，理论本身不说会落在哪一个。[PS1101E 第 8 站](../courses/PS1101E.html#ir)的 stag hunt 是同一种结构。

开头的 tennis 也逐格检查一下：(L, l) 时 Venus 想改打 R（90 > 50）；(R, l) 时 Serena 想改 lean r（她的胜率 80 > 10）；(R, r) 时 Venus 想改打 L（80 > 20）；(L, r) 时 Serena 想改 lean l（50 > 20）。四格都有人想动，没有 Nash equilibrium，这是第 3 站的问题。

### Nash equilibrium 和 dominance 对得上

:::skip
两个短证明。跳过只会少掉“第 1 站的结论和这一站的概念相容”的理由。
:::

**Claim 1.** Nash equilibrium 里的 strategy 不会在 IESDS 中被删掉。

**Proof.** 设 $s^*$ 是 Nash equilibrium，并假设它的某个 component 被删了。取最早删掉某个 $s_i^*$ 的那一轮 $k$。那一轮有 $t_i\in S_i^{k-1}$ 对所有 $s_{-i}\in S_{-i}^{k-1}$ 都比 $s_i^*$ 好。在这之前 $s^*$ 的 component 一个都没被删，所以 $s_{-i}^*\in S_{-i}^{k-1}$，于是 $u_i(t_i,s_{-i}^*)>u_i(s_i^*,s_{-i}^*)$，与 Nash equilibrium 矛盾。∎

**Claim 2.** Strategy 有限时，如果 IESDS 最后只剩一个 profile $s^*$，它就是唯一的 Nash equilibrium。

**Proof.** 唯一性由 Claim 1 得到：任何 Nash equilibrium 都活到最后，而最后只有 $s^*$。再证 $s^*$ 是 Nash equilibrium。假设某个 $t_i$ 使 $u_i(t_i,s_{-i}^*)>u_i(s^*)$。$t_i\ne s_i^*$，所以它在某一轮被某个 $t_i'$ dominate 而删掉，那一轮的 opponent strategy set 包含活到最后的 $s_{-i}^*$，所以 $u_i(t_i',s_{-i}^*)>u_i(t_i,s_{-i}^*)$。$t_i'$ 若也被删过，再找删掉它的那个。和第 1 站的证明一样，这条链在 $s_{-i}^*$ 上的 payoff 严格上升，最后停在唯一没被删的 $s_i^*$，于是 $u_i(s_i^*,s_{-i}^*)>u_i(t_i,s_{-i}^*)>u_i(s^*)$，矛盾。∎

第 1 站的 3×3 game 只剩 (Confess, Confess)，按 Claim 2 它就是唯一的 Nash equilibrium。

### Strategy 是连续的：Cournot duopoly

两家 firm 生产同一种东西，同时决定 output $q_1,q_2\in[0,1]$。Price 由总 output 决定，$P=2-q_1-q_2$，每单位 cost 是 1，这是 6.254 第 2 讲用的那组数。Firm 1 的 profit 是

$$u_1(q_1,q_2)=q_1(2-q_1-q_2)-q_1=q_1(1-q_1-q_2)$$

Strategy 有无穷多个，不能逐格检查，但 best response 可以直接求。固定 $q_2$，$u_1$ 是 $q_1$ 的 quadratic function，二次项 coefficient 是 −1，开口向下，derivative 为 0 的点就是最大值点：

$$\frac{\partial u_1}{\partial q_1}=1-2q_1-q_2=0\quad\Longrightarrow\quad B_1(q_2)=\frac{1-q_2}{2}$$

对称地，$B_2(q_1)=\dfrac{1-q_1}{2}$。Nash equilibrium 要求两式同时成立。把第二式代进第一式：

$$q_1=\frac{1-\frac{1-q_1}{2}}{2}=\frac{1+q_1}{4}\quad\Longrightarrow\quad4q_1=1+q_1\quad\Longrightarrow\quad q_1=\frac13$$

代回得 $q_2=\frac13$。Price 是 $2-\frac23=\frac43$，每单位赚 $\frac13$，每家 profit $\frac13\cdot\frac13=\frac19$。

:::wrong 两家都少生产一点对双方都更好，所以 rational 的 firm 会停在那里
两家合计的 profit 是 $Q(1-Q)$，$Q=q_1+q_2$，在 $Q=\frac12$ 时最大。各产 $\frac14$，price $\frac32$，每家 profit $\frac14\cdot\frac12=\frac18$，比 equilibrium 的 $\frac19$ 多。可是它不是 equilibrium。对方产 $\frac14$ 时，我的 best response 是 $B_1(\tfrac14)=\frac38$，profit $\frac38\left(1-\frac38-\frac14\right)=\frac38\cdot\frac38=\frac{9}{64}\approx0.141$，比守约的 $\frac18=0.125$ 多。两家都这样想，就回到 $(\frac13,\frac13)$。这和 [EC1101E 第 4 站](../courses/EC1101E.html#firm)里两家 firm 守不住 monopoly output 的 payoff table 是同一个 prisoner's dilemma 结构，只是这里 strategy 是连续的。
:::

### Cournot 用 dominance 也能解出来

这个 game 恰好是 dominance solvable，6.254 第 2 讲给出了前两轮。关键在于：固定 $q_2$ 时，$u_1$ 是开口向下的 parabola，顶点在 $B_1(q_2)$，离顶点越远越差。

- **第 1 轮。** $q_2\in[0,1]$，所以 $B_1(q_2)\in[0,\tfrac12]$。任何 $q_1>\tfrac12$ 都在每个可能的顶点右边，而 $\tfrac12$ 夹在顶点和 $q_1$ 之间，离顶点更近，所以 $q_1$ 被 $\tfrac12$ strictly dominate。剩下 $[0,\tfrac12]$。
- **第 2 轮。** 现在 $q_2\in[0,\tfrac12]$，$B_1(q_2)\in[\tfrac14,\tfrac12]$。同样的理由，任何 $q_1<\tfrac14$ 被 $\tfrac14$ strictly dominate。剩下 $[\tfrac14,\tfrac12]$。
- **一般地，** 对方在 $[a,b]$ 里，自己就只剩 $\left[\frac{1-b}{2},\frac{1-a}{2}\right]$，interval 的长度每轮减半。

| 轮 | 剩下的 interval | 长度 |
|---|---|---|
| 1 | $[0,\ 1/2]$ | 1/2 |
| 2 | $[1/4,\ 1/2]$ | 1/4 |
| 3 | $[1/4,\ 3/8]$ | 1/8 |
| 4 | $[5/16,\ 3/8]$ | 1/16 |
| 5 | $[5/16,\ 11/32]$ | 1/32 |

Interval 缩向 $\frac13$，和上面解出的 equilibrium 一致。

### Best-response dynamics

换一个角度看 equilibrium 怎样出现。设 Firm 1 原来独占市场，按 monopoly output $q_1=B_1(0)=\frac12$ 生产。Firm 2 进来，对 $\frac12$ 做 best response，产 $\frac14$；Firm 1 再对 $\frac14$ 做 best response，产 $\frac38$；两家这样轮流调整。

::fig[ma4264-brdyn] 两家 firm 轮流对对方当前的 output 做 best response。左边是两家的 output，右边是同一个过程在 $(q_1,q_2)$ plane 上：竖着走一步是 Firm 2 调整，落到它的 best response line 上；横着走一步是 Firm 1 调整。折线来回收向两条 line 的交点。

为什么 converge，算一下离 $\frac13$ 的距离。设对方的 output 是 $\frac13+e$：

$$B\!\left(\tfrac13+e\right)=\frac{1-\frac13-e}{2}=\frac13-\frac{e}{2}$$

每调整一次，距离乘 $-\frac12$：起点 $\frac12$ 离 $\frac13$ 是 $\frac16$，接着 $\frac14-\frac13=-\frac1{12}$，$\frac38-\frac13=\frac1{24}$，依此类推。原因是 best response line 的 slope 是 $-\frac12$，absolute value 小于 1，这个 map 是 contraction。上面那张 interval 表的端点和这串数完全相同（$\frac12,\frac14,\frac38,\frac5{16},\frac{11}{32}$），因为 interval 的端点也按同一个 map $q\mapsto\frac{1-q}{2}$ 更新。

:::edge Best-response dynamics 停下来的地方一定是 Nash equilibrium，但它不一定会停
如果两家的 output 都 converge，比如 Firm 1 的到 $\bar q_1$、Firm 2 的到 $\bar q_2$，而 best response 是 continuous function，在 $q_2^{(k+1)}=B_2(q_1^{(k)})$ 两边取 limit 得 $\bar q_2=B_2(\bar q_1)$，同理 $\bar q_1=B_1(\bar q_2)$，limit 是 fixed point。反过来，若 best response line 的 slope 的 absolute value 大于 1，同样的推导给出每步距离乘一个 absolute value 大于 1 的数，序列会远离 equilibrium，尽管 equilibrium 存在。Strategy 有限时还有更糟的情形：第 3 站的 matching pennies 里，best response 绕着四个格子转圈，永远停不下来。
:::

### $n$ 家 firm：Cournot 怎样走向 competition

NUS Tutorial 2 把 duopoly 推广到 $n$ 家 firm，用课程的一般记号：$P=a-Q$，$Q=q_1+\cdots+q_n$，每单位 cost $c<a$。上面的数是 $a=2$、$c=1$。记 $Q_{-i}$ 为除 $i$ 以外各家 output 之和，firm $i$ 的 profit 是

$$\pi_i=q_i\,(a-q_i-Q_{-i})-c\,q_i=q_i\,(a-c-q_i-Q_{-i})$$

和 duopoly 一样对 $q_i$ 求 derivative：

$$a-c-2q_i-Q_{-i}=0\quad\Longrightarrow\quad B_i(Q_{-i})=\frac{a-c-Q_{-i}}{2}\qquad(Q_{-i}<a-c\text{ 时；否则 }B_i=0)$$

先看 equilibrium 里有没有不生产的 firm。若某个 $q_i=0$，它的 best response 是 0 说明 $Q_{-i}\ge a-c$，于是 $Q\ge a-c$。对任何一家生产的 firm $j$，first-order condition $2q_j+Q_{-j}=a-c$ 可以写成 $q_j+Q=a-c$，即 $q_j=a-c-Q\le0$，与它生产矛盾；那就没有 firm 生产，$Q=0<a-c$，又矛盾。所以每家都生产，每家都满足

$$q_i=a-c-Q$$

右边对所有 $i$ 相同，所以 equilibrium 一定对称，$q_i=q$。代回 $q=a-c-nq$：

$$q=\frac{a-c}{n+1},\qquad Q=\frac{n(a-c)}{n+1},\qquad P=a-Q=\frac{a+nc}{n+1},\qquad P-c=\frac{a-c}{n+1}$$

取 $a=2$、$c=1$：

| $n$ | 每家 output | price |
|---|---|---|
| 1 | 1/2 | 3/2 |
| 2 | 1/3 | 4/3 |
| 3 | 1/4 | 5/4 |
| 10 | 1/11 | 12/11 ≈ 1.091 |

$n=1$ 是 monopoly，$n=2$ 就是上面的 $\frac13$。Firm 越多，price 超出 cost 的部分 $\frac{a-c}{n+1}$ 越小，$n\to\infty$ 时 price 趋于 cost $c$，total output 趋于 $a-c$，这是 perfect competition 的结果。

### 改为定 price：Bertrand

Cournot 的 firm 选 output，由 market 定 price。Bertrand 的 model 让 firm 直接定 price $p_1,p_2$，cheatsheet 里有两种。

**Differentiated products。** 两家的东西不完全一样，firm $i$ 卖出 $q_i=a-p_i+bp_j$，$b>0$ 表示对方涨价会把一部分顾客推到我这里。Profit 是

$$\pi_i=(a-p_i+bp_j)(p_i-c)$$

固定 $p_j$，对 $p_i$ 求 derivative（product rule）：

$$-(p_i-c)+(a-p_i+bp_j)=0\quad\Longrightarrow\quad B_i(p_j)=\frac{a+c+bp_j}{2}$$

Best response 的 slope 是 $\frac b2>0$：对方涨价，我也涨。Cournot 的 slope 是 $-\frac12$，对方多产我就少产。两式对称，equilibrium 里 $p_1=p_2=p$：

$$p=\frac{a+c+bp}{2}\quad\Longrightarrow\quad(2-b)\,p=a+c\quad\Longrightarrow\quad p^*=\frac{a+c}{2-b}$$

这要求 $b<2$。取 $a=2$、$c=1$、$b=\frac12$：$B_i(p_j)=\frac32+\frac{p_j}{4}$，$p^*=\frac{3}{3/2}=2$，每家卖 $2-2+\frac12\cdot2=1$，profit $1\cdot(2-1)=1$。

**Homogeneous products。** 两家的东西完全一样，顾客只买便宜的那家；一样便宜就各卖一半。Demand 是 $a-p$：

$$q_i=\begin{cases}a-p_i,&p_i<p_j\\[2pt]\dfrac{a-p_i}{2},&p_i=p_j\\[4pt]0,&p_i>p_j\end{cases}\qquad\pi_i=(p_i-c)\,q_i$$

独占 market 时 profit $(p-c)(a-p)$ 在 $p_m=\frac{a+c}{2}$ 最大，这是 monopoly price；在 $[c,p_m]$ 上它随 $p$ 增大。按 $p_j$ 分情形求 firm $i$ 的 best response：

- $p_j>p_m$：定 $p_m$，独占 market 并拿到 monopoly profit。$B_i(p_j)=\{p_m\}$。
- $c<p_j\le p_m$：定价略低于 $p_j$ 就独占 market，profit 接近 $(p_j-c)(a-p_j)$；恰好定 $p_j$ 只得一半；定价越接近 $p_j$ 越好，却又不能等于 $p_j$。所以 best response 不存在。
- $p_j=c$：定 $c$ 或更高都得 0，定得更低亏钱。$B_i(c)=[c,a]$（高于 $a$ 也是 0，cheatsheet 写到 $a$ 为止）。
- $p_j<c$：任何高于 $p_j$ 的 price 都卖不出去，得 0；不高于 $p_j$ 就亏，所以 best response 是所有高于 $p_j$ 的 price。

::fig[ma4264-bertrand] 对方定 $p_j=1.4$ 时 firm $i$ 的 profit（$a=2$、$c=1$）。$p_i$ 从左边逼近 1.4，profit 逼近 0.24；恰好等于 1.4 时掉到一半，0.12；高过 1.4 就是 0。最高点够不着，所以没有 best response。

图里的数：$p_i=1.39$ 时 $0.39\times0.61=0.2379$，$p_i=1.399$ 时 $0.399\times0.601=0.239799$，$p_i=1.4$ 时 $\frac12\times0.4\times0.6=0.12$。

Nash equilibrium 要求两家的 price 互为 best response。$(c,c)$ 是：两家都得 0，任何一家涨价卖不出去仍是 0，降价就亏。其他 profile 都不是。不妨设 $p_1\le p_2$（price 都低于 $a$），分三种：

- $p_1<c$：firm 1 有顾客，每卖一件亏 $c-p_1$。改定一个高于 $p_2$ 的 price，卖不出去，profit 0，比亏钱好。
- $p_1=c<p_2$：firm 1 得 0。改定 $c$ 与 $p_2$ 之间的某个 price，独占 market，每件赚正的钱。
- $c<p_1\le p_2$：firm 2 至多得到 $\frac12(p_1-c)(a-p_1)$（相等时分一半，更贵时是 0）。若 $p_1\le p_m$，它改定略低于 $p_1$ 的 price，profit 接近 $(p_1-c)(a-p_1)$，超过一半；若 $p_1>p_m$，它改定 $p_m$，拿到 monopoly profit。

所以唯一的 Nash equilibrium 是 $(c,c)$，profit 为 0。

:::wrong 只有两家 firm 时，price 一定像 Cournot 那样高于 cost
Cournot 的两家 firm（$a=2$、$c=1$）定出 price $\frac43$，profit 各 $\frac19$。同样的 demand 和 cost，换成 homogeneous 的 Bertrand，price 一路被压到 $c=1$，profit 为 0：只要 price 高于 cost，就有一家想略低于对方把 market 全拿走。两家 firm 就足以得到 perfect competition 的 price。Firm 数目不能单独决定 price，竞争的 variable 是 output 还是 price、东西有没有差别，同样要紧；differentiated 的 Bertrand 里 $b=\frac12$ 时 price 是 2，又高于 cost。
:::

## [mixed] Mixed strategy、indifference 与 existence

:::skip
能用 indifference condition 解出 2×2 game 的 mixed equilibrium，能说出“自己的 mix 由对方的 payoff 决定”是什么意思，就可以去第 4 站。existence theorem 的证明可以按小节开头的提示跳过。
:::

### 没有 pure equilibrium 的 game

6.254 第 2、3 讲的 matching pennies：两人同时亮出硬币的一面，相同则 P2 赢 1，不同则 P1 赢 1。

::fig[ma4264-cycle] 每一格都有一个人想换，高亮的格子沿着 best response 一格一格转圈。

每一格都有人想动，所以第 2 站意义下的 Nash equilibrium 不存在，开头的 tennis 也是如此。可是 matching pennies 该怎样玩，其实人人都知道：随机地出，让对方猜不到。要把随机本身变成 equilibrium 的一部分。

### Mixed strategy

**Definition.** Player $i$ 的 mixed strategy $\sigma_i$ 是 $S_i$ 上的一个 probability distribution，$\sigma_i(s_i)$ 是选 $s_i$ 的 probability。各人独立地随机。把 probability 1 放在一个 strategy 上的叫 pure strategy。

Payoff 取 expectation。Tennis 里设 Venus 打 L 的 probability 是 $P$，Serena lean l 的 probability 是 $Q$。Venus 的 expected 胜率是

$$u_1(P,Q)=50PQ+80P(1-Q)+90(1-P)Q+20(1-P)(1-Q)$$

按 $P$ 合并：

$$u_1(P,Q)=P\underbrace{\big[50Q+80(1-Q)\big]}_{\text{打 L 的胜率}}+(1-P)\underbrace{\big[90Q+20(1-Q)\big]}_{\text{打 R 的胜率}}$$

Mixed strategy 的 payoff 是各个 pure strategy 的 payoff 按自己的 probability 加权平均。这一站的所有结论都从这句话出来。

**Definition.** $\sigma^*$ 是 mixed strategy Nash equilibrium，如果对所有 $i$ 和所有 mixed strategy $\sigma_i$，都有 $u_i(\sigma_i^*,\sigma_{-i}^*)\ge u_i(\sigma_i,\sigma_{-i}^*)$。

### Indifference principle

**Proposition.** $\sigma^*$ 是 Nash equilibrium，当且仅当对每个 $i$：$\sigma_i^*$ 给了 positive probability 的每个 pure strategy，都是对 $\sigma_{-i}^*$ 的 best response。

**Proof.** 记 $m_i=\max_{s_i\in S_i}u_i(s_i,\sigma^*_{-i})$。对任意 $\sigma_i$，

$$u_i(\sigma_i,\sigma^*_{-i})=\sum_{s_i}\sigma_i(s_i)\,u_i(s_i,\sigma^*_{-i})\le\sum_{s_i}\sigma_i(s_i)\,m_i=m_i$$

等号成立当且仅当 $\sigma_i$ 只在达到 $m_i$ 的那些 $s_i$ 上放 probability。

（⇒）若 $\sigma^*$ 是 equilibrium，$u_i(\sigma^*)$ 不小于任何 pure strategy 的 payoff，特别地不小于 $m_i$；由上式它又不大于 $m_i$，所以等于 $m_i$，于是 $\sigma_i^*$ 只放在达到 $m_i$ 的 strategy 上。

（⇐）若 $\sigma_i^*$ 只放在达到 $m_i$ 的 strategy 上，则 $u_i(\sigma^*)=m_i$，而任何 $\sigma_i$ 的 payoff 都不超过 $m_i$。∎

两个推论。第一，检查 equilibrium 只要对 pure strategy 的 deviation 检查。第二，一个 player 在 equilibrium 里真正 mix 的那几个 strategy，payoff 必须完全相等：他对它们 indifferent。

第三个推论是第 2 站 Claim 1 的 mixed 版本，NUS Tutorial 2 第 6 题：**mixed equilibrium 里以 positive probability 出现的 pure strategy，不会在 IESDS 中被删掉。** 所以解 mixed equilibrium 之前可以先做 IESDS，删掉的 strategy 在任何 equilibrium 里 probability 都是 0。证明：设 $\sigma^*$ 是 equilibrium，取 IESDS 里最早删掉某个 support 中 strategy 的那一轮 $k$，删掉的是 $s_i$，删它的是 $t_i$（pure 或 mixed 都可以）。在这之前所有 support 里的 strategy 都还在，所以 $\sigma^*_{-i}$ 只在 $S^{k-1}_{-i}$ 上放 probability；$t_i$ 对 $S^{k-1}_{-i}$ 里的每个 $s_{-i}$ 都严格比 $s_i$ 好，按 $\sigma^*_{-i}$ 的 probability 加权平均后仍严格更好：$u_i(t_i,\sigma^*_{-i})>u_i(s_i,\sigma^*_{-i})$。可是 $s_i$ 在 $\sigma_i^*$ 的 support 里，按 proposition 它是 best response，矛盾。∎

### 解 tennis

Venus 要 mix，打 L 和打 R 的胜率必须相等，这给出一个只含 $Q$ 的 equation：

$$50Q+80(1-Q)=90Q+20(1-Q)\quad\Longrightarrow\quad80-30Q=20+70Q\quad\Longrightarrow\quad Q=0.6$$

Serena 要 mix，lean l 和 lean r 给她的胜率必须相等。她的胜率是 100 减 Venus 的：lean l 时 Venus 打 L 她赢 50、打 R 她赢 10；lean r 时分别是 20、80。

$$50P+10(1-P)=20P+80(1-P)\quad\Longrightarrow\quad10+40P=80-60P\quad\Longrightarrow\quad P=0.7$$

验算。给定 $Q=0.6$，Venus 打 L 得 $50\times0.6+80\times0.4=62$，打 R 得 $90\times0.6+20\times0.4=62$。给定 $P=0.7$，Serena lean l 得 $50\times0.7+10\times0.3=38$，lean r 得 $20\times0.7+80\times0.3=38$。两人各自 indifferent，按 proposition 这是 equilibrium，Venus 的胜率是 62%。

::fig[ma4264-tennis] 动的是 Serena 的 $Q$，Venus 的两条 line 跟着读数。只有 $Q=0.6$ 时两条 line 相交，打哪边都是 62%；$Q$ 稍大，打 R 严格更好（彩色箭头），$Q$ 稍小，打 L 严格更好。Serena 的 $Q$ 必须恰好停在让 Venus indifferent 的位置。

注意两个 equation 的来历：$Q$ 是从 Venus 的 payoff 解出来的，$P$ 是从 Serena 的 payoff 解出来的。每个人的 mix 由对方的 payoff 决定。

:::wrong 反正 Venus 在 equilibrium 里打 L、打 R 一样好，她怎么 mix 都行
给定 Serena 的 $Q=0.6$，Venus 确实怎样 mix 都得 62。但 equilibrium 要求双方同时 best response。设 Venus 改成 $P=0.8$：Serena lean l 的胜率变成 $50\times0.8+10\times0.2=42$，lean r 是 $20\times0.8+80\times0.2=32$，Serena 会一直 lean l，$Q=1$。而 $Q=1$ 时 Venus 打 L 赢 50、打 R 赢 90，她又该全打 R。只有 $P=0.7$ 能让 Serena 也 indifferent，从而愿意停在 $Q=0.6$。Venus 的 probability 不是为她自己选的，它的作用是让对方无从利用。
:::

### Comparative statics：谁的 payoff 变，谁的 mix 动

Polak 在第 9 讲接着问：Serena 练好了 backhand，(L, l) 这一格 Venus 的胜率从 50 降到 30，会怎样？直觉是 Serena 现在 lean l 更有利，她会更多地 lean l。

按 indifference 重新解。Serena 的 $Q$ 由 Venus 的 indifference 决定：

$$30Q+80(1-Q)=90Q+20(1-Q)\quad\Longrightarrow\quad80-50Q=20+70Q\quad\Longrightarrow\quad Q=0.5$$

Venus 的 $P$ 由 Serena 的 indifference 决定，Serena 在 (L, l) 的胜率从 50 变成 70：

$$70P+10(1-P)=20P+80(1-P)\quad\Longrightarrow\quad10+60P=80-60P\quad\Longrightarrow\quad P=\frac{7}{12}\approx0.583$$

Serena lean l 的 probability 从 0.6 降到 0.5，和直觉相反。Backhand 变强有两层效果：Serena 守 l 时更有利，这让她想多守 l；Venus 因此少打 L（从 0.7 降到 0.583），这又让 Serena 守 l 的必要变小。在 equilibrium 里第二层压过了第一层。Venus 的胜率降到 $80-50\times0.5=55$（打 R 也是 $20+70\times0.5=55$），练 backhand 对 Serena 有用，只是好处不是通过“多守 backhand”得到的。

### Existence：为什么总有 equilibrium

:::skip
这一小节讲 Nash 的 existence theorem 为什么成立。跳过它不影响后面任何计算，会少掉“为什么非要允许 mixed strategy 不可”的理由。
:::

先在 2×2 的 game 里看清楚。6.254 第 3 讲和 Osborne 第 4.3 节都用 battle of the sexes：两人想一起出去，P1 更想看 Ballet，P2 更想看 Football，分开走两人都没意思。

| P1 \ P2 | Ballet | Football |
|---|---|---|
| **Ballet** | (2, 1) | (0, 0) |
| **Football** | (0, 0) | (1, 2) |

设 $p$、$q$ 是 P1、P2 选 Ballet 的 probability。P1 选 Ballet 得 $2q$，选 Football 得 $1-q$，所以 $q>\frac13$ 时 best response 是 $p=1$，$q<\frac13$ 时是 $p=0$，$q=\frac13$ 时任何 $p\in[0,1]$ 都是。P2 选 Ballet 得 $p$，选 Football 得 $2(1-p)$，所以 $p>\frac23$ 时 $q=1$，$p<\frac23$ 时 $q=0$，$p=\frac23$ 时任何 $q$ 都是。

::fig[ma4264-bos] 两个 best response 画在同一个 unit square 里。P1 的（彩线）是从下边走到上边的一条连通折线，P2 的（虚线）是从左边走到右边的一条连通折线，两者必然相交。

交点有三个：$(0,0)$ 和 $(1,1)$ 是两个 pure equilibrium，$(\frac23,\frac13)$ 是 mixed 的。在 mixed equilibrium 里，P1 选 Ballet 得 $2\cdot\frac13=\frac23$、选 Football 得 $1-\frac13=\frac23$；P2 选 Ballet 得 $\frac23$、选 Football 得 $2\cdot\frac13=\frac23$。两人都只得 $\frac23$，比任何一个 pure equilibrium 都差，因为有 $\frac23\cdot\frac23+\frac13\cdot\frac13=\frac59$ 的 probability 走散。

图里那一竖段和一横段，就是 mixed strategy 补上的东西。如果只许 pure strategy，P1 的 best response 在 $q=\frac13$ 处从 $p=0$ 直接跳到 $p=1$，中间是空的；matching pennies 里正是这种跳跃让两条 best response 错开、没有交点。允许 mix 以后，indifferent 的地方 best response 是整段 $[0,1]$，折线连起来了。

一般的情形是 Nash（1950）证明的：

**Theorem.** 每个 finite game（player 和 strategy 都有限）都至少有一个 mixed strategy Nash equilibrium。

6.254 第 5 讲的证明用 Kakutani 的 fixed point theorem：若 $A$ 是 Euclidean space 里 nonempty、compact、convex 的 set，correspondence $f:A\rightrightarrows A$ 满足 (a) 每个 $f(x)$ nonempty，(b) 每个 $f(x)$ convex，(c) graph $\{(x,y):y\in f(x)\}$ 是 closed set，那么存在 $x^*$ 使 $x^*\in f(x^*)$。

取 $A=\Sigma=\Delta(S_1)\times\cdots\times\Delta(S_n)$，即所有 mixed profile 构成的 set；取 $f=B$，$B(\sigma)=B_1(\sigma_{-1})\times\cdots\times B_n(\sigma_{-n})$。$B$ 的 fixed point 就是 Nash equilibrium。逐条检查：

- **$\Sigma$ nonempty、compact、convex。** 每个 $\Delta(S_i)=\{x\ge0:\sum_kx_k=1\}$ 是 closed 且 bounded 的 simplex，也是 convex 的；有限个这样的 set 的 product 仍然如此。
- **(a) nonempty。** $u_i(\cdot,\sigma_{-i})$ 对自己的 $\sigma_i$ 是 linear 的（上面的加权平均），所以 continuous；continuous function 在 compact set 上取得 maximum。
- **(b) convex。** 若 $\tau_i$、$\tau_i'$ 都达到 maximum $m_i$，对 $\lambda\in[0,1]$，$u_i(\lambda\tau_i+(1-\lambda)\tau_i',\sigma_{-i})=\lambda m_i+(1-\lambda)m_i=m_i$，也是 best response。这一步靠的是 linear；pure strategy 构成的 set 本身连 convex 都谈不上。
- **(c) closed graph。** 设 $\sigma^k\to\sigma$，$\tau^k\to\tau$，且每个 $\tau_i^k\in B_i(\sigma_{-i}^k)$。对任意 $\sigma_i'$，$u_i(\tau_i^k,\sigma_{-i}^k)\ge u_i(\sigma_i',\sigma_{-i}^k)$。$u_i$ 是所有 probability 的 polynomial，对整个 profile continuous，两边取 limit 得 $u_i(\tau_i,\sigma_{-i})\ge u_i(\sigma_i',\sigma_{-i})$。所以 $\tau_i\in B_i(\sigma_{-i})$，limit 仍在 graph 里。

Kakutani 给出 $\sigma^*\in B(\sigma^*)$，即每个 $\sigma_i^*$ 都是对 $\sigma_{-i}^*$ 的 best response。∎

这个证明只说 equilibrium 存在，不说怎样找。2×2 的 game 用 indifference 就够；第 4 站会看到 zero-sum 的情形可以写成一个 linear program。

:::back
被 mixed strategy dominate 的概念在[第 1 站](#dom)已经用过；“best response 的 fixed point”是[第 2 站](#ne)的定义。
:::

Tennis 的四个数、两个 indifference equation、$P=0.7$、$Q=0.6$、62 与 38 的验算，以及 Serena 练 backhand 后 (L, l) 从 50 变 30、$Q$ 降到 0.5、$P$ 降到 $\frac7{12}$ 的 comparative statics 和“直接效果被 strategic 效果压过”的讲法，来自 [Yale ECON 159 第 9 讲](https://oyc.yale.edu/node/1000)的逐字稿后半段。Matching pennies、battle of the sexes 的数和 indifference principle 的陈述来自 [6.254 第 3 讲](https://ocw.mit.edu/courses/6-254-game-theory-with-engineering-applications-spring-2010/resources/mit6_254s10_lec03/)；proposition 的证明对照了 Osborne [第 4.3 节](https://www.economics.utoronto.ca/osborne/igt/igtChapter4.pdf)的 Proposition 116.2，battle of the sexes 的 best response function 和三个交点也在那一节。Kakutani 的陈述和四条检查来自 [6.254 第 5 讲](https://ocw.mit.edu/courses/6-254-game-theory-with-engineering-applications-spring-2010/resources/mit6_254s10_lec05/)。“Support 里的 strategy 活过 IESDS”来自 NUS [Tutorial 2 solution](https://www.xiangsun.org/wp-content/uploads/2013/02/MA4264-Tut2sol.pdf) 第 6 题，那里的证明是把 $s_i$ 的 probability 挪给 $t_i$、得到更好的 mixed strategy，这里改用 proposition 直接推出矛盾；同一份 solution 的 review 写了 Nash 的 theorem 和 expected payoff 的 formula，和这一站的写法一致。$P=0.8$ 的反例、走散的 probability $\frac59$、2×2 里“两条连通折线必然相交”的讲法是为这一页写的。

## [zerosum] Zero-sum game 与 minimax

:::skip

:::

:::note 这一站和读到的 NUS 材料
读到的 NUS 材料里，zero-sum game 只出现在 Tutorial 1 第 7 题：用 saddle point 的写法刻画 zero-sum game 的 Nash equilibrium，并证明 equilibrium 可以互换、payoff 都相等（本站最后的 edge）。LP、dual 和 minimax theorem 没有出现在 tutorial 和 Spring 2023 的 cheatsheet 里。课程的先修要求里有 MA3252、MA3236 这类 LP 课，这一站按标准讲法写，当学期是否讲以 Canvas 为准。

### 一方之所得就是另一方之所失

Tennis 里每一格两人的胜率加起来都是 100，这种 game 叫 constant-sum。每格两人各减 50，payoff 之和变成 0，而 strategic 结构完全不变：每个人的 payoff 只是平移了一个常数，best response 不变。所以 constant-sum 和 zero-sum 可以当成一回事。Zero-sum game 只需要一个 matrix $A$：$a_{ij}$ 是 row player 选 $i$、column player 选 $j$ 时 row player 的 payoff，column player 的 payoff 是 $-a_{ij}$。Row player 要它大，column player 要它小。

对抗性的 game 有一个自然的问题：如果对方能看穿我，我至少能保证多少？

### 先动的一方被看穿

先只用 pure strategy。Venus 先选、Serena 看到再选：Venus 打 L，Serena 会 lean l，Venus 得 50；打 R，Serena 会 lean r，Venus 得 20。Venus 能保证的是 $\max(50,20)=50$，叫 maxmin value：

$$\underline v=\max_i\min_j a_{ij}$$

反过来，Serena 先选、Venus 看到再选：Serena lean l，Venus 打 R 得 90；lean r，Venus 打 L 得 80。Serena 能把 Venus 压到 $\min(90,80)=80$，叫 minmax value：

$$\overline v=\min_j\max_i a_{ij}$$

50 和 80 差了 30 个百分点，后动的一方占了大便宜。

现在让先动的一方公布的是 mixed strategy，具体打哪边仍由随机决定。Venus 公布 $P$ 以后，Serena 的两个 pure strategy 给 Venus 的胜率是

$$\text{lean l：}\ 50P+90(1-P)=90-40P,\qquad\text{lean r：}\ 80P+20(1-P)=20+60P$$

面对一个固定的 mix，Serena 不需要 mix：她的 mix 的 payoff 是她的 pure strategy 的加权平均，不会比其中最低的那个更低。所以 Venus 能保证的是 $\min(90-40P,\ 20+60P)$，图上是两条 line 的 lower envelope。它在两条 line 相交处最高：$90-40P=20+60P$，$P=0.7$，值 62。

Serena 公布 $Q$ 时，Venus 打 L 得 $80-30Q$、打 R 得 $20+70Q$，Serena 能把 Venus 压到的是 $\max(80-30Q,\ 20+70Q)$ 的最低点：$Q=0.6$，值 62。

::fig[ma4264-envelope] 左边：Venus 先公布 $P$，彩线是她最坏情况下的胜率，最高点在 $P=0.7$。右边：Serena 先公布 $Q$，彩线是 Venus 最好情况下的胜率，最低点在 $Q=0.6$。两边都是 62。左图的虚线 rr 在后面解释。

允许 mix 以后，谁先动都是 62。这两个点正是第 3 站解出的 equilibrium，62 是 equilibrium 里 Venus 的胜率。

### maxmin 永远不超过 minmax

记 $u(x,y)=x^\top Ay$，$x$、$y$ 是两人的 mixed strategy。对任意 $x$、$y$：

$$\min_{y'}u(x,y')\ \le\ u(x,y)\ \le\ \max_{x'}u(x',y)$$

左边只依赖 $x$，右边只依赖 $y$。左边对 $x$ 取 max、右边对 $y$ 取 min，inequality 仍然成立：

$$\max_x\min_y u(x,y)\ \le\ \min_y\max_x u(x,y)$$

先动不会比后动更好，这对任何 matrix 都成立。只用 pure strategy 时可以严格小于（50 < 80）。von Neumann 的 minimax theorem 说，允许 mixed strategy 时一定相等：

**Theorem（minimax）.** 对任何有限的 zero-sum game，$\max_x\min_y x^\top Ay=\min_y\max_x x^\top Ay$。这个共同的值叫 game 的 value。

### 证明：row player 的 LP 的 dual 就是 column player 的 LP

把 row player 的问题写成 LP。Variable 是 $x_1,\dots,x_m$ 和她能保证的值 $v$：

$$\begin{aligned}\max\quad&v\\\text{s.t.}\quad&\textstyle\sum_i a_{ij}x_i\ge v\qquad j=1,\dots,n\\&\textstyle\sum_i x_i=1\\&x\ge0,\quad v\text{ free}\end{aligned}$$

第一组 constraint 说 column player 无论选哪一列，row player 都至少得 $v$。对付固定的 $x$，column player 只需考虑 pure strategy，所以这 $n$ 个 constraint 就够了。Optimal 的 $v$ 就是 $\max_x\min_y u$。

按 [MA3252 第 4 站](../courses/MA3252.html#dual)的规则取 dual。先把第一组写成 $v-\sum_ia_{ij}x_i\le0$，给第 $j$ 个配 dual variable $y_j\ge0$（max 问题里的 $\le$ constraint）；给 $\sum_ix_i=1$ 配 dual variable $w$，等式 constraint，$w$ free。Dual 的 objective 是 right-hand side 乘 dual variable：$\sum_j0\cdot y_j+1\cdot w=w$，求 min。Dual 的 constraint 每个 primal variable 一条：

- $v$ 是 free 的。它在第 $j$ 个 constraint 里的 coefficient 是 1，在等式里是 0，在 objective 里是 1，所以 dual constraint 是等式：$\sum_jy_j=1$。
- $x_i\ge0$。它在第 $j$ 个 constraint 里的 coefficient 是 $-a_{ij}$，在等式里是 1，在 objective 里是 0，所以 dual constraint 是 $\ge$：$-\sum_ja_{ij}y_j+w\ge0$。

整理得

$$\begin{aligned}\min\quad&w\\\text{s.t.}\quad&\textstyle\sum_j a_{ij}y_j\le w\qquad i=1,\dots,m\\&\textstyle\sum_j y_j=1\\&y\ge0,\quad w\text{ free}\end{aligned}$$

这正是 column player 的问题：选 $y$，使 row player 无论选哪一行都不超过 $w$，并让 $w$ 尽量小。它的 optimal value 是 $\min_y\max_x u$。

Primal 是 feasible 的（任取一个 $x$，让 $v$ 等于 $A$ 里最小的 entry），也是 bounded 的（$v$ 不可能超过 $A$ 里最大的 entry），所以有 optimal solution。Strong duality 说此时 dual 也有 optimal solution，两个 optimal value 相等。∎

Weak duality 那一行 inequality 就是上一小节的 $\max\min\le\min\max$；strong duality 补上了相等。

### Complementary slackness：谁不会被用

给 Serena 加一个选择：完全守 right，记作 rr。这时 Venus 打 L 赢 90，打 R 只赢 10（数是为这一页取的）。Venus 公布 $P$ 后，rr 给她 $90P+10(1-P)=10+80P$，就是图左的虚线。

Lower envelope 现在由三段组成：rr 与 r 在 $10+80P=20+60P$，即 $P=0.5$ 处相交（值都是 50），所以 $P\in[0,0.5]$ 时 rr 最低，$[0.5,0.7]$ 时 r 最低，$[0.7,1]$ 时 l 最低。最高点还是 $P=0.7$、62。rr 是 $P<0.5$ 时 Serena 的 best response，也不被任何 mixed strategy dominate（l、r 的任何 mix 在 Venus 打 R 时至少给她 20，压不到 10），但在 equilibrium 里它不会被用。

Complementary slackness 正好说明这一点。在 $x^*=(0.7,0.3)$ 处，rr 那一列的 primal constraint 是 $10+80\times0.7=66>62$，不 tight，对应的 dual variable 必须为 0：$y_{rr}=0$。反过来，$x_L$、$x_R$ 都是 positive，所以两行的 dual constraint 必须 tight；用 $y=(0.6,0.4,0)$ 检查，$50\times0.6+80\times0.4=62$，$90\times0.6+20\times0.4=62$，确实如此。这就是第 3 站的 indifference principle 换成 LP 的说法：被用到的 strategy 恰好都达到 value，达不到 value 的不被用。

:::wrong 先公布自己 strategy 的一方总是吃亏
只用 pure strategy 时是这样：Venus 先选只能保证 50，后选能拿到 80。公布 mixed strategy 时不吃亏：Venus 事先公开说“我 70% 打 L”，Serena 知道了也没用，Venus 照样得 62。被看穿的只是 probability，不是这一球具体打哪边。Minimax theorem 说的就是这件事：在 zero-sum game 里，optimal 的 mixed strategy 可以公开。它在 non-zero-sum 的 game 里不成立，第 5 站的 Stackelberg 是先公布 output 反而占便宜的例子。
:::

:::edge Zero-sum game 的 equilibrium 可以互换
设 $(x,y)$ 是 Nash equilibrium。$y$ 是对 $x$ 的 best response，所以 $u(x,y)=\min_{y'}u(x,y')\le\max_{x'}\min_{y'}u$；$x$ 是对 $y$ 的 best response，所以 $u(x,y)=\max_{x'}u(x',y)\ge\min_{y'}\max_{x'}u$。结合 $\max\min\le\min\max$，这四个量全相等：每个 equilibrium 的 payoff 都是 value，$x$ 是 maxmin strategy，$y$ 是 minmax strategy。反过来，任取一个 maxmin strategy $x$ 和一个 minmax strategy $y$，有 $u(x,y)\ge\min_{y'}u(x,y')=v$ 且 $u(x,y)\le\max_{x'}u(x',y)=v$，所以 $u(x,y)=v$；row player 换成任何 $x'$ 得 $u(x',y)\le v$，column player 换成任何 $y'$ 得 $u(x,y')\ge v$，谁也不想动。所以从两个 equilibrium 里各取一方拼起来，仍是 equilibrium。

NUS Tutorial 1 第 7 题对 pure strategy 走的是另一条更短的路。Zero-sum 时 $(s_1^*,s_2^*)$ 是 Nash equilibrium 当且仅当对所有 $s_1$、$s_2$ 都有 $u_1(s_1,s_2^*)\le u_1(s_1^*,s_2^*)\le u_1(s_1^*,s_2)$：左边是 P1 不想动，右边是 P2 不想动（P2 的 payoff 是 $-u_1$，她不想动就是 $u_1$ 不会因她变小）。设 $(T,l)$ 和 $(B,r)$ 都是 equilibrium，各取一条 inequality 串起来：

$$u_1(T,l)\le u_1(T,r)\le u_1(B,r)\le u_1(B,l)\le u_1(T,l)$$

第一、第四个 $\le$ 来自 $(T,l)$ 的两边，第二、第三个来自 $(B,r)$。首尾相同，四个数全相等。于是对任何 $s_1$，$u_1(s_1,r)\le u_1(B,r)=u_1(T,r)$；对任何 $s_2$，$u_1(T,r)=u_1(T,l)\le u_1(T,s_2)$，$(T,r)$ 满足 saddle point 的两边，是 equilibrium；$(B,l)$ 同理。

Battle of the sexes 不是 zero-sum，从 (Ballet, Ballet) 取 P1 的、从 (Football, Football) 取 P2 的，拼出 (Ballet, Football)，两人都得 0。
:::

## [spe] Extensive form、backward induction 与 subgame perfection

:::skip
能在 game tree 上做 backward induction，能写出 extensive form 里的完整 strategy，区分 Nash equilibrium 与 subgame perfect equilibrium，会处理 information set 和“先同时、再同时”的两阶段 game（tariff game），并能推出 Stackelberg 的 output 和 alternating-offer bargaining 的 share（包括两人 discount factor 不同时），就可以去第 6 站。
:::

### 回到 entry 的场面

开头第二个场面画成 game tree：

::fig[ma4264-entry] 左边是 game tree，payoff 写成 (entrant, incumbent)；右边是同一个 game 的 strategic form。彩线是后面求出的 subgame perfect 的选择。

Extensive form game 由一棵 tree 给出：每个 decision node 标明轮到谁动，从它出发的每条 edge 是一个 action，每片 leaf 是一个结局，写着各人的 payoff。动的人知道之前发生的一切时，叫 perfect information。

Strategy 的定义要小心。在 extensive form 里，player 的 strategy 是一份完整的计划：在每一个轮到他动的 node 上各选一个 action，包括按这份计划根本走不到的 node。Entrant 只在 root 动，strategy 是 In 或 Out。Incumbent 只在 In 之后那个 node 动，strategy 是 A（accommodate）或 F（fight）。即使 entrant 选了 Out，incumbent 的 strategy 也要写清“如果有人进来我会怎样”，因为 entrant 正是根据这一条决定进不进来。Threat 就住在走不到的那一部分里。

把每一对 strategy 的结局填进 matrix，得到 strategic form（右图）。逐格检查：

- (In, A)：entrant 改 Out，从 2 变 1；incumbent 改 F，从 1 变 0。是 Nash equilibrium。
- (Out, F)：entrant 改 In 会遇上 F，从 1 变 0；incumbent 改 A，entrant 反正不进来，它还是 2。没人能变好，也是 Nash equilibrium。
- (In, F) 里 incumbent 想改 A，(Out, A) 里 entrant 想改 In，都不是。

(Out, F) 就是“你进来我就打”被当真的情形。Nash equilibrium 只检查 payoff 会不会变：在 (Out, F) 里 incumbent 的 node 走不到，F 对它的 payoff 毫无影响，于是“打”这个选择从来没有被检验过。真的走到那个 node，incumbent 选 F 得 0、选 A 得 1，它不会打。

### Subgame perfect equilibrium

**Definition.** 从某个 decision node 出发，连同它后面的整棵 tree，叫一个 subgame（有 information set 时还有一条限制，本站后面补充）。Strategy profile $s^*$ 是 subgame perfect equilibrium（SPE），如果它在每一个 subgame 上的限制都是那个 subgame 的 Nash equilibrium。

整棵 tree 本身也是一个 subgame，所以 SPE 一定是 Nash equilibrium；多出来的要求全在走不到的地方。

用在 entry game 上：In 之后的 subgame 只有 incumbent 一个人动，它的 Nash equilibrium 就是选 payoff 大的 A。(Out, F) 在这个 subgame 上选 F，不是 SPE。(In, A) 在这个 subgame 上选 A，在整个 game 上也是 Nash equilibrium，所以是 SPE，而且是唯一的。开头的问题有了答案：entrant 不该信。

### Backward induction

Finite 的 perfect information game 里，SPE 可以从下往上求：找出最底层的 decision node，在每个这样的 node 上让 mover 选他最喜欢的 action，把这个 node 连同下面的 leaf 换成选中的那个 payoff；这样上一层的 node 就成了最底层，重复，直到 root。

::fig[ma4264-backward] 一棵三层的 tree，逐层求解。看每个 node 怎样被它的 mover 用自己的那个数（Player 1 看左边的数，Player 2 看右边的数）做出选择，再被换成一个 box。

这棵 tree 是为这一页构造的。几处值得停下来看：

- R 一侧有全图最大的 (5, 0)，只看 leaf 的话 Player 1 想往 R 走。可是走 R 以后 Player 2 在 c、d 之间选：c 会让 Player 1 拿 5、自己拿 0，d 让自己拿 2，Player 2 选 d。R 一侧对 Player 1 只值 1。
- L 一侧 Player 2 看到 (L, a, y) 上自己能拿 4，可是到了 (L, a) 是 Player 1 选，他选 x（3 > 2），Player 2 走 a 只能拿 1，于是她选 b，拿 2。
- 最后 Player 1 比较 L 的 2 和 R 的 1，选 L。结局是 (L, b, y)，payoff (2, 2)。

Backward induction 给出的是每个 node 上的选择，这就是完整的 SPE：

- Player 1：root 选 L；(L, a) 之后选 x，(L, b) 之后选 y，(R, c) 之后选 x，(R, d) 之后选 x。
- Player 2：L 之后选 b，R 之后选 d。

Player 1 有 5 个 decision node，各两个 action，strategy 共 $2^5=32$ 个；Player 2 有 $2^2=4$ 个。写成 strategic form 是 32×4 的 matrix，128 格；backward induction 只做了 7 次两两比较。

每个 node 上都没有平局时，backward induction 的结果唯一；有平局时，每种选法各走一遍，得到几个 SPE。Osborne 第 5.5 节证明了：finite horizon 的 perfect information game 里，backward induction 得到的恰好是全部 SPE，所以这类 game 一定有 SPE，而且有 pure 的。

:::wrong 只要算出 equilibrium path 上的选择就够了
Root 上 Player 1 之所以选 L，是因为 R 一侧只值 1，而这个 1 来自 Player 2 在 R 之后会选 d、Player 1 在 (R, d) 之后会选 x。这些 node 在 equilibrium 里都走不到，可 root 的决定完全靠它们。只报出“L、b、y”等于只给了结论，没有说别的路为什么不走。SPE 要写出每个 node 上的 action。
:::

### 先动的价值：Stackelberg

把第 2 站的 Cournot 改成有先后：Firm 1 先定 $q_1$，Firm 2 看到以后再定 $q_2$。这是 Stackelberg 的 model。

Backward induction。Firm 2 动的时候 $q_1$ 已经定了，它的问题就是第 2 站的 best response：$q_2=\frac{1-q_1}{2}$。Firm 2 的 strategy 是一个 function，对每个可能的 $q_1$ 给出一个 $q_2$。

Firm 1 知道这一点，把它代进自己的 profit：

$$u_1=q_1\left(1-q_1-\frac{1-q_1}{2}\right)=\frac{q_1(1-q_1)}{2}$$

令 derivative $\frac{1-2q_1}{2}=0$，得 $q_1=\frac12$，于是 $q_2=\frac{1-1/2}{2}=\frac14$。Price $2-\frac34=\frac54$，每单位赚 $\frac14$，Firm 1 的 profit 是 $\frac12\cdot\frac14=\frac18$，Firm 2 是 $\frac14\cdot\frac14=\frac1{16}$。

和 Cournot 的 $\frac19$ 比，先动的 Firm 1 多赚了，后动的少赚了。$q_1=\frac12$ 并不是对 $q_2=\frac14$ 的 best response（那应该是 $\frac38$），如果 Firm 1 事后能改，它会改小。它的优势恰恰来自不能改：output 一旦定下，Firm 2 只能接受。Osborne 第 6.2 节指出，如果加一个阶段让 Firm 1 事后还能改，Firm 2 就成了实际上的先动者，Firm 1 反而更差。

这个 game 里还有不是 SPE 的 Nash equilibrium。设 Firm 2 的 strategy 是“不管 $q_1$ 是多少，我都产 $\frac13$”，Firm 1 产 $\frac13$。给定 Firm 2 永远产 $\frac13$，Firm 1 的 best response 是 $\frac{1-1/3}{2}=\frac13$；给定 $q_1=\frac13$，Firm 2 产 $\frac13$ 也是 best response。所以这是 Nash equilibrium，结局和 Cournot 一样。但它要求 Firm 2 在 Firm 1 产 $\frac12$ 时仍产 $\frac13$，而那时它的 best response 是 $\frac14$。这又是一个在走不到的地方的 threat，SPE 把它排除了。

### 不是 perfect information 时：information set

有时后动的人看不到先动的人做了什么，这和两人同时行动是一回事。画在 tree 上，就把后动者分不清的那几个 node 圈在一起，叫一个 information set；同一个 information set 里的 node 属于同一个 player，可选的 action 也一样。

这时 subgame 必须从一个自己单独构成 information set 的 node 开始，并且不能把任何 information set 切开。下面这个例子是为这一页构造的：P1 先决定 Out 还是 In；Out 时双方各得 1.5；In 以后两人同时玩第 3 站的 battle of the sexes。

::fig[ma4264-subgame] 虚线圈起来的是 P2 的 information set：P2 不知道 P1 在 In 之后选了 B 还是 F。实线外框是 In 之后的 subgame。

P2 的两个 node 不能各自开始一个 subgame，那会把 information set 切开。In 之后 P1 的 node 可以，它下面的 subgame 就是 battle of the sexes 本身。Backward induction 推广成：先求最底层 subgame 的一个 Nash equilibrium，把 subgame 换成它的 payoff，再往上。Battle of the sexes 有三个 equilibrium，所以要分三支：

- Subgame 里玩 (B, B)，P1 在 In 之后得 2 > 1.5，root 选 In。
- 玩 (F, F)，P1 得 1 < 1.5，选 Out。
- 玩 mixed 的那个，P1 得 $\frac23<1.5$，选 Out。

一共三个 SPE。后两个 SPE 里 In 走不到，strategy 仍要写清 In 之后怎么玩，因为正是这一条让 P1 选了 Out。

### 先同时、再同时：tariff game

课程（cheatsheet）专门讲了一类两阶段的 game：第 1 阶段 Player 1、2 同时选 $a_1,a_2$；第 2 阶段 Player 3、4 看到 $(a_1,a_2)$ 以后同时选 $a_3,a_4$。每一组 $(a_1,a_2)$ 后面都是一个 subgame，它是一个 simultaneous-move game。做法和上一小节一样从下往上：

1. 对每一组 $(a_1,a_2)$，求第 2 阶段的 Nash equilibrium，记作 $\big(a_3(a_1,a_2),a_4(a_1,a_2)\big)$。这是两个 function。
2. 把它们代进 Player 1、2 的 payoff，得到一个只有 Player 1、2 的 simultaneous-move game，求它的 Nash equilibrium $(a_1^*,a_2^*)$。

课程把 $\big(a_1^*,a_2^*,a_3(a_1^*,a_2^*),a_4(a_1^*,a_2^*)\big)$ 叫 subgame-perfect outcome。SPE 本身是 $\big(a_1^*,a_2^*,a_3(\cdot,\cdot),a_4(\cdot,\cdot)\big)$：后两个人的 strategy 是整个 function，不是 path 上的那一个数。

Cheatsheet 的例子是两个 country 的 tariff。每个 country 有一个 government 和一家 firm。第 1 阶段两个 government 同时定 tariff $t_1,t_2$；第 2 阶段两家 firm 看到 tariff，同时决定在本国卖多少 $h_i$、出口多少 $e_i$。Country $i$ 的 price 是 $a-Q_i$，$Q_i=h_i+e_j$，每单位 cost 是 $c$，出口到 country $j$ 每单位还要交 $t_j$。Firm $i$ 的 profit 是

$$\pi_i=\big[a-(h_i+e_j)\big]h_i+\big[a-(h_j+e_i)\big]e_i-c\,(h_i+e_i)-t_je_i$$

Government $i$ 的 payoff 是本国的 consumer surplus $\frac12Q_i^2$、本国 firm 的 profit 和收到的 tariff 之和：$W_i=\frac12Q_i^2+\pi_i+t_ie_j$。

**第 2 阶段。** $\pi_i$ 里 $h_i$ 只出现在 country $i$ 的那一项，$e_i$ 只出现在 country $j$ 的那一项，所以两个 market 可以分开解。Country $i$ 的 market 里 firm $i$ 卖 $h_i$，firm $j$ 卖 $e_j$，cost 是 $c+t_i$。这是 cost 不同的 Cournot：

$$\frac{\partial}{\partial h_i}\Big[(a-h_i-e_j-c)\,h_i\Big]=0\ \Rightarrow\ h_i=\frac{a-c-e_j}{2},\qquad\frac{\partial}{\partial e_j}\Big[(a-h_i-e_j-c-t_i)\,e_j\Big]=0\ \Rightarrow\ e_j=\frac{a-c-t_i-h_i}{2}$$

把第二式代进第一式：$4h_i=2(a-c)-(a-c-t_i-h_i)$，即 $3h_i=a-c+t_i$。于是

$$h_i=\frac{a-c+t_i}{3},\qquad e_j=\frac{a-c-t_i-h_i}{2}=\frac{a-c-2t_i}{3}$$

Tariff 越高，外国 firm 卖得越少，本国 firm 卖得越多。

**第 1 阶段。** 把它们代进 $W_i$。$Q_i=h_i+e_j=\frac{2(a-c)-t_i}{3}$；country $i$ 的 price 减 cost 是 $a-Q_i-c=\frac{a-c+t_i}{3}=h_i$，所以 firm $i$ 在本国赚 $h_i^2$；firm $i$ 的出口 profit 只依赖 $t_j$。把与 $t_i$ 无关的项记作 $K$：

$$W_i=\frac{\big[2(a-c)-t_i\big]^2}{18}+\frac{(a-c+t_i)^2}{9}+\frac{t_i\,(a-c-2t_i)}{3}+K$$

对 $t_i$ 求 derivative：

$$-\frac{2(a-c)-t_i}{9}+\frac{2(a-c+t_i)}{9}+\frac{a-c-4t_i}{3}=\frac{-2(a-c)+t_i+2(a-c)+2t_i+3(a-c)-12t_i}{9}=\frac{3(a-c)-9t_i}{9}$$

令它为 0 得 $t_i^*=\frac{a-c}{3}$。$t_i^2$ 的 coefficient 是 $\frac1{18}+\frac19-\frac23=-\frac12<0$，这是最大值。$t_i^*$ 和 $t_j$ 无关，每个 government 不管对方怎样定都定 $\frac{a-c}{3}$。

取 $a=10$、$c=1$：$t^*=3$，第 2 阶段 $h_i=\frac{9+3}{3}=4$，$e_i=\frac{9-6}{3}=1$，每个 country 的 $W_i=32.5$。如果两国都定 $t=0$（free trade），$h_i=e_i=3$，$W_i=36$。两个 government 都想加 tariff，加完以后两国都比 free trade 差，和 prisoner's dilemma 一样。

### Alternating-offer bargaining

:::skip
这一小节是 backward induction 的一个重要应用，加上一个 infinite horizon 的证明。跳过它会少掉“耐心就是 bargaining power”的推导。
:::

两人分一块大小为 1 的 pie。Player 1 先提一个分法，Player 2 接受就成交；拒绝就轮到 Player 2 提，Player 1 决定接不接受；如此轮流。每拖一轮，pie 对双方都打一个 discount $\delta\in(0,1)$。如果有最后期限，最后一轮的提议被拒绝，双方都得 0。

**只有 1 轮。** 这是 ultimatum game。Player 2 接受任何正的份额都比 0 好，所以 Player 1 只给她 0（她接受），自己拿全部。6.254 第 13 讲和 Osborne 第 6.1 节都指出，若 Player 2 恰好在 0 处拒绝，Player 1 就找不到 optimal 的 offer（任何正数都可以再减半），所以这种情形不构成 SPE。

NUS Tutorial 4 第 6 题把这个 game 的 strategy 写全了。Player 1 的 strategy 是自己留下的份额 $s\in[0,1]$；Player 2 的 strategy 是一个 function $f:[0,1]\to\{A,R\}$，对每一个可能的 $s$ 说好接受还是拒绝。这正是本站开头说的“完整的计划”：Player 2 只看到一个 offer，strategy 却要覆盖所有 offer。Nash equilibrium 有无穷多个：给定 $f$，Player 1 会在 $f$ 接受的那些 $s$ 里取最大的（要求这个最大值存在）；所以“只接受 $s\le0.6$”配上 $s=0.6$ 是一个 Nash equilibrium，Player 2 得 0.4。甚至“什么都拒绝”配上 $s=1$ 也是：Player 1 反正得 0，留 1 也是 best response；$s=1$ 时 Player 2 接受拒绝都得 0，拒绝也是 best response。这些 equilibrium 都靠走不到的地方的 threat，例如拒绝 $s=0.7$ 让自己从 0.3 变成 0。在每个 subgame（每一个具体的 offer）上 Player 2 都必须选更好的那个，于是她接受所有 $s<1$；$s=1$ 时接受拒绝一样，按上一段，接受时才有 SPE。唯一的 SPE 是 $s=1$、$f\equiv A$。

**2 轮。** 第 2 轮 Player 2 提议，她拿全部。退到第 1 轮：Player 2 拒绝后能得到 1，但那是下一轮的 1，按今天算值 $\delta$。所以 Player 1 给她 $\delta$ 她就接受，Player 1 留下 $1-\delta$。

**3 轮。** 第 3 轮 Player 1 拿全部，按第 2 轮算值 $\delta$。第 2 轮 Player 2 提议时给 Player 1 $\delta$，自己留 $1-\delta$，按第 1 轮算值 $\delta(1-\delta)$。第 1 轮 Player 1 给 Player 2 $\delta-\delta^2$，自己留 $1-\delta+\delta^2$。

每多一轮，就是在前面的结果上再做一次“给对方他拒绝后能得到的、折算到今天的值”。Polak 在第 17 讲列出了这张表：

| 轮数 | Player 1 的 share | $\delta=0.9$ |
|---|---|---|
| 1 | $1$ | 1 |
| 2 | $1-\delta$ | 0.1 |
| 3 | $1-\delta+\delta^2$ | 0.91 |
| 4 | $1-\delta+\delta^2-\delta^3$ | 0.181 |
| 10 | $\dfrac{1-\delta^{10}}{1+\delta}$ | 0.343 |
| $\infty$ | $\dfrac{1}{1+\delta}$ | 0.526 |

10 轮那一行是 geometric series：$1-\delta+\delta^2-\cdots-\delta^9=\frac{1-\delta^{10}}{1+\delta}$。轮数趋于无穷时 $\delta^n\to0$，奇数轮、偶数轮都趋于 $\frac1{1+\delta}$。三个结论：equilibrium 里第一个 offer 就被接受，没有讨价还价的拖延；先提的人有优势，$\frac1{1+\delta}>\frac12$；offer 来得很快时（$\delta\to1$）优势消失，趋于平分。

**课程的三期版本。** NUS 的 cheatsheet 用的是另一种最后期限：第 1 期 Player 1 提，第 2 期 Player 2 提，两次都被拒绝的话，第 3 期直接按事先定好的 $(\bar s_1,\bar s_2)$ 结算，$\bar s_1+\bar s_2\le1$。倒推只需要一条 lemma：如果已知拒绝以后下一期两人分别得到 $(u_1,u_2)$，那么这一期的 proposer 给对方 $\delta u_j$，对方接受。

- 第 2 期，Player 2 提。Player 1 拒绝会在第 3 期得到 $\bar s_1$，折算到第 2 期是 $\delta\bar s_1$。Player 2 给他 $\delta\bar s_1$，自己留 $1-\delta\bar s_1$。
- 第 1 期，Player 1 提。Player 2 拒绝会在第 2 期得到 $1-\delta\bar s_1$，折算到第 1 期是 $\delta(1-\delta\bar s_1)$。Player 1 给她这么多，自己留

$$1-\delta\,(1-\delta\bar s_1)$$

上面表里的 3 轮是 $\bar s_1=1$ 的情形：$1-\delta(1-\delta)=1-\delta+\delta^2$。

**没有最后期限。** 这时没有最后一轮可以倒推。但从任何一轮开始，剩下的 game 都和原来一样，只是两人换了位置。

课程（cheatsheet 和 Tutorial 5）的论证借用上面的三期版本。设这个 infinite-horizon game 有一个 backward-induction outcome，Player 1 得 $\bar u_1$。第 3 期开始时轮到 Player 1 提，剩下的 game 和第 1 期开始时完全一样，所以第 3 期的结果就是“Player 1 得 $\bar u_1$”，可以当成三期版本里事先定好的 $\bar s_1=\bar u_1$。于是第 1 期 Player 1 得 $1-\delta(1-\delta\bar u_1)$，而这又应该等于 $\bar u_1$：

$$\bar u_1=1-\delta+\delta^2\bar u_1\quad\Longrightarrow\quad\bar u_1(1-\delta^2)=1-\delta\quad\Longrightarrow\quad\bar u_1=\frac{1}{1+\delta}$$

Player 2 得 $\frac{\delta}{1+\delta}$。

两人的 discount factor 不同时（Tutorial 5 第 2 题，Player 1 是 $\delta_1$，Player 2 是 $\delta_2$），同样两步：第 2 期 Player 2 给 Player 1 $\delta_1s$（$s$ 是 Player 1 从第 3 期起得到的），自己留 $1-\delta_1s$；第 1 期 Player 1 给 Player 2 $\delta_2(1-\delta_1s)$，自己留 $1-\delta_2(1-\delta_1s)$。令它等于 $s$：

$$s=1-\delta_2+\delta_1\delta_2s\quad\Longrightarrow\quad s=\frac{1-\delta_2}{1-\delta_1\delta_2}$$

$\delta_1=\delta_2$ 时 $\frac{1-\delta}{1-\delta^2}=\frac{1}{1+\delta}$。取 $\delta_1=0.9$、$\delta_2=0.8$：$s=\frac{0.2}{0.28}=\frac57\approx0.714$；对调成 $\delta_1=0.8$、$\delta_2=0.9$：$s=\frac{0.1}{0.28}=\frac{5}{14}\approx0.357$。先提的优势可以被对方的耐心抵消，对方越有耐心，拒绝的代价越小，能要的越多。

这个论证默认 backward-induction outcome 存在而且唯一（“第 3 期的结果就是 $\bar u_1$”只在 SPE 的 payoff 只有一个值时说得通）。6.254 第 13 讲换一种方式：猜一个 stationary 的 SPE，proposer 总是拿 $x$。Responder 拒绝以后自己成为 proposer，拿 $x$，按今天算值 $\delta x$，所以 proposer 只需给 $\delta x$，留下 $1-\delta x$。这个数又应该等于 $x$：

$$x=1-\delta x\quad\Longrightarrow\quad x=\frac{1}{1+\delta}$$

和有限轮数的 limit 一致。6.254 第 13 讲猜出 strategy 以后，再用第 6 站的 one-shot deviation principle 验证它是 SPE；那一讲还说它是唯一的 SPE，证明引用了 Fudenberg 与 Tirole 的教材。两种论证各自假设了一点东西（payoff 唯一，或者 strategy stationary）。下面的证明把这一点补上，它是凭自己的知识写的，思路和课程的论证相同，用的都是“从后面某一轮开始的 game 和原来一样”，只是不再假设 SPE 的 payoff 只有一个值。

设 $M$、$m$ 是“Player 1 先提”的这个 game 的所有 SPE 里 Player 1 payoff 的 sup 和 inf。从任何一轮开始的 game 结构相同，所以这两个数也是任何一轮的 proposer 在那一轮开始的 SPE 里能拿到的上下界（按那一轮算）。

- Player 2 拒绝后成为 proposer，至多拿 $M$，折算到今天至多 $\delta M$。所以任何给她多于 $\delta M$ 的 offer 她都会接受。Player 1 给她 $\delta M+\varepsilon$ 就能留下 $1-\delta M-\varepsilon$，$\varepsilon$ 可以任意小，所以 $m\ge1-\delta M$。
- Player 2 拒绝后至少拿 $m$，折算到今天至少 $\delta m$，所以她不会接受少于 $\delta m$ 的 offer，成交时 Player 1 至多拿 $1-\delta m$。如果第一轮不成交，下一轮 Player 2 是 proposer，至少拿 $m$，Player 1 至多拿 $1-m$，折算到今天至多 $\delta(1-m)$，而 $(1-\delta m)-\delta(1-m)=1-\delta\ge0$。所以 $M\le1-\delta m$。

两式合起来：

$$M\le1-\delta m\le1-\delta(1-\delta M)=1-\delta+\delta^2M\quad\Longrightarrow\quad M(1-\delta^2)\le1-\delta\quad\Longrightarrow\quad M\le\frac{1}{1+\delta}$$

$$m\ge1-\delta M\ge1-\frac{\delta}{1+\delta}=\frac{1}{1+\delta}$$

$m\ge M$，而 inf 不会超过 sup，所以 $m=M=\frac1{1+\delta}$：每个 SPE 里 Player 1 都拿 $\frac1{1+\delta}$。∎

[PS1101E 第 8 站](../courses/PS1101E.html#ir)的 bargaining model of war 是另一个 model：只有一次 offer，拒绝的后果是 war 的 expected payoff，那里的问题是 bargaining range 存在时 war 为什么还会发生。

### 从 PS1101E 接着往下

[PS1101E 第 2 站](../courses/PS1101E.html#collective)已经用 payoff 4、3、2、1 的 prisoner's dilemma 推过：无限期地玩，双方都用“只要你 Defect 过一次，我以后永远 Defect”，在 $\delta\ge\frac12$ 时 cooperation 划算。这一站用同一组数：

| | C | D |
|---|---|---|
| **C** | (3, 3) | (1, 4) |
| **D** | (4, 1) | (2, 2) |

那里的论证留下三个问题：只检查了“今天要不要 Defect”，没有检查真到了惩罚的时候，执行惩罚本身划不划算；没有说期数有限时怎样；只看了 (3, 3) 这一个结果。这一站依次回答。

### Finite horizon：从最后一期倒推

开头第三个场面：确定玩 10 期。

**第 10 期。** 不管之前发生了什么，这是最后一次，以后没有任何后果，它就是一次性的 prisoner's dilemma。D 是 dominant strategy，双方选 D。

**第 9 期。** 第 10 期的结果已经确定是 (D, D)，与第 9 期做什么无关。所以第 9 期的选择只影响第 9 期自己的 payoff，又是一次性的 prisoner's dilemma，双方选 D。

**一直倒推到第 1 期。** 每一期之后的结果都已确定为“以后全是 (D, D)”，每一期都选 D。

唯一的 SPE 是每一期、每个 history 下都选 D。6.254 第 15 讲把它推广为：stage game 只有一个 Nash equilibrium 时，finitely repeated game 的唯一 SPE 是每期都玩它。开头的第三个问题有了答案：关系长不够，要紧的是有没有一个确定的最后一期。

### Stage game 有多个 equilibrium 时

Unravel 依赖“最后一期只有一种可能的结果”。6.254 第 16 讲给了一个 stage game 有两个 equilibrium 的例子：

| | A | B | C |
|---|---|---|---|
| **A** | (3, 3) | (0, 4) | (−2, 0) |
| **B** | (4, 0) | (1, 1) | (−2, 0) |
| **C** | (0, −2) | (0, −2) | (−1, −1) |

(A, A) 对双方都好，但对方选 A 时自己改 B 得 4 > 3，它不是 equilibrium。Pure Nash equilibrium 有两个：对方选 B 时，自己选 A、B、C 分别得 0、1、0，B 最好，所以 (B, B) 是；对方选 C 时分别得 −2、−2、−1，C 最好，所以 (C, C) 是。

玩两期，不打 discount。Strategy：第 1 期选 A；若第 1 期双方都选了 A，第 2 期选 B，否则第 2 期选 C。

- 第 2 期无论 history 如何，玩的都是 stage game 的 Nash equilibrium，没人想改。
- 第 1 期照做，两期合计 $3+1=4$。改成 B，第 1 期得 4，第 2 期双方进入 (C, C) 得 −1，合计 3 < 4。改成 C，第  1 期得 0，第 2 期得 −1，更差。

所以 (A, A) 在第 1 期维持住了，这是一个 SPE。好的 equilibrium 和坏的 equilibrium 之间的差距，成了第 1 期的 reward 和 punishment。

### Infinite horizon 的 payoff 和 strategy

无限期时用 discount factor $\delta\in[0,1)$，并乘上 $(1-\delta)$ 做 normalize：

$$U_i=(1-\delta)\sum_{t=0}^{\infty}\delta^t\,g_i(a_t)$$

$g_i(a_t)$ 是第 $t$ 期的 stage payoff。乘 $(1-\delta)$ 是为了和 stage game 用同一个单位：每期都得 3，$U_i=(1-\delta)\cdot\frac{3}{1-\delta}=3$。

课程（cheatsheet 和 tutorial）不乘 $(1-\delta)$，从第 1 期数起，用 present value $\sum_{t=1}^{\infty}\delta^{t-1}\pi_{i,t}$；每期都得 3 时是 $\frac{3}{1-\delta}$。两种写法只差一个正的常数 $(1-\delta)$，比较两个 strategy 谁好，结论完全一样。下面的 inequality 两种写法都会出现，乘或除 $(1-\delta)$ 就能互换。

Strategy 是从 history（之前所有期的 action profile）到这一期 action 的 function。Grim trigger：没有人 Defect 过就选 C，有人 Defect 过就永远选 D。

### One-shot deviation principle

SPE 要求在每个 history 之后都是 Nash equilibrium。History 有无穷多个，每个 history 之后可能的 deviation 也有无穷多种，不可能逐个检查。下面这个原理把检查缩小到“只改一期”。

**Theorem.** 在有 discount 的 infinitely repeated game 里，strategy profile $s$ 是 SPE，当且仅当：对每个 player $i$ 和每个 history $h$，$i$ 在 $h$ 这一期改用别的 action、此后完全照 $s_i$ 做，都不能提高他从 $h$ 开始的 payoff。

**Proof.** “只改一期”是 deviation 的一种，SPE 自然不怕它，所以只需证另一个方向。

设每个 one-shot deviation 都不划算，但 $s$ 不是 SPE：在某个 history $h$ 之后，$i$ 有一个 strategy $s_i'$ 比 $s_i$ 多得 $\varepsilon>0$。Stage payoff 在 $[g_{\min},g_{\max}]$ 之间，从 $h$ 起第 $T$ 期以后的部分对 normalize 后的 payoff 的影响至多 $\delta^T(g_{\max}-g_{\min})$。取 $T$ 使它小于 $\frac\varepsilon2$，令 $s_i''$ 在 $h$ 之后的前 $T$ 期照 $s_i'$ 做、以后照 $s_i$ 做。$s_i''$ 和 $s_i'$ 只在 $T$ 期以后不同，所以 $s_i''$ 仍比 $s_i$ 多得超过 $\frac\varepsilon2$。

$s_i''$ 只在有限的几期和 $s_i$ 不同。看最后一个不同的期 $t^*$：在那一期的每个 history 上，$s_i''$ 做的是“这一期改一下，以后照 $s_i$”，恰好是一个 one-shot deviation，按假设不划算。把 $t^*$ 期的这些改动全部换回 $s_i$ 的 action，从 $h$ 起的 payoff 不会下降。现在最后一个不同的期是 $t^*-1$，重复同样的步骤。有限步之后 $s_i''$ 完全变回 $s_i$，payoff 一路没有下降，于是 $s_i$ 至少和 $s_i''$ 一样好，与“$s_i''$ 多得超过 $\frac\varepsilon2$”矛盾。∎

证明里只有一处用到 discount：远处各期的影响很小，所以任何 deviation 都可以截成有限期的。6.254 第 13 讲把这个条件叫 continuity at infinity。

### Grim trigger 是 SPE

History 只有两类，逐类检查 one-shot deviation。

**还没有人 Defect 过。** 照做是每期 3，$U=3$。One-shot deviation：今天选 D 得 4，之后照 grim trigger 做；可是今天自己的 D 已经触发了惩罚，之后双方永远 D，每期 2：

$$U=(1-\delta)\cdot4+\delta\cdot2$$

不划算的条件是 $3\ge4-4\delta+2\delta=4-2\delta$，即 $\delta\ge\frac12$，和 PS1101E 的结论一样。

**有人 Defect 过。** 照做是永远 (D, D)，$U=2$。One-shot deviation：今天改 C，对方照旧 D，今天得 1，之后仍是 (D, D)：$U=(1-\delta)\cdot1+\delta\cdot2<2$。对任何 $\delta$ 都不划算。

两类 history 都通过，所以 grim trigger 在 $\delta\ge\frac12$ 时是 SPE。真到了惩罚的时候，执行惩罚本身就是 best response，因为惩罚就是 stage game 的 Nash equilibrium (D, D)。

课程用 present value 写同一个条件，并写成一般的形式。Stage game 里 Nash equilibrium 给每人 $x$，cooperation 给每人 $y$，对方 cooperate 时自己偏离得 $z$，$x<y<z$。照 trigger strategy 做得 $\frac{y}{1-\delta}$；偏离得 $z+\delta x+\delta^2x+\cdots=z+\frac{\delta x}{1-\delta}$。不偏离的条件：

$$\frac{y}{1-\delta}\ge z+\frac{\delta x}{1-\delta}\quad\Longleftrightarrow\quad y\ge(1-\delta)z+\delta x\quad\Longleftrightarrow\quad\delta\ge\frac{z-y}{z-x}$$

这里 $x=2$、$y=3$、$z=4$，$\frac{4-3}{4-2}=\frac12$。

课程证明 SPE 时不用 one-shot deviation principle，而是把 subgame 分成两类（Tutorial 5 第 3 题）。第一类：此前每一期都是 (C, C)。从这里开始的 subgame 和整个 game 一模一样，双方的 strategy 也还是 trigger strategy，刚才证明了 $\delta\ge\frac12$ 时它是 Nash equilibrium。第二类：此前出现过别的结果。这时双方的 strategy 都是“以后每期都 D”，每期都玩 stage game 的 Nash equilibrium；对方永远 D 时，不管 history 如何，自己每一期选 D 都比选 C 多得 1，所以永远 D 是 best response，这也是 Nash equilibrium。每个 subgame 上都是 Nash equilibrium，所以是 SPE。这个论证能成立，靠的是 trigger strategy 的结构只有这两种情形；遇到更复杂的 strategy（下面的 tit-for-tat），还是 one-shot deviation principle 好用。

:::wrong Tit-for-tat 也能在 $\delta\ge\frac12$ 时维持 cooperation，所以它也是 SPE
Tit-for-tat：第一期 C，以后每期照抄对方上一期的 action。在还没有人 Defect 的 history 上，one-shot deviation 是今天 D、之后照 tit-for-tat 做，结果是 (D, C)、(C, D)、(D, C)…… 来回交替，自己的 payoff 是 4、1、4、1……：

$$U=(1-\delta)\,\frac{4+\delta\cdot1}{1-\delta^2}=\frac{4+\delta}{1+\delta}$$

不划算的条件 $3\ge\frac{4+\delta}{1+\delta}$，即 $3+3\delta\ge4+\delta$，$\delta\ge\frac12$。到这里和 grim trigger 一样。

但还要查别的 history。设上一期是“我 C、对方 D”。Tit-for-tat 让我今天 D（抄对方），对方今天 C（抄我），从今天起是 4、1、4、1……，$U=\frac{4+\delta}{1+\delta}$。One-shot deviation：今天原谅他，选 C，对方也是 C，此后双方一直互抄 C，$U=3$。取 $\delta=0.9$：

$$\frac{4+0.9}{1+0.9}=\frac{4.9}{1.9}\approx2.579<3$$

执行惩罚不如原谅，tit-for-tat 在这个 history 上不是 best response。一般地，惩罚划算要求 $\frac{4+\delta}{1+\delta}\ge3$，即 $\delta\le\frac12$。和上一个条件合起来，只有 $\delta=\frac12$ 恰好成立。这组 payoff 下，tit-for-tat 只在 $\delta=\frac12$ 这一个值上是 SPE；它的问题出在 equilibrium path 之外。
:::

### Cournot 的 collusion

第 2 站的 Cournot 回答了“两家都少产一点为什么守不住”：一次性的 game 里守不住。无限期地玩，trigger strategy 能不能守住？Cheatsheet 和 Tutorial 5 都算了这个例子。用第 2 站的数（$a-c=1$）：

- Collusion：各产 monopoly output 的一半 $\frac14$，每期各得 $\frac18$。
- 对方产 $\frac14$ 时偏离：best response $\frac38$，当期得 $\frac{9}{64}$。
- 偏离以后永远回到 Cournot equilibrium，每期 $\frac19$。

这三个数就是上面的 $y$、$z$、$x$，$\frac19<\frac18<\frac9{64}$。代进 $\delta\ge\frac{z-y}{z-x}$：

$$\delta\ge\frac{\frac9{64}-\frac18}{\frac9{64}-\frac19}=\frac{\frac{1}{64}}{\frac{81-64}{576}}=\frac{1}{64}\cdot\frac{576}{17}=\frac{9}{17}\approx0.529$$

$n$ 家 firm 时（Tutorial 5，$P=a-Q$，记 $K=(a-c)^2$）：collusion 各产 $\frac{a-c}{2n}$，各得 $y=\frac{K}{4n}$；其余 $n-1$ 家共产 $\frac{(n-1)(a-c)}{2n}$ 时，偏离的 best response 是

$$\frac{1}{2}\Big(a-c-\frac{(n-1)(a-c)}{2n}\Big)=\frac{(n+1)(a-c)}{4n},\qquad z=\Big(\frac{(n+1)(a-c)}{4n}\Big)^2=\frac{(n+1)^2K}{16n^2}$$

（第 2 站把 best response 的 first-order condition 写成 $q_i=a-c-Q$，右边就是 price 减 cost，所以 best response 的 profit 是它的 output 的平方。）Cournot 是 $x=\frac{K}{(n+1)^2}$。分别算两个差：

$$z-y=\frac{K\big[(n+1)^2-4n\big]}{16n^2}=\frac{K(n-1)^2}{16n^2}$$

$$z-x=\frac{K\big[(n+1)^4-16n^2\big]}{16n^2(n+1)^2}=\frac{K\big[(n+1)^2-4n\big]\big[(n+1)^2+4n\big]}{16n^2(n+1)^2}=\frac{K(n-1)^2\big[(n+1)^2+4n\big]}{16n^2(n+1)^2}$$

相除：

$$\delta\ge\frac{(n+1)^2}{(n+1)^2+4n}$$

| $n$ | 2 | 3 | 5 | 10 | 20 |
|---|---|---|---|---|---|
| 所需的 $\delta$ | 9/17 ≈ 0.529 | 4/7 ≈ 0.571 | 9/14 ≈ 0.643 | 121/161 ≈ 0.752 | 441/521 ≈ 0.846 |

$n=2$ 就是 $\frac9{17}$。Firm 越多，各自分到的 collusion profit 越少，偏离一次的收益相对越大，需要的耐心越高，$n\to\infty$ 时趋于 1。

Homogeneous 的 Bertrand（第 2 站）也可以这样算（AY2011/12 的 Tutorial 5）：collusion 是两家都定 monopoly price，各得 monopoly profit $\pi_m$ 的一半；偏离是定价略低于对方，当期几乎拿到整个 $\pi_m$；以后回到 $(c,c)$，每期 0。条件是 $\frac{\pi_m/2}{1-\delta}\ge\pi_m$，即 $\delta\ge\frac12$。偏离只能“几乎”拿到 $\pi_m$，所以 $\delta=\frac12$ 时也守得住。

### 哪些 payoff 能维持：folk theorem

(3, 3) 不是唯一能维持的结果。先问：在 repeated game 的任何 Nash equilibrium 里，一个 player 至少能得多少？

**Minmax value.** $\underline v_i=\min_{\alpha_{-i}}\max_{a_i}g_i(a_i,\alpha_{-i})$：别人想尽办法压低 $i$，$i$ 每次都做 best response，$i$ 能得到的最低值。Prisoner's dilemma 里设对方选 C 的 probability 是 $q$，我选 C 得 $3q+1\cdot(1-q)=1+2q$，选 D 得 $4q+2(1-q)=2+2q$，较大的是 $2+2q$；对方取 $q=0$ 把它压到最低，$\underline v_i=2$。

**下界。** 在 repeated game 的任何 Nash equilibrium 里，$i$ 的 payoff 至少是 $\underline v_i$。因为 $i$ 可以换一个 strategy：每期根据 history 推出别人这一期会怎么做（别人的 equilibrium strategy 是给定的），然后对它做 best response。这样每期至少得 $\underline v_i$，合起来至少 $\underline v_i$，而 equilibrium strategy 不会比这个差。

**Feasible.** 每期的 payoff 只能是四个 pure outcome 之一，长期平均能达到的是它们的 convex combination。为了恰好得到某个 convex combination，6.254 假设有一个双方都看得见的随机信号（例如每期公开掷一枚硬币，决定这一期玩哪个 profile），叫 public randomization。

::fig[ma4264-folk] 浅色是 feasible payoff，深色是其中两人都严格大于 minmax 2 的部分，叫 strictly individually rational。

深色区域的四个顶点：(2, 2)；边 (4, 1)–(3, 3) 上 $v_2=2$ 的点 (3.5, 2)；(3, 3)；边 (3, 3)–(1, 4) 上 $v_1=2$ 的点 (2, 3.5)。

**Theorem（Nash folk theorem）.** 设 $v$ feasible 且 strictly individually rational。则存在 $\bar\delta<1$，使所有 $\delta>\bar\delta$ 时 infinitely repeated game 有一个 payoff 为 $v$ 的 Nash equilibrium。

**Proof（$v$ 由某个 pure profile $a$ 达到时）.** Strategy：每期玩 $a$；一旦某个 player $j$ 偏离，其余人此后永远用把 $j$ 压到 $\underline v_j$ 的那个 strategy。照做得 $v_i$。设 $\bar v_i$ 是 $i$ 在 stage game 里能得的最高 payoff。$i$ 在某一期偏离，那一期至多得 $\bar v_i$，以后每期至多得 $\underline v_i$，从那一期算起 normalize 后至多 $(1-\delta)\bar v_i+\delta\underline v_i$；偏离之前各期两种做法一样，不必比较。不划算的条件是

$$v_i\ge(1-\delta)\bar v_i+\delta\,\underline v_i\quad\Longleftrightarrow\quad\delta\ge\frac{\bar v_i-v_i}{\bar v_i-\underline v_i}$$

$v_i>\underline v_i$，所以右边小于 1。取 $\bar\delta$ 为各个 $i$ 的右边中最大的一个。∎

用在 (3, 3)：$\bar v_i=4$，$\underline v_i=2$，$\bar\delta=\frac{4-3}{4-2}=\frac12$，和前面一致。

在 prisoner's dilemma 里，这个 equilibrium 还是 SPE：minmax 的惩罚 (D, D) 恰好是 stage game 的 Nash equilibrium，惩罚期在任何 history 下都是 best response，和 grim trigger 一样。6.254 第 16 讲把这一点写成 Friedman 的 theorem：若 $v$ feasible，且每个 $v_i$ 都严格大于某个 stage Nash equilibrium 给 $i$ 的 payoff，则 $\delta$ 够接近 1 时 $v$ 是某个 SPE 的 payoff，用“谁偏离就永远回到那个 stage Nash equilibrium”的 strategy 即可。

:::edge Minmax 的惩罚不一定可信
6.254 第 15 讲的例子：

| | L | R |
|---|---|---|
| **U** | (6, 6) | (0, −100) |
| **D** | (7, 1) | (0, −100) |

把 P1 压到最低的办法是 P2 选 R，P1 只能得 0，所以 $\underline v_1=0$。可是 P2 选 R 自己每期得 −100，“P1 一偏离我就永远选 R”这个 threat 让 P2 付出极大代价，真到那时 P2 不会执行，Nash folk theorem 的构造在这里不是 SPE。Friedman 的办法也用不上：stage game 唯一的 Nash equilibrium 是 (D, L)，给 P1 7，P1 从 (6, 6) 偏离到 D 以后回到 (D, L)，反而比 6 多，根本罚不了。6.254 第 16 讲给出的 Fudenberg–Maskin theorem 说，在 feasible set 满维（dimension 等于人数）的条件下，任何 strictly individually rational 的 feasible payoff 在 $\delta$ 够大时都是 SPE payoff，办法是让惩罚只持续有限期，并奖励执行惩罚的人。讲义只给了这个思路，这里也不展开。
:::

### Folk theorem 的另一面

Folk theorem 说的是“几乎什么都可能”：深色区域里的每一点都能被某个 equilibrium 维持，而永远 (D, D) 对任何 $\delta$ 也都是 SPE。所以 repeated game 的理论本身不预测 cooperation 一定出现。它说明的是 cooperation 可以是 equilibrium，以及这需要什么条件：双方足够看重未来，能观察到对方做了什么，没有确定的最后一期，或者最后一期有不止一个 equilibrium 可供奖惩。

:::back
Finite horizon 的倒推就是[第 5 站](#spe)的 backward induction；minmax value 是[第 4 站](#zerosum)那个概念在 non-zero-sum game 里的版本。
:::

## [bayes] Bayesian games

:::skip
能把“有人不知道别人的 payoff”写成 Nature 先抽 type 的 Bayesian game，能逐个 type 检验 Bayesian Nash equilibrium，能解 Cournot with private cost，并推出 two-bidder first-price auction 的 equilibrium bid，就可以去第 8 站。
:::

### 不知道对方的 payoff，best response 写不出来

回到第 2 站的 Cournot，$P=2-q_1-q_2$，Firm 1 的 cost 仍是每单位 1。现在 Firm 2 的 cost 是它自己的秘密：每单位 0.75 或 1.25，Firm 1 只知道两者各有一半可能。Firm 2 知道自己的 cost，它的 best response 写得出来，但有两个：cost 0.75 时一个，1.25 时一个。Firm 1 要对 Firm 2 的 output 做 best response，而 Firm 2 产多少取决于 Firm 1 不知道的东西。第 2 站的定义在这里用不上。

### Harsanyi 的办法：让 Nature 先动

把不确定的那个东西叫 type。设想 game 开始前，Nature 按一个所有人都知道的 probability distribution（common prior）抽出每个人的 type，每人只看到自己的。这样“不知道对方的 payoff”就变成了“不知道 Nature 抽到了什么”，后者可以用 probability 处理。

**Definition.** Bayesian game 包括：player；每人的 action set $A_i$；每人的 type set $\Theta_i$；payoff $u_i(a_1,\dots,a_n,\theta_1,\dots,\theta_n)$；type 的 common prior $p$。Player $i$ 的 strategy 是从 type 到 action 的 function $s_i:\Theta_i\to A_i$，每个 type 各选一个 action。

**Definition.** $s^*$ 是 Bayesian Nash equilibrium，如果对每个 $i$ 和每个 type $\theta_i$，$s_i^*(\theta_i)$ 在已知自己 type 为 $\theta_i$ 的条件下使 expected payoff 最大：

$$s_i^*(\theta_i)\in\arg\max_{a_i}\ \sum_{\theta_{-i}}p(\theta_{-i}\mid\theta_i)\,u_i\big(a_i,\,s_{-i}^*(\theta_{-i}),\,\theta_i,\,\theta_{-i}\big)$$

Expectation 取在别人的 type 上，别人的 action 按他们的 strategy 由 type 决定。

课程（tutorial 和 cheatsheet）的记号是 type set $T_i$、type $t_i$、belief $P_i(t_{-i}\mid t_i)$，payoff 写成 $u_i(a_1,\dots,a_n;t_i)$，这一页的 $\Theta_i$、$\theta_i$、$p(\theta_{-i}\mid\theta_i)$ 是同一回事。Belief 由 common prior 按 Bayes' rule 算出：

$$P_i(t_{-i}\mid t_i)=\frac{p(t_{-i},t_i)}{\sum_{t'_{-i}\in T_{-i}}p(t'_{-i},t_i)}$$

各人的 type 独立时，分子分母约掉 $t_i$ 的那一部分，belief 就是 $p(t_{-i})$，和自己的 type 无关。下面三个例子都是这种情形。

### 例 1：不知道对方想不想见面

6.254 第 17 讲的例子。P2 有两种 type，各占 ½：想和 P1 见面（payoff 就是第 3 站的 battle of the sexes），或者想避开 P1。P2 知道自己是哪一种，P1 不知道。

::fig[ma4264-bayesbos] Nature 先抽 P2 的 type。P1 不知道是哪张表，只能选一个 action 同时用在两张表上；P2 的 strategy 要为两种 type 各写一个 action。

检查 profile (B, (B, F))：P1 选 B，P2 想见面时选 B、想避开时选 F。

- P2 想见面：给定 P1 选 B，选 B 得 1、选 F 得 0，B 是 best response。
- P2 想避开：给定 P1 选 B，选 B 得 0、选 F 得 2，F 是 best response。
- P1：选 B，½ 的 probability 遇到 B 得 2、½ 遇到 F 得 0，expected $\frac12\cdot2+\frac12\cdot0=1$；改选 F，遇到 B 得 0、遇到 F 得 1，expected $\frac12$。B 更好。

所以 (B, (B, F)) 是 Bayesian Nash equilibrium。

上面的检查其实把 P2 的两种 type 当成了两个 player。NUS Tutorial 7 的 review 把这写成一般的办法：把每一对 (player, type) $(i,t_i)$ 当成一个新的 player，它的 action set 是 $A_i$，payoff 是 $i$ 在 type $t_i$ 下的 expected payoff；求这个新 game 的 Nash equilibrium，再把同一个 $i$ 的各个 type 的 action 拼回 strategy $s_i$。这里新 game 有三个 player：P1、“想见面的 P2”、“想避开的 P2”，各有两个 action，一共 $2^3=8$ 个 profile。逐个检查，P1 选 F 时：想见面的 P2 要选 F，想避开的 P2 要选 B，这就是紧接着那个错误想法里的 (F, (F, B))，P1 想改 B，所以 P1 选 F 的四个 profile 都不行。P1 选 B 时，两种 type 的 best response 已经算过，只能是 (B, F)。所以 (B, (B, F)) 是唯一的 pure Bayesian Nash equilibrium。

Cheatsheet 还有一种等价的说法，叫 Nature selects a game：$G$ 是一组 game（这里是两张表），Nature 按 probability $P$ 选一张；每个 player 的 type set 是 $G$ 的一个 partition，player 只知道选中的 game 落在 partition 的哪一块。这里 P1 的 partition 只有一块 $\{\{g_1,g_2\}\}$（分不清），P2 的是 $\{\{g_1\},\{g_2\}\}$（分得清）。

:::wrong P2 知道自己的 type，所以 equilibrium 就是每张表各自的 Nash equilibrium 拼起来
第一张表里 (F, F) 是 Nash equilibrium，而且 P2 喜欢它（她得 2）。照这个想法拼出 (F, (F, B))：P1 选 F，P2 想见面时选 F、想避开时选 B。检查 P1：选 F，½ 遇到 F 得 1、½ 遇到 B 得 0，expected $\frac12$；改选 B，遇到 F 得 0、遇到 B 得 2，expected 1。P1 想改，所以它不是 Bayesian Nash equilibrium。P1 只有一个 action，必须同时对付两种 type。更何况第二张表单独看连 pure Nash equilibrium 都没有：(B, B) 时 P2 想改 F，(B, F) 时 P1 想改 F，(F, F) 时 P2 想改 B，(F, B) 时 P1 想改 B，和 matching pennies 一样转圈。
:::

### 例 2：Cournot with private cost

回到开头的 Cournot。Firm 2 的 strategy 是一对数 $(q_L,q_H)$：cost 0.75（low）时产 $q_L$，cost 1.25（high）时产 $q_H$。

**Firm 2 的每个 type。** 知道自己的 cost $c$，对 $q_1$ 做 best response。$u_2=q_2(2-q_1-q_2-c)$，和第 2 站一样令 derivative 为 0：

$$q_L=\frac{2-q_1-0.75}{2}=\frac{1.25-q_1}{2},\qquad q_H=\frac{2-q_1-1.25}{2}=\frac{0.75-q_1}{2}$$

**Firm 1。** 不知道 Firm 2 的 type，最大化 expected profit：

$$E[u_1]=\tfrac12\,q_1(1-q_1-q_L)+\tfrac12\,q_1(1-q_1-q_H)=q_1\big(1-q_1-E[q_2]\big),\qquad E[q_2]=\frac{q_L+q_H}{2}$$

形式和第 2 站一样，只是 $q_2$ 换成了它的 expectation，所以 $q_1=\frac{1-E[q_2]}{2}$。

**联立。** 把两个 type 的 best response 平均：$E[q_2]=\frac{(1.25-q_1)+(0.75-q_1)}{4}=\frac{1-q_1}{2}$。代进 Firm 1 的式子：

$$q_1=\frac{1-\frac{1-q_1}{2}}{2}=\frac{1+q_1}{4}\quad\Longrightarrow\quad q_1=\frac13$$

于是 $q_L=\frac{1.25-1/3}{2}=\frac{11}{24}\approx0.458$，$q_H=\frac{0.75-1/3}{2}=\frac{5}{24}\approx0.208$。验算：$E[q_2]=\frac12\left(\frac{11}{24}+\frac5{24}\right)=\frac13$，而 $\frac{1-1/3}{2}=\frac13$。

和 Firm 1 知道 cost 时比较。若 Firm 1 知道 cost 是 0.75，解 $q_1=\frac{1-q_2}{2}$、$q_2=\frac{1.25-q_1}{2}$：代入得 $q_1=\frac{0.75+q_1}{4}$，$q_1=\frac14$，$q_2=\frac12$。若知道是 1.25：$q_1=\frac{1.25+q_1}{4}$，$q_1=\frac5{12}$，$q_2=\frac{0.75-5/12}{2}=\frac16$。

::fig[ma4264-bayescournot] 空心点是 Firm 1 知道 cost 时的两个 equilibrium。Firm 1 不知道时只能选一个 $q_1=\frac13$（竖的虚线），两种 type 各自在虚线上找自己的 best response；两者的平均落在 Firm 1 的 best response line 上。

Low cost 的 Firm 2 在 incomplete information 下产得少了（$\frac{11}{24}<\frac12$），high cost 的产得多了（$\frac5{24}>\frac16$）。原因是 Firm 1 只能对平均的对手做 best response：面对 low cost 的对手，它产的 $\frac13$ 比知道时的 $\frac14$ 多，low cost 的 Firm 2 就少产一点；面对 high cost 的对手，$\frac13$ 比知道时的 $\frac5{12}$ 少，high cost 的 Firm 2 就多产一点。

### 例 3：first-price auction

两个 bidder 争一件东西，各自的 value $v_1$、$v_2$ 独立地服从 $[0,1]$ 上的 uniform distribution，各人只知道自己的。两人同时写下 bid，高者得，付自己的 bid。Value 就是 type，strategy 是 function $b(v)$。

第 1 站证明了 second-price auction 里 bid 自己的 value 是 weakly dominant 的。First-price 时 bid value 一定不好：赢了也只得 $v-v=0$。要把 bid 压低，在“赢的 probability”和“赢了赚多少”之间取舍。

课程（cheatsheet）的做法是猜 linear 的 strategy，但不假设对称，也不假设过原点：设对方 bid $b_j(v_j)=a_j+c_jv_j$，$c_j>0$。我的 value 是 $v_i$、bid 是 $b_i$，$a_j\le b_i\le a_j+c_j$ 时，我赢当且仅当 $a_j+c_jv_j<b_i$，即 $v_j<\frac{b_i-a_j}{c_j}$，probability 是 $\frac{b_i-a_j}{c_j}$（$v_j$ 连续，平局的 probability 是 0）。Expected payoff：

$$\pi(b_i)=(v_i-b_i)\,\frac{b_i-a_j}{c_j}$$

对 $b_i$ 求 derivative（product rule）：

$$\frac{-(b_i-a_j)+(v_i-b_i)}{c_j}=\frac{v_i+a_j-2b_i}{c_j}=0\quad\Longrightarrow\quad b_i=\frac{v_i+a_j}{2}=\frac{a_j}{2}+\frac12\,v_i$$

（这要求 $v_i\ge a_j$；value 比 $a_j$ 还低的人赢了也亏，不必管。）对方用 linear strategy 时，我的 best response 也是 linear 的，系数是 $a_i=\frac{a_j}{2}$、$c_i=\frac12$。对 $j$ 做同样的推导得 $a_j=\frac{a_i}{2}$。两式联立：$a_i=\frac{a_i}{4}$，所以 $a_i=a_j=0$。唯一的 linear Bayesian Nash equilibrium 是 $b_1(v_1)=\frac{v_1}{2}$、$b_2(v_2)=\frac{v_2}{2}$，对称是推出来的，不是假设的。

还要确认 $\frac v2$ 比所有 bid 都好，而不只是 derivative 为 0。对方 bid $\frac{v_2}{2}\le\frac12$。我 bid $b\le\frac12$ 时 $\pi(b)=(v-b)\cdot2b$ 是开口向下的 parabola，maximum 在 $b=\frac v2$，值是 $\frac{v^2}{2}$。我 bid $b>\frac12$ 时必赢，得 $v-b<v-\frac12$；而 $\frac{v^2}{2}-\left(v-\frac12\right)=\frac{(1-v)^2}{2}\ge0$，所以这也不比 $\frac v2$ 好。$b(v)=\frac v2$ 是 Bayesian Nash equilibrium。

Seller 的 expected revenue。成交价是 $\frac12\max(v_1,v_2)$。$\max(v_1,v_2)\le t$ 的 probability 是 $t^2$，nonnegative random variable 的 expectation 等于 $\int_0^\infty P(X>t)\,dt$，所以

$$E[\max(v_1,v_2)]=\int_0^1\big(1-t^2\big)\,dt=\frac23,\qquad\text{revenue}=\frac12\cdot\frac23=\frac13$$

Second-price auction 里两人都 bid value，成交价是 $\min(v_1,v_2)$，$\min(v_1,v_2)>t$ 的 probability 是 $(1-t)^2$：

$$E[\min(v_1,v_2)]=\int_0^1(1-t)^2\,dt=\frac13$$

两种 auction 的 expected revenue 都是 $\frac13$。6.254 第 17 讲说明这不是巧合：value 独立同分布、bidder risk neutral 等条件下，各种标准 auction 的 expected revenue 都相同（revenue equivalence）。那一讲对 $N$ 个 bidder 推出 first-price 的 bid 是 $\frac{N-1}{N}v$，$N=2$ 时就是 $\frac v2$；NUS Tutorial 6 第 5 题验证的也是这个 $N$ 人的 bid。

NUS Tutorial 7 第 6 题把 bidder 换成 risk averse 的：赢了得到的 $v_i-b_i$ 给他的 utility 是 $(v_i-b_i)^{\alpha_i}$，$0<\alpha_i\le1$。同样设对方 bid $a_j+c_jv_j$，expected utility 是 $(v_i-b_i)^{\alpha_i}\,\frac{b_i-a_j}{c_j}$，derivative 为 0：

$$-\alpha_i(v_i-b_i)^{\alpha_i-1}(b_i-a_j)+(v_i-b_i)^{\alpha_i}=0\quad\Longrightarrow\quad v_i-b_i=\alpha_i(b_i-a_j)\quad\Longrightarrow\quad b_i=\frac{v_i+\alpha_ia_j}{1+\alpha_i}$$

联立仍得 $a_i=a_j=0$，equilibrium bid 是 $b_i(v_i)=\frac{v_i}{1+\alpha_i}$。$\alpha_i=1$ 就是上面的 $\frac v2$；$\alpha_i$ 越小越 risk averse，bid 越高：输掉的风险比少赚一点更让他难受。两人的 $\alpha$ 相同时，成交价是 $\frac{\max(v_1,v_2)}{1+\alpha}$，expected revenue 是 $\frac{2/3}{1+\alpha}$；second-price 里 bid value 仍是 weakly dominant（第 1 站的分情形论证不涉及 utility 的形状），revenue 仍是 $\frac13$。$\alpha<1$ 时 $\frac{2/3}{1+\alpha}>\frac13$，revenue equivalence 在 risk aversion 下不成立，first-price 收得更多。

Bayesian game 里也可以有先后：知道自己 type 的人先动，后动的人从他的 action 推测他的 type。这是[第 8 站](#pbe)的内容。

:::from

### 没有 subgame 时，SPE 什么也排除不了

第 5 站用 subgame perfection 排除了走不到的地方的 threat。可是 subgame 必须从一个单独成为 information set 的 node 开始，information set 一多，subgame 就没有了。MIT 14.12 讲义第 16 章的例子（Figure 16.2）：P1 先在 X、T、B 里选；选 X，game 结束，payoff (2, 6)；选 T 或 B，轮到 P2 选 L 或 R，但 P2 看不到 P1 选的是 T 还是 B。

::fig[ma4264-pbetree] P2 的两个 node 在同一个 information set 里（虚线），$\mu$ 是她认为自己在 T 那个 node 的 probability。不管 $\mu$ 是多少，R 都比 L 好。彩线是后面求出的唯一 PBE (T, R)。

写成 strategic form：

| P1 \ P2 | L | R |
|---|---|---|
| **X** | (2, 6) | (2, 6) |
| **T** | (0, 1) | (3, 2) |
| **B** | (−1, 3) | (1, 5) |

逐格检查有两个 pure Nash equilibrium。(X, L)：给定 L，P1 选 X、T、B 分别得 2、0、−1，X 最好；给定 X，P2 的 L、R 都得 6，L 是 best response。(T, R)：给定 R，P1 得 2、3、1，T 最好；给定 T，P2 选 L 得 1、选 R 得 2，R 最好。其余格子都有人想动。

P2 的 information set 有两个 node，从其中任何一个开始都会把它切开，所以除了整个 game 没有别的 subgame，两个 Nash equilibrium 都是 SPE。可是 (X, L) 里的 L 很可疑：真走到 P2 那里，在 T 那个 node 上 R 给她 2 > 1，在 B 那个 node 上 R 给她 5 > 3，无论在哪个 node，R 都更好。P1 选 X，只是因为他相信了一个 P2 一旦有机会就不会执行的 L。这和 entry game 里的 F 是同一种 threat，只是 SPE 的定义够不着它。

### Belief 与四条 requirement

要在 information set 上谈“选哪个更好”，必须说清楚 mover 认为自己在哪个 node。

**Belief.** 在一个 information set 上，belief 是这个 information set 里各 node 上的一个 probability distribution。

上面的例子里，P2 的 belief 是 $\mu$（在 T 那个 node）和 $1-\mu$（在 B 那个 node）。她选 L 和 R 的 expected payoff：

$$L:\ \mu\cdot1+(1-\mu)\cdot3=3-2\mu,\qquad R:\ \mu\cdot2+(1-\mu)\cdot5=5-3\mu$$

两者之差 $(5-3\mu)-(3-2\mu)=2-\mu\ge1>0$，对每个 $\mu\in[0,1]$ 都是 R 更好。

NUS Tutorial 8 的 review 按 Gibbons 的写法给出四条 requirement：

1. 在每个 information set 上，轮到动的 player 有一个 belief。
2. **Sequential rationality**：给定 belief 和别人以后的 strategy，每个 player 在每个 information set 上的 action（以及他以后的 action）都使自己的 expected payoff 最大。
3. 在 equilibrium path 上的 information set（按 equilibrium strategy 会以 positive probability 走到），belief 由 Bayes' rule 和 equilibrium strategy 决定。
4. 在 equilibrium path 之外的 information set，belief 也尽可能由 Bayes' rule 和 equilibrium strategy 决定；Bayes' rule 用不上（分母是 0）时，belief 可以任取。

满足这四条的 strategy 加 belief 叫 perfect Bayesian equilibrium。Tutorial 8 写了三者的关系：PBE 的 strategy 一定是 SPE，SPE 一定是 Nash equilibrium，$\text{PBE}\subseteq\text{SPE}\subseteq\text{NE}$。所以 cheatsheet 建议的求法是先找出全部 Nash equilibrium，再逐个找 belief、检验 sequential rationality。

用在上面的例子：(X, L) 在任何 belief 下都违反 Requirement 2，不是 PBE。(T, R)：P1 选 T 的 probability 是 1，P2 的 information set 在 equilibrium path 上，Requirement 3 给出 $\mu=\frac{1}{1+0}=1$；R 在这个 belief 下最好，P1 给定 R 选 T 也最好。所以 (T, R) 配上 $\mu=1$ 是唯一的 PBE。

### Off-path 的 belief

Requirement 4 在 equilibrium path 之外留了很大的空间。Tutorial 8 第 2 题的 game (a)：P1 在 L、M、R 里选；选 R，game 结束，payoff (2, 2)；选 L 或 M，P2 在同一个 information set 上选 L′ 或 R′。设 P2 认为自己在 L 之后那个 node 的 probability 是 $p$。

| P1 \ P2 | L′ | R′ |
|---|---|---|
| **L** | (4, 1) | (0, 0) |
| **M** | (3, 0) | (0, 1) |
| **R** | (2, 2) | (2, 2) |

Pure Nash equilibrium 有两个。(L, L′)：给定 L′，P1 得 4、3、2，L 最好；给定 L，P2 的 L′ 得 1 > 0。(R, R′)：给定 R′，P1 得 0、0、2，R 最好；给定 R，P2 走不到，两个 action 都是 best response。没有别的 subgame，两个都是 SPE。

P2 的 expected payoff 是 L′：$p\cdot1+(1-p)\cdot0=p$，R′：$p\cdot0+(1-p)\cdot1=1-p$，所以 L′ 最好当且仅当 $p\ge\frac12$。

- (L, L′)：information set 在 path 上，Requirement 3 给出 $p=1$，L′ 最好。是 PBE。
- (R, R′)：P1 选 L 和 M 的 probability 都是 0，Bayes' rule 的分母是 0，Requirement 4 不限制 $p$。取任何 $p\le\frac12$，R′ 就是 sequentially rational 的。是 PBE，belief 是 $p\le\frac12$。

:::edge 四条 requirement 允许的 belief，不一定合理
(R, R′) 要求 P2 认为自己至少有一半可能在 M 之后。可是 M 被 P1 的一个 mixed strategy strictly dominate：$0.6L+0.4R$ 对 L′ 给 $0.6\cdot4+0.4\cdot2=3.2>3$，对 R′ 给 $0.6\cdot0+0.4\cdot2=0.8>0$。一个知道 P1 rational 的 P2，看到自己被叫到时应该认定 P1 选的是 L，$p=1$，于是选 L′；P1 预料到这一点就会选 L（4 > 2）。所以只剩 (L, L′)。PBE 的四条 requirement 不包含这一步推理，要排除 (R, R′) 得在 off-path 的 belief 上再加条件。这一段分析是为这一页写的。
:::

### Signaling game

最常见的一类 dynamic game of incomplete information 是 signaling game（cheatsheet 的定义）：

1. Nature 按 prior 抽出 sender 的 type $t\in T$。
2. Sender 看到 $t$，选一个 message $m\in M$。
3. Receiver 看到 $m$，看不到 $t$，选一个 action $a\in A$。
4. Payoff 由 $(t,m,a)$ 决定。

Sender 的 strategy 是 function $m(t)$，receiver 的 strategy 是 function $a(m)$。每个 message 后面，receiver 的几个 node（每个 type 一个）构成一个 information set，她在上面有 belief $\mu(t\mid m)$。所有 type 发同一个 message 的 sender strategy 叫 **pooling**，不同 type 发不同 message 的叫 **separating**；对应的 PBE 叫 pooling equilibrium、separating equilibrium。

Cheatsheet 写的求法：逐个检查 sender 的 strategy。对每一个：

1. 用 Bayes' rule 算出 path 上每个 message 之后的 belief：$\mu(t\mid m)=\dfrac{P(t)}{\sum_{t':\,m(t')=m}P(t')}$（只对发 $m$ 的那些 type）。
2. 求 receiver 在每个 path 上的 message 之后的 best response。没有 type 发的 message 在 path 外，belief 可以任取，记下“取什么 belief 时 receiver 会怎样做”。
3. 检查每个 type 的 sender 在 receiver 这样回应时，是否真的愿意发他该发的 message；对 path 外的 message，看能不能找到一个 belief 让 receiver 的回应吓住所有 type。

### 例：把四个 sender strategy 全部检查一遍

Tutorial 8 第 4 题的 Game 1：两种 type $t_1$、$t_2$ 各占 $\frac12$；sender 发 L 或 R；receiver 选 u 或 d。设 receiver 在 L 之后认为是 $t_1$ 的 probability 为 $p$，在 R 之后为 $q$。

::fig[ma4264-signal] 中间是 Nature，上半是 $t_1$、下半是 $t_2$；左右两条虚线是 receiver 在 L 之后、R 之后的 information set。四个 sender strategy 依次检查，彩线是 sender 的 message 和 receiver 在 path 上的回应，底下一行说明哪个 type 想偏离。第一帧是最后的答案 (RR, ud)。

Payoff 写成 (sender, receiver)：

| type | message | u | d |
|---|---|---|---|
| $t_1$ | L | (1, 2) | (2, 0) |
| $t_1$ | R | (0, 1) | (3, 0) |
| $t_2$ | L | (0, 0) | (3, 1) |
| $t_2$ | R | (1, 0) | (2, 2) |

Receiver 在两个 information set 上的 expected payoff：

$$\text{L 之后：}\ u\to2p,\quad d\to1-p,\qquad\text{u 最好当且仅当 }p\ge\tfrac13$$

$$\text{R 之后：}\ u\to q,\quad d\to2(1-q),\qquad\text{d 最好当且仅当 }q\le\tfrac23$$

Sender strategy 写成两个字母，依次是 $t_1$、$t_2$ 的 message。

- **LL（pooling on L）。** L 在 path 上，$p=\frac12\ge\frac13$，receiver 在 L 之后选 u。$t_2$ 发 L 得 0；改发 R，receiver 选 u 他得 1，选 d 他得 2，都比 0 多。不管 off-path 的 $q$ 取什么，$t_2$ 都想偏离。不是 PBE。
- **LR（separating）。** $p=1$，L 之后选 u；$q=0$，R 之后选 d。$t_1$ 发 L 得 1，改发 R 会遇到 d，得 3。不是 PBE。
- **RL（separating）。** $p=0$，L 之后选 d；$q=1$，R 之后选 u。$t_1$ 发 R 得 0，改发 L 会遇到 d，得 2。不是 PBE。
- **RR（pooling on R）。** $q=\frac12\le\frac23$，R 之后选 d。$t_1$ 得 3，$t_2$ 得 2。L 在 path 外。$t_1$ 改发 L 至多得 2 < 3，不会偏离；$t_2$ 改发 L，receiver 选 u 他得 0，选 d 他得 3 > 2。所以 receiver 在 L 之后必须选 u，要求 $p\ge\frac13$。

唯一的 pure PBE 是 sender 发 RR、receiver 用 ud（L 之后 u，R 之后 d），belief $q=\frac12$、$p\ge\frac13$。Tutorial 8 的 solution 从 strategic form 出发，得到 (RR, ud) 是唯一的 Nash equilibrium，再配上同样的 belief，两种做法结果一致。

:::wrong Off-path 的 belief 可以随便取，它不影响 equilibrium path 上发生什么
上例里 $p$ 决定了 $t_2$ 愿不愿意待在 R：$p<\frac13$ 时 receiver 在 L 之后选 d，$t_2$ 发 L 得 3 > 2，就去发 L，(RR, ud) 不再是 equilibrium。Off-path 的 belief 管的是“偏离以后会被怎样对待”，而这正是让人不偏离的东西。下面的 Beer–Quiche 里，path 上发生什么完全由 off-path 的 belief 决定。
:::

### Beer–Quiche：两个 pooling equilibrium

MIT 14.12 讲义第 16 章的例子。Sender 是 strong（prior 0.9）或 weak（0.1），早餐点 Beer 或 Quiche；receiver 看到早餐，决定 duel 或不 duel。Sender 点到自己喜欢的（strong 喜欢 Beer，weak 喜欢 Quiche）多得 1，没被 duel 多得 2；receiver 和 weak 的 duel 得 1，不和 strong 的 duel 得 1，其余为 0。

::fig[ma4264-beer] 同一种画法：上半 strong、下半 weak，左边 Beer、右边 Quiche。彩线是全点 Beer 的 pooling equilibrium：Beer 之后不 duel；Quiche 在 path 外，receiver 认为至少一半是 weak，duel。

Receiver 在某个早餐之后认为对方是 weak 的 probability 记作 $\mu$，duel 得 $\mu$，不 duel 得 $1-\mu$，所以 duel 当且仅当 $\mu\ge\frac12$。

**全点 Beer。** Beer 在 path 上，belief 是 prior，$\mu=0.1$，不 duel；strong 得 $1+2=3$，weak 得 $0+2=2$。Quiche 在 path 外，取 $\mu\ge\frac12$，receiver duel：weak 改点 Quiche 得 $1+0=1<2$，strong 得 $0+0=0<3$。是 PBE。

**全点 Quiche。** Quiche 之后 $\mu=0.1$，不 duel；strong 得 $0+2=2$，weak 得 $1+2=3$。Beer 在 path 外，取 $\mu\ge\frac12$，receiver duel：strong 改点 Beer 得 $1+0=1<2$，weak 得 0 < 3。也是 PBE。

**Separating 都不行。** Strong 点 Beer、weak 点 Quiche：receiver 看 Beer 不 duel、看 Quiche duel，weak 得 1，改点 Beer 得 2。Strong 点 Quiche、weak 点 Beer：receiver 看 Beer duel、看 Quiche 不 duel，weak 得 0，改点 Quiche 得 3。

所以 pure PBE 只有两个 pooling 的，path 上是全点 Beer 还是全点 Quiche，取决于 receiver 在没人点的那种早餐之后怎样想。第二个的 belief 很难说得通：在全点 Quiche 的 equilibrium 里 weak 已经得到 3，这是他在这个 game 里能得到的最高 payoff，改点 Beer 怎样都不会更好；唯一可能从改点 Beer 得益的是 strong（不被 duel 时得 3 > 2）。看到有人点 Beer 却认定他多半是 weak，等于认定一个绝不会得益的 type 在偏离。按这个理由剔除 off-path belief，叫 Cho 与 Kreps 的 intuitive criterion；用它检查全点 Beer：偏离到 Quiche 的 strong 至多得 2 < 3，weak 至多得 3 > 2，只有 weak 可能得益，所以 $\mu=1$，receiver duel，weak 也就不偏离，全点 Beer 留下。这一段推理是为这一页写的，14.12 讲义只给出两个 pooling equilibrium。

### Job-market signaling

Cheatsheet 和 Tutorial 9 的 job-market signaling：worker 的 ability $\eta$ 是 $\eta_H$ 或 $\eta_L$，只有自己知道；worker 选 education $e\in\{e_c,e_s\}$（college 或 school）；firm 看到 $e$，付 wage $w$。Worker 得 $w-c(\eta,e)$；ability 为 $\eta$、education 为 $e$ 的 worker 产出 $y(\eta,e)$。Firm 的 payoff 写成 $-(y-w)^2$，这代表 firm 之间的竞争把 wage 推到 expected output：在 belief $r=\mu(\eta_H\mid e)$ 下，firm 最大化

$$-r\,\big[y(\eta_H,e)-w\big]^2-(1-r)\,\big[y(\eta_L,e)-w\big]^2$$

对 $w$ 求 derivative 并令为 0：$2r\,[y(\eta_H,e)-w]+2(1-r)\,[y(\eta_L,e)-w]=0$，得

$$w^*(e)=r\,y(\eta_H,e)+(1-r)\,y(\eta_L,e)$$

**Separating 的条件（Tutorial 9 第 3 题）。** 设 $\eta_H$ 读 college、$\eta_L$ 不读。两个 message 都在 path 上，Bayes' rule 给出 $\mu(\eta_H\mid e_c)=1$、$\mu(\eta_H\mid e_s)=0$，wage 是 $w(e_c)=y(\eta_H,e_c)$、$w(e_s)=y(\eta_L,e_s)$。两种 type 都不想偏离：

$$\eta_H:\ y(\eta_H,e_c)-c(\eta_H,e_c)\ \ge\ y(\eta_L,e_s)-c(\eta_H,e_s)$$

$$\eta_L:\ y(\eta_L,e_s)-c(\eta_L,e_s)\ \ge\ y(\eta_H,e_c)-c(\eta_L,e_c)$$

移项合并：

$$c(\eta_H,e_c)-c(\eta_H,e_s)\ \le\ y(\eta_H,e_c)-y(\eta_L,e_s)\ \le\ c(\eta_L,e_c)-c(\eta_L,e_s)$$

中间是读 college 换来的 wage 增量，左边是 high ability 的人读 college 多付的 cost，右边是 low ability 的人多付的 cost。Separating 要求这份 wage 增量对 high ability 值得、对 low ability 不值得，所以 college 对 low ability 必须更难。

举一个数（为这一页构造）：education 本身不提高 output，$y(\eta,e)=\eta$，$\eta_H=2$，$\eta_L=1$；不读 college 没有 cost，读 college 对 high ability 的 cost 是 0.4、对 low ability 是 1.5。中间是 $2-1=1$，左边 0.4，右边 1.5，$0.4\le1\le1.5$，separating equilibrium 存在：high ability 读 college 得 $2-0.4=1.6$，装成 low ability 得 1；low ability 不读得 1，装成 high ability 得 $2-1.5=0.5$。College 在这里什么也不生产，它的作用只是让两种人分开。

:::edge Cost 可以拆开时，只有 pooling
Cheatsheet 写了一个结论：若 $c(\eta,e)=c_1(\eta)+c_2(e)$，任何 PBE 都是 pooling 的。用上面的条件看，左右两边都等于 $c_2(e_c)-c_2(e_s)$，separating 要求 wage 增量恰好等于它，这时两种 type 都 indifferent，数据稍一变动就不成立。直接看更清楚：worker 的 payoff 是 $w(e)-c_1(\eta)-c_2(e)$，$c_1(\eta)$ 与选哪个 $e$ 无关，所以给定 firm 的 wage，两种 type 对 $e_c$、$e_s$ 的偏好完全一样，一个严格喜欢 $e_c$ 时另一个也严格喜欢。于是只需检查两种 pooling。Pooling 在 $e_c$ 时 $\mu(\eta_H\mid e_c)$ 是 prior，wage 是 expected output；$e_s$ 在 path 外，取 belief $q=\mu(\eta_H\mid e_s)$，记 $B(\eta,e)=y(\eta,e)-c_2(e)$，不偏离的条件是

$$\tfrac12B(\eta_H,e_c)+\tfrac12B(\eta_L,e_c)\ \ge\ q\,B(\eta_H,e_s)+(1-q)\,B(\eta_L,e_s)$$

（prior 各 $\frac12$；两边都减掉了同一个 $c_1(\eta)$，所以两种 type 的条件相同。）$B$ 随 $\eta$ 增大时右边随 $q$ 增大，满足条件的 $q$ 是一个 interval $[0,\bar q]$。
:::

### 能签合同时，问题变了

前八站都假设 agreement 不能强制执行，所以 prisoner's dilemma 里“说好都 Cooperate”没有用，第 5 站的 bargaining 也只能靠 offer 和拒绝的先后来定。如果合同可以强制执行，人们可以先约好一起行动，再约好怎么分。问题变成：合作产生的价值怎么分，多人时还有哪些人会组成一伙（coalition）。

### 两个人：Nash bargaining solution

先看两个人。Tutorial 10 第 4 题：两人分 1 块钱，Player 1 分到 $x_1$ 的 utility 是 $\sqrt{x_1}$（risk averse），Player 2 分到 $x_2$ 的 utility 是 $x_2$；谈不拢两人都得 0。“公平地分”可以有很多种说法：平分钱，平分 utility，按别的比例。Nash（1950）不直接提一个分法，而是先列出一个分法规则应当满足的性质，再证明满足这些性质的规则只有一个。

**Bargaining problem.** 一个 two-person bargaining problem 是 $(F,d)$：$F\subseteq\mathbb R^2$ 是能达成的 utility pair $(u_1,u_2)$ 的 set，$d=(d_1,d_2)$ 是谈不拢时的 utility（disagreement point，也叫 threat point）。假设 $F$ closed、bounded、convex，并且有满足 $u\ge d$ 的点。Convex 的理由：如果 $u$、$u'$ 都能达成，以 probability $\lambda$ 执行 $u$、$1-\lambda$ 执行 $u'$，expected utility 是 $\lambda u+(1-\lambda)u'$。

分钱的例子里，令 $u_1=\sqrt{x_1}$、$u_2=x_2$，$x_1+x_2\le1$ 变成 $u_1^2+u_2\le1$，所以 $F=\{(u_1,u_2):u_1^2+u_2\le1,\ u_1,u_2\ge0\}$，$d=(0,0)$。

一个 solution 是给每个 $(F,d)$ 指定一个点 $f(F,d)\in F$ 的规则。IISc 的讲义列出 Nash 的五条 axiom：

1. **Strong efficiency.** 不存在 $u\in F$ 使 $u\ge f(F,d)$ 且至少一个分量严格大。
2. **Individual rationality.** $f(F,d)\ge d$。
3. **Scale covariance.** 对 $\lambda_1,\lambda_2>0$ 和任意 $\mu_1,\mu_2$，把每个人的 utility 换成 $\lambda_iu_i+\mu_i$（$F$ 和 $d$ 一起换），solution 也跟着这样换。Utility 的单位和零点本来就是任意的，换单位不该改变实际的分法。
4. **Independence of irrelevant alternatives（IIA）.** 若 $G\subseteq F$ 是 closed convex set，且 $f(F,d)\in G$，则 $f(G,d)=f(F,d)$。去掉一些本来就没被选中的选项，选中的不变。
5. **Symmetry.** 若 $d_1=d_2$ 且 $F$ 关于直线 $u_1=u_2$ 对称，则 $f_1(F,d)=f_2(F,d)$。

**Theorem（Nash）.** 满足这五条的 solution 恰好有一个：

$$f(F,d)=\arg\max\big\{(u_1-d_1)(u_2-d_2):\ u\in F,\ u\ge d\big\}$$

$(u_1-d_1)(u_2-d_2)$ 叫 Nash product。

**用在分钱上。** 最大值一定在边界 $u_2=1-u_1^2$ 上（不在边界的点可以把 $u_2$ 增大）。代进去，最大化 $g(u_1)=u_1(1-u_1^2)=u_1-u_1^3$：

$$g'(u_1)=1-3u_1^2=0\quad\Longrightarrow\quad u_1=\frac{1}{\sqrt3}\approx0.577,\qquad u_2=1-\frac13=\frac23$$

换回钱：$x_1=u_1^2=\frac13$，$x_2=\frac23$。Risk averse 的 Player 1 只分到三分之一。原因是 Nash product 看的是 utility 的增量：Player 1 的 $\sqrt{x_1}$ 在 $x_1$ 大时增长很慢，多给他一点钱换来的 utility 不多，Nash product 在这里愿意多给 Player 2。

::fig[ma4264-nash] Feasible set 的边界 $u_2=1-u_1^2$，和 Nash product 的 level curve $u_1u_2=k$。$k$ 增大时 level curve 往右上推，最后一条碰到 $F$ 的切点就是 Nash bargaining solution $(\frac1{\sqrt3},\frac23)$。

**Disagreement point 的作用。** Tutorial 10 第 3 题：$F$ 是圆心 $(2,2)$、半径 2 的 disk。$d=(2,2)$ 时，问题关于 $u_1=u_2$ 对称，solution 在 boundary 上 45° 的方向：$(2+\sqrt2,2+\sqrt2)$。$d=(0,2)$ 时最大化 $u_1(u_2-2)$；在 boundary 上写 $u_1=2+2\cos\theta$、$u_2=2+2\sin\theta$，Nash product 是 $4\sin\theta(1+\cos\theta)$，对 $\theta$ 求 derivative：

$$4\big[\cos\theta(1+\cos\theta)-\sin^2\theta\big]=4\big[2\cos^2\theta+\cos\theta-1\big]=4(2\cos\theta-1)(\cos\theta+1)$$

$\cos\theta=\frac12$，$\theta=60^\circ$，solution 是 $(3,\ 2+\sqrt3)\approx(3,\ 3.73)$。Player 1 谈不拢时的 utility 从 2 降到 0，solution 里他的 utility 从 $2+\sqrt2\approx3.41$ 降到 3，Player 2 从 3.41 升到 3.73。谈不拢时谁损失大，谁在谈判里就弱。

**为什么只有 Nash product。** IISc 讲义的证明分两部分。

第一部分，Nash product 的 maximizer $u^*$ 满足五条。Efficiency：Nash product 在 $u>d$ 时对每个分量严格增加，比 $u^*$ 更好的点会给出更大的 product。Individual rationality：约束里就有 $u\ge d$。Scale covariance：换单位以后 product 乘上 $\lambda_1\lambda_2>0$，maximizer 跟着换。IIA：$u^*\in G\subseteq F$，在 $F$ 上最大的点在更小的 $G$ 上仍最大。Symmetry：若 $u^*=(a,b)$ 是 maximizer，对称以后 $(b,a)$ 也在 $F$ 里且 product 相同；maximizer 唯一（product 在 $u>d$ 的区域上是 strictly quasi-concave 的），所以 $a=b$。

第二部分，任何满足五条的 $f$ 都给出 $u^*$。设有 $y\in F$ 使 $y>d$（否则问题退化，只剩 efficiency 和 individual rationality 能定的那一点）。

1. 用 scale covariance 换单位，把 $d$ 移到 $(0,0)$，把 $u^*$ 移到 $(1,1)$；换完以后的 set 记作 $G$，$(1,1)$ 是 $u_1u_2$ 在 $G$ 上的 maximizer。
2. $G$ 里每一点都满足 $u_1+u_2\le2$。若有 $y\in G$ 使 $y_1+y_2>2$，取 $z=(1-\varepsilon)(1,1)+\varepsilon y\in G$（$G$ convex），则

$$z_1z_2=\big(1+\varepsilon(y_1-1)\big)\big(1+\varepsilon(y_2-1)\big)=1+\varepsilon(y_1+y_2-2)+\varepsilon^2(y_1-1)(y_2-1)$$

$\varepsilon$ 足够小时一次项占上风，$z_1z_2>1$，与 $(1,1)$ 是 maximizer 矛盾。
3. 取一个关于 $u_1=u_2$ 对称、包含 $G$ 的 closed convex set $H$，使 $H$ 里每一点也满足 $u_1+u_2\le2$（例如 $\{u:u_1+u_2\le2,\ u_1\ge-K,\ u_2\ge-K\}$，$K$ 取得够大；$G$ bounded，所以装得下）。$H$ 的 efficient 点在 $u_1+u_2=2$ 上，symmetry 要求两个分量相等，所以 $f(H,(0,0))=(1,1)$。
4. $G\subseteq H$，而 $(1,1)\in G$，IIA 给出 $f(G,(0,0))=(1,1)$。
5. 用 scale covariance 换回原来的单位，$f(F,d)=u^*$。∎

:::wrong Nash bargaining solution 就是让两人的 utility 相等
分钱的例子里 solution 的 utility 是 $(0.577,\ 0.667)$，并不相等。“Utility 相等”这个规则还违反 scale covariance。按原来的单位，$\sqrt{x_1}=1-x_1$，令 $s=\sqrt{x_1}$，$s^2+s-1=0$，$s=\frac{\sqrt5-1}{2}\approx0.618$，Player 1 分到 $x_1=s^2\approx0.382$。把 Player 2 的 utility 改用“分”做单位（乘 100），这只是换单位，实际处境没变；“utility 相等”变成 $s=100(1-s^2)$，$100s^2+s-100=0$，$s\approx0.995$，Player 1 分到 $x_1\approx0.990$，几乎全拿。同一个处境换个单位，分法从 0.38 变成 0.99。Nash product 变成 $100\,u_1u_2$，maximizer 不变，仍是 $x_1=\frac13$。
:::

第 5 站的 alternating-offer bargaining 和这里是两种问法：那里写出谈判的步骤求 SPE，这里列出分法应有的性质。两人的 utility 都是 linear 时，Nash product $x(1-x)$ 在 $x=\frac12$ 最大，正好是第 5 站 $\frac1{1+\delta}$ 在 $\delta\to1$ 时的 limit。

### 多个人：characteristic function

下面换成多个人，并且 payoff 可以用钱在人之间自由转移，叫 transferable utility（TU）。这时一伙人能得到多少只用一个数描述。

一个例子（为这一页构造）：Player 1 有一栋房子，自己留着对他值 0。Player 2 认为它值 100，Player 3 认为值 80。只有 1 和某个买家在一起才能成交，成交产生的价值是买家的 value；付多少钱只是在人之间转移，不改变总量。

**Definition.** TU coalitional game 是 $(N,v)$：$N$ 是 player 的 set，characteristic function $v$ 给每个 coalition $S\subseteq N$ 一个数 $v(S)$，表示 $S$ 里的人不靠别人能共同得到的总价值，$v(\varnothing)=0$。

房子的例子：$v(\{1,2\})=100$，$v(\{1,3\})=80$，$v(\{1,2,3\})=100$（三人一起时把房子卖给价值高的 2），其余 coalition 都是 0（没有房子或者没有买家，什么也成交不了）。下面把 $v(\{1,2\})$ 简写成 $v(12)$，依此类推。

### Core：谁也拆不散的分法

**Definition.** 分法 $x$ 在 core 里，如果 $\sum_{i\in N}x_i=v(N)$，且对每个 coalition $S$，$\sum_{i\in S}x_i\ge v(S)$。

若某个 $S$ 分到的少于 $v(S)$，$S$ 里的人自己干就能每人都多拿，他们会 block 这个分法。Core 就是没有任何 coalition 想 block 的那些分法。

房子的例子，逐个写出 constraint：

- 单人：$x_1,x_2,x_3\ge0$。
- $x_1+x_2\ge100$。结合 $x_1+x_2+x_3=100$ 得 $x_3\le0$，所以 $x_3=0$。
- $x_1+x_3\ge80$，即 $x_1\ge80$。
- $x_2+x_3\ge0$，自动成立。

所以 core 是 $\{(x_1,\ 100-x_1,\ 0):80\le x_1\le100\}$。读法：房子卖给 2，price $x_1$ 在 80 到 100 之间，3 什么也得不到。Price 低于 80，1 和 3 会私下成交；高于 100，2 不会买。这正是两个买家竞争出来的 price 的范围。

::fig[ma4264-core] 三角形里每一点是一种分 100 的方法，离哪个顶点越近，那个人分得越多。Core 是左边那条边上的一小段。

**Core 可以是空的。** UBC CS532L 的例子：一个议会有四个 party，A 45 席、B 25 席、C 15 席、D 15 席，通过一笔 100 的支出至少要 51 票，通过它的 coalition 分这 100，否则大家都是 0。所以 $v(S)=100$ 当且仅当 $S$ 的席位合计至少 51。看其中四个 constraint：$x_A+x_B\ge100$，$x_A+x_C\ge100$，$x_A+x_D\ge100$，$x_B+x_C+x_D\ge100$。最后一个和总和 100 合起来给出 $x_A\le0$，即 $x_A=0$；代入前三个，$x_B$、$x_C$、$x_D$ 都至少 100，合计至少 300，超过 100。矛盾，core 是空的：不管怎样分，总有一伙人能另起炉灶。

**每个人分到的上限。** Tutorial 10 的最后两题给出两条很好用的性质。记 $\delta_i=v(N)-v(N\setminus\{i\})$，即 $i$ 离开时全体损失多少。若 $x$ 在 core 里，$N\setminus\{i\}$ 不 block，$\sum_{j\ne i}x_j\ge v(N\setminus\{i\})$，而 $\sum_jx_j=v(N)$，相减得

$$x_i\le v(N)-v(N\setminus\{i\})=\delta_i$$

对所有 $i$ 相加，$v(N)=\sum_ix_i\le\sum_i\delta_i$。所以若 $\sum_i\delta_i<v(N)$，core 是空的（tutorial 把这一条留作 assignment，上面的证明是这里写的）。议会的例子里，任何三个 party 都凑得够 51 席（最少的 B、C、D 是 55 席），$v(N\setminus\{i\})=100$，每个 $\delta_i=0$，$\sum\delta_i=0<100$，core 是空的，和上面一致。房子的例子里 $\delta_1=100-v(23)=100$，$\delta_2=100-v(13)=20$，$\delta_3=100-v(12)=0$；core 里的 $x_2\le20$、$x_3=0$ 正是这两个上限。

另一条：若 $i$ 是 null player（加入任何 coalition 都不改变它的 value），则 $v(N\setminus\{i\})=v(N)$，$\delta_i=0$，所以 $x_i\le0$；而单人 coalition 不 block 给出 $x_i\ge v(\{i\})=v(\varnothing)=0$。所以 null player 在 core 里分 0。

### Shapley value：先写下想要的性质

Core 可能是空的，也可能是一大片，它不给出一个确定的分法。Shapley（1953）换了个问法：一个合理的分法规则 $\varphi$ 应当满足什么，满足这些的规则有几个？四条 axiom：

1. **Efficiency.** $\sum_{i\in N}\varphi_i(v)=v(N)$，全部分完。
2. **Symmetry.** 若 $i$、$j$ 可以互换，即对每个不含 $i$、$j$ 的 $S$ 都有 $v(S\cup\{i\})=v(S\cup\{j\})$，则 $\varphi_i(v)=\varphi_j(v)$。
3. **Null player.** 若 $i$ 加入任何 coalition 都不改变它的价值，即对所有 $S$ 都有 $v(S\cup\{i\})=v(S)$，则 $\varphi_i(v)=0$。
4. **Additivity.** 两个 game 的 characteristic function 相加，分法也相加：$\varphi(v+w)=\varphi(v)+\varphi(w)$。

**Theorem.** 满足这四条的规则恰好有一个：

$$\varphi_i(v)=\frac{1}{n!}\sum_{\pi}\Big[v\big(P_\pi(i)\cup\{i\}\big)-v\big(P_\pi(i)\big)\Big]$$

其中 $\pi$ 取遍 $n$ 个 player 的所有 $n!$ 种排列，$P_\pi(i)$ 是排列 $\pi$ 里排在 $i$ 前面的那些人。

读法：让 player 按随机的顺序一个一个到达，每人拿走他到达时给 coalition 带来的增量（marginal contribution），$\varphi_i$ 是这个增量的平均。把排列按“$i$ 前面恰好是哪个 set $S$”归类，前面恰好是 $S$ 的排列有 $|S|!\,(n-|S|-1)!$ 个（$S$ 内部的顺序乘以 $i$ 后面那些人的顺序），得到等价的写法

$$\varphi_i(v)=\sum_{S\subseteq N\setminus\{i\}}\frac{|S|!\,(n-|S|-1)!}{n!}\Big[v(S\cup\{i\})-v(S)\Big]$$

房子的例子，六种到达顺序：

::fig[ma4264-orders] 每一行是一种到达顺序，方框里是这个人到达时 coalition 的价值增加了多少，浅色框是增量为正的。

$\varphi=\left(\frac{190}{3},\ \frac{70}{3},\ \frac{40}{3}\right)\approx(63.3,\ 23.3,\ 13.3)$，合计 100。3 从来没有买到房子，却分到 13.3：在“1 先到、3 第二个到”的顺序里，3 让 coalition 从 0 变成 80。Shapley value 把 3 作为竞争者的作用也算了进去。

议会的例子：A 排在第 2 或第 3 位时，前面的人加起来不够 51 票（至多两个小 party，40 票），加上 A 的 45 席就够了；排第 1 位时 45 席不够，排第 4 位时 B、C、D 已经凑够 55 席。24 种顺序里恰好一半让 A 成为那个关键的人，所以 $\varphi_A=50$；B、C、D 可以互换，各得 $\frac{50}{3}$。

先验证这个 formula 满足四条 axiom。Efficiency：在每一种顺序里，各人的增量依次相加，中间项前后相消，总和是 $v(N)-v(\varnothing)=v(N)$；对 $n!$ 种顺序取平均仍是 $v(N)$。Symmetry：把每个排列里的 $i$、$j$ 对调，是排列之间的一一对应，$i$ 在原排列里的增量等于 $j$ 在新排列里的增量。Null player：每个增量都是 0。Additivity：增量对 $v$ 是 linear 的。

### 为什么只有这一个

:::skip
这一小节是唯一性的证明。跳过它会少掉“四条 axiom 怎样逼出这个 formula”的理由，计算照用。
:::

关键是一类特别简单的 game。对非空的 $T\subseteq N$ 和实数 $c$，定义

$$c\,u_T(S)=\begin{cases}c,&T\subseteq S\\0,&\text{其他}\end{cases}$$

$u_T$ 叫 unanimity game：$T$ 里的人全部到齐才有价值。

**第一步：四条 axiom 决定每个 $c\,u_T$ 的分法。** $T$ 外的人加入任何 coalition 都不改变“$T$ 是否到齐”，是 null player，分 0。$T$ 里的人两两可以互换，分得一样多。Efficiency 要求总和为 $c$。所以 $i\in T$ 时 $\varphi_i(c\,u_T)=\frac{c}{|T|}$，否则为 0。

**第二步：任何 $v$ 都能写成这类 game 的和。** 按 coalition 从小到大递归地定义 $c_T=v(T)-\sum_{\varnothing\ne R\subsetneq T}c_R$。那么对任何非空的 $S$，

$$\sum_{T\ne\varnothing}c_T\,u_T(S)=\sum_{\varnothing\ne T\subseteq S}c_T=c_S+\sum_{\varnothing\ne R\subsetneq S}c_R=v(S)$$

第一个等号是因为 $u_T(S)=1$ 恰好当 $T\subseteq S$；第二个等号把 $T=S$ 那一项单独拿出来；第三个等号是 $c_S$ 的定义。所以 $v=\sum_Tc_T\,u_T$。

**第三步：用 additivity 拼起来。** $\varphi(v)=\sum_T\varphi(c_T\,u_T)$，每一项都由第一步决定，所以满足四条 axiom 的 $\varphi$ 只能有一个。∎

在房子的例子上走一遍。单人 coalition：$c_1=c_2=c_3=0$。两人：$c_{12}=100-0-0=100$，$c_{13}=80$，$c_{23}=0$。三人：$c_{123}=100-(0+0+0+100+80+0)=-80$。于是

$$\varphi_1=\frac{100}{2}+\frac{80}{2}-\frac{80}{3}=\frac{190}{3},\qquad\varphi_2=\frac{100}{2}-\frac{80}{3}=\frac{70}{3},\qquad\varphi_3=\frac{80}{2}-\frac{80}{3}=\frac{40}{3}$$

和六种顺序算出的一样。

### Shapley value 和 core 的关系

:::wrong Shapley value 是按贡献分的公平分法，所以它一定在 core 里
房子的例子里 $\varphi\approx(63.3,\ 23.3,\ 13.3)$，coalition $\{1,2\}$ 一共分到 $\frac{190}{3}+\frac{70}{3}=\frac{260}{3}\approx86.7$，而它们自己成交能得到 100。1 和 2 会撇开 3，比如以 90 成交，两人都比 Shapley value 多。Shapley value 回答的是“按这几条 axiom 怎样分算合理”，core 回答的是“怎样分没有人想拆伙”，两个答案可以不重合。议会的例子里 core 是空的，Shapley value 照样存在。
:::

什么时候两者一定相容？

**Definition.** Game 是 convex 的，如果一个人加入大的 coalition 带来的增量不少于加入小的：对 $S\subseteq T\subseteq N\setminus\{i\}$，

$$v(S\cup\{i\})-v(S)\le v(T\cup\{i\})-v(T)$$

房子的例子不是 convex 的：取 $i=3$、$S=\{1\}$、$T=\{1,2\}$，$v(13)-v(1)=80$，而 $v(123)-v(12)=0$。

**Theorem.** Convex game 的 Shapley value 在 core 里。

**Proof.** 先证每一种到达顺序 $\pi$ 给出的 marginal contribution 向量 $x^\pi$ 都在 core 里。Efficiency 上面已经证过。任取 coalition $S$，把它的成员按在 $\pi$ 里的先后记作 $s_1,\dots,s_k$。$s_j$ 到达时，前面的人 $P_\pi(s_j)$ 包含 $\{s_1,\dots,s_{j-1}\}$，对 $\{s_1,\dots,s_{j-1}\}\subseteq P_\pi(s_j)$ 用 convexity：

$$x^\pi_{s_j}=v\big(P_\pi(s_j)\cup\{s_j\}\big)-v\big(P_\pi(s_j)\big)\ \ge\ v(\{s_1,\dots,s_j\})-v(\{s_1,\dots,s_{j-1}\})$$

对 $j=1,\dots,k$ 相加，右边中间项前后相消，得 $\sum_{i\in S}x^\pi_i\ge v(S)$。所以每个 $x^\pi$ 都满足 core 的全部 constraint。Core 是一组 linear inequality 加一个等式的解集，是 convex set，里面的点取平均仍在里面，而 Shapley value 正是所有 $x^\pi$ 的平均。∎

:::back
Core 由一组 linear inequality 定义，和 [MA3252](../courses/MA3252.html#dual) 里 LP 的 feasible region 是同一种对象，判断 core 是否为空就是判断一个 LP 是否 feasible。
:::
