先看三个问题。

**第一个。** 一个车间做两种 product，每种消耗的 machine hour、labour 和 material 不同，每样资源都有上限。每种做多少，profit 最大？两个 variable 时可以画图碰运气，二十个 variable 时，“每种试几个数”的组合数就已经算不完了。

**第二个。** 两个仓库给三家店供货，每条路线的运费不同。怎么分配，总运费最低？可行的分配方案有无穷多个，而且每多一个仓库、一家店，问题就大一圈。

**第三个。** 一个 network 里每条 pipe 有 capacity，从 source 到 sink 最多能送多少？一个看起来合理的做法是“找一条还有空余的 path 就推满”，在第 7 站的例子里它停在 3，而答案是 4。

这三个问题有同一个形状：一组 linear 的 constraint 圈出一块区域，在区域里让一个 linear function 最大或最小。这门课回答三件事。最优解在哪里找：在 feasible region 的 corner 上，所以无穷多个候选缩成有限个（第 1、2 站）。怎样不枚举就找到它：沿着 edge 从一个 corner 走到更好的相邻 corner（第 3 站）。怎么知道找到的就是最优：每个 LP 都配着一个 dual problem，它的 solution 是一张可以当场核对的证书，同时告诉你每样资源值多少钱（第 4、5 站）。后三站处理 network：同一套理论在 network 上有更快的算法，而且答案自动是 integer（第 6、7 站）；答案必须是 integer 而 network 结构又不帮忙时，问题本质上变难（第 8 站）。

前五站用同一个例子贯穿到底。

## [model] LP 建模与 graphical solution

:::skip
能把文字描述写成 LP、在 plane 上画图求解，能化成 standard form，并且会把 $\max_i(\cdot)$ 和 $|\cdot|$ 的 objective 改写成 LP，就可以去第 2 站。

### 把一个生产计划写成 LP

车间做两种 product。每单位 product 1 用 2 个 machine hour、1 个 labour hour，profit 是 4；每单位 product 2 用 1 个 machine hour、1 个 labour hour、1 单位 material，profit 是 3。每周 machine hour 最多 10，labour hour 最多 7，material 最多 5。产量可以是分数（按吨算）。

设产量是 $x_1$、$x_2$。每一句话变成一个 inequality：

$$\begin{aligned}\max\quad&z=4x_1+3x_2\\\text{s.t.}\quad&2x_1+x_2\le10&&\text{(machine)}\\&x_1+x_2\le7&&\text{(labour)}\\&x_2\le5&&\text{(material)}\\&x_1,\ x_2\ge0\end{aligned}$$

Objective 和每个 constraint 都是 variable 的 linear function，这样的问题叫 linear program（LP）。“linear”意味着两条假设：每多做一单位，profit 和资源消耗都按同样的量增加（没有批量折扣）；两种 product 各算各的，相加即可（没有互相影响）。实际问题不满足时，要么近似，要么换别的模型。

### Graphical solution：把 level line 推到最远

每个 constraint 是 plane 上的一个 half-plane，五个 half-plane 的交集就是 feasible region。它的 corner 是相邻两条边界 line 的交点：

| corner | 哪两条 line 相交 | $z=4x_1+3x_2$ |
|---|---|---|
| $(0,0)$ | $x_1=0$，$x_2=0$ | 0 |
| $(5,0)$ | $x_2=0$，$2x_1+x_2=10$ | 20 |
| $(3,4)$ | $2x_1+x_2=10$，$x_1+x_2=7$ | 24 |
| $(2,5)$ | $x_1+x_2=7$，$x_2=5$ | 23 |
| $(0,5)$ | $x_2=5$，$x_1=0$ | 15 |

$(3,4)$ 那一行的来历：两个 equation 相减，$(2x_1+x_2)-(x_1+x_2)=10-7$，得 $x_1=3$，代回 $x_1+x_2=7$ 得 $x_2=4$。

为什么只看 corner？取一个值 $k$，所有满足 $4x_1+3x_2=k$ 的点组成一条 line，叫 level line，上面每个点的 profit 都是 $k$。$k$ 变大时，这条 line 沿 $c=(4,3)$ 的方向平行移动。要 $k$ 尽量大，就把 line 往 $c$ 的方向推，推到它即将离开 feasible region 为止，最后碰到的那一点就是 optimal solution。

::fig[ma3252-feasible] 五个 constraint 围出 feasible region（浅色）。虚线是 $z=12$、$z=20$ 两条 level line，粗线是 $z=24$，它只碰到 region 的一个点 $(3,4)$。

最后碰到的地方，要么是一个 corner，要么是一整条 edge（这时 edge 两端的 corner 也都 optimal）。所以只要比较 corner 就够了。第 2 站把这句话 prove 出来，并推广到任意 dimension。

### 四种结局

改动上面的数据，可以看到一个 LP 只有四种结局。

- **唯一的 optimal solution。** 原问题，$(3,4)$，$z=24$。
- **无穷多个 optimal solution。** 把 objective 改成 $4x_1+2x_2$，它是 machine constraint $2x_1+x_2$ 的 2 倍，level line 和那条 edge 平行。$(3,4)$ 和 $(5,0)$ 处都是 $z=20$，edge 上每一点都是。
- **Unbounded。** 去掉 machine 和 labour 两个 constraint，只剩 $x_2\le5$。沿 $x_1$ 方向可以无限走下去，$z\to\infty$，没有 optimal solution。
- **Infeasible。** 加一条“总产量至少 8”：$x_1+x_2\ge8$。它和 labour 的 $x_1+x_2\le7$ 矛盾，feasible region 是空集。

::fig[ma3252-outcomes] 四种结局各一张。从左到右：唯一的 optimal vertex；level line 与一条 edge 平行；region 沿一个方向无限延伸；两个 half-plane 没有交集。

### Standard form

画图只能处理两个 variable。为了写 algorithm，需要一个统一的形式。这一页用

$$\max\ c^\top x\quad\text{s.t.}\quad Ax=b,\quad x\ge0$$

把 inequality 变成 equation 的办法是加一个 slack variable：$2x_1+x_2\le10$ 写成 $2x_1+x_2+s_1=10$，$s_1\ge0$，$s_1$ 就是没用完的 machine hour。$\ge$ 的 constraint 则减去一个 surplus variable：$x_1+x_2\ge8$ 写成 $x_1+x_2-e=8$，$e\ge0$。一个没有 sign 限制的 variable $x_j$ 写成 $x_j=x_j^+-x_j^-$，两部分都 $\ge0$。Minimize $c^\top x$ 等价于 maximize $-c^\top x$。

例子化成 standard form，variable 是 $(x_1,x_2,s_1,s_2,s_3)$：

$$\begin{pmatrix}2&1&1&0&0\\1&1&0&1&0\\0&1&0&0&1\end{pmatrix}\begin{pmatrix}x_1\\x_2\\s_1\\s_2\\s_3\end{pmatrix}=\begin{pmatrix}10\\7\\5\end{pmatrix},\qquad c=(4,3,0,0,0)$$

$A$ 是 $3\times5$ 的，$m=3$ 个 equation，$n=5$ 个 variable。

:::note Sign convention
NUS 这门课用的是 min：Spring 2026 的参考书是 Bertsimas–Tsitsiklis，学生 AY23/24 的 midterm helpsheet 上 standard form 写的是 $\min c^\top x$ s.t. $Ax=b$，$x\ge0$，max 问题先改写成 $\min -c^\top x$。这一页一律用 max，和车间例子保持一致。两者只差一个负号，对照着读时这样翻译：

| | 这一页（max） | NUS 和 MIT 15.093（min） |
|---|---|---|
| optimal 的条件 | 所有 reduced cost $\bar c_j\le0$ | 所有 $\bar c_j\ge0$ |
| entering variable | 选 $\bar c_j>0$ 的 | 选 $\bar c_j<0$ 的 |
| ratio test | $u=B^{-1}A_j$，$\min\{x_{B(i)}/u_i:u_i>0\}$ | $d_B=-B^{-1}A_j$，$\min\{x_{B(i)}/(-d_i):d_i<0\}$ |

Ratio test 那一行两边算的是同一个数，因为 $d_B=-u$。把第 3 站的例子写成 $\min -4x_1-3x_2$，final tableau 里 $s_1$、$s_2$ 的 reduced cost 就从 $-1$、$-2$ 变成 $1$、$2$，全部 $\ge0$，同样判定 optimal。
:::

### 不是 linear 的 objective 也能写成 LP

很多实际问题的 objective 不是 linear 的，但能改写成 LP。

拿 DSA2102 第 4 站的三个 data point $(1,1)$、$(2,2)$、$(3,2)$ 来说，要找一条 line $y=C+Dt$。[Least squares](DSA2102.html#ls) 让 error 的 sum of squares 最小。如果关心的是最坏的那个点，要的是

$$\min_{C,D}\ \max_i\ |C+Dt_i-y_i|$$

$\max$ 和 $|\cdot|$ 都不是 linear 的。办法是引入一个新 variable $r$，要求它压住每一个 error：

$$\min\ r\quad\text{s.t.}\quad -r\le C+Dt_i-y_i\le r,\qquad i=1,2,3$$

这是一个 LP，variable 是 $C$、$D$、$r$。为什么等价：对固定的 $C$、$D$，constraint 说的是 $r\ge$ 每个 $|{\rm error}_i|$，也就是 $r\ge\max_i|{\rm error}_i|$；minimize $r$ 会把它压到恰好等于这个 max。所以两个问题的 optimal value 相同，optimal 的 $C$、$D$ 也相同。

解出来 $C=0.75$，$D=0.5$，$r=0.25$。三个 error 是

$$0.75+0.5-1=0.25,\qquad0.75+1-2=-0.25,\qquad0.75+1.5-2=0.25$$

大小相同，符号交替。Least squares 的 line 是 $C=\tfrac23$、$D=\tfrac12$，三个 error 是 $\tfrac16$、$-\tfrac13$、$\tfrac16$，最大的是 $\tfrac13>0.25$。

同样的办法也能 minimize error 的 absolute value 之和：每个点配一个 $r_i$，$\min\sum_ir_i$ s.t. $-r_i\le C+Dt_i-y_i\le r_i$。解出来是 $C=D=0.5$，line 恰好穿过 $(1,1)$ 和 $(3,2)$，error 是 $0$、$-0.5$、$0$，总和 $0.5$。

::fig[ma3252-fit] 三个 data point，三种 error 的衡量方式给出三条不同的 line。minimax 的 line 让三个 error 一样大；sum of absolute values 的 line 穿过两个点，把 error 都集中到中间那个点上。

EE364A 把这个办法写成一般形式：$\min_x\max_i(a_i^\top x+b_i)$ 等价于 $\min t$ s.t. $a_i^\top x+b_i\le t$。新 variable $t$ 是 objective 的上界，所有满足 constraint 的 $(x,t)$ 恰好是 objective 的 graph 上方那一块（epigraph）。

:::wrong 只要用同样的 trick，带 absolute value 的 objective 都能写成 LP
Trick 能用，是因为 minimize 会把 $r$ 往下压，压到碰到 $|{\rm error}|$ 为止。换成 maximize $|x|$ s.t. $-1\le x\le2$，写成 $\max r$ s.t. $-r\le x\le r$，$r$ 就可以无限变大：取 $x=0$，任何 $r\ge0$ 都满足 constraint，LP unbounded，而原问题的答案是 $|2|=2$。

区别在 convexity。$\max_i(a_i^\top x+b_i)$ 和 $|x|$ 是 convex function，minimize convex function 可以写成 LP；maximize 它们则是在 minimize 一个 concave function，答案落在若干个分开的地方（这里 $x=-1$ 和 $x=2$ 各是一个 local maximum），只能把每一段分开解，或者用第 8 站的 integer variable。[DSA3102 第 1 站](DSA3102.html#convex)讲了为什么 convexity 决定了 local 能否推出 global。
:::

:::from
LP 的定义、“feasible set 是 polyhedron、optimal 在 vertex、$-c$ 指向 objective 下降方向”的那张图、piecewise-linear minimization 的 epigraph 写法，来自 [EE364A 的 Convex optimization problems slides](https://web.stanford.edu/class/ee364a/lectures/problems.pdf)。Standard form 的几种转换和“四种结局”的分类来自 [MIT 15.093 Lecture 2](https://ocw.mit.edu/courses/15-093j-optimization-methods-fall-2009/resources/mit15_093j_f09_lec02/)。NUS 用 min 的 standard form、max 先改写成 min、$\min|x|$ 写成 $\min t$ s.t. $t\ge x$，$t\ge-x$ 这几条，核对的是[学生 AY23/24 的 midterm helpsheet](https://snoidetx.github.io/Snoidepaedia/resource/pdf/NUS-MA3252-MidtermExaminationHelpsheet.pdf)，NUS 的 lecture notes 本身读不到。车间的例子、三个 data point 的 minimax 与 absolute value 拟合是为这一页构造并用 `scipy.optimize.linprog` 实际解过的；那个 absolute value 的 :::wrong 是自己加的。
:::

## [geom] Polyhedron、vertex 与 basic feasible solution

:::skip
能对 standard form 选 basis、算 basic solution、判断它是哪个 corner，并能说清“为什么 optimal solution 一定能在 corner 上找到”，就可以去第 3 站。
:::

### 三种 corner

第 1 站靠画图说“corner”。超过三个 variable 就画不出来了，需要一个能计算的定义。先定名词：有限个 half-space $\{x:a_i^\top x\le b_i\}$ 的交集叫 polyhedron。Standard form 的 feasible region $P=\{x:Ax=b,\ x\ge0\}$ 是一个 polyhedron（每个 equation 是两个 half-space 的交集）。

“corner”可以从三个角度定义：

- **Extreme point**：$x\in P$，不能写成 $P$ 里另外两个点的 strict convex combination。即：若 $x=\lambda y+(1-\lambda)w$，$y,w\in P$，$0<\lambda<1$，则 $y=w=x$。这是几何的说法：corner 不在任何 segment 的中间。
- **Vertex**：存在某个 $c$，使 $x$ 是 $\max c^\top y$ over $P$ 的唯一 optimal solution。这是 optimization 的说法：corner 是某个方向上最远的那一点。
- **Basic feasible solution（BFS）**：下面这个代数的定义。

### Basic solution：把 corner 变成一次 linear system

Standard form 有 $m$ 个 equation、$n$ 个 variable，$n>m$。假设 $A$ 的 $m$ 个 row linearly independent。做法分三步：

1. 选 $m$ 个 column，要求它们 linearly independent，组成 $m\times m$ 的 matrix $B$，叫 basis。对应的 variable 叫 basic variable，其余的叫 nonbasic variable。
2. 令所有 nonbasic variable 等于 0。
3. 解 $Bx_B=b$，得 $x_B=B^{-1}b$。

这样得到的 $x$ 叫 basic solution；如果它还满足 $x\ge0$，就叫 basic feasible solution。

在例子里，$m=3$、$n=5$，从 5 个 column 里选 3 个，共 $\binom53=10$ 种选法。逐一算出来：

| basic variables | nonbasic $=0$ | $(x_1,x_2,s_1,s_2,s_3)$ | feasible？ | 对应的点 |
|---|---|---|---|---|
| $s_1,s_2,s_3$ | $x_1,x_2$ | $(0,0,10,7,5)$ | 是 | $(0,0)$ |
| $x_1,s_2,s_3$ | $x_2,s_1$ | $(5,0,0,2,5)$ | 是 | $(5,0)$ |
| $x_1,x_2,s_3$ | $s_1,s_2$ | $(3,4,0,0,1)$ | 是 | $(3,4)$ |
| $x_1,x_2,s_1$ | $s_2,s_3$ | $(2,5,1,0,0)$ | 是 | $(2,5)$ |
| $x_2,s_1,s_2$ | $x_1,s_3$ | $(0,5,5,2,0)$ | 是 | $(0,5)$ |
| $x_1,x_2,s_2$ | $s_1,s_3$ | $(2.5,5,0,-0.5,0)$ | 否，$s_2<0$ | $(2.5,5)$ |
| $x_1,s_1,s_3$ | $x_2,s_2$ | $(7,0,-4,0,5)$ | 否，$s_1<0$ | $(7,0)$ |

| $x_2,s_2,s_3$ | $x_1,s_1$ | $(0,10,0,-3,-5)$ | 否 | $(0,10)$ |
| $x_1,s_1,s_2$ | $x_2,s_3$ | 无解 | | |

拿第三行核对一次：$s_1=s_2=0$ 时前两个 equation 是 $2x_1+x_2=10$、$x_1+x_2=7$，解出 $x_1=3$、$x_2=4$；第三个 equation $x_2+s_3=5$ 给出 $s_3=1$。最后一行的三个 column 是 $(2,1,0)$、$(1,0,0)$、$(0,1,0)$，第三个 entry 全是 0，linearly dependent，选不出 basis。几何上，$x_2=0$ 和 $x_2=5$ 是两条 parallel 的 line，没有交点。

“令一个 variable 等于 0”在 plane 上就是“站到一条边界 line 上”：$x_1=0$ 是 vertical axis，$s_1=0$ 是 machine 那条 line。选两个 nonbasic variable 就是选两条 line 取交点。五条 line 两两相交，得到上表的 9 个交点，其中 5 个在 region 上，正是第 1 站的五个 corner。

::fig[ma3252-bases] 五条边界 line 两两的交点就是全部 basic solution。实心点是 BFS，即 region 的 corner；空心点是 infeasible 的 basic solution，旁边标着哪个 variable 变成了 negative。

### 三个定义说的是同一个点

**Theorem.** 对 $P=\{x:Ax=b,\ x\ge0\}$ 里的点 $x$，以下三条等价：$x$ 是 vertex；$x$ 是 extreme point；$x$ 是 BFS。

按 vertex ⇒ extreme point ⇒ BFS ⇒ vertex 的顺序证。

**Vertex ⇒ extreme point。** 设 $x$ 是 $\max c^\top y$ 的唯一 optimal solution，又设 $x=\lambda y+(1-\lambda)w$，$y,w\in P$，$0<\lambda<1$。因为 $x$ optimal，$c^\top y\le c^\top x$，$c^\top w\le c^\top x$。如果其中有一个是 strict 的，那么 $c^\top x=\lambda c^\top y+(1-\lambda)c^\top w<c^\top x$，矛盾。所以 $c^\top y=c^\top w=c^\top x$，$y$ 和 $w$ 也都 optimal。唯一性给出 $y=w=x$。

**Extreme point ⇒ BFS。** 设 $x$ 是 extreme point，记它的 positive component 的 index 集合为 $J=\{j:x_j>0\}$。先证 $\{A_j:j\in J\}$ 这些 column linearly independent。反设不然，存在不全为 0 的 $d_j$（$j\in J$）使 $\sum_{j\in J}d_jA_j=0$；对 $j\notin J$ 令 $d_j=0$，于是 $Ad=0$。取很小的 $\varepsilon>0$，使得对所有 $j\in J$ 都有 $\varepsilon|d_j|<x_j$。那么

$$A(x\pm\varepsilon d)=Ax\pm\varepsilon Ad=b,\qquad x\pm\varepsilon d\ge0$$

第二条成立是因为 $j\in J$ 时 $x_j\pm\varepsilon d_j\ge x_j-\varepsilon|d_j|>0$，$j\notin J$ 时两边都是 0。所以 $x+\varepsilon d$ 和 $x-\varepsilon d$ 都在 $P$ 里，而 $x$ 是它们的中点，$\lambda=\tfrac12$，与 extreme point 矛盾。

这些 column 至多 $m$ 个。$A$ 的 rank 是 $m$，所以可以再从其余 column 里补几个，凑成 $m$ 个 linearly independent 的 column，作为 basis $B$。补进来的 column 对应的 $x_j=0$，不在 basis 里的 column 对应的 $x_j$ 也是 0，所以 $x$ 正是这个 basis 给出的 basic solution，并且 $x\ge0$。

**BFS ⇒ vertex。** 设 $x$ 是 basis $B$ 给出的 BFS，nonbasic index 集合是 $N$。取 $c_j=0$（$j$ basic），$c_j=-1$（$j\in N$）。对任何 $y\in P$，$c^\top y=-\sum_{j\in N}y_j\le0=c^\top x$，所以 $x$ optimal。若 $c^\top y=0$，则所有 $y_j=0$（$j\in N$），于是 $By_B=b$，$y_B=B^{-1}b=x_B$，$y=x$。唯一。

用例子检验最后一步：$(3,4)$ 的 nonbasic variable 是 $s_1$、$s_2$，取 objective $-s_1-s_2$。代入 $s_1=10-2x_1-x_2$、$s_2=7-x_1-x_2$，它等于 $3x_1+2x_2-17$。在 $(3,4)$ 处是 0；在 $(0,0)$、$(5,0)$、$(2,5)$、$(0,5)$ 处分别是 $-17$、$-2$、$-1$、$-7$，都更小。

### Optimal solution 一定能在 BFS 上找到

**Theorem.** 若 standard form 的 LP 有 optimal solution，则有一个 BFS 是 optimal 的。

**Proof.** 在所有 optimal solution 里取一个 positive component 最少的，记作 $x$，$J=\{j:x_j>0\}$。如果 $\{A_j:j\in J\}$ linearly independent，按上一个 proof 的后半段，$x$ 是 BFS，证完。

否则像上面一样取 $d\ne0$，$Ad=0$，$d$ 只在 $J$ 上非零，$x\pm\varepsilon d$ 都 feasible。两个点的 objective 是 $c^\top x\pm\varepsilon c^\top d$，都不能超过 optimal value $c^\top x$，所以 $c^\top d=0$：沿 $d$ 的整条 line 上 objective 不变。

$d$ 至少有一个 component 是 negative 的（如果都 $\ge0$，就把 $d$ 换成 $-d$）。从 $x$ 出发沿 $d$ 走 $\theta$，走到第一个 component 变成 0 为止：

$$\theta^*=\min\Big\{\frac{x_j}{-d_j}:d_j<0\Big\}>0$$

新的点 $x+\theta^*d$ 仍然 feasible，objective 不变所以仍然 optimal，而 positive component 至少少了一个。这和 $x$ 的选法矛盾。∎

这个 proof 里“沿着一个保持 $Ax=b$ 的方向走，走到某个 variable 碰到 0”的动作，就是第 3 站 simplex 每一步做的事。

:::wrong Corner 只有有限个，把所有 basic solution 枚举一遍就能解 LP
有限不等于少。$m$ 个 equation、$n$ 个 variable 的 standard form，basis 的候选是 $\binom nm$ 个。例子里是 $\binom53=10$。一个 $m=50$、$n=100$ 的小问题，候选有 $\binom{100}{50}\approx1.0\times10^{29}$ 个，每秒检查 $10^{9}$ 个也要 $3\times10^{12}$ 年。实际问题里 $n$ 成千上万。需要一个只走“好”的 corner 的办法，这就是 simplex。
:::

:::edge Degenerate 的 BFS
在 plane 上，一个 corner 通常恰好是两条边界 line 的交点。如果把 labour 的上限从 7 改成 7.5，三条 line $2x_1+x_2=10$、$x_1+x_2=7.5$、$x_2=5$ 同时过 $(2.5,5)$。这时 nonbasic 选 $\{s_1,s_2\}$ 或 $\{s_1,s_3\}$ 或 $\{s_2,s_3\}$ 都得到同一个点，而且每个 basis 里都有一个 basic variable 恰好等于 0。这样的 BFS 叫 degenerate：一个点对应好几个 basis。第 3 站会看到它让 simplex 原地换 basis。
:::

:::edge 没有 corner 的 polyhedron
$\{(x_1,x_2):x_1+x_2\ge1\}$ 是一个 half-plane，它包含整条 line（沿 $(1,-1)$ 方向两头无限延伸），一个 corner 也没有。MIT 15.093 Lecture 2 给出的 theorem 是：nonempty 的 polyhedron 有 BFS，当且仅当它不包含 line。Standard form 有 $x\ge0$，不可能包含 line（沿任何 $d\ne0$ 双向走，总有一头让某个 component 变 negative），所以只要 nonempty 就有 BFS。这也是把问题化成 standard form 的一个理由。
:::

:::back
例子和 standard form 来自[第 1 站](#model)。
:::

:::from
三种定义、“BFS 的构造三步”、degeneracy、“polyhedron 不含 line 才有 BFS”的 theorem、“有 optimal 就有 optimal 的 extreme point”的 theorem，来自 [MIT 15.093 Lecture 2](https://ocw.mit.edu/courses/15-093j-optimization-methods-fall-2009/resources/mit15_093j_f09_lec02/)。那份 slides 只陈述了 theorem，没有给 proof。三个 implication 的 proof 对照的是 [Waterloo 的 Geometry of LP 讲义](https://www.math.uwaterloo.ca/~mhough/assets/geometry-of-lp.pdf)：它按 $Ax\ge b$ 的一般形式写，extreme point ⇒ BFS 一步用的是“active constraint 不够 $n$ 个就有方向 $d$ 让 $x\pm\varepsilon d$ 都 feasible”，BFS ⇒ vertex 一步取 $c=\sum_{i\text{ active}}a_i$。这里改写成 standard form 的版本（active constraint 换成“positive component 的 column”，$c$ 取 nonbasic 处为 $-1$），是自己改写的。Optimal BFS 存在性：那份讲义的 proof 是“optimal solution 的集合 $Q$ 也是不含 line 的 polyhedron，所以有 extreme point，它也是 $P$ 的 extreme point”，要借用“不含 line 就有 extreme point”这个没在讲义里证明的 theorem；这里换成“取 positive component 最少的 optimal solution”的论证，不依赖那个 theorem，是凭自己的知识写的。“nonempty 的 standard form polyhedron 一定有 BFS”和“有 optimal 就有 optimal BFS”在[学生 AY23/24 的 helpsheet](https://snoidetx.github.io/Snoidepaedia/resource/pdf/NUS-MA3252-MidtermExaminationHelpsheet.pdf)上也列着，可见是 NUS 期中的范围。10 个 basis 的表是用 numpy 实际算的。
:::

## [simplex] Simplex method

:::skip
能从一个 BFS 出发做 pivot 直到 optimal，会用 two-phase 找起点，并能说清 reduced cost 全部 $\le0$ 为什么就意味着 optimal，就可以去第 4 站。
:::

### 从 origin 出发，一次只放开一个 variable

起点取 $(0,0)$：basic variable 是三个 slack，nonbasic 是 $x_1$、$x_2$。把每个 basic variable 和 $z$ 都写成 nonbasic variable 的 function：

$$\begin{aligned}s_1&=10-2x_1-x_2\\s_2&=7-x_1-x_2\\s_3&=5-x_2\\z&=4x_1+3x_2\end{aligned}$$

现在 $x_1=x_2=0$，$z=0$。$z$ 那一行说：$x_1$ 每增加 1，$z$ 增加 4；$x_2$ 每增加 1，$z$ 增加 3。两者都能改进，先选 $x_1$，$x_2$ 保持 0。

$x_1$ 能增加多少？三个 slack 不能变 negative：$s_1=10-2x_1\ge0$ 要求 $x_1\le5$；$s_2=7-x_1\ge0$ 要求 $x_1\le7$；$s_3=5$ 和 $x_1$ 无关。最紧的是 $x_1\le5$，到 $x_1=5$ 时 $s_1$ 变成 0。于是 $x_1$ 进 basis（entering variable），$s_1$ 出 basis（leaving variable）。几何上，从 $(0,0)$ 沿 $x_1$ axis 走到 $(5,0)$。

把 $s_1$ 那一行解出 $x_1$：$x_1=5-\tfrac12x_2-\tfrac12s_1$，代进其他行：

$$\begin{aligned}x_1&=5-\tfrac12x_2-\tfrac12s_1\\s_2&=7-\big(5-\tfrac12x_2-\tfrac12s_1\big)-x_2=2-\tfrac12x_2+\tfrac12s_1\\s_3&=5-x_2\\z&=4\big(5-\tfrac12x_2-\tfrac12s_1\big)+3x_2=20+x_2-2s_1\end{aligned}$$

$z=20$。$z$ 那一行里 $x_2$ 的 coefficient 是 $+1$，还能改进；$s_1$ 的是 $-2$，增加它会变差。让 $x_2$ 进来：$x_1=5-\tfrac12x_2\ge0$ 要求 $x_2\le10$；$s_2=2-\tfrac12x_2\ge0$ 要求 $x_2\le4$；$s_3=5-x_2\ge0$ 要求 $x_2\le5$。最紧的是 4，$s_2$ 出去。从 $s_2$ 那一行解出 $x_2=4+s_1-2s_2$，代回：

$$\begin{aligned}x_2&=4+s_1-2s_2\\x_1&=5-\tfrac12(4+s_1-2s_2)-\tfrac12s_1=3-s_1+s_2\\s_3&=5-(4+s_1-2s_2)=1-s_1+2s_2\\z&=20+(4+s_1-2s_2)-2s_1=24-s_1-2s_2\end{aligned}$$

现在 $x=(3,4)$，$z=24$。$z$ 那一行的两个 coefficient 都是 negative。

最后这个式子本身就是 optimality 的 proof。$z=24-s_1-2s_2$ 对每一个 feasible point 都成立，因为它只是把 equation 换了个写法；而 feasible point 满足 $s_1,s_2\ge0$，所以 $z\le24$。不需要看图，也不需要和别的 corner 比较。

### Reduced cost：一般情形的停止条件

把上面的代入写成 matrix。按 basis 把 column 分成 $A=[B\ N]$，$x=(x_B,x_N)$，$c=(c_B,c_N)$。$Ax=b$ 是 $Bx_B+Nx_N=b$，所以

$$x_B=B^{-1}b-B^{-1}Nx_N$$

代进 objective：

$$z=c_B^\top x_B+c_N^\top x_N=c_B^\top B^{-1}b+\big(c_N^\top-c_B^\top B^{-1}N\big)x_N$$

括号里的 vector 叫 reduced cost，第 $j$ 个是 $\bar c_j=c_j-c_B^\top B^{-1}A_j$。它就是上面 $z$ 那一行里 nonbasic variable 的 coefficient。

**Theorem.** 若 BFS $x$ 的所有 reduced cost $\bar c_j\le0$，则 $x$ optimal（max 问题）。

**Proof.** 取任意 feasible 的 $y$。上面的 identity 对 $y$ 同样成立：$c^\top y=c_B^\top B^{-1}b+\sum_{j\in N}\bar c_jy_j$。第一项就是 $c^\top x$（因为 $x_N=0$）。$y\ge0$ 而 $\bar c_j\le0$，所以 $\sum_{j\in N}\bar c_jy_j\le0$，$c^\top y\le c^\top x$。∎

在例子的最后一步，$B$ 由 $x_1,x_2,s_3$ 的 column 组成，$\bar c_{s_1}=-1$，$\bar c_{s_2}=-2$，就是 $z=24-s_1-2s_2$ 的两个 coefficient。

### Ratio test：走多远

若某个 $\bar c_j>0$，让 $x_j$ 从 0 增加到 $\theta$，其他 nonbasic 保持 0。basic variable 跟着变：$x_B=B^{-1}b-\theta\,u$，其中 $u=B^{-1}A_j$。$z$ 增加 $\theta\bar c_j$。

$u_i\le0$ 的那些 basic variable 不减少，不构成限制；$u_i>0$ 的那些在 $\theta=x_{B(i)}/u_i$ 时降到 0。所以

$$\theta^*=\min\Big\{\frac{x_{B(i)}}{u_i}:u_i>0\Big\}$$

取到 minimum 的那个 basic variable 出 basis。如果所有 $u_i\le0$，$\theta$ 可以无限大，$z\to\infty$，LP unbounded；这就是第 1 站第三种结局在 algorithm 里的样子。

第二次 pivot 时，$x_2$ 的 column 是 $u=(\tfrac12,\tfrac12,1)$（对应 $x_1,s_2,s_3$），当前值是 $(5,2,5)$，三个 ratio 是 $10$、$4$、$5$，取 4。

| $s_3$ | 0 | 0 | 1 | $-2$ | 1 | 1 |

粗体是 pivot column 的 reduced cost 和 pivot element。第 1 步到第 2 步的 row operation：$s_2$ row 乘 2 得新的 $x_2$ row $(0,1,-1,2,0\,|\,4)$；$x_1$ row 减去它的 $\tfrac12$ 倍，得 $(1,0,1,-1,0\,|\,3)$；$s_3$ row 减去它，得 $(0,0,1,-2,1\,|\,1)$；$\bar c$ row 减去它，得 $(0,0,-1,-2,0)$，$z$ 加上 $1\times4$ 变成 24。每张表的 row 和上面的代入式一一对应，例如第 2 步的 $x_1$ row 读作 $x_1+s_1-s_2=3$，即 $x_1=3-s_1+s_2$。

:::wrong Ratio test 取最小的 ratio，是为了每一步稳妥一点、走得少一点
取最小的 ratio 是唯一不出界的选法。第二次 pivot 时如果取 $s_3$ 的 ratio 5，$x_2=5$，那么 $s_2=2-\tfrac12\times5=-0.5$，到达的是第 2 站表里那个 infeasible 的 basic solution $(2.5,5)$，它在 labour 那条 line 的外面。Minimum ratio 恰好是沿这条 edge 能走的最远距离，走到下一个 corner 为止。
:::

### 找不到起点：two-phase 与 Big-M

从 origin 出发，是因为 $b\ge0$ 且全是 $\le$ constraint，三个 slack 天然组成一个 BFS。如果客户要求 product 1 至少做 2，加上 $x_1\ge2$，即 $x_1-e=2$，origin 就不 feasible 了：$x_1=0$ 时 $e=-2$。

**Phase I.** 给这一行加一个 artificial variable $a\ge0$：$x_1-e+a=2$。$x=0$、$e=0$、$a=2$ 加上三个 slack 是一个明显的 BFS。然后先不管 profit，解

$$\min\ w=a$$

若原问题 feasible，取它的任何一个 feasible point、令 $a=0$，就得到 $w=0$；反过来，$w$ 的 optimal value $>0$ 说明原问题 infeasible。用 $a$ 那一行写出 $w=a=2-x_1+e$，$x_1$ 增加会让 $w$ 减少，$x_1$ 进 basis。Ratio：$a$ 行 $2/1=2$，$s_1$ 行 $10/2=5$，$s_2$ 行 $7/1=7$，取 2，$a$ 出 basis。现在 $x_1=2+e$，$w=0$，Phase I 结束，得到原问题的 BFS $(x_1,x_2)=(2,0)$，$s_1=6$，$s_2=5$，$s_3=5$。

**Phase II.** 删掉 $a$，用原来的 objective 从这个 BFS 继续。$z=4x_1+3x_2=8+4e+3x_2$。$e$ 的 coefficient 最大，进 basis：$x_1=2+e$ 不受限；$s_1=10-2(2+e)-x_2=6-2e$ 要求 $e\le3$；$s_2=7-(2+e)=5-e$ 要求 $e\le5$。$e=3$，$s_1$ 出去，到达 $(5,0)$，$z=20$。之后和上面的第 1、2 步完全一样，到 $(3,4)$。$x_1=3\ge2$，新 constraint 在 optimal point 不起作用。

**Big-M** 把两个 phase 合成一次：objective 改成 $\max\ 4x_1+3x_2-Ma$，$M$ 是一个“比任何出现的数都大”的正数。只要 $a>0$，罚款 $Ma$ 压倒一切 profit，所以 optimal solution 会先把 $a$ 赶到 0。手算时 $M$ 不取具体的值，当作一个符号留在 tableau 里（学生的 NUS helpsheet 上也是这样写的）：比较两个 reduced cost 时先比 $M$ 的 coefficient，相同再比常数项。

在例子里走一遍。用 $a$ 那一行 $a=2-x_1+e$ 消去 objective 里的 $a$：

$$z=4x_1+3x_2-M(2-x_1+e)=-2M+(4+M)x_1+3x_2-Me$$

三个 coefficient 是 $4+M$、$3$、$-M$，$4+M$ 最大，$x_1$ 进 basis。Ratio test 和 Phase I 完全一样，取 $a$ 行的 2，$a$ 出 basis。代入 $x_1=2+e-a$：

$$z=4(2+e-a)+3x_2-Ma=8+4e+3x_2-(4+M)a$$

$a$ 的 coefficient 是 $-(4+M)<0$，它以后不会再进 basis；其余部分 $8+4e+3x_2$ 正是 Phase II 开头那个式子，之后的 pivot 和上面一样。Big-M 的代价在计算机上：$M$ 必须换成一个具体的数，取小了可能不足以把 $a$ 赶出去，取得太大，tableau 里同时出现 $10^{8}$ 和 1 量级的数，有 rounding 问题（DSA2102 第 1 站的那种）。Two-phase 没有这个参数。

:::edge Degeneracy 与 cycling
如果某个 basic variable 当前就等于 0，并且它在 ratio test 里 $u_i>0$，那么 $\theta^*=0$：basis 换了，点没动，$z$ 也没变。第 2 站最后那个 labour 上限 7.5 的例子里，$(2.5,5)$ 处就有一个 basic variable 等于 0。一般情形下，这样的 pivot 可能一连串地发生，最后回到出发时的 basis，simplex 永远转圈，这叫 cycling。只要每一步 $\theta^*>0$，$z$ 严格增加，basis 不会重复，而 basis 只有有限个，simplex 一定停；degeneracy 恰好破坏了“严格增加”。MIT 15.093 给出的防法是 smallest index rule（Bland's rule）：entering variable 在所有 $\bar c_j>0$ 的里面取 index 最小的，ratio test 打平时 leaving variable 也取 index 最小的。按这个规则 simplex 一定停；这里不给 proof。
:::

:::edge Simplex 要走多少步
MIT 15.093 Lecture 4 给出一族问题：feasible region 是一个压扁的 $n$ 维 cube，有 $2^n$ 个 vertex，可以排成一条每一步都是相邻 vertex、objective 每一步都变好的路径，某个 pivot rule 会把这 $2^n-1$ 步全部走完。所以 simplex 的 worst case 是 exponential 的。实际问题里它通常只走 $m$ 的若干倍步。LP 有 polynomial time 的 algorithm（interior point method），这门课的大纲不讲。
:::

## [dual] Duality 与 complementary slackness

:::skip
能写出任意 LP 的 dual、用 complementary slackness 从 primal solution 求 dual solution，并能说清 simplex 停下时为什么同时得到了 dual optimal，就可以去第 5 站。
:::

### 不解 LP，先给 z 一个 upper bound

Simplex 告诉我们 $z^*=24$。如果有人只给你 $(3,4)$ 这个答案，不给计算过程，怎么快速确认它真的是最大的？$(3,4)$ feasible、$z=24$ 只说明 $z^*\ge24$。需要的是另一个方向：一个能证明 $z^*\le24$ 的论证。

把 constraint 乘上 nonnegative 的数再相加，可以得到新的 valid inequality。试几组：

- labour constraint 乘 4：$4x_1+4x_2\le28$。因为 $x_2\ge0$，$4x_1+3x_2\le4x_1+4x_2\le28$，所以 $z^*\le28$。
- machine 乘 2、material 乘 1：$4x_1+2x_2+x_2\le20+5$，即 $4x_1+3x_2\le25$，所以 $z^*\le25$。
- machine 乘 1、labour 乘 2：$(2x_1+x_2)+2(x_1+x_2)=4x_1+3x_2\le10+14=24$，所以 $z^*\le24$。

最后一组和 $(3,4)$ 的 $z=24$ 对上了，$24$ 就是 optimal value，任何人拿着这两个 multiplier 都能核对。

一般地，给三个 constraint 配 multiplier $y_1,y_2,y_3\ge0$，相加后左边是 $(2y_1+y_2)x_1+(y_1+y_2+y_3)x_2$，右边是 $10y_1+7y_2+5y_3$。要让左边压住 $4x_1+3x_2$（利用 $x\ge0$），需要 $x_1$ 和 $x_2$ 的 coefficient 分别不小于 4 和 3。最好的 upper bound 是

$$\begin{aligned}\min\quad&10y_1+7y_2+5y_3\\\text{s.t.}\quad&2y_1+y_2\ge4\\&y_1+y_2+y_3\ge3\\&y_1,y_2,y_3\ge0\end{aligned}$$

这个 LP 叫原问题（primal）的 dual。$y=(1,2,0)$ 满足 constraint，objective 是 24。

### 任意 LP 的 dual 怎么写

对 $\max c^\top x$ s.t. $Ax\le b$，$x\ge0$，同样的推理给出 dual $\min b^\top y$ s.t. $A^\top y\ge c$，$y\ge0$：primal 的每个 constraint 对应一个 dual variable，每个 primal variable 对应一个 dual constraint，$b$ 和 $c$ 互换位置，$A$ 转置。

Constraint 不是 $\le$、variable 不是 $\ge0$ 时，只要问 multiplier 的 sign 怎样才保证 inequality 方向对：

| primal（max） | dual（min） |
|---|---|
| 第 $i$ 个 constraint 是 $\le$ | $y_i\ge0$ |
| 第 $i$ 个 constraint 是 $\ge$ | $y_i\le0$（乘 negative 数，inequality 翻过来变成 $\le$） |
| 第 $i$ 个 constraint 是 $=$ | $y_i$ free（等式两边乘什么都行） |
| $x_j\ge0$ | 第 $j$ 个 dual constraint 是 $\ge$ |
| $x_j\le0$ | 第 $j$ 个 dual constraint 是 $\le$ |
| $x_j$ free | 第 $j$ 个 dual constraint 是 $=$（coefficient 必须恰好相等，否则 $x_j$ 取另一个 sign 时压不住） |

把 dual 再按同样的规则取一次 dual，回到 primal。

[DSA3102 第 6 站](DSA3102.html#dual)用 Lagrangian 从另一个方向推出同样的东西：把 constraint 乘上 multiplier 加进 objective，对 $x$ 取 sup，得到的 dual function 是 upper bound。对 LP，sup 有限当且仅当 $x$ 的 coefficient 满足上表的 sign 条件，于是 dual function 只剩 $b^\top y$。MIT 15.093 Lecture 5 用的就是这个推导。

### Weak duality

**Theorem.** 若 $x$ 是 primal feasible，$y$ 是 dual feasible，则 $c^\top x\le b^\top y$。

**Proof.**

$$c^\top x\ \le\ (A^\top y)^\top x\ =\ y^\top(Ax)\ \le\ y^\top b$$

第一个 $\le$ 用了 $c\le A^\top y$ 和 $x\ge0$；第二个用了 $Ax\le b$ 和 $y\ge0$。∎

这正是上一节“乘 multiplier 相加”的过程写成一行。推论：如果找到一对 feasible 的 $x$、$y$ 使 $c^\top x=b^\top y$，两者同时 optimal。$(3,4)$ 和 $(1,2,0)$ 就是这样一对。

### Strong duality：simplex 停下时顺手给出 dual

一对 objective 相等的 $x$、$y$ 总是存在吗？

**Theorem.** 若 primal 有 optimal solution，则 dual 也有，且两者 optimal value 相等。

**Proof.** 加 slack 化成 standard form，$\max c^\top x$ s.t. $Ax+s=b$，$x,s\ge0$。Simplex 停在某个 optimal basis $B$，所有 reduced cost $\le0$。定义

$$y^\top=c_B^\top B^{-1}$$

对原 variable $x_j$，reduced cost 是 $c_j-y^\top A_j\le0$，即 $A^\top y\ge c$。对 slack $s_i$，它的 column 是 $e_i$，cost 是 0，reduced cost 是 $0-y^\top e_i=-y_i\le0$，即 $y\ge0$。所以 $y$ dual feasible。它的 objective 是 $b^\top y=c_B^\top B^{-1}b=c_B^\top x_B=c^\top x$。由 weak duality 的推论，$y$ 是 dual optimal，两个 optimal value 相等。∎

在例子里读出来：final tableau 中 $s_1$、$s_2$、$s_3$ 的 reduced cost 是 $-1$、$-2$、$0$，所以 $y=(1,2,0)$，和上面凑出来的 multiplier 一样。证书不用另外找，它就印在 final tableau 的 slack column 上。

几何上看：在 $(3,4)$ 处，$c=(4,3)$ 恰好等于两条 active constraint 的 normal 的 nonnegative combination，$(4,3)=1\cdot(2,1)+2\cdot(1,1)$，coefficient 就是 $y_1$ 和 $y_2$。

::fig[ma3252-cone] 在 optimal vertex $(3,4)$ 处画出两条 active constraint 的 normal $(2,1)$、$(1,1)$。它们张成一个 cone（浅色），$c=(4,3)$ 落在 cone 里：$c=1\cdot(2,1)+2\cdot(1,1)$。往 $c$ 的方向走，必然会穿出至少一条 active constraint。

### Complementary slackness

**Theorem.** 设 $x$ primal feasible，$y$ dual feasible。两者同时 optimal，当且仅当

$$y_i\,(b_i-a_i^\top x)=0\ \ \text{对所有 }i,\qquad x_j\,\big((A^\top y)_j-c_j\big)=0\ \ \text{对所有 }j$$

即：一个 constraint 有 slack，它的 multiplier 就是 0；一个 dual constraint 有 slack，对应的 variable 就是 0。

**Proof.** 把 weak duality 那一行的两个 gap 写出来：

$$b^\top y-c^\top x=\underbrace{y^\top(b-Ax)}_{=\sum_iy_i(b_i-a_i^\top x)}+\underbrace{(A^\top y-c)^\top x}_{=\sum_jx_j((A^\top y)_j-c_j)}$$

验证：右边展开是 $y^\top b-y^\top Ax+y^\top Ax-c^\top x$，中间两项抵消。由 feasibility，右边每一个乘积都 $\ge0$。若 $x$、$y$ 都 optimal，strong duality 说左边是 0，于是每个乘积都是 0。反过来，若每个乘积都是 0，左边是 0，由 weak duality 的推论两者都 optimal。∎

**用它找 dual solution。** 只知道 $x=(3,4)$。Material constraint $x_2\le5$ 有 slack（$4<5$），所以 $y_3=0$。$x_1>0$、$x_2>0$，所以两个 dual constraint 都必须 tight：

$$2y_1+y_2=4,\qquad y_1+y_2+0=3$$

相减得 $y_1=1$，代回得 $y_2=2$。检查 $y\ge0$，成立，于是 $x$ 和 $y$ 都 optimal。如果解出来某个 $y_i<0$，就说明这个 $x$ 不是 optimal。

**再做一个带 equality constraint 的。** MIT 15.093 的例子：$\min13x_1+10x_2+6x_3$ s.t. $5x_1+x_2+3x_3=8$，$3x_1+x_2=3$，$x\ge0$。问 $x=(1,0,1)$ 是否 optimal。这是 min 问题，dual 是 $\max8p_1+3p_2$ s.t. $5p_1+3p_2\le13$，$p_1+p_2\le10$，$3p_1\le6$，$p$ free（primal 是 equality）。$x_1$、$x_3>0$，所以第 1、3 个 dual constraint tight：$3p_1=6$ 得 $p_1=2$，$5\times2+3p_2=13$ 得 $p_2=1$。第 2 个 dual constraint：$2+1=3\le10$，成立。Primal cost $13+6=19$，dual objective $16+3=19$，相等，$x$ optimal。

:::wrong Primal infeasible，dual 就一定 unbounded
Weak duality 给出的只是：一边 unbounded，另一边必定 infeasible（否则那一边的 feasible point 就成了 bound）。反过来不成立，两边可以同时 infeasible。$\max x_1+x_2$ s.t. $x_1-x_2\le-1$，$-x_1+x_2\le-1$，$x\ge0$：两个 constraint 相加得 $0\le-2$，infeasible。它的 dual $\min-y_1-y_2$ s.t. $y_1-y_2\ge1$，$-y_1+y_2\ge1$，$y\ge0$：相加得 $0\ge2$，也 infeasible。
:::

:::back
Strong duality 的 proof 用的是[第 3 站](#simplex)的 reduced cost 和停止条件。
:::

:::from
用 Lagrangian 引出 dual、primal 与 dual 的对应表、weak duality 的一行 proof、用 simplex 的 $p^\top=c_B^\top B^{-1}$ prove strong duality、complementary slackness 的 proof（把 gap 拆成两组 nonnegative 的乘积）和 13、10、6 那个例子，来自 [MIT 15.093 Lecture 5](https://ocw.mit.edu/courses/15-093j-optimization-methods-fall-2009/resources/mit15_093j_f09_lec05/)，这里全部改成 max 的符号。“在 optimal vertex 处 $c$ 是 active constraint normal 的 nonnegative combination，coefficient 就是 dual solution”的几何讲法，以及“一边 unbounded 另一边必 infeasible、两边可以同时 infeasible”的可行性表，来自 [CMU 15-451 Lecture 16](https://www.cs.cmu.edu/~15451-s25/notes/lecture16.pdf)；那份讲义用木匠做桌椅的例子、把 dual 讲成“收购原料的商人定价”，两边同时 infeasible 的例子留作练习，这里的例子是自己构造的。“先手凑几组 multiplier 给 upper bound”的引入方式和 cone 的图是自己加的。

## [sens] Sensitivity analysis 与 dual simplex

:::skip
能从 final tableau 读出 right-hand side 和 objective coefficient 的 range、判断新 product 值不值得做，并在 basis 失去 feasibility 后做 dual simplex，就可以去第 6 站。
:::

### 数据变了，哪些不用重解

车间的数据会变：多雇一个人，labour 从 7 变成 8；原料涨价，profit 从 4 变成 3.5。每变一次都从头跑 simplex 太浪费。Final tableau 里已经有 $B^{-1}$，大多数变化可以直接读出答案。

一个 basis $B$ 是 optimal 的，靠两个条件：

$$\text{feasibility：}B^{-1}b\ge0,\qquad\text{optimality：}c_N^\top-c_B^\top B^{-1}N\le0$$

$b$ 只出现在第一个条件里，$c$ 只出现在第二个里。所以改 $b$ 只要检查 feasibility，改 $c$ 只要检查 optimality。

### Right-hand side 变化

Labour 从 7 变成 $7+\Delta$，即 $b$ 变成 $b+\Delta e_2$。新的 basic variable 是 $B^{-1}(b+\Delta e_2)=B^{-1}b+\Delta\,B^{-1}e_2$。$B^{-1}e_2$ 是 $B^{-1}$ 的第二个 column，就是 final tableau 里 $s_2$ 那一列（因为 $s_2$ 原来的 column 是 $e_2$）：$x_1$、$x_2$、$s_3$ 三行分别是 $-1$、$2$、$-2$。所以

$$x_1=3-\Delta,\qquad x_2=4+2\Delta,\qquad s_3=1-2\Delta$$

三个都 $\ge0$ 要求 $\Delta\le3$、$\Delta\ge-2$、$\Delta\le\tfrac12$，合起来 $-2\le\Delta\le\tfrac12$，即 labour 在 $[5,7.5]$ 之间时这个 basis 一直 optimal。这期间 $z=4(3-\Delta)+3(4+2\Delta)=24+2\Delta$，每多一个 labour hour 多赚 2，正是 $y_2$。所以 dual variable 叫 shadow price：资源的边际价值。

Machine hour 同理，读 $s_1$ 那一列 $(1,-1,1)$：$x_1=3+\Delta$，$x_2=4-\Delta$，$s_3=1+\Delta$，range 是 $-1\le\Delta\le4$，$z=24+\Delta$，shadow price $y_1=1$。Material 的 shadow price 是 0：现在还剩 1 单位没用完，多给也没用。

::fig[ma3252-sens] Labour 上限 $b_2$ 从 4 变到 9。左边那条 labour line 平移，optimal vertex 跟着滑；右边是 optimal value $z^*(b_2)$。$b_2$ 在 $[5,7.5]$ 之间，vertex 沿 machine line 滑动，slope 是 shadow price 2；$b_2<5$ 时 slope 是 4，$b_2>7.5$ 时 labour 不再是 bottleneck，slope 是 0。

$z^*(b_2)$ 是 piecewise linear 的，而且 slope 只会变小（concave）。每一段对应一个 basis，slope 是那个 basis 的 shadow price。

:::wrong Labour 的 shadow price 是 2，所以再雇 3 个 labour hour 能多赚 6
Shadow price 只在 basis 不变的 range 里有效。Labour 从 7 加到 10，$\Delta=3$ 超出了 $\Delta\le\tfrac12$。实际上 labour 到 7.5 时 material 就用完了，optimal point 停在 $(2.5,5)$，$z^*=25$，只多赚 1。在图里，这是 $z^*(b_2)$ 过了 7.5 之后的那段水平线。
:::

### Objective coefficient 变化

Product 1 的 profit 从 4 变成 $c_1$。$x_1$ 是 basic variable，$c_B$ 变了，所以每个 nonbasic 的 reduced cost 都要重算。用 final tableau 的 row：$\bar c_j=c_j-c_B^\top(B^{-1}A_j)$，$B^{-1}A_j$ 就是 tableau 里 $j$ 那一列。$c_B=(c_1,3,0)$ 对应 $(x_1,x_2,s_3)$：

$$\bar c_{s_1}=0-(c_1\cdot1+3\cdot(-1)+0\cdot1)=3-c_1,\qquad\bar c_{s_2}=0-(c_1\cdot(-1)+3\cdot2+0\cdot(-2))=c_1-6$$

两个都 $\le0$ 要求 $3\le c_1\le6$。代 $c_1=4$ 核对：$-1$ 和 $-2$，和 tableau 一致。几何上，objective 的 level line 的 slope 夹在两条 active line 之间：$c_1/3$ 在 $1$（labour line）和 $2$（machine line）之间。$c_1<3$ 时 optimal 跳到 $(2,5)$，$c_1>6$ 时跳到 $(5,0)$。

如果变的是一个 nonbasic variable 的 cost，只有它自己的 reduced cost 变：$\bar c_j+\Delta\le0$。

### 加一个新 product

考虑一个新 product 3，每单位用 1 machine hour、1 labour hour、1 material，profit 2.5。要不要做？不用重解。把它当作一个新的 nonbasic column $A_6=(1,1,1)$，算它的 reduced cost：

$$\bar c_6=2.5-y^\top A_6=2.5-(1\cdot1+2\cdot1+0\cdot1)=-0.5\le0$$

当前 basis 仍然 optimal，不做。经济上：它消耗的资源按 shadow price 值 $1+2+0=3$，只卖 2.5。Profit 超过 3 才值得做。

### 超出 range 之后：dual simplex

Labour 变成 8（$\Delta=1$），超出 range。代进上面的公式：$x_1=2$，$x_2=6$，$s_3=-1$。Basis 不 feasible 了，但 reduced cost 没变，仍然全部 $\le0$。

这和 primal simplex 的处境正好相反：primal simplex 一路保持 feasibility，追求 optimality；现在 optimality 成立，缺 feasibility。Dual simplex 一路保持 reduced cost $\le0$（也就是 dual feasible，第 4 站），每一步修复一个 negative 的 basic variable：

1. **Leaving variable**：选一个 negative 的 basic variable，这里是 $s_3=-1$。它那一行是 $s_3+s_1-2s_2=-1$。
2. **Entering variable**：要把 $s_3$ 拉回 0，需要让这一行里 coefficient 为 negative 的某个 nonbasic variable 增加。候选只有 $s_2$（coefficient $-2$）。若有多个候选，取 $|\bar c_j|/|a_{rj}|$ 最小的（$a_{rj}<0$ 是 pivot row 里第 $j$ 个 entry）。理由：pivot 之后，第 $k$ 个 reduced cost 变成 $\bar c_k-\dfrac{\bar c_j}{a_{rj}}a_{rk}$。$\bar c_j/a_{rj}\ge0$，所以 $a_{rk}\ge0$ 的那些只会变得更 negative；$a_{rk}<0$ 的那些要求 $\bar c_k\le\dfrac{\bar c_j}{a_{rj}}a_{rk}$，两边除以 $a_{rk}<0$，inequality 反向，得 $\dfrac{\bar c_k}{a_{rk}}\ge\dfrac{\bar c_j}{a_{rj}}$；两边都是 nonnegative 的，就是 $|\bar c_k|/|a_{rk}|\ge|\bar c_j|/|a_{rj}|$，所以 $j$ 要取这个 ratio 最小的。这里只有一个候选，$|{-2}|/|{-2}|=1$。如果 pivot row 里没有 negative 的 entry，这一行读作 $x_{B(r)}=(\text{negative 的 RHS})-\sum_ka_{rk}x_k$，$a_{rk}\ge0$、$x_k\ge0$，它永远是 negative，primal infeasible（MIT 15.093 的说法是 dual 的 optimal value 为 $+\infty$）。
3. **Pivot**：和 primal 一样做 row operation。

| $b_2=8$，pivot 前 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | $s_3$ | RHS |
|---|---|---|---|---|---|---|
| $\bar c$ | 0 | 0 | $-1$ | $-2$ | 0 | $z=26$ |
| $x_1$ | 1 | 0 | 1 | $-1$ | 0 | 2 |
| $x_2$ | 0 | 1 | $-1$ | 2 | 0 | 6 |
| $s_3$ | 0 | 0 | 1 | $\mathbf{-2}$ | 1 | $-1$ |

| pivot 后 | $x_1$ | $x_2$ | $s_1$ | $s_2$ | $s_3$ | RHS |
|---|---|---|---|---|---|---|
| $\bar c$ | 0 | 0 | $-2$ | 0 | $-1$ | $z=25$ |
| $x_1$ | 1 | 0 | $\tfrac12$ | 0 | $-\tfrac12$ | 2.5 |
| $x_2$ | 0 | 1 | 0 | 0 | 1 | 5 |
| $s_2$ | 0 | 0 | $-\tfrac12$ | 1 | $-\tfrac12$ | 0.5 |

$s_3$ row 除以 $-2$ 得新的 $s_2$ row $(0,0,-\tfrac12,1,-\tfrac12\,|\,0.5)$；$x_1$ row 加上它，$x_2$ row 减去它的 2 倍，$\bar c$ row 加上它的 2 倍，$z$ 减去 $2\times0.5$ 变成 25。RHS 全部 $\ge0$，reduced cost 全部 $\le0$，optimal：$(2.5,5)$，$z=25$，labour 剩 0.5 小时没用。新的 shadow price 是 $y=(2,0,1)$：labour 不再值钱，material 成了 bottleneck。这和图里 $b_2>7.5$ 那一段一致。

Pivot 前 $z=26$ 是一个 infeasible 点的值，它是 dual 的 objective，也就是 upper bound；dual simplex 每一步让这个 upper bound 下降，降到 feasible 时就是 optimal value。

### 加一个新 constraint

加一条 $x_1\le2.5$（product 1 的设备检修）。当前的 $x_1=3$ 违反它。加 slack $s_4$：$x_1+s_4=2.5$。用 final tableau 的 $x_1=3-s_1+s_2$ 把它写成 nonbasic variable 的形式：$s_4=2.5-3+s_1-s_2$，即新的一行

$$s_4-s_1+s_2=-0.5$$

$s_4=-0.5$，又是 dual simplex 的局面。Leaving 是 $s_4$；这一行 coefficient negative 的只有 $s_1$，entering 是 $s_1$。解出 $s_1=0.5+s_4+s_2$，代回 final tableau 的各行：

$$x_1=3-s_1+s_2=2.5-s_4,\quad x_2=4+s_1-2s_2=4.5+s_4-s_2,\quad s_3=1-s_1+2s_2=0.5-s_4+s_2$$

$$z=24-s_1-2s_2=23.5-s_4-3s_2$$

全部 feasible，reduced cost 全部 negative，optimal：$(2.5,4.5)$，$z=23.5$。

Shadow price 就是[第 4 站](#dual)的 $y=c_B^\top B^{-1}$；dual simplex 每一步保持的“reduced cost $\le0$”就是 dual feasibility。

## [path] Network 模型、shortest path、MST 与 postman problem

:::skip
能把 network problem 写成 node-arc incidence matrix 的 LP，能跑 Dijkstra、Kruskal 并说出它们为什么对，会解 Chinese postman problem，就可以去第 7 站。
:::

### 同一个 matrix 描述所有 network problem

一个 directed network 有 node 和 arc。给每条 arc $(i,j)$ 一个 flow $f_{ij}\ge0$、一个单位 cost $c_{ij}$，每个 node $i$ 有一个 supply $b_i$（$b_i>0$ 是供给，$b_i<0$ 是需求，$\sum_ib_i=0$）。Flow conservation 说：从 node $i$ 流出的减去流进的，等于它的 supply：

$$\sum_{j:(i,j)}f_{ij}-\sum_{k:(k,i)}f_{ki}=b_i$$

写成 matrix 是 $Mf=b$，$M$ 叫 node-arc incidence matrix：每个 node 一行，每条 arc 一列，arc $(i,j)$ 那一列在 row $i$ 是 $+1$、row $j$ 是 $-1$、其余是 0。Minimize $c^\top f$ s.t. $Mf=b$，$0\le f\le u$（$u$ 是 capacity）就是 min cost flow problem。它是一个 LP，前五站的理论全都适用；这两站看的是，network 结构让它们变得更快、更具体。

### Shortest path 是一个 min cost flow

下面这个 network 有 6 个 node、9 条 arc，arc 上的数是 cost（长度）：

| arc | $s\to a$ | $s\to b$ | $b\to a$ | $a\to c$ | $b\to c$ | $b\to d$ | $c\to d$ | $c\to t$ | $d\to t$ |
|---|---|---|---|---|---|---|---|---|---|
| cost | 4 | 1 | 2 | 3 | 7 | 4 | 1 | 5 | 2 |

从 $s$ 到 $t$ 的最短 path，就是从 $s$ 送 1 单位 flow 到 $t$（$b_s=1$，$b_t=-1$，其余 0）、cost 最小的 min cost flow。Flow 只会沿一条 path 走：第 7 站会证明这个 LP 有 integer 的 optimal BFS，于是每条 arc 的 flow 是 0 或 1。

### Dijkstra

求 $s$ 到所有 node 的最短距离 $d(\cdot)$。每个 node 有一个 label，表示“目前找到的最短距离”，开始时 $d(s)=0$，其余为 $\infty$。每一轮：

1. 在还没定下来的 node 里，取 label 最小的 $u$，把它定下来。
2. 对每条 arc $(u,v)$，若 $d(u)+c_{uv}<d(v)$，把 $d(v)$ 改成 $d(u)+c_{uv}$，并记下 $v$ 的前驱是 $u$。

| 定下来的 node | $a$ | $b$ | $c$ | $d$ | $t$ |
|---|---|---|---|---|---|
| $s$（0） | 4 | **1** | $\infty$ | $\infty$ | $\infty$ |
| $b$（1） | **3** | | 8 | 5 | $\infty$ |
| $a$（3） | | | 6 | **5** | $\infty$ |
| $d$（5） | | | **6** | | 7 |
| $c$（6） | | | | | **7** |
| $t$（7） | | | | | |

第二行的来历：$b$ 定在 1，经 $b$ 到 $a$ 是 $1+2=3<4$，到 $c$ 是 $1+7=8$，到 $d$ 是 $1+4=5$。第三行：经 $a$ 到 $c$ 是 $3+3=6<8$。第四行：经 $d$ 到 $t$ 是 $5+2=7$；经 $d$ 不能改进 $c$。第五行：经 $c$ 到 $t$ 是 $6+5=11>7$，不改。最短 path 是 $s\to b\to d\to t$，长度 7。

记下的前驱组成一棵 tree：$s\to b$、$b\to a$、$a\to c$、$b\to d$、$d\to t$，叫 shortest path tree。

::fig[ma3252-sptree] 同一个 network。左边粗线是 Dijkstra 得到的 shortest path tree，node 旁是距离；右边把 arc 当作 undirected，粗线是 minimum spanning tree。两棵 tree 不一样：MST 用了 cost 1 的 $c$–$d$，没用 cost 4 的 $b$–$d$。

**为什么对。** 要证：$u$ 被定下来时，$d(u)$ 已经是真正的最短距离。设已定下来的 node 组成集合 $S$，任取一条 $s$ 到 $u$ 的 path。它从 $S$ 里出发，在某处第一次离开 $S$，经过 arc $(x,y)$，$x\in S$，$y\notin S$。这条 path 的长度至少是

$$\underbrace{d(x)+c_{xy}}_{\text{到 }y\text{ 的那一段}}+\underbrace{(\text{从 }y\text{ 到 }u\text{ 的剩余部分})}_{\ge0}\ \ge\ \text{label}(y)\ \ge\ \text{label}(u)$$

第一个 $\ge$：$x$ 定下来时已经用 $(x,y)$ 更新过 $y$ 的 label，而剩余部分的长度 $\ge0$ 用到了所有 cost nonnegative。第二个 $\ge$：$u$ 是 label 最小的那个。所以任何 path 都不比 $\text{label}(u)$ 短。

### Dual 是 potential

Shortest path LP 的 dual 给每个 node 一个 variable $\pi_i$：$\max\ \pi_t-\pi_s$ s.t. $\pi_j-\pi_i\le c_{ij}$ 对每条 arc。（按第 4 站的表：primal 是 min、equality constraint，所以 $\pi$ free，每条 arc 对应一个 dual constraint。）取 $\pi=d$：

| arc | $s\to a$ | $s\to b$ | $b\to a$ | $a\to c$ | $b\to c$ | $b\to d$ | $c\to d$ | $c\to t$ | $d\to t$ |
|---|---|---|---|---|---|---|---|---|---|
| $d_j-d_i$ | 3 | 1 | 2 | 3 | 5 | 4 | $-1$ | 1 | 2 |
| $c_{ij}$ | 4 | 1 | 2 | 3 | 7 | 4 | 1 | 5 | 2 |

每一列都满足 $d_j-d_i\le c_{ij}$，dual feasible；dual objective $d_t-d_s=7$，等于 path 的长度。所以这张表就是 optimality 的证书。Tree 上的五条 arc 恰好 tight（$d_j-d_i=c_{ij}$），这是 complementary slackness：flow 只走 tight 的 arc。

:::wrong Dijkstra 对任何 network 都给出最短距离
Proof 里用到了“剩余部分的长度 $\ge0$”。取 $s\to a$ cost 2、$s\to b$ cost 3、$b\to a$ cost $-2$。Dijkstra 第一轮把 $a$ 定在 2；但 $s\to b\to a$ 的长度是 $3-2=1$。$a$ 已经定下来，不会再改。有 negative cost 时要用 Bellman–Ford：对所有 arc 反复做第 2 步的更新，做 $n-1$ 轮，不再要求“定下来就不改”。为什么 $n-1$ 轮够：没有 total cost 为 negative 的 cycle 时，取 $s$ 到 $v$ 的最短 path 里 arc 最少的一条 $s=v_0\to v_1\to\cdots\to v_k=v$，它不重复 node，所以 $k\le n-1$。第 1 轮更新过 $(v_0,v_1)$ 之后 $d(v_1)$ 正确，第 $i$ 轮更新过 $(v_{i-1},v_i)$ 之后 $d(v_i)$ 正确，$k$ 轮后 $d(v)$ 正确。在这个例子里：第 1 轮按 $s\to a$、$s\to b$、$b\to a$ 的顺序更新，$d(a)$ 先是 2，再被改成 1。做完 $n-1$ 轮后再扫一遍所有 arc，如果还有 arc 能更新，就说明从 $s$ 能走到一个 negative 的 cycle，最短距离没有定义。
:::

### Minimum spanning tree

另一个问题：把 arc 看作 undirected 的 edge，要选一些 edge 把 6 个 node 全部连起来，总 cost 最小。连通而 cost 最小的选法一定不含 cycle（去掉 cycle 上一条 edge 仍然连通、cost 更小），所以答案是一棵 spanning tree，叫 minimum spanning tree（MST）。

**Kruskal：** 把 edge 按 cost 从小到大排，依次考虑，加进来不形成 cycle 就加。

| edge | $s$–$b$ | $c$–$d$ | $a$–$b$ | $d$–$t$ | $a$–$c$ | $s$–$a$ | $b$–$d$ | $c$–$t$ | $b$–$c$ |
|---|---|---|---|---|---|---|---|---|---|
| cost | 1 | 1 | 2 | 2 | 3 | 4 | 4 | 5 | 7 |
| 加不加 | 加 | 加 | 加 | 加 | 加 | | | | |

前四条把 node 分成 $\{s,a,b\}$ 和 $\{c,d,t\}$ 两块；$a$–$c$ 连起两块，5 条 edge，6 个 node 已经连通，停。总 cost $1+1+2+2+3=9$。

**为什么对：cut property。** 把 node 分成两组，横跨两组的 edge 里 cost 最小的那条 $e$，一定在某个 MST 里。Proof：取一个不含 $e$ 的 MST $T$。把 $e$ 加进 $T$ 形成一个 cycle，这个 cycle 从一组走到另一组再走回来，所以除了 $e$ 还至少有一条横跨的 edge $e'$。$c_{e}\le c_{e'}$。$T-e'+e$ 仍是 spanning tree（去掉的 $e'$ 在 cycle 上，不破坏连通），cost 不超过 $T$，所以也是 MST，而它含 $e$。

Kruskal 每加一条 edge $e=(u,v)$，取“$u$ 当前所在的那一块”作为一组、其余所有 node 作为另一组。$e$ 横跨这两组，因为它不形成 cycle，$v$ 不在 $u$ 那一块里。比 $e$ 便宜的 edge 都已经考虑过：每一条要么被加了，两端从此在同一块里；要么被拒绝了，因为当时两端已经在同一块里。块只会合并不会拆开，所以这些 edge 现在两端都在同一块里，没有一条横跨这两组。于是 $e$ 是横跨的 edge 里最便宜的，由 cut property 它在某个 MST 里。CMU 15-451 的讲义把这一步写成一次 induction：设当前选中的 edge 都在某个 MST $M$ 里，加进 $e$ 之后用上面的交换把 $M$ 改成一个同时含 $e$ 的 MST。

两棵 tree 对比：shortest path tree 的总 cost 是 $1+2+3+4+2=12$，MST 是 9；而 MST 里从 $s$ 到 $t$ 的 path $s$–$b$–$a$–$c$–$d$–$t$ 长度是 9，比最短距离 7 长。一个让“到每个点都近”，一个让“总共花得少”，目标不同，tree 就不同。

### Chinese postman problem

邮递员要走遍每一条 edge（街道）至少一次，回到起点，总长度最短。

如果每条 edge 恰好走一次就能回到起点（这样的 closed walk 叫 Eulerian circuit），总长度就是所有 edge 的 cost 之和，不可能更短。Euler 的 theorem：connected graph 有 Eulerian circuit，当且仅当每个 node 的 degree 都是 even。必要性：closed walk 每经过一个 node 一次，进来用一条 edge、出去用一条，所以每个 node 用掉的 edge 数是 even。充分性：从任一 node 出发沿没走过的 edge 走，因为 degree 都是 even，进了一个 node 就总能出去，只可能卡在起点，得到一个 closed walk；若还有 edge 没走，从这个 walk 上某个还有剩余 edge 的 node 出发再走一圈（剩余的 degree 仍然都是 even），拼进去，重复直到走完。

有 odd degree 的 node 时，某些 edge 必须走两次以上。把一条走了 $k$ 次的 edge 换成 $k$ 条平行的副本，得到的 graph 叫原 graph 的一个 extension；邮路在这个 extension 上每条 edge 恰好走一次，所以它是 extension 的 Eulerian circuit，extension 的每个 node 都是 even degree。反过来，任何一个所有 node 都是 even degree 的 extension 都有 Eulerian circuit，它就是原 graph 上的一条邮路。所以：最短邮路的长度 = 原 graph 的总长 + 加进来的副本的最小总长，约束是加完之后所有 degree 都是 even。

把上面的 network 当作 undirected 的街道图，各 node 的 degree 是：$s$：2，$a$：3，$b$：4，$c$：4，$d$：3，$t$：2。$a$ 和 $d$ 是 odd。加进来的副本要让 $a$ 和 $d$ 的 degree 变成 even、其余 node 保持 even，所以在副本组成的 edge 集合里，$a$ 和 $d$ 的 degree 是 odd、其余 node 是 even。这样的 edge 集合一定包含一条从 $a$ 到 $d$ 的 path：从 $a$ 出发沿副本走，每用一条 edge 就把它划掉，到达一个 even 的 node 时它还剩 odd 条没划掉的 edge，至少一条可以出去，所以只能停在 $d$。反过来，加一条 $a$ 到 $d$ 的 path 正好够：中间的 node 每个加 2，两端各加 1。最短的 $a$–$d$ path 是 $a$–$c$–$d$，长度 $3+1=4$（另一条 $a$–$b$–$d$ 长 6）。所以最短的邮路长度是全部 edge 之和 $4+1+2+3+7+4+1+5+2=29$，加上 4，等于 33：$a$–$c$ 和 $c$–$d$ 各走两次，其余 edge 各走一次。

Odd degree 的 node 多于两个时（它们的个数总是 even：所有 degree 之和是 edge 数的 2 倍），同样的论证一步步做下去：副本组成的 edge 集合可以拆成若干条互不共用 edge 的 path，每个 odd node 恰好是其中一条 path 的端点（找到一条 path 后把它的 edge 去掉，剩下的 odd node 正好少了这两个，继续找）。所以问题变成：把 $m$ 个 odd node 两两配对，每对之间走最短 path，配对的总长度最小。这是 complete graph 上的 minimum weight perfect matching，Edmonds 的 algorithm 能在 polynomial time 内解。手算时直接枚举：$m$ 个 odd node 的配对方式有 $(m-1)(m-3)\cdots3\cdot1$ 种，$m=4$ 时是 3 种，$m=8$ 时已经是 105 种。

:::back

## [flow] Max flow / min cut、min cost flow 与 transportation

:::skip
能在 residual network 上找 augmenting path 求出 max flow 并读出 min cut，能用 $u$–$v$ potential 解 transportation problem、在一般 network 上做 network simplex，并能说清 network LP 为什么自动给出 integer solution，就可以去第 8 站。
:::

### Max flow

每条 arc 有 capacity $u_{ij}$。从 source $s$ 往 sink $t$ 送 flow，每条 arc 上 $0\le f_{ij}\le u_{ij}$，$s$、$t$ 以外的 node 进出相等。最多能送多少？这是一个 LP：variable 是各 arc 的 flow 和总量 $v$，$s$ 的 supply 是 $v$，$t$ 的是 $-v$。下面这个 network：

| arc | $s\to a$ | $s\to b$ | $a\to b$ | $a\to c$ | $b\to d$ | $c\to d$ | $c\to t$ | $d\to t$ |
|---|---|---|---|---|---|---|---|---|
| capacity | 3 | 2 | 2 | 2 | 3 | 1 | 3 | 2 |

:::wrong 找到一条每条 arc 都还有空余的 path 就推满，推到没有这样的 path 为止，就是 max flow
先沿 $s\to a\to b\to d\to t$ 推：bottleneck 是 $\min(3,2,3,2)=2$。再沿 $s\to a\to c\to t$ 推：$s\to a$ 只剩 1，推 1。总量 3。现在 $s\to a$ 满了；从 $s$ 出发只能走 $s\to b$（剩 2），然后 $b\to d$（剩 1），然后 $d\to t$ 已满，$d$ 没有别的出路。没有 path 了，停在 3。

而 max flow 是 4：$a\to b$ 那 2 单位占用了 $s\to a$ 的 capacity，其实它们可以从 $s\to b$ 直接走，把 $s\to a$ 让给 $a\to c\to t$。第一步选错了 path，greedy 没有办法反悔。
:::

### Residual network：让算法能反悔

反悔的办法是把“已经推过去的 flow 可以退回来”也当作一种可走的路。对当前 flow $f$，residual network 的每条 arc：

- $(i,j)$ 还剩 $u_{ij}-f_{ij}>0$，就有一条 forward arc $i\to j$，residual capacity 是 $u_{ij}-f_{ij}$；
- $f_{ij}>0$，就有一条 backward arc $j\to i$，residual capacity 是 $f_{ij}$。沿它走 $\delta$，意思是把 $(i,j)$ 上的 flow 减少 $\delta$。

Residual network 里一条 $s$ 到 $t$ 的 path 叫 augmenting path。沿它推 bottleneck 那么多，forward arc 加 flow，backward arc 减 flow，每个中间 node 进出仍然平衡，总量增加。不断找 augmenting path，直到没有为止，这是 Ford–Fulkerson algorithm。

在 greedy 卡住的地方（总量 3）：$a\to b$ 有 flow 2，所以 residual network 里有 backward arc $b\to a$。Path $s\to b\to a\to c\to t$ 的 residual capacity 是 $\min(2,2,1,2)=1$。推过去：$s\to b$ 变成 1，$a\to b$ 从 2 减到 1，$a\to c$ 从 1 加到 2，$c\to t$ 从 1 加到 2。总量 4。

::fig[ma3252-maxflow] 三次 augmentation。每一帧高亮这一次的 augmenting path，arc 上标 flow / capacity。第三次沿 backward arc $b\to a$ 走，$a\to b$ 上的 flow 从 2 退到 1。第一帧（也是每一轮的最后一帧）是做完之后的结果：从 $s$ 出发在 residual network 里能到达的 node 是 $\{s,a,b,d\}$，横跨到 $\{c,t\}$ 的两条 arc 都满了，cut capacity $2+2=4$。

### Max-flow min-cut theorem

为什么 4 就是最大？把 node 分成 $S\ni s$ 和 $T\ni t$ 两组，叫一个 cut。它的 capacity 是从 $S$ 指向 $T$ 的 arc 的 capacity 之和（从 $T$ 指向 $S$ 的不算）。

**任何 flow 都不超过任何 cut。** 对 $S$ 里每个 node 写出 flow conservation（流出减流进）：$s$ 那一个等于 $v$，其余等于 0。把它们全部相加。一条两端都在 $S$ 里的 arc，在它的起点算一次 $+f$、在终点算一次 $-f$，抵消。剩下的是

$$v=\sum_{i\in S,\,j\in T}f_{ij}-\sum_{i\in T,\,j\in S}f_{ij}\ \le\ \sum_{i\in S,\,j\in T}u_{ij}=\text{cap}(S,T)$$

$\le$ 用了 $f_{ij}\le u_{ij}$ 和 $f_{ij}\ge0$。这是一个 weak duality。

**Theorem.** Ford–Fulkerson 停下时，flow 的总量等于某个 cut 的 capacity。所以 max flow = min cut。

**Proof.** 停下时 residual network 里没有 $s$ 到 $t$ 的 path。令 $S$ 为从 $s$ 出发在 residual network 里能到达的 node，$T$ 为其余，$t\in T$。

- 从 $S$ 指向 $T$ 的 arc $(i,j)$ 都满了：否则 forward arc $i\to j$ 在 residual network 里，$j$ 也能到达，与 $j\in T$ 矛盾。
- 从 $T$ 指向 $S$ 的 arc $(j,i)$ 上 flow 都是 0：否则 backward arc $i\to j$ 在 residual network 里，同样矛盾。

代进上面的等式，第一项等于 $\text{cap}(S,T)$，第二项是 0，$v=\text{cap}(S,T)$。由 weak duality，这个 flow 最大，这个 cut 最小。∎

在例子里，最后 $S=\{s,a,b,d\}$，$T=\{c,t\}$。从 $S$ 到 $T$ 的 arc 是 $a\to c$（2/2）和 $d\to t$（2/2），都满；从 $T$ 到 $S$ 的 arc 是 $c\to d$，flow 是 0，capacity 1 不计入。Cut capacity 4 = flow 4。

每次 augmentation 至少推 1（capacity 是 integer 时 bottleneck 是 integer），所以至多推 $v^*$ 次就停。每次用 BFS 或 DFS 找 path 是 $O(m)$，总共 $O(mv^*)$。

### 为什么 network LP 的答案总是 integer

上面的 flow 全是 integer。第 6 站说 shortest path 的 LP 会给出 0 或 1 的 flow。这不是巧合。

一个 matrix 的每个 square submatrix 的 determinant 都是 0、$+1$ 或 $-1$，这个 matrix 叫 totally unimodular（TU）。

**Theorem.** Node-arc incidence matrix $M$ 是 TU。

**Proof.** 对 submatrix 的大小 $k$ 做 induction。$k=1$：entry 只有 $0,\pm1$。设 $k-1$ 时成立，取一个 $k\times k$ submatrix $Q$。$M$ 的每一列只有两个非零 entry（一个 $+1$，一个 $-1$），所以 $Q$ 的每一列至多两个非零。三种情况：

- $Q$ 有一列全是 0：$\det Q=0$。
- $Q$ 有一列恰好一个非零 $\pm1$：沿这一列做 cofactor expansion，$\det Q=\pm\det Q'$，$Q'$ 是 $(k-1)\times(k-1)$ 的 submatrix，由 induction 是 $0,\pm1$。
- $Q$ 的每一列都恰好两个非零，一个 $+1$、一个 $-1$：把 $Q$ 的所有 row 相加，每一列得 0，rows linearly dependent，$\det Q=0$。∎

**推论。** $b$ 是 integer 时，$Mf=b$ 的每个 basic solution 都是 integer。由 Cramer's rule，$f_B=B^{-1}b$ 的每个 component 是 $\det(B_j)/\det(B)$，$B_j$ 是把 $B$ 的第 $j$ 列换成 $b$；$\det B=\pm1$（$B$ 是 $M$ 的 nonsingular square submatrix），$\det B_j$ 是 integer 的和与积，所以 $f_B$ 是 integer。加上 capacity $f\le u$ 后 matrix 变成 $\begin{pmatrix}M\\I\end{pmatrix}$，仍然是 TU（多出来的 row 只有一个 1，沿它 expand 即归到 $M$ 的情形）。Simplex 停在 BFS（第 2 站），所以 network LP 用 simplex 解出来的就是 integer solution，不用另外要求 integer。第 8 站会看到，没有这个结构时 integer 的要求让问题难得多。

### Transportation problem

两个仓库 $W_1$、$W_2$ 的库存是 30 和 40，三家店 $S_1$、$S_2$、$S_3$ 的需求是 20、25、25（总量都是 70）。每单位的运费：

| | $S_1$ | $S_2$ | $S_3$ | supply |
|---|---|---|---|---|
| $W_1$ | 4 | 6 | 9 | 30 |
| $W_2$ | 5 | 3 | 7 | 40 |
| demand | 20 | 25 | 25 | |

$x_{ij}$ 是从 $W_i$ 运到 $S_j$ 的量。Constraint 是每个仓库运出的等于库存、每家店收到的等于需求：

$$\sum_jx_{ij}=s_i,\qquad\sum_ix_{ij}=d_j,\qquad x\ge0$$

这是一个 min cost flow：仓库是 supply node，店是 demand node，arc 从每个仓库指向每家店。两个仓库的 equation 之和与三家店的 equation 之和是同一个式子（都等于总量 70），所以 5 个 equation 里有一个是多余的，所以 basis 有 $2+3-1=4$ 个 basic variable。

**起点：northwest corner。** 从表的左上角开始，尽量多分配，用完一行往下、满足一列往右：$x_{11}=20$（$S_1$ 满足），$x_{12}=10$（$W_1$ 用完），$x_{22}=15$（$S_2$ 满足），$x_{23}=25$。Cost $4\cdot20+6\cdot10+3\cdot15+7\cdot25=360$。

**检查 optimality：$u$–$v$ potential。** Dual 给每个仓库一个 $u_i$、每家店一个 $v_j$，dual constraint 是 $u_i+v_j\le c_{ij}$。Complementary slackness 要求 basic cell 上取等号：

$$u_1+v_1=4,\quad u_1+v_2=6,\quad u_2+v_2=3,\quad u_2+v_3=7$$

4 个 equation、5 个 unknown，令 $u_1=0$，依次得 $v_1=4$，$v_2=6$，$u_2=-3$，$v_3=10$。Nonbasic cell 的 reduced cost 是 $c_{ij}-u_i-v_j$：

$$\bar c_{13}=9-0-10=-1,\qquad\bar c_{21}=5-(-3)-4=4$$

$\bar c_{13}<0$（min 问题），说明 dual constraint $u_1+v_3\le9$ 被违反，从 $W_1$ 往 $S_3$ 运会更便宜。

**Pivot：沿 cycle 调整。** 让 $x_{13}$ 增加 $\theta$。为了保持行和列的总量，$x_{23}$ 减 $\theta$，$x_{22}$ 加 $\theta$，$x_{12}$ 减 $\theta$，形成 cycle $(1,3)^+\to(2,3)^-\to(2,2)^+\to(1,2)^-$。减少的 cell 不能变 negative：$\theta\le\min(x_{23},x_{12})=\min(25,10)=10$。取 $\theta=10$，$x_{12}$ 变成 0 出 basis：

$$x_{11}=20,\quad x_{13}=10,\quad x_{22}=25,\quad x_{23}=15$$

Cost 降低 $\theta\cdot|\bar c_{13}|=10$，变成 350。核对：$80+90+75+105=350$。

重算 potential：$u_1=0$，$v_1=4$，$v_3=9$，$u_2=7-9=-2$，$v_2=3+2=5$。Reduced cost：$\bar c_{12}=6-0-5=1$，$\bar c_{21}=5+2-4=3$，都 $\ge0$，optimal，最低运费 350。

::fig[ma3252-transport] 两个仓库、三家店画成 bipartite network。左边是 northwest corner 的方案，右边是 optimal 方案；arc 上是运量，彩色的是 $W_1\to S_3$，左边画成虚线，表示它即将进入 basis。四条 basic arc 在两边都组成一棵 spanning tree。

四个 basic cell 在 network 里是一棵连接全部 5 个 node 的 tree。Potential 能从 $u_1=0$ 一路解出来，就是沿着这棵 tree 走；pivot 时加进一条 arc，和 tree 形成唯一的一个 cycle，沿 cycle 调整 flow，再去掉一条 arc，又是一棵 tree。下一节把这件事推广到任意的 min cost flow。

### Network simplex：basis 就是 spanning tree

NUS Spring 2026 的安排里 network simplex 单独占一讲。先看没有 capacity 的情形：$\min c^\top f$ s.t. $Mf=b$，$f\ge0$，network 是 connected 的。

**Basis 长什么样。** $M$ 的 $n$ 个 row 加起来是 0（每一列一个 $+1$、一个 $-1$），所以 rank 至多 $n-1$；network connected 时它有 spanning tree，下面第二条说明 tree 的 $n-1$ 个 column linearly independent，所以 rank 恰好是 $n-1$。去掉任意一个 row 就满足第 2 站“row linearly independent”的假设。于是一个 basis 由 $n-1$ 条 arc 的 column 组成。哪些 arc 的 column 是 linearly independent 的？

- 这些 arc（不看方向）含一个 cycle 时，dependent。沿 cycle 走一圈，顺着走的 arc 的 column 乘 $+1$，逆着走的乘 $-1$，再相加。每走一步，不论 arc 的方向如何，都在出发的 node 贡献 $+1$、在到达的 node 贡献 $-1$；走完一圈每个 node 一进一出，和为 0。
- 不含 cycle 时，$n-1$ 条 arc 连着 $n$ 个 node，是一棵 spanning tree，independent。Tree 至少有两个 leaf（只连一条 arc 的 node），取一个不是被去掉那一行的 leaf，它的 row 在这些 column 里只有一个非零 entry。像 TU proof 的第二种情况那样沿它 expand，去掉这个 leaf 和它的 arc，剩下的还是一棵 tree，重复下去，determinant 是 $\pm1\ne0$。

所以 basis 和 spanning tree 一一对应：nonbasic 的 arc 上 flow 为 0，tree 上的 flow 由 conservation 唯一决定，全部 $\ge0$ 时就是 BFS。QMUL 的讲义把这样的 flow 叫 spanning tree solution。

**例子。** 4 个 node，supply $b=(5,2,-3,-4)$，6 条 arc：

| arc | $(1,2)$ | $(1,3)$ | $(2,3)$ | $(2,4)$ | $(3,4)$ | $(1,4)$ |
|---|---|---|---|---|---|---|
| cost | 2 | 4 | 1 | 6 | 2 | 9 |

**Tree 上的 flow：从 leaf 往里推。** 起点取 tree $T=\{(1,3),(2,3),(3,4)\}$。Node 1 只连 $(1,3)$，conservation 给出 $f_{13}=b_1=5$；node 2 只连 $(2,3)$，$f_{23}=2$；node 4 只连 $(3,4)$，流进 $f_{34}$ 等于需求 4。最后核对 node 3：流出减流进 $f_{34}-f_{13}-f_{23}=4-7=-3=b_3$。Cost $4\cdot5+1\cdot2+2\cdot4=30$。

**Potential 与 reduced cost。** 这个 LP 的 dual 给每个 node 一个 $p_i$（equality constraint，所以 free），每条 arc 一个 constraint $p_i-p_j\le c_{ij}$。Arc $(i,j)$ 的 reduced cost 是 $\bar c_{ij}=c_{ij}-(p_i-p_j)$，basic arc 的 reduced cost 是 0，所以 tree 上 $p_i-p_j=c_{ij}$。去掉的那一行对应的 node 取 $p_4=0$，沿 tree 解：$p_3=p_4+c_{34}=2$，$p_2=p_3+c_{23}=3$，$p_1=p_3+c_{13}=6$。$p_i$ 就是沿 tree 从 $i$ 送 1 单位到 node 4 的 cost。三条 nonbasic arc：

$$\bar c_{12}=2-(6-3)=-1,\qquad\bar c_{24}=6-(3-0)=3,\qquad\bar c_{14}=9-(6-0)=3$$

这是 min 问题，$\bar c_{12}<0$ 说明 $(1,2)$ 值得用。读法：从 node 1 送 1 单位到 node 3，tree 上走 $(1,3)$ 要 4；改走 $1\to2\to3$ 只要 $2+1=3$，省 1。

**Pivot：沿 cycle 调整。** 把 $(1,2)$ 加进 tree，和 tree 形成唯一的 cycle $1\to2\to3$，再沿 $(1,3)$ 逆着回到 1。让 $f_{12}=\theta$，为了守恒，$f_{23}$ 加 $\theta$，$f_{13}$ 减 $\theta$：

$$f_{12}=\theta,\qquad f_{23}=2+\theta,\qquad f_{13}=5-\theta$$

逐个 node 核对：node 1 流出 $\theta+(5-\theta)=5$；node 2 流出减流进 $(2+\theta)-\theta=2$；node 3 流出减流进 $4-(5-\theta)-(2+\theta)=-3$。只有逆着走的 arc 在减少，$\theta\le5$，取 $\theta=5$，$(1,3)$ 降到 0 出 tree。Cost 降低 $\theta\cdot|\bar c_{12}|=5$，变成 25。核对：新 tree $\{(1,2),(2,3),(3,4)\}$ 上 flow 是 5、7、4，cost $2\cdot5+1\cdot7+2\cdot4=25$。

重算 potential：$p_4=0$，$p_3=2$，$p_2=3$，$p_1=p_2+c_{12}=5$。Reduced cost：

$$\bar c_{13}=4-(5-2)=1,\qquad\bar c_{24}=6-(3-0)=3,\qquad\bar c_{14}=9-(5-0)=4$$

全部 $\ge0$，optimal，最低 cost 25。

::fig[ma3252-netsimplex] 同一个 4-node network 的两棵 tree。粗线是 tree arc，方框里是 flow，node 旁是 potential $p_i$；细线是 nonbasic arc，旁边是 reduced cost。左边彩色的 $(1,2)$ reduced cost 是 $-1$，它和 tree 形成的 cycle 围出浅色的三角形；推 5 单位后 $(1,3)$ 出 tree，得到右边，reduced cost 全部 $\ge0$。

如果 cycle 上所有 arc 都和 entering arc 同向，没有一条在减少，$\theta$ 可以无限大：这是一个 total cost 为 negative 的 cycle，沿它转圈 cost 无限下降，LP unbounded。

整个 pivot 只做加减：tree flow 从 leaf 往里推是加减，$\theta$ 是某条 arc 当前的 flow。$b$ 是 integer 时，每一步的 flow 都是 integer，这是上一节 total unimodularity 结论的另一种看法（QMUL 讲义的说法是 network simplex 不做除法）。

:::edge 找第一棵 feasible 的 tree
起点不是总能凑出来。QMUL 讲义的办法和 Big-M 一样：加一个辅助 node $d$，每个 supply node $i$ 加 arc $(i,d)$，每个 demand node 加 $(d,i)$，cost 都取一个很大的数（讲义取所有 $c_{ij}$ 之和，这里是 $2+4+1+6+2+9=24$）。这些辅助 arc 本身是一棵 spanning tree，flow $f_{1d}=5$，$f_{2d}=2$，$f_{d3}=3$，$f_{d4}=4$，自动 feasible。从它出发做 network simplex；如果 optimal solution 里某条辅助 arc 还有 flow，原问题 infeasible。
:::

:::edge 有 capacity 时
有 $0\le f_{ij}\le u_{ij}$ 时，nonbasic arc 可以停在 0，也可以停在 $u_{ij}$（满）。Tree 上的 flow 仍由 conservation 决定。Optimality 条件变成两种：停在 0 的 arc 要 $\bar c_{ij}\ge0$（增加它不会省钱），停在满的 arc 要 $\bar c_{ij}\le0$（减少它不会省钱）。违反的 arc 进来，沿 cycle 推 $\theta$ 时，$\theta$ 同时受“减少的 arc 不能低于 0”和“增加的 arc 不能超过 capacity”限制；卡住的可能就是 entering arc 自己，这时它从一头换到另一头，tree 不变。
:::

Assignment problem（$n$ 个人做 $n$ 件事，每人一件，总 cost 最小）是 supply 和 demand 都是 1 的 transportation problem。由 TU，LP 的 BFS 自动是 0 或 1，所以“每人恰好一件”不用另外要求。

## [ip] Integer programming 入门与 TSP

### 必须是 integer 的时候

有些 variable 只能是 integer：一台机器买或不买，一架飞机飞或不飞。MIT 15.093 Lecture 13 的 knapsack：四件物品，value 12、8、7、6，weight 8、6、5、4，背包限重 15，每件拿或不拿：

$$\max\ 12x_1+8x_2+7x_3+6x_4\quad\text{s.t.}\quad8x_1+6x_2+5x_3+4x_4\le15,\quad x_j\in\{0,1\}$$

把 $x_j\in\{0,1\}$ 放宽成 $0\le x_j\le1$，得到的 LP 叫 LP relaxation。

**LP relaxation 给出 bound。** Relaxation 的 feasible region 包含原问题的 feasible region，在更大的集合上取 max 不会更小，所以 LP 的 optimal value $\ge$ integer 问题的 optimal value（max 问题）。

这个 LP 好解：按 value/weight 从大到小装，$x_1$（1.5）和 $x_4$（1.5）先装满，weight 用掉 12；接着是 $x_3$（1.4），只剩 3，装 $3/5=0.6$。LP optimal $x=(1,0,0.6,1)$，value $12+4.2+6=22.2$。所以 integer 的答案不超过 22.2；又因为 value 都是 integer，不超过 22。

:::wrong 解 LP relaxation，再把答案 round 到最近的 integer
$(1,0,0.6,1)$ 的 $x_3$ round up 成 1，weight $8+5+4=17>15$，infeasible。Round down 成 0，得 $(1,0,0,1)$，value 18。真正的 optimal 是 $(0,1,1,1)$，weight 15，value 21：它不要 value/weight 最高的 $x_1$，和 LP 的答案几乎完全不同。Rounding 既可能出界，也可能离 optimal 很远，而且不告诉你差多少。
:::

### Branch and bound

办法是把问题分成几块，每块用 LP relaxation 求 bound，bound 不够好的块整个丢掉。

1. **Branch**：LP 的答案里有一个 fractional 的 $x_j$，就分成两个子问题，一个加 $x_j=0$，一个加 $x_j=1$（一般 integer variable 是 $x_j\le\lfloor x_j^*\rfloor$ 和 $x_j\ge\lceil x_j^*\rceil$）。两个子问题都排除了当前这个 fractional 的点，而所有 integer 的 feasible point 都落在其中一个里。
2. **Bound**：对每个子问题解 LP relaxation。
3. **Prune**：子问题 infeasible，丢掉；LP 的答案是 integer，它是一个候选（incumbent），记下最好的；LP 的 bound 不比 incumbent 好，丢掉，因为这一块里的 integer point 都不会超过它的 bound。

对上面的 knapsack，先在 $x_3$ 上分，每次先试 $=1$：

| node | 加的条件 | LP 的答案 | LP value | 处理 |
|---|---|---|---|---|
| 0 | 无 | $(1,0,0.6,1)$ | 22.2 | 在 $x_3$ 上分 |
| 1 | $x_3=1$ | $(1,0,1,0.5)$ | 22 | 在 $x_4$ 上分 |
| 2 | $x_3=1,x_4=1$ | $(0.75,0,1,1)$ | 22 | 在 $x_1$ 上分 |
| 3 | $x_3=1,x_4=1,x_1=1$ | | | infeasible：$8+5+4=17>15$ |
| 4 | $x_3=1,x_4=1,x_1=0$ | $(0,1,1,1)$ | 21 | integer，incumbent $=21$ |
| 5 | $x_3=1,x_4=0$ | $(1,\tfrac13,1,0)$ | 21.67 | 剪掉：integer value $\le21$ |
| 6 | $x_3=0$ | $(1,0.5,0,1)$ | 22 | 在 $x_2$ 上分 |
| 7 | $x_3=0,x_2=1$ | $(1,1,0,0.25)$ | 21.5 | 剪掉：integer value $\le21$ |
| 8 | $x_3=0,x_2=0$ | $(1,0,0,1)$ | 18 | 剪掉 |

Node 2 的 LP：$x_3=x_4=1$ 用掉 weight 9，剩 6；$x_1$ 的 value/weight 是 1.5，高于 $x_2$ 的 1.33，装 $6/8=0.75$，value $7+6+9=22$。Node 5：$x_3=1$、$x_4=0$，剩 10，$x_1$ 装满剩 2，$x_2$ 装 $2/6$，value $7+12+\tfrac83=21.67$。Node 5、7 的 bound 不到 22，而 value 是 integer，所以这两块里最好也只有 21，不可能超过 incumbent。

9 个 node 就证明了 21 是 optimal。全部枚举是 $2^4=16$ 种。规模大时，好的 bound 能剪掉的比例远大于此；bound 不好时，branch and bound 退化成枚举。

### Formulation 有强弱

同一个 integer 问题可以有不同的 formulation，integer solution 完全一样，LP relaxation 却差很多。MIT 15.093 的例子：$n+1$ 只 pigeon、$n$ 个 hole，每只 pigeon 进一个 hole，每个 hole 至多一只。显然 infeasible。$x_{ij}=1$ 表示 pigeon $i$ 进 hole $j$，每只 pigeon：$\sum_jx_{ij}=1$。

- **Formulation 1**：对每个 hole $j$ 和每两只 pigeon $i\ne k$，$x_{ij}+x_{kj}\le1$。
- **Formulation 2**：对每个 hole $j$，$\sum_ix_{ij}\le1$。

两者的 integer solution 相同（都是“每个 hole 至多一只”）。Formulation 1 有 $n\binom{n+1}{2}$ 条这样的 constraint（$n=10$ 时 550 条），formulation 2 只有 $n$ 条。但 LP relaxation 反而是 constraint 少的那个更紧：在 formulation 1 里取所有 $x_{ij}=1/n$，每只 pigeon 的和是 $n\cdot\tfrac1n=1$，每对的和是 $\tfrac2n\le1$（$n\ge2$），LP feasible，branch and bound 要分很多层才能发现 infeasible。在 formulation 2 里，把每个 hole 的 constraint 加起来得 $\sum_{i,j}x_{ij}\le n$，把每只 pigeon 的加起来得 $\sum_{i,j}x_{ij}=n+1$，矛盾，LP relaxation 本身就 infeasible，在 root 就结束。

LP relaxation 的 feasible region 越贴近 integer point 的 convex hull，bound 越好。第 7 站的 network 问题是极端情形：relaxation 的每个 vertex 本身就是 integer。

### Travelling salesman problem

6 个城市，要找一条经过每个城市恰好一次、回到起点的 tour，总距离最短。距离：城市 1、2、3 之间是 $d_{12}=3$、$d_{23}=3$、$d_{13}=4$；城市 4、5、6 之间是 $d_{45}=3$、$d_{56}=3$、$d_{46}=4$；两组之间 $d_{34}=5$、$d_{16}=5$，其余的 pair 都是 9。

$x_{ij}=1$ 表示 tour 从 $i$ 直接走到 $j$。每个城市恰好出去一次、进来一次：

$$\sum_jx_{ij}=1\ \ (\text{每个 }i),\qquad\sum_ix_{ij}=1\ \ (\text{每个 }j),\qquad x_{ij}\in\{0,1\}$$

这正是第 7 站的 assignment problem，由 TU 可以当作 LP 来解。解出来是 $1\to2\to3\to1$ 和 $4\to6\to5\to4$，总距离 $3+3+4+4+3+3=20$。每个城市都是一进一出，却是两个分开的 cycle，不是一条 tour。这样的 cycle 叫 subtour。

要排除 subtour，对城市的每个 nonempty 真子集 $S$ 加一条 constraint：$S$ 内部的 arc 至多用 $|S|-1$ 条，

$$\sum_{i\in S}\sum_{j\in S}x_{ij}\le|S|-1$$

一个 cycle 恰好经过 $S$ 的全部城市时，$S$ 内部用了 $|S|$ 条 arc，被这条 constraint 禁止；一条真正的 tour 在任何真子集 $S$ 内部至多用 $|S|-1$ 条（否则那部分自己就闭合了）。在这个例子里，只加 $S=\{1,2,3\}$ 一条，integer 问题的解就变成 tour $1\to2\to3\to4\to5\to6\to1$，长度 $3+3+5+3+3+5=22$，和枚举全部 tour 得到的最短长度一致。

::fig[ma3252-tsp] 左边：只有 assignment constraint 时的解，两个 subtour，总长 20。右边：加上 $S=\{1,2,3\}$ 的 subtour elimination constraint 后的解，一条 tour，总长 22。

这样的 constraint 有 $2^n-2$ 条，不能全部写出来。实际做法是先不加，解出来有 subtour 就把那个 $S$ 的 constraint 加上再解，配合 branch and bound。Assignment relaxation 给出的 20 是一个 lower bound（min 问题），MIT 15.093 用它在 branch and bound 里剪枝。TSP 没有已知的 polynomial time algorithm；第 6 站的 postman problem 要走遍每条 edge，却有。两者只差“每个 node”和“每条 edge”，复杂度天差地别。

:::back
LP relaxation 的 bound 是[第 4 站](#dual) weak duality 之外另一种得到 bound 的办法；assignment problem 自动给出 integer 解来自[第 7 站](#flow)的 total unimodularity；postman problem 在[第 6 站](#path)。
:::
