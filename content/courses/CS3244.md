先看三次失败。每一次都是 training data 上做得最好的那个，在新 data 上输了。

**第一次。** Target 是 $\sin(\pi x)$，在 $[-1,1]$ 上取 20 个点，加上 standard deviation 0.3 的 noise。用 degree-15 polynomial 去 fit，training error 平均只有 0.018；拿新的点检验，error 平均是 0.960。Degree-3 polynomial 在 training set 上是 0.078，在新的点上是 0.111。

**第二次。** 同一个 target，只给两个点，不加 noise。用 line 去 fit，在新的点上平均 error 是 1.88；用一个 constant 去 fit，是 0.75。Line 明明比 constant 更像 $\sin(\pi x)$。

**第三次。** 1000 枚公平的 coin，每枚掷 10 次。挑出 10 次全是正面的那一枚，它在“training data”上的正面率是 100%；这样的 coin 出现的 probability 是 62%，而它下一次掷出正面的 probability 仍是一半。

三件事是同一个问题：在 training data 上 error 小，凭什么相信在没见过的 data 上 error 也小？这门课一半的内容在回答它。第 1 站把 test error 拆成 bias 和 variance，第 2 站用 probability 给出一个 bound，第 3 站讲两个对策：给 model 加 penalty，以及留一部分 data 检验。后半门课的每个方法都可以用这三站的眼光去看：SVM 用 margin 控制 complexity（第 4 站），ensemble 用平均压 variance、用 reweighting 压 bias（第 5 站），neural network 的 training 首先要让 gradient 能传得动（第 6 站）。最后两站没有 label，要从 data 本身找结构：cluster（第 7 站）和 dimension（第 8 站）。

## [gen] Generalization：E_in、E_out 与 bias-variance

:::skip
能推出 $\mathbb E_\mathcal{D}[E_\text{out}]=\text{bias}+\text{var}$，能算两个点学 $\sin(\pi x)$ 时 constant model 的 bias 和 variance，能由 hat matrix 推出 $\mathbb E[E_\text{in}]=\sigma^2\big(1-\tfrac{d+1}{N}\big)$，就可以去第 2 站。
:::

### 两种 error

给定一个 hypothesis $h$ 和一个 pointwise 的 error measure $e$（regression 用 squared error，classification 用 $[h(x)\ne y]$），定义

$$E_\text{in}(h)=\frac1N\sum_{n=1}^Ne\big(h(x_n),y_n\big),\qquad E_\text{out}(h)=\mathbb{E}_{x,y}\Big[e\big(h(x),y\big)\Big]$$

前者是 training set 上的平均，算得出来；后者是对产生 data 的那个 distribution 求 expectation，算不出来。Learning algorithm 在 hypothesis set $\mathcal H$ 里挑 $E_\text{in}$ 最小的，记作 $g$。我们关心的是 $E_\text{out}(g)$。

开头第一次失败的完整数据：$x$ 取 $[-1,1]$ 上 20 个 equispaced 的点，$y=\sin(\pi x)+\epsilon$，$\epsilon$ 的 standard deviation 是 0.3（variance 0.09）。对每个 degree 用 least squares fit，noise 重抽 5000 次取平均：

| degree | 0 | 1 | 3 | 5 | 10 | 13 | 15 |
|---|---|---|---|---|---|---|---|
| $E_\text{in}$ | 0.561 | 0.313 | 0.078 | 0.063 | 0.041 | 0.027 | 0.018 |
| $E_\text{out}$ | 0.594 | 0.302 | 0.111 | 0.113 | 0.138 | 0.207 | 0.960 |

::fig[cs3244-complexity] 同一张表画出来。$E_\text{in}$ 一路下降，$E_\text{out}$ 在 degree 3 最低，之后上升。

$E_\text{in}$ 一路下降是必然的：degree 高的 hypothesis set 包含 degree 低的，在更大的集合里取 minimum，结果只会更小。$E_\text{out}$ 没有这个保证。要知道它为什么先降后升，得把它拆开。

### 把 $E_\text{out}$ 拆开

$g$ 依赖于这一次抽到的 training set $\mathcal D$，记作 $g^{(\mathcal D)}$。换一个 $\mathcal D$，得到另一个 $g$。所以先对 $\mathcal D$ 取 expectation，问“平均而言”这个 learning 过程有多好。先看没有 noise 的情形，$y=f(x)$，squared error：

$$\mathbb E_\mathcal D\big[E_\text{out}(g^{(\mathcal D)})\big]=\mathbb E_\mathcal D\,\mathbb E_x\Big[\big(g^{(\mathcal D)}(x)-f(x)\big)^2\Big]=\mathbb E_x\,\mathbb E_\mathcal D\Big[\big(g^{(\mathcal D)}(x)-f(x)\big)^2\Big]$$

第二个等号交换了两个 expectation 的次序，于是可以固定一个 $x$ 来看里面那一项。定义 average hypothesis

$$\bar g(x)=\mathbb E_\mathcal D\big[g^{(\mathcal D)}(x)\big]$$

在括号里减去再加上 $\bar g(x)$，展开 square：

$$\mathbb E_\mathcal D\Big[\big(g^{(\mathcal D)}-\bar g+\bar g-f\big)^2\Big]=\mathbb E_\mathcal D\Big[\big(g^{(\mathcal D)}-\bar g\big)^2\Big]+2\big(\bar g-f\big)\,\mathbb E_\mathcal D\big[g^{(\mathcal D)}-\bar g\big]+\big(\bar g-f\big)^2$$

$\bar g-f$ 与 $\mathcal D$ 无关，提到 expectation 外面；而按 $\bar g$ 的定义 $\mathbb E_\mathcal D[g^{(\mathcal D)}-\bar g]=0$，中间一项消失。再对 $x$ 取 expectation：

$$\mathbb E_\mathcal D\big[E_\text{out}\big]=\underbrace{\mathbb E_x\Big[\big(\bar g(x)-f(x)\big)^2\Big]}_{\text{bias}}+\underbrace{\mathbb E_x\,\mathbb E_\mathcal D\Big[\big(g^{(\mathcal D)}(x)-\bar g(x)\big)^2\Big]}_{\text{var}}$$

Bias 量的是“无限多个 training set 的平均”离 target 有多远（已经是 square 过的量），variance 量的是一次具体的 $g$ 围绕这个平均摆动多大。有 noise 时再加上 $\sigma^2$，理由和 [CS2109S 第 6 站](../courses/CS2109S.html#logreg)相同：新点的 noise 与 $\mathcal D$ independent、mean 为 0，cross term 消失。

拿上表核对。Degree 3：bias 0.0051，variance 0.0158，加上 $\sigma^2=0.09$ 得 0.111，正是表里的 $E_\text{out}$。Degree 15：bias 0.0001，variance 0.870，合计 0.960。Degree 0：bias 0.500，variance 0.004。左边贵在 bias，右边贵在 variance。

### 只有两个点的时候

开头第二次失败出自 Abu-Mostafa 第 8 讲。Target $f(x)=\sin(\pi x)$，$x$ 在 $[-1,1]$ 上 uniform，只有 $N=2$ 个点，没有 noise。两个 hypothesis set：$\mathcal H_0$ 是 constant $h(x)=b$，$\mathcal H_1$ 是 line $h(x)=ax+b$。

先只问能 approximate 得多好。$\mathcal H_0$ 里最好的是 $b=0$，$E_\text{out}=\mathbb E[\sin^2\pi x]=\tfrac12$；$\mathcal H_1$ 里最好的是 $0.955x$，$E_\text{out}=0.196$。$\mathcal H_1$ 好得多。

现在只给两个点 $(x_1,y_1)$、$(x_2,y_2)$。$\mathcal H_0$ 的 least squares 是 $b=\tfrac{y_1+y_2}2$，可以手算：

- $\bar g(x)=\mathbb E\big[\tfrac{\sin\pi x_1+\sin\pi x_2}{2}\big]=0$，因为 $\sin\pi x$ 在 $[-1,1]$ 上的 mean 是 0。
- bias $=\mathbb E_x[(0-\sin\pi x)^2]=\tfrac12$。
- var $=\mathrm{Var}\big(\tfrac{y_1+y_2}2\big)=\tfrac14\cdot2\,\mathrm{Var}(\sin\pi x)=\tfrac14\cdot2\cdot\tfrac12=\tfrac14$。$g$ 是 constant，所以对每个 $x$ variance 都一样。

合计 0.75。$\mathcal H_1$ 是过两点的 line，slope $a=\tfrac{y_2-y_1}{x_2-x_1}$。这里用数值 integration 算：$\mathbb E[a]=0.776$，$\mathbb E[b]=0$，所以 $\bar g(x)=0.776x$，bias 是 0.21；$\mathrm{Var}(a)=2.296$，$\mathrm{Var}(b)=0.911$，两者的 covariance 由 symmetry 为 0，于是在 $x$ 处 variance 是 $2.296x^2+0.911$，对 $x$ 取平均得 $\tfrac{2.296}{3}+0.911=1.68$。合计 1.88。

::fig[cs3244-sinfit] 两个点学 $\sin(\pi x)$。$\mathcal H_1$ 的 $\bar g$ 更贴近 target，但每次 fit 出的 line 在两端可以偏到 2 以外。

> 选 model 的 complexity，看的是手里有多少 data，不是 target 有多复杂。

:::wrong Target 是 sine，比 line 还复杂，所以至少该用 line 去 fit
“能 approximate 得多好”只是 bias 那一项。$\mathcal H_1$ 的 bias 确实小（0.21 对 0.50），但两个点定一条 line，slope 的 variance 是 2.3，平均下来 variance 1.68，把 bias 上省下的全赔进去还倒贴。只有两个点时 constant 的 $E_\text{out}$ 0.75 远好于 line 的 1.88。Data 多了，variance 会降，line 才会赢。
:::

### Learning curve：N 变大时会怎样

固定 model，改变 $N$，画 $\mathbb E[E_\text{in}]$ 和 $\mathbb E[E_\text{out}]$，叫 learning curve。Linear regression 的 learning curve 可以精确算出来。设 $y=Xw^*+\epsilon$，$X$ 是 $N\times(d+1)$（含 constant 的那一个 column），$\epsilon$ 的各个 component independent、mean 0、variance $\sigma^2$。Least squares 给出

$$\hat y=X(X^\top X)^{-1}X^\top y=Hy$$

$H$ 是向 $X$ 的 column space 做 projection 的 matrix（[DSA2102 第 4 站](../courses/DSA2102.html#ls)的那张图），满足 $H^\top=H$、$H^2=H$，而且 $HX=X$。

**$E_\text{in}$。** Residual 是 $y-\hat y=(I-H)y=(I-H)(Xw^*+\epsilon)=(I-H)\epsilon$，因为 $(I-H)X=0$。$I-H$ 也是 symmetric 而且 $(I-H)^2=I-H$，所以

$$N\,E_\text{in}=\|(I-H)\epsilon\|^2=\epsilon^\top(I-H)\epsilon$$

对任意 matrix $A$，$\mathbb E[\epsilon^\top A\epsilon]=\sum_{i,j}A_{ij}\,\mathbb E[\epsilon_i\epsilon_j]=\sigma^2\sum_iA_{ii}=\sigma^2\,\mathrm{tr}(A)$。而 $\mathrm{tr}(H)=\mathrm{tr}\big(X(X^\top X)^{-1}X^\top\big)=\mathrm{tr}\big((X^\top X)^{-1}X^\top X\big)=\mathrm{tr}(I_{d+1})=d+1$。于是

$$\mathbb E[E_\text{in}]=\frac{\sigma^2\,(N-d-1)}{N}=\sigma^2\Big(1-\frac{d+1}{N}\Big)$$

**$E_\text{test}$。** 在同样的 $x$ 上重新抽 noise $\epsilon'$，$y'=Xw^*+\epsilon'$。Prediction 的 error 是 $\hat y-y'=Hy-y'=H\epsilon-\epsilon'$（用了 $HXw^*=Xw^*$）。$\epsilon'$ 与 $\epsilon$ independent、mean 0，cross term 的 expectation 是 0：

$$N\,\mathbb E[E_\text{test}]=\mathbb E\|H\epsilon\|^2+\mathbb E\|\epsilon'\|^2=\sigma^2\,\mathrm{tr}(H^\top H)+N\sigma^2=\sigma^2(d+1)+N\sigma^2$$

所以 $\mathbb E[E_\text{test}]=\sigma^2\big(1+\tfrac{d+1}{N}\big)$，两者之差 $\tfrac{2\sigma^2(d+1)}{N}$。

拿开头的例子检验：degree-5 polynomial 有 6 个 coefficient，$d+1=6$；$\sigma^2=0.09$；它对 $\sin(\pi x)$ 的 bias 小到可以忽略。Noise 重抽 20000 次：

| $N$ | 8 | 10 | 15 | 20 | 50 | 100 |
|---|---|---|---|---|---|---|
| $E_\text{in}$ 实算 | 0.0226 | 0.0363 | 0.0540 | 0.0630 | 0.0792 | 0.0847 |
| $\sigma^2(1-6/N)$ | 0.0225 | 0.0360 | 0.0540 | 0.0630 | 0.0792 | 0.0846 |
| $E_\text{test}$ 实算 | 0.157 | 0.145 | 0.126 | 0.117 | 0.101 | 0.095 |
| $\sigma^2(1+6/N)$ | 0.158 | 0.144 | 0.126 | 0.117 | 0.101 | 0.095 |

上一节表里 degree 5 那一格的 $E_\text{in}=0.063$ 也正是 $0.09\times(1-\tfrac6{20})$。$E_\text{test}$ 用的是原来的 $x$；换成 $[-1,1]$ 上全新的 $x$，实算是 0.152（$N=8$）、0.113（$N=20$）、0.095（$N=100$），与上式相差不大，但不再精确相等。

::fig[cs3244-learncurve] 两条 curve 从两侧以 $1/N$ 的速度趋向 $\sigma^2$。$E_\text{in}$ 低于 $\sigma^2$，是因为 model 用掉了 $d+1$ 个 degree of freedom 去 fit noise。

读 learning curve：gap 大，variance 占主导，加 data 或 regularization 有用；两条 curve 都高且已靠在一起，bias 占主导，加 data 没用，要换更复杂的 model。

## [vc] Learning 的可行性：Hoeffding、growth function 与 VC dimension

:::skip
能说清为什么挑出来的 $g$ 要付 union bound 的代价，能算三个例子的 growth function，能证明 $B(N,k)$ 的 recursion 和 perceptron 的 $d_\text{VC}=d+1$，就可以去第 3 站。
:::

这一站只谈 binary classification，$e(h(x),y)=[h(x)\ne y]$，所以 $E_\text{out}(h)$ 是一个 probability，$E_\text{in}(h)$ 是 sample 里的比例。

### 一个固定的 hypothesis：Hoeffding

先想一个比 learning 简单的问题。一个罐子里红球的比例是未知的 $\mu$，independent 地摸 $N$ 个，红球的比例是 $\nu$。$\nu$ 能告诉我们 $\mu$ 吗？不能确定地告诉，但能以很大的 probability 告诉：

$$\mathbb P\big[|\nu-\mu|>\epsilon\big]\le2e^{-2\epsilon^2N}$$

这是 Hoeffding inequality。右边与 $\mu$ 无关，也与 distribution 的形状无关。

对应到 learning：固定一个 $h$，每个 $x$ 是一个球，$h(x)\ne f(x)$ 就是红球。于是 $\mu=E_\text{out}(h)$，$\nu=E_\text{in}(h)$，Hoeffding 直接给出 $E_\text{in}(h)$ 离 $E_\text{out}(h)$ 不远。$N=100$、$\epsilon=0.1$ 时，右边是 $2e^{-2}=0.27$。要 $\epsilon=0.05$ 且 probability 不超过 $\delta=0.05$，解 $2e^{-2\epsilon^2N}\le\delta$ 得

$$N\ge\frac{\ln(2/\delta)}{2\epsilon^2}=\frac{\ln40}{0.005}=738$$

为什么非要 exponential 的 bound？[ST2131](../courses/ST2131.html#limit) 的 Chebyshev inequality 也能用：$\mathrm{Var}(\nu)=\tfrac{\mu(1-\mu)}N\le\tfrac1{4N}$，所以 $\mathbb P[|\nu-\mu|>\epsilon]\le\tfrac{1}{4N\epsilon^2}$。$N=100$、$\epsilon=0.1$ 时是 0.25，和 Hoeffding 差不多；$N=1000$ 时 Chebyshev 是 0.025，Hoeffding 是 $2e^{-20}=4\times10^{-9}$。下一节要把这个 probability 乘上很大的数，只有 exponential 的才经得起乘。

### 挑出来的那一个：union bound

Hoeffding 有一个前提：$h$ 要在看到 data 之前就定好。Learning 恰恰相反，$g$ 是看了 data 之后挑的。

开头的 coin 说明了差别。一枚指定的 coin 掷 10 次全正面，probability 是 $2^{-10}=\tfrac1{1024}$。1000 枚 coin 里至少有一枚全正面：

$$1-\Big(1-\frac1{1024}\Big)^{1000}=0.624$$

挑出那一枚，它的 $\nu=1$ 而 $\mu=\tfrac12$。每一枚 coin 单独都满足 Hoeffding，但“挑出 $\nu$ 最极端的那一枚”之后，就不满足了。

$\mathcal H$ 里有 $M$ 个 hypothesis 时，$g$ 是其中之一，所以“$g$ 偏得厉害”这件事蕴含“某一个 $h_m$ 偏得厉害”。用 union bound（几个 event 之并的 probability 不超过各自 probability 之和）：

$$\mathbb P\big[|E_\text{in}(g)-E_\text{out}(g)|>\epsilon\big]\le\sum_{m=1}^M\mathbb P\big[|E_\text{in}(h_m)-E_\text{out}(h_m)|>\epsilon\big]\le2Me^{-2\epsilon^2N}$$

$M=1000$、$\epsilon=0.05$、$\delta=0.05$：$N\ge\tfrac{\ln(2M/\delta)}{2\epsilon^2}=\tfrac{\ln40000}{0.005}=2120$。$M$ 只在 log 里，代价不大。麻烦是 perceptron 有无穷多个 hypothesis，$M=\infty$，这个 bound 什么也没说。

:::wrong Hoeffding 保证 $E_\text{in}$ 接近 $E_\text{out}$，所以 training error 小的 model，test error 也小
Hoeffding 只对事先固定的 $h$ 成立。Training 把 $E_\text{in}$ 最小的那个挑出来，正像从 1000 枚 coin 里挑全正面的那枚：被挑中，恰恰因为它在这个 sample 上碰巧走运。挑的范围越大，走运的越极端，所以 bound 里要乘上 $M$，或者下面要讲的 $m_\mathcal H(N)$。只有 test set 上的 error 才适用不乘 $M$ 的 Hoeffding，因为 test set 没有参与挑选。
:::

### 把 M 换成 dichotomy 的个数

Union bound 浪费在哪里？它假设各个 bad event 互不重叠。两条几乎一样的 line，在同一个 sample 上的 $E_\text{in}$ 几乎一样，它们的 bad event 几乎是同一个 event，却被加了两次。

在 $N$ 个固定的点上，一个 $h$ 的作用只体现为它给这 $N$ 个点贴的 label，叫 dichotomy。无论 $\mathcal H$ 多大，不同的 dichotomy 至多 $2^N$ 个。定义 growth function

$$m_\mathcal H(N)=\max_{x_1,\dots,x_N}\big|\{(h(x_1),\dots,h(x_N)):h\in\mathcal H\}\big|\le2^N$$

三个例子：

- **Positive ray**，$h(x)=\mathrm{sign}(x-a)$。$N$ 个点把 real line 分成 $N+1$ 段，$a$ 落在哪一段决定 dichotomy，所以 $m_\mathcal H(N)=N+1$。
- **Positive interval**，区间 $[l,r]$ 内为 $+1$。两个 endpoint 落在 $N+1$ 段里的两段不同的段，$\binom{N+1}2$ 种；落在同一段时全是 $-1$，再加 1 种。$m_\mathcal H(N)=\tfrac12N^2+\tfrac12N+1$。
- **2D perceptron**，$h(x)=\mathrm{sign}(w_0+w_1x_1+w_2x_2)$。三个不 collinear 的点，8 种 label 都能用一条 line 实现，$m_\mathcal H(3)=8$。四个点时有 label 做不到。四个点若构成 convex quadrilateral，把一条 diagonal 的两端标 $+1$、另一条的两端标 $-1$：如果有 line 分开它们，两条 diagonal 各自落在一个 half-plane 内（half-plane 是 convex 的，两个 endpoint 在里面，segment 就在里面），可两条 diagonal 相交，矛盾。这样的 label 有 2 种。若一个点在另外三点的 triangle 里面，把它标 $+1$、其余标 $-1$ 不可能（triangle 落在 $-1$ 的 half-plane 里，里面的点也是），反过来也一样，同样 2 种。所以无论四个点怎么摆，至少缺 2 种；convex 位置时其余 14 种都能实现，$m_\mathcal H(4)=16-2=14$。对一般位置的 $N$ 个点，逐个 labeling 用 linear programming 判断能否分开，$N=1$ 到 $7$ 数出来是 $2,4,8,14,22,32,44$，正是 $N^2-N+2$。

$m_\mathcal H(k)<2^k$ 的最小的 $k$ 叫 break point：positive ray 是 2，positive interval 是 3，2D perceptron 是 4。

::fig[cs3244-growth] 三个 growth function 和 $2^N$。有 break point 的都只按 polynomial 增长；灰线是下一节证明的 upper bound。

### 有 break point 就只能是 polynomial

记 $B(N,k)$ 为：在 $N$ 个点上、任意 $k$ 个点都不能被 shatter（所有 $2^k$ 种 label 都出现）的前提下，dichotomy 最多有多少个。证明它被一个 polynomial 控制。

把所有 dichotomy 按前 $N-1$ 个点上的 label 分组。有的 pattern 只和 $x_N=+1$ 或只和 $x_N=-1$ 搭配出现，设有 $\alpha$ 个；有的 pattern 两种都出现，设有 $\beta$ 个，各占两行。于是 $B(N,k)=\alpha+2\beta$。

- 只看前 $N-1$ 个点，不同的 pattern 有 $\alpha+\beta$ 个，它们仍然不能 shatter 任何 $k$ 个点，所以 $\alpha+\beta\le B(N-1,k)$。
- 只看那 $\beta$ 个 pattern，它们不能 shatter 前 $N-1$ 个点里的任何 $k-1$ 个点：否则对这 $k-1$ 个点的每种 label，$x_N$ 都可以取 $+1$ 或 $-1$，加上 $x_N$ 就 shatter 了 $k$ 个点。所以 $\beta\le B(N-1,k-1)$。

两式相加：

$$B(N,k)\le B(N-1,k)+B(N-1,k-1)$$

Boundary：$B(N,1)=1$（任何一个点都不能有两种 label，只能有一个 dichotomy），$B(1,k)=2$（$k\ge2$）。按 induction 可以验证 $B(N,k)\le\sum_{i=0}^{k-1}\binom Ni$：boundary 显然成立；代入 recursion，用 Pascal's rule $\binom{N-1}i+\binom{N-1}{i-1}=\binom Ni$，

$$\sum_{i=0}^{k-1}\binom{N-1}i+\sum_{i=0}^{k-2}\binom{N-1}{i}=1+\sum_{i=1}^{k-1}\Big[\binom{N-1}i+\binom{N-1}{i-1}\Big]=\sum_{i=0}^{k-1}\binom Ni$$

右边是 $N$ 的 degree-$(k-1)$ polynomial。用在 2D perceptron（$k=4$）上：$N=5$ 时 bound 是 $1+5+10+10=26$，实际 22；$N=10$ 时 bound 是 176，实际 92，而 $2^{10}=1024$。

把 $M$ 换成 $m_\mathcal H$ 还有一个细节：$E_\text{out}$ 依赖于整个 input space，不是 $N$ 个点上的事。Abu-Mostafa 的做法是再抽一个 $N$ 个点的“ghost” sample，用它的 error 代替 $E_\text{out}$，于是要数 $2N$ 个点上的 dichotomy。结果是 VC inequality：

$$\mathbb P\big[|E_\text{in}(g)-E_\text{out}(g)|>\epsilon\big]\le4\,m_\mathcal H(2N)\,e^{-\epsilon^2N/8}$$

常数变差了，结构没变：polynomial 乘 exponential，$N$ 足够大时趋于 0。证明这里不给出。

### VC dimension

$m_\mathcal H(N)=2^N$ 成立的最大的 $N$ 叫 VC dimension，$d_\text{VC}=k-1$。于是 $m_\mathcal H(N)\le\sum_{i=0}^{d_\text{VC}}\binom Ni\le N^{d_\text{VC}}+1$。

**$d$ 维 perceptron 的 $d_\text{VC}=d+1$。** 把 $x$ 写成带 1 的 $\tilde x=(1,x_1,\dots,x_d)\in\mathbb R^{d+1}$，$h(x)=\mathrm{sign}(w^\top\tilde x)$。

- $\ge d+1$：取原点和 $d$ 个 standard basis vector，共 $d+1$ 个点。它们的 $\tilde x$ 排成的 $(d+1)\times(d+1)$ matrix $X$ 第一行是 $(1,0,\dots,0)$，第 $i+1$ 行是 $(1,e_i)$；后面每一行减去第一行就得到 identity matrix，所以 $X$ invertible。对任意 label $y\in\{\pm1\}^{d+1}$，取 $w=X^{-1}y$，则 $Xw=y$，sign 恰好是 $y$。
- $\le d+1$：任取 $d+2$ 个点，它们的 $\tilde x$ 是 $\mathbb R^{d+1}$ 里 $d+2$ 个 vector，必然 linearly dependent，某一个可以写成 $\tilde x_j=\sum_{i\ne j}a_i\tilde x_i$，$a_i$ 不全为 0。考虑这样的 label：$a_i\ne0$ 的点取 $y_i=\mathrm{sign}(a_i)$，第 $j$ 个点取 $y_j=-1$。如果某个 $w$ 实现了它，那么每个 $a_i\ne0$ 都有 $a_i\,w^\top\tilde x_i>0$，相加得 $w^\top\tilde x_j=\sum a_i\,w^\top\tilde x_i>0$，$x_j$ 会被标 $+1$，矛盾。

$d=2$ 时 $d_\text{VC}=3$，与 break point 4 吻合。这里 $d_\text{VC}$ 正好等于 parameter 的个数 $w_0,\dots,w_d$。

:::wrong VC dimension 就是 parameter 的个数
$h(x)=\mathrm{sign}(\sin\omega x)$ 只有一个 parameter $\omega$，$d_\text{VC}$ 却是 infinite。取 $x_i=10^{-i}$，$i=1,\dots,N$，对任意 label 取 $\omega=\pi\big(1+\sum_i\tfrac{1-y_i}{2}10^i\big)$ 即可实现，这里对 $N=3,4,5$ 的全部 labeling 逐个算过。反方向也有：一个 parameter 如果只是另一个的复制品，加上它不增加任何 dichotomy。VC dimension 数的是 $\mathcal H$ 实际能产生多少种 label，parameter 的个数只是常见情形下的近似。
:::

### 要多少 data

把 VC inequality 的右边记作 $\delta$，解出 $\epsilon$：以至少 $1-\delta$ 的 probability，

$$E_\text{out}(g)\le E_\text{in}(g)+\Omega,\qquad\Omega=\sqrt{\frac8N\ln\frac{4\,m_\mathcal H(2N)}{\delta}}$$

取 $d_\text{VC}=3$、$\delta=0.1$，$m_\mathcal H(2N)\le(2N)^3+1$：

| $N$ | 100 | 1000 | 10000 | 100000 |
|---|---|---|---|---|
| $\Omega$ | 1.25 | 0.46 | 0.16 | 0.057 |

反过来问：要 $\Omega\le0.1$ 需要多大的 $N$？$N$ 同时出现在两边，用 iteration 解 $N=\tfrac8{\epsilon^2}\ln\tfrac{4((2N)^3+1)}{\delta}$：从 $N=1000$ 出发，依次得到 21193、28522、29235、29294、29299，converge 到约 29300。$d_\text{VC}=4$ 时约 39000，$d_\text{VC}=5$ 时约 48900。

这个 bound 非常松，因为它对任意 distribution、任意 target 都要成立。实际经验是 $N\ge10\,d_\text{VC}$ 就能得到不错的 generalization。Bound 的价值在于相对关系：每多一个 VC dimension，所需的 $N$ 大约多一份，$N$ 与 $d_\text{VC}$ 大致成正比。第 1 站的 learning curve 里 gap 是 $\tfrac{2\sigma^2(d+1)}{N}$，说的是同一件事。

:::back
VC 的分析与[第 1 站](#gen)的 bias-variance 从两个角度看同一个 tradeoff：$\mathcal H$ 越复杂，$E_\text{in}$ 越小（bias 越小），$\Omega$ 越大（variance 越大）。
:::

罐子与球、Hoeffding 到 $E_\text{in}$、$E_\text{out}$ 的对应、1000 枚 coin 的例子和 $2Me^{-2\epsilon^2N}$ 来自 [Caltech CS156 第 2 讲](http://work.caltech.edu/slides/slides02.pdf)；dichotomy、growth function 的三个例子、break point 来自[第 5 讲](http://work.caltech.edu/slides/slides05.pdf)；$\alpha$、$\beta$ 分组证明 recursion、closed form、ghost sample 与 VC inequality 来自[第 6 讲](http://work.caltech.edu/slides/slides06.pdf)；perceptron 的 $d_\text{VC}=d+1$ 的两个方向、$\Omega$ 的 formula、$N\ge10d_\text{VC}$ 来自[第 7 讲](http://work.caltech.edu/slides/slides07.pdf)。四份 slides 读的是全文，VC inequality 的证明那里只有图示；[CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)第 8.3 节与此一致。Chebyshev 与 Hoeffding 的对比、四个点不能 shatter 的几何论证、用 linear programming 数出的 $N^2-N+2$、$\sin\omega x$ 的验证、iteration 的数列是为这一页写和算的；$\sin\omega x$ 的构造是常见的教科书例子，这里凭自己的知识写。

## [reg] Linear model 作为 MLE：L1、L2 regularization 与 validation

:::skip
能从 likelihood 和 prior 推出 least squares、ridge、lasso，能写出 soft-thresholding 并说清 L1 为什么给出 0，能推出 LOOCV 的 shortcut $\tfrac{e_n}{1-H_{nn}}$，就可以去第 4 站。
:::

### Squared error 从哪里来

[CS2109S](../courses/CS2109S.html#linreg) 直接把 squared error 当成 loss。它其实是一个 probability model 的 maximum likelihood。设

$$y_n=w^\top x_n+\epsilon_n,\qquad\epsilon_n\sim\mathcal N(0,\sigma^2)\ \text{independent}$$

Log-likelihood 是

$$\ell(w,\sigma^2)=\sum_{n=1}^N\ln\Big[\frac1{\sqrt{2\pi\sigma^2}}e^{-(y_n-w^\top x_n)^2/(2\sigma^2)}\Big]=-\frac N2\ln(2\pi\sigma^2)-\frac1{2\sigma^2}\sum_n(y_n-w^\top x_n)^2$$

$w$ 只出现在最后一项里，前面带着负号，所以对 $w$ 最大化 likelihood 就是最小化 sum of squares。再对 $\sigma^2$ 求 derivative 令其为 0，$-\tfrac N{2\sigma^2}+\tfrac{\text{RSS}}{2\sigma^4}=0$，得 $\hat\sigma^2=\text{RSS}/N$。用 DSA2102 那三个点 $(1,1)$、$(2,2)$、$(3,2)$：line 是 $\tfrac23+\tfrac12t$，RSS $=\tfrac16$，所以 $\hat\sigma^2=\tfrac1{18}$。MLE 的一般性质见 [ST2132 第 2 站](../courses/ST2132.html#est)。

同样的推理用在 label 为 0 或 1、$\mathbb P(y=1\mid x)=\sigma(w^\top x)$ 的 Bernoulli model 上，负的 log-likelihood 就是 [CS2109S 第 6 站](../courses/CS2109S.html#logreg)的 cross-entropy。Loss 的选择等于 noise model 的选择。

### Prior 变成 penalty

MLE 只问 data 支持哪个 $w$。如果事先相信 $w$ 不会太大，可以给它一个 prior $p(w)$，然后最大化 posterior。由 Bayes' rule $p(w\mid\mathcal D)\propto p(\mathcal D\mid w)\,p(w)$，取 negative log：

$$-\ln p(w\mid\mathcal D)=\frac1{2\sigma^2}\sum_n(y_n-w^\top x_n)^2-\ln p(w)+\text{const}$$

这叫 maximum a posteriori（MAP）。

- **Gaussian prior** $w_j\sim\mathcal N(0,\tau^2)$：$-\ln p(w)=\tfrac{1}{2\tau^2}\|w\|_2^2+\text{const}$。乘以 $2\sigma^2$，要最小化的是 $\|y-Xw\|^2+\tfrac{\sigma^2}{\tau^2}\|w\|_2^2$，正是 ridge regression，$\lambda=\sigma^2/\tau^2$。
- **Laplace prior** $p(w_j)=\tfrac1{2b}e^{-|w_j|/b}$：$-\ln p(w)=\tfrac1b\|w\|_1+\text{const}$，得到 $\|y-Xw\|^2+\tfrac{2\sigma^2}{b}\|w\|_1$，这叫 lasso。

$\lambda$ 大，等于 prior 很窄（$\tau$ 或 $b$ 小），事先就很确信 weight 接近 0。两个 prior 的差别在形状：Gaussian 在 0 附近是平的，Laplace 在 0 处有一个尖。这个尖带来下面的 sparsity。

### L1 为什么给出 0

先看能完全算出来的情形：design matrix 的 column 是 orthonormal 的，$X^\top X=I$。记 $z=X^\top y$，它就是不加 penalty 时的 least squares solution。展开

$$\|y-Xw\|^2=\|y\|^2-2w^\top X^\top y+w^\top X^\top Xw=\|y\|^2-2w^\top z+\|w\|^2=\sum_j(w_j-z_j)^2+\text{const}$$

问题按 coordinate 拆开，每个 $w_j$ 单独解。

**Ridge**：最小化 $(w-z)^2+\lambda w^2$，derivative $2(w-z)+2\lambda w=0$，得 $w=\dfrac{z}{1+\lambda}$。每个 coordinate 按同一个比例缩小，只要 $z\ne0$，结果就不为 0。

**Lasso**：最小化 $(w-z)^2+\lambda|w|$。$|w|$ 在 0 处不可导，分三种情况：

- 若 $w>0$，derivative 是 $2(w-z)+\lambda=0$，$w=z-\tfrac\lambda2$。要它真的大于 0，需要 $z>\tfrac\lambda2$。
- 若 $w<0$，同理 $w=z+\tfrac\lambda2$，需要 $z<-\tfrac\lambda2$。
- 若 $|z|\le\tfrac\lambda2$，两种都不成立。这时在 0 的右边 derivative 是 $-2z+\lambda\ge0$，左边是 $-2z-\lambda\le0$：function 在 0 处向两边都上升，minimum 就在 $w=0$。

合起来

$$w=\mathrm{sign}(z)\,\max\Big(|z|-\frac\lambda2,\ 0\Big)$$

叫 soft-thresholding。取 $z=(3,\ 0.8)$、$\lambda=2$：ridge 给出 $(1,\ 0.267)$，lasso 给出 $(2,\ 0)$。Ridge 把两个 coordinate 都缩小到三分之一；lasso 把每个 coordinate 往 0 平移 1，第二个越过了 0，就停在 0。所有 $|z_j|\le\tfrac\lambda2$ 的 feature 被整个删掉，lasso 同时在做 feature selection。

一般的 $X$ 没有 closed form，几何图更能说明问题。Penalty 的写法与 constraint 的写法等价：对每个 $\lambda$，存在 $t$ 使 $\min\|y-Xw\|^2+\lambda\|w\|_1$ 与“在 $\|w\|_1\le t$ 中最小化 $\|y-Xw\|^2$”有同一个 solution。$\|y-Xw\|^2$ 是 $w$ 的 quadratic function，contour 是以 least squares solution $\hat w$ 为中心的 ellipse。下图取 $\hat w=(2,\ 0.6)$，loss $(w-\hat w)^\top Q(w-\hat w)$，$Q=\begin{pmatrix}1&0.5\\0.5&1\end{pmatrix}$，$t=1$。

::fig[cs3244-l1l2] 从 $\hat w$ 往外一圈圈扩大 contour，第一次碰到 constraint region 的那一点就是 solution。L2 的 region 是 circle，碰到的是一般位置；L1 的 region 是 diamond，碰到的是 corner。

两个 solution 都是实际算的。L2 的 solution 是 $(0.870,\ 0.494)$，loss 1.41；在这一点 gradient $2Q(w-\hat w)=(-2.37,\ -1.34)$，与 $w$ 方向相反、比例相同（$1.34/2.37=0.567=0.494/0.870$），这正是 contour 与 circle 相切的条件。L1 的 solution 是 corner $(1,0)$，loss 1.96。验证它确实最优：在 $(1,0)$ 处 gradient 是 $2Q\big((1,0)-\hat w\big)=2Q(-1,\,-0.6)=(-2.6,\ -2.2)$。从 corner 出发只能沿两条 edge 走，方向是 $(-1,1)$ 和 $(-1,-1)$，loss 的 directional derivative 分别是

$$(-2.6)(-1)+(-2.2)(1)=0.4>0,\qquad(-2.6)(-1)+(-2.2)(-1)=4.8>0$$

沿哪条 edge 走 loss 都上升，corner 就是 solution，$w_2$ 恰好是 0。只要 gradient 落在“两个 directional derivative 都为正”的那个 cone 里，solution 都停在这个 corner；这个 cone 有一定的宽度，所以 $\hat w$ 在一大片区域里变动时，solution 都是 sparse 的。Circle 没有 corner，切点随 $\hat w$ 连续移动，落在 axis 上只是巧合。

:::wrong L1 和 L2 都是把 weight 压小，只是压的力度不同
在 orthonormal 的情形下差别一目了然：ridge 是 $z/(1+\lambda)$，乘法，任何 $\lambda$ 下 $z=0.8$ 都不会变成 0；lasso 是 $z-\tfrac\lambda2$ 截断在 0，减法，$\lambda\ge1.6$ 时它就是 0。一个只缩放，一个会删 feature。要从几百个 feature 里挑出少数几个，ridge 做不到。
:::

### Validation：用来选 $\lambda$ 的 error 也会偏乐观

$\lambda$、degree、tree 的 depth 都要靠 data 来选，[CS2109S 第 6 站](../courses/CS2109S.html#logreg)讲了 $k$-fold cross-validation 的做法。

留出 $K$ 个点作为 validation set，在其余 $N-K$ 个点上 train 出 $g^-$，在这 $K$ 个点上算 $E_\text{val}$。这 $K$ 个点没有参与 training，所以 $E_\text{val}$ 是 $E_\text{out}(g^-)$ 的 unbiased estimate，standard deviation 按 $1/\sqrt K$ 缩小。

一旦用 $E_\text{val}$ 去挑 model，它就不再 unbiased。设两个 model 的 $E_\text{out}$ 都是 0.5，各自的 $E_\text{val}$ 是 $[0,1]$ 上 independent 的 uniform。挑 $E_\text{val}$ 小的那个，报告的 error 的 expectation 是

$$\mathbb E[\min(e_1,e_2)]=\int_0^1\mathbb P(\min>t)\,dt=\int_0^1(1-t)^2\,dt=\frac13$$

真实值是 0.5，报告值平均 0.333。这和第 2 站的 coin 是一回事：$M$ 个 candidate 就是 $M$ 个 hypothesis，validation set 是它们的 training set。用 Hoeffding 加 union bound（binary error），以至少 $1-\delta$ 的 probability，

$$E_\text{out}\le E_\text{val}+\sqrt{\frac{\ln(2M/\delta)}{2K}}$$

$K=100$、$\delta=0.05$ 时，$M=1,10,100$ 对应的 gap 是 0.136、0.173、0.204。$M$ 在 log 里，所以在十几个 $\lambda$ 里挑一个，代价不大；但在 validation set 上反复试几千种设定，validation error 就不可信了。最后报告的 test error 必须来自从未用来做任何选择的 data。

### Leave-one-out 不必重算 N 次

Leave-one-out cross-validation（LOOCV）每次留出一个点，用其余 $N-1$ 个点 fit，在留出的点上算 error，共 $N$ 次。对 least squares 不必真的 fit $N$ 次。

记 $A=X^\top X$，$h_n=x_n^\top A^{-1}x_n$（hat matrix 的 diagonal entry $H_{nn}$），$u=A^{-1}x_n$。去掉第 $n$ 个点后 matrix 是 $A-x_nx_n^\top$，它的 inverse 由 Sherman–Morrison formula 给出：

$$(A-x_nx_n^\top)^{-1}=A^{-1}+\frac{uu^\top}{1-h_n}$$

核对：把右边乘上 $A-x_nx_n^\top$，用 $u^\top A=x_n^\top$ 和 $u^\top x_n=h_n$，

$$\Big(A^{-1}+\frac{uu^\top}{1-h_n}\Big)(A-x_nx_n^\top)=I-ux_n^\top+\frac{ux_n^\top-h_n\,ux_n^\top}{1-h_n}=I-ux_n^\top+ux_n^\top=I$$

对 Sherman–Morrison formula 左乘 $x_n^\top$：

$$x_n^\top(A-x_nx_n^\top)^{-1}=u^\top+\frac{h_n\,u^\top}{1-h_n}=\frac{u^\top}{1-h_n}$$

留出第 $n$ 个点后的 solution 是 $w_{(n)}=(A-x_nx_n^\top)^{-1}(X^\top y-x_ny_n)$，它在 $x_n$ 上的 prediction 是

$$x_n^\top w_{(n)}=\frac{u^\top X^\top y-u^\top x_n\,y_n}{1-h_n}=\frac{\hat y_n-h_ny_n}{1-h_n}$$

（$u^\top X^\top y=x_n^\top A^{-1}X^\top y=\hat y_n$，$u^\top x_n=h_n$。）于是留出那个点的 residual 是

$$y_n-x_n^\top w_{(n)}=\frac{y_n-h_ny_n-\hat y_n+h_ny_n}{1-h_n}=\frac{y_n-\hat y_n}{1-h_n}$$

只要 fit 一次，拿到 residual 和 $H$ 的 diagonal，就有全部 $N$ 个 leave-one-out residual。Ridge 只是把 $A$ 换成 $X^\top X+\lambda I$，推导一字不改，所以扫一遍 $\lambda$ 选 LOOCV 最小的，每个 $\lambda$ 只需 fit 一次。

用那三个点比较 line 和 constant。Line 的 residual 是 $\big(-\tfrac16,\ \tfrac13,\ -\tfrac16\big)$。$A=\begin{pmatrix}3&6\\6&14\end{pmatrix}$，$A^{-1}=\tfrac16\begin{pmatrix}14&-6\\-6&3\end{pmatrix}$，代入 $x_n=(1,t_n)$：

$$h_1=\tfrac16(14-12+3)=\tfrac56,\qquad h_2=\tfrac16(14-24+12)=\tfrac13,\qquad h_3=\tfrac16(14-36+27)=\tfrac56$$

Leave-one-out residual：$\dfrac{-1/6}{1/6}=-1$，$\dfrac{1/3}{2/3}=\tfrac12$，$\dfrac{-1/6}{1/6}=-1$。直接核对第一个：去掉 $(1,1)$，剩下两点定出 line $y=2$，在 $t=1$ 处预测 2，residual $-1$。LOOCV error 是 $\tfrac13(1+\tfrac14+1)=0.75$。

Constant model 的 leave-one-out prediction 是另外两个 $y$ 的平均：$2$、$1.5$、$1.5$，residual $-1$、$0.5$、$0.5$，LOOCV error $\tfrac13(1+0.25+0.25)=0.5$。

| model | $E_\text{in}$ | $E_\text{cv}$ |
|---|---|---|
| line | $\tfrac1{18}=0.056$ | 0.75 |
| constant | $\tfrac29=0.222$ | 0.5 |

$E_\text{in}$ 选 line，$E_\text{cv}$ 选 constant。三个点太少，这和第 1 站两个点学 sine 的结论一致。

:::edge Leverage 接近 1 的点
$h_n$ 介于 0 和 1 之间，$\sum_nh_n=\mathrm{tr}(H)=d+1$。某个点的 $h_n$ 接近 1，说明它在 input space 里离群，fit 被它拉过去，自己的 residual 很小，可一旦留出它，prediction 就差得很远，formula 里除以 $1-h_n$ 正是在放大它。上例两端的点 $h=\tfrac56$，residual 被放大 6 倍。
:::

:::back
$\mathrm{tr}(H)=d+1$ 与[第 1 站](#gen)的 learning curve 用的是同一个事实。Validation 的 bound 是[第 2 站](#vc)的 Hoeffding 加 union bound。
:::

## [svm] SVM：dual、KKT 与 kernel

:::skip
能由 Lagrangian 推出 dual 并手解三个点的例子，能用 complementary slackness 求 $b$，能说出 kernel 为什么要经过 dual 才用得上，就可以去第 5 站。
:::

[CS2109S 第 7 站](../courses/CS2109S.html#svm)已经推出了 primal problem

$$\min_{w,b}\ \tfrac12\|w\|^2\qquad\text{subject to}\qquad y_n(w^\top x_n+b)\ge1,\quad n=1,\dots,N$$

并用 Lagrangian 的 stationarity 写出了 $w=\sum\alpha_ny_nx_n$。

### Margin 为什么值得要

第 2 站说 generalization 取决于 $\mathcal H$ 能产生多少 dichotomy。要求 margin 至少为 $\rho$，等于把 $\mathcal H$ 缩小了。看三个点，构成边长为 1 的 equilateral triangle。把一个顶点和另外两个分开的 line，最多离两边各 $\tfrac12\times\tfrac{\sqrt3}2=0.433$（顶点到对边的 distance 的一半）。所以要求 margin 大于 0.433 时，8 种 dichotomy 只剩全 $+1$ 和全 $-1$ 两种，这三个点不再能被 shatter。Margin 的要求越高，能实现的 dichotomy 越少，而且这件事与 input 的 dimension 无关。

另一个更直接的论证只用 leave-one-out。SVM 的 solution 只由 support vector（$\alpha_n>0$ 的点）决定。留出一个 $\alpha_n=0$ 的点：原来的 $(w,b)$ 和其余的 $\alpha$ 仍然满足剩下这个问题的全部 KKT 条件（$w=\sum\alpha_my_mx_m$ 里本来就没有它，$\sum\alpha_my_m=0$ 也不受影响），convex problem 的 KKT 条件是充分的，所以 solution 不变；而这个点满足 $y_n(w^\top x_n+b)\ge1$，被分对了。Leave-one-out 时只有 support vector 可能出错，因此

$$E_\text{cv}\le\frac{\#\text{support vectors}}N$$

Support vector 越少，这个 bound 越好，与 dimension 无关。下面 12 个点的例子有 3 个 support vector，bound 是 0.25；实际逐个留出算一遍，12 次全对。

### Dual 是怎么来的

给每个 constraint 一个 multiplier $\alpha_n\ge0$：

$$L(w,b,\alpha)=\tfrac12\|w\|^2-\sum_{n=1}^N\alpha_n\big[y_n(w^\top x_n+b)-1\big]$$

先看对 $\alpha$ 取 maximum 会怎样。如果某个 constraint 不满足，方括号是负的，让对应的 $\alpha_n\to\infty$，$L\to\infty$；如果全部满足，每个方括号 $\ge0$，取 $\alpha=0$ 最大，$L=\tfrac12\|w\|^2$。所以

$$\max_{\alpha\ge0}L(w,b,\alpha)=\begin{cases}\tfrac12\|w\|^2&\text{constraint 全部满足}\\\infty&\text{否则}\end{cases}$$

Primal 就是 $\min_{w,b}\max_{\alpha\ge0}L$。把次序反过来，$\max_{\alpha\ge0}\min_{w,b}L$，叫 dual。一般只有 dual $\le$ primal；objective 是 convex 的、constraint 是 linear 的并且能满足时，两者相等（CS229 讲义第 6.5 节给出的条件）。

里面的 $\min_{w,b}$ 是 unconstrained 的，令 derivative 为 0：

$$\nabla_wL=w-\sum_n\alpha_ny_nx_n=0\ \Rightarrow\ w=\sum_n\alpha_ny_nx_n,\qquad\frac{\partial L}{\partial b}=-\sum_n\alpha_ny_n=0$$

代回 $L$。中间那项是 $\sum_n\alpha_ny_nw^\top x_n=w^\top\sum_n\alpha_ny_nx_n=w^\top w$，含 $b$ 的项是 $b\sum_n\alpha_ny_n=0$：

$$L=\tfrac12\|w\|^2-\|w\|^2-0+\sum_n\alpha_n=\sum_n\alpha_n-\tfrac12\Big\|\sum_n\alpha_ny_nx_n\Big\|^2$$

把 square 展开，得到 dual problem：

$$\max_\alpha\ W(\alpha)=\sum_n\alpha_n-\frac12\sum_n\sum_m\alpha_n\alpha_my_ny_m\,x_n^\top x_m\qquad\text{subject to}\qquad\alpha_n\ge0,\ \ \sum_n\alpha_ny_n=0$$

这是 $N$ 个 variable 的 quadratic programming。解出 $\alpha$ 之后，$w=\sum\alpha_ny_nx_n$。

还剩 $b$。KKT 条件里的 complementary slackness 说

$$\alpha_n\big[y_n(w^\top x_n+b)-1\big]=0$$

所以 $\alpha_n>0$ 的点必须恰好在 margin 上，$y_n(w^\top x_n+b)=1$；不在 margin 上的点 $\alpha_n=0$，对 $w$ 没有贡献。任取一个 support vector $x_s$，由 $y_s(w^\top x_s+b)=1$ 和 $y_s^2=1$ 得 $b=y_s-w^\top x_s$。

### 手解一个

三个点：$x_1=(0,0)$，$y_1=-1$；$x_2=(2,0)$，$x_3=(0,2)$，$y_2=y_3=+1$。Inner product：$x_1$ 与谁都是 0，$x_2^\top x_2=x_3^\top x_3=4$，$x_2^\top x_3=0$。$W$ 的 double sum 里只剩 $\alpha_2^2\cdot4$ 和 $\alpha_3^2\cdot4$ 两项：

$$W=\alpha_1+\alpha_2+\alpha_3-\tfrac12\big(4\alpha_2^2+4\alpha_3^2\big)$$

Constraint $-\alpha_1+\alpha_2+\alpha_3=0$，即 $\alpha_1=\alpha_2+\alpha_3$。代入：

$$W=2\alpha_2+2\alpha_3-2\alpha_2^2-2\alpha_3^2$$

两个 variable 分开了，$\partial W/\partial\alpha_2=2-4\alpha_2=0$，所以 $\alpha_2=\alpha_3=\tfrac12$，$\alpha_1=1$，都 $\ge0$。

$$w=1\cdot(-1)\cdot(0,0)+\tfrac12\cdot(2,0)+\tfrac12\cdot(0,2)=(1,1),\qquad b=y_2-w^\top x_2=1-2=-1$$

Boundary 是 $x_1+x_2=1$。三个 $\alpha$ 都大于 0，三个点都应在 margin 上：$y_1(w^\top x_1+b)=-(-1)=1$，$y_3(w^\top x_3+b)=2-1=1$。Margin $1/\|w\|=1/\sqrt2=0.707$，也就是原点到 line $x_1+x_2=2$ 的 distance $\sqrt2$ 的一半。Dual 的最优值 $W=2-1=1$，primal 的 $\tfrac12\|w\|^2=1$，两者相等。

大一点的例子用 QP solver 解。12 个点：

$$+1:\ (1,4),(2,5),(1.5,6),(3,5.5),(2.5,3.5),(4,6)\qquad-1:\ (3,1),(4,2),(5,1.5),(4.5,3),(6,3),(5.5,4.5)$$

::fig[cs3244-svm] 12 个点的 dual 解出来只有 3 个 $\alpha$ 不为 0。

解出的 $\alpha$ 是 $\tfrac{37}{64}$（$(2.5,3.5)$）、$\tfrac{22}{64}$（$(3,1)$）、$\tfrac{15}{64}$（$(5.5,4.5)$）。核对 $\sum\alpha_ny_n=\tfrac{37-22-15}{64}=0$，以及

$$w=\tfrac{37}{64}(2.5,3.5)-\tfrac{22}{64}(3,1)-\tfrac{15}{64}(5.5,4.5)=\tfrac1{64}(92.5-66-82.5,\ 129.5-22-67.5)=\big(-\tfrac78,\ \tfrac58\big)$$

由 $(2.5,3.5)$ 得 $b=1-\big(-\tfrac78\cdot2.5+\tfrac58\cdot3.5\big)=1-0=1$。另外两个 support vector 上 $w^\top x+b$ 都等于 $-1$。

:::wrong 解 dual 总比解 primal 省事
Primal 有 $d+1$ 个 variable，dual 有 $N$ 个，而且要用到 $N\times N$ 的 matrix $[y_ny_mx_n^\top x_m]$。$N=10^5$ 时这个 matrix 有 $10^{10}$ 个 entry，用 double 存要 80 GB。Feature 不多、data 很多的 linear SVM，实际的 solver 都在 primal 上做。Dual 的好处不在于快，在于下一节。
:::

### Dual 让 kernel 成为可能

看 dual 里 data 出现在哪：只在 $x_n^\top x_m$ 里。Prediction 是 $\mathrm{sign}\big(\sum_n\alpha_ny_n\,x_n^\top x+b\big)$，$b=y_s-\sum_n\alpha_ny_nx_n^\top x_s$，也只用 inner product。所以先用 $z=\varphi(x)$ 把 data 送到 feature space，再做 SVM，只需要会算 $\varphi(x)^\top\varphi(x')$。这个 function 记作 $K(x,x')$，叫 kernel。

这时 primal 有 $\dim z$ 个 variable，可能是几十万，甚至 infinite；dual 始终是 $N$ 个 variable、一个 $N\times N$ 的 matrix，与 $\dim z$ 无关。Kernel 能用，是因为换成了 dual。

一个例子。12 个点，内圈 5 个标 $-1$，外圈 7 个标 $+1$：

$$-1:\ (\pm0.5,0.2),\ (\pm0.3,-0.5),\ (0,0.6)\qquad+1:\ (\pm1.8,0.4),\ (\pm1,1.6),\ (\pm1.2,-1.4),\ (0,-2)$$

用 linear programming 检查，不存在 line 把它们分开。取 $\varphi(x)=(x_1^2,\ \sqrt2x_1x_2,\ x_2^2)$，

$$\varphi(x)^\top\varphi(x')=x_1^2x_1'^2+2x_1x_2x_1'x_2'+x_2^2x_2'^2=(x_1x_1'+x_2x_2')^2=(x^\top x')^2$$

用一对点核对：$x=(0,0.6)$，$x'=(1.2,-1.4)$，$x^\top x'=-0.84$，$K=0.7056$；$\varphi(x)=(0,0,0.36)$，$\varphi(x')=(1.44,\ -2.376,\ 1.96)$，inner product $0.36\times1.96=0.7056$。

把 dual 里的 $x_n^\top x_m$ 全部换成 $(x_n^\top x_m)^2$ 再解，得到 $w=\sum\alpha_ny_n\varphi(x_n)=\big(\tfrac{25}{38},\ 0,\ \tfrac{25}{38}\big)$，$b=-\tfrac{47}{38}$。Decision boundary 是 $\tfrac{25}{38}(x_1^2+x_2^2)=\tfrac{47}{38}$，即 circle $x_1^2+x_2^2=1.88$。

这个结果可以手算验证。Data 关于 $x_2$ axis 对称，solution 唯一，所以 $w$ 的中间那个 component（$x_1x_2$ 的 coefficient）必须是 0；剩下的只和 $r^2=x_1^2+x_2^2$ 有关。内圈 $r^2$ 最大的是 $(0,0.6)$ 的 0.36，外圈 $r^2$ 最小的是 $(\pm1.8,0.4)$ 和 $(\pm1.2,-1.4)$ 的 3.4，maximum margin 的 threshold 在两者正中：$\tfrac{0.36+3.4}2=1.88$。

::fig[cs3244-kernel] 在 $\varphi$ 的 space 里 boundary 是一个 plane，投到 $(x_1^2,x_2^2)$ 上是一条 line，回到原来的平面是一个 circle。

省下的计算量在 dimension 高时才明显。$x$ 有 100 个 component，用 $K(x,x')=(1+x^\top x')^3$，对应的 $\varphi$ 包含所有 degree 不超过 3 的 monomial，共 $\binom{103}3=176851$ 个 feature；算 $K$ 只要一次 100 维的 inner product。Gaussian kernel $K(x,x')=e^{-\gamma\|x-x'\|^2}$ 对应的 $\varphi$ 是 infinite-dimensional 的，只能通过 $K$ 来用。

### 什么样的 function 能当 kernel

如果 $K(x,x')=\varphi(x)^\top\varphi(x')$，那么对任意 $N$ 个点，Gram matrix $G_{nm}=K(x_n,x_m)$ 是 symmetric positive semidefinite 的：对任意 $c$，

$$c^\top Gc=\sum_{n,m}c_nc_m\,\varphi(x_n)^\top\varphi(x_m)=\Big\|\sum_nc_n\varphi(x_n)\Big\|^2\ge0$$

Mercer 的 theorem 说反过来也成立：$K$ symmetric 且在任意有限个点上 Gram matrix 都 PSD，就存在对应的 $\varphi$。所以检验一个 kernel，只需要找一组点让 $G$ 出现 negative eigenvalue 就能否定它。

:::wrong 任何衡量两点相似程度的 function 都能当 kernel
取“两点距离不超过 1 时为 1，否则为 0”，看起来是合理的 similarity。在 line 上取三个点 0、1、2：

$$G=\begin{pmatrix}1&1&0\\1&1&1\\0&1&1\end{pmatrix},\qquad c=(1,-1,1):\quad c^\top Gc=3+2(-1+0-1)=-1<0$$

它的 eigenvalue 是 $1+\sqrt2$、1、$1-\sqrt2=-0.414$。没有 $\varphi$ 能让 $\|\sum c_n\varphi(x_n)\|^2=-1$，dual 的 objective 也不再是 concave 的，QP 可能没有 maximum。
:::

### 分不开时：soft margin 的 dual

Soft margin 的 primal 加入 slack $\xi_n\ge0$ 和 $C\sum\xi_n$。Lagrangian 对 $y_n(w^\top x_n+b)\ge1-\xi_n$ 用 $\alpha_n\ge0$，对 $\xi_n\ge0$ 用 $\beta_n\ge0$：

$$L=\tfrac12\|w\|^2+C\sum_n\xi_n-\sum_n\alpha_n\big[y_n(w^\top x_n+b)-1+\xi_n\big]-\sum_n\beta_n\xi_n$$

对 $w$、$b$ 的 derivative 与前面完全相同。对 $\xi_n$ 的 derivative 是 $C-\alpha_n-\beta_n=0$。代回去，含 $\xi_n$ 的项合起来是 $\xi_n(C-\alpha_n-\beta_n)=0$，全部消失，$W(\alpha)$ 与 hard margin 一字不差。唯一的变化是 $\beta_n=C-\alpha_n\ge0$ 给 $\alpha$ 加了一个上限：

$$0\le\alpha_n\le C$$

Complementary slackness 把 support vector 分成两类：$0<\alpha_n<C$ 的 $\beta_n>0$，所以 $\xi_n=0$，点恰好在 margin 上，求 $b$ 要用这类；$\alpha_n=C$ 的点 $\xi_n$ 可以大于 0，在 margin 以内或者被分错。Kernel 照样只是替换 inner product。$C$ 变大变小的效果见 CS2109S 那张表。

:::back
Margin 缩小 dichotomy 的论证用的是[第 2 站](#vc)的 growth function；$C$ 与[第 3 站](#reg)的 $1/\lambda$ 对应，用 cross-validation 选。
:::

:::from
Fat margin 让 dichotomy 变少、$\min\max$ 与 $\max\min$ 的推导顺序、代回 $w$ 得到的 QP、complementary slackness 与“$b$ 由任一 support vector 求出”、$E[E_\text{out}]\le E[\#\text{SV}]/(N-1)$、“只用到 $z_n^\top z_m$ 所以可以换 kernel”、Mercer 的条件、soft margin 的 $C-\alpha_n-\beta_n=0$ 与两类 support vector，来自 [Caltech CS156 第 14 讲](http://work.caltech.edu/slides/slides14.pdf)和[第 15 讲](http://work.caltech.edu/slides/slides15.pdf)（slides 全文）。$\max_\alpha L$ 等于 primal、strong duality 的条件、KKT 条件的完整列表来自 [CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)第 6.5 至 6.7 节。Triangle 的 0.433、leave-one-out bound 的 KKT 论证、三个点的手解、两个 12 个点的 dataset（scikit-learn 的 SVC 解，再手算核对）、“dual 不一定省事”、不是 kernel 的反例，是为这一页写和算的。

:::

### 长满的 tree：bias 小，variance 大

[CS2109S 第 4 站](../courses/CS2109S.html#dt)看到，tree 一直长到每个 leaf 都 pure，training error 为 0，test error 却变差。用第 1 站的语言重新量一遍。Regression 的例子：10 个 feature 在 $[0,1]$ 上 uniform，target

$$f(x)=10\sin(\pi x_1x_2)+20(x_3-0.5)^2+10x_4+5x_5$$

只用到前 5 个 feature，再加 standard deviation 1 的 noise，每个 training set $N=200$。重复 300 个 training set，在 30 个固定的 test point 上看一棵长满的 regression tree：bias 是 2.66，variance 是 11.15。Error 的大头是 variance。

如果有 $B$ 个 independent 的 training set，各长一棵 tree 再平均，variance 变成 $1/B$。可手里只有一个。

### 平均 B 个 correlated 的量

设 $X_1,\dots,X_B$ identically distributed，每个 variance 是 $\sigma^2$，两两之间 correlation 是 $\rho$，即 covariance 是 $\rho\sigma^2$。

$$\mathrm{Var}\Big(\frac1B\sum_bX_b\Big)=\frac1{B^2}\Big[\sum_b\mathrm{Var}(X_b)+\sum_{b\ne b'}\mathrm{Cov}(X_b,X_{b'})\Big]=\frac1{B^2}\Big[B\sigma^2+B(B-1)\rho\sigma^2\Big]$$

整理：

$$\mathrm{Var}(\bar X)=\rho\sigma^2+\frac{1-\rho}B\sigma^2$$

第二项随 $B$ 消失，第一项不会。$B\to\infty$ 时 variance 停在 $\rho\sigma^2$。Mean 则完全不变：$\mathbb E[\bar X]=\mathbb E[X_1]$，所以平均不改变 bias。

### Bagging

Bootstrap：从 $N$ 个点里有放回地抽 $N$ 个，得到一个新的 training set。重复 $B$ 次，各长一棵 tree，prediction 取平均（classification 取 majority vote）。这叫 bagging（bootstrap aggregating）。

一个 bootstrap sample 包含多少原来的点？某个点在一次抽取中没被抽到的 probability 是 $1-\tfrac1N$，$N$ 次都没被抽到是

$$\Big(1-\frac1N\Big)^N\to e^{-1}=0.368$$

$N=200$ 时是 0.366。所以每棵 tree 只见过约 63% 的 distinct 点，其余约 37% 叫 out-of-bag（OOB）。对每个点，用没见过它的那些 tree 的平均去预测它，得到的 OOB error 和 leave-one-out 很像，不必另留 validation set。

这些 tree 来自同一个 training set，互相 correlated。上面的例子实测（300 个 training set，每个 100 棵 tree）：$\sigma^2=11.15$，$\rho=0.115$。

| $B$ | 1 | 2 | 5 | 10 | 20 | 100 |
|---|---|---|---|---|---|---|
| variance 实测 | 11.17 | 6.39 | 3.26 | 2.31 | 1.78 | 1.38 |
| $\rho\sigma^2+(1-\rho)\sigma^2/B$ | 11.15 | 6.21 | 3.25 | 2.27 | 1.77 | 1.38 |

Bias 始终是 2.66。Bias 加 variance 从一棵 tree 的 13.83 降到 100 棵的 4.04。

::fig[cs3244-bagvar] Variance 随 $B$ 下降，但各自停在 $\rho\sigma^2$。空心点是 bagging 的实测，实心点是 random forest 的实测，curve 是 formula。

:::wrong Tree 种得足够多，variance 可以压到 0
从 20 棵到 100 棵，variance 只从 1.78 降到 1.38，下限是 $\rho\sigma^2=0.115\times11.15=1.28$。再加 tree 没用，只能降低 $\rho$。另一方面，tree 加多了也不会 overfit：$B$ 只影响第二项，bias 不变。所以 $B$ 不需要用 validation 选，取到 variance 不再明显下降即可。
:::

### Random forest：降低 ρ

Tree 之间 correlated，主要是因为同一批强的 feature 在每棵 tree 的上层被反复选中，每棵 tree 的大结构都差不多。Random forest 在 bagging 之外再加一步：每次 split 时只从随机抽出的 $m$ 个 feature 里挑最好的。不同的 tree 被迫走不同的路，$\rho$ 下降；代价是每棵 tree 变差，$\sigma^2$ 和 bias 上升。

同一个例子，$p=10$：

| | $\sigma^2$ | $\rho$ | $B=100$ 时 variance | bias | bias + variance |
|---|---|---|---|---|---|
| bagging（$m=10$） | 11.15 | 0.115 | 1.38 | 2.66 | 4.04 |
| random forest，$m=6$ | 12.27 | 0.078 | 1.06 | 2.81 | 3.88 |
| random forest，$m=3$ | 15.63 | 0.045 | 0.85 | 3.73 | 4.57 |

$m=6$ 时 $\rho$ 降低的收益大于 $\sigma^2$ 和 bias 上升的损失，比 bagging 好。$m=3$ 时 variance 更低，但 10 个 feature 里只有 5 个有用，每次只看 3 个，常常一个有用的都没抽到，bias 涨了一截，反而变差。$m$ 是要调的 hyperparameter，用 OOB error 选就行。常用的默认值是 regression 取 $\lfloor p/3\rfloor$，classification 取 $\lfloor\sqrt p\rfloor$。

### Boosting：对付 bias

反过来的情形：一个 decision stump（只 split 一次的 tree）variance 很小，bias 很大。把很多个 stump 平均，bias 不变，没有用。Boosting 让后来的 model 专门去修前面的 model 错的地方。

AdaBoost 的步骤（label 记作 $\pm1$）：

1. 每个点的 weight 初始为 $D_1(n)=\tfrac1N$。
2. 对 $t=1,\dots,T$：在 weight $D_t$ 下 train 一个 weak learner $h_t$，算 weighted error $\epsilon_t=\sum_nD_t(n)[h_t(x_n)\ne y_n]$；令 $\alpha_t=\tfrac12\ln\tfrac{1-\epsilon_t}{\epsilon_t}$；更新 $D_{t+1}(n)=D_t(n)\,e^{-\alpha_ty_nh_t(x_n)}/Z_t$，$Z_t$ 是让 weight 之和为 1 的 normalizer。
3. 最终的 classifier 是 $\mathrm{sign}\big(F(x)\big)$，$F=\sum_t\alpha_th_t$。

分对的点乘 $e^{-\alpha_t}$，分错的点乘 $e^{\alpha_t}$，下一轮分错的点更重。

**例子。** 10 个点 $x=1,\dots,10$，label 是 $+,+,+,-,-,-,-,+,+,+$。Stump 是 $x$ 上一个 threshold，左右各给一个 label。任何一个 stump 至少错 3 个。

- **第 1 轮。** Weight 全是 0.1。“$x\le3.5$ 为 $+$，否则为 $-$”错了 $x=8,9,10$，$\epsilon_1=0.3$。（“$x>7.5$ 为 $+$”也错 3 个，按搜索顺序取前者。）$\alpha_1=\tfrac12\ln\tfrac{0.7}{0.3}=0.424$。分对的乘 $e^{-\alpha_1}=\sqrt{3/7}$，分错的乘 $\sqrt{7/3}$，$Z_1=0.7\sqrt{3/7}+0.3\sqrt{7/3}=2\sqrt{0.21}=0.917$。新的 weight：分对的 7 个各 $\tfrac1{14}$，分错的 3 个各 $\tfrac16$。分错的合起来正好 $\tfrac12$：$h_1$ 在新的 weight 下等于瞎猜，下一轮必须选别的 stump。
- **第 2 轮。** “$x>7.5$ 为 $+$”错的是 $x=1,2,3$，weight 各 $\tfrac1{14}$，$\epsilon_2=\tfrac3{14}=0.214$，$\alpha_2=\tfrac12\ln\tfrac{11}3=0.650$。更新后 $x=1,2,3$ 合起来占 $\tfrac12$，各 $\tfrac16$；其余 7 个按原比例分另一半：$x=4..7$ 原来各 $\tfrac1{14}$、$x=8..10$ 原来各 $\tfrac16$，比例 $\tfrac1{14}:\tfrac16=3:7$，合计 $4\cdot\tfrac1{14}+3\cdot\tfrac16=\tfrac{11}{14}$，所以 $x=4..7$ 各 $\tfrac{1/14}{11/14}\cdot\tfrac12=\tfrac1{22}$，$x=8..10$ 各 $\tfrac{7}{66}$。
- **第 3 轮。** 现在 $x=4..7$ 最轻。“全部为 $+$”（threshold 在最左边）错的正是它们，$\epsilon_3=\tfrac4{22}=0.182$，$\alpha_3=\tfrac12\ln\tfrac92=0.752$。

三轮之后 $F$ 在三段上的值：

$$x\le3:\ 0.424-0.650+0.752=0.526,\qquad4\le x\le7:\ -0.424-0.650+0.752=-0.321,\qquad x\ge8:\ -0.424+0.650+0.752=0.978$$

Sign 全部正确，training error 为 0。没有一个 stump 能做到，三个 stump 的 weighted sum 做到了：boosting 降的是 bias。

### $\alpha_t$ 的 formula 从哪里来

把 weight 的更新连乘 $T$ 次：

$$D_{T+1}(n)=\frac1N\cdot\frac{e^{-y_n\sum_t\alpha_th_t(x_n)}}{\prod_tZ_t}=\frac{e^{-y_nF(x_n)}}{N\prod_tZ_t}$$

$D_{T+1}$ 的和是 1，所以

$$\frac1N\sum_ne^{-y_nF(x_n)}=\prod_{t=1}^TZ_t$$

左边是 exponential loss 的平均。点 $n$ 被分错时 $y_nF(x_n)\le0$，$e^{-y_nF(x_n)}\ge1$；分对时它仍然 $>0$。所以 $[\text{分错}]\le e^{-y_nF(x_n)}$，training error $\le\prod_tZ_t$。

于是每一轮选 $\alpha_t$ 让 $Z_t$ 尽量小。分对的点 weight 合计 $1-\epsilon_t$，分错的合计 $\epsilon_t$：

$$Z_t(\alpha)=(1-\epsilon_t)e^{-\alpha}+\epsilon_te^{\alpha},\qquad Z_t'(\alpha)=-(1-\epsilon_t)e^{-\alpha}+\epsilon_te^{\alpha}=0\ \Rightarrow\ e^{2\alpha}=\frac{1-\epsilon_t}{\epsilon_t}$$

这就是 $\alpha_t=\tfrac12\ln\tfrac{1-\epsilon_t}{\epsilon_t}$。代回：

$$Z_t=(1-\epsilon_t)\sqrt{\frac{\epsilon_t}{1-\epsilon_t}}+\epsilon_t\sqrt{\frac{1-\epsilon_t}{\epsilon_t}}=2\sqrt{\epsilon_t(1-\epsilon_t)}$$

只要 $\epsilon_t<\tfrac12$，$Z_t<1$，training error 的 bound 随 $T$ 按 exponential 下降。核对例子：$Z_1Z_2Z_3=0.917\times0.821\times0.771=0.580$；直接算 exponential loss，$\tfrac1{10}\big(3e^{-0.526}+4e^{-0.321}+3e^{-0.978}\big)=0.580$，一致。

:::edge Training error 到 0 之后还在进步
上例第 3 轮 training error 已经是 0，接着跑下去，最难分的那段的 normalized margin $\min_ny_nF(x_n)/\sum_t\alpha_t$ 从第 3 轮的 $0.321/1.826=0.176$ 升到第 6 轮的 $1.038/3.982=0.261$。Exponential loss 会把已经分对、但离 0 不远的点继续往外推。实际中 AdaBoost 的 test error 常在 training error 到 0 之后继续下降，常见的解释就是 margin 变大，与[第 4 站](#svm)同理。
:::

:::back
Bias、variance 的定义来自[第 1 站](#gen)；OOB error 是[第 3 站](#reg)的 leave-one-out 的近亲。
:::

:::from
$\rho\sigma^2+\tfrac{1-\rho}B\sigma^2$、random forest 的步骤与 $m$ 的默认值、OOB error 的 formula、“random forest 降 variance、boosting 降 bias”来自 [Oslo STK2100 转述 ESL 第 15 章的课件](https://www.uio.no/studier/emner/matnat/math/STK2100/v25/undervisningsmateriell/presentasjoner/stk2100-ch15.pdf)；ESL 原书的 PDF 没有抓到。“只有 estimator 不完全 correlated 时平均才有用”来自 [Berkeley Stat 154 的讲义](https://stat154.berkeley.edu/fall-2025/lectures/unit4/unit4_bagging.html)。AdaBoost 的步骤、$\alpha_t$ 由最小化 $Z_t$ 得出、$Z_t=2\sqrt{\epsilon_t(1-\epsilon_t)}$、training error $\le\prod Z_t$、margin 的解释来自 [CMU 10-301/601 第 30 讲](https://www.cs.cmu.edu/~hchai2/courses/10601/lectures/Lecture30.pdf)；“indicator 不超过 exponential、连乘得到 $\prod Z_t$”的证明步骤对照了 [Columbia COMS 4771 的讲义](https://www.cs.columbia.edu/~djhsu/coms4771-f20/mlnotes/adaboost.pdf)。variance of average 与 63% 的推导、Friedman target 上的全部模拟（scikit-learn 的 DecisionTreeRegressor）、10 个点上的 AdaBoost 手算，是为这一页写和算的。

## [nn] Neural network：matrix 形式的 backpropagation 与 initialization

:::skip
能写出 matrix 形式的 backward recursion，推出 softmax 加 cross-entropy 的 gradient 是 $p-y$，并说明 ReLU network 为什么用 $\mathrm{Var}(w)=2/n$，就可以去第 7 站。
:::

[CS2109S 第 8 站](../courses/CS2109S.html#nn)在一个 2-2-1 的 network 上逐个 weight 做了 backpropagation，也算过它为什么比 numerical differentiation 省。

### 写成 matrix

Layer $l$ 有 $n_l$ 个 unit。Forward pass：

$$z^{[l]}=W^{[l]}a^{[l-1]}+b^{[l]},\qquad a^{[l]}=\sigma\big(z^{[l]}\big),\qquad a^{[0]}=x$$

$W^{[l]}$ 是 $n_l\times n_{l-1}$ 的 matrix，$\sigma$ 逐个 component 作用。最后一层的 $z^{[L]}$ 交给 loss。定义 $\delta^{[l]}=\partial J/\partial z^{[l]}$，一个 $n_l$ 维的 vector。三个 formula 都从一个 component 的写法出发。

**对 weight。** $z_i=\sum_jW_{ij}a_j+b_i$，所以 $\partial z_i/\partial W_{ij}=a_j$，而 $W_{ij}$ 只影响 $z_i$：

$$\frac{\partial J}{\partial W_{ij}}=\delta_i\,a_j\qquad\Longrightarrow\qquad\frac{\partial J}{\partial W^{[l]}}=\delta^{[l]}\,a^{[l-1]\top},\qquad\frac{\partial J}{\partial b^{[l]}}=\delta^{[l]}$$

一个 $n_l$ 维的 column 乘一个 $n_{l-1}$ 维的 row，正好是 $W^{[l]}$ 的形状。

**往前一层。** $a_j$ 影响所有的 $z_i$，每条路径的 derivative 是 $W_{ij}$：

$$\frac{\partial J}{\partial a_j}=\sum_i\delta_iW_{ij}=\big(W^\top\delta\big)_j$$

**穿过 activation。** $a_j=\sigma(z_j)$ 只依赖 $z_j$，乘上 $\sigma'(z_j)$：

$$\delta^{[l-1]}=\sigma'\big(z^{[l-1]}\big)\odot W^{[l]\top}\delta^{[l]}$$

$\odot$ 是逐个 component 相乘。从 $\delta^{[L]}$ 出发反复用这一行，就得到每一层的 $\delta$，再用第一个 formula 得到每个 $W^{[l]}$ 的 gradient。Forward pass 要把每层的 $z^{[l]}$ 和 $a^{[l]}$ 存下来，backward pass 要用。

### Softmax 与 cross-entropy：gradient 是 p − y

$K$ 个 class 时，output layer 的 $z\in\mathbb R^K$ 经过 softmax

$$p_k=\frac{e^{z_k}}{\sum_je^{z_j}}$$

label 写成 one-hot vector $y$，loss 是 cross-entropy $J=-\sum_ky_k\ln p_k$（即 categorical distribution 的 negative log-likelihood）。先求 $\ln p_k=z_k-\ln\sum_je^{z_j}$ 对 $z_i$ 的 derivative：

$$\frac{\partial\ln p_k}{\partial z_i}=[k=i]-\frac{e^{z_i}}{\sum_je^{z_j}}=[k=i]-p_i$$

于是

$$\delta^{[L]}_i=\frac{\partial J}{\partial z_i}=-\sum_ky_k\big([k=i]-p_i\big)=-y_i+p_i\sum_ky_k=p_i-y_i$$

最后一步用了 $\sum_ky_k=1$。Output layer 的 $\delta$ 就是“predicted probability 减去 label”，和 logistic regression 的 $h-y$ 同形（$K=2$ 时 softmax 就是 sigmoid）。

### 走一遍

$x=(1,2)^\top$，hidden layer 用 ReLU，两个 class，label 是第 1 类，$y=(1,0)^\top$，bias 都取 0：

$$W^{[1]}=\begin{pmatrix}0.5&-0.4\\0.1&0.4\end{pmatrix},\qquad W^{[2]}=\begin{pmatrix}1&-1\\0.5&0.5\end{pmatrix}$$

**Forward。**

$$z^{[1]}=\begin{pmatrix}0.5-0.8\\0.1+0.8\end{pmatrix}=\begin{pmatrix}-0.3\\0.9\end{pmatrix},\qquad a^{[1]}=\begin{pmatrix}0\\0.9\end{pmatrix},\qquad z^{[2]}=\begin{pmatrix}0-0.9\\0+0.45\end{pmatrix}=\begin{pmatrix}-0.9\\0.45\end{pmatrix}$$

$p_1=\dfrac{e^{-0.9}}{e^{-0.9}+e^{0.45}}=\dfrac1{1+e^{1.35}}=0.2059$，$p_2=0.7941$，$J=-\ln0.2059=1.581$。

**Backward。**

$$\delta^{[2]}=p-y=\begin{pmatrix}-0.7941\\0.7941\end{pmatrix},\qquad\frac{\partial J}{\partial W^{[2]}}=\delta^{[2]}a^{[1]\top}=\begin{pmatrix}0&-0.7147\\0&0.7147\end{pmatrix}$$

$$W^{[2]\top}\delta^{[2]}=\begin{pmatrix}1\cdot(-0.7941)+0.5\cdot0.7941\\-1\cdot(-0.7941)+0.5\cdot0.7941\end{pmatrix}=\begin{pmatrix}-0.3971\\1.1912\end{pmatrix}$$

ReLU 的 derivative 在 $z>0$ 处是 1，$z<0$ 处是 0。$z^{[1]}_1=-0.3<0$：

$$\delta^{[1]}=\begin{pmatrix}0\\1.1912\end{pmatrix},\qquad\frac{\partial J}{\partial W^{[1]}}=\delta^{[1]}x^\top=\begin{pmatrix}0&0\\1.1912&2.3824\end{pmatrix}$$

用 central difference 核对 $\partial J/\partial W^{[1]}_{22}$：把它加减 $10^{-6}$，两次 $J$ 之差除以 $2\times10^{-6}$，得 2.38239。

第一个 hidden unit 在这个 input 上没有 activate，它的 incoming weight（$W^{[1]}$ 的 row 1）和 outgoing weight（$W^{[2]}$ 的 column 1）的 gradient 全是 0。一个 unit 若对所有 input 都 $z<0$，它的 weight 永远不再更新，叫 dead ReLU。

### Initialization：每一层的 scale 要保持不变

20 层、每层 256 个 unit 的 ReLU network，input 是 standard normal，weight 取 standard deviation 0.01 的 normal。实际跑一次，activation 的 RMS（root mean square）是：

| layer | 1 | 2 | 5 | 10 | 20 |
|---|---|---|---|---|---|
| RMS | 0.114 | 0.0126 | $1.8\times10^{-5}$ | $3.4\times10^{-10}$ | $9.6\times10^{-20}$ |

每层缩小大约 9 倍，到第 20 层只剩 $10^{-19}$。Gradient $\partial J/\partial W^{[l]}=\delta^{[l]}a^{[l-1]\top}$ 里乘着这么小的 $a$，backward 方向的 $\delta$ 也按同样的比例缩小，算出来的 weight gradient 在 $10^{-20}$ 量级，network 根本学不动。

算一下每层缩小多少倍。设 $W_{ij}$ independent、mean 0、variance $v$，与 $a$ independent。$z_i=\sum_{j=1}^nW_{ij}a_j$ 的 mean 是 0，各项 independent，所以

$$\mathrm{Var}(z_i)=\sum_j\mathbb E[W_{ij}^2]\,\mathbb E[a_j^2]=n\,v\,\mathbb E[a^2]$$

ReLU 把 $z$ 的负半边变成 0。$z$ 关于 0 对称，所以 $\mathbb E[a^2]=\mathbb E[z^2;\,z>0]=\tfrac12\mathrm{Var}(z)$。合起来：

$$\mathbb E\big[(a^{[l]})^2\big]=\frac{n\,v}2\,\mathbb E\big[(a^{[l-1]})^2\big]$$

每层乘上 $\tfrac{nv}2$。

| $\mathrm{Var}(w)$ | $\tfrac{nv}2$ | RMS 每层乘 | 20 层之后（实测） |
|---|---|---|---|
| $0.01^2$ | $0.0128$ | 0.113 | $9.6\times10^{-20}$ |
| $1/n$ | $\tfrac12$ | 0.707 | $7.7\times10^{-4}$ |
| $2/n$ | 1 | 1 | 1.15 |

前两行的实测与 formula 吻合：0.114 到 0.0126 是 0.11 倍，$0.707^{20}\approx10^{-3}$。让 factor 等于 1，得 $v=\tfrac2n$，这叫 He initialization。

::fig[cs3244-init] 三种 initialization 下 activation 的大小随 layer 的变化（log scale）。

Backward 方向同理：$\delta^{[l-1]}=\sigma'\odot W^{[l]\top}\delta^{[l]}$，$W^\top$ 的每一行有 $n_l$ 个 entry，ReLU 的 $\sigma'$ 有一半是 0，所以 $\mathrm{Var}(\delta^{[l-1]})=\tfrac{n_lv}2\mathrm{Var}(\delta^{[l]})$。每层宽度相同时，同一个 $v=\tfrac2n$ 让两个方向都保持 scale。

:::wrong 用很小的 random 数 initialize 最稳妥
Random 是为了打破 symmetry（CS2109S 讲过全部相同为什么不行），但 scale 不能随便取。上表第一行就是“0.01 乘 standard normal”这种常见写法，20 层之后 signal 只剩 $10^{-19}$。反过来，$v$ 取得比 $2/n$ 大，每层乘一个大于 1 的数，20 层之后会 overflow。Variance 要按每层的 fan-in $n$ 来定。
:::

:::edge 不是 ReLU 时
tanh 在 0 附近近似 linear（$\tanh'(0)=1$），不砍掉一半，factor 是 $nv$，取 $v=1/n$。前后两层宽度不同时，forward 要 $v=1/n_\text{in}$，backward 要 $v=1/n_\text{out}$，Glorot 的折中取 $v=\tfrac{2}{n_\text{in}+n_\text{out}}$。
:::

:::back
Output 层的 $p-y$ 与 [CS2109S 第 6 站](../courses/CS2109S.html#logreg)的 logistic regression 同形；softmax 加 cross-entropy 是[第 3 站](#reg)“loss 等于 negative log-likelihood”用在 categorical distribution 上。
:::

:::from
Matrix 形式的 forward pass、backward function（$B[\text{MM},z](v)=W^\top v$、对 $W$ 是 $vz^\top$、activation 是 $\sigma'(z)\odot v$、softmax cross-entropy 是 $p-e_y$）、MLP 的 backward recursion 来自 [CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)第 7.2 至 7.4 节，这里改成逐个 component 推出。$\mathrm{Var}(s)=n\,\mathrm{Var}(w)\,\mathrm{Var}(x)$、$1/n$、He 的 $2/n$、Glorot 的 $2/(n_\text{in}+n_\text{out})$ 来自 [CS231n notes 的 Weight Initialization 一节](https://github.com/Alireza-Akhavan/cs231n.github.io/blob/master/neural-networks-2.md)（读的是 GitHub 上的镜像）；那里没有推导 ReLU 砍掉一半的那一步，这一步和 tanh 的对照是我补的。2-2-2 network 的数、central difference 的核对、20 层 network 的实测是为这一页算的。

## [em] Clustering：k-means、Gaussian mixture 与 EM

:::skip
能证明 k-means 的两步都不让 $J$ 变大，能手算一轮 EM，能用 Jensen's inequality 说明 EM 每一轮 log-likelihood 都不下降，就可以去第 8 站。
:::

### k-means 在最小化什么

没有 label，只有 $x_1,\dots,x_N$，想分成 $k$ 组。k-means 交替做两步：把每个点分给最近的 center；把每个 center 移到它那组点的 mean。它为什么会停，停在哪里？写出它在最小化的量，叫 distortion：

$$J(c,\mu)=\sum_{n=1}^N\big\|x_n-\mu_{c_n}\big\|^2$$

$c_n$ 是第 $n$ 个点所属的组，$\mu_j$ 是第 $j$ 组的 center。

- **Assignment。** 固定 $\mu$，$J$ 是 $N$ 项之和，每一项只依赖自己的 $c_n$，各自取最近的 center 就让每一项最小。$J$ 不会变大。
- **Update。** 固定 $c$，第 $j$ 组的那部分是 $\sum_{n:c_n=j}\|x_n-\mu_j\|^2$，对 $\mu_j$ 求 gradient $-2\sum_{n:c_n=j}(x_n-\mu_j)=0$，得 $\mu_j$ 等于组内的 mean。$J$ 也不会变大。

这是对 $J$ 做 coordinate descent。分组的方法只有有限多种（不超过 $k^N$），$J$ 严格下降时不会回到出现过的分法，所以有限步内一定停下。

例子：$x=\{1,2,3,5,8,9\}$，$k=2$，初始 center $\mu=(1,2)$。

| 轮 | assignment | assignment 后的 $J$ | 新的 $\mu$ | update 后的 $J$ |
|---|---|---|---|---|
| 0 | $\{1\},\ \{2,3,5,8,9\}$ | $0+(0+1+9+36+49)=95$ | $(1,\ 5.4)$ | 37.2 |
| 1 | $\{1,2,3\},\ \{5,8,9\}$ | 24.88 | $(2,\ 7.33)$ | 10.67 |
| 2 | 不变 | 10.67 | 不变 | 10.67 |

第 1 轮里，$x=3$ 到 1 的距离是 2，到 5.4 是 2.4，所以归第 1 组；$x=5$ 到 5.4 只有 0.4，归第 2 组。第 2 轮里 $x=5$ 到 2 是 3、到 7.33 是 2.33，留在第 2 组，不再变化。

换一个初始值 $\mu=(2,8)$：$x=5$ 到两者都是 3，按规则归第 1 组，得到 $\{1,2,3,5\}$、$\{8,9\}$，center $(2.75,\ 8.5)$，$J=8.75+0.5=9.25$，也不再变化。9.25 比 10.67 好，前一个初始值停在了 local minimum。$k=3$ 时更明显：初始值 $(1,2,9)$、$(1,8,9)$、$(1,2,3)$ 分别停在 $J=3.0$、$2.5$、$9.17$。实际做法是从多个随机初始值出发，留下 $J$ 最小的。

::fig[cs3244-kmeans] 二维的三团 data，从很差的初始 center 出发。$J$ 每一步都下降。

### 硬分配不够：Gaussian mixture

上例里 $x=5$ 到两个 center 一样远，k-means 只能硬分给一组；右边那组 $\{8,9\}$ 很紧、左边那组散得开，k-means 的距离却对两组一视同仁。Gaussian mixture 把这两点写进 model：每个点先以 probability $\pi_j$ 选一个 component $z_n=j$，再从 $\mathcal N(\mu_j,\sigma_j^2)$ 抽出 $x_n$。于是

$$p(x)=\sum_{j=1}^k\pi_j\,\mathcal N(x;\mu_j,\sigma_j^2),\qquad\ell(\theta)=\sum_{n=1}^N\ln\sum_{j=1}^k\pi_j\,\mathcal N(x_n;\mu_j,\sigma_j^2)$$

如果知道每个点的 $z_n$，MLE 很简单（[ST2132 第 2 站](../courses/ST2132.html#est)）：$\pi_j$ 是第 $j$ 组的比例，$\mu_j$、$\sigma_j^2$ 是组内的 mean 与 variance。不知道 $z_n$，$\ell$ 里 log 套着 sum，对 $\mu_j$ 求 derivative 令其为 0 得不到 closed form。

EM 的做法：用当前的 parameter 算每个点属于各组的 posterior probability，然后把它当作“部分属于”去做 MLE。

- **E-step。** $r_{nj}=\dfrac{\pi_j\,\mathcal N(x_n;\mu_j,\sigma_j^2)}{\sum_i\pi_i\,\mathcal N(x_n;\mu_i,\sigma_i^2)}$，叫 responsibility。
- **M-step。** $N_j=\sum_nr_{nj}$，$\pi_j=\dfrac{N_j}N$，$\mu_j=\dfrac{\sum_nr_{nj}x_n}{N_j}$，$\sigma_j^2=\dfrac{\sum_nr_{nj}(x_n-\mu_j)^2}{N_j}$。

M-step 就是知道 $z_n$ 时的那三个 formula，只是把“属于第 $j$ 组记 1、否则记 0”换成 $r_{nj}$。

**手算第一轮。** 同样的 6 个点，初始 $\pi=(\tfrac12,\tfrac12)$，$\mu=(2,8)$，$\sigma^2=(1,1)$。两个 component 的 $\pi$ 和 $\sigma$ 相同，所以 responsibility 只取决于 $e^{-(x-\mu_j)^2/2}$ 之比：

- $x=5$：到两个 mean 都是 3，$r=(\tfrac12,\tfrac12)$。
- $x=3$：两个 exponent 是 $-\tfrac12$ 和 $-\tfrac{25}2$，之比 $e^{12}\approx1.6\times10^5$，$r_{n1}=1-6\times10^{-6}$。$x=1,2$ 更接近 1，$x=8,9$ 的 $r_{n1}$ 同理接近 0。

取到四位小数，第 1 个 component 的 responsibility 是 $(1,1,1,0.5,0,0)$。M-step：

$$N_1=3.5,\quad N_2=2.5,\qquad\pi=\Big(\tfrac{3.5}6,\ \tfrac{2.5}6\Big)=(0.583,\ 0.417)$$

$$\mu_1=\frac{1+2+3+0.5\times5}{3.5}=\frac{8.5}{3.5}=2.429,\qquad\mu_2=\frac{0.5\times5+8+9}{2.5}=\frac{19.5}{2.5}=7.8$$

$$\sigma_1^2=\frac{1.429^2+0.429^2+0.571^2+0.5\times2.571^2}{3.5}=\frac{2.041+0.184+0.327+3.306}{3.5}=1.673$$

$$\sigma_2^2=\frac{0.5\times2.8^2+0.2^2+1.2^2}{2.5}=\frac{3.92+0.04+1.44}{2.5}=2.16$$

Log-likelihood 从 $-14.979$ 升到 $-13.744$。继续 iterate：$-13.708$、$-13.617$，约 10 轮后停在 $-12.510$，此时 $\mu=(2.753,\ 8.500)$，$\sigma^2=(2.203,\ 0.250)$，$\pi=(0.667,\ 0.333)$。左边的 component 宽、右边的窄，$x=5$ 最终几乎全归左边。

::fig[cs3244-em] Mixture density 在第 0 轮、第 1 轮和 converge 时的样子。

### 为什么 likelihood 每一轮都不下降

固定一个点 $x_n$，任取一个 distribution $q_n(j)$（$q_n(j)\ge0$，$\sum_jq_n(j)=1$）。把 sum 里每一项乘上又除以 $q_n(j)$：

$$\ln\sum_j\pi_j\mathcal N_j(x_n)=\ln\sum_jq_n(j)\,\frac{\pi_j\mathcal N_j(x_n)}{q_n(j)}\ \ge\ \sum_jq_n(j)\ln\frac{\pi_j\mathcal N_j(x_n)}{q_n(j)}$$

不等号是 Jensen's inequality：$\ln$ 是 concave 的，“平均的 log”不超过“log 的平均”（这里的平均按 $q_n$ 加权）。对 $n$ 求和，右边记作 $\mathcal F(q,\theta)$，叫 ELBO（evidence lower bound）：对任何 $q$ 都有 $\ell(\theta)\ge\mathcal F(q,\theta)$。

什么时候取等号？Jensen 在被平均的量是 constant 时取等号，即 $\tfrac{\pi_j\mathcal N_j(x_n)}{q_n(j)}$ 与 $j$ 无关，也就是 $q_n(j)\propto\pi_j\mathcal N_j(x_n)$。Normalize 之后，这正是 E-step 的 responsibility $r_{nj}$。

现在把一轮 EM 拆成两步看：

$$\ell(\theta_{t+1})\ \ge\ \mathcal F(r^{(t)},\theta_{t+1})\ \ge\ \mathcal F(r^{(t)},\theta_t)\ =\ \ell(\theta_t)$$

最右的等号是 E-step：$q$ 取 posterior，bound 贴紧。中间的不等号是 M-step：$\mathcal F(r^{(t)},\theta)=\sum_{n,j}r_{nj}\ln\big(\pi_j\mathcal N_j(x_n)\big)-\sum_{n,j}r_{nj}\ln r_{nj}$，后一项与 $\theta$ 无关，前一项就是 weighted log-likelihood，M-step 的 formula 正是它的 maximizer。最左的不等号是 ELBO 对任何 $q$ 成立。

拿第一轮的数核对：$\ell(\theta_0)=-14.979$；固定 $r^{(0)}$、换成 $\theta_1$，$\mathcal F=-13.759$；而 $\ell(\theta_1)=-13.744$，比 $\mathcal F$ 还高一点，因为 $r^{(0)}$ 已经不是 $\theta_1$ 下的 posterior，bound 不再贴紧。

k-means 是它的极限情形。让所有 component 的 variance 都固定为同一个 $\sigma^2$ 且 $\pi_j$ 相同，$r_{nj}\propto e^{-\|x_n-\mu_j\|^2/(2\sigma^2)}$；$\sigma\to0$ 时，离得最近的那个 $j$ 的 exponent 远大于其余的，$r_{nj}$ 变成 0 或 1，E-step 成了 assignment，M-step 成了求 mean。

:::wrong EM converge 到的就是 maximum likelihood estimate
EM 只保证 $\ell$ 不降，和 k-means 一样会停在 local maximum 或 saddle point，结果取决于初始值。更糟的是 Gaussian mixture 的 likelihood 没有 maximum：让一个 component 的 mean 恰好落在某个 data point 上（比如 $\mu_2=9$），$\sigma_2\to0$，这一项的 density $\tfrac1{\sqrt{2\pi}\sigma_2}$ 趋于 infinity（$\sigma_2=0.01$ 时已是 39.9），而其余的点仍由另一个 component 给出正的 density，$\ell\to\infty$。实际做法是给 $\sigma^2$ 设下限或加 prior，并从多个初始值出发比较。
:::

:::back
M-step 是 [ST2132](../courses/ST2132.html#est) 的 MLE 加上 weight；把 loss 看成 negative log-likelihood 与[第 3 站](#reg)相同。
:::

:::from
Distortion function、“k-means 是对 $J$ 的 coordinate descent，所以一定 converge，但只到 local optimum”、Gaussian mixture 的 E-step 与 M-step、Jensen's inequality、ELBO、取等号的条件、$\ell(\theta_{t+1})\ge\mathcal F\ge\ell(\theta_t)$ 的链条来自 [CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)第 10、11 章。“complete data 时 formula 是 closed form，EM 把 indicator 换成 soft count”、likelihood 在 covariance 塌缩时 unbounded 来自 [MIT 6.867 第 15 讲的讲义](https://www.ocw.mit.edu/courses/6-867-machine-learning-fall-2006/a5a5b7b5a8c2eb7d7d23eac5c7f3a9af_lec15.pdf)；那份讲义只陈述 likelihood 单调上升，没有给出证明。6 个点上的 k-means 与 EM、ELBO 的数值核对、$\sigma\to0$ 的极限，是为这一页写和算的。

## [pca] PCA：maximum variance 与 minimum reconstruction error

:::skip
能推出 principal component 是 covariance matrix 的 eigenvector，并用 Pythagorean theorem 说明它同时让 reconstruction error 最小，就读完这门课了。
:::

### 想留下哪个方向

784 个 pixel 的图像，大部分方向上 data 几乎不变化。想换成少数几个新的 coordinate、尽量保留 data 的差别。先只留一个方向：一个 unit vector $u$，每个点只记它在 $u$ 上的 coordinate $u^\top x_n$。

先把 data 减去 mean，使 $\sum_nx_n=0$。Projection 后的 coordinate mean 为 0，variance 是

$$\frac1N\sum_n(u^\top x_n)^2=\frac1N\sum_nu^\top x_nx_n^\top u=u^\top Su,\qquad S=\frac1N\sum_nx_nx_n^\top$$

$S$ 是 covariance matrix（按 MLE 的写法除以 $N$）。在 $u^\top u=1$ 下最大化 $u^\top Su$，用 Lagrange multiplier：$\nabla_u\big[u^\top Su-\lambda(u^\top u-1)\big]=2Su-2\lambda u=0$，所以

$$Su=\lambda u$$

$u$ 必须是 $S$ 的 eigenvector。此时 variance $u^\top Su=\lambda u^\top u=\lambda$，所以取 eigenvalue 最大的那个。第二个方向要求与第一个 perpendicular，同样的论证给出第二大的 eigenvalue 的 eigenvector；$S$ 是 symmetric 的，eigenvector 本来就两两 perpendicular。这些方向叫 principal component。实际计算时不必形成 $S$，对 centered 的 data matrix 做 SVD，right singular vector 就是它们，$\lambda_i=\sigma_i^2/N$，见 [DSA2102 第 5 站](../courses/DSA2102.html#eig)。

例子：6 个点 $(1,2)$、$(2,1)$、$(3,4)$、$(4,3)$、$(5,6)$、$(6,5)$。Mean 是 $(3.5,3.5)$，centered 之后是 $(\mp2.5,\mp1.5)$、$(\mp1.5,\mp2.5)$、$(\mp0.5,\pm0.5)$。$\sum x_1^2=2(6.25+2.25+0.25)=17.5$，$\sum x_2^2$ 同样是 17.5，$\sum x_1x_2=2(3.75+3.75-0.25)=14.5$。

$$S=\frac16\begin{pmatrix}17.5&14.5\\14.5&17.5\end{pmatrix}=\frac1{12}\begin{pmatrix}35&29\\29&35\end{pmatrix}$$

形如 $\begin{pmatrix}a&b\\b&a\end{pmatrix}$ 的 matrix，eigenvector 是 $(1,1)$ 和 $(1,-1)$，eigenvalue 是 $a+b$ 和 $a-b$：

$$\lambda_1=\frac{64}{12}=\frac{16}3=5.333,\quad u_1=\tfrac1{\sqrt2}(1,1);\qquad\lambda_2=\frac6{12}=0.5,\quad u_2=\tfrac1{\sqrt2}(1,-1)$$

在 $u_1$ 上的 coordinate：$(-2.5-1.5)/\sqrt2=-2\sqrt2$，依次是 $-2\sqrt2,-2\sqrt2,0,0,2\sqrt2,2\sqrt2$，mean square $\tfrac{4\times8}{6}=\tfrac{16}3$，正是 $\lambda_1$。

### 同一个方向让 reconstruction error 最小

另一种要求：用一个方向去 approximate 每个点，$x_n\approx(u^\top x_n)\,u$，让 approximation error 的 sum of squares 最小。$(u^\top x_n)u$ 是 $x_n$ 在 $u$ 上的 projection，$x_n$ 减去它与 $u$ perpendicular，Pythagorean theorem 给出

$$\|x_n\|^2=(u^\top x_n)^2+\big\|x_n-(u^\top x_n)u\big\|^2$$

对 $n$ 求平均：

$$\underbrace{\frac1N\sum_n\|x_n\|^2}_{\mathrm{tr}(S),\ \text{与 }u\text{ 无关}}=u^\top Su+\underbrace{\frac1N\sum_n\big\|x_n-(u^\top x_n)u\big\|^2}_{\text{reconstruction error}}$$

左边是 constant，所以让 projection 的 variance 最大与让 reconstruction error 最小是同一件事。例子里 $\mathrm{tr}(S)=\tfrac{70}{12}=5.833=5.333+0.5$；每个点在 $u_2$ 上的 component 都是 $\pm\tfrac1{\sqrt2}$（例如 $(-2.5+1.5)/\sqrt2$），square 都是 0.5，reconstruction error 正是 $\lambda_2$。

::fig[cs3244-pca] PCA 的 line 与 least squares 的 line 不一样。

和 least squares 对照。用 $x_1$ 预测 $x_2$，least squares 的 slope 是 $\tfrac{\sum x_1x_2}{\sum x_1^2}=\tfrac{14.5}{17.5}=0.829$，而 principal component 的 slope 是 1。Least squares 最小化的是 vertical distance，$x_1$ 被当作没有 error 的 input；PCA 最小化的是到 line 的 perpendicular distance，两个 coordinate 地位相同。

### 留几个方向

留 $k$ 个方向时，保留的 variance 是 $\lambda_1+\dots+\lambda_k$，丢掉的 reconstruction error 是其余 eigenvalue 之和。$\tfrac{\lambda_1+\cdots+\lambda_k}{\lambda_1+\cdots+\lambda_d}$ 叫 explained variance ratio。例子里留一个方向保留 $\tfrac{5.333}{5.833}=91.4\%$。常见做法是留到 ratio 达到 90% 或 95%；如果 PCA 之后还要接一个 supervised model，$k$ 应该按那个 model 的 validation error 来选。

:::wrong PCA 留下的方向就是对 classification 最有用的方向
PCA 不看 label。14 个点 $(x,\pm0.5)$，$x\in\{-3,-2,\dots,3\}$，$y$ 坐标为 $+0.5$ 的是一类，$-0.5$ 的是另一类。$S=\begin{pmatrix}4&0\\0&0.25\end{pmatrix}$，第一个 principal component 是 $x_1$ axis，保留 94% 的 variance；可投到这个方向上，每个 $x$ 上两类各有一个点，完全重合，classification 等于瞎猜。被丢掉的那 6% 恰好把两类完全分开。
:::

:::edge 不 center 会怎样
不减 mean，直接对 $\tfrac1N\sum x_nx_n^\top$ 求 eigenvector，第一个方向会被 mean 占据。50 个点散布在 $(10,10)$ 附近，$x_1$ 方向 standard deviation 1.5、$x_2$ 方向 0.3：不 center 时第一个 eigenvector 是 $(-0.708,-0.706)$，指向 mean；center 之后是 $(-0.999,-0.038)$，才是 data 伸展的方向。另外，几个 feature 的 unit 不同时（比如一个用米、一个用毫米），variance 大的 feature 会仅仅因为 unit 小而主导 principal component，这时要先把每个 feature 除以它的 standard deviation。
:::

:::from
“projection 的 variance 是 $u^\top Su$”、principal component 是 eigenvector、PCA 的用途来自 [CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)第 12 章（我抓到的部分在讲 noise reduction 时被截断）。三种推导的并列、Pythagorean theorem 联系 maximum variance 与 minimum projection error、“与 least squares 相似，但 error 按 perpendicular 方向量”、normalize 与否、按 explained variance 或 validation 选 $k$，来自 [Berkeley CS189 第 20 讲](https://people.eecs.berkeley.edu/%7Ejrs/189/lec/20.pdf)。6 个点的例子、两个反例的数值是为这一页算的。
:::
