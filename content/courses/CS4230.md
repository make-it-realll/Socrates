先看两次失败和一个问题。

**第一次。** Alice 和 Bob 事先见过面，约好一个 16 bit 的 random key $K$。Alice 把 message 和 $K$ 逐 bit 做 XOR 发出去，这叫 one-time pad，下一站会 prove 它在数学上完美：Eve 看到 ciphertext，对 message 一无所知。第二天 Alice 图省事，用同一个 $K$ 又发了一条。

::fig[cs4230-twotime] 两条 message 是 “OK” 和 “NO”（ASCII，每个字母 8 bit），key 两次相同。最后一行只有两个 1，它与 key 无关，就是两条 message 的 XOR。

Eve 只要猜中其中一条是 “OK”，把它和最后一行 XOR，另一条就出来了。一个被 prove 为 perfect 的 scheme，换一种用法就完全失效。问题出在“完美”的 definition 只说了“用一次”。

**第二次。** Alice 给银行发 `PAY 100`，用的仍是 XOR 一个 random pad。Eve 读不懂 ciphertext，但她把其中一个 bit 翻过来再转发。

::fig[cs4230-flip] 第 5 个字符 “1” 的 ASCII 是 00110001，“9” 是 00111001，只差第 5 个 bit。Ciphertext 那一位翻了，解出来的 plaintext 那一位跟着翻。

Bob 解出 `PAY 900`，没有任何报错。Encryption 只承诺 Eve 读不懂，从来没有承诺 Eve 改不了。

**第三件事**是一个更根本的问题：上面两次都假设 Alice 和 Bob 事先共享了 key。浏览器第一次连上一个网站时，两边从来没有见过，中间的每个 packet Eve 都看得见。只靠公开的对话，能约定出一个只有两人知道的 key 吗？

这门课处理这些问题的办法每次都一样，分三步。第一步，把“secure”写成一个 game：adversary 能做什么（看 ciphertext、要求 encrypt 任意 message、要求 decrypt、改 message），赢的条件是什么。第二步，构造 scheme。第三步是 proof：如果有 efficient 的 adversary 赢这个 game，就能用它当零件造出一个 efficient 的 algorithm，去解一个公认很难的问题。最后这一步叫 reduction，全课的每一个 theorem 都是这个形状。

::fig[cs4230-map] 全课的 primitive 和它们之间的构造关系。上半部分只需要“存在 one-way function”这一个 assumption；下半部分需要更具体的数学结构。

课程顺序：第 1 站讲“完美”能做到什么、做不到什么；第 2 到 4 站放松到 efficient adversary，从 PRG、PRF 一路追到最根本的 one-way function；第 5、6 站进入 public key；第 7、8 站处理 integrity，也就是 MAC 和 signature；第 9、10 站是在不公开的数据上计算和 prove；第 11 站是不怕 quantum computer 的 lattice。开头这三件事分别在第 1、7、5 站解决。

## [otp] Perfect secrecy 与 one-time pad

:::skip
能写出 perfect indistinguishability 的 definition、prove one-time pad 满足它，并用 Shannon 的 argument 说明 key 必须不比 message 少，就可以去第 2 站。
:::

### Encryption scheme 是三个 algorithm

一个 encryption scheme 由三个 algorithm 组成，key space 记作 $\mathcal K$，message space 记作 $\mathcal M$，ciphertext space 记作 $\mathcal C$：

- $\mathsf{KeyGen}()$：随机取一个 key $k\in\mathcal K$；
- $\mathsf{Enc}(k,m)$：输出 ciphertext $c$，可以是 randomized 的；
- $\mathsf{Dec}(k,c)$：输出 message。

Correctness 要求对每个 $m$，$\Pr_{k\leftarrow\mathsf{KeyGen}()}[\mathsf{Dec}(k,\mathsf{Enc}(k,m))=m]=1$。

Eve 知道这三个 algorithm 的全部细节，不知道的只有 $k$ 和 Enc 用的 randomness。这叫 Kerckhoffs's principle。理由很实际：algorithm 写在软件里、标准里，迟早公开；key 是每次重新随机取的，能保密的只有它。

### “什么都没泄露”写成 definition

最直接的想法：Eve 看到 $c$ 之后，对 message 的认识和没看之前一样。设 message 本身也是 random variable $M$（Eve 事先对它有某种猜测，比如 70% 是 “YES”），$C=\mathsf{Enc}(K,M)$。**Shannon secrecy** 要求对每个 $M$ 的 distribution、每个 $m$、每个 $c$：

$$\Pr[M=m\mid C=c]=\Pr[M=m]$$

这个 definition 涉及 $M$ 的 distribution，用起来不方便。NUS 讲义用的是另一个等价的版本。设想两个世界：世界 0 里 encrypt 的是 $m_0$，世界 1 里 encrypt 的是 $m_1$。Eve 看到 $c$，要猜自己在哪个世界。**Perfect indistinguishability** 要求对任意 $m_0,m_1\in\mathcal M$、任意 $c$：

$$\Pr_k[\mathsf{Enc}(k,m_0)=c]=\Pr_k[\mathsf{Enc}(k,m_1)=c]$$

两个世界里 ciphertext 的 distribution 完全相同，Eve 怎么猜都只有 ½。

两个 definition 等价，用 Bayes' rule 两个方向各一行。

**Indistinguishability 推出 secrecy。** 设对所有 $m$，$\Pr[\mathsf{Enc}(K,m)=c]$ 都等于同一个数 $p_c$。先算 $C$ 的 distribution：

$$\Pr[C=c]=\sum_{m}\Pr[\mathsf{Enc}(K,m)=c]\Pr[M=m]=p_c\sum_m\Pr[M=m]=p_c$$

再用 Bayes：

$$\Pr[M=m\mid C=c]=\frac{\Pr[C=c\mid M=m]\Pr[M=m]}{\Pr[C=c]}=\frac{p_c\Pr[M=m]}{p_c}=\Pr[M=m]$$

**Secrecy 推出 indistinguishability。** 对任意 $m$（让 $M$ 的 distribution 在 $m$ 上有正的 probability），

$$\Pr[\mathsf{Enc}(K,m)=c]=\Pr[C=c\mid M=m]=\frac{\Pr[M=m\mid C=c]\Pr[C=c]}{\Pr[M=m]}=\frac{\Pr[M=m]\Pr[C=c]}{\Pr[M=m]}=\Pr[C=c]$$

右边和 $m$ 无关，所以对 $m_0$ 和 $m_1$ 相等。

### One-time pad

$\mathcal K=\mathcal M=\mathcal C=\{0,1\}^n$，$\mathsf{KeyGen}$ uniform 地取 $k$，$\mathsf{Enc}(k,m)=k\oplus m$，$\mathsf{Dec}(k,c)=k\oplus c$。

Correctness：$k\oplus(k\oplus m)=(k\oplus k)\oplus m=0^n\oplus m=m$。

Perfect indistinguishability：固定 $m_0$ 和 $c$，$k\oplus m_0=c$ 当且仅当 $k=c\oplus m_0$，这是唯一一个 key，所以

$$\Pr_k[k\oplus m_0=c]=\Pr_k[k=c\oplus m_0]=\frac1{2^n}$$

对 $m_1$ 同样是 $1/2^n$，两者相等。

::fig[cs4230-otp] $n=2$，四个 key 逐个画出来。左边 encrypt 01，右边 encrypt 10：两边都是 4 条线一一落到 4 个 ciphertext 上，每个 ciphertext 恰好被一个 key 命中。

拿图来检验 definition：问“$c=00$”在两个世界里的 probability。左边 $01\oplus k=00$ 要 $k=01$，右边 $10\oplus k=00$ 要 $k=10$，各是 4 个 key 里的一个，都是 ¼。

### 同一个 key 用两次

开头第一次失败可以写成 definition 的语言。Eve 现在看到两个 ciphertext $(c,c')$。世界 0 encrypt $(m_0,m_0')$，世界 1 encrypt $(m_1,m_1')$。选 $m_0=m_0'$、$m_1\ne m_1'$：

- 世界 0：$c\oplus c'=(k\oplus m_0)\oplus(k\oplus m_0)=0^n$，永远相等；
- 世界 1：$c\oplus c'=m_1\oplus m_1'\ne0^n$，永远不等。

Eve 只要检查 $c=c'$，赢的 probability 是 1。开头的图是同一个计算：$C_1\oplus C_2=(M_1\oplus K)\oplus(M_2\oplus K)=M_1\oplus M_2$，“O” 和 “N” 的 ASCII 01001111、01001110 只差最后一位，“K” 和 “O” 的 01001011、01001111 只差倒数第 3 位，所以结果是 00000001 00000100。

:::wrong Perfect secrecy 保证 ciphertext 不泄露 message 的任何信息
它不保护 message 的长度。One-time pad 的 $\mathcal M=\{0,1\}^n$ 固定了长度，definition 只比较同样长的 $m_0,m_1$。如果 Alice 回答 “YES”（3 个 byte，24 bit）或 “NO”（2 个 byte，16 bit），用的 pad 分别是 24 和 16 bit，ciphertext 长度一看就知道是哪个。实际系统要先把 message 填充（padding）到同一长度，这一步不在 definition 里，是使用者的责任。
:::

### Shannon：key 不能比 message 少

One-time pad 的 key 和 message 一样长，16 GB 的文件要 16 GB 的 key，而且只能用一次。能不能省一点？Shannon prove 了不能。

**Theorem。** 如果一个 scheme 满足 correctness 和 perfect indistinguishability，那么 $|\mathcal K|\ge|\mathcal M|$。

**Proof。** 设 $|\mathcal K|<|\mathcal M|$。取一个 $m_0$ 和一个 $k_0$，令 $c=\mathsf{Enc}(k_0,m_0)$，于是 $\Pr_k[\mathsf{Enc}(k,m_0)=c]>0$。

现在数一下有多少个 message 有可能被 encrypt 成 $c$。对每一个 key $k$，$\mathsf{Dec}(k,c)$ 是一个确定的 message，由 correctness，用 $k$ 能 encrypt 成 $c$ 的 message 只能是它，最多一个。所以所有 key 加起来，能变成 $c$ 的 message 最多 $|\mathcal K|$ 个。$|\mathcal K|<|\mathcal M|$，必定有一个 $m_1$ 不在其中：$\Pr_k[\mathsf{Enc}(k,m_1)=c]=0$。两个 probability 一正一零，违反 perfect indistinguishability。

::fig[cs4230-shannon] 一个 key 不够的 scheme：message 是 0 到 3，$\mathsf{Enc}(k,m)=m+k\bmod4$，key 只有 0、1、2 三个。

用图走一遍 proof。$c=0$ 可以来自 $m=0$（$k=0$）、$m=3$（$k=1$）、$m=2$（$k=2$），三条线；$m=1$ 要 $k=3$，不存在。所以 $\Pr[\mathsf{Enc}(K,1)=0]=0$，而 $\Pr[\mathsf{Enc}(K,0)=0]=\tfrac13$。换成 Shannon secrecy 的说法：$M$ uniform 时 $\Pr[C=0]=3\times\tfrac14\times\tfrac13=\tfrac14$，Eve 看到 $c=0$ 之后 $\Pr[M=1\mid C=0]=0$，而事先是 ¼，她排除了一个 message。

:::edge Key 不 uniform
Proof 里 key 的 uniform 很关键。如果 KeyGen 有 bug，取到的 $k$ 第一个 bit 永远是 0，那么 $c$ 的第一个 bit 就等于 $m$ 的第一个 bit，Eve 直接读出。Perfect indistinguishability 对 2 bit 的例子不成立：$m_0=00$、$m_1=10$ 时 $c=00$ 的 probability 分别是 ½ 和 0。
:::

## [prg] Computational security、PRG 与 reduction

:::skip
能写出 negligible、advantage、PRG 的 definition，能独立写出“PRG encryption secure”的 reduction，并说清 hybrid argument 的套路，就可以去第 3 站。
:::

### 放松到 efficient 的 adversary

Shannon theorem 说，要对**任意** Eve 完美，key 就得和 message 一样长。逃出去只有一条路：只防 efficient 的 Eve，并且允许她以极小的 probability 赢。

两件事都要写清楚。引入 security parameter $\lambda$（可以理解为 key 的长度），所有 algorithm 都拿 $1^\lambda$ 当输入。“Efficient”指 probabilistic polynomial time（PPT）：running time 是 $\lambda$ 的某个 polynomial。“极小”指 negligible：

**Definition。** $\nu:\mathbb N\to\mathbb R$ 是 negligible 的，如果对每个 positive polynomial $p$，存在 $\lambda_0$，使得 $\lambda\ge\lambda_0$ 时 $\nu(\lambda)<1/p(\lambda)$。

$2^{-\lambda}$ 是 negligible 的，但“比每个 inverse polynomial 都小”只在 $\lambda$ 足够大时才开始。拿 $1/\lambda^{10}$ 比：

| $\lambda$ | $2^{-\lambda}$ | $\lambda^{-10}$ |
|---|---|---|
| 40 | $9.1\times10^{-13}$ | $9.5\times10^{-17}$ |
| 58 | $3.5\times10^{-18}$ | $2.3\times10^{-18}$ |
| 59 | $1.7\times10^{-18}$ | $2.0\times10^{-18}$ |
| 128 | $2.9\times10^{-39}$ | $8.5\times10^{-22}$ |

从 $\lambda=59$ 起 $2^{-\lambda}$ 才更小。选 negligible 这个 class 的原因是它在 polynomial 次重复下封闭：adversary 跑 $q(\lambda)$ 次，每次赢的 probability 是 $\nu(\lambda)$，union bound 给出 $q(\lambda)\nu(\lambda)$，还是 negligible（对任意 $p$，取 $\nu<1/(p\,q)$ 的那个 $\lambda_0$）。所以“efficient”和“negligible”是配套的：efficient 的 adversary 重复多少次也攒不出不可忽略的 probability。

一个 algorithm $A$ 区分两个 distribution $D_0,D_1$ 的 **advantage** 是

$$\mathrm{adv}^A_{D_0,D_1}=\Pr_{x\leftarrow D_0}[A(x)=1]-\Pr_{x\leftarrow D_1}[A(x)=1]$$

两族 distribution $\{X_\lambda\}$、$\{Y_\lambda\}$ **computationally indistinguishable**，记作 $X\approx_cY$，是指每个 PPT 的 $A$ 的 advantage 都是 negligible。Encryption 的 computational 版本：对任意 $m_0,m_1$，$\mathsf{Enc}(k,m_0)\approx_c\mathsf{Enc}(k,m_1)$。也可以写成 game：

::fig[cs4230-game] Indistinguishability game。和第 1 站的两个世界是同一件事：challenger 秘密地抛硬币决定在哪个世界。

### Pseudorandom generator

要用短 key encrypt 长 message，最自然的办法是把短 key 拉长成一个“看起来像 random”的长 pad，再做 one-time pad。

**Definition。** Deterministic polynomial-time 的 $G:\{0,1\}^\lambda\to\{0,1\}^{m(\lambda)}$ 是 PRG，如果

- expansion：$m(\lambda)>\lambda$；
- pseudorandomness：$G(U_\lambda)\approx_cU_{m(\lambda)}$。

这里 $U_n$ 是 $\{0,1\}^n$ 上的 uniform distribution。

Definition 一用：$G(s)=s\,\|\,\mathrm{parity}(s)$ 把 $\lambda$ bit 拉长 1 bit，是 PRG 吗？Distinguisher $D(y)$：检查最后一位是不是前 $\lambda$ 位的 parity，是就输出 1。$y=G(s)$ 时永远是，$\Pr[D=1]=1$；$y$ uniform 时最后一位 independent of 前面，$\Pr[D=1]=\tfrac12$。Advantage $\tfrac12$，不是 negligible，所以不是。“Pseudorandom”要对**所有** efficient 的检查都成立，一个 output bit 如果能由其他 bit 算出来就完了。

PRG 的存在没法无条件 prove（第 4 站会看到它推出 $\mathrm P\ne\mathrm{NP}$），只能基于 assumption 构造。讲义给的候选是 subset sum：取 $n$ 个 $\ell$ bit 的数 $\vec a=(a_1,\dots,a_n)$ 和一个 subset $S\subseteq[n]$，

$$f(\vec a,S)=\Big(\vec a,\ \sum_{i\in S}a_i\bmod2^\ell\Big)$$

Input 是 $n\ell+n$ bit，output 是 $n\ell+\ell$ bit，$\ell>n$ 时就拉长了 $\ell-n$ bit。小例子：$n=3$、$\ell=4$，$\vec a=(5,11,14)$，$S=\{1,3\}$，output 末尾是 $5+14=19\bmod16=3$；input 15 bit，output 16 bit。Impagliazzo 和 Naor prove 了：只要 $f$ 难以 invert，它就是 PRG。

### PRG encryption 与第一个 reduction

Scheme：$\mathsf{KeyGen}$ 取 $k\leftarrow\{0,1\}^\lambda$，$\mathsf{Enc}(k,m)=G(k)\oplus m$，$\mathsf{Dec}(k,c)=G(k)\oplus c$，message 长 $m(\lambda)$ bit。Correctness 和 one-time pad 一样。

**Theorem。** $G$ 是 PRG，则这个 scheme computationally indistinguishable。

要证的是“对所有 PPT 的 $D$”，直接证没有抓手。证 contrapositive：假设有一个 $D$ 能区分，用它造一个区分 $G$ 的 $D'$。

设有 $m_0,m_1$、PPT 的 $D$、polynomial $p$，对无穷多个 $\lambda$：

$$\Pr[D(G(U_\lambda)\oplus m_0)=1]-\Pr[D(G(U_\lambda)\oplus m_1)=1]\ge\frac1{p(\lambda)}$$

中间插入两项再减掉：$\Pr[D(U\oplus m_0)=1]$ 和 $\Pr[D(U\oplus m_1)=1]$，$U$ 是 uniform 的 $m(\lambda)$ bit。由 one-time pad，$U\oplus m_0$ 和 $U\oplus m_1$ 都是 uniform，这两项相等，插进去不改变数值：

$$\underbrace{\Pr[D(G\oplus m_0)=1]-\Pr[D(U\oplus m_0)=1]}_{W_0}+\underbrace{\Pr[D(U\oplus m_1)=1]-\Pr[D(G\oplus m_1)=1]}_{W_1}\ge\frac1{p(\lambda)}$$

两项之和至少 $1/p$，其中一项至少 $1/(2p)$。设是 $W_0$（$W_1$ 对称）。造 $D'$：收到 $y$，算 $c=y\oplus m_0$，输出 $D(c)$。

::fig[cs4230-reduction] $D'$ 的内部。它自己不知道 $y$ 从哪来，只是把 $y$ 当 pad 用，交给 $D$。

$y=G(s)$ 时 $D$ 看到的是真 ciphertext $G(s)\oplus m_0$；$y$ uniform 时看到的是 one-time pad 的 ciphertext。所以

$$\mathrm{adv}^{D'}_{G(U_\lambda),U}=\Pr[D(G\oplus m_0)=1]-\Pr[D(U\oplus m_0)=1]=W_0\ge\frac1{2p(\lambda)}$$

$D'$ 比 $D$ 只多一次 XOR，仍是 PPT，与 $G$ 是 PRG 矛盾。

> Reduction 的方向：从“scheme 被攻破”出发，造出“assumption 被攻破”。attacker 是假设存在的零件，我们只负责把它接到正确的输入上。

:::wrong 要 prove scheme secure，就是把 PRG 的 distinguisher 改造成 scheme 的 attacker
方向反了。“PRG 的 distinguisher 可以变成 scheme 的 attacker”说的是“PRG insecure 则 scheme insecure”，这对 scheme 的 security 什么都没 prove（PRG secure 时 scheme 照样可能被别的办法攻破）。要证的是“PRG secure ⇒ scheme secure”，contrapositive 是“scheme insecure ⇒ PRG insecure”，所以必须拿 scheme 的 attacker $D$ 当零件造出 PRG 的 distinguisher $D'$，正如上面做的。CS3230 讲 NP-hardness 时同样强调 reduction 的方向。
:::

### Next-bit unpredictability

$G$ 的 output $y=y_1\cdots y_m$。一个更容易用的条件是：看到前 $i-1$ 位，猜不出第 $i$ 位。

**Definition。** $G$ next-bit unpredictable，如果对每个 PPT 的 predictor $P$ 和每个 $i$：

$$\Pr_{s,\,y=G(s)}[P(y_1\cdots y_{i-1})=y_i]\le\tfrac12+\mathrm{negl}(\lambda)$$

**Theorem。** $G$ 是 PRG 当且仅当它 next-bit unpredictable。

**PRG 推出 unpredictable**（contrapositive）。设 $P$ 在位置 $i$ 猜对的 probability $\ge\tfrac12+1/p$。造 distinguisher：收到 $x$，若 $P(x_1\cdots x_{i-1})=x_i$ 则输出 1。$x=G(s)$ 时输出 1 的 probability $\ge\tfrac12+1/p$；$x$ uniform 时 $x_i$ independent of 前缀，probability 恰好 $\tfrac12$。Advantage $\ge1/p$。

**Unpredictable 推出 PRG** 是方向难的一边，第一次用到 hybrid argument。设 $D$ 区分 $X=G(U_\lambda)$ 和 $U=U_m$，advantage $\ge1/p$。define 中间的 distribution

$$D_i=X[1{:}i]\;\|\;U[i{+}1{:}m],\qquad i=0,1,\dots,m$$

前 $i$ 位来自 $G$，后面是 random。$D_0=U$，$D_m=X$。令 $p_i=\Pr[D(D_i)=1]$，则

$$\frac1p\le p_m-p_0=\sum_{i=1}^m(p_i-p_{i-1})$$

$m$ 项加起来至少 $1/p$，必有某个 $i$ 使 $p_i-p_{i-1}\ge1/(mp)$。$D_i$ 和 $D_{i-1}$ 只差第 $i$ 位：前者是真的 $X_i$，后者是 random bit。记 $D_i'$ 为把 $D_i$ 的第 $i$ 位翻过来，$p_i'=\Pr[D(D_i')=1]$。$D_{i-1}$ 的第 $i$ 位一半时候等于 $X_i$、一半时候等于它的翻转，所以

$$p_{i-1}=\tfrac12(p_i+p_i')$$

Predictor $P$：收到前缀 $y_1\cdots y_{i-1}$，随机取一个 bit $c$，后面再补 random bit，交给 $D$；$D$ 输出 1 就猜 $c$，否则猜 $1-c$。$c=X_i$（probability ½）时 $D$ 看到的是 $D_i$，猜对要 $D$ 输出 1；$c\ne X_i$ 时 $D$ 看到的是 $D_i'$，猜对要 $D$ 输出 0：

$$\Pr[P\text{ 猜对}]=\tfrac12p_i+\tfrac12(1-p_i')=\tfrac12+\tfrac12(p_i-p_i')$$

由上一个等式 $p_i'=2p_{i-1}-p_i$，代进去 $p_i-p_i'=2(p_i-p_{i-1})$，所以

$$\Pr[P\text{ 猜对}]=\tfrac12+(p_i-p_{i-1})\ge\tfrac12+\frac1{m\,p}$$

$m$ 是 polynomial，$1/(mp)$ 仍不是 negligible，与 unpredictable 矛盾。（$P$ 事先不知道 $i$ 是哪一个，可以随机猜 $i$，再损失一个 factor $m$。）

:::edge Advantage 的正负号
Definition 里的 advantage 没有加绝对值。若某个 $D$ 的 advantage 是 $-1/p$，把它的输出取反就得到 $+1/p$。所以“所有 PPT 的 advantage 都 negligible”加不加绝对值是同一回事，proof 里可以假设它是正的。
:::

### 把 1 bit 的 stretch 拉到任意长

有了一个只多 1 bit 的 $G:\{0,1\}^\lambda\to\{0,1\}^{\lambda+1}$，反复用它：

1. $s_0=s$；
2. 对 $i=1,\dots,L$：$(b_i,s_i)=G(s_{i-1})$，$b_i$ 是 1 bit，$s_i$ 是 $\lambda$ bit；
3. 输出 $G'(s)=b_1b_2\cdots b_L\,s_L$。

每一步吐出 1 bit、留下新的 seed。实践里这叫 stream cipher。prove $G'$ 是 PRG 仍是 hybrid：$H_i$ 是把前 $i$ 个 bit 换成真 random，并从一个 fresh random seed 继续迭代。

::fig[cs4230-hybrid] $L=4$ 的五个 hybrid 依次播放。每一帧只换掉一格：那一格的 (seed, bit) 是 $G$ 的 output 还是真 random。

$H_0=G'(U_\lambda)$，$H_L$ 是 $L+\lambda$ 个 random bit。若 $D$ 区分 $H_0$ 和 $H_L$ 的 advantage 是 $\varepsilon$，同上面一样某对相邻的 $H_{i-1},H_i$ 被区分的 advantage $\ge\varepsilon/L$。这两者只差一处：$(b_i,s_i)$ 是 $G(s_{i-1})$（$s_{i-1}$ random）还是 $\lambda+1$ 个 random bit。造 $G$ 的 distinguisher：收到 challenge $z\in\{0,1\}^{\lambda+1}$，前 $i-1$ 个 bit 自己随机取，第 $i$ 格放 $z$，后面用 $z$ 的 seed 部分自己迭代 $G$，交给 $D$。$z=G(\cdot)$ 时 $D$ 看到 $H_{i-1}$，$z$ random 时看到 $H_i$。Advantage $\ge\varepsilon/L$，$L$ 是 polynomial，矛盾。

Hybrid argument 的套路就是这样：两端差得远，就在中间放一串每步只差一点的 distribution，每一步差的那一点恰好是某个已知 secure 的东西；损失的 factor 就是步数。

:::from
Negligible、advantage、PRG 的 definition，subset sum PRG 的长度计算，PRG encryption 的 $W_0$、$W_1$ proof，$D_i$ 的 hybrid 与 predictor（讲义原稿 else 分支漏了取反，这里按正确的写），stretch 的构造，来自 [Rahul Jain 讲义第 2 讲](https://www.comp.nus.edu.sg/~rahul/lecture-notes/CS4230-5430-lecture-notes.pdf)及其附录 A.3。Telescoping lemma、$p_{i-1}=\tfrac12(p_i+\bar p_i)$ 的写法、“stream cipher”的叫法来自 [MIT 6.875 第 3 讲](https://mit6875.github.io/FA22SLIDES/lec3.pdf)。Stretch 的 hybrid proof 两份材料都留作练习，这里的写法是我按 hybrid 的标准套路补的。negligible 对照表、parity 的反例、subset sum 的数字是这一页实算的。
:::

## [prf] PRF、CPA security 与 GGM

:::skip
能写出 PRF 和 CPA 的 game，能 prove PRF encryption 是 CPA-secure 的并算出 collision 项，能在 GGM tree 上算一个值，就可以去第 4 站。
:::

### 一个 key encrypt 很多条 message

PRG encryption 用同一个 key encrypt 两次，就是 $G(k)\oplus m$ 和 $G(k)\oplus m'$，两者 XOR 得到 $m\oplus m'$：又回到了 two-time pad。

MIT 的讲法给了两个补救。第一个是 stateful：两人都记住用到 pad 的第几位，下次接着往后用。可以，但两边必须严格同步，同时发消息就乱了。第二个是 stateless：pad 做得极长，每次随机挑一个位置 $j$，发送 $(j,\,m\oplus\text{pad 的第 }j\text{ 段})$。位置要从很大的范围里挑才不会撞车，可这样 pad 有 exponentially 长，算不出来。需要的是不把整个 pad 算出来、直接算出第 $j$ 段的办法，这就是 PRF。

### Pseudorandom function

PRF family 是 $\{f_k:\{0,1\}^n\to\{0,1\}^m\}_{k\in\mathcal K}$，取 $k$ 和计算 $f_k(x)$ 都 efficient。security 用 game 来 define：challenger 抛硬币，$b=0$ 时取一个**真 random function** $f$（在所有 $\{0,1\}^n\to\{0,1\}^m$ 的 function 里 uniform 地取），$b=1$ 时取 $f=f_k$；adversary 可以 adaptive 地问 polynomial 次 $f(x_i)$，最后猜 $b$。PRF 要求赢的 probability $\le\tfrac12+\mathrm{negl}$。

数一下两边的大小就知道这个要求有多强。所有 $\{0,1\}^n\to\{0,1\}^m$ 的 function 有 $(2^m)^{2^n}=2^{m2^n}$ 个；$n=m=128$ 时是 $2^{128\cdot2^{128}}$。PRF 只有 $2^{128}$ 个 key。一个极小的子集，要让 efficient 的 adversary 从 polynomial 次查询里分辨不出它和整个 set。

### CPA security

Adversary 现在不只看 challenge，还能在之前和之后让 challenger encrypt 任意自选的 message。这叫 chosen-plaintext attack，网页里注入一段内容让你的浏览器 encrypt，就是这种情况。

**IND-CPA game。** Challenger 取 $b$ 和 $k$；adversary 问若干个 $\hat m_i$，得到 $\mathsf{Enc}(k,\hat m_i)$；adversary 给出 $m_0,m_1$，得到 $\mathsf{Enc}(k,m_b)$，之后还能继续问；最后输出 $b'$。CPA-secure 要求 $\Pr[b'=b]\le\tfrac12+\mathrm{negl}$。

Definition 一用：任何 **deterministic** 的 Enc 都不是 CPA-secure 的。Adversary 先问 $\mathsf{Enc}(k,m_0)$ 得到 $c_0$，再把 $m_0,m_1$ 当 challenge，拿到 $c^*$ 后比较：$c^*=c_0$ 就猜 0。赢的 probability 是 1。所以 CPA-secure 的 encryption 必须是 randomized 的：同一个 message 每次 encrypt 的结果都不同。

### PRF encryption

$\mathsf{Enc}(k,m)$：随机取 $r\leftarrow\{0,1\}^\lambda$，输出 $(r,\ f_k(r)\oplus m)$。$\mathsf{Dec}(k,(r,c))=f_k(r)\oplus c$。

$r$ 就是 stateless 方案里随机挑的位置，$f_k(r)$ 就是 pad 的第 $r$ 段，只算这一段。

**Proof 的思路**（两个 hybrid）。

1. 把 $f_k$ 换成真 random function $F$。如果 adversary 在两种情况下赢的 probability 差得不可忽略，就能拿它去赢 PRF game：PRF game 里的 adversary 自己扮演 CPA 的 challenger，每次需要 $f(r)$ 就去问它的 oracle。所以这一步只差 negligible。
2. 在 $F$ 的世界里，challenge 是 $(r^*,F(r^*)\oplus m_b)$。只要 $r^*$ 和之前所有 encryption 用过的 $r$ 都不同，$F(r^*)$ 是一个从没被看过的 uniform string，这就是 one-time pad，$b$ 完全隐藏。

剩下的只有 collision：$q$ 次 encryption 里 $r^*$ 和某个之前的 $r$ 相同。$r^*$ uniform，和某个固定的 $r$ 相同的 probability 是 $2^{-\lambda}$，union bound 给出 $\le q/2^\lambda$；把任意两次 encryption 之间的 collision 都算上是 $\le q^2/2^\lambda$。合起来：

$$\Pr[\text{赢}]\le\tfrac12+\mathrm{adv}_{\text{PRF}}+\frac{q^2}{2^\lambda}$$

数字：$\lambda=128$，encrypt $q=2^{32}$ 次（四十亿次），任意两次撞车的 probability 是 $\binom q2/2^{128}\approx2^{-65}$。

:::wrong $r$ 不用随机，固定用 0 也行，反正 $f_k(0)$ 是 pseudorandom 的
那样 Enc 就是 deterministic 的：$\mathsf{Enc}(k,m)=(0,f_k(0)\oplus m)$，同一个 $m$ 永远得到同一个 ciphertext，上面那个 adversary 以 probability 1 赢。更糟的是，任意两条 ciphertext 的第二部分 XOR 起来就是 $m\oplus m'$，这又是 two-time pad。$f_k(0)$ 单独看是 pseudorandom 的，可它被用了两次。PRF 的 security 只保证**不同** input 的 output 互相 independent。用 counter $0,1,2,\dots$ 代替 random $r$ 是可以的，因为 input 两两不同，但这需要 state。
:::

:::edge $r$ 的范围太小
若 $r$ 只取 20 bit（$N=2^{20}$ 种），encrypt $q=2^{10}$ 次后至少一次 collision 的 probability 约是 $1-e^{-q^2/2N}=1-e^{-0.5}\approx0.39$（第 8 站推这个 formula）。collision 的两条 ciphertext 用了同一段 pad，又是 two-time pad。所以 $r$ 的长度必须随 $\lambda$ 增长。
:::

### GGM：从 PRG 造 PRF

Goldreich、Goldwasser、Micali 的构造。取一个 length-doubling 的 PRG $G:\{0,1\}^\lambda\to\{0,1\}^{2\lambda}$，把 output 劈成左右两半：$G(s)=G_0(s)\,\|\,G_1(s)$。Key 是 $k\in\{0,1\}^\lambda$，

$$f_k(x_1x_2\cdots x_n)=G_{x_n}\big(\cdots G_{x_2}(G_{x_1}(k))\cdots\big)$$

画成一棵深度 $n$ 的 binary tree：root 上放 $k$，每个 node 上的 string 经过 $G$ 得到两个孩子，左孩子取左半、右孩子取右半。Input $x$ 就是从 root 走到 leaf 的 path。

::fig[cs4230-ggm] $n=3$，计算 $f_k(101)$：第 1 位是 1 往右，第 2 位是 0 往左，第 3 位是 1 往右。整棵树有 8 个 leaf，但只走了一条 path，调用 3 次 $G$。

结果是 $f_k(101)=G_1(G_0(G_1(k)))$。实际里 $n=128$，树有 $2^{128}$ 个 leaf，从来不会被整棵算出来，每次 evaluation 只要 128 次 $G$。

**Proof（$n=2$）。** 三个 hybrid。

- Hybrid 1：真的 GGM tree，第一层是 $G_0(k),G_1(k)$，第二层由它们再过 $G$。
- Hybrid 2：$k$ 是 random，所以 $G(k)=G_0(k)\|G_1(k)$ 看起来像 random，把第一层换成两个 independent 的 random string $r_0,r_1$。
- Hybrid 3：同理把 $G(r_0)$、$G(r_1)$ 换成 random，四个 leaf $r_{00},r_{01},r_{10},r_{11}$ 互相 independent 且 uniform，这就是 2 bit input 上的真 random function。

若 adversary 区分 Hybrid 1 和 3 的 advantage 是 $\varepsilon$，由 triangle inequality 它区分 1 和 2 或 2 和 3 的 advantage 至少 $\varepsilon/2$，两种都能造出 $G$ 的 distinguisher。

一般的 $n$ 有 $n+1$ 个 hybrid，每次替换一整层。难点在于一层有 $2^i$ 个 node，reduction 不可能放 $2^i$ 个 challenge。解决办法是只在 adversary 实际问到的 path 经过的 node 上放：$q$ 次查询最多经过这一层的 $q$ 个 node，reduction 向 PRG 要 $q$ 个 challenge（这本身是一个 $q$ 步的 hybrid），用到哪个 node 才临时赋值。所以总损失是 $nq$ 量级的 factor，仍是 polynomial。

反方向 PRF 推出 PRG 很简单：$G(k)=f_k(1)\,\|\,f_k(2)$，两个不同 input 的 output 像两段 independent 的 random string，长度翻倍。

:::from
CPA game、PRF 的 FN-IND game、PRF encryption、GGM 的 definition 和 $n=2$ 的三个 hybrid、PRF 推出 PRG，来自 [Rahul Jain 讲义第 3 讲和第 5 讲的 primitive 表](https://www.comp.nus.edu.sg/~rahul/lecture-notes/CS4230-5430-lecture-notes.pdf)（讲义的 CPA proof 只有思路，没有处理 $r$ collision）。Stateful 与 stateless 两种补救、“pad 太长算不出来所以要 PRF”的引入顺序、function 个数的比较来自 [MIT 6.875 第 3 讲](https://mit6875.github.io/FA22SLIDES/lec3.pdf)；collision 项 $q^2/2^n$、多查询时 reduction 只在用到的 node 上放 challenge 来自 [第 4 讲](https://mit6875.github.io/FA22SLIDES/lec4.pdf)。Deterministic encryption 不 CPA-secure 的 adversary、$2^{32}$ 次 encryption 的数字、20 bit $r$ 的例子是这一页补的。
:::

### PRG 背后最少需要什么

PRG、PRF、encryption 都是“看起来像 random”的东西。往下追：最少要假设什么？答案是“有一个 function 容易算、难以 invert”。

**Definition。** $f:\{0,1\}^\lambda\to\{0,1\}^{m(\lambda)}$ 是 one-way function（OWF），如果 $f$ 可以 deterministic polynomial time 计算，而且对每个 PPT 的 $A$：

$$\Pr_{x\leftarrow U_\lambda}\big[f(A(1^\lambda,f(x)))=f(x)\big]=\mathrm{negl}(\lambda)$$

注意 $A$ 只需要找到**某个** preimage，不必是原来的 $x$。如果要求找回 $x$ 本身，constant function $f(x)=0$ 就成了 one-way 的：看到 0 根本无从知道 $x$。可它显然不配叫 one-way，因为任何 $x'$ 都是 preimage。

**PRG 推出 OWF。** 要证的是“有 PRG 就有 OWF”。先用第 2 站的办法把手上的 PRG 拉长成 $G:\{0,1\}^\lambda\to\{0,1\}^{2\lambda}$，它仍是 PRG；下面证这个 $G$ 本身就是 one-way 的。设不是，有 $A$ 以 $\ge1/p$ 的 probability invert $G$。Distinguisher $D(y)$：算 $x'=A(y)$，若 $G(x')=y$ 输出 1。

- $y=G(s)$ 时 $\Pr[D=1]\ge1/p$；
- $y$ uniform（$2\lambda$ bit）时，只有 $y$ 落在 $G$ 的 image 里才可能输出 1，image 最多 $2^\lambda$ 个 element，$\Pr[D=1]\le2^\lambda/2^{2\lambda}=2^{-\lambda}$，negligible。

Advantage 不是 negligible，矛盾。

同样的 argument 说明 PRG 的存在推出 $\mathrm P\ne\mathrm{NP}$：语言 $L_G=\{y:\exists x,\ G(x)=y\}$ 在 NP 里（witness 是 $x$）。若 $\mathrm P=\mathrm{NP}$，有 deterministic polynomial time 的 decider，用它当 distinguisher，$G(s)$ 上永远输出 1，uniform 上输出 1 的 probability $\le2^\lambda/2^m\le\tfrac12$，advantage $\ge\tfrac12$。所以这门课里的每一个 computational 的 theorem 都附带 assumption，不可能无条件 prove。

:::edge “把两个数乘起来”作为 OWF 的陷阱
$f(x,y)=x\cdot y$（$x,y$ 是随机的 $\lambda$ bit 整数）看起来是 factoring，可它不是 OWF：$x,y$ 至少一个是 even 的 probability 是 $1-\tfrac14=\tfrac34$，这时 $N$ 是 even，inverter 直接输出 $(2,N/2)$ 就是一个合法的 preimage。Factoring 难是对两个随机 prime 的乘积说的，OWF 的 input distribution 要和 assumption 对得上。
:::

### Hardcore predicate

OWF 只保证 $x$ 整个找不回来，不保证每一位都藏得住。PRG 需要的是：从 $f(x)$ 连**一个 bit** 都猜不出。

**Definition。** $h:\{0,1\}^\lambda\to\{0,1\}$ 是 $f$ 的 hardcore predicate，如果对每个 PPT 的 $A$：

$$\Pr_x[A(f(x))=h(x)]\le\tfrac12+\mathrm{negl}(\lambda)$$

**OWP 加 hardcore predicate 推出 PRG。** 设 $f$ 是 one-way permutation（OWF 且是 $\{0,1\}^\lambda$ 上的 bijection），$h$ 是它的 hardcore predicate。令

$$G(s)=f(s)\,\|\,h(s)$$

$\lambda$ bit 变 $\lambda+1$ bit。用 next-bit unpredictability：$f$ 是 permutation，$s$ uniform 时前 $\lambda$ 位 $f(s)$ 本身就是 uniform 的，没有哪一位能被前面的猜出；最后一位被前面猜出，就是从 $f(s)$ 猜出 $h(s)$，与 hardcore 矛盾。所以 $G$ 是 PRG。

:::wrong $f$ 是 OWF，所以 $f(x)$ 不泄露 $x$ 的任何一个 bit
反例：设 $g$ 是 OWF，令 $f(x_1x_2\cdots x_\lambda)=x_1\,\|\,g(x_2\cdots x_\lambda)$。Invert $f$ 要 invert $g$，所以 $f$ 仍然 one-way；可 $f(x)$ 的第一位就是 $x_1$。同样的办法可以让 $f$ 泄露 $x$ 的任意一个**固定**的 bit，所以不存在一个固定的 predicate 对所有 OWF 都 hardcore。Goldreich–Levin 的办法是让 predicate 带一个 random 的 parameter。
:::

### Goldreich–Levin

**Theorem。** 对任意 OWF $f$，在 $f(x)$ 和一个 random 的 $r$ 下，$\langle x,r\rangle=\sum_ix_ir_i\bmod2$ 是 hardcore 的：对每个 PPT 的 $A$，

$$\Pr_{x,r}\big[A(f(x),r)=\langle x,r\rangle\big]\le\tfrac12+\mathrm{negl}(\lambda)$$

等价地，$f'(x,r)=(f(x),r)$ 是 OWF，$\langle x,r\rangle$ 是它的 hardcore predicate。

Proof 是 contrapositive：给一个 predictor $A$，猜对的 probability 是 $\tfrac12+\varepsilon$，造一个 invert $f$ 的 algorithm。关键工具只有 inner product 的 linearity：

$$\langle x,r\rangle\oplus\langle x,r\oplus e_i\rangle=\langle x,e_i\rangle=x_i$$

$e_i$ 是只有第 $i$ 位为 1 的 vector。

**Warm-up 1：$A$ 永远猜对。** 直接问 $A(f(x),e_i)$，得到 $\langle x,e_i\rangle=x_i$。问 $\lambda$ 次，$x$ 全出来了。

**Warm-up 2：$A$ 对每个 $x$ 都至少 0.8 的 probability 猜对**（probability 只来自 $r$）。不能再直接问 $e_i$：$A$ 可能恰好在 $e_i$ 这种特殊的 $r$ 上全错，0.8 只是对 random $r$ 平均而言。办法是把 $e_i$ 藏进 random 的 $r$：随机取 $r$，问 $A(f(x),r)$ 和 $A(f(x),r\oplus e_i)$，两个答案 XOR。$r$ 和 $r\oplus e_i$ 各自都是 uniform 的，所以各自答错的 probability $\le0.2$；由 union bound，两次都对的 probability $\ge1-0.2-0.2=0.6$，这时 XOR 恰好是 $x_i$。

::fig[cs4230-gl] $x=1011$，$r=0110$，求 $x_2$。下方的条是 union bound：两段“错”最坏情况下不重叠，剩下的部分两次都对。

用图核对：$\langle1011,0110\rangle=1\cdot0+0\cdot1+1\cdot1+1\cdot0=1$；$r\oplus e_2=0010$，$\langle1011,0010\rangle=1$；$1\oplus1=0$，$x_2$ 确实是 0。

0.6 的单次成功率还不够，要放大：independent 地取 $k$ 个 $r_j$，各得到一个 $x_i$ 的猜测，取 majority。每次猜对的 indicator $X_j$ 的 expectation $\ge0.6$，majority 错意味着猜对的次数 $X=\sum X_j\le k/2$，比 expectation 少了至少 $0.1k$。Chebyshev（见 [ST2131 第 7 站](../courses/ST2131.html#limit)）：

$$\Pr[X\le k/2]\le\Pr\big[|X-E[X]|\ge0.1k\big]\le\frac{\mathrm{Var}[X]}{(0.1k)^2}\le\frac{k/4}{0.01k^2}=\frac{25}{k}$$

这里用到 $\mathrm{Var}[X]=\sum\mathrm{Var}[X_j]$，只要 $X_j$ **两两 independent** 就成立，每项 variance $\le\tfrac14$。

::fig[cs4230-vote] 单次猜对的 probability 0.6（$\delta=0.1$）时，majority 出错的 probability 随 $k$ 的变化，纵轴是 log scale。完全 independent 时可以用下降快得多的 Chernoff bound；只有 pairwise independence 时只能用 Chebyshev，下降慢，但同样趋于 0。

取 $k$ 使 $25/k\le1/(4\lambda)$，即 $k=100\lambda$，每一位出错 $\le1/(4\lambda)$；union bound 到 $\lambda$ 位，全部猜对的 probability $\ge1-\lambda\cdot\frac1{4\lambda}=\tfrac34$。

### Goldreich–Levin 的完整 proof

:::skip
这一小节处理一般的 $\tfrac12+\varepsilon$。只想知道结论和 warm-up 的，可以跳到第 5 站。
:::

一般情况有两个新困难。

**第一，$A$ 的成功率是对 $x$ 和 $r$ 平均的**，有些 $x$ 上可能很差。用 averaging 挑出“好的” $x$：称 $x$ good，如果 $\Pr_r[A(f(x),r)=\langle x,r\rangle]\ge\tfrac12+\tfrac\varepsilon2$。记 $p_g=\Pr_x[x\text{ good}]$，bad 的 $x$ 成功率 $<\tfrac12+\tfrac\varepsilon2$，所以

$$\tfrac12+\varepsilon\le p_g\cdot1+(1-p_g)\big(\tfrac12+\tfrac\varepsilon2\big)\le p_g+\tfrac12+\tfrac\varepsilon2$$

得到 $p_g\ge\varepsilon/2$。下面只对 good 的 $x$ 做，只损失一个 factor $\varepsilon/2$。

**第二，单次成功率 $\tfrac12+\tfrac\varepsilon2$ 时 union bound 失效**：两次都对的下界是 $1-2(\tfrac12-\tfrac\varepsilon2)=\varepsilon$，比 ½ 还小，majority 没有意义。解决办法是不去问 $A(f(x),r)$，而是**猜** $\langle x,r\rangle$。

1. 取 $\ell$ 个 random 的 $r_1,\dots,r_\ell$，猜 $b_j=\langle x,r_j\rangle$。$\ell$ 个都猜对的 probability 是 $2^{-\ell}$。
2. 对每个非空 subset $S\subseteq[\ell]$，令 $r_S=\bigoplus_{j\in S}r_j$、$b_S=\bigoplus_{j\in S}b_j$。若 $b_j$ 都对，由 linearity $b_S=\langle x,r_S\rangle$ 也都对。这样从 $\ell$ 个猜测得到 $2^\ell-1$ 个正确的 inner product。
3. 对每个 $S$，问 $A(f(x),r_S\oplus e_i)$，与 $b_S$ XOR 得到 $x_i$ 的一个猜测。现在只有一次查询可能出错，猜对的 probability 就是 $A$ 在 $r_S\oplus e_i$ 上答对的 probability，$\ge\tfrac12+\tfrac\varepsilon2$。
4. 对 $2^\ell-1$ 个猜测取 majority。

这些 $r_S$ 不是 independent 的（$r_{\{1,2\}}=r_1\oplus r_2$ 由前两个决定），但它们 **pairwise independent**：取 $S\ne T$，不妨设 $j\in S\setminus T$。固定除 $r_j$ 以外的所有 $r$，$r_T$ 就固定了，而 $r_S=r_j\oplus(\text{其余})$ 随 $r_j$ uniform 地变化；$r_T$ 本身是 uniform 的（$T$ 非空）。所以 $(r_S,r_T)$ 在所有 pair 上 uniform，两两 independent。Chebyshev 只需要这个。

数字：$\lambda=128$，$\varepsilon=0.1$，单次成功率 $\ge\tfrac12+0.05$。Chebyshev 给出 $\Pr[\text{majority 错}]\le\frac{k/4}{(0.05k)^2}=\frac{100}{k}$，要 $\le\frac1{4\lambda}=\frac1{512}$ 需要 $k\ge51200$ 个猜测，取 $\ell=16$（$2^{16}-1=65535$ 个 subset）。成功的 probability 至少是 $x$ good、16 个猜测全对、majority 全对三者相乘：

$$\frac\varepsilon2\cdot2^{-16}\cdot\frac34=0.05\times\frac1{65536}\times0.75\approx5.7\times10^{-7}$$

很小，但它是 $1/\mathrm{poly}(\lambda)$：$2^\ell$ 只是 $k$ 的量级，$k$ 是 $\lambda/\varepsilon^2$ 的 polynomial。而且每得到一个候选 $x'$ 都能检查 $f(x')=f(x)$，可以把 $2^{16}$ 种猜测全部枚举一遍，挑出对的那个。这就与 $f$ one-way 矛盾。

MIT 的 slide 给了另一种看法：$x\mapsto(\langle x,r\rangle)_{r\in\{0,1\}^\lambda}$ 是 $x$ 的 Hadamard code，predictor 给出的是一个错误率接近 ½ 的 codeword，Goldreich–Levin 就是这个 code 的 list decoding。

### Secret-key 这一侧只有一个 assumption

把前四站的构造放在一起（第 7 站的 MAC 也属于这一侧）：

| 构造 | 在哪 |
|---|---|
| OWF ⇒ PRG | Goldreich–Levin 加 HILL（Håstad、Impagliazzo、Levin、Luby，难得多，这门课不证） |
| PRG ⇒ OWF | 本站 |
| PRG ⇒ PRF | 第 3 站，GGM |
| PRF ⇒ PRG | 第 3 站 |
| PRF ⇒ CPA-secure encryption | 第 3 站 |
| Encryption ⇒ OWF | Impagliazzo–Luby，不证 |

OWF、PRG、PRF、secret-key encryption，有一个就有全部，它们要么都存在，要么都不存在。Public-key encryption 不在这个圈里：没有已知的办法从 OWF 造出它，下一站开始要用更具体的数学结构。

:::from

## [dh] Discrete log、Diffie–Hellman 与 ElGamal

:::skip
能在 $\mathbb{Z}_{23}^*$ 里手算一次 Diffie–Hellman 和 ElGamal，分得清 DL、CDH、DDH，知道 DDH 在整个 $\mathbb{Z}_p^*$ 里为什么不成立，就可以去第 6 站。
:::

### 不事先见面能约定 key 吗：Merkle puzzles

开头的第三件事。Merkle 1974 年的想法只用一个公开的 random function $H:[M]\to[M^{10}]$（range 很大，几乎不会 collision），Eve 也能调用它：

1. Alice 随机取 $n$ 个 $X_1,\dots,X_n\in[M]$，公开 $H(X_1),\dots,H(X_n)$；
2. Bob 随机取 $Y_1,\dots,Y_n$，公开 $H(Y_1),\dots,H(Y_n)$；
3. 两人找出 $H(X_i)=H(Y_j)$ 的那一对，共享的 key 是 $X_i=Y_j$。

每一对 $(i,j)$ 撞上的 probability 是 $1/M$，所以撞上的对数的 expectation 是 $n^2/M$。

::fig[cs4230-merkle] $M=400$，各取 $n=40$ 个，expectation 是 $40^2/400=4$，这次实际重合 3 处。

Alice 和 Bob 各自只调用 $H$ 共 $n\approx\sqrt M$ 次。Eve 只看到 hash 值，$H$ 是 random function，要知道哪个 $X$ 对应那个 hash，只能自己一个个试，问了 $q$ 次猜中的 probability 是 $q/M$，要 $\Omega(M)$ 次。

这个 gap 只有平方：honest party 花 $T$，Eve 花 $T^2$。MIT 的 slide 引了 Merkle 当年的数字：$M=10^8$，每秒试 1000 次，两人各要 $10^4$ 次，10 秒；Eve 要 $10^8$ 次，$10^5$ 秒，约一天多。Eve 买一台快 100 倍的机器，就只要 17 分钟。Polynomial 的 adversary 可以是 $T^2$ 的，所以这在这门课的 definition 下不算 secure。需要的是 honest party polynomial、Eve exponential 的 gap，这要用数学结构。

### Public-key encryption 的 definition

Bob 生成一对 key：$(pk,sk)\leftarrow\mathsf{KeyGen}(1^\lambda)$，公开 $pk$。任何人用 $\mathsf{Enc}(pk,m)$ encrypt，只有 Bob 能用 $\mathsf{Dec}(sk,c)$ 解开。

**IND-CPA。** Challenger 生成 $(pk,sk)$，把 $pk$ 给 adversary；adversary 给出 $m_0,m_1$，得到 $\mathsf{Enc}(pk,m_b)$，猜 $b$。不需要单独的 encryption oracle：adversary 有 $pk$，自己就能 encrypt 任何东西。也正因为如此，PKE 必须是 randomized 的：deterministic 的话，adversary 自己算 $\mathsf{Enc}(pk,m_0)$ 和 challenge 比一下就赢了。

### Group 与 discrete log

需要的结构是 cyclic group。$\mathbb{Z}_p^*=\{1,\dots,p-1\}$ 在乘法 mod $p$ 下是 group，$p$ 是 prime 时它是 cyclic 的：存在 generator $g$，$g^0,g^1,\dots,g^{p-2}$ 恰好走遍所有 element。

拿 $p=23$。$5$ 的 order 是 22，是 $\mathbb{Z}_{23}^*$ 的 generator。$2$ 的 order 是 11：$2^0,\dots,2^{10}$ 依次是 1、2、4、8、16、9、18、13、3、6、12，然后 $2^{11}\equiv1$ 回到起点。这 11 个数恰好是 mod 23 的 quadratic residue（某个数的平方），它们自己构成一个 order 11 的 subgroup，记作 $\mathrm{QR}_{23}$。

**Exponentiation 很快。** $g^x$ 不用乘 $x$ 次：按 $x$ 的 binary 从高位到低位，每一位先 square，这一位是 1 再乘一次 $g$。

::fig[cs4230-sqmul] 算 $2^9\bmod23$，$9=1001_2$。外圈是 $2^i$ 的值，内圈是 exponent $i$。Square 让 exponent 翻倍，乘 $g$ 让 exponent 加 1。

$\lambda$ bit 的 exponent 只要 $\lambda$ 次 square 加最多 $\lambda$ 次乘法，每次乘法 $O(\lambda^2)$，总共 $O(\lambda^3)$。

**反方向难。** Discrete log（DL）问题：给 $g$ 和 $h=g^x$，求 $x$。DL assumption 说，随机取 $\lambda$ bit 的 prime $p$、generator $g$、$x\leftarrow\mathbb{Z}_{p-1}$，每个 PPT 的 $A$ 求出 $x$ 的 probability 是 negligible。

为什么一定要乘法 group？在加法 group $\mathbb{Z}_{23}$ 里，“$g^x$”是 $x\cdot g$。取 $g=5$、$h=18$：$5^{-1}\bmod23=14$（$5\times14=70=3\times23+1$），$x=18\times14=252\equiv22$，检验 $22\times5=110=4\times23+18$。Extended Euclid 一步就解完了，同样是 cyclic group，DL 的难度取决于 group 怎么表示。

DL 的 generic algorithm 是 baby-step giant-step，用 $O(\sqrt{|G|})$ 次运算：

::fig[cs4230-bsgs] 在 $\mathrm{QR}_{23}$ 里解 $2^x=18$。$m=\lceil\sqrt{11}\rceil=4$：先把 $2^0$ 到 $2^3$ 存表（baby steps），再从 18 出发每次乘 $2^{-4}=13$（giant steps），直到落进表里。

18 不在表里；$18\times13=234=10\times23+4$，4 在表里，$4=2^2$。退了 1 次 giant step，所以 $x=1\times4+2=6$，检验 $2^6=64=2\times23+18$。表有 $\sqrt{|G|}$ 项，giant step 最多 $\sqrt{|G|}$ 次。

$|G|=2^{256}$ 时这要 $2^{128}$ 次，够 secure；但 $\mathbb{Z}_p^*$ 有专门的 index calculus 和 number field sieve，running time 是 sub-exponential，所以 $\mathbb{Z}_p^*$ 的 $p$ 要 2048 bit 以上，而 elliptic curve group 上目前只有 generic 的 $\sqrt{|G|}$ attack，256 bit 就够。这就是实践中两种 parameter 大小差这么多的原因。

另一个要避免的是 $|G|$ 的 prime factor 都很小。Pohlig–Hellman 的办法是分别求 $x$ 模 $|G|$ 的每个 prime factor，再用 CRT 拼起来，代价只取决于最大的 prime factor $q$，是 $O(\sqrt q)$。下面 DDH 那一节就是它在 factor 2 上的一个实例。

**Random self-reduction。** DL assumption 只说 random 的 $x$ 难。会不会大部分 $x$ 难、但你关心的那个恰好容易？不会：设 $A$ 对 random 的 $h$ 以 probability $\varepsilon$ 求出 discrete log。给任意 $h=g^x$，随机取 $r$，问 $A(h\cdot g^r)$。$h\cdot g^r=g^{x+r}$，$x+r$ uniform，所以这是一个 random instance，$A$ 以 probability $\varepsilon$ 回答 $x+r$，减去 $r$ 得 $x$。答案可以用 $g^{\text{答案}}=h$ 检查，重复 $1/\varepsilon$ 次就几乎一定成功。所以 average case 难等价于 worst case 难。

由 DL 立刻得到 OWF：$f(p,g,x)=(p,g,g^x\bmod p)$。但 OWF 只够 secret-key 这一侧。

### Diffie–Hellman key exchange

公开 group 和 generator $g$。Alice 随机取 $a$，发 $A=g^a$；Bob 随机取 $b$，发 $B=g^b$。Alice 算 $B^a=g^{ab}$，Bob 算 $A^b=g^{ab}$，得到同一个 key。

::fig[cs4230-dh] 在 $\mathrm{QR}_{23}$（$g=2$，order 11）里完整走一遍。Eve 看到的是中间那一列。

逐步核对：$2^6=64\equiv18$；$2^9=512=22\times23+6$，得 6。Alice 算 $6^6=46656$，$46656=2028\times23+12$，得 12；Bob 算 $18^9\bmod23$，同样得 12。两边都是 $2^{54}$，exponent 在 order 11 的 group 里可以 mod 11，$54=4\times11+10$，$2^{10}=1024=44\times23+12$。

Eve 要从 $(g,g^a,g^b)$ 得到 $g^{ab}$。三个 assumption 由弱到强：

- **DL**：从 $g^a$ 求 $a$ 难；
- **CDH**（computational Diffie–Hellman）：从 $(g,g^a,g^b)$ 算出 $g^{ab}$ 难；
- **DDH**（decisional）：$(g,g^a,g^b,g^{ab})\approx_c(g,g^a,g^b,g^c)$，$c$ independent 且 random，即连 $g^{ab}$ 和一个 random element 都分不清。

能解 DL 就能解 CDH（求出 $a$ 再算 $B^a$），能解 CDH 就能解 DDH（算出 $g^{ab}$ 再比较），所以 DDH 是最强的 assumption。反方向都没有 proof。要把 $g^{ab}$ 直接当 key（当 one-time pad 用），需要的是 DDH：CDH 只保证 Eve 算不出整个 $g^{ab}$，不保证它的每个 bit 都藏得住。只有 CDH 时可以取 $g^{ab}$ 的一个 hardcore bit 当 pad。

### ElGamal encryption

把 Diffie–Hellman 改成 encryption：Bob 的 $g^x$ 一次性公开当 $pk$，Alice 每次 encrypt 时做她那一半。

- $\mathsf{KeyGen}$：$sk=x$，$pk=(G,g,h=g^x)$；
- $\mathsf{Enc}(pk,m)$，$m\in G$：随机取 $y$，输出 $(c_1,c_2)=(g^y,\ h^y\cdot m)$；
- $\mathsf{Dec}(sk,(c_1,c_2))$：$m=c_2\cdot(c_1^x)^{-1}$。

Correctness：$c_1^x=g^{xy}=h^y$，$c_2\cdot(c_1^x)^{-1}=g^{xy}m\cdot g^{-xy}=m$。

在 $\mathrm{QR}_{23}$ 里走一遍：$x=6$，$pk$ 里 $h=2^6=18$。encrypt $m=13$（$13=2^7$ 在 $\mathrm{QR}_{23}$ 里），取 $y=3$：

$$c_1=2^3=8,\qquad h^y=18^3=5832=253\times23+13,\qquad c_2=13\times13=169=7\times23+8$$

Ciphertext 是 $(8,8)$。decrypt：$c_1^x=8^6=262144\equiv13$（就是 $h^y$），$13^{-1}\equiv16$（$13\times16=208=9\times23+1$），$m=8\times16=128=5\times23+13$。

**CPA security（基于 DDH）。** Adversary 看到的是 $(g^x,g^y,g^{xy}m_b)$。一串 distribution：

$$(g^x,g^y,g^{xy}m_0)\ \approx_c\ (g^x,g^y,g^zm_0)\ \equiv\ (g^x,g^y,g^zm_1)\ \approx_c\ (g^x,g^y,g^{xy}m_1)$$

第一个和第三个 $\approx_c$ 是 DDH：能区分它们的 adversary，拿到 DDH 的 challenge $(g^x,g^y,T)$ 后把 $T\cdot m_0$ 当 $c_2$ 交给它，就区分了 $T=g^{xy}$ 和 $T=g^z$。中间的 $\equiv$ 是完全相等：$g^z$ 是 group 里 uniform 的 element，乘任何固定的 $m$ 仍是 uniform，这就是 group 上的 one-time pad。

### DDH 在整个 $\mathbb{Z}_p^*$ 里不成立

上面的例子用的是 $\mathrm{QR}_{23}$ 而不是整个 $\mathbb{Z}_{23}^*$，原因在这里。

::fig[cs4230-ddh] $\mathbb{Z}_{23}^*$ 的 22 个 element 按 $5^i$ 排成一圈。Exponent 是偶数的 11 个（深色）是 quadratic residue。

Euler's criterion：$z\in\mathbb{Z}_p^*$ 是 quadratic residue 当且仅当 $z^{(p-1)/2}\equiv1$。用 $g=5$ 检验：$5^2=25\equiv2$，$2^{11}=2048=89\times23+1$，是；$5^1=5$，$5^{11}\equiv22\equiv-1$，不是。所以任何人看 $g^a$ 都能算出 $a$ 的 parity，这就是 Pohlig–Hellman 在 factor 2 上的那一步。

$g^{ab}$ 是 QR 当且仅当 $ab$ 是偶数，当且仅当 $a$、$b$ 至少一个偶数，这能从 $g^a$、$g^b$ 判断出来。Distinguisher：拿到 $(g^a,g^b,T)$，检查“$T$ 是不是 QR”和“$a$、$b$ 是否至少一个偶数”是否一致，一致就输出 1。

- $T=g^{ab}$：永远一致，输出 1 的 probability 是 1；
- $T=g^c$ random：$T$ 是不是 QR 是一个 independent 的 ½，一致的 probability 是 ½。

Advantage $\tfrac12$。ElGamal 在 $\mathbb{Z}_p^*$ 里因此不 CPA-secure：选 $m_0$ 是 QR、$m_1$ 不是，从 $pk=g^x$ 和 $c_1=g^y$ 得知 $g^{xy}$ 是不是 QR，再看 $c_2$ 是不是 QR，就知道 $m$ 是不是。

修法：用 safe prime $p=2q+1$（$q$ 也是 prime），只在 order $q$ 的 subgroup $\mathrm{QR}_p$ 里工作。$23=2\times11+1$ 就是 safe prime，$\mathrm{QR}_{23}$ 的 order 11 是 prime，没有可以利用的小 factor。

:::wrong CDH 难，所以 DDH 也难
$\mathbb{Z}_p^*$ 就是反例：那里 CDH 被认为是难的（算不出 $g^{ab}$），DDH 却以 advantage ½ 被破。判断一个 element“是不是 $g^{ab}$”可以只靠它的部分信息（这里是 QR 与否），而算出它要全部信息。所以 ElGamal 的 proof 要求的是 DDH，选 group 时要专门检查 DDH。
:::

:::edge Message 不在 subgroup 里
在 $\mathrm{QR}_{23}$ 里用 ElGamal，$m$ 也必须在 $\mathrm{QR}_{23}$ 里。如果把 $m=5$（不是 QR）直接拿来 encrypt，$c_2=h^y\cdot5$ 也不是 QR，任何人用 Euler's criterion 就知道 $m$ 不是 QR。实际系统要先把 message 编码进 subgroup。
:::

## [tdp] Trapdoor permutation：RSA、Rabin 与 quadratic residuosity

:::skip
能用 TDP 加 hardcore bit 构造 PKE，能用 CRT 在 mod 77 里求 square root 并由两个不同的 root 分解 77，能手算一次 Goldwasser–Micali，就可以去第 7 站。
:::

### Trapdoor permutation

ElGamal 的构造依赖一个具体的 group。另一条路更通用：找一个 permutation，正着算谁都会，反着算只有掌握 trapdoor 的人会。

**Definition。** Trapdoor permutation（TDP）是三个 algorithm：$\mathsf{Gen}(1^\lambda)\to(k,t)$ 给出公开的 evaluation key $k$ 和 trapdoor $t$；$f_k(x)$ 可以 efficient 地计算，是 domain $D_k$ 上的 permutation；有 $t$ 就能 efficient 地 invert；没有 $t$ 时对每个 PPT 的 $A$，$\Pr_{x\leftarrow D_k}[f_k(A(k,f_k(x)))=f_k(x)]$ 是 negligible。

最直接的 PKE 是 $c=f_k(m)$，但它是 deterministic 的，上一站说过不可能 CPA-secure。正确的做法是 encrypt 一个 bit $m$：

- $\mathsf{Enc}(pk=k,m)$：随机取 $x\in D_k$，输出 $(f_k(x),\ h_k(x)\oplus m)$，$h_k$ 是 $f_k$ 的 hardcore predicate（Goldreich–Levin 保证有）；
- $\mathsf{Dec}(sk=t,(y,c))$：用 $t$ 算 $x=f_k^{-1}(y)$，输出 $h_k(x)\oplus c$。

**Proof。** $\mathsf{Enc}(0)=(k,f_k(x),h_k(x))$。第 4 站的 OWP 加 HCP 推出 PRG 说明 $(f_k(x),h_k(x))\approx_c(R_1,R_2)$，$R_1$ random，$R_2$ 是 random bit。$R_2\oplus0$ 和 $R_2\oplus1$ 分布相同，所以

$$(k,\mathsf{Enc}(0))\approx_c(k,R_1,R_2\oplus0)\equiv(k,R_1,R_2\oplus1)\approx_c(k,\mathsf{Enc}(1))$$

### RSA

$N=pq$，取 $e$ 与 $\varphi(N)=(p-1)(q-1)$ coprime，$d=e^{-1}\bmod\varphi(N)$。$f(x)=x^e\bmod N$，trapdoor 是 $d$：$(x^e)^d=x^{1+j\varphi(N)}=x\cdot(x^{\varphi(N)})^j=x$，因为 Euler theorem 给出 $x^{\varphi(N)}\equiv1$。[CS2105 第 8 站](../courses/CS2105.html#sec)用 $N=35$、$e=5$、$d=29$ 把 encrypt 和 decrypt 和 square-and-multiply 完整走过一遍，这里接着用这组数。

$f$ 确实是 $\mathbb{Z}_{35}^*$ 上的 permutation：$\mathbb{Z}_{35}^*$ 有 $\varphi(35)=24$ 个 element，把 24 个 element 都 5 次方 mod 35，得到的恰好还是这 24 个 element，没有重复。

**RSA assumption**：给 $(N,e,x^e)$，求 $x$ 难。会 factoring 就能破 RSA：知道 $p,q$ 就能算 $\varphi(N)$ 和 $d$。知道 $\varphi(N)$ 也等于知道 factoring：$\varphi(N)=N-(p+q)+1$，所以 $p+q=N-\varphi(N)+1$；对 $N=35$、$\varphi=24$ 得 $p+q=12$，$p,q$ 是 $t^2-12t+35=0$ 的两个 root，即 5 和 7。

**Textbook RSA** 指直接用 $c=m^e$ encrypt，它有两个毛病。一是 deterministic。二是 malleable：$(m^e)(s^e)=(ms)^e$，Eve 把 $c$ 乘上 $s^e$，Bob 解出 $ms$。用数字：$m=12$ encrypt 成 $c=17$；Eve 算 $17\times2^5=544=15\times35+19$，发出 19；Bob 算 $19^{29}\bmod35=24=2\times12$。

:::wrong 破解 RSA 和 factoring 是同一个问题
已知的只有一个方向：factoring 容易 ⇒ RSA 容易。反方向是公开问题：可能存在不分解 $N$ 就能开 $e$ 次方的办法。所以 RSA assumption 可能比 factoring 更强（更容易被破）。下面的 Rabin function 是另一回事，它的 invert 被 **prove** 和 factoring 一样难。
:::

### Rabin：square mod $N$

取 prime $p\ne q$，都 $\equiv3\pmod4$，$N=pq$。$f_N(x)=x^2\bmod N$，trapdoor 是 $(p,q)$。

Square 不是 $\mathbb{Z}_N^*$ 上的 permutation，因为 $x$ 和 $-x$ 平方相同。要看清它的结构，用 CRT：$\mathbb{Z}_N$ 的每个 element 对应一对 $(x\bmod p,\ x\bmod q)$，乘法在两个 coordinate 上分别做。

::fig[cs4230-rabin] $N=77=7\times11$，按 CRT 排成 7 行 11 列：第 $a$ 行第 $b$ 列的数 $z$ 满足 $z\equiv a\pmod7$、$z\equiv b\pmod{11}$。第 0 行和第 0 列（画成 · 的格子）不在 $\mathbb{Z}_{77}^*$ 里，浅色是 $\mathrm{QR}_{77}$。

**求 square root。** 对 $p\equiv3\pmod4$ 和 QR $y$，$\big(y^{(p+1)/4}\big)^2=y^{(p+1)/2}=y\cdot y^{(p-1)/2}=y$，最后一步是 Euler's criterion。所以 mod $p$ 的 square root 是 $\pm y^{(p+1)/4}$，一次 exponentiation。

拿 $y=23$：$23\bmod7=2$，root 是 $2^{(7+1)/4}=2^2=4$，检验 $4^2=16\equiv2\pmod7$；$23\bmod11=1$，root 是 $1^3=1$。所以 mod 77 的 root 是 CRT 下的 $(\pm4,\pm1)$，四个：

| CRT | $(4,1)$ | $(4,-1)$ | $(-4,1)$ | $(-4,-1)$ |
|---|---|---|---|---|
| mod 77 | 67 | 32 | 45 | 10 |

检验 $10^2=100=77+23$。

**为什么四个 root 里恰好一个是 QR。** 对 $p\equiv3\pmod4$，$(p-1)/2$ 是奇数。设 $x=g^a$，则 $-x=g^{a+(p-1)/2}$，两个 exponent 一奇一偶，所以 $x$ 和 $-x$ 恰好一个是 QR。在 CRT 的每个 coordinate 上各有一种 sign 是 QR，$\mathrm{QR}_N$ 的 element 要两个 coordinate 都是 QR，四种组合里恰好一种。图里是 $67=(4,1)$：$4$ mod 7 是 QR，$1$ mod 11 是 QR。所以 $f_N$ 限制在 $\mathrm{QR}_N$（$\varphi(77)/4=15$ 个 element）上是 permutation。

**两个不同的 root 推出 factoring。** 若 $x^2\equiv z^2\pmod N$ 且 $x\ne\pm z$，那么 $N\mid(x-z)(x+z)$，但 $N$ 不整除任何一个 factor，所以 $\gcd(x+z,N)$ 是 $N$ 的 nontrivial factor。$x=10$、$z=32$：$\gcd(42,77)=7$，$\gcd(-22,77)=11$。

**Invert Rabin 和 factoring 一样难。** 设 $A$ 能求 square root。随机取 $x\in\mathbb{Z}_N^*$，把 $y=x^2$ 给 $A$，得到 root $z$。$A$ 只看到 $y$，而 $y$ 的四个 root 里 $x$ 是哪一个对 $A$ 完全隐藏，所以 $z\notin\{x,-x\}$ 的 probability 恰好 ½，这时 $\gcd(x+z,N)$ 就分解了 $N$。

### Quadratic residuosity 与 Goldwasser–Micali

Mod prime 判断 QR 容易（Euler's criterion）。Mod $N=pq$ 时，$z$ 是 QR 当且仅当它 mod $p$ 和 mod $q$ 都是 QR。不知道 $p,q$ 时能算的只有 Jacobi symbol $\big(\tfrac zN\big)=\big(\tfrac zp\big)\big(\tfrac zq\big)$，它对“两边都是 QR”和“两边都不是 QR”都给出 $+1$，分不开这两种。**Quadratic residuosity assumption（QRA）**：只给 $N$，分不清 random 的 QR 和 Jacobi symbol 为 $+1$ 的 random non-QR。

**Goldwasser–Micali**（第一个被 prove CPA-secure 的 PKE）：

- $pk=(N,x)$，$x$ 是一个 Jacobi symbol 为 $+1$ 的 non-QR；$sk=(p,q)$；
- $\mathsf{Enc}(b)$：随机取 $r\in\mathbb{Z}_N^*$，输出 $c=x^b r^2\bmod N$；
- $\mathsf{Dec}(c)$：$c$ mod $p$ 是 QR 就输出 0，否则输出 1。

$N=77$，取 $x=6$：$6\bmod7=6$，$6^3=216=30\times7+6\equiv-1$，不是 QR；$6\bmod11=6$，$6^5=7776=706\times11+10\equiv-1$，不是 QR；所以 Jacobi symbol 是 $(-1)(-1)=+1$，看起来和 QR 一样。

- $\mathsf{Enc}(0)$，$r=9$：$c=81\equiv4$。$4\bmod7=4$，$4^3=64\equiv1$，QR，解出 0。
- $\mathsf{Enc}(1)$，$r=9$：$c=6\times81=486=6\times77+24$，$c=24$。$24\bmod7=3$，$3^3=27\equiv6\equiv-1$，不是 QR，解出 1。

Security 直接就是 QRA：$\mathsf{Enc}(0)$ 是 random QR，$\mathsf{Enc}(1)=x r^2$ 是 random 的 Jacobi $+1$ non-QR，能区分两者就破了 QRA。

GM 还有一个性质：两个 ciphertext 相乘，$x^{b}r^2\cdot x^{b'}r'^2=x^{b+b'}(rr')^2$，$x^2$ 是 QR 可以并进平方里，所以得到 $b\oplus b'$ 的 ciphertext。数字：$4\times24=96\equiv19$，$19\bmod7=5$，$5^3=125=17\times7+6\equiv-1$，解出 $1=0\oplus1$。不 decrypt 就能在 ciphertext 上算 XOR，这叫 homomorphic，第 11 站会再遇到。

:::edge $x$ 碰巧和 $N$ 不 coprime
TDP 的 domain 是 $\mathbb{Z}_N^*$。随机取 $x\in\mathbb{Z}_N$ 落在 $\mathbb{Z}_N^*$ 外的 probability 是 $1-\varphi(N)/N=(p+q-1)/N$，对 $N=77$ 是 $17/77$，很大；对 1024 bit 的 $p,q$ 约是 $2^{-1023}$，negligible。万一真的碰上，$\gcd(x,N)$ 就分解了 $N$。
:::

:::from
TDP 的 definition、naive $c=f(m)$ 不行、$(f_k(x),h_k(x)\oplus m)$ 的构造与 proof 链、RSA 的 definition、RSA assumption 不知是否等价于 factoring、Rabin 的全部论证（$(p+1)/4$ 次方求 root、$p\equiv3\pmod4$ 时 $x$ 与 $-x$ 恰一个是 QR、$|\mathrm{QR}_N|=\varphi(N)/4$、两个 root 分解 $N$、invert 等价于 factoring），来自 [Rahul Jain 讲义第 7 讲](https://www.comp.nus.edu.sg/~rahul/lecture-notes/CS4230-5430-lecture-notes.pdf)（讲义的 Rabin 例子是 $N=77$ 里 4 的四个 root，这里换成 23 以便画 CRT 网格）。Jacobi symbol、QRA、Goldwasser–Micali 和它的 XOR homomorphism、RSA 的 hardcore bit 来自 [MIT 6.875 第 10 讲](https://mit6875.github.io/FA22SLIDES/lec10.pdf)。$\varphi(N)$ 推出 factoring、textbook RSA 的数值、GM 的数值是这一页实算的。

## [cca] MAC 与 CCA security

:::skip
能写出 EUF-CMA game、知道 PRF 就是 MAC、给出 CBC-MAC 的 variable-length forgery，能 prove encrypt-then-MAC 是 CCA-secure 的，就可以去第 8 站。
:::

### Encryption 挡不住篡改

开头第二次失败：到目前为止的每一种 encryption 都是“$c=\text{pad}\oplus m$”的形状（PRG encryption、PRF encryption 的第二部分、one-time pad），翻 $c$ 的一个 bit 就翻 $m$ 的同一个 bit。这叫 malleability。Privacy 和 integrity 是两件不同的事，需要另一个 primitive。

### MAC

Message authentication code 是三个 algorithm：$\mathsf{Gen}(1^\lambda)\to k$；$\mathsf{MAC}(k,m)\to t$（tag）；$\mathsf{Verify}(k,m,t)\to$ accept/reject。Alice 发 $(m,t)$，Bob 用共享的 $k$ 检查。

Adversary 能看到很多合法的 $(m,t)$，甚至能让 Alice 给她选的 message 算 tag（chosen-message attack）。攻破的程度有三种：找出 key（total break）、能给任意 message 造 tag（universal forgery）、能给**某一个**新 message 造 tag（existential forgery）。要防的是最弱的那种。

**EUF-CMA game。** Challenger 取 $k$；adversary 问 polynomial 次 $m_i$，得到 $t_i=\mathsf{MAC}(k,m_i)$；最后输出 $(m',t')$。$\mathsf{Verify}(k,m',t')=1$ 且 $(m',t')$ 不是问过的某一对，就算赢。要求赢的 probability 是 negligible。

**PRF 就是 MAC：$t=f_k(m)$。** Proof：设 $A$ 以 $\ge1/p$ 赢。造 PRF game 的 adversary $B$：替 $A$ 回答 tag 查询时去问自己的 oracle $f$；$A$ 输出 $(m',t')$ 后，$B$ 再问一次 $f(m')$，相等就猜“PRF”，否则随机猜。

- $f=f_k$ 时 $A$ 处在真正的 EUF-CMA game 里，$f(m')=t'$ 的 probability $\ge1/p$；
- $f$ 是真 random function 时，$m'$ 没被问过，$f(m')$ 对 $A$ 是一个全新的 uniform 的 $m$ bit string，$A$ 猜中的 probability 是 $2^{-m}$。

两种情况下 $B$ 的行为差别是 $1/p-2^{-m}$ 量级，不是 negligible，矛盾。

MAC 不需要 randomized：同一个 $m$ 永远得到同一个 tag 没有问题，tag 不需要隐藏 $m$。

### 长 message

PRF 的 input 是固定长度（比如 128 bit）。长 message 切成 block $m=m_1\|\cdots\|m_L$。几种看起来合理的拼法，MIT 的 slide 一个个拆：

1. $t=f_k(m_1\oplus\cdots\oplus m_L)$：任何 XOR 相同的 message 有相同的 tag。问 $m_1\|m_2$ 的 tag，它也是 $m_2\|m_1$ 的 tag。
2. $t=f_k(m_1)\oplus\cdots\oplus f_k(m_L)$：XOR 与顺序无关，同样把 block 调换顺序就是 forge。
3. $t=\bigoplus_if_k(\langle i\rangle\|m_i)$，把位置编进去：问 $a_1\|a_2$、$a_1\|b_2$、$b_1\|a_2$ 三个 tag，XOR 起来，$f_k(\langle1\rangle\|a_1)$ 和 $f_k(\langle2\rangle\|a_2)$ 各出现两次抵消，剩下 $f_k(\langle1\rangle\|b_1)\oplus f_k(\langle2\rangle\|b_2)$，正是没问过的 $b_1\|b_2$ 的 tag。

**CBC-MAC** 是把 block 串起来：$t_0=0^\lambda$，$t_i=f_k(m_i\oplus t_{i-1})$，tag 是最后的 $t_L$。只要所有 message 的 block 数都固定为同一个 $L$，它就是 secure 的 MAC。一旦允许不同长度：

::fig[cs4230-cbcmac] 问一个 block 的 $m$，得到 $t=f_k(m)$。两个 block 的 $m\,\|\,(t\oplus m)$ 从没问过，可它在 CBC-MAC 下的 tag 也是 $t$。

逐步核对：第一个 block 得 $t_1=f_k(m\oplus0)=t$；第二个 block 进 $f_k$ 之前是 $(t\oplus m)\oplus t_1=(t\oplus m)\oplus t=m$，所以 $t_2=f_k(m)=t$。Tag 的值同时又被当作下一步的 chaining value，attacker 知道 chaining value，就能把它抵消掉。修法 ECBC-MAC：最后再用一个 independent 的 key 过一次 PRF，$t=f_{k_2}(\text{CBC-MAC}_{k_1}(m))$，外人看到的 tag 不再是内部的 chaining value。

还有一件 EUF-CMA 不管的事：Eve 可以把一个旧的合法 $(m,t)$ 原样再发一次（replay）。这不算“新的 pair”，game 不把它算作攻破。实际系统要在 $m$ 里加上 timestamp 或 sequence number。

### CCA security

现在让 adversary 更强：她还能让 Bob decrypt 她构造的 ciphertext，看到 decryption 的结果（真实情况里，服务器对不合法的 ciphertext 返回什么错误，就泄露了 decryption 的一部分）。

**IND-CCA2 game。** 和 CPA 一样，另外 adversary 在 challenge 前后都能问 decryption oracle，唯一的限制是不能问 challenge $c^*$ 本身。（只允许在 challenge 之前问的叫 CCA1。）

PRF encryption 在 CCA 下立刻被破：

::fig[cs4230-cca] Adversary 不能问 challenge 本身，就把 challenge 的最后一位翻转后去问。

$c^*=(r,f_k(r)\oplus m_b)$，她问 $(r,c\oplus0001)$，这不是 $c^*$，合法；decrypt 得 $f_k(r)\oplus f_k(r)\oplus m_b\oplus0001=m_b\oplus0001$。$m_0=0000$ 时得到 0001，$m_1=1111$ 时得到 1110，赢的 probability 是 1。CPA-secure 的 scheme 只要 malleable，在 CCA 下就失败。

### Encrypt-then-MAC

两把 independent 的 key $k_1,k_2$。$\mathsf{Enc}$：$c=\mathsf{Enc}_{\text{CPA}}(k_1,m)$，$t=\mathsf{MAC}(k_2,c)$，输出 $(c,t)$。$\mathsf{Dec}$：先 verify，不通过就输出 $\bot$，通过再 decrypt。

直觉：decryption oracle 变得没用，因为 adversary 能交上去的 ciphertext，要么是她之前从 encryption oracle 拿到的（她已经知道 plaintext），要么 tag 是她 forge 的（不可能成功）。

**Theorem。** $\mathsf{Enc}_{\text{CPA}}$ CPA-secure、MAC EUF-CMA-secure，则 encrypt-then-MAC CCA-secure。

**Proof。** 设 $A$ 以 $\tfrac12+1/p$ 赢 CCA game。令 $E$ 为事件“$A$ 交给 decryption oracle 的某个新的 $(\hat c,\hat t)$ 通过了 verify”。

- **$\Pr[E]$ 不是 negligible。** 造 MAC 的 forger $B$：$B$ 自己取 $k_1$，MAC 用 MAC game 的 oracle，替 $A$ 回答所有查询；$A$ 每交一个 decryption query，$B$ 就把它当作候选 forgery。$E$ 发生时其中有一个是成功的 forgery（$B$ 随机挑一个查询输出，只损失一个查询次数的 factor）。与 MAC 的 security 矛盾。
- **$\Pr[E]$ 是 negligible。** 造 CPA 的 adversary $D$：$D$ 自己取 $k_2$，encryption 查询转给 CPA 的 encryption oracle 再自己加 tag，decryption query 一律回答 $\bot$（问的是之前 encrypt 过的，就回答当时的 plaintext）。$E$ 不发生时，真实的 decryption oracle 也会对所有新的 query 回答 $\bot$，$D$ 的模拟和真的完全一样。所以

$$\Pr[D\text{ 赢}]\ge\Pr[A\text{ 赢}\wedge\bar E]\ge\Pr[A\text{ 赢}]-\Pr[E]\ge\tfrac12+\frac1p-\mathrm{negl}$$

第二个不等号是 $\Pr[X]\le\Pr[X\wedge\bar E]+\Pr[E]$。与 CPA security 矛盾。

:::wrong 对 plaintext 算 MAC 就行：发送 $(\mathsf{Enc}(m),\mathsf{MAC}(m))$
这叫 encrypt-and-MAC。MAC 的 definition 只要求造不出 tag，从没要求 tag 隐藏 $m$。最常用的 MAC（PRF）是 deterministic 的：同一个 $m$ 两次发送，tag 完全相同，Eve 一看就知道两条 message 一样，CPA 的 adversary 问一次 $m_0$ 的 ciphertext、和 challenge 的 tag 比较就赢了。更极端地，$\mathsf{MAC}'(k,m)=\mathsf{MAC}(k,m)\,\|\,m_1$（附上 $m$ 的第一位）仍然 EUF-CMA-secure，却直接泄露 $m_1$。对 ciphertext 算 MAC 就没有这个问题：$c$ 本来就是公开的。
:::

Public key 一侧同样有 CCA。ElGamal 也是 malleable 的：上一站的 ciphertext $(8,8)$ encrypt 的是 13，把 $c_2$ 乘 2 得到 $(8,16)$，decrypt 得 $16\times16=256=11\times23+3$，而 $2\times13=26\equiv3$。所以 ElGamal 不 CCA-secure。Public key 下不能用 MAC 修，因为 encrypt 的人没有共享的 key；Cramer–Shoup 在 DDH 下给出了 CCA-secure 的 PKE，Naor–Yung 从任意 CPA-secure PKE 加上第 10 站的 zero-knowledge proof 得到 CCA1。这两个构造讲义只提了名字，这里也不展开。

:::from

## [sig] Digital signature、random oracle 与 hash

:::skip
能对 textbook RSA signature 做两种 forgery，能写出 FDH 的 reduction 和 $1/q$ 的来历，能从 DL hash 的 collision 解出 discrete log，就可以去第 9 站。

### 为什么 MAC 不够

MAC 的 verify 要用 $k$，能 verify 的人就能造 tag。一份软件更新要让一百万台机器都能验证，就得把 $k$ 发给一百万台机器，任何一台都能 forge。需要的是 public key 版本：只有 $sk$ 能 sign，$vk$ 公开，谁都能验。

**Definition。** $\mathsf{KeyGen}\to(sk,vk)$，$\mathsf{Sign}(sk,m)\to\sigma$，$\mathsf{Verify}(vk,m,\sigma)\to\{0,1\}$。EUF-CMA 和 MAC 一样，只是 adversary 一开始就拿到 $vk$。

### Textbook RSA signature

最直接的做法：$\sigma=m^d\bmod N$，验证 $\sigma^e\equiv m$。还是 $N=35$、$e=5$、$d=29$。

**No-message forgery。** 不需要看任何 signature：先随便取 $\sigma=3$，再算 $m=\sigma^e=3^5=243=6\times35+33$。$(33,3)$ 是合法的 pair：$3^5\equiv33$。attacker 控制不了 $m$ 是什么，但 existential forgery 本来就不要求。

**Multiplicative forgery。** $(m_1m_2)^d=m_1^dm_2^d$。问到 $\sigma(2)=2^{29}\bmod35=32$ 和 $\sigma(12)=12^{29}\bmod35=17$，相乘 $32\times17=544\equiv19$，这就是 $24=2\times12$ 的 signature：$19^5\bmod35=24$。

两个毛病：$m$ 可以从 $\sigma$ 倒推出来，而且 algebra 结构让 signature 可以组合。

### Hash-and-sign 与 random oracle

先 hash 再 sign：$\sigma=H(m)^d$。No-message forgery 现在要找一个 $m$ 使 $H(m)=\sigma^e$，要 invert $H$；multiplicative forgery 要 $H(m_3)=H(m_1)H(m_2)$，要 $H$ 没有 algebra 结构。

这两条要求很难用标准的 assumption 写出来。**Random oracle model（ROM）** 的做法是把 $H$ 理想化成一个公开的真 random function：所有人（包括 adversary）只能通过查询得到 $H(x)$，每个新的 $x$ 得到一个 fresh 的 uniform 值，重复的 $x$ 得到相同的值。实践里拿 SHA-256、SHA-3 代替，这是 heuristic：没有 proof 说明真实的 hash 像 random function，但对 RSA 加 SHA-3 这类用法没有已知的 attack。

**Full-domain hash（FDH）。** TDP $f$ 加 random oracle $H$（output 落在 $f$ 的整个 domain 上）：$\mathsf{Sign}(t,m)=f^{-1}(H(m))$，$\mathsf{Verify}(k,m,\sigma)$：检查 $f(\sigma)=H(m)$。

**Theorem。** $f$ 是 TDP，则 FDH 在 ROM 里 EUF-CMA-secure。

**Proof。** 设 $A$ 以 $\varepsilon$ forge，最多问 $q$ 次 $H$（不妨设 signature 查询和最后的 forgery 都事先问过 $H$，不重复）。造 $B$：收到 $k$ 和 challenge $y$，要求出 $f^{-1}(y)$。$B$ 替 $A$ 扮演 random oracle，事先随机猜一个 $j^*\in[q]$：

::fig[cs4230-fdh] $B$ 怎样回答 $A$ 的 $q$ 次 hash 查询。只有第 $j^*$ 行的 preimage $B$ 不知道。

- 第 $j\ne j^*$ 次查询 $z_j$：$B$ 随机取 $x_j$，回答 $H(z_j)=f(x_j)$，记下 $x_j$；
- 第 $j^*$ 次：回答 $H(z_{j^*})=y$；
- signature 查询 $z_j$（$j\ne j^*$）：回答 $x_j$，确实 $f(x_j)=H(z_j)$；若 $A$ 要 sign $z_{j^*}$，$B$ 放弃；
- $A$ 最后输出 $(m,\sigma)$：若 $m=z_{j^*}$，则 $f(\sigma)=H(m)=y$，$\sigma$ 就是答案。

$f$ 是 permutation、$x_j$ uniform，所以 $f(x_j)$ uniform；$y=f(x)$ 对 random $x$ 也 uniform。$A$ 看到的 hash 值全是 independent、uniform 的，和真 random oracle 一样，看不出哪一行特殊。$A$ forge 的 $m$ 一定是某个 $z_j$，等于 $z_{j^*}$ 的 probability 是 $1/q$（此时 $A$ 也不会去要 $z_{j^*}$ 的 signature，否则就不算新的 forgery）。所以

$$\Pr[B\text{ 成功}]=\frac1q\sum_{j=1}^q\Pr[A\text{ 赢且 }m=z_j]=\frac\varepsilon q$$

$q$ 是 polynomial，$\varepsilon/q$ 不是 negligible。这里用到了 ROM 的一个能力：reduction 可以自己决定 random oracle 的答案（programming），把 challenge 埋进去。真实的 SHA-256 不给人这种能力，这是 ROM 的 proof 和标准的 proof 的根本区别。

:::wrong Signature 就是用 private key encrypt message 的 hash
这个说法只对 RSA 碰巧成立，因为 RSA 的 encryption 和 decryption 是同一个运算 $x\mapsto x^{\text{exponent}}$。Signature 和 encryption 的 secure 目标不同：encryption 要隐藏 $m$，signature 根本不隐藏 $m$（$m$ 明文发送），要防的是 forge。按“用 $sk$ encrypt”的思路用 ElGamal 去 sign，没有任何意义：ElGamal 用 $pk$ encrypt、$sk$ decrypt，“用 $sk$ encrypt”不是一个 well-defined 的 operation。Schnorr、DSA 这些 signature 都不是“反过来的 encryption”。
:::

### Collision-resistant hash

Hash-and-sign 里如果 Eve 能找到 $m\ne m'$ 使 $H(m)=H(m')$，她让 Alice sign $m$，signature 对 $m'$ 也有效。

**Definition。** Hash family $h_k:\{0,1\}^n\to\{0,1\}^m$，$m<n$（压缩），对每个 PPT 的 $A$：$\Pr_k[A(k)\text{ 输出 }x\ne y,\ h_k(x)=h_k(y)]$ 是 negligible。$k$ 是公开的，只是随机选的，作用是不让 adversary 事先把 collision 写进代码里。

**从 DL 造。** Prime order $q$ 的 group，$k=(g,h=g^x)$，$x$ 没人知道。$H(y_0,y_1)=g^{y_0}h^{y_1}$，两个 $\mathbb{Z}_q$ 的 element 压成一个 group element，大约压缩一半。

若 $(y_0,y_1)\ne(z_0,z_1)$ 是 collision：$g^{y_0+xy_1}=g^{z_0+xz_1}$，所以 $y_0+xy_1\equiv z_0+xz_1\pmod q$。$y_1=z_1$ 会推出 $y_0=z_0$，不可能；所以 $y_1\ne z_1$，

$$x=\frac{z_0-y_0}{y_1-z_1}\bmod q$$

$q$ 是 prime，分母可逆。找到 collision 就解了 DL。

在 $\mathrm{QR}_{23}$ 里试：$g=2$，$h=2^7=13$。$H(1,0)=2$；$H(2,3)=4\times13^3$，$13^3=2197=95\times23+12$，$4\times12=48=2\times23+2$。Collision！代进 formula：$x=(2-1)/(0-3)=1\times(-3)^{-1}=8^{-1}\bmod11=7$（$8\times7=56=5\times11+1$），确实 $h=2^7$。

### Birthday bound

Hash 的 output 有 $N=2^m$ 种。随机找 collision 要试多少次？$q$ 个 random 的 output 全都不同的 probability 是

$$\prod_{i=1}^{q-1}\Big(1-\frac iN\Big)\le\prod_{i=1}^{q-1}e^{-i/N}=e^{-q(q-1)/2N}$$

（用 $1-u\le e^{-u}$）。$q$ 远小于 $N$ 时这个 bound 很紧，所以至少一个 collision 的 probability 约是 $1-e^{-q^2/2N}$。

::fig[cs4230-birthday] 横轴是 $q/\sqrt N$。$q\approx1.18\sqrt N$ 时 collision 的 probability 过半。

令 $1-e^{-q^2/2N}=\tfrac12$，$q^2/2N=\ln2$，$q=\sqrt{2\ln2}\sqrt N\approx1.177\sqrt N$。所以 $m$ bit 的 hash 只有 $m/2$ bit 的 collision security：要 128 bit 的 security，output 要 256 bit。第 3 站 PRF encryption 里 $r$ 的 collision 项和 [IS4302 第 1 站](../courses/IS4302.html#hash)里 SHA-256 的 $2^{128}$ 都是同一个 bound。

:::edge Random oracle 在现实中不存在
ROM 里的 proof 说的是“如果 $H$ 像 random function”。已知有（人为构造的）scheme 在 ROM 里可证 secure，但换成任何一个具体的 hash 都 insecure（Canetti、Goldreich、Halevi）。这条我是凭自己的知识写的，没有在这次读的材料里核对。实际意义是：ROM 的 proof 排除了“只把 $H$ 当黑箱用”的 attack，但不是完整的保证。
:::

:::from
Signature 的 definition 与 EUF-CMA、ROM 的描述、FDH 的构造与 proof（随机猜 $j^*$、把 $y$ 埋进去、$\frac1q\sum_j$ 的计算）、naive “$\sigma$ 是 $m$ 的 preimage”被反过来构造的 attack、CRHF 的 definition 与 DL hash 的 proof，来自 [Rahul Jain 讲义第 9 讲](https://www.comp.nus.edu.sg/~rahul/lecture-notes/CS4230-5430-lecture-notes.pdf)。Textbook RSA signature 的两种 attack、hash-and-sign 对 $H$ 的两条要求、random oracle heuristic 与 SHA-3 的说明来自 [MIT 6.875 第 13 讲](https://mit6875.github.io/FA22SLIDES/lec13.pdf)。MAC 不够的理由、birthday bound 的推导、$N=35$ 和 $\mathrm{QR}_{23}$ 的数字、“signature 就是用 $sk$ encrypt”的辨析是这一页补的；Canetti–Goldreich–Halevi 那条见上面的说明。
:::

## [mpc] Secret sharing 与 secure computation

:::skip

### 三个人算 XOR

三个人各有一个 bit $a,b,c$，想知道 $a\oplus b\oplus c$，但谁都不想让别人知道自己的 bit。讲义的第一个办法：$P_a$ 取 random $r$，把 $a\oplus r$ 交给 $P_b$；$P_b$ 把 $a\oplus r\oplus b$ 交给 $P_c$；$P_c$ 把 $a\oplus r\oplus b\oplus c$ 交回 $P_a$；$P_a$ XOR 上 $r$ 得到结果。每个人收到的都是被 $r$ 盖住的值。

但 $P_a$ 和 $P_c$ 联手就能算出 $b$：$P_c$ 收到 $a\oplus r\oplus b$，$P_a$ 知道 $a$ 和 $r$。所以 security 必须说清楚“最多几个人勾结”。

**Definition（semi-honest，perfect）。** Party $P_i$ 的 view 是它的 input、它的 randomness 和它收发的所有 message。Protocol 对最多 $t$ 个勾结的 party secure，如果存在 simulator $\mathsf{Sim}$，对每个 $|S|\le t$ 的 party set，只给它们的 input 和 output，就能生成和真实 view 分布完全相同的东西：

$$\mathsf{Sim}\big(\{x_i\}_{i\in S},\,f(x)\big)\equiv\mathrm{View}_S$$

意思是：它们从 protocol 里看到的一切，都能从“自己的 input 加最终结果”凭空造出来，所以没有多学到任何东西。Semi-honest 指它们按 protocol 做，只是事后翻看 view。

### Shamir secret sharing

想把一个 secret $s$ 分给 $n$ 个人，任意 $t$ 个人能还原，少于 $t$ 个人什么都不知道。

**Interpolation。** 过 $d+1$ 个 $x$ 坐标不同的点，恰好有一个 degree $\le d$ 的 polynomial。存在性：Lagrange 的 $\ell_j(x)=\prod_{i\ne j}\frac{x-x_i}{x_j-x_i}$ 在 $x_j$ 处为 1、在其他 $x_i$ 处为 0，$\sum_jy_j\ell_j(x)$ 就过所有点。唯一性：两个这样的 polynomial 之差 degree $\le d$，却有 $d+1$ 个 root，只能是 0。Mod prime $p$ 时这些全部照样成立，因为每个非零的数都能除。

**Scheme。** Secret $s\in\mathbb{Z}_p$（$p>n$），随机取 degree $t-1$ 的 $f(x)=s+a_1x+\cdots+a_{t-1}x^{t-1}$，第 $i$ 个人得到 $(i,f(i))$。

::fig[cs4230-shamir] 左边是 Joy of Cryptography 的例子：实数上过 $(3,1)$、$(4,1)$、$(5,9)$、$(2,6)$ 的唯一 cubic $\tfrac12x^3-2x^2-\tfrac92x+19$。右边是 mod 11 的 3-out-of-5：$s=7$，$f(x)=x^2+4x+7$。

右边的 share：$f(1)=12\equiv1$，$f(2)=19\equiv8$，$f(3)=28\equiv6$，$f(4)=39\equiv6$，$f(5)=52\equiv8$。

**用 3 个 share 还原**，取第 1、2、3 个人。在 0 处的 Lagrange coefficient：

$$\lambda_1=\frac{(0-2)(0-3)}{(1-2)(1-3)}=\frac62=3,\quad\lambda_2=\frac{(0-1)(0-3)}{(2-1)(2-3)}=\frac3{-1}=-3\equiv8,\quad\lambda_3=\frac{(0-1)(0-2)}{(3-1)(3-2)}=\frac22=1$$

$s=3\times1+8\times8+1\times6=73=6\times11+7$，得 7。

**少于 $t$ 个 share 毫无信息。** 只有第 1、2 个人的 $(1,1)$、$(2,8)$。对每个候选 secret $s'$，过 $(0,s')$、$(1,1)$、$(2,8)$ 的 degree 2 polynomial 恰好一个，比如 $s'=0$ 时 $f(x)=ax^2+bx$ 要 $a+b\equiv1$、$4a+2b\equiv8$，第二式减两倍第一式得 $2a\equiv6$，$a=3$、$b=9$；$s'=7$ 时就是真的 $x^2+4x+7$。11 个候选各对应一个 polynomial，而 dealer 是在 $11^2$ 个 degree 2 polynomial 里 uniform 地取的，所以看到这两个 share 后，11 个 secret 的 posterior 仍然各是 $\tfrac1{11}$。一般地，固定 $|U|<t$ 个点和 $f(0)$，满足条件的 degree $t-1$ polynomial 有 $p^{t-1-|U|}$ 个，与 $f(0)$ 无关。

:::wrong 拿到 $t-1$ 个 share 至少能把 secret 的范围缩小一点
上面的计数说明一点都缩小不了：两个 share 时 11 个 secret 每个恰好对应一个 polynomial，probability 完全相同。对比一个看起来也合理的方案：把 500 bit 的 secret 切成五段各 100 bit 分给五个人，拿到一段就知道 secret 的 100 bit，范围从 $2^{500}$ 缩到 $2^{400}$。Shamir 的 share 和 secret 一样长，却每一个单独看都是 uniform 的。
:::

Shamir 是 linear 的：两组 share 逐个相加，得到的是两个 secret 之和的 share，因为 $f+g$ 仍是 degree $t-1$，常数项是 $s_f+s_g$。这正是下面计算的基础。

### BGW：在 share 上算

$n$ 个 party，最多 $t$ 个勾结，每个 wire 的值都以 degree $t$ 的 Shamir share 存在（任意 $t+1$ 个人能还原）。

- **Input**：每个人把自己的 input share 给所有人。
- **加法 gate**：每个人本地把两个 share 相加。
- **乘以公开常数**：本地相乘。
- **乘法 gate**：本地相乘得到 $h(i)=f(i)g(i)$，$h=fg$ 的常数项正是 $ab$，但 degree 变成 $2t$。

::fig[cs4230-bgw] $n=3$、$t=1$，$a=3$、$b=4$，$g_a=3+2x$、$g_b=4+5x$。三个点的乘积恰好落在 degree 2 的 $h$ 上，$h(0)=12$。

在 $\mathbb{Z}_{11}$ 里：$g_a$ 的 share 是 $(5,7,9)$，$g_b$ 的是 $(9,3,8)$，本地乘积 $v=(45,21,72)\equiv(1,10,6)$。Degree $2t=2$ 要 3 个点才能还原，所以需要 $2t+1\le n$。如果不处理，再乘一次 degree 就变成 4，3 个人就还原不了了。

**Degree reduction。** 在 0 处对点 $1,2,3$ 的 Lagrange coefficient 是 $L=(3,8,1)$（和上面算的一样），$ab=h(0)=\sum_jL_jv_j=3+80+6=89\equiv1$，确实 $12\equiv1$。但不能直接把 $v_j$ 公开出来算。每个 party $j$ 把自己的 $v_j$ 再用一个 random 的 degree $t$ polynomial $r_j$ 分享出去，然后每个人 $i$ 本地算 $w_i=\sum_jL_j\,r_j(i)$。$w$ 是 $r=\sum_jL_jr_j$ 的 share，$r$ 的 degree 是 $t$，常数项是 $\sum_jL_jv_j=ab$。

| | 给 party 1 | 给 party 2 | 给 party 3 |
|---|---|---|---|
| $r_1(x)=1+x$ | 2 | 3 | 4 |
| $r_2(x)=10+5x$ | 4 | 9 | 3 |
| $r_3(x)=6+3x$ | 9 | 1 | 4 |
| $w_i=3r_1(i)+8r_2(i)+r_3(i)$ | 3 | 5 | 7 |

$w=(3,5,7)$ 在一条 line 上（每步加 2），往回推一步 $w(0)=3-2=1=ab$。Degree 回到了 1。

**$t\ge n/2$ 时不可能**（不借助任何 assumption）。两个人 $A$、$B$ 要算 $x_A\wedge x_B$，$t=1=n/2$。设 transcript 的 distribution 是 $\Pi(x_A,x_B)$。Correctness：$x_A=1$ 时输出就是 $x_B$，所以 $\Pi(1,0)$ 和 $\Pi(1,1)$ 的 support 不相交（否则同一个 transcript 对应两个不同的结果）。Security 对 $A$：$x_A=0$ 时输出永远是 0，$A$ 不该知道 $x_B$，所以 $\Pi(0,0)$ 和 $\Pi(0,1)$ 分布相同；对 $B$ 同理 $\Pi(0,0)$ 和 $\Pi(1,0)$ 相同。于是 $\Pi(0,1)=\Pi(1,0)$。

矛盾来自 transcript 的一个性质。取 $\tau$ 在 $\Pi(1,0)$ 的 support 里，它也在 $\Pi(0,1)$ 的 support 里：有 coin $r_A,r_B$ 使 $(x_A,x_B)=(1,0)$ 时产生 $\tau$，也有 $r_A',r_B'$ 使 $(0,1)$ 时产生 $\tau$。现在让 $A$ 用 $(1,r_A)$、$B$ 用 $(1,r_B')$ 运行。$A$ 的每条 message 只取决于它自己的 input、coin 和之前收到的 message，$B$ 也一样；对 message 的条数做 induction，每一步双方发出的都和 $\tau$ 里那一条相同，所以产生的仍是 $\tau$。于是 $\tau$ 在 $\Pi(1,1)$ 的 support 里，与“$\Pi(1,0)$ 和 $\Pi(1,1)$ 不相交”矛盾。（讲义把这最后一步留作作业，上面是我补的。）

结论是两个人之间的 AND 需要 computational assumption，这就是下一节的 OT。

### Oblivious transfer

Sender 有两个 bit $m_0,m_1$，receiver 有 choice bit $b$。Receiver 得到 $m_b$，对 $m_{1-b}$ 一无所知；sender 对 $b$ 一无所知。

**从 RSA 造。** Sender 公开 $(N,e)$，自己留 $d$。Receiver 对自己要的那一个知道 preimage，另一个是随手取的：

::fig[cs4230-ot] $N=35$、$e=5$、$d=29$，receiver 要 $m_1$。LSB 是最低位，当 hardcore bit 用。

逐步核对：$12^5\bmod35=17$；sender 算 $9^{29}\bmod35=4$、$17^{29}\bmod35=12$；$c_0=1\oplus0=1$，$c_1=0\oplus0=0$；receiver 用自己的 $x_1=12$ 得 $m_1=0\oplus0=0$。

- Sender 看到的 $(y_0,y_1)$：$y_1=x_1^e$，$x_1$ uniform 且 $x\mapsto x^e$ 是 permutation，所以 $y_1$ 也 uniform，和 $y_0$ 分布一样，看不出 $b$。
- Receiver 要知道 $m_0$ 就要 $\mathrm{hc}(y_0^d)$，而它不知道 $y_0$ 的 preimage，由 hardcore bit 的性质猜不出。

（这是 semi-honest 的 security：如果 receiver 故意两个都按 $x^e$ 生成，就能拿到两个。）

**用 OT 算 AND。** Alice 有 $x_A$，Bob 有 $x_B$。Alice 当 sender，$m_0=0$、$m_1=x_A$；Bob 当 receiver，$b=x_B$。$x_B=0$ 时 Bob 得到 0，$x_B=1$ 时得到 $x_A$，正好是 $x_A\wedge x_B$。

要算任意 circuit，GMW 让每根 wire 的值以 XOR share 的形式分在两人手里（$v=v_A\oplus v_B$）。XOR gate 本地做。AND gate 用 OT 得到 share 而不是结果：Alice 取 random $r$，以 $m_0=r$、$m_1=r\oplus a$ 做 OT，Bob 用 $b$ 选，得到 $s=r\oplus ab$；Alice 的 share 是 $r$，Bob 的是 $s$，$r\oplus s=ab$，各自单看都是 random。两人都有 share 时，$(a_A\oplus a_B)(b_A\oplus b_B)$ 展开成四项，两项本地算，交叉的两项各用一次这个 OT。

### Garbled circuit

:::skip
NUS AY25/26 的讲义没有这一节，2023 年的课在第 10 周讲。跳过会少掉“constant round 的两方计算”这一种做法。
:::

GMW 每一层 AND gate 要一轮交互。Yao 的 garbled circuit 只要常数轮：Alice 把整个 circuit“encrypt”好一次性交给 Bob，Bob 自己算。

每根 wire $w$ 有两个 random label $K_w^0,K_w^1$，Bob 握着 $K_w^v$ 就表示这根 wire 的值是 $v$，但 label 本身看不出 $v$。

::fig[cs4230-garble] 一个 AND gate 的 garbled table。每一行用一对输入 label 两层 encrypt 对应的输出 label，四行打乱顺序。

Alice 的 input 直接发对应的 label；Bob 的 input 的 label 通过 OT 拿（sender 的两个 message 是 $K^0,K^1$，choice 是 Bob 的 bit），Alice 不知道他拿了哪个。然后 Bob 逐个 gate 往下：手里每根输入 wire 恰有一个 label，四行里恰好一行打得开（encryption 的格式让他能识别哪一行解对了），得到输出 wire 的一个 label。最后 Alice 给出 output wire 的 label 与 bit 的对照表。

Bob 看到的一切：每根 wire 一个 random label，每张表一行打开、三行打不开。Simulator 只需要 $f(x,y)$：每个 gate 只 encrypt 一个 label，其余三行放 random string，最后的对照表把那个 label 对到 $f(x,y)$。由 encryption 的 CPA security，这和真的 garbled circuit 分不出来。

:::edge Share 不能发在 $x=0$
Shamir 的 share 是 $f(1),\dots,f(n)$，不能有 $f(0)$，那就是 secret。同样要 $p>n$，否则 $n$ 个 $x$ 坐标不能两两不同且都非零。
:::

## [zk] Zero-knowledge proof

:::skip
AY25/26 的 NUS 讲义没有这一站，2023 年的课在第 11 周讲，第 9 站提到的 GMW compiler 和第 7 站的 Naor–Yung 都要用它。能走一轮 QR protocol、写出 honest-verifier simulator、说清 3-coloring protocol 每轮的 soundness，就可以去第 11 站。
:::

### 让人相信一件事，却不交出 witness

Peggy 想让 Victor 相信“$y=23$ 是 mod 77 的 quadratic residue”。普通的 NP proof 是把 square root $w=10$ 交出来，Victor 检查 $10^2=100\equiv23$。可这样 Victor 也拿到了 $w$。第 6 站说过，mod $N$ 的 square root 和 factoring 一样难，$w$ 是有价值的。

**Interactive proof** 加两样东西：交互，以及 Victor 可以随机、允许以很小的 probability 出错。要求 completeness（$y$ 真是 QR 时诚实的 Peggy 能让 Victor 接受）和 soundness（$y$ 不是 QR 时，任何 Peggy 让 Victor 接受的 probability 都很小）。

### Quadratic residuosity 的 protocol

1. Peggy 随机取 $r\in\mathbb{Z}_N^*$，发 $s=r^2$；
2. Victor 随机发一个 bit $b$；
3. Peggy 回 $z=r\cdot w^b$；
4. Victor 检查 $z^2\equiv s\cdot y^b$。

::fig[cs4230-zkqr] 左边是真实的一轮，右边是 simulator。下一小节解释右边。

Completeness：$z^2=r^2w^{2b}=s\,y^b$。左边的数字：$r=4$，$s=16$；$b=1$，$z=4\times10=40$；$40^2=1600=20\times77+60$，$16\times23=368=4\times77+60$，相等。

**Soundness。** 设 Peggy 发出 $s$ 后，对 $b=0$ 和 $b=1$ 都答得出：$z_0^2=s$，$z_1^2=sy$。那么 $(z_1/z_0)^2=y$，$y$ 就是 QR。所以 $y$ 不是 QR 时，对每个 $s$ 最多答得出一个 $b$，Victor 随机挑，抓住她的 probability $\ge\tfrac12$。重复 $k$ 轮，作弊成功 $\le2^{-k}$。用左边的数字：同一个 $s=16$，$b=0$ 时答 $z_0=4$，$b=1$ 时答 $z_1=40$，$z_1/z_0=40\times4^{-1}\bmod77=10=w$。这个计算同时说明了 Peggy 必须真的知道 $w$。

### Zero knowledge 用 simulator 来 define

Victor 的 view 是 $(s,b,z)$ 加上他自己的 randomness。Zero knowledge 的意思是：这个 view 他自己就能造出来，不需要 Peggy。有一个 PPT 的 simulator，只拿 $y$ 不拿 $w$，输出的分布和真实的 view 相同。

**Simulator（honest verifier）**：倒着做。先随机取 $b$，再随机取 $z$，算 $s=z^2/y^b$，输出 $(s,b,z)$。右边的数字：$b=1$、$z=20$，$z^2=400=5\times77+15$，$s=15\times23^{-1}\bmod77=4$，检查 $4\times23=92\equiv15$。

两边分布为什么一样：真实的 view 里 $b$ 是 uniform 的 bit；$r$ 在 $\mathbb{Z}_N^*$ 里 uniform，$z=r\,w^b$ 是 $r$ 乘一个固定的 element，也 uniform；$s$ 由 $z$ 和 $b$ 唯一决定（$s=z^2/y^b$）。Simulator 的输出同样是 $b$ uniform、$z$ uniform、$s$ 由它们决定。两个分布完全相同，这叫 perfect zero knowledge。

Simulator 能做到而 Peggy 做不到的，是**先知道 $b$**。真实的 protocol 里 $s$ 必须在 $b$ 之前发出，这就是 soundness 的来源。

**Malicious verifier。** 作弊的 Victor 可能根据 $s$ 来选 $b$，simulator 没法事先知道 $b$。办法是 rewinding：simulator 猜一个 $b$ 造出 $s$，把 $s$ 喂给 Victor 的程序，看他选的 $b'$；$b'=b$ 就输出，否则倒回去重来。$s$ 的分布和 $b$ 无关（都是 uniform 的 QR），所以 Victor 猜不到 simulator 选了哪个，每次成功 probability ½，expected 2 次。

:::wrong Victor 被说服了，transcript 就是一份证据，可以转给别人看
Simulator 不用 $w$ 就能造出分布完全相同的 transcript，所以 transcript 不能说服任何第三方：Victor 拿给 Carol 看，Carol 无法区分它是真的交互还是 Victor 自己倒着算出来的。Victor 被说服，靠的是他亲眼看到 $s$ 在 $b$ 之前发出、$b$ 是他自己随机选的，这个时间顺序在 transcript 里看不出来。所以 zero-knowledge proof 是不可转让的，这正是“zero knowledge”的含义。
:::

### 所有 NP 语言都有 zero-knowledge proof

QR 有特殊的 algebra 结构。对任意 NP 语言，只要把它 reduce 到一个 NP-complete 问题，比如 3-coloring：一个 graph 能否把顶点涂成 3 种颜色，使每条 edge 两端不同色。

需要一个 **commitment**：把一个值锁进盒子交出去，以后可以打开。Hiding：盒子不泄露里面的值；binding：锁上之后不能打开成别的值。从 OWP $f$ 和 hardcore bit $h$ 造：commit $v$（一个 bit）就发 $(f(r),h(r)\oplus v)$，open 时公布 $r$。Hiding 来自 hardcore bit；binding 来自 $f$ 是 permutation，$f(r)$ 唯一决定 $r$。

**Protocol（每轮）**：Peggy 把她的 coloring $\chi$ 的三种颜色随机换一遍（随机 permutation $\rho$），对每个顶点的新颜色各做一个 commitment；Victor 随机挑一条 edge $(u,v)$；Peggy 打开这两个 commitment；Victor 检查两色不同。

::fig[cs4230-col3] 4 个顶点 5 条 edge 的 graph，走一轮。打开的两个颜色是 1 和 3，Victor 只知道“这条 edge 两端不同色”。

- Soundness：graph 不能 3-color 时，Peggy commit 的任何 coloring 都至少有一条 edge 两端同色，被挑中的 probability $\ge1/|E|$。重复 $k|E|$ 轮，作弊成功 $\le(1-1/|E|)^{k|E|}\le e^{-k}<2^{-k}$。$|E|=5$、$k=10$：$0.8^{50}\approx1.4\times10^{-5}$，比 $2^{-10}\approx9.8\times10^{-4}$ 还小。
- Zero knowledge：每轮 Victor 看到的是一条 edge 两端的两个不同颜色。因为每轮都重新随机换色，这两个颜色在 6 种有序的“两个不同颜色”里 uniform，和 coloring 无关。Simulator 先猜 Victor 会挑哪条 edge，给那两端 commit 两个随机的不同颜色、其余顶点随便 commit，猜错就 rewind；没打开的 commitment 由 hiding 保证和真的分不出。这是 computational zero knowledge（依赖 commitment 的 hiding）。

**为什么必须交互。** 设 3-coloring 有 non-interactive 的 zero-knowledge proof：Peggy 发一个 string，Victor 检查。Zero knowledge 说 simulator 只看 graph 就能造出 Victor 会接受的 string。那么对一个不能 3-color 的 graph 运行 simulator：simulator 和 Victor 都是 PPT，分不出 graph 能不能 3-color，所以它造出的 string 仍会被接受。Simulator 就成了一个能 prove 错误 statement 的 Peggy，与 soundness 矛盾。实际的 non-interactive 方案要么在 random oracle model 里用 Fiat–Shamir（把 Victor 的 random $b$ 换成 $H(s)$），要么假设双方共享一个可信的 random string。

:::from
QR protocol、soundness 的两个答案推出 square root、honest-verifier simulator、view 的 definition、perfect/statistical/computational 三种 zero knowledge 来自 [MIT 6.875 第 14 讲](https://mit6875.github.io/FA22SLIDES/lec14.pdf)；malicious verifier 的 rewinding、commitment 的 definition 与 OWP 构造、3-coloring protocol 与 $(1-1/|E|)^{k|E|}\le2^{-k}$、simulator 的 hybrid、“interaction 是必需的”的论证、Fiat–Shamir 与 common random string 两条路来自[第 15 讲](https://mit6875.github.io/FA22SLIDES/lec15.pdf)。Rahul Jain 的讲义没有这一讲，只在 MPC 里提到 zero-knowledge 用于 GMW compiler；这一站列在 [Prashant 2023 年课程页](https://www.comp.nus.edu.sg/~prashant/teaching/CS5430)的第 11 周。$N=77$ 的数字、4 顶点的 graph、“transcript 不可转让”的 wrong 是这一页补的。
:::

## [lwe] Lattice、LWE 与 homomorphic encryption

:::skip
能写出 LWE、用 $q=17$ 的例子做一次 Regev encryption 和 decryption、说出 correctness 要求 noise 小于 $q/4$，就读完这门课了。
:::

### 为什么还要另一种 assumption

第 5、6 站的 assumption 都是 discrete log 和 factoring。Shor 的 quantum algorithm 在 polynomial time 内解这两个问题，大型 quantum computer 一旦造出来，DH、ElGamal、RSA、Rabin 全部失效。Lattice 问题目前没有已知的 quantum 快速解法，最好的 classical algorithm 也接近 $2^n$。

### Lattice

$b_1,\dots,b_n\in\mathbb R^n$ linearly independent，它们的所有**整数**组合

$$L(B)=\Big\{\sum_ia_ib_i:\ a_i\in\mathbb Z\Big\}$$

叫 lattice，$B$ 是它的一组 basis。同一个 lattice 有无穷多组 basis。

::fig[cs4230-lattice] 同一组点的两组 basis。两边的点完全一样。

为什么是同一个 lattice：$(7,4)=2(3,1)+(1,2)$，$(11,7)=3(3,1)+2(1,2)$，系数 matrix $\begin{pmatrix}2&1\\3&2\end{pmatrix}$ 的 determinant 是 $4-3=1$，它的 inverse 也是整数 matrix，所以两组 basis 互相整数表示。也可以看 basis 的 determinant：$3\cdot2-1\cdot1=5$，$7\cdot7-4\cdot11=5$，相同。

两个基本问题。**SVP**：找最短的非零 lattice vector。**CVP**：给一个点 $t$，找离它最近的 lattice vector。好的 basis（短、接近 perpendicular）下两者都容易看出来；拿到坏的 basis，高维时都被认为很难，worst case 下对 quantum computer 也难。

### 加了 noise 的 linear equation

Crypto 里实际用的是 LWE，它和 lattice 的关系由 Regev prove（LWE 至少和某些 worst-case lattice 问题一样难），这门课不证。LWE 本身很好理解。

解 $As=b$ 很容易，Gaussian elimination。MIT 的讲法是两个改动各自不够、合起来才难：

- 只 mod $q$：Gaussian elimination mod $q$ 照样做；
- 只加 noise $b=As+e$（实数上）：least squares，就是 [DSA2102 第 4 站](../courses/DSA2102.html#ls)的那种；
- mod $q$ **且**加 small noise：被认为非常难。

**LWE。** $A\in\mathbb{Z}_q^{m\times n}$ uniform，$s\in\mathbb{Z}_q^n$，$e$ 的每个分量是 small 的（比如在 $[-B,B]$ 里），给 $(A,\ b=As+e\bmod q)$，求 $s$。parameter：$n$ 是 security parameter（几百到上万），$m$ 是 polynomial，$q$ 是比 $B$ 大的 polynomial。

小例子：$q=17$，$s=(3,5)$，四个 equation，noise $e=(1,-1,0,1)$：

| $a_i$ | $\langle a_i,s\rangle\bmod17$ | $e_i$ | $b_i$ |
|---|---|---|---|
| $(1,2)$ | $3+10=13$ | 1 | 14 |
| $(4,1)$ | $12+5=17\equiv0$ | −1 | 16 |
| $(6,11)$ | $18+55=73\equiv5$ | 0 | 5 |
| $(9,7)$ | $27+35=62\equiv11$ | 1 | 12 |

只看前两个 equation、当作没有 noise 去解 $s_1+2s_2\equiv14$、$4s_1+s_2\equiv16$，得到 $s=(5,13)$；代回后两个 equation，误差是 15 和 5（mod 17），远不是 small。Noise 被 elimination 放大了。暴力枚举所有 $17^2=289$ 个 $s$，只有 $(3,5)$ 让四个 equation 的误差都在 $\{-1,0,1\}$ 里。$n=2$ 时枚举容易，$n=500$ 时是 $17^{500}$。

:::wrong noise 小就用 least squares，把 mod $q$ 当成普通实数算，最后再 round
Mod $q$ 把 $\langle a_i,s\rangle$ 绕了若干圈，实数上的 linear 关系不再成立。对上面的四个 equation 在实数上做 least squares，得到 $s\approx(2.51,-0.89)$，round 成 $(3,-1)$，代回去 mod 17 的误差是 $(4,12,2,8)$，没有一个是 small 的。真正的 $s=(3,5)$ 给出的是 $(-1,1,0,-1)$。只有 noise 没有 mod，或只有 mod 没有 noise，才各有好办法。
:::

**Search 与 decision。** Decisional LWE（DLWE）：区分 $(A,As+e)$ 和 $(A,u)$，$u$ uniform。会 search 就会 decision：求出 $s$ 再用多出来的 equation 检查误差是否 small。反方向是讲义里的 search-to-decision reduction：要确定 $s$ 的第 $i$ 位，猜它是 $c$；随机取 $r$，把每个 $a_j$ 的第 $i$ 位加 $r$、$b_j$ 加 $rc$。猜对时新的 $b_j=\langle a_j',s\rangle+e_j$，还是 LWE；猜错时多出 $r(c-s_i)$，$r$ uniform 且 $c-s_i\ne0$（$q$ 是 prime），这一项 uniform，整个 $b'$ 变 uniform。用 DLWE 的 oracle 判断是哪种，就知道猜得对不对。每一位最多猜 $q$ 次，共 $nq$ 次 oracle，polynomial。

$g_A(s,e)=As+e$ 在 LWE 下是 OWF，在 DLWE 下是 PRG（input 是 $s$ 和 $e$，output 看起来 uniform）。

### Regev encryption

**Secret key 版本**（encrypt 一个 bit $m$）：$s$ uniform；$\mathsf{Enc}(m)$：取 uniform 的 $a$ 和 small 的 $e$，输出 $(a,\ b=\langle a,s\rangle+e+m\lfloor\tfrac{q+1}2\rfloor)$；$\mathsf{Dec}$：算 $b-\langle a,s\rangle=e+m\lfloor\tfrac{q+1}2\rfloor$，离 0 近就是 0，离 $q/2$ 近就是 1。$|e|<q/4$ 时一定判断对。Security：DLWE 下 $\langle a,s\rangle+e$ 像 uniform，当 one-time pad 用。

$q=17$ 时 1 编码成 $\lfloor18/2\rfloor=9$，分界是 $q/4=4.25$。encrypt 1，$a=(8,3)$，$e=-1$：$\langle a,s\rangle=24+15=39\equiv5$，$b=5-1+9=13$。decrypt $13-5=8$，离 9 只差 1，解出 1。

**Public key 版本。** 把很多个“0 的 encryption”公开出去：$pk=(A,\ b=As+e)$，就是上面那张表。encrypt bit $c$：随机取 $r\in\{0,1\}^m$（挑出一个 subset 的 equation 加起来），输出

$$u=r^\top A,\qquad v=r^\top b+c\lfloor\tfrac{q+1}2\rfloor$$

decrypt $v-\langle u,s\rangle=r^\top(As+e)-r^\top As+c\lfloor\tfrac{q+1}2\rfloor=r^\top e+c\lfloor\tfrac{q+1}2\rfloor$。Noise 变成 $r^\top e$，是挑中的那几个 $e_i$ 之和，$|r^\top e|<q/4$ 就解对。

::fig[cs4230-zq] $\mathbb{Z}_{17}$ 排成一圈，深色弧解成 0，粗黑弧解成 1。三个点是下面三次 decrypt 的 $v-\langle u,s\rangle$。

用表里的 $pk$，$r=(1,0,1,1)$：$u=(1+6+9,\ 2+11+7)=(16,20)\equiv(16,3)$，$r^\top b=14+5+12=31\equiv14$。

- encrypt 0：$v=14$。decrypt $\langle u,s\rangle=48+15=63\equiv12$，$14-12=2$，在 0 那一侧。$r^\top e=1+0+1=2$，对得上。
- encrypt 1：$v=14+9=23\equiv6$，$6-12=-6\equiv11$，离 9 只差 2，解出 1。
- 如果 noise 太大，比如 $e=(4,-3,2,3)$（$b$ 变成 $(0,14,7,14)$），同一个 $r$ 下 $r^\top e=4+2+3=9$，encrypt 0 得到 9，超过 4.25，错解成 1。

Security：DLWE 说 $(A,b)$ 看起来像 $(A,u)$；而对真 uniform 的 $(A,u)$，leftover hash lemma 说 $(r^\top A,r^\top u)$ 在 $m$ 足够大时接近 uniform。所以 $v$ 里的 $r^\top b$ 像一个 one-time pad，盖住了 $c$。

### Homomorphic：在 ciphertext 上算

两个 secret-key ciphertext 相加：$(a+a',\ b+b')$，decrypt 得 $(e+e')+(m+m')\lfloor\tfrac{q+1}2\rfloor$，正是 $m\oplus m'$ 的 encryption（$m=m'=1$ 时 $2\times9=18\equiv1$，接近 0），noise 变成 $e+e'$。

数字：$c_1=((8,3),13)$ encrypt 1（$e=-1$），$c_2=((5,9),2)$ encrypt 1（$\langle(5,9),s\rangle=15+45=60\equiv9$，$e=+1$，$b=9+1+9=19\equiv2$）。相加 $((13,12),15)$，$\langle(13,12),s\rangle=39+60=99\equiv14$，$15-14=1$，解出 0，确实 $1\oplus1=0$。

每加一次 noise 最多加 $B$：$k$ 个 noise $\le B$ 的 ciphertext 相加，noise $\le kB$，要 $kB<q/4$。$q=17$、$B=1$ 时最多加 4 个。$q$ 取得大，就能做更多次加法。

XOR 和 AND 能拼出任何 circuit，所以只要还能在 ciphertext 上做乘法（AND），就能在不 decrypt 的情况下算任意 function，这叫 fully homomorphic encryption（FHE）。第一个 FHE 是 Gentry 2009 年的构造。乘法会让 noise 增长得快得多，怎样控制它是 FHE 的核心问题，NUS 讲义到此为止，这一页也不往下写。第 6 站的 Goldwasser–Micali 只能做 XOR，ElGamal 只能做乘法，lattice 是第一个两种都能做的。

:::back
LWE 的 security 用的 one-time pad 论证是[第 1 站](#otp)的；“$(A,b)$ 像 uniform”就是[第 2 站](#prg)的 PRG；加法 homomorphism 和[第 6 站](#tdp)的 Goldwasser–Micali 是同一种性质。
:::
